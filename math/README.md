## Status and interpretation

Historical files preserve their original mathematical claims and dates. Their claims may have been narrowed, disproved or superseded. Consult the current status register and scoped review statements before treating a historical headline as accepted. Catalogue rows, source files, fusions and versions are not independent discovery counts.

Mathematical correctness, novelty, exact model assumptions, constructive existence, numerical implementation and measured speed are separate questions. In particular, a restricted-family Fourier result or a bank-count theorem is not an unrestricted FFT complexity breakthrough. The accepted checkpoint does not assert that all 178 proofs were independently audited.

## Reproduction and integrity

Original numeric arrays and compressed numeric certificates are included as inert data; they are not runnable executable files. No supplied research program was executed, imported or compiled during this publication preparation. Recorded historical test results are preserved with their source status; the repository export did not rerun every experiment. Newly authored controls are identified within their packages. Review and run any code only in an appropriate isolated environment.

Original source hashes identify the evidence before publication cleanup. Export hashes identify the actual bytes here. Files with private-link/path or metadata cleanup can differ from their source; redacted code has not been revalidated and may require local path repair. Historical internal manifests refer to their original packages. The top-level [SHA256SUMS](SHA256SUMS) and export manifests are authoritative for this tree.

No blanket redistribution license is assigned by this export. Public scholarly references remain cited. Third-party papers and separately identified upstream code were omitted where redistribution/attribution packaging was not established.
