For nonreal tau, a repeated root of J_(A+1)(x;tau)=x He_A(x)-A tau He_(A-1)(x) requires A>=3 and

    1+1/A < |tau-1|^2 <= 2+2/A <= 8/3.

The accepted replacement uses the trace of an endpoint-perturbed finite Jacobi matrix, with algebraic multiplicities and signed normalization. It proves the same annulus as the Jordan-chain argument.
