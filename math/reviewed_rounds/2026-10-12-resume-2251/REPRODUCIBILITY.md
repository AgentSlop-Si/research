# Scope and replay guide

This package separates the frozen numerical-priority baseline, later scoped status updates, newly checked mathematics, and inert submitted source archives. Read README.md and EFFECTIVE_STATUS_DELTA.json before interpreting a dated status string in a baseline row.

## Portable verification entrypoints

Use Python 3 in a fresh copy of the package, since checker programs write their result files beside themselves. The scientific checkers use the Python standard library; do not execute the submitted source archives as part of this replay.

- Ranking: run `python ranking/verify_rankings.py`. To reconstruct the current 327-record outputs from the exact included scientific snapshot, run `node ranking/build_ranking.mjs --output replay_ranking_output` in a fresh copy (Node.js is required for that builder). This reconstructs every numeric score from the explicit published dimension scores, weights and caps and checks the canonical/novelty identity coverage. It does not independently establish the human-assigned dimensions or audit every underlying theorem.
- b27 overlap: run `python b27_independent_interval_review.py`, then `python b27_independent_finite_A_review.py`. The first needs the included `b27_interval_certificates.json`; the second is self-contained. The outputs may be compared byte-for-byte with the retained review JSON. The two d57 candidate certificate files are included because the frozen reviewer manifest pins them; the independent prime-229 proof is the accepted finite-A route.
- Qtorus: run `python intake_qtorus_independent_check.py` and `python review_qtorus_frontier.py`. Both are newly authored reviewer programs and write results relative to their own file locations. Finite controls support the accompanying symbolic proof; they do not alone prove a statement for every size.
- PR622 profile comparison: run `python pr622_moment_comparison_check.py sources/FFT_PR622_Repacking_Candidate_2026-10-13.zip sources/PR623_pinned_EXPECTED.json sources/PR624_pinned_EXPECTED.json`. This reads only selected JSON members and pinned primary data; it does not deserialize the pickle or run archive programs.
- Q2 guard: run `python q2_guard_check.py`. It is an independently reconstructed bounded control for the specific solver-guard correction, not a replay or validation of the entire supplied Q2 implementation.
- CHIRP rank-two gate: run `python chirp_rank2_fresh_check.py` and `python chirp_rank2_independent_check.py`. They test mathematical design controls only; the metered executor, its interruption ledger and implementation acceptance remain open.
- PREFIX: run `python prefix_p13/controls.py`. It invokes the included fresh finite checker for the p11,r13 calibration and p13,r17 candidate in a new temporary directory. It compares semantic outputs while excluding measured elapsed time. Run `python prefix_p13/independent_review.py` for the separately reconstructed graph and actual permutation-group/bitset witness checks; its inherited premises and finite scope are recorded in INDEPENDENT_REVIEW.md.

No installation of third-party packages is required by these listed Python entrypoints. The repository's historical mathematical programs and submitted archive programs are inert inputs, not trusted executables run by this cycle.
