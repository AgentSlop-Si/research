# Reproducing the bounded comparison controls

This packet contains original comparison and review prose, source locators, source-receipt identities, and small independently authored algebra checks. It does not redistribute third-party papers or their extracted text. Read the linked originals to inspect the cited theorem statements and proofs.

## Package integrity

From this directory, run:

    python -I -S verify_package.py

The verifier uses only the Python standard library. It checks each payload file against FILE_MANIFEST.json, checks the manifest and payload against SHA256SUMS, rejects duplicate or unexpected entries, and rejects symlinks or escaping paths. SHA256SUMS cannot hash itself. The separate delivery seal binds its bytes and the archive.

## ALG060 algebra controls

From this directory, run:

    python -I -S checks/alg060/check_comparisons.py

The checker uses exact fractions and modular arithmetic. It checks nine dense quasiseparable examples, nine cyclic Green examples, five fixed-line permutation examples, seven Fourier displacement and dense-endpoint examples, nine conditional sparse-summand lifts, and one explicit two-way cut-kernel map. It rewrites only checks/alg060/CONTROL_RESULTS.json. The generated bytes should match the included result and the publication manifest. Run the package verifier again afterward.

The finite-field examples check the displayed algebraic identities. They do not transfer a characteristic-zero uncertainty theorem to finite fields. Finite controls corroborate the elementary comparisons; they do not prove arbitrary-size theorems by enumeration.

## Scope of reproduction

The original ALG037 proof, ALG041 constrained-packet proof, and ALG060 restricted grammar theorem are retained prior results. This packaging pass does not rerun historical source implementations, manufacture production evidence, or establish a faster Fourier algorithm. The report and review identify exactly which prior source bytes and primary theorem passages were read.

Hash identities are typed. A hash of a rendered passage, indexed result, or access-failure receipt is not a hash of a publisher PDF. Full PDF bytes were not recovered for the blocked Mathé and Helmke–Fuhrmann sources. Hashes identify the retained evidence but do not by themselves establish the truth of a mathematical claim, a redistribution license, or historical priority.

Original reports retain their original artifact names and local verification references. Live-read payloads, exact-cell before/after proposals, raw service responses, full papers, and scratch materials mentioned there are not included or promised as downloadable files. The publication map explicitly lists the included files and transformations.

No repository or workbook write is performed by these scripts. Any record-status or dashboard change requires its own actual write and post-write verification; acceptance of a proposal is not proof of application.
