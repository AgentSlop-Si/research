# Public-copy portability, provenance and evidence

Original final reviews apply to the original inspected bytes at their stated scopes and with all mandatory errata. This package performs privacy/provenance adaptations only. All production implementation files are byte-exact. No scientific program, historical source or adapted checker was executed during packaging. AST/JSON parsing, exact file hashes and privacy scans are packaging checks only.

Raw native-register cells and their direct source fingerprints, private filesystem locations, internal task identifiers, Library identifiers, private conversation links, transfer helpers, caches and whole source archives are excluded. Original paths, full author source manifests and unadapted bytes of every modified copy are retained privately. Safe original review manifests are included as ORIGINAL_REVIEW_MANIFEST.json so original seal hashes can be checked. COPY_BINDINGS.json exposes only public paths, byte counts, hashes and explicit adaptation descriptions.

Public local manifests are recomputed for the selected public files. Original review reports and recorded process/results may retain original manifest or source-body hashes as historical evidence. Those are not assertions that a privacy-adapted public file is byte-identical. Each ORIGINAL_REVIEW_SEAL.json binds the accompanying ORIGINAL_REVIEW_MANIFEST.json, not the recomputed public local manifest. Original review member hashes describe reviewed pre-adaptation bytes; COPY_BINDINGS.json maps those to public copies. The root manifest and exact allowlist bind this package.

The Fourier public proof has one attribution-only locator removal. Its formulas and scientific text are unchanged. The wrapper and shared scientific manuscripts are byte-exact; their required companion errata supersede only the specified cost/explanation claims.

Five exact cited adaptive source members and two exact R30 proof/report excerpts are inert evidence. They are not a complete historical program or a request to run it. The adaptive antecedent documents are the prior privacy-adapted public copies. Original and public document hashes remain separately recorded. Full archives remain private.

## Reproduction

- Preserve the folder layout and run checks from each script’s own directory, preferably in a disposable copy so recorded results are not overwritten. Read the complete code before execution.
- Python 3.12 and the standard library suffice for production. Some bucket author/reviewer diagnostics additionally require mpmath. This package installs nothing.
- Candidate launchers and review launchers retain their finite caps. Scripts without launchers retain the original declared bounded test workload; host/process restrictions are the caller’s responsibility.
- The scalar and wrapper portable reviewers bind the recomputed public manifests, not the withheld full original manifests. Their numerical/structural tests are unchanged.
- Fourier source provenance is read from SOURCE_PROVENANCE.json rather than rehashing the withheld archive. Its retained archive digest is historical evidence only.
- The adaptive portable control checks exact included source members and privacy-adapted antecedent copies instead of reopening the private archive. All numerical controls remain unchanged.
- No rerun of a portable checker is implied by including it. Original completed-run results remain the evidence reviewed here.
