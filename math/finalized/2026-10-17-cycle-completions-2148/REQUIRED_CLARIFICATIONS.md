# Mandatory interpretation and publication companions

These three clarifications are acceptance conditions, not optional commentary. The manuscripts are preserved rather than silently rewritten. Read the full linked errata alongside their original claims.

## Outer-wrapper cost and retained storage

[Full mandatory erratum](q16_wrapper/review/ERRATUM.md), bound to original PROOF.md SHA-256 651d2c5f443a8aede073ef2ef3a536331728352ddc65fc4ec199524db4444b08 and original candidate manifest f14e4bbd92c98063902e262ce699bfa58c6ba4333562bbbe683deb97714dff8f.

The unrestricted amplitude-width-only producer bound is not accepted. General event cost must include address widths, row counts, prior cumulative-counter widths and extra validation work. Retained original rows, producer records and sorting workspace are additional to the wrapper endpoint table. Receipt snapshots, retained incidence lists and serialization add caller/harness costs. The bounded R=3, S=4, m=57 fixture remains accepted with these qualifications.

## Fourier §7.1 representation and evaluator

The support argument concerns an exact product of N×N maps on the same coordinates, with invertible monomial boundaries and no hidden embedding or packing. Runtime values may be zero. The 4ND real-addition count charges the specified literal sequential evaluator, not all evaluators, shared computations or representations. Exact Fourier-root boundaries must be represented and paid for; the formal identity does not extend the implemented Gaussian-dyadic evaluator automatically.

## Shared dispatcher §§4–5 threshold and global metadata

[Full mandatory erratum](shared_adaptive/review/ERRATUM.md), with its exact reviewed manuscript/source hashes.

The fixed 1024-bit base-case threshold does not imply that content extraction always reaches the base case as n grows. The surviving normalized core can have O(log n) bits. The recognized-family linear result instead uses its bounded-support structure and the general upper bound on that logarithmic-size core, together with all dense-input/output, certificate and bookkeeping work. Root-wide counters, retained logs and cache indices also require root-size bookkeeping, rather than a child-local constant-time charge. The full erratum supplies the exponent-margin argument absorbing the resulting fixed polynomial logarithmic factor. The unrestricted fallback upper bound is unchanged.
