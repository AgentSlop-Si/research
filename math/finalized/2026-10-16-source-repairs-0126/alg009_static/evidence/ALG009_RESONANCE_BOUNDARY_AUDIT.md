## 2. Exact resonance theorem

Let F be a field, let omega have exact order N, and take 1<=delta<N and alpha!=0. Let g=gcd(N,delta) and m=N/g. The group homomorphism

    k mod N -> omega^(delta*k)

has kernel size g and image the cyclic subgroup generated by omega^delta, of order m. Its image is exactly the set of m-th roots of unity in F: it contains m distinct such roots, and a degree-m polynomial has no additional roots. Therefore

    1-alpha*omega^(delta*k)=0

has a solution iff alpha^m=1, and, if it has one, it has exactly g solutions. Consequently the pole count is

    rho = g if alpha^m=1, otherwise 0.

Equivalently, I-alpha*S^delta is nonsingular iff alpha^m!=1. Its g permutation cycles each have length m, so its determinant is (1-alpha^m)^g. At resonance its kernel has dimension g. These statements agree with Fourier diagonalization. Exact-order roots imply the characteristic does not divide N, so the Fourier matrix is invertible.

The source test alpha^N=1 is sufficient for resonance only when g=1. For g>1 it tests membership in the larger group of N-th roots. Since m divides N, true resonance always triggers the old rejection, but the converse fails. For each fixed noncoprime delta over a field containing all N-th roots, precisely N-m nonzero alpha values are falsely rejected by this predicate. There are no guard-induced false acceptances relative to the at-most-one-pole policy.

A nonzero alpha with alpha^N!=1 is always nonresonant. If g=1, there is either no pole or exactly one, and the current decoder computes that one Fourier value directly. Thus changing only the admission predicate as above restores the exact zero/one-pole boundary. The existing `count_resonant_binomial` in the same source already implements the correct general ratio test for b*I-a*S^delta, b!=0: use (a/b)^m=1.

True resonance is not itself an invalid input or a proof that the transform cannot be computed. It means h=(I-alpha*S^delta)r does not determine the g missing Fourier coordinates. Those coordinates require additional information, which the full input supplies. The declared decoder can evaluate them by direct dots at O(N*rho) cost. For rho growing with N this is outside the stated O(N) single-pole fast branch; declining is conservative and appropriate to that policy. Extending to a different repair algorithm or a fixed larger pole budget is separate work.

## 5. Why this is safe over-rejection rather than wrong accepted output

After the guard, the source scans all N coordinates of h and accepts only one or two nonzero defects. The Fourier identity

    Fh[k]=(1-alpha*omega^(delta*k))*Fr[k]

then holds at every frequency. Nonzero denominators are divided exactly; each zero denominator is evaluated from r directly. Under the old guard an admitted noncoprime candidate is nonresonant, and an admitted coprime candidate has at most one pole. Hence this guard error removes some valid fast-path opportunities but does not create an incorrect accepted Fourier output.
