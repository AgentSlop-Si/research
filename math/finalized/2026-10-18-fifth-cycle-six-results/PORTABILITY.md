# Original acceptance identities and public portability

All six candidate reports, complete scientific proofs, exact target systems, sources, checkers, required data, final reviews, failure logs and scientific source history are retained. No fourth-cycle scientific payload was copied wholesale. The corrected Weil ZIP and every nested predecessor ZIP are byte-identical; packaging treated them as data and recursively inspected members without importing or executing any archived program.

COPY_BINDINGS.json records the original and public hash and byte length of every copied file. Current route manifests bind current copies where source-locator or documentary adaptations require it. Exact original manifest/deliverable inventories are retained in provenance/original_integrity/. Original review verdicts and historical receipts still describe the accepted original bytes. FINAL_ACCEPTANCES.json gives original scientific identities separately from current public report identities. Current public integrity is established by the root manifest/verifier; a historical embedded hash is never silently reinterpreted as a new public hash.

Only source lookup locations change in executable code. The small path-only changes are listed literally in SOURCE_BINDINGS.json and COPY_BINDINGS.json. The weighted reviewer gets a separately retained exact controlling-source copy. The Weil record reviewer reads relocated source files but checks historical mount commands against their original recorded static-source paths. Its recorded execution commands remain unchanged. The downloaded corrected package core, tests, verifier, result builder and driver remain byte-identical.

Private Google Sheets URLs are removed. The multi-task selection plan is replaced by a clearly labelled excerpt preserving exactly its relevant ALG-070 section, with original whole-file length/hash. The native bit-reversal source response is a labelled scientific-history projection retaining all nonempty scientific field text in original order; its original native wrapper is not published. Current source pins are updated where necessary while original identities remain recorded. These changes are documentary and do not strengthen the scientific acceptances. Python caches are omitted with hashes. Nothing is silently represented as the omitted original.

Historical run commands retain their synthetic workspace or temporary paths as evidence. Those paths are not promises of files on a reader's machine. Public checkers use relative source paths where needed; fresh execution belongs in an isolated disposable copy. The launcher may require installed bwrap, timeout and prlimit with permissions matching its recorded environment; preservation of the script is not a claim that those capabilities exist elsewhere.

Original source-history manifests inside the corrected Weil archive and its historical_outputs refer to their historical layouts. The current package retains that layout and those bytes, but these older manifests are not recursively asserted to be current top-level manifests. Every archived member is separately covered by the inert archive audit. Earlier unavailable API/review bytes are not invented or replaced with a summary claimed to be original evidence.
