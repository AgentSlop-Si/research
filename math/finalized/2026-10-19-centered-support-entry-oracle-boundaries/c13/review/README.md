# C13 independent scoped review

Read REVIEW.md and DISPOSITION.json for the accepted frozen scope and retained owner gates. OPTIONAL_STRENGTHENING.md is explicitly outside that acceptance scope.

Run python3 -B -I independent_check.py, or use --candidate /path/to/candidate. The fresh checker verifies the frozen adapter hash before import. The default also verifies every archival file in the original candidate manifest. --adapter-only runs all mathematical controls without requiring administrative source snapshots and records that archival seal checking was skipped.

The replay/ directory contains exact copies of the current candidate adapter/checker/example, plus the reproduced result. Historical programs were not executed. SOURCE_HASHES.json preserves the original candidate seal and all source hashes. No external read or write was performed for this review.

All-size conclusions depend on the written elementary proof, not finite test counts. This is not a Fourier lower bound, all-length construction, whole-owner closure, or priority assessment.
