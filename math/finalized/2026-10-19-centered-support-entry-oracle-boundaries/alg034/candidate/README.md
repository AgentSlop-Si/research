# Centered sparse-output capacity obstruction

Run:

    python check_obstruction.py
    python verify_packet.py

Read REPORT.md, then PROOF.md. The result is a counterexample to extending the accepted bounded-variation O(M^(1/4)) candidate budget to arbitrary dyadic originals under the same centered-target tolerance. It is not a lower bound on Fourier algorithms generally, an efficient heavy-coordinate recovery method, or closure of ALG-034.

The accepted BV source is copied without modification. Recognition-only cap overrides in the checks are explicitly diagnostic and do not claim a larger successful provider. All proof/experiment artifacts are local; independent review remains pending.
