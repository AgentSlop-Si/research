# Portability and preservation

The public root is self-contained for package integrity verification. The verifier uses Python's standard library, never imports candidate or reviewer programs, and never executes scientific computations.

All exact proofs, certificate data, output logs and resource blockers are preserved byte-for-byte unless COPY_BINDINGS.json explicitly identifies a documentary privacy adaptation. Source-plan copies are scoped scientific projections with original full-file hashes. Private register locators and native workflow annotations are omitted. No private register export, credentials or account data are included. The original full selection plan is not supplied; its digest identifies the historical source without publishing unrelated selection material.

Some reviewer source lookups and historical exploratory output paths originally used absolute synthetic workspace directories. Explicit substitutions bind them to this public layout. Original and public code hashes and literal substitutions are retained. Metadata/source binding updates distinguish original identities from public derivatives. Their scientific arithmetic and control flow are unchanged. Original source-identity checks establish historical provenance; a public replay validates the packaged source copy, not unavailable private/original locations.

Exact original integrity receipts remain under provenance/original_integrity/. Current route inventories are rebound only to public descendants; other historical receipts and recorded execution paths remain historical. COPY_BINDINGS.json and FINAL_ACCEPTANCES.json keep these roles distinct. Review receipts may retain original hashes in documentary fields even where a route's current manifest is different.

Compiled executables and interpreter caches are omitted as disposable build products, with hashes recorded in OMISSIONS.json. Fresh C++ source/header and every recorded certificate/log remain. The original sixteen-point tar.gz is retained inert and audited member-by-member; it contains its historical source bindings. No archive is extracted or executed by the package verifier.

To rerun science, first make a separate writable copy. Several supplied programs overwrite their result files. Dependency versions and exact historical commands remain in each report or provenance file. A rerun produces a new attestation; do not replace this frozen packet or call the existing logs new execution evidence.
