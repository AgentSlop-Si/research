# Verification and scientific replay

## Safe package check

From any directory, run `python /path/to/public/verify_package.py`. This checks the exact allowlist, all package sizes/hashes, frozen acceptance identity, original/public copy bindings, current inventories, archive-member safety, Python syntax and privacy-pattern screening. It does not execute or import scientific programs. The local packaging record also tests a relocated copy using only this verifier.
