# Preservation, privacy and portability

## Publication boundary

Only files in PRESERVATION_ALLOWLIST.json are eligible. Excluded material includes compiled executables, bytecode/cache directories, redundant candidate working snapshots, duplicated full reproduction trees, raw private register snapshots and private spreadsheet links. No Library identifiers, internal note locators or private workspace paths are included. Complete mathematical proofs, exact outputs, certificates, controls, final reviews and needed source code are retained.

Two raw research-register snapshots are replaced by explicit omission stubs carrying their original lengths and hashes. Three private spreadsheet URLs in the inherited ALG-070 report are redacted; its mathematical text and public source credits remain. Its original source Git blob and SHA-256 are preserved in historical records and copy bindings, while the portable checker binds the redacted public source's blob.

## Code and metadata changes

All changes are enumerated in COPY_BINDINGS.json. They are input-location and source/public-byte-integrity adaptations only. Mathematical operations, algorithms, finite test domains, seeds, coefficients, assertions of mathematical identities and numerical certificates are not changed.

- Reviewers read the single sibling candidate copy instead of redundant candidate_snapshot/reviewed_candidate trees.
- The Mersenne source-binding utility resolves inherited files relative to its own directory; all five pinned source reports are included.
- Rank-two code resolves its four accepted dependencies relative to the candidate directory; the independent reviewer resolves those same source metadata paths against that candidate directory.
- Centered and sparse reviewers resolve retained source paths relative to the sibling candidate. Checks against separate original local source locations become checks against the corresponding retained public source copy. This reproduction binding is not a fresh independent attestation of the historical local source; the unchanged original review receipts document the historical comparison.
- Centered review's expected candidate-manifest hash is rebound to the public-copy manifest after source metadata path adaptation. The five runtime programs, adapter, exact input/output and numerical checks remain byte-identical.
- The ALG-070 candidate checker binds the public redacted documentary source blob. Its mathematical checks are unchanged. The original blob remains identified in source provenance and historical results.

Public candidate/review manifests and relevant seal hash fields are rebound after the disclosed adaptations and labelled as public-copy integrity. Historical result hashes, original input-manifest copies and final review verdicts retain their original scientific meaning; no historical execution is claimed on later public-copy bytes. The root public manifest independently binds every included byte.

## Reproduction data

Centered reviewer prose refers historically to its candidate snapshot and full reproduction folder. The public package retains a single complete candidate, both independent checker implementations, full independent interval evidence, exact rerun comparison and rerun stdout/stderr/exit receipts. Duplicate complete candidate/reproduction trees are omitted. Degree-seventeen's historical snapshot-preparation utility is omitted, while its inert certificate, arithmetic reviewer, cold replay and full source-binding receipts remain.

Scientific commands write new receipts; run them in a disposable copy. Expected result hashes may differ for intentionally rebound source metadata, public source hashes, timings and absolute output locations. Such a run is new evidence, never the original retained review. The package verifier checks paths, exact bytes, Python syntax and disclosed source bindings without importing or executing any scientific program.
