# Native final-only product interface

Read candidate/REPORT.md for the full proof and retained controls, and review/ for the independent final assessment. The root FINAL_ACCEPTANCES.json, when present, identifies the original accepted bytes. Read ../REQUIRED_CLARIFICATIONS.md before quoting the outcome. Historical pending candidate labels do not replace the final review.

Mandatory storage correction: general non-backend storage is O(L(H+t+g)), g=ceil(log2 L), plus backend workspace. The intended H=2m+g product specialization retains O(LH) when t<=H. The frozen candidate is qualified by review/REVIEW.md.
