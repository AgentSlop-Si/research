Run `python verify_package.py` from this public root. It checks the exact file boundary, root and route integrity, copy/source bindings, required exact certificates, Python syntax, privacy-locator hygiene and final acceptance gates. It imports no scientific program, performs no scientific rerun, accesses no network and makes no external write.

For scientific execution, first copy the entire packet to a disposable directory and read each full report and final review.
