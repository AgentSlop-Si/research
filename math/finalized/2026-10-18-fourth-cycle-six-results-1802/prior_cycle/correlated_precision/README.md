# Correlated products and guard precision

Ordinary integer-point interpolation needs exactly v2((2L−2)!) guard bits for arbitrary degree-at-most-(2L−2) integer polynomials; this is sufficient for the product service, with canonical-factor sharpness proved here only for sufficiently large H. The original candidate README is preserved; its shorter exact-canonical-product wording is superseded by this notice and the review. H=1,L=4 has guard 3<Gamma(6)=4. Fixed-precision bilinear rank and bounded-Taylor-image guard optimality are distinct questions.
