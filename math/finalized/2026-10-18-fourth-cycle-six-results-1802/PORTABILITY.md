# Portability, original identities and preservation

All complete proofs and final reviews are retained. Canonical literal/minor/parity/witness certificates, exact scientific result payloads, C++ arithmetic source and headers remain byte-identical. Python source is retained except for individually disclosed source-locator adaptations. No scientific logic is deliberately modified. COPY_BINDINGS.json records every original/public hash and size, identity status and adaptation. PACKAGING_CHECKS.json lists each changed Python file and all required exact payloads.

The complete preceding public release is retained byte for byte under prior_cycle/, with its original verifier, manifests, acceptance gates, correction and original/public source-normalization disclosures. The current result summaries supersede only the specifically improved mathematical bounds; they do not erase earlier qualifications.

Current route MANIFEST.json and SHA256SUMS files bind public copies. ORIGINAL_MANIFEST.json and ORIGINAL_SHA256SUMS retain supplied original integrity evidence, subject only to disclosed documentary-locator sanitization if needed. Historical run outputs, source hash snapshots, accepted verdicts and cold replay receipts continue to describe their original scientific runs. Their embedded hashes must not be misrepresented as hashes of modified public documentary files. FINAL_ACCEPTANCES.json records the original scientific gate separately from current public report hashes.

Source pin metadata is rebound to current-public dependency copies and preserves original source hashes for changed documentary bytes. Historical source-rebuild and snapshot-preparation audits can refer to original, pre-publication documentary identities or omitted historical trees. They are provenance tools rather than promised drop-in public replay entry points. The root verifier establishes current public integrity without reconstructing private local paths. All fresh scientific execution should occur in an isolated disposable copy and should write a new receipt.

One raw private research-register snapshot is replaced by an explicit original-size/SHA256 stub with only the already-public owner projection needed by its metadata control. Preceding-cycle stubs remain intact. Private source locations and register links are removed or replaced by relative retained locations; labelled retained-source-history and temporary-replay-location references are historical, not promised files. Complete scientific content is never replaced by a summary stub.

Compiled binaries, caches and redundant reviewer candidate snapshots are excluded with hashes. The sixteen-point candidate uses exactly its author's canonical manifest; noncanonical exploratory files and its redundant compressed archive are excluded with original hashes and reasons. The 30 canonical parity trace payloads are retained individually, as are their generator, verifier, proof and original run results. The exact publication boundary is PRESERVATION_ALLOWLIST.json, never this directory's parent.
