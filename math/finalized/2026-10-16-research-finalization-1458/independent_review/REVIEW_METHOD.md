# Independent review method

16 October 2026. Baseline: AgentSlop-Si/research at `35d9dcdc3f3869de75b33b2b09705222e8d09e8d`, with 85 closed and 242 open activity views (327 total). The pinned index was retrieved independently; its Git blob is `19971f78be002abe2d4f19a190aa4053ce8bf619`.

This review checks complete owning scopes, current gates, exact proof hypotheses, source bytes, arithmetic versus bit/physical costs, and what any proposed status change actually closes. A source comparison is not a novelty certificate. A finite control is not a universal proof. A completed child does not automatically complete its owner.

An administrative archive may retire an exhausted current activity while preserving an unproved broader question. It must not say that unfinished mathematics, engineering, or historical attribution is complete. Reopening conditions and retained limitations must be explicit.

Historical programs and worker-supplied checkers are inspected only as text; none are imported or executed in this review. Any independently authored checks, if used, are separately identified. Source files are retrieved through read-only GitHub operations and compared as exact bytes. No external writes are performed by this reviewer.

Scientific acceptance is separate from application acceptance. Exact native preimages, metadata preservation, derivative reconstruction, Git allowlists and independent terminal readback must be checked before accepting publication.
