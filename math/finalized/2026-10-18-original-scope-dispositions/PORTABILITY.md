# Portability and preservation

The public tree is self-contained for integrity verification. verify_package.py uses only the Python standard library. It does not import or execute candidate science, source builders, or review programs. No symlinks, archives, binaries, source-paper images, or interpreter caches are included.

COPY_BINDINGS.json distinguishes exact copies, privacy-only projections, and exact source-body extractions. Harper's source URLs are replaced with nonlocating native-register references; every mathematical field in its 19-clause JSON matrix remains unchanged. Spreadsheet identifiers are withheld. Transformations record original token hashes, replacement text, and full original/public file hashes. The private original locators are intentionally not reconstructible from the public packet alone.

The finite-chirp accepted classification and audit are exact UTF-8 bodies extracted from connector JSON, retaining their established content hashes. Its public source binding points to these .md bodies. That path adaptation is documentary; no scientific formula or control flow changed. It is reversible to the original paths using the two recorded substitutions, while original wrappers remain omitted.

Historical source manifests and reviewer references retain original hashes, original omitted-file names, and original evidence meanings. They are not current public-tree manifests. References to native receipts mean privately reviewed source evidence; those receipts are unavailable in the public tree. Existing statements that a pass performed no external writes apply to that historical pass; the packet itself does not attest later application.

Only the exact PRESERVATION_ALLOWLIST paths may be published beneath the declared prefix. Do not publish this tree's parent, build scripts, sibling source roots, relocated verification copies, or local handoff materials wholesale.
