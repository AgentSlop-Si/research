Small order Fourier synthesis manuscript
10 October 2026

This directory is outside every frozen research packet. It contains a new
manuscript draft and inert exact certificate data. It does not alter the source
packets, and no research source program was executed, imported, compiled, or
parsed while preparing it. The small local build_register.py reads byte hashes,
JSON data, and receipts only; it is not a mathematical verification program.

MANUSCRIPT
small_order_synthesis.tex is the editable mathematical source.
receipt_appendix.tex contains the exact accepted receipt identifiers.
small_order_synthesis.pdf is the typeset draft.
SOURCE_REGISTER.json binds the source proofs, verifiers, and recorded results.
THEOREM_STATUS.json records source acceptance and draft-review boundaries.
certificate_data/ contains byte-exact copies of core JSON certificates and
acceptance receipts, with COPY_PROVENANCE.json giving original paths/hashes.

The manuscript alone gives finite formulas for every construction amplitude,
all N5 lower-bound residues, and the complete short N7 lower good-reduction
certificate. The larger independent rational Bezout cofactors and upper literal
data are copied into certificate_data. No numerical root approximation is needed.

MATHEMATICAL REPRODUCTION
Implement Q[q]/Phi_N(q) using exact rational arithmetic. For order seven upper
work, extend to E=Q(q)[t]/(t^3+s2*t-s3); do not presume this quotient is a field.
All needed inverses are units and can be verified by multiplication. Trace in
this separable cubic algebra sums the three root evaluations. Test all guards
before inverse formation and verify both left and right inverse products.

1. N3: use the explicit character and axis recipe in Section 3. Compare every
   original 3-by-3 matrix entry, not merely its support.
2. N5 lower: verify the row and axis formulas and all four elimination residues
   modulo Phi_5; enumerate the diagonal/nondiagonal types logically, not by a
   finite node search.
3. N5 upper: use the five stated nodes and three square systems or the copied
   N5_WITNESS.json. Apply C times Delta times the inverse-character sum for raw
   weights. Verify all 25 inverses and Fourier entries.
4. N7 lower: derive m, n, R, E from the displayed Gaussian formulas, or compare
   with N7_EXACT_ROW_CERTIFICATE.json (which names E as F). Verify the rational
   Bezout identity or the complete displayed modular identity and good-reduction
   hypotheses. An empty finite-field search is not the stated proof.
5. N7 upper: derive the cubic, edge moments, three square systems, and reflected
   rows. Convert moment triples by the Lagrange formula. Verify all original
   inverse and trace-summed matrix identities in E and in K for singletons.
   The raw eight-bank parameters live in the cubic splitting field, not
   necessarily Q(q). The expanded 1/29 formulas cannot be reduced termwise mod29.

OPTIONAL ARCHIVED PROGRAM REPRODUCTION

record that this synthesis ran them. The archived sources are identified by

First copy the relevant full source directories to a new writable location,
keep their relative paths, and verify each hash. Some programs write result
files beside themselves, so do not run them in a frozen packet. Use Python 3
and install SymPy for the controls that require it. Review their declared local
file dependencies before execution. No network or remote writes are needed.

recipe. The control's independent free-coordinate choice need not give the
identical amplitude vector, but each exact construction gives the same target.

TYPESETTING
A normal TeX Live installation can compile the source twice with pdflatex from
this directory. It uses standard article, Latin Modern, AMS, geometry, hyperref,
and xurl packages. The three explicit pdfmapfile lines compensate for missing
system map configuration in the preparation environment and are harmless with
a normal installation. No source research program is invoked by typesetting.
