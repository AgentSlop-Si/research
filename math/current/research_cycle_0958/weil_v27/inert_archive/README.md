# Primitive-phase invariant-subspace rigidity — v27

Run:

```bash
python run_all.py
sha256sum -c MANIFEST.sha256
```

The package proves and verifies a scoped exact obstruction: a Weyl-covariant embedding preserving a primitive length-`N` phase contains a full `N`-dimensional Schrödinger/Fourier block. It does **not** prove a lower bound for unrestricted arithmetic circuits and does **not** construct a faster FFT.
