# Reproduction and evidence boundaries

All executed programs here are newly authored audit programs. `phase40_source/` contains supplied material retained as inert provenance only. Do not execute or import it. No submitted program, package, native binary or test suite was executed by this audit.

From the workspace root:

1. Run `python research_cycle_0958/masks/fresh_reconstruct.py`. This independently constructs sparse cycle matrices, inverts them, builds all outer/target matrices, validates prime/root/inverse guards, compares source numeric data, and writes eight fresh data sets.
2. Compile only the new `fresh_exhaust.cpp` using a C++17 compiler, e.g. `g++ -O2 -std=c++17 research_cycle_0958/masks/fresh_exhaust.cpp -o research_cycle_0958/masks/fresh_exhaust`.
3. For N=4 and8 and each p=998244353,2013265921 run `fresh_exhaust fresh_N${N}_p${p}.txt 0 witness_N${N}_p${p}` from this directory. Zero means the fully bounded enumeration for that specific N. Save stdout as `exhaust_N${N}_p${p}.json`. These four runs contain 188,736 mappings across primes and sizes, each checked with two certificate types.
4. For N=16 and32 run the same command with **2048** instead of zero. These are distinct finite samples, not full enumerations. No complete N16 or larger replay is included in this audit.
5. Run `python research_cycle_0958/masks/fresh_holonomy_controls.py`. It imports only the new `fresh_reconstruct` helpers, reconstructs the exact original integer graph inputs, and verifies all six Jacobian residues plus whole-middle invertibility/nonzero guards.
6. Run `python research_cycle_0958/masks/fresh_crosscheck.py`. Its Python polynomial construction and exact elimination separately check both selected maximal minors for every N4 ledger row and 64 rows of each other ledger, 1,920 minors total. It also checks the explicit dense F8 local/global counterexample.

The C++ CSV `*_row_mask` identifies rows in ascending order of the standard monomial-multiple coefficient matrix. Bit k selects row k. The recorded determinant uses that ascending row order. Monomials of degree d are ordered by decreasing x0 exponent and then decreasing x1 exponent. Cubic rows use pairs (01),(02),(03),(12) and degree-one multipliers in that monomial order. Quartic rows use pairs (01),(02),(13) and degree-two multipliers in that order. The selected determinant for every checked mapping is nonzero.

For full enumerations the `mapping` field is the lexicographic row-pair rank times (N)_4 plus the lexicographic four-column rank. For the 2,048-mapping samples, indices are `(17+t*step) mod total`, where step is the least integer at least total/2+1 coprime to total. This intentionally transparent rule yields distinct samples; it has no distributional guarantee. Exact counts and the chosen step are in the JSON run records.

The direct matrices generated by Step 1 match all source instance elements. The displayed cycle arrays and integer weights are also saved in JSON, so the final finite mathematical objects do not depend on a future random-library version. A port can construct from those arrays and recheck their hashes instead of regenerating a seeded stream.

Finite tests support only their recorded scopes. The source's N16 exhaustive logs, direct Q(i) tests, online execution tests, timings and larger sampled audits have not been replayed by this work. Historical Phase38 independent acceptance is preserved separately, not recertified by renaming the new family.
