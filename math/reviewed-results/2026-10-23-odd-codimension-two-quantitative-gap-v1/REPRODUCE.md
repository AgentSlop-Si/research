# Integrity checking and scientific replay limits

From this directory, run python verify_package.py for data-only verification. It checks the ZIP digest and CRCs, the exact member inventory, original-to-public correspondences, historical manifests and seals, declared source bindings, and direct scientific copies. It does not import or execute any archived scientific program, run a proof search, or validate a numerical result anew. It uses only the Python standard library. Normal and optimized modes are both supported because checks use explicit errors rather than Python assertions.

The archived scientific programs are preserved byte for byte. The author program imports NumPy. The independent program imports NumPy and SymPy, binds an absolute original candidate directory, and follows original source paths from the candidate binding file. Dependency versions and platform characteristics are not pinned by these packets. A clean extraction by itself does not create those locations or install dependencies. Original source inventories retain their original hash checks, including where public documentary metadata has been projected.

Therefore this is archived execution evidence, not certified turnkey scientific replay. No scientific program was run, no equivalent environment was recreated, and no replay output is newly certified by packaging. The data checker verifies stored evidence integrity only. Future reproduction must explicitly establish the needed environment and bound source layout before running scientific controls, without treating a rewritten program or changed hash checks as the original run.

Stored normal and optimized author outputs match each other; stored independent normal and optimized outputs also match each other. Exact independent identity controls use a certified rational upper bound for the squared norm, not exact spectral norms of each sample. Actual spectral-norm samples are explicitly numerical. The initial ill-conditioned harness failure remains archived and its operation-scaled residual correction is documented in the unchanged review. That retained harness history is not a correction to the theorem.
