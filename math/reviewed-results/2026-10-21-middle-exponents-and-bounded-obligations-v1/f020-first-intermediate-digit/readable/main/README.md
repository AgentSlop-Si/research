# F020 first intermediate digit n = 2p^3 + p

The exact theorem is independently accepted. This inert documentary delivery is frozen for a separate package audit; producer packaging checks are not independent package acceptance. A detached audit applies only when it names the exact SHA-256 of this main ZIP.

For every odd prime p, every integer s>3, n=2p^3+p, and every characteristic-zero primitive p^s-th phase, the original P_n and Gaussian H_n are squarefree. The original algebraic-square Christoffel-Darboux kernel is nonzero at every P_n root. Read author/REPORT.md for the proof, independent-review/INDEPENDENT_REVIEW.md for the accepting mathematical review, independent-review/VERDICT.json for its exact contract, and SCOPE.json for this release's bounded summary.

The disjoint exhaustive partition is 2p^3 high boundary roots, one exact simple zero, and p-1 separated tail roots. More specifically, the central high disk contains 2p^2 boundary roots and its additional exact zero; the other p-1 old disks contain 2p^2 boundary roots each. The added noncentral tail disks are separate from all old disks. The proof does not extend the old d<p shallow/unit-tail argument. Original ordinary derivatives are taken in characteristic zero, not by differentiating an inseparable residual.

There is no global F020/F023 closure, assertion for other intermediate digits or arbitrary degrees, p=2, s<=3 or composite orders, historical novelty/priority claim, or FFT/cost improvement claim.
