# Exact degree existence for distinct odd-semiprime fixed-Fourier masks

Independently accepted original-model theorem, 23 October 2026.

For every distinct odd prime pair p<q, N=pq and every primitive complex Nth
root zeta, there EXISTS a binary N-by-N matrix R such that
D[r,c]=R[r,c] zeta^(rc) has either scalar Gram equal to dI exactly when

    d is one of 0, 1, p, q, pq.

Necessity covers every arbitrary mask satisfying the Gram condition.
Sufficiency is supplied by divisor constructions. It is NOT a claim that
every binary mask with an allowed degree is orthogonal.

There is no prime-ratio restriction. New credit is only p>=7: previously
accepted 3q and 5q classifications are retained, not counted again. The
narrower compatibility theorem is a dependency, not a separate discovery.
Global column-degree propagation forces a full q-line; a derived boundary
cross row then exceeds incidence capacity by (p-2)(q-1)>0. Both original
square Grams, actual CRT phases and arbitrary pair-dependent supports matter.
No common-support, Cartesian, rectangular, free-phase or finite-field model
is substituted. The earlier rectangular Fano obstruction remains valid.

For the original normalized complex Fourier target and simultaneous sparsity
of every inverse row, within 1<=s<=N-1 the spectral-norm infimum floor
sqrt(1-s/N) is sharp exactly at s=N-1,N-p,N-q. Every other proper budget has
a strict infimum gap, not merely nonattainment. No exact larger optimum or
new quantitative gap rate is supplied; d=N is not an invertible s=0 witness.
