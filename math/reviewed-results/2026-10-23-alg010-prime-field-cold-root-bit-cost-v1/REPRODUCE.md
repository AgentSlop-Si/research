# Integrity checks and scientific replay limits

Run python -B verify_package.py from this directory for data-only verification. Python standard-library code checks the archive SHA-256, size, CRCs, exact member set and safe paths; each public source mapping; original manifests and SHA256SUMS; explicitly excluded historical entries; retained source-body Git blobs and SHA-256 bindings; scope/projection metadata; and direct-file identity. It works under normal and optimized Python because it raises explicit errors rather than relying on assert. This checker imports or executes no scientific program.

The archive is not certified turnkey scientific replay. All three scientific programs are byte-exact. In particular, review/independent_controls.py expects a sibling directory literally named alg010_prime_field_cold_20261023_v1, checks the original candidate manifest and all thirteen entries, reads the private sources/PINNED_FETCH.json and sources/CURRENT_ROW.json records and the candidate's private sources/LIVE_ROW.json, and writes ORIGINAL_REMOTE.md and CONTROL_RESULTS.json if invoked. Those non-scientific records are intentionally not in this public archive. Two source-binding documents have documentary locator projections, while the original manifest hashes remain unchanged. Simply extracting author/ and review/ cannot satisfy these original dependencies.

No original verifier/hash logic has been deleted, weakened or rewritten to make the projected evidence appear replayable. The unchanged scientific scripts also contain assert checks; do not interpret optimized execution with assertions disabled as equivalent certified verification. No script was run in either mode during packaging. The data-only package checker is separate from these scientific scripts.

The candidate fresh_controls.py imports its fresh sibling prime_field_executor.py, while the independent script reconstructs the mathematics without importing candidate or historical code. Their recorded controls use standard-library Python; interpreter/platform versions are not pinned by this package. Their saved outputs are retained, not regenerated. Future scientific reproduction needs a separately established authorized environment and complete original dependencies, preserving original hash checks. A rewritten standalone adaptation would be a new artifact, not the original run.

Integrity checks establish correspondence of stored bytes, not the proof, timing, physical entropy quality, success of future scientific replay or continued repository/native-table state. Projected original-byte digests and excluded-file digests can be cross-checked against the retained original inventories; their unavailable full original bodies cannot be independently rehashed from this public archive. The private packaging audit checked them before exclusion. No replay or environment equivalence is newly certified.
