# Integrity checking and scientific replay limits

Run python verify_package.py from this directory for data-only verification. It uses only the Python standard library and checks every raw ZIP part, the assembled archive digest, ZIP CRCs, exact members and hashes, original/public correspondence, original manifest inventories and seals, scientific source bindings, Git blob hashes, recorded replay equivalences, and the direct proof/review copies. It never imports or executes an archived scientific program. All checks use explicit errors and remain active under python -O.

If the archive is split, the ordered parts are listed in PUBLIC_MANIFEST.json. Concatenate them in that order to reconstruct evidence.zip before extraction. The verifier assembles the parts in memory and checks their aggregate digest without writing an extraction. Each delivered raw part is at most 409600 bytes. A member inside the ZIP can be larger than a raw upload part.

Scientific programs are unchanged historical source. The new author checker reads its local source copies and verifies original SHA-256 and selected Git blob hashes. The new independent checker also verifies the original candidate manifest at an absolute original candidate location. Source hashes and old inventories refer to original bytes. The two documentary locator projections deliberately produce different public whole-file hashes in the older weighted bindings, and omitted non-scientific records remain absent. The complete original environment is not recreated by extraction, and no path rewrite, original hash substitution or removal of provenance logic is implied.

The older weighted candidate and independent programs use assertion-based validation, so optimized execution must not be substituted for their recorded normal runs. The new mixed-prime controls have separately recorded normal/optimized agreement. That agreement is not a claim about optimized-mode behavior of the older weighted programs. The only code executed for this preparation is data-oriented retrieval, packaging and static integrity checking; archived scientific programs are parsed as text only.

Recorded programs write result files if run. Future scientific reproduction should use a separate working copy, preserve the original evidence and all original checks, explicitly establish the required source layout and original bytes, and distinguish new outputs from the retained run. This package provides archived evidence with a verified data manifest, not certified turnkey scientific replay.
