# Data integrity and scientific replay boundaries

From this directory, run python -B verify_package.py. The standard-library checker verifies archive size (at most 409600 bytes), SHA-256, CRCs, safe names and exact member inventory; current public file pins; every retained source correspondence and documentary projection; original manifests and SHA256SUMS against original-byte mappings; explicitly omitted entries; all selected digest bindings and available byte-exact source-body Git blob identities; ancestor-reference boundaries; unchanged program inventory; administrative accounting; and direct report/review copies. Its explicit runtime checks remain active under Python -O. It imports or executes no archived scientific program.

## Not certified turnkey scientific replay

All five scientific programs are unchanged. ALG064 review/control.py still hard-codes its original absolute candidate directory and verifies all original author manifest members and source Git bindings. This provenance logic has not been removed, weakened or silently redirected. The public projection of the inherited fallback review changes one documentary locator, so it does not hash to the historical original manifest entry. Extracting alg064/author under a new path is therefore not a turnkey reproduction of the original reviewer run.

ALG064 author/checks.py imports its fresh sibling discovery.py and writes CHECK_RESULTS.json in the current working directory. Never run it in a frozen evidence tree. Its checks and the discovery source include assert statements. Both ALG076 control programs are self-contained standard-library exact-fraction controls that print results, but use assertions. Optimized scientific execution can disable those assertions and is not equivalent certification. The earlier ALG064 independent control uses explicit checks and has stored byte-identical normal/optimized outputs; those stored results are not a new packaging execution.

The original ALG076 SHA256SUMS and review manifest also name excluded native snapshots and raw connector receipts, plus documentary originals whose public bytes differ. Whole-packet original inventory replay cannot be claimed from this projected archive. Some historical ancestor files referenced by PREDECESSOR_BINDINGS.json are outside the four supplied packet inventories and are not recursively bundled. Exact source bodies from both omitted GitHub receipts are present; the omitted wrappers are not science-code substitutes.

The package establishes source/data preservation only. It does not pin the original interpreter/platform, run numerical experiments, implement a DFT backend, certify timings or establish future replay equivalence. Future scientific replay needs a separately prepared authorized environment, original dependencies where required and retained original hash logic; any portable adaptation is a new artifact. Projected/omitted original-byte pins can be compared with retained inventories but absent bodies cannot be independently rehashed from this public package. The local preparation audit checked those originals before projection/exclusion. In particular, the projected inherited fallback review retains its original Git blob declaration, but that original blob cannot be rehashed from its projected public body; the checker compares declarations rather than pretending otherwise.
