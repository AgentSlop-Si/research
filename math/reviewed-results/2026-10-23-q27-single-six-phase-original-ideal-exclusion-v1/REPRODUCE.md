# Data integrity and scientific replay limits

Run python -B verify_package.py from this directory. The checker reads each raw evidence.zip.partNNN in manifest order, verifies every part (at most 409,600 bytes), reconstructs the ZIP only in memory, checks CRCs and exact membership, and hashes every original/public source correspondence. It checks both current historical manifests, review/author source bindings, matrix headers and byte hashes, matching stored output pairs, and the complete nested previously published four/five-phase artifact. Normal and python -O modes use explicit errors; no scientific code is imported or run and no output file is written.

For manual inspection only, concatenate all parts in the listed order to a separate scratch evidence.zip and extract after verification. This is archive transport reassembly, not mathematical reproduction. The complete matrix source bytes are preserved exactly inside the archive; they were not truncated, projected or regenerated.

No turnkey scientific replay is newly certified. The current author builder imports its sibling original_model.py and reads sources/CHART.json; its original hash assertions are retained. It writes matrices and metadata. Author exact_controls.py needs NumPy, SymPy and a separately compiled eliminate.cpp executable named eliminate in the candidate directory, and invokes it on temporary mutation data. That reproducible compiled executable is not an omitted historical source, but it has not been built or run here. The original model and builder use assert checks; optimized execution of those programs does not certify equivalent checks.

The current independent model_six.py reads Q27_CANDIDATE_DIR and otherwise defaults to the original absolute candidate path. Set that existing variable explicitly to an authorized separate extracted author directory for any future replay. replay.py imports only reviewer-owned routines, reads chart/metadata/certificates/full stored matrices, reconstructs both full matrices and checks their SHA-256 and equality, then writes RESULT.json in its own review directory. exact_checks.py imports its sibling exact_base.py and model_six.py, uses NumPy/SymPy and prints exact controls. All source programs and provenance/hash checks are preserved unchanged. No source was adapted to make a relocated public tree silently satisfy historical defaults.

The nested dependency is the exact prior published four/five-phase public tree. Its own verifier uses assert and writes evidence.zip when invoked; it is archived inertly, not run by this wrapper. Its historical original manifests and bindings refer to eight originally projected members, including two reviewer default-directory strings. Public hashes differ as explicitly mapped in that dependency's unchanged PUBLIC_MANIFEST.json. Explicit Q27_CANDIDATE_DIR values may locate data, but cannot restore projected original hashes or certify all environment assumptions. The old dependency's self-contained replay wording is retained as historical text, not promoted into a new end-to-end guarantee.

Python, NumPy, SymPy and a C++17 compiler/runtime are not vendored or version-pinned. Future scientific execution requires a separately authorized working environment and scratch copies to avoid overwriting frozen evidence. This package preserves the scientific sources and evidence; it does not establish new timing, mathematical validity, runtime equivalence or recursive completeness of the entire historical research corpus.
