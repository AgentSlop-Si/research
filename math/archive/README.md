# Historical research objects

Every filename begins with the SHA-256 of the original source bytes. Each distinct original version is retained separately; repeated identical copies share one object. The payload manifest records both original and exported hashes, sanitation and source-path aliases. Repeated outer bundle paths are collapsed to distinct logical inner paths; scanned original bundle hashes remain in SCANNED_ARCHIVES.json.

These are historical research records. They can contain superseded claims, rejected approaches, unfinished proofs or old status labels. Use the latest status and the 178-row catalogue to interpret them. Inclusion is not proof acceptance, novelty clearance or implementation verification. No research source was executed during this export. Redacted source code is not revalidated.
