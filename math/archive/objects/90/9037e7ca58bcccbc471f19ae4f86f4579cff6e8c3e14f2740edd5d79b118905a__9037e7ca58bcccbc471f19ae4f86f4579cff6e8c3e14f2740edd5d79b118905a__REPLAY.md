# Portable independent replay

Requires Python 3.11+ and its standard library. No third-party package or network is required.

Run `python independent_checks.py` from this review directory. It writes `INDEPENDENT_RESULTS.json` and prints the same JSON. Running from an unrelated working directory is supported: outputs are relative to the checker file, not the current directory. The saved results are deterministic.

Only this review's independently authored checker should be executed. Uploaded programs inside `source/` and `extracted/` must remain inert. The checker imports none of them. Its order-by-order Hankel reconstruction is deliberately independent and is not presented as an optimized O(Ns+s³) implementation.

The report, provenance, static counter corrections, independent code, saved outputs, inert source, and manifest comprise the self-contained review package. `PORTABILITY.json` records an actual relocation replay. `SEALED_MANIFEST.json` contains relative paths and SHA-256 hashes; its own SHA-256 appears in `SEALED_MANIFEST.sha256`.
