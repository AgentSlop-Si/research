# Nonlinear routing for exact FFT — research report

**Date:** October 10, 2026  
**Question:** Can overlapping linear-work quasiseparable scans, joined by genuinely nonlinear permutations, compute a full exact power-of-two Fourier transform with less than `N log N` arithmetic?  
**Result:** Two exact analysis tools and new no-go certificates. **No faster transform constructed.**

## Prior checkpoint and the unresolved question

The previous archive established an exact parity-vs-parity Fourier rank formula and a stage-depth restriction for GF(2)-affine routing. At `N=256`, a particular seeded four-stage affine layout passed all sampled parity and other saved rank tests. Its coefficient feasibility, and any asymptotic extension, remained open. We did **not** reinterpret that rank-survival as an FFT.

A simple two-control Toffoli gate is nonlinear over GF(2) and can be inserted between two stage scans at linear index-processing cost. Earlier exact parity-oracles no longer applied directly after such nonlinear shuffles: the final output set ceases to be a parity set. This motivated the new rank formula.

## Result 1 — exact characteristic-zero ranks with irregular output sets

For input columns repeating a universal pattern `E` of period `h`, Fourier rows split into `d=N/h` independent residue blocks after a column Fourier transform. Each block has rank equal to the number of its selected rows, capped by `|E|`.

`rank F_N[R,E+h{0,...,d-1}] = Σ_{ρ=0}^{d-1} min(|R∩(ρ+dZ)|, |E|)`.

For `N` and `h` powers of two, any `E` that picks exactly one of `j` and `j+h/2` for each `0≤j<h/2` is universal by the established prime-power sampling theorem. All binary-parity input halfsets are included, and output rows can now be arbitrary.

The result covers input sets that are **not parity sets** as well: choose the `h/2` bits of the transversal independently. We verified 360 randomized non-parity universal inputs with arbitrary row sets against independently computed finite-field ranks in two primes.

The formula is exact over complex numbers, with `O(N)` integer residue accounting and no root approximations. A consequence is `rank F_N[R,C_a]≥N/4` for any output halfset `R` and parity input halfset `C_a`. If the input parity mask contains the top `k-1` bit, the rank equals `N/2` for *every* output halfset. This extends the earlier all-length depth restriction even to arbitrary output coordinate reorderings when inputs remain in natural or GF(2)-affine order.

## Result 2 — an exact nonlinear N=256 exclusion

We reconstructed the three dense GF(2) shuffles of the saved 256-point four-stage survivor. We changed **only its third interstage shuffle** by composing five reversible Toffoli gates, in order:

`((2,7)->6), ((3,6)->2), ((2,4)->3), ((3,4)->2), ((2,3)->4)`.

The resulting permutation is genuinely non-affine: it disagrees on 160 of 256 indices with the affine interpolation through its images of the zero vector and the eight basis vectors.

For input mask `112` the stage crossing budgets are `[11, 53, 43, 17]`. The final output selection contains 64 even and 64 odd indices. Its exact Fourier rank is 128 and the network bound is 124. An independent 8,176-node directed-network maximum-flow calculation returned exactly 124. Modular rank tests in GF(12289) and GF(65537) both returned 128 for the actual 128×128 Fourier submatrix. Thus the altered architecture is excluded for arbitrary complex generator coefficients.

**Caution:** the *unchanged affine 256-point candidate still passes these tests*. The excluded candidate is a deliberately modified, nonlinear layout; this is a useful demonstration of the oracle rather than a global resolution.

## Result 3 — quantitative resistance to sparse nonlinear edits

For the same stage matrices, changing interstage permutations from `A_j` to `P_j` changes the whole product by matrix rank at most `H=Σ rank(P_j-A_j)`. The proof is an elementary telescoping sum.

For permutation matrices, `rank(P-A)` is `N` minus the number of cycles of the relative permutation, so the exact cost is fast to compute. An `m`-control NOT contributes `N/2^(m+1)` rank. Consequently one two-control Toffoli has edit rank `N/8` regardless of where it appears among affine shuffles.

Combining this with the affine depth witness from the earlier checkpoint yields the robust restriction:

`if Σq_j<k and Σr_j(N/2^q_j-1)+H<N/4, the Fourier factorization is impossible.`

In particular, with `t=4` order-1 stages, GF(2)-affine interstage routing plus just **one** Toffoli is excluded at all `N≥2^21`. This follows with quota `q=5`. It is an all-length restriction for that family, not a general FFT lower bound.

For the saved deterministic dense affine layouts we can certify more at smaller sizes. With **two** Toffoli insertions, the 2,048-point layout has Fourier rank 1,024 versus rank bound 902; the 4,096-point layout has Fourier rank 2,048 versus bound 1,911. These bounds hold for any placement of two such nonlinear gates amid the chosen affine interstage layouts.

## Experiments and negative results

1. The original 256-point GF(2)-affine seed had best parity-witness gap `-39` (negative means no rank contradiction). The new arbitrary-output oracle agrees exactly with the old parity formula on all 21,342 tested ordered mask pairs.
2. Searching **504 single-Toffoli modifications** of that candidate found no contradiction; best gap was `-10`. This is only a finite search result.
3. A targeted search using further Toffoli compositions progressively improved the best gap from `-10` to `-4`, `-2`, `0`, and finally `+4` after five gates in the last interstage permutation. The entire sequence, gate list, rank witness, and affine bases are saved.
4. A search over periodic universal (generally nonparity) input transversals also found **no contradiction for the unchanged affine seed** in the tested configurations. This is not proof that the original seed has full network capacity on every subset.
5. Direct finite-field four-stage products with actual nonlinear permutations confirm the rank perturbation predictions. At `N=64`, an exact random product had baseline selected-block rank 4, edited selected-block rank 19, perturbation rank 16, and Fourier block rank 32 (two primes).

## Validation summary

- 9/9 new regression groups pass on a clean execution.
- 580 parity-input/arbitrary-output rank cases and 360 nonparity periodic-input rank cases were checked independently in each of two prime fields.
- 21,342 parity-mask pairs from the earlier rank theorem were reconstructed exactly.
- 168 controlled-NOT permutation-rank instances were checked against cycle formulas; small ones were also checked by exact modular Gaussian elimination.
- The 256-point obstruction has independent graph min-cut and two-prime Fourier checks.
- The 2,048/4,096 per-layout two-Toffoli certificates are recreated directly from the archived deterministic seed, without loading the previous ZIP.

All finite-field checks are corroboration of the characteristic-zero theorems, **not** their logical justification.

## Why this does not beat FFT

The tested transformations either fail necessary rank inequalities or merely survive. No coefficients have been supplied for a new full Fourier factorization. The formulas concern **rank expressivity** of linear-work stages, not an independent count of exact field operations for a working FFT. Changing or even greatly increasing permutation rank can still be implemented using linear-time indexing, so these no-go certificates do not imply a lower bound for every computational graph.

The project should now focus on genuine coefficient compatibility for the **unmodified rank-feasible 256-point architecture**, or investigate nonlinear permutations with no low-rank affine approximation. If a construction succeeds, compare a fully executable exact transform against optimally implemented radix-2 and mixed-radix FFTs, counting preparation, index work, and arithmetic.

## Reproduction

Run `python test_new.py` in this directory. It uses NumPy for modular tests and NetworkX/SciPy for the independent min-cut. The new theorems are documented in `PROOF_CERTIFICATE.md`. `EXACT_CERTIFICATES.json` contains the reproducible dense affine bases and nonlinear gate schedule. `build_certificates.py` reproduces the certificate file from a deterministic integer seed without requiring the nested prior archive. `prior_checkpoint_full.zip` preserves the entire earlier research generation.
