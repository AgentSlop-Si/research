# Hero #0 Phase 9 — Learned dense Green/circulant cycles with recoverable innovations

**Date:** 2026-10-10  
**Research status:** New project-specific exact identities, finite-field algorithms, positive and adversarial regression tests. **Not a uniform all-input sub-`N log N` transform, not a faster integer multiplication theorem, and not a novelty claim.** The accepted input sets are exponentially rare under a uniform random-input model.

## 1. Precise computational model

Let `N=K*M`, both factors powers of two, `K>=M`, and in the asymptotic regime `M=Theta(log N)`. Work over an exact field `F` with a primitive `N`th root `omega_N` and characteristic coprime to `N`. The executable certificate uses `GF(2013265921)` (`p-1` divisible by `2^27`); that **fixed field does not by itself constitute an unbounded-length asymptotic family**. Extension to variable fields or exact complex coefficients needs root, coefficient, random sampling and inversion costs charged in the chosen model.

Use the unnormalized, negative-exponent DFT

```
F_K(v)[ell] = sum_b v[b] * omega_K^(-ell*b)
X[k] = sum_n x[n] * omega_N^(-k*n)
```

Write `v_t[b] = x[b*M+t]`. The output is the entire explicit length-`N` vector. All algorithms make a **first-request** input scan, learn parameters, and write all outputs. Field inversions, comparisons, all Fourier roots, short-NTT operations, randomized checks, and indexing are accounted for. These algorithms branch on values, unlike pure input-independent scalar linear circuits.

## 2. Main learned dense controller

Let `C` be an arbitrary unknown circulant operator

```
C = sum_{d=0}^{K-1} c[d]*S^d, where (S v)[b]=v[(b+1) mod K].
```

Its Fourier eigenvalues are `lambda[ell]=sum_d c[d]*omega_K^(ell*d)`, with **no sparsity or low-degree assumption on `c`**. Impose the clean first-transition condition `v_1=C*v_0`. If `F_K(v0)[ell] != 0` for every `ell`, the operator is identified uniquely by

```
lambda[ell] = F_K(v1)[ell] / F_K(v0)[ell].
```

This costs **two length-K NTTs** and a batch inversion of the denominators: `O(K log K)` arithmetic, which is `O(N)` when `M=Theta(log N)`. We also support zero seed-spectrum entries when the first transition agrees at those entries, by choosing `lambda[ell]=0`; the fully identifiable theorem assumes all entries nonzero.

For later transitions `t=1,...,M-2`, allow *unknown innovations*

```
v_(t+1) = C*v_t + e_t,    E_t[ell] = F_K(e_t)[ell].
```

Thus `F_(t+1)[ell]=lambda[ell]*F_t[ell]+E_t[ell]`. Denote `z=omega_N^(-k)`, `k=ell+j*K`. The exact input-output identity is

```
X[ell+j*K] = F0[ell] * S_M(lambda[ell]*z)
             + sum_(t=0..M-2) E_t[ell] * z^(t+1)
                                   * S_(M-1-t)(lambda[ell]*z),

S_h(r) = sum_(u=0..h-1) r^u.
```

This is an identity for **every input and any chosen controller `C` and true residuals**. It is NOT by itself a fast algorithm when residuals are arbitrary/dense.

Let `H_ell(z)=sum_t E_t[ell]*z^t` and `B_ell=sum_t E_t[ell]*lambda[ell]^(M-1-t)`. Algebraic summation yields

```
X = { F0[ell]*(1-(lambda*z)^M) + z*H_ell(z) - z^M*B_ell }
    / (1-lambda*z),                                      (1)
```

whenever `1-lambda*z` is nonzero. For a zero denominator, the original finite sum gives the exact branch

```
X = M*F0[ell] + sum_t E_t[ell]*z^(t+1)*(M-1-t).      (2)
```

No pole or zero-division is introduced. All `N` nonzero denominators can be batch-inverted with **one inversion plus O(N) field multiplications**; the special cases are handled separately. The factor `(lambda*z)^M=lambda^M * omega_K^(-ell)` is **independent of j**.

## 3. Theorem A — sparse *positions* in the innovations

Assume each `e_t` has at most `s` nonzero coordinates, `s` known but locations and values hidden. Consecutive spectral samples

```
E_t[ell], ell=0,...,2s-1
```

are an `s`-exponential sequence in `ell`, with nodes `theta_b=omega_K^(-b)` and amplitudes `e_t[b]`. **Two-sparse uniqueness:** the difference between two at-most-s-sparse vectors has at most `2s` positions; the rectangular Fourier/Vandermonde matrix on those positions and the first `2s` frequencies has full column rank. Therefore 2s samples uniquely determine any at-most-s-sparse innovation.

Prepare these spectral probes for each original column by direct dots in `O(sN)` work, subtract `lambda[ell]*F_t[ell]`, use Berlekamp–Massey and scan the K possible roots per time step to recover all locations, then solve a size-s Vandermonde system. The deterministic decoder costs `O(sN + Ms^3)` field operations (the small-factor root searches and polynomial evaluation are charged; for growing s additional `poly(s)` terms apply). A matching sparse probe sequence **alone is not a proof** of the actual residual being sparse; the independent certificate in §5 is required for unpromised inputs.

**A1. Total E=O(1) position errors:** for each recovered event `(t,b,a)`, its output contribution is

```
a*omega_K^(-ell*b) * z^(t+1) * S_(M-1-t)(lambda*z).
```

Evaluating at all N outputs costs `O(E N)`; including identification, scalar prep and certification, **`O(N)` for constant s and E**.

**A2. At most s errors *per time step*:** there may be `Theta(sM)` events. For each `ell`, compute all `E_t[ell]` in `O(sN)` total work and the polynomial `H_ell` at all `M` points

```
z_j=omega_N^(-ell)*omega_M^(-j)
```

by **one length-M NTT**, after `O(M)` coefficient scaling. This costs `O(N log M)` across all K frequency classes. `B_ell` and the remaining numerator/denominator work cost `O(N)`; singular branches cost `O(N)`. Total

```
O(N*(s + log M + R) + R*K log K + M*s^3)
```

for `R` verification rounds (simplified for constant s). With `M=Theta(log N)`, `R=O(1)` and `s=O(log log N)`, this is **`O(N log log N)`** in exact field-operation arithmetic. The code includes a sparse-total shortcut and the batch of K length-M NTTs; it does not hide `M` length-K NTTs.

## 4. Theorem B — sparse *Fourier modes* in the innovations

Suppose instead `E_t` has at most `s` nonzero Fourier coefficients **at every transition**, with unknown support. Such `e_t` can be **dense in all K position coordinates**; a single Fourier mode already has every position nonzero.

Compute the full dense time-domain kernel `c` using **one length-K NTT** of `lambda` and scale `1/K`, charged `O(K log K)=O(N)`. To inspect `e_t[b]` at `b=0,...,2s-1`, compute the corresponding `2s` entries of `C*v_t` by `2s` dense dot products (`O(sK)` per time step, `O(sN)` total). Since

```
e_t[b] = sum_(ell in support) (E_t[ell]/K)*omega_K^(ell*b),
```

the 2s consecutive **position-domain** samples form a Prony sequence. Berlekamp–Massey, an O(sK) scan of the candidate Kth roots, and a small exact Vandermonde solve recover the **unknown Fourier-mode indices and amplitudes**. The same Vandermonde uniqueness argument applies with time/frequency exchanged.

Every recovered mode affects only one frequency class `ell`, hence only the M outputs `ell+jK`. Compute its exact geometric-series correction in `O(M)` time using a single seed power and an M-step geometric walk. At most `s(M-2)` modes are introduced, giving `O(sM^2)` output-correction work. The full algorithm therefore costs

```
O(N*(s+R+1) + (R+1)*K log K + s*M^2 + M*s^3)
```

for constant-size field inversions and constant R, provided `2s<=K`. With `M=Theta(log N)`, **constant s gives `O(N)` exact output work on every promised input**; `s=O(log log N)` gives `O(N log log N)`.

This is strictly wider along a new axis than the Phase 8 fixed-sparse-controller family: `C` can be fully dense and every transition may inject a different *dense position-domain vector*.

## 5. Randomized all-input membership check and its precise scope

Neither a short syndrome nor a learned `lambda` proves the entire raw data obeys the claimed model. Independently of the input and the recovered proposed innovations, choose a uniformly random vector `w in F_q^K`, and compute

```
phi = C^T*w
F_K(phi)[ell] = lambda[-ell mod K] * F_K(w)[ell].
```

Thus each `phi` costs **two length-K NTTs and O(K)**, i.e. `O(K log K)=O(N)`; checking all `M-1` transitions uses `O(N)` dot products. Compare

```
w^T*v_(t+1) = phi^T*v_t + w^T*e_t(candidate)
```

for each transition. A sparse position error gives `w^T e` as a few direct samples; a sparse spectrum gives `(1/K)*sum_ell E_t[ell]*F_K(w)[-ell]`, again O(s) per transition once the transform of w is known.

If any true residual differs from its proposed value, form the `K x (M-1)` residual matrix `R`. For uniform independent w,

```
Pr[all checks pass in one round] = q^(-rank(R)).
Pr[false accept after h independent rounds] = q^(-h*rank(R)) <= q^(-h).
```

**Promised inputs always pass and get an exact full transform**, regardless of the random vectors. Inputs outside the promise may be rejected and passed to a general `O(NlogN)` NTT; a wrong acceptance has only the stated bounded probability, not zero probability. The published algorithm is *not* an unconditional deterministic exact-FFT certificate. Three independent rounds in GF(2013265921) have worst-case false-accept bound `p^-3 < 1.23e-28` (for an input independent of those random vectors). Reproducible seeded PRNG tests are not a substitute for independent true randomness in a security/adversarial setting.

An *entirely deterministic* verification of the dense arbitrary C can be obtained by recomputing all K-convolutions/NTTs, but then loses the advertised fast-path bound. This is an explicit open derandomization obligation, not a hidden assumption.

## 6. Strong witness, negative controls and input rarity

The Phase9A `N=128`, `K=16`, `M=8` deterministic witness has all 128 input values nonzero; learned circulant kernel support **16/16**, distinct eigenvalues **16/16**, polyphase rank **8/8**, Phase7 dechirped rank **8/8**, all 8 Green modes occupied, Hankel rank **64/64**, and **zero modular transform errors**. It has an unknown position-sparse deviation in *every* late transition. See `AUDIT_RESULTS.json` and `audit_phase9.py` for exact seeds, hashes and verification.

The dual spectral family passes independent exact tests on analogous dense-input/full-rank examples. For a single nonzero spectral innovation, **all K position entries of the injected error are nonzero**, verified by `test_spectral.py`.

For a uniformly random length-N input, condition on the first seed transform having all nonzero Fourier coefficients. The first two columns determine the stationary dense C. Conditional on any previous columns, each later random column is uniform in F_q^K, so each **true innovation** is uniform in F_q^K, independently in sequence. Let

```
D_s(K,q) = sum_{i=0}^s binom(K,i)*(q-1)^i.
```

The **exact** conditional probability that **every** innovation has spatial support `<=s` is

```
Pr[all accepted structurally | F(v0) fully nonzero]
  = (D_s(K,q) / q^K)^(M-2).
```

The same formula holds for spectral sparsity because Fourier inversion is bijective. At `N=128,K=16,M=8,s=2`, this probability is about `10^-769`, not a generic-input speedup. This rarity says nothing about whether **other**, entirely different, universal FFT circuits could be fast.

The critical adversarial tests deliberately choose nonzero residuals invisible in the `2s` sampled Fourier or position coefficients. Syndrome-only decoding then proposes the wrong sparse correction; independent random-vector verification rejects the false certificate. See `test_phase9.py::test_h_syndrome_alias_requires_fingerprint` and `test_spectral.py::test_f_invisible_probes_detected_by_freivalds`.

## 7. Empirical operation accounting (not FFT superiority)

`audit_phase9.py` and `audit_spectral.py` execute fresh transformations for N=256...65536 and compare every output with an independent full modular NTT. The code counts field additions, multiplications, per-root products, small spectral recovery, inversions via a conservative exponentiation bound, all Freivalds checks and final output work.

For `N=65536,M=16`, the recorded counts per input element were:

| Workload | Counted field operations / N |
|---|---:|
| Plain dense cycle (A, no innovations) | 33.28 |
| Dense cycle, 1 unknown position spike / late step | 72.02 |
| Dense cycle, 3 position spikes / late step | 87.14 |
| Dense cycle, 1 unknown spectral mode / late step | 41.05 |
| Dense cycle, 3 spectral modes / late step | 51.71 |
| Plain baseline length-N radix-2 NTT (same counter primitives, no root prep) | 32.02 |

The special algorithms are **not faster in measured finite-size field-operation count** on the tested N, and these are not FFTW/NumPy wall-clock comparisons. The complexity claims describe asymptotic classes with `M=Theta(log N)`, not practical speed records. The root generator assumes a supplied primitive field root; precomputed coefficient and sampling costs are otherwise charged.

## 8. Prior art and novelty boundary

The ingredients have well-established histories: circulant diagonalization by the DFT; rational generating functions for forced linear recurrences; Prony/Berlekamp–Massey and sparse Fourier syndrome recovery; exact fast Fourier interpolation and small NTTs; Freivalds-style randomized linear identity testing. The contribution here is the particular charged **dense-learned-controller plus dual-domain innovation recovery** composition, its split direct/short-FFT execution, and reproducible finite-field tests. We have not verified whether this exact composition was published previously; make **no claim of mathematical novelty**.

A published uniform all-length arbitrary-input exact complex DFT result achieves `O(N (log N)^(1-10^-13))` in an unrestricted-coefficient exact complex model (OpenAI math #130, https://github.com/openai/math/blob/main/lean/docs/130.md). Its input scope is strictly broader than Phase 9. Neither these tests nor this model imply any new worst-case FFT or exact integer multiplication bound.

## 9. The exact next gate for the universal target

Eliminating sparsity assumptions on innovations, i.e. allowing `s=Omega(K)` per transition, makes each arbitrary residual a fresh K-vector whose Fourier spectrum must be obtained. Taking its value-side samples needs Omega(K) measurements per column; reconstructing K independent spectra by M generic length-K transforms recovers the unresolved `O(NlogK)` cost. **This is an obstruction of the present innovation-decoder route, not an FFT lower bound.**

A genuine universal advance would need an input-independent *global* contraction handling the entire K×M innovation matrix in less work than M separate K-transforms, while maintaining exact output, O(N) charged setup and a uniform family-of-N complexity proof. One next test is to search for a factorization of the whole bivariate polyphase map whose boundary matrix has a low-cost inverse for every input without low-parameter controls. Reject attempts that merely move the K-transform into a hidden verifier, oracle, or high-precision packed word.

## 10. All-input telescoping cross-check: exact algebra does not imply faster execution

For **any** choice of `lambda[ell]` and **any** original raw vector, one may define the true residual spectra `E_t[ell]=F_(t+1)[ell]-lambda[ell]*F_t[ell]`. The forced rational identity (1) then holds automatically, independent of sparsity or recurrence membership. Its numerator telescopes:

```
B_ell = lambda[ell] * F_(M-1)[ell] - lambda[ell]^M * F_0[ell]

F0*(1-(lambda*z)^M) + z*H(z) - z^M*B
  = F0 + z*H(z) - lambda*z^M*F_(M-1).
```

Consequently

```
X[ell+jK] = (F0[ell] + z*H_ell(z) - lambda[ell]*z^M*F_(M-1)[ell])
             / (1-lambda[ell]*z)
```

when the denominator is nonzero; the finite polynomial formula gives the singular limit. **This is a universal mathematical identity but not an all-input fast algorithm:** computing generic `E_t` first requires all `M` length-K Fourier transforms of the `M` unconstrained input columns (or a genuinely new all-input method we have not found). Choosing lambda differently rearranges those unknown transforms; it does not automatically eliminate them.

`audit_universal_identity.py` independently tested **18 full-rank random-input cases, 6,048 exact output identities, including 12 singular denominator cases**. All innovation spectral matrices had full possible column rank `M-1`. The universal identity remains an audit tool and proof bridge—not a computational breakthrough.
