# Source provenance and related work

- The project is a direct continuation of the saved `fft_hero0_phase15_weyl_symmetry_2026-10-10.zip`, included unmodified as `prior_phase15_bundle.zip`. That nested archive preserves Phase 14 and earlier materials.
- The new monomial classification, gauge no-go, phase-only error bound, single-Green/rook bound, exact F4 decomposer, and code are derived and independently tested **within this Phase 16 checkpoint**.
- Classical prior work on DFT-commuting permutations includes P. J. S. G. Ferreira, *A Group of Permutations that Commute with the Discrete Fourier Transform* (IEEE Transactions on Signal Processing, 1994; https://sweet.ua.pt/pjf/PDF/Ferreira94a.pdf). A corresponding publication listing was discovered during the phase's targeted prior-art search.
- Diagonal similarity of weighted directed graphs via cycle weights is an established line of matrix-scaling research; see M. MacCaig, *On scaling to an integer matrix and graphs with integer weighted cycles* (Linear Algebra and its Applications 498, 2016; https://doi.org/10.1016/j.laa.2016.01.018).
- No exhaustive priority search has been completed; **do not claim these equations are first in the literature** without independent verification.
- The exact N=4 example is a finite symbolic identity and no more; **no O(N) universal Fourier circuit has been constructed**.
