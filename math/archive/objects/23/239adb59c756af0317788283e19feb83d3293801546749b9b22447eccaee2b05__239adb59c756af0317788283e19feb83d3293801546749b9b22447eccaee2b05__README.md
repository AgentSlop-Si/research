# A sparse grading for the full finite q-kernel

This gives an O(N) change of coordinates splitting the actual nilpotent operator
C into two parity blocks, and a related-query covariance that preserves input
support. It is an exact structural improvement within this project, not an
independent sub-N-log-N FFT or a mathematical priority claim.

Use the previous notation C=U+W, U=diag(q^(-i)), Q=U^-1, with q a supplied
primitive Nth root, N an even power of two. The upper cyclic weights of W are
w_i=q-q^(-i) for i<N-1 and w_(N-1)=-q/N. The finite corner is retained.
Let H=H_q(C), where C^N=0 and (I-C)H_q(C)=H_q(qC).

## Sparse input and output transport

Define R=QW. It is a weighted cyclic permutation:

    (Rx)_i=r_i x_(i+1 mod N),
    r_i=q^(i+1)-1 for i<N-1,   r_(N-1)=-1/N.

Since UW=qWU, both RU=q^-1 UR and RW=q^-1 WR hold. Thus

    RC=q^-1 CR,    R^N=I.

The second identity follows because the product of the N weights is one:
product_(j=1..N-1)(q^j-1)=-N, multiplied by -1/N. In particular R and its
inverse preserve support cardinality for every input. Polynomial substitution
and the finite q-difference identity now give

    H R = R H_q(qC) = R(I-C)H = D H,   D=R(I-C).

The output operator D is also sparse, though it does not preserve support:

    (Dy)_i = r_i(1-q^(-(i+1))) y_(i+1)
             -r_i w_(i+1) y_(i+2),

with cyclic indices. Exactly one first coefficient, at i=N-1, is zero. Hence
D has 2N-1 nonzero entries. Since H is invertible, D=HRH^-1 and D^N=I.

Once y_0=Hx_0 has actually been computed, the declared family x_(j+1)=Rx_j
can be evaluated with x_(j+1)=Rx_j and y_(j+1)=Dy_j. Each complete input/output
update uses exactly 3N-1 scalar multiplications and N-1 additions in the
implemented convention. Every output coordinate and input update is charged.
The first H action still costs its chosen backend's full amount. Keeping all
query outputs uses O(R_count N) storage; streaming uses O(N) working storage.

This complements the previous dense-prefix input / monomial output covariance:
here the input update itself is monomial and keeps a sparse source sparse.
These are different related-input families. No arbitrary new x can be assumed
to equal a cheap update of a cached input. The nonunitary scalings also give
no automatic numerical error guarantee for approximate anchors.

## Linear-work parity coordinates

Set K=R^(N/2). Then K^2=I and KC=-CK, because q^(-N/2)=-1. Write m=N/2 and
h_i=product_(a=0..m-1) r_(i+a). Then

    (Kx)_i=h_i x_(i+m mod N),     h_i h_(i+m)=1.

For 0<=i<m define paired coordinates

    a_i=(x_i+h_i x_(i+m))/2,
    b_i=(x_i-h_i x_(i+m))/2.

The inverse is x_i=a_i+b_i and x_(i+m)=h_(i+m)(a_i-b_i). In these coordinates
K=diag(I,-I), so anticommutation forces C's two diagonal blocks to vanish.
Both changes of coordinates cost O(N), without applying a triangular kernel
or FFT. The explicit paired forward transform costs 3m multiplications, m
additions and m subtractions; its inverse costs m of each.

The companion `fft_exact_decimation_research` develops the reduced blocks and
tracks their increasing polynomial bandwidth. A cheap first split alone does
not establish a cheaper full recursion.

## Preparation and verification

`prepare_grading` explicitly constructs the roots, sparse weights, output
coefficients, inverse weights and half-shift weights in O(N). The inverse
weights use prefix/suffix products and the known total product one, so they
need no N separate inversions. A sliding product prepares h_i in O(N), not
N separate products of length N/2. The implementation conservatively duplicates
one root-power table rather than claiming unimplemented sharing. Its complete
count, including the imported sparse-C plan, is

    (21/2)N+log2(N)-3 multiplications,
    2N-1 subtractions, N+1 negations, two inversions of constant 2.

Scalar and index storage is O(N). Root validity is an input precondition;
finding the supplied root and exact field representation are not free bit
operations. The algorithm is stated in exact field arithmetic and word indices.

Run `python3 run_audit.py` with the standard library and the sibling earlier
`fft_qweyl_boundary_research` dependency. It passes 13 configurations over two
prime fields and exact cyclotomic fields, 138 full basis vectors and 552 related
outputs. It verifies grading, R^N=D^N=I, half-shift anticommutation, paired
inverses, off-diagonal parity blocks, support preservation and every displayed
implementation count. Dense matrices occur only in the independent verifier.

The q-Pascal starting factorization is established prior art:
[Kuznetsov, 2015/2017](https://arxiv.org/abs/1507.02959). The identities here
follow from the stated finite q-Weyl algebra; they are not claimed as a new
general theory of q-exponentials.
