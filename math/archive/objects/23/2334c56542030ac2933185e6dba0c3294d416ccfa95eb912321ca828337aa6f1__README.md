# Hero #0 Phase 7: Exact Hidden-Shift Green-Phase Fusion

Run from this directory using Python 3.10+ (NumPy is needed only for complex numerical tests):

```bash
python verify_all.py
```

The self-contained modular pipeline uses `phase6_exact.py` as the unchanged baseline source from Phase 6 and tests against an independent radix-2 NTT and, for small lengths, a quadratic DFT.

Core files:

- `THEOREMS.md`: precise model, exact formulas, rank/geometry proofs, error and novelty boundaries.
- `phase7_rank_fusion.py`: exact known-shift rank-r detector, rank factorization, and shared small-FFT execution.
- `phase7_hidden_shift_detector.py`: unknown-shift rank-one recognition via cyclic support-gap/projective KMP with a single batch inversion. Supports zeros and arbitrary shifts per column.
- `test_phase7.py`: exact finite-field adversarial/structural oracle tests.
- `phase7_orbit_union.py`: detect multiple unknown cyclic-shift templates and cluster every input column, including zeros, with one batch inversion.
- `test_orbit_union.py`: strict exact field regression tests for multi-template graph union.
- `phase7_complex_check.py`: independent 48-case complex128 formula check (NOT exact certification of numerical input rank).
- `scale_audit.py`: complete-input operation count versus full NTT on identical inputs and N-output scope.
- `explicit_certificate.py`: a deterministic N=128 all-nonzero, full-Hankel, full-block-rank, all-Green-mode strict equality certificate.
- `CHAIN_HANDOFF.md`: exact continuation target and negative-result register.
- `prior_phase6_bundle.zip`: preserved earlier research checkpoint.

**Result:** exact O(N log log N) for a restricted but dense, potentially full-Hankel-rank, full-block-rank class, extended to O(N(r+log log N)) with up to r unknown template-orbit clusters. **Not** a uniform FFT improvement and not a verified novel literature-first result. An arbitrary input that fails the detector requires a conventional FFT fallback.
