# Independent FFT research continuation: endpoint-optimal Fourier quasiseparable layouts

**Date:** 2026-10-09  
**Goal:** Explore input-independent, exact, fully charged FFT sharing with overlapping nonunitary stages; distinguish matrix representation properties from actual arithmetic speedups.

## Executive findings

1. **Optimal maximum quasiseparable rank of one Fourier matrix.** For \(N=2^m\ge8\), the minimum over *all independently chosen input and output permutations* is **exactly \(N/4+1\)**. Bit reversal on both endpoints attains the minimum. This is a proved single-matrix rank statement, not an FFT circuit bound.
2. **Optimal total rank asymptotically.** Every reordered Fourier matrix has upper-right cut-rank sum at least \((N^2-1)/6\). The bit-reversal layout has exactly \(N^2/6+O(N\log N)\); its rank area is asymptotically minimal. A closed expression for each parity of \(m\) is in `PROOF_CERTIFICATE.md`.
3. **Exact rank recursion.** Bit reversal reduces the rank at any cut \(k\le N/2\) to \(\lceil k/2\rceil+r_{N/4}(\lfloor k/2\rfloor)\). This completely resolves the rank profile for this non-affine layout, unlike the preceding window-rank tests, which required numerical exact ranks per submatrix.
4. **Endpoint-safe quantitative lower bound.** A Fourier projection *second-moment* inequality strengthens the ordinary uncertainty/first-trace bound at critical cuts, proving optimality even under arbitrary endpoint permutations.
5. **Coset spectral decomposition.** Full dyadic-coset Fourier submatrix ranks split exactly into smaller Fourier blocks. This explains the special singular Fourier minors that allowed the previous valid N=16 two-stage Cooley--Tukey control.

## Rejected avenues that we must not repeat

- A simple all-subset boundary-rank cut was **weaker** than the previous contiguous-window screen. At N=8 it accepted 31,384 of the 40,320 internal permutations, while the older window screen accepted 15,728. It is valid but not a useful improvement. See `subset_gate.py`.
- Allowing arbitrary retained support sets containing the selected columns produced **no additional rejections** beyond the 15,728 survivors of the old window screen at N=8. See `optimized_support.py`.
- The first-trace Fourier uncertainty inequality alone is useful as an endpoint-robust necessary condition but **strictly weaker** than the old natural-input Vandermonde window filter at N=8. The **second moment**, together with the odd-cardinality translation argument, is what proves the new sharp lower bound.
- A single bit-reversal global Fourier matrix has rank \(\Theta(N)\) in this quasiseparable sense. That does not imply a new general FFT time bound; replacing an FFT by one expensive rank-\(N/4\) global stage loses the arithmetic goal.

## Independent verification

`test_exact_gate.py` passes nine test groups. Each of the two prime fields verifies all ranks at N=4,8,16,32,64 and 26 further cuts at N=128, as well as all 3,136 N=8 critical minors; random dyadic-coset decompositions are also exact. The characteristic-zero result rests on the proofs, not the two prime fields.

The package embeds `prior_checkpoint_full.zip` byte-for-byte, containing the old eight-window-test and previous nested generations. The new suite is independent of that old archive; the old tests can be rerun separately.

## What this means for the main goal

The representation of a **single** Fourier matrix is now largely solved with respect to the permitted coordinate-reordering trick. This is a boundary for one stage, not for genuinely overlapping stage products with global shuffles. If we continue to optimize only one matrix's QS rank, we cannot produce an O(N) FFT. The next meaningful step is a **joint-factorization rank-profile invariant** for three or more stages, or an actual construction with full arithmetic-count proof. Keep the exact N=16 two-stage Cooley--Tukey positive control in every regression suite; otherwise an apparent universal obstruction may be false.

**Novelty note:** The arguments use classical Fourier uncertainty, projectors, and group decomposition. This checkpoint records new-to-this-project exact deductions and tests; no claim of priority in the research literature is made.

## Related mathematical context (not used in the proof)

The 2015 butterfly-factorization literature represents complementary-low-rank operators as \(O(\log N)\) sparse stages with \(O(N\log N)\) application cost (Li, Yang, Martin, Ho, and Ying; DOI [10.1137/15M1007173](https://doi.org/10.1137/15M1007173)). A separate October 2026 OpenAI mathematics release describes a uniform exact-complex DFT bound \(O(N(\log N)^{1-10^{-13}})\) in an unrestricted-coefficient model ([overview](https://github.com/openai/math/blob/main/overview.tex), [formalization scope](https://github.com/openai/math/blob/main/lean/docs/130.md)). Neither result is implemented or improved by this project checkpoint; our proved statements are about endpoint-permuted one-stage rank, not total algorithmic complexity.
