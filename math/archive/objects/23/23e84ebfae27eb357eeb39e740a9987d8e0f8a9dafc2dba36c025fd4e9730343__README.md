# Exact Fourier ranks under nonlinear routing — reproducible checkpoint

**2026-10-10 | Verified analysis, not a faster FFT.**

This checkpoint continues the independent quasiseparable-scan/overlapping-graph research. It proves an exact complex Fourier-submatrix rank formula for arbitrary output sets, excludes one specifically modified nonlinear four-stage 256-point routing pattern, and extends GF(2)-affine depth restrictions to low-rank nonlinear permutation edits (including controlled NOTs).

## Quick start

```bash
python test_new.py
```

Requires Python 3.11+, NumPy; the standalone directed-network cut check also uses SciPy and NetworkX. `test_new.py` does not need the nested prior ZIP and reproduces **all 9 new test groups** from the explicit files here. `build_certificates.py` independently regenerates `EXACT_CERTIFICATES.json` using a fixed seed.

## Core files

- `PROOF_CERTIFICATE.md`: statements, assumptions, full proofs and mathematics references.
- `RESEARCH.md`: narrative, certified findings, negative experiments, limitations.
- `nonlinear_fourier_oracle.py`: exact complex rank formula and arbitrary-permutation stage-boundary certificate.
- `permutation_edits.py`: relative permutation rank via cycles, GF(2) affine maps, controlled NOT edits.
- `scan_network_cut.py`: independent exact scalar-scan graph max-flow implementation.
- `exact_field_controls.py`: independent modular ranks and stage-product controls.
- `EXACT_CERTIFICATES.json`: exact 256, 2048, and 4096 certificates and all shuffle bases.
- `build_certificates.py`: deterministic construction of those certificates.
- `test_new.py`: complete nine-group regression suite.
- `SESSION_HANDOFF.md`: next research gate and chain-break recovery.
- `prior_checkpoint_full.zip`: bit-for-bit copy of the previous research checkpoint.

## Crucial distinction

The 256-point obstruction excludes a **nonlinearly modified** layout, not the unmodified four-stage affine survivor. The latter remains rank-feasible under tests performed, but no actual Fourier factorization is known. No new `o(N log N)` or `O(N)` FFT has been constructed. The imported universal-sampling theorem belongs to prior mathematical literature, not this project.
