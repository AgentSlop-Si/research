# Phase 22 — Fourier Gram gates and real phase extraction

**Start with `CHECKPOINT.md`; read `THEOREM.md` for exact statements and limitations.**

Research question: can independently ordered Green sums and internal phase masks generate the Fourier transform using `o(N log N)` total arithmetic? **Answer so far: not established.**

This phase contributes two exact gates and one constructive change of coordinates:

1. A **real one-mask obstruction**: if the left real mixer's column-Gram support is connected, no right real mixer, intermediate permutation or single complex diagonal can produce the Fourier transform.
2. An exact **bilinear Fourier-Gram gate**, which excludes every middle phase mask/permutation at once for fixed outer factors, or recovers the hidden mask and permutation in nondegenerate positive controls.
3. A cheap exact parity transform `F=H Q C` where `H` and `Q` apply in `O(N)`, `C` is real orthogonal and obeys `CZ=RC` for an explicit sparse real rotation matrix `R`. A complete seed vector fixes `C` uniquely. The hard arithmetic remains in `C`, and the two-coordinate-unitary entropy bound remains logarithmic.
