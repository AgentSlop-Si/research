## Purpose

Stationary Toeplitz Gram chart and full-rank Fourier evaluator.

## Complete logic and mathematical identity

States a_i=1+iK,beta=3s+i(K+1) give V=D W; exponent nodes reduce to u mod K, so Vandermonde columns are independent and q=M spans all local input blocks. Gram Toeplitz is input/block independent. Public evaluator validates dimensions via bank setup, estimates Gram condition, solves all K right-hand sides for each odd column and decodes q streams.

## Actual work and memory

O(Mq^2+mq^3+Nq+(N/M)q^2+qN+q(N/M)log(K+1)+Nlog(m+1)) literal arithmetic, including an SVD condition check. np.linalg.solve refactors Gamma for each odd column rather than reusing one factorization; extra mq^3 is absorbed because q<=K. At q=M actual work is O(NM+Nlog(K+1)+Nlog(m+1)), FFT-scale for M~log G. Memory O(N) for supported q<=M,K>=M.
