# Exact Fourier action on dyadic detail blocks

This is a cost audit and exact verifier, not a faster transform or a novelty claim. It follows directly from the usual even/odd frequency decomposition. This package continues the previous deferred-correction audit without re-running its rank search.

Let N=2^L, F_N[k,j]=q^(kj) with q a primitive Nth root, H_N[k,j]=(-1)^popcount(k&j), P_N the bit-reversal permutation, and C_N=H_N P_N. Because H_N commutes with P_N and H_N^2=N I, C_N^2=N I. The Fourier-to-core map is U_N=F_N C_N/N, hence F_N-C_N=(U_N-I)C_N.

For the natural Hadamard matrix,

    (F_N H_N)[k,u] = product_(r=0)^(L-1) (1 + (-1)^(u_r) q^(k 2^r)).

If k is nonzero and v2(k)=s, this is nonzero only when the highest set bit of u is L-s-1. Substituting u=bitreverse(j), U_N is block diagonal under the SAME row and column grouping by v2, with a separate DC block. If m=N/2^(s+1), the block indexed by k=2^s(2a+1), j=2^s(2b+1) is

    B_m = (1/m) F_m diag(zeta_(2m)^t) C_m.

Thus the exact blocks have sizes 1 (DC), 1, 2, 4, ..., N/2. This is not low-rank approximation. The formula accounts for the entire high-rank correction. It expresses its remaining action using smaller twisted Fourier transforms.

## Implementable linear-time preparation

For a length-2m vector, split into contiguous halves a,b and form s=a+b, d=a-b. Its even Fourier coefficients are F_m s; its odd Fourier coefficients are F_m diag(zeta_(2m)^j) d. Repeat only on s. This prepares independent detail vectors of sizes N/2,N/4,...,1 plus DC using exactly 2(N-1) additions/subtractions. The map is invertible: a=(s+d)/2, b=(s-d)/2. Consequently those detail vectors can take arbitrary independent values; no repeated-input assumption has been created by the representation.

For each detail vector of size m, perform one twisted length-m DFT and place its result at output indices (2k+1)N/(2m). All N outputs are recovered. This is the executable `from_details` identity; its local DFT is deliberately quadratic for an independent audit oracle.

Using radix-two FFTs for the subtransforms, their additions sum to

    sum_(t=0)^(L-1) t*2^t = (L-2)N+2.

Adding preparation gives EXACTLY N log2(N) additions. Twiddle multiplications are extra; N-1-L detail phases are nonunit. Given a primitive Nth root, preparation of the powers used by all detail diagonals needs O(N) scalar operations/storage. Construction and representation of that root depend on the exact arithmetic model and are separate costs; the finite-field verifier also checks primitivity. The subtransform cost, indexing, and output writes remain charged.

The recursively specified work obeys A(1)=0 and A(N)=2(N-1)+sum_(t<L) A(2^t), giving A(N)=N log2(N) for this addition schedule. This is a statement about this algorithm, not a lower bound on arbitrary linear circuits. Joint evaluation across the independent blocks might conceivably share work through a different circuit; no such faster circuit has been supplied here.

## Verification

Run `python3 audit.py`. Standard library only. It checks all basis vectors for N=2,4,8,16,32,64 over both primes 65537 and 998244353; validates the detail inverse and all Fourier outputs; independently checks every entry of the claimed block diagonalization. The exact all-N conclusion follows from the algebra above, not extrapolation from the finite tests. Complex roots and finite-field roots share these polynomial identities when the characteristic does not divide N.

## Reuse decision

The decomposition is retained as a verified coordinate system for future correction-circuit work. Do not relabel it as a new sub-NlogN algorithm. Do not infer any stronger all-N formula for rank(F_N-C_N) from these identities alone.
