# Replay

Requires Python 3.10 or newer; uses only its standard library. No network, source-code imports, numerical package or external executable is used by the checker.

Run:

    python check_extension.py --out-dir three-green-extension-replay

Optional exact physical-family control:

    python check_extension.py --q 483 --out-dir three-green-q483

The default q list is 1, 483, 1447, 1929, 2411. Exact factors are included in JSON for q=1 and q=483. Symbolic identities and the local-ring proof in the report, rather than the finite list, establish the infinite theorem. The source snapshots are inert evidence and are never executed. This checker is the only mathematical program required for replay.

To check file integrity, run `python verify_seal.py`. Replaying into another directory keeps the sealed certificate untouched.
