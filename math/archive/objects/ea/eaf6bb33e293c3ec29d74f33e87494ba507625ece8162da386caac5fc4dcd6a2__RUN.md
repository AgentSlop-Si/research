# Reproduction instructions

Requires Python >=3.10, standard library only. All finite-field numerical tests use exact modular integers, not floating-point approximations.

```bash
cd hero17_phase13_weyl_branch
python -m unittest -v test_phase13
python independent_audit.py
python orientation_audit.py
sha256sum -c SHA256SUMS.txt
```

The operation ledger charges additions/subtractions, field multiplications and field inversions; reads/writes are additionally O(N). A primitive root `omega` is treated as supplied in the abstract field model; the finite-field test helper discovers a root for testing. The large test also charges the preparation of all `omega^j` and reciprocal diagonal factors.

For independent characteristic-zero scrutiny, read the proofs before interpreting finite-field evidence. Tests do not establish historical novelty or unrestricted FFT lower bounds.
