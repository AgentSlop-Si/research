## 2. Actual estimator and probability model

### 2.1 Inherited row, target, and normalization

V7:89–134 implements, with zeta=exp(2*pi*i/N),

- S[r,t] = zeta^(a*t^2 + (2*a*M*r+beta)*t),
- d[r] = sum_t S[r,t] x[r*M+t],
- y[r,t] = conjugate(S[r,t]) d[r],
- one ideal row Xhat = U_N y, where U_N is the negative-sign unitary DFT.

The map called a rank-one "projection" is M times an orthogonal rank-one projector, not an idempotent projection. Its block operator norm is M. This explains the magnitude bound ||y||_2<=M||x||_2 used to bound cell IDs. The compression is not normalized by 1/M; adding that factor would change unbiasedness and the decoder.

The exact-arithmetic reference function's name `exact_unitary_dft` (V7:51–55) means a full NumPy FFT rather than a sketch; it is not exact arithmetic. Likewise the "exact covariance" routine is a closed-form formula evaluated using floating complex values.

### 2.2 Sampling, unbiasedness, and covariance

`draw_state` (V7:72–78) draws an odd a from 2*integers(0,N/2)+1 and beta from integers(0,N), using the passed RNG. Under the ideal sampling model these are independent uniform choices within a row; successive independent choices give independent rows. The implementation is a pseudorandom generator interface, not a source-level proof of ideal independence for every possible caller-supplied generator.

For fixed x independent of the seeds, beta orthogonality cancels off-diagonal terms of the expected block map, so E[Xhat]=U_N x. The central dyadic theorem provides

    E|Xhat[k] - (U_N x)[k]|^2 <= (2M/N)||x||_2^2.

For M>=2,K>=2M the covariance operator norm equals 2M/N; M=1 is the exact identity map with zero variance instead. V7 `variance_bound` handles that M=1 special case and otherwise enforces K>=2M (V7:235–244). V8 bypasses that validated helper when it constructs tau directly (V8:369).

The previous v7 proof gives the stronger covariance decomposition Q_k=(2M/N)P_k, with P_k an orthogonal projector of rank K(M-1)/2. The displacement derivation uses beta to force equal displacements and odd-a averaging to select N|4d(n'-n). K>=2M makes the resulting congruence enforce the same within-block column. None of this treats different blocks as independent. The two global seed parameters deliberately correlate every block and every output in a row.

The guarantee is for every fixed input, simultaneously over all N outputs, with probability over newly sampled rows. It is not a guarantee that one realized seed set works for all inputs subsequently chosen with knowledge of those seeds. No subgaussian assumption or coefficient-relative error guarantee is present. Heavy-tailed one-row errors are compatible with the second-moment argument.

### 2.3 V7 median aggregation

`chirp_median_fft` (V7:221–232) retains a Python list of R complete rows, stacks them, and takes separate medians of real and imaginary parts. This is not a geometric complex median. The median need not be unbiased even though each ideal row is unbiased.

For R=2s-1, the median moment argument and union bound over 2N scalar components give exactly the returned bound (V7:247–263):

    2 (2N binom(2s-1,s)/delta)^(1/(2s)) sqrt(M/N)||x||_2.

The proof needs independence across rows, not independence across frequencies or between real and imaginary parts. The list plus stacked copy costs O(RN) numerical storage. O(RN) median work in an abstract algorithm requires a linear-selection implementation; the source does not establish an implementation complexity guarantee for the installed `np.median`.

### 2.4 V8 three-grid majority mechanism

V8:296–342 stores three candidate cell IDs and counters for a scalar output vector, updating each with standard Boyer–Moore cancellation. There are separate instances for real and imaginary components, hence six candidate IDs and six counters per complex output. The IDs are quantized using width W=7*tau and offsets 0,W/3,2W/3.

The exact deterministic lemma is correct. If a strict majority of samples lie in the whole interval I=[mu-tau,mu+tau], the combined boundary lattice has spacing 7*tau/3>2*tau, so I intersects boundaries from at most one grid. In each of the other two grids I lies within one cell. Its center is within W/2-tau=5*tau/2 of mu, because the *entire interval*, not merely observed good sample points, is contained in that cell. That cell is a strict-majority cell; Boyer–Moore returns it in any ordering. The median of three centers lies between the two good centers. No second counting pass is required conditional on that majority event.

This reasoning neither says the three grids are independent nor treats them as three additional stochastic trials. They process the same samples deterministically. Likewise real/imaginary aggregation is separate computationally, not independent probabilistically. The final union bound tolerates all such within-row dependence.

The estimator is deliberately quantized and may be biased even with perfect input samples. For example, if every scalar sample equals zero with tau>0, ideal cell centers for the three grids are 7*tau/2, -7*tau/6, and +7*tau/6; the returned median is +7*tau/6. This stays inside the theorem radius but shows the method does not converge to an exact coefficient merely by adding rows at fixed tau. With M=1, ideal rows are exact, but V8 still chooses a positive tau for nonzero x and applies this quantization; it does not preserve V7's exact M=1 limit. The separately handled all-zero input does return exact zero.

### 2.5 Confidence bounds and parameters

V8:345–383 sets tau=g sqrt(2M/N)||x||_2. For one scalar component of an ideal row, Chebyshev gives bad probability <=p=1/g^2. For g>sqrt(2), p<1/2. With R independent rows, the Chernoff/KL bound is

    Pr[some scalar component lacks a good strict majority]
        <= min(1, 2N exp(-R D(1/2 || p))),
    D(1/2 || p) = (1/2)log(1/[4p(1-p)]).

The complex error on the complement is (5*sqrt(2)/2)*tau = 5g sqrt(M/N)||x||_2, matching `majority_uniform_error_bound` (V8:431–434). This is an upper bound, not the true observed failure rate. The probability functions do not inspect data, RNG states, rows, or observed majorities.

`required_rows` (V8:437–444) rounds up log(2N/delta)/D to an odd count; subject to valid finite inputs and ordinary numerical rounding it implements the sufficient exact-arithmetic schedule. The claim "smallest odd" is mathematical, not a certification against floating-point rounding at an exact threshold. `majority_failure_bound` allows even positive row counts; its conservative at-least-half tail bound is still valid. The streaming wrapper requires odd R, a narrower interface.

For odd R=2s-1, a separate bound is N*2^R*g^(-2s), clipped at one. It follows by bounding every term of the upper binomial tail by p^s and summing upper-half binomial coefficients to 2^(R-1), then union bounding over 2N components. V8:404–429 implements this through logarithms. It does not require independence of coordinates. The corresponding `fixed_rows_required_g` inverts this sufficient bound, not an optimal tail probability.

Neither a deterministic PRNG seed nor the one saved run certifies the theorem's confidence numerically. The same RNG instance is advanced through all rows; there is no accidental reset inside a streaming call. In the experiment driver, `seed+rows*1009+len(name)` deliberately or incidentally gives identical seed streams to equal-length case names, including `random_phase`, `global_chirp`, and `single_spike`. This does not break row independence in the ideal analysis, but those cross-case experiments are not independent replications.

## 3. Decoder identity and precision boundary

### 3.1 Exact recurrence and gauge

V7:155–208 evaluates the two cycles generated by k -> k+2a modulo N. For N>=2 dyadic and odd a, gcd(2a,N)=2, so seeds 0 and 1 cover all outputs. The two seeds are evaluated directly in O(N) work apiece, and a length-K FFT supplies forcing terms.

Writing k_j=s+2aj modulo N and

    A_j=zeta^(a*j^2+(beta+s)*j),

one has A_(j+1)/A_j=zeta^(a+beta+k_j). The recurrence becomes z_(j+1)=z_j-F_(k_j)/A_j, hence

    Y_(k_j)=A_j [Y_s - sum_(h<j) F_(k_h)/A_h].

V8 `_cycle_arrays` (149–193) implements this identity, and `decode_balanced_scan` (196–221) uses the exclusive prefix, not an inclusive prefix, with the correctly matched forcing terms. The source's calculation for the last forcing term is unnecessary for output recovery but harmless: the last exclusive prefix excludes it. Both cycles are decoded, and indices are disjoint in the valid domain.

### 3.2 Reduction/scan behavior

- `pairwise_sum_1d` (55–72) flattens any input, pads to the next power of two, and reduces a balanced tree. Empty input returns zero.
- `pairwise_sum_axis1` (75–91) requires a matrix, pads the column dimension, and performs a balanced reduction. A zero-column matrix returns row-wise zeros.
- `balanced_exclusive_scan` (94–124) flattens input, pads to a power of two, performs up-sweep/down-sweep, and returns each prefix without its current term. Empty input returns an empty vector. It uses O(n) additions and O(log n) arithmetic depth, with O(n) workspace.

These are source-derived structural statements, not executed checks. A logarithmic-depth summation tree controls accumulation error in proportion to an absolute sum of magnitudes and a gamma_{O(log n)} factor. It does not imply small relative error under cancellation, and it does not bound errors already present in seeds, phases, forcing terms, or compression.

### 3.3 Actual precision path

The implementation's effective precision is mixed:

1. `balanced_one_row_estimate` converts x to complex128 and invokes unchanged V7 compression before the requested dtype enters the decoder (V8:291–293).
2. Compression uses complex128 roots and `np.sum`, not V8's pairwise summary routine (V7:107–115).
3. `decode_balanced_scan` casts d to the requested dtype, casts it back to complex128 for `np.fft.fft`, then casts the FFT result to that dtype (V8:211–213). This is rounded storage around a double-precision FFT, not a single-precision FFT implementation.
4. `_stable_seed_value` and `_cycle_arrays` generate phases using float64/complex128 `np.exp`, then cast to the requested dtype. They use int64 arrays for exponents/indices.
5. Pairwise seed sums and scan accumulation are at the requested dtype. Some scalar conversions and normalizations use Python complex/float and are subsequently recast. The source does not specify a platform-independent per-operation single-precision model.
6. Grid classification and center generation always use float64 and int64, regardless of decoder dtype. The final result is complex128.
7. `stable=False` chooses the inherited complex128 sequential implementation and does not use or validate the supplied dtype. Invalid dtype values are therefore rejected only on the stable, nonzero-input path.

The word "stable" labels structural improvement, not a complete end-to-end stability certificate. Source `RESEARCH.md` explicitly recognizes that boundary. The numerical radius returned by `majority_uniform_error_bound` nevertheless includes no measured or proved floating-point allowance, and the runtime wrapper does not enlarge tau for decoder error.

### 3.4 Missing finite-precision obligations

A certified implementation needs a bound on summary, FFT, seed, root, normalizer, gauge/forcing, scan, final multiplication, norm, classification, and output rounding errors. It also needs range/underflow assumptions and precise integer semantics.

V8's scalar division by an approximate gauge does not use the exact identity 1/A=conjugate(A) in a certified numerical contract. `np.exp` is not accompanied by a uniform root-error certificate. Floating `(value-offset)/width` followed by `floor` is not exact grid classification at boundaries. `tau` is based on an uncertified floating norm; finite input can still encounter underflow/overflow in norms or intermediate operations. `_grid_offsets` validates tau before multiplying it by 7, but does not verify that the resulting width remains finite. Candidate conversion cannot safely represent arbitrary nonfinite or out-of-range helper inputs.

Fixed-width products occur before reduction in local phases, seed phases, and `_cycle_arrays`. An important nuance: wrapping modulo 2^64 by itself does not necessarily corrupt a subsequent residue modulo a dyadic N dividing 2^64. One must not report every int64 wrap as a demonstrated wrong residue. Still, this source supplies no portable exact-integer contract covering scalar conversion/promotion, indices, large N, RNG bounds, and representability; arbitrary-size correctness is not established by the comments about moderate test sizes. Phase conversion to float64 is also a numerical approximation, not an exact root lookup.

The appropriate transfer principle is deterministic: if each computed ideal-row approximation is within eta of its ideal value, use a common certified radius r>=tau+eta in all grids, account for exact represented-grid classification and final output error, and then retain the probability statement for ideal independent rows. One must not simply assign a fresh unbiased variance to rounding error.

## 4. Public API domains and concrete defects

These are source-derived findings. None is a newly executed failing test.

### D1. Covariance helper gives a false result for an accepted input

`covariance_matrix_formula` (V7:276–305) calls `_dimensions` and validates the output index, but does not enforce the theorem regime or prevent displacement aliasing. For N=M=2 and output=0:

- a=1 is the only odd seed; beta is 0 or 1.
- For beta=0, S=(1,-1), and output 0 of the projected signal is zero.
- For beta=1, S=(1,1), and output 0 is 2X_0.
- Thus the row error is -X_0 or +X_0, where X_0=(x_0+x_1)/sqrt(2).
- The actual covariance is Q=(1/2)[[1,1],[1,1]], with operator norm 1.
- The source only intersects equal displacement sets; for its off-diagonal entry their intersection contains only d=0, which it excludes. Its returned formula is (1/2)I, with operator norm 1/2.

The missing terms are displacements differing by N that beta averaging also permits. This is outside K>=2M and does not refute that theorem. It does refute the helper's unrestricted "Exact covariance matrix" contract over its accepted arguments. `covariance_operator_norm` inherits this defect.

### D2. Streaming estimator does not enforce its advertised variance domain

`streaming_majority_fft` validates odd positive rows and g>sqrt(2), but not M, shape, dyadic dimensions, or K>=2M before constructing tau (V8:360–369). On a nonzero input some shape/dimension errors are caught later by V7 compression; K>=2M is never checked. For example N=8,M=8 enters the estimator even though the stated theorem requires K>=2M. This review does not assert the inequality necessarily fails on that particular case; it asserts that the public result is not covered by the supplied proof and the API does not say so.

The zero-norm fast path occurs before input shape, M, dtype, or dyadic validation. It accepts empty zero input, zero matrices, non-dyadic lengths, and invalid M/dtype values that the nonzero path rejects. It returns a one-dimensional vector of `x.size`, potentially silently changing a zero matrix's shape. This is inconsistent interface behavior even though a flattened all-zero transform is mathematically harmless.

### D3. Lower-level V8 decoders have weaker dimension/state checks

- `decode_balanced_scan` computes K=N//M, checks only d.shape==(K,), and calls `state.validate(N)`. It never validates that M is a power of two dividing N. For example N=8,M=3,d of length 2 passes these checks and evaluates an unrelated floor-partition calculation. M=0 causes integer division failure before a useful validation message.
- `decode_sequential_low_precision` likewise lacks `_dimensions` and also lacks `state.validate`. With invalid a, seed cycles need not cover the output; because `np.empty` is used, uncovered entries can remain uninitialized. For example N=8,a=0 yields step=0 and only the two seeds are assigned. This is an accepted low-level call with meaningless remaining output, not a theorem-domain failure of the normal wrapper.
- `decode_sequential_gauged_scan` validates neither d shape nor state nor dimensions; malformed cycles can repeat indices and leave entries unwritten, or indexing can fail.
- Type annotations are not runtime checks: `ChirpState.validate` checks oddness/ranges but not integer types. Nonintegral beta within range passes its check despite beta being described as a residue in Z_N. Valid `draw_state` calls do generate Python integers.

The intended high-level, nonzero, stable path obtains dimensions and state checks through compression. That mitigates several of these defects for normal use, but does not repair the publicly callable helpers or the missing variance-regime guard.

### D4. N=1 is inconsistently admitted

`is_power_of_two(1)` is true and `_dimensions(1,1)` accepts it. `draw_state(1,...)` then requests integers(0,0), so the odd-seed sampler has no admissible state. The two-cycle code also assumes seed index 1 exists. The nonzero N=1 streaming call fails while an all-zero one returns. Special-casing the trivial one-point DFT or requiring N>=2 is necessary. This is outside the M>=2,K>=2M theorem.

### D5. Majority helper preconditions are not represented in state

`MajorityGridState` stores only candidates/counts. It does not store the tau used, number of updates, shape invariants, or whether candidate/counter arrays have safe dtypes. Public callers can update with one tau and finalize with another, making candidate IDs refer to different cells. Finalizing an untouched state manufactures nonzero default centers rather than indicating no observations. `majority_grid_update` checks values against `candidate.shape[1]`, not complete state shapes/dtypes or finiteness. The normal wrapper consistently supplies one tau and positive row count, so these are low-level contract gaps.

Counters are int32 (V8:301,307). A sufficiently long same-ID stream can exceed 2^31-1; there is no row upper bound or checked increment. Signed wrapping breaks the nonnegative Boyer–Moore counter invariant. O(N) state independent of R therefore does not imply these fixed-width counters support arbitrary R. Candidate IDs are int64, while public helper inputs are not restricted by the theoretical row-magnitude bound.

### D6. Parameter and numerical validation is inconsistent

- `streaming_majority_fft`'s `g<=sqrt(2)` check does not reject NaN; nonzero inputs fail later when `_grid_offsets` sees a nonfinite tau. Zero input bypasses even that.
- Bound helpers validate different subsets of n, M, rows, g, delta. `majority_failure_bound` divides by g*g before checking a valid finite positive domain; zero g can divide by zero, negative g is treated by its square, and infinite g makes p=0, which the KL helper rejects. `required_rows` has related endpoint behavior.
- `fixed_rows_*` use `float(n)` and logarithms, so integer sizes beyond floating range are not handled purely symbolically despite asymptotic prose. Rounding of the returned sufficient g is not certified upward.
- `majority_uniform_error_bound` validates none of its input domain and can return a negative value for negative g, zero for M=0, or fail on an empty array. It is an algebraic expression helper, not a validated error certificate.
- A finite positive tau near the floating maximum can pass `_grid_offsets` while W=7*tau overflows. Very small widths, large values, NaN/Inf, and quotient conversion can invalidate int64 floor IDs.

These do not invalidate the ideal theorem after its assumptions are supplied. They require narrowing/documenting public contracts or adding validation before describing the source as a general-purpose certified implementation.

## 5. Charged costs and asymptotic meaning

Let K=N/M and R be the row count.

### 5.1 Main transform costs

Per row, with fixed-cost suitable scalar/word operations and available compatible phase values:

- O(N) work and storage for phase matrix construction and compression;
- O(K log K) for the summary FFT;
- two O(N)-work seed calculations;
- O(N) gauge/forcing/index preparation and balanced scans;
- O(N) work for six scalar-grid state updates.

Thus the ideal main evaluator costs O(R[N+K log K]+N), including norm/setup scans and final N-output aggregation, and O(N) live numerical/integer registers for V8. The additive N term includes output generation and cannot be discarded as a zero-cost full-output operation. The source constructs large phase matrices and NumPy temporaries, but their individual sizes remain O(N) in the valid block domain. It need not retain all previous rows.

`decode_balanced_scan`'s docstring "Stable O(N)-work decoder" (V8:203) is too broad without a relation between M and N: it includes a length-K FFT. The accurate general cost is O(N+K log K), becoming O(N) when, for example, M=Theta(log N). For M=1 it includes a conventional N-point FFT, so it is not an O(N) decoder.

The algorithm streams over randomized rows while retaining/revisiting x. Each row forms fresh summaries from the full input. It is not a one-pass data stream, an O(K)-space algorithm including the input/output, or a scheme that emits all N outputs without paying their write cost.

V7 instead retains O(RN) estimates plus a stacked array and median temporaries. R fixed makes this O(N), but growing R does not. V8 genuinely removes the R multiplier in the count of stored output-sized arrays; it does not remove the R multiplier in work.

### 5.2 Root, random, integer, and bit costs

A source-level count of `np.exp` as one operation is not a field-operation count. Exact compatible roots and normalizers must be available under a specified algebraic model or prepared/charged. An O(N)-entry root table can be shared and generated in O(N) exact scalar multiplications from a supplied compatible primitive root; supplying/certifying that root and finite-precision generation are separate obligations. Naively multiplying approximate roots at working precision may accumulate O(Nu) root error.

Generating R independent seed pairs consumes O(R log N) random bits in the ideal model. Indices and modular exponents require enough exact integer width; actual RNG and NumPy integer interfaces have finite ranges. Grid floor/quantization is not an arithmetic-and-comparison field primitive simply because the resulting ID is short.

From ||Xhat||_infinity<=M||x||_2 and tau=g sqrt(2M/N)||x||_2, cell IDs are O(sqrt(MN)/g) in magnitude, hence O(log N) bits in the theorem regime. Counters need O(log R) bits. Numerical values require an explicit precision/range model. For numerical word width w and counter width w_R, the storage claim is of the form O(N(w+log N+w_R)) bits, rather than O(N) bits. Polynomial R and suitable logarithmic precision permit O(N) words of Theta(log N) bits under an explicitly defined word model.

In a bit model a defensible schematic budget is

    O(R[N+K log K] C_arith(w) + root/setup costs
      + input bit-reading costs + N-output bit-writing costs),

with any integer division, exact classification, conversion, and randomness costs included. Arbitrarily precise input numbers cannot be read for unit cost. This review does not promote the scalar little-o comparison to a bit-complexity or wall-clock claim.

### 5.3 Parameter regimes

For fixed R=2s-1, fixed delta in (0,1), and dyadic M within a constant factor of log N, choose g from the fixed-row bound. Then g=Theta(N^(1/(2s))) and

    work O(N), memory O(N) words,
    error O(sqrt(log N) N^(-1/2+1/(2s)) ||x||_2).

Shrinking energy-relative error requires s>=2 at fixed confidence. R=1 does not supply that shrinking guarantee. If delta=N^(-a), the exponent includes (1+a)/(2s), so a fixed s must be sufficiently large.

For growing rows, choose fixed epsilon>0, fixed a>=0, 1<=f=o(log log N), dyadic M=Theta(log N/f), g=(log N)^epsilon, and a sufficient bounded choice R=Theta((1+a)log N/(epsilon log log N)). For sufficiently large N, g>sqrt(2), K>=2M, and the work is

    O(((1+a)/epsilon) N log N * f/log log N)=o(N log N),

with error O((log N)^(1/2+epsilon)/sqrt(f) * ||x||_2/sqrt(N)). Use delta=min(1/2,N^(-a)) or a fixed confidence when a=0; delta=1 gives a vacuous claim and is rejected by the bound API. The Theta schedule needs an adequately chosen constant, not any arbitrary proportional row count.

The symbolic experiment points in V8:599–622 do not construct their astronomical N, use non-dyadic `M_proxy`, omit parity adjustment, and omit the log(2) numerator constant required for the exact 2N confidence formula. They are appropriately named proxies; they are not actual valid parameter/output executions or precise certificates of delta=N^(-a). The fixed-row symbolic points (571–597) likewise report formulas and do not instantiate input vectors.

### 5.4 What the proxy and diagnostic costs do not prove
