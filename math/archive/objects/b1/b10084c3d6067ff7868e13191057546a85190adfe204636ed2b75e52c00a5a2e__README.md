## Reproduce

From this directory, with Python 3.11+ and **no external Python packages**:

```bash
python -m unittest -v test_phase17
python independent_audit.py
sha256sum -c SHA256SUMS.txt
```

To rerun predecessor:

```bash
mkdir -p hero17_prev16
unzip -q PHASE16_PREDECESSOR.zip -d hero17_prev16
cd hero17_prev16
python -m unittest -q test_phase16
```

The root `ω` and prime `p` in the exact finite-field tests are mathematical test parameters; the special Green-feedback solver is **not** a Fourier evaluator.
