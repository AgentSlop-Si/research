# Hero #0 — composite Green FFT research checkpoint

Full proof, scope, and numerical caveats: **`HERO0_RESEARCH.md`**.

This bundle extends the previous unit-step-chirp work to **composite** transform lengths `N=K M` (without assuming prime powers) and proves the general covariance bound `M(M−1)/φ(N)`. It also contains an exact offset-class modulation shortcut for length families `N=c p^a`. Results are **randomized and approximate**, not an exact worst-case O(N) FFT.

## Install and reproduce

```bash
python -m pip install -r requirements.txt
python verify_composite.py
python verify.py
```

Optional benchmark scripts `bench_composite.py` and `benchmark.py` compare against the separately saved historical v11 source tree. Their saved results (`composite_benchmark.json`, `benchmark.json`) are included so you do not need that source to inspect the previous comparison.

## Minimal use

```python
import numpy as np
from composite_lift import CompositePlan,robust_estimate

x = np.random.default_rng(7).normal(size=3600)
plan = CompositePlan.build(len(x))     # chooses M=12
estimate = robust_estimate(x,plan,rows=9,seed=123)
exact_for_testing = np.fft.fft(x)/np.sqrt(len(x))
```

The core source's recursive scan is a linear-arithmetic exact method for the *projected* signal. The estimator is not exact for generic `x`. Input-data-dependent caches, threads and uncharged preprocessing are absent. Word/bit complexity and a universal fixed-floating-point stability proof are not established.
