# Phase 17 reproduction instructions

All the exact algebra experiments are reproducible with the Python standard library. The numerical approximation-gap audit additionally needs NumPy. No internet or external numerical service is required.

From this folder:

```bash
OPENBLAS_NUM_THREADS=1 PYTHONPATH=. python -m unittest discover -s tests -v
python green_sum_cert.py > green_prime_audit.json
python chirp_hankel.py > chirp_and_common_order_audit.json
OPENBLAS_NUM_THREADS=1 python approximation_gap.py > approximation_gap_audit.json
python product_escape_probe.py > product_escape_audit.json
```

`phase17_exact_certificates.json` contains additional fixed seeds, fields and exact minor polynomials for prime and 2^k targets, and nonzero commutator certificates.

The power-of-two polynomial calculation reduces minors modulo `Phi_(2^k)(X)=X^(N/2)+1`, avoiding floating-point Fourier determinants. Prime-size minors use the nonvanishing polynomial modulo `X^N-1` together with `Phi_N(X)=1+...+X^(N-1)` and an exact coefficient check. Independent modular Fourier ranks are one-way nonvanishing certificates, not proofs based on a zero modular determinant.

In the full archive, `previous_full_phase16_checkpoint.zip` includes Phases 12–16 and earlier original research materials. To audit independently, extract into a fresh directory and rerun the suite. The archive includes `SHA256SUMS.txt` for all Phase17 files.
