# Stable-scan, streaming-majority global-chirp Fourier sketch

**Checkpoint:** 9 October 2026  
**Version:** v8  
**Status:** A reproducible continuation of the v7 global quadratic-chirp theorem candidate. The new contributions are (i) a gauge transformation that turns the two sequential output recurrences into balanced prefix scans, and (ii) a deterministic three-shift quantization lemma that converts strict-majority concentration into an online, constant-state robust aggregator. Together they close the two explicit v7 engineering/theory obligations: logarithmic arithmetic depth for the recurrence accumulation and `O(N)` memory even when the number of randomized rows grows.  
**Not claimed:** an exact linear-time FFT, machine-precision relative accuracy, an all-length theorem, a complete bit-complexity theorem, practical superiority to FFTW/cuFFT, independent peer verification, or established novelty.

---

## 1. Executive result

Assume the v7 dyadic row theorem:

- `N=K M` with `N,K,M` powers of two and `K>=2M`;
- one independently randomized global quadratic-chirp row outputs all `N` unitary-DFT estimates in

  \[
  T_{\rm row}(N,M)=O(N+K\log K);
  \]

- every output is unbiased; and
- for every input `x` and every output index `m`,

  \[
  \mathbb E\left|\widehat X_m-X_m\right|^2
  \le \frac{2M}{N}\lVert x\rVert_2^2,
  \tag{1.1}
  \]

  with equality for an explicit worst-case input family.

This checkpoint adds an online robust aggregator. For a parameter `g>sqrt(2)`, define

\[
\tau
 =g\sqrt{\frac{2M}{N}}\lVert x\rVert_2.
\tag{1.2}
\]

For each real and imaginary output component, run Boyer--Moore majority cancellation on **three shifted scalar grids** of width `7 tau`. Store only one candidate cell and one counter per grid. If `R` independent chirp rows are consumed, the final estimate uses `O(N)` memory independent of `R`.

Let

\[
p=\frac1{g^2},
\qquad
D_g=D\!\left(\frac12\middle\|p\right)
=\frac12\log\frac1{4p(1-p)}.
\tag{1.3}
\]

Then

\[
\Pr\!\left[
 \lVert\widetilde X-U_Nx\rVert_\infty
 >5g\sqrt{\frac MN}\lVert x\rVert_2
\right]
\le 2N e^{-R D_g}.
\tag{1.4}
\]

The total charged work and storage are

\[
\boxed{
T(N,M,R)=O\!\left(R\left[N+\frac NM\log\frac NM\right]\right)
}
\tag{1.5}
\]

and

\[
\boxed{S(N,M,R)=O(N),}
\tag{1.6}
\]

where the storage bound includes the input, one active row, scan workspace, the output, block summaries, grid candidates, and counters.

Two consequences follow.

### Fixed-row `O(N)` regime

For `R=2s-1` fixed, `M=Theta(log N)`, and constant target failure probability, choose

\[
g=\Theta\!\left(N^{1/(2s)}\right).
\]

Then

\[
T(N)=O(N),\qquad S(N)=O(N),
\tag{1.7}
\]

and

\[
\lVert\widetilde X-U_Nx\rVert_\infty
=O\!\left(
 \sqrt{\log N}\,N^{-1/2+1/(2s)}\lVert x\rVert_2
\right)
\tag{1.8}
\]

with constant success probability. This recovers the v7 constant-row exponent using linear rather than `O(RN)` row storage.

### Growing-row `o(N log N)` regime

Let

\[
L=\log N,\qquad \ell=\log\log N,
\]

choose any

\[
1\le f(N)=o(\ell),
\]

and set

\[
M=\Theta\!\left(\frac{L}{f(N)}\right),
\qquad
 g=L^\varepsilon,
\qquad
 \delta=N^{-a},
\tag{1.9}
\]

for fixed `a>=0` and fixed `epsilon>0`. Taking

\[
R=\Theta\!\left(
\frac{(1+a)L}{\varepsilon\ell}
\right)
\tag{1.10}
\]

gives

\[
\boxed{
T(N)=O\!\left(
 \frac{1+a}{\varepsilon}
 \frac{f(N)}{\log\log N}
 N\log N
\right)
=o(N\log N)
}
\tag{1.11}
\]

and, with probability at least `1-N^{-a}`,

\[
\boxed{
\lVert\widetilde X-U_Nx\rVert_\infty
=O\!\left(
 \frac{(\log N)^{1/2+\varepsilon}}{\sqrt{f(N)}}
 \frac{\lVert x\rVert_2}{\sqrt N}
\right).
}
\tag{1.12}
\]

This is the strongest v7 time/error tradeoff with the previously missing `O(N)`-memory implementation.

## 2. Inherited global-chirp row

Write the input in contiguous blocks

\[
x_{r,t}=x_{rM+t},
\qquad 0\le r<K,\quad 0\le t<M.
\]

Let

\[
\zeta=e^{2\pi i/N}.
\]

Choose independently:

- `a`, uniformly among odd residues modulo `N`;
- `beta`, uniformly in `Z_N`.

Define

\[
S_{r,t}=\zeta^{a t^2+(2aMr+\beta)t}
\tag{2.1}
\]

and one block summary

\[
d_r=\sum_{t=0}^{M-1}S_{r,t}x_{r,t}.
\tag{2.2}
\]

The implicitly projected block is

\[
y_{r,t}=\overline{S_{r,t}}d_r.
\tag{2.3}
\]

The row estimate is

\[
\widehat X=U_Ny.
\tag{2.4}
\]

The projected vector is not materialized. A length-`K` FFT of the summaries and a first-order recurrence recover all outputs.

Let `D` be the unnormalized length-`K` DFT of `d`. The inherited recurrence is

\[
\begin{aligned}
\widehat X_m
={}&\frac{D_{m\bmod K}}{\sqrt N}
+\zeta^{-(a+m+\beta)}\widehat X_{m+2a}\\
&-\zeta^{-(aM^2+mM+\beta M)}
\frac{D_{(m+2aM)\bmod K}}{\sqrt N}.
\end{aligned}
\tag{2.5}
\]

Since `a` is odd and `N` is a power of two,

\[
\gcd(2a,N)=2.
\]

The output indices therefore form exactly two cycles, one even and one odd.

The v7 covariance calculation proves (1.1). This checkpoint treats that theorem as an inherited contract; it does not silently replace or weaken it.

## 3. Gauge transformation of the output recurrence

Fix a cycle seed `s in {0,1}` and enumerate

\[
m_j=s+2aj\pmod N,
\qquad 0\le j<N/2.
\tag{3.1}
\]

Define the forcing term

\[
F_m
=\frac1{\sqrt N}
\left[
D_{m\bmod K}
-\zeta^{-(aM^2+mM+\beta M)}
D_{(m+2aM)\bmod K}
\right].
\tag{3.2}
\]

Solving (2.5) in the forward cycle direction gives

\[
\widehat X_{m_{j+1}}
=\alpha_j\left(\widehat X_{m_j}-F_{m_j}\right),
\qquad
\alpha_j=\zeta^{a+\beta+m_j}.
\tag{3.3}
\]

The exact cumulative phase is

\[
A_j
=\prod_{h=0}^{j-1}\alpha_h
=\zeta^{a j^2+(\beta+s)j}.
\tag{3.4}
\]

Set

\[
Z_j=\frac{\widehat X_{m_j}}{A_j}.
\tag{3.5}
\]

Because `A_{j+1}=alpha_j A_j`, the recurrence collapses to

\[
\boxed{
Z_{j+1}=Z_j-\frac{F_{m_j}}{A_j}.
}
\tag{3.6}
\]

Thus every output on a cycle is one seed plus an exclusive prefix sum:

\[
\widehat X_{m_j}
=A_j\left[
 \widehat X_s-
 \sum_{h=0}^{j-1}\frac{F_{m_h}}{A_h}
\right].
\tag{3.7}
\]

This identity removes the long multiplicative dependency chain. It is also useful conceptually: the recurrence was never intrinsically sequential; it was a disguised scan.

## 4. Balanced scan and conditional floating-point stability

The prototype evaluates the two prefix vectors with a Blelloch up-sweep/down-sweep exclusive scan. The scan uses `O(N)` additions and has arithmetic depth `O(log N)`. The two directly evaluated cycle seeds use pairwise reductions in both the local and block dimensions.

Under the standard floating-point model, and **conditional on already supplied forcing terms and phase factors**, a serial prefix accumulation has an absolute error bound of the form

\[
\gamma_{\Theta(N)}
\sum_h\left|F_{m_h}/A_h\right|,
\tag{4.1}
\]

whereas the balanced scan gives

\[
\gamma_{O(\log N)}
\sum_h\left|F_{m_h}/A_h\right|.
\tag{4.2}
\]

Here

\[
\gamma_q=\frac{qu}{1-qu}
\]

for unit roundoff `u` whenever `qu<1`; constants for complex arithmetic are absorbed into the `O(.)` index.

This is an **absolute forward accumulation bound**, not a promise of small relative error when the true prefix is highly cancellation-dominated. It also does not yet include:

- the numerical error of the length-`K` FFT;
- correctly rounded evaluation of the roots of unity;
- modular phase arithmetic at arbitrary sizes;
- the error in forming the summaries;
- overflow/underflow and fixed-point representation choices.

Consequently, this checkpoint establishes a structural stabilization and a conditional scan bound, not a complete platform-independent floating-point theorem.

### Work remains linear

A balanced scan is not being used to claim parallel hardware. Its total arithmetic work is still `O(N)`, so it preserves the sequential row bound

\[
O(N+K\log K).
\]

Its logarithmic depth matters here because it changes the rounding-error path length.

## 5. Why exact medians caused a memory problem

The v7 robust theorem took the coordinatewise median of `R` complete output rows. A straightforward exact implementation stores `R` values for every one of `N` coordinates:

\[
\Theta(RN)
\]

scalar storage.

For constant `R`, this is still `O(N)`. In the strongest regime, however,

\[
R=\Theta\!\left(\frac{\log N}{\log\log N}\right),
\]

so exact median storage becomes superlinear.

Generic online approximate quantile structures would introduce another approximation theorem and typically nonconstant state per coordinate. The new construction instead converts a radius-majority event into an **exact discrete strict-majority event**, allowing one-pass Boyer--Moore cancellation.

## 6. Three shifted quantization grids

Consider one real scalar target `mu`. Suppose more than half of the observations lie in

\[
I=[\mu-\tau,\mu+\tau].
\tag{6.1}
\]

Use cells of width

\[
W=7\tau
\tag{6.2}
\]

with the three boundary offsets

\[
0,\qquad W/3,\qquad 2W/3.
\tag{6.3}
\]

The union of all grid boundaries has spacing

\[
W/3=7\tau/3>2\tau.
\]

Therefore the closed interval `I`, whose length is `2 tau`, intersects boundaries from at most one of the three grids. In at least two grids, the whole interval lies strictly inside one cell.

For either safe grid:

1. every good observation has the same cell ID;
2. that ID occurs in a strict majority of the complete stream;
3. Boyer--Moore cancellation returns that cell ID after one pass;
4. because the entire radius-`tau` interval lies inside the cell, its center is at most

   \[
   W/2-\tau=5\tau/2
   \]

   from `mu`.

At least two of the three candidate centers are thus in

\[
[\mu-5\tau/2,\mu+5\tau/2].
\]

Their scalar median is in the same interval, regardless of the third grid.

### Lemma 6.1 — deterministic grid-majority recovery

If a strict majority of a real stream lies within distance `tau` of `mu`, then the three-grid Boyer--Moore estimator satisfies

\[
\boxed{|\widetilde\mu-\mu|\le 5\tau/2.}
\tag{6.4}
\]

No randomness, ordering assumption, moment assumption, or second verification pass is required **conditional on the strict majority existing**.

### General constant

More generally, width

\[
W=(6+\eta)\tau,
\qquad \eta>0,
\]

gives boundary spacing greater than `2 tau` and scalar radius

\[
(2+\eta/2)\tau.
\]

The prototype uses `eta=1` for simple exact constants and comfortable finite-precision separation.

## 7. One-pass implementation

For every real Fourier component, retain three pairs

\[
(\text{candidate cell ID},\text{counter}).
\]

Do the same independently for every imaginary component. A new randomized row is processed as follows:

1. compute its `N` output estimates using the balanced decoder;
2. map each real component into its three shifted grid cells;
3. update the three Boyer--Moore candidate/counter pairs;
4. repeat for imaginary components;
5. discard the row.

After all rows, convert the candidate cell IDs to cell centers and take the median of the three centers separately for the real and imaginary parts.

If a strict majority cell exists, Boyer--Moore guarantees that its final candidate is that cell. We do not need a second counting pass because the probabilistic analysis separately bounds the event that a strict majority of good rows fails to exist.

## 8. Probability theorem

Let

\[
\sigma^2=\frac{2M}{N}\lVert x\rVert_2^2.
\tag{8.1}
\]

For one real or imaginary component of one exact row, (1.1) implies

\[
\operatorname{Var}(Y)\le \sigma^2.
\]

Choose

\[
\tau=g\sigma,
\qquad g>\sqrt2.
\tag{8.2}
\]

By Chebyshev,

\[
\Pr(|Y-\mathbb EY|>\tau)
\le p:=\frac1{g^2}<\frac12.
\tag{8.3}
\]

Rows are independent. A standard Bernoulli KL tail bound gives

\[
\Pr[\text{at least half the rows are bad}]
\le
\exp\left[-R D\!\left(\frac12\middle\|p\right)\right].
\tag{8.4}
\]

Union-bound over the real and imaginary parts of all `N` outputs:

\[
\Pr[\text{some scalar coordinate lacks a good strict majority}]
\le
2N e^{-R D_g}.
\tag{8.5}
\]

Conditional on the complement of that event, Lemma 6.1 gives a radius `5 tau/2` for each scalar component. Therefore

\[
\begin{aligned}
|\widetilde X_m-X_m|
&\le \sqrt2\frac{5\tau}{2}\\
&=5g\sqrt{\frac MN}\lVert x\rVert_2.
\end{aligned}
\tag{8.6}
\]

### Theorem 8.1 — streaming robust full-output estimator

For every `g>sqrt(2)` and every number `R` of independent rows,

\[
\boxed{
\Pr\!\left[
 \lVert\widetilde X-U_Nx\rVert_\infty
 >5g\sqrt{\frac MN}\lVert x\rVert_2
\right]
\le 2N e^{-R D_g}.
}
\tag{8.7}
\]

Choosing the nearest larger odd integer to

\[
\frac{\log(2N/\delta)}{D_g}
\tag{8.8}
\]

ensures failure probability at most `delta`.

The theorem uses only the inherited second-moment bound. It makes no subgaussian assumption; v7 already exhibited heavy-tailed one-row inputs for which such an assumption would be false.

## 9. Fixed-row analysis

Let

\[
R=2s-1.
\]

For one scalar coordinate, a bad majority requires at least `s` bad rows. Since

\[
\sum_{j=s}^{2s-1}{2s-1\choose j}=2^{R-1},
\]

we have

\[
\Pr[\text{bad scalar majority}]
\le 2^{R-1}p^s.
\]

Union-bound over `2N` scalar coordinates:

\[
\Pr[\text{failure}]
\le N2^R g^{-2s}.
\tag{9.1}
\]

It is sufficient to choose

\[
\boxed{
g\ge \left(\frac{N2^R}{\delta}\right)^{1/(2s)}.}
\tag{9.2}
\]

For fixed `R`, fixed `delta`, and `M=Theta(log N)`, one row costs `O(N)` and hence

\[
T(N)=O(N),\qquad S(N)=O(N).
\tag{9.3}
\]

The error is

\[
\boxed{
O\!\left(
 \sqrt{\log N}\,
 N^{-1/2+1/(2s)}
 \lVert x\rVert_2
\right).
}
\tag{9.4}
\]

Examples:

| Rows `R` | `s` | Simultaneous error scale at constant failure |
|---:|---:|---:|
| 3 | 2 | `O(sqrt(log N) N^(-1/4) ||x||_2)` |
| 5 | 3 | `O(sqrt(log N) N^(-1/3) ||x||_2)` |
| 9 | 5 | `O(sqrt(log N) N^(-2/5) ||x||_2)` |

This matches the v7 polynomial exponents while using online linear storage.

## 10. Growing-row analysis

Let

\[
L=\log N,
\qquad
\ell=\log L,
\]

and take

\[
M=\Theta(L/f),
\quad
1\le f=o(\ell),
\quad
g=L^\varepsilon.
\]

Then

\[
p=L^{-2\varepsilon}
\]

and

\[
D_g
=\frac12\log\frac1{4p(1-p)}
=\varepsilon\ell-O(1).
\tag{10.1}
\]

For target failure `delta=N^{-a}`,

\[
R=\Theta\!\left(
 \frac{(1+a)L}{\varepsilon\ell}
\right).
\tag{10.2}
\]

Also,

\[
K\log K
=\frac NM\Theta(L)
=\Theta(Nf),
\]

so one row costs `O(Nf)`. Multiplying by (10.2),

\[
T(N)
=O\!\left(
 \frac{1+a}{\varepsilon}
 \frac f\ell
 NL
\right).
\tag{10.3}
\]

Because `f=o(ell)`, this is `o(N log N)`.

The error becomes

\[
\begin{aligned}
5g\sqrt{\frac MN}\lVert x\rVert_2
&=O\!\left(
 L^\varepsilon
 \sqrt{\frac{L}{fN}}
 \lVert x\rVert_2
\right)\\
&=O\!\left(
 \frac{L^{1/2+\varepsilon}}{\sqrt f}
 \frac{\lVert x\rVert_2}{\sqrt N}
\right).
\end{aligned}
\tag{10.4}
\]

This proves (1.11)--(1.12).

The asymptotic statement does not assert a practical crossover at ordinary `N`. The certified constants from Chebyshev, union bounds, three grids, and Boyer--Moore are intentionally conservative; the saved symbolic proxy remains above the FFT baseline at the finite logarithms tested.

## 11. Fully charged storage

The online algorithm stores:

- the input `x`: `N` complex words;
- one active row or scan output: `N` complex words;
- balanced scan workspace: `O(N)` complex words;
- final output: `N` complex words;
- `K=N/M` summaries and their FFT: `O(K)` complex words;
- for each scalar output, three candidate cell IDs and three counters.

There are two scalar components per complex output, so the majority state uses a constant number of machine words per output.

### Candidate ID bit width

Each block projection has operator norm `M`, hence

\[
\lVert y\rVert_2\le M\lVert x\rVert_2.
\]

The unitary DFT preserves the norm, so every row output magnitude is at most `M||x||_2`. Dividing by the cell width

\[
7g\sqrt{2M/N}\lVert x\rVert_2
\]

shows that a cell ID has magnitude at most

\[
O\!\left(\frac{\sqrt{MN}}{g}\right)
\le O(N).
\]

It therefore fits in `O(log N)` bits. In the growing-row regime the counter is at most polylogarithmic in `N`, so it also fits in one `Theta(log N)`-bit word.

Thus

\[
\boxed{S(N)=O(N)\text{ words, independent of }R.}
\]

The Python prototype uses `int64` candidate IDs and `int32` counters for the tested sizes. A production arbitrary-size implementation must use the word-width assumptions above rather than silently relying on fixed NumPy integer ranges.

## 14. Prior-art boundary

The ingredients are not individually new:

- balanced prefix scans are classical; the implementation follows the up-sweep/down-sweep structure associated with Blelloch;
- logarithmic-depth pairwise summation and its improved roundoff-depth bound are standard numerical analysis;
- Boyer--Moore majority cancellation is classical and returns a strict majority in one pass using a candidate and counter;
- Chebyshev, binomial/KL tails, and union bounds are standard;
- quadratic chirps, block projections, and FFT recurrences have extensive prior art.

The project-specific combination is:

1. the v7 exact `2M/N` per-output covariance theorem for this global-chirp row;
2. the explicit gauge that turns its two output cycles into prefix scans;
3. three shifted grids that convert a continuous radius-majority event into at least two discrete strict majorities;
4. one Boyer--Moore state per grid and scalar output;
5. the resulting `O(N)`-memory preservation of both the constant-row and growing-row v7 tradeoffs.

A limited search did not locate this exact combination. That is not a novelty proof. No novelty claim should be made without a substantially broader literature review and independent mathematical verification.

Useful classical references:

- Guy E. Blelloch, *Prefix Sums and Their Applications*.
- Robert S. Boyer and J Strother Moore, *MJRTY -- A Fast Majority Vote Algorithm*.
- Nicholas J. Higham, *Accuracy and Stability of Numerical Algorithms*, 2nd ed.

## 15. Honest boundary

This checkpoint does **not** establish any of the following:

1. **Exact sub-`N log N` DFT.** The transform is randomized and approximate.
2. **Coefficientwise relative error.** The guarantee is absolute and energy-relative.
3. **Machine-precision FFT replacement.** The asymptotic error is much larger than ordinary floating-point FFT error on many inputs.
4. **All lengths.** The proof currently assumes dyadic `N=KM` and `K>=2M`.
5. **Complete floating-point theorem.** The scan accumulation is stabilized, but FFT, phase generation, summary formation, and range reduction remain to be incorporated.
6. **Bit complexity.** Arithmetic, word operations, transcendental phases, and input precision still require a precise computational model.
7. **Practical speedup.** The Python code is a verifier. No fair native benchmark against FFTW, MKL, pocketfft, or cuFFT has been run.
8. **Independent proof verification.** The inherited covariance theorem and this continuation are project results, not peer-reviewed theorems.
9. **Established novelty.** The prior-art search is incomplete.

The robust theorem itself is exact-arithmetic. If each numerically computed row has an additional deterministic coordinate error at most `eta_fp`, the same grid proof can be rerun with radius `tau+eta_fp`; obtaining a useful rigorous `eta_fp` is the remaining numerical-analysis task.

## 16. Exact next targets

The next phase should not return to coordinate sparsification, `A-k` decompositions, or cached-input relations. The surviving obligations are now narrower:

1. **Full end-to-end floating-point bound.** Combine a stable FFT bound, correctly rounded/root-table phases, balanced seed reductions, and the scan bound into an explicit `eta_fp(N,M,x)`.
2. **Native implementation.** Implement the scan and six Boyer--Moore states per complex output in C++ with FFTW/pocketfft, SIMD-friendly cell-ID updates, and no `R x N` allocation.
3. **Mixed-radix/all-length extension.** Generalize the two-cycle structure and the v7 covariance decomposition beyond powers of two.
4. **Sharper robust constants.** The general width `(6+eta)tau` approaches complex constant `4g` as `eta` tends to zero; a finite-precision implementation must balance this against boundary sensitivity.
5. **Independent proof audit.** Formalize the v7 covariance theorem and the v8 grid-majority theorem separately, preferably with a computer algebra or proof-assistant certificate for the finite dyadic identities.
6. **Prior-art audit.** Search robust streaming mean estimation, quantized majority sketches, chirp sensing, randomized Fourier transforms, and scan-stabilized recurrences before discussing novelty.

> The v7 global-chirp approximation no longer needs a sequential `N`-deep accumulation or `O(RN)` median storage.
