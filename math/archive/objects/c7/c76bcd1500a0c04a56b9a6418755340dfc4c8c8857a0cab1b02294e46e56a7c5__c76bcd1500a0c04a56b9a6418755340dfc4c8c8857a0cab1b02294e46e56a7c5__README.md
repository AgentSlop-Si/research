# FFT research: 3-stage bit-reversal exclusion — October 10, 2026

**Primary finding:** For all powers of two `N>=64`, the exact Fourier matrix cannot equal `S3 @ bitrev @ S2 @ bitrev @ S1` with three arbitrary quasiseparable rank-one matrices (natural Fourier endpoints). This is proved by an explicit `12m+1` scalar-channel cut against a full-rank `13m×13m` Fourier minor, `N=32m`. No assumptions on generator nonzero entries, coefficient size, stability, or matrix invertibility.
