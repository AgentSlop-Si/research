# Do not repeat: bidirectional macro FFT work audit

## What was resolved

- A single independent forward+backward scan stage has off-diagonal cut rank at most one per direction.
- Reordering both inputs and outputs lets one stage implement a **four-point** DFT exactly.
- For eight points, the exact minimum number of independent channels per direction is **three** across all endpoint orderings. Proven by a dyadic three-character uncertainty induction, checked by exhaustive endpoint-order DP and independent cyclotomic/module tests.
- For complete B-point radix blocks, each one-stage sum of full-length independent scan channels needs Omega(B) channels and Omega(B^2) scan work per block. A blockwise mixed-radix FFT assembled this way cannot asymptotically beat N log N by increasing B.
- A standard exact radix-4 computation in this form reduces macro-stage count by about half but is slower in the Python prototype and uses more elementary gates.
- Unitarty fixed-rank quasiseparable stages remain within established unitary Givens lower-bound arguments; this does not reject nonunitary stages.

## The genuinely unresolved hypothesis

Can **nonunitary overlapping full-array bidirectional stages** with arbitrary inter-stage O(N)-cost permutations multiply to F_N with a number of stages o(log N), each stage requiring only O(N) *charged* scalar operations and correctly producing all N outputs for every fresh complex input?

Do not try a blockwise B-point FFT disguised as one O(N) macro: channel rank scales with B. Do not ignore condition numbers, scalar preparation, memory movement, input restrictions, cached answers, or output representation.

A valid positive result would need an exact uniform all-N identity, a printed scalar circuit, a bound on its total O(N)*stage work, independent verifier, and prior-art comparison with both ordinary FFT and #130 in the same model. A numerical fit at N=8 or N=16 is not enough.

## Immediate falsification test

For a proposed nonunitary overlap stage, analyze its inverse's quasiseparable/displacement structure *after each inter-stage shuffle* and compare the actual forward/backward rank profiles against the Fourier target. A nonunitary stage with a dense inverse alone is insufficient; we already checked that. Examine intermediate coefficient magnitudes, state traffic and cancellation, not just stage count.
