# FFT offset-class joint lift v12

Reproducible research package for:

- exact nearest-grid offset classes for prime-power lifts;
- an unbiased exact-center randomized all-output Fourier estimator;
- adaptive selection between offset classes and the v11 Bessel lift;
- an exact restricted rank gate for black-box scan fusion;
- a repaired standalone v11 regression suite.

Run:

```bash
python -m pip install -r requirements.txt
pytest -q
python prototype.py --output results.json
python benchmark.py
```

Read `RESEARCH.md` for theorem statements, proofs, scope, and limitations.
