## Result

There is no new arbitrary-input exact o(N log N) FFT construction here. Three archives add substantive scoped mathematics; the fourth supplies the missing original implementation for an already-audited theorem. All four are worth preserving with distinct verification labels.

- **HERO17:** newly available original code, but the research note is byte-identical to the note already independently audited. Static implementation matches the proved fixed-r restricted theorem and does not include our later polynomial-cost eliminant extension.
- **Phase26:** a new common-cut theorem for products of sums of weighted, bounded-affine-step cyclic Green inverses. The initial proof review found no central mathematical flaw. Deeper independent checking is warranted.
- **Sparse-defect gate:** a credible, elementary Fourier-specific sparse-plus-low-rank inverse-stage obstruction. Its purported surviving-class conclusion is broader than the supplied separating proof, and its variable-r Woodbury preparation cost needs correction.
- **v13:** a genuine mixed-radix composition of the inherited randomized dyadic sketch, with independent-column covariance and an exact M-bank frame. The exact M-bank identity was already proved in the master checkpoint at 17:17 UTC on October 9; its appearance here is corroborating implementation/packaging, not a new discovery. The exact reconstruction uses M passes and does not improve the target FFT bound. Deeper independent checking should focus on inherited covariance, physical projector conventions, and charged costs.

## 2. Phase26: simultaneous common-character cuts

Read first:

- `phase26/fft_green_phase26_simultaneous_cuts/THEOREM.md`
- `phase26/fft_green_phase26_simultaneous_cuts/phase26_cuts.py`
- `phase26/fft_green_phase26_simultaneous_cuts/tests/test_phase26.py`
- `phase26/fft_green_phase26_simultaneous_cuts/audit.py`

Compared with Phase25's single twisted zigzag sum, this adds variable edge weights, arbitrarily many product stages, arbitrary diagonal gates, and intermediate **affine** coordinate permutations. It uses one simultaneous Fourier-character cut for the full transformed stride set. With d bounded steps per Green term, Q total terms, s≤dQ distinct transformed strides, and B exceptional edges, it obtains rank ≤2dQN/floor((N−1)^(1/s))+B. For bounded d and bridges per term, exact Fourier equality requires Q=Ω(log N/log log N).

The initial mathematical chain is coherent: pigeonhole yields a nonzero character; power-of-two lengths make its half-circle cut exactly balanced even when the character is nonprimitive; each translation crosses exactly the centered-residue magnitude; inverse off-block ranks equal denominator off-block ranks because proper cycle restrictions are acyclic; sums/products have additive common-cut rank; affine permutations can be conjugated to a boundary. The universal Fourier balanced-block rank N/4 and the stated spectral error floor follow from Frobenius norm and contraction bounds. Arbitrary internal non-affine permutations remain outside the theorem.

Audit priorities: independently test weighted zero/nonzero edge cases, affine conjugation orientation, the special alternating-quarter Fourier minor, and the spectral theorem over C separately from modular rank checks. The coarse cut routine implements the d=1 budget; do not mistake it for a general-d cost routine. `simultaneous_cut` uses a floating threshold/tolerance in a witness search, despite the exact underlying theorem; an independent verifier should compare `r*abs(t)<N` with integers.

The 67 reported suite passes are source-recorded historical claims. Static code contains 15 new test methods. Note `tests/test_phase26.py` places a `unittest.main()` guard before later test classes; discovery/import as documented sees all classes, but directly executing that file would start tests before the later classes are defined.

## 3. Sparse-plus-low-rank inverse-stage gate

Read first:

- `sparse_gate/fft_sparse_defect_gate_2026-10-10/PROOF_CERTIFICATE.md`
- `sparse_gate/fft_sparse_defect_gate_2026-10-10/sparse_defect.py`
- `sparse_gate/fft_sparse_defect_gate_2026-10-10/green_woodbury.py`
- `sparse_gate/fft_sparse_defect_gate_2026-10-10/interleaved_separation.py`

New main theorem: for arbitrary row-q-sparse B, rank(F_N−B)≥floor(N/(q+1)), robust under endpoint monomials. Choosing consecutive Fourier-frequency rows and avoiding their sparse supports gives a nonsingular Vandermonde minor. Telescoping inverse-stage products yields sum r_j≥floor(N/(1+product s_j)). The argument is elementary, all-length, and does not depend on conditioning. This genuinely extends the previous pure sparse-inverse support barrier.

The explicit dense separated scan S with lower/diagonal/upper entries 1/3/2 has an elementary O(N) inverse scan and an explicit off-band minor proving rank(S⁻¹−T)≥floor((N+b)/(2b+2)) for **bandwidth-b T**.

Two cautions need follow-up:

1. This proves escape from bounded-bandwidth-plus-small-rank inverses in the displayed ordering. The main negative theorem permits **arbitrary row-sparse** baselines and arbitrary monomial connectors. The provided off-band proof does not establish escape from that whole larger class. The theorem title, research interpretation, and handoff overstate the surviving-class conclusion. Either narrow the wording or prove a stronger arbitrary-sparsity separation.
2. Woodbury preparation explicitly forms VᵀZ, which costs O(Nr²), then inverts an r×r matrix. Charged preparation is O(Nr²+r³), while fresh-vector application is O(Nr+r²). Statements quoting O(Nr+r³) preparation/application together need correction. Constant-r O(N) still holds, so the principal scoped depth exclusion is unaffected.

All five new Python files were read and parsed. Seven test groups are present. The supplied runner compiles and executes nested predecessor C++/Python; it was not run here. Saved modular test counts are historical source evidence only. General int64 NumPy modular products can overflow outside the tested small-N/prime regimes; tests do not establish arbitrary-size executable modular arithmetic.

## 4. v13: mixed-radix sketches and exact beta frames

Read first:

Read all six newly written Python files; the five inherited source/test files were verified byte-identical rather than re-audited.

The new composition is classical Cooley–Tukey for N=Gm, dyadic G and odd m, using **independent** G-point sketch states across the m input columns. It removes v12's Bessel truncation bias for these factors but retains stochastic projection error. The exact fixed-state operator is F_NP with P²=MP, rank(P)=N/M, operator error M−1 for M≥2, and expected global squared error (M−1)||x||². Independent states correctly remove cross-column covariance terms; common states can multiply variance by m.

M shifted beta banks sum to MI and therefore reconstruct Fourier exactly. The parent confirms this exact M-bank identity was already proved in the master checkpoint at 17:17 UTC on October 9, 2026. This package supplies another implementation and finite-instance certificate, not a newly discovered bank identity. It is a useful exact identity and a tight rank count for sums of these whole sketch maps, but the supplied implementation does M complete passes. Its all-bank cost remains O(MN+MN log(m+1)+N log(G/M)); no arbitrary dense sub-N-log-N executor follows. Odd lengths fall back to a conventional FFT. The source explicitly states these limitations.

Priority independent checks: physical projector signs/gauges against the inherited core; exhaustive small-state covariance; rank and beta-bank reconstruction with independently written exact modular code; inherited majority-estimator conditions; complete precision/bit costs. The supplied finite-field script verifies a projected-input Fourier identity, not the optimized floating scan executor itself. These are complementary evidence streams, not interchangeable implementation proofs.

The 45,696 finite-field matrix entries, 1,664 local entries, 38 source-reported tests, and 10 precision diagnostics remain historical here. Work proxies explicitly omit phase/root generation, sampling, and constant factors; keep them labeled proxies and preserve the source's different-accuracy-target warning. Finite-precision discussion is partial and conditional, not a completed end-to-end theorem.
