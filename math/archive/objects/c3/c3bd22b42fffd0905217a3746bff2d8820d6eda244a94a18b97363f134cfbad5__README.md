# Fourier–Green two-column phase pencil — reproducible package

**Purpose:** derive a sharper exact phase rejection gate for the user's candidate four-Green product, distinguish it from the earlier Phase 18/19 diagonal similarity/cocycle machinery, and supply a full-spark counterexample to rank-only tests.

**Files:** `THEORY.md` (formal theorems/proofs), `verify.py` (primary GF65537 verifier), `independent_certificate.py` (independent Green series and 8x8 determinant checker), `stress_sizes.py` (power-of-two repeated pencil tests), `RESULTS.json` (complete witness, including branch permutations/weights), `CERTIFICATE.json` (compact pencil determinant witness), `STRESS_RESULTS.json`, `VERIFY_LOG.txt`, `SOURCE_ARCHIVE_AUDIT.json`, `NEXT_EXACT_GATE.md`.

Reproduce:

```bash
python verify.py
python independent_certificate.py
python stress_sizes.py
```

No NumPy FFT or external solver is required. The first verifier reconstructs and checks **all 12,869 square minors** of the witness, so it is intentionally an N=8 audit rather than a fast practical FFT engine.

**Key numerical field certificate:** `N=8`, `GF(65537)`, `ω=4096`, `det K_0=55687`, all 12,869 square minors nonzero, all 225 Fourier coset rank profiles passed. These exact modular results have an algebraic lifting interpretation in `THEORY.md`.

**Not claimed:** any exact all-input O(N) FFT, all-parameter impossibility for four Green branches, publication-level novelty, practical linear-time phase-certifier, or free preprocessing.
