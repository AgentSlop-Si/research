## New positive theorem

For arbitrary length `N` and prime-power lift `Q=p^E >= N`, nearest-grid residuals

`theta_k = kQ/N - round(kQ/N)`

form exactly

`L = N/gcd(N,Q)`

distinct classes.

For each class `theta`, modulate and pad

`y_theta[n] = x[n] exp(-2*pi*i*n*theta/Q)`.

Then for every `k` in that class,

`sqrt(Q/N) * U_Q(y_theta)[j_k] = U_N(x)[k]`.

One v9 unit-step chirp row per class is therefore unbiased for the exact `N`-DFT center and obeys

`E |Xhat_k-X_k|^2 <= (M/N)||x||_2^2`.

One row costs

`O(L [Q + (Q/M) log(Q/M)])`

and uses `O(Q+N)` memory when classes are streamed.

For `N=c p^e` with fixed `c,p`, `L=c`, so this is an `O(N)` fresh-input full-output randomized row with no Bessel truncation bias.

## Restricted negative theorem

After `R` arbitrary channel forcing sequences have already been materialized, choose only their first forcing values nonzero. At `R` distinct offsets the later outputs contain a diagonally scaled Chebyshev--Vandermonde map of exact rank `R`.

Therefore an exact **linear black-box** one-pass state across that scan cut needs at least `R` scalar coordinates. This is not a lower bound for all FFT algorithms and does not rule out pre-materialization analytic fusion.
