# Implemented median baseline for the shrinking-error decoder

9 October 2026. This is an independently authored implementation and verification of the median refinement already suggested in the uploaded `fft_control_variate_fusion_research/THEOREM_REVIEW.md`. The idea and factor-one L1 property are not new discoveries or novelty claims.

## Exact fit and optimal guarantee

Let M(v)=sum_j(|Re(v_j)|+|Im(v_j)|), q=gcd(N,4), n=N/q. For each of the q index classes j mod q, choose the lower median of its real coordinates and the lower median of its imaginary coordinates. Write that Gaussian-integer pair as a_s and set h_j=a_(j mod q), r=x-h.

For any q-periodic complex comparison h*,

    M(r) = min_{q-periodic h*} M(x-h*) <= M(x-h*)
    M(r) <= M(x).

The first equality follows because each real absolute-deviation sum is minimized by a median and the 2q clusters separate. For an even-size cluster, either middle order statistic is a minimizer; choosing the lower one retains an integer. This improves the exact-mean fit's factor-two comparison to factor one. It also cannot have larger residual mass than the uploaded componentwise mean-or-zero choice, including when that choice uses rational means.

No universal improvement factor tending to zero is possible for this small family. At N=8, x=(1,1,1,1,-1,-1,-1,-1) has two opposite values in each of the four clusters, so even its optimal periodic L1 residual equals M(x)=8. A minimizing median need not be zero; the tie does not change the optimal mass.

## Exact cheap spectrum and finite words

Only q Fourier bins can be nonzero:

    (Fh)_(tn) = n sum_(s=0..q-1) a_s exp(-2πist/q),  0<=t<q.

All q-th roots are ±1 or ±i. These values are Gaussian integers. The implementation fills all N output positions, so writing zero slots is charged too. The raw class sums also give (Fx)_(tn) exactly, independently of the fit. The adapter preserves the uploaded integrator's useful exact replacement of those q bins.

For input component magnitudes at most A, medians have magnitude at most A, residual components at most 2A, M(r)<=M(x)<=2NA, and each baseline component is at most NA. With A=N^C for fixed C, these quantities have O(log N) bits. Unlike the uploaded exact means, this fit requires no n-scaled residual or rational time-domain baseline.

The decoder's rational numerator/denominator output still needs its existing O(log N)-bit width contract. Combining baseline and residual may require increasing the fixed constant in the machine width. Python's arbitrary integers are used for exact testing, not claimed as unit-cost for arbitrary-size inputs.

## All fitting, selection and outputs are paid

`median_baseline.py` implements deterministic median-of-medians selection. It sorts only groups of at most five, recursively selects the group-median pivot, partitions, then recurses on the selected side. Standard counting gives

    T(n) <= T(ceil(n/5)) + T(7n/10+O(1)) + O(n) = O(n).

There are 2q<=8 disjoint real clusters with total 2N entries. Input validation, clustering, raw sums, selections, residual construction and mass, q²<=16 short-spectrum terms, and the full N-slot baseline all cost O(N). The implementation uses O(N) memory; it does not sort an entire cluster and call that linear time.

`combine_decoded_mean` takes an already validated decoder sample-mean approximation A_k/D to (Fr)_k/M(r). It returns

    Fhat_k = (D*(Fh)_k + M(r)*A_k)/D,

then overwrites q corner bins from the exact raw sums. It does O(N) work and emits all N rational coefficient pairs. Zero residual bypasses the decoder and returns the exact integer spectrum. A supplied failure flag remains a flagged failure; placeholders are never labeled accurate. This adapter does not sample or run a decoder and is not an end-to-end Fourier implementation.

## Error and normalization contract

If the existing decoder has simultaneous error eta_N*M(r) for the unnormalized DFT, the fused result satisfies

    ||Fhat-Fx||_infinity <= eta_N M(r).

Equivalently, for U=F/sqrt(N),

    max_k |Fhat_k/sqrt(N)-(Ux)_k| <= eta_N M(r)/sqrt(N).

The stored outputs are rational approximations to the UNNORMALIZED transform. The /sqrt(N) in the second statement is mathematical. It is not a claim that finite dyadic unit-normalized outputs are exact at zero residual. For example the all-ones N=2 input has exact unnormalized DC=2 but unitary DC=sqrt(2). Ordinary numerical unitary outputs need a separately charged normalization/rounding term, or an explicitly allowed algebraic shared scale. The uploaded theorem makes this distinction correctly.

Using eta_N=O(loglog N/sqrt(log N)) keeps all fitting, cold tables, sampling and N outputs in the established O(N) bounded/common-scale word model. The wider O(N tau) versus O(loglog N/sqrt(tau log N)) tradeoff is preserved. This improves a data-dependent error certificate, not exact arbitrary-input complexity or conventional FFT accuracy.

## Concrete improvements and boundary examples

- N=21, twenty copies of 100 and one 101: input mass 2101, uploaded mean residual mass 40/21, median residual mass 1. Both fits are useful; median roughly halves the residual certificate.
- N=9, eight copies of 5 and one 100: mean residual mass is 1520/9>140, so the uploaded safeguard chooses zero with residual 140. Median 5 gives residual 95.
- N=8, four +1 followed by four -1: optimal residual is 8, exactly input mass. No improvement is certified.
- N=12, three repetitions of the same four complex integer values: residual zero and a fully exact unnormalized spectrum.

## Verification actually run

Run `python3 median_baseline.py` with standard Python. It writes `median_results.json` alongside the script. No uploaded code is imported or executed.

- 9,822 exact selection checks against order statistics, including ties and endpoints.
- 1,000 random integer-complex fits over N=1 through 100.
- 20 exact finite-field reference DFT checks of the baseline support and quarter-rotation signs.
- Four named boundary/examples and four rational-adapter checks, including exact corner overrides and failure propagation.
- The separate `check_residual_independent.py` used 3,000 rational cases to verify the uploaded fit's decomposition, no-worse bound, exact periodic behavior, and factor-two comparison.

These finite checks support the implementation and algebra. They are not a practical FFT speed benchmark, independent proof of the decoder, or novelty evidence.
