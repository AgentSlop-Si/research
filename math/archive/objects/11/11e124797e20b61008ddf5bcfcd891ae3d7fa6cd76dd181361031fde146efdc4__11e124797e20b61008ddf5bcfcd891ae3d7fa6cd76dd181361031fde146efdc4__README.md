# Exact Fourier reuse and structured-input transforms

## Direct extension to the complete Fourier transform

The stronger `fourier_rational.py` implementation works directly on the full
positive-sign DFT F, using only its supplied primitive Nth root q. Define

    E[i,i] = -q^i,
    E[i,i+1] = -q^i (q^(i+1)-1)   for i<N-1,
    (J y)_i = (q^(-i-1)-1)y_(i+1) - q^(-i-1)y_(i+2),

with cyclic output indices. The last upper edge of E is zero, so E is
upper bidiagonal, not cyclic. Direct entrywise multiplication proves
**F E=J F**, including the endpoints. Equivalently this follows from the
ordinary Fourier shift/modulation relations; it is not an independent
faster-FFT theorem or a novelty claim for these identities.

For a supplied lambda!=0 with lambda^N!=1 and a paid Fourier anchor y=F x,

    x'=(E-lambda I)^-1 x,
    F x'=(J-lambda I)^-1 y.

E-lambda I has nonzero diagonal entries -q^i-lambda: since N is even,
their zeros are precisely the Nth roots of unity. Their inverses are
prepared with prefix/suffix batch inversion using one field inverse and
O(N) multiplications. A backward bidiagonal scan produces x'. The output
uses the width-two cyclic solver below. Checking the whole source equation
before emitting the reused output also takes O(N).

These source inverses are upper triangular. A final-coordinate basis vector
becomes fully dense, and generic dense queries can change every coordinate;
the statement below about *every* basis vector becoming dense concerns the
different weighted-cyclic R family only. Both families are full-rank maps.

Sixteen additional related queries, with the initial FFT, all preparation,
source generation, relation verification and outputs charged, give:

| N | Rational graph scalar operations | Separate ordinary FFT scalar operations |
|---:|---:|---:|
| 128 | 34,830 | 30,247 |
| 512 | 141,008 | 147,177 |
| 2,048 | 570,322 | 693,227 |
| 8,192 | 2,306,004 | 3,190,765 |

Every transition changed all N coordinates in these finite-field workloads.
The smaller case loses because setup/constants matter. These are exact
instrumented field-operation counts, not timings; the ordinary FFT shares
its setup and already skips re-preparation. Both methods return the same
full Fourier vectors. Unlike the H-only comparator below, no 2Nth root is
needed for this comparison.

`python3 audit_fourier.py` checks 132 complete basis vectors and 30 mixed
vectors in exact prime/cyclotomic fields, 50 invalid-shift/relation controls,
and every large batch output against an ordinary radix-two DFT. The batch
cost is O(N log N+QN), so amortized linear work holds for sufficiently many
queries satisfying the explicit verified relation. Arbitrary independent
inputs remain outside that promise.

For a fresh arbitrary x', one can certainly form x=(E-lambda I)x' in linear
work. However its Fourier anchor F x has then not been computed. Treating
that new anchor as cached would hide the original difficulty. The benefit
requires an actually available anchor whose creation is paid in the ledger.

## Cold full Fourier transforms from sparse recurrence defects

The same identity also gives an exact fresh-input algorithm for a restricted
class of dense vectors, without a paid FFT anchor. For a supplied admissible
lambda, discover the complete residual

    u=(E-lambda I)x.

If u has s nonzero entries, compute all N entries of F u directly from those
entries, then solve

    F x=(J-lambda I)^-1 F u.

Preparation, residual discovery, and the band solve each cost O(N). Sparse
Fourier evaluation costs O(Ns), including all N outputs. Explicit binary
exponentiation charges O(s log N) work for the phase roots; this is absorbed
in O(N(s+1)). Thus the cold cost is **O(N(s+1)) exact field operations**, with
O(N+s) storage. No FFT anchor is hidden. Fixed s gives linear work even for
some fully dense inputs: solving (E-lambda I)x=e_(N-1) gives nonzero entries
at every coordinate because all backward-solve diagonal and upper coefficients
are nonzero.

`try_recurrence_fourier` implements this cold route. `corrected_fourier_output`
also allows a paid nonzero anchor: for the verified sparse defect
u=(E-lambda I)x'-x_anchor, it returns

    F x'=(J-lambda I)^-1(y_anchor+F u).

The plus sign is essential. Both functions scan every input coordinate and
decline if the residual exceeds the supplied support cap. Declined queries
still pay that scan and residual arithmetic; no favorable shift search is
included in these two supplied-plan entry points. A corrupted nonzero anchor
output is not authenticated by residual verification.

For an accepted residual with support s, the implementation charges
13N-2+(2N-1)s+P online field operations, where P is the explicitly counted
phase-root exponentiation cost. The full cold plan adds 21N+7, giving
34N+5+(2N-1)s+P. Declines pay 4N-2 field operations and N support comparisons
after plan preparation. Output writes and support storage are also linear.

`python3 audit_defects.py` checks 40 accepted full Fourier outputs and 30
decline controls in prime and characteristic-zero cyclotomic fields, including
fully dense one-defect inputs and perturbed nonzero anchors. Every accepted
output is compared with a dense Fourier-matrix oracle. This structural promise
does not cover arbitrary inputs; exact field-operation bounds do not assert
linear bit complexity or numerical stability for floating-point arithmetic.

## The original finite q-kernel extension

9 October 2026. This extends the earlier support-preserving orbit update
H R = D H to dense inverse queries. Given one exact paid anchor y=H x,
for a supplied scalar lambda with lambda^N!=1, define

    x' = (R-lambda I)^-1 x.

Then

    H x' = (D-lambda I)^-1 y.

Both related input and full output can be computed in O(N) exact field
operations and O(N) field-element storage. A supplied query can instead be
verified by checking (R-lambda I)x'=x in O(N) before using the cached result.
The implementation charges that full check. This is a full-rank family of
dense related queries; it is not restricted to low-rank tail operators.

**It does not accelerate a single fresh arbitrary transform.** An arbitrary
new vector need not satisfy this relation for any lambda. The initial H action
is charged, and finding a suitable relation among many anchors is outside the
one-supplied-edge contract. The current solver requires lambda!=0 and dyadic
N>=4; zero shift is excluded by this triangular representation, even though
the underlying R and D are invertible.

## Exact finite operators

Use the earlier finite-boundary C and H=H_q(C). The supplied q is a primitive
Nth root over a field of characteristic not dividing N. From
`fft_sparse_grading_research`, R is a weighted cyclic shift of order N,
and D=R(I-C)=H R H^-1 has only a first and a second upper cyclic diagonal.
The original boundary corner is included in both coefficients.

Intertwining gives H(R-lambda I)=(D-lambda I)H. When invertible, multiplication
by the two inverses proves the displayed query identity. Since R has one
weighted cycle with product of weights one, its characteristic polynomial is
z^N-1. D is similar to R. Hence both shifted operators are invertible exactly
when lambda^N!=1. No spectral approximation or field extension is used by
the query solver.

The inverse input map is dense. For example,

    (R-lambda I)^-1
      = (sum_(j=0)^(N-1) lambda^(N-1-j) R^j)/(1-lambda^N).

For nonzero lambda every coordinate basis input therefore maps to a vector
with every coordinate nonzero. Expanding this formula directly is quadratic;
the solver below exploits the sparse inverse equation instead. The tests also
find dense differences at every coordinate in the generated workload.

## Constant-width cyclic solve, with closure charged

For either shifted operator, write A=T+U V^T. T keeps the nonwrapping upper
diagonals and has constant diagonal -lambda. V selects the first w coordinates,
where w=1 for R and w=2 for D. U contains exactly the removed wraparound
entries. T is invertible because lambda!=0 and can be solved by one backward
scan using at most w successors per row.

Prepare Z=T^-1 U and S=I+V^T Z. The dimensions of S are at most two. A right
hand side b is solved by

    z=T^-1 b,   alpha=S^-1 V^T z,   A^-1 b=z-Z alpha.

The formula follows by substitution. The 1-by-1 or 2-by-2 closure inverse is
prepared explicitly and its zero determinant is rejected. No dense N-by-N
matrix, hidden H action, or Fourier transform appears in this procedure.
Preparation uses w triangular scans, a constant-size inverse, O(N) coefficient
storage, and O(N) arithmetic. Each solve uses one triangular scan and w
rank-one corrections. Setup is linear even when lambda changes for every
query; sharing it for a fixed lambda improves constants.

This is an application of standard low-rank boundary closure and resolvent
intertwining, not a novelty claim for matrix inversion. Cyclic-band solving
has extensive prior work, including T. Sogabe, *New algorithms for solving
periodic tridiagonal and periodic pentadiagonal linear systems*, Applied
Mathematics and Computation (2008),
https://doi.org/10.1016/j.amc.2008.03.030 . The implementation and the exact finite
q-kernel application are the contribution of this checkpoint.

## Cost and trust boundaries

Every field addition, subtraction, multiplication, negation and inverse used
in preparation/solving is instrumented. Zero coefficients are conservatively
charged. Indexing, padding, copies, equality checks and full output writes are
O(N) and are reported separately or covered by the asymptotic word-work bound;
field operation totals are not exhaustive CPU instruction counts.

The anchor y=H x and supplied grading plans are trusted internal state. Query
verification checks the entire relation but does not authenticate a corrupted
cached y. A plan checks its N/q keys when reusing a grading plan. A caller must
also keep the exact field representation consistent. Primitive-root discovery
and the bit sizes of exact field elements are outside this arithmetic model.
No floating-point conditioning guarantee is supplied for shifts near a root
of unity.

The comparison in `results.json` uses the existing ordinary O(N log N) H(C)
evaluator as the same-target baseline. Both methods pay for their first H
anchor, common related-input generation, common preparation, and all output
vectors. The graph also pays its target solve preparation and verifies every
query relation. The baseline shares its ordinary Fourier preparation among
all queries; it is not forced to reprepare on every input. Its supplied
primitive 2Nth root is an explicit extra assumption of that comparator.

Thus a chain of Q related queries costs O(N log N+QN) including its anchor,
against O((Q+1)N log N) for separately applying the ordinary H evaluator.
For Q growing at least as fast as log N, the amortized work per fully emitted
related output is O(N), matching its output-size order. This is a batch and
relation promise, not a worst-case single-query FFT theorem.

## Reproduce

Run `python3 run_audit.py`. Dependencies are the sibling earlier grading,
boundary, q-basis and resolvent helper folders. The audit uses two prime fields
at N=4,8,16,32 and exact cyclotomic fields at N=4,8. It checks 132 complete
basis vectors, 30 mixed vectors, 20 singular-shift rejections and 10 corrupted-
relation rejections. Each accepted query is checked against independent
sparse-C Horner, and both shifted inverse equations are checked separately.
Larger prime-field batch comparisons at N=32,64,128,256 check every output
against the ordinary H(C) comparator. All initial and per-query field ledgers
are retained. Finite checks audit the implementation; the formulas above
prove the stated all-size relationship.


## Automatic shift discovery for the cold defect family

`detected_fourier.py` removes the need to supply a favorable lambda. It scans
the fresh input first. If at most 2s coordinates are nonzero, it computes the
complete sparse-input DFT directly. Otherwise, any shift producing at most
s defects must be a strict majority among `(E x)_i/x_i` at nonzero x_i.
Boyer-Moore cancellation compares these ratios using exact cross-products,
uses one paid inverse for the candidate, rejects zero/root-of-unity shifts,
and verifies every residual coordinate before evaluation.

All discovery, phase construction, input-dependent inversions, cold solver
preparation and N output writes are charged. The accepted cost is
O(N(s+1)); unsuccessful detection costs O(N) and returns a decline. This
covers the union of inputs with at most 2s nonzero coordinates and inputs
with at most s recurrence defects for some admissible shift. It remains a
restricted family of fresh inputs, not a universal faster FFT. The historical
`constant_inverse` ledger label includes paid input-dependent inversions here;
this is an adaptive rational arithmetic algorithm, not a fixed linear circuit.

See `DETECTOR_PROOF.md` for the acceptance theorem and exact stage counts.
`python3 audit_detector.py` passes 51 accepted outputs, 40 decline controls
and four invalid-argument controls. Cold sampled constants still lose to
the ordinary FFT: N=8192 costs 344,080 versus 167,949 scalar field operations.
Root source review and independent adverse-case/count review are complete;
see `DETECTOR_INDEPENDENT_REVIEW.md` for scope and targeted checks.
