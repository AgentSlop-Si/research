# Next gate: test Fourier phase coherence, not more global-mixing proxies

We now have ONE O(N)-work stage that meets all the stage-level tests that blocked the prior Green constructions: unitarity, O(N) inverse, growing 1-condition, and order-robust Omega(N) significant balanced-cut singular values. **These are necessary-condition proxies, not evidence of an exact DFT factorization.**

The next falsification/synthesis target is the Fourier intertwining equation:

```
F_N Z_N = D_N F_N,
```

where `(Z_N x)[j]=x[j-1 mod N]` is the cyclic shift and `D_N[k,k]=omega_N^k` for the same sign convention as the chosen DFT. For any claimed exact factorization `A_N=S_t P_{t-1} ... S_1` including all monomials/scalings, require

```
A_N Z_N - D_N A_N == 0
```

**algebraically for every N**, not just small residual norms. This covariance plus a normalization such as `A_N e_0=ones` pins down the Fourier matrix, since the columns follow by repeated shifts.

Plan:
1. Build a correct, inexpensive covariance-defect executor using only the O(N) stage oracles, and audit it against standard FFT and deliberate near-gauge decoys. Avoid dense symbolic fitting at large N.
2. Use the tree/path graph's sparse shift commutators to understand why `S` alone cannot intertwine; identify which phase/permutation schedules might cancel this defect across stages.
3. Seek identities for an all-N parameterized product family with t=o(log N), but reject any candidate that uses a hidden O(Nlog N) parameter-fitting, scalar-generation, inverse, or output step. The exact-complex field model is distinct from numerical/bit complexity.
4. Check rank *and* both induced norms at every candidate; these only veto specific designs and do not establish synthesis.
5. Build an algebraic certificate independent of numerical fitting (e.g., Laurent-polynomial or cyclotomic reduction) before claiming even one new Fourier factorization.

Failure condition: if after finite symbolic tests no coherent solution exists, record a no-go for the attempted parameterization rather than generalize it to all O(N) circuits.
