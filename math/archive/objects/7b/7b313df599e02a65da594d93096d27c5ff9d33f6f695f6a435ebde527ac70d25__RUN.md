# How to reproduce Phase 20

Start in the `fft_green_phase20_weyl_shared_state` directory after extracting the complete archive.

```bash
# Phase 20's exact and numerical tests
OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -v

# Complete deterministic audit of the actual O(N) Green solvers and controls
OPENBLAS_NUM_THREADS=1 python audit.py > audit.json

# Optional exact modular four-call black-box gate and two-column fingerprint demos
python weyl_gate.py  # module exports functions, no standalone output
python projective_gate.py

# From a parent directory, validate all Phase 12–20 suites from a fresh archive
python fft_green_phase20_weyl_shared_state/verify_full_lineage.py /absolute/path/to/fft_green_research_phase20_2026-10-09.zip
```

Requirements: Python 3.11+, NumPy for independent numerical controls. The finite-field Green solver, Weyl gate, and projective gate use only the Python standard library. `OPENBLAS_NUM_THREADS=1` ensures small numerical audits are reproducible.

The seeded field experiments are repeatable but should not be interpreted as statistical confidence guarantees. A formal Monte Carlo one-sided error bound is valid when the oracle is linear over the field and each probe is genuinely independently uniformly distributed; pass `seed=None` to use OS-backed randomness. Checking finite samples is a rejection test, not proof of complex equality.
