# Phase 20 — FFT Green research continuation

A fully reproducible continuation from Phase 19. We **did not** construct an FFT below `N log N`. Instead, Phase 20 upgrades Fourier phase-coherence verification and proves new restrictions on several near-resonant Green-circuit subclasses.

## New proof statements

- **Complete Weyl duality:** `MZ=DM`, `MD=Z^-1M` implies `M=cF`. One scalar calibration fixes the normalized DFT.
- **Sharp Weyl residual spectral gap:** `min_c||M-cF||_F<=R(M)/(2sin(pi/N))`.
- **Linear-work probabilistic finite-field verifier:** 4 oracle calls per trial including initial calibration, without forming a dense matrix; 1+3h calls for h trials.
- **Projective Fourier curvature:** two oracle calls can exclude *all* outer diagonal/permutation gauges; a complete O(N²) matrix test reconstructs gauges and permutations when they exist. Based on the classical Haagerup cross-ratio invariant.
- **Sparsity and stationary Green barriers:** sharp sparse-column Weyl defect, conditioning-independent approximate inverse-sparse bound, and a commutator-rank barrier for products of stationary path solves.
- **Real-mask phase rigidity:** one complex diagonal mask between real invertible mixers must contain only real/purely imaginary entries, and a unit-modulus mask must use `±1, ±i` with exact parity-sector multiplicities.
