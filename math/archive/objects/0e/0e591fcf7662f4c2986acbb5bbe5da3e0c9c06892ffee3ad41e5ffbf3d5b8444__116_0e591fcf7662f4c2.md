# Wide global scans versus a fresh exact FFT

This reproducible package tests whether **O(N)-work full-array weighted prefix scans**, composed in sequence, could form a novel O(N) full Fourier evaluator on arbitrary fresh inputs. The answer is **no** within the specified fixed-layout scan architecture. A theorem from quasiseparable off-diagonal ranks proves an all-N obstruction even under optimal endpoint reorderings; intermediate shuffles are not excluded.

## Key results

* Fixed-layout N-dimensional weighted forward/backward one-state scans (with any diagonals): at least N/2 forward and N/2 backward passes for natural-order even-length Fourier.
* Allow arbitrary row and column permutations only *at the endpoints*: at least N/4 forward and N/4 backward scan passes (N divisible by 4).
* Rank of any complex Fourier submatrix with |R| selected rows and |C| selected columns is at least |R||C|/N. The balanced N/4 bound is sharp, attained by parity order.
* A permutation in the *middle* changes the rank budget; an unconstrained shuffle can neutralize this particular cut-rank test. No stronger arbitrary-permutation lower bound claimed.
* The trace/multicut potential makes permutation requirements explicit, without pretending long-distance register movement necessarily costs superlinear time in a random-access model.

There are **no benchmarks advertising a faster FFT**. All main operations in the tests are exact finite-field computations; the all-size proof uses unitary Fourier algebra over C. No third-party packages, threads or internet required.

## Reproduce

```bash
cd fft_wide_scan_cutrank
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 python independent_certificate.py
PYTHONDONTWRITEBYTECODE=1 python routing_budget.py
```

## Files

`RESEARCH.md` gives proofs, cases and claim boundaries; `NEXT_GATE.md` states the next falsifiable challenge; `wide_scan.py` contains exact field matrices, rank and scan composition; `routing_budget.py` tests the internal-shuffle rank budget; `independent_certificate.py` independently verifies the key ranks using two primes; `tests/` are regression checks; JSON files contain captured finite certificates. See `SHA256SUMS.txt` for checksums.

Reference checkpoint: `FFT_RESEARCH_CANONICAL_CHECKPOINT_2026-10-09.md` (a prior artifact, not bundled again). Earlier phases covered caching, bounded tables, Boolean/Galois output sharing, conditioned macro FFTs, packed giant-integer work, chirp recurrence and many other distinct mechanisms. This package does not restart them.

**Novelty:** The linear algebra, Fourier-submatrix rank estimate and quasiseparable product rule are known techniques. Their application as a falsification gate for our hypothesized O(N) global-scan FFT is the result of this research pass. We claim no priority or universal FFT theorem.
