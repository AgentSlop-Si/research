## Findings

### B3-F01 — Independent verifier accepts malformed/degenerate certificates (high)

Prime/root/alpha validity and complete rank-list shape are not checked. Empty block_ranks skips rank checks; singular denominator is converted to zero, allowing the concrete n=3,p=7,omega=1,alpha=1 record to return True.

Recommended correction: Reject invalid parameters and missing/extra cases; require exactly n ranks; use guarded inverse; recompute every report field claimed to be certified.

### B3-F02 — Negative channel ranks create a false positive rank gap (high)

ranks=[-1] for k=1 and no shuffles returns capacity -1 and rank_gap 2. The certificate currently accepts a mathematically impossible channel-rank input.

Recommended correction: Require finite nonnegative integer ranks and validate the architectural rank assumptions before presenting a gap as an obstruction.

### B3-F03 — Graph component count is not a component count (low)

sum(d_i==1) can count several vertices in one connected component, and is not the number of connected components.

Recommended correction: Increment a component counter when starting each new DFS/BFS root.

### B3-F04 — Precision and complexity tests validate narrower models than their names suggest (medium)

The complex64 comparison keeps weights, input compression and FFT in double precision. Allocation/work claims are formula comparisons; the large scalar lengths are not actual transform runs.

Recommended correction: Label mixed-precision stress precisely; test a truly specified precision path and separately instrument actual allocation/work when required.

### B3-F05 — Assertion-disabled execution removes proof gates (medium)

Several scripts and helpers rely on assert for arithmetic identities, modulus/coefficient guards or claimed outcomes. python -O removes these checks. unittest calls themselves remain enabled, but some dependency proofs are assert-only.

Recommended correction: Use explicit validation exceptions for certificate acceptance, or enforce and record an unoptimized interpreter. No -O run was performed.

### B3-F06 — Absolute output destination is not portable (medium)

The entrypoint writes fft_dyadic_green_20261010/RESULTS.json without creating it.

Recommended correction: Take an explicit output path and ensure its directory exists; avoid overwriting original result evidence.

### B3-F07 — Regular must retain the documented bi-regular restriction (scope)

The necessary seed leverage condition requires both equal row sums and equal column sums of the right factor; the source header only says regular.

Recommended correction: Describe the exact bi-regular, common-coupling, fixed-pair scope wherever reporting all-complex exclusion.

### B3-F08 — Shape-blind equality helpers can accept unequal matrices (medium)

weyl_line_basis.matrices_equal and two_line_weyl.mat_eq use nested zip; an empty matrix equals any matrix and strict prefixes can compare equal. Intended constructors currently match shapes.

Recommended correction: Check exact row and column dimensions before entry comparison; reject ragged inputs.

### B3-F09 — Negative matrix exponent does not terminate (medium)

matrix_power(a,-1,p) retains e=-1 after every right shift, so while e never ends.

Recommended correction: Reject negative exponents or explicitly implement inverse powers.

### B3-F10 — Zero-direction line predictor disagrees with direct construction (low)

For u=(0,0), the direct line operator is nI while the a==0 predictor is diag(n*omega^(j*j)). This is outside the intended nonzero line direction domain but is not rejected.

Recommended correction: Reject the zero direction or return nI for that branch.

### B3-F11 — Index casts and selector helpers accept unintended domains (medium)

rank_periodic_universal truncates fractional rows to int64; transversal_columns omits positivity/divisibility/power-of-two validation and parity_columns omits sign validation.

Recommended correction: Validate exact integer labels and the complete domain before casting/building selectors.

### B3-F12 — Parameterized witnesses retain fixed-size and fixed-field output claims (medium)

mismatched_interface_example permits any even n although its n/4 spectrum formula requires a multiple of four. four_green_two_sum_witness has n,p parameters but labels field GF(193), target rank 16 and fixed norm bounds.

Recommended correction: Restrict the API to the verified default case or derive and check all metadata and hypotheses from n,p.

### B3-F13 — Phase14 test header overstates exactness and independence (medium)

The suite includes finite random checks, numerical SVD/eigenvalues and shared implementation helpers. Weyl acceptance is probabilistic under a fixed-linear-operator assumption.

Recommended correction: Report each test as exact finite, numerical, randomized, or theorem-dependent; do not infer all-case proof coverage.

### B3-F14 — A test writes beside its imported module and misses a malformed-output gate (medium)

numerical_weight_audit.run writes NUMERICAL_AUDIT.json. The imported weyl gate accepts an empty-output callable vacuously because output length is unchecked; no regression covers it. These are dependency contract observations only.

Recommended correction: Separate pure computation from output writes; validate operator output length; add malformed-output negative controls.

### B3-F15 — Fiber transform relies on field and promise validation (scope)

A primitive root-order test does not prove p prime or ensure Fourier identities over a composite ring. O(N) counts field operations under K=O(Q),Q^2=O(N), not arbitrary inputs or bit complexity.

Recommended correction: State/validate a prime-field contract, positive dimensions and valid row certificates; preserve the sparse-promise scope.
