# Replay

Use Python 3.9 or later with its standard library only:

    python independent_checks.py --output regenerated.json
    cmp INDEPENDENT_RESULTS.json regenerated.json

The checker can be copied alone to another directory. It does not import the constructor's code or any uploaded program. Dense reference construction and expansion are research controls, not part of the claimed linear coefficient-plan recovery. Root/field searches in the test harness likewise generate finite test instances rather than furnishing a free-root claim.
