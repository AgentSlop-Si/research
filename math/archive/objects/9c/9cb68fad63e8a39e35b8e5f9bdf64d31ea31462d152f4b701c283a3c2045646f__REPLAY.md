# Portable replay

Requires Python 3.10+ and its standard library. Copy only `independent_checks.py` and `independent_phase21_math.py` to any directory, then run:

    python -B independent_checks.py phase22_results.json

Compare the output byte-for-byte with `INDEPENDENT_RESULTS.json`. The second Python file is a byte-preserved copy of our own independent Phase21 checker, not an uploaded program. No source archive, extracted source, external package, network access or cached result is needed. Quadratic roots use a deliberately slow exhaustive oracle in these bounded controls; this is not the algorithm's claimed fast root-extraction cost.
