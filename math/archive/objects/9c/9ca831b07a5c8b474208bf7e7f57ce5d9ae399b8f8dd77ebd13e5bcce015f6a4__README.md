# Phase 16 — The entropy barrier and Green Givens compiler

We continued Phase15's **own** exact Galois-folding Fourier executor and Phase13's Haar–Green mixer without adopting CrocSwap or OpenAI's tensor-network algorithm.

**Main conclusion:** the Phase15 base bank, residual fold, and orbit bank are each already **optimal in the model of in-place 2-coordinate unitary gates**; every butterfly in the full factorization earns exactly the maximum 2-bit increase in matrix entropy. Separately, the entire Phase13 Haar–Green stage has a representation using at most `(11N/2)-8` such gates. Therefore `t=Ω(log N)` Haar–Green stages are required to obtain an exact normalized DFT, even if their real coupling strengths vary with N. This is a theorem about the specified stage family, **not** a universal FFT lower bound.

**Honesty:** the entropy lower-bound technique was already known (Nir Ailon, 2013); the project contribution is applying it with explicit algebraic decompositions and independent validation. No sub-`N log N` FFT or improved integer-multiplication bound was discovered.
