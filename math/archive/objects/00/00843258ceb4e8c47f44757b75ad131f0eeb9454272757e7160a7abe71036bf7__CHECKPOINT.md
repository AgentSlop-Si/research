3. Hankel rank barrier: any `r`-geometric or order-r linear recurrence representation has Hankel rank <=r. The classical binary Hankel rank distribution gives `Pr(rank_F2<=r)=2^(2r-N+1)` for r<N/2. Complex rank is >= F2 rank on binary matrices. Thus arbitrary r=o(N) exponentials almost never cover a random binary input. GF2 *full rank distribution* independently audited for m=1..9. This directly addresses the user's original collision-growth intuition without treating it as an FFT lower bound.
4. Added independent sparse-cyclic-difference Green executor, including raw-input recognition of <=2 jumps/kinks. Derived permutation-equivariance and exact binary transition distribution. For N>=8, probability adaptive linear fast path <=(N(N-1)+34)/2^N. Validated first/second/third cyclic-difference cases and conjugated-shift invariance.
5. Exact inverse residual sparsity profile: odd-index rows of `C^T` have `N-1` nonzeros; products of invertible Green blocks with inverse row sparsity `s` need at least `ceil(log_s(N-1))` factors to equal `C`. Sums of Green blocks escape that specific argument.
