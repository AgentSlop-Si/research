# FFT global reuse: adaptive-branch and cyclotomic-orbit audits

## What this package does

An exact, single-threaded, fresh-input mathematical audit rather than another cached FFT engine.

1. `cyclotomic_orbits.py` constructs an **O(N) shared symbolic representation** of all Fourier outputs for a length-N integer vector, with exactly `2N-2` additions/subtractions. **It does not compute all N numerical complex outputs in O(N) operations.** It can calculate all `log_2(N)+1` selected dyadic frequency representatives in O(N) arithmetic and can expand any single output in O(phi(m)).
2. `circuit.py` constructs FFT circuits with input-dependent nonlinear/rational `k` and extracts exact linear tangent circuits, even when different inputs select different fixed branches.
3. `boolean_cube.py` demonstrates why binary-only arithmetic has a separate polynomial identity theory, and why expanding all Boolean monomials can be exponentially expensive.
4. `symbolic_check.py` checks input-dependent polynomial/rational k cancellation and Jacobians in characteristic zero with SymPy.

The mathematical scope and limitations are in `RESEARCH.md`. The next research gate is in `NEXT_RESEARCH_GATE.md`. The canonical source-history guard is `PRIOR_WORK_GUARD.md`.

## Reproduce

Python 3.11+, **no packages** needed for all tests and modular audits:

```sh
python -m unittest discover -s tests -v
python audit.py
python orbit_audit.py
```

Optional (requires `sympy`):

```sh
python symbolic_check.py
```

### A tiny example

```python
from cyclotomic_orbits import OrbitDFT
x = [2,1,0,1,3,2,1,0]
orbits = OrbitDFT.build(x)
print(orbits.add_sub_count)        # 14, not a complete numerical FFT
print(orbits.stored_coefficients)  # 8 shared integers
print(orbits.coefficients(1))      # power-basis coefficients of X[1]
print(orbits.evaluate_mod(1))      # the corresponding exact NTT result mod p
print(orbits.representative_bins_mod())  # bins 0,1,2,4 only
```

## Do not misreport

- Galois conjugacy across frequencies requires rational (or appropriately fixed-field) input. The underlying fold identity also works for arbitrary complex inputs, but cannot be called Galois conjugacy in general.
- Orbit descriptors share information; treating Galois automorphisms as O(1) numerical operations would hide the FFT itself. Expanding the largest orbit **is** another half-size FFT.
- Exact finite-field checks are finite instances, not a proof of the infinite-field algebraic computation tree lemma.
- Symbolic output representation is **not** explicit scalar output. No new O(N) complex FFT theorem or improvement to OpenAI #130 was found.
- Branch selection/tangent linearization derives a nonuniform circuit unless constant/path preparation is separately uniform and charged.
