# HERO #17 — Phase 10: Spectral Projector Graph-Union

**Research checkpoint:** October 10, 2026  
**Objective:** continue the user's Graph + Union + Sparse Table + quantum-inspired FFT project without hiding operations or falsely declaring an O(N) full arbitrary-input FFT.

## Executive result

We obtained a fully charged exact **O(N) spectral projection algorithm** for arbitrary fresh inputs, whenever the frequency mask is a union of fixed-modulus residue classes with a constant number of exceptional frequencies. This is a genuinely different output task from the full FFT: it returns the time-domain filtered signal `P_K x`, **not** the list of all Fourier coefficients.

The same algebra corrects an interpretation of Phase 9: its nonzero quotient-remainder reflection commutator does not imply noncommuting *true Fourier spectral projectors*. All true Fourier spectral projectors commute.

Our batch executor merges a graph of multiple such filters by sharing the base comb, exceptional Fourier measurements and completed correction vectors. The exact common-output comparison at N=4,096 achieved **78.30% fewer charged field operations** than eight standalone filter implementations. That is workload sharing, not a sub-NlogN full DFT algorithm.

## 1. Precise theorem

Let `w` be a primitive Nth root of unity in a field `F` with invertible N. For `d|N`, `m=N/d`, any residue set `S subset Z_d`, and exception sets `E_+` outside the base `B={k:k mod d in S}` and `E_-` inside B, define `K=(B\E_-) union E_+`. Put `q=|E_+|+|E_-|`.

For every fresh `x in F^N`, **all N entries of `P_K x`** can be computed exactly using

    T(N,d,q) = O((d+q)N + d|S| + N + log p + sqrt N),
    space = O(N+d+q)

for the explicitly implemented finite-prime-field word-RAM model (the `sqrt N` is a conservative bound for trial-division root-order validation). All unit-cost field arithmetic, root generation, constant inverses via exponentiation, integer indexing, full input reads, and output writes are charged. If `d+q` is constant, this is `O(N)` including the plan. The identity is valid over exact complex numbers as well, though the code tests finite fields only.

The central equation is

    (P_K x)[j]
      = sum_{ell=0}^{d-1} c[ell] x[(j+ell*m) mod N]
        + (1/N) sum_{k in E_+} w^{kj} sum_s w^{-ks}x[s]
        - (1/N) sum_{k in E_-} w^{kj} sum_s w^{-ks}x[s],
    c[ell] = (1/d) sum_{a in S} w^{-a*ell*m}.

`PROOF_CERTIFICATE.md` gives the complete elementary proof.

## 2. Why this matters for Graph + Union

- **Graph:** a periodic shift-comb operator plus Fourier-character outer products; all scalar operations are linear.
- **Union:** the projector Boolean algebra `P_A P_B=P_{A∩B}` and `P_{A∪B}=P_A+P_B-P_A P_B` is exact. Multiple masks can share common subgraphs.
- **Sparse table:** the `d` short comb coefficients and selected roots are materialized explicitly and charged. There is no exponential lookup table.
- **Quantum connection:** these `P_K` are commuting Fourier-basis projectors (orthogonal over C), not noncommuting quantum gates; their nontrivial-looking coefficient transfer counterparts from Phase 9 are coordinate-dependent.

The projector matrix can be fully dense while exact application is linear. In exact tests of a parity mask swapping frequency 0 for 1, matrices for N=8,16,32 had every entry nonzero, yet were applied in O(N) field operations. Matrix density and the rank of an internal bridge are not reliable complete-circuit cost estimates.

## 3. Strong invariant absent from Phase 9's coefficient commutator

For any A,B:

    rank(P_A-P_B)=|A symmetric_difference B|.

For `q` exceptional frequencies, the correction from its periodic reference projector has rank **exactly q**. Thus `q` is the *minimum additive correction rank in that fixed reference model*. It does not imply a lower bound on unrestricted arithmetic gates.

Compare the two relevant facts:

    rank([R_A,R_B]) = 2 min(t,m-t)   (Phase 9 quotient transfer),
    rank([P_A,P_B]) = 0             (genuine Fourier projectors).

The test suite rebuilds both sides independently for a one-swap root exchange and verifies each. This keeps us from pursuing an illusory quantum noncommutativity obstruction.

## 4. Fully charged implementation

`phase10.py` contains `SpectralUnion`, `BatchSpectralUnion` and the generic same-output double-FFT control.

- A supplied prime field and primitive Nth root form the stated input domain; primitive-order validation is charged. The executor does not silently select primes, roots or use a cached input transform.
- Root table powers are generated in `N-1` charged multiplications.
- Constant inverses use charged binary-exponentiation by `p-2`, no hidden unit-cost modular inversion.
- Weight precomputation and each exceptional frequency dot product are explicit.
- A complete N-vector is written for each requested filter.
- Batch sharing is fully charged, with repeated outputs still copied/materialized.

Field operations and machine-word indexing are reported separately. `p` is chosen polynomially in N for tested settings. This is not a finite-precision floating-point or integer-bit-complexity claim.

## 6. Why this does not close the universal FFT target

A singleton projector `P_{ {k} }` can be applied in `O(N)` work, but it only isolates one Fourier mode. Applying N such projectors separately takes `O(N²)` work. The periodic mask class also doesn't provide every Fourier mode at constant complexity.

**Restricted signature gate:** if each frequency is identified only by its membership in B binary masks, distinguishing N frequencies requires `B>=ceil(log2 N)`. Explicitly materializing a separate N-vector per mask therefore requires `Omega(N log N)` writes. This lower bound is only for that particular binary-signature, materialized-filter architecture; lazy shared circuits and unrestricted arithmetic remain possible, and in fact a specialized uniform exact-complex-arithmetic full-DFT bound of `O(N(log N)^(1-1e-13))` was announced in 2026.

**Next research target:** exploit this commuting projector algebra to build *lazy, non-materializing multi-level spectral refinement* and a cross-level scalar DAG that actually saves work on **every fresh input** when producing all N Fourier bins. A proposed win must include the whole decoder and show an asymptotic recurrence strictly better than the current baseline; otherwise it is only a useful spectral filtering result.

## 7. Prior art and originality

The projector and character-orthogonality identities are classical finite-group Fourier theory, and comb filters / periodic spectral masks are standard DSP. A related coset filter implementation is described in NetKet's translation-group documentation. We claim **no first discovery** and no new unrestricted exact DFT complexity bound. The useful project advances are: exact formal separation of the Phase 9 quotient-reflection versus Fourier-projector operators, a charged batch graph combining their proper algebra, and a reproducible negative boundary for all-output reconstruction.
