# FFT coprime Green + polyphase closure v15

This package contains:

- a frozen, cold-rerun Phase-4 all-length randomized approximate transform;
- a new exact joint decoder for its complete beta-shift Green frame;
- an algebraic collapse of that decoder to mixed-radix Cooley–Tukey;
- an independent exact finite-field certificate;
- automated tests, benchmarks, logs, and manifests.

Run:

```bash
OPENBLAS_NUM_THREADS=1 python run_all.py
```

Core new files:

- `polyphase_exact.py`
- `finite_field_polyphase_certificate.py`
- `test_checkpoint.py`
- `RESEARCH.md`

The project does **not** claim an exact sub-`N log N` FFT or a fixed-precision theorem.
