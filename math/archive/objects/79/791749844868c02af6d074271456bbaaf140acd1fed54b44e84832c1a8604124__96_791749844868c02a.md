# Simpler single-table closure from the fourth attachment

The single-table guarded-addition alternative below comes from the user-supplied `fft_wordram_packed_decoder_v3(1).zip`. It replaces the second lookup table and tiled transpose in `PACKING_AND_MODEL_THEOREM.md`. The bounded-integer input model, exact sampling with a charged failure budget, phase preparation, O(N) descriptor creation, uniform table build, and explicit normalized output treatment from that proof carry over. The packing step is proved here; it is not an unresolved assumption.

## Exact guarded-lane algebra

After quantizing a first-level group trajectory on a fixed dyadic grid of step h1, represent each real or imaginary component as an integer a in [−U,U], where U=O_epsilon(1). Use 2B scalar lanes for B complex outputs. Let G be the number of equal-size sample groups. Store biased components a+U in [0,2U], using a field of

    h = ceil(log2(2UG+1))

bits. The +1 inside the logarithm matters: it guarantees 2UG<2^h even when 2UG is itself a power of two.

Put exactly r=floor(w/h) complete fields in each word, with the final word possibly shorter. Every table entry is stored ALREADY PACKED in

    P = ceil(2B/r) = O(1+Bh/w)

words. This layout depends only on N and fixed algorithm parameters, not the input.

Add the G corresponding table-entry words with ordinary unsigned word addition. At every partial sum, each lane is nonnegative and bounded by 2UG<2^h. Therefore no carry crosses its field boundary. Also the greatest possible accumulated word is at most

    (2^h−1)(1+2^h+...+2^((r−1)h)) = 2^(rh)−1 <= 2^w−1,

so there is no overflow of the physical word itself. No giant Python integer or unit-cost multiword addition is being assumed.

Extracting one field by a shift and mask gives S=sum_(u=1)^G(a_u+U). Its exact mean before final rounding is

    h1 (S−GU)/G.

Division can be a stated word-RAM operation or a precomputed reciprocal followed by correction; all numerators and products here are polynomially bounded in N and fit the chosen fixed multiple of log N bits. The subtraction is signed word arithmetic on a known bounded value. Final rounding and output scaling follow the explicit budget in the companion proof. Both complex components are processed, so the displayed factor 2 in the lane count is genuinely charged.

## Fully charged complexity

Keep B=Theta(log N), g=Theta(log N/log log N), and G=Theta(log log N) for fixed epsilon and polynomially small failure probability. Now

    h = O_epsilon(log G) = O_epsilon(1+log log log N),
    P = O(h).

For one output block, initialize P zero accumulator words, retrieve and add P words for each of G table entries, then extract and explicitly write 2B scalar output components. Cost is

    O(GP+B) = O(Gh+B).

Across ceil(N/B) blocks, the accumulation term is

    O(N log log N (1+log log log N)/log N) = o(N).

Descriptor construction still costs O(N), and explicit output writes cost O(N). The first table has at most N^gamma entries; storing P words per entry and building each by O(gB) or other conservative polylogarithmic work costs N^gamma polylog(N)=o(N). No preinstalled table or online lazy computation is hidden in that bound.

The complete algorithm is therefore O(N) under the bounded-precision model already stated. This route has no G-by-G one-word tile, so it removes the extra condition qG^2<=w and the second-table construction. It still has parameter-dependent asymptotic thresholds and potentially unusable constants. Ordinary 64-bit performance is not proved by big-O notation.

## Independent checks and implementation boundary

The independent strict-64-bit verifier at `verification/packed/check_guarded_add.py` checked 720 blocks and 33,552 lanes. Cases include minimum, maximum, alternating, and random signed lanes, group counts from 1 through 256, quantization bounds 1,3,8,17, and block lengths through 129. Every stored/accumulated word was checked to stay within 64 bits, and all extracted signed sums matched scalar addition. Results are in `guarded_add_results.json` beside that verifier.

These tests validate the guarded arithmetic primitive, not a complete approximate Fourier implementation or runtime speedup. The uploaded prototype uses lazy phasor computation on cache misses and re-packs scalar lanes at each lookup. Thus its stored experiments validate a numerical/algebraic control, not the complete prepacked-table O(N) evaluator proved above. Its g=4 override also gives 72–76-bit keys in the 64-bit toy configuration; those runs are not one-word-key demonstrations.

The exact-output goal, a strong useful relative-error goal, practical advantage, and literature novelty all remain separate and unproved by this closure.
