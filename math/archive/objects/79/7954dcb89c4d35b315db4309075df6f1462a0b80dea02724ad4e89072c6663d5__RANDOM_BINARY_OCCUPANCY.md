# Sharp expected work for ordinary random-binary shared FFT DAGs

Date: 10 October 2026. This theorem concerns literal whole-subproblem memoization and explicit materialization. It is not an FFT lower bound outside that architecture.

## Model

Take M independent uniformly random binary vectors of length N=2^L. Use ordinary radix-2 decimation-in-time recursion. A node key is (length, even-child-ID, odd-child-ID), with the two binary leaf values interned. Identical complete input subvectors share one node. Each unique length-m node materializes its full m-entry transform, using the standard m/2 butterfly combines. The field/root and exact scalar representation are whatever make these transforms meaningful; the combinatorial count below is independent of them. Any additional scalar bit cost only increases the total.

Let U_m be the number of unique length-m subvectors among all MN/m occurrences at that level. Put K=MN. Because these are disjoint coordinates within each input, and inputs are independent, the occurrences at a fixed level are independent uniformly distributed m-bit strings. Thus exactly

    E U_m = 2^m [1−(1−2^(−m))^(K/m)].

The number of standard butterflies is exactly

    B = Σ_(s=1)^L 2^(s−1) U_(2^s).

In particular,

    E B = (1/2) Σ_(s=1)^L 2^s · 2^(2^s)
                       · [1−(1−2^(−2^s))^(K/2^s)].

There is no independence assumption between different levels; linearity of expectation suffices.

## Asymptotic result

For each fixed A≥0, uniformly over integers 1≤M≤N^A as N→∞,

    E B = (MN/2)[log2 N − log2 log2(MN) + O_A(1)].

Equivalently, the expected saving from the ordinary MN log2 N/2 butterfly count is

    (MN/2) log2 log2(MN) + O_A(MN).

For M polynomial in N this is Θ(MN log log N) saved work, while a 1−o(1) fraction of the ordinary total remains. The result applies to a single random input as well as to any polynomial-size independent corpus.

### Proof

Write R=log2 K. For m<R/2, use U_m≤2^m. The total cost of all these low levels is at most O(R 2^(R/2))=O(K).

There are only O(1) dyadic block lengths between R/2 and 2R, and each contributes at most K/2. Their cost is O(K).

For m≥2R, the number of duplicate occurrences r−U_m, r=K/m, is at most the number of equal occurrence pairs. Hence

    E(r−U_m) ≤ binom(r,2) 2^(−m).

The butterfly deficit from these upper levels sums to at most

    (K²/4) Σ_(dyadic m≥2R) [1/(m 2^m)] = O(1).

There are L−log2 R+O(1) such upper levels. Since R=Θ_A(log N), this proves the stated formula. Floors and ceilings change only O(1) levels.

A high-probability version also follows. For any fixed b>0, a union bound shows that with probability at least 1−O(K^(−b)), there are no duplicate occurrences at any dyadic level m≥(2+b)R. The low-level deterministic bound above and the O(1) boundary levels then imply

    B = (K/2)[L−log2 R+O_(A,b)(1)]

with that probability. This strengthens the expectation statement without pretending that all nodes or levels are mutually independent.

## Hashing, preparation, memory, and output

Bottom-up interning needs fewer than 2MN node-key encounters. Every key consists of O(1) IDs of O(log(MN)) bits. For fixed A these fit O(1) words of Θ(log N) bits. A standard exact hash dictionary with expected O(1) operations per key gives O(MN) expected graph-construction work, including equality of complete keys. It need not re-hash each m-bit subvector. Tree ingestion and final explicit MN-value output also cost O(MN).

Evaluation can proceed by levels, retaining only a level's materialized unique transforms and its children; each level contains at most MN scalar entries, so O(MN) scalar words suffice. Storing all materialized levels at once would use more space and is unnecessary.

The exact butterfly formula is for the stated ordinary combine implementation. Even if arithmetic special cases are optimized, an architecture that explicitly stores every new m-value subtransform incurs Σ m U_m = 2B value writes. Avoiding that cost requires changing the representation or evaluation architecture, not merely using a better hash table.

## Growing binary leaf tables are a different mechanism

A complete table of all length-K0 binary transforms has 2^K0 entries, each K0 scalar values. For K0 a power of two with K0≈c log2 N, 0<c<1, a straightforward table build costs O(K0 log K0 2^K0), with O(K0 2^K0) scalar storage. Under a suitable explicitly charged scalar/root model this is sublinear in N. Fetching and copying all leaf outputs costs O(N). But only log2 K0=log2 log2 N+O(1) bottom stages are removed. The remaining standard levels cost

    Θ(N[log2 N−log2 log2 N]).

Unlike finite-field all-level tabulation, the original binary alphabet does not persist through the upper complex/large-field layers. Leaf tables and adaptive whole-subtree caching must not be conflated with a table that can jump the same number of levels everywhere.

## Independent checks

check_occupancy.py was written from scratch. It enumerates every binary input corpus for (M,N)=(1,2),(1,4),(2,2),(2,4),(1,8),(2,8),(4,4), constructs the actual even/odd recursion DAG, and compares the exact mean against the rational occupancy formula. All seven checks pass, including 65,536 corpora in each of the two largest cases. Floating log-scale evaluations in OCCUPANCY_CHECKS.json illustrate the asymptotic remainder; they are not a substitute for the proof.
