# HERO #0 — Composite Green-cycle theorem and residue-class lift

**Checkpoint:** 2026-10-09  
**Research aim:** An input-independent, charged, sequential `O(N)` / `O(N log log N)` execution schedule for all `N` outputs of a fresh arbitrary Fourier transform, ultimately exact.  
**Proved here (conditional only on standard inherited dyadic routine as separately checked):** A **randomized approximate**, full-output Fourier method with `O(N)` ideal arithmetic work for all lengths `N` that admit a divisor `M=Theta(log N)`; a deterministic exact cycle for the *random projected* signal for every composite factorization `N=KM`, `K>=M`; and an elementary, explicit per-output covariance certificate over arbitrary composite `N`.  
**Not proved:** Exact `O(N)` FFT on arbitrary input, universally over **every** length; binary64/fixed-precision theorem; improved exact integer multiplication; a peer-reviewed novelty claim.

## Executive result

For every `N = K M`, `K>=M`, choose `a` uniformly among the units of `Z/NZ` and `beta` uniformly in `Z/NZ` (or use the explicitly bounded uniform-rejection sampler with an additional negligible failure event). The **unit-step binomial chirp** block projection `P_{a,beta}` and its full frequency vector

`Y = U_N P_{a,beta} x`

can be executed with **one `K`-point FFT**, one scan of `N` elements, plus linear-time setup:

`W(N,M) = O(N+(N/M)log(N/M))`.

This exact execution identity does **not** require `N` to be a prime power. Its expectation is the full arbitrary-input transform, `E Y=U_N x`. For each fixed output `k` and fixed arbitrary `x`, the composite-modulus covariance is bounded by

`E |Y[k]-(U_N x)[k]|^2 <= M(M-1)/phi(N) * ||x||_2^2`.    **(A)**

Therefore, for lengths admitting a divisor `M=Theta(log N)` (and `K>=M`), every full-output row costs `O(N)`, with variance `N^{-1+o(1)} ||x||_2^2`. A fixed sufficiently large **odd** number `s` of independently sampled rows, combined by coordinate-wise real and imaginary medians, gives simultaneous probability tending to one for

`||Y_robust-U_N x||_infty <= sqrt(2) N^{-alpha} ||x||_2`   **(B)**

for every **fixed** `0<alpha<1/2`, as `N` tends to infinity along those admissible lengths. The number of rows is a constant depending on `alpha`, not on `N`. Thus **`O(N)` sequential complex-arithmetic work, `O(N)` memory, all `N` explicit approximate outputs** in this *restricted-length* class. The input values themselves are completely arbitrary.

**Interpretation:** This is stronger than the user's previous **prime-power** unit-step-chirp lemma in supported lengths, but has a weaker proved covariance constant. It retains the essential `approximate` qualifier. Fast *exact* Fourier computation for every arbitrary length is not solved.

## 1. Exact projector and expectation

Let `zeta=exp(2*pi*i/N)` and `eta=exp(pi*i/N)`, `h=N mod 2`. Write the input in `K` contiguous length-`M` blocks, `x[bM+t]`, `0<=b<K`, `0<=t<M`.

For a unit `a` modulo `N` and any `beta mod N`, set

```
S[b,t] = zeta^(a*t*(t-1)/2+(a*M*b+beta)*t) * eta^(h*t),
d[b]   = sum_t S[b,t] x[bM+t],
y[bM+t] = conjugate(S[b,t])*d[b].
```

Because `|S[b,t]|=1`, `y=P_{a,beta}x` is linear in `x`. Every diagonal entry of its `M x M` blocks is 1. Every off-diagonal entry contains `zeta^(beta*(u-t))` with `0<|u-t|<M<=N`, whose average over uniform `beta` vanishes. Therefore

`E_beta(P_{a,beta}) = I_N`, for every fixed `a`, hence `E U_N P_{a,beta}x = U_N x`.

This is exact for arbitrary complex `x`, even adversarial dense inputs, as long as randomness is chosen *after* `x` is fixed. It is not a computation of the exact DFT for a single state.

## 2. Exact one-cycle executor without the prime-power assumption

The former v9 core required a prime-power modulus in `validate_dimensions`. The **algebraic** recurrence uses only the following:

- `N=KM` and `K>=M`;
- `gcd(a,N)=1`, so `j -> a*j mod N` visits every output exactly once;
- a length-`K` FFT of the block summaries `d[b]`, because `N=KM` aligns the block-start frequencies;
- the parity twist `eta^(h*t)`.

The multiplier encountered along the full cycle has product

`prod_(j=0)^(N-1) exp(2*pi*i*(a*j+beta+h/2)/N)`

`= (-1)^(a*(N-1)+h) = -1`.

The last equality is valid for **every** `N`: for even `N` any unit `a` is odd; for odd `N`, `h=1` and `N-1` is even. Consequently the closure denominator is exactly 2, independent of whether the length is prime-power. The cycle seed comes from one sum of gauged forcing; all other outputs come from a single prefix scan. The explicit `K`-FFT indices, gauge and forcing are implemented verbatim in `composite_cycle_core.py`.

An independent reference oracle constructs the projected vector `y` and calls NumPy's full length-`N` FFT *only for testing*. The executor itself does **not** call an `N`-FFT. It calls a single length-`K` FFT and `O(N)` arithmetic.

For `M=Theta(log N)` and `K=N/M`:

`N + K log K = O(N)`.

Generating a random unit `a` via rejection incurs sublinear **expected** setup overhead. The packaged composite executor explicitly caps trials at `8 ceil(log2 N)^2` (at least 64), and returns an explicit failure if none is a unit. The probability of that event is at most `(1-phi(N)/N)^T`, which is superpolynomially small for the chosen `T` using the standard totient lower bound. Thus the non-failed implementation has deterministic `O(N)` charged work (including bounded state selection); on the rare rejection failure the Monte Carlo algorithm reports failure instead of silently biasing the distribution. No large lookup tables or reused input spectra are assumed.

## 3. New composite-covariance certificate

Fix an output frequency `k` and let `D_t={u-t : 0<=u<M, u!=t}`. Set `i=bM+t` and let `e_i` denote the linear coefficient of `x_i` in the one-output error `Y[k]-(U_Nx)[k]`.

Averaging over `beta` kills terms with unequal displacement `d`, because `|d-d'|<=2M-2<N` when `N>=M^2`. Hence the error-coefficient covariance, up to a diagonal Fourier phase conjugation, is

```
Q = (1/N) sum_(d=-(M-1), d!=0)^(M-1) D_d B_d D_d,           (1)
```

where `D_d` is the diagonal zero-one mask selecting input positions where the local displacement `d` stays inside its block. `B_d` is the mean over units `a` of the rank-one Fourier character matrix for frequency `a*d mod N`. In explicit entry form (one phase convention):

```
Q[i,j] = exp(2*pi*i*k*(i-j)/N) / N
       * sum_(d in D_(i mod M) intersection D_(j mod M))
         c_N(d*(i-j))/phi(N),                                (2)
```

where `c_N` is the Ramanujan sum. The **normalized** Ramanujan-sum identity is

`c_N(t)/phi(N)=mu(N/g)/phi(N/g)`, `g=gcd(N,t)`.

To bound the norm, set `g_d=gcd(N,d)`. Multiplication by `d` maps the units modulo `N` uniformly onto precisely the `phi(N/g_d)` distinct Fourier frequencies `g_d*v` with `v` a unit modulo `N/g_d`. These Fourier characters are orthogonal, and each has norm `sqrt(N)`. Therefore

`||B_d||_op = N/phi(N/g_d)`.

Since `||D_d||<=1`, every covariance summand in (1) is positive semidefinite and

```
||Q||_op <= sum_(d != 0, |d|<M) 1/phi(N/g_d)
        <= (1/phi(N)) sum_(d != 0, |d|<M) g_d
        <= M(M-1)/phi(N).                                 (3)
```

The middle inequality follows from `phi(N/g)>=phi(N)/g`. The last one uses `gcd(N,d)<=|d|`. For any `x`, this gives the variance inequality (A).

The bound is **loose** at finite sizes and need not be less than one at small `N`. The old sharper projector variance `M/N` for prime powers remains preferable there. The proof is uniform over arbitrary composite moduli and arbitrary complex inputs.

For asymptotics, elementary number theory gives `phi(N)=N^{1-o(1)}`. One proof: `phi(N)>=N/2^{omega(N)}`, and if `omega(N)=r`, the product of its `r` distinct prime divisors is at least `(r+1)!`, forcing `r=O(log N/loglog N)`. With `M=Theta(log N)`, (3) becomes `N^{-1+o(1)}`.

## 4. High-probability all-outputs guarantee

Fix `alpha in (0,1/2)`, set `t=N^{-alpha} ||x||_2`, and let

`p_N = min(1, M(M-1) N^(2alpha)/phi(N))`.

By Chebyshev/Markov, a single real or imaginary coordinate error larger than `t` has probability at most `p_N`. Draw `s` independent `(a,beta)` pairs, `s` odd, and take coordinatewise medians of the `s` full spectra. If the median real or imaginary coordinate misses the target by more than `t`, at least `q=(s+1)/2` independent rows must miss. Thus by a binomial union bound, for **all N output coordinates**,

```
P[||median-U_N x||_infty > sqrt(2)*t]
    <= 2*N*2^s*(p_N)^q.                                     (4)
```

Since `M=Theta(log N)` and `phi(N)=N^{1-o(1)}`, the right side tends to zero whenever

`q*(1-2*alpha)>1`.

For example `alpha=1/3`, `s=9`, `q=5` gives asymptotic failure `N^(-2/3+o(1))`. The formal union bound is extremely conservative at practical lengths; the provided empirical test errors are not probabilistic proof on their own.

Time is `s*O(N)` when `M=Theta(log N)`, and space `O(s N)=O(N)` because `s` is a fixed constant. This is a *weak energy-relative all-bin additive* approximation guarantee, **not** accurate convolution suitable for integer coefficient rounding.

## 5. Separate residue-class lift for lengths without a suitable composite divisor

Let `Q=p^L>=N`, with fixed prime `p` and `Q<pN`. Define `j_k=round(kQ/N)` with ties rounded up and

`theta_k=kQ/N-j_k`.

The number of distinct exact offsets `theta_k` is

`h=N/gcd(N,Q)=N/p^(v_p(N))`.

For each class `theta`, apply one ordinary length-`Q` prime-power chirp estimator to the *modulated* input

`z_theta[n]= x[n]*exp(-2*pi*i*theta*n/Q), 0<=n<N`, zero-padded to `Q`.

The identity

`(U_N x)[k] = sqrt(Q/N) * (U_Q z_(theta_k))[j_k]`  **(5)**

is exact. Approximation enters only through the chirp estimator. Its projectively verified prime-power one-output variance `M/Q` becomes `M/N` after rescaling, independently of class count. This yields work `O(hN)` per row when `M=Theta(log N)` and `p` fixed. Thus lengths `N=c*p^a` with fixed cofactor `c` gain an `O(N)` approximation even when a near-log divisor of `N` is unavailable.

For prime `N` substantially different from every fixed small prime, the cofactor `h` is `N` and this route is not an improvement. Nor does this solve the exact FFT problem.

## 6. Independent reproduction and measurements

All tests are run from this package with a fixed random seed:

- **1,018** combinations of arbitrary modulus `N<=600` and nontrivial block divisor passed the composite-cycle executor versus an independently materialized full-FFT oracle (including **289 odd-length factor pairs**). Maximum absolute discrepancy: `3.59e-14`.
- **5** full-state covariance enumerations on arbitrary composite moduli (`12,18,30,36,60`) match the exact Ramanujan covariance formula to within `3.8e-16` entrywise. Every largest eigenvalue lies below the theorem's explicit `M(M-1)/phi(N)` bound; direct first-moment unbiasedness verified.
- Composite Green execution tested against materialization through `N=20736`; random complex, flat, spike, pure-frequency and alternating inputs passed the empirical error tests.
- Offset-class branch tested with full state enumerations for `Q=16,27,32`, independent projection-versus-Green checks, and 75-decimal-digit exact-modulation numerical checks for four short lengths.
- The v11 15-order Python implementation was about **9.5×, 9.7×, 11.3× slower** than the one-row composite method at `N=840,3600,20736` in the saved run. Native NumPy FFT is **much faster than either**. These timings are *not* comparison of matched accuracy tolerances and are not asymptotic evidence.

Run `python verify_composite.py` and `python verify.py`. The `bench_composite.py` and `benchmark.py` comparison scripts require the separate original v11 source tree at the included saved path; their JSON benchmark outputs are nevertheless retained in this bundle.

## 7. Precision, novelty, and the exact-FFT frontier

1. **Randomized vs exact.** E[Y]=U_N x does **not** mean Y=U_N x; each sample has nonzero variance on general inputs. Median outputs are approximate.
2. **Additive norm.** The guarantee `N^{-alpha} ||x||_2`, `alpha<1/2`, is weak compared with machine-precision FFTs. For bounded integer data `||x||_2=Theta(sqrt N)`, the permitted error can diverge and cannot support exact integer multiplication or coefficient rounding.
3. **Arithmetic model.** The proofs count arithmetic on complex values and `O(log N)`-bit indexing as unit operations and assume root of unity preparation in linear work. Floating-point phase generation, cancellation, finite mantissas, and bit complexity are *not* proved uniformly. The Python prototype uses complex128 and NumPy FFTs.
4. **New theorem status.** These are checked mathematical derivations plus reproducible tests within the user's research, *not independently peer reviewed* and not verified against every existing FFT/sparse Fourier paper. Random projections, Ramanujan sums, sparse Fourier recovery and Green recurrences have prior literature; do not claim absolute mathematical priority.
5. **Exact full-DFT target.** The best published all-length exact-complex upper bound in OpenAI #130 is `O(N (log N)^(1-10^-13))`, under unbounded input-independent constants and charged scalar setup, not a numerical/bit bound. The current result is incomparable because it relaxes exactness and restricts N. Exact `O(N)` or `O(N log log N)` for arbitrary fresh input and *every* N is **not established here**. The source demonstrates a **conditional length-family O(N) randomized approximate theorem**, which is a fundamentally different guarantee.
6. **Next genuinely hard gate.** For lengths with **no** divisor near logarithmic scale (especially prime N), either derive an O(N) one-cycle forcing scheme without `M|N`, or a truly O(N) rectangular Fourier evaluator with dimensions `N x ceil(N/log N)` at the requisite precision. Separately, exact circuit reuse would require removing random projection variance altogether without paying an extra `log N` factor. Small finite numerics alone will not establish those results.
