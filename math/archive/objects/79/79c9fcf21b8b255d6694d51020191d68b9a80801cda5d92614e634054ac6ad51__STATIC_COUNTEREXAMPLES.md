# Static acceptance counterexamples and repair obligations

These are source-level arguments. No supplied program was executed and no preserved input was modified.

## 1. Five-parameter saved coefficients omitted

Target: independent_exact_check.py, lines 107–125.

Keep the saved `upper_matrix` as three rows of three entries, but replace each entry with `[]`. The outer loops still visit three rows and three entries. Each reconstructed coefficient triple `polys` is calculated from the internally reconstructed resultants. The loop `for P, terms in zip(polys, saved)` is then empty. `entries.append(polys)` still executes and reconstructs the same full `Ecoeff` as before. Subsequent witness calculations use `Ecoeff`, not omitted saved data. Therefore this check can accept missing saved polynomials while emitting a full coefficient-match label.

Repair obligations: validate exact 3×3×3 shape; validate every polynomial term’s two-item encoding, coordinate indices 0..7 and canonical four-component coefficient vector; check metadata variable order/field and required complete schemas; reject unexpected trailing rows/entries; use explicit exceptions for validation failures. Add negative tests for missing/extra entries and run the same tests under optimized Python if that mode is supported.

## 3. Anchored minors with zero anchors

Target: dual_support.constraints, used by exhaust_smallfield.py.

Consider an 8×8 matrix B=I+E_(4,1)+E_(5,2), with zero-based indices. This matrix is unit lower triangular and hence invertible. B[7,0]=B[0,7]=0, and all off-diagonal entries in column 0, row 7, row 0 and column 7 are zero. Consequently every anchored lower and upper minor implemented by constraints is zero. But the fully lower 2×2 block on rows {4,5}, columns {1,2} is the identity, of determinant 1. It cannot have globally separated rank-one lower generators.

This establishes that the acceptance predicate lacks sufficient guards. It does not assert that this B is attained by the restricted onion constructor, nor that the saved GF(17) run found it. That saved run reports zero successes.

Repair obligations: require nonzero anchor corners when using anchored-minor equivalence; otherwise implement a complete branch-safe rank-one test. For a regular factorization also check det(C), inverse-C corners, exact F/C/permutation identity, all denominator guards and the intended diagonal/generator conventions.

## 4. Four advertised variables, index 4 present

Target: adjacent_tail_elimination.json produced by adjacent_tail.py.

The data declares variables [h0,h1,h2,hl], but its term-coordinate set is {1,2,3,4}. The source evaluates W on `[0]+h+[0]`, preserving original six-coordinate placement. A consumer passing the advertised four-vector cannot use index 4, and indices 1–3 no longer mean the advertised coordinates.

Repair obligations: emit monomial indices 0..3 and evaluate on the four-vector, or explicitly state the full original parameter array and map. Validate max index against the declared coordinate layout; round-trip at several exact points using a consumer that obtains its layout only from the artifact.

## 5. No proof of a full solution from determinant zero

Upper resultant gates and G/H determinants are necessary elimination constraints. If the chosen base pair A4=B4=0, every base-anchored cross-product vanishes regardless of other compatibility pairs. Separately, a singular coefficient matrix can have kernel spanned by (0,u,v), which supplies no affine solution of the form (1,gamma1,gamma2). No general converse follows from determinant zero. Branch-safe reconstruction plus original-equation and guard validation is required.
