# Minimum cycle-flow corrections for a q-kernel graph

**Constructive result:** a sequential graph of phase-modulated q-kernel convolutions can be compiled into one smaller orbit action and the minimum number of signed first-order filters in the specified cycle-flow rewrite family. Matching and compilation take deterministic O(N+b) word work. The result is exact for every fresh input vector. The class of operators is restricted; this is not an arbitrary-input FFT breakthrough.

## Accepted graph

N=2^L, q has exact order N, and b is a power of two with 2<=b<=N. Each graph node is multiplication modulo z^N by

    H_q(q^e z),  H_q(z)=sum_(j<N) z^j / product_(a=1..j)(1-q^a).

The input graph is the list of its b integer phase exponents e in [0,N). All nodes act sequentially on the same vector, using the same root, size and nilpotent shift. Arbitrary diagonals, reversals, additions of graph branches, or different inputs between nodes are not permitted by this interface. Exponents are symbolic metadata, not inferred from floating-point coefficients. Duplicate phases are allowed.

For the reference orbit with phases 0,N/b,2N/b,...,(b-1)N/b, the product is H_(q^b)(z^b) modulo z^N. Its action is b identical shorter kernel calls on residue chains of length N/b. See the companion `orbit_norm` proof for the finite root-of-unity identity.

## Cycle graph and exact correction

Let c_e count the graph's phase e and let h_e count the reference orbit. Both have sum b. Write delta_e=c_e-h_e. Regard phases as vertices of a cycle, with signed edge flow f_e from e to e+1 modulo N. Require

    delta_e = f_(e-1) - f_e.

The coefficient recurrence proves

    H_q(q^(e+1)z)/H_q(q^e z) = 1-q^e z modulo z^N.

Every denominator has constant term one, so division here is valid in the truncated polynomial ring. Multiplying these identities with signed integer powers gives

    product_e H_q(q^e z)^c_e
      = H_(q^b)(z^b) * product_e (1-q^e z)^f_e modulo z^N.

This retains the correction exactly. Positive f uses forward-difference filters; negative f uses inverse first-order filters. No correction term is omitted and no input-dependent identity is assumed.

## Optimal correction within this rewrite family

A particular solution is a_e=-sum_(j=0)^e delta_j, with a_(N-1)=0. Every integer solution is f_e=a_e+t for one integer t. Adding a constant circulation leaves the operator unchanged because

    product_(e=0)^(N-1)(1-q^e z) = 1-z^N = 1 modulo z^N.

The number of unit filter passes is D=sum_e |f_e|. A median of the a_e minimizes this sum: each step toward the median decreases the contribution of at least half the entries and increases the rest. Choose f_e=a_e-median(a). Since every a_e lies in [-b,b], counting into 2b+1 buckets finds a median deterministically in O(N+b) word operations. No sorting, assignment solver, numerical phase test, or exponential search is hidden.

This is optimal among these signed unit edge-flow factorizations. It is not claimed optimal among all arithmetic circuits, other polynomial identities, or other choices of the reference orbit.

## Evaluation and full cost

After the smaller orbit action, apply each unit factor with c=q^e:

    (1-cz):     y_0=x_0; y_j=x_j-c*x_(j-1).
    1/(1-cz):  y_0=x_0; y_j=x_j+c*y_(j-1).

The implementation updates the positive case backward and the inverse case forward. Each pass uses N-1 multiplications and N-1 additions/subtractions, with O(N) logical traffic and no input-dependent divisions. All q powers are generated once with N-1 multiplications, including when D=0 in this implementation. Space is O(N+b), and indices/counts fit O(log N)-bit words because b<=N.

If C(m) denotes applying a prepared length-m kernel, total evaluation and compilation are

    b C(N/b) + O(N(1+D)+b),

plus O(N/b) preparation of the smaller kernel and O(log b) root squarings. Constant 1/2 generation, coefficient powers, gather/scatter and output copies are charged in the executable reports. When b=N the orbit part is identity. Therefore a graph with a complete N-phase orbit and D=O(1) correction has an exact O(N) evaluator for arbitrary fresh input.

Example: start with phases 0,1,...,N-1 and replace phase 0 by phase 1. The N-kernel graph equals multiplication by 1-z, so every output is simply x_j-x_(j-1), taking x_(-1)=0. This is a real graph cancellation, not a faster algorithm for an arbitrary unrelated operator.

No supplied evidence makes the Fourier factorization S T diag(d) T^transpose S an accepted orbit path. Its reversal and nonconstant intervening diagonal remain outside this rewrite rule. Converting them without reintroducing the original work is the unresolved step. Large D also gives no sub-NlogN guarantee.

## Verification

Run `python3 audit.py`. Every basis vector in each tested graph is compared to explicit sequential full convolutions, not another flow implementation. Tests include complete orbits, forward/backward defects, duplicated and random phases, two prime fields and exact rational cyclotomic fields. The median minimum is independently compared with all relevant integer offsets at these small sizes. A size-4096 single-defect case is compared to its proved first-difference formula; that large case is not a replay of 4096 full convolutions.

The all-size proof is the finite orbit identity, edge-ratio identity and telescoping flow calculation above. Existing q-exponential identities and cycle/median mathematics are not claimed as globally novel. The contribution here is their explicit composition into a charged exact compiler for this research project. No floating-point stability, integer bit bound, or general FFT speedup is asserted.
