# Phase 28 runbook

```bash
python -m unittest discover -s tests -v
python audit.py
python build_certificates.py
python phase28_executor.py
```

The tests use only Python standard library. Environment variables `PHASE28_PRIME` and `PHASE28_GENERATOR` can select another NTT-friendly finite field; the saved certificates use `p=998244353`, primitive generator 3.

To independently verify a saved Bezout certificate **without recomputing the Green matrices**:

```python
import json
from phase28_polynomial import poly_add, poly_mul
c=json.load(open('certificates/bezout_N16.json'))
assert poly_add(poly_mul(c['bezout_u'],c['p1_coefficients']),
                poly_mul(c['bezout_v'],c['p2_coefficients'])) == [1]
```

The leading-degree and known-denominator-factor arguments are in `THEOREM.md` and are required to interpret that *modular* identity as a *characteristic-zero* nonfactorization certificate. None of these scripts compute an arbitrary-input FFT faster than N log N.
