# Predecode-median Fourier sketch v6

This bundle continues the v5 frequency-shift sketch.

Main change: take robust medians of the intermediate Cooley–Tukey coordinates first, then execute the family of short `M`-point decoders once. This permits about `log N / log log N` robust rows while retaining strict sub-`N log N` arithmetic time.

Main arbitrary-input result for powers of two:

```text
Time:   o(N log N)
Memory: O(N), including explicit output
Error:  O((log N)^(1+eps) / h(N) * ||x||_2 / sqrt(N))
Failure: at most N^(-a)
```

for fixed `a >= 0`, `eps > 0`, and any `1 <= h(N) = o(log log N)`, with the precise parameterization in `RESEARCH.md`.

The bundle also proves a heavy-tail obstruction for one row and an exact high-probability `O(N log log N)` result when every interleaved column has constant local Fourier sparsity.
