# The normalization-balanced Fourier folding defect has full row rank

## Scope and result

Let b=2^r, a=b or a=2b, and N=ab. Index the small grid by t=bx+y and the large grid by j=2bX+Y. Let pi(X,Y)=(X mod a,Y mod b), and let Q be its unnormalized four-fiber sum, Qe_j=e_(pi(j)). Let F_N and F_(4N) use compatible positive-exponent roots zeta=omega^4.

For **every scalar gamma**,

    rank(Q F_(4N)-gamma F_N Q)=N.

This includes the normalization-balanced value gamma=2. It holds over any field containing a primitive4Nth root, with characteristic not dividing4N. It strengthens the previous complex norm-gap argument in a separate note; that earlier argument alone did not cover |gamma|=2.

The proof gives an explicit N-column minor for every nonzero gamma. It is a property of this actual two-dimensional folding layout, not of every arbitrary four-to-one Q.

## 1. Choose one representative column per fiber

For t=bx+y, with0<=x<a and0<=y<b, choose

    j(t)=2bx+y, if y>0;
    j(t)=2bx+b, if y=0.

All selected columns are distinct and pi(j(t))=t. In this order, writing J for the selected column list,

    (F_N Q)[:,J]=F_N.

Put A=(QF_(4N))[:,J] and K=F_N^(-1) A. The selected minor of the target defect is

    A-gamma F_N = F_N(K-gamma I).

It remains to prove K nilpotent.

## 2. Exact Fourier aliasing formula

For a small row i=bx+y and a large input j, its four output fibers are the large indices2bx+y,2bx+y+b,2bx+y+2N,2bx+y+b+2N. Therefore

    (QF_(4N))[i,j]
      = omega^((2bx+y)j) (1+omega^(bj)) (1+(-1)^j).

This vanishes for odd j. Using F_N^(-1)[s,i]=N^(-1) omega^(-4si), for even j=j(t) one obtains

    K[s,t] = (2/b) * 1_(s congruent j/2 mod a)
             * (1+omega^(bj))
             * sum_(y=0)^(b-1) omega^((j-4s)y).

Indeed the x-sum is

    sum_(x=0)^(a-1) omega^(2b x(j-2s)),

which equals a when s congruent j/2 modulo a, and0 otherwise. No division by the last geometric sum, or assumption that it is nonzero, is used. The only divisions are by N and b, both units under the field assumptions.

## 3. A nilpotent grading

Define the capped low-coordinate valuation

    nu(t)=v2(t mod b), if t mod b is nonzero;
    nu(t)=r, if t mod b=0.

If nu(t)=0, then the selected j(t) is odd, so column t of K is zero. If nu(t)=h>=1, then v2(j(t))=h. This also holds when t mod b=0, because j(t)=b(2x+1) has valuation r.

Any nonzero K[s,t] requires s congruent j(t)/2 modulo a. Since b divides a and h-1<r, this forces

    nu(s)=h-1=nu(t)-1.

Thus, as a column operator, K lowers the grading by exactly one wherever it is nonzero. Ordered by increasing nu, it is strictly upper triangular. Consequently

    K^(r+1)=0,
    det(K-gamma I)=(-gamma)^N.

For nonzero gamma the selected determinant is therefore exactly

    det((QF_(4N)-gamma F_NQ)[:,J]) = det(F_N)(-gamma)^N,

which is nonzero. This proves full row rank. For gamma=0, QF_(4N) has full row rank because Q does and F_(4N) is invertible.

The case b=1 is included: every selected j is odd, K=0, and the same determinant formula applies.

## 4. Consequence for scaled copying through a proper active bank

Let B_small have F_b on active blocks J and identity elsewhere, and let B_large have F_(2b) on the pulled-back set J union(J+a). The earlier exact bank calculation gives

    rank(Q B_large-B_small Q)=b|J|.

Suppose three layers at both levels obey Q H_(l,large)=gamma_l H_(l,small)Q with nonzero gamma_l, and suppose both products H3 H2 B H1 equal the respective Fourier targets. The same telescoping calculation as before gives

    QF_(4N)-(gamma_1 gamma_2 gamma_3)F_NQ
      = gamma_3 gamma_2 H_(3,small)H_(2,small)
        (Q B_large-B_small Q)H_(1,large).

The right side has rank b|J|, whereas the left side has rank N for every product of the scalars. Therefore **no proper active bank can lift by scalar-multiple layer descent alone**, including normalization-balanced scalings. This statement covers both the unnormalized target and its unitary-normalized variant after inserting their known scalar factors.

It does not exclude actual four-fiber coefficient mixing, different bank layouts or normalizations, or layers that do not satisfy the assumed scalar descent. It is not an unrestricted FFT lower bound.

## 5. How much descent failure a genuine coefficient law must provide

For candidate layers define

    D_l=Q H_(l,large)-gamma_l H_(l,small)Q.

Let E_B=Q B_large-B_small Q and Gamma=gamma_1 gamma_2 gamma_3. For the specified product C=H3 H2 B H1, exact telescoping gives

    Q C_large-Gamma C_small Q
      = D_3 H_(2,large) B_large H_(1,large)
      + gamma_3 H_(3,small) D_2 B_large H_(1,large)
      + gamma_3 gamma_2 H_(3,small)H_(2,small) E_B H_(1,large)
      + gamma_3 gamma_2 H_(3,small)H_(2,small) B_small D_1.

Under the two Fourier identities, the left side has rank N. Rank subadditivity, rank(E_B)=b|J|, and the theorem imply

    rank(D_1)+rank(D_2)+rank(D_3) >= N-b|J|.

At a half-active bank this lower bound is N/2. This is a rank requirement on deviations from scalar layer copying, not an operation-count lower bound. A linear-rank diagonal or sparse correction can still have O(N) application cost.

Every factor position is counted in this sum. For a longer product, the same telescoping argument counts one transported defect at each occurrence; if a layer is reused k times, its rank bound is charged k times unless a separate sharing identity proves something sharper. Here each of the three displayed layers occurs once. All gamma_l are nonzero, and both levels use the same bank placement and the pulled-back active labels stated above.

For the proposed one-sided endpoint model and an exactly quotient-compatible route family with matching poles,

    D_l = sum_j E_(l,j) G_(j,large),
    E_(l,j)=Q diag(a_(l,j,large))-gamma_l diag(a_(l,j,small))Q.

Each column of E has at most one nonzero entry. Its rank is exactly the number of small fibers on which at least one coefficient differs from its scalar-pulled-back value. Thus the total number of affected small fibers, charged separately across all24 endpoint masks, must be at least N-b|J|. This prevents hiding all lifting freedom in only a sublinear number of endpoint mismatches under this particular model.

## 6. Rank-compatible freedom remains cheap

This necessary rank budget does not exclude a genuine four-fiber law. For example, on a fiber with high bits (epsilon_x,epsilon_y), take the nontrivial character chi=(-1)^epsilon_y and set one large mask to chi times a nonzero pulled-back small mask. For every scalar gamma, the defect on each fiber has coefficients proportional to1-gamma and-1-gamma. In characteristic different from2 they cannot both vanish. Therefore this single endpoint-mask defect has full row rank N, while its coefficients can be generated in O(N) word/field operations and remain nonzero.

More generally the four fiber characters1,(-1)^epsilon_x,(-1)^epsilon_y,(-1)^(epsilon_x+epsilon_y) span every coefficient pattern on a four-point fiber. Their three nonconstant channels supply rank-compatible freedom. The remaining open problem is to choose the channel coefficient laws so that all Fourier entry equations, bank even/odd twiddles, inverse guards, and size-lifting relations hold simultaneously. The rank-compatible mask example is not such a solution.
