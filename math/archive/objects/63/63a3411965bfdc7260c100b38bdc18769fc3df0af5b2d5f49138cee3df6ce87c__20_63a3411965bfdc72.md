# Phase 10: Can fresh Fourier subgraphs share fewer exact intermediates?

Date: 9 October 2026. Status: completed finite experiment and elementary
restricted-model proofs; **the project's general `o(N log N)` goal is not met.**

## 1. Scope and the supplied compiler

The main test is a fresh arbitrary vector, all outputs, and input-independent
preparation. We distinguish three problems: exact complex-field arithmetic,
finite-precision numerical FFTs, and integer multiplication measured in bit
operations. A result for one does not automatically establish a result for
another. This round studies dyadic lengths, a necessary useful subproblem;
it supplies no all-length complexity theorem.

The uploaded `fft_phase9_compiler_research(1).zip` implements known-edit
polynomial convolution updates. Its generated loop is linear in output length
for bounded degree *after* data-dependent kernel preparation. Those kernels
change when the base data changes. They are not preprocessing that can be
reused for every unrelated fresh input. The source itself correctly states
this limitation. We retain it unchanged and record the current rerun separately
from its historical performance results.

This distinction also prevents a misleading global claim. OpenAI's official
[result #130 scope page](https://github.com/openai/math/blob/main/lean/docs/130.md)
reports a uniform all-length exact DFT/convolution result below `n log n` in an
unrestricted-coefficient complex-arithmetic model with a supplied root. Its
separate subsequential statement has different scope. We did not implement or
independently audit those constructions here. Saying *our project has not
achieved the goal* does not mean no external exact-arithmetic result exists.
Nor does that source establish our practical FFT or integer bit-complexity goal.

## 2. Candidate: share an encoding, then correct the outputs

Let `F[i,j] = zeta^(ij)`, where zeta has exact order N. The positive-exponent
convention differs from the usual negative-exponent forward transform only
by an output permutation. Seek a fixed decomposition

`F = U V + E`,

where `U` is N-by-r, `V` is r-by-N, and E is sparse or cheaply factored. For
each fresh x, evaluate `z = Vx`, reuse its r values in `Uz`, and add `Ex`.
This shares actual linear values inside one computation, not values from an
earlier input. Rank alone is not a cost: both maps and the correction must be paid.

We implemented the concrete skeleton family

`U = F[:, C]`, `V = F[R,C]^-1 F[R,:]`, `E = F - UV`,

for equally sized anchor sets R and C with an invertible anchor minor. This
includes general anchors and periodic ones. Every emitted addition,
subtraction, nontrivial scalar multiplication, and required standalone
negation is explicit in a straight-line graph. All N outputs are materialized.
Node results can be reused by multiple later nodes.

The search scans small modular instances, then lifts selected anchor choices
to `Q[zeta]` and checks the resulting graph on every input basis vector.
Linearity makes this an all-input identity check. Modular coincidences are
not silently carried into the complex model: one 8-point candidate costs 82
gates modulo 17 but 84 gates over the cyclotomic field.

## 3. Exact block rank: a small numerical rank is not an identity

Take a rows and b columns in arithmetic progressions:

`i = i0 + s*u`, `j = j0 + t*v`, with `0 <= u < a`, `0 <= v < b`.

Then

`rank(F[rows,cols]) = min(a, b, N/gcd(N, s*t))`.

Proof: multiplying by invertible diagonal matrices removes the offsets,
leaving `(zeta^(s*t))^(u*v)`. The base has order
`h = N/gcd(N,s*t)`. Rows and columns repeat after h, so rank is at most h
and at most a and b. The first `min(a,b,h)` rows and columns form a
Vandermonde matrix at distinct nodes, so that minor is nonsingular.

In particular, a consecutive b-by-b Fourier block has exact rank b. It cannot
be replaced by fewer than b linear summary values with an exact linear decoder
and no correction. Conversely, complementary *strided* blocks can have rank
one. This is genuine algebraic structure, already exploited by FFT factorizations;
it does not by itself bound the work of the whole graph below `N log N`.

The numerical diagnostic uses the first 64 rows and columns of `F_4096`.
At relative singular-value threshold `1e-12`, its apparent rank is 12;
its exact rank is 64, also witnessed modulo 12289. Dropping singular directions
is therefore an approximation. The supplied adversarial vector illustrates
nonzero error; scaling it to unit absolute output error does not refute a
relative-tolerance approximation guarantee.

This boundary agrees with the scope of established
[butterfly factorization](https://arxiv.org/abs/1502.01379): complementary
numerical low rank supports useful approximate sparse factorizations and
`O(N log N)` applications. It is not an exact sublogarithmic-stage theorem.

## 4. A general rank-plus-sparse restriction

For any fixed rank-at-most-r matrix L and `E = F-L`, with `0 <= r < N`,

`nnz(E) >= (N-r) * floor(N/(r+1))`.

Proof: split the columns into disjoint consecutive groups of r+1, ignoring
the last shorter group. In any full group, at least N-r rows must contain a
nonzero E entry. Otherwise at least r+1 rows have zero error throughout that
group. On those rows and columns, L equals a nonsingular Vandermonde minor
of F, contradicting `rank(L) <= r`. Each full column group therefore contributes
at least N-r distinct nonzero entries. Summing proves the inequality.

This is an elementary restricted rank/sparsity bound, not a new general Fourier
circuit lower bound. In particular, it does not rule out rapidly evaluated
structured E, several shared components, or cross-layer cancellation.

### Consequence for the direct skeleton evaluator

All entries of U, being selected Fourier columns, are nonzero. Our architecture
forms each of its N length-r output dot products independently, using
`N(r-1)` additions. Direct E row sums plus their merges with the low-rank
outputs require at least `nnz(E)` further additions. Thus its scalar-gate count obeys

`C(N,r) >= N(r-1) + (N-r) floor(N/(r+1))`.

This is `Omega(N^(3/2))` uniformly over `1 <= r < N`. To see this, if
`r >= sqrt(N)`, the first term already has that order; for `r < sqrt(N)`,
the second does, using `N-r >= N/2` and
`floor(N/(r+1)) >= N/[2(r+1)]` for N at least 4. The endpoint r=N is
a direct dense Fourier-column decoder and is quadratic.

The restriction to independent direct dot products and entrywise corrections
is essential. Rewriting the decoder and residual into a shared sparse graph
can evade this architecture-specific argument. That is exactly why the next
candidate must be evaluated as a whole graph, rather than scored only by rank.

## 5. Stronger restriction for cheap periodic decoding

The most tempting decoder uses regularly spaced Fourier columns: it is
periodic, so a smaller FFT can generate its values. Does that leave a sparse
correction? For dyadic N, let r divide N, also dyadic, set `q=N/r=2^t`, and choose

`C = {c, c+q, ..., c+(r-1)q}` modulo N.

For **every** L whose column space lies inside the span of these Fourier columns,

`nnz(F-L) >= N² - Nr(1+t/2)`.

The bound is attained. Consequently if `r <= N/2`,

`nnz(F-L) >= N²/4`.

Proof: first take c=0. Every vector in this subspace is periodic with period r.
For a fixed input column j and residue i0 modulo r, the q target entries in
rows `i0+r*h` equal

`zeta^(i0*j) * (zeta^(r*j))^h`.

There are `q/gcd(j,q)` distinct values, each repeated `gcd(j,q)` times.
Any one periodic predicted value can match at most `gcd(j,q)` of those q
entries. With r row groups, the total matches across all N columns are at most

`r * sum_(j=0)^(N-1) gcd(j,q) = Nr(1+t/2)`.

Here `sum_(j=0)^(q-1) gcd(j,q) = q(1+t/2)`: the j=0 term is q, and
each possible two-adic valuation from 0 through t-1 contributes q/2.
Choosing each group's prediction to match h=0 attains this count. All such
periodic vectors lie in the stated column span, so this is a true minimum,
not just the count of one bad encoder. For nonzero c, divide each row by
`zeta^(c*i)`; the same argument uses j-c, which merely permutes the gcd sum.
Finally `(1+t/2)/2^t <= 3/4` for every integer t at least 1.

These proofs apply over the complex field and over any field admitting the
required primitive Nth root. They are project-specific derivations using
standard Vandermonde and character arguments; no claim of literature novelty
is made.

## 6. Dense does not mean intrinsically slow

At `r=N/2`, the periodic residual has `N²/4` nonzeros, yet those entries share
structure. Write the two half-length transforms of even and odd inputs as
`A_k` and `B_k`. The full outputs are

`X_k = A_k + zeta^k B_k`,
`X_(k+N/2) = A_k - zeta^k B_k`.

The periodic low-rank part repeats the top half; its correction subtracts
`2 zeta^k B_k` in the bottom half. Sharing `zeta^k B_k` and combining the
addition/subtraction avoids scanning the dense correction. It gives the
classical radix-2 FFT. The executable control verifies this identity on all
basis vectors; **it recovers `Theta(N log N)`, not a new improvement**.

The same warning applies to known non-rigidity results. The
[Alman–Rao paper](https://arxiv.org/abs/2211.06459) demonstrates useful
constant-factor Fourier and Walsh–Hadamard savings. Its Section 8 explicitly
retains a positive `N log N` Fourier term even under a hypothetical sub-`N log N`
WHT subroutine in that reduction. Replacing just one component is insufficient.

## 7. Resource accounting and a sharper research filter

The reported gate model counts a scalar add/subtract as one, multiplication
by a fixed scalar other than +/-1 as one, and a necessary standalone negation
as one. In particular multiplying a complex value by i is counted here;
the comparison FFT uses the same convention. Data movement, allocation,
indexing, input reads, N output writes, and preparation are additional work.

The skeleton preparation materializes N² matrix entries, inverts an r-square
minor, and forms its factors/residual. A naive field-operation upper bound is
`O(N²r + Nr² + r³)` plus root generation and indexing, with `O(N²+Nr+r²)`
stored field elements. Search repeats this work across anchor choices.
The exact rational implementation can also incur growing bit costs. None is
amortized away to claim a fast first transform. Recorded setup times include
candidate creation and the evaluated search; validation times and raw logs
are supplementary. The graph interpreter itself keeps all scalar nodes alive,
so its memory is O(N+g), not a claimed optimized liveness schedule.

There is also a model constraint beyond caching. The determinant argument
for bounded-coefficient linear circuits, reviewed by
[Ailon](https://arxiv.org/html/1403.1307v5), implies for the **unnormalized** DFT
with two-input linear gates whose coefficient magnitudes are at most C>=1:

`g >= N log2(N) / [2 log2(2C)]`.

For completeness, start with the input-coordinate rows, whose maximum absolute
N-row determinant is 1. Adjoining a row `lambda*a + mu*b` increases this maximum
by at most `|lambda|+|mu| <= 2C`, by multilinearity. The final Fourier determinant
has magnitude `N^(N/2)`, proving the inequality. This statement permits saved
intermediates; it is not a universal bound covering other models or a normalized
transform. Unrestricted-coefficient exact algorithms are outside the fixed-C case.

Thus if `g <= c0*N*(log2 N)^(1-delta)`, a necessary condition in this gate model is

`C(N) >= 2^((log2 N)^delta/(2*c0)-1)`.

Growing coefficients are not sufficient, but a uniformly bounded-coefficient
rewrite cannot supply the proposed exponent saving for this target. This is
a useful early rejection rule for future graph synthesis.

## 8. Next decisive candidate and what would count as success

The next search should allow exact cancellation and shared computation across
both the decoder and correction, with unrestricted scalar coefficients. It
should not restrict the encoding to one coset of Fourier modes or evaluate a
dense decoder row by row. The exported linear graph format already permits
shared nodes and arbitrary rational cyclotomic constants; the present candidate
generator does not synthesize that stronger family.

A growing family of b-input fused stage graphs must include the twiddle patterns
it encounters. If b=2^t divides the dyadic stage structure, h=log_b N groups with
kernel cost G(b) give the budget

`T(N) <= P(N) + (N/b)*h*G(b) + O(Nh)`.

P(N) includes **all** required pattern preparation and constants. A fixed
30% saving keeps `T(N)/(N log N)` bounded away from zero. Merely fusing t
ordinary stages also retains their arithmetic. A genuine result needs a
vanishing normalized budget, appropriate preparation, and a proof for a growing
family. For example `G(b)=O(b)` for suitable b about log N would suggest a
log-log saving, but that exact family is **not supplied here**. Remaining short
stage groups and a transfer beyond dyadic lengths must also be handled.

Required evidence for the next candidate: an exact all-input identity, the full
scalar graph, growing-family cost including correction and preparation,
coefficient/precision control for any numerical or bit claim, and explicit
outputs. We preserve the linked
[integer-mult-kappa repository](https://github.com/Swapnil-jain/integer-mult-kappa)
as a separate possible future integration. No code, exponent, tape-layout
contract, or correctness theorem from it is imported by this round.
