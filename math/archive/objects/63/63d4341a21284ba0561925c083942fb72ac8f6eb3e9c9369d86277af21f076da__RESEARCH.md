## 1. Model and exact matrix

Let `N=QM`, `omega` be a primitive Nth root of unity over a field of characteristic coprime to N, `eta=omega^Q` of order M, and `xi=omega^M` of order Q. Arrange the raw input as `y_t[u]=x_{t+Qu}`. Its fiber spectra are

`C_t[h]=sum_{u=0}^{M-1} y_t[u] eta^(-h u)`.

For the original unnormalized Fourier transform, with `k=h+sM`,

`X[h+sM]=sum_{t=0}^{Q-1} C_t[h] omega^(-h t) xi^(-s t)`.

When orbit coefficients happen to be available,

`C_t[h]=sum_{j=0}^{g-1} B_j[h] lambda_j(h)^t`, where

`lambda_j(h)=mu_j eta^(-a_j h)`.

Define `z_s(h)=omega^(-h) xi^(-s)` and `G_Q(z)=sum_{t=0}^{Q-1} z^t`. The `Q x g` orbit-output matrix is

`K_h[s,j]=G_Q(z_s(h)*lambda_j(h))`.

**All operations to compute the raw-to-orbit coefficients B must be charged.** Re-labeling an arbitrary transform as `K_h B` alone is not an algorithm.

## 2. Exact geometric routing dichotomy (proved)

Since `z_s(h)^Q=eta^(-h)` is independent of `s`, for fixed `h,j` either:

- `(z_s lambda_j)^Q != 1` for all `s`; then every one of the Q values `G_Q(z_s lambda_j)` is **nonzero**; or
- `(z_s lambda_j)^Q = 1` for all `s`; exactly one `s` has `z_s lambda_j=1`, giving `G_Q=Q`, and **all other Q-1 entries are zero**.

Thus every orbit at every h has **exactly 1 or exactly Q nonzero output edges**, no intermediate sparsity. The routed-channel condition is

`mu_j^Q = eta^(h*(a_j*Q+1))`.

For fixed `(a_j,mu_j)`, the number of routed channels h is either zero or

`gcd(a_j*Q+1,M)`.

Proof: if `mu_j^Q` lies outside the cyclic group generated by eta, there are none. Otherwise write it as `eta^c`; then solve the elementary congruence `(a_jQ+1)h=c mod M`.

## 3. Complete routing possible if and only if gcd(Q,M)=1 (restricted design)

For **one shear a shared across all orbits** to route every h, including h=0 and 1, it is necessary that `mu_j^Q=1` and `a Q+1=0 mod M`. The latter has a solution **iff** `gcd(Q,M)=1`.

When Q and M are coprime, take

`a = -Q^{-1} mod M`, `b=(aQ+1)/M`, and `mu_j=xi^j` for `j=0,...,Q-1`.

Then `lambda_j(h)=xi^j eta^(-ah)` and

`z_s(h)*lambda_j(h)=xi^(j-s-bh)`.

Consequently

`K_h[s,j]=Q` if `j=s+b*h (mod Q)`, and `0` otherwise.

**All N output coefficients are routed in O(N) operations if B is already known.** This example deliberately uses a common shear `a` for all Q orbits, so it is an orbit-representation experiment, not an input that necessarily satisfies the earlier distinct-shift multi-shear *recognizer* assumptions. The coefficients are *not* known for a fresh arbitrary raw input. They are exactly

`B_j[h]=(1/Q) * sum_{t=0}^{Q-1} C_t[h] eta^(aht) xi^(-jt)`.

Obtaining `C_t[h]` requires Q length-M DFTs. Obtaining all B requires M length-Q DFTs. Output routing is therefore the classical mixed-radix / Good-Thomas-type two-stage transform in different coordinates (and still costs O(N log N) with standard FFT primitives, or O(N(M+Q)) with direct short DFTs). **No complexity breakthrough.**

`routing_gate.py::two_stage_arbitrary_raw_routing()` implements the complete fully charged *direct-transform* pipeline, verifies recovered orbits against every original input sample, and checks all outputs against a separate direct DFT. It makes no asymptotic speed claim.

## 4. Square-length obstruction for the earlier universal basis

Let `Q=M>=2`, `N=M²`, and select the universal orbit basis from the earlier checkpoint in a particularly explicit form:

`a_j=j` and `mu_j=omega^j`, for `j=0,...,M-1`.

Then `lambda_j(h)=omega^((1-Mh)j)` and the nodes are all distinct, since `1-Mh` is coprime to M². The Vandermonde matrix of temporal orbit values is nonsingular at every channel, so the representation spans **all arbitrary** N-input vectors.

But the routing condition becomes

`mu_j^M=eta^h`, i.e., `eta^j=eta^h`, equivalent to `j=h mod M`.

For fixed h, precisely one orbit j=h routes to one output s; **each of the other M-1 orbit columns is nonzero at all M outputs**. Thus

`nonzero edges per h = M(M-1)+1 = M²-M+1`

and over all M channels

`nonzero edges = M³-M²+M = Theta(N^(3/2))`.

This is a **lower bound only for the term-by-term orbit-edge accumulation model**, not a lower bound on FFT arithmetic circuits or finite-field linear circuits. A dense matrix may still admit a fast structured multiplication.

## 5. New useful structural certificate: Sylvester displacement rank one

For arbitrary `Q,M,g`, put `D_z=diag(z_0,...,z_(Q-1))` and `D_lambda=diag(lambda_0,...,lambda_(g-1))`. Using

`(1-z lambda) G_Q(z lambda)=1-(z lambda)^Q`, valid even at `z lambda=1`, yields exactly

`K_h - D_z K_h D_lambda = one_Q * d_h^T`, with

`d_h[j]=1-eta^(-h)*lambda_j(h)^Q`.

Therefore the Sylvester *displacement matrix* has rank <=1, even if K_h is dense and full rank. This is classical Cauchy-like structure; low **displacement rank** must not be confused with low ordinary matrix rank.

In the coprime complete-routing construction d_h is identically zero, and K_h is a monomial/permutation matrix. In the square universal basis, d_h has M-1 nonzero values at every h, displacement rank is one, and the **ordinary rank of K_h is M**.

To see full ordinary rank, use the exact factorization

`K_h = F_Q * diag(omega^(-h*t))_(t=0..Q-1) * V_h`, with

`(F_Q)_(s,t)=xi^(-st)` and `(V_h)_(t,j)=lambda_j(h)^t`.

For g=Q distinct lambdas, both F_Q and V_h are nonsingular, hence rank K_h=Q. A rank-one Sylvester *defect* does not imply a rank-one matrix or an O(Q) generic matvec.

### Quantum-inspired operator sanity check

On M-coordinate fibers define a cyclic shift S and a character-modulation T. Then

`S T = eta^(-1) T S`.

They cannot be simultaneously diagonalized when eta !=1. This is the elementary finite Heisenberg/Weyl commutation relation; it cautions against declaring a single global basis that makes every shift and phase operation diagonal for free. It does **not** imply any superlinear lower bound for a general Fourier algorithm, classical or quantum.

## 7. What counts as future progress

**Do not repeat**: (i) one-orbit-per-output routing with free access to B; (ii) claiming O(N) because K has displacement rank one; (iii) charging only nonzero edges but not coefficient recovery; (iv) renaming mixed-radix/Good-Thomas FFT as a shear graph breakthrough; or (v) treating Weyl noncommutation as a universal FFT lower bound.

**Next legitimate target:** design an explicit **joint full-input** evaluator for all h that bypasses the separate `Q` row DFTs and the per-channel Vandermonde/Cauchy computation. Its uniformly charged arithmetic complexity must beat actual baselines **in the same arithmetic model**. For Q=M the challenge is evaluating the dense full-rank, rank-one-displacement blocks across all h in jointly O(M²) operations, **and** recovering their arbitrary input coefficients in O(M²) work. A single-channel Cauchy `O(M log^c M)` evaluation leaves O(N log^c M) total.

**Literature boundaries:** Good–Thomas (CRT factorization), finite displacement-rank/Cauchy and multipoint evaluation, and the Sep 2026 exact-complex Fourier result (#130, O(N(log N)^(1-1e-13))) all predate this checkpoint. Our value here is a scoped, tested obstruction and a clean problem definition for the proposed Graph+Union program, **not priority for those algebraic ingredients**.
