# Portable independent replay

Run `python independent_checks.py` with Python 3.11+ and its standard library. It imports no uploaded modules and requires no source data files or network. It writes deterministic `INDEPENDENT_RESULTS.json` beside itself and prints the same JSON. Its working directory can differ from its file location.

All uploaded programs in the preserved source archive and extraction remain inert. The independent checks use companion-operator powers and exact integer cyclotomic reduction; saved source benchmark and predecessor test logs are not executed. The sealed report states the scope and boundary correction.
