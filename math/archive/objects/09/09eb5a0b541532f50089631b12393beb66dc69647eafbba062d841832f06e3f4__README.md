# FFT research checkpoint — Recursive Fourier-Mass Contraction

**10 October 2026. No new universal fast Fourier algorithm has been constructed.**

This package contains a conditional complexity theorem, a concrete unproved Green-network factorization conjecture, a proved bank-aware inverse-support/defect obstruction, and exact finite verification code.

All six test groups should pass. The program writes `RESULTS.json` beside itself. It uses a direct quadratic DFT and dense matrix operations as independent validation tools; it is **not** a sub-N-log-N implementation.

## Main conditional result

If an exact fully charged decomposition has recursive calls of length at most approximately sqrt(N), total recursive length at most rho*N, and O(N) other work, then:

- rho<1 gives O(N).
- rho=1 gives O(N log log N).
- 1<rho<2 gives O(N*(log N)^(log_2 rho)).

No rho<2 decomposition is supplied. The concrete candidate is a single partially active Fourier bank between four layers, each a sum of two independently ordered weighted Green resolvents. Its uniform exact coefficient construction is the missing result.

## Do not claim

Do not turn the recurrence theorem into an unconditional FFT upper bound. Do not label the invalid bank-deletion control a fast algorithm. Do not call dense-inverse examples Fourier factorizations. Do not infer a complex identity from modular equality alone. Do not treat root extension, coefficient search, precision or output writes as free.
