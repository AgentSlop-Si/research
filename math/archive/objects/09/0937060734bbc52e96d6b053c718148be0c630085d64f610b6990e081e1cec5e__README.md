# Hero #17: Spectral Newton-Union Research

Exact, reproducible **structured-input** `O(N)` transform, not a universal new FFT.

## Requirements

Python 3.10+ standard library only. No NumPy or SciPy needed. Modular field `p` prime, `N|(p-1)`, primitive order-N root `omega` supplied. Tests prepare roots for explicit fixtures using the inherited `tensor_union.root_for` helper.

## Reproduce

From this folder:

```bash
python -m unittest discover -v -p 'test_*.py'
python independent_audit.py
```

## Key API

```python
from newton_union import transform_if_recognized

# Returns (N-value spectrum, certificate) if raw input fits the promise;
# otherwise (None, None).  No generic-input fallback is claimed.
spectrum, certificate = transform_if_recognized(
    raw_x, p, primitive_omega, order=3, total_modes=Q, q=Q
)
```

- `Q` divides `N`, `M=N//Q`, both approximately sqrt N.
- All first d rows may be arbitrary dense vectors.
- The sum of spectral support sizes of their *d-th temporal differences* is at most `total_modes`.
- Recognition scans raw x and verifies every recovered row structure.
- The full N-point output is written in exact modular arithmetic.

Source modules: `newton_union.py`, `delta_graph_budget.py`, `second_difference_graph.py`, `delta_graph.py`, `graph_convolution_delta.py`. The retained Hero #17 modules are bundled for lineage and tests.

See `RESEARCH.md` for theorem assumptions, full derivations, charged work, scaling counts, prior art and reasons the all-input problem is still open. `CHAIN_CHECKPOINT.md` is the resumable short handoff.
