# Phase 15 — Exact dyadic compression of Galois residuals and a Green-stage sparsity barrier

**Date:** 2026-10-09  
**Target:** an exact Fourier algorithm with genuinely less than `N log N` *charged* work.  
**Outcome:** constructive residual compression, explicit inverse, exact circuit budget, and an architecture-specific no-go. **No new sub-`N log N` Fourier bound.**

## 1. Context and definitions

We continue Phase 14's exact Galois descent, not the OpenAI/CrocSwap tensor-network route. Work first over `C`, using the **positive-exponent, unnormalized** DFT matrix `F_N[k,j] = ζ_N^(kj)`. Finite-field code uses the same identities with a primitive root modulo `998244353`, which does not establish floating-point stability.

Let `N = B L`, with `N,B,L` powers of two and `8 <= B < N <= B²`, so `L <= B`. Let `ζ_B = ζ_N^L` and `σ(ζ_N)=ζ_N^(1+B)`. For each orbit under `k -> (1+B)k mod N`, let `k0` be its least (scanning) representative, `d` its length, and `g=L/d`. Then `k0 = g u`, with `0<=u<B`, and when `d>1`, `u` is odd. The orbit's `d` character labels are `e=0,...,d-1`, with `r_e=g e`.

The previous exact factorization is `F_N = B_orbit Q A`, with `B_orbit` a blockwise unnormalized Fourier matrix of lengths `d`, `Q[orbit,e]=ζ_N^(r_e)`, and

`A[orbit,e,j] = ζ_B^((k0*j-r_e)/L)` when `k0*j == r_e (mod L)`, and `0` otherwise.

Phase 14 counted `nnz(A)=N[B+(B/2)log2L]` and evaluated it as a sparse matrix; the following result avoids that naive cost.

## 2. The dyadic frequency-folding identity

For each dyadic `d` dividing `L`, each `a=0,...,d-1` and `h=0,...,B-1`, define a cyclically folded stream

`z[d,a,h] = sum_{t=0}^{L/d-1} x[a + d*(h + B*t)]`.

Define its **B-point Fourier spectrum**

`Y[d,a,q] = sum_{h=0}^{B-1} z[d,a,h] ζ_B^(q h)`.

At the finest level `d=L`, this is simply an ordinary B-point transform of the strided input `x[a+Lh]`, for each of the `L` residue classes `a`.

**Lemma (folding):** For `d>=2`, with `a<d/2` and `0<=q<B/2`,

`Y[d/2,a,q] = Y[d,a,2q] + ζ_B^q Y[d,a+d/2,2q]`,

`Y[d/2,a,q+B/2] = Y[d,a,2q] - ζ_B^q Y[d,a+d/2,2q]`.

Indices in the first two spectra are modulo `B`. **Proof:** Write `h=2v+s` in the definition of `z[d/2,a,h]`, with `s=0,1` and `0<=v<B/2`. Since `B` is even, the `L/(d/2)` summands split into two sets, giving

`z[d/2,a,2v+s] = z[d,a+s*d/2,v] + z[d,a+s*d/2,v+B/2]`.

Taking the B-point DFT, the two parities have twiddle `ζ_B^q`, and the inner half-length DFT equals the even-frequency sample `Y[d,*,2q]`. The partner `q+B/2` flips the odd-parity sign. QED.

**Lemma (residual extraction):** For `d>1`, compute `a = u^(-1)e mod d` and `c=(u a-e)/d` (an integer). Then

`(Ax)[orbit,e] = ζ_B^c Y[d,a,u]`.

For `d=1`, take `a=0` and the same identity with `u=k0/L`. **Proof:** Precisely the columns `j=a+dh` contribute to this residual row, with `h=0,...,Bg-1`; their coefficient is `ζ_B^(c+u h)`. Partition the index `h` by residues modulo `B`, obtaining `ζ_B^c Y[d,a,u]`. QED.

**Executor:** Perform `L` length-`B` FFTs at the finest level; compute all lower `Y[d]` with the folding lemma; read one prescribed spectral coordinate per residual output and apply its phase. No dense or sparse residual matrix is materialized.

## 3. The folding network has an O(N) inverse and is scaled-unitary

Let `P_in` reshape the input into `L` streams of length `B`, and let `D_B=I_L ⊗ F_B`. The executor expresses

`A = R D_B P_in`,

where `R` is the folding-and-extraction network. Exactly `(N-B)/2` radix-2 butterflies, plus `O(N)` gathers/scalings, apply `R` for any input. All stored multiscale spectral vectors together have `B*(2L-1) = 2N-B` scalar coordinates.

To invert `R`, start with the complete `d=1` spectrum and fill each level's **odd** frequency components from the corresponding `A` output, undoing the known diagonal phase. The **even** frequencies at level `d` are recovered from the complete level `d/2` by

`u=(Y[d/2,a,q]+Y[d/2,a,q+B/2])/2`,

`v=ζ_B^(-q)*(Y[d/2,a,q]-Y[d/2,a,q+B/2])/2`.

These are the two parent values `Y[d,a,2q]` and `Y[d,a+d/2,2q]`. Repeat up to `d=L`. This costs the same `(N-B)/2` butterflies. The full residual inverse `A^-1` then performs `L` length-`B` inverse FFTs. Exact modular round trips have been checked through `N=4096`.

There is also an **exact complex spectral identity**. Since the unnormalized DFT obeys `F_N F_N* = N I`, `Q Q*=I`, and `B_orbit* B_orbit = diag(d_e)`,

`A A* = diag(N/d_e)`.

Because `D_B D_B* = B I`, we obtain

**`R R* = diag(L/d_e)`.**

Thus `diag(sqrt(d_e/L)) R` is exactly unitary; its inverse is also a linear-work wavelet-type network. It is *not* a new Fourier algorithm. A complex numerical Gram check corroborates this statement up to `N=256`.

A row associated with an orbit of length `d` has exactly `g=L/d` nonzero entries in `R`. Therefore

`nnz(R) = N [1 + (1/2)log2 L]`,

`nnz(A) = B * nnz(R)`.

The matrix `R` itself has `Theta(N log L)` entries but an `O(N)` arithmetic executor because the intermediate even-frequency sums are shared. This is a concrete, exact instance of the project's **computation-graph reuse** idea; importantly it applies to a *wavelet-like factor*, not the costly entire Fourier transform.

## 4. Butterfly conservation theorem: no full FFT speedup

Write `b=log2 B` and `h=log2 L`. Count all radix-2 butterflies of the explicit full factorization `F_N = B_orbit Q R D_B P_in`.

1. `L` ordinary length-`B` FFTs: `C_base=(N/2)b` butterflies.
2. Dyadic folding across `L,L/2,...,1`: `C_fold=(N-B)/2` butterflies.
3. Orbit Fourier transforms: for each `d=2^t`, `1<=t<=h`, exactly `B/2` orbits have length `d`, each requiring `(d/2)t` radix-2 butterflies. Thus

   `C_orbit=(B/4) sum_{t=1}^h t*2^t = B/2 + (N/2)(h-1)`.

Adding yields the **exact identity**

`C_base + C_fold + C_orbit = (N/2)(b+h) = (N/2)log2N`.

This is a **count for this constructed radix-2 network**, not an asymptotic lower bound on all FFT algorithms. Twiddle preparation, permutations, phase masks, and output writes additionally cost at most the usual `O(N log N)` in the supplied executor and do not improve its asymptotic time.

Under the one-mask field condition `B >= sqrt(N)`, the `B`-point bank alone requires at least `(N/4)log2N` radix-2 butterflies. For balanced `B≈L≈sqrt(N)`, the orbit bank also requires `Theta(N log N)` butterflies. Thus replacing only the `O(N)` folding/Green/Haar part **cannot** yield `o(N log N)`; we must compress/fuse *both* expensive Fourier banks.

The new `phase15_executor.py` independently matched the original Phase-14 sparse residual and direct Fourier sums for sizes through `N=1024`; at `N=2048`, the complete output matched a separate radix-2 transform. `haar_coherence.py` checked both `R^-1(R U)=U` and `A^-1(Ax)=x` for multiple random inputs through `N=4096`. These tests check algebra, **not practical speed** or floating-point error.

## 5. An additional exact no-go for *pure* sparse-inverse Green stages

Suppose each stage is `G_j=B_j^-1`, with every row of the invertible matrix `B_j` containing at most `s` nonzeros; arbitrary invertible monomial matrices `M_j` (permutations and nonzero diagonals) may be inserted:

`F_N = M_t B_t^-1 M_(t-1) ... B_1^-1 M_0`.

Taking inverses yields

`F_N^-1 = M_0^-1 B_1 M_1^-1 ... B_t M_t^-1`.

Each multiplication by a row-`s` sparse matrix can enlarge the nonzero support of any row by a factor of at most `s`; monomial factors preserve support cardinality. Therefore the inverse product has **at most `s^t` potentially nonzero entries per row**. But *every* entry of `F_N^-1` is nonzero. Necessarily

**`s^t >= N`, hence `t >= ceil(log_s N)`.**

This applies with *no condition-number, Galois-field, or root-order restriction*. It defeats the plan to obtain a sublogarithmic number of pure bounded-degree Green solves simply by allowing arbitrary phase and permutation layers. **It does NOT apply to sums of Green inverses, sparse-plus-low-rank inverses, or general unitary Haar–Green stages whose inverses are not row-sparse.** Those are possible escape routes and are the project's actual remaining direction.

Related one-stage uncertainty statement: if `F_N=B^-1 A`, and each row of `B` has support at most `s` while each row of `A` has support at most `t`, then `s*t>=N`. Indeed each row of `A=BF_N` is the Fourier transform of a row of `B`, and the standard complex Fourier support uncertainty principle gives `|supp b| |supp(bF_N)|>=N`. This too applies only to sparse right-hand preprocessing, not a fast *dense-structured* input transform.

## 6. Research target, not a claimed solution

Our next genuinely promising gate is **cross-bank fusion**, not improving the now-linear `R`:

- Construct a single, non-monomial Green/Haar/reuse network that links the `L` base B-point transforms **and** the orbitwise Fourier transforms before their independent butterfly passes are committed.
- It must respect **both** exact Fourier intertwining `FZ=DF` and the Galois covariance `σ(F)=P_(1+B) F`, rather than only matrix density, crosscut rank, unitarity, or small numerical reconstruction residuals.
- Explicitly evade the sparse-inverse stage bound (e.g. by genuinely noncommuting sums of Green resolvents); do not re-test pure path Green solves or single-mask chirps.
- Establish a uniform bound on *all* arithmetic, graph construction, scalar preparation, and memory traffic. An isolated finite-size speedup or a precomputed dense table is insufficient.

**What is new here relative to earlier checkpoints:** a linear-work exact residual folding factor `R` with an exact inverse and scaled-unitarity proof, an explicit `O(N log B)` residual executor, an exact butterfly accounting revealing no global saving, and the elementary but strong sparse-inverse product obstruction. The mathematical ideas resemble known FFT polyphase, Haar, and uncertainty principles; novelty/priority beyond this project has **not** been established.
