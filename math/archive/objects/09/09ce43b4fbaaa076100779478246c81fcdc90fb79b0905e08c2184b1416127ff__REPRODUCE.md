# Reproduce this independent audit

Only the newly written audit programs need to be executed. No submitted or predecessor implementation is run or imported.

Requirements: Python 3, SymPy 1.14.0, and the read-only source JSON records at the exact paths shown in `audit_exceptions.py`.

Run from this directory:

```
python audit_exact.py > EXACT_RUN.log 2>&1
python audit_characteristic.py > CHARACTERISTIC_RUN.log 2>&1
python audit_exceptions.py > EXCEPTION_RUN.log 2>&1
```

The first two programs are exact symbolic computations. The last uses only the Python standard library. `audit_exact.py` explicitly uses the empty-product convention `Disc(1)=1`.

The source comparison and preservation results were produced by direct JSON-array equality and SHA-256 hashing, not by invoking source scripts. Output timing fields/log times are not deterministic. Mathematical arrays and checks are deterministic. Re-running overwrites these local output files and invalidates the old manifest for any changed log bytes; regenerate the audit manifest after a deliberate rerun.
