# Window-rank Fourier research checkpoint — 9 October 2026

This package continues the user's exact, fresh-input FFT research. The new contribution is an **interval-window rank certificate** for two invertible quasiseparable stages, an elementary all-length permutation-independent obstruction within its stated endpoint model, and a **corrected general gate** valid when *both* FFT endpoints are arbitrarily reordered.

**No faster FFT has been constructed.** This is a lower-bound/architecture audit, not an algorithmic speedup or a universal FFT lower bound.

## Files

- `PROOF_CERTIFICATE.md`: full proof, including the endpoint limitation and counting argument
- `RESEARCH.md`: numerical outcomes, counterexample, implications
- `window_gate.py`: prefix/suffix and new three-sided window necessary-condition screen
- `finite_field_audit.py`: exact finite-field rank checks, arbitrary endpoint correction, Cooley–Tukey positive control
- `ct_reference_control.py`: the previously validated exact Cooley–Tukey reference construction
- `test_window_gate.py`: eight regression tests
- `run_all.py`: reproduce all results and regenerate JSON
- `SCREEN_RESULTS.json`, `FIELD_AUDIT_RESULTS.json`: captured data
- `SESSION_HANDOFF.md`: continuation instructions
- `prior_checkpoint_full.zip`: complete previous checkpoint, including older archives

## Run

```bash
python run_all.py
```

Requirements: Python 3.10+, NumPy.

**Scope:** the simplified full-Vandermonde theorem allows arbitrary *output* permutation, and natural or affine coprime-stride *input* order. With arbitrary input permutation use the exact submatrix-rank version; the simplified theorem is false there, as the exact classical Cooley–Tukey positive control demonstrates.
