# Phase20 independent audit bundle

- `PHASE20_AUDIT.md`: conclusions, complete proof reconstructions, scope limits and bounded improvements.
- `independent_checks.py`: freshly authored verifier. Uploaded source files are never executed or imported.
- `results.json`: exact finite-field certificates, source-data comparisons and separately labeled complex128 controls.
- `SHA256SUMS.txt`: hashes for this bundle.

Requirements: Python 3.10+ and NumPy. The exact finite-field routines use only Python's standard library; NumPy supplies the labeled numerical controls.

Run the self-contained checks without any uploaded archive:

    OPENBLAS_NUM_THREADS=1 python independent_checks.py --output results.json

To also reproduce the six small source-parametrized Green candidates and compare their source JSON reports, pass the extracted source directory as data:

    OPENBLAS_NUM_THREADS=1 python independent_checks.py --source /path/to/fft_green_phase20_weyl_shared_state --output results.json

All assertions fail closed. The normalization-free exact controls are enough for Weyl/monomial claims; the source comparison additionally matches its chosen finite-field square root. Finite-field tests and floating-point experiments do not prove a characteristic-zero identity, a universal family exclusion, novelty, or an asymptotic Fourier speedup.
