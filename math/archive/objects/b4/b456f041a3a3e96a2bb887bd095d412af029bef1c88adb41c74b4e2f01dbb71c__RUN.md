# Reproduction guide — Phase18

Run in Python 3.11+ from this folder. NumPy is not required. `mpmath` is needed only for the complex precision diagnostic. The prime-field algorithm does not access the network.

```sh
python -m unittest -v test_phase18
python exact_basis_audit.py
python union_audit.py
python union_benchmark.py
python generic_gate.py
python operation_benchmark.py
python precision_gate.py
```

To run all of these and independently rerun the preserved Phase17 tests, use `python run_all.py --prior` (or `python run_all.py` for Phase18-only). Run `sha256sum -c MANIFEST.sha256` after clean archive extraction. Test results are recorded in `TEST_RUN.log`, `BASIS_AUDIT.json`, `BENCHMARK.json` and `PRECISION_GATE.json`.

Prime fields: `p=2013265921`, primitive generator `31`; `p=998244353`, generator `3`. Fourier lengths used divide `p-1`, and Bluestein requires its doubled root and short power-of-two convolution roots. Code checks root primitivity, shift-graph denominators and Green closure. The exact finite-field tests are not automatically bit-model or complex-rounding guarantees.
