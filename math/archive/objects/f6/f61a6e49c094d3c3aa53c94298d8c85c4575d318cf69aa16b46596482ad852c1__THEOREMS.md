**Date:** 10 October 2026  
**Status:** Complete internal mathematical derivations, reproducible modular and complex tests, and an explicit infinite-family counterexample to the *sufficiency* of the Phase 13 graph-cut conditions. **No uniform exact O(N) or O(N log log N) FFT algorithm. Independent novelty review not complete.**

## 1. Exact question and model

We keep the original target: compute all `N` Fourier coefficients for a **fresh arbitrary** input with sequential arithmetic work `O(N)` or `O(N log log N)` and all memory, coefficient, and preprocessing costs charged.

Let `N=s^2`, `s>=2`, and write coordinates as `i=(x,y)` with linear index `sx+y`. Let

`U_N[(x,y),(x',y')] = s^-1 exp(-2*pi*i*(sx+y)*(sx'+y')/s^2)`.

An *X-fiber operator* preserves the second coordinate (`y`):

`X[(u,v),(x',y')] = [v=y'] X_y'[u,x']`.

A *Y-fiber operator* preserves the first coordinate (`x`):

`Y[(x,y),(u,v)] = [x=u] Y_x[y,v]`.

Each may contain arbitrary `s x s` blocks, not necessarily invertible, bounded, sparse, or even computable efficiently. In particular, any sum/product of invertible weighted-permutation Green resolvents that **all preserve the same coordinate** is an operator of this type. Products of consecutive same-axis stages remain in the same class.

This paper's principal no-go applies to `T=YX`, or sums of parallel paths `T=sum_{a=1}^r Y_a X_a`. It does **not** apply to a single layer that mixes both axis orientations, or to products with multiple axis switches.

## 2. The transverse-rank identity (exact, all sizes)

For each fixed *output* first-coordinate `x` and fixed *input* second-coordinate `y'`, form an `s x s` **transverse block** by varying output `y` (rows) and input `x'` (columns).

**Theorem A.** Every polarized two-stage operator obeys

`T[(x,y),(x',y')] = Y_x[y,y'] X_y'[x,x']`.

For fixed `x,y'`, the right side is the outer product of the vector `(Y_x[y,y'])_y` and the vector `(X_y'[x,x'])_x'`. Thus this transverse block has rank <=1, for arbitrary complex coefficients and without any invertibility assumption. For a sum of `r` parallel paths, each such block has rank <=r.

**Proof.** In `(YX)[(x,y),(x',y')] = sum_{u,v} Y[(x,y),(u,v)] X[(u,v),(x',y')]`, the support restrictions force `u=x` and `v=y'`; precisely one intermediate coordinate remains. QED.

## 3. Every Fourier transverse block is flat and full rank

Write `omega_n=exp(-2*pi*i/n)`. Expanding `(sx+y)(sx'+y')` yields

`omega_N^((sx+y)(sx'+y')) = omega_s^(x*y' + y*x') omega_N^(y*y')`.

For fixed `x,y'`, the corresponding transverse block of the **unitary** DFT is

`B_(x,y') = (omega_s^(x*y')/s) diag_y(omega_N^(y*y')) W_s`,  
`W_s[y,x'] = omega_s^(y*x')`.

Since `W_s W_s^* = s I_s`, **all s singular values of B are exactly 1/sqrt(s)**. In particular, `rank(B)=s`. Therefore:

**Theorem B.** `U_N` does not equal `Y X` for any polarized two-stage operators and any `s>=2`, even if the fiber operators are dense, have unrestricted coefficients, and are expensive to apply.

This is a specific architecture lower bound, *not* a general exact-FFT lower bound.

## 4. Uniform and distributional approximation barriers

The `s^2` transverse blocks (one per pair `(x,y')`) are disjoint and partition all entries of the matrix. The best rank-r approximation to a block with s identical singular values `1/sqrt(s)` has squared Frobenius residual at least `(s-r)/s` when `r<s`, by Eckart--Young.

Summing the independent block contributions gives

`||U_N - T||_F^2 >= s^2 (s-r)/s = N(1-r/s)`.

And `||A||_F^2 <= N ||A||_2^2` yields:

**Theorem C (all inputs, operator norm).** For any sum `T=sum_{a=1}^r Y_a X_a`, `r<s`,

`||U_N-T||_2 >= sqrt(1-r/s)` and `||U_N-T||_F/||U_N||_F >= sqrt(1-r/s)`.

Therefore:

- Exact equality in this grammar requires at least `r>=s=sqrt(N)` paths.
- Uniform operator error `<=epsilon<1` requires `r>=s(1-epsilon^2)`.
- Fixed `r`, or even `r=o(s)`, has an operator error lower bound tending to 1 as N grows.
- For an input-independent T and isotropic complex Gaussian `x` with `E[xx*]=I_N`, `E|| (U_N-T)x ||_2^2 >= N(1-r/s)`. Thus it also fails mean-squared global-energy approximation on that distribution.

**Caution:** The Gaussian statement does not cover nonlinear, data-adaptive decoders or weak per-bin / energy-relative `l_infinity` guarantees. Nor does the number of paths alone prove a runtime lower bound when sharing between paths is permitted.

### Exact algebraic sharpness for the enlarged fiber-linear grammar

The minimum path count s is **attainable algebraically** if each fiber factor may be an arbitrary linear operator, including singular factors. Define for `a=0,...,s-1`:

`X_a[(x,z),(x',y')] = [z=y'][x'=a] omega_s^(x*y')`,

`Y_a[(x,y),(u,z)] = [x=u] (1/s) omega_s^(y*a) omega_N^(y*z)`.

Then `sum_a Y_a X_a = U_N` entrywise by substitution. This demonstrates that `r>=s` is **sharp as a representation-rank statement** in the enlarged grammar. These factors are not asserted to be sums of O(1) Green resolvents or to admit linear-work application. Explicit modular entry checks passed at s=2,4,8.

## 5. A uniform Cartesian expander that passes *all* old cut gates

This is the principal constructive counterexample to treating expansion as sufficient.

Let `s=t^2`, `N=s^2=t^4`, `t>=2`. On each size-s fiber, take the four classical Margulis--Gabber--Galil affine permutations

`(u,v)->(u+2v,v)`, `(u+2v+1,v)`, `(u,v+2u)`, `(u,v+2u+1)`, all mod `t`.

Repeat the four maps five times with independently selected nonzero Green weights (or simply constant complex weight 1/4 to avoid all singular cycles). This supplies **20 resolvents per fiber-axis layer**. In the first layer, lift them as `(x,y)->(pi(x),y)` so it preserves `y`. In the second, lift them as `(x,y)->(x,pi(y))` so it preserves `x`. There are 40 total resolvents, a constant independent of N.

Each weighted permutation Green inverse `(I-P)^-1` is executable in O(N) arithmetic operations by solving each cycle, including one inversion per cycle and O(N) scalar work. The graph topology and weights are generated in O(N). Hence the resulting candidate `T=YX` is a **uniform O(N)-applicable matrix family**, but it is not the Fourier family.

### All-subset graph expansion proof

Let `A_s` be the undirected eight-regular Margulis adjacency on one fiber, counting multiple/loop edges as appropriate. Its classical eigenvalue estimate is `|lambda(nontrivial A_s)|<=5sqrt(2)`. For five copies of its four directed maps, the symmetric cut Laplacian of one fiber is

`L_s = 5 (4I_s-A_s/2)`, with `lambda_2(L_s)>=5(4-5sqrt(2)/2)>2.32233`.

The 40 lifted permutations on the whole s-by-s coordinate grid give the **Cartesian-product** cut Laplacian

`L_N=L_s tensor I_s + I_s tensor L_s`.

Its spectral gap is at least the same constant, because its eigenvalues are pairwise sums of fiber eigenvalues. For any coordinate subset R with `m=|R|`, the exact directed edge cut budget `b(R)` satisfies

`b(R) = 1_R^T L_N 1_R >= 2.32233*m*(N-m)/N > min(m,N-m)`.

Thus **every** Phase 13 same-subset rank-capacity condition, including its strongest prefix version, passes on **every N=t^4**. The same is true of the reverse-direction budget. This is a proof over the entire infinite size family, not a finite random-graph observation.

Nevertheless, by Theorems A--C the network always has transverse-block rank<=1 while the Fourier blocks have rank `s`; furthermore,

`||U_(t^4)-T||_2 >= sqrt(1-1/t^2)`.

This lower bound tends to 1, independent of **all** weights. Hence passing even strong, uniform graph expansion does not ensure approximate Fourier compatibility.

**What this does not exclude:** The Phase 13 **mixed-axis within each layer** Margulis candidate is a different architecture. It contains both types of fiber operator within each stage and is *not* of the polarized form above.

## 6. A separate generic-matrix obstruction for *mixed-axis* two-layer networks

The original Phase 13 mixed-axis topology also has a clear algebraic capacity restriction, although it **does not exclude the special Fourier matrix**.

Let `R_s` denote the vector space of matrices whose entries vanish unless the output and input grid coordinates share `x` or share `y` (a *rook-support* matrix). Each of N rows has `2s-1` supported entries, so

`dim_C R_s = d=N(2s-1)=2s^3-s^2`.

Every arbitrary sum of Margulis-type Green resolvents in one stage belongs to `R_s`. A two-stage candidate `T=Y X` with `X,Y in R_s` is an image of a polynomial map on at most `2d` parameters. For invertible `T`, both factors are invertible. For every invertible diagonal `D`, the pairs `(DX, YD^-1)` give the same product and remain in the rook-support class. The action is free, yielding at least N dimensions per fiber. Hence the algebraic closure of invertible rook products has dimension <=`2d-N` and codimension at least

`N^2-(2d-N) = s^2(s-1)(s-3)`.

For `s>=4` this is positive. It proves that **Zariski-generic N-by-N matrices cannot be represented** by two rook-supported stages. It does *not* prove that `F_(s^2)` is outside this exceptional variety. The Fourier matrix is highly structured; genericity is not a valid replacement for its exact compatibility equations.

Over `GF(q)`, a uniform random N-by-N matrix has probability at most `q^(2d-N^2)/(q-1)^N` of being an *invertible* two-rook product (using the free nonzero-diagonal gauge). This is a counting statement about randomly chosen target matrices, not about randomly chosen inputs to a fixed Fourier transform.

## 7. Exact O(N)-work Fourier-candidate verification via Weyl intertwining

Let `S e_j=e_(j+1 mod N)` and `D=diag(1,omega,...,omega^(N-1))`, with `omega=exp(-2pi*i/N)`. The unnormalized Fourier matrix obeys `F_N S=D F_N` and `F_N e_0=1`.

**Theorem D (necessary and sufficient certificate).** Any linear operator T satisfies

`T=F_N  iff  (T S=D T and T e_0=ones)`.

**Proof:** The forward implication is elementary. Conversely, for `j>=0`, `T e_j=T S^j e_0=D^j T e_0=D^j ones`, which is exactly Fourier column j.

If T applies in O(N) field operations, over a finite field with a primitive Nth root of unity we can check the seed column deterministically in O(N), then for h independent uniform test vectors `v` check `T(Sv)=D(Tv)` in O(hN). If T is not the Fourier matrix but has the correct seed, the fixed nonzero defect `TS-DT` annihilates one random uniform vector with probability at most `1/q`, so h independent tests have false-accept probability at most `q^-h`.

This is a standard polynomial-identity / Freivalds-type randomized verification principle, specialized to the Fourier Weyl relation. It is **not a proof of a Fourier circuit** and does not establish exact equality from finitely many random checks. It is valuable as a cheap rejection gate during weight search. The saved `weyl_gate.py` includes positive Fourier controls, a deliberately falsified operator that passes the seed check, and the expander candidate.
