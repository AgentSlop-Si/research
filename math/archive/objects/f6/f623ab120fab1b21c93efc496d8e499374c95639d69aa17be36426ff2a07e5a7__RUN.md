# Reproducibility — Hero #1 Phase20

After extracting the Phase20 ZIP, enter `fft_hero1_phase20/`. All imports are local, with no internet or third-party Python dependency needed.

```bash
python3 -m unittest discover -p 'test_*.py' -v
python3 exact_basis_audit.py
python3 exhaustive_small_gate.py
python3 benchmark_phase20.py
sha256sum -c MANIFEST.sha256
```

The three audit/benchmark scripts write their respective JSON receipts. A clean extraction should reproduce them up to harmless serialization/order differences. `MANIFEST.sha256` authenticates included sources and logs (but not itself). To audit the prior immutable archive:

```bash
unzip -t PRIOR_PHASE19_COMPLETE.zip
```

The archives are self-contained. For independent verification of exact algebra, do not replace the direct DFT oracle by the adaptive Green engine or its Bluestein implementation. Tests also compare adaptive outputs against independently calculated direct finite-field Fourier sums.
