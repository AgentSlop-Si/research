# fft_all_length_lift_v10

Reproducible research bundle extending the v9 unit-step chirp approximation from dyadic/prime-power-friendly lengths to **every integer length**.

## Run

```bash
python -m pip install -r requirements.txt
python prototype.py --output results.json
python test_checkpoint.py
```

## Main files

- `RESEARCH.md` — theorem derivation, complexity, boundaries, and prior-art audit.
- `CHAIN_CHECKPOINT_2026-10-10_v10.md` — compact recovery checkpoint.
- `prototype.py` — all-length Bessel/Chebyshev lift and robust estimator.
- `unit_step_core.py` — retained v9 dyadic chirp engine.
- `test_checkpoint.py` — 12 automated checks.
- `results.json` — saved experiment results.
- `requirements.txt` — Python dependencies.
- `MANIFEST.sha256` — file hashes.

This is a theorem-candidate research artifact, not a production FFT library.
