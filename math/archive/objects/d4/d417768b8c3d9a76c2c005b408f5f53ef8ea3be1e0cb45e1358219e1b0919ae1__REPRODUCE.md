# Replay

Use Python 3, standard library only, in this directory:

```
python check_independent.py
python compare_data.py
python verify_seal.py
```

The first command regenerates INDEPENDENT_RESULTS.json deterministically. The second reads the supplied source JSON as data and compares exact field coordinates. No constructor or uploaded program is executed. For isolated algebra replay, copy only check_independent.py into a fresh directory and run it there; compare the result JSON byte for byte.
