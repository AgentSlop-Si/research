# Phase 31 — rectangular Fourier-phase certificates for Green networks

**Quick result:** Five independently ordered Hamiltonian Green resolvents with four free complex couplings, as constructed in the preserved Phase29–30 seeded family, cannot be converted into its required Fourier middle matrix by any two diagonal masks and permutations at N=4 or N=8. A single 3×4 projective window and only seven quadratic conditions suffice; all N=8 mappings were exhaustively audited with a square 35×35 modular rank certificate. N=16 has 100,000 sampled mappings, NOT full coverage.

`THEOREM.md` contains the exact model, proof and limits. `CHECKPOINT.md` explains where to resume.

- `phase31_rectangular.py`: deterministic five-Green generator and rectangular Macaulay quadrics; input serialization.
- `rectangular_seven.cpp`: exhaustive/window-indexed native exact verifier (seven minors, 35×35 degree-3 certificate).
- `rectangular_audit.cpp`: independent alternative verifier using eight adjacent minors; also passed the complete N8 audit.
- `phase31_executor.py`: genuine O(N) per-vector cyclic Green-sum executor (NOT an FFT).
- `phase31_six_control.py` and `phase31_seven_control.py`: exploratory larger-component controls, with explicit sample scopes.
- `independent_audit.py`: direct Python determinant witnesses.
- `tests_phase31.py`: reproducible eleven-test suite; prior dependency modules are vendored locally.
- `certificates/`: exact finite-field inputs, exhaustive and sampled rank records, positive control and independent witnesses.
- `previous_full_phase30_checkpoint.zip`: complete historical research chain.

Run commands are in `RUN.md`. No claim of `o(N log N)` for arbitrary FFT inputs or faster integer multiplication is made.
