# FFT Green research — Phase 37

This phase resumes from Phase 36 (included in `previous_full_phase36_checkpoint.zip`). It investigates noncommuting **complex** Green products with two internal phase masks, with an exact projective-curvature gate.

**Proved:** (1) an all-`N` curvature-rank obstruction for a single cyclic Green with primitive root holonomy; (2) exact no-complex-parameter certificates for a specified six-Green two-mask pencil at `N=4,8,16,32,64,128`. These are restricted mathematical claims and **not** a new fast Fourier transform.

Start with `THEOREM.md` for precise assumptions and proofs. `CHECKPOINT.md` lists the next gate. The independent certificate files contain actual finite-field polynomial and Bézout coefficients rather than summary claims.

The `N=8` direct SymPy characteristic-zero expansion is **not** part of the validation (it is prohibitively slow); characteristic-zero exclusion at larger sizes follows instead from the **degree-preserving modular resultant argument** in `THEOREM.md`.

**Main novelty relative to the project's earlier phases:** an anchored exponent-curvature *module* invariant that separates primitive-holonomy single Green kernels from Fourier under arbitrary external gauges, and a two-small-plaquette `2N`-degree exact obstruction for a true two-mask complex Green-product circuit. Prior art on cross-ratio invariants is acknowledged.
