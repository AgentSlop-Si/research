# HERO #17 Phase 10 — Spectral Projector Union

This self-contained Python package implements exact Fourier spectral filtering of arbitrary fresh dense inputs in a finite prime field when the frequency mask is a periodic residue pattern with a few exceptional bins. It additionally implements a shared batch graph for related filters.

**It is not an O(N) algorithm computing the complete DFT of an arbitrary dense input.**

## Contents

- `phase10.py`: charged `SpectralUnion`, `BatchSpectralUnion`, generic FFT–mask–inverse-FFT comparison, ledger.
- `test_phase10.py`: exact finite-field regression tests, direct independent DFTs, projector rank and commutativity, previously noncommuting reflection contrast.
- `independent_audit.py`: unrelated iterative NTT oracle, 65,536-output verification, large selected direct bin checks, and operation-count comparisons.
- `PROOF_CERTIFICATE.md`: complete algebraic proof and exact model assumptions.
- `RESEARCH.md`: full findings, limitations, negative signature gate, prior-art discussion.
- `CHAIN_CHECKPOINT.md`: recovery instructions and Phase 11 challenge.
- `AUDIT_RESULTS.json`: machine-readable evidence (regenerated by audit).
- `TEST_LOG.txt`, `PHASE9_PREDECESSOR_TEST_LOG.txt`, `AUDIT_LOG.txt`: command outputs.
- `SHA256SUMS.txt`: SHA-256 file manifest.

## Run

```bash
python -m unittest discover -v
python independent_audit.py
```

No external Python libraries needed. Python >=3.10 is sufficient. A suitable prime p and primitive Nth root are supplied to the algorithm; selection of prime field is test fixture setup, not a free general FFT operation.

## Quick example

```python
from phase10 import SpectralUnion
# A length-16 exact finite-field Fourier-domain parity filter, with one
# frequency swapped. p=17 has primitive root w=3 of order 16.
x=list(range(16))
filter_plan=SpectralUnion(16, 17, 3, 2, {0}, add=(1,), remove=(0,))
y=filter_plan.apply(x)
print(y)                    # all 16 filtered time samples
print(filter_plan.cost())   # plan and online work charged
```

Always distinguish **full-length filtered time-domain signal** from **full Fourier spectrum**.
