# HERO #0 — Phase 10: learned rational cycles + universal Schmidt gate

**Target:** exact O(N) / O(N log log N) FFT on fresh arbitrary inputs. **Not solved**.

This phase gives:

1. A charged, exact, `O(d N + d^2 N/log N)` algorithm for a certified family whose frequency-wise time sequences have unknown order <=d. In particular fixed d gives exact O(N) *only on this structured family*. Recurrence coefficients can be fully dense and frequency dependent; one-step innovation is generically dense in both time and frequency.
2. An all-input, but highly restricted, *operator factorization theorem*: the unitary Fourier operator at a balanced input/output bit cut has maximal (N) operator Schmidt rank and a flat Schmidt spectrum. It cannot be replaced by a small one-shot sum of bipartition-separable operators, even approximately in relative Frobenius norm.
3. A testable next objective: cheap, high-Schmidt-rank noncommuting full-vector Green/graph factors, charged end-to-end. We have **no** such universal sub-N-log-N factorization.

**Model caveats:** This implementation uses GF(2013265921) supporting only finite power-of-two sizes; the asymptotic theorem is conditional on compatible exact field arithmetic or exact complex arithmetic. Membership checks are randomized (false acceptance <=p^-rounds for a fixed bad input independent of the random draws). No finite-precision stability claim. The new method is currently **slower**, not faster, than the ordinary NTT in finite arithmetic counts.
