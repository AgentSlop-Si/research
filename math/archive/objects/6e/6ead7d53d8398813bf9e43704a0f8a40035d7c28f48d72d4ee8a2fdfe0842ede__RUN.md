# Reproducing Phase 15 from a clean extraction

Requires Python 3.11+; `numpy` only for the optional numerical unitary Gram check. The exact algebra, forward and inverse, and unit tests otherwise need only the Python standard library.

```bash
cd fft_green_phase15_folding
PYTHONPATH=. python -m unittest discover -s tests -v
python phase15_executor.py
python haar_coherence.py
OPENBLAS_NUM_THREADS=1 python unitarity_probe.py
python complexity_budget.py
python sparse_green_gate.py
```

**Important:** the finite-field numerical engine uses a primitive Nth root in `F_998244353` with positive exponent. Its exact identities remain valid over complex numbers using a specified primitive Nth root, but modular correctness is not a proof of numerical stability. `unitarity_probe.py` separately checks complex Gram matrices. The `phase15_executor.py` file checks the expensive independent sparse residual oracle through N1024; larger N uses an independent radix-2 transform for comparison.

The previous full Phase 14 checkpoint is stored at the top of the ZIP as `previous_full_phase14_checkpoint.zip`. It carries earlier research and previous archives. The user-provided original nonunitary research zip and original discussion text are also included explicitly.

Validation target:
- `45` total tests (10 Phase15 + 15 Phase14 + 12 Phase13 + 8 Phase12) from their original directories.
- End-to-end independent DFT and inverse-residual tests up to N16384 in an additional smoke test.
- Complex scaled-unitary Gram checks at N16–256.
- Exact network work `N log2(N)/2` butterflies—not an improvement to that count.
