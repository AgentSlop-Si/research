# HERO #0 — Phase 4 package (10 October 2026)

**Verified research extension — not an exact faster FFT.**

This package follows the Phase 3 all-length Gaussian + projected Green approximate transform. It adds:

1. `coprime_pad.py`: a constructive prime-block and rough-cofactor short-slack `Q=MK` selector, making every `1≤d<M` coprime to `Q`.
2. `PROOF_AUDIT.md`: an independent sharpened `O(M/phi(Q))` *noise-variance bound*, an elementary `N^{o(1)}` padding-search proof, and a carefully limited all-N `O(N loglog N)` ideal-model approximate-transform theorem candidate.
3. `verify_phase4.py`: exact finite covariance-matrix and exhaustive state-average audits plus fresh-prime-length output checks.
4. `verify_exactness_barrier.py`: exact completeness identity and nonzero zero-measurement counterexamples for fewer than M fixed Green rows.
5. `exact_batch.py`: `O(Q log M)` batched input summaries for an exact M-row complete Green frame. Full exact execution still costs `O(Q log Q)`.
6. Frozen Phase 3 source `gaussian_lift.py` and `composite_cycle_core.py`, the Phase 3 local cancellation proof, and generated JSON verification logs.

## Run

From this folder with Python 3 and NumPy installed:

```sh
OPENBLAS_NUM_THREADS=1 python verify_phase4.py
OPENBLAS_NUM_THREADS=1 python verify_exactness_barrier.py
OPENBLAS_NUM_THREADS=1 python exact_batch.py
```

## Results

- For the selected same `(Q,M)`, the analytical random-error variance upper bound is a **factor M smaller** than the Phase 3 local-cancellation bound; this is **not** a speed ratio.
- For fixed `α∈(0,1/2)` the candidate approximate guarantee remains `O_α(N loglog N)` for every N; for α=1/3, **7 rows** suffice for an all-bin failure upper bound of `N^{-1/3+o(1)}` under the stated model, while **9 rows** give `N^{-2/3+o(1)}`.
- Exact frame identity with M rows is proved and numerically checked, but the separate scans leave **O(QM)=O(N log N)** work for exact arbitrary-input FFT.
- All claims use an idealized complex-arithmetic/numerical-coefficient model, not fixed precision or bit complexity. Independent mathematical peer review and literature novelty audit remain outstanding.
