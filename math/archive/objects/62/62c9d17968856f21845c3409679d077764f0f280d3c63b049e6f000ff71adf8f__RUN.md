# Phase 32 reproduction

Python 3.10+ only, no third-party dependencies.

From this directory:

```sh
python3 -m unittest -v tests_phase32
python3 phase32_interpolation.py --k 5 --sizes 8 16 32 64 128 256 --output audit.json
python3 phase32_interpolation.py --k 5 --sizes 512 1024 2048 4096 --output audit_large.json
python3 phase32_interpolation.py --k 4 --extra 1 --sizes 8 16 32 64 --output audit_extra.json
python3 phase32_interpolation.py --k 7 --sizes 8 16 32 --output audit_seven.json
```

`audit.json` reports five exactly matched columns, an all-coordinate sixth-column mismatch, nonzero Weyl defects on fresh random inputs, and deterministic SHA256 fingerprints for the coupled Hamiltonian cycles and gauges.

The `q=N` positive control is in the tests at N=8 and N=16. It correctly gives the **full DFT** but costs O(N²) to apply and O(N⁴) with the naive preprocessing routine. Each `q=5` online application uses five cyclic recurrences and five diagonal passes, O(5N) field arithmetic; the preprocessing builds response powers and solves N small 5×5 systems.

The predecessor suite can be rerun from the nested `previous_full_phase31_checkpoint.zip`, as documented in its own `RUN.md`. Current tests do not rerun the predecessor's enormous exhaustive native sweep; historical exact records remain preserved.
