# Hero #17 — Phase 14: Magnetic Green / Weyl Union

Reproducible exact-prime-field mathematical research. **Not a general linear-time FFT.**

## Main results

- Noncommuting root-of-unity Green operator + exact O(N) input evaluator.
- Signed orientation span classification and an exact missing Fourier coefficient when N divisible by 4.
- A mixed-depth nearest-neighbor branching cut-rank obstruction.
- O(N) shared evaluation of N Weyl-conjugate Green branches.
- An O(N) long-range Green stage with maximum cut rank, showing how to escape that obstruction.

## Reproduce

Use Python 3.10+ and its standard library; no packages need installation.

```bash
python -m unittest -v test_phase14
python independent_audit.py
```

Examine `AUDIT_RESULTS.json`, `TEST_LOG.txt`, and `AUDIT_LOG.txt` after running. The independent audit intentionally uses a separate Gauss-Jordan inverse, direct Fourier rows, and a Green kernel-product formula; it does not call FFT routines.
