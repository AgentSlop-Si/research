6. Common eigenvectors, matrix commutators, rank-one Segre varieties, and Hadamard-quotient diagonal scaling are established mathematical topics. New naming is not itself novelty.

## New application developed in this round

For a fixed four-Green two-stage network, an **arbitrary right input gauge is added** to the unknown middle and left gauges. The new problem is not linear in the prior phase-pencil variable. The Hadamard quotient converts it to a rank-one matrix in an N-dimensional linear space, and the first-three-column common-eigenvector matrices yield an exact determinant rejection for *all three gauges*. A second derived bound gives positive operator-norm distance for all gauges at these fixed stages. Eight independently reconstructed integer-parameter Green witnesses and the other exact controls verify the new application.

## Caveats requiring external review

- Fixed A,B,C only: a nonzero commutator at one parameter point does not rule out exceptional weights or different permutations.
- Entrywise B nonzero and base P0 invertible are hypotheses; candidate architectures exploiting zero-pattern exceptions need separate handling.
- A finite-field reduction is a rigorous **nonzero witness** for the explicitly saved rational/cyclotomic data, not a proof of nonexistence over C for all parameter choices.
- The numerical lower-bound decimals are not interval-certified; the positivity itself is proved algebraically.
- There is still no exact O(N) FFT for arbitrary fresh inputs in these files.
