# Reproduction

Run only these freshly written files, with installed Python and SymPy 1.14.0:

    python content_probe.py 17 21 25
    python structural_controls.py
    python reduced_obstruction_controls.py

The first writes exact coefficient arrays for the three allowed new bases. The second uses direct ordinary discriminants and direct resultants and checks every array, plus formal local leading terms. The third checks the two Gaussian unit removals and computes the reduced obstruction by an explicit multiplication-matrix determinant.

The optional `symbolic_mod2_probe.py` records a rejected exploratory simplification. It does not prove the general prime-support assertion. Do not run `reduced_obstruction_controls.failed.py`; it retains the observed swapped-degree resultant-sign failure documented in `RESULTANT_SIGN_CONTROL.md`.

No source or predecessor implementation needs to be imported or executed. No package installation, floating-point root finder, target-order scan, or downloaded code is used.

The uniform conditional valuation theorem is a symbolic proof in `RESEARCH_REPORT.md`. The computational controls guard its normalizations and supporting identities but do not establish the theorem by induction from samples.
