# Portable independent replay

Requires Python 3.11+ and its standard library. Run `python independent_checks.py`. It reads only the four preserved `EXACT_NETWORK_CERTIFICATE_*.json` files as inert data and regenerates `INDEPENDENT_RESULTS.json`. No uploaded Python module is executed or imported. Outputs are located relative to the checker, so its working directory may differ.

The report, source provenance, checker, saved results, inert source, and hashes form the self-contained review package. `PORTABILITY.json` records an actual relocated replay. The source's optional optimizer programs are not part of this replay.
