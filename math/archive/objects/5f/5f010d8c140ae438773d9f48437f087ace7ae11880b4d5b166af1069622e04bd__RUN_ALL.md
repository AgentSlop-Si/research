# Reproduction

Run `python run_all.py` inside this extracted directory. The script executes the new eight tests, including an independent SymPy resultant check, then runs the complete earlier 64-test checkpoint (which is extracted automatically from `prior_checkpoint_full.zip`), and reports both counts. It also checks that both exact coefficient exports exist. All calculations use exact modular arithmetic or exact cyclotomic integer polynomial arithmetic; no floating-point fit is accepted as proof.

If the prior checkpoint is not found, `_bootstrap.py` automatically extracts it into `_previous_extracted/`. All earlier generations are nested in the prior ZIP.
