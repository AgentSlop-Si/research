# Portable independent replay

Requires Python 3.10+ and its standard library. Copy only `independent_checks.py` to any directory and run:

    python independent_checks.py phase10_results.json

Compare output bytes with `INDEPENDENT_RESULTS.json`. The checker does not read, import or execute any uploaded file. Large published field counts are independently reconstructed analytically, not by executing the source's large NTT audit.
