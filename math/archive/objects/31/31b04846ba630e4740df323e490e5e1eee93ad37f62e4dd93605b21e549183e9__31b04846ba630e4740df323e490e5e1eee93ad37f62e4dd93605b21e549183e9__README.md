# Boolean-domain Fourier bridge: independent reproduction

Read `BOOLEAN_DOMAIN_BRIDGE.md` for the theorem, proof, scope, and exact findings.

## Reproduce

Python 3.9 or newer; standard library only. In this directory run:

    python independent_boolean_audit.py

The checker writes `independent_boolean_results.json` beside itself. No original uploaded script or package is needed, imported, or executed. The supplied JSON witness data are included unchanged, with their SHA-256 in `source_provenance.json`.

The run independently checks:

- Degree-three Fourier non-completion determinants at N=8,16,32.
- The 8-point cubic identity on all 256 Boolean inputs in a characteristic-zero cyclotomic ring.
- All even-spectrum ambiguity witnesses at N=8 and N=16, including distinctness of the odd spectra.
- The sharp 3/4 quadratic reconstruction example over exact rational numbers.
- Degree-three exact recovery of two packed bits.
- 49 rational midpoint controls.

The all-length claims rely on the report’s proofs. These finite checks are not runtime benchmarks or an FFT speedup. The information-orbit theorem is source-reviewed; its separate interpolation calculations are outside this checker.
