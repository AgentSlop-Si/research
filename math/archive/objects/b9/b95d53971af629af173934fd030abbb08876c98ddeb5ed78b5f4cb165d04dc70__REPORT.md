## Main conclusions

1. **The endpoint restriction is correctly preserved.** The window inequalities substitute full Vandermonde rank only for natural or invertible-affine Fourier input ordering; arbitrary output-row order is allowed. The stored Cooley–Tukey controls explicitly show that arbitrary input-endpoint permutations can lower the actual submatrix rank. At N=8 and N=16, the actual ranks are 4 and 8 rather than 5 and 9; the corrected required rank is 2, while the naive substitution gives 3. The source and independent stored controls agree on the permutations, ranks and lower bounds. These are positive controls against a false extension of the theorem.

2. **The concrete Phase22 cost defect remains.** `phase22_parity.py` recomputes individual root powers at every angle each time `apply_R` is called. The advertised O(N) support work is O(N log N) in ordinary field multiplication arithmetic as written. The assigned `linear_rotation_reference.py` remedies the coefficient generation by consecutive-power recurrence, yielding O(N) preparation and application after field/root setup. This corrects implementation charging; it does not evaluate the residual C cheaply. The historical Phase22 audit already documented the same issue.

3. **Two direct test entry points omit tests.** `test_phase22.py` calls `unittest.main()` before its four parity/covariance methods; direct execution normally runs 8 of 12. `test_phase23.py` calls it before 15 later methods; direct execution normally runs 9 of 24. Their documented commands and lineage runners use discovery, which imports the whole file. The stored Phase22 log explicitly contains all 12 names. Therefore this direct-mode defect does not invalidate the actual stored discovery route. Moving those main guards to the end is the bounded maintenance fix, not an action performed here.

4. **The root-free recurrence extension handles real exceptional cases.** The independently authored source recognizes and verifies an order-at-most-two recurrence, evaluates its rational generating-polynomial formula at all Fourier roots, batch-inverts regular denominators and uses Horner evaluation at at most two exceptional frequencies. The algebra covers repeated, zero and irreducible roots as well as split exponentials. Recognition, exceptional handling, materialization and storage are O(N) field work on that restricted path after setup. Arbitrary inputs still take the O(N log N) FFT fallback. Stored 36 recurrence/42 adaptive cases through N=8192 are retained as historical evidence.

5. **No inspected actual stored witness is newly invalidated.** Phase22's 24 negative records, including every zero-diagonal count, and 12 positive statuses match the independent stored report by exact JSON comparison. Phase23's stored `audit.json` and `audit_output.txt` agree as parsed JSON. The window endpoint witnesses agree across the two stored audits. Public helper guard gaps are distinguished from these valid fixed callers.

## Mathematical scope and costs

### Bilateral and polynomial gates

The boundary matrix has n−3 rows and six columns. Under its generated three-frequency lower-tail hypothesis and n≥9, it reduces to a four-column fixed Fourier span plus the two-dimensional boundary coefficient matrix. The rank-five condition is exactly the vanishing of U3 L4−U4 L3. At n=8 there are only five rows, so rank≤5 need not force that determinant to vanish; the source and independent receipt explicitly retain this exception.

The cyclotomic source enumerates all 55 maximal minors of the inherited 11×9 gate, not a sample: 45 vanish structurally and ten share the existing DB·DH equation. Its nonzero finite-field four-by-four quadratic coefficient minor can certify nonzero characteristic-zero rank and the stated quadratic irreducibility. This is conditional on the imported exact polynomial construction and arithmetic. It does not show DB=0 has no solutions, dispose of saturation/zero-generator branches or settle all F8 feasibility.

The separate lower gate scans a chart with h0, Delta and t nonzero over p=17. Its omission of exceptional branches is deliberate scope, not global exclusion. The four specialized minors in `minor_plane.py` are exploratory. Neither file is called by `run_new.py`; the aggregate receipt must not be misused as their execution receipt.

Both permutation screens are necessary filters. The original bilateral profile is O(N²) as implemented. `check_windows` is O(N²) after permutation validation, with potentially O(N²) stored violations. Exhaustive N8 enumeration has factorial cost; larger seeded screens are not proofs. The source's coarse rank-one ceiling 21 remains a correct necessary bound even though the historical independent window audit sharpens the same filter to 16. The supplied N16 permutation witnesses filter survival, not existence of stage coefficients or a fast Fourier factorization.

### Gram/parity routines

The identity uses the **bilinear transpose**, not the conjugate transpose. Squared-entry fingerprints are necessary invariants for diagonal/permutation congruence. Zero-diagonal count mismatch is a veto; equal positive zero counts remain inconclusive; repeated row signatures remain ambiguous. Full ratio and square-root recovery is conditional on nonzero support and intended invertibility. The source explicitly tests a Gram-congruent non-Fourier matrix and normalization failure.

Prepared weighted cyclic Green application is O(N), and a q-term sum is O(qN), with nonsingular cycle closure. Dense reconstruction is N oracle calls per matrix, costing O(qN²) scalar work for these oracles; subsequent inversions/products are cubic and need quadratic storage. The audit's “O(N²) oracle operations” phrase conflates scalar work and basis-query count.

A covariance seed plus finitely many fixed-seed tests is regression evidence for correctly sized fixed linear oracles. It does not prove linearity, protect against a test-aware adaptive oracle, or justify fresh-independent-random soundness without that contract. The source's zip comparisons and trial count are not complete API guards. Existing callers are explicit, correctly sized linear maps with two trials.

### Phase23 exact arithmetic

The original distinct-exponential detector can reject repeated-pole sequences and correctly fall back. The separate root-free recurrence implementation widens the fast path without changing the arbitrary-input worst case. Its generating-polynomial derivation is independent of quadratic root discovery; transform-root/normalization setup, batch inversion, input reading, all output writes and O(N) memory remain charged.

GF2 Hankel counts, integer nonzero-determinant lifting and working-prime ranks are distinct assertions. An odd integer determinant need not remain nonzero modulo a different odd prime. The source's separated checks and the independent auditor's explicit binary classification preserve this distinction. Finite exhaustive counts remain finite enumerations rather than automatic proofs for every length.

F_998244353 supports only dyadic N≤2²³. Uniform unbounded-N claims require a field family and charged field/root/normalization preparation. Finite-field exactness is not an exact-real implementation, a stability theorem, a bit-complexity proof or a measured FFT speedup.
