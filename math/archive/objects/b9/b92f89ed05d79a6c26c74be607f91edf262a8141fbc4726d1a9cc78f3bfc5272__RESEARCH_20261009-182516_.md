## Result A: all contiguous windows

For `B = F C[:,pi]`, choose intermediate columns `u..v` (`t=v-u+1`), let `a=min(pi[u:v+1])`, `b=max(...)`, and `h=b-a+1`. Write `beta=(u>0)r_B^upper + (v<N-1)r_B^lower`. With standard or affine-coprime-stride FFT input order and arbitrary FFT output order, the following **necessary** bounds hold:

```
min(t,a)     <= beta + (a>0)*r_C^upper
min(t,N-1-b) <= beta + (b<N-1)*r_C^lower
min(t,N-h)   <= beta + (a>0)*r_C^upper + (b<N-1)*r_C^lower
```

The proof is exact rank-nullity plus Fourier Vandermonde rank. It does not use numerical conditioning or generator normalizations. `PROOF_CERTIFICATE.md` includes every step.

## Result B: exact permutation filtering

All 40,320 permutations for N=8 were enumerated. The old prefix/suffix check with rank sum 2 allowed 28,584; the new window check allows 15,728. Exactly 12,856 cases were removed by the new filter that had passed the old one. Zero cases pass the new filter and fail the old one.

The identity permutation is an explicit newly detected obstruction at N=8: first three B columns correspond to C columns 0,1,2, and the tail inequality requires 3 ranks with budget 2.

To verify that the method does not overreach, here is an N=16 internal permutation passing *all* its window inequalities:

`[8,0,13,4,9,3,15,5,6,1,12,11,10,2,14,7]`

That pass is not a factorization. Further nonlinear conditions may exclude it.

## Result C: permutation-independent counting bound, restricted endpoints

For rank ceiling `r` in both orientations of both stages, every interior window of width `3r+1` must contain an index from the last `3r+1` positions. Pigeonhole counting bounds N by `9r²+9r+3`, regardless of the **internal** permutation. Thus two rank-one stages are impossible at N>=22 (including N=32), for Fourier input order natural/affine and Fourier output order arbitrary.

This is a restricted two-stage structural result, weaker than pre-existing stronger lower bounds in other restricted models. It is **not a lower bound for unrestricted FFT circuits**. Two-stage Cooley–Tukey with independently reordered input/output endpoints is not covered by this simplified inequality.

## Result D: arbitrary endpoint gate and exact counterexample

For arbitrary invertible M (including independently endpoint-permuted Fourier matrices), the universal valid form replaces `min(t,N-h)` with

` t-h + rank(M[R,H]) `

where R is the complement of the chosen B column window and H is the convex hull of the corresponding C column indices. It has the same off-diagonal rank budget. Analogous head/tail replacements are provided in the proof.

**Exact Cooley–Tukey positive controls:** A valid two-rank-one-stage factorization of the N=16 Fourier matrix over GF(12289) with reordered input/output endpoints has `pi=[0,8,4,12,2,10,6,14,1,9,5,13,3,11,7,15]`. For the first three B columns, the naive formula would require rank 3 with budget 2 and falsely reject it. The actual `13×9` endpoint-reordered Fourier submatrix has rank **8, not 9**, so the corrected necessary quantity is 2, exactly meeting the budget. A separate N=8 control has rank 4 instead of 5, with the same effect. All entries of both exact CT factorizations are verified.

This counterexample proves why a theorem for naturally ordered Fourier inputs **cannot** silently be extended to both independently permuted endpoints.

## Result E: input affine permutation still safe

If the input index order is `k -> c+d*k (mod N)` with gcd(d,N)=1, every consecutive window still gives a full-rank rectangular Fourier Vandermonde matrix (the bases are raised to the invertible exponent d). Therefore all the simplified window inequalities and the counting obstruction remain valid even after modular shifts or odd-stride permutations at power-of-two N, with arbitrary output endpoint ordering.

This means that **non-affine** input reorderings (such as bit reversal) are essential for the classical two-stage counterexample to evade the particular Vandermonde barrier.

## What remains unresolved

1. The revised arbitrary-endpoint inequality can be evaluated exactly for bit-reversal and other non-affine layouts, but may leave many candidate factorizations unexcluded.
2. Passes through any rank certificate do not imply existence. The separated-generator polynomial compatibility problem for the original 8-point fixed shuffle remains unresolved over the complex numbers.
3. Neither the archive nor this checkpoint provides an arithmetic operation reduction. A future construction must be verified exactly, with all setup, memory, and coefficient costs accounted for, against modern FFT and NTT baselines.
