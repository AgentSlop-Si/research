Combined research conclusions and the remaining proof gates
October 9 2026

CONCLUSION
The new packages strengthen our checks against hidden information and hidden bit work. They do not supply a faster arithmetic kernel. Combining them with the verified recurrence fusion does not yet yield a novel exact dense FFT or integer-multiplication bound.

The strongest concrete unresolved shortcut remains the thin-matrix total-operation claim. It has explicit published support, and our reduction from logarithmic-support exponential sums is proved conditionally. None of these six uploads contains the original 1976 construction needed for the independent addition-count audit.

1. WHAT WAS ACTUALLY NEW
Three ZIPs are byte-identical copies of our rectangular, cross-block, and fused-reconstruction reports. Two Galois ZIPs are byte-identical to each other. There are two new unique packages: joint Galois stability and global bottleneck. Repeated copies are not independent evidence or multiplicative improvements.

2. WHICH RESULTS CAN BE COMBINED
Dense arbitrary complex input:
- A smooth exact information bottleneck must retain N complex dimensions, counting original inputs, stored outputs and side state that cross the cut.
- This allows a wide O(N) arithmetic algorithm. It does not prove an N log N runtime lower bound.

Dense binary input:
- Bounded encoded values and polynomial decoder amplification require Omega(N/log N) complex registers for exact recovery, or for the stated small absolute unnormalized error.
- The Galois package supplies a concrete selected-frequency case, including exponential sensitivity when only a few odd bins carry the varying information.

Sparse input with k supplied frequencies:
- The amplitude dimension is k. The applicable smooth width bound is k, not N.
- Unknown k-hot supports have binomial(N,k) possibilities. The corresponding polynomial-range/conditioning requirement is Omega(k log(N/k)/log N), which is only Omega(log N) for k=Theta(log N).
- Therefore these new barriers do not reject the k-state recurrence, its complete decoded-state fusion, or the conditional thin-matrix route. See GLOBAL_ASSESSMENT.txt for the proofs.

Bit-cost claims:
- A giant integer product cannot be charged as one ordinary scalar/word operation.
- Omega(N log N) bits for N growing-field transform outputs is a statement about that output format. With N approximately n/log n in an n-bit multiplication reduction, it is only Theta(n) output bits. It does not exclude linear-time integer multiplication.

3. THE CONSTRUCTIVE CORE THAT SURVIVES
For a rational sequence P/Q and a decoded length-L state v, compute
 R=floor(Qv/t^L),
 next=-((Q^-1 mod t^L)R mod t^L).
Parity extraction from [v;next] produces both decoded children. This exactly eliminates separate spectrum-extension and terminal-decoding stages. Standard convolution still gives O(N log k), with setup charged. A genuinely cheaper joint application remains unproved.

Under hypothesis H, a uniform exact total-O(n^2) n-by-O(log n) times O(log n)-by-n product, the baby-step/giant-step factorization gives O(N) expansion for arbitrary k=O(log N) modes. Chan explicitly cites such an operation bound; the original abstract foregrounds multiplication count, so the independent full-construction audit is still open. The new stability/packing files neither verify nor refute H.

4. A JOINT CHECK AGAINST AN INVALID DENSE COMPOSITION
Suppose someone proposes computing an arbitrary dense N-input DFT by first smoothly encoding the entire input into just two matrices U of size n-by-p and W of size p-by-n, with n=ceil(sqrt N), p=O(log N), and then reconstructing all outputs from UW alone. The complete pre-product state has only 2np=O(sqrt(N) log N) complex coordinates. For large N this is less than N. The global rank theorem therefore rules out this exact factorization on an open complex input set.

This is not a restriction on the sparse construction, whose amplitudes have only k dimensions. It also does not prohibit schemes retaining the original input, additional wide state, many products, or a different computation structure. Those must be analyzed and charged separately. It explains precisely why a linear-cost sparse expansion cannot simply be relabeled as a linear-cost dense FFT.

Even splitting a dense input into N/k sparse groups and fully expanding each by an O(N) black box costs O(N^2/k), before aggregation. A new sharing identity would be needed to avoid this repetition.

5. A VALID CONDITIONAL APPROXIMATE COMPOSITION
COMBINED_THEOREM.txt derives a separate consequence: adaptive importance sampling plus H yields conditional O(N) work for fixed epsilon and inverse-polynomial failure probability, with unitary-DFT max error at most epsilon ||x||_1/sqrt(N).

This is a different accuracy target from the original exact FFT goal. For dense flat input it permits epsilon sqrt(N) absolute error per frequency and need not preserve relative energy. It is included because the composition is mathematically coherent, not presented as having beaten an exact numerical FFT. The sampling/model assumptions and all costs are explicit in that note.

6. EVIDENCE QUALITY
The uploaded central theorems are sound within their stated interfaces. Their code and captured results were reviewed statically; their Python test suites and timings were not rerun. Manifest hashes were checked, and integer precision bounds were independently recalculated.

Small corrections worth retaining:
- Galois witness ratios with float64 output gaps should not be printed as certified 25-30-digit ratios.
- Floating-grid collision counts are illustrative near quantization boundaries.
- The Galois test file does not provide the claimed fractional-bit-growth coverage.
- The global packed evaluator is implemented for supported power-of-two lengths with prime/root assumptions; its all-length mathematical statements are not all-length implementation tests.

7. WHAT WOULD CHANGE THE VERDICT
A verified complete addition-count construction for H would establish the narrow sparse-expansion consequence as classical prior-art-based work. It would not establish novelty or solve the dense exact target.

For the original dense goal, a successful next submission must provide a complete wide arithmetic evaluator with a scalable operation recurrence, all coefficients/preprocessing/output costs included. For the current sparse route, it must supply H's audited construction or a faster fully charged joint recurrence/transposed-remainder algorithm. The two new packages contain no such positive construction yet.
