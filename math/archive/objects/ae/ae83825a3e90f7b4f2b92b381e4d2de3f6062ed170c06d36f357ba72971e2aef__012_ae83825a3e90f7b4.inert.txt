# Constructive controls and exact certificates for the bidirectional-sum FFT model

9 October 2026. The main target, a uniform fresh-input exact DFT using o(log N) fully charged stages, remains unachieved here. This report provides a concrete ordinary-FFT control in the proposed model, an exact single-stage obstruction, and algebraic certificates. No new asymptotically faster FFT is claimed.

## 1. Results at a glance

* One bidirectional-sum stage, with suitable independent input/output permutations, computes F4 exactly.
* No single such stage computes a row/column-permuted F_N for N >= 5. The proof works over any field containing a primitive Nth root, not just the complex numbers.
* Consequently ordinary radix-4 FFT has an exact encoding using log_4(N) bidirectional stages for N = 4^s. Mixed radix 2/4 uses ceil(log_4(N)) stages for every power of two.
* This establishes the optimal stage depth 2 at N = 8 and N = 16. It does not establish a logarithmic lower bound at growing N.
* Independent complete-basis checks pass at every power of two from 2 through 256 over two prime fields: 1,020 basis columns and 48 fresh random vectors.
* The first elementary finite depth-improvement question is two stages at N = 32 or N = 64, whose ordinary mixed-radix controls use three. No numerical fit or answer to that question is claimed.

## 2. Exact stage model and raw parameter count

For a vector x of length N, define two independent scans of the SAME input:

    f_0 = b_0 x_0
    f_i = a_i f_(i-1) + b_i x_i
    u_(N-1) = e_(N-1) x_(N-1)
    u_i = c_i u_(i+1) + e_i x_i
    y_i = f_i + u_i + d_i x_i.

There are (N-1)+N+(N-1)+N+N = 5N-2 stored scalar coefficients in this direct representation. Zero propagation weights are permitted and reset the appropriate scan. Each stage is evaluated by two linear sweeps and pointwise arithmetic, with no dense primitive. A straightforward generic implementation uses 5N-2 multiplications and 4N-2 additions; reset boundaries save one multiplication and one addition per direction.

Every strict lower cut H[k:N,0:k] and strict upper cut H[0:k,k:N] has rank at most one. Each cut has only one scan-state channel crossing it. This remains true when propagation weights vanish. In the generic nonzero case the off-diagonal entries have the form

    H_ij = u_i v_j,  i > j;
    H_ij = p_i q_j,  i < j;
    H_ii = delta_i.

That dense generic chart has 5N-6 effective scalar parameters for N >= 3, rather than 5N-2: each strict triangular rank-one part has 2N-3 parameters, and the diagonal has N. This is an upper-dimensional description, not a lower bound for the special Fourier target. The full raw scan class is a subset of the rank-one quasiseparable class on degenerate boundaries; do not identify the two classes without checking zero patterns.

## 3. A single exact F4 leaf

Let i be a primitive fourth root, i^2 = -1, and F4[k,j] = i^(kj). Reorder the rows by

    r = [0,2,1,3]

and columns by

    c = [1,3,0,2].

The reordered matrix is

    H = [ 1   1   1   1
         -1  -1   1   1
          i  -i   1  -1
         -i   i   1  -1 ].

It is precisely one stage with

    forward propagation a = [0,-1,-i,-1]
    forward injection   b = [1, 1,-1, 1]
    backward propagation c = [1,-1,-1,0]
    backward injection   e = [1, 1,-1, 1]
    extra diagonal       d = [-1,-3,3,-3].

The boundary zeros are resets, not extra arithmetic gates. To transform an ordinary leaf z, feed x = [z1,z3,z0,z2] to the stage and scatter its outputs to indices [0,2,1,3]. Directly expanding the two recurrences gives the displayed H. This identity is valid in any field with a primitive fourth root (necessarily characteristic not 2); it does not depend on floating-point fitting.

A radix-2 leaf is also one stage, in ordinary input/output order:

    a = [0,1], b = [1,1], c = [1,0], e = [1,1], d = [-1,-3].

It gives [[1,1],[1,-1]]. Repeating either leaf's weights along the full array, with resets at every leaf boundary, performs all disjoint leaf transforms as a single global bidirectional-sum stage.

## 4. Single-stage impossibility beyond length four

### Rank-one Fourier rectangle lemma

If a Fourier submatrix F_N[I,J] has rank one, then |I||J| <= N. This holds over any field with a primitive Nth root omega.

Proof. Every entry is nonzero. Choose i0 in I and j0 in J. Vanishing 2-by-2 minors implies

    omega^((i-i0)(j-j0)) = 1

for all i in I and j in J. Let G be the subgroup of Z/NZ generated by the differences I-i0. Then I is contained in the coset i0+G. Every difference J-j0 lies in the annihilator G-perp. Therefore

    |I| <= |G|,  |J| <= |G-perp| = N/|G|,

giving the inequality. This is a direct argument using the order of omega; it uses neither a norm nor an assumption that N is prime.

### Theorem

No bidirectional-sum stage, even preceded and followed by arbitrary permutations and nonsingular diagonal scalings, equals F_N for N >= 5.

Proof. Let r=floor(N/2). Its upper-right block on the first r outputs and the last N-r inputs has rank at most one. In a permuted Fourier target this is a Fourier rectangle with r(N-r)=floor(N^2/4)>N. Diagonal scalings preserve rank. The rectangle lemma gives a contradiction.

The F4 construction proves the endpoint sharp. This is a ONE-STAGE theorem only. Internal permutations between several stages change which coordinate cuts align, so this theorem cannot be multiplied into a log_4(N) depth lower bound.

## 5. All-N ordinary-FFT assembly

For N=4M, writing input index n=4m+r and output index k=j+qM gives

    F_N(x)_(j+qM)
      = sum_(r=0)^3 i^(qr) omega_N^(jr)
          sum_(m=0)^(M-1) omega_M^(jm) x_(4m+r).

Thus four smaller DFTs are followed by diagonal twiddles and disjoint F4 leaves. Induction provides log_4(N) global bidirectional stages for N=4^s. All N outputs are materialized and the input is arbitrary and fresh. For N=2^ell with odd ell, one radix-2 level and the remaining radix-4 levels give ceil(ell/2) stages.

`radix4_bidirectional.py` implements this without using dense transforms: initial mixed-base digit reversal; gathered twiddle-scaled leaf inputs; two whole-array recurrences with resets; output scatter. Direct DFT evaluation is used only by the separate verification routine.

### Fully charged reference implementation, N=4^s

Each stage contains g=N/4 independent leaves. The deliberately simple implementation performs:

* scan-and-sum multiplications: 5N-2g = (9/2)N;
* scan-and-sum additions: 4N-2g = (7/2)N;
* a gather and scatter of N data words each.

These counts include multiplication by +/-1, +/-i, and the fixed diagonal constants. Such operations can be simplified, but the displayed numbers match the explicit straightforward gate schedule and are not claimed minimal.

Across s levels, the nonidentity DATA twiddle multiplications total

    (3/4) N s - N + 1.

The scan contribution is (9/2)Ns multiplications and (7/2)Ns additions. Hence the complete data path is

    (21/4)Ns - N + 1 multiplications,
    (7/2)Ns additions.

Twiddle scalar PREPARATION is separately charged. A level of length m tabulates powers using 3(m/4-1) multiplications; the sum is N-1-3s. The reference code independently forms stage roots and the fourth root by repeated squaring, using (s-1)(s+2) additional multiplications. This redundant O((log N)^2) root schedule can be reduced to O(log N) by reusing stage roots, but the executable counts the schedule actually used. A primitive Nth root is supplied, in the same exact-field model as the target question.

The initial digit reversal moves N words; all level gathers/scatters move 2Ns words. A moved word here means one read/write transfer, so gather/scatter read-plus-write accesses are twice that number. Scan traffic, output additions, coefficient reads, and allocation writes are additional O(Ns), not hidden or free.

The verification harness precomputes and retains three N-entry arrays (gather indices, scatter indices, replicated twiddles) per stage, so its plan occupies O(Ns) words. The data path uses at most five N-entry working arrays at a time, excluding the caller's input and the retained plan. Plans may instead be generated level by level with O(N) peak auxiliary storage and O(Ns) index-generation/plan-write traffic. Distinct scalar twiddle tables contain only O(N) entries, but copying them into routing plans still has its stated cost.

All these bounds remain Theta(N log N). This scan encoding is less economical in elementary arithmetic than a standard hand-optimized radix-4 butterfly. Reducing the count of named stages does not constitute a new FFT speedup. Exact complex arithmetic is the model; no fixed-precision, coefficient-conditioning, or bit-complexity claim follows. Finite modular checks do not create an all-length fixed-prime NTT theorem.

## 6. Executed exact checks

After the final source edits, the test suite evaluates every basis vector for N in {2,4,8,16,32,64,128,256}, independently at primes 998244353 and 2013265921. Primitive roots are verified at every length. It also checks three fresh random vectors for every length/prime pair against the direct quadratic DFT.

Totals: 1,020 complete basis columns; 48 fresh random vectors. All pass. `radix4_results.json` contains each length, field, stage count, data arithmetic count, preparation count, and routing count. `test_run.txt` is the captured output. The all-N proof is the explicit leaf identity and radix induction above, not the numerical test count.

Useful endpoints:

* N=8: 2 stages, and 1 is impossible.
* N=16: 2 stages, and 1 is impossible.
* N=32: 3 stages in this control; possibility of 2 unresolved here.
* N=64: 3 stages in this control; possibility of 2 unresolved here.
* N=256: 4 stages; 4,608 scan multiplications, 3,584 additions, 513 nonidentity data twiddle multiplications, 243 twiddle-preparation multiplications, 18 root-preparation multiplications, and 2,304 moved data words for initial reversal plus level routing.

## 7. Reset-safe tridiagonal normal form

The following stronger normal form was independently supplied and tested by the parent investigation. Let

    A = I - (forward weighted subdiagonal),
    C = I - (backward weighted superdiagonal),
    B = diag(b), E = diag(e), D = diag(d).

Then H=A^(-1)B+C^(-1)E+D. Provided every backward injection e_i is nonzero, define

    K = A H E^(-1) C
      = B E^(-1) C + A + A D E^(-1) C.

K is tridiagonal, even when propagation weights are zero. Therefore

    H = A^(-1) K C^(-1) E,
    H^(-1) = E^(-1) C K^(-1) A

when H is invertible. This explains why H^(-1) can be fully dense: a tridiagonal inverse is generally dense. The e_i != 0 hypothesis is explicit; no division by propagation weights is used. The F4 construction satisfies it.

The ordinary dense generic chart gives a second easy certificate: choose a unit lower-bidiagonal L whose subdiagonal is -u_i/u_(i-1), and a unit upper-bidiagonal U whose superdiagonal is -q_j/q_(j-1). Then L H U is tridiagonal. Boundary generator values can be chosen arbitrarily nonzero. This version divides by generators and should not replace the reset-safe formula when resets occur.

For a proposed factorization, the useful finite certificate is the exact raw stage weights, permutations, and either the full basis equality or symbolic identity. The tridiagonal identity is a valuable intermediate structural check; it is not itself evidence that the Fourier product exists. A factor search over arbitrary tridiagonal pencils must recover valid raw scan weights, particularly at singular/zero-generator boundaries.

Quasiseparable cut ranks are invariant under matrix inversion in the same coordinate order: the complementary-minor/nullity identity gives rank(H^(-1)[I,I-complement])=rank(H[I,I-complement]). They need not remain small after arbitrary coordinate reordering. Standard displacement rank with a FIXED shift is a different invariant and need not be small for arbitrary weighted scans; the shifts/operators and ordering must always be specified.

## 8. Direct-feedthrough scalar scans: a model correction and certificate

For the hypothetical one-direction model

    h_i=a_i h_(i-1)+b_i x_i,
    y_i=c_i h_i+d_i x_i,

let t_i=c_i b_i+d_i. Invertibility requires every t_i != 0. The inverse always has the scalar PRE-update-output realization

    h_i = (a_i d_i/t_i) h_(i-1) + (b_i/t_i) y_i,
    x_i = -(c_i a_i/t_i) h_(i-1) + y_i/t_i.

If also d_i != 0, it has a POST-update-output realization of the original syntax:

    h_i = (a_i d_i/t_i) h_(i-1) + (b_i/t_i) y_i,
    x_i = -(c_i/d_i) h_i + y_i/d_i.

Without d_i != 0, claiming closure in that exact post-update syntax is false. A prefix-sum matrix is such a scan, but its three-by-three bidiagonal inverse is not: in a post-update one-state scan, nonzero entries S21 and S32 force S31 != 0, contrary to the inverse prefix-sum matrix. The broader state-space or quasiseparable description is inverse-closed; the restricted post-update realization has a degenerate-boundary issue.

Generically a post-update scan is an inverse lower-bidiagonal times a lower-bidiagonal, so its inverse can be dense and the pure-scan inverse-support proof does not apply. An explicit two-stage screening certificate is available. A dense generic lower scan S has strict entries u_i v_j. There are unit lower-bidiagonal L and R such that L S and S R are lower-bidiagonal: take left row ratios u_i/u_(i-1) and right column ratios v_j/v_(j+1), with arbitrary nonzero boundary generators. Thus

    M = S2 P S1  implies  L2 M R1 = B2 P C1,

where B2 and C1 are lower-bidiagonal. The right-hand side has at most four nonzeros in each row and column, with the stronger specific bidiagonal-permutation-bidiagonal support. This is a concrete exact sparse weighted-difference certificate for a two-stage candidate in prescribed outer orders. It is necessary in its nondegenerate domain, not sufficient by itself, and it is not a general lower bound with arbitrarily many shuffled stages.

## 9. Bounded next gate and literature scope

A useful next finite experiment is a two-bidirectional-stage factorization of F32 or F64, with all raw coefficients and permutations supplied and exact basis verification. Finding one would be a constant-size stage improvement only. A claimed asymptotic gain still requires a uniform infinite family, all scalar/routing preparation charged, and complete arbitrary-input outputs. Repeated numerical nonconvergence is not a no-go proof. The surviving asymptotic question remains open within this investigation.

Relevant primary references:

* Clement Pernet, Computing with quasiseparable matrices: https://arxiv.org/abs/1602.01246 . The structured off-diagonal-rank language and linear-in-dimension representations are established literature.
* Nir Ailon, An n log n Lower Bound for Fourier Transform Computation in the Well Conditioned Model: https://arxiv.org/abs/1403.1307 . Conditioning-restricted circuit bounds should not be promoted to unrestricted coefficient bounds.
* OpenAI exact Fourier formalization, theorem #130: https://github.com/openai/math/blob/main/lean/docs/130.md . Its current scope includes a uniform exact unrestricted-coefficient power saving with a supplied root. Therefore a universal unrestricted N log N barrier is not an appropriate claim. The present ordinary-radix control does not improve that comparator.

The leaf construction and rectangle argument here are elementary derived controls. No literature-priority claim is made.
