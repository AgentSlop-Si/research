# Exact black-box scan-fusion rank gate

## Statement

Let `R` independent gauged prefix scans have forcing vectors `q_r[j]`. Restrict inputs so only the first values `q_r[0]=z_r` may be nonzero. At any later position, the `r`th scan output is a nonzero diagonal multiple of `z_r`.

Evaluate the final rank-`R` Chebyshev combination at `R` distinct residual offsets `theta_i`. After deleting nonzero diagonal row/column factors, the map from `z` to these outputs is

`C[i,r] = T_r(2 theta_i)`.

Since `T_r` has degree `r` and nonzero leading coefficient, this is a Chebyshev--Vandermonde matrix and has rank `R`. Therefore any exact linear one-pass state carrying arbitrary already-materialized channel data across the cut after position zero has dimension at least `R`.

## Exact certificates

`scan_fusion_rank_certificate` uses Python `Fraction` arithmetic and Gaussian elimination. Saved cases certify ranks:

- `R=8`, `N=127`, `Q=128`;
- `R=10`, `N=255`, `Q=256`;
- `R=12`, `N=511`, `Q=512`.

## What this does not prove

It is not a general Fourier lower bound. It does not cover:

- algorithms exploiting Bessel structure before channels are materialized;
- nonlinear encodings with a different computational model;
- approximate state compression;
- repeated residual offsets, where the output-side rank is at most the number of distinct classes;
- unrelated FFT factorizations.
