# Independent audit of the adjacent-anchor exact unit-ideal obstruction

## Verdict

**PASS, at the claimed guarded scope.**

An independently written checker regenerates the 20 row-resultant identities from the exact matrix product `F8 T K_adj`, verifies every canceled polynomial factor and nonzero cyclotomic scalar, and checks the entire supplied proof DAG coefficient by coefficient. Its final polynomial is exactly **1** in

`Q[z]/(z^4+1)[t0,t1,t2,t3,w]`.

Consequently, for the stated adjacent anchor and fixed support pair, the necessary off-support equations have no solution over a characteristic-zero field containing a primitive eighth root of unity when

`u0 * B1 * B5 * B6 != 0`, with `B_j = (U M)_(0,j)`.

This excludes the entire exported guarded 12-variable, 40-equation chart. It does **not** exclude the whole adjacent-anchor diagonal orbit. The branches `u0=0`, `B1=0`, `B5=0`, and `B6=0` remain unresolved by this proof. This audit does not claim that those branches contain a Fourier solution; it simply does not eliminate them.

No fatal error, unguarded cancellation, support-orientation error, hidden row-equation division, or gap in the certificate's derivation of 1 was found.

## 1. Field and exact matrix reconstruction

The coefficient field is the abstract quotient `K = Q[z]/(z^4+1)`. Irreducibility over Q is independently justified by Eisenstein at 2 after translation:

`(z+1)^4 + 1 = z^4 + 4 z^3 + 6 z^2 + 4 z + 2`.

Thus a nonzero reduced polynomial of degree below 4 is a nonzero field element. Every claimed normalization scalar is explicitly nonzero in this basis. Every rational denominator is represented as an integer and checked nonzero; no specialization-dependent denominator is introduced by the certificate.

The checker builds full exact matrices F, T, and the four adjacent 2-by-2 anchor blocks, then multiplies them. It separately compares the resulting columns with

`M[r,2a] = z^(2ar) + t_a z^((2a+1)r)`,

`M[r,2a+1] = z^(2ar) - t_a z^((2a+1)r)`.

It reconstructs the cycle maps from the supplied support orders and confirms

- `pi = [1,2,3,4,5,6,7,0]`;
- `sigma = [2,7,5,0,6,1,3,4]`;
- pivot rows `[3,0,0,1,0,0,0,1]`.

With `U = I + diag(u) P_pi`, it multiplies U M, regenerates the pivot coefficients, all 64 minors, and all 8 diagonal equations. **All 88 stored coefficient polynomials match exactly.** The 40 zero-equation indices match the independently generated list.

In particular, the pivot-row-zero columns are exactly `J = {1,2,4,5,6}` and `B_j = M[0,j] + u0 M[7,j]`. Therefore `B1`, `B5`, and `B6` are respectively the exported guards `a_1`, `a_5`, and `a_6`; `u0` is an exported variable guard.

## 2. Necessity and elimination without row pivots

For every eligible off-support row r and column j, the checker reconstructs

`b_rj = B_sigma(j) M[r,j] - B_j M[r,sigma(j)]`,

`c_rj = B_sigma(j) M[r-1,j] - B_j M[r-1,sigma(j)]`.

It verifies the full polynomial identity

`h_rj = b_rj + u_r c_rj`

against the stored interface, and confirms that each used h is one of its zero equations. For each selected pair j,k, it verifies

`R_(r;j,k) = b_rj c_rk - b_rk c_rj = c_rk h_rj - c_rj h_rk`.

This is a polynomial identity. It never solves for u_r and never divides by `c_rj`, `c_rk`, or a row-equation coefficient. The inference from vanishing necessary minors to vanishing raw resultants therefore has no additional pivot exception.

The eligible columns are independently regenerated as:

- row 3: 1, 4, 5;
- row 4: 1, 2, 5, 6;
- row 5: 1, 6;
- row 6: 1, 2;
- row 7: 2, 4, 5.

All column pairs are used, giving 20 resultants.

## 4. Exact proof-DAG audit

The certificate contains 20 separately stored input generators. All 20 are compared with the resultant export and independently tied to the Fourier construction above.

The retained DAG has:

- **57 total nodes**;
- **6 retained input leaves**: indices `2,4,7,10,12,18`;
- **51 derived nodes**;
- **575 polynomial-combination entries**, containing **688 multiplier monomials**;
- final node **78**, whose polynomial is exactly **1**.

Every retained node is an ancestor of the final node. Every dependency refers to a previously verified retained node. Each input leaf agrees with its corresponding audited generator; no unexplained leaf, forward reference, or cycle is admitted.

For a derived identity `p = sum(q_j p_j)`, the independent checker represents each polynomial as an integer numerator divided by one positive integer denominator. It sets

`D = lcm(den(p), den(q_j) den(p_j) for all j)`

and verifies that the integer polynomial

`-D p + sum(D q_j p_j)`

is identically zero after reducing powers by `z^4 = -1`. It compares exact integer coefficients, including the constant term. Thus each node's claimed linear-combination identity is proved directly, rather than accepted because a basis algorithm reported success.

Induction through the DAG proves that its final 1 belongs to the ideal of the audited generators. Evaluation at any common zero would consequently give `1=0`, which is impossible.

### Minor descriptive precision

The source describes the final certificate as using all 20 generators. The file exports and this audit verifies all 20, but the retained dependency DAG actually uses only the six leaves listed above. The independently checked identities therefore also establish the six-generator unit-ideal statement in characteristic zero for those particular indices. This is a valid strengthening of the input-subset description, not a flaw in the claimed 20-generator obstruction. It does not remove any of the four required nonzero factors: the retained leaves collectively still require all four.

### Arithmetic cost

The largest cleared denominator in the node checks has **87,909 bits**. Large integer coefficients and denominator arithmetic are real costs. The measured run finishes in approximately 16 seconds on this environment; no uniform constant-bit-cost or asymptotic claim is inferred.

## 6. Precise scope and unresolved boundaries

The characteristic-zero theorem is valid under every embedding of Q(zeta8) into a characteristic-zero field extension; the checker chooses no approximate complex root. It does not assert a result in positive characteristic, where rational denominators or scalar factors could fail to be invertible.

Only `u0`, `B1`, `B5`, and `B6` are assumed nonzero in the obstruction. None of the other seven row-edge variables, nor any anchor ratio t_a, is divided by. The bounded polynomial contradiction therefore still applies if those other variables are zero, provided the four stated factors remain nonzero.

The proof does not use the remaining endpoint guards, `1-product(u)`, or `product(c)-product(a)`. It arises before endpoint-scale reconstruction and invertibility. Therefore scale restoration or the factor of 2 in the actual Fourier second factor cannot repair a candidate inside this chart.

The following remain outside the conclusion:

- the Fourier boundary `u0=0`;
- the Fourier boundaries `B1=0`, `B5=0`, or `B6=0`;
- any assertion that full nonzero cycle edges imply nonzero pivots;
- different support cycles or arbitrary endpoint permutations;
- a free first layer or a general two-layer Fourier-8 kernel;
- a universal Fourier obstruction, growing-size algorithm or lower bound, or novelty claim.

The previously accepted half-anchor orbit exclusion is neither rerun nor altered by this audit. This continuation addresses the adjacent-anchor open-chart obstruction only.
