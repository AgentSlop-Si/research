# Hero #1 Phase 25 — Exact CRT-deferred Green FFT

**Result:** exact all-input Fourier computation over suitable prime fields for `N=3·2^t` with deferred output preview, zero field-arithmetic recomputation on completion, and a fair comparison against an optimized native mixed-radix FFT. The existing Green sparse-rational certificate is integrated; it does **not** beat a native FFT in the tested sizes. The unitary gate-entropy theorem identifies a restricted model where beating `NlogN` is impossible.

This is **not** an unrestricted exact sub-`NlogN` FFT or a historical claim to invent Good–Thomas, Winograd, or the entropy bound.

## Main files

- `THEOREM.md`: CRT proof, exact per-input operation counts, deferred completion identity, memory and root caveats, unitary entropy obstruction.
- `gt3_deferred.py`: no-repeated-work GT3 transform for every input; full native Cooley–Tukey control and direct DFT oracle.
- `gt3_green.py`: Phase 23/24 exact sparse-rational Green certificate with input-side preview and exact GT3 fallback.
- `entropy_gate.py`: numerical cross-check of known unitary 2×2 entropy potential, **not** a new proof.
- `test_phase25.py`, `test_phase25_green.py`, `audit_phase25.py`, `benchmark_phase25.py`: reproducible tests and independently derived Fourier-matrix checks.
- `COST_LEDGER.md`, `PHASE25_AUDIT.json`, `PHASE25_BENCHMARK.json`: precise arithmetic resource accounting.
- `phase24_source/`: unchanged Phase 24 Python implementation dependencies, included so this ZIP runs alone.
- `PRIOR_PHASE24_COMPLETE.zip`: original, untouched full Phase 24 archive preserving all previous checkpoints.

## Reproduce (Python 3.11+; standard library only)

```sh
python3 -m unittest -q test_phase25 test_phase25_green
python3 audit_phase25.py
python3 benchmark_phase25.py
cd phase24_source && python3 -m unittest discover -p 'test_*.py' -q
# return to package root:
cd .. && sha256sum -c MANIFEST.sha256
```

The audit verifies two finite fields and complete Fourier basis matrices; the complex entropy checker is a distinct analytical domain. Input/root setup, word RAM index operations and numeric floating-point stability are **not** covered by the steady-state field-operation proxy. The executable code and theorem are research prototypes, not independently peer-reviewed contributions.
