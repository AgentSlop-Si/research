# Deferred FFT corrections: an exact audit

**Question:** Can the corrections exposed by graph rewrites be postponed across
many FFT levels, then combined into one small correction for every fresh input?

This package tests one precise proposal: retain a shared butterfly core with
all phase multipliers replaced by 1, and compute the difference from the DFT
as one global correction. It contains an all-length rank bound, a support-count
formula, and independently replayable finite certificates.

**Outcome:** no new faster FFT was obtained. The proposed global correction
has rank at least `N/2-1`. For the explicit core, exact complex ranks certified
at tested sizes are:

| N | Correction rank | Independent kernel vectors | Nonzero correction entries |
|---:|---:|---:|---:|
| 16 | 11 | 5 | 176 |
| 64 | 57 | 7 | 3,648 |
| 256 | 247 | 9 | 63,232 |

The finite calculations use exact modular arithmetic, with nonzero minor
certificates that lift to the cyclotomic field. Small cases are also checked
directly in exact cyclotomic arithmetic. No numerical rank threshold is used.

**Scope:** a large rank is not a running-time lower bound. Even the identity
matrix has full rank and a linear-time action. This result rejects a small-rank
correction for the stated common-core architecture. It does not rule out a
structured fast correction, other cores, or other FFT algorithms.

## Reproduce

Python and NumPy are required. All scripts run sequentially.

```bash
python3 -m unittest -v test_deferred
python3 run_audit.py
```

The saved run has **8 passing tests**, **16 replayed rank certificates** over
two primes, and **25 checks of different common cores**. The files in `results/`
contain the certificates, the mixed-term counterexample, and execution logs.
These are offline mathematical audits, not performance benchmarks. Dense
matrices are built explicitly; this program is not an FFT implementation.

Read `AUDIT.md` for the proof, the correct telescoping identity, and cost
accounting. `SOURCES.md` records the checkpoint and prior code used, plus
relevant primary literature. The project has a descriptive name to avoid
colliding with the parallel numbered research branches.
