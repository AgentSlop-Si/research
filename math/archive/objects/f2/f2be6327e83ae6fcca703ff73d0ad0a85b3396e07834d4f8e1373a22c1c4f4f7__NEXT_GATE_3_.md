`M_N=(A_N^{-1}+B_N^{-1})(C_N^{-1}+D_N^{-1})=U_N`,

where each denominator is `I-diag(w) P_sigma` with a Hamiltonian cycle, each of four scans works in O(N), and all permutations, root phases, and weights are generable in O(N) uniform sequential operations.

## Order of checks

1. **Reject graph architectures** failing any dyadic coset cut using the O(N+E) trie verifier (`all_exit_counts`). Also retain the older balanced Fourier-character cuts, not replaced by coset cuts.
2. **Reject wrong complex phases** using exact finite-field Weyl identities `MS=DM`, `Me_0=v`, as developed in the saved Weyl dual-certificate branch. Do not mistake a positive graph expansion test for FFT correctness.
3. **Sparse bridge:** use `AFD=(A+B)(CB)^{-1}(C+D)` as an algebraic identity / sparse polynomial gate. But note `K^{-1}=(CB)^{-1}=B^{-1}C^{-1}` is **already O(N)** to apply. Faster generic K solvers are not the missing step.
4. **Synthesize families, not instances:** find symbolic recurrences for the weights and cycle orders that work at N=2^k for unbounded k, with proof and all preprocessing counted. Disprove a candidate at the first exact modulus showing nonzero Weyl residual.
5. **Check stability and prior art** before claiming a practical new FFT.
