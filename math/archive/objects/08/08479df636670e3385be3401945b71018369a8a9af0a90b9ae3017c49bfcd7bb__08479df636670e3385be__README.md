# Centered v12 independent audit supplement

9 October 2026. Standalone audit of the supplied centered-Fourier v12 checkpoint.

## Start here

- `audit/SHORT_RESEARCH_NOTE.md`: short research page.
- `audit/V12_AUDIT_AND_EXTENSION.md`: identities, costs, provenance, sharper Bessel envelope and midpoint variant.
- `precision_audit/V12_PRECISION_AUDIT.md`: carrier correction, constructive reanchoring, summary-interface ledger and charged setup.

The source exact-arithmetic identities and advertised finite parameter proxies check out. The audit adds a pointwise fusion factor below 2.278 and an occupied-block midpoint construction. Product-tree depth is not a floating-point forward-error bound; the precision report gives a conditional repair. None of these establishes a faster exact FFT, a better asymptotic approximation bound, or a numerical-library certificate.

## Contents and boundaries

`original/` preserves the 50,575-byte source ZIP. `extracted/` contains all 26 inert source members. Uploaded source was never executed or imported during this audit. Its historical logs are user-supplied data, not our test logs.

`audit/` and `precision_audit/` contain independent reports, newly authored checks, completed result files and run logs. `prior_context/` carries relevant earlier reports unchanged so the assumptions and comparisons can be followed. The prior reports' older tests were not rerun in this audit.

## Reproduce independent checks only

With Python, NumPy and mpmath installed:

    python audit/independent_v12_checks.py
    python precision_audit/independent_precision_checks.py

These two programs do not execute or import the uploaded programs. Results combine exact integer/rational and finite-field checks with explicitly identified high-precision or floating-point controls. Numerical controls corroborate the proofs and do not certify every uploaded floating-point operation.

`SHA256SUMS.txt` covers every packaged file except itself. The archive has a separate SHA-256 checksum. No master research package or Library file was modified by this supplement.
