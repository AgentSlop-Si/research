# Hero #1 Phase 17 — exact sparse-residual Green FFT

**Date:** 2026-10-10. **Headline:** Exact all-output Fourier evaluation for arbitrary-length, *structured-input* signals whose noncommuting Green residual has K nonzeros, with `O(N log(K+1)+K log^2(K+1))` field arithmetic. **No exact arbitrary-input sub-`NlogN` FFT.**

This is an independent research continuation of the supplied Phase16 archive, preserving the older checkpoint and regression logs. It uses the fully priced `L F = F P` Weyl–Green identity, then makes `F(Px)` cheap **only when** `Px` is sparse. A rational generating-function recurrence streams all N frequencies via short size-O(K) convolutions, not a disguised N-point FFT; the short NTT kernels are cached within each call and their creation is fully charged. A full Bluestein fallback remains available for generic input.

**Entry points:** `rational_forcing.py` is the all-length engine; `green_sparse.py` contains dyadic pruned FFT plus adaptive bank selection. `THEOREM.md` gives the proof; `COST_LEDGER.md` distinguishes arithmetic, bit complexity and numerical error; `NEXT_GATE.md` lists open work. `PRIOR_ART.md` credits existing FFT/pruned transform/power-series algorithms.

**Reproduce:** `python run_all.py` (needs NumPy for one complex diagnostic; everything else Python stdlib). For the unchanged previous phase, execute `python run_all.py --prior`. All generated results and regression receipts are included.

**Verification:** 16 focused Phase17 tests, 222,111 whole-basis/identity finite-field entries, 32 arithmetic-proxy benchmark configurations, clustered-phase precision warning, successful Phase16 regression (17 tests and 654,752 entries). No formal proof assistant certificate or all-size machine-theorem claim.
