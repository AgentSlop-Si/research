Historical output names and hard-coded PASS labels are not evidence of a fresh run.

The most useful findings are:

1. Phase35's signature gate is sufficient for its constructed first-row/first-column calibration, but its stated necessity requires invertibility assumptions absent from the public helper. A concrete exact algebra counterexample is below. Matching signatures containing a zero also produce a failure dictionary that a downstream caller cannot handle.
2. The Weyl verifier does implement a fixed four-branch linear-time apply, but its seed-correction setup allocates a dense identity matrix. Its tiny dense controls and exponential graph-cut enumeration are separate costs. The finite-field result is a test in one fixed field, not a characteristic-zero or all-size equality certificate.
3. The phasor program is an approximate, integer-atom simulator with an L1-scaled probabilistic error target. It expressly does not implement the claimed precomputed-table word-RAM runtime. Its eager table check is one 4,096-entry toy instance.
4. Phase16 confirms the conventional N log2(N)/2 pair-unitary gate count and small-size dense numerical realizations. Linear-size Green-stage gate schedules do not prove linear coefficient preparation or a faster Fourier algorithm. No general arithmetic/word-RAM FFT lower bound follows from the restricted unitary entropy model.

### 1. fft_phasor_lookup_verify.py

- **Trace:** `signed_atoms` separates each complex coordinate into signed real/imaginary integer atoms (36–42). The integer Vose sampler preprocesses their absolute weights (14–34). Padding takes extra samples rather than inserting zero atoms. The direct DFT oracle has the same negative exponent and unitary normalization (198–199).
- **Model/cost:** k is g*ceil(ceil(16 eps^-2 log(4n/delta))/g). Symbol/phasor construction and decoding are proportional to n*k; the exact oracle is quadratic in n. Python big-integer packed shifts are not bounded-word unit-cost operations, and the chunk width is hard-coded to 2. No production first-level or final-decoder table is eagerly built. The full transpose lookup is only G=2, L=3, s=2, giving 2^12 entries (94–113). These restrictions are disclosed in the source.
- **Acceptance:** phase error is asserted against pi/P0+t*pi/P1; normalized decoder error is asserted against phase plus two coordinate-quantization errors. Each normal `simulate` result has `passed = max_error <= eps*L/sqrt(n)+1e-9`; main demands all 25 fixed-seed cases pass. The sampler histogram merely reports deviation and has no threshold. The zero-mass early return omits `passed`, n, eps and normalized-decoder fields (157), so it cannot be appended unchanged to main's schema.
- **Limitations/controls:** `int(z.real)` and `int(z.imag)` silently truncate noninteger inputs while the exact oracle still uses the original x. Thus the result supports the integer-input model only, not arbitrary complex vectors. n versus len(x), eps, delta, B and g are not validated. Float-valued integer weights pass the explicit weight check but can fail `randrange(L)`; the actual supplied atom weights are ints. There are positive, oscillatory, sparse and partial-block examples, but no intentionally corrupted table, wrong phase, or violated-input control proving rejection behavior. Fixed seeds and tolerances are not a proof of the advertised probability.
- **Dependencies/provenance:** standard library only. The imported bisect helper is unused. THEOREM.md is referenced but not read or granted coverage by this source inspection. Same-hash occurrences remain those recorded in the preserved inventory.

### 2. verify(3).py / Weyl-expansion verifier
SHA256: `e255424eb7f6358a3f758884baa36e09caae669ebcebb070e6d61e5ff2911bad`
Read: lines 1–405, 15,544 bytes.

- **Trace:** `Green.apply` solves (I-diag(w)P)y=v by closing one cycle and sweeping backward (60–75). Its small nonzero weights have magnitude below .41, avoiding a singular cycle denominator in generated complex examples. The network is (G1+G2)(G3+G4), implemented with four Green applications, not four compositions per expanded term (90–102). The Weyl relation uses the negative-sign Fourier convention; `phiweyl` realizes the required conjugated modulation/shift. Dense twirl sums compare with distance to the scalar Fourier line; the probe estimator applies two networks per shot to a complex Gaussian vector.
- **Model/cost:** one network apply is O(n) arithmetic and storage for a fixed four branches; cycle order is rebuilt each call. SeedCorrected.apply is O(n), but its constructor uses `np.eye(n)[:,0]` (210), allocating n^2 entries. `dense` constructs another identity inside every column evaluation (102); dense controls therefore include repeated quadratic allocation. Dense twirl uses n^2 dense matrix pair tests, conventionally O(n^5) arithmetic, and the n=16 graph control enumerates 2^n-2 subsets with O(n) boundary work. Exact-field inversion is dense elimination, while modular recurrence uses `math.prod(w)` before reduction, so fixed-field-operation claims should not be confused with literal bounded-word Python bit cost.
- **Acceptance:** `main` writes RESULTS.json only after assertions in six control families. Numerical tolerances include twirl equality at 1e-10, recurrence residual below 1e-9, estimator relative error below .12, cut numerical ranks at 1e-8, and one-column probe mean between .55 and 1.45. Standard error is reported but no confidence interval is used as the acceptance criterion. Python `assert` is central and disappears under optimized execution.
- **Negative controls:** explicitly includes a cut-capacity-passing graph that fails Fourier phase, an exactly seed-corrected wrong Green network, a rank-one localized column defect, and positive exact Fourier covariance. These test distinct necessary-versus-sufficient gaps. They are deterministic selected instances, not universal impossibility results.
- **Finite-field caveat:** q=331,n=11 and twelve random vectors test one fixed residual map. The printed q^-12 bound requires an actually nonzero linear residual and independent uniform field vectors. Fixed-seed pseudorandom demonstrations are not an adversarially sound certificate. The source correctly warns that characteristic-zero lifting additionally requires a valid reduction; no such lift is established here. Prime n=11 makes the nontrivial root chosen by the source primitive. Other input dimensions are not covered by that root search.
- **Dependencies/provenance:** NumPy plus standard library; no sibling imports. THEOREMS.md is referenced but not covered. No fresh RESULTS.json was generated.

### 3. phase35_balance.py
SHA256: `e8c842423f1484572a8ffb974aef467438e52386a70dd8faba362e1aa98a5ba4`
Read: lines 1–248, 9,709 bytes.

- **Trace:** GreenStage sums weighted constant-cycle resolvents, creates transposed cycle representations, and records row/column mass (24–53). `signature_gate` compares multisets of normalized A first-row and B first-column values, obtains a pullback permutation, and sets D_i=1/(mass(B)*A_0i). The apply and transpose implementations use that convention consistently (104–120). A matching nonzero signature makes both boundary vectors all ones. `balanced_residual` tests A(1/A_0i)=n e0 without constructing an inverse.
- **Model/cost:** fixed-width Green-stage applications and transposes are linear field-operation work conditional on the bundled CyclicGreen helper. Signature extraction and dictionary matching use linear expected dictionary work and O(n) inversions; inversion bit cost is not free in a bit model. Dependency setup checks cycle permutations using sorting. The Hadamard positive control is a dense n=4 factorization explicitly marked `outer_stage_is_Green_sum=False`; it must not be promoted to an admissible large-n Green FFT construction.
- **Acceptance/schema:** exact assertions certify the planted first cross and n=4 full algebraic factorization for the chosen cases. Negative next-column, balance and all-ones defects are reported as counts, not asserted positive. `independent_control` reports whether signatures/balance match rather than requiring rejection. A matched signature with any zero entry returns only `possible=False, reason=...` (97–98), but line 188 reads `moment2_A` and `moment2_B` for every false result. This is an unhandled conditional schema branch, not an observed failure of the fixed default cases. `planted_control` likewise assumes the balance result contains `nonzero_coordinates`. Empty greens are indexed before the nonempty assertion (29–31).
- **Important scope defect:** the “necessary and sufficient” docstring (76–80) has no invertibility precondition, while necessity/unique diagonal is false for singular sums. Each summand invertible plus nonzero common mass does not imply the sum invertible. Example over either bundled prime: let S swap two coordinates, G_a=(I-aS)^-1, A=G_(1/4), B=G_(1/4)-(24/25)G_(1/5)=(I+S)/15, P=I and D=(45/4)I. Then ADB=J, so both Fourier boundary vectors match. Yet A's normalized first-row signature is (4/5,1/5), while B's normalized first-column signature is (1/2,1/2), so this gate rejects. All coefficients/denominators are valid in the bundled fields and B's mass is 2/15, nonzero. This example is within GreenStage's direct constructor interface; make_stage's separate nonaffine-cycle generator does not construct n=2. The correction is to state the invertible-stage model needed by necessity, or describe this as the specific calibrated sufficient construction outside that model. No assertion is made that this singular example is a full Fourier matrix.
- **Controls/theory limits:** planted transposed/permuted Green pairs pass only the boundary test. Weak-coupling inequalities use exact Fraction arithmetic and positive weighted-average assumptions; they do not automatically cover signed/complex weights or arbitrary strong couplings. Duplicate signature values can allow several matching permutations, so exact recovery of the initially planted inverse permutation is stronger than mere gate success.
- **Dependencies:** `phase33_two_sided` is not bundled inside this single source. Candidate exact helper hash 8d85e9d3f6316fb50caecdd5f475b0cf612c576551a48e833359a0bda88b9d26 was inspected only at lines 1–200 for orientation, prime constants and inverse semantics. That partial dependency read receives no full-read credit. Runtime module resolution is unverified. Unused imports inverse_small and field_rank do not establish dependency coverage.
