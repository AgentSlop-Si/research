# Whole-network Fourier rank certificate: one strict improvement over interval cuts

**Date:** 2026-10-09.  **Finding:** independently checked exact rank obstruction for a *specific* two-stage rank-one quasiseparable Fourier factorization. No faster FFT achieved.

## 1. Research question and context

The earlier work ruled out several families of seemingly attractive speedups: ordinary separated forward/backward scan macro-stages, bounded-condition Green combinations, and gauge-dressed butterfly networks. The extension package found arbitrary endpoint permutations make the old natural-endpoint linear rank bound inapplicable: the ordinary Cooley–Tukey decomposition itself provides two-stage factorizations with growing stage quasiseparable ranks, at larger-than-FFT arithmetic cost. A second extension derived an arbitrary-subset interval-bound condition.

The unresolved class is: exact power-of-two DFTs over arbitrarily fresh inputs, all endpoint/middle permutations allowed, **low-rank nonunitary quasiseparable global stages**, total arithmetic, coefficient preparation, memory and indexing fully charged. Proving a stronger *rank-only necessary condition* is worthwhile, but it does not give any FFT complexity bound unless it can be made universal and tied to algorithmic costs.

## 2. Directed scalar-signal graph and theorem

For each stage `s` and coordinate `j`, introduce scalar input `x[s,j]` and output `y[s,j]` with **capacity 1** each. There are two state registers crossing the left/right and right/left cuts, `f[s,j]` and `b[s,j]`, each of capacity at most `r_s`. Admissible connections include the diagonal `x_j -> y_j`, input-to-register injection, recurrence propagation, and register-to-output transfer. All register recurrences are allowed to use arbitrary coefficient matrices, and adjacent stages are connected using an arbitrary fixed permutation `P_s` of scalar wires. Endpoint input/output orders may also be arbitrary.

A quasiseparable matrix of lower/upper order at most `r_s` admits a forward/backward generator representation with such register widths; see Eidelman–Gohberg and Pernet–Storjohann's quasiseparable generator literature. **The graph-cut criterion is a relaxation:** it assesses each selected minor separately. Satisfying every tested rank inequality does not provide a single compatible assignment of generator coefficients producing all the prescribed Fourier entries.

**Theorem (whole-network rank cut).** Let `M` be a product of `t` quasiseparable stages with ranks `r_1,...,r_t` and the given shuffles/endpoints. For any stage-ordered final output subset `R` and initial input subset `C`, let `c_G(R,C)` be the value of an integer minimum cut in the expanded directed signal graph, connecting a supersource to the inputs `C` and the outputs `R` to a supersink. Then, over any field,

```
rank(M[R,C]) <= c_G(R,C).
```

**Proof sketch:** Each scalar input and output represents at most one independent field element, and each register of dimension `r_s` transmits at most `r_s`. Removing a set of signal vertices/edges whose total capacity is `c` separates the chosen sources from chosen sinks. The remaining chosen outputs depend on the chosen inputs only through these `c` scalar channels. The linear map from selected input columns to selected output rows factors through a space of dimension at most `c`, hence rank at most `c`. This argument is independent of unitarity, entry magnitudes, norms, coefficient signs or intermediate permutations.

The previously proved two-stage multi-interval upper bound

```
rank((S2 P S1)[R,C]) <= |P(R) intersection C| + b(R)*r2 + b(C)*r1
```

is obtained by considering a particular allowed network cut (and bounding crossed states). Thus the optimized whole-network bound is no weaker, and can be **strictly** stronger.

## 3. Explicit Fourier obstruction at N=64

Fix bit-reversal at BOTH endpoints, and the exact middle permutation in `rank_profiles_results.json` for the `n=64, endpoints=bitrev_both` entry. Consider two stages `S2 P S1` both with quasiseparable rank **1**. Define the selected stage-coordinate sets:

```
R = [10..20] union [36..48]        (24 final output positions)
C = [4..11] union [43..61]         (27 initial input positions)
```

For this particular R,C the earlier multi-interval inequality has overlap `9` and four internal boundary crossings each: `9+4*1+4*1=17`. Thus the old upper bound is `17`, insufficient to exclude rank 17.

The full network instead has a recorded explicit cut of capacity `16`. `new_network_certificate_N64.json` stores its complete source-side partition and the 16 crossing scalar edges. An independent script checks the partition's membership constraints and sums capacities to exactly 16. A separate SciPy Dinic flow and NetworkX minimum cut both agree the minimum is 16.

For the same R,C, a **17x17 Fourier minor** is nonzero at primitive 64th roots over BOTH fields:

```
prime 998244353:   determinant = 959841740 (mod prime)
prime 2013265921:  determinant = 1437727086 (mod prime)
```

The *same exact physical row/column indices* are stored in the JSON file and used for both determinants. These modular evaluations certify nonvanishing over the complex numbers: the determinant is an integer polynomial `D(x)` in a 64th root `x`; if it vanished at a primitive complex 64th root, the monic cyclotomic polynomial `Phi_64(x)=x^32+1` would divide `D(x)` over integers, hence `D(alpha)=0` at any primitive 64th root `alpha` in these finite fields, contradicting either nonzero evaluation.

Therefore the Fourier rectangle has rank at least 17, while any two-stage rank-(1,1) scan realization with these fixed orderings has rank at most 16. **Contradiction.** This certificate *strictly improves on the prior interval method for exactly these R,C*.

**Scope:** the result rejects one fixed choice of both endpoints, one fixed internal permutation, and two rank-one stages. It is **not** a theorem covering every permutation, larger stage rank, more stages, all power-of-two lengths, or unrestricted linear circuits.

## 4. Checks on the general channel model

1. The old checkpoint's exact two-stage Cooley–Tukey controls pass random subset mincut checks for sizes 4,16,32. Their stage ranks are increasing and their arithmetic cost grows faster than optimized FFT.
2. The standard exact radix-2 FFT was explicitly represented as `log2(N)` rank-one two-coordinate butterfly stages with internal coordinate shuffles. Every basis vector and eight fresh random inputs agree with an independent exact DFT up to N=64. Its butterfly evaluation uses `3(N/2)log2(N)` modular adds/multiplies in the reference implementation **excluding separate twiddle/root preparation**, not linear.
3. For 420 tests involving fresh randomly generated **actual quasiseparable stage matrices** (t=1,2,3,4), the output/input minor rank was at most the network flow.
4. For 210 tests of true Fourier submatrices through the multistage radix-2 graph, the exact field rank was at most network flow.
5. SciPy's integer Dinic maximum flow agreed with NetworkX's independent implementation over repeated randomized two- and three-stage networks. The stored proof additionally supplies an explicit cut, so correctness does not depend on the optimizer.

All arithmetic for Fourier-minor verification is exact integer arithmetic modulo a prime; each root has verified multiplicative order 64. No floating-point residual is used as proof.

## 5. Rank-two search: unresolved, explicitly negative outcome

A deterministic seeded search evaluated 25,000 R,C pairs across random subsets, single intervals, two separated intervals, unions of up to four intervals, dyadic blocks, and intervals with holes against the rank-(2,2) graph at N=64 with the same endpoint/middle orders. For 4,221 cases where the network flow was below the trivial upper bound `min(|R|,|C|)`, exact modular Fourier rank was checked. **No contradiction was found; the smallest observed cut-rank slack was +1**. These data are in `witness_search_n64_r2.json` and can be reproduced with `python search_witness.py 2 25000`.

This does **not** mean an exact rank-(2,2) Fourier factorization exists. The **min-cut inequalities** overapproximate algebraic feasibility: they bound possible information flow, not whether one assignment of generators can realize all Fourier coefficients simultaneously.

## 6. Next gate (high priority)

Move beyond rank-only necessary conditions to **algebraic compatibility** of the generator parameters across an entire network. Build an exact finite-field parametric realization `S_t P ... S_1`, choose small sizes (N=8,16) and low ranks, calculate tangent/Jacobian rank to identify algebraic dependencies among the output matrix entries, and seek an explicit polynomial identity violated by the corresponding Fourier matrix at a primitive Nth root. An identity must be exact, have a reproducible certificate, and be checked against the classical Cooley–Tukey positive control. Extend or construct scalably; do not extrapolate from small numerical residuals.

A successful FFT construction would require explicit all-N formulas, actual execution on arbitrary fresh inputs, non-gauge factorization, rigorously counted stage generators, twiddles, coefficient preparation and operation/precision costs, and a proof of `o(N log N)` total arithmetic (ideally `O(N)`). Fewer graph stages or no violated mincuts do not establish that.
