# Hero #17 continuation — Delta-Graph, Amortized Union and Spectral Newton Graphs

**Checkpoint:** 10 October 2026  
**Status:** exact finite-field theorems under explicit promises, working raw-input recognizers, independent tests and a scoped reconstruction improvement for structured convolution. **No universal fresh arbitrary-input `O(N)` DFT, no arbitrary multiplication speedup, and no publication-priority claim.**

## 1. Research target and meaningful progress

The original goal is a sequential, **fully charged** `O(N)` Fourier transform for *every arbitrary fresh* input, producing **all N explicit outputs** without relying on previous-input cache hits, uncharged tables, threads or a new quantum hardware oracle. That goal remains unsolved by this checkpoint.

The previous Hero #17 Tensor/Fiber/Graph bundle (`fft_hero17_tensor_fiber_graph_union_2026-10-10.zip`) gave exact linear algorithms for *recognized special inputs*, including QxM fiber matrices with maximum ordinary rank, but required every individual fiber to have sparse M-point Fourier support. It rejected a particular convolution output because it had `S=Q^(3/2)` surviving spectral states.

**New gain:** Replace *per-fiber spectral sparsity* with *sparsity of the **d-th temporal finite differences** of fiber spectra*, while letting each of the first `d` fibers have an arbitrary dense spectrum. The `d`-th difference's total number of Fourier modes, summed over all later fibers, is `R=O(Q)`; it can be highly unbalanced across rows. This is recognized from the raw input in `O(N)` charged work for balanced `N=QM` and fixed `d`, and all N exact transform values are then evaluated in `O(N)` using precomputed geometric/binomial-rational kernels. Separate graph-convolution reconstruction uses the same sparse-difference principle and **accepts the exact adversarial example that the previous state-count criterion rejected**.

Classical foundations include discrete Newton identities, geometric series, finite-field Prony/Berlekamp--Massey, Fourier character orthogonality and batch inversion. These ingredients and structured-transform ideas have extensive prior art. The contribution here is a reproducible combined algorithm, proof and constraint audit, not an originality claim.

## 2. Arithmetic model and accounting

- Let `N=Q*M` be a balanced composite length: `Q^2<=C*N` and `M^2<=C*N` for fixed `C` (therefore `Q,M=Theta(sqrt N)`). Source treats any composite factorization satisfying this condition; no coprimality is necessary. Balanced-factor discovery is an `O(sqrt N)` divisor scan.
- Work exactly over prime field `F_p`, with `N | (p-1)`, `p>N`, `p=N^O(1)`, and a **supplied primitive N-th root** `omega`. Prime modulus and root are standard interface premises; `phase_table` checks order in `O(N)` operations. Generating a primitive root from scratch is not included in the online theorem. The word-RAM has `Theta(log N)`-bit words large enough for a constant number of modular words, unit-cost modular arithmetic and random addressing. For formal field-operation complexity, addition, multiplication and field inversions can be charged separately; any `O(R)` inversions are `O(R log p)` word operations via extended Euclid, absorbed for `R=O(sqrt N)`.
- The online algorithm receives the **complete raw input**, not a precomputed decomposition. It reads, recognizes or rejects, builds roots and reciprocal tables, executes all phase work, and explicitly writes N outputs. Unsupported arbitrary inputs return `None`; there is no claim their spectra are calculated in linear time.
- No FFT/NTT algorithm is called by the online executors. The only dense short transforms in the online code are plainly written `M^2` loops; this is linear in the original N for a fixed number of balanced-length anchors. Test references use slow O(N^2) DFT/convolution and, for one large convolution regression, an independently implemented ordinary NTT **only in the test suite**.
- Finite-field exactness is proven. Conditioning and robust finite-precision complex-arithmetic recognition are not proven; neither is arbitrary-precision bit complexity.

## 3. New general theorem: Spectral Newton-Union

Write the raw signal as interleaved `Q` rows of length `M`:

`y_t[u] = x[t+Q*u]`, for `0<=t<Q`, `0<=u<M`, `N=Q*M`.

Let `eta=omega^Q`, a primitive Mth root. Define the **unnormalized** M-point row DFT

`C_t[h] = sum_{u=0}^{M-1} y_t[u] eta^(-h*u)`, `0<=h<M`.

For some fixed integer `d>=1`, assume the first d raw rows are **arbitrary**; for each `t>=d`, the dth **backward difference** of the raw rows has an M-character representation

`nabla^d y_t[u] = sum_{(h,c) in E_t} c eta^(h*u)`.

The unknown sets `E_t` may have arbitrary, distinct frequencies and unequal sizes; only their **total** support `R=sum_{t=d}^{Q-1}|E_t|` is bounded by `R<=cQ`, with fixed c. Recognizer discovers modes from x; no side metadata.

**Theorem (exact conditional transform, raw input).** For every fixed d and c, every balanced `N=QM` under the stated field/word-RAM model admits a deterministic algorithm which, on an arbitrary raw x, either rejects its proposed `R<=cQ` promise in `O_d(N)` work or recognizes the promise and computes **all N exact DFT coefficients** in `O_{d,c}(N)` work with `O(N)` storage. A slightly more informative charged bound is

`O_d(N + d*M^2 + M*(Q+R) + Q*R + R*log p)`

word operations. For `R=O(Q)`, fixed d, and balanced Q,M this is `O(N)` because `M^2`, `Q^2` and `MQ` are each `O(N)`. The additional `R log p` inversion term is `o(N)` when `p=N^O(1)` and `R=O(sqrt N)`.

### 3.1 Exact identity

By Fourier orthogonality, each recognized difference obeys

`nabla^d C_t[h] = M * sum_{(h',c) in E_t, h'=h} c`.

Use forward Newton coefficients from the first d **dense** row spectra:

`A_j[h] = sum_{i=0}^j (-1)^(j-i) binom(j,i) C_i[h]`, `0<=j<d`.

The discrete Newton identity, proved by applying `nabla^d` and checking initial rows, gives

`C_t[h] = sum_{j=0}^{d-1} binom(t,j) A_j[h] +
           M sum_{a=d}^t sum_{(h',c) in E_a,h'=h} c binom(t-a+d-1,d-1)`.

For output bin `k=h+sM`, `z=omega^(-k)`, the full DFT factors exactly as

`F_N(x)[k] = sum_{t=0}^{Q-1} z^t C_t[h]`.

Define truncated binomial-geometric kernel

`B_{d,L}(z) = sum_{v=0}^{L-1} binom(v+d-1,d-1) z^v`.

Reordering finite sums yields the complete, **not approximate**, output formula:

```
F_N(x)[h+sM]
  = sum_{j=0}^{d-1} A_j[h] z^j B_{j+1,Q-j}(z)
    + M * sum_{event (a,h,c)} c z^a B_{d,Q-a}(z).
```

The exact closed form for z!=1 is

`B_{d,L}(z) = [1 - z^L * sum_{j=0}^{d-1} binom(L+j-1,j)*(1-z)^j] / (1-z)^d`.

At z=1, `B_{d,L}(1) = binom(L+d-1,d)`. This follows from summing a binomial coefficient and extends to all d as an integer polynomial identity; reduction modulo p is exact. For fixed d, a B-evaluation takes `O_d(1)` field operations **provided z^L is looked up**, rather than exponentiated per bin.

The implementation carefully uses the global `omega` powers table for `z`, `z^j`, `z^a`, and `z^L`; it never hides an `O(log N)` modular exponentiation inside a loop over output bins or events. For k!=0, all `(1-z)^(-1)` values are prepared by a single Montgomery-style batch inversion and `O(N)` products. For k=0, the polynomial limit above is used. Exact root-order validation is charged.

### 3.2 Recognition without a supplied decomposition

For each t, build the dth raw difference explicitly (d is fixed, total `O_d(N)` input work). Let `r_t` denote the true M-point DFT support of this length-M difference.

`modes_with_budget` tries caps `1,2,4,...,min(remaining_budget, floor(M/3))` with bounded Berlekamp--Massey, scans **all M roots** to identify modes, recovers coefficients by an exact Vandermonde solver, and **fully verifies every raw difference sample**. A k-character sequence with `k<=M/3` is recovered once the attempted bound reaches k; all doubling attempts cost `O(M*(k+1)+k log p)`.

If the support is larger and the global remaining budget is at least `M/3`, a plainly charged `M^2` direct row DFT is permitted. The work is `O(M * remaining_budget)`, so one fully dense difference is affordable when `M=O(Q)` and the global budget is still `Omega(M)`. If the remaining budget is smaller, recognition simply rejects. All-zero differences cost `O(M)` to check. No false positives are possible because the recovered row representation is checked against every input sample (or found by a direct full short DFT).

Across all accepted rows the total work is `O(M*(Q+R)+R log p)`; on the first rejection, the attempted work is still covered by unspent budget. A `Q=Theta(sqrt N)` total-mode budget suffices for linear complexity even when **one** transition is completely dense, in contrast to a fixed per-row mode bound.

### 3.3 The d=1 and d=2 special cases

- **d=1 Delta-Graph:** first fiber completely arbitrary; each later difference is frequency-sparse. Its output contributions are geometric **suffix interval** sums `(z^a-z^Q)/(1-z)`, with value `Q-a` at z=1. Supports up to a constant number B of unrestricted dense anchor resets by adding independent direct M-point anchor transforms. Charged time `O(N+B*M^2+B*N+M*(Q+R)+Q*R)`, with B fixed.
- **d=2 Acceleration-Graph:** first two fibers arbitrary; the **second** differences are sparse. Output uses truncated arithmetic-geometric sums `(1-(L+1)z^L+L*z^(L+1))/(1-z)^2`. This accepts full-rank examples where **every first difference has a dense Fourier spectrum** and d=1 correctly rejects.
- **d>=3 Newton-Union:** arbitrary dense initial d fibers, total sparse order-d changes. The same exact finite-precision-free algebra works for d=3 and d=4 in the test suite and for any fixed d in the theorem.

### 3.4 Maximum ordinary matrix rank and dense spectra do not defeat the method

Take square `N=Q^2`, `Q=M`, `d<Q`, and choose initial d spectral rows with independent projections onto the first d frequency coordinates. Arrange each subsequent `nabla^d y_t` to be one nonzero character at a **new distinct** frequency `h=t`. The mapping from raw rows to initial rows plus high differences is invertible and lower triangular, so the raw QxQ fiber matrix has **rank Q**, its maximum possible rank. Add generic nonzero shared dense background coefficients so that every raw row can have **all Q spectral coefficients nonzero**. Then R=Q-d, and the exact full DFT still takes `O(N)` word work under the theorem.

This is a new extension relative to the previous project's per-fiber-sparse recognizer: the fibers can each have *dense* spectra, not just dense time-domain values.

## 4. Graph convolution rescued by sparse transitions

Previous `fiber_convolution.py` builds exact output fiber Fourier-character amplitudes `A[t,h]` by matching frequency labels. With fixed r modes per input fiber and balanced Q,M, forming the QxM **full state array** costs `O(N)` including the `O(r^2 Q^2)` edge work.

The previous method reconstructed directly from all nonzero states, costing `O(N+M*S)`, where `S=number of (t,h) with A[t,h]!=0`. If `S` was large it rejected.

**New reconstruction gate:** count instead

`D = nnz(A[0,:]) + sum_{t=1}^{Q-1} nnz(A[t,:]-A[t-1,:])`.

This count and each difference row are discovered by an `O(N)` scan of the already formed state array. Compute the first output row directly using `O(M^2)` arithmetic, then reconstruct successive rows from their parents via just D character updates, plus `O(N)` row writes. Fully charged time is

`O(N + M^2 + M*D)`.

For balanced Q,M and `D=O(Q)`, this is **exact O(N) convolution**, even when S is much larger than Q.

**Previously rejected adversarial graph, now accepted:** for `Q=M=s^2`, set first input's single frequency in fiber t to `h_x(t)=t mod s`, second's to `h_y(t)=floor(t/s)`, all amplitudes 1. The matched graph has exactly `S=s*Q=Q^(3/2)` nonzero states. As a function of t, each of the s output-frequency columns is **piecewise constant with at most one transition**. Therefore `D=s+(s-1)=2s-1=O(s)=O(sqrt Q)`, much smaller than Q, and all output samples are computed in linear time. Exact tests confirm:

| Q=M | N=Q² | S nonzero states | D changes | Outcome |
|---:|---:|---:|---:|---|
| 16 | 256 | 64 | 7 | Accepted, direct O(N²) convolution equality |
| 64 | 4,096 | 512 | 15 | Accepted, independent NTT full-output equality and direct selected checks |
| 256 | 65,536 | 4,096 | 31 | Accepted, event/statistical check; not claimed as a full independent slow-convolution audit |

A counterexample with nonuniform random input amplitudes has large temporal differences and is explicitly rejected by the new gate. This is a conditional reconstruction theorem, not closure of all sparse-fiber inputs under linear-time convolution.

## 5. Information-theoretic boundary — why universal O(N) is still open

Fix order d and global event budget R. Initial d raw rows range over `p^(dM)` possibilities. Each later dth difference is described by at most R nonzero Fourier coordinates among `(Q-d)M` positions, each with a nonzero coefficient. By invertibility of the finite-difference representation, a **rigorous upper bound** on the number of supported raw vectors is

`p^(dM) * sum_{e=0}^R binom((Q-d)M,e) * (p-1)^e`.

There are `p^N` total fresh input vectors. For `Q,M=Theta(sqrt N)`, `d=O(1)`, `R=O(Q)`, and `p>=N`, the supported fraction is at most `p^(-N+O(sqrt N))`, up to fixed factors in the exponent (using `binom(N,e)<=N^e<=p^e`). Uniformly random dense vectors therefore almost surely fail the recognizer, as the tests confirm. Having full ordinary matrix rank and every fiber spectrum dense does **not** mean the family has high input entropy; its spectral **variation** is still constrained.

To represent every arbitrary input by this same bounded-order difference scheme, either d or R must grow substantially. The straightforward executor then pays `d*M^2` or `Q*R`, exceeding the claimed linear bound. This is a **barrier to this family and implementation**, not a complexity lower bound for arbitrary DFT algorithms. A future genuinely universal construction would need a joint evaluator that avoids that growing per-event/per-channel cost.

### Why graph/union/quantum terminology does not smuggle a solution

- **Graph:** a path over physical fiber indices; graph edges encode raw row changes. The convolution branch uses a frequency-matching graph, then a path-difference graph for reconstruction.
- **Union:** merge spectral changes into root+edge / Newton basis descriptions; only the distinct change events are evaluated.
- **Sparse table:** the global length-N root and reciprocal tables turn each geometric/binomial interval into a constant-work lookup plus field operations. Table construction is charged; the table is O(N) entries, not an all-input oracle.
- **Quantum-inspired phase:** the root-of-unity character group models constructive/destructive Fourier phases exactly; **there is no quantum hardware speedup or free classical readout of amplitudes**.

## 7. Next decisive target

The unresolved case is still a completely fresh input whose polyphase frequency channels have unrelated **dense** high-order differences: `R=Theta(N)` for every fixed d. The current union executor costs `Q*R=Theta(N sqrt N)`, while FFT-style channel evaluation costs roughly `Theta(N log Q)`.

A meaningful next theorem must compress **all** these dense channel contributions into an input-independent shared arithmetic graph without hiding a new FFT, table of all inputs, nonuniform constants with uncharged preparation, or quantum output-readout. We recommend using the exact `newton_union.py` identity as a sharply defined testbed: propose a joint evaluator for the event matrix and compare it against the `R*Q` cost on random full-support instances, not just slowly varying signal families.
