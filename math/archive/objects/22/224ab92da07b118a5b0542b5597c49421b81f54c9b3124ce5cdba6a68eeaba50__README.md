# Phase 24 — sorting does not give free Fourier reuse

**Research outcome:** A precise rank theorem quantifies the cost hidden by binary stable sorting. A finite-field Woodbury implementation then shows when *small* permutation changes can be handled using a genuinely `O(N)` Green correction. No arbitrary-input FFT speedup is claimed.

Start with `THEOREM.md`, then run:

```bash
python -m unittest discover -s tests -v
python audit.py
```

Key files:

- `phase24_ordering.py`: exact sorting rank, rank of differences of permutation matrices, all-stride probability bound, exact modular Woodbury correction.
- `phase23_resolvent.py`: retained, independently verified Phase 23 implementation used as reference.
- `tests/test_phase24.py`: exhaustive and independent modular tests.
- `audit.py` and `audit.json`: standalone reproducible experiment results.
- `CHECKPOINT.md`: chain-safe continuation instructions.
- `previous_full_phase23_checkpoint.zip`: complete nested research chain through Phase 23.

All arithmetic is exact over a finite field for the test implementation. This does not imply floating-point numerical stability, sub-`NlogN` arithmetic for arbitrary inputs, or an improved bit-complexity bound for integer multiplication.
