# Exact reuse across a cyclic feedback graph

This package extends the previous acyclic target-difference compiler to an actual
cycle with a rank-one closing edge. It uses no additional T action to handle the
feedback, including in coefficient preparation. It also implements changes to
the loop gain as exact rank-one corrections with zero new transforms, after the
initial computation has been charged. The full fresh arbitrary-input exact FFT
goal remains unresolved.

## Closed graph and its solution

Retain the exact q-Weyl operators T=H_q(A), K=I+B, J=I+C, with T K=J T and the
essential finite corner in C. Let R be the number of target banks. An injection
at vertex r contributes b_r=T x_r; absent injections contribute zero. Several
vertices may have genuinely independent source banks. Close the last target to
the first by the edge u e_j^transpose:

    z_0 = b_0 + u (z_(R-1))_j,
    z_r = b_r + J z_(r-1),    1<=r<R.

Let w be the solution without the closing edge:

    w_0=b_0,  w_r=b_r+J w_(r-1).

Define a=(J^transpose)^(R-1)e_j, beta=a^transpose u and kappa=1-beta. If kappa is
nonzero, the unique closed solution is

    z_r = w_r + J^r u * (e_j^transpose w_(R-1))/kappa.       (1)

Substitution proves both equations. Uniqueness follows because the homogeneous
feedback scalar s must satisfy kappa*s=0. This is a rank-one inverse calculation,
not an iterative convergence claim. When kappa=0 the problem can be inconsistent
or nonunique, so the compiler rejects it. For example b_0=u and other b_r=0 are
inconsistent in that case: the closing scalar equation becomes s=1+s.

## Covariance makes feedback preparation cheap

For an injection at vertex r,

    e_j^transpose J^(R-1-r) T x_r = ell_r^transpose x_r,
    ell_r=(K^transpose)^(R-1-r) T^transpose e_j.

The vector T^transpose e_j is exactly a row of the known Toeplitz kernel:
its ith component is t_(j-i) for i<=j and zero otherwise. Preparing it requires
only O(N) kernel accesses, no T or T^transpose action. The other ell_r follow by
sparse K^transpose steps. Similarly, sparse J^transpose steps prepare a.

Thus the feedback scalar in (1) is the known linear functional

    s=(sum_over_injections ell_r^transpose x_r)/kappa.

An arbitrary dense observation vector v in place of e_j would require preparing
T^transpose v; this package does not assume that action is cheap. The fast
preparation claim is for the specified coordinate-observation closing edge.

On top of the existing q-kernel plan, coefficient preparation uses exactly

- (R-1)(3N-1)+2N multiplications;
- (R-1)(2N-1)+N-1 additions;
- one subtraction and one constant inversion.

It stores O(RN) field coefficients. Combining the rows for the selected source
banks adds M*N coefficient accumulations for M injections. These costs are
reported separately from online gate counts. No input-dependent inverse occurs.

## Reversible implementation on arbitrary initial registers

All source banks, targets, and the optional unused workspace w may initially
contain arbitrary values. The compiler performs:

1. Descending r: y_r -= J y_(r-1).
2. For each injection, y_r += T x_r.
3. Add u*s to y_0 using one rank-one cross-bank update.
4. Ascending r: y_r += J y_(r-1).

The descending/ascending passes cancel all original target contributions and
propagate the new increments. Step 3 supplies the missing closing-edge forcing.
Consequently the net map is y_r <- y_r+z_r, with every source and w restored.
There is one ADD_T per supplied injection and zero additional ADD_T calls for
feedback. The implementation does not claim to collapse unrelated independent
sources into a single transform; their first transform costs are retained.

To implement y += v*(ell^transpose x) without clean scratch, choose a nonzero
coefficient ell_p. Reversibly replace source coordinate x_p by ell^transpose x:
scale x_p by ell_p and add the other weighted source coordinates. Add multiples
of this pivot into the target, then reverse the source operations. This works
even when the original pivot value is zero and never divides by an input value.
With m nonzero source coefficients and k nonzero target coefficients, its cost
is exactly 6m+3k-4 scalar instructions: each shear expands to two source scalings
and one addition, and the pivot contributes two more scalings. A zero update is
omitted. One constant pivot inverse is prepared.

Let M be the number of injections. Before the feedback correction, the online
cost is

    3 M N(N+1)/2 + 2(R-1)(6N-3).

Add the measured 6m+3k-4 rank-one correction cost. For a single dense source and
dense u, the feedback overhead is at most 9N-4 instructions. For M independent
source banks it is at most 6MN+3N-4. No dense feedback matrix is built.

The unchanged baseline prepares the q-kernel and sparse gates using O(N) constant
field operations/inversions plus root generation and checking. Gate emission,
constant reciprocal preparation in scalar expansion, and materialized circuit
storage are O(the emitted instruction count). They are real setup costs, not
free preprocessing. All reported bounds use unit exact field arithmetic and
explicit word indexing; they are not bit-complexity or floating-point stability
bounds. The expensive reference ADD_T is still quadratic.

## Changing the feedback gain: no new transform

Keep sources, J, u and j fixed, but multiply the closing edge by a gain gamma.
Let c_r=J^r u and let s_0=sum ell_r^transpose x_r, before division. Then

    z_r(gamma)=w_r + gamma*c_r*s_0/(1-gamma*beta).

For two nonsingular gains eta and gamma,

    z_r(gamma)-z_r(eta)
       = (gamma-eta)*c_r*s_0 /
         ((1-gamma*beta)(1-eta*beta)).                       (2)

The gain-update compiler emits one rank-one cross-bank update to all R target
banks, with no ADD_T and no graph elimination passes. Every source is restored;
arbitrary preexisting target content is preserved. Applied after the first
charged closed-graph computation, it produces exactly the result for the new
gain.

Preparing (2) from the stored graph plan costs (3R-2)N+4 multiplications,
(R-1)N additions, four subtractions and one constant inverse, plus M*N source-row
accumulations. This implementation recomputes and charges the response vectors
c_r for each update. Its dense online bound is 6MN+3RN-4 instructions, where M
is the number of independent source banks. All R*N target outputs are updated.
Old or new singular gains are invalid.
Both compilers reject empty injection lists, out-of-range vertices and negative
source-bank indices before emitting register operations.

## Verification, limits, and prior art

Run `python run_audit.py`. The standard-library-only audit uses N=2,4,8,
R=1,2,4, and primes 65537 and 998244353. It checks one root and genuinely
independent roots, all source/target/workspace basis vectors, arbitrary mixed
states, scalar expansion, inverse recovery, exact closed-cycle residuals,
coefficient preparation counts, instruction counts, and gain updates after the
initial computation. The captured run passes 36 cases, 840 full-register basis
vectors for each of the initial and gain-update maps, 144 random full states,
and 18 singular-feedback rejections. Observation coordinate j=N-1 is used in
these tests; the displayed proof applies to every coordinate j.
The independent review additionally checks observation coordinate zero, repeated
source banks, non-root injections, zero feedback, zero/equal gains, a zero-valued
source pivot, zero rank-one updates, eight invalid-injection rejections across
both compilers, and two singular gain-endpoint rejections. See
`INDEPENDENT_REVIEW.md` for its scope and the corrected validation issue.

The initial computation has not become a sub-N-log-N arbitrary FFT. The new
reuse is for a specified graph with a rank-one closing edge or subsequent gain
changes. General dense feedback, arbitrary new sources, unstable floating-point
execution, and arbitrary cyclic networks are not covered by the fast claims.

Rank-one inverse updates are classical; no global novelty is claimed. Primary
historical context: Jack Sherman and Winifred J. Morrison, *Adjustment of an
Inverse Matrix Corresponding to a Change in One Element of a Given Matrix*,
Annals of Mathematical Statistics 21(1), 124-127 (1950),
https://doi.org/10.1214/aoms/1177729893 . The project-specific contribution here is
the cheap row preparation through T K=J T, its exact arbitrary-state reversible
compiler, and the explicitly charged feedback-gain correction.
