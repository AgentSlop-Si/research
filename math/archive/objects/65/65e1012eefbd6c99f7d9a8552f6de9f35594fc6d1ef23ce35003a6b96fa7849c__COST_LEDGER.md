# Phase 27 scalar-operation and cold-setup ledger

**Domain:** exact root-rich prime-field linear transform, not complex floating point. A nonidentity field-scalar multiplication is one field operation even when the scalar is a fourth root of unity.

Each 3-point codelet: 6 additions + 2 multiplications = 8.

Each 5-point Winograd codelet: 17 additions + 5 multiplications = 22.

Each 15-point `GT(3,5)` codelet: 5 × 8 + 3 × 22 = 106, exactly 81 additions and 25 multiplications. A CT `(3,5)` implementation using these same two short codelets pays 8 more cross twiddle multiplications = 114.

For `G=2^t, N=15G`:

- Warm GT15 additions = `15 G t + 81 G`.
- Warm GT15 multiplications = `(15G/2)t+10G+15`.
- Warm GT15 total = `(45G/2)t+91G+15`.
- Compared to *outer CT with the same GT15 codelet*: exactly `14(G−1)` data multiplications saved.
- Compared to *outer CT with inner CT(3,5) codelet*: exactly `22G−14` data multiplications saved.

This is an improvement over **specified comparators**, not a new optimal NTT or better worst-case asymptotic bound.

**Actual charged cold setup.** Plan construction performs binary powering to obtain the supplied transform root from a known field generator, derives all subroots, builds the dyadic table, and prepares the Winograd coefficients once. Its operation counts are in `BENCHMARK_PHASE27.json`. CT additionally builds length-`N` and length-15 twiddle tables; for *these implementations*, the extra setup is `N+13` field multiplications. These table choices are not claimed to be optimal; a different CT could reduce setup through a different twiddle generator.

The order/primality certificates, integer indexing (`CRT` inverses and modular indexing), data movement, and actual machine bit-cost remain outside the field-operation column; the code separately tracks partial word reads and writes but does not claim a complete byte-traffic count. Both warm algorithms are `Theta(NlogN)` and use `O(N)` vector storage. The cold model is one transform using newly constructed plans, **not** a streaming plan reused over many calls. Roots must exist in the stated prime field, so `15G | p−1`.
