# Static review: Green gauges, rank profiles and regression controls

Twelve exact source bodies were read completely as inert text, without executing, importing, compiling or parsing supplied programs. The coverage ledger binds every byte and line count. The frozen inventory and original sources remain unchanged. These are finite controls, helper implementations and numerical probes; their names do not confer independent historical execution credit.

## Findings worth retaining

1. Radix2Control construction computes bitrev(n) inside a length-n list comprehension. That repeats the entire bit-reversal list n times, giving quadratic-times-logarithmic bit/string preparation in this implementation. Its operation_count counts only conventional butterfly arithmetic, excluding this setup, root/twiddle preparation, indexing and allocations. The transform remains a classical FFT control, not a new asymptotic claim.
2. The modular-minor unittest accepts an empty field_evidence list after checking two top-level constants. It also does not validate that supplied row/column sets match the declared intervals, that the minor has the claimed dimension, or that there are the intended two fields. With fixed archived input, separate certificate construction/review can supply these facts; the test alone is not an adversarial certificate validator.
3. Tridiagonal plans correctly reject zero Thomas pivots but can reject an invertible tridiagonal matrix that requires pivoting. For example [[0,1],[1,1]] is invertible over the fixed field yet has a zero initial pivot. This is an explicit solver-domain limitation, not a false result on an accepted plan. Prime-modulus validity and compatible plans are caller assumptions.
4. Numerical real-conditioning and Torch synthesis routines are finite floating-point checks. Neither numerical optimizer failure nor small residual proves an exact existence/nonexistence theorem. The synthesis routine does not return the fitted coefficients for exact reconstruction.
5. Assertion-based archive/control routines can emit literal OK/PASS fields under optimized Python with checks removed. In contrast, unittest self.assert... calls remain active; do not conflate those with Python assert statements. A subprocess runner checking return codes still depends on the child tests' actual acceptance conditions.

### fc769bc1ba6668075c49f322ffb6aff4f5489343bcf1b5d76a112a44b03e60d1 — green_stages.py

139 lines /4536 bytes. Thomas factorization, forward solve and back substitution have the correct signs. Plan construction validates lengths, requires nonzero pivots and precomputes inverses using Fermat powers. The two-Green inverse identity is U(T+U)^−1T and does not require commutation, provided the supplied third plan really represents T+U. The implementation does not check that relationship, common modulus, or field primality. Its fixed families T=3I−adjacency, U=4I−adjacency and V=7I−2adjacency satisfy it. Over reals they are SPD; that alone does not guarantee modular pivots at every length, and the docstring limits finite-field acceptance to tested lengths. Apply costs O(N) scalar field operations after planning; this source performs O(N) exponentiation-based inversions during setup, so growing-modulus bit cost is not constant. Dense basis_matrix/inverse/rank/cut utilities are separate quadratic/cubic-or-higher checks. Rectangular shape checks are incomplete and support_count treats raw Python nonzero values, not residues modulo p.

### 6487084b522c91943f913447ce25a1b6109d263a7b02548f398789be8646fb57 — rank_profile_optimizer.py

90 lines /3343 bytes. Computes modular Fourier prefix-corner ranks and overlap counts, then heuristically minimizes the strongest necessary two-stage rank gap over permutations. Rank profiles involve repeated dense eliminations; each score constructs a dense overlap matrix and cumulative sums. The source explicitly says a low score means a weak obstruction, not a factorization. It is not an exact global minimax solver despite its exact modular scoring. Initialization is not entered into best until an iteration; iterations<5 leaves best=None, and n<2 invalidates pair sampling. Input/output orders and initial permutation are assumed valid. The secondary score and occasional uphill step are search heuristics. Fixed finite-field ranks can give valid nonzero-minor lower witnesses for characteristic zero, but exact equality of an entire complex rank profile requires separate theory/certificates. Complementary-rank redundancy is a mathematical assumption, not independently checked by this source.

### cb732187d10a8f66c7e1baf89508d8cd5c4642a218a56025776efc3366504421 — rank_certificate.py

95 lines /4113 bytes. Exact Python-integer elimination tracks original pivot row/column indices and rechecks the selected minor. Python assertions enforce the fixed expected overlap/ranks/bound; optimized execution can still print a certificate. A rank-zero empty minor convention det[]=1 is mathematically standard here, but higher-level validators must enforce requested positive dimensions. The source is a constructor for one fixture, not a general external-certificate verifier.
