# Chain checkpoint — all-length dyadic lift v10

**Canonical bundle:** `fft_all_length_lift_v10.zip`

## Goal

Fresh arbitrary dense input, every Fourier output explicit, sequential work below `N log N`, with the speedup inherited from the project’s unit-step chirp evaluator.

## New bridge

For arbitrary `N`, set `Q=2^ceil(log2 N)<2N`. Map `k/N` to its nearest dyadic frequency `j_k/Q`, with offset `theta_k in [-1/2,1/2]`.

Use

`exp(-2*pi*i*s*theta) = J_0(pi*s) + 2 sum_{r>=1} (-i)^r J_r(pi*s) T_r(2 theta)`.

A rank-`R` truncation has a certified superexponential tail `tau_R`. Each term is one dyadic `Q`-DFT of a Bessel-weighted input.

## Key composition identity

Use the same v9 random projection for every term. For each final output `k`, all term errors combine into one v9 row applied to

`z_k[n] = x[n] p_R(n/Q, theta_k)`.

Therefore

`E|Xhat_k-Xbar_k|^2 <= (M/N)(1+tau_R)^2 ||x||_2^2`,

where `M=Theta(log Q)` is the v9 dyadic block size. The denominator is the original arbitrary `N`.

## Theorems

### Fixed epsilon

For every fixed `epsilon>0`, constant Bessel rank and three randomized rows give

`T=O_epsilon(N)`, `S=O(N)`,

`||Xtilde-U_Nx||_inf <= epsilon ||x||_2`,

with failure `O((log N)^2/(epsilon^4 N))`.

### Shrinking error

For fixed `a>=0` and integer `s>1+a`, `2s-1` rows and

`R=Theta(log N/log log N)`

give

`T=O(N log N/log log N)=o(N log N)`, `S=O(N)`,

and with probability at least `1-N^-a`,

`||Xtilde-U_Nx||_inf = O(sqrt(log N) N^[-1/2+(1+a)/(2s)] ||x||_2)`.
