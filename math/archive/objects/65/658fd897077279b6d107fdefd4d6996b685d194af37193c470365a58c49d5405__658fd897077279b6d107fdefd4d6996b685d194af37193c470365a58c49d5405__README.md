# Hero #17 — Phase 7: Fourier Rectangle-Union Gate

Exact study of the independent-block shortcut to a universal linear FFT.

## Central result

For `N >= 2`, the minimum total endpoint incidence of any **disjoint rank-one rectangular tiling** of the full Fourier matrix is exactly

`N * min_{d | N}(d + N/d)`.

For perfect-square N, this equals `2 N^(3/2)`. Higher-rank factorized tiles with declared dense-factor cost `r(a+b)` satisfy the same sharp bound over the complex numbers at square lengths. This is **not a lower bound** on arbitrary FFT circuits; cross-block sharing recovers the classical Cooley–Tukey FFT.

## Reproduce

```bash
cd hero17_phase7_rect_union
python -m unittest -v test_phase7.py
python independent_audit.py
python rank_r_experiment.py  # optional, scipy MILP
```

Requirements: Python 3.10+, NumPy (complex stable-rank regression) and SciPy (independent MILP audits). The core `phase7.py` is pure Python/stdlib.

Files: `RESEARCH.md` for full proofs and scope, `phase7.py` for exact modular executors, `test_phase7.py` for 11 groups, `independent_audit.py` and `AUDIT_RESULTS.json` for independent results, `rank_r_experiment.py` for the exploratory higher-rank tile problem, `CHAIN_CHECKPOINT.md` for continuity, and `SHA256SUMS.txt` for integrity.

All roots of unity are supplied to the online arithmetic routines. Offline finite-field test fixture generation is not an FFT primitive.
