# Hero #1 Phase 14 — orthogonal-bank certificates, noncommuting chirp unions, and a Green forcing obstruction

**Research date: 2026-10-10. Status: exact-arithmetic identities + reproducible tests, NOT an arbitrary-input sub-`N log N` FFT.**

## 0. Scope and exact-arithmetic model

Normalize `F_N` by `1/sqrt(N)`. Work first over complex numbers with exact roots, additions, multiplications, comparisons and inverses; arithmetic complexity counts *all* data-dependent scalar work. Root-table generation and materialization, per-column state preparation, `K`-point and odd-part FFTs, scans, Gram solves, and all output writes must be charged. The supplied NumPy implementation uses float64 and ordinary short FFT backends. It is **not a validated finite-precision/bit-complexity algorithm**, and an exact-arithmetic energy identity does not by itself certify the numeric float64 output. Numerical tests are diagnostic; an independent finite-field interpreter checks the algebra.

Let `N=Gm`, with `G=2^v2(N)` and odd `m`; for `G=1` the algorithm falls back to the conventional length-`m` FFT. For `G>=2` choose `M|G`, `K=G/M>=M`, with M a power of two. The input is indexed as `x_s[rM+u] = x[m(rM+u)+s]` for `0<=s<m`, `0<=r<K`, `0<=u<M`. The frequency output is indexed `k=k1+G*k2`. The Cooley–Tukey decomposition reads

`X[k1+G*k2] = [F_m( (F_G x_s)[k1] exp(-2πi k1 s/N))_{s=0}^{m-1}][k2]`.

The fast dyadic chirp decoder below is inherited unchanged in mathematical content from the v9–v13 project and *uses one K-point FFT and a G-step signed scan per state*. The primitive Gth-root table can be made with **one root and O(G) complex multiplications**, rather than treating an O(G)-long list of transcendental exponentials as free. The Nth-root twiddle table costs O(N) arithmetic. `one_root_chirp.py` supplies a fully explicit float64 version; bit-accurate precision analysis remains separate.

## 1. A local chirp decomposition

For any state `(a,beta)` with gcd(a,G)=1, let `zeta=exp(2πi/G)` and

`S_{a,beta}[r,u] = zeta^(a*C(u,2)+(a M r + beta)u)`, `C(u,2)=u(u-1)/2`.

Put `v_{a,beta,r}[u] = conjugate(S_{a,beta}[r,u])`. Fix q states `(a_i,beta_i)` for each input column s. In block r, form `V_{s,r}` whose q columns are `v_{a_i,beta_i,r}`. Assume these columns are linearly independent, `q<=M`, and set

`Gamma_{s,r}=V_{s,r}^* V_{s,r}`, `b_{s,r}=V_{s,r}^* x_{s,r}`, `c_{s,r}=Gamma_{s,r}^-1 b_{s,r}`.

The orthogonal projector onto the selected chirp union is

`Pi_{s,r} = V_{s,r} (V_{s,r}^*V_{s,r})^-1 V_{s,r}^*`.

Write `Pi` for the direct sum over all s,r. Its rank is `sum_{s,r} q_s = K sum_s q_s`. It is self-adjoint and idempotent. The projected input is exactly `Pi x`.

**Theorem A (noncommuting chirp-union evaluator).** Define the K-vector `c_{s,i}[r]` from the i-th component of the local Gram solve. The inherited unit-step dyadic decoder on the state `(a_i,beta_i)` gives the normalized `G`-point transform of the length-G signal

`u_{s,i}[rM+u] = conjugate(S_{a_i,beta_i}[r,u]) c_{s,i}[r]`.

Sum the q decoded outputs for column s and do the usual *single shared* odd-part `m`-point FFT layer. The result is exactly `F_N Pi x` for every x. Since F_N is unitary,

`||F_N x - F_N Pi x||_2^2 = ||x-Pi x||_2^2 = ||x||_2^2 - sum_{s,r} b_{s,r}^* Gamma_{s,r}^-1 b_{s,r}`. (**A.1**)

Thus both the approximation and its complete vector squared-error value are determined without calculating a full Fourier reference. Whenever every x block belongs to the chosen local span, `Pi x=x`, and the algorithm computes *all N Fourier coefficients exactly* (under the stated exact-arithmetic model). Such supported inputs are generally **dense** in physical coordinates but lie in a proper subspace of rank `K sum_s q_s < N` if all q_s<M. This does **not** compute the exact transform of arbitrary fresh inputs.

**Proof.** `Gamma` is positive definite, so `Pi^*=Pi` and `Pi^2=Pi`. Gram coefficients reconstruct `Pi x` as the stated sum of q chirp-modulated K-block streams. By linearity, summing their decoded G-point transforms equals `F_G (Pi x)_s`; the exact Cooley–Tukey factorization finishes `F_N Pi x`. The Pythagorean identity for the orthogonal projector and Parseval for F_N prove (A.1). No approximate phase truncation or probabilistic argument occurs.

### Arithmetic inventory (not a disguised complete FFT)

For each s, building phases/b coefficients is O(q_s G), building all q-by-q Gram matrices is O(q_s^2 G), and their K inversions/solves cost O(K q_s^3); the q_s decoders cost O(q_s G + q_s K log(K+1)). With one shared root table, one twiddle table, final short odd transforms and output writes, a conservative total is

`O(N + N log(m+1) + G sum_s(q_s+q_s^2) + K sum_s(q_s log(K+1)+q_s^3))`.

This includes a full phase-table generation cost and all data movement at O(N) per constant number of streams. For **fixed odd m, fixed bounded q=max_s q_s, M=Theta(log G)** and `K>=M`, the total is `O(N)` arithmetic per fresh *promised-structure* input, with O(N) working storage. If q=M is required for arbitrary inputs, the stated inventory no longer improves on FFT. This is **not a worst-case general O(N) result**. The floating implementation uses `np.fft.fft` only on the **K- and m-point** subproblems; this work is explicitly charged.

### Noncommutation is genuine but not sufficient

For two local *normalized* chirp vectors u,v, let `Q=uu^*`, `R=vv^*`, and `c=|u^*v|`. Then the exact relation

`||QR-RQ||_F^2 = 2c^2(1-c^2)`

shows their projectors fail to commute when `0<c<1`. The 2x2 Gram matrix has eigenvalues `M(1+c)` and `M(1-c)`; its spectral condition number is `(1+c)/(1-c)`. The selected `a1=1,beta1=3s`, `a2=1+G/4,beta2=3s+1` at G=128, M=8 has `c≈0.050190887`, commutator Frobenius norm `≈0.070891172`, and condition number `≈1.10568626`. Gram overlap correction is essential: simply adding two rank-one projectors double counts their shared component. These identities do not make an M-dimensional generic block describable by q=2 coefficients.

## 2. Orthogonal beta banks: adaptive optimum and faster special case

Fix a and beta for each s; take states `beta_t=beta+tK (mod G)` for t=0..M-1. Their local chirp vectors satisfy

`v_t[u]=v_0[u] exp(-2πi t u/M)`.

Thus `v_t^*v_{t'}=M delta_tt'`, and `Q_{s,t}=v_t v_t^*/M` are pairwise orthogonal rank-one projectors on every M-block. Their block sums resolve the identity: `sum_t Q_{s,t}=I`. Across all K blocks per column, rank(Q_{s,t})=K.

The unnormalized compressed coefficients are

`d_{s,t}[r] = sum_{u=0}^{M-1} S_{s,0}[r,u] exp(+2πi t u/M) x_s[rM+u]`.

A bank's captured energy is

`E_{s,t}=||d_{s,t}||_2^2/M`, with `sum_{s,t} E_{s,t}=||x||_2^2`.

For any selection `B_s` of bank IDs per input column, the output

`Y_B=(1/M) sum_s sum_{t in B_s} [mixed-radix Fourier of the s-th chirp projector]`

is `F_N Q_B x`, and

`||F_N x-Y_B||_2^2 = ||x||_2^2 - sum_s sum_{t in B_s} E_{s,t}`. (**B.1**)

This yields two modes:

- **Known-mask recovery** (`known_banks`): calculate only selected d vectors, decode them, combine all selected stage outputs *before* performing the final m-point FFTs, and calculate the captured energies on the way. For L selected column-bank pairs the cost is `O(N + L(G+K log(K+1))+N log(m+1))`. With L=O(m), fixed m and M~log G, this is O(N). The error-energy expression is available for every input, not only promised x.
- **Adaptive bank selection** (`analyze_banks`, `budget_mask`, `evaluate_mask`): compute *all* d coefficients by K independent short inverse length-M Fourier transforms per input column, at `O(N log M)` arithmetic and O(N) space. Keep the globally highest-energy bank-column pairs. For every fixed bank count L, this minimizes (B.1) over **all bank subsets** with L pairs. Data is then decoded with L long scans, and the odd-part FFT is run just once. Sorting the mM measured bank energies costs `O(mM log(mM))`; this cost is explicitly included in the experimental proxy. For `M=Theta(log G)`, the screening stage is `O(N log log G)`, not O(N). If the chosen bank set is small and m fixed, the *complete* adaptive procedure has this bound. It becomes O(N log G) for worst-case banks and is not an all-input sub-FFT claim.

**Proof of optimality among fixed-size orthogonal bank selections.** The mutually orthogonal ranges give exactly additive captured energies. The error is total energy minus captured energy; hence selecting the L largest E values is optimal by exchange of smaller values with larger values. This does not claim optimality among all possible chirp states or general algorithms.

**Sharp adversarial case.** Choose x supported at local position `u=0` in every length-M block with equal amplitudes. Since S[r,0]=1 for every state, all mM bank energies are equal. To guarantee relative full-vector error <=epsilon, the scheme must retain at least `(1-epsilon^2)mM` banks. Thus a dense-in-frequency, sparse-in-time input forces essentially all M scans when epsilon is small. The new algorithm is an honest data-adaptive compressor, not a generic sub-FFT method.

## 3. A stronger fixed-frame minimax obstruction (also noncommuting)

Let V be any fixed M-by-q full-column-rank local chirp family, not necessarily orthogonal. Its orthogonal projector Pi has rank q. Its diagonal leverage scores `ell_u=e_u^* Pi e_u` obey `0<=ell_u<=1`, and `sum_u ell_u=tr(Pi)=q`. Some u therefore has `ell_u<=q/M`.

Choose the impulse input `x=e_u` in that local block. Its captured energy is `ell_u` and its residual satisfies

`||F_N x - F_N Pi x||_2^2 >= (1-q/M)||x||_2^2`. (**C.1**)

For any *input-independent* family with at most q chirp states in every block, a sparse nonzero input (one carefully selected coordinate) witnesses a worst-case relative error at least `sqrt(1-q/M)`. To guarantee relative error <=epsilon for **every input using only this fixed local projection**, one needs `q>=M(1-epsilon^2)`; exact recovery of every input requires q=M. The orthogonal beta-bank choice meets the leverage average exactly on every coordinate, making the bound sharp in this architecture. `leverage_gate.py` constructs witnesses and verifies the formula.

**Scope:** this is NOT a lower bound for arbitrary FFT algorithms, nor for arbitrary state selection after inspecting the whole input. It is a rank/leverage gate against a fixed q-stream projection architecture.

### A sketch-only *adaptive decoder* obstruction

Even if a decoder chooses the next rank-`N/M` sketch after seeing the preceding sketch outputs, r<M sketch-only stages cannot recover arbitrary x exactly by any postprocessing, even nonlinear: follow the deterministic zero-input transcript; the r linear operators chosen along it have joint rank at most rN/M<N. Pick a nonzero h in their common kernel. h generates the same zero transcript, so the decoder cannot distinguish x=0 from x=h. This assumes the decoder's state choices depend **only on the sketch observations**; if it directly reads x or performs additional independent measurements, the conclusion does not apply. Randomized success-probability guarantees across random seeds also require separate quantifiers.

## 3A. Stationary Toeplitz **full-rank** noncommuting frame (the decisive new exact control)

The q-slope Gram construction above has a particularly useful **input-independent factorization**. Fix `G=K M`, with powers of two, `K>=M>=2`; let `zeta=exp(2*pi*i/G)`. For each input column s choose q state parameters, for `i=0,...,q-1`,

`a_i=1+i K`, `beta_{s,i}=3s+i(K+1) mod G`.

Each `a_i` is an **odd unit modulo G** (since K is even). Define the length-M phase nodes

`z_u = zeta^(-[K*C(u,2)+(K+1)u])`, `0<=u<M`,

and the `M x q` Vandermonde-type frame `W[u,i]=z_u^i`. For local input block r, the q conjugated chirp vectors factor **exactly** as

`V_{s,r}=D_{s,r} W`, where `D_{s,r}[u,u]=zeta^(-[C(u,2)+(M r+3s)u])`.

Every `D_{s,r}` is unitary diagonal. Hence every local Gram is the SAME matrix,

`Gamma_{s,r}=V_{s,r}^* V_{s,r}=W^*W=Gamma`,

independent of s, r and x. Furthermore,

`Gamma[i,j]=sum_u z_u^(j-i)`

is **Hermitian Toeplitz**; one q-by-q factorization/solve matrix can be prepared and reused on every input block. Building the q coefficient streams becomes a shared Vandermonde operation `b=W^* D^* x` followed by the same Gamma solve. It does not require O(Km) independently formed dense Gram matrices.

**Theorem D (all-size full-rank chart).** The nodes are pairwise distinct for every allowed K>=M. Indeed their integer exponents

`E(u)=K*C(u,2)+(K+1)u = K*(C(u,2)+u)+u`

satisfy `E(u) mod K = u`. As `0<=u<M<=K`, the `E(u)` and thus `z_u` are distinct. Every M-by-q Vandermonde subframe `W` therefore has rank q, and the **q=M frame is invertible**. Consequently the exact-arithmetic stationary Gram evaluator with q=M applies `F_N` to **every** x, not just structured inputs. Its output agrees with the ordinary Fourier transform for arbitrary complex data.

The full set is genuinely noncommuting: if all rank-one column projectors were commuting, full linear independence would make the columns orthogonal and force `W^*W=M I`. Then the rows of the square unitary-scaled W would also be orthogonal; the vanishing geometric sums between distinct rows would require every ratio `z_u/z_v` to be an Mth root of unity, i.e. every exponent difference `E(u)-E(v)` divisible by K. But `E(u)-E(v) mod K=u-v` is nonzero for u!=v, contradiction. Thus the **Gram has a nonzero off-diagonal** and at least one projector commutator is nonzero. This is not restricted to sampled instances.

**Accounting is decisive.** The shared W/Gram setup is `O(M q^2+q^3)` basic arithmetic in a naive implementation; the per-input Gram coefficient work is `O(N q+(N/M)q^2)`, plus **q separate long scans**, `O(q N)`, and `O(q (N/M) log(G/M))` shorter-FFT arithmetic and a shared `O(N log(m+1))` final stage. For q=M and M=Theta(logG), the algorithm is `O(N log G +N log(m+1))`, **not** `o(N log N)` when m is fixed. A stationary Gram saves repeated matrix setup, but the exact full-rank q=M construction does not solve the joint-decoder sharing challenge. The computed condition number is not proved uniformly bounded as M,G increase; exact algebraic invertibility is separate from stable finite precision.

**Explicit graph-union collision gate.** The a_i scan's coordinate at clock j is `idx_i(j)=(1+iK)j mod G = j + K*(ij mod M)`. At fixed j the M channels therefore have precisely `M/gcd(j,M)` distinct destinations. For M=2^h, summing over all residue classes j modulo M gives exactly `(2M^2+1)/3` distinct *(clock,residue-of-destination)* pairs; hence across G=KM clocks, **K(2M^2+1)/3** distinct *(clock,destination)* pairs, compared with the naive `M G=K M^2` visits. Simply unioning identical destination writes at the **same clock** saves only a constant factor asymptotically (ratio tends to 2/3). The exact derivation splits residues by their 2-adic valuation: `sum_{t=0}^{h-1}(M/2^{t+1})(M/2^t)+1=(2M^2+1)/3`. This is a sharply scoped **collision-count fact**, NOT a lower bound on deeper algebraic prefix sharing across clocks or on unrestricted FFT circuits. `orbit_collision_gate.py` verifies 15 instances. To break NlogN, sharing must use more than same-clock index collisions.


`stationary_toeplitz.py` implements this reuse, `test_stationary.py` checks Toeplitz/commutator/rank identities and arbitrary-input numerical FFT agreement, and `field_stationary_audit.py` independently verified **202,240 exact all-basis Fourier entries** over N=48,80,96,192,384, including complete q=M cyclic recurrence decoding. Test-only basis-response caching is *not* an operation allowed for fast fresh-input FFT execution. The finite-field checker rejects an incorrect Toeplitz phase-step mutation.

## 4. Green-forcing density gate (fresh exact theorem for our restricted proposal)

Suppose an exact Green solver is offered as `L y=B x`, with invertible L and `y=F_N x`. Then necessarily `B=L F_N`. Consider any nonzero row l of L supported on at most w coordinates. Its Fourier transform `b=l F_N` obeys the standard discrete support uncertainty principle:

`|supp l| * |supp b| >= N`.

One proof uses unitarity and `||b||_infty <= sqrt(w/N)||l||_2`: if t entries of b are nonzero, `||l||_2^2=||b||_2^2 <= t (w/N)||l||_2^2`, hence `t>=N/w`. So **every** forcing row B has at least ceil(N/w) nonzero entries, regardless of noncommutative order of application. This is sharp for suitable subgroup rows at composite N.

For a row supported on w **consecutive cyclic coordinates**, `b_n = zeta^(jn) p(zeta^n)/sqrt(N)` with a nonzero polynomial p of degree at most w-1. It has at most w-1 roots among the N distinct roots of unity, giving the stronger `|supp b| >= N-w+1`. This is sharp even when L is invertible: let L be the identity except for one row replaced by coefficients of `p(z)=prod_{t=0}^{w-2}(z-zeta^t)`, whose constant coefficient is nonzero.

For exactly two row entries at j and j+a (distinct modulo N), `p(z)=alpha+beta z^a`; the number of zeros among Nth roots is either 0 or `gcd(a,N)`, so `|supp b|>=N-gcd(a,N)`. For gcd(a,N)=1, each forcing row has at least N-1 nonzeros. Both bounds have exact modular sharpness controls in `green_forcing_gate.py`. The input-independent root table and all Green solve operations must also be charged.

**Crucial limit:** *a dense B matrix is not a quadratic-time lower bound*. FFT is itself dense. The theorem rejects an **entrywise sparse forcing** shortcut, but leaves open a shared, structured, nonunitary evaluator for the dense `B x` that is provably cheaper than FFT. No such all-input evaluator is supplied here.
