# Phase 21 — Green–Weyl phase compression and the common-order barrier

This continues Phase 20 from the actual saved checkpoint, preserving the research chain. This phase derives an exact quadratic Fourier chirp identity in the algebra of weighted cyclic shifts, a rigorous `N/2` pole lower bound and matching computer-certified algebraic representations at powers of two through `N=8192`, and a more general `N/2` total-Green-term barrier covering products of same-order cyclic Green sums, including noncommuting weighted shifts. It also gives an exact O(N)-apply unit-circle Green matrix with all entries of equal modulus, and a second O(N) Green with a full-rank commutator. **None of these is a new faster FFT.**

Read `THEOREM.md` for definitions, full proofs, and excluded computational models, then `CHECKPOINT.md` for the next gate.

Implementation: `phase21_weyl.py` is standalone (Python 3.11+), uses modular arithmetic `p=998244353`, and has a conventional FFT reference plus a direct O(N²) chirp executor and modular exact algebraic pole certificates. The `CyclicGreen`, `SecondCyclicGreen`, and `CyclicWeightedGreen` solve routines are O(N) per input after O(N) preparation. Numerically testing the spectral condition number additionally requires NumPy. All other code uses only standard-library Python.

The complete prior archive is nested without modification as `previous_full_phase20_checkpoint.zip`. `verify_full_lineage.py` fresh-extracts and runs this phase and all earlier test suites.
