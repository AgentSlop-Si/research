# Independent replay

Requirements: Python with SymPy; a C++17 compiler with OpenMP. Run from
this checkpoint directory. Do not execute the uploaded source programs
under phase31/ or bank_v18/.

```sh
python prepare_phase31.py
python check_bank_v18.py
python check_phase31_auxiliary.py
g++ -O3 -std=c++17 -fopenmp independent_rectangular_audit.cpp -o independent_rectangular_audit
OMP_NUM_THREADS=4 ./independent_rectangular_audit REBUILT_INPUT_N4.bin RECHECKED_RANKS_N4.bin
OMP_NUM_THREADS=4 ./independent_rectangular_audit REBUILT_INPUT_N8.bin RECHECKED_RANKS_N8.bin
OMP_NUM_THREADS=4 ./independent_rectangular_audit REBUILT_INPUT_N16.bin RECHECKED_RANKS_N16_SAMPLED.bin phase31/fft_green_phase31_rectangular/certificates/indices_N16_100000.bin
OMP_NUM_THREADS=4 ./independent_rectangular_audit phase31/fft_green_phase31_rectangular/certificates/input_planted_N8.bin RECHECKED_RANKS_PLANTED.bin PLANTED_CASE_ID.bin
```

The generated JSON outputs and four rank streams must match the hashes
in PORTABLE_REPLAY.json. Thread count can be changed without changing
the rank output. N16 remains a replay of 100,000 samples, not an
exhaustive audit. The independent bank proof retains prime complex
Fourier length and every individual cycle's invertibility guard.

Source archives are retained under original/. Their programs are for
static source inspection only in this review. The exact all-prime
bank theorem is proved in the report using prime Fourier full-spark;
its selected finite-field controls do not replace that theorem.
