# Hero #0 — Phase 10: learned rational Fourier cycles and global Schmidt-rank gate

**Checkpoint:** 10 October 2026  
**Status:** Exact algebraic identities, independently checked finite-field implementations, reproducible structured-input witnesses, and a restricted **all-input matrix factorization obstruction**. **No universal sub-\(N\log N\) exact FFT; no improved integer-multiplication theorem; no novelty claim.**

## 1. Problem and arithmetic model

We seek the entire explicit discrete Fourier transform (DFT) of a **fresh** length-\(N\) input, not just a few frequencies or an update to cached data. The original ambition is \(O(N)\) or \(O(N\log\log N)\) worst-case sequential work on arbitrary inputs.

This phase gives an **input-conditional** exact algorithm. Let \(N=KM\), with \(K,M\) powers of two and \(K\ge M\), and take \(M=\Theta(\log N)\). Work over an exact field \(\mathbb F\) containing a primitive \(N\)-th root \(\omega_N\), of characteristic not dividing \(N\). Count scalar additions, multiplications, inversions, zero tests, root preparation, input scans, output writes, and logarithmic-word index operations. A uniform bounded-size representation of exact coefficients is **not** assumed. The test implementation uses \(\mathbb F_{2013265921}\), which only supports powers of two up to \(2^{27}\): this **fixed field is not itself an asymptotic family of unbounded transform lengths**. The algebra is also valid over exact complex numbers, with input-dependent inversions/branching, which are not the same resources as predetermined-coefficient linear circuits.

Use the unnormalized negative-exponent DFT and polyphase columns

\[
F_t[\ell]=\sum_{b=0}^{K-1}x_{bM+t}\,\omega_K^{-\ell b},
\qquad 0\le t<M,\;0\le\ell<K.
\]

Direct index expansion gives the identity, for \(k=\ell+jK\), \(z=\omega_N^{-k}\):

\[
\boxed{X_{\ell+jK}=\sum_{t=0}^{M-1}F_t[\ell]z^t.}\tag{1}
\]

This identity holds for **all** inputs but does not yet reduce the cost of obtaining the \(F_t\).

## 2. The learned-frequency-recurrence promise

For each frequency \(\ell\) independently, assume the full time sequence satisfies some homogeneous linear recurrence of order \(r_\ell\le d\):

\[
\boxed{F_t[\ell]+\sum_{i=1}^{r_\ell}q_{i,\ell}F_{t-i}[\ell]=0
\quad(r_\ell\le t<M).}\tag{2}
\]

The unknown coefficients \(q_{i,\ell}\) may be arbitrary, dense as a function of frequency, and entirely unrelated between frequencies. Equivalently, the input columns evolve under \(d\) separately learned circulant operators \(C_i\), and the spatial kernel of each \(C_i\) may be fully dense. There is **no spatial sparsity or single-step innovation sparsity assumption**.

Algorithm:

1. Read all \(N\) input entries. Compute **only** the first \(2d\) full length-\(K\) DFTs \(F_t\); work \(O(dK\log K)\).
2. At each \(\ell\), run Berlekamp–Massey on the \(2d\) samples. If its minimal fitted order exceeds \(d\), reject the fast path. For a genuinely order-\(\le d\) full stream, \(2d\) samples suffice to recover a compatible recurrence, including repeated roots and zero roots. Work \(O(d^2K)\).
3. Check **every raw input column** against the learned circulant recurrence using independent random-vector identities (Section 4); work \(O(R(dN+dK\log K))\) for \(R\) fixed independent trials. A failure returns `None`, not a guessed transform.
4. Synthesize all \(N\) Fourier outputs from degree-\(d\) rational functions, **without \(K\) length-\(M\) FFTs and without the remaining \(M-2d\) length-\(K\) FFTs**; work \(O(dN)\), including singular denominators and a batch inversion.

### Rational output identity, including singularities

Fix \(\ell\); write \(f_t=F_t[\ell]\), \(r=r_\ell\), and

\[
Q(z)=1+q_1z+\cdots+q_rz^r,
\qquad S_M(z)=\sum_{t=0}^{M-1}f_tz^t.
\]

By the recurrence, all coefficients of \(Q(z)S_M(z)\) at degrees \(r,r+1,\ldots,M-1\) vanish. Therefore

\[
\boxed{Q(z)S_M(z)=P(z)+z^MB(z),\quad \deg P,\deg B<r.}\tag{3}
\]

The coefficients of \(P\) come from the first \(r\) stream values; those of \(B\) from the last \(r\) values:

\[
P_j=\sum_{i=0}^{j}q_i f_{j-i},\qquad
B_j=\sum_{i=j+1}^{r}q_i f_{M+j-i},\quad 0\le j<r,
\]
with \(q_0=1\). All last values are generated in \(O(rM)\) scalar work per frequency from the learned recurrence; coefficients use \(O(r^2)\) operations per frequency.

At the \(M\) output frequencies belonging to \(\ell\),

\[
z^M=\omega_K^{-\ell}=:\gamma_\ell,
\]
which is **independent of \(j\)**. Thus away from zeros of \(Q\),

\[
\boxed{X_{\ell+jK}=\frac{P(z)+\gamma_\ell B(z)}{Q(z)}.}\tag{4}
\]

Every numerator and denominator now has degree at most \(r\), hence each output costs \(O(r)\) scalar operations. If \(Q(z)=0\), the singularity is removable because \(S_M\) is a polynomial; evaluate the original \(M\)-term expression directly at that \(z\). A nonzero polynomial of degree \(r\) has at most \(r\) distinct roots, so at most \(r\) expensive exceptions per \(\ell\), each costing \(O(M)\): still \(O(rM)\) per frequency. All other denominators use **one batch field inversion and \(O(N)\) multiplications**.

This proves the conditional exact execution/work bound

\[
\boxed{T(N,d,R)=O\left(RdN+d^2K+N\right)
=O\left(RdN+\frac{d^2N}{\log N}\right),\quad M=\Theta(\log N).}\tag{5}
\]

For a fixed number \(R\) of verification trials, \(d=O(1)\) yields \(O(N)\); \(d=O(\log\log N)\) yields \(O(N\log\log N)\). Storage is \(O(N)\). This conclusion applies **only on the stated promised input family**.

## 3. Why this extends the previous conditional algorithms

Phase 9 learned one arbitrary dense stationary circulant operator, then required each later innovation to be sparse in positions or sparse in frequencies. An order-2 Phase 10 input can have every one-step innovation **dense simultaneously in both domains**, at every transition. This is not low rank of the global \(K\times M\) polyphase matrix: that matrix can have rank \(M\) and the full length-\(N\) Hankel matrix can have maximum rank \(N/2\).

Our deterministic \(N=128, K=16, M=8, d=2\) witness has:

| Property | Exact value |
|---|---:|
| Nonzero entries of input | 128 of 128 |
| Rank of \(K\times M\) raw polyphase matrix | 8 of 8 |
| Rank of \(64\times64\) Hankel matrix | 64 of 64 |
| Green-phase modes active under Phase 7 dechirp | 8 of 8 |
| Rank of Phase 9 stationary-controller innovation matrix | 6 of 6 |
| Nonzero innovation coordinates, each of 6 steps | 16/16 in positions, **and** 16/16 in frequencies |
| Fourier output discrepancies against independent quadratic DFT | **0** |
| Rational removable singularities exercised | **1** |

This is a **finite exact witness**, not an all-input asymptotic speedup.

## 4. Randomized but charged membership verification

Let \(C_i\) be the circulant matrix with DFT eigenvalues \(q_{i,\ell}\). The claimed raw-input recurrence is

\[
r_t=v_t+\sum_{i=1}^{d} C_iv_{t-i}=0,\qquad t\ge d,
\]
where \(v_t=(x_{bM+t})_b\). For a random row vector \(w\), check

\[
w^T v_t+\sum_{i=1}^{d}(C_i^Tw)^T v_{t-i}=0
\quad\text{for every }t\ge d.
\]

Since \(C_i\) is circulant, \(C_i^Tw\) has DFT

\[
\operatorname{DFT}_K(C_i^Tw)[\ell]
=q_{i,-\ell}\operatorname{DFT}_K(w)[\ell].
\]

Compute \(\operatorname{DFT}_K(w)\) **once per round**, then \(d\) inverse length-\(K\) transforms and \(O(dN)\) dot-product work. Nothing is assumed about sparse \(C_i\).

For a fixed learned model and fixed input, assemble the matrix of actual residuals \(R=[r_d\;r_{d+1}\;\cdots]\). Over \(\mathbb F_q\), independent uniform \(w\) yield

\[
\Pr[\text{all checks pass in one round}]=q^{-\operatorname{rank}(R)},
\]

so a **false acceptance** after \(h\) independent rounds has probability at most \(q^{-h}\), and **promised inputs always pass**. The executable test field has \(q=2013265921\), for which three rounds give at most \(q^{-3}\) false acceptance on a fixed nonpromised input independent of the random vectors. Sampling must occur **after** model learning; seeded random tests alone are not a security guarantee. Over exact complex numbers, sampling each coordinate from an independent finite set \(S\) yields at most \(|S|^{-h}\) false acceptance by a degree-one polynomial identity argument.

This algorithm must **not** be described as a deterministic exact full-input FFT. A deliberately crafted corrupted input in the tests passes a single *predictable* random check but is rejected by the second independent check. If the check fails, obtaining exact output for a generic input requires conventional FFT fallback (\(O(N\log N)\)) or a new universal method.

## 5. Genuine generic-input obstruction for this entire family

Let inputs be iid uniform in \(\mathbb F_q^N\). The \(M\) polyphase column spectra are iid uniform vectors in \(\mathbb F_q^K\) because the length-\(K\) DFT is invertible. At a **single** frequency, a length-\(M\) sequence satisfying some order-\(\le d\) recurrence is fully determined by at most \(d\) initial values and \(d\) coefficients. Thus at most \(q^{2d}\) such sequences exist, out of \(q^M\) possible sequences.

Independence across all \(K\) frequencies gives the robust union-count bound

\[
\boxed{\Pr[\forall\ell:\text{order}(F_\bullet[\ell])\le d]
\le q^{-K(M-2d)}\qquad (2d<M).}\tag{6}
\]

At \(N=128, K=16, M=8, d=2\) and \(q=2013265921\), this upper bound is about \(10^{-595.45}\). For \(d\le(\frac12-\varepsilon)M\), acceptance on a uniformly random input is at most \(q^{-2\varepsilon N}\). To make this recurrence-family promise relevant to generic inputs, \(d\) must approach \(M/2\), at which point \(O(dN)\) reverts to \(O(N\log N)\). **This is not an FFT lower bound**: it limits this particular low-order recurrence representation. We also ran explicit generic-input checks with \(d=M/2\): the learned formulas return the exact FFT in those cases, but computing the initial \(2d=M\) column transforms has already forfeited the hoped-for savings.

## 6. A new *universal-input* obstruction: Fourier Schmidt-rank budget

Now discard all input promises. Let \(N=AB\) with \(A,B\) powers of two and \(A\le B\), and split the \(\log_2N\) input/output bits into a first register of dimension \(A\) and second of dimension \(B\). For the **unitary** Fourier matrix \(U_N\), write input \(x=aB+b\) and output \(y=cB+d\). Define its *operator realignment* as the \(A^2\times B^2\) matrix

\[
R_{(a,c),(b,d)}=(U_N)_{cB+d,aB+b}.
\]

Because \(A\mid B\), exact index expansion gives

\[
\boxed{R_{(a,c),(b,d)}
=\frac{1}{\sqrt{AB}}\,\omega_A^{-(ad+cb)}\omega_N^{-bd}.}\tag{7}
\]

The \(\omega_N^{-bd}\) factor has modulus one and depends only on the column. Orthogonality of the \(A\)-th roots over each of the \(B\) complete residue ranges yields

\[
\boxed{RR^*=\frac BA I_{A^2}.}\tag{8}
\]

Therefore **every one of the \(A^2\) nonzero operator Schmidt coefficients equals \(\sqrt{B/A}\)**. In particular, with a balanced cut \(A=B=\sqrt N\), operator Schmidt rank is **\(N\)** and all Schmidt coefficients equal **1**.

The consequences are precise and restricted:

* Any **one-shot sum** \(U_N=\sum_{j=1}^{s}A_j\otimes B_j\) across this fixed register split requires **\(s\ge A^2\)** separable operator terms.
* By best low-rank approximation, the *optimal* relative Frobenius error with at most \(s\le A^2\) separable terms is exactly

  \[
  \boxed{\min_{\operatorname{SchmidtRank}(T)\le s}
  \frac{\|U_N-T\|_F}{\|U_N\|_F}
  =\sqrt{1-\frac{s}{A^2}}.}\tag{9}
  \]
* A product \(T_L\cdots T_1\) with operator Schmidt ranks \(s_1,\ldots,s_L\) across the **same** split satisfies \(\operatorname{SchmidtRank}(T_L\cdots T_1)\le\prod_j s_j\). An exact factorization into such layers must therefore obey

  \[
  \boxed{\sum_{j=1}^L\log s_j\ge2\log A.}\tag{10}
  \]

For balanced cuts, a constant-Schmidt-rank cycle needs \(\Omega(\log N)\) complete layers. **If** each such layer necessarily makes \(\Omega(N)\) scalar operations, this particular full-scan layer architecture cannot deliver \(O(N\log\log N)\). This is a *restricted factorization barrier*, not an unrestricted Fourier-circuit lower bound.

**Critical escape route:** a high-Schmidt-rank layer can still be cheap. For example, a diagonal controlled-phase operator \(D|a,b\rangle=\omega_A^{ab}|a,b\rangle\) has Schmidt rank \(A\) but applies in \(O(N)\) scalar multiplications. Hence this theorem does **not** rule out a few cheap, high-Schmidt-rank, noncommuting Green/graph layers. It instead specifies how much rank they must collectively carry. Quantum gates act on implicit amplitude states; state preparation and extracting all \(N\) classical output amplitudes are distinct costs.

`operator_schmidt_gate.py` checks exact rank for balanced \(N=4,16,64,256\) over the modular field; `operator_schmidt_general.py` checks nine balanced/unbalanced partitions in exact arithmetic and independently checks their singular-value Gram matrices in complex128. This is an application of standard tensor linear algebra; no priority/novelty claim is made.

## 8. Exact next research gate

Search for a small number of **cheap, high-operator-Schmidt-rank, noncommuting full-vector layers** that contract arbitrary dense innovations without first Fourier-transforming most input columns. Any candidate must explicitly pay for learning (if adaptive), preparing roots and coefficients, validating arbitrary inputs, executing each layer, and writing all outputs. The flat Schmidt spectrum proves that a *one-shot low-rank* cross-mode tensor sum, exact or small-relative-Frobenius-error, will fail. It does **not** exclude a multistage nonunitary network—our desired frontier.
