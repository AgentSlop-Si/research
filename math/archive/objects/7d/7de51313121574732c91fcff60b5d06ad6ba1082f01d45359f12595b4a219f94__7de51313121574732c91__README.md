# Portable static-triage supplement

Read TRIAGE_REPORT.md for findings and CHECKPOINT_ADDITION.md for integration guidance. This package preserves four original Library-discovered research archives without redundant extracted copies. PROVENANCE.json preserves their original download locations as historical metadata and also supplies portable `package_archive_path` locations.

Contents:

- TRIAGE_REPORT.md: bounded mathematical/code triage, with exact source paths inside the archives.
- CHECKPOINT_ADDITION.md: proposed integration notes and verification boundaries.
- PROVENANCE.json: archive/source hashes, Library IDs, source classification, and portable archive paths.
- STATIC_VALIDATION.json: independently computed AST/import summaries, test-method counts, manifest and ancestry checks.
- source_archives/: the four unchanged ZIPs.
- SHA256SUMS: hashes of every payload file except itself and the later verification transcript.
- verify_package.py: independently authored, read-only hash checker. It never imports or executes any source archive code and does not extract the archives.
- VERIFICATION.txt: recorded successful package verification.

Run `python verify_package.py` from any directory. It verifies payload hashes, each archive hash, each preserved archive member's size/hash, complete member inventory, and the HERO17 note identity. The original nested archives remain bytes and are never executed. Reproducing source test suites is deliberately outside this package's verification scope.

The paths to earlier independent audits in TRIAGE_REPORT.md describe provenance dependencies. They are not required for the self-contained integrity check. The new source proof/code is accessible by opening the four preserved archives.
