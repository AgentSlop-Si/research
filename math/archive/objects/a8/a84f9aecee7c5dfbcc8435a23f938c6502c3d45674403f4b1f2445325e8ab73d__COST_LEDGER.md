# Exact scalar/field operation accounting: Phase16

All counts are for arbitrary fresh N-vector data. Fixed scalar multiplications, roots, output writes, local divisions, and memory are charged. No precomputed input-dependent cache exists.

## Green operator `L=7I+2S+D` and linear solver

- Generate `omega^0,...,omega^(N-1)`: N-1 scalar multiplications from one primitive omega. Specifying the primitive root and its precision is a separate setup/bit-complexity requirement; in exact finite-field audits the prime and generator are fixed for the finite length set, not an asymptotic p(N) assertion.
- Form the diagonal `a_k=7+omega^k`: N additions.
- Precompute `inverse_diag[k]=1/a_k`: N exact scalar divisions (or finite-field inversions). These are input-independent and depend on N; charge O(N) arithmetic even if cached across repeated inputs.
- Precompute cyclic coefficient `h_k=(-2 h_(k-1))/a_k`: N scalar multiplications using inverse_diag. `1-h_(N-1)` and inverse: O(1) arithmetic.
- Apply `L x`: at most 2N scalar multiplications and 2N additions in direct scalar accounting; O(N) accesses/writes.
- Solve `L y=b` given precomputed factors: first recurrence N iterations of two multiplications and one subtraction, scalar cyclic correction O(1), then N iterations of one multiply and one addition. Approximately **3N+1 scalar multiplications and 2N additions/subtractions**, plus N writes. Working arrays z and h are N entries each, so O(N) words.
- Apply right preconditioner `P=7I+S+2D^-1` to x: O(N) arithmetic, O(N) root powers, O(N) accesses. Computing `F(Px)` is STILL one arbitrary-input Fourier transform, not a free scan.
- Source forcing `B=LF` has N² nonzeros with each nonzero coefficient between 4/sqrt(N) and 10/sqrt(N) in absolute value. A **naive entrywise** implementation takes Theta(N²) arithmetic. This density alone is NOT a lower bound against clever subquadratic shared circuits; the known O(NlogN) FFT computes it using P and FFT.

## Arbitrary permutation graph Green `L_pi=7I+D+2P_pi`

- Read and validate permutation pi: O(N) entries and O(N) memory. Find its disjoint cycles by following edges and marking visited vertices: O(N) time, no costly dynamic graph structure required.
- An independent union-find component check takes O(N alpha(N)) operations; it is an **audit** and is NOT charged to the fast solver implementation, which uses direct cycle traversal.
- Each cycle of length r has one length-r affine recurrence and a one-scalar closure. Summed over disjoint cycles, arithmetic setup and solve are **O(N)** even if cycles cross all blocks.
- Precompute roots and diagonal inverses in O(N) scalar arithmetic; applying L_pi requires O(N) loads and arithmetic; L_pi^-1 requires O(N) field/arithmetic operations and O(N) working storage.
- The fully dense complex forcing B_pi=L_pi F_N has N^2 nonzero entries; **do not mistake density for a quadratic arithmetic-circuit lower bound**. We have C_F<=C_Bpi+O(N) and C_Bpi<=C_F+O(N).

## General q-atom Weyl polynomial

- Apply each weighted permutation `S^a D^b`: O(N) scalar work and O(N) element accesses; q atoms at most O(qN).
- Enumerating atom indices/exponents and recording coefficients may be O(q) or larger bit complexity if exponents scale; precomputed phases cost O(qN) without exploiting repeated powers. q is fixed in the six-term exact witness.
- Applying the resulting right-side preconditioner `sum c D^-a S^b` costs O(qN) too, but still leaves F to evaluate.
- For variable q=q(N), no asymptotic speedup is claimed; even O(qN) preprocessing may exceed NlogN when q grows rapidly.

## Unitary 2-coordinate graph circuits

- Each 2x2 complex unitary rotation acting on TWO current data coordinates counts as **one gate** in Ailon's restricted model; a real/complex scalar addition/multiplication implementation costs a constant number of arithmetic operations, so the Ω(NlogN) gate bound transfers to that restricted constant-size-operation implementation.
- Permuting input/output indices does not increase row entropy, even if counted as free in the idealized model; realistic data routing only adds work.
- A k-local high-arity unitary is NOT considered a free constant-time gate when k grows; the entropy budget permits at most k log_2 k bits for such a gate, but its actual arithmetic and memory cost requires independent accounting.
- Arbitrary nonunitary graphs, conditioning-losing intermediates, ancilla/extra space, data-dependent branches, and quantum state circuits do not satisfy this exact unitary in-place bound without additional assumptions.

## Machine-model honesty

The all-size complex theorems use unit-cost exact complex arithmetic as a hypothetical algebraic model. Finite field tests have finite modulus and finite N. To claim a Word-RAM/Turing bit upper bound, charge number sizes, roots, divisions, intermediate precision, output bit lengths and tolerance. The Phase16 certificates do not prove an arbitrary-input fast discrete bit implementation.
