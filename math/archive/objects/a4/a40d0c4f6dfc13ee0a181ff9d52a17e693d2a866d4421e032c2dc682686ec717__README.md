# Outer-inverse spectral stability checkpoint — October 10, 2026

This package continues the **unchanged 256-point four-stage scan factorization** from `prior_checkpoint_full.zip`. No change of permutation or parallel/cached FFT interpretation is made.

## Reproduce with two commands

```bash
python verify_moment_rational.py
OPENBLAS_NUM_THREADS=1 python verify_outer_stability.py
```

The first script uses **only Python integer and rational arithmetic** (not NumPy) to prove that the rank-16 target Fourier block has 17th singular value strictly greater than `3sqrt(2)/5`. It computes exact cyclotomic coefficients from the saved shuffle and certifies the Fourier fourth moment via rational arctangent/Taylor enclosures.

The second independently enumerates all 255 nonzero eight-bit parity masks, identifies **32 simultaneous rank-deficit constraints** (seven with a direct positive energy bound), checks 64 exact modular Fourier ranks, 14 synthetic middle-stage rank cases (including singular zero-generator branches), and runs numerical SVD only as an optional non-proof sanity check.

Read `PROOF_CERTIFICATE.md` for full mathematical statements. `EXACT_AND_NUMERIC_CERTIFICATES.json` contains the 32 rank masks; `RATIONAL_MOMENT_CERTIFICATE.json` contains the integer moment coefficients and full rational bounds.

## Honest status

A valid exact factorization would require outer inverse stages substantially outside the neighborhood of diagonal unitary matrices (at least one outside radius ≈0.359606 in spectral norm). This **does not establish nonexistence** for arbitrary quasiseparable outer inverses and **does not construct a new FFT**.

The complete preceding research ZIP is saved byte-for-byte as `prior_checkpoint_full.zip`, so this package can be used as a next-chain handoff.
