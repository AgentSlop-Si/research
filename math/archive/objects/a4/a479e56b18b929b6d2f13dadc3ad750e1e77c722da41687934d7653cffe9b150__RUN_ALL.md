# Reproducible tests

Install `sympy` and `numpy` in a Python 3.10+ environment, then run

```
python run_all.py
```

The runner performs three independent phases:

1. Nine new FFT spectral-gate regression tests: exact cyclotomic coefficients, direct finite-field determinants, three upper resultants, a nonzero Jacobian minor, exact five-variable arithmetic circuit, 31-term cubic, and the spectral-tail equivalence at several FFT sizes.
2. Extract `previous_research_checkpoint.zip` into a fresh temporary directory and run the previous 55 tests. The saved checkpoint itself recursively verifies older archives, yielding a true complete-regression check rather than trusting a stored log.
3. Enumerate the stated 78,608-quadruple GF17 regular branch, verifying essential counters from `exhaustive_GF17_chart.json`.

The new runner prints `FINAL: 64/64 passing tests` only after all phases succeed. This is a **software regression count**, not the number of independent mathematical theorems and not a proof over the complex numbers.

`python adjacent_tail.py` reexports the 31-term cubic. `python exact_minor.py`, `python exact_upper.py`, `python five_parameter_gate.py` independently reexport other exact coefficients. `SHA256SUMS.txt` validates the distributed research archive contents; rewriting an output intentionally changes its hash and requires regeneration of the manifest.
