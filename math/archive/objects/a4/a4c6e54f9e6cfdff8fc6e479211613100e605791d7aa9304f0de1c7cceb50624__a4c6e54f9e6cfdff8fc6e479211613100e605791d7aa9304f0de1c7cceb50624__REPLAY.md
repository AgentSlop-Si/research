# Portable independent replay

Requires Python 3.11+ and its standard library only. No network or source imports are used.

Run `python independent_checks.py` from this review directory. It regenerates `INDEPENDENT_RESULTS.json` and prints the same JSON. The archived independent results were reproduced byte-for-byte from a relocated directory containing only this checker.

The programs inside `source/` and `extracted/` are uploaded evidence and must remain inert. Do not run or import them. The checker uses independently authored mathematical controls only. The report states the exact scope of each result; these are not general FFT circuit lower bounds.
