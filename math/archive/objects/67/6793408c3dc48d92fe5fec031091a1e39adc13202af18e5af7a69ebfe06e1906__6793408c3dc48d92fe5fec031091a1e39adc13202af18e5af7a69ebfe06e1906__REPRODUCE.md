# Portable independent replay

Requirements: Python 3 with SymPy; a C++17 compiler. No uploaded source program is imported or executed. Only the newly authored checker scripts and C++ source at this directory's top level are run. Uploaded JSON files supply certificate data.

To preserve this sealed directory, copy it into a new temporary working directory before running. All authored mathematical checkers resolve paths relative to their own location and do not need the original master archive. The extraction/provenance script is not part of mathematical replay because it intentionally compares to the dated master snapshot.

From the copied directory, run:

```
python independent_checks.py
python separator_checks.py
python v16_extra_checks.py
python paired_dressing_check.py
g++ -O3 -std=c++17 exhaustive_anchor.cpp -o exhaustive_anchor_replay
./exhaustive_anchor_replay family_N8.txt anchor_ranks_replay.bin anchor_failures_replay.txt
sha256sum anchor_ranks_replay.bin
```

The replay regenerates these five JSON artifacts, which should match the sealed copies byte-for-byte: INDEPENDENT_RESULTS.json, FAMILY_SPECIFICATIONS.json, SEPARATOR_RESULTS.json, V16_EXTRA_RESULTS.json, PAIRED_DRESSING_RESULTS.json; it also regenerates family_N4.txt, family_N8.txt and family_N16.txt.

Verify payload integrity before replay with `sha256sum -c SEALED_MANIFEST.sha256`. This manifest covers every payload file except the manifest itself, its JSON companion, and transient Python __pycache__ files. Run it in this directory. Original source archives and extracted members are retained read-only; a duplicate nested archive need not be extracted for these tests.

The certified scope is in REVIEW_MILESTONE.md. A matching finite-field rank digest supports the stated characteristic-zero nonvanishing proof with its explicitly checked denominator/root guards. It does not certify other untested parameter families, all lengths, numerical stability, or an efficient Fourier executor.
