# A target-specific exact F8 three-stage existence certificate

9 October 2026 UTC. This is a bounded positive expressivity result, not an all-length FFT or a fully charged coefficient compiler. Independent review is requested separately.

## Statement and exact definition of the candidate

Let R be bit reversal on8 coordinates, [0,4,2,6,1,5,3,7]. For a stage with40 complex parameters use

S[i,j] = L[i] V[j] for i>j,
         U[i] W[j] for i<j,
         d[i] for i=j.

There exist three such stages for which

S3 R S2 R S1 = F8/sqrt(8),

where F8[k,j]=exp(2*pi*sqrt(-1)*k*j/8).

The coefficient tuple is specified exactly as follows. Read the120 Gaussian-rational center coordinates and64 selected complex coordinate indices from CANDIDATE_DATA.json. Freeze the other56 coordinates at their listed rational values. The chosen64 coordinates are the unique solution of all64 matrix-entry equations in the closed ball

max_j (|Re(z_j-z0_j)|+|Im(z_j-z0_j)|) <= 2^-30.

This uniquely specified root is the exact candidate, not the floating center. Multiplying the last stage bysqrt(8) gives an unnormalizedF8 factorization. Target invertibility forces all three factors to be invertible.

## Polynomial map and exact target constants

Let f(z) be the64-vector of entries of S3 R S2 R S1-F8/sqrt(8), with only the64 selected coordinates variable. Each entry is a polynomial: the product has64 terms indexed by its two intermediate indices, each term a monomial of degree at most6 in the stage parameters. No coefficient division is used.

The normalized Fourier values, according to the exponent modulo8, are exactly

sqrt(2)/4, (1+i)/4, i*sqrt(2)/4, (-1+i)/4,
-sqrt(2)/4, (-1-i)/4, -i*sqrt(2)/4, (1-i)/4.

The checker bounds sqrt(2) by h/2^100 and (h+1)/2^100, where h is the integer square root of2*2^200. It verifies both integer square inequalities. Thus no approximate trigonometric or floating Fourier value enters any certificate inequality.

## Norms and rational data

For a complex scalar use |a+ib|_1=|a|+|b|, and on vectors take the maximum coordinate norm. A matrix operator norm is bounded by the maximum row sum of these scalar norms. The scalar norm is submultiplicative, so this supplies valid bounds for all products and derivatives below.

The center has common denominatorQ=2^60. The64-by-64 approximate inverse B of the selected Jacobian has common denominator2^44. The checker recomputes the exact polynomial value with denominatorQ^6 and the exact selected Jacobian with denominatorQ^5 using Gaussian-integer arithmetic. It does not trust the saved floating diagnostics or any residual reported by the search routine.

The exact rational checks yield the following conservative displayed values; the full numerators and denominators are saved in EXACT_CERTIFICATE_RESULTS.json:

||f(z0)|| <= 1.030e-15,
||B|| <= 60.849,
beta=||B||*||f(z0)|| <= 6.265e-14,
eta=||I-B f'(z0)|| <= 5.773e-12.

In particular eta<1, so B f'(z0), and hence the square matrices B and f'(z0), are invertible by the Neumann-series criterion. B is not assumed to be an exact inverse.

## A conservative derivative bound valid throughout the ball

Every center coordinate has scalar norm at most3. In the ball of radius at most1 every variable and frozen parameter therefore has scalar norm at most M=4. For a monomial of degree d<=6, its second derivative as a bilinear map is bounded by d(d-1)M^(d-2)<=30M^4. Each output polynomial has at mostN^2=64 monomials, so

||f''(z)|| <= H=30*64*4^4=491520.

This bound remains valid when some parameters repeat in a directional derivative or when some coordinates are frozen; restricting the variables cannot increase it. Consequently

||B(f'(z)-f'(z0))|| <= L||z-z0||,
L=||B||H <= 29,908,494.

All bounds use the complete polynomial, not a linearized-only argument.

## Contraction proof

Define G(z)=z-B f(z), and set r=2^-30. On the closed radius-r ball,

||G'(z)|| <= eta+Lr <0.027855<1.

Taylor's formula along a line segment also gives

||G(z)-z0|| <= beta+eta*r+(L/2)*r^2
             <1.304e-11
             <r=9.313225746154785e-10.

Both strict inequalities are tested using exact rational comparisons. Thus G maps this complete closed ball into itself and is a contraction. Banach's fixed-point theorem supplies a unique fixed point there. Since B is invertible, G(z)=z implies f(z)=0. This proves the target-specific exact factorization.

A nonzero Jacobian minor or a tiny numerical residual alone would not prove the statement; the self-mapping and derivative inequalities supply the missing existence argument.

## Verification and limitations

Run `python verify_candidate.py` in this folder. It uses only Python integers, Fractions, integer square root and JSON for the proof checks. Floating conversions in the final JSON are display-only and are not used by any assertion. The optional build_candidate.py uses numerical QR/Newton solely to produce proposed rational certificate data; its diagnostics are not part of the proof. Neither program imports or executes uploaded code.

This proves that the particular complex Fourier targetF8 is in the three-stage separated-generator image. Earlier generic image dominance did not establish membership of this specific target. It is compatible with the new asymptotic three-stage obstruction and the explicit repeated-bit-reversal failure atN128.

The exact coefficients are implicitly defined by the isolated polynomial root. No claim is made that they belong to the original cyclotomic field, admit short radical expressions, or can be generated by a uniform linear-time arithmetic compiler. Applying supplied exact coefficients to a fresh8-vector uses the usual three linear scans and writes every output, but the cost of supplying those exact constants is not silently discarded. A convergent Newton iteration with rational approximations is not a finite exact coefficient-generation algorithm. This fixed-size existence certificate therefore does not meet the project's all-length, arbitrary-fresh-input, fully charged exact sub-N-log-N goal.
