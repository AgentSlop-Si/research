# Conditioned macro material: independent bridge review

The supplied archive gives a conditional composition principle, not a completed
independent faster FFT. Its reset idea is sound after a complete local block
becomes unitary. The work below supplies exact witnesses for two formulation
details and bounds the conditioning of our unresolved q-Pascal middle factor.
It does not modify the supplied sources.

## 1. Identity padding must be included in the prefix bound

For a local nonsingular prefix P acting on only one fiber, untouched coordinates
contribute an identity block. Exactly,

    kappa_2(P direct-sum I)
      = max(1, ||P||_2) * max(1, ||P^(-1)||_2).

This need not equal kappa_2(P): P=100 I_2 has condition 1, while
P direct-sum I_2 has condition 100. Previously completed unitary blocks and
unitary coordinate changes preserve the displayed padded condition.

Therefore the sequential macro theorem can use

    K_*(B) = max_prefix max(1,||P||_2) max(1,||P^(-1)||_2).

Alternatively, state that every local prefix has determinant of modulus one.
Then its singular values straddle 1, so the padded expression equals kappa_2(P).
Pure elementary shear words and unit-modulus monomial gates satisfy this
condition. Arbitrary nonsingular or arbitrarily scaled monomial prefixes do not.
The supplied tensor formula is correct at synchronized I tensor P checkpoints;
it alone omits intermediate states while processing fibers sequentially.
This repair preserves the qualitative finite-bound staircase argument.

## 2. Alternating banks requires alternating source/target roles

Three transparent additions for a unitary U give

    W_U = [[0,-U^(-1)],[U,0]],
    W_U(x,0) = (0,Ux).

Applying W_V next in the **same orientation** gives (-V^(-1)Ux,0), rather
than (VUx,0). For the next level, exchange the logical source/target roles.
If S swaps the two coordinate banks, use S W_V S, yielding

    (S W_V S) W_U (x,0) = (VUx,0).

This is an instruction-orientation change; the conjugation expresses it without
requiring a physical whole-bank copy. The exact certificate uses noncommuting
rational orthogonal matrices

    U = [[1,0],[0,-1]],
    V = [[3/5,-4/5],[4/5,3/5]].

For x=(1,0), the corrected output is (3/5,4/5) in the active bank, whereas
the unchanged orientation gives (-3/5,4/5). Both local three-addition identities
and orthogonality of the corrected complete four-register operation are checked
entrywise with rational arithmetic. This does not implement the source's
arbitrary-scratch replay lemma or establish its operation count independently.

## 3. The q-Pascal middle factor is not a unitary reset point

In our previously verified factorization, let

    f_j = product_(r=1..j)(1-q^r),
    d_j = (-1)^j q^(j(j-1)/2) / f_j,
    M = diag(d) R,

where R reverses coordinates and q is a complex primitive Nth root. Since R
is unitary, M has singular values |d_j|. We have |d_0|=1 and
|d_(N-1)|=1/N, using product_(r=1..N-1)(1-q^r)=N. Thus kappa_2(M)>=N
for every such primitive root.

For the **canonical** root q=exp(2 pi i/N), N>=8, put m=floor(N/8).
For 1<=r<=m,

    |1-q^r| = 2 sin(pi r/N) <= 2 pi r/N <= pi/4.

Consequently |f_m| <= (pi/4)^m. Comparing |d_m| to |d_(N-1)| gives

    kappa_2(M) >= N (4/pi)^m >= N (14/11)^m,

where the final conservative rational bound uses pi<22/7.
An elementary stronger bound follows by retaining the individual r factors and
using AM-GM on 1,...,m:

    |f_m| <= (2 pi/N)^m m! <= [pi(m+1)/N]^m,
    kappa_2(M) >= N [N/(pi(m+1))]^m
                 >= N [7N/(22(m+1))]^m.

These are analytic inequalities for all stated sizes. The script evaluates only
their exact rational right sides for N=8,16,32,64,128,256; it does not estimate
complex singular values or infer a theorem from finite measurements.
The exponential argument uses the canonical root's order around the unit circle;
it is not asserted for every primitive exponent with this same index m.

For a nonunitary M, the analogous bank exchange
[[0,-M^(-1)],[M,0]] is not unitary: its Gram matrix has blocks
M* M and (M^(-1))* M^(-1). Scalar rescaling cannot remove kappa_2(M).
If an implementation explicitly crosses from P_before to
P_after=M P_before, then

    kappa_2(M) <= kappa_2(P_after) kappa_2(P_before).

At least one of these adjacent cumulative states therefore has condition at
least sqrt(kappa_2(M)). This concerns retaining this particular middle-factor
interface, not every Fourier algorithm or every factorization.

## 4. Consequences and limits

The orbit compiler remains correct for its specified sequential phase-kernel
paths. The supplied conditioned construction neither invalidates those rewrites
nor makes diag(d)R commute with them. Resetting around an entire normalized
local Fourier block is possible under the transparent-word assumptions; resetting
around this middle factor alone is not.

A slowly growing local size B can absorb a finite, even enormous K_*(B).
However, the macro work ratio still contains s(B)/(B log B). Our present
independent q-kernel evaluator has no proved o(B log B) local cost. Wrapping it
in a condition-reset construction does not supply that missing saving. Using
#130 as the local black box is a separate, explicitly dependent route.

The current official scope document,
https://github.com/openai/math/blob/main/lean/docs/130.md (read 2026-10-09),
states a separate uniform exact-complex result with
O(n(log n)^(1-10^(-13))) work, including scalar preparation and root-order
selection, with the chosen root supplied. Its coefficients are unrestricted;
this is not a conditioned implementation theorem. This review does not
re-verify that formalization or import it into the independent orbit route.

The archive itself leaves extraction of a fixed local linear DAG, certified
coefficient/prefix bounds, and effective uniform scheduling as further work.
DAG extraction must also establish that execution and indexing are independent
of the variable input. Charging a scheduler requires an actual bounded-work
construction, not only existence of arbitrarily distant thresholds.

The known conditioned lower-bound claim is model-specific (Ailon,
https://arxiv.org/abs/1403.1307). No such restriction is transferred here to
unbounded-coefficient exact circuits. Neither the archive's matrix tests nor
these rational witnesses prove floating-point stability, a bit-complexity
improvement, or a new general FFT algorithm.
