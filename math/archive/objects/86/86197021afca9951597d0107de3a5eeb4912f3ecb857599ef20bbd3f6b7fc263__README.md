# Phase 18: Green products, Harper phases and exact certificates

The project seeks an exact `o(N log N)` DFT executor in scalar arithmetic. **None is established.** This bundle reproduces an exact impossibility theorem for scalar Harper resolvent functional calculus, an optimal-degree parity-resolved polynomial representation, a single four-phase (not fast) real spectral decomposition, and exact phase-gate vetos for particular complex-gauged noncommuting Green-sum products.

**First read:** `THEOREM.md`, then `CHECKPOINT.md`. Tests: `python -m unittest discover -s tests -v` from this folder.

Files:
- `harper_certificate.py` — self-contained exact finite-field Fourier polynomial audit.
- `weyl_gate.py` — exact modular diagonal similarity solver, permutation-invariant 1/2-cycle certificates, and Green product samples.
- `dual_intertwiner.py` — exact sparse generator exchange test and a one-probe positive control.
- `spectral_basis_control.py` — independent numerical real orthogonal Fourier basis and four-phase control.
- `*_audit.json` — saved reproducible outputs.
- `previous_full_phase17_checkpoint.zip` — all earlier research and test suites retained.

Prior-art attribution and limitations are in the full proof document.
