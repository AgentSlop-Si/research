# Reproducibility instructions

From the top-level directory, execute:

```bash
python run_all.py
```

That performs exact N=8 permutation enumeration, regenerates `SCREEN_RESULTS.json`, reruns the GF(12289) and GF(65537) rank audits, regenerates `FIELD_AUDIT_RESULTS.json`, and executes eight unit tests.

The original `fft_fourier_tail_rank_gate_2026-10-09.zip` archive is included unchanged as `prior_checkpoint_full.zip`. To independently recheck the earlier immediate checkpoint after extraction:

```bash
mkdir old_gate
cd old_gate
unzip ../prior_checkpoint_full.zip
# Locate run_new.py within the extracted fft_bilateral_gate_2026-10-09 folder.
```

**Reporting policy:** The new suite has eight tests. Earlier 55-minor and tail-rank checks were rerun once at the start of this session. We do not silently add prior test counts to eight or claim an unverified all-generation regression total.
