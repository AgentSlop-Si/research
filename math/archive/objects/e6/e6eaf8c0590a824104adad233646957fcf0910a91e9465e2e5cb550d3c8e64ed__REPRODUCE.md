# Reproduce this independent audit

Only Python 3's standard library is required. The uploaded scripts remain inert.

1. Copy this review directory to a new writable temporary directory (do not edit the sealed original).
2. Verify the snapshot: `python3 -I -S verify_seal.py`.
3. Execute only the independently authored checker: `python3 -I -S independent_checks.py phase16-independent-results.json`.
4. Compare `phase16-independent-results.json` with `INDEPENDENT_RESULTS.json`. Exact algebraic outcomes and counts must agree; final floating display digits can be platform-dependent.

The checker uses `source/` relative to its own location, not absolute workspace paths. Its only parsed Python AST inputs are certificate arithmetic strings in an allowlisted inert grammar and the test file for counting definitions; neither is executed or imported. It does not run any source command shown in the source README or logs.
