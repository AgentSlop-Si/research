# Green-family condition and spectral gates

Standalone verification bundle, 9 October 2026.

Start with `SUMMARY.md`. The full arguments are:

- `PROOF.md`: low-rank perturbation versus induced-1 conditioning, including the rank-one Householder/Green tradeoff and explicit-pass scope.
- `FORWARD_K_AND_COMBINED_GATE.md`: determinant-normalized spectral gates for forward full-cycle K factors, and the combined Green/forward-K family.

The proofs are self-contained. Earlier source files and uploaded archives are not needed to read the proofs or run the checks. The supported conclusions are family-specific factor-count and explicitly charged full-array-pass barriers. They do not settle the broader exact FFT target or claim literature priority.

## Reproduce the sanity checks

Requirements: Python 3, NumPy, and SymPy. The recorded run used NumPy 2.3.5 and SymPy 1.14.0.

From this directory:

    python independent_checks.py
    python spectral_companion_checks.py

Each program writes its corresponding JSON result file in this directory and prints a short PASS summary. Both scripts were independently authored. They neither import nor execute uploaded source code. They use deterministic random seeds recorded in their source or result files.

`independent_checks.py` uses SymPy for exact Fourier-4 ranks, sparse witnesses, and inverse identities; the scalar norm inequalities and larger cases use floating-point arithmetic. `spectral_companion_checks.py` uses NumPy for spectral, determinant, isolation, and boundary checks. Numerical checks corroborate the algebra but are not the all-size proof.
