# HERO #0 / Phase 6: Exact adaptive sparse Green-phase transform

**This ZIP is a scientific research checkpoint, not a universal fast FFT claim.**

## What is actually new in this project checkpoint

- An *adaptive and certified* mode-column detector that uses no given phase-support metadata and detects the `r` globally active chirp-demodulated block frequencies.
- An exact all-output `O((r+1)Q)` Green-cycle decoder for `Q=KM, M=Theta(log Q)` on the certified input class. When `r` is constant, the exact algorithm is linear-time. For generic input `r=M`, and there is **no** asymptotic improvement over FFT.
- A formal proof that this input class includes fully dense signals with maximal ordinary Hankel rank, so it does not collapse to the prior low-global-exponential-rank special cases.
- A finite-union coverage obstruction ruling out this mechanism as a universal solution by choosing arbitrary chirps from the finite family.
- An independent entropy/quantum-inspired obstruction for classical two-coordinate **unitary** gates.

## Run

Requires Python 3.11+ and NumPy. From this directory:

```
python verify_all.py
```

The operation-count implementation `phase6_exact.py` is exact over the prime field `2013265921` with primitive root `31`. Accepted inputs are certified by strict equality, and the outputs are compared with an independent full radix-2 NTT oracle.

The `phase6_complex.py` implementation uses the prior Green-cycle decoder and complex128; its support detection is **tolerance-based** and cannot certify mathematical exactness at arbitrary floating precision. The testing oracle (NumPy full FFT) is not called on its successful execution path.

## Important distinctions

`O(N)` is obtained only on an explicitly defined *restricted* input class. There is no all-input exact `O(N)` result here, no faster integer-multiplication theorem, and no comparison demonstrating faster practical throughput than optimized FFT libraries.
