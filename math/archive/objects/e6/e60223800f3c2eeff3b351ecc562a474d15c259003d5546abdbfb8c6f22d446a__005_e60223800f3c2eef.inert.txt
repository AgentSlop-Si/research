# Static audit: newest single-table guarded Word-RAM decoder (v3)

Date: 2026-10-09. Source directory: `newest_wordram_v3fft_wordram_packed_decoder_v3/`.

## Verdict

The new attachment's **single first-level table plus guarded additions is a valid way to remove the former second-table/transpose obligation**, under the stated fixed-accuracy, logarithmic-word RAM setting. The guard-bit proof checks out, including signed recentring, partial final blocks, and whole-word overflow. The first-level table must store **already packed** words, and every returned word must be charged. With that implementation, the stated coarse all-output approximate-transform complexity is asymptotically consistent.

However, **the submitted Python program is an algebra demonstration, not an implementation or timing validation of the claimed O(N) evaluator**. It builds phasor entries online, stores unpacked lane arrays, and re-packs every array on every lookup. Its reported counters omit these operations. Its experimental group keys also exceed its emulated word width. These are disclosed in part by the research note, and do not by themselves refute the corrected prepacked-table theorem.

No cached transform, prior-input relation, or answer contamination was found. The exact DFT target remains unmet: this is a randomized additive approximation on the permissive `eps L_box(x)/sqrt(N)` scale. The simpler mechanism is the contribution of the newest uploaded material, not an independent novelty claim by this audit. Novelty and the literature assertions were not independently established in this static audit.

## 1. Guarded packed sums are sound

Let each rounded signed integer lane satisfy `z in [-U,U]`, with `U=ceil(1/h1)+2` as in the prototype. Store `z+U`, so a lane lies in `[0,2U]`. For `G` group entries, choose

`q = ceil(log2(2UG+1))` and `s=floor(w/q)`.

The prototype uses an additional guard bit, which is conservative. For each lane, the biased accumulated sum is at most `2UG < 2^q`. A packed word containing at most `s` lanes therefore obeys

`sum_t H_t 2^(qt) <= (2^q-1) sum_{t=0}^{s-1} 2^(qt) = 2^(qs)-1 < 2^w`.

Every partial sum is nonnegative and bounded by the final maximum, so **neither inter-lane carry nor whole-word overflow occurs at any addition**. Mask/shift extracts exactly `H_t`. Subtracting `GU` gives the signed sum; multiplying by `h1/G` gives the average of all rounded group averages. Equal group lengths matter: the code rounds `k` upward to a multiple of `g`, so every group has the same weight.

This uses a list of ordinary bounded words, not one integer containing the entire output. At saved test parameters, `q=13`, four lanes occupy 52 bits in each 64-bit word. Python big integers implement the emulation, but the valid packed values themselves do not exceed the declared word width. A real RAM implementation must use bounded machine words and the prescribed lane count.

## 2. The claimed complexity needs prepacked table entries

For fixed accuracy and `delta=N^{-c}`:

- `B=Theta(log N)`.
- Descriptor width `p=O(loglog N)`.
- `g=floor(gamma log2(N)/p)=Theta(log N/loglog N)` for sufficiently large N.
- `k=Theta(log N)` and `G=k/g=O(loglog N)`.
- `q=O(log G)=O(logloglog N)` and `s=floor(w/q)`.
- Each real or imaginary B-lane table result needs `W=ceil(B/s)=O(q)` words, with both components adding only a constant factor.

Precompute all `2^(pg)<=N^gamma` indexed entries, including arbitrary treatment of unused bit patterns. Construct, quantize, bias and pack each full B-lane result in preprocessing. Work per entry can be polylogarithmic, so full table construction/storage is `N^gamma polylog N=o(N)`. Computing these phasors is not a unit-cost primitive of the listed RAM instruction set; a uniform finite-precision construction must be supplied, but allowing a polylogarithmic cost per entry preserves the bound.

Online descriptor/key construction costs `ceil(N/B) k=O(N)`. Returning a vector is **not a single unit-cost lookup**: load its W ordinary words and add them. All returned-word loads and additions together cost

`O((N/B) G W) = O(N loglog N logloglog N/log N)=o(N)`.

Finally, each output lane is extracted and rescaled once, costing O(N), in addition to the mandatory input scan. No uncharged global transpose or unbounded-length integer addition is necessary.

The attachment's formulas are asymptotic, not a practical threshold. For example, its model still predicts about **15.1 packed additions per output at N=2^1024**, before other costs. Its `max(1, floor(...))` also violates the `pg<=gamma log N` table bound at some small sizes: at `log2N=20`, the saved table exponent is 0.95 rather than at most 0.75. This disappears only beyond the stated sufficiently-large-N regime. The note saying the exponent is strictly less than gamma should be `<= gamma`; some saved points equal 0.75 exactly.

## 3. The uploaded executed-work path differs materially

Relevant source locations:

- Lines 124–137 build a group entry using `g*lanes` complex phasor evaluations.
- Lines 170, 182–185 create a fresh on-demand dictionary for each call and build a missing entry **inside the output loop**.
- Lines 186–189 store unpacked int64 lane arrays and **re-pack real and imaginary arrays at every lookup**, even on a cache hit.
- Lines 190–194 count only packed additions and logical group lookups.
- Lines 214–248 are a separate symbolic cost model; they do not instrument the actual work above.

At `N=1024` and `N=4096`, all saved cases have `table_entries==lookup_count`: every group lookup misses. Consequently, each case directly evaluates respectively **229,376** and **1,032,192** phasors online (`N*k`). It also performs respectively **114,688** and **516,096** scalar lane-packing iterations, omitted from `packed_word_adds` (34,384 and 129,024 respectively).

Even if the cache were prefilled with its current unpacked arrays, re-packing on every lookup costs `Theta(NG)=Theta(N loglog N)` under theorem parameters. With a constant grouping override and logarithmic k, it becomes `Theta(N log N)`. The way to obtain the theorem is to store already packed results and remove those packing loops from online execution.

The dictionary keys are tuples of descriptors, not packed one-word integer keys. Hashing/scanning them costs O(g); that can be included in the O(N) descriptor budget, but it does not demonstrate the stipulated one-word table addressing. More concretely, every saved case uses `g=4`: keys need **72 bits** at N=256 and 1024 and **76 bits** at N=4096, while the emulated word is 64 bits. The note explicitly calls this an algebra-testing override. Neither that override nor the symbolic counter ratios prove machine-word performance.

No timing measurements or full input-independent table construction are supplied. NumPy FFT is called twice per case for references (lines 97–104 and 272–274); these reference transforms **do not feed the decoder output**. The decoder receives only N, L, sampled atoms and parameters.

## 4. Sampling, phase and normalization checks

### Sampling bound

The signed atoms have phases `+1,-1,+i,-i`, sampled with probabilities proportional to absolute real/imaginary component masses. For `L>0`, their mean is `x/L`; multiplying the sample average by L is unbiased. A normalized phasor contribution has real and imaginary components in [-1,1]. Scalar Hoeffding plus component thresholds `eps_s/sqrt(2)` gives

`P(any complex-bin error > eps_s) <= 4N exp(-k eps_s^2/4)`.

Thus `k >= ceil(4 eps_s^-2 ln(4N/delta))` is correct. Rounding k upward to a multiple of g preserves the guarantee. All saved parameter records satisfy this formula.

The source uses floating masses, Python floating summation and `numpy.random.Generator.choice`, **not** the exact integer sorted-threshold sampler in the note. Thus the source does not certify exact sampling or arbitrary fixed-point dynamic ranges: mass summation can overflow, tiny masses can be lost, and finite RNG probabilities need analysis. The 15 saved cases use `delta=0.05`, while the symbolic model uses `delta=N^-1`; the two types of experiments are different and are not a single timing/probability experiment.

### Phase rounding

The exact integer formula `((Q*(num mod N)+floor(N/2))//N) mod Q` is a valid nearest circular-bin rule, including odd N and wraparound. A lane has phasor error at most

`pi/Q_start + pi*(B-1)/Q_slope <= eps_phi`.

The prototype's negative exponential matches its FFT convention. The proof is unaffected by choosing the opposite Fourier sign consistently. Slope descriptors are recomputed per block in code, rather than cached once per sample, but this is a constant-factor extra operation within O(N) descriptor work.

### Decoder and output scale

A complex value rounded independently by nearest h1 real/imaginary grids has error at most `h1/sqrt(2)`. Averaging group errors does not amplify it. Final h2 rounding adds at most `h2/sqrt(2)`. The stated decoder bound is correct in ideal arithmetic. The sampled transform scaling is also correct: `(h1/G) * sum(group rounded integer lanes)`, followed by `L/sqrt(N)`, produces the desired sampled normalized Fourier average.

The saved parameters imply total theoretical budget `0.45+0.1436396103067893=0.5936396103067893` in units of `L/sqrt(N)`. Saved total errors are at most 0.2111555800643266, and every saved error triple satisfies the triangle inequality. These are consistency checks on recorded data, not a probability guarantee.

### Zero and final partial block

`L=0` returns the all-zero spectrum before divisions in both sampling and decoding. This branch is correct for exact zero inputs; the supplied run does not test it. The last output block writes only `min(B,N-m0)` coefficients, and the packed-add counts in every JSON record exactly match the partial-block formula.

The cache key omits the lane count, but this is safe in the current forward loop: all earlier blocks are full length and the unique short block is last. A previously cached full entry may be used for the final short prefix; unused lanes are ignored. An entry first created at the short block is never later used by a full block. Always preprocessing full B-lane entries is simpler.

## 5. Small but necessary theorem/model completion items

These are repairable specification obligations in the uploaded note, not a new packing obstruction. The companion `../approximation/PACKING_AND_MODEL_THEOREM.md` now fills them with bounded-integer inputs, capped exact sampling, charged uniform constants, explicit error slack and output normalization; `../approximation/GUARDED_ADDITION_APPENDIX.md` replaces its second table with this attachment's simpler mechanism. Thus the combined audit has a model-specific proof, rather than an unresolved packing condition:

1. **Input representation:** state a common fixed-point scale and O(log N) bits per component. The total integer mass may need component bits plus `ceil(log2(2N))`, still O(1) words. Arbitrary floating-point values with independently encoded enormous exponent ranges are not automatically covered.
2. **Randomness/time qualifier:** exact uniform integer thresholds for arbitrary total mass generally use rejection sampling. Without a cap this yields expected, not deterministic worst-case, sample-generation time. Either state expected O(N) time, or cap retries, allocate part of delta to this event, and use the remaining failure budget in Hoeffding. With O(log N) samples and O(log(N/delta)) trials per sample the bounded overhead remains polylogarithmic, hence O(N).
3. **Allowed arithmetic:** the listed RAM primitives omit division/modulo, square root and transcendental functions. Constant-denominator reduction and rounded division should be realized by precomputed reciprocal multiplication with correction, fixed-point approximation, or small tables; power-of-two N simplifies modular reduction. In particular each lane can recover `(H/G)-U` using a precomputed reciprocal and final rounding in O(1) operations. The one-time reciprocal/square-root work is at most polylogarithmic. Do not silently assume Python division or NumPy exp is a word instruction.
4. **Rounding margin:** reserve explicit positive slack for finite phasor generation, reciprocal/square-root approximation, and final output representation. The displayed four-term epsilon split spends the entire epsilon budget before those errors. Shrinking h1/h2 or the other allocations by fixed factors repairs this without changing the asymptotics.
5. **Output width:** O(1) words per coefficient remains possible, but specify precision relative to the input scale and `L/sqrt(N)`; an unexplained fixed absolute grid need not work for very small L. Returning only a shared scale and packed normalized values is not the same output convention as explicitly writing N ordinary coefficients unless declared.
6. **Uniformity/domain:** state N>=1, valid positive h1,h2 and error parameters, exclude NaN/Inf, and handle the sufficiently-small-N fallback. The Python float/int64 program is not an implementation over arbitrarily growing RAM words or arbitrarily tiny fixed epsilon.

## 6. Evidence and claim boundaries

The 15 saved main cases are present and internally coherent. The research note additionally claims a 100-case stress test and 100 Gaussian sampling trials at each size, but **their scripts, raw results and logs are not in this archive**. Those claims cannot be independently audited from this bundle.

The all-bin norm remains the central limitation: for dense unit-magnitude random-phase data, `L_box/sqrt(N)=Theta(sqrt(N))`, while ordinary unitary coefficients are typically much smaller. No exact DFT result, ordinary machine-precision relative accuracy, useful per-bin relative error, integer-multiplication advance or practical FFT speedup follows from this archive. No literature novelty conclusion follows from the document's unsuccessful search for a matching paper.

**Recommended status:** the guarded single-table coarse approximate theorem has a model-specific proof when combined with the explicit finite-arithmetic/randomness specifications in the companion reports; the uploaded program verifies only small-scale algebra and saved-data consistency. The complete O(N) evaluator has not been implemented or benchmarked. Exact-transform goal remains open.
