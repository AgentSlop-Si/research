# Hero #1 Phase 17 — highest-priority exact FFT gate

**OPEN:** No exact all-input sub-`N log N` classical FFT is established by Phases 1–16.

## Stop repeating these paths

1. Full-rank local chirp frames by themselves: Phase15 proves stationary families collapse to a gauged Cooley–Tukey circuit, and a more variable family can be exponentially ill-conditioned.
2. Exact O(N) Green inversion by itself: Phase16 exhibits `L=7I+2S+D` with cond<=2.5 and O(N) inverse, yet `LF=F(7I+S+2D^-1)` has dense forcing and is FFT-equivalent up to O(N) operations.
3. Any fixed-q graph union of shift/modulation Weyl atoms: by `S^aD^b F=F D^-a S^b`, it is just O(qN) input preconditioning. **Even arbitrary irregular permutation graph Green operators** `7I+D+2P_pi` have O(N) inverses, cond<=2.5, and fully dense FFT-equivalent forcing (Phase16 Theorem1b).
4. Networks of bounded-size **unitary** pair/local gates, however arranged or cached: Ailon (2013) gives an Ω(NlogN) gate lower bound; the project reproduced the tight radix-2 case and a robust approximate corollary.
5. Low-rank nonunitary stochastic sketches: exact matrix rank and worst-case operator error barriers from Phase13/14 persist. They may be useful for input-specific approximation but cannot claim all-input exactness.
6. Sparse L and sparse LF in the same original basis with a constant-width local row stencil: standard Fourier uncertainty and polynomial zero arguments forbid this in the worst case; read older Green gate files.

## Actual next experiment, in priority order

**A. Global forcing compression certificate (nonunitary, across blocks).** Search for a genuinely new sparse/dense factored source `B_N` together with an explicit linear-time invertible `L_N` such that `B_N=L_N F_N`, but where evaluation of `B_N x` can be implemented with `o(N log N)` total scalar work for *all* x. Require a distinct execution DAG not reducible to q=o(logN) Weyl-preconditioned FFT and not built by adding an already-costly Fourier routine under another name. Test identities first over finite fields, and supply a complete all-size argument.

**B. Certified nonlocal algebraic-sharing claim.** Enumerate common subexpressions across Fourier/Weyl residue classes, identify how cost scales with N, and require a reusable symbolic operation identity for arbitrary input variables. Random data collision reuse alone is insufficient. Any measured rank deficit must include the lifting/reconstruction cost and all outputs.

**C. Unit conditioning and bit-precision gate.** If using nonunitary global factors, track condition numbers of all prefixes, size of intermediate values, exact divisions, and bit complexity. Ailon 2014/2015 conditioned-model results are model-limited but important warnings.

## Acceptance tests for a claimed breakthrough

- Exact equality for every input (or explicitly state an epsilon and a norm guarantee), not only 20 random vectors.
- Independent finite-field **all-basis checks**, wrong-sign/wrong-shift mutation failures, and an algebraic proof for arbitrary N.
- A *fully priced* DAG: arbitrary-input preprocessing, scalar additions/multiplications, depth, writes, memory, roots/prime selection and precision. Account for old/borrowed rows and cache invalidation.
- Worst-case complexity rigorously `o(N log N)` under a stated machine model, or honestly mark the candidate as constant-factor / structured-input / approximation only.
- Compare against Phase15 common-frame collapse and Phase16 Weyl-Green plus arbitrary-permutation Green examples before claiming new noncommuting sharing.

Keep all previous ZIPs inside the next archive or provide verified paths and source hashes. Never claim Ailon's unitary lower bounds cover unrestricted arithmetic circuits or a quantum state-preparation/readout setting automatically.
