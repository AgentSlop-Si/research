# Deferring corrections across FFT levels

## Research contract and relation to the existing work

The target remains a uniform, sequential algorithm producing the full transform
of an arbitrary fresh input with total work `o(N log N)`. Input-dependent caches
from a previous problem, partial outputs, and free preprocessing are excluded.
An exact-arithmetic claim must also be distinguished from bit complexity and
finite-precision numerical performance.

The canonical research checkpoint was reviewed before this experiment. Exact
subtree collisions, sparse baseline menus, short annihilating filters, fixed
leaf tables, selected-bin queries and local circuit searches were not rerun.
The prior cache-rewrite package remains valid for its related product-graph
workloads, but it does not change the fresh-input FFT bound.

This pass asks a narrower question: after replacing expensive phase-weighted
butterflies by a reusable common core, can *all* omitted corrections be fused
into only a few linear features? This is a static operator question, not a
search for repeated numerical inputs.

## 1. Deferral is algebraically valid, but mixed terms matter

Write the exact FFT stages as `B_1,...,B_L` and proposed replacement stages as
`C_1,...,C_L`. Let `R_j=B_j-C_j`. Matrix multiplication is ordered. The exact
telescoping identity is

\[
B_L\cdots B_1-C_L\cdots C_1
=\sum_{j=1}^{L}
B_L\cdots B_{j+1}R_jC_{j-1}\cdots C_1.
\]

The future stages on the left of each correction are the **true** stages `B`.
Replacing those by `C` drops interactions between corrections. Already for two
stages,

\[
(C_2+R_2)(C_1+R_1)-C_2C_1
=C_2R_1+R_2C_1+R_2R_1.
\]

The last term cannot be silently omitted. In the 8-point exact modular example,
using only single-correction terms gives eight wrong matrix entries. For input
basis vector `e_3`, correction output 1 should be 15 modulo 65537; the incomplete
expansion gives 3838. The missing contribution is 61714 modulo 65537.

`telescope()` verifies the complete matrix identity, hence every input vector,
at each tested length. It is an audit implementation using dense matrices. The
identity itself does not supply a cheaper way to apply the products of stages.

## 2. A general common-core rank bound

Let `N=2m`, and write the DFT after the even/odd input permutation as

\[
\mathcal F_N=
\begin{pmatrix}F_m&D F_m\\F_m&-D F_m\end{pmatrix},
\qquad D=\operatorname{diag}(1,\omega_N,\ldots,\omega_N^{m-1}).
\]

Here `omega_N` is a primitive Nth root. The result applies over the complex
numbers and over fields of characteristic not 2 that contain such a root.

Allow **any** fixed `m by m` common core `G`, not necessarily invertible, and
any diagonal replacement `D_0`. Consider

\[
\mathcal C_{G,D_0}=
\begin{pmatrix}G&D_0G\\G&-D_0G\end{pmatrix}.
\]

Set `A=F_m-G` and `B=D F_m-D_0G`. An invertible butterfly row operation takes
the difference to a block diagonal matrix:

\[
\frac12\begin{pmatrix}I&I\\I&-I\end{pmatrix}
(\mathcal F_N-\mathcal C_{G,D_0})
=\begin{pmatrix}A&0\\0&B\end{pmatrix}.
\]

Consequently its rank is `rank(A)+rank(B)`. But

\[
B-D_0 A=(D-D_0)F_m.
\]

Since `F_m` is invertible and rank is subadditive,

\[
\boxed{\operatorname{rank}(\mathcal F_N-\mathcal C_{G,D_0})
\ge \operatorname{rank}(D-D_0)
=\#\{k:D_{kk}\ne(D_0)_{kk}\}.}
\]

For `D_0=I`, only `k=0` matches, giving

\[
\boxed{\operatorname{rank}(\mathcal F_N-\mathcal C_{G,I})\ge N/2-1.}
\]

This holds for every choice of `G`, so improving the smaller common core alone
does not remove this obstruction. The bound is tight for the class: choosing
`G=F_m` gives equality, although computing that core is precisely the smaller
DFT cost that still must be paid. More permissive diagonal replacements leave
a lower bound equal to the number of unmatched phases.

Joint invertible changes of input and output basis preserve the rank of the
residual. A different baseline architecture is not excluded by this statement.

## 3. The explicit butterfly core

Let `L=log_2 N`, and let `rev_L(j)` reverse the L binary digits of j. Replacing
every phase by 1 in the radix-two graph gives

\[
C_N[k,j]=(-1)^{\langle k,\operatorname{rev}_L(j)\rangle_2}.
\]

This is a Walsh-Hadamard matrix with a bit-reversal permutation. The exact
positive-exponent Fourier matrix has entries `F_N[k,j]=omega_N^(kj)`. A
negative-exponent convention conjugates the matrix and leaves these rank and
support conclusions unchanged.

Define `E_N=F_N-C_N`. It has at least `L+1` independent kernel vectors:

- the impulse at index zero;
- for each `s=0,...,L-1`, the indicator of positions `j=2^s(2t+1)`.

These vectors have disjoint nonempty supports. For the indicator at level s,
write `M=N/2^(s+1)`. Its DFT is zero unless M divides k, and otherwise equals
`M*(-1)^(k/M)`, by a geometric sum. The sign-matrix transform gives exactly
the same result by summing over the free binary digits. The impulse also maps
to the all-ones vector under both transforms. Therefore, for every N,

\[
N/2-1\le\operatorname{rank}(E_N)\le N-\log_2N-1.
\]

The exact upper bound is attained in every certified size from 2 through 256.
This package **does not prove attainment for all powers of two**. It proves
the lower and upper bounds for all such N and exact rank at the listed finite
sizes.

| N | Exact certified complex rank | Kernel dimension |
|---:|---:|---:|
| 2 | 0 | 2 |
| 4 | 1 | 3 |
| 8 | 4 | 4 |
| 16 | 11 | 5 |
| 32 | 26 | 6 |
| 64 | 57 | 7 |
| 128 | 120 | 8 |
| 256 | 247 | 9 |

## 4. Exact support count and the cost of a direct correction

For nonzero indices let `v_2(j)` be the number of trailing binary zeros.
An entry of `E_N` vanishes precisely when one index is zero or

\[
v_2(k)+v_2(j)\ge L-1.
\]

When the sum is at least L, both entries equal 1. At sum `L-1`, both equal
-1. Below that sum, the Fourier entry is neither 1 nor -1, so cannot equal
the sign-matrix entry.

There are `N/2^(s+1)` columns with valuation s, and each has exactly `2^(s+1)`
zero entries in the difference. They contribute N zeros for each s. Column
zero contributes another N. Hence

\[
\boxed{\operatorname{nnz}(E_N)=N^2-N(\log_2N+1).}
\]

This is an all-length support formula, independent of any numerical threshold.
At N=256 it gives 63,232 nonzero entries. Applying this matrix by explicit
row dot products takes quadratic work. Building and storing it explicitly also
has quadratic size. Writing down a compact telescoping expression does not
make those costs disappear; it requires a better evaluation circuit.

Neither this support count nor the rank bound is a lower bound against all
structured algorithms. The DFT itself is dense yet has FFT factorizations,
and the identity matrix has full rank yet is cheap to apply.

## 5. Why the modular certificates establish complex ranks

For power-of-two N, the entries belong to the ring

\[
\mathbb Z[z]/(z^{N/2}+1).
\]

Choose an odd prime p and a primitive Nth root w modulo p. Substitution
`z -> w` defines a ring homomorphism. If an r by r minor has a nonzero
determinant modulo p, its cyclotomic determinant was not zero. Thus it proves
a complex rank lower bound of r. Combined with the explicit `L+1` kernel
vectors, it proves exact rank when `r=N-L-1`.

Each certificate includes the prime, primitive root, original row and column
indices of such a minor, its determinant, and the relevant size and bounds.
Replay reconstructs the matrices, recomputes the determinant using an
independent arbitrary-precision implementation, and checks the kernel vectors.
The two primes used are 65537 and 998244353; both support every tested length.
Small N=2,4,8,16 cases are also ranked directly over the cyclotomic field with
rational coefficients. The earlier project's exact field implementation is
reused unchanged.

Tests cover the complete telescoping matrix equality, the failure of the
incomplete expansion, arbitrary common cores, tightness, corrupted certificates,
the support formula, field/root validation, and avoidance of machine-integer
overflow in modular matrix products. Sixteen certificates pass over two primes,
along with eight tests and 25 different common-core checks.

## 6. What this establishes about the main goal

The tested route does not produce a new `o(N log N)` algorithm. In particular:

1. An explicit small-rank final correction cannot represent this residual
   for every fresh input; its rank grows at least linearly with N.
2. Directly applying the fused correction is quadratic.
3. The correct deferred expression retains products of true FFT stages; its
   evaluation cost is not shown to improve on FFT.

A faster **structured high-rank correction circuit** remains logically possible.
So do architectures outside the shared-core model. This audit does not assert
a general FFT lower bound and does not contradict results in more permissive
exact-arithmetic models. The existing cache-reuse speedup likewise remains a
valid workload-specific engineering result.

The missing constructive result is still an explicit uniform family of circuits
whose full cost is below `N log N`, with scalar preparation, corrections,
indexing, representation sizes and all outputs charged. No new such family was
found in this pass. This conclusion is separate from whether the narrow rank
lemma or support formula has appeared in prior literature; no novelty claim
is made for standard linear-algebra identities.
