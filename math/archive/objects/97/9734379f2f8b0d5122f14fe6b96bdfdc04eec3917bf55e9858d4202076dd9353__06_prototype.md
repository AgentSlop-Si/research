## Mathematical and program scope

v10 arbitrary-length approximate normalized DFT lift through Q=next-power-of-two(N), using nearest-grid residual Taylor or Jacobi-Anger/Chebyshev expansion and a randomized dyadic chirp row, then majority-grid aggregation.

## Control/dataflow and mathematical assessment

The decomposition uses scale sqrt(Q/N), grid phases and residual theta in [-1/2,1/2]; Taylor/Bessel tails control each output error by tail*||x||2 through Cauchy-Schwarz. Reusing the same chirp state across terms is the intended fixed-output linearity/variance mechanism. The statistical radius is a coordinatewise uniform-over-outputs bound for a fixed input and random rows, conditional on the core theorem; it is not a spectral operator norm or exact all-input transform. fixed_row_g algebraically inverts 2N*comb(rows,s)*g^(-2s).
