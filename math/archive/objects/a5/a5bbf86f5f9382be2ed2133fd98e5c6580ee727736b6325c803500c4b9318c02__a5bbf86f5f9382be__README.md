# A fresh-input side-information certificate with a linear full evaluator

This package gives an **exact O(N) scalar-operation full DFT for freshly
verified binary-index rank-one tensors**. It reads and verifies the original
N inputs, constructs every root power it uses, and returns all N explicit
outputs. It does not recover the spectrum from a few Fourier measurements.
It therefore supplies one constructive, restricted bypass of the joint-orbit
measurement interface. It is **not an arbitrary-input FFT improvement** and
does not establish literature-wide novelty.

The candidate is `tensor_sideinfo.py`. Its executable arithmetic is modular;
the identity also holds over the complex numbers. The implementation calls no
FFT backend. `run_audit.py` uses independent direct DFT and radix-two FFT
references only to check the candidate.

## Exact certificate from the original input

Let N=2^d, and write j=sum_l j_l 2^l. The accepted form is

    x_j = c product_(l=0)^(d-1) a_l(j_l).

The factors are discovered, rather than supplied as an unchecked promise:

1. Validate and scan all inputs. The all-zero input is immediate.
2. Choose a nonzero pivot p and c=x_p. In the code this is the first nonzero
   pivot, so no magnitude comparison or ordering of field elements is used.
3. With one inversion of c, compute

       r_l = x_(p xor 2^l) / c,
       a_l(p_l)=1,  a_l(1-p_l)=r_l.

4. Generate every c product_(l in J) r_l by a doubling tree. The tree takes
   exactly N-1 scalar multiplications and writes N scalars.
5. Compare each generated scalar with x_(p xor J), charging all N reads,
   index operations and comparisons. Accept only if every comparison passes.

The comparisons are a complete exact certificate: they check every coefficient
of the displayed tensor identity. A failed certificate returns `None`; a
general FFT fallback, if desired, remains paid work outside this package.

Over a prime field, every nonzero pivot is invertible. The code also works in
an odd residue ring when this chosen pivot is a unit, and raises an error if
it is not. It does not perform or assume an uncharged primality test.

## Shared full-output evaluation

For P(z)=sum_j x_j z^j, the certified identity implies

    P(z) = c product_l [a_l(0) + a_l(1) z^(2^l)].

Let omega be the supplied primitive N-th root, with the positive-exponent
DFT convention. Set M_l=2^(d-l) and

    f_l(k) = a_l(0) + a_l(1) omega^(k 2^l).
    S_d(0) = c.
    S_l(k) = f_l(k) S_(l+1)(k mod (M_l/2)),   0 <= k < M_l.

The suffix product at level l+1 is periodic in k with period M_l/2:
every factor there uses a power at least 2^(l+1). Consequently the recurrence
computes the exact suffix product, by downward induction. At l=0,

    S_0(k) = P(omega^k),   0 <= k < N.

There are sum_l M_l = 2N-2 evaluated states. Each uses two scalar
multiplications, one addition, two array reads and one array write.
The code constructs the entire N-entry power table of omega with N-1
multiplications, then selects powers by the explicit index k << l.
No automorphism expansion, large integer packing, convolution, or small
Fourier measurement decoder occurs inside a gate.

For the odd orbit alone, the same induction can retain only odd k at each
level: there are N-1 states. This is an identity observation, not a separate
implemented path or an additional measured result. The delivered candidate
computes all N outputs.

This class includes dense signals with independently chosen nonzero factors
at each bit position. For example, factors (1,2), (1,3), (1,5) give
(1,2,3,6,5,10,15,30). Generic such data need not be periodic or a geometric
progression. The restriction is still substantial: d+1 parameters describe
the signal, and arbitrary dense binary or complex vectors do not satisfy the
certificate.

## Fully charged arithmetic and model

For an accepted nonzero input and N>=2, write d=log2 N. The implementation
performs exactly:

| Work | Multiplications | Additions | Other work |
|---|---:|---:|---|
| Discover factors | d | 0 | One inversion, d neighbor reads |
| Regenerate and verify | N-1 | 0 | N exact comparisons; O(N) reads, writes and indices |
| Validate supplied root | d-1 | 0 | Exact comparison with -1 |
| Prepare all root powers | N-1 | 0 | N table writes |
| Evaluate all suffix states | 4N-4 | 2N-2 | O(N) reads, writes and indices |
| **Total** | **6N-7+2d** | **2N-2** | **One inversion and O(N) additional work** |

Input validation and the pivot scan visit all N values. N=1 uses no field
arithmetic. The zero path validates and prepares the root table, then writes
N zeros; it is also linear. The current code keeps O(N) scalar storage in
addition to the input. All stage arrays are explicit.

In the exact complex-register model the division, scalar arithmetic, exact
equality tests and word-sized indices must be allowed and charged as above.
The primitive root is supplied; constructing that exact complex constant is
not claimed to be free. The same supplied-root convention must be used for a
comparison FFT. This restricted result places no requirement on arbitrary
dense inputs, so it does not contradict general FFT circuit restrictions.

In the modular implementation, let b be the modulus bit length. Multiplication
followed by reduction involves O(b)-bit operands and can conservatively be
charged O(b^2) elementary bit work. More generally, write M_mod(b) for that
cost and I(b) for one inversion: the bound is
O(N M_mod(b) + I(b) + N log N), including index work. One ordinary extended-Euclid inversion is
paid; even the loose bound of O(b) divisions of O(b)-bit numbers gives
O(b^3). Thus a conservative fully charged bound is

    O(N b^2 + b^3 + N log N) bit operations,
    O(N b) stored bits plus O(N log N) index/address bits.

Faster multiplication and inversion can improve that bound. The fixed prime
65537 used for larger tests supports only N<=65536; these tests are not an
all-N finite-field or bit-complexity theorem. The algebraic recurrence is
uniform for every power-of-two N in a field containing the supplied root.

For N>1 the root check is omega^(N/2)=-1. This implies omega^N=1 and is a
principal dyadic root over every odd residue ring: for a nonzero exponent
a=2^s u with u odd, shift by N/2^(s+1) changes the root power by -1, so the
sum over each even-length shift cycle cancels. N is a unit in such a ring.
The positive composite-ring test is therefore mathematically valid.

## Stability and approximate certificates: theorem, not floating-point code

For complex inputs, choose a pivot of maximum magnitude instead of the
first nonzero pivot. This requires O(N) magnitude comparisons, a separate
operation from purely algebraic complex-register arithmetic. Then |r_l|<=1
and both entries of each normalized factor have magnitude at most one.
The implemented first-nonzero rule is not a numerical stability guarantee
over the rationals or complex numbers: its ratios can be arbitrarily large.
Every exact intermediate suffix has magnitude at most

    2^(d-l) |c| <= N ||x||_infinity.

There is no exponential-in-N intermediate growth or division by an input
smaller than the maximum input magnitude. This is an absolute-stability
statement; a Fourier coefficient close to zero still has poor relative
conditioning, as in ordinary Fourier evaluation.

A quantitative local-error bound follows by telescoping products. Suppose
each effective factor used on an output's path differs from the exact
f_l(k) by at most e, including the local multiplication error, and e<=1/d.
The exact factors have magnitude at most two. Then

    |product_l fhat_l - product_l f_l|
      <= d e (2+e)^(d-1) <= N d e.

An error delta_c in the pivot scale adds at most 2N |delta_c|. Thus the full
absolute output error is bounded by

    N d e |c| + 2N |delta_c|.

Under the usual stable complex-operation model, O(u) ratio/arithmetic errors
and root-power errors eta give e=O(u+eta). Sequential power-table construction
from a root with O(u) error gives the conservative eta=O(Nu) when Nu is small,
so O(u N^2 log N ||x||_infinity) is a conservative polynomial forward bound.
Exponent range, roundoff constants, and root approximation must be charged;
the present code does not implement directed rounding or certify such bounds.

For a nonexact tensor fit xhat, the independently checked residual supplies
another useful deterministic certificate:

    max_k |DFT(x)_k - DFT(xhat)_k| <= ||x-xhat||_1.

The right-hand side costs one complete input scan after regenerating xhat.
For a unitary DFT divide it by sqrt(N). A rounded implementation would need
outward-rounded residual bounds. The modular implementation accepts only
exact equality; neither floating-point equality nor an unchecked small
residual is used to claim exact outputs.

## Verification

Run `python run_audit.py` from this directory. The recorded audit passes:

- 291 exact full-output cases, including every coordinate basis through
  length 32, zero/constant controls, dense tensor examples, three prime
  fields, a composite-ring control, and lengths through 4096.
- 18 fresh dense non-tensor inputs correctly declined before root-table
  preparation or output evaluation.
- Eight invalid input/root/pivot cases rejected.
- Exact arithmetic and preparation counts checked on every accepted
  nonzero case, with size-indexed records in `results.json`.

The measured claim is correctness and the charged count, not wall-clock
superiority over an optimized FFT library. `evaluate` assumes a certificate
issued by `certify`; manually forged dataclass instances are not authenticated.
`transform` is the safe fresh-input entry point.
