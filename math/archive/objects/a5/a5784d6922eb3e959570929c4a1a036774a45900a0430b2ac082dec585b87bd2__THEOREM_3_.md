# Sparse-Preconditioned Fourier Separation Barrier (SPFSB)

**10 October 2026 — project research draft — proof supplied, publication priority unverified**

This report proposes a mathematically precise *new extension within the inspected FFT project archive*: an additive quasiseparable/Green rank barrier that survives multiplication by an arbitrary invertible **row-sparse preconditioner**. It is **not** an exact O(N) FFT construction, not a general arithmetic-operation lower bound, and not a claim that an expert could not have proved or published an equivalent statement elsewhere.

## 1. Model and statement

A complex `N x N` matrix `T` is *totally nonsingular* (or *full spark in every square minor*) if **every square submatrix has nonzero determinant**. The unnormalized `p`-point complex DFT `F_p[j,k]=exp(-2 pi i jk/p)` has this property for each prime `p` (Chebotarev's theorem). The term *full spark* is sometimes applied to rectangular matrices; our assumption throughout is the stronger unambiguous *all square minors nonzero* property.

For a bijective row-position map `a : {0,..,N-1}->{0,..,N-1}` and an independent column-position map `b`, define the **separation rank** of `H` under `(a,b)` to be at most `r` if

- `rank H[R,C]<=r` whenever `max a(R) < min b(C)`, and
- `rank H[R,C]<=r` whenever `max b(C) < min a(R)`.

The matrix may otherwise be dense. Independent permutations, nonzero diagonal left/right gauges and arbitrary non-affine cyclic Green inverses fit the model with `r=1`.

Let `P` be invertible and contain at most `s>=1` **nonzero coefficients per row**, where `s` is an integer. Let

    H = H_1 + ... + H_Q

with `Q>=1`, and suppose branch `H_j` has separation rank at most `r_j` in a possibly independent row/column order pair. Let `R=sum_j r_j`. Let `d` be the number of distinct order pairs among the branches, counting identical row/column order pairs only once (`1<=d<=Q`).

**Theorem (SPFSB).** If `T` is totally nonsingular and

    T = P^(-1) H,

then, with `m=floor(N / (s*2^d))`,

    **m <= R.**                                             (1)

Equivalently, a necessary condition is

    N < s*2^d * (R+1).                                      (2)

All matrix coefficients may be arbitrary complex numbers, and the row/column permutations in distinct summands can be completely unrelated. **Input dependence of the coefficient matrices is not permitted**: the claim concerns a fixed exact linear factorization valid on all vectors.

The transposed statement also holds for `T=H P^(-1)` if `P` has at most `s` nonzeros **per column** (apply the theorem to the transposes and interchange row/column orders).

## 2. New proof: an asymmetric simultaneous-separation lemma

**Lemma.** Let `X` and `Y` be finite nonempty row and column sets of sizes `u,v>=2`, each carrying its own injective position map `a` and `b` into a common linearly ordered label set. Then subsets `X' subset X` and `Y' subset Y` of sizes `floor(u/2)` and `floor(v/2)` exist such that either **every** row position precedes **every** column position or vice versa.

**Proof.** Let `h=floor(u/2)`, `k=floor(v/2)`. Take the lowest and highest `h` rows, denoted `X_lo, X_hi`, in row order; and lowest and highest `k` columns, `Y_lo,Y_hi`, in column order. If `max a(X_lo)<min b(Y_hi)`, choose `X_lo,Y_hi`. Otherwise, supposing the opposite pair `X_hi,Y_lo` also fails would give

    max a(X_lo) >= min b(Y_hi) > max b(Y_lo)
                  >= min a(X_hi) > max a(X_lo),

an impossibility. Thus the opposite pair is separated. (The strict middle comparisons follow because the chosen lower and upper subsets are disjoint.) QED.

**Corollary.** For any `d` specified independent order pairs and any initial sets `X_0,Y_0`, repeated application yields sets `X_d,Y_d` satisfying separation in *every* specified pair, with sizes

    |X_d| = floor(|X_0|/2^d),
    |Y_d| = floor(|Y_0|/2^d).

Separation survives further subset restriction.

## 3. Rank preservation under full-spark mixing

**Lemma.** If `T` is totally nonsingular, `B` is an invertible `N x N` row-sparse matrix with at most `s` nonzeros per row, `X` is a row set of size `m`, and `Y` is a column set of size `c>=s*m`, then

    rank (B T)[X,Y] = m.                                    (3)

**Proof.** Let `S` be the union of the support coordinates of the rows `B[X,:]`. Then `|S|<=s*m<=c`. The `m` selected rows of invertible `B` are independent, so `rank B[X,S]=m`. Since `T` has *every square minor nonzero*, the `|S| x c` matrix `T[S,Y]` has full row rank `|S|`. It thus admits a right inverse `V` with `T[S,Y] V=I_|S|`. Consequently

    B[X,S] = (B T)[X,Y] V,

and hence `rank (B T)[X,Y]>=m`; the opposite inequality is trivial. QED.

Note this lemma is **not true for general composite-length Fourier matrices**: some rectangular submatrices are rank deficient. That is why the strongest Fourier corollary here explicitly assumes prime length.

## 4. Proof of main theorem

Choose any initial row set `X_0` of size `floor(N/s)` and take `Y_0` to be *all N columns*. Apply the asymmetric separation lemma once for each of the `d` distinct order pairs. The result `X,Y` satisfies

    |X| = floor(N/(s*2^d)) = m,
    |Y| = floor(N/2^d) >= s*m.

Every `H_j[X,Y]` has rank at most `r_j` by simultaneous separation, so by rank subadditivity

    rank H[X,Y] <= R.

On the other hand, `H=P T` and the full-spark rank-preservation lemma (3) gives

    rank H[X,Y] = m.

Therefore `m<=R`. This proves (1). If `floor(N/(s*2^d))<=R`, then `N/(s*2^d)<R+1`, proving (2). QED.

## 5. Consequence for exact prime Fourier circuits

Take `T=F_p` with `p` prime. Let `G_j=(I-D_j P_{sigma_j})^(-1)` be invertible weighted Hamiltonian-cycle Green resolvents. Each has separation rank one in its cycle order. Independently chosen invertible monomial gauges on the **left and right of each summand** preserve separation rank one, possibly under independent row/column permutations.

Now let `G_1,...,G_t` be a *prefix product* of individual Green factors, allowing arbitrary invertible diagonal gauges and coordinate permutations between them. Its inverse `P` is a product of `t` row-two-sparse matrices and monomial matrices; therefore each row of `P` contains at most `s=2^t` nonzero entries. Suppose

    F_p = (G_t ... G_1) (H_1+...+H_Q),

where each `H_j` is an independently gauged/permuted Green branch. Then the theorem implies

    floor(p / 2^(t+d)) <= Q,
    p < 2^(t+d) * (Q+1),                                    (4)

where `d<=Q` counts distinct terminal order pairs. In the unrestricted order-pair worst case `d=Q`, the necessary condition simplifies to

    **p < (Q+1)*2^(t+Q).**                                  (5)

If `t` and `Q` are fixed constants, the architecture fails for all sufficiently large primes, irrespective of its cycle orders, weight choices, phases or conditioning.

In particular, a *single* Green prefix followed by a *two-branch* Green sum (`t=1,Q=2`) is impossible for every prime `p>=29`; two individual Green prefixes followed by two branches (`t=2,Q=2`) are excluded for all prime `p>=53`. The theorem can be transposed to rule out the corresponding single-Green *suffix* architectures.

If many branches share a common order pair, the `d` refinement yields a stronger requirement. For fixed `t,d`, necessarily `Q >= p/2^(t+d)-1`: merely piling more globally dense scans on the same relative row/column ordering does not achieve a constant-size representation.

### Important interpretation

This is a **representation lower bound**, not an unconditional lower bound on the number of arithmetic operations in *any* FFT algorithm. It counts terms in a chosen formula. A fused implementation could share internal operations; an algorithm outside this formula is not restricted by it. Likewise, a product of **two independently additive Green sums** generally has a dense inverse in each additive stage, and is *not* covered by this theorem.

## 6. Quantitative approximate corollary (conditional on chosen weights)

For a candidate `M=P^(-1)H` in the same architecture and the certificate sets `X,Y`, let `q=R<m`. The Eckart–Young theorem implies

    ||T-M||_2 >= sigma_(q+1)((P T)[X,Y]) / ||P||_2 > 0.    (6)

Indeed `H[X,Y]` has rank at most `q`, while `(PT)[X,Y]` has rank `m`. This lower bound is positive for a **fixed** complex preconditioner `P`; it does **not** give a uniform condition-independent approximation gap because the displayed singular value can be arbitrarily small. Do not substitute such a gap for the previous additive theorem's different operator-norm result.

## 8. Reproducibility

Run

    python verify.py --repetitions 4 --json RESULTS.json

The verifier constructs random non-affine Hamiltonian cycles, arbitrarily permuted and gauged term matrices, potentially zero edge weights, arbitrary independent interstage monomial shuffles, sparse inverse prefixes, and a primitive `p`th Fourier root in an auxiliary prime field. For each sample it extracts the predicted simultaneous rectangle and checks the ranks. The default 24 trials include lengths `p=13,29,53,101,131,257` and depths from `t=0` to `t=3` with terminal `Q=2` or `3`.

**These finite-field checks do not prove that every complex Fourier minor is nonsingular.** The proof of the theorem uses the characteristic-zero Chebotarev theorem; modular test zeros can occur accidentally, and no converse is assumed. Verification output is stored in `RESULTS.json`.

## 9. Sharp remaining constructive gate

The smallest architecture this argument deliberately does **not** exclude is

    M_N = (G_1+G_2) (G_3+G_4),                              (7)

with distinct non-affine Green cycles, independent per-branch gauges and arbitrary charged interstage routing. To obtain an **actual** exact all-input FFT, prove for every length `N` the two Fourier covariance conditions

    M_N S = D M_N,
    M_N e_0 = ones / sqrt(N)

for unitary `U_N`, where `S e_j=e_(j+1 mod N)` and `D=diag(exp(-2 pi i k/N))`. This is necessary and sufficient for `M_N=U_N`. Do not infer its existence from the fact that it escapes the current theorem. No representation or complexity improvement has been found here.

If a constructive solution does exist, all cycle/phase constants, solves, permutations, preprocessing, reads/writes, and precision or bit costs must be charged. Classical stable/bounded-coefficient lower bounds mean an `O(N)` *well-conditioned* exact linear implementation cannot simply be assumed.
