# Sparse-surrogate research recovery checkpoint — 2026-10-09

## Main goal
Fresh arbitrary dense input, all N Fourier outputs, asymptotic speedup derived from our own relation/sparsification mechanism, not #130/CrocSwap/Swapnil.

## Established branch
For the unitary DFT U_N, importance-sample a fresh dense input into a k-sparse time-domain surrogate. With failure probability delta:

- universal error: ||U_N y - U_N x||_inf <= eps ||x||_1 / sqrt(N)
- support k = O(eps^-2 log(N/delta))
- using the existing input-pruned full-output transform: O(N log(k+2))
- hence fixed/polylog-vanishing accuracy gives O(N log log N) or more generally
  O(N [log(1/eps)+log log(N/delta)]).

Head/tail sparsification improves k for compressible signals. A perturbed-identity rank argument gives a flat-input lower bound k = Omega(log N /(eps^2 log(1/eps))) even for arbitrary complex sparse weights, so the logarithmic support scale is nearly optimal for the sparse-surrogate model.

## v3 linear-decoder experiment
Implemented quadratic-chirp block projection. A chirp polynomial P(z)=sum_{t<M} eta^(t^2) z^t satisfies
P(z)=1+eta z P(eta^2 z)-eta^(M^2) z^M,
allowing its values on all Nth roots to be generated in O(N) when eta is an Nth-root-compatible chirp.

One chirped block sketch decodes in O(N + (N/M) log(N/M)). However a general block-projection variance identity forces Omega(M) independent sketches for constant relative RMS error, so choosing M=Theta(log N) returns Omega(N log N). This family is a no-go for universal worst-case improvement.

## Recovered current frontier: structured CountSketch Fourier decoder
Let N=K M and split the input into K contiguous blocks. Use a shared quadratic phase sequence
sigma_t = exp(2 pi i (a t^2 + b t)/M)
inside every block and summarize
c_r = sum_t sigma_t x_{rM+t}.

For every Fourier bin m, the CountSketch-style estimate factors exactly as

    Xhat_m = conj(G_m)/sqrt(N) * C[m mod K],

where C is one K-point FFT of c and G_m is the oversampled chirp transform. All G_m can be generated in O(N) by the q-difference recurrence. Thus one sketch has true O(N + K log K) decoding cost, O(N) for polylog K.

### Empirical result
The decoder algebra is correct, but the shared randomness is statistically insufficient for worst-case inputs. At N=16384:

- Gaussian/random-phase errors improve as K grows (median normalized max error about 0.74 at K=16, 0.33 at K=128).
- Flat input remains order-one error (median around 1--2) even at K=128.
- Repeated identical local patterns / repeated local Fourier modes also remain order-one or worse.

So reusing the same chirp in every block creates coherent adversarial errors. The O(N) decoder is not yet a universal approximation algorithm.

## Exact next question
Can we introduce enough *independent block randomness* for simultaneous all-bin concentration while preserving a jointly decodable structure?

Promising algebraic family:
  sigma_{r,t} = exp(2 pi i [a t^2 + c_r t]/M),
with structured c_r (e.g. affine/polynomial in r).

Independent c_r would fix the coherence issue but destroys the simple single K-FFT decoder. The research target is to find a structured family c_r whose decoder is a convolution/chirp/twisted-convolution computable in O(N) or O(N polylog(1/eps)), while still giving enough moment independence across blocks.

This is the current frontier after recovery.

## Continuation after chain recovery: global quadratic chirp with exact O(N) decoder

A stronger block-dependent family was derived. Let N=K M, block r contain positions n=rM+t, and choose random odd a plus beta. Use the global quadratic chirp

    sigma_n = exp(2*pi*i*(a*n^2 + beta*n)/N).

Equivalently, inside block r this is (up to a block scalar)

    sigma_{r,t} = exp(2*pi*i*(a*t^2 + c_r*t)/N),
    c_r = 2*a*M*r + beta mod N.

For block summary d_r = sum_t sigma_{r,t} x_{rM+t}, reconstruct the block as conjugate(sigma)*d_r. This estimator is unbiased over uniform beta.

### Exact decoder recurrence
For the local chirp factor

    P_n = sum_{t=0}^{M-1} exp(-2*pi*i*(a*t^2+n*t)/N),

we have

    P_n = 1 + exp(-2*pi*i*(a+n)/N) P_{n+2a}
            - exp(-2*pi*i*(a*M^2+n*M)/N).

The choice c_r=2aMr+beta makes the r-dependent factor close under this recurrence. If D is the K-point DFT of the local block summaries, the full N-point estimate obeys a first-order recurrence along m -> m+2a. For power-of-two N and odd a there are exactly two cycles. Thus all N Fourier outputs can be decoded using:

- one K-point FFT of block summaries;
- two direct cycle seeds;
- O(N) recurrence steps.

The identity was numerically verified against materializing the reconstructed signal and applying a reference FFT, with max errors about 1e-13 to 2e-12 for N up to 4096.

### Statistical results
With K=M=sqrt(N), averaging a fixed number of independent global chirps is dramatically better than the earlier shared-local-chirp sketch. For flat and repeated-mode adversaries, 64 sketches gave median max-error/||x||2 roughly:

- flat: 0.089 (N=1024), 0.070 (4096), 0.064 (16384), 0.055 (65536)
- repeated mode: 0.087, 0.071, 0.059, 0.050

Dense Gaussian/random-phase cases are easier.

A more interesting decoder-cost regime is M=Theta(log N), K=N/M. Then K log K=O(N), so one global-chirp sketch is still O(N). Dense/flat cases improve under a constant number of sketches, but sparse inputs have poor error relative to the strong ||x||1/sqrt(N) target. This indicates a hybrid dense-sketch + sparse-surrogate/exact path rather than a universal single estimator.

### Recursive decoder attempt: negative
The remaining K-point FFT can itself be replaced recursively by the same global-chirp estimator, giving a formal cost recurrence T(N)=O(N)+T(N/M)=O(N). A prototype was implemented in recursive_chirp_fft.py.

However the approximation error compounds badly across levels. At N=1024, even averaging four recursive trees left max-error/||x||2 around 0.56--0.76 on dense cases and was much worse relative to ||x||1/sqrt(N) on sparse inputs. This recursive version is not worth optimizing in its current form.

## Current exact frontier
The strongest live primitive is therefore:

1. one-level global quadratic-chirp block sketch;
2. exact O(N + K log K) decoder by a two-cycle q-difference recurrence;
3. choose M=Omega(log N) so K log K=O(N), giving a true O(N) decoder per sketch;
4. combine with the existing sparse-surrogate / exact-sparse paths for inputs on which the strong l1-scale target makes block projection inefficient.

The unresolved theorem problem is to characterize, for arbitrary x, how many global-chirp sketches L(x,M,eps,delta) are sufficient for

    ||Xhat-X||_inf <= eps ||x||1/sqrt(N),

and whether the hybrid planner can guarantee o(N log log N), ideally O(N), in the worst case.
