# Reproduction and seal

This is a priority comparison, not a replacement correctness audit. Read DECISION_MEMO.md first, then PRIMARY_REDUCTIONS.md for exact mathematical reductions and SOURCE_LEDGER.md for inspection limits. HERMITE_DEGENERATION_COMPARISON.md supplies the fixed-root/generalized-Hermite/Uglov comparisons. CLAIM_SCOPE.md gives safe theorem scope.

The only executed mathematics script in this package is the newly authored check_normalizations.py. It imports installed SymPy and Python's standard library; it does not import or run a submitted/predecessor program. Run it with an available Python containing SymPy. It reproduces NORMALIZATION_CHECKS.json and the 30 exact normalization controls. The symbolic derivations in PRIMARY_REDUCTIONS.md, rather than those finite controls, justify the reductions for arbitrary degrees.

INPUT_HASHES.json records the exact mathematical reports used. PRESERVATION.json verifies that those seven files remain unchanged. The independent content audit was added after its acceptance and sealing. All project inputs remain at their original locations; this package does not modify them.

MANIFEST.sha256 seals every regular file in this directory other than itself. Verify from this directory with `sha256sum -c MANIFEST.sha256`. The seal protects provenance and byte identity; it does not turn a bounded search into an originality certificate.
