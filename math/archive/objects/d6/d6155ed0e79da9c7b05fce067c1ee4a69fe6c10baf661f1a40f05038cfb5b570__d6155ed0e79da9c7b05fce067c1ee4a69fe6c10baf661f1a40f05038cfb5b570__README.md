# Exact multi-stage FFT scan research: gauge-complete Jacobian dimensions

**Date:** 2026-10-09  
**Status:** New exact *restricted-model* algebraic geometry result; **no new fast Fourier algorithm**.

We continue the independent global/nonunitary FFT project after the exact endpoint-layout rank checkpoint. The new question is whether multiple cheap quasiseparable scans gain genuine nonlinear expressivity when global bit-reversal permutations are inserted.

**Proved (not extrapolated):** If `N=8, 16, 32`, there is a **fixed repeated bit-reversal permutation** between every pair of rank-one separated-generator stages such that the complex algebraic image dimension of `t` stages is exactly

`min(N*N, N + t*(4*N-6))`

for every `1 <= t <= N/4+1`. The witnesses are *explicit integer matrices* with nonzero Jacobian minors modulo 12,289 and 65,537. At `t=N/4+1`, the product map is locally surjective and its image is Zariski-dense; this does **not** assert it maps onto every matrix, and it does **not** assert it factors the Fourier matrix with fewer FFT operations.

**All-length upper bound:** For any `N>=3`, `t>=1`, and even for **arbitrary** fixed/free intermediate permutations, the image dimension is at most `min(N*N, N+t*(4*N-6))`. Therefore a generic matrix cannot be represented with fewer than `ceil((N*N-N)/(4*N-6))` such stages. For `N` divisible by 4 this threshold equals `N/4+1`. This lower bound concerns **generic matrices**, not the Fourier matrix.

**Why bit reversal matters:** With *identity* shuffles, every `t`-stage product has quasiseparable rank at most `t`; when `t < floor(N/2)`, it cannot represent a generic matrix. But repeated bit reversal reaches full dimension at `N=8,16,32` as above.
