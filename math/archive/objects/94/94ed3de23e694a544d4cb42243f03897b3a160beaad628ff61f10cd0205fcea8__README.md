# Portable independent triple-intersection audit

Read `TRIPLE_INTERSECTION_AUDIT.md` for results, repaired proof and scope.

Required checks, in order:

    python independent_exact_audit.py
    python independent_modular_audit.py
    python independent_finite_fiber_check.py

Only Python 3 and SymPy are required. Uploaded code is never executed or imported. Original JSON comparison data are in `input_data/`; the first checker rebuilds all mathematics rather than trusting those coefficients. No absolute workspace or master paths are needed.

Main outputs: `exact_results.json`, `modular_results.json`, `finite_fiber_results.json`, `independent_polynomials.json`.

The exploratory factorization log is incomplete and supports no factorization conclusion; it is not part of the required checks.
