# Frequency-sketch audit and synthesis

Independent audit of the supplied v5 and v6 research, plus proved rank, spectral-tail, and periodic-mean/Green consequences.

- AUDIT.md: findings, corrections, primary median-theorem source, and independently reproduced test summary.
- FUSION_THEOREMS.md: complete self-contained new derivations and their scope.
- independent_tests.py: independent NumPy algebra and probability checks; writes independent_results.json.
- covariance_probe.py: exhaustive local-median covariance checks, including a dyadic example; writes covariance_results.json.
- exact_covariance_witness.py: standard-library-only integer/rational proof-by-enumeration of the smallest covariance counterexample; writes exact_covariance_results.json.

Run with Python 3 and NumPy installed:

    python independent_tests.py
    python covariance_probe.py
    python exact_covariance_witness.py

All output paths are relative to the corresponding script. No script imports or executes the supplied research code. DFT/solve operations in the tests are reference calculations, not a production speed implementation. Numerical agreement supports implementation checking; the mathematical results rely on the proofs and explicitly exact enumerations.

Theorems use exact arithmetic, plus comparisons for median selection. They do not establish ordinary floating-point accuracy, a bounded-word v6 decoder, arbitrary-input exact FFT speedups, or research novelty. The rank-based exactness obstruction concerns continuous input classes and must not be silently extended to finite binary or bounded-integer domains.
