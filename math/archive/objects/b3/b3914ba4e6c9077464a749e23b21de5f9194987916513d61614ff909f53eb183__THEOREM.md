## Assumptions and Fourier convention

Let `N=G*m`, with `G=2^g>=4`, `m` odd, and `G=K*M`, `2<=M<=K`, both dyadic. For a Gth primitive root `zeta=exp(2*pi*i/G)`, use normalized complex Fourier `F_G` (negative exponent). Arithmetic counts roots, data-dependent multiplications/additions, state vectors, all short FFT calls, and output writes. Statements over complex numbers presume **exact root arithmetic**; Python NumPy float64 does not supply a rigorous end-to-end rounding certificate. The finite-field checks use *unnormalized* DFT so that no square root is required in the field.

For dyadic `M`, let `T_u=u(u+1)/2`. **Lemma 1 (triangular permutation).** `u -> T_u mod M` is a permutation of `Z/M` as `u` runs from `0` to `M-1`.

*Proof:* For `0<=u<v<M`, `T_v-T_u=(v-u)(u+v+1)/2`. If `v-u` is even, `u+v+1` is odd and the 2-adic order of the difference is `v2(v-u)-1<log2(M)`. If `v-u` is odd, `u+v+1` is even but in `(0,2M)`, hence its 2-adic order is at most `log2(M)`, and division by two leaves an order strictly below `log2(M)`. Thus `T_u` and `T_v` are distinct modulo `M`.

## Theorem 2: The stationary noncommuting frame collapses to a gauged Cooley–Tukey circuit

Use the inherited Phase14 states `a_i=1+iK`, `beta_{s,i}=3s+i(K+1)` for `0<=i<M`. In every input block `r`, define `D_{s,r,u}=zeta^{-[C(u,2)+(Mr+3s)u]}` and

`W[u,i] = zeta^{ -i [K*T_u+u] }`.

Then the actual local phase-bank matrix is **exactly** `V_{s,r}=diag(D_{s,r}) W`. It has full rank by Lemma 1, and the same `W` at every `s,r`. If `x_{s,r,u}=D_{s,r,u} sum_i W[u,i] c_{s,r,i}`, the critical joint coefficient is

`y_{s,r,u}:=sum_i W[u,i] c_{s,r,i}=D_{s,r,u}^-1 x_{s,r,u}`.

This identity permits all `M` chirp streams to be fused **before** computing their Fourier transforms. Let `H_{s,u}[t]=sum_{r=0}^{K-1} y_{s,r,u} exp(-2*pi*i*t*r/K)` be `M` ordinary length-K DFTs per odd input column. Then for `0<=v<K`, `0<=ell<M`, the exact normalized length-G output is

`Y_s[v+K*ell] = (1/sqrt(G)) sum_{u=0}^{M-1}`

`    [zeta^{-[v*u+C(u,2)+3s*u]} * H_{s,u}[(v+u) mod K]] * exp(-2*pi*i*ell*u/M)`.

This final sum is one length-M DFT for each `v`. It uses **no** length-G Green scan, and the odd-factor `m` transform is shared using ordinary Cooley–Tukey twiddles.

*Proof:* In the original DFT kernel, separate `t=rM+u`. Multiplying the Fourier phase by `D_{s,r,u}` yields the factor `zeta^{-Mr(k+u)}` in the `r` coordinate. Hence the frequency of the inner length-K DFT is `(k+u) mod K`. With `k=v+K*ell`, the remaining `ell` phase is `exp(-2*pi*i*ell*u/M)`. This is the displayed formula. Applying the conventional odd-part twiddle and m-point DFT gives `F_N` for every input.

**Cost:** `mM` length-K FFTs, `mK` length-M FFTs, `G` length-m FFTs, `O(N)` root/setup/twiddle, `O(N)` writes. Thus `O(N[log K + log M + log(m+1)] + N)=O(N log N)` arithmetic and `O(N)` working memory. Removing `M` length-G scans is a real implementation cleanup, **not an asymptotic improvement**. All required K-FFTs remain.

**Generalized no-go:** whenever `a_i` share the same residue `a0 mod K`, the block factor `a_i Mr u` is common mod `G` and `V_{r}=D_r W` with `W` independent of r. Any *invertible* such local frame admits the same collapse. Thus this broad stationary-residue class cannot create extra power merely through its full-rank, noncommuting block-local chart. This is not a lower bound for arbitrary circuits or more global Green constructions.

## Theorem 3: Exact size-uniform conditioning for the Phase14 stationary Toeplitz W

Since `K*T_u+u` is the stationary node exponent,

`W[u,i] = exp(-2*pi*i*T_u*i/M) * exp(-2*pi*i*u*i/(K*M))`.

Let `U[u,i]=exp(-2*pi*i*T_u*i/M)`. By Lemma 1, `U` is a row-permuted Fourier matrix, so all singular values are `sqrt(M)`. Center `u` and `i` at `(M-1)/2`. The terms linear in either index are harmless unit-modulus diagonal multipliers. The remaining phase perturbation has the series

`A= sum_{p>=0} [(-2*pi*i/(K*M))^p/p!] diag((u-(M-1)/2)^p) U diag((i-(M-1)/2)^p)`.

By the operator 2-norm and triangle inequality,

`||A-U||_2 / sqrt(M) <= delta := exp(pi*(M-1)^2/(2*K*M))-1`.

For `K>=4M`, `delta<exp(pi/8)-1`. A completely rational verification uses `pi<22/7`, the positive Taylor series for `exp(11/28)`, and a geometric bound on its tail after order eight, giving `exp(11/28)<741/500`. Therefore `delta<241/500`, and Weyl's singular-value bound yields

**`cond_2(W*W) < (741/259)^2 < 41/5 = 8.2` for every dyadic M and K>=4M.**

This is a *uniform complex-exact* frame bound. It is not a proof that repeated root generation or a floating-point FFT is uniformly stable at all N; individual rounding errors and precision requirements still have to be charged. `conditioning.py` computes the exact rational inequality with `Fraction` and checks finite numerical cases.

### Fast approximate local frame solver (not an exact FFT speedup)

Truncate the centered series after degree `P`. Its operator-norm error is at most `sqrt(M)*tau_P`, where

`lambda=pi*(M-1)^2/(2*K*M)` and `tau_P<=lambda^(P+1)/((P+1)!*(1-lambda/(P+2)))`.

Each term is one Fourier-matrix multiply with diagonal weights, which is a length-M FFT with a fixed row permutation. A left-Fourier preconditioned stationary iteration contracts by at most `delta<1` for the exact series; for the truncated series its contraction `delta_P=sum_{p=1}^P lambda^p/p!` is also less than 1. Let `z_j` be the jth iterate on the centered core with RHS `b`, `z_true` the exact W-solution with its unit phases removed. Then

`||z_j-z_true|| <= (||b||/sqrt(M)) [delta_P^j/(1-delta_P) + tau_P/((1-delta)*(1-delta_P))]`.

The numerical module `fast_frame.py` charges `j*(P+2)` short length-M FFTs and verifies the stated analytic error estimates. It only **approximates the frame coefficients**, and even perfect coefficients would leave the long-direction K Fourier work.

## Theorem 4: A tunable full-rank nonstationary family with an exponential conditioning barrier

Choose any even power of two `d|K`, `2<=d<=K`, and set `L=K/d`. Define

`a_i=1+di`, `beta_{s,i}=beta0_s+di`, `i=0,...,M-1`.

All slopes are odd units modulo G. The local frame factors as `V_{s,r}=D_{s,r} W_r` with

`W_r[u,i] = exp(-2*pi*i*i*(T_u+M*r*u)/(L*M))`.

Here the symbol `i` is overloaded in code as the integer column index; the imaginary unit is written `sqrt(-1)` in this formula's exponent. The nodes are distinct because `(T_u+Mr u) mod M=T_u mod M`, a permutation by Lemma 1. Therefore **every block's M-by-M Vandermonde frame is invertible**, not just almost every block. `W_r` has exactly `L` different block charts, since its factor at `u=1` changes by `exp(-2*pi*i/L)` upon incrementing r.

At block r=0, all nodes lie near one when `L/M` is large. Let `z_u=exp(-2*pi*i*T_u/(L*M))` and take coefficient vector `c_i=(-1)^i*C(M-1,i)` for the polynomial `(1-z)^(M-1)`. Then

`||W_0 c||_2 <= sqrt(M) [pi*(M-1)/L]^(M-1)`

and `||c||_2^2=C(2M-2,M-1)`, while `||W_0||_2>=sqrt(M)` from its first all-ones column. Thus

**`cond_2(W_0*W_0) >= C(2M-2,M-1) * [L/(pi*(M-1))]^(2(M-1))`**.

Using `pi<22/7` gives the **strict, entirely rational** bound

**`cond_2(W_0*W_0) > C(2M-2,M-1) * [7L/(22*(M-1))]^(2(M-1))`**.

In particular, with `L/M` fixed sufficiently large, this family becomes exponentially ill-conditioned in M despite having exact full rank on every input block. This shows an explicit cost of some attempts to obtain many distinct noncommuting local frames. It does **not** prove that every nonstationary construction, nonunitary global Green algorithm, or exact FFT must be ill-conditioned.

At `d=K` (`L=1`) the entire family reduces to a common W equal to the row-permuted DFT_M, and all long-direction block dependence disappears. Nonstationarity alone does not guarantee a new algorithm: local frame inversion always reconstructs the ordinary input, and a naive full-rank decoder still costs M independent long scans.
