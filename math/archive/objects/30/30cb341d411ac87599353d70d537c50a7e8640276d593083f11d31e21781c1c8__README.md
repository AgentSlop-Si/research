# Hero #0 Phase 8 — cycle-rational exact Fourier research

This folder contains a **certified-input exact O(N) NTT specialization**, higher-order rational cycle extension, and an exact O(NloglogN) noncommuting Weyl dynamical specialization. None is a worst-case arbitrary-input FFT breakthrough. Proofs, caveats, and cost contracts: `THEOREMS.md`.

## Reproduce

Python 3.10+; no third-party packages required.

```bash
python test_phase8.py
python explicit_witness.py
python audit_phase8.py
python control_barrier.py
python verify_all.py
```

The NTT verifier uses GF(2013265921), root of unity derived from 31; N must divide p-1. For arbitrary vectors, the specialized functions return `None` when the structure test fails. The fallback full NTT is `full_ntt_oracle` and runs in O(NlogN).

## Contents

- `phase8_weyl_cycle.py`: exact first-order, unknown shift, higher-order rational, and noncommuting Weyl implementations; op counter; independent NTT/direct oracle; synthesis generators.
- `test_phase8.py`: 13 automated tests, 414 successful exact structured cases (120+140+70+84), other independent checks, corruption negative tests.
- `explicit_witness.py` + `EXPLICIT_CERTIFICATES.json`: 3 dense full-rank/full-Hankel/full-Green-mode exact examples.
- `audit_phase8.py` + `AUDIT_RESULTS.json`: operation counts, fair NTT baseline, finite-field generic-input cardinality bound, 100 negative samples per model.
- `COUNTS.json`: fixed dictionary arithmetic counts.
- `control_barrier.py` + `CONTROL_BARRIER.json`: 180 exact convolution-identity tests and quantified generic dense-control obstruction.
- `phase6_exact.py`: imported verified radix-2 NTT root code and Hankel rank helper.
- `prior_phase7_bundle.zip`: full previous Phase 7 line.
- `CHAIN_HANDOFF.md`: precise next-session continuation.
- `verify_all.py`: deterministic top-level replay.

We deliberately do **not** claim novel mathematics for geometric sums, rational generating functions, cyclic diagonalization, modular batch inversion, or polyphase FFT identities, which are classical. The concrete project contribution is a testable composition and carefully stated recognition/complexity contract.
