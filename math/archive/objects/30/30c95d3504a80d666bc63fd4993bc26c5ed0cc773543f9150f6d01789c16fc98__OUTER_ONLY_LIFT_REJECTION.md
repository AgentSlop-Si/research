# The accepted N16 seed cannot lift by outer-only correction

## Exact scope

Use the N16-to-N64 nested routes, eight poles 1/2,...,1/9, and pulled-back bank with F8 blocks {0,1,4,5} specified in the complete lift-system note. Freeze the two inner N64 layers to literal fiber pullbacks of the accepted N16 algebraic coefficients. Allow every one of the 512 outer physical endpoint coefficients to vary arbitrarily, even permitting zero values for this rejection test.

No outer choice yields F64. This rejects the outer-only correction law, not the complete 1536-variable N64 family, not the 1152-variable mean-anchored law with inner changes, and not other routes or banks. At least one inner layer must change if this seed is to lift in the stated geometry.

The proof uses a nonsingular 9-by-9 augmented row-template minor at the actual algebraic seed. A rational interval separation bound certifies nonsingularity over its isolating region. There is no modular specialization of the seed center and no assumption that a numerical residual is exact.

## 1. The actual seed and a sharpened root enclosure

The accepted seed is a*=a0+V y*, with exact dyadic a0,V and the unique root y* in the accepted chart. Its source chart SHA256 is 904d7d24bf3aeee0a7c206eb8fd98ee11045fbc22cc97a105511b51907e1b188. The prior exact contraction proof supplies e>=||f16(0)|| and q<1 bounding the contraction map T(y)=y-f16(y) throughout the original radius-10^-9 polydisk.

At the fixed point,

    ||y*|| <= ||T(0)|| + q ||y*|| <= e + q ||y*||,
    ||y*|| <= e/(1-q) < 2*10^-12.

The new verifier checks the last strict rational inequality using the accepted certificate. This smaller radius is derived from the accepted proof; it is not a new numerical assumption or a different seed.

The two frozen large layers are H_0(y*) and H_1(y*), obtained by copying a0+Vy* onto all four sheets. Their variation with the 256 small root coordinates is linear. The outer layer remains entirely free.

## 2. One augmented minor suffices

Write X(y)=H_1(y) B64 H_0(y). At output row 0, the eight outer templates are

    row_0(G_j,64 X(y)),  j=0,...,7.

The Fourier target row is exactly the all-ones row. It involves no new root approximation. Select the columns

    K = (27,31,11,28,47,10,30,59,51).

Let M(y) be the 9-by-9 matrix consisting of those eight template rows restricted to K and the all-ones target row. If M(y*) is nonsingular, the target row is outside the span of all eight templates. The row-0 outer equation is then impossible, regardless of the other 63 rows or any outer nonzero guard.

The supplied `EXACT_MINOR_CHART.json` gives a proposed dyadic 9-by-9 preconditioner R with denominator 2^80. Its numerical origin is irrelevant to acceptance. We verify

    ||I-R M(y*)||_infinity < 1.

This implies R M(y*) is invertible by the Neumann-series criterion, hence M(y*) is invertible. No separate assumption that the proposed R is invertible is needed.

## 3. Exact center product and bank enclosure

Let L be the least common multiple of the eight positive denominators d_j^64-1, d_j=j+2, and D=2^60 L. Every large Green has integer numerator over L. Every frozen inner center layer and every chart-direction matrix has Gaussian-integer numerator over D. They are regenerated from the explicit cycles, not read from a floating array.

The active bank F8 has entries among 1,-1,i,-i and (+/-1 +/-i)/sqrt(2). Set Q=2^160 and s=floor(sqrt(2 Q^2)). In the approximate bank replace sqrt(2)/2 by s/(2Q). This is a rational lower approximation, with scalar error less than 1/(2Q). Each complex bank entry has real/imaginary l1 error below 1/Q. The exact matrix infinity error therefore obeys

    ||B64-B0||_infinity <= 8/Q.

The true bank norm is ||B64||_infinity=8. Its inactive blocks are unchanged identities. No approximation of the Fourier target row is necessary, because row 0 is exactly one in every column.

The verifier calculates R M0 exactly, where M0 uses the dyadic seed center and B0. All products use Gaussian integers and a common rational denominator. It then bounds every row sum of I-R M0 using |Re z|+|Im z| as an upper bound for |z|.

## 4. Amplified seed-coordinate bounds

Let h_0,h_1 bound the matrix infinity norms of the frozen inner center layers. Let L_0,L_1 bound the operators from ||y||_infinity to each large-layer matrix infinity variation. These are computed directly from the full 256-direction matrix after fiber pullback. In particular, the amplification by V is fully included.

Let rho=2*10^-12. The exact inequalities give approximately

    h_0 < 64.842, h_1 < 52.089,
    L_0 < 383.329, L_1 < 370.104.

The verifier uses the exact fractions, not these rounded displays. For the prefix,

    ||X(y*)-H_1(0) B0 H_0(0)||_infinity <= Delta,
    Delta = 8 L_1 rho (h_0+L_0 rho)
            +8 h_1 L_0 rho
            +h_1 (8/Q) h_0.

The first two terms account for all seed-coordinate variation, including the quadratic product of inner variations. The last accounts for the bank enclosure.

For each preconditioned row define the exact row functional

    f_r = sum_(j=0)^7 R[r,j] row_0(G_j,64).

Its coefficients are summed exactly before their norm is bounded. This retains cancellations in R rather than multiplying a loose ||R|| bound by separate template errors. Let beta=max_r ||f_r||_1; its certified bound is below 0.420.

Each selected entry of the preconditioned template variation is at most beta Delta. There are nine selected columns. The ninth target row is constant, so it contributes no variation. Consequently

    ||R(M(y*)-M0)||_infinity <= 9 beta Delta.

## 5. Separation result and guards

`OUTER_PREFIX_REJECTION_CERTIFICATE.json` records exact rational numerators and denominators for every bound. The total satisfies

    ||I-R M(y*)||_infinity
       <= ||I-R M0||_infinity + 9 beta Delta
       < 2.659*10^-6 < 1.

Thus the augmented minor is nonzero at the actual algebraic seed. This is a characteristic-zero rejection certificate for the complete 512-variable outer correction problem with the stated frozen inner layers.

All eight fixed large Green denominators d_j^64-1 are explicitly checked positive. The inner physical endpoints inherit nonzero guards from the accepted N16 seed because they are copied, not approximated. No outer guard or pivot denominator is needed for rejection: even completely unrestricted outer coefficients cannot meet row 0.

The small root's accepted contraction certificate is a declared prerequisite. The new argument derives a narrower root bound from it and verifies the new minor uniformly there. It does not assume that the dyadic center itself is a root.

## 6. Bounded discovery and reproduction

The proposal script inspected only three row-minor candidates for conditioning, and retained the first, row 0. It did not fit any large coefficients. The exact gate stopped on that first certified minor; no indefinite search occurred.

Run the acceptance path with

    python certify_outer_prefix.py

It reads the exact accepted seed chart/certificate and proposed dyadic preconditioner, rebuilds the nested geometry, checks all inverse guards, recomputes the amplified seed-direction bounds, and verifies the strict rational separation inequality. The optional `--propose` flag only converts the saved floating preconditioner into exact dyadic input; it is unnecessary for acceptance.

All scripts are newly authored for this track and import only previously authored geometry helpers. No uploaded source is executed. An independent review is still required before sealing this additional exclusion.
