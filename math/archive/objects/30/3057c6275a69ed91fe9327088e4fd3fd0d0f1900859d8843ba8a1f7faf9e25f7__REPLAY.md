# Portable independent replay

Copy `independent_checks.py`, `independent_phase21_math.py` and `independent_trace_math.py` to any directory. These are all auditor-authored files; no uploaded code is imported. Python 3.10+ and its standard library suffice:

    python -B independent_checks.py phase23_results.json

Compare output byte-for-byte with `INDEPENDENT_RESULTS.json`. The separate benchmark-difference JSON is a static comparison of source data with independently derived formulas, not an execution of the source benchmark or a certification of its absolute grand totals.
