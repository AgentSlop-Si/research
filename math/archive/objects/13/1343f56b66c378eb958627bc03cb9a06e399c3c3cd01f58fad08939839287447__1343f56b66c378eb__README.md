# Hero #0 — FFT cycle research checkpoint

This package links the project's Phase 23 Green-operator track with its v11 Bessel-channel track.

## Contents
- `HERO0_RESEARCH.md` — full mathematical statement and proofs, limitations, arithmetic accounting, next construction gates.
- `cycle_bridge.py` — standalone reproducible exact modular and high-precision numerical verifier.
- `results.json` — output of the verifier's seeded tests.
- `requirements.txt` — Python dependencies.

## Run

```bash
python -m pip install -r requirements.txt
python cycle_bridge.py
```

**Research status: no unconditional `O(N)` or `O(N log log N)` algorithm for fresh arbitrary exact FFT is claimed.** The observed Bessel recurrence requires an operator that currently costs `O(K log K)` using two FFTs; the remaining full-length decoder scans also require work.
