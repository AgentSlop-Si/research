## F3 — Weyl soundness depends on an unvalidated oracle contract

`a2ee70df98f74b5ffdc5c67de06522a99f5dabcd4b2e9a39f1166ff5a8e79c8b`, lines 93–125. The intended theorem applies to a fixed linear endomorphism of F_p^n, independent of fresh probes, with canonical length-n field outputs. The function does not validate those conditions. In particular, lines 119–120 use zip, silently discarding unmatched coordinates.

A purely static adversarial trace illustrates the API gap: an oracle returns `[c0,0,...,0]` on its first calibration call; on each following triple of calls it returns length-n zero output, then an empty list, then an empty list. `modulate(out)` remains well-defined, each zip comparison has zero pairs, both mismatch counters stay zero and calibration is true. The report returns passed=True. This is not a fixed linear map; it is a counterexample to unconditional black-box API acceptance, not to the fixed-linear-map theorem. No such oracle was executed.

With a fixed seed the source docstring correctly disclaims independent randomness, but line 125 still prints the independent-uniform P^-trials guarantee. Report the seeded case as a deterministic regression sample. Shape/type/canonical-residue checks should reject malformed outputs; a linearity/fixed-state contract must remain explicit because finite probing cannot certify it for arbitrary programs.

## F5 — Kernel nontriviality is weaker than nonzero shared image

`83597683ff56a19053aaf6639bd7d04010924f34bf90a9acaf1e2c44fa7c31eb`, lines 87–89 and 130, respectively label rank deficiency as “nontrivial_intersection” and inspect coefficient-coordinate visibility. Let e1,e2,e3 be the first three standard vectors in F^5 and set

- A=[e1,e1,0]
- B=[e2,e2,0]
- C=[e3,e3,0]

The block matrix G=[A,-B,0; A,0,-C] has rank 3 and nullity 6. Yet col(A), col(B), col(C) are three distinct coordinate lines and their triple intersection is {0}. The coefficient vector (1,-1,0;1,-1,0;1,-1,0) is in ker(G), has all three distinguished coordinates nonzero, and maps to the zero common image. This proves the general linear-algebra limitation exactly without running supplied code.

Classification: diagnostic/sufficiency gap, not a demonstrated false rejection. This example is an abstract choice of column spaces, not claimed to be an actual enumerated Fourier-chart tuple. No archived accepted factorization was found relying on the weaker test. The archived README/RESEARCH/SESSION_HANDOFF explicitly keeps 1,330 universal-gate survivors possibly invalid. Rank-9 rejection remains valid as a necessary gate, and the bounded resultant argument does not require interpreting every kernel as a nonzero common image. A strengthened diagnostic should check the image of the kernel under [A,0,0] and retain all affine diagonal/nonzero-generator constraints.

## F6 — Saved exact coefficients are not authenticated by the tests

`79a603d938319dbab89ebed5fe81fb88ef106929ddd0157d67e6173ee4f56d61`, lines 39–41, reads the saved polynomial export but compares term counts only. Altered coefficient values with unchanged term counts would evade this check. The saved `exact_nonzero_resultants.json` is never read by the reviewed suite; resultants are recomputed in memory. `RUN_ALL.md` claims both coefficient exports are checked, which the reviewed runner/suite does not implement.

This is an artifact-acceptance gap, not evidence that the preserved exports are actually corrupt. Their bytes matched frozen master hashes when preserved here. Source evaluation/determinant comparisons are seeded finite modular samples, not coefficient-by-coefficient proof. Strengthen acceptance with exact full coefficient identity and declared metadata equality before attaching a theorem certificate to a saved export.

## F7 — Preserve the mathematical scope

- The three-stage block control disproves a naive rank-propagation rule over the intended odd field; it does not construct a Fourier circuit.
- The real-mask audit requires real invertible mixers and diagonal-mask invertibility. Numerical rank/eigenbasis controls are dense and not a faster FFT.
- The Weyl field tester is one-sided Monte Carlo for a fixed linear map. A pass is not a proof of a complex-number identity; fixed-seed passes do not have adversarial soundness.
- The fixed-eight-point polynomial/resultant construction concerns one permutation and a globally separated-generator regular chart, h0*Delta*T!=0. Nonzero resultants constrain base parameters; they do not prove general emptiness. Exceptional branches remain unresolved.
- The fixed regular slice argument can legitimately lift from a nonzero integral cyclotomic resultant reduction to characteristic zero. It must retain exact integral coefficient identity and degree hypotheses. The preserved W export has degree at most two in h6; the degree claim is not established merely by sampling three values.
- Full reading of these 24 source hashes neither closes imported dependency coverage nor verifies all archived research materials.
