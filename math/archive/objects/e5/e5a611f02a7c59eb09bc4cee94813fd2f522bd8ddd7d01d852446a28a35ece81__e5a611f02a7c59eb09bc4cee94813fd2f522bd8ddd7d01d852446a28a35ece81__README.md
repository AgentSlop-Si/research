# FFT project synthesis, October 10 2026

This package is an independent focused synthesis of the user's large FFT master archive and the newer Green, Hero0/Hero1/Hero17 and sparse-surrogate branches.

**Best new-to-the-project result:** `THEOREM.md` proposes a complete, fully charged `O(N)` *expected word-RAM* **approximate** all-output Fourier method for bounded-integer inputs and fixed `epsilon`, derived from signed-atom importance sampling and three finite-state lookup tables. It expressly does not solve exact FFT. The major new constructive ingredient is the packed transposition table that closes the older checkpoint's hidden aggregation-cost gap. This is an internally rigorous proof sketch, not an externally certified publication-level novelty claim.

Other files:

- `fft_phasor_lookup_verify.py` — independent standard-library checks; precomputes one small transposition table exhaustively but uses lazy tables for phasor simulation (not a speed benchmark).
- `TEST_RESULTS.json` — 25/25 finite end-to-end numerical tests, 3,090 randomized layout tests, all 4,096 entries of a toy eager transpose table checked.
- `cost_ledger.py` and `COST_LEDGER.json` — symbolic word-level asymptotic parameter sizes; illustrates astronomical constants and why the result is not presently practical.
- `RESEARCH_INDEX.md` — source coverage and duplication/negative-result register.
- `NEXT_EXACT_GATE.md` — explicit surviving *conjectural*, phase-correct non-affine Green product target, not a theorem.
- `SHA256SUMS.txt` — package-integrity hashes.

Reproduce with `python fft_phasor_lookup_verify.py > local_results.json` and `python cost_ledger.py`. Python 3 standard library only. The archived source projects were read and used as evidence, but the simulator was independently written; it is not a general runtime implementation of the large precomputed tables.
