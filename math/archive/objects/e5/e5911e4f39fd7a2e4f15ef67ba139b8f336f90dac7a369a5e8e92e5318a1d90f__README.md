# Hero #1 — Phase 26: exact gate accounting beyond the radix-2 graph

**Status:** 12 new tests pass; two-field full-basis audit checks 567,912 exact Fourier matrix entries; all 74 Phase 25 lineage tests replay. **No faster asymptotic all-input FFT** is claimed.

This checkpoint tests two routes beyond Phase 25: a genuinely different exact split-radix Fourier recursion and a nonunitary shear realization of the butterfly. In the defined prime-field scalar-operation model, the first has **exactly the same** cost as optimized radix-2, and the second costs more. The accompanying complex matrix volume/entropy analysis supplies a restrictive high-arity and coefficient-growth test for future candidates.

## Key lesson

**Gate count ≠ scalar-operation count.** A high-arity or nonunitary circuit is a plausible research direction only when its implementation and numeric/bit requirements are fully paid. This phase deliberately reports scoped negative results instead of calling established FFT reorganizations an `O(N)` breakthrough.
