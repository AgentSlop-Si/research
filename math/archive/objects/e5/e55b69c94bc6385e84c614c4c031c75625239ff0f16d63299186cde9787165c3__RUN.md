# Reproduction instructions

```
cd hero17_phase14_qgreen_union
python -m unittest -v test_phase14
python independent_audit.py
```

The tests cover primitive roots at various composite and prime-power lengths, every signed Green orientation, zero diagonal pivots, matrices and all basis inputs, q-binomial power identities, Weyl support and its finite-field rank, odd/even Gauss defects, both Weyl twirls, mixed-depth sums, the long-range escaping counterexample, and general multi-cycle stride solvers.

The independent audit writes `AUDIT_RESULTS.json` and verifies a 65,536-sample random fresh input through two mixed Green solve residuals, two complete Weyl twirls, 13 separately computed Green kernel rows, seven independently summed DFT rows (which must NOT equal Green outputs), and a long-range stride solve whose full vector is compared to a separate closed formula.

All operation ledgers distinguish field additions, multiplications, inversions, and explicit reads and writes. Modular inversion is counted as one exact-field operation, but is not constant-time in a growing-bit-length model. The primitive root is a supplied model parameter.
