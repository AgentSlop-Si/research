# Reproduction

```bash
cd hero17_phase12_green_union
python -m unittest -v test_phase12
python independent_audit.py
python large_green_audit.py
```

No extra packages are required. Results are deterministically seeded. The independent audit enumerates all 3,701 tested prime-field minors and all Green-pair parameters in specified small finite fields. Both exact modular reports overwrite their corresponding JSON outputs.

Compare the theoretical claims only under their stated assumptions: fixed complex Fourier transform, invertible factors, sparse inverses and bounded total correction rank. A recorded O(N) Green program is not an FFT if its output differs from the DFT.
