**Main goal: not achieved.** Exact proofs and finite checks eliminate specific candidate architectures; translated multiplication supplies special-case gains.

## Translation idea: full-cost local Python measurements

Each call includes detection, correction multiplication, shifting, addition, and full output allocation. Both methods start from already constructed inputs. ## Verified restrictions and control

- 400 modular arithmetic-progression block ranks match the proved formula; additional cyclotomic cases are in the test suite.
- 55 coset examples attain the proved minimum residual count, including shifted cosets.
- For any dyadic r <= N/2, the Fourier-coset subspace requires at least N^2/4 entry corrections. Factoring the half-rank correction recovers the classical FFT; density is not a general lower bound on graph cost.
- Six modular radix-2 control graphs and four small cyclotomic controls pass every input-basis check.
- The direct independent-dot-product skeleton architecture has a proved Omega(N^(3/2)) lower bound. The scope is essential.

The 64-by-64 consecutive block of F_4096 has exact rank 64; its apparent rank at relative SVD threshold 1e-12 is 12. Rank-8 truncation has output L2 error 1.303e-06 on the supplied unit direction. This distinguishes approximation from exactness, without rejecting relative-error algorithms.
