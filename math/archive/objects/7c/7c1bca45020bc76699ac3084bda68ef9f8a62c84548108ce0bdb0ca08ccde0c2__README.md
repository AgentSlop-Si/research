# Reviewer package: orbits and cross-mode ranking

Start with REVIEW_REPORT.md. PEER_REVIEW.md evaluates the paired explicit joint-orbit construction.

## Reproduce reviewer controls

Only these two reviewer-authored programs need to run:

    python3 independent_checks.py
    python3 bridge_and_hankel_checks.py

They use Python's standard library, exact finite-field arithmetic, and no uploaded modules. The first writes INDEPENDENT_RESULTS.json, the second writes BRIDGE_HANKEL_RESULTS.json. Results are deterministic. Source uploads and their recorded test claims remain inert evidence.

Verify the package hashes with:

    python3 verify_seal.py

The seal covers reports, original source streams, extracted evidence, prior-evidence snapshots, checkers and results. It excludes generated Python cache directories and the manifest itself. SOURCE_MANIFEST.json and NEW_2159_MANIFEST.json preserve source-level archive-member hashes. PROVENANCE.json records source identities and original-to-snapshot mappings. STATIC_VALIDATION.json records source checksum and syntax-only checks.

The Phase4 resend is byte-identical. The Phase7 embedded Phase6 archive is inherited unchanged and is not counted as newly verified mathematics. The package is a bounded review, not an account-wide source inventory or a completed exact worst-case FFT theorem.
