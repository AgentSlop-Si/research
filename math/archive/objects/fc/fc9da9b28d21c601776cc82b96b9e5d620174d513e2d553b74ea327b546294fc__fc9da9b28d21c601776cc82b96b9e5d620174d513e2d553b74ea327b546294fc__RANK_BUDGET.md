# Rank budget for assembling the full kernel from small corrections

This is a representation-specific limit, not an FFT complexity lower bound.
Let H=H_q(C) in the exact field model of this package, where C is similar to
one weighted nilpotent shift with all N-1 interior weights nonzero. Then

    rank(H-I)=N-1.

Indeed H-I=C g(C), with g(0)=1/(1-q) nonzero. Since C is nilpotent, g(C) is
invertible, so rank(C g(C))=rank(C)=N-1.

Suppose a proposed correction graph starts with the identity and expresses H
as either I+sum_j L_j or as an ordered product product_j(I+L_j), where
rank(L_j)<=r_j. In both cases necessarily

    sum_j r_j >= N-1.

The additive case is rank subadditivity. For the product, let P_j denote the
partial product and telescope P_s-I into sum_j P_(j-1)L_j (using a consistent
left-to-right convention). Every summand has rank at most r_j. The argument
does not assume the L_j commute or that the individual factors are invertible.

Consequently a constant number of bounded-rank resolvent aggregates or feedback
corrections cannot equal the entire H. If a PARTICULAR implementation applies
each rank-at-most-r correction separately and materializes a full N-vector
after each, it needs at least ceil((N-1)/r) such passes, hence
Omega(N ceil((N-1)/r)) output-write work. For fixed r this is quadratic.

This does not exclude fusing the corrections, keeping a compact intermediate,
changing the base operator, applying high-rank structured maps cheaply, or using
an entirely different graph. Rank alone does not imply that an arbitrary
high-rank operator is expensive. The restricted O(N log(r+1)) high-degree tail
primitive is useful; the missing step is shared evaluation across enough tails
to recover the full rank budget without charging their full-vector passes
independently.
