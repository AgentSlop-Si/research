# A rank constraint for the proposed compressed linear decoder

9 October 2026. This elementary argument audits the newly supplied structured
chirp-sketch proposal. It is a model-specific constraint, not a general FFT
time lower bound and not a mathematical priority claim.

## Contract

Let U be an N by N unitary matrix (in particular the unitary DFT). A seed w is
drawn independently of the input. For each seed, the entire approximation is
a linear map A_w of rank at most K. A K-measurement linear sketch followed by
a linear decoder has this property, regardless of how the sketch and decoder
are prepared. Suppose for every fixed input x,

    Pr[ ||A_w x - U x||_infinity <= epsilon ||x||_1 / sqrt(N) ] >= 1-delta,

where 0 <= epsilon < 1 and 0 <= delta < 1. The probability is over the seed;
the claim does not require one seed to work simultaneously for every input.

**Then K >= N (1-delta) (1-epsilon^2).**

For variable rank, the same proof gives
E[rank(A_w)] >= N (1-delta) (1-epsilon^2).

## Proof

Fix a seed, and let V be the range of A_w with orthogonal projection P_V.
For each coordinate vector e_j that meets the error guarantee, its error in
Euclidean norm is at most epsilon, since ||e_j||_1=1. Since A_w e_j is in V,

    ||(I-P_V) U e_j||_2^2 <= epsilon^2,
    ||P_V U e_j||_2^2 >= 1-epsilon^2.

The N columns U e_j are an orthonormal basis. Consequently

    sum_j ||P_V U e_j||_2^2 = trace(P_V) = rank(A_w).

If S_w is the number of coordinate vectors succeeding for this seed, then
S_w (1-epsilon^2) <= rank(A_w). Take expectations. The separate guarantee
for each of the N fixed coordinate inputs gives E[S_w] >= N(1-delta), proving
the bound. No unbiasedness, independence between coordinates, or moment bound
is used.

## Dense-input promises do not avoid this linear-map argument

If the guarantee instead covers every vector with all coordinates nonzero,
take x_j(t_m)=e_j+t_m*1 for t_m=1/m tending to zero. These vectors are dense,
and for each fixed seed linearity and continuity imply

    limsup_m 1{success on x_j(t_m)} <= 1{success on e_j}.

Indeed, infinitely many successful vectors tending to e_j force success at
e_j by the closed, non-strict error inequality. Reverse Fatou for bounded
indicators yields Pr[success on e_j] >= limsup_m Pr[success on x_j(t_m)]
>=1-delta. The same rank bound follows. A quantitative promise separating
inputs from coordinate vectors, such as a fixed lower bound on
||x||_1/(sqrt(N)||x||_2), changes this argument and must be analyzed separately.

## Implications and precise limits

- For epsilon=1/4 and delta=1/10, K must be at least 0.84375 N.
  A polylogarithmic K cannot give the stated universal error guarantee by a
  seed-dependent but input-independent linear decoder.
- Averaging R such estimators with fixed weights has rank at most R K, so
  R K obeys the same lower bound. The seeds need not be mutually independent.
- The proposed one-K-FFT chirp decoder is linear for a fixed seed. Thus this
  argument applies if that remains its complete input-to-output map. Paying
  for its conventional K-point FFT with K proportional to N retains the
  conventional N log N cost. Rank alone is not a lower bound on time: a
  full-rank map can still have a linear-work algorithm.
- The argument does not cover input-dependent importance probabilities,
  adaptive head selection, nonlinear decoding, input-dependent selection
  among cached graphs, or a decoder receiving additional input information
  outside its K measurements. All those costs and information must be counted.
- It does not exclude the weaker error epsilon*||x||_2, for which a coordinate
  input permits Euclidean error epsilon*sqrt(N), rather than epsilon.
- It does not say approximate Fourier recovery is impossible. It locates the
  missing ingredient for this proposal: input adaptation, a stronger input
  promise, nonlinear information recovery, or a different error scale.

The proof is all-size and independent of finite experiments. The separate
structured-phase package supplies counterexamples and a restricted variance
repair for particular chirp families.
