# Hero #1 Phase 18 gate — all-input exact FFT challenge

**Current frontier (Phase 17):** Exact `O(N log(K+1)+K log^2(K+1))` for Green residual support `K=||P x||_0`, including dense inputs with `K=1` and transform lengths not dyadic. For generic fresh `x`, `K=N` and the fallback is `O(NlogN)`. No all-input exact sub-`NlogN` result has been established.

## The next real question

Can one make a **uniformly inexpensive residual compression operator `P_N`**, possibly built from graph union, sparse-table operators and noncommuting Green resolvents, such that for *every* input vector the transformed residual admits a provably cheap exact representation — **without** paying the same work in finding, representing, decoding or applying it?

The present `P` is invertible and linear, so it maps a full-measure set of input vectors to vectors with all `N` coordinates nonzero; choosing a *fixed finite bank* of invertible linear `P`s does not evade this observation. For arbitrary data, coordinate sparsity is not the answer.

## Priority A — structured dense **non-coordinate** residuals

A Fourier residual `r` could admit a short exact circuit even when `||r||_0=N`: for example a low-degree recurrence, sum of exponentials, or a compact straight-line program. Develop an executable recurrence extractor with a **fully charged** build time, bit precision and full output computation. Benchmark on generic and adversarial vectors. Do not treat detecting a short recurrence or diagonalizing a recurrence as free.

## Priority B — joint basis/source complexity

Extend the Phase17 within-call denominator cache to *many output families* with differing supports/roots. Build a symbolic DAG and charge kernel changes, routing, merging, source-register lifetime and dirty-restoration if relevant. The exact condition to beat is `total_arithmetic < O(NlogN)` with a **rigorous all-input asymptotic**. Saving 20% in a particular `N,K` proxy does not suffice.

## Priority C — stability barrier

For complex arithmetic, clustered source nodes cause `B(t)` coefficients approximately binomial in K. Find a stable algorithm that evaluates the length-N recurrence directly while maintaining a norm-based, all-size forward-error guarantee. A bounded Green condition number is not enough. Independent finite-field identities and high-precision/interval complex tests must remain separate.

## Stop rules

- Do not re-propose sparse Green inversion alone: Phase16 proves forcing is FFT-equivalent for arbitrary data.
- Do not equate short NTTs on **K-sparse** residuals with a general exact sub-`NlogN` FFT: generic `K=N`.
- Do not claim the rational generating-function machinery as mathematically unprecedented; sparse input pruning and fast power series are standard.
- Do not use fixed-size unitary gate circuits to claim all-input `o(NlogN)`; check model-specific Ailon/Morgenstern lower bounds first.
- Do not count data-dependent kernel caches across unrelated inputs without verification and invalidation. Within-call kernel reuse is precisely recorded in `PolyStats`.

## Exact next acceptance test

For any proposed all-input forcing evaluator `B_Nx`, provide (a) symbolic equality of all output linear forms; (b) independent prime-field whole-basis verification; (c) a cost DAG including precomputation and precision; (d) a proof of `o(NlogN)` under a named machine model and a clear general/structured input distinction. Keep Phases 14–17 immutable for reproducible comparisons.
