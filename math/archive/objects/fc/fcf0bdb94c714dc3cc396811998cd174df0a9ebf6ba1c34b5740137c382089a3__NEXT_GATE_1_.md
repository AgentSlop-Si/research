# Next construction gate: phase-correct, expanding two-stage Green sums

The current exact first-principles target remains

    U_N = (G_1+G_2)(G_3+G_4)

or its independently diagonally gauged / rank-one-seed-corrected variant, with O(N) charged recurrence work on fresh arbitrary inputs. There is no known all-N parameter construction in these research materials.

## Research program

1. **Graph stage:** propose explicit non-affine cycle families sigma_1,..,sigma_4 with O(N) construction and O(N) stored indices. For a given N, reject any cycle family violating the necessary expansion bound at a certified Fourier-full-rank cut. For prime N the condition is all subsets; for N=2m, m odd, inspect the parity cut first, which has a constant spectral gap.
2. **Phase stage:** using O(N) Green forward solves, evaluate the Weyl-twirl phase loss `Z=(1/2)||M W z-Phi(W) M z||^2` with random a,b,z, and enforce the first Fourier column through `M_tilde=M+(v-Me0)e0^T`. Unlike tests on a few Fourier input vectors, this loss has EXACT expectation equal to the distance from the scalar Fourier line, and zero loss exactly identifies Fourier after seed correction.
3. **Optimization stage:** exploit differentiability of cyclic inverse solves. Reverse-mode differentiation of a fixed O(N)-arithmetic graph costs O(N) per probe, producing all O(N) coefficient gradients without materializing Fourier matrices. This does not prove convergence nor reduce the online execution cost of any actual FFT instance.
4. **Exact algebra gate:** take small-N candidates to finite fields with valid roots/denominators and test `M e0=v` and `MS=DM` using one-sided randomized exact linear identity checks. Nonzero residuals reject proposed algebraic parameter rules. Passing random finite-field tests is not symbolic proof.
5. **Proof gate:** only claim a new exact FFT theorem upon deriving an explicit uniform all-N formula and proving both Fourier covariance and coefficient/operation/precision bounds. If a candidate uses near-singular Green resolvents, explain its arithmetic model and stability separately.

## Strong quantitative rejection criterion

For N=2m, m odd, if the total crossing-edge rank budget across the even/odd parity cut is below m, any candidate M from this class satisfies

    ||M-U_N||_2 >= 1/sqrt(2).

If additionally `Me0=U_N e0`, its exact *mean random Weyl-probe energy* obeys

    E[ (1/2)||M Wz-Phi(W) Mz||_2^2 ] >= 1/8.

This can falsify models at large N without building U_N.

## What cannot be concluded

- A cut-expanding network can still have completely wrong Fourier phases (N=16 exhaustive example in RESULTS.json).
- Low stochastic loss at one size does not imply exact equality or generalization to all lengths.
- An O(N) verification/training step is not itself an O(N) Fourier implementation. The number of iterations to discover parameters is not proved bounded.
- The Weyl twirl result is derived from standard mathematics; novelty of an optimized research workflow requires broader prior-art and expert review.
