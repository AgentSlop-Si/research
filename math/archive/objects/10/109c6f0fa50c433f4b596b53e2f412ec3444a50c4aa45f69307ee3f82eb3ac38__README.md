# Sealed Delta/Newton material audit

Read AUDIT_REPORT.md for the accepted theorem, recognition/inversion accounting, exact family count, source coverage defects and fresh checks. Read EXTENSIONS_AND_FUSION.md for the complete optional-reset repair, output-rank/variation union and separately budgeted Toeplitz fusion.

Run independent checks from this directory:

    python3 independent_checks.py

To save a new result without altering the sealed result:

    python3 independent_checks.py --output delta_newton_independent_results.json

Only Python's standard library is required. The checker does not read or import the uploaded source files, require network access, or modify a research master. Source programs were read as data only. Its direct transforms/convolutions are correctness references, not the claimed fast-path performance benchmark.

The 36,422-byte tensor/fiber `(1)` source is a byte duplicate of the prior archive. The Delta archive adds sound fixed-order Newton structure but retains the old fused dispatcher. See provenance and hashes in the parent package. The findings include two actual sparse-input graph families proving strict complementarity of rank and first-variation reconstruction, and a concrete missed B-anchor/global-budget representation caused by greedy reset placement.

No universal arbitrary-input O(N) FFT, stable floating-point recognizer, generic multiplication speedup or novelty claim is established.
