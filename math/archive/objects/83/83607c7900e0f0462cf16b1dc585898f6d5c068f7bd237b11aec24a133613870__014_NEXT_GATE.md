# Next gate: from structured O(N) transforms to an arbitrary-input exact FFT

The O(N) results in Phase 14 are **on promised lower-dimensional chirp unions**. An explicit **stationary Toeplitz q=M frame** now supplies full rank and exact arbitrary-input recovery, but pays M separate G-scans, so the general speedup remains open. No unconditional exact o(N log N) FFT has been constructed. Read THEOREM.md and the tests before editing code.

## Main remaining challenge

For G=KM, fixed rank-q chirp unions have rank qG/M per input column. Exact arbitrary-input recovery requires local rank M (or an entirely different global computation). A q=M literal decoder calls M scans of length G, restoring Omega(NM) work. The new all-size stationary Toeplitz chart in THEOREM.md makes the Gram factorization reusable across all blocks and proves Vandermonde nodes distinct, so the remaining bottleneck is unambiguously the **joint q=M output decoder**. The **next task is to share these q scans algebraically**, or design an entirely different nonunitary Green evaluator, without hiding full-size FFTs, free precomputation, threads, cached outputs, or unrestricted costly matrix operations.

A credible candidate MUST give an explicit straight-line/vector program with (1) exact Fourier matrix identity for *every* input, (2) all-N correctness or honest restricted length scope, (3) total counts of N-FFT vs K-FFT calls, scans, roots, pairwise algebra, Gram inversions, routing, memory traffic and precision, (4) arbitrary dirty states, (5) independent finite-field all-basis checks, and (6) mutation rejection. Reprove covariance `M Z=R M` with the real residual seed, or both Fourier Weyl identities, from the Green Phase22 checkpoint.

## High-value hypotheses to try

- **Noncommuting frame sharing:** try the already VERIFIED stationary Toeplitz family `a_i=1+iK`, `beta_i=3s+i(K+1)` with q=M. Exact fusion of multiple *slopes* a_i, not only beta shifts. Derive an explicit recurrence for *all* q forcing streams with a number of shared states growing slower than qG. Examine commutator/Gram rank and conditioning, and reject stale/precomputed input values.
- **Graph/union reuse gate:** the verified Toeplitz slopes `a_i=1+iK` collide at a given scan-clock only along `M/gcd(j,M)` unique outputs, with exact total `K(2M^2+1)/3` distinct same-clock destinations, i.e. ~2/3 of the naive count. This is only constant-factor sharing. Seek *cross-clock algebraic* sharing or a genuinely different evaluator; do not equate destination collisions with recovered scalar operation savings.
- **Block Green forcing factorization:** find B=L F_N with a fast **structured** application despite its proven dense rows. Mere row sparsity is impossible when L is sparse. A low-dimensional forcing bottleneck without new input-side channels has insufficient rank; a dense forcing matrix is not by itself a quadratic lower bound.
- **Input-independent exact circuits:** try nonunitary, globally shared arithmetic DAGs that genuinely cross the rank-q projection boundary. Count state words and all gate costs. Existing Fourier well-conditioned unitary gate lower bounds are important restrictions, not a proof of a universal nlogn barrier.

## Immediate rejection tests

1. Fixed q<M projector claimed to approximate all x with relative full-vector error epsilon<sqrt(1-q/M) — rejected by leverage_gate.py, with an explicit one-sparse-per-block witness.
2. Adaptive beta-bank selection claimed to require o(M) banks on every x — rejected by equal-energy u=0 impulses.
3. Only r<M rank-N/M sketch outputs used, with postprocessing/adaptive output-dependent state choices but no independent input reads — zero-transcript common-kernel argument rejects exactness.
4. Sparse L claimed to generate sparse B=L F_N directly — Green density gate gives at least N/w entries per row, or N-1 for coprime two-coordinate shift.
5. Nonzero commutator claimed as speedup — q=2 remains rank 2 per M block; condition numbers and full numerical/finite-field checks are required.
6. Sublinear arithmetic work inferred from one-step variance, per-coordinate error or source-data dependence — a high-probability all-output guarantee or exact operator claim needs a separate proof.
