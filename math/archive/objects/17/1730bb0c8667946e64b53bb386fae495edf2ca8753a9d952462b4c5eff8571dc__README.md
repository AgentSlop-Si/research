# Hero #0 Phase 13 — Graph-cut capacity and explicit expander escape

Research continuation of `fft_hero0_phase12_fourier_green_rigidity_2026-10-10.zip`.

**Main conclusions**

- Every sum/product of weighted permutation Green resolvents has an off-cut rank bounded by the number of crossing nonzero edges in the **union of its graph factors**.
- The normalized Fourier matrix requires substantial rank across **every** index cut. At contiguous prefix cuts it has maximal possible off-cut rank, and small-capacity graph networks cannot even approximate it in operator norm.
- A uniform explicit 20-resolvent expander topology on square lengths passes **all** these necessary cut-rank tests in O(N) graph preparation and O(N) operator application, but its weights are **not** known to make it the Fourier matrix.
- A lifted block-matrix rank identity turns the unresolved weight problem into an exact polynomial compatibility gate for arbitrary two-layer Green sums.
