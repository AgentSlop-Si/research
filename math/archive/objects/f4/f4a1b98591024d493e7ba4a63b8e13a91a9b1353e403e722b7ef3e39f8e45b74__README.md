## What is useful here

1. **Query-v2 fixes.** Modular phase reduction, safe calibration-row reuse,
   accurate zero-trial behavior, recent-suffix shared/group replay, corrected
   fusion cost choices, requested-member cache publication, compact projection
   ownership, and improved numeric accounting.
2. **Phase7 fixes.** Recovered dispatcher/cache regressions, atomic rejected
   subscription edits, real-input validation, iterative deep-chain access and
   evaluation, and correct cross-engine sharing diagnostics.
3. **Experimental single-view policy.** Snapshot/coalesced changes remove
   lifetime-history dependence, with matched-output comparators. It has an
   explicitly demonstrated floating-point cancellation failure that requires
   rebasing. It is not a generally interchangeable numerical replacement.
4. **Exact fixed-pair algebra.** Maintain four convolution kernels to update two
   fixed editable factors without dropping their bilinear cross term. This is
   a derived specialization, with exact integer checks, not production code or
   a new general FFT algorithm.

## Main boundaries

- The uploaded pruning and convolution identities are valid classical algebra.
  These experiments do not establish a new uniform sub-N-log-N FFT or a new
  integer-multiplication complexity bound.
- Setup, output copies, history reclamation, cache misses, retained versions,
  memory allocation and numerical conditioning all count.
- A cached query returning q values costs at least O(q). If required history is
  missing, the min(lag, relation-size) bound need not hold.
- The coalesced Python prototype costs
  O(q[1+min(u,r+k)]+u) per query, including releasing u pending entries. Strong
  snapshot subtraction cancellation can remain until explicit `rebase()`.
- Iterative Phase7 traversal avoids recursion failure but does not balance an
  append-built graph. Tuple-key hashing and linear seed ownership scans remain.
- The fixed-pair dense bound is O(N[1+s_a+s_b]) after preparation, with 4N
  kernel scalars and generally up to 3N additional scalars per retained fork.
  It does not automatically apply to changing arbitrary pairs, many changing
  factors or selected time coefficients.
- Numerical arrays and exact algebra are distinct. Modular identity checks do
  not certify floating-point stability. No benchmark is a universal speedup.

## Best bounded next experiment

Implement the fixed editable-pair four-kernel path behind an explicit policy.
Compare a mutable stream and retained forks against both a hand-specialized
four-kernel baseline and the existing FFT path. Charge all preparation and
memory; vary N, edit supports, reuse count and query shape; verify every output
and stress cancellation/overflow. In parallel, measure the single-view policy
with rebasing before considering it a default.
