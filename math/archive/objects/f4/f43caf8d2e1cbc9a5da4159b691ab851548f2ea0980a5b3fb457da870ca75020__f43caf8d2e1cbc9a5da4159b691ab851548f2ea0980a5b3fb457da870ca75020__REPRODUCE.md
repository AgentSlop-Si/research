# Portable replay

Run only this review's two independently authored root-level programs:

    python check_integrity.py
    python independent_checks.py

Python 3 and NumPy are required. Do not run or import programs under `extracted/`; they are preserved source evidence only. No other review folders or absolute paths are required. Outputs are `INTEGRITY_RESULTS.json` and `INDEPENDENT_RESULTS.json`. The original copies, extraction and inherited-reference ZIP needed by the integrity checker are included in this folder.

`SEAL.json` records byte lengths and SHA-256 hashes for all payload files other than the seal itself and its text rendering. `SHA256SUMS.txt` is a convenience rendering of those hashes. A replay in a separately copied temporary directory is recorded in the sibling `review_incoming_2309_phase10_replay` folder so this sealed payload remains immutable.
