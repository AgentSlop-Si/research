# Hero #1 v12 — centered all-length Fourier correction with rank-independent fusion certificate

**9 October 2026.** Scope: arbitrary fresh complex input, every output explicitly produced, **randomized approximate normalized DFT** through the inherited v9 chirp row. This document does **not** claim an exact sub-`N log N` FFT, a new integer-multiplication exponent, peer-reviewed novelty, or unconditional bit complexity.

## Setup and exact kernel identity

Let `1<=N<=Q=2^ceil(log2 N) <2N` (the last strict inequality holds for N>1), `j_k=floor(kQ/N+1/2)` and `theta_k=(kQ-j_k N)/N`, so `|theta_k|<=1/2`. For `n in {0,...,N-1}`, let `s_n=n/Q` and

    c = (N-1)/(2Q),    u_n=s_n-c.

The normalized N-point Fourier kernel decomposes **exactly** as

    exp(-2 pi i k n/N)
       = exp(-2 pi i j_k n/Q) exp(-2 pi i c theta_k)
         exp(-2 pi i u_n theta_k).

With `v=2 theta_k in [-1,1]`, the classical Jacobi–Anger expansion is

    exp(-i pi u v) = J_0(pi u) + 2 sum_{r>=1} (-i)^r J_r(pi u) T_r(v).

This holds also for negative `u`. Accordingly, the existing shared dyadic chirp-decoder architecture can be used unchanged, with Bessel weights `J_r(pi(n/Q-c))` rather than `J_r(pi n/Q)` and **one output-side unit phase** `exp(-2 pi i c theta_k)`.

## Theorem 1. Optimal single global center and certified rank savings

Since `s_0=0` and `s_(N-1)=(N-1)/Q`, every real center `c'` satisfies

    max_n |s_n-c'| >= (N-1)/(2Q).

Equality holds at `c=(N-1)/(2Q)`. Consequently the maximum Bessel argument is halved, from `z_old=pi(N-1)/Q` to `z_new=pi(N-1)/(2Q)<=pi/2`.

Let `a=z/2`. From the power series of integer Bessel functions, for `r>=1`,

    |J_r(z')| <= a^r/r! * exp(a^2/(r+1))    when |z'|<=z.

Therefore for any rank `R>=1` with `a<R+1`, the omitted Jacobi–Anger modes have uniform pointwise error at most

    tau_R(z) = 2 exp(a^2/(R+1)) * a^R/R! / (1-a/(R+1)).

The normalized transform's deterministic truncation error in any output is at most `tau_R(z_new) ||x||_2`. This is a proven worst-case guarantee, not an expected-error claim.

Using this same formula for the active input interval at `N=511, Q=512` and target truncation error `10^-8`, the smallest certified rank is **R=15 uncentered versus R=11 centered**. This means 4 fewer rank-dependent dyadic decoders; it is not a claim that the actual FFTW wall-clock time decreases by 4/15. The original v11 worst-case bound also gives R=15 there.

## Theorem 2. Neumann local-fusion error can be bounded independently of R

In the existing one-pass local input compressor, `n=bM+t`, `Q=K M`,

    z_b = pi(bM/Q - c),  delta_t=pi t/Q.

Neumann's addition identity gives

    J_r(z_b+delta_t)=sum_{h in Z} J_(r-h)(z_b) J_h(delta_t).

Our implementation retains only `|h|<=H` locally, for every global Bessel order `r` among `0,...,R-1`. Let `delta_max=pi(M-1)/Q` and let `A_H(delta_max)` be the **two-sided Bessel tail** explicitly bounded by the `small_argument_bessel_tail` formula in the supplied v11 code. Let

    B(z)=sup_|t|<=z sum_{a in Z}|J_a(t)|
        <= 1 + 2 exp(z^2/8) (exp(z/2)-1).

**Claim:** the entire local-fusion kernel error satisfies

    kappa_H <= B(z_new) A_H(delta_max) < 4.25 A_H(delta_max),

**with no factor of R**.

**Proof:** the negative and positive Fourier-order representation of the Jacobi–Anger expansion uses coefficients `(-i)^r J_r(z)` and unit-modulus harmonics. The neglected local channels at order `r` have coefficient

    e_r = sum_|h|>H J_(r-h)(z_b) J_h(delta_t).

The error in the *truncated* global series is bounded by

    sum_|r|<R |e_r|
      <= sum_(r in Z) sum_|h|>H |J_(r-h)(z_b)| |J_h(delta_t)|
      = (sum_(a in Z)|J_a(z_b)|) (sum_|h|>H |J_h(delta_t)|)
      <= B(z_new) A_H(delta_max).

The equality is a reindexing of an absolutely convergent double sum. The symmetric `r`/`-r` terms are equivalent to the implemented positive-order Chebyshev terms. Because only active input blocks need to be considered, `|z_b|<=z_new`. QED.

This improves the v11 bound `(2R-1) A_H` in the common regime R>3; **it does not reduce the number of decoder scans**.

### Consequences

For the deterministic centered/fused transform center, every output satisfies

    |Xbar_k - (U_N x)_k| <= epsilon_RH ||x||_2,
    epsilon_RH = tau_R(z_new) + B(z_new) A_H(delta_max).

The inherited shared-state v9 covariance calculation then yields, for each output,

    E|Xhat_k - Xbar_k|^2 <= (M/N) (1+epsilon_RH)^2 ||x||_2^2.

The output carrier has unit modulus, so it does not change that variance. All other assumptions of the v11 robust majority-grid decoder continue to apply (including its exact-arithmetic quantization and failure-probability contracts). For `H=0`, the improved local error is `O(M/N)=O(log N/N)` for the chosen dyadic block size, improving the prior `O(R M/N)` certificate. The **total** running time remains `O(RN)`.

## Theorem 3. Only two phase transitions are needed algebraically

Put `r_k=kQ-j_kN`. The carrier is

    phase_k=exp(-2 pi i c r_k/N).

Because `1<=Q/N<2`, the nearest-grid increments `d_k=j_(k+1)-j_k` are always in `{1,2}`. Thus

    phase_(k+1) = phase_k * gamma_(d_k),
    gamma_d = exp(-2 pi i c (Q-dN)/N).

There are **two** distinct transition factors. A Blelloch product scan computes all N phases from those two constants using `O(N)` scalar complex multiplications and `O(N)` space, with `O(log N)` multiplication depth. The carrier can be retained once and reused for every randomized row; there is no hidden `O(RN)` output-phase table.

**Important finite-precision caveat:** balanced multiplication depth reduces *arithmetic rounding* depth. It **does not** prevent root-constant error from accumulating when the same approximate `gamma_d` is reused N times. A certified implementation must either compute the two phases to absolute accuracy `O(target/N)`, periodically reanchor the phase, or evaluate phases directly at adequate precision. The original v11 conditional mantissa-bit result is **not automatically extended** to the two-root shortcut. `shared_carrier` is a demonstrator of the algebraic accounting, not an independently certified fixed-precision root generator.

## Fully charged work model

With `H=O(1)`, `R` global Bessel orders, Q=KM, and the inherited FFT and scan modules:

    input compression          O((2H+1) Q)
    block-order Bessel fusion  O((2H+1) R K)
    length-K FFTs              O(R K log K)
    dyadic gauged scans        O(R Q)
    selected output Clenshaw   O(R N)
    phase generation/writes    O(N) plus certified root setup

The asymptotic sequential arithmetic remains `O(RN)`. At `R=Theta(log N/log log N)`, the polynomially shrinking-error theorem is still `O(N log N / log log N)`. At fixed error epsilon and constant R, the inherited randomized approximate result is `O_epsilon(N)` under its original model assumptions.

`work_proxy` explicitly prices the large loops, but omits constant factors and implementation-specific high-precision Bessel/root generation. It must not be interpreted as an exact arithmetic-gate count or a bit complexity certificate.
