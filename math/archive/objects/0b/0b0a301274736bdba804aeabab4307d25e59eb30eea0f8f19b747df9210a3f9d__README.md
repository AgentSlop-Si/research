# Global chirp streaming extension and comparative audit

Read `STREAMING_ROBUST_SYNTHESIS.md` for the theorem and comparison with previous sketches and recovered obstructions.

Main addition: five dynamic representatives per real output coordinate replace exact medians. With R=4s-1 independent chirp rows, this changes only constants in v7's error/work exponents and reduces growing-row storage to O(N) exact-arithmetic registers. It is a different robust estimator, with an all-size proof and independent invariant checks. Numerical stability, bit complexity, and novelty are not established.

Files:
- `STREAMING_ROBUST_SYNTHESIS.md`: full theorem, arithmetic/model audit, and scoped comparison
- `INDEPENDENT_LEMMA_REVIEW.md`: independent proof review
- `independent_streaming_checks.py`: independently authored standard-library checker
- `streaming_check_results.json`: saved exact-integer check summary

Reproduce the finite checks from any working directory:

    python independent_streaming_checks.py

No uploaded code or external research tree is needed by this checker. The proof cites original research paths for provenance; its mathematical arguments and checker are self-contained.
