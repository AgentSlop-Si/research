# Hero #1 v13 — mixed-radix FFT-sketch fusion and exact phase-bank rank gate

**Date:** October 10, 2026. New independent checkpoint, built from the user-supplied v9/v12 unit-step sketch architecture and classical mixed-radix Fourier factorization. CrocSwap was consulted for accounting and reproducibility standards, **not** adopted as an algorithmic approach.

## Quick findings

1. For `N=G*m` with `G=2^v2(N)` and odd `m`, **no Bessel-rank scans** are needed: independently sketch `m` length-G columns and finish with G FFTs of length m. The exact-arithmetic one-row expectation is **exact F_N x**, and every output variance is `<= (M/N)||x||_2^2`.
2. Scalar work is `O(N(1+log(m+1)))` per row when `M~log G`. This is `O(N)` for fixed odd m and `O(N loglog N)` for polylogarithmic m on the indicated even-length families. **Not a worst-case all-length FFT bound**; for odd prime N it calls an ordinary FFT.
3. A strong negative barrier was made exact: every one-row map equals `F_N P` with rank `N/M`, spectral error `M-1`, and Frobenius error squared `N(M-1)`. This rules out uniformly accurate single-row full-vector transforms, despite the pointwise variance guarantee.
4. `M` phase-shifted beta banks average to the **exact Fourier transform**. Fewer cannot work by rank. This explicitly locates the next gate: compress the **complete joint bank** below its ordinary `Omega(N log G)` work, not just the input summaries.
5. Reproducible verification: 13 v13 Python tests, complete finite-field all-basis checks (45,696 entries), mutation controls, and regression against direct FFT. No full independent finite-precision bit-operation theorem is claimed.
