# Archived proof-source review, batch 09

## Result

All 42 assigned exact hashes were read first-to-last as inert text: 348,883 bytes and 7,388 lines in 18 complete display groups. No supplied source was executed, imported, compiled, or AST-parsed. Every source has an exact snapshot, numbered text, per-hash semantic review and full-read receipt. Prior seals and originals are preserved. This package does not edit the central registry.

Eight exact archive containers were rehashed. All 111 assigned source occurrences match: 65 archive members checked by exact index/name/hash/size and 46 standalone master paths. All historical evidence document hashes reconcile. The starting registry records 1,323 full reads; this package supplies 42 new direct reads for separate acceptance.

## Important findings

1. A companion composite-covariance document disagrees with its inherited local manifest. Expected 8e1949fc…; current and multiple older archived copies are 2080056b…. No assigned Python hash mismatch. The document, manifest and previous seals are untouched.
2. Three twisted-bound manifest targets are old absolute paths. Their relocated same-directory contents match the expected hashes exactly. Literal path resolution and relocation are explicitly separate.
3. The twisted-displacement product rank-budget test is dimensionally automatic in all 13 listed cases. The bound is already >=N. Other exact identities and branch tests are not invalidated; this observation concerns test strength.
4. Historical provenance checkers have varying scope. The 1807 metadata has no predeclared hashes, so its size check plus computed SHA256 is measurement rather than verification of a prior identity. Both actual recorded archive digests freshly match. Phase18 hash-set membership does not establish path/multiplicity completeness. Some source-driven loops permit empty data; actual reviewed relevant certificates are nonempty and have their expected recorded counts.
5. The N5 source constructs and checks a three-Green representation; its stated minimality lower bound is inherited from a separate sealed audit. Do not promote this construction checker into a standalone minimality proof.

## Evidence classes

- Direct source inspection: complete for the 42 hashes only. Hashing a source, recording authorship, or having a historical result was not counted as reading it.
- Fresh controls: five independently authored arithmetic/text/data checks ran, isolated from supplied code. They test same-size ZIP identity ambiguity, content-set multiplicity loss, list vacuity versus actual cardinalities, the dimensionally automatic rank budgets and small field constants.
- Historical execution: original inventory flags and recorded-run evidence are retained unchanged. Stored logs/results are indexed, snapshotted and compared where parsable; they are not fresh runs. Wrappers, helpers and copied results do not automatically inherit entrypoint or branch coverage.
- Mathematics: exact fixed-size symbolic coefficient/minor checks express genuine algebraic certificate logic for those parameterized fixed-size identities. Finite modular checks, random searches, high-precision controls, double-precision ranks/entropy and Decimal ledgers are not uniform proofs. Numerical computations are not interval certificates.
- Costs: operation counts are field/gate models with stated setup, checking, memory or bit-complexity exclusions. Permuted-geometric DFT evaluator is restricted-input and explicitly does not claim a generic faster FFT.
- Novelty: no literature-wide novelty or priority conclusion is made. No unrestricted exact sub-N-log-N FFT result is established by this review.

## Dependency and stored-integrity limits

Textual imports were reconciled to same-directory hashes where available; external package versions and runtime import closure were not executed or certified. Three distinct imported helper hashes are also in this batch; other helpers retain exact candidate and prior-registry/frozen-inventory mappings. Driver targets are listed independently. Required certificate JSON is data, not executable authority.

Conservative stored-integrity reconciliation checks 1,841 local manifest entries: 1,837 literal matches, one document mismatch and three explicitly relocated matches. JSON hash-reference resolution is record-relative and separately reports unresolved references; an unresolved reference is not a finding of corrupt or absent corpus content.
