# Packed Phasor-Table Fourier Estimation (PPTFE)

**Research note, 10 October 2026**

**Status:** A new, self-contained asymptotic **conditional theorem in a restricted finite-word model**, based on and completing an unfinished proof obligation in the user's `SPARSE_SURROGATE_WORDRAM_CHECKPOINT_2026-10-09_v2.md`. The packing/transposition gadget and full complexity ledger below are new to this synthesis, but their **external research originality is unconfirmed**; categorical sampling, Hoeffding, Four Russians, and word-level bit transposition are established methods. A simulator independently checks the finite algebra and error decomposition, not the asymptotic performance or a full physical implementation. **This is NOT an exact O(N) FFT and NOT a real-RAM/bit-complexity lower-bound counterexample.**

## Abstract

For every **fixed** accuracy `0 < eps < 1`, **fixed** failure-exponent `a > 0`, and **fixed** integer input magnitude exponent `c >= 0`, there exists a randomized, single-processor word-RAM algorithm which, given any fresh `x in (Z+iZ)^N` with `|Re(x_j)|,|Im(x_j)| <= N^c`, produces all `N` explicit finite-precision Fourier estimates `yhat_m`. For the unitary DFT `U_N` and

```
L(x) = sum_j ( |Re x_j| + |Im x_j| ),
```

it guarantees

```
Pr[max_{0<=m<N} |yhat_m - (U_N x)_m| <= eps * L(x)/sqrt(N)] >= 1 - N^{-a}.
```

In a standard random-word RAM with word size `w = C(eps,a,c) ceil(log2(N+2))`, constant-time word arithmetic including integer multiplication/division and random-word generation, explicit `N`-value output, and **all preprocessing charged**, the expected running time is `O_{eps,a,c}(N)` word operations, with `O(N)` total space. Lookup tables are input-independent, take `o(N)` time and memory to build, and are not supplied by a free oracle. The estimate is generally *not close* to the DFT in relative `l2` error; its `l_infinity` error scale is proportional to `L(x)/sqrt N`, which can be much larger than typical Fourier coefficients.

The crucial new-to-this-writeup step is a **third (transpose) lookup table** which converts `G=Theta(log log N)` packed group trajectories to `B=Theta(log N)` lane keys in `O(G^2+B)` operations **per B-lane block**, preventing a hidden `O(N log log N)` aggregation cost.

## Model and excluded interpretations

- The entries are bounded-magnitude **integers**, not arbitrary infinitely precise complex numbers. Intermediate sums and output mantissas/exponents fit `O(log N)` bits, with multiplicative word-size constants depending on the fixed parameters.
- The word-RAM has uniform `O(1)` lookup into arrays of `N^gamma polylog N` precomputed entries, and `O(1)` arithmetic on a constant number of machine words. Random unbiased bounded integers cost `O(1)` **expected** random-word operations by rejection.
- The output is an explicit vector of `N` approximations, not a delayed-query handle. One may store each in a shared-scale fixed-point/float representation; a common normalization can be materialized per output at `O(1)` word work.
- All constants, including lookup-table construction and coefficient/root approximation, are charged. They can be *astronomical* for useful eps; no practical speed comparison is claimed.
- No conclusion for exact outputs, shrinking eps, high relative accuracy, bounded-coefficient complex arithmetic circuits, or multiplication upper bounds follows.

## Lemma A: unbiased signed-atom surrogate

Represent x by 2N possible signed unit atoms:

```
atom_(j,R) = sign(Re x_j) e_j, weight = |Re x_j|
atom_(j,I) = sign(Im x_j) i e_j, weight = |Im x_j|.
```

Choose each of k independent atoms `a_l` with probability `weight/L`, and set

```
Y = (L/k) * sum_{l=1}^k a_l.
```

Then `E Y=x`. For every `m`, the normalized scalar random variable `Z_l(m)=sqrt(N)* (U_N a_l)_m` has `|Z_l(m)|=1`. Hoeffding on its real and imaginary components gives

```
Pr[ |(U_N Y)_m - (U_N x)_m| > eta L/sqrt N ]
    <= 4 exp(-k eta^2/4).
```

Union bound over all N bins yields failure at most `4N exp(-k eta^2/4)`. With `eta=eps/2` and

```
k_min = ceil( 16 eps^{-2} ln(4N^(a+1)) ),
```

failure is at most `N^{-a}`. Categorical sampling can use a word-level integer alias table built from the 2N weights in `O(N)` operations, followed by `k=O(log N)` draws. If L=0, output N exact zeros.

## Lemma B: compact trajectory descriptors

Partition output frequencies into consecutive blocks of width `B=ceil(log2(N+2))` (the final block may be shorter). Fix block start `b`. For a sampled atom with time position j and sign `s in {1,-1,i,-i}`, define its trajectory

```
z_t = s * omega_N^(j*(b+t)),  0 <= t < B.
```

The only block-specific information is the starting phase `u=omega_N^(jb)` and the slope `v=omega_N^j`. Quantize the starting angle to a circular grid of `P0=ceil(32*pi/eps)` phases, and the slope to `P1=ceil(32*pi*B/eps)` phases, both via rounded integer quotients. This needs

```
p_d = ceil(log2( 4 P0 P1 )) = O(log log N)
```

bits/descriptor for fixed eps. Angular discrepancies are at most `pi/P0` and `pi/P1`, respectively. As `|exp(iθ)-exp(iφ)|<=|θ-φ|`, every lane suffers at most

```
eta_phase <= pi/P0 + (B-1) pi/P1 <= eps/16.
```

(Our grid constants in fact give `<= eps/16` with room to spare.) Precompute templates for all descriptor/lane pairs to complex absolute error at most `eps/32`. There are `O(B^2/eps^2)=polylog N` pairs. Fixed-point trig/root preparation can be performed by polynomial-time-in-`log B` rational approximation, so total template preparation is `polylog N = o(N)` word operations under the fixed-parameter model.

Online per descriptor, compute `jb mod N` and `j mod N` and rounded phase buckets with `O(1)` integer word operations. Since there are k samples per output block, all descriptors take `O(k)=O(log N)` operations per block. Each original `j` is available from the alias sampler; no FFT is called.

## Lemma C: first-level table

Fix `0<gamma<1/3` once and for all, and let

```
g = floor( gamma log2 N / p_d )
G = ceil( k_min/g ),   k=Gg
```

for sufficiently large N, so `g>=1` and `G=O_{eps,a}(log log N)`. Draw k rather than k_min samples, maintaining the guarantee. Each group of g trajectory descriptors is a single key with at most `gamma log2 N` bits. Build table T1 containing for **every** such key the B-lane average of the corresponding phasor templates, rounded to a constant-precision complex grid of max absolute rounding error `eps/32` per lane.

A first-level grid symbol has `s1=O(log(1/eps))` bits, a constant for fixed eps. Thus one B-lane table output contains `B*s1=O(log N)` bits and fits in `O(1)` machine words. There are at most `2^(p_d*g)<=N^gamma` keys. Constructing each vector by g·B additions yields

```
T1 build time = O(N^gamma g B) = N^gamma polylog N = o(N).
T1 space = O(N^gamma) RAM words = o(N).
```

With one T1 lookup per group and output block, we obtain G packed words, logically a G×B symbol matrix. Naively extracting all G groups at each of B frequencies would take B·G operations per block, and that would yield **O(N log log N)** total: the exact gap in the earlier v2 checkpoint. Do not skip this cost.

## Lemma D: transpose lookup Ttr — the additional decisive step

Let `s1` be the bits per rounded group symbol. Choose a lane-chunk width

```
L_chunk = floor( gamma log2 N / (G*s1) ) = Theta(log N/log log N).
```

For each consecutive chunk of `L_chunk` lanes, extract its `L_chunk*s1`-bit subword from each of the G packed T1 outputs and concatenate those G subwords into a row-major key:

```
[symbol(0,0),...,symbol(0,L-1), symbol(1,0),...,symbol(G-1,L-1)].
```

Its length is at most `gamma log2 N`. Define an input-independent lookup Ttr that permutes these bits to the **lane-major** order

```
[symbol(0,0),...,symbol(G-1,0), symbol(0,1),...,symbol(G-1,L-1)].
```

That word holds all L individual second-stage keys of G*s1 bits, concatenated; extract each in one shift/mask operation. Ttr is a genuine word-level perfect-transpose table. It has at most `2^(G*s1*L_chunk) <= N^gamma` input keys and is constructed using `O(G*L_chunk)` bit-field operations per key, totaling `N^gamma polylog N=o(N)` time and `o(N)` words. No uncharged matrix transpose is assumed.

There are `ceil(B/L_chunk)=O(G)` lane chunks. Building each chunk key requires O(G) shifts/masks, for **O(G^2)** work per output block; Ttr itself costs O(G) lookups per block. Extracting B individual lane keys costs **O(B)** operations, but the N explicit outputs must be written anyway. Since `G^2=O((log log N)^2)=o(log N)=o(B)`, transpose plus extraction is `O(B)` per block.

## Lemma E: second-level table

Each lane key is G fixed-alphabet first-level symbols. Define table T2 to return their mean (over G groups), rounded once more to complex error at most `eps/32`. Since `s1*G=O(log log N)`, there are at most

```
2^(s1 G) = (log N)^O_{eps,a}(1)
```

keys. T2 takes `polylog N=o(N)` time and words to construct, counting its G additions per key. Each of the B lanes costs O(1) T2 lookup and O(1) output scaling/writing. Total T2 work O(B) per block.

## Theorem: accuracy and total cost

Let `avg_m=(1/k) sum_l sign_l omega_N^(j_l*m)` denote the empirical Fourier phasor average. Combining the starting/slope phase quantization, phase-template error, T1 group rounding, and T2 aggregation rounding gives, uniformly in all m,

```
|z_m - avg_m| <= eps/16 + eps/32 + eps/32 + eps/32
               = 5 eps/32 < eps/2.
```

An `eps/32`-relative approximation of the scalar `L/sqrt N`, together with `|z_m|<=1+eps/2`, adds less than `eps/16 * L/sqrt N` to the final absolute error when eps<1 (choose a smaller normalization accuracy if desired). Combining with Lemma A gives the advertised `eps L/sqrt N` bound with probability `>=1-N^{-a}`.

An output-block cost audit is

```
O(k)                           descriptor construction & group-key packing
+ O(G)                         T1 lookups
+ O(G^2)                       row-major chunk assembly / Ttr lookups
+ O(B)                         T2 extraction, final scaling, explicit writes
= O(B)                         for fixed eps,a because k=Theta(B), G^2=o(B).
```

There are `ceil(N/B)` blocks, giving `O(N)` online decoding work. Add O(N) fresh-input scan + exact categorical alias setup, O(k) sampling, and `o(N)` total table construction. The total is `O(N)` **expected** random-word RAM operations and `O(N)` space.

This is a proof for the specified computational model and *extremely weak, norm-scaled* approximation contract, not for arbitrary floating complex inputs or exact DFT.

## Corollary: certified structured baseline / control variate

Let `z` be any selected baseline and `r=x-z` have bounded-integer coordinates in the same word-RAM model. If a separately charged evaluator produces all estimates `w` of `U_N z` with deterministic error at most `tau` per coordinate, apply the algorithm to `r` and return `w + estimate(U_N r)`. The triangle inequality gives

```
Pr[ ||reported - U_N x||_infinity <= tau + eps L(r)/sqrt N ] >= 1-N^{-a}.
```

When an available *linear-word-cost* baseline is verified (periodic, known recurrence, certain tensor fibers), this hybrid remains O(N) with the baseline's separate precision/setup charged. It can greatly improve accuracy when L(r)<<L(x). If the baseline is only mathematically exact in a different algebraic model, do NOT set tau=0 in a finite-word implementation without separately proving exact representation.

## Accuracy barrier: fixed eps must not be silently replaced by eps(N)->0

`k_min=Theta(eps^{-2} log(N/delta))`. If eps=N^{-b} for fixed b>0, then `k_min=Omega(N^{2b} log N)` for the stated failure probability; the first-level descriptor grouping and T2 alphabet counts also change. Therefore **this algorithm does not yield exact integer multiplication, uniformly tiny floating-point error, or an exact FFT by letting eps shrink polynomially**. It is not a new bound in the exact complex-arithmetic model.
