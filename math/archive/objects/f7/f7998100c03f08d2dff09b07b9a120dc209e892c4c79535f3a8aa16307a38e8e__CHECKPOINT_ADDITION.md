There is still no new exact arbitrary-fresh-input all-output transform below N log N. This update adds a proved sorting obstruction and a better restricted exact evaluator, with explicit corrections to the uploaded implementation.

## New accepted results

- Stable binary sorting has exact shift-defect rank r=2 floor(T/2), where T counts internal noncyclic transitions. The theorem holds over every field.
- For iid fair binary inputs, Pr(r=2k)=binom(N,2k+1)/2^(N−1), E[r]=N/2−1 and Var(r)=N/4 for N≥3. A fixed rank cap covers only polynomially many of the 2^N binary words.
- Simultaneously for every nonzero cyclic stride, including noncoprime strides, the correction rank is at least N/8 with explicit probability tending to one; the source guarantee is about 0.995693 at N=8192.
- The nearby-order Woodbury identity is valid off the root locus. Its small correction determinant is exactly one. The supplied dense schedule is an upper bound, not a lower bound for all implementations.
- A separately authored sparse twisted-difference method evaluates every output of a given near-order geometric input in O(N(s+1)) field arithmetic and O(N) space, where s counts changed successor edges. It handles all z, including the root locus, by directly summing one possibly singular output. Its standalone implementation avoids dense test-harness setup.

## Required corrections and limits

- For T≤1, changed-edge count s=0 and there is no nontrivial defect cycle. The source's s=r+1 statement applies only to T≥2.
- The source's s=0 code repeats z^N in every output, adding Θ(N log N) modular arithmetic. Hoisting the shared factor fixes the implementation.
- The uploaded Phase24 routine excludes z^N=1. Phase23's shortcut for an unpermuted character does not directly cover a reordered one; the independent sparse evaluator supplies a complete branch.
- Field/root/normalization setup, input-family verification, permutation validation, output materialization, inversions, bit costs, and complex conditioning remain charged. A fixed finite field and finite tests do not establish an asymptotic arbitrary-size complex transform.
- Rank bounds restrict the stated cyclic-reference correction architecture. They do not rule out faster algorithms through unrelated sparse graphs, nonlinear operations, independent noncommuting orders, or a genuinely efficient treatment of a high-rank correction.
