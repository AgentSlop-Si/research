# Reproduction guide

Python 3.11+ recommended. NumPy is used for one complex-norm diagnostic; without it that one unittest is skipped and the finite-field tests still work. Run from the Phase17 directory:

```sh
python run_all.py
```

Individual passes:

```sh
python -m unittest -v test_phase17
python field_basis_audit.py
python operation_benchmark.py
python precision_gate.py
```

To run the original Phase16 checkpoint as an independent regression, rather than replacing or modifying its sources:

```sh
python run_all.py --prior
```

Archive integrity after extraction:

```sh
sha256sum -c MANIFEST.sha256
```

The exact prime fields used are 2013265921 (generator 31) and 998244353 (generator 3). The chosen transform lengths divide `p-1`, and Bluestein additionally requires `2N` and the auxiliary power-of-two convolution length to divide `p-1`. Code explicitly tests root primitivity and the Green cycle closure. No network, GitHub checkout, or external integer-multiplication implementation is required.
