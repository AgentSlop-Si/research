# Stop-list and next gate — fresh Boolean FFT

1. **Do not repeat:** exact FFT cache collisions; shift/reversal equivalence; precomputed full input-output lookup; symbolic Galois descriptor without numerical expansion; chirp recurrence; low-degree annihilators; prepared incremental corrections; arbitrary-input algebraic differentiation; low-overlap one-hot coefficient extraction; OpenAI/CrocSwap circuit retuning.
2. **Quadratic gate already closed:** any total-degree-two Boolean-correct polynomial P is exactly recoverable as a full field-linear Fourier map with two evaluations at 1/2±h. Quadratic Boolean idempotency does not create an independent asymptotic route in that circuit model.
3. **Cubic gradient barrier is narrow:** N fixed gradient basepoints needed in the universal weighted-extraction model; nonlinear output readouts or different gate types may evade it. Do not claim a general cubic lower bound.
4. **Large-overlap gauge is not a speedup:** Θ(N²) formal pair coefficients can be factored in O(N), but G(x)=0 on the cube. Adding G to an FFT expression increases, not decreases, the work.
5. **Linear-readout feature bank:** exactly N shared scalar features capable of giving N independent Fourier outputs by linear readout must span only Boolean-linear functions. Any nonlinear feature needs extra dimension. This is not a lower bound on arbitrary circuits.
6. **New candidate acceptance:** exact every-binary-input full-output algorithm, sequential cost with all scalar and precomputation work, at least one provable growing saving over the best fair comparable baseline; gate construction/inversion count and uniform family rather than isolated N=8 or N=16 results. Input-independent lookup tables must be charged; exact numerical output format stated.
7. **Separate target:** an arbitrary complex exact O(N) FFT is strictly harder/different from Boolean-only evaluation; don't infer that one solves the other without a priced reduction.
