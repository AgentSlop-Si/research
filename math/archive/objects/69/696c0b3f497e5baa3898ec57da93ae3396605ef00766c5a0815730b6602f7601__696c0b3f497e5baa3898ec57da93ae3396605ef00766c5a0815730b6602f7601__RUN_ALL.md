# Run all verification checks

Requirements: Python 3.10+, NumPy and a C++17 compiler `g++`. No internet services or third-party closed-source solvers needed.

```bash
python run_all.py
```

The runner compiles `rankmod.cpp`, invokes the independent large-minor certificates in two primes, verifies explicit gauge kernels and fresh-vector stage execution, runs new unit tests, and independently extracts and runs the prior endpoint-rank checkpoint's nine tests. The test suite uses saved exact integer generator matrices; modular nonzero determinants prove the claimed rank lower bounds over the complex numbers.

The complete 34-case bit-reversal Jacobian rank census may be regenerated with:

```bash
python generate_bitrev_certificates.py
```

This updates `BITREV_RESULTS.json` and three saved witness JSON files. Use this only if you want to reproduce the original deterministic certificates; for a read-only check, use `independent_verifier.py`.
