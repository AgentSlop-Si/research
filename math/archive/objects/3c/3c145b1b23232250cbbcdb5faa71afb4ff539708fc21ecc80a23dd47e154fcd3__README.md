# FFT global-chirp research v8

This bundle continues the v7 global quadratic-chirp Fourier sketch with two additions:

1. a gauge-transformed balanced prefix-scan decoder; and
2. an `O(N)`-memory three-grid Boyer--Moore robust output aggregator.

The result is a reproducible theorem candidate for fresh arbitrary dense inputs, all `N` approximate Fourier outputs, dyadic lengths, and exact complex arithmetic. It is **not** an exact FFT replacement or a claim of established novelty.

## Files

- `RESEARCH.md` — theorem statements, derivations, complexity accounting, numerical audit, and limitations.
- `prototype.py` — v8 implementation and experiment generator.
- `prototype_base_v7.py` — inherited v7 row and independent reference implementation.
- `test_checkpoint.py` — 11 automated tests.
- `results.json` — saved deterministic experiment results.
- `MANIFEST.sha256` — integrity hashes.

## Requirements

- Python 3.11 or later
- NumPy

## Reproduce

```bash
cd fft_streaming_majority_stable_v8
python prototype.py --output results.json --seed 0
python -m unittest -v test_checkpoint.py
```

## Main exact-arithmetic statement

For `N=KM`, with dyadic `N,K,M`, `K>=2M`, `R` independent global-chirp rows, and `g>sqrt(2)`, the streaming estimator uses

```text
Time:   O(R [N + (N/M) log(N/M)])
Memory: O(N)
```

and satisfies

```text
Pr[ ||X_hat - U_N x||_inf > 5 g sqrt(M/N) ||x||_2 ]
    <= 2 N exp(-R D(1/2 || 1/g^2)).
```

See `RESEARCH.md` for the assumptions, proof, fixed-row and growing-row corollaries, and the finite-precision boundary.
