# Power-of-two Boolean Fourier orbit recovery — exact research audit

A reproducible mathematical exploration of whether cyclotomic/Galois sharing can reduce the **fully charged** cost of a fresh full binary-input FFT.

## Status

- **No new O(N) FFT.** No runtime FFT speedup claimed.
- The minimum number of ordinary Fourier scalar values needed to uniquely identify *every* N-bit input is exactly `log2(N)+1`, if the scalar values are available exactly with unlimited precision. This is a uniqueness statement; producing all N numerical outputs still has a cost.
- Generating a different primitive conjugate from only **one** exact primitive bin using a polynomial needs exponential algebraic degree. The analogous rational function also has exponential numerator/denominator degree. A one-scalar rational arithmetic program needs `Omega(N)` gates.
- For N=8, degrees are **exactly 11 (polynomial)** and **8 (rational)** for X[3] recovered from X[1] on the 16 binary inputs whose last four bits are zero.

Read `RESEARCH.md` for fully scoped proofs, conditions and caveats. Read `NEXT_GATE.md` before new experiments to prevent repeating the same scalar descriptor idea.

## Reproduce (Python 3 standard library)

```bash
python -m unittest discover -s tests -v
python run_audit.py
python independent_modular_certificate.py
```

Files:
- `orbit_recovery.py`: conductor partitions, exact cyclotomic Fourier coefficient vectors, and binary collision witnesses;
- `cyclotomic_interpolation.py`: exact Q(zeta_N) field arithmetic, polynomial and rational interpolators, and rank checks;
- `independent_modular_certificate.py`: separate finite-field determinant specializations establishing characteristic-zero nonexistence;
- `tests/`: regression cases including exhaustive N=8 input uniqueness;
- `audit_results.json` / `modular_certificate.json`: deterministic machine-readable evidence;
- `RESEARCH.md`: mathematical scope and proofs;
- `NEXT_GATE.md`: next problem and anti-duplication guard.

Use standard FFT implementations if you need an actual working fast Fourier transform: this is a mathematical certificate and falsification project, not an FFT replacement.
