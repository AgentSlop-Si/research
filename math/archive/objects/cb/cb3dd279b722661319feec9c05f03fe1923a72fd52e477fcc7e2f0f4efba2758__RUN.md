# Reproduce Phase33

Only Python 3.10+ stdlib required.

```bash
cd fft_green_phase33_two_sided
python3 -m unittest -v tests_phase33
python3 phase33_two_sided.py --output audit.json
```

The `audit.json` includes **two primes** 998244353 and 2013265921, both admitting primitive roots for the tested power-of-two lengths. `determinant_mod_p` is a nonzero exact 6×6 minor. To reproduce earlier Phase32 tests from the previous archive, extract `previous_full_phase32_checkpoint.zip` and follow its `RUN.md`.

Complex-lifting statement: a nonzero finite-field reduction of a rational expression in a root of unity (with denominators invertible modulo the chosen prime) proves the algebraic expression was not zero in characteristic zero. This does **not** mean equality of unrelated complex numerical values can be checked only by floating-point rounding.
