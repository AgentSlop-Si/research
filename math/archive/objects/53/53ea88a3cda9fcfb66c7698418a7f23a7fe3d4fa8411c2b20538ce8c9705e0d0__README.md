# FFT research checkpoint — October 10, 2026

**Topic:** All-length square-root depth barrier for bit-reversed quasiseparable global scans.

## Main result

For length `N=2^k`, with arbitrary quasiseparable matrices of orders `r_i` and interstage shuffles that preserve or swap the central-bit groups:

`sum(r_i) >= ceil(N/(2*d_N))`, where `d_N = 2^((k+1)/2)-1` for odd `k` and `d_N = 2^(k/2)` for even `k`.

In particular, **four rank-one stages with three repeated bit reversals cannot equal the Fourier transform for any power-of-two `N>=128`.** This applies to arbitrary complex coefficients, zero generators, and singular stages. It is **not** a general FFT arithmetic-circuit lower bound.

## Status

This work establishes an exact **no-go result for one global-scan architecture**, not an `O(N)` FFT or an improved integer-multiplication algorithm. The next target requires shuffles that genuinely mix the central-bit partition, plus exact nonlinear compatibility tests and fully charged arithmetic.
