# Global linearization gate — fresh exact FFT research

**Result:** Every division-free arithmetic DAG computing the entire exact *linear* DFT on arbitrary inputs can be converted into a linear DAG with at most 3 times its arithmetic-gate count, while charging one O(s) pass to prepare constant terms. Division/rational circuits regular at a fixed basepoint admit the analogous differential construction. This is established algebra, not a new FFT.

This package is a **research falsifier**, not an optimized Fourier engine. The recorded alternatives use nonlinear square cancellations, generic rational cancellations, and an input-dependent `A-k` split. They work algebraically but do not lower the full FFT cost.

## Run

```bash
python -m unittest discover -s tests -v
python run_audit.py
python verify_matrix.py
python symbolic_complex_audit.py   # requires sympy
```

- `jet_linearize.py`: exact finite-field arithmetic DAG, first-order extraction to a linear DAG, and independent dual-number interpreter.
- `run_audit.py`: 24 size/method variants, 960 fresh exact checks, gate counts in `audit_results.json`.
- `verify_matrix.py`: independent full-matrix certificate, 504 basis columns / 21,840 entries in `matrix_certificate.json`.
- `symbolic_complex_audit.py`: exact symbolic complex F4 identity and Jacobian, separate `symbolic_complex_certificate.json`.
- `tests/`: linearization, rational singularities, nonlinear k, binary and Frobenius model caveats.
- `RESEARCH.md`: proof, model distinctions, prior work and next problem.

The modular experiments use p=998244353 and p-th roots; they verify finite instances only. The theorem is an algebraic derivation over any field where the stated circuit represents a genuine polynomial/rational identity. Rational gadgets are undefined on their denominator-zero hypersurfaces unless a fallback is specified. The square and k-rewrite gadgets are total.

**No new general O(N) FFT or CrocSwap bound.**
