# Dual/onion independent audit

Read `INDEPENDENT_DUAL_AUDIT.md` for the result, proof, chart restrictions and next gate.

Reproduce with Python 3.10+ (standard library only):

```sh
python independent_dual_checks.py
```

The default source is the original dual/onion ZIP under `../../source_archives/`. You may instead supply `--source-root` naming that ZIP or the extracted package, and `--output-dir` for generated artifacts. Submitted programs are never imported or executed.

Main artifacts:

- `independent_dual_results.json`: exact export comparison, modular reconstruction and exception checks.
- `explicit_dual_saturation.json`: polynomial factors and matrix for the correctly localized twenty-equation chart.
- `primitive_twenty_equations.json`: equivalent list after removing required-nonzero t/h0 monomial factors.
- `onion_eight_variable_exact_circuit.json`: exact twelve-equation rational target, physical matrices and 29 nonzero requirements.
- `characteristic_zero_exception_certificate.json`: an exact regular partial candidate with S1=0, certified nonzero by good reduction.
- `prior_comparison_provenance.json`: hashes and facts used from the preceding independently audited checkpoint.

No valid full F8 factorization, exhaustive exclusion or new FFT algorithm is claimed.
