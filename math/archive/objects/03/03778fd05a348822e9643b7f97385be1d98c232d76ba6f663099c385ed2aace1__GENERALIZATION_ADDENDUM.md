# Root proposal addendum, 2026-10-10 04:47 UTC

The independent audit is still the authoritative acceptance gate. This preserves author-side developments sent during that audit, without overwriting its frozen original proposal.

1. Zero columns can be placed in any rank-one direction class with scalar coefficient zero; an identically zero branch uses a dummy class. Hence k rows need at most k rank-at-most-one classes, not k+1. The improved necessary bound is N <= r(r+1)^r.

2. The same lemma extends to every invertible denominator Q with at most two nonzero entries per column. Represent a two-support column by an edge on its two row variables, and a singleton column by a loop. Column independence implies each connected component has edges <= vertices. Since globally there are N edges and N vertices, every component has equal numbers, hence is unicyclic. Delete the k constraint columns corresponding to selected inverse rows. The remaining graph is a union of trees and surviving unicyclic components; V-E=k is exactly the number of tree components. Independence of retained columns implies each tree has left-kernel dimension one, each surviving unicyclic component dimension zero. Thus the selected inverse rows have columns in at most k lines.

The auditor corrected a wording detail: a surviving unicyclic component can have lost an attached tree through bridge deletion; it need not be untouched. That correction is included here.

3. For k=r+1 consecutive Fourier rows, the common refinement of the r rank-one partitions has at most k^r cells. Every cell of k columns would have sum rank <=r, contrary to its Fourier Vandermonde rank k. Therefore every cell has <=r columns and N<=r k^r. This holds for any target with a k-row full-spark restriction, not only Fourier; it also excludes matching only those prescribed k Fourier rows when the inequality fails.

4. With an additional correction matrix having at most delta nonzeros in each selected row, discard at most delta*k affected columns. The necessary bound becomes N <= delta(r+1)+r(r+1)^r. A free diagonal has delta=1. No unrestricted non-diagonal endpoint mixing or arbitrary matrix product is covered.

5. The asymptotic consequence is a necessary r=Omega(log N/log log N) branch count. It supplies no construction attaining that count, and no lower bound for arbitrary shared arithmetic evaluation. The O(N) inverse solves and permutation/diagonal endpoint operations are a particular representation model, not all linear-time algorithms.

6. Primary antecedent leads found by the separate priority review: classical inverse-bidiagonal semiseparability (Higham/Vandebril); gain-graph contraction in Zaslavsky, Biased Graphs IV (2003), §2.1; generalized networks/binet matrices (Appa–Kotnyek2003); graph-induced rank structure closure (Chandrasekaran–Epperly–Govindarajan2021); full-spark Vandermonde frames (Alexeev–Cahill–Mixon2012). The column-direction lemma should be credited as a classical structural specialization. Combined Fourier branch-count application novelty remains unresolved.
