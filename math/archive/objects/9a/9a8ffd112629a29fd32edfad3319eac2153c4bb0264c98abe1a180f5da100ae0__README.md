# Hero #1 FFT research — Phase 22 (trace-cyclotomic root gate)

**Research checkpoint | 2026-10-10 | exact finite-field arithmetic.**

Main result: Phase 21's palindromic Hankel resultant `U(w)=w^b V(w+w^-1)` admits an exact no-false-rejection group-root sieve based on `gcd(V_*, D_N-2)`, where `D_N` is a Dickson/Chebyshev polynomial and `V_*` omits the identity trace `t=2`. This reduces the global root-existence calculation to a polynomial quotient of dimension at most b and `O(b^2 log N)` field operations, rather than evaluating U at every Fourier root. When the gcd has degree one, reconstruct its two Fourier roots by a quadratic and a charged baby-step/giant-step index calculation. A higher-degree gcd is handled by a complete half-subgroup trace scan.

Everything remains exact and independently certified. The inherited inverse-resultant/Prony stages and full cyclic certificate are retained, together with a correct fallback for arbitrary data. No general exact `o(NlogN)` FFT has been proved. The generic input still uses ordinary exact Bluestein and incurs positive failed-discovery overhead.

## Main files

- `THEOREM.md`: algebra, proofs, precise hypotheses and cost complexity.
- `trace_subgroup.py`: self-contained implementation of Dickson reduction, polynomial gcd, square root, baby-step/giant-step and half-subgroup trace enumeration.
- `compressed_resultant.py`: integrates the trace sieve and root extraction with the existing fully certified Phase 21 Green forcing algorithm.
- `test_trace_subgroup_phase22.py`: independent subgroup oracles, exhaustive GF(17) small case, malicious input regressions, cross-field exact DFT.
- `PHASE22_BENCHMARK.json`: charged arithmetic comparisons; two unknown factors/two defects and generic random data.
- `PHASE22_AUDIT.json`: direct DFT oracle, two prime fields.
- `COST_LEDGER.md`, `RUN.md`, `NEXT_GATE.md`, `PRIOR_ART.md`: required handoff.
- `PRIOR_PHASE21_COMPLETE.zip`: byte-preserved original Phase 21 package and earlier archived lineage.

## Bottom line

The trace root filter closes an avoidable arithmetic bottleneck in exact structured-input discovery, with a mathematically proved nonexistence test. At N=32768 and s=4, Phase 22 uses 2,962,215 counted field operations versus 3,213,392 for Phase 21 on the same certified structured input (7.82% reduction), and versus 5,440,325 for the full-FFT forcing baseline (45.55% reduction). These are counted field operations and **not** wall-clock/bit-time claims.
