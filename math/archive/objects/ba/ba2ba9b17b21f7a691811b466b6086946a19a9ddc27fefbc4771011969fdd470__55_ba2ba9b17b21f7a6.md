## The graph-theory connection

Let q have exact order N=2^L and let

    H_q(z)=sum_(j<N) z^j / product_(a=1..j)(1-q^a).

A complete b-phase orbit has the finite identity

    product_(a<b) H_q(q^(aN/b) z)=H_(q^b)(z^b) modulo z^N.

It replaces b sequential length-N triangular convolution operators by b shorter residue-chain operators. To handle mismatched phases, count actual phases c_e and reference phases h_e on a cycle. Solve the integer flow equation

    c_e-h_e=f_(e-1)-f_e.

Moving one unit along edge e multiplies the operator by 1-q^e z. Moving backward applies its inverse, which is an exact first-order prefix recurrence. All possible flows differ by a constant circulation. Choosing a median minimizes D=sum |f_e| in deterministic O(N+b) word work.

With C(m) denoting one prepared length-m kernel application, the resulting evaluation costs

    b C(N/b)+O(N(1+D)+b),

with scalar preparation, coefficient powers, addressing, gathers, scatters and every output accounted for. When b=N and D=O(1), this graph has an O(N) evaluator for arbitrary input. This is a concrete instance of using a nearby reusable graph and retaining its correction exactly.

For example, start with all N phase operators and replace phase 0 by another phase 1. Their composition is exactly multiplication by 1-z: y[0]=x[0], y[j]=x[j]-x[j-1]. The size-4096 implementation used 12,297 field operations including its deliberately unoptimized root/coefficient preparation, plus O(N) compilation and logical data movement. This is an operation count, not a timing benchmark or an FFT speedup. It simplifies an existing matching operator word; adding an expensive identity word to an FFT and canceling it would not constitute a new FFT improvement.

## Linear spectrum preparation

The exact polynomial boundary term gives

    H_q(qz)=(1-z)H_q(z)+z^N/N.

Given a primitive 2N-th root eta with q=eta^2, v[k]=H_q(eta^k) satisfies

    v[k+2]=(1-eta^k)v[k]+(-1)^k/N.

Even and odd indices form two affine cycles. One cycle has a zero multiplier and the other's total multiplier is 2, so all bins can be initialized and generated in O(N) work. At N=4096 this changes cold kernel setup from 176,139 to 40,970 counted field operations against the included ordinary radix-two setup. The subsequent online convolution remains 335,872 operations in both versions.

The complete q-Pascal implementation still uses four length-2N FFTs and remains more expensive than direct radix two. The setup improvement therefore does not establish the main goal.

## Why general inputs are still unresolved

For arbitrary P, the same q-difference identity has a forcing polynomial:

    P(qz)-(1-z)P(z)=z Q(z).

Its coefficient map is upper triangular with diagonal 1, hence invertible in O(N). Thus Q is arbitrary when P is arbitrary: computing all its Fourier values is the original evaluation problem after a cheap invertible encoding. Sparse forcing yields the restricted O(N(s+1)) algorithm, but does not make every input sparse.

The known Fourier factorization also contains a reversal and a nonconstant diagonal between its two q-kernel actions. Those operations violate the orbit compiler's accepted pattern. The included exact negative control demonstrates wrong outputs if that middle is replaced by an alternating-sign operator merely to enable a rewrite.

## Next exact construction target

Find a legal factorization of the actual Fourier operator that exposes sufficiently large complete or near-complete phase orbits, with small total correction distance D and inexpensive intervening operators. Derive the input-to-all-outputs cost before building another prototype. The total must improve on a direct FFT, including any work used to create the orbit structure; cancellation of artificially added redundant work is insufficient.

Alternatively, supply a genuinely faster evaluator for a single q-kernel action. The norm identity alone retains a same-size inverse kernel, and the derived fractional-power multiscale route has dense factors with quadratic direct cost. These are identified remaining steps, not completed speedups.
