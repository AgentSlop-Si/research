# Divisor-spectrum adaptive randomized Fourier transform — v13

**Date:** 10 October 2026  
**Status:** proved project-internal randomized approximation theorems, standalone executable implementation, exhaustive finite covariance checks, and an adaptive three-route planner. **This is not an exact FFT, not a machine-precision replacement for FFTW, and not a claimed literature-first result.**

## 1. Target and inherited machinery

The long-term target remains the exact, full-output DFT of an arbitrary fresh input using less than \(N\log N\) fully charged sequential work. v13 does **not** attain that target.

It inherits three previously checked approximation mechanisms:

1. **Direct composite unit-step chirp.** For
   \[
   N=KM,\qquad K\ge M,
   \]
   a randomized block projector can be evaluated exactly for its projected signal using one length-\(K\) FFT, one length-\(N\) gauged prefix scan, linear setup, and all \(N\) output writes:
   \[
   W(N,M)=O\!\left(N+\frac NM\log\frac NM\right).
   \]
   Its expectation is the exact unitary DFT of the original input.

2. **Prime-power offset classes.** An arbitrary length can be lifted to a nearby prime power and separated into exact residual-frequency classes. This is especially effective when the class count is small.

3. **Bessel/Chebyshev all-length lift.** This remains the fallback for prime or rough lengths. It has deterministic truncation error and rank-dependent work.

The new v13 contribution is a substantially sharper covariance certificate for the first route, a family theorem based on the divisor spectrum of \(N\), and an accuracy-aware planner that compares all three routes with setup and output work charged.

## 2. Direct composite estimator

Let \(\zeta=e^{2\pi i/N}\), \(h=N\bmod2\), and \(\eta=e^{\pi i/N}\). Write the input as \(x[bM+t]\), where \(0\le b<K\), \(0\le t<M\).

Choose \(a\) uniformly from the units of \(\mathbb Z/N\mathbb Z\) and \(\beta\) uniformly from \(\mathbb Z/N\mathbb Z\). Define

\[
S[b,t]
 =\zeta^{a\binom t2+(aMb+\beta)t}\eta^{ht},
\]

\[
d[b]=\sum_{t=0}^{M-1}S[b,t]x[bM+t],
\qquad
 y[bM+t]=\overline{S[b,t]}d[b].
\]

The returned row is

\[
Y=U_Ny.
\]

Averaging over \(\beta\) kills every off-diagonal within-block displacement, so

\[
\boxed{\mathbb E Y=U_Nx.}
\]

A single row is not the exact DFT; it is an unbiased random estimator.

The saved executor does not materialize \(y\) or compute an \(N\)-point FFT. The binomial phase gives a one-cycle recurrence in output frequency. Its gauge converts the recurrence into one prefix scan, while the forcing is supplied by one \(K\)-point FFT of the block summaries. The charged arithmetic is

\[
\boxed{
W(N,M)=O\!\left(N+K\log K\right),\quad K=N/M.
}
\]

Trial factorization and divisor discovery use \(O(\sqrt N)\) integer divisions in the standalone planner, which is dominated by \(O(N)\) in every linear-time regime claimed below.

## 3. New Ramanujan divisor-sum covariance certificate

Fix one output frequency. For every nonzero local displacement

\[
d\in\{-(M-1),\ldots,-1,1,\ldots,M-1\},
\]

let \(D_d\) be the diagonal zero-one mask selecting source coordinates for which displacement \(d\) remains in the same block. Let

\[
B_d=\mathbb E_{a\in(\mathbb Z/N\mathbb Z)^*}v_{ad}v_{ad}^*,
\]

where \(v_f[n]=\zeta^{fn}\). Averaging over \(\beta\) separates unequal displacements. Because \(K\ge M\), no two allowed displacement differences wrap modulo \(N\), and the one-output covariance, up to a harmless diagonal Fourier modulation, is

\[
Q=\frac1N\sum_{d\ne0}D_dB_dD_d.
\]

Put

\[
g_d=\gcd(N,d).
\]

Multiplication by \(d\) maps the units modulo \(N\) uniformly onto the \(\varphi(N/g_d)\) Fourier frequencies with gcd class \(g_d\). These characters are orthogonal and each has squared norm \(N\). Hence

\[
\|B_d\|_{2\to2}=\frac{N}{\varphi(N/g_d)}.
\]

Every covariance summand is positive semidefinite, so the triangle inequality yields

\[
\boxed{
\|Q\|_{2\to2}
\le
V(N,M)
:=2\sum_{d=1}^{M-1}
\frac1{\varphi\!\left(N/\gcd(N,d)\right)}.
}
\tag{3.1}
\]

Therefore, for every arbitrary fixed input \(x\) and every output \(k\),

\[
\boxed{
\mathbb E|Y[k]-(U_Nx)[k]|^2
\le V(N,M)\|x\|_2^2.
}
\tag{3.2}
\]

This certificate is exact rational arithmetic once \(N,M\) are specified. It is an upper bound on the operator norm, not generally the exact covariance eigenvalue.

### Relation to the previous coarse bound

The elementary inequality

\[
\varphi(N/g)\ge\frac{\varphi(N)}g
\]

and \(\gcd(N,d)\le d\) give

\[
V(N,M)
\le
\frac2{\varphi(N)}\sum_{d=1}^{M-1}d
=
\frac{M(M-1)}{\varphi(N)}.
\]

Thus (3.1) never weakens the inherited certificate and can be dramatically smaller.

In the saved exact covariance cases, the ratio

\[
V(N,M)\Big/\frac{M(M-1)}{\varphi(N)}
\]

fell as low as \(0.2857\). The actual covariance norm was at most one half of the new bound in those cases; that observed extra factor is **not** promoted to a theorem.

## 4. Least-prime-factor theorem

Let \(p=p_{\min}(N)\) be the least prime factor of a composite \(N\), and choose

\[
M=p,\qquad K=N/p.
\]

Because \(p\le\sqrt N\), the executor condition \(K\ge M\) holds. For every \(1\le d<p\), no prime divisor of \(N\) divides \(d\), so

\[
\gcd(N,d)=1.
\]

The divisor-sum certificate collapses to

\[
\boxed{
V(N,p)=\frac{2(p-1)}{\varphi(N)}.
}
\tag{4.1}
\]

The row work is

\[
\boxed{
W(N,p)=O\!\left(
N+\frac Np\log\frac Np
\right).
}
\tag{4.2}
\]

Consequences:

- If \(p(N)\to\infty\), then \(W=o(N\log N)\).
- If \(p(N)=\Omega(\log N)\), then \(W=O(N)\).
- If \(p=N^{\gamma+o(1)}\) for fixed \(0<\gamma\le1/2\), then \(W=O(N)\).

Using \(\varphi(N)=N^{1-o(1)}\), equation (4.1) becomes

\[
V(N,p)=N^{\gamma-1+o(1)}.
\]

### Balanced semiprimes

For

\[
N=pq,\qquad p\le q,
\]

with \(p\) the least prime factor,

\[
\boxed{
V(N,p)=\frac2{q-1}.
}
\tag{4.3}
\]

When \(p\asymp q\asymp\sqrt N\), one row costs \(O(N)\) and has per-output variance factor \(N^{-1/2+o(1)}\). The older coarse certificate was order one here and could not prove polynomially shrinking error. This is the main new family unlocked by v13.

## 5. Constant-row all-output theorem

Take

\[
R=2r-1
\]

independent rows and use coordinatewise medians of real and imaginary parts. Suppose

\[
V_N=N^{-\beta+o(1)}.
\]

For target complex error

\[
\sqrt2\,N^{-\alpha}\|x\|_2,
\]

Chebyshev gives a one-component bad-row probability at most

\[
V_NN^{2\alpha}.
\]

The event that a coordinatewise median is bad requires at least \(r\) bad rows. A union bound over real/imaginary parts and all outputs gives

\[
\Pr\!\left[
\|\widetilde X-U_Nx\|_\infty
>\sqrt2N^{-\alpha}\|x\|_2
\right]
\le
2N\,2^R\left(V_NN^{2\alpha}\right)^r.
\tag{5.1}
\]

Consequently, if

\[
\boxed{r(\beta-2\alpha)>1,}
\]

then the failure probability tends to zero.

For the least-prime-factor family \(p=N^{\gamma+o(1)}\), we have \(\beta=1-\gamma\). Therefore every

\[
\boxed{
\alpha<\frac{1-\gamma}{2}
}
\]

is attainable with a sufficiently large **constant** odd number of rows.

For balanced semiprimes, \(\gamma=1/2\), so every fixed

\[
\boxed{\alpha<1/4}
\]

is attainable in \(O(N)\) arithmetic and \(O(N)\) storage, with all \(N\) approximate outputs explicitly written.

Again, this is additive energy-relative approximation, not coefficientwise relative error and not exact coefficient recovery.

## 6. Divisor-spectrum planner

The new planner factors \(N\) by charged trial division, enumerates every divisor

\[
2\le M\le\sqrt N,
\]

and computes for each direct candidate:

- the row-work proxy \(N+(N/M)\log(N/M)\);
- the exact rational bound \(V(N,M)\);
- a requested median/union failure certificate.

It then compares these candidates against:

- prime-power offset-class lifts for \(p\in\{2,3,5,7\}\);
- the all-length Bessel/Chebyshev fallback.

The comparison is accuracy-aware: deterministic Bessel bias, stochastic variance, row count, output count, and setup work are represented separately. When no finite-size candidate meets the requested conservative union bound, the planner returns the best available bound rather than claiming certification.

This matters because different arithmetic shapes favor different routes:

- balanced or rough composites can favor the new direct route;
- fixed-cofactor prime-power families can favor offset classes;
- prime lengths retain the Bessel fallback.

The planner is a research dispatcher, not an optimized production FFT planner.

## 8. Wall-clock benchmark boundary

The Python/NumPy prototype is not a practical FFT replacement.

Saved one-row ratios versus NumPy's optimized full FFT ranged from approximately

\[
1.89\times
\quad\text{to}\quad
15.6\times
\]

slower on the tested lengths. At \(N=10403=101\cdot103\), the direct row was about \(2.53\times\) slower than NumPy FFT; at \(N=47053=211\cdot223\), about \(1.89\times\) slower.

These are unmatched-accuracy Python prototype timings, not evidence about the asymptotic theorem and not a native-code performance claim.

## 9. Prior-art boundary

The ingredients include classical FFTs, random phase projections, Ramanujan sums, coordinate medians, and nearby-grid/NUFFT corrections. The project-specific contribution claimed here is only the derived divisor-spectrum covariance certificate and its integration with the existing unit-step-chirp executor and adaptive planner.

A limited literature search did not establish that this compound result is new. No priority claim is made. Sparse Fourier and compressed-sensing methods generally change the output or signal model; NUFFT methods address off-grid evaluation using interpolation/low-rank corrections. Those are important adjacent areas, but they do not by themselves certify this exact randomized full-output construction.

## 10. Honest status and next gate

v13 materially broadens the approximate sub-\(N\log N\) and linear-time families:

\[
\boxed{
\text{balanced semiprimes and many growing-least-factor composites now have}
\ O(N)\text{ rows with polynomially shrinking all-output error.}
}
\]

It does **not** establish:

- an exact sub-\(N\log N\) FFT;
- an \(O(N)\) theorem for prime lengths;
- coefficientwise relative error;
- fixed-binary64 asymptotic stability;
- practical superiority to FFTW, MKL, cuFFT, or NumPy;
- a literature-wide novelty claim.

The remaining finish-line obstruction is now concentrated on prime/rough lengths with no useful divisor:

> Construct a rigorously low-variance \(O(N)\) forcing evaluator without requiring \(M\mid N\), or a pre-materialization joint evaluator that compresses the Bessel correction before its rank-\(R\) channels become independent.

That is the correct next research gate. Another cache, gauge rename, or black-box fusion of already materialized channels cannot close it.
