# FFT Weyl-line / Bluestein checkpoint v21

This package continues the exact arbitrary-input FFT research after v20.

## Main result

All nonzero shift-step Weyl–Green character packets are generically complete for off-diagonal matrices. A diagonally gauged Fourier matrix has an exact representation using `N-1` Green resolvents, but those resolvents lie on one common Weyl line and fuse to a full quadratic-chirp polynomial—Bluestein convolution in disguise.

**No exact faster FFT is claimed.**

## Reproduce

```bash
python run_all.py
sha256sum -c MANIFEST.sha256
```

The test suite uses exact finite-field arithmetic. `PRIOR_v20_COMPLETE.zip` preserves the immediate predecessor.
