# Portable v10 lift audit

Read `AUDIT_REPORT.md` first. `independent_results.json` and `independent_run.log` are the independently reproduced controls.

Run from any working directory with Python, NumPy and mpmath available:

```sh
python -I /path/to/independent_lift_audit.py --output /path/to/new_results.json
```

The checker does not read, import or execute the uploaded source or bytecode. Its small dense matrices are verification tools, not a claimed fast implementation. Its Bessel coefficients are independently reconstructed from the defining series with 90-digit arithmetic. The numerical checks supplement the report's proof audit.

`SOURCE_EVIDENCE.json` preserves source hashes, manifest results, and static source locations. These are provenance and source-reading records, not execution results.

No master archive was modified and nothing was uploaded by this audit.
