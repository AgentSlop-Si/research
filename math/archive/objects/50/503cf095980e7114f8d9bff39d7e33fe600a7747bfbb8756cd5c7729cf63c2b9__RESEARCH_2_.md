# Hero #17: Phase-Union Graph / Exact Bounded-Chirp-Rank Fourier Transform

**Checkpoint:** 2026-10-09. **Status:** proved scoped algebraic theorem, executable proof-of-concept, independent finite-field checks. **Not a faster exact FFT for arbitrary fresh dense inputs.** No novelty priority or measured wall-clock advantage over tuned FFT libraries is claimed.

## 1. Goal and provenance

The actual unsolved goal is a full, exact, all-output DFT of any fresh length-`N` input using `O(N)` fully charged sequential arithmetic, without input promises, arbitrary preprocessing, parallelism, or an implicit output. The recovered project already had low-ordinary-Hankel-rank (Prony) Green executors, quadratic-chirp transforms for supplied parameters, restricted lower-bound certificates on Green networks, approximate all-length transforms, and many failed general collision/lookup approaches. This module **does not** restart those: it certifies and autodetects an enlarged **quadratically dephased** low-rank family directly from raw input, then returns the exact entire spectrum.

The new source is an independently runnable Python finite-field prototype with no NumPy/SciPy runtime dependence.

## 2. The proved, deliberately restricted theorem

Let `N >= 3r`, `r >= 1`, with `r` a fixed constant independent of `N`. Let `p` be a prime with `N | (p-1)` and let `omega` be a supplied primitive `N`th root of unity in `F_p`. Assume exact unit-cost field arithmetic (or a word-RAM with `p=N^{O(1)}`, unit-cost multiplication/modular reduction on bounded-size words, and a root supplied with certification); setup and output writes are charged.

For an arbitrary **raw** `x` in `F_p^N`, `recognize(x,p,omega,r)` costs worst-case `O_r(N)` field operations and:

* **Success:** supplies and exhaustively verifies a representation

  `x[j] = omega^(a*j^2) * sum_{ell=1}^s c_ell * omega^(b_ell*j)`,

  with `s <= r`, distinct residue frequencies `b_ell`, nonzero coefficients, and **any** quadratic parameter `a` modulo `N`, including nonunits and zero; the complete exact DFT `X[k]=sum_j x[j]omega^(-kj)` is constructed in a further `O_r(N)` operations.
* **Failure:** certifies only that no such bounded-rank representation exists; it does **not** compute the DFT. An ordinary FFT/NTT must handle unrestricted arbitrary inputs.

`O_r(N)` is linear in `N` only with `r` fixed. A conservative explicit upper bound is

`O(N*r*binom(r+2,3) + (r+1)!*r^2 + binom(r+2,3)*r^3 + N)`

field operations plus `O_r(log N)` word operations for modular inversions and gcd when needed, and `O(N)` output/memory. The hidden constant is expensive and factorial in `r`; performance for growing `r` is not claimed. The Python code uses arbitrary-precision integers to **validate** identities, rather than measuring a fixed-word deployment.

The mathematical identity extends to exact complex arithmetic with a primitive root and exact equality tests, but the prototype and numerical stress-free guarantee are for exact prime fields. Standard complex floating-point stability, equality recognition, and integer-multiplication bit complexity are **not** proved.

## 3. Graph/Union/Sparse/Quantum mapping

The **graph** is a directed dependency network `raw input -> polynomial phase eliminant -> O_r(1) candidate chirp gauges -> bounded-rank Hankel recurrence -> root-frequency union -> one quadratic Gauss row -> N output coefficients`.

The **union** identifies equivalent quadratic phases. For even `N`, the parameterizations `(a,b)` and `(a+N/2,b+N/2)` produce identical individual columns because `j^2 = j (mod 2)`. We retain only canonical `a=0,...,N/2-1`; for odd `N` all `a` classes are distinct. This is precise group-symmetry quotienting, not cache coincidence or parallel threads.

The **sparse table** is the charged length-`N` list `[omega^0, ..., omega^(N-1)]`. It permits constant-time character/phase evaluation. There are only `s<=r` active spectral modes after removing the common quadratic phase; the table never stores an exponential number of input states.

The **quantum-inspired** component is the quadratic-phase / Gauss-sum structure, related to discrete Weyl/Clifford stabilizer chirps. The algorithm is fully classical; quantum Fourier gates or phase-state readout do **not** produce an arbitrary classical full spectrum for free.

## 4. One-window phase elimination

For a nonzero input entry `x[s+r]`, build an `(r+1)x(r+1)` polynomial matrix

`H_s(t)[i,j] = x[s+i+j] * t^binom(i+j,2)`, `0<=i,j<=r`.

Define `E_min = (r+1)*r*(r-1)/2`, and

`P_s(t) = t^(-E_min) det(H_s(t))` (a polynomial: all monomials contain `t^E_min`).

For a true quadratic phase `a`, `t=omega^(-2a)`: the matrix differs by invertible row/column diagonal scalings from the ordinary Hankel matrix of the dechirped data `y_j=x_j*omega^(-a*j^2)`. A sum of at most `r` characters has Hankel rank at most `r`, so `P_s(t)=0`.

The determinant expansion contains terms indexed by permutations `sigma` of `{0,...,r}`, with exponent `sum_i binom(i+sigma(i),2)`. Rearrangement says **unique** minimum exponent comes from reversal, unique maximum from identity, and their difference is

`D_r=binom(r+2,3)`.

The constant term is exactly

`P_s(0)=(-1)^(r(r+1)/2) * x[s+r]^(r+1)`.

Therefore `P_s` is not the zero polynomial when the center entry is nonzero; it has at most `D_r` field roots. No generic polynomial-factorization algorithm is needed.

For any nonzero ≤`r`-character signal, **no `r` consecutive entries vanish**: `r` consecutive samples give a full-column-rank Vandermonde system on the distinct character nodes. The common quadratic chirp never creates or removes zeros. Since `N>=3r`, the interior range of indices `[r,N-r-1]` contains at least `r` positions and thus has a nonzero entry. We find such an entry with one scan and construct the nonzero `P_s` in `O((r+1)!r^2)` arithmetic.

The map `a -> omega^(-2a)` has fibers of size `gcd(2,N)`. For **even** `N`, `omega^((N/2)j^2) = omega^((N/2)j)`, so any signal represented with `a+N/2` is also represented using `a` after shifting every frequency by `N/2`; it suffices to scan `a=0,...,N/2-1`. For odd `N`, scan all `a`. On this canonical range the map is injective, leaving **at most `D_r` possible phases**. All are found with `O(N D_r)` work by Horner evaluation at the precomputed phase table entries.

The concrete `r=2` eliminant (after dividing the determinant by `t^3`) is

`x_s*x_(s+2)*x_(s+4)*t^4 - (x_s*x_(s+3)^2+x_(s+1)^2*x_(s+4))*t^3 + 2*x_(s+1)*x_(s+2)*x_(s+3)*t - x_(s+2)^3`.

The constant term `-x_(s+2)^3` is the nonzero-witness certificate; `D_2=4`.

## 5. Completion of the raw-input certificate

For each of at most `D_r` candidate phases, dechirp all `N` entries. A bounded Berlekamp--Massey pass detects a linear recurrence of order at most `r`; abort immediately if the order would exceed `r`. This is worst-case `O(Nr)` even on rejected candidates. BM changes its baseline at most `r` times before aborting; thus we cache an inverse and need at most `r` field inversions, not `N` hidden modular inversions.

For an order-`s` recurrence, scan the `N` precomputed roots of unity and retain those annihilated by its characteristic polynomial. Require **exactly `s` distinct admissible nodes**, solve the `s x s` Vandermonde system for their amplitudes, and check **all `N` input values**. The verification makes acceptance sound independent of random tests and even if short-sequence recurrence ambiguities arise. For a genuine ≤`r`-character family with `N>=3r`, the Vandermonde ranks make the process complete.

## 6. Exact full-output Gauss evaluator, *every* integer length

For one mode, write `c=b-k`, `d=gcd(a,N)` (using `gcd(0,N)=N`), `m=N/d`, `a'=a/d`, and `eta=omega^d` of order `m`. Split `j=t+qm` in `S_a(c)=sum_{j=0}^{N-1}omega^(a j^2+c j)`:

`S_a(c)=0` if `d` does not divide `c`; otherwise

`S_a(c)=d * T_(a',m)(c/d)`, where `T_(a',m)(v)=sum_{t=0}^{m-1}eta^(a't^2+vt)`.

For `m=1` this gives the usual `N`-spike response. Otherwise `a'` is invertible modulo `m`.

**Odd `m`:** compute `G=T(0)` in one length-`m` pass, and apply completion of squares:

`T(v)=G * eta^(-v^2 * (4a')^(-1) mod m)`.

**Even `m=2q`:** translation by `q` proves `T(v)=0` unless `v==q (mod 2)`. Choose `v0=q mod 2`. Compute just one base Gauss sum `G=T(v0)` in one length-`m` pass. For permitted `v`, choose

`t = ((v-v0)/2) * (a')^(-1) mod q`,

with `t=0` when `q=1`. Then `v=v0+2a't mod m` and

`T(v)=G * eta^(-a't^2-v0*t)`.

The right-hand side is independent of the lift of `t` modulo `2q`; parity gives that independence. Hence **all even/odd lengths and every nonunit phase** reduce to one charged Gauss sum and `O(1)` phase work per active mode/output pair. Summing at most `r` modes produces all `N` outputs in `O(rN + N)` arithmetic. No FFT call is hidden in this evaluator.

## 7. Why this is beyond the previous ordinary Prony fast path

For `gcd(2a,N)=1`, even the pure quadratic chirp `x_j=c*omega^(aj^2+bj)` has an `m x m` ordinary Hankel matrix (`m<=N/2`) of **full rank**:

`H[u,v]= c*omega^(a u^2+b u) * (omega^(2a u))^v * omega^(a v^2+b v)`.

The middle factor is Vandermonde with distinct nodes `omega^(2a u)`. Thus ordinary rank grows linearly with `N` although removing *one discovered quadratic phase* makes rank one. Exact modular rank audits for `N=7,17,31,63,119,127` reproduced ranks `3,8,15,31,59,63`. This does **not** imply random arbitrary inputs are compressible.

## 8. Why this is *not* the universal goal

Fix `r<N`. Each chosen phase/frequency support `(a, {b_1,...,b_r})` defines a linear subspace of dimension at most `r`. There are finitely many phase/support choices. Their union is a proper measure-zero subset of `C^N` for `r<N`. The structured algorithm cannot represent an arbitrary complex vector with a fixed `r`. In `F_p^N` the union-bound mass is at most `N*binom(N,r)*p^(r-N)` (loosely counting repeated supports). This is a **coverage barrier for this method**, not an FFT lower bound.

Raising `r` to `Theta(N)` restores representational universality, but ruins the current recurrence/candidate/Gauss evaluation bound. To beat the worst-case FFT, one would need a **genuine joint evaluator** of the resulting many dense quadratic-phase contributions in sub-`N log N` total work (and ultimately `O(N)`), or a different input-independent arithmetic circuit with a complete operation/precision ledger. Merely calling the basis a graph, a quantum circuit, or a table does not solve this.

## 10. Prior-art framing and next research gate

Quadratic Gauss sums and their gcd reduction are classical; Prony's method/Berlekamp--Massey are classical; quadratic-phase estimation has a substantial signal-processing literature. Relevant background includes the 1997 Fast Quadratic Phase Transform paper (DOI 10.1006/dspr.1997.0286), Hostens--Dehaene--De Moor (2005) on Clifford/stabilizer systems of arbitrary dimension (DOI 10.1103/PhysRevA.71.042315), and standard quadratic Gauss sum references. We **do not** assert that this compound certificate is new to the literature without a dedicated novelty review.

The next nontrivial target is: **find a fully charged, input-independent directed arithmetic graph that jointly evaluates a basis of size `Theta(N)` made from quadratic-phase characters with `O(N)` sequential work and exact output.** It must beat standard FFT in the same model rather than rely on supplied sparse metadata, uncharged phase-candidate search, oracle lookup, or quantum-state output.
