# v11 finite-precision interface audit

9 October 2026. Independent mathematical/static-source review. The uploaded
`RESEARCH.md`, `prototype.py`, and `unit_step_core.py` were read as inert text;
none of the uploaded code was executed or imported. The prior charged Taylor
extension was also read for its representation and setup requirements.

## Finding

The no-leading-rank-factor precision conclusion is repairable, but does not
follow from the stated full-row hypothesis (6.1) alone for the fused program.
That program bypasses ordinary compression and calls a decoder on separately
approximated Bessel summary channels. It needs a decoder-on-summaries contract,
a charged coefficient generator, and explicit summary/Clenshaw error budgets.
The following supplies a sufficient composition theorem. It does not certify
SciPy, NumPy, BLAS, or the uploaded implementation.

## 1. The missing interface

Fix one random state. Let C:C^Q -> C^K be exact block compression,

    (Cy)[b] = sum_t S[b,t] y[bM+t],       |S[b,t]|=1.

Then CC*=M I, ||C||2=sqrt(M). With U_Q unitary, the exact summary decoder is
D=U_Q C*, and the exact full row is A=DC. Selection of output coordinates does
not increase any norm below. In particular,

    ||D||2->infinity <= ||D||2->2 = sqrt(M).

The stated full-row inequality constrains the composite numerical procedure
`Ahat(y)`, not the intermediate map `Dhat(d)` called by fusion. A bound on a
composite does not separate errors in its stages. Even in a scalar example,
Chat(y)=2y and Dhat(d)=d/2 make Dhat(Chat(y)) exact while Dhat is inaccurate on
an independently supplied summary. This illustrates logical insufficiency,
not an allegation that the uploaded decoder behaves this way.

If compression were exact and Ahat(y)=Dhat(Cy), taking y=C*d/M would give the
desired decoder bound because ||y||2=||d||2/sqrt(M). Exact, well-normed lifting
through the *computed* compression is not supplied by (6.1). In the actual
compression formula one can put d in the t=0 positions to obtain an exact
simple lift, but its norm is ||d||2, losing a factor sqrt(M). That observation
gives only C_A u log(Q)sqrt(MQ)||d||2, hence a fused leading error of order
u log(Q) M sqrt(Q)X. For M=Theta(log N), that suffices with an additional
(1/2)log2(log N)+O(1) mantissa bits, but does not prove the displayed v11
log-log coefficient. The issue is missing justification, not impossibility.

A sufficient replacement, uniform in the state and in every supplied summary,
is

    ||Dhat(d)-D(d)||infinity <= epsilon_D ||d||2,
    epsilon_D = C_D u log(Q) sqrt(Q).                         (D)

Input conversion to the decoder's working format must either be included in
(D) or charged separately. The input must not be restricted to summaries that
happen to arise from a particular rounded compression routine.

There is a direct route to proving (D). Let f=FFT_K(d), with the unnormalized
FFT convention in the source, so ||f||2=sqrt(K)||d||2. Each source-index list in
the Q-vector forcing repeats every FFT coordinate M times. Exact forcing and
gauged terms therefore obey

    ||terms||2 <= 2||d||2,
    ||terms||1 <= 2sqrt(Q)||d||2.

A short-FFT guarantee ||fhat-f||2 <= c_F u log(K)sqrt(K)||d||2, uniformly O(u)
accurate unit-modulus phase tables/normalizers, and balanced total/prefix sums
with O(u log Q) absolute-sum error imply (D), including the seed and final
subtraction. This proof concerns the summary interface itself. Exact modular
indices, certified phase preparation, adequate exponent range, and smallness
conditions such as u log Q << 1 are part of it.

## 2. A summable fused envelope, with the norm order correct

Set w_0=1 and w_r=2 for r>=1. Define uniform, nonnegative majorants

    m_0=1,
    m_j=exp(pi^2/8)(pi/2)^j/j!  (j>=1),
    B = m_0 + 2 sum_{j>=1} m_j < 27.17.

Let ell_h bound |J_h(delta_t)| uniformly in t; use ell_{-h}=ell_h,
ell_0=1, and, for h>=1,

    ell_h = exp(Delta^2/[4(h+1)])(Delta/2)^h/h!.

For each retained global order define

    v_r = sum_{|h|<=H} m_|r-h| ell_h,
    B_RH = sum_{0<=r<R} w_r v_r.

If G_h=C diag(J_h(delta))x and
d_r=sum_h diag(J_{r-h}(z))G_h, then, writing X=||x||2,

    ||G_h||2 <= sqrt(M) ell_h X,
    ||d_r||2 <= sqrt(M) v_r X.

For H=0, B_R0<=B. More generally

    B_RH <= 2 B sum_{|h|<=H} ell_h,

which is independent of R for fixed H and bounded Delta. Thus the desired
rank-free *sum of norm bounds* is available. One must use the sum of uniform
majorants above. The identity or inequality

    sum_r w_r ||J_r(z_n)x_n||2
       <= [sup_z sum_r w_r |J_r(z)|] ||x||2

does not hold for arbitrary families of weights. Section 6's notation B_J
should be replaced by B (or another explicitly justified sum-of-suprema
bound) when it is used this way. The displayed numerical majorant suffices;
the pointwise envelope alone is not the proof. For H>0, use the shifted fused
envelope rather than silently reusing the unfused Bessel sequence.

## 3. Explicit deterministic error ledger

Compare the computed row with the ideal *truncated fused* row, so the existing
Jacobi--Anger and local-addition truncation errors remain separate. Assume:

1. Computed local channels satisfy

       ||Ghat_h-G_h||2 <= e_G sqrt(M) ell_h X.

   This includes local phase error, local Bessel error, input multiplication,
   and the block reduction. Input representation error can instead be kept
   separate relative to the represented x.

2. Computed block factors satisfy

       ||fhat_rh - J_{r-h}(z)||infinity <= e_B m_|r-h|.

3. Summary synthesis, including any summary-format conversion, has residual

       ||dhat_r-sum_h diag(fhat_rh)Ghat_h||2
           <= e_S sum_h ||diag(fhat_rh)Ghat_h||2.

4. Decoder contract (D) holds for every dhat_r.

Put

    rho=(1+e_G)(1+e_B)(1+e_S)-1.

Then

    ||dhat_r-d_r||2 <= rho sqrt(M)v_r X,
    ||dhat_r||2 <= (1+rho)sqrt(M)v_r X,

and each decoded term obeys

    ||Dhat(dhat_r)-D(d_r)||infinity
      <= [epsilon_D sqrt(M)(1+rho) + M rho] v_r X.       (1)

No statistical independence, cancellation, or unbiased rounding is used.

For one output let ahat_r be its decoded coefficients, including the exact
factors 2(-i)^r. Their absolute sum is at most

    A_1=(1+rho)(M+epsilon_D sqrt(M)) B_RH X.             (2)

Suppose Clenshaw plus node approximation has absolute error <=chi sum|ahat_r|.
Let the final normalizer and its final multiplication have combined relative
error <=sigma. Writing C_N=sqrt(Q/N), the complete numerical-row allowance is

    eta_fp <= C_N B_RH X {
      epsilon_D sqrt(M)(1+rho) + M rho
      + [(1+sigma)(1+chi)-1]
          (1+rho)(M+epsilon_D sqrt(M)) }.               (3)

This is an explicit replacement for the unsupported auxiliary assertion
(6.4). It compares the same random state with its ideal fused row.

### A sufficient Clenshaw contract

At a represented node xhat in [-1,1], write each computed recurrence as the
exact recurrence plus a residual e_r, and the final expression plus e_0.
Assume the local residual bounds

    |e_r| <= t(|ahat_r|+2|bhat_{r+1}|+|bhat_{r+2}|),
    |e_0| <= t(|ahat_0|+|bhat_1|+|bhat_2|),

where t=O(u) follows from a specified real/complex operation model. Perturbed
Clenshaw is exactly evaluation with coefficient perturbations e_r. Since
|T_r|<=1 and |U_j|<=j+1 on [-1,1], putting L_R=1+3R^2/2 gives

    sum_r |e_r| <= t L_R(sum_r |ahat_r|+sum_r |e_r|).

For t L_R<1, its forward error is therefore at most

    [t L_R/(1-t L_R)] sum_r |ahat_r|.

If |xhat-x|<=e_x with both nodes in [-1,1], the derivative bound
|T'_r|<=r^2 adds at most e_x(R-1)^2 sum_r|ahat_r|. Consequently one may take

    chi=t L_R/(1-t L_R)+e_x(R-1)^2.                    (4)

This proves a conservative O(uR^2) allowance under explicit smallness and
node-domain conditions. Exact integer residuals followed by certified
rounding provide the node contract; floating subtraction kQ/N-j is not an
adequate substitute.

With e_G=O(u log M), e_B=O(u), e_S=O(u log(2H+1)), e_x=O(u), sigma=O(u), and
constant H, (3) becomes

    eta_fp = O(B_RH [u log Q sqrt(MQ)
                     +u M(log M+R^2+1)] X).

In the stated M=Theta(log N), R=Theta(log N/log log N) regime, the first term
dominates. The same u=O(g/[N log N]) and leading mantissa-bit order therefore
follow once these contracts are proved. There is no leading multiplicative
R penalty. Numerical error must be included in the robust aggregator's
radius; the computed estimator need not remain unbiased.

## 4. What the source currently establishes

- `prototype.py:199-214` is exactly the separate summary decoder at issue.
- `prototype.py:338-346` evaluates local coefficients, computes channels with
  `base @ local_weights`, evaluates block factors, then uses `np.sum` for
  synthesis. Matrix multiplication does not specify a pairwise reduction
  tree. A BLAS dot-product analysis can instead supply e_G=O(uM), but that is
  a different stated contract. It still leaves the leading asymptotic term
  dominant; it is not proof of the exact auxiliary formula printed in §6.
- The decoder casts its summaries to the selected storage dtype; NumPy FFT
  and SciPy Bessel evaluations still run at their library precision. The
  complex64 stress case is not a b-bit end-to-end implementation.
- `finite_precision_lift_bound` simply evaluates the proposed formula. It
  has no H parameter and does not certify shifted coefficient envelopes,
  coefficient-generation accuracy, root preparation, or summary rounding.
- Exact int64 arithmetic is not an all-size indexing implementation. Phase
  products, nearest-grid products, conversion accuracy, overflow, underflow,
  and the precision of the norm/normalizer all need contracts or budgets.

## 5. Charge the Bessel preparation, not just its applications

As written, the fused implementation requests (2H+1)M local Bessel values and
(2H+1)RK block Bessel values per lifted row. Thus its arithmetic count includes

    O((2H+1)(RK+M) C_J(b,R,H))

for an actual certified scalar generator cost C_J, or a justified batch cost.
These calls are not automatically unit-cost b-bit arithmetic. Uniform absolute
accuracy 2^-b independent of the order would also give an avoidable R-sized
sum; the majorized error envelope used above must be supplied explicitly.

An affordable constructive replacement is available. For integer m>=0 use

    J_m(z)=(z/2)^m/m! sum_{j>=0}
          (-z^2/4)^j m!/[j!(m+j)!].

For |z|<=4, the tail after j=L-1, divided by |(z/2)^m/m!|, is bounded by

    exp(4) 4^L/(L!)^2.

Indeed m!/(m+j)!<=1/j!, and (L+l)!>=L!l!. Hence
L=O((b+1)/log(b+2)) terms suffice for error O(2^-b) times a summable factorial
majorant. For example exp(4)2^m/m! is a valid loose envelope on this enlarged
argument interval. Negative orders use the exact parity identity.

A certified rational pi approximation with error O(u/(R+H+1)), accurate
rational-grid conversion, and guard roundoff O(u/(R+H+L+1)) cover arguments,
leading-factor generation, term recurrences, and accumulation. The added
mantissa length is only O(log(R+H+L)); sufficient exponent range is still
required. These are specifications for a constructive variant, not properties
established for `scipy.special.jv`.

Generate the leading factors across orders by a factorial recurrence once
per gridpoint, then spend O(L) operations/value. This gives O(RKL) block work
for constant H, plus the lower-order local/setup work. Storing an order-by-
block table costs O(RK)=O(N) in the theorem regime R=O(M). Alternatively,
stream values and recompute their leading factors in O(R) work/value; since
R=Theta(L) in the shrinking regime, the same asymptotic charge results.

With b=Theta(log N), R,L=Theta(log N/log log N), and K=Theta(N/log N),

    R K L = Theta(N log N/(log log N)^2) = o(RN).

Thus charging a specified generator can preserve the total O(RN) arithmetic
bound. The simpler O(b)-terms-per-value construction also fits O(RN).
Neither justifies counting all coefficient preparation inside the advertised
O(Q+RK) fused-input work. That narrower saving concerns input/phase traversal
or a model with prepared coefficients. Working/guard precision, exact integer
and rational preparation, and input/output bit costs must be charged in a
separate bit-complexity statement.

## Conclusion

Replace (6.1) by the actual summary-interface contract, replace the ambiguous
pointwise B_J use by a summable uniform majorant, and add ledger (3) with
certified coefficient and phase preparation. These amendments retain v11's
leading precision and total-arithmetic asymptotics. The current package
provides encouraging finite tests and an implementation plan, not this full
finite-precision implication or a certified fixed-binary64 theorem.
