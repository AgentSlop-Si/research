# A hidden-order obstruction for the parity-mixed Green stage

**Scope:** Exact algebra, every even `N` for the structural-rank claims; exact DFT block invertibility for powers of two `N>=8`. This corrects the overly optimistic interpretation of the prior checkpoint's natural-order cut rank.

## The stage and its hidden permutation

Let `T=tridiag(-1,3,-1)`, `G=T^{-1}`. For `N=2m`, let `P` reorder standard coordinates into the list

```
sigma=[0,2,4,...,N-2,1,3,5,...,N-1].
```

The previous candidate was `M=P G P^T+epsilon G`, with `epsilon=1/20`. Introduce the inverse permutation `Q=P^T`, which reorders coordinates in the list

```
tau=[0,m,1,m+1,2,m+2,...,m-1,N-1].
```

Then **exactly**

```
Q M Q^T = G + epsilon Q G Q^T.
```

Under the tau ordering, the sparse precision `Q T Q^T` consists of a path with edges `(i,i+2)` for `0<=i<=N-3`, together with one extra edge `(1,N-2)`. Thus every contiguous prefix/suffix cut has **at most 3** cross edges in that reordered path (at most one from each parity strand and at most one from the long bridge).

## A Green cross-block identity

Let `D` be an SPD matrix. For any partition `(I,J)` of all coordinates, write

```
D = [[U, B], [B^T, V]].
```

The block-inversion identity gives

```
(D^-1)[I,J] = - U^-1 B (V-B^T U^-1 B)^-1.
```

Both outer factors are invertible, hence

```
rank((D^-1)[I,J]) = rank(D[I,J]).
```

For `G=T^-1`, the path precision `T` has one crossing edge per natural-order prefix, so `rank(G[I,J])<=1`. The permuted `Q G Q^T` has at most 3 crossing edges per tau-order prefix, so its cross-block rank is at most 3. Rank subadditivity implies

```
rank((Q M Q^T)[0:k,k:N]) <= 1+3 = 4, for EVERY 1<=k<N.
```

Lower cross blocks satisfy the same bound by symmetry. A left Householder transform `H=I-2u u^T/(u^T u)` modifies the stage by rank at most one; hence a phase-dressed reflected stage `D_L H M D_R` has quasiseparable cut rank <=5 in the tau ordering. Diagonal phases and scalings cannot change individual block ranks.

**Meaning:** The earlier `Omega(N)` **natural-order** half-cut rank is true, but it is NOT permutation-robust. The stage admits a low-rank representation in one very inexpensive hidden order.

## The Fourier matrix still has full half-block ranks in that order

For `N=4q=2^k` with `k>=3`, let `m=N/2=2q` and let `omega` be a primitive Nth root in any field of characteristic not 2. Define the Fourier matrix `F[i,j]=omega^(ij)` and `F'=Q F Q^T`. The first half of the tau order selects Fourier row indices

```
R={a,a+m : 0<=a<q}.
```

The first or second half of the columns similarly selects `C={b,b+m}` with `b` in a **consecutive interval of q integers** (`0..q-1` or `q..2q-1`). We prove `F[R,C]` is nonsingular.

Suppose coefficients `u_b,v_b` form a null vector for the chosen columns. The equations for rows `a` and `a+m` are

```
sum_b omega^(ab) (u_b+(-1)^a v_b) = 0,
sum_b omega^(ab) (-1)^b (u_b+(-1)^a v_b) = 0.
```

Adding/subtracting them separates even/odd `b`. Restricting to even or odd `a` separates the combinations `u_b+v_b` and `u_b-v_b`. Each resulting square system has `q/2` consecutive indices of the form `a=a0+2i`, `b=b0+2j`, and coefficient matrix

```
omega^((a0+2i)(b0+2j))
 = (nonzero row factor) * (omega^4)^(ij) * (nonzero column factor).
```

Because `omega^4` has order `q`, the `q/2` evaluation nodes `(omega^4)^i` are distinct. The central block is a nonsingular Vandermonde matrix, so all `u_b+v_b` and `u_b-v_b` vanish. Characteristic != 2 gives `u_b=v_b=0` for every b.

Therefore BOTH `F'[L,L]` and `F'[L,R]` have rank `m=N/2` in the tau ordering.

## Consequences for the previous family

The previous checkpoint's half-cut theorem applies to a factorization

```
F' = S2' * W * S1',
```

where W is **any** intermediate monomial (permutation times nonsingular diagonal) and `S1',S2'` have natural-order (here tau-order) upper/lower quasiseparable cut ranks at most `r1,r2`. As both target half blocks have full rank, that theorem's proof yields

```
r1+r2 >= N/4.
```

For two parity-mixed Green stages (each rank <=4 after conjugation), `r1+r2<=8`, making an exact DFT factorization impossible at `N>=64` (indeed any N>32 in the proved power-of-two family). With a rank-one Householder and arbitrary phase/scalar diagonals, each transformed stage has rank <=5, and `r1+r2<=10`, **still ruling out N>=64**.

If all stages keep the same hidden ordering and intermediate operations are only diagonal (NO arbitrary shuffles), the upper cut rank of a matrix product is at most the sum of its factors' ranks. Since `rank(F'[L,R])=N/2`, a product of t bare stages requires `4t>=N/2`, hence `t>=N/8`. For reflected stages, `5t>=N/2` and `t>=N/10`. These are **architecture-specific factor-count** obstructions; they are not general FFT arithmetic lower bounds. Arbitrary shuffles between 3+ stages invalidate this additive-rank argument.
