# Next research gate: exhaustive interface obstruction, then phase compatibility

1. Fix the user’s candidate exact architecture `M=(G1+G2)(G3+G4)` with independently permuted non-affine weighted Hamiltonian cycles.
2. For N=8,16,32,64 test Fourier coset pairs `(R,C)` at all divisor scales, not just `(A,A^c)`.
3. For each pair, minimize the *submodular* interface budget

   `f(S)=Σ_{j=1,2} rank G_j[R,S^c] + Σ_{j=3,4} rank G_j[S,C]`.

   Use the `O(N)` individual Green rank oracle. Optimize f using a correct submodular minimization algorithm or a certified solver, not a heuristic success assertion. A supplied S with f(S)<h already provides an exact formal rejection witness.
4. If no interface cut rejects a candidate, test the **actual complex phases** by exact Weyl equations. Passing cuts is necessary but nowhere near sufficient.
5. Study parameter synthesis on all N rather than finite-N numerical fitting. Count coefficient-generation and constant/data movement work.
6. Benchmark any surviving positive network in the same exact arithmetic model as the public all-length sub-NlogN bound; separately analyze bit complexity/stability.

Negative results are not universal FFT lower bounds. At present no all-N parameter family is known to satisfy exact Fourier identities with O(N) charged work.
