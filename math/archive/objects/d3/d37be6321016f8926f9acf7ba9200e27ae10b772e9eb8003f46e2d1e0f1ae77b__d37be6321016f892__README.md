# Reversible affine q-Weyl reuse with arbitrary dirty scratch

Research continuation, 9 October 2026. This is a constructive extension of the
previous exact relation `T B = C T`. It does not give a faster fresh FFT and
does not import a fast local transform from #130. No priority claim is made.

## The positive result

Set `K = I+B`, `J = I+C`. Then

    T K^r = J^r T

for every integer r, including negative r. Although C is nilpotent and cannot
be reversed, J is invertible and admits an explicit O(N)-length reversible
gate word. This allows an exact related-input cache trajectory to run forwards
and backwards without replaying T. The strongest implemented compiler uses
ONE ADD_T and the first arbitrary target as an anchor. It needs no extra
N-register scratch bank and restores the source exactly.

The new supplied conditioning theorem motivates requiring a square reversible
map on arbitrary formal scratch coordinates and examining individual scalar
instructions. Its conditional fast-block theorem is not used as an algorithm
primitive here.

## Exact factorization of the affine update

Assume even power-of-two N, primitive Nth root q, and characteristic zero or a
field whose characteristic does not divide N. Let

    u_j = q^(-j),       a_j = 1+u_j,
    b_j = q-u_j         (0 <= j < N-1),
    b_(N-1) = -q/N.

The previous boundary-corrected operator has

    (Jx)_j = a_j x_j + b_j x_(j+1 mod N).

Every b_j is nonzero. Precisely a_m=0 at m=N/2. Put r_j=a_j/b_j. Define
`Sx` by `(Sx)_(j+1)=x_(j+1)+r_j x_j`, omitting the edge j=m. Cutting this
cycle gives an acyclic chain. Executing its N-1 shears in reverse chain order
`j=m-1,m-2,...,m+1 (mod N)` uses each source before it is changed, and therefore
implements S exactly without cross terms. With `(Pz)_j=z_(j+1 mod N)`,

    J = diag(b) P S.

The emitter uses N-1 shears, N-1 adjacent swaps implementing P, and N nonzero
scalings. Reverse the gate order and invert each coefficient for J^-1. This
requires neither a dense inverse nor evaluating T. The construction remains
valid at the zero diagonal: it never divides by a_j.

The claimed identity `T K = J T` follows directly from the previously proved
`T B = C T`. It is also independently checked here against the dense triangular
kernel T on every basis vector for both test fields.

## One-call target-anchor compiler

Let x be the source and y_0,...,y_(R-1) arbitrary target banks. Desired behavior
is `y_r <- y_r + T K^r x`, with x restored. Use y_0 as the anchor:

1. For r=1,...,R-1, advance `y_0 <- J y_0` and `x <- K x`, then subtract the
   current anchor from y_r. At this point the anchor is J^(R-1)y_0_old and the
   source is K^(R-1)x_old.
2. Execute ONE `y_0 += T x`. Intertwining changes the anchor to
   J^(R-1)(y_0_old+T x_old).
3. For r=R-1,...,1, add the current anchor to y_r, then apply J^-1 to the
   anchor and K^-1 to x.

The old anchor contributions cancel in every later target. The final anchor
itself is `y_0_old+T x_old`, and x has returned to x_old. This is an identity
on arbitrary formal starting coordinates; it requires no zero-initialized
bank or scratch register. The audit retains an unused dirty w bank only for
direct comparison with the earlier implementations and confirms it is untouched.

If ADD_T costs A_T gates, J/J^-1 costs G_J, and K/K^-1 costs G_K, the compiler
uses

    A_T + 2(R-1)(G_J+G_K) + 2(R-1)N copy-add gates.

Thus any transparent ADD_T primitive yields a transparent related-input batch
at cost A_T+O(RN), including full target writes and restored source. This is a
general intertwiner construction, not specific to the quadratic reference T.
It does not imply that arbitrary unrelated inputs satisfy the relation.

## Earlier two-call comparators

Let x be the source, w an arbitrary dirty N-register bank, and let y_0,...,y_(R-1)
be arbitrary target banks. Desired behavior is

    y_r <- y_r + T K^r x,     x <- x,     w <- w.

Use this sequence:

1. Follow w,Jw,...,J^(R-1)w, subtracting each state from its corresponding y_r.
   Run J^-1 R-1 times to restore w.
2. Perform `w += T x`.
3. Repeat the trajectory, adding each state to y_r; reverse it to return to w+Tx.
4. Perform `w -= T x`.

The dirty contributions cancel because the two trajectories start at w and
w+Tx. The net addition is J^r Tx=T K^r x. Both x and w are restored as formal
independent coordinates, not merely on initially zero values.

If ADD_T costs A_T primitive gates and one J or J^-1 application costs G, the
construction costs

    2 A_T + 4(R-1) G + 2 R N copy-add gates.

The intermediate serpentine variant carries x forward to K^(R-1)x, applies
ADD_T at the far endpoint, and returns x and w together while adding outputs.
It costs `2 A_T + 2(R-1)(G_J+G_K) + 2RN` copy-add gates. All three variants
are retained and verified; the target-anchor compiler is the strongest result.

Preparation, index traversal, and output materialization are not omitted.
This comparison is against independently replaying ADD_T for every source;
it is not a claim to outperform the already known strategy with a clean cached
Tx. This is specifically the reversible arbitrary-dirty-buffer extension.

## Implemented primitive counts

The executable reference implements ADD_T by all N(N+1)/2 triangular scalar
shears; it is explicitly quadratic. A faster transparent ADD_T can be inserted,
but none is assumed in the recorded results.

Every shear coefficient in this construction is nonzero. An atomic shear
`target += alpha*source` expands into three reversible register instructions:
`source *= alpha; target += source; source *= alpha^-1`. No destructive
multiplication temporary is hidden. An adjacent swap expands as
`x += y; y -= x; x += y; y *= -1`, four reversible scalar instructions.
Coefficients and their inverses are prepared before execution.

Write A=N(N+1)/2. The original dirty-buffer batch word contains

    shears   = 2A + 4(R-1)(N-1) + 2RN,
    scalings = 4(R-1)N,
    swaps    = 4(R-1)(N-1).

Consequently its scalar expansion has

    6A + 6RN + 4(R-1)(8N-7)

instructions. The serpentine word uses `6A+6RN+2(R-1)(11N-10)` instructions.

The one-call target-anchor word contains

    shears   = A + 4(R-1)(N-1) + 2(R-1)N,
    scalings = 2(R-1)N,
    swaps    = 2(R-1)(N-1).

Its fully reversible scalar expansion therefore uses

    3A + 2(R-1)(14N-10)

instructions. The independent-replay comparison preserves the original x by
reversing its K trajectory. It has `R*A+2(R-1)(N-1)` shears, or three times that
many scalar instructions under the same deliberately unoptimized expansion.

| N | R | Original dirty buffer | Serpentine | One-call anchor | Independent replay | Replay / anchor |
|---:|---:|---:|---:|---:|---:|---:|
| 32 | 4 | 6,924 | 5,988 | 4,212 | 6,894 | 1.637x |
| 64 | 4 | 20,076 | 18,180 | 11,556 | 26,094 | 2.258x |
| 128 | 8 | 84,156 | 75,252 | 49,716 | 203,478 | 4.093x |

These are exact emitted instruction counts, not runtime speedups, not the
optimal circuit for either workload, and not evidence about fresh FFT
asymptotics. Even unit-coefficient shears are expanded uniformly, so later
local simplifications could improve both sides.

The script prepares O(N) distinct field values and inverses, plus one root
extraction from the field's supplied primitive generator. It uses modular
inversion as an explicit preparation operation; O(N) arithmetic-inversion
calls are not O(N) bit complexity. Root extraction uses modular powering and
its exponent is explicit. With a supplied root, coefficient preparation is
O(N) exact field operations counting inversions. Emitting and storing the
unrolled reference program costs O(N^2+RN), explicitly charged here. A looped
emitter can share the O(N) coefficient table, but this code keeps the expanded
word reviewable. The anchor algorithm needs (R+1)N data registers; RN hold the
requested full outputs, plus any scratch required by the plugged-in ADD_T.
This implementation's direct ADD_T needs no such scratch. The uniform test
layout keeps an unused extra dirty N-bank and verifies it stays unchanged.
The earlier dirty-buffer algorithms use (R+2)N data registers. There is no
claim of O(N) total storage for unbounded R.

The completed ADD batch is invertible but generally not unitary. Neither J
nor the batch supplies the unitary reset required by the supplied conditioning
theorem. Reversibility and the absence of destructive dirty-scratch assignments
do not imply numerical stability or a dimension-independent condition bound.

## Verification

Run `python3 run_audit.py`. Exact modular arithmetic uses primes 65537 and
998244353, each at N=2,4,8,16,32.

- 124 basis vectors verify J's emitted factorization, its inverse, and T K=J T.
- 168 full-state basis vectors verify batch behavior on x, dirty w, and every
  target coordinate, covering N=2,4,8 in both fields.
- 50 random full states check the larger cases as well.
- 56 additional full-state basis vectors check anchor batch sizes R=1,2.
- Every batch case checks all three compilers against direct triangular T,
  the independent replay word, and each literal scalar-instruction expansion.
- Reversing each entire batch word restores every initial register.

These finite tests support the implementation; the factorization and batch
identities above are algebraic proofs for all admissible N.

Files: `affine_reuse.py` is the emitter and evaluator; `run_audit.py` is the
independent direct-output audit; `audit_results.json` records all counts.
