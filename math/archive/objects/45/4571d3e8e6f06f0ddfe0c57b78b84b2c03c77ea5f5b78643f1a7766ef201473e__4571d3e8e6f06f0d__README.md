# Finite q-exponential tail: a fast first layer and an exact recurrence

This checkpoint extracts useful structure from the finite tail, instead of
discarding it. Its first homogeneous layer is a weighted cyclic convolution
with an explicit Fourier spectrum, so it has an exact O(N log N) evaluator with
O(N) coefficient preparation. Further layers satisfy an exact sparse recurrence.

The full recurrence still costs Theta(N^2). It is not competitive with the
O(N log N) FFT-based fallback for the complete operator, and it does not improve
an arbitrary FFT. The positive result is an exact fast action for the first tail
layer and short prefixes of tail layers, for every input vector.

## Finite algebra, with the boundary retained

Let N=2^L >=2, q a supplied primitive Nth root, and let

    f_j = product_(a=1..j)(1-q^a),   t_j=1/f_j,   f_0=1
    H_q(X) = sum_(j=0..N-1) t_j X^j.

Use the previous exact cyclic pair U,W, where U=diag(q^(-j)), W has upper
weights q-q^(-i), and its lower-left corner is -q/N. Thus

    UW=qWU,  U^N=I,  W^N=-I,  C=U+W,  C^N=0.

The corner remains in every action and every reference matrix in this package.
The exact normal-ordered expansion is

    H_q(C) = sum_(r+s<N) t_r t_s W^s U^r.

Define homogeneous layers

    P_n = sum_(r+s=n; 0<=r,s<N) t_r t_s W^s U^r.

Then the complete tail is

    E = H_q(W) H_q(U)-H_q(C) = sum_(n=N..2N-2) P_n.

These are finite polynomial identities. For n<N the q-binomial formula gives
P_n=t_n C^n. There is no inference that the terms with n>=N vanish.

## The first tail layer is one cyclic convolution

Set V=W U^-1. Directly,

    V^N=I,  UV=qVU,  C=(I+V)U.

The root-of-unity factorial reflection and normal ordering give

    t_(N-s)=(-1)^(s-1) q^(-s(s-1)/2) f_(s-1)/N,
    W^s U^(N-s)=q^(s(s-1)/2) V^s.

Therefore the first tail layer is exactly

    P_N = (1/N) sum_(s=1..N-1) (-1)^(s-1) V^s/(1-q^s).       (1)

This is a polynomial of one cyclic weighted shift, not a general matrix that
must be stored densely. Let J be the ordinary cyclic upper shift, with its
wraparound entry equal to +1, and define

    Sigma[j,j]=(-1)^j q^(-j)/f_j.

Then V=Sigma J Sigma^-1. The ratio of successive diagonal entries is
-q(1-q^(j+1)), and the wraparound ratio is -q/N, exactly the weights of V.
Both Sigma and its inverse can be prepared in O(N) operations using the already
known f_j and t_j; no independent inversion of each entry is necessary.

For the positive-exponent Fourier convention F[k,j]=q^(kj), J has spectral
value q^(-k). The spectrum of the kernel in (1) is explicit. Set

    r = (N/2-k) modulo N.

Then

    lambda[k] = -(N-1)/(2N),                  if r=0,
                (N+1-2r)/(2N),               otherwise.

To prove this, let A_r=sum_(s=1..N-1)q^(rs)/(1-q^s). Pairing s with N-s gives
A_0=(N-1)/2. Also A_(r+1)-A_r equals -(N-1) at r=0 and +1 otherwise.
Thus A_r=r-(N+1)/2 for 1<=r<N, and lambda[k]=-A_((N/2-k) mod N)/N.
This proof works in characteristic zero and in the odd-characteristic fields
used by the verifier. No numerical approximation is involved.

The actual algorithm is consequently

    P_N x = Sigma F^-1 diag(lambda) F Sigma^-1 x.              (2)

All N inputs and all N outputs are retained. The scalar spectrum is generated
directly; no transform is hidden in spectrum preparation. The implementation
uses two ordinary exact radix-2 N-point Fourier transforms. It therefore uses,
and does not improve upon, an O(N log N) FFT backend.

## Grading relation and the rest of the tail

Writing P_N=G(V), the explicit coefficients give

    G(qV)-G(V)=Pi_(-1)-I/N,
    Pi_(-1)=(1/N) sum_(s=0..N-1)(-V)^s.

Since (I+V)Pi_(-1)=0 and C=(I+V)U, this proves

    [P_N,C] = P_N C-C P_N = C/N.                             (3)

The complete homogeneous recurrence, including its missing-edge terms, is

    C P_(N+k-1) = (1-q^k) P_(N+k)
                   +(t_k/N)(q^k W^k-U^k),                  (4)

for 1<=k<=N-1, where P_(2N-1)=0. To derive it, multiply each normal-ordered
monomial by C on the left. Interior coefficients combine to 1-q^(r+s).
The r=N edge reduces with U^N=I; the s=N edge reduces with W^N=-I. Those two
edges produce precisely the displayed forcing term. The terminal equation is
also included in the audit.

Equivalently, for 0<=k<=N-2,

    P_(N+k) = t_k [C^k P_N
       -(1/N) sum_(j=1..k) C^(k-j)(q^j W^j-U^j)/(1-q^j)].    (5)

Equations (3)-(5) retain a concrete unresolved term: q^j W^j-U^j is generally
not a polynomial of C. The grading commutator does not license deleting these
forcing terms or replacing the whole tail by P_N H_q(C).

## Implemented exact layer-prefix evaluator

`apply_tail_prefix(...,k)` returns the exact operator

    (P_N+P_(N+1)+...+P_(N+k)) x,   0<=k<=N-2.

It first applies (2), then uses (4), advancing W^j x and U^j x with one sparse
pass each. It retains O(N) working storage and accumulates the requested prefix.
It is not an approximation to H_q(C); the omitted layers are not declared zero.
For k=N-2 it returns the complete tail, but the quadratic route should be replaced
by the FFT-based complete-operator fallback when that is the requested result.

All roots and scalar coefficients are prepared explicitly. The complete plan
used here, including coefficients for all possible recurrence steps, conservatively
charges 14N-7+2log2(N) field multiplications, 2N-2 subtractions, 2N negations,
and three inversions of the fixed constant 2. Supplying 1/2 can remove those
constant inversions. The plan stores O(N) field elements. Some duplicated
preparation could be shared, but no sharing is assumed in these counts.

For L=log2(N), the exact counted online operations are:

| Action | Multiplications | Additions | Subtractions | Asymptotic work |
|---|---:|---:|---:|---|
| One ordinary N-point FFT used by this backend | NL/2 | NL/2 | NL/2 | O(N log N) |
| First tail layer P_N | NL+4N | NL | NL | O(N log N) |
| Tail prefix through P_(N+k) | NL+4N+7Nk | NL+2Nk | NL+2Nk | O(N log N+kN) |
| Complete tail by this recurrence, k=N-2 | NL+4N+7N(N-2) | NL+2N(N-2) | NL+2N(N-2) | Theta(N^2) |

The first-layer action has the cost of two FFTs plus four N-vector scalings,
including inverse normalization. It is not a faster FFT. The table also makes
the failed full-tail scaling explicit: the recurrence cannot be sold as a
sub-N-log-N algorithm merely because its individual steps are sparse.

Bit reversal, addressing, coefficient lookup, copies, and full output writes
take O(N log N+kN) word operations or less and are included in the asymptotic
claims. The model uses exact field arithmetic and O(log N)-bit word indices;
there is no Turing bit-complexity or floating-point stability claim.

## Comparison with the O(N log N) baseline

The correct comparison is not only with the previous quadratic Horner oracle.
The known exact identity

    F_N = P H_q(C) H_q(A) Gamma

already gives

    H_q(C) = P^-1 F_N Gamma^-1 H_q(A)^-1.

Here H_q(A)^-1 is a fixed triangular convolution. With ordinary FFT convolution,
this applies H_q(C) in O(N log N), including suitable one-shot coefficient
preparation. It invokes an existing Fourier transform and is circular as a
proposal for improving that Fourier transform.

Likewise H_q(W) is a diagonally conjugated negacyclic convolution and H_q(U) is
diagonal, so E=H_q(W)H_q(U)-H_q(C) has an O(N log N) FFT-based implementation.
That baseline beats the full recurrence asymptotically.

If only the Nth root q is available, ordinary degree-<N polynomial products can
be split into halves of length N/2 and evaluated using N-point FFTs. Each short
linear product has degree at most N-2, so no 2Nth root is needed. A fixed
truncated length-N convolution can share its two input transforms and use two
inverse transforms; this gives an O(N log N) baseline with more FFT calls. With
a supplied compatible 2Nth root, a more direct padded-convolution implementation
is available. Root availability and kernel transforms must be counted in either
contract. The companion baseline package provides the latter implementation.

The useful new restricted result is the explicit first-tail spectrum and its
O(N log N) action, plus exact short-prefix evaluation. Neither improves the
already available asymptotic bound for the full operator.

## Reproduce and inspect

Run `python run_audit.py` using Python's standard library. It writes
`results/tail_audit.json`. The independent normal-ordered matrices are compared
with every basis-vector output over F_65537 and F_998244353 at N=2,4,8,16,32,
and rational cyclotomic fields at N=2,4,8. Checks include the backend Fourier
convention, sawtooth spectrum, grading identity, every homogeneous recurrence
including the terminal one, short prefixes, the complete tail, and exact gate
counts. These finite tests audit the implementation; the displayed algebra has
all-N scope under its stated assumptions.

`tail_layers.py` and `run_audit.py` are new. The exact arithmetic and q-Weyl
operator helpers are copied unchanged from the previous checkpoint. No global
novelty claim is made for the identities. Context for the starting q-factorial
Fourier factorization is Alexey Kuznetsov, *Using q-calculus to study LDL^T
factorization of a certain Vandermonde matrix*, https://arxiv.org/abs/1507.02959 .
General q-exponential normal ordering and root-of-unity versions have established
literature; this checkpoint derives its finite expressions directly.
