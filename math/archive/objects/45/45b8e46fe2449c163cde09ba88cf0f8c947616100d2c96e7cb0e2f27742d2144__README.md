# Hero #1 Phase 23 — Short-Probe Hankel Fusion

**Date:** 2026-10-10. **Status:** exact structured-input arithmetic improvement, no general sub-NlogN Fourier theorem.

This phase cuts the reciprocal graph-union detector's input Fourier probes from `4s` to `2s+2`. At `s=4` this is `16 -> 10`, and all ten are evaluated in one shared streaming input scan. Adjacent Hankel pencils also reuse intermediate powers and data values. It is **not** safe to infer the full Fourier transform from ten probes alone; the code checks a complete cyclic convolution identity for every candidate and falls back to a regular exact FFT whenever there is no certified candidate.

**Measured on the structured N=32768 test:** Phase 22 needed 2,962,215 counted modular field operations; Phase 23 needs 2,006,612 (32.26% reduction), versus the exact full Bluestein/Green baseline's 5,440,325 (63.12% saving). Generic random input still requires 6,165,969 versus 5,440,325 baseline operations (+13.34%). The comparison counts field arithmetic, **not** CPU time, float stability or bit cost.

**Independent reproducibility:** 58 tests pass (51 inherited, seven new); 35,206 direct-DFT output comparisons across two prime fields and 11 lengths; 75 separate exact comparisons of the joint-pencil compiler with the original compiler. Adversarial equal-prefix/different-spectrum input is rejected by two complete failed certificates and a correct FFT fallback.
