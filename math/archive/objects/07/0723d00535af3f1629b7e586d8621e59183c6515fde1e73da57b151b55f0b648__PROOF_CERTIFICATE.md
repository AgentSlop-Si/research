# Proof certificate — dual Fourier support and eight-coordinate onion chart

**October 9, 2026.** The statements below are elementary algebraic identities over any field of characteristic not dividing `n` containing a primitive n-th root `z`. In particular they hold over `Q(z)` and the complex numbers. Modular computations verify the implementations; they are **not** the logical basis of the algebraic proof.

## Scope and notation

Let `F_n[i,k]=z^(i*k)` and `F_n=B P A`. Set `C=A^-1`, hence `B=F_n C P^-1`. The code stores the matrix `C[:,perm[j]]` as output column `j` before applying `F_n`. Assume `n>=6`, and the intermediate permutation satisfies

`perm[0]=n-1, perm[1]=0, perm[2]=n-2; perm[3:]` permutes `1..n-3` arbitrarily.

Work in the global separated rank-one quasiseparable chart

```
C[i,i]=1
C[i,j]=L_i V_j                   (i>j)
C[i,j]=U_i W_j                   (i<j)
L_(n-1)=1, U_0=1.
```

Normalize the open locus by requiring `t=C[n-1,0]=V_0!=0` and `s=C[0,n-1]=W_(n-1)!=0`. Put `h_i=U_i*s` for `i=0..n-2`, so `h_0=s`, and `eta_j=W_j/s` for `j=1..n-2`. Then `C[i,n-1]=h_i` for `i<n-1` and `C[i,j]=h_i eta_j` for `i<j<n-1`.

We characterize a **necessary subset** of the full B-stage rank-one conditions. B's lower / upper corner pivots `B[n-1,0]` and `B[0,n-1]` must be nonzero in the regular patch. In addition, all denominators explicitly inverted below must be nonzero. Full FFT feasibility also requires `det C!=0` and that `A=C^-1` belongs to the intended separated chart; nonzero inverse corners ensure the latter given inversion's preservation of quasiseparable crossing ranks.

## 1. Two spectral-support lemmas

**Column lemma.** If `B[i,j]=rho B[i,0]` for all `i=j+1..n-1`, then

`F_n(C[:,perm[j]]-rho C[:,perm[0]])` is supported only on Fourier frequencies `0..j`. Its inverse transform is therefore a linear combination of the sequences `z^(-m*k)` for `m=0..j`.

**Row lemma.** If `B[i,j]=gamma B[0,j]` for `j=i+1..n-1`, then the row functional with weights `q_r=z^(i*r)-gamma` annihilates columns `C[:,perm[j]]` for those `j`. This statement is exact because `B=F_n C P^-1`.

The rank-one separated chart for B, on nonzero corners, supplies the hypotheses of both lemmas with `rho=B[n-1,j]/B[n-1,0]` and `gamma=B[i,n-1]/B[0,n-1]`. The inner-index ranges of the original 30 equations generalize to `(n-2)(n-3)` equations.

## 2. First column => explicit lower generators

For output column `j=1`, `perm[1]=0`, and `perm[0]=n-1`. Define `beta=B[n-1,1]/B[n-1,0]` and `xi=z^-1`. The column lemma gives

`C[k,0]-beta C[k,n-1] = a+b xi^k`.

At `k=0,n-1`: `a+b=1-beta*s`, `a+b*z=t-beta`. Therefore

```
b=(t-1+beta*(s-1))/(z-1)
a=1-beta*s-b
L_k=(a+b*xi^k+beta*h_k)/t       for k=1..n-2.
```

This makes the `n-3` lower stage constraints for output `j=1` hold identically, provided `t!=0`.

## 3. First row => explicit upper generators

Put `q^(1)_r=z^r-gamma1`, `gamma1=B[1,n-1]/B[0,n-1]`, and for `1<=k<=n-2` define

```
S^(1)_k = sum_(r<k) q^(1)_r h_r
R^(1)_k = sum_(r>k) q^(1)_r L_r.
```

The row lemma for `i=1` says `q^(1) C[:,k]=0` for every `1<=k<=n-2`, equivalent to

`q^(1)_k + eta_k S^(1)_k + V_k R^(1)_k =0`.

If `S^(1)_k !=0`, solve

`eta_k=-(q^(1)_k+V_k R^(1)_k)/S^(1)_k`.

This makes all `n-3` upper stage constraints for output row `i=1` hold identically. First two sections together yield `2n` parameters and `(n-3)(n-4)` remaining constraints. At `n=8`, the exact denominator-free, **20-equation/16-variable degree-at-most-9 polynomial system** is exported in `dual_twenty_equations.json`. In its derivation, the 10 removed rank-one polynomials are identically zero over `Z[z]/(z^4+1)`, not merely under modular sampling.

## 4. Second column => a three-frequency recurrence

Now `perm[2]=n-2`. Define `rho=B[n-1,2]/B[n-1,0]`. The column lemma implies

`v=C[:,n-2]-rho C[:,n-1] = u_0 + u_1 xi^k+u_2 xi^(2k)`.

For positions `k=0..n-3`, `v_k=(eta_(n-2)-rho) h_k`. This scalar **cannot be zero for an invertible C**: if it were zero, `v` would be supported only on the last two time coordinates, but a two-tap vector has no more than one zero Fourier frequency unless it is zero. The column lemma forces vanishing on at least two distinct frequencies because `n>=6`; hence `v=0`, contradicting `det C!=0`.

Therefore `h_0..h_(n-3)` are samples of a combination of the three characters `1,xi^k,xi^(2k)`. Their characteristic polynomial is `(X-1)(X-xi)(X-xi^2)`. The exact recurrence is

```
h_(k+3)=(1+xi+xi^2)*h_(k+2)
         -(xi+xi^2+xi^3)*h_(k+1)+xi^3*h_k
```

for `k=0..n-6` (there are `n-5` independent linear identities). The first three values `h0,h1,h2` determine all `h3..h_(n-3)`; `h_(n-2)` remains free.

Call the full Fourier-three-mode extrapolation `h*_0..h*_(n-1)` (this includes values at the final two positions; the actual `h_(n-2)` need not equal `h*_(n-2)`). Let `k=n-2` and write `eta_k=a_k+b_k V_k`, where

```
a_k=-q^(1)_k / S^(1)_k
b_k=-R^(1)_k / S^(1)_k.
```

The two boundary conditions `v_(n-2)=(eta_k-rho)h*_(n-2)` and `v_(n-1)=(eta_k-rho)h*_(n-1)` give a **2×2 linear system** for `(V_k,rho)`:

```
[ b_k*h*_(n-2)       h_(n-2)-h*_(n-2) ] [ V_k ]
[ 1-b_k*h*_(n-1)     h*_(n-1)-1     ] [ rho ]
   = [ 1-a_k*h*_(n-2),  a_k*h*_(n-1) ].
```

If its determinant is nonzero, the solution is unique and makes the `n-4` lower-column `j=2` identities hold identically. This removes `n-5` recurrence variables plus one `V_(n-2)` variable, a reduction of `n-4` independent variables.

## 5. Second row => solve the other lower-column generators

Define `gamma2=B[2,n-1]/B[0,n-1]`, and similarly `q^(2)_r=z^(2r)-gamma2`, `S^(2)_k`, `R^(2)_k`. Row `i=2` constraints, for all `1<=k<=n-3`, become

`q^(2)_k+eta_k S^(2)_k+V_k R^(2)_k=0`.

Eliminate `eta_k` using section 3:

```
V_k * Delta_k = q^(1)_k S^(2)_k - q^(2)_k S^(1)_k
Delta_k = R^(2)_k S^(1)_k - R^(1)_k S^(2)_k.
```

Thus each `V_k` is a rational function if `Delta_k!=0`, removing `n-3` variables while introducing one `gamma2`. This eliminates another `n-4` independent upper rank-one constraints.

## 6. The constant-eight-parameter chart

**Theorem (within the stated open chart).** If the rank-one B-stage identities for the first two lower columns and first two upper rows hold, with `perm[0]=n-1,perm[1]=0,perm[2]=n-2`, then the C-stage entries are rational functions of just

`(t,h0,h1,h2,h_(n-2),beta,gamma1,gamma2)`, **eight variables, regardless of n**.

Conversely, applying these reconstruction formulas on the denominator-nonzero patch makes all `4n-14` selected identities hold identically. The remaining complete B-stage conditions number

`(n-2)(n-3) - (4n-14) = (n-4)(n-5)`.

There is no inference that those remaining equations have a solution, and no inference that a two-stage Fourier FFT is faster than a standard FFT. For `n=8`, this is a **12-rational-equation/8-variable feasibility system**. `general_onion.py` is the exact arithmetic-circuit specification; `onion_peel.py` is an independently written n=8 implementation.

## 7. Exceptional cases are nonempty

The chart excludes vanishing `S^(1)_k`, `Delta_k`, and the boundary 2×2 determinant. This cannot simply be ignored. `exception_s1.py` constructs, over two prime fields, an **invertible C** with nonzero B pivots and nonzero inverse-C corners, satisfying the first 10 selected constraints while `S^(1)_1=0`. It is **not** a full FFT factorization, because the other 20 constraints fail. The previous ZIP's 176-quadratic/184-variable model remains the exception-complete control for *all global separated-generator charts*.

## 8. What is and is not proven

**Proven by algebra:** support lemmas, recurrence, rational reconstruction, equation counts, and equivalence on the listed open locus. The 20-exact-polynomial export passes formal ring cancellation and matches independent direct matrix products. The finite-field tests cover n=8/16/32/64 but do not confer an all-n theorem by themselves; the formulas and elementary proof above do.

**Not proven:** a solution or an inconsistency for the 12 remaining equations at n8, for any n, or for the singular/exceptional branches; a new `o(n log n)` or `O(n)` FFT; a general lower bound for all FFT circuits, arbitrary QS operators, or independently permuted endpoints.
