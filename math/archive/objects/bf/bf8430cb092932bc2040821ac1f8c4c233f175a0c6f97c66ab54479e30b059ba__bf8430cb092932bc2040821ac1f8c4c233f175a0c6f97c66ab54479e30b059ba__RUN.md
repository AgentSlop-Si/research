# Reproduce Hero #17 Phase Union

Requires Python 3.10+; core algorithms and tests use Python standard library only.

From this folder:

```bash
python -m unittest discover -s . -p 'test_*.py' -v
python independent_audit.py
python independent_audit_general.py
```

The first audit writes `audit_results.json`, the second writes `audit_results_general.json`.

Example exact transform (finite field `F_127`, length `N=63`, primitive `omega=9`):

```python
from phase_union_general import make_signal, transform_if_recognized
N,p,omega=63,127,9
x=make_signal(N,p,omega,a=7,modes=[(2,19),(21,30),(51,4)])
X,certificate=transform_if_recognized(x,p,omega,r=3)
print(certificate)
print(X[:8])
```

For unstructured input, `transform_if_recognized` returns `(None,None)` and an ordinary FFT/NTT is still needed. The running-time theorem assumes prime `p` and primitive `omega` are supplied; `phase_table` checks `omega`'s exact order in O(N) steps but **does not run a primality test on p**. All hard-coded test moduli are prime. The output transform is unnormalized with negative exponent.

Modules:

- `phase_union_general.py`: recommended all-length/rank-r linear-work exact certificate engine.
- `phase_union.py`: frozen narrower odd-length/rank-2 precursor for comparison.
- `test_phase_union_general.py`, `test_phase_union.py`: regression suites.
- `independent_audit_general.py`: independent determinant/direct-DFT checks, separate from production evaluator.
- `independent_audit.py`: precursor random/rank/exhaustive checks.
- `RESEARCH.md`: mathematical proof and explicit limitation of the result.
