# Hero #0 / Phase 7 — Exact cross-phase fusion through hidden cyclic-shift rank

**Date:** 10 October 2026  
**Status:** Fully specified conditional exact algorithm and independent algebraic tests. **Not** a worst-case `O(N log log N)` DFT of arbitrary inputs, **not** a newly established literature-first theorem, **not** a bit-complexity or floating-point stability result.

## 0. Research question inherited from Phase 6

Phase 6 gave exact `O(rN)` for inputs whose dechirped block Fourier representation has only `r` globally active Green modes. All `M` modes are nonzero for generic inputs, so Phase 6's support detector cannot accelerate them. Phase 5 proved that simply fusing all `M` Green scans recovers mixed-radix Cooley–Tukey with `O(N log N)` time.

**Phase 7 asks:** can a representation with *all* modes active reuse the same long transform across modes? Answer: **yes for a strictly defined hidden-cyclic-shift-rank family**. The shifts can be unknown to the algorithm. This family can have maximal usual block rank and maximal global Hankel rank, yet it is measure zero among arbitrary complex inputs.

## 1. Exact setting and notation

Let `N=KM`, `K>=M>=2`, both powers of two (the algebra does not require powers of two, but the implementation uses radix-2 NTTs). Let `ζ=exp(2πi/N)` and adopt the **unnormalized negative-exponent DFT**

\[
X_k=\sum_{n=0}^{N-1} x_n\zeta^{-kn},\qquad 0\le k<N.
\]

Choose an invertible chirp slope `a mod N` and shift `β`, and define the `K×M` *dechirped block matrix*

\[
V_{b,t}=x_{bM+t}\zeta^{a\binom t2+(aMb+\beta)t}.\tag{1}
\]

For each column `t`, suppose **some** cyclic-shift amount `g_t in Z/KZ` makes the resulting column-translation matrix

\[
W_{q,t}=V_{(q-g_t)\bmod K,t}\tag{2}
\]

have row/column rank `r`, or equivalently

\[
\boxed{V_{b,t}=\sum_{i=1}^{r}U_i[(b+g_t)\bmod K] H_i[t].}\tag{3}
\]

This is *global shear-corrected (shift-aligned) rank*, not Fourier support sparsity. A fixed shift schedule `g` may be known (rank-r track); for `r=1`, this checkpoint also **recovers arbitrary unknown g** by a linear-time exact detector. Each input is fresh, all `N` outputs are explicitly written, and every relevant root/index/preparation and input scan is charged.

The exact finite-field verifier uses `p=2013265921` and `N|p−1`; this fixed prime supports only finitely many lengths and does **not** by itself prove an asymptotic finite-field theorem. The algebraic proof works over an exact complex field, or compatible fields with primitive roots and char not dividing `N`. The detection uses exact zero/equality tests and input-dependent inversions: it is a **branching algebraic-RAM** result, not the restricted scalar *linear-circuit* model used by many FFT complexity comparisons.

## 2. Main fusion identity — all phase modes can be active

For every output write `k=ell+jK` with `0<=ell<K` and `0<=j<M`. From (1), split `n=bM+t` and use `ζ^M=ζ_K`, `ζ^K=ζ_M`:

\[
X_{\ell+jK}=\sum_{t=0}^{M-1} \zeta^{-a\binom t2-(\beta+\ell)t}\zeta_M^{-jt}
\sum_{b=0}^{K-1}V_{b,t}\zeta_K^{-(\ell+a t)b}.\tag{4}
\]

The column shift in (3) is diagonalized by the long DFT. Set

\[
G_i(u)=\sum_{q=0}^{K-1}U_i[q]\zeta_K^{-u q}.
\]

With `mu_t=(ell+a*t) mod K` we obtain exactly

\[
\sum_bV_{b,t}\zeta_K^{-\mu_t b}
=\zeta_K^{\mu_t g_t}\sum_{i=1}^r H_i[t]G_i(\mu_t).\tag{5}
\]

Substitute into (4):

\[
\boxed{X_{\ell+jK}=\sum_{t=0}^{M-1}Z_\ell[t]\zeta_M^{-jt},}\tag{6}
\]

where

\[
\boxed{Z_\ell[t]=\zeta^{-a\binom t2-(\beta+\ell)t}
\zeta_K^{\mu_t g_t}\sum_{i=1}^r H_i[t]G_i(\mu_t).}\tag{7}
\]

**Execution:** compute the `r` transforms `G_i` of length `K`; for every `ell`, form all `M` values `Z_ell[t]` and compute **one** length-`M` DFT, incorporating contributions of *all* `r` factors *before* that small FFT. This is exact for every input *satisfying (3)*, with no probabilistic step and no omitted mode.

## 3. Complexity theorem with a supplied shift schedule

For any fixed `g`, detect `rank(W)<=r_max` by exact incremental row elimination (pivoted field reduction, validating all entries). At most `r_max` input-dependent inversions are required for normalization. With `K>=M` and `r<=r_max<=M`, detection costs `O((r_max+1)KM)` field operations; a successful rank-`r` factorization costs `O((r+1)KM)`. Input-independent root-power table preparation is `O(N)`.

The exact evaluator from (6) has cost

\[
O(rK\log K)+O(rKM)+O(KM\log M)+O(N).
\]

Thus, with `M=Theta(log N)` and a successful rank `r`,

\[
\boxed{T(N,r)=O\!\left(N(r+\log\log N)\right),\quad S(N,r)=O(N).}\tag{8}
\]

In particular `r=O(log log N)` yields `O(N log log N)`; constant rank does as well. The detector can reject at rank `r_max+1` and use a conventional FFT, without falsely claiming an all-input speedup. When `r=M=Theta(log N)` (generic inputs), the same bound is `O(N log N)`.

## 4. Linear-work detection of *unknown* shifts for rank one

For `r=1`, (3) reads

\[
V_{b,t}=h_t f[(b+g_t)\bmod K].\tag{9}
\]

Here the algorithm is **not given `f,h,g`**. Choose the first nonzero column as a reference `f`. An all-zero column corresponds to `h_t=0` and is harmless. For a nonzero column `v_t`, form the ordered nonzero support sites

\[
i_0<i_1<\cdots<i_{s-1}\quad (\mathrm{mod}\ K).
\]

For each successive pair of nonzero sites, including the cyclic closing pair, define a token

\[
\tau_j=\left(d_j,\;\frac{v_{i_{j+1}}}{v_{i_j}}\right),
\quad d_j=(i_{j+1}-i_j)\bmod K
\]

and set `d_j=K` in the single-support-site case. This is a *cyclic projective support-gap signature*. Multiplying the entire column by any nonzero scalar preserves the tokens; cyclically shifting the column simply rotates the token sequence.

**No division is needed for token comparison.** Treat each ratio as an ordered numerator/denominator pair and test `(a/b)=(c/d)` using `ad=bc`. The denominators are nonzero by definition of the support sites, so this equality is transitive and KMP string matching applies.

Run KMP against the doubled reference token sequence. One match identifies the support-index offset `g_t` in `O(K)` worst-case time, even if the original vector has zeros. Matching every support gap and adjacent nonzero ratio is *sufficient*, because equal gaps align the zero pattern and the equal ratios telescope into one common scalar factor. An independent full-coordinate multiplication-only certificate checks the recovered proportionality.

For each nonzero column pick one supported index `j_t`; then `h_t=V[j_t,t]/f[(j_t+g_t) mod K]`. All denominators are nonzero and a single **batch inversion** (prefix products, one field inversion, suffix products) computes every `h_t` using `O(M)` field multiplications and **one** inversion. Zero columns have `h_t=0`.

Total hidden-shift detection cost, including dechirping and certification: `O(KM)=O(N)` field arithmetic, comparisons and random-access operations, one inversion, and `O(N)` memory. Combining with §2 gives:

\[
\boxed{\textbf{Theorem (conditional, exact):}\qquad
 T(N)=O(N\log\log N)\quad\text{for all inputs of the form (9),}\ }
\]

with arbitrary *unknown* shifts `g`, including zero patterns, full explicit outputs, and charged recognition. The `N`-DFT is exact in its algebraic field. If no certificate exists, the detector **rejects**; it does not approximate an arbitrary input or falsely output a short result.

## 4B. Graph-union extension: discover `r` hidden templates in `O(rN)`

The rank-one template in (9) need not be the same across all columns. Suppose there are `r` unprovided reference sequences `f_i`, and each column belongs to one unprovided cluster `c_t`:

\[
\boxed{V_{b,t}=h_t\,f_{c_t}[(b+g_t)\bmod K],\qquad c_t\in\{1,\ldots,r\}.}\tag{9b}
\]

An adaptive *union of projective cyclic orbits* discovers **both** the templates and the column-to-template graph, in addition to all shifts and column scales:

1. Scan one column. If zero, mark it zero. If nonzero, compare its cyclic support-gap/edge-ratio necklace to each known template by the linear-time detector in §4.
2. If any template matches, record that cluster and the matching shift. If none match, start a new template whose reference is the current column; reject if this would exceed `r_max` templates.
3. After all columns, recover their scales with one batch inversion and verify every dechirped coordinate against the claimed template, shift and scale.
4. Form `r` long basis vectors `U_i=f_i`, with `H_i[t]=h_t` only when `c_t=i` and zero elsewhere. Now (3) holds with the discovered common per-column shift schedule. Execute (6)-(7), combining **all template contributions before** the small length-`M` FFT for each `ell`.

Every attempted template comparison costs `O(K)` field operations and comparisons, and there are at most `r_max` attempts for each of `M` columns. Template storage is `O(r_max K)<=O(N)` since `r_max<=M`. For an accepted instance with `r` discovered templates (or a chosen `r_max=O(log log N)` and ordinary FFT fallback),

\[
\boxed{T(N,r)=O\left(N(r+\log\log N)\right),\quad\text{recognition }O(rN),\quad\text{inversions }1.}\tag{9c}
\]

The implementation `phase7_orbit_union.py` is deterministic and exact over the modular test field, tolerates arbitrary zero patterns, and is not given templates, clustering, shifts or scales. This *is not* the problem of representing every column as a superposition of `r` independent shifted templates: exactly **one** template is assigned to each nonzero column. The latter more general unknown-shift sparse-coding task remains open here.

### Geometry of the union family

For a fixed assignment of nonzero columns to `r` templates and fixed shift schedule, there are `rK+M` parameters: the `r` templates and one scalar per column. At least `r` independent template-scaling gauges are redundant. Thus the dimension is at most `rK+M-r` and its codimension in `C^(KM)` is at least

\[
\boxed{KM-(rK+M-r)=(M-r)(K-1)>0\quad(r<M).}\tag{9d}
\]

The number of cluster assignments and integer shifts is finite for each `N`. Hence **even allowing all such unknown shift/cluster assignments, generic complex inputs cannot be compressed to fewer than M template orbits**. This is a restricted dimension argument; it is not an FFT lower bound.

The exact finite-field suite `test_orbit_union.py` passed 168 synthetic unknown-template cases including one-to-five nontrivial templates, zero-patterned sequences and independently chosen shifts. Further tests verify exact rejection beyond the template budget, corrupted late inputs, duplicate-orbit merging, zero columns and the zero vector.

## 5. Why this is stronger than Phase 6 — full mode support and full original block rank

The ordinary, unshifted dechirped matrix is `V[b,t]=h_t f[(b+g_t) mod K]`. Suppose the shifts `g_t` are pairwise distinct (`K>=M`). Set `f` to a coordinate basis vector and `h_t=1`. Then the `M` columns of `V` are *distinct standard basis columns*, so some `M×M` minor is nonzero. This minor is a polynomial in the free variables `f,h`, hence it is nonzero for almost every continuously chosen complex `f,h`:

\[
\boxed{\operatorname{rank}(V)=M\quad\text{generically}.}\tag{10}
\]

If `D=V F_M` is the array of local Green-phase coefficients, then `F_M` is invertible. Consequently `rank(D)=M`, and **every one of the `M` phase modes is globally nonzero**. Phase 6's sparse-global-support shortcut requires all but `r` columns of `D` to vanish, and therefore cannot accelerate this generic full-mode family.

The same family can also have *maximal global Hankel rank*, not merely full local rank. For `K` even set `H=N/2` and consider the `H×H` Hankel matrix of `x[i+j]` (`0<=i,j<H`). Choose one active time offset `t=M-1`, one shifted-reference support coordinate corresponding to block `b=K/2-1`, and zero every other factor. Then `x[H-1]!=0` and all `x[n]=0` for `n>=H`. The Hankel matrix is anti-triangular with nonzero anti-diagonal, determinant `±x[H-1]^H`. Therefore its determinant polynomial is not identically zero on this rank-one shifted parameterization; for generic continuous `f,h` it has rank `H`. All `N` time samples are also nonzero generically. Combining finite many nonzero-polynomial conditions gives **dense, full-Hankel-rank, full-Green-mode, full-dechirped-rank** signals in the exact hidden-shift family.

This dispels the mistaken inference that “full Hankel rank” or “all phase modes nonzero” implies a signal cannot have a different easily recognized algebraic compression. It does not imply that most inputs have this structure.

### Fully explicit dense, maximal-rank, full-support certificate

The file `explicit_certificate.py` constructs a fully deterministic witness over `F_2013265921`: `N=128`, `K=16`, `M=8`, `a=1`, `β=0`, `g_t=t`, `h_t=t+1`, and `f=(2,1,1,...,1)`. The 128 entries of the resulting original time-domain input are **all nonzero**. Independent exact algorithms certify:

| Property | Exact result |
|---|---:|
| Nonzero original input entries | `128/128` |
| Ordinary rank of original dechirped K×M matrix | `8/8` |
| Global Green-phase modes active | `8/8` |
| Global (N/2)×(N/2) Hankel rank | `64/64` |
| Full length-128 Fourier output vs independent NTT | exactly equal |
| Input-dependent field inversions for hidden-shift recovery | `1` |

These are direct finite-field equalities, not approximate tolerances or distributional claims. They witness all four structural properties **simultaneously** on one explicit nonzero input. The exact modular arithmetic operation count on this small example remains larger than a conventional NTT; the certificate does not establish a finite-size speedup.

## 6. Why it still does *not* solve generic FFT

For any **fixed** shift schedule `g`, the rank-one family (9) depends on `K+M` complex parameters `f,h`, with one redundant global scaling. Thus it has algebraic dimension at most `K+M-1`, compared with the ambient dimension `KM=N`. Because `K,M>=2`, this is **strictly lower dimensional** except the edge case `K=M=2`, where `K+M-1=3<4` anyway. There are only `K^M` possible integer shift schedules at each length, a finite set, so the union is still measure zero in `C^N`.

Likewise, for known-shift rank at most `r<M`, the image of matrices with rank at most `r` has dimension

\[
\boxed{r(K+M-r)<KM,\quad\text{codimension }(K-r)(M-r)>0.}\tag{11}
\]

Even allowing *all possible* cyclic shift schedules cannot cover arbitrary continuous inputs when `r<M`: it is a finite union of proper algebraic varieties. Generic inputs have full shift-corrected rank `M` for **every** schedule, and the method reverts to `O(N log N)`. This is a restricted geometric barrier only; no lower bound for general exact Fourier circuits follows.

## 7. Verification and honest performance accounting

The included `test_phase7.py` makes exact finite-field comparisons for 168 parameterized rank-factor tests plus 48 random **unknown-shift** cases, and `test_orbit_union.py` checks another 168 unknown multi-template cases with full unshifted block rank and all phase modes. It also tests sparse supports, zero columns, the all-zero input, late corruption/rejection, synthetic rank greater than threshold, global Hankel rank, batch inversion, cyclic matching, and direct quadratic DFT oracles at small N. `phase7_complex_check.py` runs 48 complex128 numerical formula tests, maximum recorded relative infinity discrepancy around `1.96e-13`; complex tests do not certify exact complex zero detection or stability.

`scale_audit.py` counts the fresh-input detector and fused exact evaluator on the *same N explicit outputs* as a full NTT baseline. At N=65,536, M=16, rank1 hidden-shift input, the candidate uses about **39.3 counted algebraic ops/input** versus **32.0** in the full NTT baseline (its root exponentiations are excluded). The candidate therefore **does not beat the baseline at these finite lengths**. Timings are also Python-overhead dominated. The improvement claimed is conditional asymptotic scaling, not measured superiority.

The code outputs a strict equality certificate for finite-field Fourier values. The fixed 31-bit prime does not support unbounded N, and `complex128` is not an exact arithmetic representation. Assertions of numerical stability or large-integer multiplication savings need additional proof.

## 8. Next gate (Phase 8)

Find a **generic-input**, computationally recognizable relation across the entire `K×M` array, rather than finitely many lower-dimensional shift-and-template orbits. In particular, prove that a nonunitary global contraction uses `o(M)` long transforms **on every input** with all `M` shift-corrected modes independent; or produce a counterexample to the proposed scheme. Simple low-rank representation, unknown cyclic shifts, and finite dictionaries/orbit unions are all now known to be conditional only.

Another worthwhile specialized goal is to fuse the `K` short `M`-point FFTs in §2 to `O(N)` total **without** uncharged lookup, hidden M-dimensional transforms, or access to precomputed input spectra. This would improve an existing *conditional* family, not the uniform FFT problem.
