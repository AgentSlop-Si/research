# Reproduction commands

Python 3.11+ with `numpy` and `sympy`. No network is needed. Run from this directory:

```bash
python -m unittest -v tests_phase36
python phase36_two_mask.py --output audit_recomputed.json
cmp audit.json audit_recomputed.json
python phase36_phase_rigidity.py
python phase36_scale.py --output large_audit_recomputed.json
cmp large_audit.json large_audit_recomputed.json
sha256sum -c SHA256SUMS.txt
```

The exact `Q(i)` check is `phase36_phase_rigidity.exact_four_point_certificate()`. The full spectral-error bound and phase-rank theorem are proved in `THEOREM.md`. The numeric full matrix verification covers `N<=64`; large numerical tests check only matrix-free Fourier first-cross calibration and the mismatching next column, not full matrix transforms.

Run inherited Phase 35 regression tests by extracting `previous_full_phase35_checkpoint.zip` and running `python -m unittest -v tests_phase35` within its Phase 35 folder.
