# Normalized packet reuse: a fixed-recurrence obstruction and a concrete partial-transform reduction

## Result and scope

Normalization is a genuine change of interface. It defeats the accepted determinant witness; it does **not** make the ordinary packet recurrence cheaper. The useful outcomes here are:

1. **Exact recurrence obstruction.** Any evaluation that obtains the requested normalized packets by pruning and memoizing the usual packet butterfly graph still evaluates at least `N(n-L)/4096` non-input packet nodes. This is a graph-specific statement, not a lower bound against all exact linear algorithms.
2. **A smaller, lossless representation for the high-time part.** All requested packets with `h >= n-L` admit an orthonormal antichain representation `W` with at most `N` rows. This representation, the high-time packet bank, and an explicit partial normalized Fourier transform are interconvertible for `O(NL)` scalar work, with all transforms and output writes paid. At the accepted marker choice, `L = Theta(n/ln n)`, so this overhead is `o(Nn)`.
3. **A concrete alternative avoiding that packet graph.** The partial transform is selected coefficient extraction from a fixed chirp convolution. An integer-triangular chirp formula uses the supplied `N`th root directly; no unnoticed `2N`th-root extension is needed. Ordinary FFT-based convolution still costs `O(Nn)`. A sub-`Nn` selected-convolution primitive would give a sub-`Nn` algorithm for the high-time normalized bank, but no such primitive is supplied here.
4. **No unsupported full-transform equivalence.** A rigorously constructible cover uses `O(L)` modulated instances, not a proved constant number. Whether a bounded number of suitable affine frequency images covers this marker set remains unresolved here. Constant density alone cannot establish that claim.

The result therefore identifies a precise constructive target and excludes one familiar implementation, without claiming a faster full FFT, a universal normalized lower bound, or novelty. The early-time bank, causal inverse, and final full recovery remain separate obligations for a complete algorithm.

## 1. Setup and the changed model

Use the notation of the accepted reports:

    N = 2^n, L = 2^(b-1), r = N/2^b,
    b >= 7, L + 2b <= n,
    b = floor(log2(n/(4 ln n))) for the asymptotic choice.

Let `omega` be the supplied primitive complex `N`th root. Define the unphased normalized packet

    p[h,q,f] = 2^(-h/2) sum_{s = q mod 2^(n-h)} omega^(s f) x_s,
    0 <= q < 2^(n-h), 0 <= f < 2^h.

The actual retained rows differ by known unit phases. Those phases can be removed or restored for one scalar multiplication per row; none changes supports, subspaces, orthogonality, or the graph counts below. Every quantity remains a linear function of the same original `N` inputs.

For `1 <= t <= L` and `h >= 2b+t`, selected labels have the `h`-bit pattern

    0^b  rev_t(k)  0^b  [arbitrary remaining bits],

where `k` starts and ends with `1` and avoids `0^b`. For each selected `(h,f)`, the complete bank of all `q` is present. Write its frequency cylinder as

    C(h,f) = {ell in [0,N): ell = f mod 2^h}.

The normalized bank has unit-norm rows and a Fourier-diagonal Gram whose eigenvalues are event counts. Every square full-dimensional minor after identity augmentation has modulus at most one. Nothing in this report restores the vanished determinant bound by pretending the requested rows are still unnormalized.

The algorithmic accounting is exact scalar arithmetic over a field containing the stated roots and `1/sqrt(2)`, with word-address routing charged. It is not a bit-complexity theorem. A hypothetical new primitive must specify its gates, constants, coefficient preparation, and exact representation costs; packing many scalar values into an uncharged wide word is not allowed.

## 2. The exact normalized recurrence

Put `M = 2^(n-h)`, `a = 2^(h-1)`, and `f = f0 + sigma a`, with `0 <= f0 < a` and `sigma in {0,1}`. Then

    p[h,q,f] = omega^(q sigma a) / sqrt(2)
                 * (p[h-1,q,f0] + (-1)^sigma p[h-1,q+M,f0]).       (1)

To check the phase, split the source residue class into `q mod 2M` and `q+M mod 2M`. In the first class, `omega^(s sigma a) = omega^(q sigma a)`; in the second, the same factor gains `(-1)^sigma`. The factors `2^(-h/2)` and `2^(-(h-1)/2)` supply exactly `1/sqrt(2)`.

For a fixed `q,f0`, the two outputs are a unitary butterfly, with a unit phase on the second output. Normalization changes neither its dependency edges nor the number of distinct source forms. All child coefficients are nonzero. At depth `h`, packets with different `q` have different supports, and packets with the same `q` and different canonical `f` are nonproportional characters on that support. Different depths have different support cardinalities. Consequently ordinary copies or scalar-phase memoization cannot identify distinct nodes of this graph.

This is an actual recurrence, not a future-jet alias. Its cost is assessed next, rather than declared free.

## 3. Ancestor-density lemma for the fixed butterfly graph

**Lemma.** Let `S` be any collection of complete packet banks whose depths satisfy `h >= H0`. Let

    E = union_{(h,f) in S} C(h,f),  m = |E|.

At every depth `0 <= j <= H0`, the complete backward dependency closure of `S` under (1) is exactly

    {(j,q,a): a in pi_j(E), 0 <= q < N/2^j},
    pi_j(E) = {ell mod 2^j: ell in E}.                            (2)

In particular the number of depth-`j` ancestors is

    V_j = (N/2^j) |pi_j(E)| >= m.                               (3)

**Proof.** Repeatedly applying (1) reduces `f` modulo the earlier depth and doubles the number of residue classes. Since every `q` at the selected depth was included, the resulting bank at depth `j` includes every `q < N/2^j`. The possible reduced labels are precisely `pi_j(E)`. Each reduced label accounts for at most `N/2^j` members of `E`, giving (3).

Use `H0 = n-L` and retain only selected banks at those high times. The accepted isolated-marker argument supplies at least `N/4096` frequencies belonging to one of these high banks. Thus every standard ancestor-pruned or memoized recurrence evaluation includes at least

    sum_{j=1}^{H0} V_j >= m H0 >= N(n-L)/4096                    (4)

non-input packet nodes. A one-output recurrence operation must construct each such node; a two-output butterfly can discharge at most two of them. Both conventions give `Omega(Nn)` operations at the marker choice. Unlimited storage, arbitrary scheduling, and sharing identical ancestors are already allowed in this count.

**Boundary.** Equation (4) concerns evaluation of this particular recurrence graph. It does not forbid a different linear factorization, a convolution computation, a nonunitary circuit, or a circuit that combines several stages algebraically without materializing those nodes. Treating (4) as a universal normalized-transform lower bound would be incorrect.

## 4. An orthonormal frontier with fully paid conversion

Let `H_hi` consist only of the normalized selected rows with `n-L <= h <= n`, and let `E` be the union from Section 3. Its output count satisfies

    D_hi <= r(L+1) = N(1/2 + 2^(-b)) = O(N).                    (5)

Frequency cylinders are laminar: two are disjoint or one contains the other. Among selected cylinders keep those not strictly contained in another selected cylinder. They form an antichain `A` of pairwise disjoint cylinders and cover exactly `E`. Equivalently, keep the first selected cylinder encountered on each root-to-leaf path of the low-bit trie. Keep its complete normalized `q` bank. Stack these rows into `W`.

For one cylinder `(h,f)`, its `M=N/2^h` rows are orthonormal because their source supports are disjoint and each row has norm one. Their span is the Fourier subspace on `C(h,f)`. Different antichain cylinders have disjoint Fourier support, hence orthogonal spans. Therefore

    W W* = I_m,  m = sum_{(h,f) in A} N/2^h = |E|,
    N/4096 <= m <= N.                                           (6)

This removes repeated representation, without inventing independent source variables or asserting sublinear rank.

Let `ybar = F_unitary x`. For an antichain bank,

    p[h,q,f] = (1/sqrt(M)) sum_{v=0}^{M-1}
                         omega^(-q v 2^h) ybar[f+v 2^h],        (7)

and, exactly inversely,

    ybar[f+v 2^h] = (1/sqrt(M)) sum_{q=0}^{M-1}
                         omega^(q v 2^h) p[h,q,f].              (8)

These are unitary transforms of size `M <= 2^L`. Running all of them costs

    O(sum_{A} M log2 M + m) <= O(m L + m) = O(NL).              (9)

The data being transformed is paid for: (7) assumes the indicated partial Fourier values are already available; (8) assumes `W x` is already available. Neither formula creates its inputs.

There are two explicit ways to regenerate `H_hi`:

- Apply (7) separately to every selected high-time bank. Its cost is `O(sum_h D_h(n-h+1)) <= O(D_hi(L+1)) = O(NL)`.
- Start from `W` and refine its cylinders with the normalized butterflies (1), saving requested rows. At any one depth, total live bank dimension is at most `m`; there are at most `L` refinements. Charge `O(mL + D_hi)` including copies and all output writes.

Extracting `W` from `H_hi` is only row selection and phase removal, costing `O(m)`. Consequently, in either direction,

    high-time normalized packets <--> partial Fourier values ybar|E

have additive conversion cost `O(NL)`, not a free or zero-cost equivalence.

The mask and antichain can be prepared in `O(N+n)` address work: enumerate all binary strings of lengths at most `n` (fewer than `2N` trie nodes), propagating the finite-state test for `0^b k 0^b` in constant work per node. Use arrays indexed by `(h,f)` to propagate a selected-ancestor flag in the low-bit trie. The two tries have different parent relations; confusing them would invalidate the construction. Phase/root tables use linear recurrences in `O(N+n)` field operations. Working storage is `O(N)` words; saving `H_hi` adds `O(D_hi)` words.

At the accepted marker choice,

    L = Theta(n/ln n), O(NL) = O(Nn/ln n) = o(Nn).              (10)

This genuinely isolates an asymptotically cheaper transition and recovery bill for this part of the interface. It does not show how to obtain the frontier itself faster.

## 5. A second scoped obstruction: simultaneous unitary realization

Ailon's entropy method proves a normalized Fourier lower bound for two-register unitary circuits, a substantially narrower model than general bounded-coefficient linear circuits. See [Ailon 2013](https://arxiv.org/abs/1305.4745).

Its immediate packet specialization is useful: if a unitary circuit ends with all `m` rows of `W` in physical registers, it needs at least `m(n-L)/2` two-register gates. Define the potential as the sum of row entropies of squared coefficient magnitudes. It starts at zero, changes by at most two per gate, and each final `W` row contributes its support exponent `h >= n-L`. Other rows contribute nonnegative entropy. The same proof allows zero-initialized ancillas: an output already having original-input norm one has zero coefficients on ancillary formal inputs.

This specialization requires simultaneous unitary realization. It does not cover free copying into a historical output tape, generic additions, or nonunitary intermediates. It is not used to close the general normalized question. [Ailon 2014](https://arxiv.org/abs/1403.1307) studies broader well-conditioned models; applying those results to a different rectangular or streaming interface would require checking their hypotheses rather than citing them as a universal obstruction.

## 6. Concrete alternative: selected coefficients of a fixed chirp convolution

The convolution route avoids evaluating the packet ancestors from Section 3. It supplies a concrete alternative representation, although its ordinary implementation gives no speedup.

For integers `s,ell`, the exact identity

    s ell = s(s-1)/2 + ell(ell+1)/2
                              - (ell-s)(ell-s+1)/2              (11)

uses only integer exponents. Define

    a_s = x_s omega^(s(s-1)/2),                 0 <= s < N,
    b_(N-1+t) = N^(-1/2) omega^(-t(t+1)/2),    -(N-1) <= t <= N-1,
    c = a * b                                 (ordinary linear convolution).

Then

    ybar_ell = omega^(ell(ell+1)/2) c_(N-1+ell).                 (12)

Both polynomial lengths and extraction indices are explicit: lengths `N` and `2N-1`, product length `3N-2`. The required coefficients are exactly the indices `N-1+E`. Equation (12) follows by expanding the coefficient and substituting (11). No Fourier values are supplied as inputs, and no exponent represents packed input data.

All chirp factors have unit modulus before the normalization in `b`. They can be generated in `O(N)` work by first-order phase-ratio recurrences. This variant requires only `omega`, unlike a square-chirp presentation that may silently adjoin a square root of `omega`. Any extra roots required by the chosen polynomial multiplication implementation must still be supplied or constructed under that implementation's model.

This is within the established chirp/convolution approach; see the primary implementation account [AMD rocFFT, Bluestein design](https://rocm.docs.amd.com/projects/rocFFT/en/docs-6.3.0/design/bluestein.html). Its standard FFT realization uses padded transforms and remains `O(N log N)`; precomputing the fixed kernel's transform does not remove the input transform or inverse transform on each new input.

**Precise conditional algorithm.** Suppose `T_E(N)` is the fully charged cost of computing just the coefficients `c_(N-1+ell)`, `ell in E`, of this fixed-kernel normalized convolution, from arbitrary `N` scalar inputs. Then

    cost(H_hi x) <= T_E(N) + O(NL + N).                         (13)

If `T_E(N)=o(Nn)` in the intended exact scalar model, (13) is a sub-`Nn` high-time normalized packet algorithm. It automatically accounts for reading the original input, diagonal phases, antichain/label preparation, the inverse bank transforms, and the explicit high-time outputs.

**What is missing.** No such faster selected-convolution primitive is derived. Using ordinary polynomial multiplication gives `T_E(N)=O(Nn)`, even if unused coefficients are subsequently discarded. A generic sub-`Nn` multiplication primitive powerful enough to compute the whole chirp product would already give a full sub-`Nn` Fourier algorithm through (12); renaming it cannot be counted as progress. The more specific target is selected coefficient extraction at the explicit marker-cylinder index set. A proposed solution must show where it improves on dense multiplication and charge every stage it still executes.

For the bounded-coefficient model, a convolution implementation must also pay for multipliers whose moduli grow with `N`; a precomputed large kernel-spectrum value is not a free unit-bounded scalar. Equation (13) is conditional on `T_E` being measured in the same declared model. Nothing here claims that an abstract polynomial-multiplication oracle automatically meets that requirement.

## 7. Covering by modulations: an explicit upper bound, no constant-cover claim

The accepted density proof provides a convenient subset. Let `T` consist of the `L`-bit strings whose first and second halves each contain `1 0^b 1`. Its density `alpha` is at least `1/4096`. Put `B=2^(n-L)` and

    E0 = {B t + u: t in T, 0 <= u < B}.

The earlier adjacent-marker construction proves `E0 subset E`. Adding `a B` modulo `N` shifts only the high-block label modulo `2^L`, leaving `u` unchanged.

In a cyclic group of size `Q=2^L`, averaging over all translates shows that some translate of `T` covers at least an `alpha` fraction of any remaining uncovered set. Greedily choosing translates therefore covers the whole group with

    k <= ceil((ln Q + 1)/alpha) = O(L)                          (14)

translates. Exhaustive deterministic construction costs at most `2^O(L)` word operations, which is `N^o(1)` at the marker choice; it is not an uncharged search. This is an existence and constructive upper bound, not an optimal-cover theorem.

Input modulation `x_s -> omega^(a s) x_s` shifts output frequency by `a`. Thus a partial-Fourier oracle of cost `T(N)` on `E` yields a full transform via at most `O(L)` calls and `O(kN)` modulation/routing work. The resulting bound is

    O(k T(N) + kN + 2^O(L)).                                   (15)

It does not turn an arbitrary `o(Nn)` partial algorithm into an `o(Nn)` full algorithm: the factor `k` is unbounded. If the oracle instead supplies high-time packet values, each call also has the paid `O(NL)` conversion, giving only

    O(k T_H(N) + kNL + 2^O(L)).                                (16)

**Unresolved issue.** We neither prove nor disprove a constant-size cover for this specific `E`, under translations or under the affine frequency maps realized by source permutations and modulations. Constant density does not suffice to infer one. Arbitrary bit permutations of frequency labels are not free source permutations in the Fourier transform, so they cannot be inserted as an uncharged way around this gap.

The finite cover examples in the verifier use smaller, separately stated windows. They check a concrete greedy cover and the elementary density lower bound on its size. They do not extrapolate an optimal asymptotic covering number.

## 8. Consequences for a complete exact FFT attempt

The best constructive next target from this analysis is now explicit:

    Prove a fully charged sub-Nn selected-chirp-convolution algorithm
    for indices N-1+E, or a different sub-Nn algorithm for W x.

This target avoids redundant high-time outputs and has only `O(Nn/ln n)` certified transition/recovery overhead. It must involve more than pruning the ordinary scalar packet recurrence, because Section 3 accounts for all of that graph's sharing already.

Even success would first solve the high-time normalized component. A full transform still needs a causal construction or recovery for the remaining information, and a cost bound for all early-time requested outputs if those remain part of the chosen interface. A cheap normalized component does not automatically solve the source-constrained inverse. Likewise, a constant-cover lemma would be useful but is not currently available here; the proved `O(L)` cover can be too expensive.

The frontier is mathematically well-conditioned: its rows are orthonormal and conversions use unitary transforms. That is a property of the representation, not a guarantee that every proposed fast way to compute it is stable. Exact complex scalar arithmetic does not by itself bound word length, roundoff, or input/output encoding. Any claim of exact finite-precision acceleration must separately specify and pay those costs.
