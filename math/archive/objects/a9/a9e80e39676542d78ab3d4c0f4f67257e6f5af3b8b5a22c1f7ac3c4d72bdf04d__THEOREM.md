# Hero #1 — Phase 25: Exact mixed-radix graph and unitary-gate boundary

**Date:** October 10, 2026. **Scope:** an exact, all-input finite-field DFT for `N=3·2^t`, `t≥1`, with cached previews and no repeated arithmetic on fallback. This uses *classical* Good–Thomas/prime-factor decomposition and three-point Winograd-style arithmetic, combined with our Phase 24 deferred graph and the existing Phase 23 full certificate. **There is no claim of a new unrestricted sub-`N log N` FFT.**

## 1. Arithmetic domain and normalization

Let `p` be a prime with `N | (p−1)` and a supplied element `ω∈F_p` of exact multiplicative order `N`. We compute the **unnormalized** DFT

\[
(F_Nx)_k = \sum_{j=0}^{N-1} x_j\,\omega^{jk}.
\]

We count each nontrivial prime-field addition/subtraction and multiplication as one arithmetic operation. Multiplication by `1` is omitted on **both** candidate and reference. Constant precomputation, data copying, integer index arithmetic, and modular representation/bit costs are outside the steady-state field-operation count and explicitly disclosed. We use root `ω_G=ω^3` and `η=ω^G`, with `G=2^t`.

## 2. Exact CRT factorization — all inputs

Let `a=3^{-1} mod G` and `b=G^{-1} mod 3`, and set `e_G=3a`, `e_3=Gb`. Define input indices and output indices by

\[
 j=(e_Gj_G+e_3j_3)\pmod N,\qquad
 k=(3k_G+Gk_3)\pmod N,
\]

with `0≤j_G,k_G<G` and `0≤j_3,k_3<3`. Each map is a bijection. Because `e_G≡1 mod G` and `e_G≡0 mod 3` (and symmetrically for `e_3`),

\[
 \omega^{jk}=(\omega^3)^{j_Gk_G}(\omega^G)^{j_3k_3}.
\]

Consequently, the length-`N` DFT is exactly **three length-`G` DFTs followed by `G` length-three DFTs**, plus input/output permutations. There are no interstage twiddle products. This is the established Good–Thomas prime-factor FFT: <https://en.wikipedia.org/wiki/Prime-factor_FFT_algorithm>.

### A shared exact three-output codelet

For inputs `(a,b,c)` to an unnormalized DFT_3 and a primitive cube root `η`, define

\[
 t=b+c,\quad d=b-c,\quad y_0=a+t,\quad
 m=a-\tfrac12 t,\quad z=\tfrac{\eta-\eta^2}{2}d,
\]
\[
 y_1=m+z,\quad y_2=m-z.
\]

Since `η+η²=−1`, these are exactly the three Fourier outputs. The full graph uses **six field additions and two field multiplications**, assuming the two fixed coefficients are prepared once. When only `y_0` is requested, it needs **two additions**; `y_1` or `y_2` alone uses **four additions and two multiplications**; subsequent requests reuse all precomputed intermediates, and full completion always totals six additions and two multiplications.

## 3. Fully charged steady-state finite-field operation identity

An optimized radix-2 DIF DFT of `G=2^t` samples uses

\[
 C_2(G)=G t + \big(\tfrac{G}{2}t-(G-1)\big)
       =\tfrac32 Gt-G+1
\]

field operations: `G t` additions, `Gt/2` butterflies, with exactly `G−1` unit twiddle multiplications omitted. This is fairer than the earlier Phase 24 count that charged those identity multiplications.

The new complete Good–Thomas evaluator uses

\[
\boxed{C_{GT3}(N)=3C_2(G)+8G
=\tfrac92 Gt+5G+3.}
\]

A comparably optimized Cooley–Tukey `3×G` decomposition uses the *identical* three dyadic transforms and length-three codelet, but its two nonidentity interstage twiddles for each `k_G>0` add exactly `2(G−1)` multiplications. Hence

\[
\boxed{C_{CT3}(N)-C_{GT3}(N)=2(G-1).}
\]

This identity is verified by executing both independent implementations and checking the counters for all benchmark lengths. The gain is **input-independent** but lower-order. Both costs remain `Θ(N log N)`; their ratio approaches `1` as `G→∞`.

**Setup and memory:** the new length-`G` root progression takes `G−1` field multiplications if built cold; the triple constants need 2 field multiplies and 1 subtraction. In the direct CT reference, the current implementation prepares `2G−1` length-`N` root powers for its twiddle lookup, as a separate cold setup. Generator/root primality checks and modular-index arithmetic are excluded from all these field-operation counts. The candidate reads/reindexes `N` input words, copies `N` input-field words into its row sessions, and eventually writes `N` outputs. Its in-memory state includes `N` dyadic working field elements, up to `N−3|J|` backed-up elements for a preview querying the set of dyadic column indices `J`, a `G`-entry root table, `O(G)` codelet and node metadata, and output storage. Transient startup input rows require another `N` words and are released. Precise Python object/byte costs are **not** equated to these word counts.

## 4. Deferred mixed-radix preview: zero arithmetic recomputation

For a nonempty requested set `Q` of output frequencies, map each `k∈Q` to

\[
 k_G = (k\bmod G)3^{-1}\pmod G,\quad
 k_3 = (k\bmod 3)G^{-1}\pmod3.
\]

Let `J` be the distinct `k_G` values. Request the `J` outputs of **each** of the three dyadic graphs using Phase 24's deferred sibling mechanism. Then partially evaluate the corresponding three-point codelets only for the requested `k_3` entries.

Every arithmetic node in the three dyadic graphs and each codelet has a memoized completion state. Any later `full()` evaluates the *missing* nodes only. Since the full graph is fixed and the arithmetic subgraphs do not change when the preview is taken, for **every** input and every nonempty `Q` we have

\[
\boxed{C_{preview}+C_{remaining}=C_{GT3}(N).}
\]

There is no repeated field addition/multiplication. The dyadic row backups are exactly

\[
 \boxed{B=N-3|J|}\quad \text{field elements},
\]

on the present implementation's frozen preview (all three dyadic rows query the same `J`). Its codelet state needs additional `O(|J|)` words. For fixed preview size `|Q|=O(1)`, the arithmetic prefix takes `O(N)` field operations; for general `|Q|=q`, `O(N log(q+1))` arithmetic is sufficient, and completion remains `Θ(N log N)` in the worst case.

## 5. Exact Green certificate on mixed lengths

Retain the Phase 24 identity `F_NP=LF_N` with `L=diag(a+cω^k)+bS` and `r=Px`. The Phase 23 detector requests `R_k=F_Nr[k]` for `k=0..m−1`, `m=2s+2`. It obtains these from the mixed-radix preview of the original input using

\[
 R_k=(a+c\omega^k)(F_Nx)_k+b(F_Nx)_{k-1},
\]

with the cyclic predecessor `N−1` at `k=0`. The original Phase 23 exact all-coordinate cyclic certificate is **unchanged**. On acceptance, its existing solver recovers `F_Nx`; otherwise, the new graph completes itself to return `F_Nx` with no repeated FFT work. Thus arbitrary-input correctness does not require the structure detector to succeed.

Measured **overall** costs are much higher than a native mixed-radix FFT at moderate sizes, even when the sparse-rational certificate succeeds. The exact mixed-radix fast-output preview is useful, but Phase 23's current determinant/resultant compiler is **not** competitive with native Good–Thomas in the tested range. See `COST_LEDGER.md`.

## 6. Graph-gate obstruction: established unitary entropy lower bound

For clarity, this subsection takes place over `C`, not `F_p`. Let `A` be an `N×N` unitary accumulated from pairwise `2×2` unitary row gates on **N registers with no extra workspace**. Define matrix entropy (bits)

\[
 \Phi(A)=-\sum_{i,j}|A_{ij}|^2\log_2|A_{ij}|^2,
\]

with `0log0=0`. For `A=I`, `Φ=0`; for a normalized Fourier matrix, every squared modulus is `1/N`, so `Φ=N log₂ N`.

A `2×2` unitary gate acting on rows `a,b` preserves each column's combined row mass `|A_{aj}|²+|A_{bj}|²`. All untouched-row contributions are constant. As a joint distribution where the column is uniform, the total probability of being in the affected row pair is exactly `2/N` (unitary rows each have unit norm). The conditional choice between the two rows has entropy at most one bit. Therefore **one gate changes `Φ` by at most two bits**, and any such circuit computing normalized DFT needs at least

\[
\boxed{N\log_2N/2\ \text{pairwise unitary gates}.}
\]

The ordinary normalized radix-2 FFT uses exactly this many mixing gates and saturates the bound. A programmatic sanity check reproduces the exact entropy `0,N,2N,...,N log₂N` up to roundoff for `N=2..64`.

**Prior art:** this matrix-entropy lower bound is due to Nir Ailon, *A Lower Bound for Fourier Transform Computation in a Linear Model Over 2x2 Unitary Gates Using Matrix Entropy* (2013): <https://arxiv.org/abs/1305.4745>. Well-conditioned extensions: <https://arxiv.org/abs/1403.1307>. We do not claim a new lower bound, and we do not transfer the lower bound to arbitrary finite-field or nonlinear circuits.

### Rejection criterion for future graph-union ideas

Any proposed Phase 26 graph consisting solely of `N` complex-number registers and 2-input *unitary* mixing gates cannot beat `Ω(N log N)` in gate count, no matter how irregular its graph, how its rows are permuted, or how gates are cached. A plausible all-input breakthrough must legitimately leave this restricted model **and then pay for** global operations, intermediate conditioning, scalar coefficient heights, memory, accuracy, and bit cost. A sparse inverse for a Green operator is not by itself a fast evaluator for `F_N`.

## 7. Scope and novelty

The new project deliverable is the **implementation and verification of a CRT-compatible, no-recomputation preview/certificate pipeline with a fair arithmetic ledger**, not the Good–Thomas identity, the triple codelet, or the entropy barrier, all of which have prior art. All finite-field checks verify the specified exact arithmetic code, not correctness of any unimplemented arbitrary-precision complex-number FFT or asymptotic result. **No unrestricted exact sub-`N log N` algorithm has been established.**
