## Reliable discoveries

1. **Quantum binomial fusion:** For `W=αS^ε+βT^δ`, `W^N=(α^N+β^N)I`. Exact inverse when `Δ=1-α^N-β^N !=0` is a degree-N-1 polynomial in W.
2. **Charged O(N) executor** for arbitrary fresh x using one cyclic recurrence (two passes) including zero diagonal pivots, one input-independent root table, two scalar inversions. Independent full-size test N=65,536.
3. **Signed Weyl span theorem** over C: four orientation families span dimension N² (odd N), N²−1 (even N). The missing atom for even N is `(N/2,N/2)`.
4. **Four-divisible impossibility:** For N divisible by 4, the missing Fourier coefficient is the nonzero quadratic Gauss sum `G_N/N`, so *no finite scalar sum* of the un-gauged four nearest-neighbor magnetic Green families equals F_N.
5. **Mixed-depth cut-rank gate:** For sums of products of nearest-neighbor magnetic Green factors, with diagonal gauges, `rho <= sum(path depths)`; hence exact F_N requires depth budget at least floor(N/2). Not a shared-DAG time lower bound.
6. **N-way twirl fusion** of mixed Green Weyl conjugates, exact and O(N) including all-output writing, even for degenerate one-direction denominator cases.
7. **Escape found:** One long-range stride `S^(N/2)` yields full balanced cross rank N/2 while being O(N). General stride works cycle by cycle. This invalidates extending the cut-rank budget to arbitrary sparse/long-range Green stages.

## Strict stop list

- Never compare these Green outputs to DFT as if they were the same operation.
- Theorems exclude endpoint shifts, arbitrary long-range strides, changing Weyl directions, and arbitrary shared DAGs; don't silently broaden them.
- N-way branch twirls are *real* O(N) sharing, so literal branch-count lower bounds alone do not imply N² running time.
- For even N divisible by 4, 4-orientation span codim1 only; a single additional Weyl monomial gateway can evade it. Do not call it a universal FFT lower bound.
- Don't assume inverse bidiagonal cyclic pivot divisions are safe; code deliberately handles zero d_i.
- The repeated noncommutative words need not be naively enumerated; an O(N²) polynomial dynamic program already beats literal 2^N words. The new executor is O(N) for this operator.
- No proof of historical novelty, numerical stability, or arbitrary-bit integer multiplication.
