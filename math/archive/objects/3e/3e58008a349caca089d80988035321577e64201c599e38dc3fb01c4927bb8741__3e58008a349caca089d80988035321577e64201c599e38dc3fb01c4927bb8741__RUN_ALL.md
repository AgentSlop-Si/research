# Exact regression / certificate commands

From this directory:

```bash
python -m unittest -v test_gate
python uniform_cut.py
python verify_uniform_cut_independent.py
```

The files above require only the Python standard library. A fresh directory unzip reproduces the same results. For independent minimum-cut search, if the optional dependencies are present:

```bash
python network_cut_probe.py
python certify_network.py
```

`certify_network.py` generates larger source-partition certificates for one nonuniform 128-point witness as well as the uniform 64-point witness. The proof itself does not depend on min-cut optimization. `PROOF_CERTIFICATE.md` explains the all-N binary identity and scalar channel count.

To rerun the previous checkpoint's tests, unpack `prior_checkpoint_full.zip` and execute:

```bash
python -m unittest -q test_new_gate
python independent_verifier.py
```

from its `fft_local_annihilator_gate_2026-10-10` directory.
