# Offset-class v12 audit supplement

Start with `audit/OFFSET_V12_AUDIT.md`.

This self-contained supplement preserves the original offset-class v12 archive and two exact prior archives needed for dependency/provenance checks. It contains independent reviewer-owned checks and their saved results. No uploaded module was run or imported. Do not confuse this source with the differently named centered-v12 archive.

- `sources/`: unmodified original ZIPs, read as data only.
- `audit/independent_offset_checks.py`: exact integer/Fraction checks and independent dense numerical operator checks. Requires Python 3 and NumPy.
- `audit/independent_results.json` and `audit/independent_run.log`: executed independent results.
- `audit/prior_source_hashes.json`: earlier source member hashes.
- `verify_provenance.py`: standard-library-only portable verification of original archive hashes, embedded v12 manifest and byte-identical lineage.
- `SHA256SUMS.txt`: hashes of all other supplement files.

From this directory:

    python verify_provenance.py
    python audit/independent_offset_checks.py --output offset_v12_recheck.json
    sha256sum -c SHA256SUMS.txt

The original source's saved pytest and benchmark claims were not independently rerun. The mathematical audit, exact certificates, numerical operator checks and provenance checks are separately labelled in the report. No master research archive or Library item is modified by these files.
