# Independent replay

Run only the newly authored checker in this directory:

    python independent_checks.py

It uses only Python standard-library modules. It does not import or execute any supplied checker, archive source, or external code. Expected result is PASS with the counts recorded in INDEPENDENT_CHECK_RESULTS.json. The run rewrites that results file, so use a copy if preserving this seal. REPLAY_STDOUT.json records the final pre-seal run.

The packed conversion code uses bounded data-word arrays; independent slow algebraic references use Python integers. Python indices are not a fully specified RAM simulation. Finite checks support algebra and boundary handling, not asymptotic complexity or practical speed. The imported Cantor–Kaltofen algorithm is not reimplemented; only its small-ring blocking/recovery reduction is checked here.

INPUT_HASHES_BEFORE.txt and INPUT_HASHES_AFTER.txt match exactly. Source checkers remained inert. SHA256SUMS covers every report/check/result/input-hash file. SEALED_MANIFEST.json records the file inventory, and SEALED_MANIFEST.sha256 authenticates that manifest.
