# Marked-cycle Fourier synthesis — exact research checkpoint

**No sub-N-log-N Fourier algorithm is claimed.** This package constructs an exact arbitrary-input dyadic Fourier transform on one explicit weighted shift-register graph, proves linear-work auxiliary cycle and Green-tree algorithms, and formulates an unproved faster marked-determinant circuit target.

## Contents

- `THEORY.md`: all formulas, proofs, complexity charges, conjecture and boundaries.
- `fixed_graph.py`: actual O(N log N) Fourier executor and O(N) auxiliary algorithms.
- `verify.py`: standalone deterministic independent verification over two prime fields.
- `RESULTS.json`: results from the executed eight-group test suite.
- `SOURCE_LEDGER.md`: archive coverage, provenance, prior-art distinctions and source hashes.
- `SOURCE_INVENTORY.json`: path/hash inventory of 1,935 text occurrences in master archive v17.
- `MANIFEST.sha256`: hashes for the delivered files.

## Reproduce

Use Python 3.10 or later, without external packages:

```bash
python verify.py --output RESULTS.json
```

Example of the implemented exact transform:

```python
from fixed_graph import Field, FixedGraph
plan = FixedGraph(8, Field(65537, 3))
y = plan.fourier([1, 2, 3, 4, 5, 6, 7, 8])
print(y)
```

This example computes a finite-field DFT, not a floating-point complex spectrum. Roots, phase and address tables are constructed by the plan. The evaluator remains Theta(N log N).

## Acceptance condition

The missing algorithm must compute the explicit marked scalar coefficient from Section 5 in o(N log N) fully charged sequential arithmetic. A fast unmarked determinant jet, graph-rank success, dense test oracle, or several successful finite lengths does not satisfy that condition.
