# Independent review of `fft_wordram_integration/sampling.py`

The implementation's essential probability and integer arithmetic are correct under its documented finite-input model.

* A real component has phase 0 or 2 and an imaginary component has phase 1 or 3. Thus the labels are the appropriate signed atoms, including negative imaginary components.
* The cumulative masses are strictly increasing because zero masses are omitted. For an integer ticket `t` in `[0,L)`, `bisect_right(cumulative,t)` chooses exactly the interval of length equal to that atom's mass. In particular, a ticket equal to a cumulative endpoint belongs to the next interval.
* `bits=(L-1).bit_length()` generates tickets from the smallest power-of-two interval containing `[0,L)`. For L=1 this uses zero random bits and the sole ticket is zero. Otherwise acceptance probability exceeds 1/2, and it is exactly 1 when L is a power of two.
* With R independent attempts, the probability of returning any particular accepted ticket t is `sum_(j=0)^(R-1) (1-L/2^b)^j / 2^b`, independent of t. Therefore conditioning on success preserves uniformity. Independent samples remain independent after conditioning on every sample succeeding, since the success event factors over independent random blocks. Hoeffding is consequently applicable conditionally, and the unconditional bad-event probability is at most `delta_cap + delta_MC`.
* The cap calculation uses `Fraction(cap_failure).as_integer_ratio()`, preserving exact rational inputs and the exact value of any supplied binary floating-point input. Its integer `ratio_ceiling` and bit length yield `R >= log2(k/cap_failure)`. Therefore the union bound `k 2^(-R) <= cap_failure` is valid relative to that encoded parameter.
* The formula `4 N exp(-k a^2/4)` correctly accounts for complex modulus using a real/imaginary threshold of a/sqrt(2), followed by a union bound over both components and all N frequencies.
* Rounding k upward to a multiple of the group size reduces sampling error. Creating genuinely new samples for the padding is necessary, and this implementation does so.
* For fixed accuracy and polynomially bounded inverse failure probability, `k=O(log N)` and `R=O(log N)`. The capped random attempts and the binary searches both cost at most `O(log^2 N)`, in addition to the O(N) fresh-input scan. A random draw has O(log N) bits under the input magnitude assumption; it fits a constant number of RAM words.

The experimental `sample_count` uses floating logarithms; `sample_count_integer` now supplies a conservative uniform exact rational alternative. Its integer bit length is `ceil(log2(ceil(4N/delta)))`, which is at least `ln(4N/delta)`. The ceiling of `4*log_upper/error^2` and the subsequent group-size rounding therefore preserve the advertised probability guarantee. For fixed rational error and polynomially bounded failure denominator, these parameter calculations use O(log N)-bit integers; even an explicit Euclidean gcd overhead is negligible in the complete O(N) bound. The common input denominator D should either fit a constant number of words, be fixed, or remain an explicitly documented shared symbolic scale; an arbitrary-size denominator cannot silently receive unit-cost arithmetic. Taking D=1 removes this detail.

Python's seeded pseudorandom generator is suitable for repeatable experiments; a mathematical probability theorem assumes fresh independent random bits. A run using the default fixed seed does not by itself demonstrate a high-probability guarantee against an adversary who knows that seed.
