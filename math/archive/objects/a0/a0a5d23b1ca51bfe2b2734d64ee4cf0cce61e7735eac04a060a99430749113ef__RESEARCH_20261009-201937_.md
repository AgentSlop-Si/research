# Rough-length unequal-block Green recurrence — v14

**Date:** 10 October 2026  
**Status:** exact algebraic executor for one randomized projected signal at every integer length, sharper covariance certificate, exact finite-field checks, and a scoped amplification/exactness barrier. **Not an exact FFT, not a simultaneous machine-precision guarantee, and not a practical speed win.**

## 1. Starting gate

v13 handled a factorization

\[
N=KM
\]

with equal block length \(M\). One randomized projected spectrum was decoded using one \(K\)-point FFT and one length-\(N\) gauged scan. This was especially useful when \(N\) possessed a suitable divisor. Prime and rough lengths remained on the Bessel/Chebyshev fallback.

v14 removes the **divisor requirement from the exact projected-signal executor**. It divides an arbitrary length into nearly equal contiguous blocks and replaces the missing \(K\)-FFT by a fast blocked recurrence for two exponential-sum forcing sequences.

The result should be read carefully:

* every row explicitly emits all \(N\) output values;
* the center of the estimator is the exact DFT;
* one row is still noisy;
* the strongest new guarantee is per-output and bulk/average error, not an all-output \(\ell_\infty\) theorem with vanishing error;
* fixed-precision stability of the high-order recurrence is not proved.

## 2. Arbitrary contiguous partition

Fix an integer length \(N\) and a block count \(B\ge3\). Partition

\[
\{0,1,\ldots,N-1\}
\]

into \(B\) contiguous blocks

\[
I_b=\{s_b,s_b+1,\ldots,s_b+\ell_b-1\},
\]

where

\[
\ell_b\in\{\lfloor N/B\rfloor,\lceil N/B\rceil\},
\qquad
L:=\max_b\ell_b=\lceil N/B\rceil.
\]

For the covariance proof we require

\[
2(L-1)<N.
\]

The balanced partition satisfies this for the nontrivial regimes used here.

Let

\[
\zeta=e^{2\pi i/N},
\qquad
\eta=e^{\pi i/N},
\qquad
h=N\bmod2.
\]

Choose

\[
a\in(\mathbb Z/N\mathbb Z)^*
\]

uniformly and \(\beta\in\mathbb Z/N\mathbb Z\) uniformly. For local position \(0\le t<\ell_b\), define

\[
S_{b,t}
=
\zeta^{a\binom t2+(a s_b+\beta)t}\eta^{ht}.
\]

The block summary and projected signal are

\[
d_b=\sum_{t=0}^{\ell_b-1}S_{b,t}x_{s_b+t},
\]

\[
y_{s_b+t}=\overline{S_{b,t}}d_b.
\]

The estimator is

\[
Y=U_Ny,
\]

where \(U_N\) is the unitary DFT.

### Exact expectation

Inside one block, the coefficient from input position \(u\) to reconstructed position \(t\) contains

\[
\zeta^{\beta(u-t)}.
\]

The average over uniform \(\beta\) is zero unless \(u=t\). Therefore

\[
\boxed{\mathbb E_\beta P_{a,\beta}=I_N}
\]

for every fixed unit \(a\), and hence

\[
\boxed{\mathbb E Y=U_Nx.}
\]

This is an **exact-center** randomized estimator. It is not the exact DFT for one sampled state.

## 3. Exact unequal-block Green recurrence

Define the local chirp polynomial

\[
P_\ell(r)
=
\sum_{t=0}^{\ell-1}
\zeta^{-a\binom t2-r t}\eta^{-ht}.
\]

Since

\[
\binom{t+1}{2}=\binom t2+t,
\]

we obtain

\[
\boxed{
P_\ell(r)
=
1+A_rP_\ell(r+a)-q_\ell(r)
}
\]

with

\[
A_r=\zeta^{-r}\eta^{-h},
\]

\[
q_\ell(r)
=
\zeta^{-a\binom\ell2-r\ell}\eta^{-h\ell}.
\]

For output index \(k\), define

\[
D_k=\sum_{b=0}^{B-1}d_b\zeta^{-k s_b},
\]

and

\[
E_k=\sum_{b=0}^{B-1}c_bd_b\zeta^{-k e_b},
\qquad e_b=s_b+\ell_b\pmod N,
\]

where

\[
c_b=
\zeta^{-a\binom{\ell_b}{2}-a s_b\ell_b-\beta\ell_b}
\eta^{-h\ell_b}.
\]

Substitution gives the exact recurrence

\[
\boxed{
Y_k
=
\frac{D_k-E_k}{\sqrt N}
+
\zeta^{-(k+\beta)}\eta^{-h}Y_{k+a}.
}
\tag{3.1}
\]

Because \(a\) is a unit, the map \(k\mapsto k+a\) is one cycle through all \(N\) outputs.

Set

\[
k_j=aj\pmod N
\]

and define the gauge

\[
G_j
=
\zeta^{a\binom j2+\beta j}\eta^{hj}.
\]

Then (3.1) becomes

\[
\frac{Y_{k_{j+1}}}{G_{j+1}}
=
\frac{Y_{k_j}}{G_j}
-
\frac{F_{k_j}}{G_j},
\qquad
F_k=\frac{D_k-E_k}{\sqrt N}.
\]

The full-cycle multiplier is

\[
G_N=-1
\]

for every integer \(N\): if \(N\) is even then every unit \(a\) is odd, while if \(N\) is odd the parity twist contributes the minus sign. Thus the cycle seed is

\[
\boxed{
Y_0
=
\frac12
\sum_{j=0}^{N-1}\frac{F_{k_j}}{G_j}.
}
\]

All outputs then follow from one balanced prefix scan.

The only missing task is to generate \(D_k\) and \(E_k\) without a length-\(N\) FFT.

## 4. The forcing vectors are order-\(B\) recurrences

The start nodes are

\[
\lambda_b=\zeta^{-s_b}.
\]

Because the blocks are contiguous, the cyclic set of endpoints is the same as the set of starts:

\[
\{e_b\bmod N\}_b=\{s_b\}_b.
\]

Therefore both forcing vectors use the same nodes:

\[
D_k=\sum_b d_b\lambda_b^k,
\qquad
E_k=\sum_b \widetilde d_b\lambda_b^k
\]

for suitable cyclically shifted boundary weights \(\widetilde d_b\).

Let

\[
q(z)=\prod_{b=0}^{B-1}(1-\lambda_b z)
=1+q_1z+\cdots+q_Bz^B.
\]

Every sequence

\[
s_k=\sum_bw_b\lambda_b^k
\]

satisfies

\[
\boxed{
s_k+q_1s_{k-1}+\cdots+q_Bs_{k-B}=0,
\qquad k\ge B.
}
\tag{4.1}
\]

### Blocked power-series solver

Suppose \(B\) consecutive past values are known and the next \(B\) values are unknown. The known past contributes one middle convolution with \(q\). The unknown block solves a lower-triangular Toeplitz system whose inverse is

\[
q(z)^{-1}\pmod{z^B}.
\]

Thus one output block requires a constant number of degree-\(B\) polynomial products.

Let \(\mathsf M(B)\) denote polynomial multiplication cost. After charging characteristic-polynomial construction, reciprocal construction and the first \(B\) sequence values, both forcing vectors can be produced in

\[
\boxed{
O\!\left(
N+rac NB\mathsf M(B)+B^2
\right)
}
\tag{4.2}
\]

arithmetic operations.

With standard FFT polynomial multiplication,

\[
\mathsf M(B)=O(B\log B),
\]

so

\[
\boxed{
W(N,B)=O(N\log B+B^2).
}
\tag{4.3}
\]

The full output, scan workspace and recurrence buffers use

\[
\boxed{O(N+B)=O(N)}
\]

storage.

The saved NumPy implementation uses FFT convolution for the blocked recurrence. The finite-field certificate independently checks the same recurrence exactly.

## 5. Overlap-aware covariance theorem

Fix one output. Averaging over \(\beta\) separates unequal local displacements because

\[
|d-d'|\le2(L-1)<N.
\]

Up to a harmless diagonal Fourier modulation, the one-output covariance is

\[
Q
=
\frac1N
\sum_{d\ne0}D_dB_dD_d,
\]

where \(D_d\) masks coordinates for which displacement \(d\) remains inside the same block, and

\[
B_d=\mathbb E_{a\in(\mathbb Z/N\mathbb Z)^*}v_{ad}v_{ad}^*.
\]

Writing

\[
g_d=\gcd(N,d),
\]

multiplication by \(d\) maps units uniformly onto \(\varphi(N/g_d)\) orthogonal Fourier characters. Hence

\[
\|B_d\|_{2\to2}
=
\frac{N}{\varphi(N/g_d)}.
\]

Since every covariance summand is positive semidefinite,

\[
\frac1N D_dB_dD_d
\preceq
\frac{D_d}{\varphi(N/g_d)}.
\]

For a position \(t\) in a block of length \(\ell\), the allowed positive and negative displacements are

\[
1,\ldots,t
\quad\text{and}\quad
1,\ldots,\ell-1-t.
\]

Define

\[
w_d=rac1{\varphi(N/\gcd(N,d))}
\]

and

\[
\boxed{
V_{\rm ov}(N;\ell_0,\ldots,\ell_{B-1})
=
\max_{b,t}
\left(
\sum_{d=1}^{t}w_d
+
\sum_{d=1}^{\ell_b-1-t}w_d
\right).
}
\tag{5.1}
\]

Then

\[
\boxed{
\mathbb E|Y[k]-(U_Nx)[k]|^2
\le
V_{\rm ov}\|x\|_2^2
}
\tag{5.2}
\]

for every input and every output.

### Why this improves v13

The prior triangle certificate counted every positive and negative displacement at full operator norm:

\[
2\sum_{d=1}^{L-1}w_d.
\]

The diagonal-overlap argument counts only displacements that can meet at one coordinate. It is always no larger and can be exactly a factor two smaller.

For equal blocks of length equal to the least prime factor \(p\mid N\), all \(1\le d<p\) are coprime to \(N\), so

\[
\boxed{
V_{\rm ov}(N,p)=\frac{p-1}{\varphi(N)}.
}
\]

This halves the v13 certificate

\[
2(p-1)/\varphi(N).
\]

For a balanced semiprime \(N=pq\), it becomes

\[
\boxed{V_{\rm ov}(N,p)=\frac1{q-1}.}
\]

The asymptotic exponents from v13 are unchanged, but the theorem constant is corrected.

## 6. Prime and rough lengths

If \(N\) is prime, every nonzero displacement is coprime to \(N\), so

\[
w_d=\frac1{N-1}.
\]

Every coordinate in a block of length \(\ell\) has exactly \(\ell-1\) allowed nonzero displacements. Hence the balanced partition satisfies

\[
\boxed{
V_{\rm ov}(N,B)
=
\frac{\lceil N/B\rceil-1}{N-1}
=
\frac1B+O\!\left(\frac1N\right).
}
\tag{6.1}
\]

Combined with (4.3), this gives an exact-center full-output row for prime lengths with tradeoff

\[
\boxed{
W=O(N\log B+B^2),
\qquad
\operatorname{Var}(Y[k])
\le
\left(\frac1B+O(N^{-1})\right)\|x\|_2^2.
}
\]

Examples:

### Polylogarithmic block count

For

\[
B=(\log N)^c,
\]

\[
W=O(N\log\log N+\log^{2c}N),
\]

and each output has RMS error

\[
O((\log N)^{-c/2})\|x\|_2.
\]

### Subpolynomial block count

For fixed \(0<\delta<1\), let

\[
B=\exp((\log N)^\delta).
\]

Then

\[
\boxed{
W=O(N(\log N)^\delta)
=o(N\log N)
}
\]

and the per-output RMS scale is

\[
\boxed{
\exp\!\left(-\tfrac12(\log N)^\delta\right)\|x\|_2.
}
\]

This is a genuine rough-/prime-length improvement **for each fixed output and for average/bulk error**. It is not yet a simultaneous all-output \(\ell_\infty\) theorem.

## 7. Average and bulk-output guarantees

Because \(U_N\) is unitary and each block projector has squared action

\[
P_b^2=\ell_bP_b,
\]

while \(\mathbb E P_b=I\),

\[
\boxed{
\mathbb E\|Y-U_Nx\|_2^2
=
\sum_b(\ell_b-1)\|x_{I_b}\|_2^2
\le
(L-1)\|x\|_2^2.
}
\tag{7.1}
\]

Thus the average squared error per output is at most

\[
\frac{L-1}{N}\|x\|_2^2
\approx
\frac1B\|x\|_2^2.
\]

Let \(Z_\tau\) be the number of outputs with

\[
|Y[k]-(U_Nx)[k]|>\tau\|x\|_2.
\]

From (5.2),

\[
\boxed{
\mathbb E Z_\tau
\le
\frac{NV_{\rm ov}}{\tau^2}.
}
\]

Consequently, with probability at least \(1-\delta\),

\[
\boxed{
\frac{Z_\tau}{N}
\le
\frac{V_{\rm ov}}{\delta\tau^2}.
}
\tag{7.2}
\]

For prime lengths and growing \(B\), an asymptotically vanishing fraction of outputs are inaccurate at any fixed energy-relative threshold. The theorem does not identify those outputs without additional work.

## 8. Two scoped barriers

### 8.1 Variance-only simultaneous amplification gate

For prime \(N\), one row has variance factor \(\Theta(1/B)\) and costs \(\Theta(N\log B)\) in the fast recurrence model.

Using only Chebyshev plus an independent coordinatewise median, a constant error threshold has one-row bad probability \(\Theta(1/B)\). To union-bound over all \(N\) outputs, the number of rows must satisfy

\[
R\log B=\Omega(\log N).
\]

The charged work is then

\[
\boxed{
R\,N\log B=\Omega(N\log N).
}
\]

This is a barrier for the **current variance-plus-median proof strategy**, not a lower bound on all robust estimators or all FFT algorithms.

The numerical diagnostics reinforce the issue: one row can have a small per-coordinate variance while placing an order-one outlier at a state-dependent frequency. Medians reduce these outliers, but the saved experiments do not establish a sub-\(N\log N\) simultaneous theorem.

### 8.2 Exact row-combination rank gate

On a block of length \(\ell\), every sampled projector has rank one. Any weighted linear combination of \(R\) such rows has rank at most \(R\) on that block. Therefore

\[
\sum_{r=1}^R w_rP_r=I_\ell
\quad\Longrightarrow\quad
\boxed{R\ge\ell.}
\]

Thus exact cancellation of the random block-projection noise cannot come from a constant number of rows. This statement does not exclude a jointly evaluated nonlinear circuit or a different projector family.

## 10. Numerical and practical boundary

The blocked recurrence is exact algebraically but can be ill-conditioned in ordinary floating point. Its characteristic polynomial has roots on the unit circle, and coefficient magnitudes can grow exponentially with \(B\). In the saved binary64 benchmark:

* \(B\) near \(\log_2N\) remained accurate to roughly \(10^{-8}\) or better at the tested sizes;
* \(B\) near \((\log_2N)^2\) overflowed or lost all useful accuracy.

Therefore the asymptotic recurrence theorem is presently an **exact-complex / exact-field result**. A certified high-precision or stable structured-Vandermonde implementation is still required.

The Python recurrence implementation is also much slower than NumPy FFT at every tested size. It is a proof-of-concept, not a production benchmark victory.

## 11. Prior-art boundary

The following ingredients are classical:

* power-series reciprocal and division in time comparable to polynomial multiplication;
* fast polynomial convolution;
* linear-recurrence and rational-generating-function methods;
* chirp-\(z\) / geometric-progression transform techniques;
* random rank-one projection and median amplification ideas.

The project-specific result is the combination of:

1. an unequal-block unit-step-chirp Green recurrence;
2. two shared-node exponential forcing sequences;
3. a blocked power-series forcing evaluator;
4. the overlap-aware Ramanujan covariance certificate.

A limited literature search is not a novelty proof, so no priority claim is made.

## 12. Exact next gate

v14 removes the divisor obstruction from the **one-row exact-center executor**, but exposes a sharper finish-line problem:

> Find a robust all-output decoder that exploits the structured, moving outlier pattern across a constant or sublogarithmic number of unequal-block rows, without reverting to the variance-only union bound.

Equivalently, either:

* prove and exploit higher-order joint structure of the error vector;
* design a projector with enough independent block randomness while preserving a joint \(o(N\log N)\) forcing evaluator;
* or abandon the rank-one block projector and construct a different exact input-independent circuit.

**No exact universal \(O(N)\) FFT has been established.**
