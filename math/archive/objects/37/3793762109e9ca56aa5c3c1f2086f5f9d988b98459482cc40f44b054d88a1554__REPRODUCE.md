# Portable replay

Python3.9 or later, standard library only.

    python independent_checks.py pencil-review.json
    python -c 'import json; assert json.load(open("pencil-review.json")) == json.load(open("INDEPENDENT_RESULTS.json")); print("EXACT REPLAY PASS")'
    python verify_seal.py

For isolated replay copy only the own checker and `source/RESULTS.json`, `source/CERTIFICATE.json`. These files are read as inert data; no source programs are executed.
