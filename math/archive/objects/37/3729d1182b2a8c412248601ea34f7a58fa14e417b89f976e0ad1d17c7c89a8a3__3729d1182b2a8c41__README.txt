Chirp block decoder and repetition research
9 October 2026

Constructive result: all sketch reconstruction outputs in O(N log(2K)) exact arithmetic for K<=M, with O(N) chirp setup covering every a,b,d and O(M+K) working memory beyond output. This reconstructs the sketch, not the original DFT exactly.

Repeated-sketch analysis: raw means have a spike obstruction; a prime diffuse-input median theorem spends the available decoder saving on repetitions. No arbitrary-input sub-N log N algorithm or novelty is established.

DECODER.md and REPETITION.md give proofs and assumptions. AFFINE_RESONANCE.md supplies the preceding obstruction. tests/ contains independently written NumPy sources and numerical results. Small correctness tests are not a stability or speed benchmark. Original uploaded code was not executed.
