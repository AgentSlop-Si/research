# Growing tables give a fully charged exact binary-input NTT family

Date: 10 October 2026. Status: a mathematical construction and independent finite algebra checks, not a practical benchmark or an external originality claim. The transform engine is the published Frobenius additive FFT. The new work in this report is an explicit word-RAM cost derivation, growing chunk tables, packed basis-conversion ledger, and full cyclic-output materialization.

## 1. Precise result

Let d=2^r, Q=2^d, and N=Q−1. On a random-access word RAM with w=Θ(log(N+2)) bits, Boolean operations, shifts, integer arithmetic/division, and independent random words, there is a uniform algorithm that computes

    X[k] = Σ_(j=0)^(N−1) x[j] g^(jk) in F_(2^d),  0≤k<N,

for every binary input x∈{0,1}^N and a primitive N-th root g in an explicitly specified representation of F_(2^d), using expected O(N log log(N+2)) word operations and O(N) words of space. It explicitly writes N field elements, each d bits. All field construction, table construction, basis conversion, twiddle evaluation, root preparation/verification, input reads, addressing, output expansion, and output ordering are charged.

If g is supplied in the specified field representation, its order is verified and the computation can be deterministic. Alternatively, the algorithm generates and returns a primitive g by a Las Vegas procedure, and computes the transform defined by that returned root. Root generation is independent of the input. There is no approximation or failure probability for the returned answers.

This is an exact cyclic NTT on an infinite restricted length family, with a restricted binary input alphabet. It is not the ordinary complex DFT, not an arbitrary-field-input NTT result, and not a bit-operation o(N log N) claim. Its explicit output already has Θ(N log N) bits. No assertion of research priority is made: the key Frobenius transform is established prior art.

## 2. Explicit field and growing block tables

Construct a tower F_2⊂F_4⊂F_16⊂⋯⊂F_(2^d). At a doubling step K⊂K[u], use

    u²+u+τ = 0,

where τ is the product of the earlier tower generators; at the first step τ=1. The absolute trace of τ is 1 inductively: the relative trace of τu is τ. Therefore each Artin–Schreier polynomial is irreducible. Represent elements by their d binary coefficients in the tower-product basis v_i. The established Cantor-basis properties used below are that v_0=1, W_i=span_F2(v_0,…,v_(i−1)) is Frobenius-stable, and its monic vanishing polynomial s_i satisfies

    s_0(x)=x,  s_(i+1)(x)=s_i(x)²+s_i(x),  s_i(v_i)=1.

Thus s_i has binary coefficients, and s_(a+b)=s_a∘s_b. For k a power of two, s_k(x)=x^(2^k)+x.

For d≥8, partition each d-bit field element into eight positional h=d/8-bit chunks. For each ordered chunk-position pair (i,j), 0≤i,j<8, build the complete table

    T_ij[a,b] = (a shifted to position i) · (b shifted to position j),
    0≤a,b<2^h,

where multiplication is in the tower field. Each output is one d-bit word. The tables have 64·2^(2h)=64 Q^(1/4) entries in total. Slow recursive tower arithmetic builds each entry in poly(d) word operations, for total Q^(1/4)poly(d)=o(Q) preparation and o(Q) words. Small d are fixed base cases.

Bilinearity gives any full field product as the XOR of the 64 table outputs. Operand extraction, key assembly, table addresses and all 64 lookups/XORs cost O(1) word operations. This is a constant depending on the fixed choice of eight chunks, not on d. Squaring uses the same routine. No unit-cost carryless-multiply, field-automorphism oracle, arbitrary-width integer, or free multiplication table is assumed.

The table dimensions grow with N: each chunk alphabet has Q^(1/8) symbols. The complete table for two whole field elements would have Q² entries; the positional bilinear decomposition is what avoids that cost.

## 3. Binary monomial-to-novel-basis conversion, fully charged

Pad the binary coefficient vector to Q entries by adding a zero coefficient at x^(Q−1). Define

    B_j(x) = ∏_i s_i(x)^(bit_i(j)).

These monic polynomials have degrees j. We need the unique binary coefficients c_j such that f=Σ c_j B_j. Binary coefficients remain binary because every s_i has binary coefficients.

A packed conversion can use only contiguous bit-string shifts and XORs. No transposition is implicit. It is useful to allow a coefficient to be an h-bit vector, so a polynomial with n coefficients is one contiguous nh-bit string. Such vector coefficients form an F_2-vector space; the conversion uses only binary scalar additions and is applied componentwise.

### The division identity

For a polynomial of fewer than 2H coefficients, write f=low+x^H high. Divide by x^H+x^R, with R≤H/2. Then

    q = high XOR (high >> (H−R)),
    remainder = low XOR ((q << R) truncated below degree H).

This is exact polynomial long division in characteristic two: the shift operator by H−R squares to zero on a polynomial of degree below H. With h-bit vector coefficients, multiply each shift distance by h. Implementing these operations on arrays of w-bit words costs O(1+Hh/w), including cross-word boundaries and copies.

### Recursive conversion

For n=2^m with m a power of two greater than one, put k=m/2 and D=2^k. First express f as a polynomial in y=s_k(x)=x^D+x, with coefficient polynomials of degree below D. Repeated division by powers

    y^(2^t) = x^(D·2^t)+x^(2^t)

uses the preceding identity. Across all division levels this costs

    O((nh/w)·k + 2^k).

Now recursively convert the upper polynomial in y, treating each D-coefficient block as one hD-bit vector coefficient. Recursively convert each of its D lower coefficient polynomials in x. This is correct because s_(k+i)(x)=s_i(s_k(x)), so the upper novel-basis factors are exactly the missing high-index B_j factors. The base m≤1 needs no nontrivial conversion.

For the volume-dependent cost, normalizing by nh/w gives the recurrence

    V(m) ≤ 2 V(m/2)+O(m),  hence V(m)=O(m log m).

The number of constant-overhead pieces obeys

    J(m) ≤ (1+2^(m/2)) J(m/2)+O(2^(m/2)) = O(2^m).

For the last equality, divide by 2^m; the resulting multipliers are 1+2^(−m/2), whose product over m=2^r,…,2 converges to a constant, and the additive terms have bounded sum. Thus conversion costs

    O((nh/w) m log m+n).

At the top n=Q, h=1, m=d, and w=Θ(d), giving O(Q log d) word operations. This explicitly pays for binary basis conversion rather than treating its O(Qd log d) bit-addition count as free.

## 4. Frobenius representatives and the operation count

Use the established Frobenius additive FFT on the binary novel-basis coefficients. For a subproblem of 2^k coefficients and offset α, a normal node forms

    q0[i] = p0[i] + s_(k−1)(α) p1[i],
    q1[i] = q0[i] + p1[i].

Its pruning state l determines the number of children: at l=0 it has one l=0 child and one l=1 child; at positive power-of-two l it keeps one child, with state l+1; otherwise it keeps both children, each with state l+1. The leaf outputs give one representative from each orbit under a↦a². This is Algorithm 3 of Li–Chen–Kuo–Cheng–Yang (2018); the correctness and Cantor cross-section construction are prior work.

Here is the word-cost derivation, which does not substitute a unit-cost field operation into the paper's dimension-normalized bit bound. Start in state (k,1). At depth t, the number of nodes is

    2^(t−a(t)),  a(t)=#{powers of two in {1,…,t}}.

Each has Θ(2^(k−t)) coefficient work, and 2^(−a(t))≤1/(t+1). Consequently all coefficient work is at most

    O(2^k Σ_(t=0)^(k−1) 1/(t+1)) = O(2^k log(k+1)).

The l=0 chain spawns one such subtree at each smaller k, and their geometric size sum is O(Q log d). Each field operation costs O(1) by Section 2.

Twiddles are also charged. At a node, s_(k−1)(α) can be computed by k−1 repetitions of z←z²+z, taking O(k) word operations. In a (k,1) subtree their total is

    O(Σ_(t=0)^(k−1) (k−t) 2^t/(t+1)) = O(2^k).

Split at t=k/2: the first half is bounded by k·2^(k/2), and in the second half substitute r=k−t and use Σ r/2^r<∞. Summing along the l=0 spine gives O(Q) twiddle preparation. Offsets, state counters, bit tests, and node addressing are included in these bounds.

## 5. Full outputs, primitive root, and cyclic ordering

For each representative α with y=f(α), repeatedly square both α and y. Because f has binary coefficients,

    f(α²)=f(α)².

Store each result in E[α], indexed by its d-bit field representation. All orbits together contain exactly Q points, so orbit expansion costs O(Q) field operations and writes. It returns an explicit full evaluation array, not only representative values or a compressed answer.

Find the distinct prime factors of N by trial division in O(sqrt(N)) integer word operations. Test any proposed g using g^N=1 and g^(N/p)≠1 for every distinct prime p|N. Binary powering and all tests cost O(d²). A uniformly random nonzero element is primitive with probability φ(N)/N. If N has s distinct prime divisors, p_i≥i+1 gives φ(N)/N≥1/(s+1)≥1/(d+1). Thus expected root generation costs O(d³), after the charged trial factorization. A supplied primitive root can instead be verified by the same tests.

Finally iterate a=1,g,g²,…,g^(N−1), writing E[a] as the corresponding ordered NTT output. This costs O(N) field multiplications, array reads, index operations and full-word output writes.

Depth-first evaluation permits O(Q) field-word working space. Packed conversion and its temporary arrays, tables, representative outputs, the full E array, and the final output fit O(Q) words. Input ingestion costs O(N), even when bits arrive one per word.

Total:

    O(Q^(1/4)poly(d) + sqrt(N) + poly(d) + Q log d + Q)
      = O(N log log N) expected word operations.

## 6. What was independently checked

The newly written check_exact_ntt.py imports no uploaded research code. Its exact reference checks use direct polynomial evaluation and independent triangular monomial-basis elimination, not the fast conversion or FFT routine as their own oracle.

- 65,814 exhaustive binary basis-conversion cases through 16 coefficients
- 360 randomized vector-coefficient packing cases, checked lane by lane
- Cantor flag/root properties for d=1,2,4,8
- All 65,536 operand pairs for chunk-product reconstruction in F_256
- Exact full NTT comparisons at N=1,3,15,255, including all binary inputs at N=1,3 and 28 inputs each at N=15,255
- Independently counted recursion units versus actual executed nodes, plus symbolic-size recurrence calculations through d=256

All passed. The checker uses Python arbitrarily large integers to represent bit strings. This verifies the algebra, not a physical w-bit implementation or a practical running-time claim; the word-array cost proof is above. Finite checks are not a proof of the infinite family. The known Frobenius FFT's general correctness is imported from the primary paper and is not re-formalized here.

## 7. Prior work and scope

Primary sources inspected:

- Li, Chen, Kuo, Cheng, Yang, Frobenius Additive Fast Fourier Transform, ISSAC 2018: https://arxiv.org/abs/1802.03932 and https://arxiv.org/pdf/1802.03932 . Sections 2–3 provide Cantor bases, novel-basis conversion and the Frobenius-pruned additive FFT. This report relies on those established facts and separately counts a word implementation.
- van der Hoeven and Larrieu, The Frobenius FFT, ISSAC 2017: https://www.texmacs.org/joris/ffft/ffft.pdf . The general idea of exploiting finite-field Frobenius orbits, including cyclic transforms, predates this construction.
- Alman, Faster Walsh–Hadamard Transform and Matrix Multiplication over Finite Fields using Lookup Tables, SOSA 2023: https://arxiv.org/abs/2211.04643 . Its constant-field theorem explicitly covers fixed-matrix Kronecker powers, so merely replacing Walsh with a fixed small-group Fourier tensor is not a new extension.

The exact synthesis here is distinct from collision caching: it exploits algebraic Frobenius symmetry for every binary input, and the growing tables implement finite-word field products. It does not establish an improvement for arbitrary complex inputs or binary-input complex DFTs. Its length and field restrictions are material. A broader prior-art search and a second proof review are needed before describing any part as novel.
