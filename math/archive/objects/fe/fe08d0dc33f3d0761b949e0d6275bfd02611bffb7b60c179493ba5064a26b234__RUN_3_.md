# Reproduce Phase19 from a clean extraction

Requirements: Python >=3.11, standard library only. No network, numpy, SciPy, compiled NTT extension or precomputed user input is required. Tests use exact modular arithmetic.

From this directory:

```bash
python -m unittest test_phase19 test_inverse test_hybrid -v
python exhaustive_gate.py
python exhaustive_inverse_gate.py
python exact_basis_audit.py
python exact_inverse_basis_audit.py
python benchmark_phase19.py
python benchmark_inverse.py
python benchmark_hybrid.py
```

These produce the checked JSON and log receipts stored in the release. `PRIOR_PHASE18_COMPLETE.zip` is the exact original Phase18 archive, whose source `annihilator_engine.py`, `green_sparse.py` and `rational_forcing.py` are copied byte-identically into this checkpoint. Test the older checkpoint independently after extracting that ZIP and running its `test_phase18.py`. The preceding Phase17 test suite remains nested in its immutable Phase17 archive inside Phase18.

The strongest new source is `blind_inverse.py`; `blind_discovery.py` covers the complementary graph-ratio family; `hybrid_engine.py` wires them together. `THEOREM.md` separates proven completeness, conditional K>=2 recovery, exact all-input soundness, and fallback/worst-case asymptotics.
