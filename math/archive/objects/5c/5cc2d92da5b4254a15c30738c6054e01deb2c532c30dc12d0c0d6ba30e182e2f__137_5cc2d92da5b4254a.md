# Result

A useful combination was found on the approximate branch: the path-Green filter, optimal periodic median and shrinking-error decoder can be joined with **explicit finite-word rounding certificates**. The certificate comes from two inexpensive residual checks, one before the decoder and one after it.

The exact unnormalized Fourier error certificate is

    error <= (73/18)[η M(r)+E+ε_v]+τ,

where r is the fitted Green-filtered residual, E is computed from two tridiagonal solve residuals, ε_v pays quantization, and τ is computed from the Fourier-side rank-two solve residual and certified root error. Exact rational Green denominators are never materialized. A zero fitted residual retains its rounding floor.

The independent implementation supplies integer fixed-point source/target operators, bounded-word root preparation, linear-time median fitting and exact common-denominator certificates. All 33 checks passed: 15 general complex-integer cases, five deliberately constructed near-Green-periodic dense cases, a zero control, and 12 isolated target checks. No uploaded code was executed.

A N=128 constructed dense-integer example has filtered residual mass 13.49352, versus original periodic residual mass 1,128,508. With the same illustrative decoder allowance, its complete certificate is 3.42023 rather than 70,531.75; the added numerical floor is about 2.1e-8. This is conditional structure, not a general improvement guarantee or a benchmark.

All bridge steps, including residual verification and output writes, use O(N) word work at O(log N)-bit precision. Combining them with the already proved O(N) decoder gives a mathematical O(N) pipeline. The program here tests the decoder interface with a direct-DFT oracle; it does not implement the complete growing-parameter decoder. The original exact arbitrary-input all-output sub-N-log-N Fourier goal remains open.

The obvious phase-orbit/affine-defect exact composition was not presented as a new result because the existing ordered-filter framework already permits it. This bounded pass found no new exact universal factorization. No publication novelty or practical speedup is claimed.
