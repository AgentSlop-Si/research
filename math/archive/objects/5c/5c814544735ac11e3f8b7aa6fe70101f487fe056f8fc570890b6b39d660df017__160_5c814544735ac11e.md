# Fresh Boolean FFT — quadratic/cubic high-overlap research

Recovered after an interrupted conversation on October 9, 2026. This code investigates whether Boolean-specific nonlinear algebra permits global sharing for a **fresh, complete exact** Fourier transform. **There is no improved FFT algorithm in this package.**

## Reproduce with standard-library Python 3.11+

```bash
python -m unittest discover -s tests -v
python independent_audit.py
python feature_rank_audit.py
python benchmark_counts.py
python degree_boundary.py
```

Files:
- `degree_boundary.py`: exact NTT reference, quadratic-midpoint recovery, cubic gauges and gradient recovery, global-wedge compression, exact rank verifier.
- `tests/test_degree_boundary.py`: 15 regression tests.
- `independent_audit.py`: independent characteristic-zero rational-number verification.
- `feature_rank_audit.py`: example testing the nonlinear-feature/linear-readout rank condition.
- `benchmark_counts.py`: arithmetic gate counter for expanded and factored cubic gauge and FFT comparator.
- `RESEARCH.md`: proofs, scope, negative findings and next criterion.
- `audit_results.json`, `feature_rank_results.json`, `operation_counts.json`: captured output.

The chosen field is F_998244353. The plain NTT counter does not include root generation and memory movement; **do not** interpret its numbers as full machine complexity. No cached state, threads, or FFT precomputations are supplied to candidate circuits. NTT roots are nevertheless computed by the reference implementation.
