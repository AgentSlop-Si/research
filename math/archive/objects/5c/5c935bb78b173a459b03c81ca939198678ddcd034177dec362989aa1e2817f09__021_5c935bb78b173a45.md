# Independent review: shrinking accuracy and control-variate fusion

The v4 asymptotic schedule is sound after making the machine model and complete cost explicit. Its uploaded prototype does **not** implement the charged lookup cost: it repacks every lane of a cached group vector on every lookup. Reusing our earlier fully built, prepacked guarded table fixes that implementation gap. The improvement remains an approximate all-output transform; exactness does not follow.

## 1. Complete cost before dropping ceiling terms

Write `L=log2 N`, `ell=log2 L`, K for the padded sample count, B for block width, p for descriptor bits, `g=floor(gamma L/p)`, `G=K/g`, q for guarded lane bits, and w=Theta(L). Assume g>=1 and q<=w. Define

    R = ceil(N/B),
    W = ceil(B / floor(w/q)).

With every lookup returning words packed during preprocessing, the complete online bound is

    O(N + sampling(K,N) + R K + R G W).

The factor W already includes a final partial word. Full rows can also be used for the final partial output block: read the prepacked row but emit only its valid outputs. Since `W=O(1+Bq/w)`, a useful expanded bound is

    O(N + sampling(K,N) + N K/B + K
      + (N/B+1)G + (N+B)Gq/w).

For sufficiently large N, `g=Theta(L/p)` and `G=Theta(Kp/L)`. If K and B are polylogarithmic in N, the additional K, G, and B*G*q/w terms are polylogarithmic and hence o(N). This yields the v4 simplified bound

    O(N + N K/B + N K p q/L^2),

provided sampling is charged. The ceil terms are harmless in the stated regimes, but cannot be discarded without the polylogarithmic restrictions.

Integer CDF sampling plus binary search costs O(N+K log N), using the already implemented capped sampler. A sorted-threshold implementation can instead use O(N+K log K) expected word operations; bounded rejection adds O(K log(K/delta)) worst-case attempts plus a declared failure event. These are all O(N) when K is polylogarithmic and delta>=N^(-c). Allocate separate portions of delta to rejection-cap failure and the Hoeffding event.

## 2. Precision, preprocessing, and model repair

Inputs should be signed integer real/imaginary components of O(log N) bits, optionally sharing a common bounded fixed-point denominator. Saying only “finite precision in O(1) words” is insufficient if those words permit an exponent of magnitude exponential in the word size: the exact integer mass sum may then need more than O(log N) bits. Fixed-size experimental binary64 inputs are a separate concrete format; their floating CDF sampler is not an exact integer-mass proof.

For inverse-polynomial-in-log-N accuracy eta, choose power-of-two grids with `Q0=Theta(1/eta)` and `Q1=Theta(B/eta)`, H=Theta(1/eta), and certified trigonometric error O(eta). Then

    p = Theta(log B + log(1/eta)),
    q = Theta(1 + log G + log(1/eta)).

Both are O(ell) in the schedules under review. The certified Machin/Taylor phasor constructor already supplied in `guarded_decoder.py` can run with `b=O(ell)` accuracy bits. Its working precision, angle indices, intermediate products, and guard precision remain O(log N) bits. Its degree and preparation cost grow, but only polynomially in ell. The whole phase grid and each complete group row therefore still require polylogarithmic work. Enumerating every one of at most N^gamma keys costs

    N^gamma polylog(N) = o(N)

time and words for fixed gamma<1. Variable accuracy does not invalidate this preprocessing estimate.

The v4 primitive list omits division even though phase descriptors and fixed-point preparation use it. Our earlier model explicitly includes bounded-word integer division, which is a sufficient repair. Alternatively, the online fixed denominator N can be removed without adding a division primitive. Precompute `mu=floor(2^t/N)` with `2^t` above the maximum descriptor numerator. For `0<=a<2^t`, `floor(a*mu/2^t)` equals `floor(a/N)` or one less. A single remainder comparison and increment correct it. Choose a sufficiently large constant word width so the full product fits; prepare mu by charged binary long division in O(log N) operations. Divisions confined to table construction can be emulated with polynomial-in-log-N overhead without changing its o(N) bound. Output rational pairs can retain a declared shared denominator.

The fresh input, finite-word sampler, full table generation, descriptor arithmetic, every row read, and all outputs must stay in this same model. Exact scalar-field complexity results alone do not establish bounded-word complexity.

## 3. The linear and sub-FFT schedules survive review

For polynomial failure probability, sampling accuracy is

    eta_sample = O(sqrt(L/K)).

Match deterministic quantization error to this scale and take B=Theta(K). With

    K = Theta(L^2/ell^2),

one obtains p,q=Theta(ell), G=Theta(L/ell), W=Theta(L/ell), total online O(N), and error factor O(ell/sqrt(L)). Full cold preprocessing is o(N). The new schedule genuinely improves the fixed-accuracy theorem within the specified approximation model.

With `K=Theta(L^3/ell^3)`, the same calculation gives online `O(N L/ell)` and error `O(ell^(3/2)/L)`. This is o(N log N), with all N approximate outputs written.

There is a useful larger family. Let the allowed online overhead be tau, with `1<=tau<=L`, and use

    K = Theta(tau L^2/ell^2),    B=Theta(K).

For these polylogarithmic schedules p,q remain Theta(ell), and

    T = O(N tau),
    eta = O(ell / sqrt(tau L)).                    (1)

Equivalently, for any `h(N)->infinity` with `1<=h(N)<=L`, take

    T = O(N L/h),
    eta = O(ell sqrt(h)/L).                        (2)

Every such schedule is sub-N-log-N. The uploaded sub-FFT point sets h=ell. A slower-growing h, such as log(ell), gives a smaller error, at a larger but still sub-N-log-N running time. Thus the uploaded point is one useful tradeoff, not a uniquely optimal accuracy. These are upper bounds for this architecture, not global optimality claims.

Within the specific guarded-table cost accounting, linear time and p,q=Theta(ell) permit K on the order of L^2/ell^2. Increasing B beyond Theta(K) cannot asymptotically improve the compulsory O(N) descriptor/output term and increases the descriptor precision. This explains the linear-time balance without claiming a lower bound for different algorithms.

## 4. What the energy statement does and does not mean

The inequality

    L_box(x) <= sqrt(2N) ||x||_2

is correct, so an error `eta L_box(x)/sqrt(N)` implies

    ||Xhat-Ux||_infinity <= sqrt(2) eta ||x||_2.

This is vanishing maximum-coordinate error relative to the signal's Euclidean norm. Calling it simply “relative energy error” can mislead: energy is the squared norm, and this bound does not guarantee a vanishing relative l2 error of the whole output vector. The direct conversion only gives

    ||Xhat-Ux||_2 <= sqrt(2N) eta ||x||_2.

For flat cancellation-heavy inputs with ||x||2=Theta(sqrt(N)), the guaranteed error of each coefficient can still greatly exceed a typical O(1) coefficient. This is stronger than constant coarse error, but remains far from usual FFT roundoff or relative accuracy.

For the exact sampled surrogate before deterministic decoding, unitarity gives the sharper identity

    E ||U(y-x)||_2^2 = (L_box(x)^2-||x||_2^2)/K.

Thus for a flat real unit-magnitude input the relative RMS l2 error of that surrogate is `sqrt((N-1)/K)`. With polylogarithmic K it grows, even while the maximum-coordinate guarantee divided by ||x||2 tends to zero. These are different error metrics, so there is no contradiction.

The coordinate-sampling variance claim is also correct within its stated class. An unbiased one-coordinate estimator has

    E|Z_m|^2 = (1/N) sum_j |x_j|^2/p_j
               >= ||x||_1^2/N.

For K independent samples, mean-square error is `(E|Z_m|^2-|Ux_m|^2)/K`. On flat unit-magnitude data with a target coefficient of size O(1), the numerator is Theta(N), so constant RMS error needs K=Omega(N). This is an RMS statement about independent coordinate-sample means, not a lower bound for all high-probability estimators or all algorithms. Signed real/imaginary sampling has second moment L_box(x)^2/N and obeys the same order of obstruction. The half-length-squared/half-uniform alternative does not improve this worst-case scale.

## 5. Stronger fusion through a certified control variate

Suppose a paid procedure constructs a finite-word template h, its residual `r=x-h`, and a vector H approximating Uh with certified infinity error xi. Apply the shrinking-accuracy algorithm to r using fresh random bits, then output `H + approximate(Ur)`. On the sampling success event,

    ||output-Ux||_infinity
      <= xi + eta_N L_box(r)/sqrt(N)

plus any separately charged final addition/rounding error. If a supplied exact representable template transform gives xi=0, only the residual term remains.

Include h=0 as a candidate and select a candidate only when its exactly measured residual mass is no larger than L_box(x). This gives `L_box(r)<=L_box(x)` without guessing whether a template is useful. Consequently the fusion never worsens the base error bound and improves it by the measured factor

    rho = L_box(r)/L_box(x) <= 1.

In particular, the linear schedule gives `O(rho ell/sqrt(L)) L_box(x)/sqrt(N)`, and every tradeoff (1)-(2) receives the same rho improvement. Directly from the residual one also has `eta_N L_box(r)/sqrt(N) <= sqrt(2) eta_N ||r||2`. Selection and template evaluation must be charged: a fixed number of O(N) candidates preserves the linear schedule; an increasing dictionary does not automatically do so.

This fusion needs a bounded-word evaluator, not just an exact finite-field or abstract complex-scalar algorithm. An algebraic-complex template transform may need rounding; an ill-conditioned recurrence can require more than O(log N) bits. Retain xi unless a stable finite-word implementation or an exactly representable output has been demonstrated. Likewise, approximate source templates must be subtracted at a precision whose residual and error are explicitly accounted for. Finite-field graph identities cannot be imported into a complex probability theorem unchanged.

There is no universal rho=o(1) claim. On inputs well described by an existing graph/periodic/structured template the improvement is real and certifiable; generic flat cancellation-heavy residuals can retain the coordinate-sampling variance obstruction. Exact r=0 is an exact structured-input success, not a worst-case exact FFT theorem.

## 6. Uploaded prototype limitations and concrete repair

The uploaded `packed_decode` caches **unpacked** arrays `(zr,zi)`. For every lookup, it calls `pack_nonnegative_lanes` twice, each visiting B lane values. Thus its online scalar packing work is Theta(R G B)=Theta(NG), rather than the modeled Theta(R G W). This is not cured by caching phasor values. Build and cache the packed rows during full preprocessing, as our `GuardedDecoder` already does.

Other experimental limitations are explicitly separable from the asymptotic theorem: lookup rows are generated lazily; group keys are Python tuples rather than bounded-word integers; transcendental values use NumPy exponentials; mass sampling uses floating probabilities; `g_wordfit=max(1,...)` forces a key group even when the declared gamma-key budget would allow none; and input/output arithmetic is not fully instrumented. These are valid functional experiments but are not an end-to-end execution of the cold Word-RAM theorem.

The last partial block is not a functional cache bug: every earlier occurrence of a key stored a full row, and a first occurrence in the final block cannot later be reused by a larger block. A corrected implementation can simplify this by always storing full B-lane packed rows and ignoring unused final lanes.

`verify_review.py` instruments the uploaded prototype without modifying it, records the repeated scalar packing, checks the exact expanded cost on several schedules, and verifies the norm/error conversions algebraically on finite examples. It does not benchmark asymptotic tables or claim a practical crossover.
