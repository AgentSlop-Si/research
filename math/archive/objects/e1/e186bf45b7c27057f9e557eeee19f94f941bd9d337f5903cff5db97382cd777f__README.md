# Coalesced projected-Fourier experiment

Independent experimental derivative of the supplied `projected_fourier.py`, preserving the original source unchanged under `vendor/`.

The change replaces a single view's chronological event log with at most one pre-query snapshot per changed coefficient or point. It owns its selected-bin projection and reduces integer phase products modulo N before float conversion.

**Result:** 16 bounded tests pass, including a regression explicitly recording a numerical limitation. In the final eight matched-q workloads, this implementation beats none of the fastest alternatives including setup (0/8). One stream-only median is 1.03× faster, too small to claim a robust speedup. It still beats compacted original replay in some scenarios, but the faster rebuild/eager comparators prevent a best-method win. This is a useful negative research result, not a universal speedup or a new FFT complexity theorem.

**Important:** floating-point coalescing can lose small results after severe cancellation. `rebase()` recomputes from current metadata, but is explicit and costs a full projected rebuild. Do not treat incremental output as bitwise-equivalent to chronological updates or a fresh NumPy FFT.

Read `REPORT.md` for the exact-arithmetic argument, honest reclamation bound, all wins/losses, numerical counterexample and reproducibility details.

## Run

From this directory, with Python and NumPy already installed:

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s tests -v
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python benchmark.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python diagnostics.py
```

No external services, downloads or compiled binaries are used. The bounded benchmark completes in a few seconds on the recorded cloud runtime; timings vary.

## Files

- `coalesced_projected.py`: new implementation and matched-q rebuild/eager comparators
- `vendor/projected_fourier.py`: unmodified supplied source; exact provenance in `vendor/PROVENANCE.json`
- `tests/test_coalesced.py`: 16 tests, including an explicit known-limitation regression
- `benchmark.py`: eight workloads, seven randomized-order matched trials each
- `diagnostics.py`: phase accuracy, floating-point drift/cancellation and pending reclamation
- `results/`: raw trials, medians, numeric diagnostics and captured test output
- `REPORT.md`: interpretation and proof notes
