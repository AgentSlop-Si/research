# Portable replay

Requirements: Python3.8+ standard library. Work on a copy if preserving this seal.

1. Run `python verify_baseline_gates.py` and `python verify_baseline_corrections.py`.
2. Each independently authored checker writes its corresponding JSON beside itself. Compare those bytes against BASELINE_GATE_CONTROLS.json and BASELINE_CORRECTION_CONTROLS.json in this sealed package.
3. Run `python verify_package.py` to hash-check every listed package file and all136 source snapshots against their per-row identities.

No uploaded code is executed by these commands. Source snapshots have `.inert.txt` names and are only read as bytes for hashing. SOURCE_QUEUE.json retains the original historical pending labels as provenance; COVERAGE.json supplies the additive current reading status.

PORTABLE_REPLAY.json records an actual replay from a separate temporary directory containing only the two auditor-authored checkers and expected result bytes. These bounded controls are not the historical source suites and do not certify numerical stability, the complete software pipeline, or every claim in the source texts.
