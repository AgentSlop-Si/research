# Hero #1: centered Fourier correction v12

**Date:** 2026-10-09. Independent FFT research, continued from the uploaded v11, Green Phase22 and rank-window checkpoints. CrocSwap was **read for verification methodology only**, not used as the algorithmic route.

## Actual results

1. **Minimax Bessel recentering:** shifting the input support to `(N-1)/(2Q)` halves the largest Jacobi–Anger argument while preserving an exact output carrier identity and the inherited random chirp shared state.
2. **Rank-independent local-fusion bound:** `kappa_H<=B(z_max) A_H(delta_max)`, with `B(z_max)<4.25`. Unlike v11's `(2R-1)A_H`, this does not increase with the global Bessel truncation rank.
3. **Two-phase-factor output carrier:** nearest-grid jumps are 1 or 2, so a balanced prefix product constructs all output corrections in O(N) arithmetic after two phase setups, with an important root-precision qualification.
4. **Validated finite proxy comparison:** at N=511 for normalized deterministic error at most 1e-4, the v11 proxy's best tested pair is (R,H)=(11,2); this v12 construction uses (7,2), reducing the declared arithmetic proxy from 22,068 to 15,160 (31.3%). This is **not** a wall-clock benchmark or exact bit-operation count.
5. **Negative rank gate:** a valid two-interval generalization at N=8 adds no new rejected permutations beyond the saved rank-window gate.

**Boundary:** This is still a **randomized approximation**. Its polynomially shrinking-error work remains `O(N log N/log log N)`, and it has **not** beaten the exact FFT asymptotic bound.

```sh

python experiment.py
python rank_multicut_screen.py
```
