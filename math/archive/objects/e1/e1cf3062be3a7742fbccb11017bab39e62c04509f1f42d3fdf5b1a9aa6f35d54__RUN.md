# Reproduce Hero #1 Phase 23

Install Python 3.11+; no third-party libraries are required.

```bash
cd fft_hero1_phase23
python -m unittest discover -p 'test_*.py' -q
python audit_phase23.py
python benchmark_phase23.py
python build_checkpoint.py
```

The benchmark prints field-operation counts, checked against Phase 22 and a same-root exact Bluestein/Green reference. It is not a wall-clock/bit-time benchmark. The package includes `PRIOR_PHASE22_COMPLETE.zip` unmodified.

Verify source hashes using the contained `MANIFEST.sha256` with `sha256sum -c MANIFEST.sha256` on Unix. The manifest excludes itself and contains each non-cache file in the package. The archive has a top-level `fft_hero1_phase23` directory.
