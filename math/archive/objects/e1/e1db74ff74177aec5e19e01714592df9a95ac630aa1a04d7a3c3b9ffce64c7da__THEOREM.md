# Hero #1 Phase 16 — Weyl–Green forcing equivalence and unitary graph gate

**Date:** 2026-10-10. **Status:** Exact algebraic results with complete finite-field all-basis audits, unitary entropy reproduction, and reproducible code. **No unrestricted exact sub-`N log N` FFT.**

## 1. Model, conventions, and scope

For any integer `N>=2`, use the **normalized complex** Fourier transform

`(F_N x)_k = N^-1/2 * sum_{j=0}^{N-1} omega^(kj) x_j`,

where `omega=exp(-2*pi*i/N)`. Define the cyclic shift `S` and diagonal modulation `D` on N-vectors:

`(S x)_k=x_(k-1 mod N)`,  `(D x)_k=omega^k x_k`.

Consequently `D S=omega S D`, and the exact Fourier intertwining laws are

`F_N S = D F_N`, `F_N D=S^-1 F_N`, `S F_N=F_N D^-1`, `D F_N=F_N S`.

All statements are exact complex-algebra identities. The **finite-field** auditor replaces `F_N` by the unnormalized matrix `F[k,j]=omega^(kj)` over `F_p`, eliminating square-root issues. The same intertwining statements hold. The finite-field tests are correctness evidence for finitely many lengths, **not** a proof of arbitrary-precision numerical stability or all-size runtime.

## Theorem 1. A noncommuting, uniformly conditioned O(N)-solvable Green operator has fully dense Fourier forcing

Set

`L=7 I + 2 S + D`, `B=L F_N`.

**(a) Noncommutation.** For any `N>=2`, `S D != D S` because `omega!=1`. Because both shift and diagonal parts are present, `L` does not commute with either `S` or `D`.

**(b) Uniform conditioning.** Let `E=2S+D`; as `S,D` are unitary, `||E||_2<=3`. The reverse triangle inequality gives `sigma_min(L)>=7-3=4`, while `||L||_2<=7+3=10`. Thus

`cond_2(L)<=10/4=5/2` for *every* N.

**(c) Linear-time exact Green solve.** If `a_k=7+omega^k`, then the equation `Ly=b` is the cyclic first-order recurrence

`a_k y_k + 2 y_(k-1) = b_k`.

Every `|a_k|>=6`, so the recurrence coefficients `-2/a_k` have modulus <=1/3. Write the forward affine solution as `y_k=z_k+h_k c`, with

`z_(-1)=0, h_(-1)=1, z_k=(b_k-2 z_(k-1))/a_k, h_k=-2h_(k-1)/a_k`.

The cyclic condition `c=y_(N-1)` implies `c=z_(N-1)/(1-h_(N-1))`. Because `|h_(N-1)|<=(1/3)^N<1`, this is nonsingular. Compute `z,h` in one pass and restore all `y_k` in one pass: **O(N)** additions/multiplications/divisions, O(N) workspace; root powers and inverses require another O(N) arithmetic operations if generated by recurrence. This is an exact-arithmetic count; bit precision for growing N remains to be charged.

**(d) Explicit dense forcing.** Direct calculation gives

`B[k,j] = N^-1/2 * omega^(k j) * (7+omega^k+2 omega^(-j))`.

For every k,j, `4 <= |7+omega^k+2omega^(-j)| <=10`, so **every one of the N^2 forcing-matrix entries is nonzero**, even though L has only O(N) nonzeros.

**(e) Complexity equivalence.** From the Weyl laws,

`B=L F_N = F_N P`,  where `P=7I+S+2D^-1`.

`P` is a diagonal-plus-cyclic-shift operator and is invertible with the same singular-value bounds as `L`, since `P=F_N^-1 L F_N`. Applying `P` costs O(N), so `B x` is just a Fourier transform of an O(N)-preprocessed arbitrary input. Conversely `F_N x=L^-1 Bx`, and the explicit recurrence evaluates `L^-1` in O(N). For arithmetic circuit complexity `C_F,C_B` under this interface,

`C_F(N) <= C_B(N)+O(N)` and `C_B(N) <= C_F(N)+O(N)`.

Therefore an exact all-input `o(N log N)` algorithm for this B would indeed give the desired `o(N log N)` FFT, but **a fast Green inverse alone offers no such algorithm**. This proves a project-specific rejection gate for a concrete globally coupled, noncommuting, well-conditioned Green proposal. It is NOT a complexity lower bound on unrestricted forcing circuits.

## Theorem 1b. Arbitrary permutation graphs have the same exact forcing barrier

**This strengthens the concrete Theorem 1 from uniform shifts to arbitrary, irregular, cross-block permutation graphs.** Let `pi` be any permutation of `{0,...,N-1}`, with `(P_pi y)_k=y_(pi(k))`. The permutation matrix P_pi is unitary. Set

`L_pi = 7 I + D + 2 P_pi`, `B_pi = L_pi F_N`.

**(a) Arbitrary graph and conditioning.** Because `||D+2P_pi||_2<=3`, `sigma_min(L_pi)>=4`, `||L_pi||_2<=10`, and `cond_2(L_pi)<=5/2`, for *every* permutation and *every* N. In particular, no regular Cayley structure or commuting frames are assumed.

**(b) Exact O(N) inverse through permutation cycles.** Decompose pi into disjoint directed cycles in O(N) time with a visited array; an independent disjoint-set-union (union–find) check may verify these graph components. For each cycle `v_0 -> v_1 -> ... -> v_(r-1) -> v_0`, the equation becomes

`(7+omega^(v_t)) y_(v_t) + 2 y_(v_(t+1))=b_(v_t)`.

Traverse the cycle in reverse order to obtain precisely the first-order predecessor recurrence of Theorem 1(c). One affine recurrence and one scalar cycle-closure correction suffice, requiring O(r) arithmetic and O(r) workspace. Sum of cycle lengths is N; hence preprocessing and inversion together cost **O(N)** exact operations, even when a cycle crosses arbitrary blocks. Nonzero denominators follow from the same bound `|2/(7+omega^k)|<=1/3` and the product around each cycle.

**(c) Forcing remains dense.** Every matrix entry is

`B_pi[k,j] = N^-1/2 * omega^(k j) * [7+omega^k+2omega^((pi(k)-k)j)]`.

The bracket has absolute value between 4 and 10, so **all N² entries are nonzero**, independent of the graph. Nevertheless the dense matrix can be computed with an ordinary FFT followed by L_pi, in O(NlogN) operations; this support statement is *not* an N² lower bound on circuit complexity.

**(d) Exact forcing/FFT equivalence.** `B_pi=L_pi F_N`, so `F_N=L_pi^-1 B_pi`. Both left multipliers are executable in O(N) exact operations; therefore `C_{B_pi}(N)=C_F(N)+O(N)` in the two-way reduction sense. Unlike a constant-size Weyl-polynomial preconditioner, the graph can be fully irregular; the equivalence does not require a sparse Fourier-conjugate of P_pi.

**Union/graph conclusion:** cycle decomposition, DSU, sparse graph adjacency, and a uniformly well-conditioned global sparse Green inverse do not suffice to accelerate arbitrary-input Fourier forcing. This is a broader concrete rejection class, **not** an unrestricted FFT lower bound.

## Theorem 2. General constant-Weyl-atom graph union is still Fourier preconditioning

Let `L= sum_(a,b) c_(a,b) S^a D^b` be any finite Weyl polynomial, with integer positive/negative exponents; scalar coefficients commute with roots. For each monomial, the shift/modulation conjugations above imply

`S^a D^b F_N = F_N D^(-a) S^b`.

Thus for every input,

`L F_N x = F_N [sum_(a,b) c_(a,b) D^(-a) S^b] x`.

Each Weyl atom is a weighted permutation, requiring O(N) scalar operations to apply to arbitrary data; a sum of `q` atoms uses **O(qN)** work (less when matching supports combine). Even arbitrarily noncommuting graph shifts of fixed Weyl-atom width q therefore transform under Fourier conjugation into a sparse input preconditioner of the same width.

**Scope:** It does not prove that computing `L F_N` requires `Omega(N log N)` work; nor does it cover arbitrary non-Weyl-list operators with cheap nonlocal descriptions. A family of q=o(log N) such terms can still be *used* in a better algorithm if a separate, genuinely new faster forcing circuit is found. If both L and L^-1 admit O(N) application, however, computing LF_N is equivalent to computing F_N up to O(N) work by Theorem 1(e).

**Graph interpretation:** `S^a D^b` is a weighted permutation edge set. Graph union, edge sharing, and commutators among a fixed number of such operators alone do not change the requirement to perform the Fourier step.

## Theorem 3. Classical local-unitary entropy barrier (Ailon 2013; reproduced, not new)

For a unitary N-by-N state matrix U, define the matrix-row entropy

`H(U)= -sum_(i,j) |U[i,j]|^2 log2 |U[i,j]|^2`, with `0log0=0`.

Start with the identity (or any permutation): `H=0`. For the normalized Fourier target, `|F_N[i,j]|^2=1/N`, so `H(F_N)=N log2 N`.

A 2-row unitary gate changes only rows r,s. At column j, their total mass `m_j=|U[r,j]|^2+|U[s,j]|^2` is invariant. Given m_j, the within-pair entropy can change by at most `m_j log2 2=m_j` bits; summing columns gives at most `sum_j m_j=2` bits per gate. Hence any exact in-place unitary circuit using only pairwise row-mixing gates and permutations requires

**`gates >= N log2 N / 2`.**

The standard normalized radix-2 FFT with free input bit-reversal uses exactly `N log2 N/2` such gates, and the Phase16 diagnostic checks its increase is **exactly 2 bits per gate in exact arithmetic** (numerically to floating tolerance). Thus the restricted bound is tight. For a unitary mixing gate on at most r rows, entropy can increase by at most `r log2 r`; with such gates all of fixed maximal width r, at least `N log2 N/(r log2 r)` gates are needed. If r grows, its own evaluation cost must also be charged.

This result's source is **Nir Ailon, *A Lower Bound for Fourier Transform Computation in a Linear Model Over 2x2 Unitary Gates Using Matrix Entropy* (2013), https://arxiv.org/abs/1305.4745**. It is emphatically **not a newly proved unrestricted FFT lower bound**, and does not apply to nonunitary/reversible-with-ancilla general circuits, numerical overflow/underflow, classical batched lookup, data-dependent branching, or quantum multi-amplitude gates without checking those models.

### Corollary 3a. Stable approximate unitary graphs retain a near-NlogN gate lower bound

Let U be unitary and suppose `||U-F_N||_F <= eps sqrt(N)` with `0<=eps<=1/2`. For each row i, with squared-entry distributions p_i and the uniform target q, the total-variation distance satisfies

`TV(p_i,q) <= ||U[i,:]-F_N[i,:]||_2`

by Cauchy–Schwarz on `|u_j|^2-|f_j|^2`. The classical Fannes–Audenaert continuity bound gives

`H(p_i) >= log2 N - tv_i log2(N-1) - h2(tv_i)`.

Averaging, using RMS>=mean and concavity of binary entropy, yields

`H(U)>=N[log2 N-eps log2(N-1)-h2(eps)]`.

Dividing by the maximum 2-bit gain per pair gate,

**`gates >= (N/2)[log2 N-eps log2(N-1)-h2(eps)]`**.

An operator-norm guarantee `||U-F_N||_2<=eps` implies the Frobenius hypothesis. The familiar classical entropy continuity theorem is described in Audenaert, *A sharp continuity estimate for the von Neumann entropy* (2007), arXiv:quant-ph/0610146. This derived bound is a simple project-specific corollary of known results, not a new unrestricted theorem.

It **does not apply** to the Phase13 low-rank nonunitary stochastic sketches, nor to a guarantee of small mean-square error at each coordinate without a uniform circuit-operator approximation.

## 5. Relevance to the project goal

This checkpoint provides two explicit restrictions to *avoid rediscovering*:

- A well-conditioned noncommuting cyclic Green solve can be cheap while the forcing remains generically Fourier-hard (in the precise linear-equivalence sense).
- A graph-union network of **only in-place local unitaries** cannot beat the `N log N` pair-gate count; the same holds asymptotically for sufficiently accurate unitary approximations.

The search remains open for all-input exact circuits that are genuinely **nonunitary/nonlocal/global in an algorithmically meaningful sense** without merely hiding an FFT in their forcing, change of basis, inverse or preprocessing. Any such construction must charge intermediate conditioning, precision, memory, routing and root setup. No claim of an exact `o(NlogN)` algorithm is made here.
