# fft_green_packet_separator_v19

Research checkpoint for the exact arbitrary-input FFT project.

## Reproduce

Requires Python 3.11+; the core certificates use only the standard library.

```bash
python run_all.py
python benchmark.py
```

`run_all.py` executes the 8 test groups and regenerates `results.json`.

## Files

- `RESEARCH.md` — theorem statements, proofs, limitations and next gate.
- `CHAIN_CHECKPOINT_2026-10-10_v19.md` — compact handoff.
- `cyclotomic_packet.py` — exact packet fusion and O(N) cycle solver.
- `rational_scan_gate.py` — common-order recurrence rank certificate.
- `separator_inverse_gate.py` — inverse separator and treewidth certificate.
- `test_checkpoint.py` — regression tests.
- `benchmark.py` — packet-fusion microbenchmark; not an FFT benchmark.
- `PRIOR_v18_COMPLETE.zip` — byte-identical predecessor.
