## Reproduce the independent checks

Requirements: Python 3 and NumPy. No uploaded Python module is imported or executed by these scripts. The algebraic checker reads three supplied JSON certificates as data. All scripts resolve paths relative to their own location and write results beside themselves.

From this extracted package directory:

```sh
python3 algebraic/independent_algebraic_checks.py
OPENBLAS_NUM_THREADS=1 python3 chirp/independent_checks.py
OPENBLAS_NUM_THREADS=1 python3 phase15/independent_phase15.py
python3 chirp_audit/independent_streaming_checks.py
```

All four were rerun successfully from this portable layout before packaging. Their results and portable execution logs are included. These checks support the separate mathematical proofs; finite examples do not prove an asymptotic theorem, establish numerical stability, or certify novelty.

The original source scripts are archived for completeness. Their stated regression counts are source-reported, and are not substituted for the independent executions above.

`SHA256SUMS.txt` covers all package files other than itself. Original archive hashes are also repeated in the main audit and source metadata. Library organization and source archives were not modified.
