# Phase 13 — the hidden ℓp obstruction and a Haar–Green escape

**Date:** 2026-10-09. **Status:** Algebraic proof of a restricted lower bound, constructive replacement, finite exact falsifications. **NOT an exact Fourier factorization and NOT a sub-\(N\log N\) algorithm.**

## 0. Research question and model

We continue Phase 12's *own* graph/Green/Cayley route to transform computation. The normalized complex DFT is
\(\widehat F_N[k,j]=N^{-1/2}\omega_N^{kj}\), for \(|\omega_N|=1\). We seek a uniform, all-input, exact implementation with fully charged work. For this proof, a *stage* means precisely the fixed-strength Phase 12 unitary mixer or its inverse, with any choice of path permutations. Any number of coordinate permutations and **unit-modulus** coordinate phase diagonals may be interspersed. The number of full stages is \(t\), each of which has an \(O(N)\) executor.

The phase-12 architecture escaped a constant induced \(\ell_1\) norm budget, but that is NOT sufficient to beat logarithmic stage count. We show why with another norm.

## 1. A general bounded-degree Cayley lemma

Let \(A\) be a real symmetric adjacency matrix whose maximum vertex degree is \(\Delta\), \(\alpha\in\mathbb R\) fixed, and
\[
C_\alpha(A)=(I+i\alpha A)(I-i\alpha A)^{-1}
             =2(I-i\alpha A)^{-1}-I.
\]
For \(1<p<2\), set \(\delta=2/p-1\in(0,1)\). If \(\alpha\Delta\delta<1\), then
\[
\boxed{\|C_\alpha(A)\|_{p\to p}\le1+\frac{2}{1-|\alpha|\Delta\delta}.}
\]
Exactly the same bound holds for its inverse (replace \(\alpha\) by \(-\alpha\)), uniformly for **every graph size** and every labeling.

**Proof.** Since \(A\) is real symmetric, \(e^{itA}\) is unitary and \(\|e^{itA}\|_{2\to2}=1\). The power series, \(\|A\|_{1\to1}\le\Delta\), and submultiplicativity imply \(\|e^{itA}\|_{1\to1}\le e^{|t|\Delta}\). The finite-dimensional Riesz–Thorin interpolation inequality gives
\[
\|e^{itA}\|_{p\to p}\le e^{|t|\Delta\delta}.
\]
Since \(A\) is Hermitian,
\[
(I-i\alpha A)^{-1}=\int_0^\infty e^{-s}e^{i\alpha s A}\,ds.
\]
For \(|\alpha|\Delta\delta<1\), the norm of this integral is at most \((1-|\alpha|\Delta\delta)^{-1}\). Then use \(C=2(I-i\alpha A)^{-1}-I\) and the triangle inequality. \(\square\)

**General consequence.** Any family in which every stage is a bounded number of Cayley transforms of uniformly bounded-degree graphs with fixed finite strengths, composed with coordinate permutations and unit-modulus phases, admits a fixed \(p<2\) and constant \(K<\infty\) such that each stage and inverse have \(\|S\|_{p\to p}\le K\). This rules out a sublogarithmic number of such stages representing the normalized DFT. It does **not** cover strengths, graph degrees, or number of Cayleys per stage growing with \(N\); general shears; non-unit-modulus scalings; or an executor that fuses operations across stages and is not charged per stage.

## 2. Quantitative sharp-enough bound for Phase 12

For the path Cayleys, \(\alpha=1/32\), \(\Delta\le2\). The Neumann bound in \(\ell_1\) and exact \(\ell_2\) unitarity give
\[
\|C_{1/32}(A_{\rm path})\|_{1\to1}\le\frac{1+2/32}{1-2/32}=\frac{17}{15},\quad
\|C_{1/32}(A_{\rm path})\|_{2\to2}=1.
\]
Interpolating gives \(\|C_{1/32}\|_{p\to p}\le(17/15)^\delta\), also for the inverse. For the tree Cayley \(B=C_2(A_T)\), \(\Delta\le3\), and \(p=9/5\) so \(\delta=1/9\), the general lemma gives \(\|B\|_{p\to p},\|B^{-1}\|_{p\to p}\le1+2/(1-6/9)=7\).

The Phase 12 involution
\[
R=\begin{pmatrix}0&B\\B^*&0\end{pmatrix}
\]
has \(\|R\|_{p\to p}\le7\) because its two blocks have disjoint output support. With \(\varepsilon=1/512\),
\[
V=(I+i\varepsilon R)/\sqrt{1+\varepsilon^2},\qquad S=V C_{1/32}(A_1) C_{1/32}(A_2),
\]
we therefore have
\[
\boxed{\|S\|_{p\to p},\|S^{-1}\|_{p\to p}\le K
=(17/15)^{2/9}\frac{1+7/512}{\sqrt{1+512^{-2}}}<1.042260.}
\]
Every coordinate permutation and every diagonal matrix of unit-modulus phases is an \(\ell_p\)-isometry. Hence any \(t\)-stage product \(A_N\) in this class obeys \(\|A_N\|_{p\to p}\le K^t\).

But \(\widehat F_N e_0=N^{-1/2}(1,\dots,1)\), so
\[
\|\widehat F_N\|_{p\to p}\ge\|\widehat F_N e_0\|_p=N^{1/p-1/2}=N^{1/18}.
\]
Therefore an **exact** factorization \(A_N=\widehat F_N\) requires
\[
\boxed{t\ge\frac{\ln N}{18\ln K}>0.9303\log_2N.}
\]
In particular \(t=\Omega(\log N)\). This strengthens the earlier \(t\ge6\) restricted spectral-distance result into a growing-stage obstruction. It is a theorem about these stages and this composition model, NOT a lower bound on arbitrary Fourier algorithms.

## 3. Escape from *every fixed* ℓp norm via a Haar–Green module

The previous tree Cayley is replaced by an **orthonormal Haar synthesis** \(H_m\) on \(m=N/2\) coordinates (here \(N\) is a power of two). Its first column is \(m^{-1/2}(1,\dots,1)^T\), and the other \(m-1\) columns are the wavelets of a balanced binary tree. Haar synthesis and analysis both require \(O(m)\) arithmetic, with \(O(\log m)\) distinct normalization constants. \(H_m\) is a full-rank unitary transformation, not a stored lookup table or rank-one operator.

Define
\[
R_H=\begin{pmatrix}0&H_m\\H_m^*&0\end{pmatrix},\quad
V_H=\frac{I+i\varepsilon R_H}{\sqrt{1+\varepsilon^2}},\quad
S_H=V_H C_{1/32}(A_1)C_{1/32}(A_2).
\]
Because \(R_H^*=R_H\), \(R_H^2=I\), **both** \(S_H\) and \(S_H^{-1}\) are exactly unitary and take \(O(N)\) arithmetic to apply. Moreover \(\|V_H-I\|_2\le\varepsilon+\varepsilon^2/2<1/64\), so the Phase 12 proof of all-order balanced-cut \(\Omega(N)\) robust singular values for the same path pair \(U\) carries over *without change*.

For the standard basis vector \(e_m\) in the second half (Haar scaling coefficient),
\[
\|V_He_m\|_p=\frac{\bigl(1+\varepsilon^p m^{1-p/2}\bigr)^{1/p}}{\sqrt{1+\varepsilon^2}}
\ge \frac{\varepsilon}{\sqrt{1+\varepsilon^2}}m^{1/p-1/2}.
\]
For every fixed \(1\le p<2\), the two path Cayleys and their inverses have uniform \(\ell_p\) norm at most \((17/15)^2\), so the product rule \(V_H=S_HU^{-1}\) yields
\[
\boxed{\|S_H\|_{p\to p}\ge
\frac{\varepsilon}{(17/15)^2\sqrt{1+\varepsilon^2}}\left(\frac N2\right)^{1/p-1/2}.}
\]
The inverse has the same type of bound. This **breaks every fixed-\(p<2\) norm-budget obstruction**, whereas the tree-Cayley variant only broke the \(p=1\) one.

This is a *structural repair*, not a DFT algorithm. The final circuit still has to establish exact Fourier phase coherence; the Haar module by itself changes the norm budget without solving it. The whole device is unitary, but its tridiagonal-solve internal execution is not asserted to be a sequence of O(N) unitary 2-register gates, so published restricted entropy lower bounds cannot be automatically applied to this implementation.

## 4. Exact covariance and the low-rank repair gate

For \(Z e_j=e_{j+1\pmod N}\), \(D_{kk}=\omega_N^k\), and a candidate transform \(A\), define \(\mathcal E(A)=AZ-DA\). Exact Fourier phase coherence requires \(\mathcal E(A)=0\), plus the first-column normalization.

For any additive correction \(E\),
\[
\mathcal E(A+E)=\mathcal E(A)+EZ-DE.
\]
Since \(\operatorname{rank}(EZ-DE)\le2\operatorname{rank}(E)\), the necessary condition for fixing covariance by \(\operatorname{rank}(E)\le r\) is
\[
\boxed{r\ge \frac12\operatorname{rank}\mathcal E(A).}
\]
Over \(\mathbb F_{998244353}\), with an exact primitive \(N\)th root and an exact square root of 2, we find full-rank defects for BOTH variants at sampled \(N=8,16,32,64,128\). Therefore, on those *specific algebraic matrices*, every additive repair imposing covariance has rank at least \(N/2\). This rules out a low-rank **additive patch** for those instances, not multi-stage factorization or a general all-\(N\) theorem.

Nonzero determinants modulo this prime certify nonzero determinants of the corresponding algebraic matrices over characteristic zero, because the finite-field implementation is a reduction of the rational/\(i\)/\(\sqrt2\) arithmetic up to nonzero overall unitary normalizers. All inverses used in the reduction have nonzero modular denominators. The modular \(Q=I+i\varepsilon R\) intentionally omits only the common nonzero scalar \(1/\sqrt{1+\varepsilon^2}\).

## 5. Where we stand

**Proved:** (i) constant-strength bounded-degree Cayley modules cannot generate Fourier using a sublogarithmic number of the above fixed-complexity stages and unit-modulus monomials; (ii) the Haar–Green stage with the same expander path core escapes all fixed \(\ell_p, p<2\) stage norm budgets and retains all-order robust cut ranks; (iii) tested one-stage covariance defects have full rank exactly, preventing low-rank additive repairs in those instances.

**Not proved:** any exact Fourier factorization, any improvement over \(N\log N\), novelty over prior mathematical literature, numerical stability of the extended pipeline, or a lower bound for unrestricted linear circuits.

## 6. Next research gate

The future search must prioritize \(AZ=DA\), not cross-cut rank or norms. Try a *uniform explicitly parameterized* hierarchy with Haar mixing, path Green resolvents, phase diagonals, and cheap inverse operations. Check the full vector identity over cyclotomic fields or modular reductions first. If a candidate fails, use the covariance rank to reject additive patches and identify a new design. If it passes at finite lengths, **still** demand an all-\(N\) identity and fully charged precomputation before considering any asymptotic claim.

## 7. Phase- and permutation-independent two-stage synthesis test

A further *exact algebraic* test avoids trying millions of intermediate phase choices. Suppose two fixed invertible stages \(S_1,S_2\) could be joined by **some arbitrary permutation** \(P\) and **some arbitrary invertible diagonal** \(Q\) to form a Fourier intertwiner \(A=S_2QP S_1\). Then
\[
A Z = D A\quad\Longrightarrow\quad
QP\underbrace{(S_1 ZS_1^{-1})}_{M}(QP)^{-1}
=\underbrace{S_2^{-1} D S_2}_{B}.
\]
Taking diagonal entries removes \(Q\) completely, and \(P\) can only permute them. Thus an **unconditional necessary criterion for these fixed two stages** is
\[
\boxed{\operatorname{multiset}\operatorname{diag}(S_1 ZS_1^{-1})
=\operatorname{multiset}\operatorname{diag}(S_2^{-1} D S_2).}
\]
If the multisets differ, no choice of intermediate permutation and no choice of intermediate diagonal values (even non-unitary scalings) can solve the Fourier covariance equation. This is a *one-way* veto, not a sufficiency test.

`phase_permutation_gate.py` evaluates this in exact finite-field arithmetic. For each \(N=8,16,32,64,128\), all six prescribed first/second stage pairings (tree/tree, tree/Haar, Haar/tree, Haar/Haar, strong-Haar/strong-Haar, strong-Haar/Haar) have **unequal** diagonal multisets, ruling out the entire phase/permutation family for those sampled fixed stages. This covers only those specific finite algebraic matrices and **not** arbitrary stage parameters, arbitrary external monomials, or three-stage products. The result remains useful even when the fixed small-angle spectral-distance veto is lifted by retuning coupling strengths.

This gate can be computed in \(O(N^2)\) work for verification using \(N\) black-box applications of each \(O(N)\)-work forward/inverse stage (rather than enumerating any of the \(N!\) permutations or unknown phase variables). The saved regression verifies its diagonal formulas against independently composed transform applications on every basis vector for \(N=8\).


### Strong-coupling control

The two extra pairings use `StrongHaarEscapeMixerMod`, where each path Cayley uses strength `1/2` instead of `1/32`, and the Haar involution rotation uses `epsilon=1/2` instead of `1/512`. The Phase 12 small-angle five-stage veto does **not** cover this retuned family; its previous robust cross-cut perturbation proof is also **not** being claimed for these parameters. Nevertheless the diagonal-multiset necessary condition rules out the exact two-stage Fourier covariance for all sampled `N=8..128`, even if its intermediate diagonal is allowed **arbitrary nonzero** entries. This shows the gate is useful beyond the near-identity regime. It is still not an all-parameter no-go theorem.
