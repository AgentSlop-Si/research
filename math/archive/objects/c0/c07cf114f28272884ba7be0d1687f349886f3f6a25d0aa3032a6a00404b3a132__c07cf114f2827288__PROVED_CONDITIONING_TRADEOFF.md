# Explicit conditioning certificates for transparent macro FFTs

9 October 2026. Constructive conditional theorem. This develops the supplied proposal; it does not claim literature novelty or independent verification of the underlying #130 exact-DFT theorem.

## Result in one paragraph

A uniform input-linear exact Fourier algorithm with local work A(B)=o(B log B) can be converted into determinant-one, transparent two-bank Fourier exchanges using O(A(B)+B) shears and O(A(B)+B) reused local scratch. A syntactic algebraic-height calculation supplies an explicit finite certificate K(B) for every full-state prefix, including primitive scalar instructions. Processing ONE fiber at a time resets conditioning at every completed fiber and needs only 2N+O(A(B)) data/scratch registers. Choosing a sufficiently slowly growing radix gives o(N log N) arithmetic work and any prescribed efficiently usable condition budget tending to infinity. An explicitly bounded transparent Bluestein wrapper extends the result from powers of two to every length. Under a polynomial bound on the local coefficient printer, an explicit choice gives polylogarithmic full-state conditioning and a fourth-iterated-log arithmetic speedup. This is a conditioning theorem, not a floating-point stability or bit-complexity theorem.

## 1. Exact hypotheses and the model

For B=2^b, assume a deterministic, input-independent program for the normalized Fourier map U_B=B^(-1/2) F_B. Its variable-data part unrolls to a fan-in-two linear DAG with g(B) gates and B designated output reads, with g(B)=O(A(B)+B). Source copying can bound fan-out at linear additional cost if a layer count is wanted; the scalar replay count below needs only fan-in two.

The input-independent coefficients have a shared arithmetic preparation DAG over rational literals and roots of unity in a number field K_B=Q(zeta_D). Every division has a proof that its denominator is nonzero. Write d=[K_B:Q]<=D. Include normalization in this DAG. For B=2^b, adjoining zeta_8 suffices for sqrt(B), so replacing D by lcm(D,8) changes the degree bound only by a constant factor.

Count all local printing, scalar preparation, array work, root extraction and index work. The source #130 all-length construction supplies a local root order D(B)<1024 B^3 before this constant-factor enlargement. The global twiddles are separately unit-modulus. Do not use the degree of the global supplied root for local coefficient heights: these coefficients lie in the local field K_B.

The inactive output bank is initialized to zero once during input loading, before the gate-prefix sequence begins. Borrowed scratch may start arbitrary. No destructive zero assignment is used mid-computation. The condition metric is the spectral condition number of the square defining matrix on ALL input-linear data and scratch registers, treating even the initially-zero bank as formal independent coordinates. Prepared constant registers, address registers and nonlinear scalar-preparation computations are not part of that defining matrix. This is not the rectangular map obtained by restricting to the actual initially-zero auxiliary trajectory.

## 2. Transparent replay closes the workspace bridge

For a linear DAG M:C^e -> C^a with g gates, reserve g scratch coordinates z with arbitrary initial values. Its forward additive sweep is z -> Lz+Tx, where L is unit lower triangular. Output reads have the form Rz+Dx, and RT+D=M.

Run forward sweep, add output reads into target y, and undo sweep. This adds Mx+RLz and restores z. Run the same sweep with direct input-source edges suppressed, subtract its output reads, and undo again. This removes RLz and restores z. Therefore

ADD_M:(x,y,z) -> (x,y+Mx,z)

is an identity on arbitrary independent x,y,z, including correlated actual states. The count is at most 8g+2a elementary shears. The pinned source proves this in its local replay lemma; the calculation above also proves its scalar version without any bounded-fan-out requirement.

Apply ADD_U, ADD_(-U^-1) in the opposite bank direction, then ADD_U again:

(x,y) -> (-U^-1 y, Ux).

Thus the completed local map is

W_U = [[0,-U^-1],[U,0]],

with identity on restored scratch. W_U is unitary and determinant one. It is NOT U direct-sum I. If y starts at zero, the data move to y as Ux and x becomes zero. Order the two banks as (currently active, currently inactive) at each macro stage.

For Fourier matrices U^-1=J U, where J reverses Fourier indices. Thus the inverse uses the same coefficient DAG, an output permutation, and the same gate-count bound. Three replay words use at most

L(B)=24g(B)+6B

shears and 2B+g(B) local coordinates, with shared scratch. Each elementary shear is I+alpha e_j e_i^T, i!=j. Its inverse changes alpha to -alpha. Zero alpha is harmless.

## 3. Explicit coefficient, gate-norm and prefix certificates

Use binary absolute logarithmic Weil height h_2. Its elementary inequalities are

h_2(a +/- b) <= h_2(a)+h_2(b)+1,
h_2(ab), h_2(a/b) <= h_2(a)+h_2(b),
h_2(a^-1)=h_2(a), h_2(conjugate(a))=h_2(a),
h_2(root of unity)=0.

Division requires b!=0. A rational p/q in lowest terms has height log_2 max(|p|,q). From the definition as a sum over places, for every embedding into C,

log_2 max(1,|a|) <= d h_2(a).

The same applies to 1/a when a!=0.

A verifier can therefore annotate the coefficient DAG with INTEGER budgets H:

- H(zeta)=0;
- H(p/q)=ceil(log_2 max(|p|,q));
- H(a +/- b)=H(a)+H(b)+1;
- H(ab)=H(a/b)=H(a)+H(b);
- H(conjugate(a))=H(a).

No eigenvalue calculation, approximate nonzero test, or coefficient evaluation is needed. The nonzero proofs remain part of the primitive's hypotheses.

For a shear E_alpha,

||E_alpha||_2, ||E_alpha^-1||_2 <= 1+|alpha| <= 2^(1+d H(alpha)).

If alpha_1,...,alpha_L is the transparent word, define the integer

E_B = 2 sum_(j=1)^L [1+d H(alpha_j)].

Then EVERY prefix P satisfies

||P||_2 <= 2^(E_B/2),
||P^-1||_2 <= 2^(E_B/2),
kappa_2(P) <= Khat(B):=2^(E_B).

A sharper implementation can use the actual prefix sums. Using the full sum is simpler and certified.

If the coefficient preparation DAG has P arithmetic nodes and rational literals have height at most h, induction gives

max H <= (h+1) 2^P,
E_B <= 2L [1+d(h+1)2^P].

This is an explicit, possibly enormous bound. The exponent E_B has O(P+log L+log d+log(h+1)) binary digits. Store E_B, NOT the expanded integer 2^(E_B). The height pass has polynomial bit work in the printed DAG size, d's bit length and h's bit length; elementary schoolbook arithmetic suffices.

For nonzero coefficients, the same certificate bounds |alpha|^-1. Their degree is at most d; a primitive integer minimal polynomial has coefficient bit lengths at most d+d(h+1)2^P+O(1), using the elementary-symmetric bound on its conjugates. This is a bit-LENGTH upper bound, not a claim that exact field operations have unit bit cost. Repeated squaring can already create exponentially many coefficient bits from a short arithmetic program.

### Scalar-instruction implementation, including multiplication intermediates

A shear is an addition plus a multiplication in the source cost model. Treating it as atomic can conceal intermediate register conditioning. The following explicit expansion removes that issue.

Let H*=max H(alpha_j), A=dH*, and C=2^(A+1). Prepare C by binary exponentiation in O(log(A+2)) field operations and O(log(A+2))-bit exponent bookkeeping. Split every coefficient as alpha=C+(alpha-C). Both parts beta are nonzero: C/2<=|beta|<=3C/2. Prepare their inverses; this inequality proves the new divisions safe.

Implement each beta-shear by three scalar register instructions: source *= beta; target += source; source *= beta^-1. Thus one original shear becomes six instructions, a constant-factor data-work overhead. No temporary multiplication register and no zero test are needed.

For |alpha|<=G and real C>=max(2,2G), the nontrivial two-register prefix matrices, in (source,target) order, include

[[C,0],[C,1]], [[1,0],[C,1]], [[beta,0],[C,1]], [[beta,0],[alpha,1]],

and the final [[1,0],[alpha,1]], with the one-instruction scaling prefixes as well. Direct triangle bounds on these matrices and their explicit inverses give norm and inverse norm at most 4C. Every completed original shear has both norms at most 1+G.

Consequently, with G=2^A, every scalar-instruction prefix of the whole L-shear word has BOTH norms at most

2^[L(A+1)+2].

The valid strengthened certificate is therefore

Escalar_B=2L(A+1)+4, Kscalar(B)=2^(Escalar_B),

for L>=1; the empty word has certificate 1. This includes identity padding directly and does not rely on determinant one during the temporary source scalings. It has the same double-exponential worst-case growth and polynomial-size binary exponent as the earlier certificate. The subsequent work/conditioning tradeoff uses this strengthened certificate when conditioning is measured after every scalar field instruction.

For a whole diagonal-add block (z,w)->(z,w+D z), execute these six-instruction updates one coordinate pair at a time. Those pairs are disjoint. Its prefix norm and inverse norm are bounded by max(1+||D||,4C), NOT by (4C) to the number of coordinates. This observation will matter for the all-length construction below.

## 4. Correct serial reset lemma

Every transparent prefix P is a product of shears, hence det(P)=1. Consequently

sigma_min(P) <= 1 <= sigma_max(P).

Therefore adjoining untouched coordinates does not alter its condition number:

kappa_2(P direct-sum I)=kappa_2(P).

Suppose the completed global map Q is unitary on all data/scratch registers. During one local fiber, after a coordinate permutation, the defining matrix is

(P direct-sum I) Q.

Its condition equals kappa_2(P). When that fiber completes, its full action is W_U direct-sum I, hence the new global map is unitary. The scratch can be reused for the next fiber, even though previous completed fibers used those same scratch addresses: their COMPLETED action on scratch was exactly identity.

This proves Khat(B) bounds every serial macro prefix at shear boundaries, independent of the number of fibers and stages. The strengthened scalar certificate bounds every intervening scalar instruction as well: use its separate norm and inverse-norm bounds for the padded local matrix.

Two necessary qualifications:

1. An arbitrary local condition number alone is insufficient: P=alpha I has local condition 1 but P direct-sum I has condition max(|alpha|,|alpha|^-1). Determinant-one shears supply the missing scale anchor here.
2. Do not run unrelated local prefixes concurrently under this exact K claim. Determinant-one P=diag(4,1/2,1/2) and Q=diag(2,2,1/4) each have condition 8, but P direct-sum Q has condition 16. The proven schedule is serial. Its total arithmetic work is unchanged.

Zero scratch at the end of one actual run is also insufficient: U direct-sum 2I leaves zero scratch zero but amplifies the square full-state condition under repetition. The replay identity restores arbitrary scratch and avoids this error.

## 5. Power-of-two work, roots and space

Let N=2^k and B=2^b with 1<=b<=k. Use standard Cooley-Tukey factorization into floor(k/b) radix-B macro stages, phase twiddles and permutations. Process each stage's N/B fibers serially with W_U; alternate the active data bank. Handle the final r=k mod b binary levels with the ordinary normalized FFT on the active bank.

Unit-modulus twiddles and coordinate permutations are unitary. A normalized two-coordinate butterfly can either be treated as a constant-cost two-register unitary or expanded into a fixed number of scalar operations with a fixed additional prefix bound. The same convention applies to swaps. Take C_0 to bound the SQUARED strong prefix envelope of these fixed implementations, and define K(B)=max(Kscalar(B),C_0). Thus every dyadic prefix has both norms at most sqrt(K(B)) and condition at most K(B), rather than a factor growing with N.

If Cprep(B) denotes charged one-time local compilation/preparation and certificate bit work, the arithmetic/address count is

T(N;B) = O((N/B)(k/b)[A(B)+B] + Nk/b + Nb + Cprep(B) + k).

Equivalently,

T(N;B)/(Nk) = O(A(B)/(Bb) + 1/b + b/k + Cprep(B)/(Nk)).

The 2N data registers plus g(B) reusable scratch are essential. Total data/scratch space is 2N+g(B), not N registers and not (N/B)g(B). Store the printed program and prepared scalars separately and charge their size. If g(B), program size and preparation are polynomial in B and B=N^o(1), total space is O(N).

After choosing B from N and the symbolic local DAG, supply ONE root of order

D_global=lcm(N,D(B),8),

which is at most 8N D(B). Extract the local root and the Nth root by powering. For B=N^o(1), this order is polynomial in N and the exponents have O(log N) bits. Do not repeatedly request a new uncharged root for every block. The specified-root assumption is retained.

## 6. Explicit work-versus-conditioning tradeoff

Assume effectively known constants C,a>0 bound all local printing/preparation/certificate overhead by a polynomial in B and give

log_2 log_2 K(B) <= C B^a

for all sufficiently large powers of two B. The explicit P,L,d,h bound above supplies such constants whenever their printed sizes have polynomial bounds. It does NOT generally give Khat(B)<=exp(poly B); the generic bound is double exponential.

For a target R(N)>2, set x=log_2 log_2 R(N). Choose the largest power of two B not exceeding

(x/C)^(1/a),

also imposing log_2 B <= sqrt(log_2 N) and any polynomial-preparation budget needed for small exceptional sizes. Then K(B)<=R(N). For ordinary explicit budgets tending to infinity this B grows, b/k tends to zero, preparation is negligible, and A(B)=o(B log B) implies T=o(N log N).

For a fully computable but arbitrarily expensive diverging budget function, mere computability does not make evaluating it cheap. An effective qualitative theorem must additionally charge its evaluation or use a globally time-bounded dovetailed selector. The explicit polylog and polynomial examples below need no such oracle.

Insert the source-reported #130 rate

A(B)=O(B (log B)^theta (log log B)^(4-theta)), theta<1.

Write delta=1-theta>0, p=4-theta and L_j(N)=the j-times iterated logarithm, for sufficiently large N.

- If R(N)=(log N)^c with fixed c>0, B=Theta(L_3(N)^(1/a)) up to power-of-two rounding, b=Theta(L_4(N)), and
  T/(N log N)=O(L_4(N)^(-delta) [log L_4(N)]^p + 1/L_4(N) + L_4(N)/log N).
- If R(N)=N^c, b=Theta(L_3(N)) and the same expression uses L_3 instead of L_4.

Both ratios tend to zero. With the very small source exponent saving and enormous constants, these statements do not imply a useful finite crossover. They do provide an explicit proved rate rather than an unevaluated K(B) hypothesis.

A practical certificate-based selector can improve this conservative rate: print candidate local DAGs, compute their actual integer Escalar_B, and accept candidates with max(Escalar_B,ceil(log_2 C_0)) <= floor(log_2 R(N)) plus a total planning/preparation budget. Such an optimization is optional; the displayed choice already proves the conditional theorem.

## 7. All lengths: a bounded transparent Bluestein wrapper

The naive claim that zero-padding, projection and a convolution diagonal are square unitary is false. The following additive construction avoids that claim and never divides by a convolution multiplier.

### 7.1 Uniform constant bound for the normalized chirp multiplier

For any real t and integer N>=1 define

S_N(t)=sum_(u=-N+1)^(N-1) exp(2 pi i [-u^2/(2N)+tu]).

We prove |S_N(t)|<=32 sqrt(N), uniformly in t.

For N>=16 put delta=N^(-1/2). The phase increments

Delta_u=t-(2u+1)/(2N)

are monotone, spaced 1/N apart, and span an interval of length less than 2. Call an index bad if Delta_u is within delta of an integer. At most four integer neighborhoods meet this range; each contains at most 2 delta N+1 indices. Thus there are at most 8 sqrt(N)+4 bad indices. The remaining indices form at most five consecutive good runs. Because the increment spacing 1/N is smaller than 2 delta, a good run cannot jump over an excluded integer neighborhood; its fractional increments stay on one cotangent branch.

On a good run the increments, modulo one, vary monotonically inside [delta,1-delta]. Set z_u=exp(2 pi i f(u)) and

a(v)=1/(1-exp(2 pi i v))=1/2+(i/2)cot(pi v).

Since z_u=a(Delta_u)(z_u-z_(u+1)), telescoping gives an upper bound equal to the two endpoint magnitudes of a plus its total variation. These are at most 1/(2 delta) and cot(pi delta)<=1/(pi delta), respectively. Their sum is less than 1/delta. Each good run therefore contributes at most sqrt(N).

The total is at most 13 sqrt(N)+4<=14 sqrt(N). For N<16 the trivial bound 2N-1<8 sqrt(N) suffices. The deliberately loose universal constant 32 follows without evaluating any Gauss sum or assuming a frequency grid.

Let M be the least power of two at least 2N-1 (N=1 can be direct), eta=exp(pi i/N), and define b[u mod M]=eta^(-u^2) for -N+1<=u<=N-1, with zeros elsewhere. The residues are distinct. Every entry of F_M b is exactly S_N(t) for an appropriate real t, so

D=diag(F_M b / sqrt(N)) satisfies ||D||_2<=32.

There is NO required positive lower bound on the diagonal entries. Zero entries are allowed.

### 7.2 A constant-factor linear factorization

Use the positive-exponent Fourier convention. Let E embed x_j eta^(j^2) at coordinates 0<=j<N of an M-vector. Let P crop those coordinates and multiply coordinate k by eta^(k^2). Then ||E||=||P||=1, and the exact chirp identity gives

U_N=P U_M^* D U_M E.

The normalization is important: the diagonal is F_M b / sqrt(N), with no extra sqrt(M).

### 7.3 Transparent ADD without dense compilation

Use input/target banks x,y of length N and dirty scratch banks z,w of length M. Execute:

1. z += E x
2. z <- U_M z
3. w += D z
4. w <- U_M^* w
5. y += P w
6. w <- U_M w
7. w -= D z
8. z <- U_M^* z
9. z -= E x

This restores z,w and adds U_N x plus a linear function of their original dirty contents to y. Repeat the same sequence with steps 1 and 9 suppressed and step 5 replaced by y -= P w. The dirty-scratch contribution cancels exactly. Thus the net map is ADD_(U_N) on arbitrary x,y,z,w.

This uses eight dyadic transforms, four diagonal-add passes, two input-add passes and two output-add passes. E/P additions are sparse coordinate-pair shears; D additions are coordinate-pair shears. Their count is O(M), not O(N^2).

To apply a dyadic transform to an arbitrary dirty scratch bank, use its two-bank algorithm and a final bank permutation. Its completed full-state action has the form diag(U_M,V) with V some unitary matrix on its companion bank, and identity on local scratch. Reverse that entire algorithm for its inverse. Give z and w separate M-coordinate companion banks to make their cancellation explicit. Both companions and the local scratch are restored by each compute/uncompute pass. This does not assume that a zero-initialized helper remains zero for arbitrary data.

Three such ADDs give W_(U_N), as in Section 2. For the inverse ADD use U_N^-1=J_N U_N and change only the output permutation. There are 24 dyadic transforms for the paired exchange, plus one transform of the fixed b in scalar preparation, and O(N) additional operations.

### 7.4 Conditioning at every scalar instruction

At completed dyadic boundaries the Fourier lifts are unitary. With ||D||<=32, all input, output and D additive passes have operator norm and inverse norm bounded by an absolute constant. During coordinate-by-coordinate execution, partial blocks are direct sums and obey the same kind of dimension-independent bound.

For literal scalar instructions, use the six-instruction split from Section 3. For D coefficients choose C=64, so both split coefficients are nonzero and the partial-block strong bound is at most 4C=256. For E/P phase coefficients choose C=2. No division by D_j occurs.

For an explicit conservative overall constant, let S_M bound BOTH norms of every dyadic prefix. Across one transparent ADD there are eight additive passes. Every completed pass has both norms <=33; an in-progress scalar pass has both norms <=256. Every other completed operation is unitary. Thus every prefix of one ADD has both norms at most 256^8 S_M. The two previously completed ADDs in the three-ADD exchange have both norms at most 2^2 because their intended off-diagonal maps are unitary. Therefore the full paired wrapper obeys

max_prefix kappa_2 <= Cwrap S_M^2,
Cwrap=(4*256^8)^2.

This huge fixed constant is intentionally crude. If the dyadic construction has the strong certificate S_M^2<=R(M), the wrapper has condition <=Cwrap R(M). Therefore any diverging efficiently usable budget R_target(N) can be met by running the dyadic construction at size M with budget R_target(N)/Cwrap, for sufficiently large N. A constant adjustment does not change the asymptotic radix/work tradeoff. For an irregular budget, use this explicit N-dependent budget; do not silently replace it by R_target(M).

Thus the normalized all-length transform, not just powers of two, has the same conditional o(N log N) exact-arithmetic work and arbitrarily slowly diverging full-state condition allowance. Polylog and polynomial budgets have the same iterated-log rates as Section 6, with N and M=Theta(N) interchangeable in those rates.

### 7.5 Workspace, scalar preparation and one root

The paired all-length exchange uses 2N data registers, z and w of length M, two M-coordinate companion banks, and the reused g(B) local scratch:

2N+4M+g(B) < 18N+g(B).

Program tables and prepared scalars are additional explicitly charged storage. This is O(N) when the slow-radix local sizes are polynomial in B=N^o(1). It is not an N-register algorithm.

Computing the fixed F_M b is one more charged fast transform in scalar preparation. That input-independent computation is outside the input-linear defining-matrix condition metric; finite-precision coefficient evaluation remains a separate problem.

For arbitrary N, normalization sqrt(N) must not be an uncharged oracle. With the canonical positive root, the classical quadratic Gauss-sum identity gives

sum_(j=0)^(4N-1) zeta_(4N)^(j^2)=2(1+i)sqrt(N).

The sum and powers can be formed in O(N) exact operations by successive phase ratios. Dividing by 2(1+i), then by the resulting nonzero sqrt(N), prepares the normalization. This uses the explicit nonzero Gauss identity, not a numerical root choice. A single supplied root of order lcm(4N,M,D(B),8), polynomial in N, supplies everything. Its extraction cost and all chirp preparation are charged. The smaller local field still governs the local height certificate.

The Gauss identity is used only to prepare normalization, not to prove the uniform chirp bound above. See Murty and Pathak, Theorem 1.1: https://www.cmi.ac.in/~siddhi/Quadratic_Gauss_Sum.pdf .

## 8. Claim boundaries and sources

The claimed low-condition output is the NORMALIZED transform U_N x. Scaling only the output bank by sqrt(N) to produce the unnormalized F_N x can increase the full-state condition; no low-condition final unnormalization is claimed.

This theorem is about exact arithmetic work and square full-state conditioning with additional data/scratch registers. It does not establish forward/backward floating-point error, safe coefficient rounding, range safety, bit-operation complexity, or Ailon-model equivalence. A finite-precision theorem additionally needs an error recurrence for the implemented gates and coefficient approximations.
