# Hero #17 — Phase 9: Root-Exchange Union

A reproducible exact finite-field research package on polynomial-CRT Fourier root exchanges. **Not a universal faster Fourier transform.**

## Files

- `PROOF_CERTIFICATE.md`: full theorems and derivations (involutions, ranks, Lagrange corrections, Cauchy inverses, complexity).
- `RESEARCH.md`: result, audit, comparison with prior phases, research limitation.
- `CHAIN_CHECKPOINT.md`: recovery context and next target.
- `phase9.py`: standalone exact modular forward/inverse bridge, adaptive root orientation, one-swap closed form, honest full DFT controls.
- `test_phase9.py`: 15 groups of regression tests.
- `independent_audit.py`: independent direct evaluations, a separate rank implementation, scalar operation ledgers, 65,536-point DFT check.
- `AUDIT_RESULTS.json`: saved numeric results.
- `TEST_LOG.txt`, `PHASE8_PREDECESSOR_LOG.txt`: test logs.
- `SHA256SUMS.txt`: package file checksums.

## Run

Python 3.10+ (tested with Python 3.13). No pip installations required.

```bash
python -m unittest discover -v
python independent_audit.py
```

`fixture(n)` searches for a prime p with N | p-1 and a primitive N-th root only to build test fixtures; it is NOT counted as an input-independent uniform Fourier-root supplier. The mathematical theorem is conditional on the given exact field and primitive root. All field plan operations, modular inversions, and online arithmetic are counted in the executor; the model of modular inversions must be stated separately for bit complexity.

For a full fresh arbitrary input, `full_dft_via_hybrid_children` explicitly calls two conventional length-m FFTs. The package does not hide that cost.
