# Portable independent replay

Copy only `independent_checks.py` and `independent_math.py` to any directory. Python 3.10+ and the standard library suffice:

    python -B independent_checks.py marked_cycle_review_results.json

Compare the output byte-for-byte with `INDEPENDENT_RESULTS.json`. `independent_math.py` is our own previously authored mathematical checker, not an uploaded program. Neither the source archive nor the constructor snapshots are executed, imported or required by this replay. Dense matrices, interpolation and solves in the checker are bounded verification oracles, not the proposed fast algorithm.
