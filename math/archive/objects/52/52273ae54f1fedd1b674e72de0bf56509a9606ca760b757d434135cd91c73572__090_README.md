# FFT structural research — Phase 28: Two-mask Green synthesis

**This is a verified research checkpoint, not an `o(N log N)` FFT.** It continues Phase 27's non-affine Hamiltonian Green circuits and targets the previously uncontrolled internal complex diagonal gates.

## What is actually new in this checkpoint

- Exact two-sided monomial-invariant correlation `R(M)=M(M^(circ -1))^T`, and a permutation/gauge recovery algorithm using row/column pair-moment fingerprints. The underlying type-II notion is classical; the Green phase-synthesis specialization is project-specific.
- **For every N and every fixed selection of Hamiltonian Green cycle orders:** generic values of continuously adjustable three-mixer parameters cannot yield a DFT with two arbitrary internal masks/permutations. Exceptional tuned values are not ruled out.
- For fixed outer mixers and tunable middle scalar coupling, the first trace condition leaves at most **N^2** admissible complex candidates unless its polynomial vanishes identically.
- Explicit cyclotomic-rational Green triples at **N=4,8,16** are proven impossible for **every complex** middle scalar coupling, even with arbitrary internal phase masks and permutations. Reproducible modular Bezout polynomial certificates lift to characteristic zero under the checked denominator/degree conditions.
- Additional single-setting certificates at N=32,64,128 exclude the specified fixed Green parameters.
- The underlying Green stages remain O(N)-apply, demonstrated independently by `phase28_executor.py`.

## Reproduction

Python 3.10+ standard library only.

```bash
cd fft_green_phase28_internal_phase_synthesis
python -m unittest discover -s tests -v
python audit.py
python build_certificates.py
python phase28_executor.py
sha256sum -c SHA256SUMS.txt
```

See `THEOREM.md` for fully qualified statements and scope. `certificates/` contains the exact finite-field coefficient arrays and explicit Bezout multipliers. `previous_full_phase27_checkpoint.zip` retains every previous phase checkpoint.

## Key warning

Synthesis/testing uses O(N^3) dense inverses of fixed mixer matrices **offline**. Those inverses are never treated as O(N) on-current-input computations. Neither the invariant nor the Bezout certificates are a faster Fourier executor.
