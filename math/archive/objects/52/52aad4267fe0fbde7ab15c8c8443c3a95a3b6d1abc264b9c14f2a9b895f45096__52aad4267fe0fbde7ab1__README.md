# Verified Phase23 and interval-window supplement

This bounded checkpoint audits two newly located Fourier-research archives and adds four independently proved refinements. It does not establish a new exact arbitrary-input, all-output faster Fourier transform.

Read first: CHECKPOINT_ADDITION.md.

## Main findings

- Two quasiseparable stages with both ranks <=r require N<=9r^2+7r in the stated natural/affine Fourier input order. Rank-one is therefore excluded at N>=17. Arbitrary input reorderings require the general actual-submatrix-rank gate.
- All interval-window inequalities can be screened exactly in O(N) time using sliding extrema. This is a candidate filter, not a transform algorithm.
- A square-root-free exact executor computes all Fourier outputs of any verified order-at-most-two recurrence in O(N) field arithmetic, with root/normalization preparation and inversions charged. It covers repeated and nonsplit roots but remains a special-input result.
- The original Phase23 adaptive fast path covers exactly N(N-1)+4 binary inputs at supported dyadic N>=8, an exponentially small fraction of all binary inputs.

## Reproduce

Use Python 3.10+ with the standard library. From this directory run:

`python3 run_independent_audits.py`

This reads original archives only to check bytes/manifests and runs only independently authored code. It never executes or imports uploaded programs. Mathematical checks need no network or external package. They rewrite their adjacent JSON results; the Phase23 result includes diagnostic timing/environment fields that naturally vary across machines.
