# Hero #17 Phase 13 — Branching Weyl–Green Union

**Exact mathematical research artifact — not a universal O(N) FFT.**

This package contains executable finite-prime-field verification and proofs of restricted lower bounds for Fourier representations by branching one-pole Green paths, plus positive but **non-Fourier** linear-work branching Green operators.

Read `CHAIN_CHECKPOINT.md` if continuing the multi-phase project, `RESEARCH.md` for the full report, and `PROOF_CERTIFICATE.md` for all six precise proof statements.

Run with Python 3.10+ (no required third-party packages):

```bash
python -m unittest -v test_phase13
python independent_audit.py
python orientation_audit.py
```

`phase13.py` contains the exact modular Weyl coefficient checks, rank elimination, cyclic Green recurrences, batched one-inversion modulation preparation and correct O(N) operator executors. `test_phase13.py` has 21 test groups; independent audit scripts reconstruct dense operators and sample random full vectors. `AUDIT_RESULTS.json`, `ORIENTATION_AUDIT_RESULTS.json`, and the corresponding logs preserve exact outcomes. `SHA256SUMS.txt` verifies the frozen package.

**Do not compare the O(N) Green-surrogate operation counts to FFT and claim a transform speedup.** They compute different operators.
