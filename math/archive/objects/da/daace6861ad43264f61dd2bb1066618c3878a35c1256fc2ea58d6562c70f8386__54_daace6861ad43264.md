# FFT equivalence caching: research findings — 2026-10-08

## Question
Can caching not only identical FFT subproblems but FFTs of equivalent, nonidentical inputs break the `O(N log N)` barrier? How does this compare with CrocSwap/integer-mult-bounds?

## Summary
- It is possible to reconstruct the DFT of a rotated, reversed, scaled, complemented (binary only), or sparsely edited input from a previously computed DFT in `O(m)` or `O(rm)` arithmetic operations for a block of length `m`.
- The included Python prototype canonicalizes all cyclic rotations, reversals, and binary complements for every node in an even/odd radix-2 FFT recursion. It memoizes each canonical transform and reconstructs other orbit members.
- This saves butterflies on structured inputs but did not beat a basic unoptimized radix-2 FFT in the measured wall-clock tests. Additional canonicalization and output reconstruction overhead dominates.
- On independent uniformly random binary data, even a more generous class of *all* invertible affine index permutations plus complementation has too few equivalences at large recursion levels to change the asymptotic butterfly count. This is a restricted negative result, **not** a general lower bound for all FFT algorithms.
- CrocSwap shares symbolic intermediate computations in fixed linear circuits and improves recursive transformations and data movement; it does **not** memoize the results of numerical FFT subproblems based on input collisions. The two approaches share a broad strategy of exploiting algebraic structure, not an algorithm.

## Conventions
Define the unnormalized DFT by:

`F(x)[k] = sum_{j=0}^{m-1} x[j] * omega^(j*k)` where `omega = exp(-2*pi*i/m)`.

### Useful equivalence identities

1. **Scaling:** for `y[j] = c*x[j]`, `F(y)[k] = c*F(x)[k]`. Recovery `O(m)`.
2. **Circular shift:** for `y[j] = x[(j-s) mod m]`, `F(y)[k] = omega^(s*k)*F(x)[k]`. Recovery `O(m)`.
3. **Reversal:** for `y[j] = x[(-j) mod m]`, `F(y)[k] = F(x)[(-k) mod m]`. Recovery `O(m)`.
4. **Affine index reordering:** for `y[j] = x[(a*j+b) mod m]`, `gcd(a,m)=1`, set `q=a^{-1} mod m`. Then `F(y)[k] = omega^(-q*b*k) * F(x)[(q*k) mod m]`. Recovery `O(m)`.
5. **Complement of binary input:** for `y[j]=1-x[j]`, `F(y)[k] = m*[k=0] - F(x)[k]`. Recovery `O(m)`.
6. **Sparse changes:** for `y = x + sum_{t in S} delta_t * e_t`, `F(y)[k] = F(x)[k] + sum_{t in S} delta_t*omega^(t*k)`; recovery `O(m*|S|)`.

The formulas describe relationships between *complete* FFT outputs and do not imply their input relationship can be detected for free.

### Computation-graph cache
Each recursive block of `m` input elements is assigned its lexicographically smallest representative among `4m` possible shift/reversal/complement variants (some may coincide). The algorithm computes the FFT of each distinct representative once, then reconstructs each matched block via phase rotations, frequency reversal, and possibly complement correction. Booth's minimum rotation algorithm yields a linear-time canonical rotation for each orientation and complement. This costs O(m) per visited node and does **not** magically eliminate the cost of recognition.

### Tests
The script `fft_equivalence_research.py` compares the reconstructed results against an independent radix-2 FFT implementation.
- 56 independent binary-array comparisons for lengths 2 through 128.
- 5 single-orbit transform comparisons.
- 78 additional affine-index-permutation, complement and sparse-edit reconstruction comparisons.
- Arithmetic tolerance: `1e-7` for small tests; `1e-6` for the large workloads.

### Restricted negative result for uniform random binary input
At recursion level `m`, there are `B=N/m` disjoint blocks in an even/odd radix-2 FFT recursion tree. For independent uniform binary input, these blocks are independent and uniformly distributed over `2^m` binary strings.

Consider the class formed by all permutations `j -> a*j+b mod m` with `a` invertible modulo `m` and by optional binary complement. Its group size is at most `2*m*phi(m)`, which equals `m^2` for even powers of two `m` (since `phi(m)=m/2`). Each input's orbit thus contains at most `m^2` candidates.

For independent uniform random blocks `U,V` of length m:

`Pr[V is in the orbit of U] <= m^2 / 2^m`.

Union-bounding over at most `B*(B-1)/2` block pairs gives:

`Pr[any equivalent pair at size m] <= (B^2/2) * (m^2/2^m) = N^2 / 2^(m+1)`.

For all levels with `m >= 3 log_2 N`, the per-level collision probability is `<=1/(2N)`. Taking the union over `O(log N)` large-block levels still gives `o(1)` probability of such a collision. Those large levels number `log_2 N - O(log log N)`, each having `N/2` distinct butterflies without sharing. Therefore this particular orbit-based DAG approach still requires `Omega(N log N)` butterfly operations with high probability on independent uniformly random binary input, even if orbit detection and storage were free.

This argument does not rule out more powerful nonlocal linear-network transformations, nonstandard computation models, sparse spectra, structured signal families, preprocessing or amortization across many related FFT queries.

### Important modeling warning
FFT arithmetic on unit-cost real/complex numbers, exact FFT output at varying precision, and bit-complexity of integer multiplication on a fixed-alphabet multitape Turing machine are different computational models. An `O(m)` vector output transformation assumes constant-cost arithmetic and sufficient precision. A precomputed lookup for *every possible input*, with free access, behaves like a nonuniform oracle and is not an ordinary fixed finite-machine algorithm.

## Next investigational targets
1. Efficiently classify affine time-index equivalence without enumerating `O(m^2)` candidate permutations.
2. Reuse FFTs across a *sequence of related queries* with sparse edits and cached spectra; analyze throughput including oracle identification costs.
3. Recognize structural equivalences of linear expressions/symbolic circuit nodes independent of numerical input values, and compare to CrocSwap's shared intermediate sums and rank budget.
4. If targeting a new integer-multiplication exponent, express the proposed primitive in the paper's actual fixed finite-alphabet tape cost model and show a strict recursive inequality, rather than extrapolating floating-point FFT counts.

This is an exploratory experiment, not a claimed general sub-n-log-n FFT algorithm or a novel mathematical result.

## Separate experiment: updating a previously computed spectrum

If an array changes at one known index, the sparse-edit identity gives an O(N) update to the existing FFT. These exploratory pure-Python measurements used three timed repetitions per method and report the median. They do **not** include the original FFT computation, which is a required setup cost and only amortizes across a sequence of updates.

| N | Full FFT of changed input | Update cached FFT for one change | Speedup | Maximum abs difference |
|---|---:|---:|---:|---:|
| 4,096 | 0.00880 s | 0.00043 s | 20.5x | 6.24e-13 |
| 16,384 | 0.04497 s | 0.00186 s | 24.1x | 1.97e-12 |
| 65,536 | 0.19329 s | 0.00901 s | 21.4x | 3.37e-12 |

This illustrates a concrete useful domain—related FFT queries with sparse known edits—rather than a general single-instance FFT breakthrough.
