# FFT Hero #1 — Phase 14 (2026-10-10)

**Checkpoint is reproducible. Main goal remains UNSOLVED: no exact general-purpose `o(N log N)` FFT or integer-multiplication improvement is claimed.**

## Positive technical results

1. **Known orthogonal bank masks:** for arbitrary input x, evaluate the transform of a selected chirp projection with a deterministic **whole-vector** exact-arithmetic squared-error identity `||F x - Y||² = ||x||² - captured_energy`, costing `O(N)` arithmetic for fixed odd m and O(1) selected banks per column with M≈logG. It is **exact on the corresponding dense but lower-dimensional subspace**, not on arbitrary x.
2. **Adaptive energy-optimal bank recovery:** O(N logM) short block transforms measure every bank's energy, selecting the fewest banks that meet a target vector error within this fixed orthogonal family. Once chosen, fuse all selected dyadic stages **before** the one final odd FFT, instead of recomputing the odd FFT for every phase bank.
3. **Noncommuting chirp-frame union:** select q different slopes per column, solve the q×q Gram normal equations in each input block, use q inherited linear-work Green/chirp decoders, and certify the full-vector residual energy. A genuinely noncommuting, well-conditioned two-slope family is checked both numerically and over finite fields. For fixed q,m it is O(N) exact arithmetic **on its fixed structured subspace**.
4. **Stationary full-rank Toeplitz chart:** an explicit M-slope frame has distinct Vandermonde nodes for **all** G=KM with K>=M. Its Gram is the same Hermitian Toeplitz matrix at every input block. For q=M it computes an **exact transform for arbitrary inputs**, but still pays M long scans—O(NlogG) for M≈logG, not a faster general FFT. The all-basis finite-field audit passed 202,240 entries.
5. **Graph-union collision gate:** for these stationary slopes, simply merging equal same-clock destinations leaves `K(2M²+1)/3` distinct visits versus `K M²` raw visits, asymptotic ratio **2/3**. More powerful sharing is needed.
6. **Sharp honest limitations:** any fixed q-dimensional local frame misses at least `(1-q/M)` squared energy for a suitable input impulse; adaptive beta-bank selection can require nearly all M banks; rank-only sketch transcripts cannot reconstruct arbitrary x with fewer than M probes; and one sparse Green solve has dense forcing `B=L F_N` even when L itself is sparse.
7. **One-root accounting:** an O(G) dyadic root table and O(N) twiddle generation replace uncharged local transcendental tables. All short FFTs, long scans, Gram solves, root tables and output writes are explicitly included in complexity formulas.

## Implementation modules

- `phase_bank.py`: known-bank energy certificate, fast screening, globally optimal selection within this orthogonal family, shared final CT.
- `gram_union.py`: noncommuting Gram projection and fast union evaluation.
- `one_root_chirp.py`: one-root dyadic chirp phase and scan decoder; float64 numerics, **not** certified bit precision.
- `leverage_gate.py`: rank/leverage lower-bound witnesses against fixed frames.
- `green_forcing_gate.py`: exact support-density sharpness controls.
- `field_gram_audit.py`: exact prime-field independent all-basis test, including mutation controls.
- `stationary_toeplitz.py`, `field_stationary_audit.py`, `test_stationary.py`, `orbit_collision_gate.py`: new all-rank stationary Toeplitz chart, exact prime-field full-basis controls and q=M regressions.
- `test_phase14.py`: unit tests, plus complete prior v13 regression sources.

**Important numeric caveat:** computing `||x||²-captured_energy` in double precision may involve severe cancellation when the true residual is almost zero. The formula is an **exact-arithmetic certificate**; the displayed float64 value is a diagnostic, not a rigorous bound on all implemented rounding errors. Conditioning checks prevent obvious singular local Gram solves but do not replace verified interval precision.
