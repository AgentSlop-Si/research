# Fourier endpoint permutation / quasiseparable exact-rank research

**Date:** October 9, 2026 · **Status:** Proofs and runnable finite-field verification; no new FFT runtime bound.

This checkpoint proves that for every power of two N>=8, the minimum possible maximum off-diagonal cut rank of an N-point Fourier matrix, over **all independent row and column permutations**, is `N/4 + 1`. The bit-reversal ordering attains that bound. Its complete cut-rank profile obeys a recursion that also proves its summed cut ranks are asymptotically optimal.

Read `PROOF_CERTIFICATE.md` for the characteristic-zero proof, `RESEARCH.md` for interpretation and negative attempts, and `SESSION_HANDOFF.md` to continue without restarting. The previous complete research ZIP is nested under `prior_checkpoint_full.zip` unchanged.

## Quickstart

```bash
python run_all.py
```

Requires Python 3.10+ and NumPy. The mathematical proofs do not depend on either implementation or finite-field testing.

Useful scripts:
- `bitrev_rank.py`: exact recursion, works up to huge power-of-two sizes without building Fourier matrices.
- `test_exact_gate.py`: nine independent test groups over exact finite fields.
- `coset_rank.py`: structural formula for exact ranks of Fourier submatrices with input dyadic cosets.
- `subset_gate.py`, `optimized_support.py`, `uncertainty_gate.py`: exploratory methods that did **not** outperform the old interval gate; preserved to prevent duplicated effort.

**Scope:** single matrix representation. Arbitrary overlapping multi-stage Fourier factorizations and arithmetic complexity improvements remain unresolved.
