# Phase 21 exact reproduction

Requirements: Python 3.11+ standard library only. Runs in the extracted archive directory. NTT field root choices are given in the source; you do not need a network connection.

```bash
python -m unittest discover -p 'test_*.py' -v
python audit_phase21.py
python audit_compressed_phase21.py
python benchmark_phase21.py
python resultant_pattern.py
sha256sum -c MANIFEST.sha256
```

`test_compressed_phase21.py` independently constructs the **full degree-bound resultant** and verifies the universal factors and reciprocal coefficient identity at orders s=1..6, not merely testing a few final DFT outputs. The two independent audits compare the *entire* new and fallback transform against direct O(N²) finite-field DFTs, including N=384 and two prime fields. The benchmark evaluates larger lengths against the exact Bluestein/Green reference, not against a floating-point NumPy FFT.

By design the previous Phase20 ZIP is retained and can be extracted separately. File hashes are in `SOURCE_INVENTORY.md` and `MANIFEST.sha256`.

The test suite accepts some structured cases as correct FFT fallbacks due to explicit nondegeneracy checks. A correctness pass does **not** imply the structured branch was chosen. Negative inputs with identical first 16 spectral probes are included and must not be accepted without a full cyclic check.
