Use Python 3 and NumPy. In a writable copy of this directory run:

    python3 prepare_check_inputs.py
    python3 independent_phase14_checks.py

The first program was independently written for packaging. It verifies the complete original's hash/length/CRC and safe first-level paths, then materializes exactly the original bytes in `extracted/fft_hero1_phase14`. It never runs any of that source code. The second program is the unchanged independently authored mathematical checker; its source access is limited to hashes, text/AST inspection and predecessor-byte comparisons. Do not execute the uploaded source programs as part of this reproduction.

The expanded predecessor ZIPs are needed only as read-only integrity input. They remain inside the unchanged original in the delivered package and are not duplicated as expanded delivery files. Mathematical checks and floating diagnostics retain the distinctions in the main audit.
