# Phase 28 — internal-phase synthesis by projective trace invariants

**Date:** 10 October 2026  
**Status:** Rigorous restricted algebraic statements; executable finite-field and characteristic-zero-lifting certificates for fixed Green circuits. **No new arbitrary-input `o(N log N)` FFT.** The method tests whether fixed fast Green stages *could* be made Fourier-correct by two internal phase masks and permutations.

## 1. Precise circuit model

Let `N` be a power of 2, and let `F=[zeta_N^(ij)]` be the **unnormalized** complex DFT. The unknown factorization is

```
F = A D1 P1 B P2 D2 C,                       (1)
```

where `A,B,C` are **fixed invertible** Green-sum matrices, `D1,D2` are arbitrary invertible complex diagonals, and `P1,P2` are arbitrary coordinate permutations. The scalar `sqrt(N)` needed to normalize the DFT can be absorbed into a diagonal and does not change any result here. Fixing the Green mixers is essential: the phase/permutation gate does not prove that other mixer parameters cannot succeed.

Put `T=A^(-1) F C^(-1)`. Then (1) is equivalent to `T=D1 P1 B P2 D2`. This is equivalence under independent **row and column monomial** transformations, not ordinary similarity or congruence.

A Hamiltonian-cycle Green term is `(I-alpha W)^(-1)` where `W` is a cyclic permutation; for `alpha^N != 1`, it is executable in `O(N)` arithmetic by a cyclic recurrence. Sums of a fixed number of independently ordered, diagonally gauged terms retain `O(N)` forward cost. Dense inversion of A/C below is an **offline synthesis test** and has `O(N^3)` standard field-operation cost.

## 2. Projective correlation operator and exact invariance

For an entrywise-nonzero matrix `M`, write `M^(circ -1)` for entrywise reciprocals. **It is not the ordinary matrix inverse.** Define

```
R(M)=M (M^(circ -1))^T,
R(M)[i,j] = sum_k M[i,k]/M[j,k].              (2)
```

If `M'=L P M Q R` with invertible diagonal L,R and permutation matrices P,Q, then

```
R(M') = L P R(M) P^(-1) L^(-1).             (3)
```

This follows by writing the entrywise reciprocal of `LPMQR` explicitly and multiplying. Therefore every similarity invariant of `R(M)`—rank, characteristic polynomial and `tr(R(M)^s)`—is unchanged by **both unknown diagonal masks and both permutations**.

In particular, for every integer `s>=1` define the row-pair projective moment

```
h_s(i,j;M) = (sum_k (M[i,k]/M[j,k])^s)
             (sum_k (M[j,k]/M[i,k])^s).      (4)
```

Its multiset over all unordered row pairs is a monomial invariant. The column analog is too. If either multiset disagrees between T and B, (1) is mathematically impossible for every D1,P1,P2,D2. If all matrices are nowhere zero, and row/column vertex fingerprints of the pair-moment graphs are unique, they determine the only possible row and column permutations. Diagonal scalings follow from the first row and column and are verified against **every matrix entry**. Fingerprint collisions return `inconclusive`, not a claimed recovery.

The fast scalar invariant used for the main certificates is

```
Q(M) = tr(R(M)^2)
     = N^3 + 2 sum_{i<j} h_1(i,j;M).        (5)
```

The formula follows from `R(M)[i,i]=N`. Equality `Q(T)=Q(B)` is necessary for (1), regardless of both masks or permutations. A mismatch is a complete **fixed-mixer veto**. In the classical literature, `R(M)=NI` is the type-II/inverse-orthogonal condition. We do not claim type-II matrices or monomial invariance are previously undiscovered (references in PRIOR_ART.md).

For the unnormalized Fourier matrix, character orthogonality gives `R(F)=NI`; hence `Q(F)=N^3`.

## 3. Uniform all-N generic obstruction for triple Green sums

**Theorem A (generic, not universal).** Fix any `N>=4`, any Hamiltonian cycle orderings in three Green-sum stages `A(theta),B(theta),C(theta)`, and let their scalar couplings and diagonal gauges vary freely in an algebraic parameter family containing the perturbative specialization `alpha=e>0`, all term weights positive and all gauges identity. On the domain where A,C are invertible and T,B have no zero entries, the exact-factorization parameters satisfying (1) are contained in a **proper algebraic subvariety**. In particular, they have Lebesgue measure zero in the continuous parameter space.

**Proof.** Entries and inverses of Green stages are rational functions of the tunable parameters, so `Delta(theta)=Q(A^-1 F C^-1)-Q(B)` is rational. Every factorization (1) requires `Delta=0` by (3). To show Delta is not the zero rational function, specialize all Green term couplings to a shared small positive `epsilon`, all diagonal gauges to I, and all term coefficients to positive constants. Every Hamiltonian-cycle resolvent has strictly positive entries for `0<epsilon<1`; all three Green sums approach positive scalar multiples of I as `epsilon ->0`. Therefore

```
T=A^-1 F C^-1 -> c F       (c !=0),
Q(T)->N^3.
```

For strictly positive B, set `u_k=B[i,k]/B[j,k]>0`. Cauchy–Schwarz gives `(sum u_k)(sum 1/u_k)>=N^2`, for each `i!=j`, whence

```
Q(B) = N^3+2 sum_{i<j} h_1(i,j;B) >= N^4.
```

As `N^4>N^3`, Delta is nonzero at all sufficiently small epsilon. Clearing its denominators therefore yields a **nonzero polynomial**. Its zero set is proper. This argument applies to arbitrary fixed cycle orderings, including non-affine and expanding ones, and arbitrary complex parameter values *generically*. It does **not** rule out the exceptional parameters where a deliberately designed Fourier construction might lie. QED.

## 4. Finite exceptional-coupling theorem

Fix A,C and two entrywise-nonzero middle matrices B0,B1, and set `B(lambda)=B0+lambda B1`. Keep the two internal arbitrary diagonal gates and permutations from (1).

Define `D(lambda)=product_{i,j} B(lambda)[i,j]`, with degree at most `N^2`. Since

```
Q(B) = N^3 + 2 sum_{i<j} sum_{k,l}
     B[i,k] B[j,l] / (B[j,k] B[i,l]),
```

it follows that, after clearing denominators,

```
P_1(lambda)=D(lambda) [Q(B(lambda))-Q(T)]
```

is a polynomial of degree at most `N^2`. Every *admissible* coupling (all entries of B nonzero) passing the first necessary invariant is a root of P1. If P1 is not identically zero, there are therefore at most **N^2 complex scalar couplings** even worth testing further, counting multiplicity. This finite exceptional-set theorem assumes A,C,B0,B1 fixed; it does not control a simultaneous optimization of all those mixers.

For `s=2`, define the independent invariant `Q_2(M)=N^3+2 sum_{i<j}h_2(i,j;M)`, and

```
P_2(lambda)=D(lambda)^2 [Q_2(B(lambda))-Q_2(T)],
```

which has degree at most `2N^2`. An admissible exact Fourier factorization requires a common complex root of P1 and P2. The source constructs their reductions modulo a prime in two independent ways: symbolic product/division and exact consecutive-point polynomial interpolation. For tested sizes the coefficient arrays coincide.

## 5. Exact fixed-circuit certificates over the complex numbers

The seeded Green matrices are fully specified by `green_components`, `green_sum`, seeds `2800+N`, rational `alpha=1/4`, `beta=1/5`, second-term coefficient `lambda=3/2`, phase exponents in roots of unity, and Hamiltonian orders generated by the included Python code. These are **exact cyclotomic-rational** matrices over `K=Q(zeta_N)`, not floating-point approximations.

The prime `p=998244353` satisfies `N | p-1` for the checked N. The chosen primitive root `omega` realizes a reduction of the localized cyclotomic integer ring (after clearing all denominators, which are checked nonzero modulo p). A polynomial identity holding over K must reduce to one holding modulo p. Consequently a nonzero modular trace difference is also a proof of nonzero characteristic-zero difference for the same exact algebraic parameters.

For `N=4,8`, P1 and P2 have degrees exactly `N^2` and `2N^2`, with nonzero leading coefficients mod p. Their reductions are coprime and the code supplies explicit Bezout polynomials `U,V` with `U P1+V P2=1 mod p`. Since the leading degrees are preserved, the exact characteristic-zero resultant is also nonzero. Thus **no complex lambda** can satisfy both constraints for these fixed A,C,B0,B1.

For **N=16**, the unreduced P1 and P2 have degrees 256 and 512 and share a spurious factor corresponding to zeros of B. At rows 5,6,15 the first Green term's diagonal-gauge exponents are `(7,4,4)` and the second term's are `(3,0,0)` modulo 16. Thus their three diagonal entries all contain the **same affine factor up to nonzero scalar**:

```
E(lambda)=B0[5,5]+lambda B1[5,5].
```

`D` contains E cubed; each summand of Q_s has at most two denominator entries raised to the sth power. Therefore **over characteristic zero**, P1 is divisible by E and P2 by E squared. Removing these exact known factors leaves degrees 255 and 510, with nonzero modular leading coefficients. The reduced polynomials have coprime reductions and explicit Bezout certificates. Their characteristic-zero resultant is nonzero. Any root of E makes three B entries zero, while T has no zero entries (again certified by nonzero modular reductions), so E roots are inadmissible. Hence **no complex lambda whatsoever** can make this N=16 specified network equal F after arbitrary D1,P1,P2,D2.

The finite-field computation at N=16 is therefore used as an **algebraic certificate over K**, not mistaken for a statistical simulation of complex numbers. This argument does not extend automatically to every N, nor to freely retuning A, C, Green cycle orders, or individual term gauges.

The complete coefficient arrays and explicit Bezout multipliers are stored as `certificates/bezout_N{4,8,16}.json`. Validation checks the polynomial identity in F_p, degree preservation, and the shared-factor rule. The files can be inspected without rerunning any dense Green-matrix inversion.

## 6. Executable cost and limitations

| Component | Cost in field arithmetic | Claim |
|---|---:|---|
| Apply one cyclic Green term | O(N) | Exact recurrence |
| Apply one two-term Green mixer | O(N) | Verified against independently materialized dense matrices through N=128 |
| Apply fixed three-mixer circuit with two diagonal masks/permutations | O(N) | **Provided the masks/permutations are known**; not a Fourier implementation |
| Construct dense A,B,C,F for synthesis | O(N^2) entries | Offline only |
| Invert outer A,C | O(N^3) standard elimination | Offline only |
| Row/column moment fingerprints | O(N^3) modular arithmetic | Exact monomial test; not an FFT runtime improvement |
| Symbolically form coupling polynomials | High-order polynomial arithmetic | Offline certificate |
| Reconstruct actual Fourier values with the candidate | **Not achieved** | No new `o(N log N)` bound |

A positive-control Fourier factorization is deliberately provided using two Green mixers plus a **dense expensive third factor**; it proves the algebraic test accepts valid identities but is not an FFT speedup. Equal projective traces alone do **not** imply monomial equivalence. Repeated vertex fingerprints cause `inconclusive`. A match of all signatures is only trusted after the exact full-entry reconstruction. Floating-point numerical conditioning, bit cost of constants, graph preparation, and any general all-N synthesis remain unresolved.
