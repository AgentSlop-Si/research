## Material findings

1. **Historical source-audit conclusions are not present executions.** The existing inventory marks 35 of these hashes as historically executed and 17 as authorship-only/execution-unverified. There are 71 corresponding evidence records. Those statuses are retained rather than upgrading a source simply because a neighboring result or command exists. S02 is a dependency helper with no standalone result. Fifty-one sources have a directly associated stored artifact; four local Python dependency edges resolve to exact sibling hashes fully read in this review. External package/runtime and general data-dependency closure are not established.
2. **The tensor checker's coverage comment is broader than its loop.** S08 L170 says every factorization, while L173 restricts Q to at most floor(sqrt(N)). At N=12 the loop examines Q=1,2,3, while all positive factor choices are 1,2,3,4,6,12. Its saved exact tests remain useful; this is a test-scope correction, not a discovered failure of the transform identities.
3. **The N8 C++ certificate driver has unchecked input/output assumptions.** S24 L9,26–30,38–39 use signed 64-bit modular products and Fermat inversion without a prime, canonical-residue or overflow guard. L22 and L42 never verify that output streams opened or wrote successfully. The actual preserved N8 input has p=998244353, 256 canonical matrix entries and a safe maximum single product. Its stored rank stream contains exactly 112,896 bytes, all rank 15, with the documented digest; the failure list is empty. These facts do not rerun the Macaulay calculation. The finding concerns the general CLI contract, not a demonstrated overflow in the saved run.
4. **One purported data-only certificate route uses an expression parser.** S33 L46 applies SymPy sympify to stored coefficient strings. That is not a generic inert JSON-only boundary and should not be reused on untrusted expression text without a restricted parser. This review never invokes sympify or the archived script. The stored modular Bezout identity was separately checked with plain integer JSON arithmetic over F29, including the image of i.
5. **Reproducibility scopes need to remain literal.** S07 L303–304 intentionally makes original-source byte verification optional when the extraction directory is absent, as its historical README explains. S19 dynamically loads S18; S27/S28 import S25. S30 writes its layout-probe result to an absolute historical directory. Several scripts run their entire audit at import time. None should be imported simply to retrieve a helper in this review.
