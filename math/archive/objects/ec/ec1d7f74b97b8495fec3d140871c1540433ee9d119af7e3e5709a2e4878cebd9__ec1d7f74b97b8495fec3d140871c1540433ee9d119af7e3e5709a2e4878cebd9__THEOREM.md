# Phase 25 — two-run affine Fourier queries, near-maximal Green commutators, and a hidden-cut obstruction

**Date:** October 9, 2026  
**Status:** Project-specific exact constructions and impossibility results in specified arithmetic/factor models. No new worst-case sub-`N log N` Fourier transform or integer-multiplication upper bound. Results are not independently peer reviewed.

## Definitions

Let `N=2^k`, `k>=3`; `m=N/2`; `Z e_j=e_(j+1 mod N)`; `omega=exp(-2*pi*i/N)`, and `Fhat_(j,k)=omega^(jk)/sqrt(N)`.

For any even `a=2u` where `u` is odd (equivalently `gcd(u,m)=1`), define the *two-run order*

```
L_a[t]   = a*t mod N                  (0 <= t < m)
L_a[m+t] = -1 - a*t mod N             (0 <= t < m)
```

This is a permutation: the first run enumerates the even residues, the second the odd residues. Define `W_a e_(L_a[t])=e_(L_a[(t+1) mod N])`. The ordinary zigzag is `a=2`; the *twisted zigzag* is `a=m+2` when `N>=16`.

## Theorem 1 — O(rN) Fourier transform on affine-run geometric signals

More generally, let a permutation order `L` have `r` consecutive arithmetic runs. Run `s` consists of times `t_s,...,t_s+l_s-1` and locations `L[t_s+v]=b_s+a_s*v mod N` for `0<=v<l_s`. Define the input by `x[L[t]]=z^t`, with a supplied field element `z`.

Then the normalized DFT is, **exactly**,

```
Fhat(x)[k] = 1/sqrt(N) * SUM_s
      z^(t_s) * omega^(k*b_s) * G_(l_s)(z*omega^(k*a_s)),

G_l(q) = (1-q^l)/(1-q) if q != 1,
       = l             if q == 1.
```

This follows by substituting the affine progression of each run into the DFT sum and summing its geometric series. It remains valid for degenerate root-of-unity and zero-node cases.

For `r` supplied runs, all outputs can be produced with `O(rN+r log N)` field arithmetic and `O(N+r)` auxiliary space: powers of `omega` across all frequency indices are generated by constant-time recurrences, each run's at most `N` nonzero denominators are batch-inverted with one field inversion and `O(N)` field products, and the `q=1` singular case uses `G_l(1)=l`. Checking that the runs cover a permutation takes `O(N)` time with a Boolean table. For fixed `r`, this is `O(N)`.

**This is a structured-input executor, not an arbitrary-input FFT.** Constructing a representation with few affine runs and few geometric components is a separate and potentially expensive problem.

## Theorem 2 — exact all-stride obstruction for every odd slope u

For `N>=8`, power of two, and each odd `u`, let `a=2u` and define `W_a` above. Then

```
min_(1<=b<N) rank(W_a - Z^b) = N/2 - 1.
```

All ranks here are exact over **every field**, including characteristic two.

**Proof.** For arbitrary permutations `U,V`, `rank(U-V)=N-#cycles(V^-1 U)`, since fixed vectors of a permutation are constant on its cycles. At all but two bridge edges the differences `W_a(j)-j mod N` equal `+a` on even indices and `-a` on odd indices. Exactly `m-1` edges have each such difference; the two bridges have differences `+(a-1)` and `-(a-1)`.

For a stride `b` other than `+a` or `-a`, at most one edge agrees with `Z^b`. If `f` vertices of a permutation are fixed and the others form cycles of length >=2, its rank is at least `(N-f)/2`. Therefore for these strides the rank is at least `ceil((N-1)/2)=m`.

For `b=+a,-a`, conjugate the ordinary zigzag case using the parity-preserving bijection `phi(j)=u*j+(u-1)*(j mod 2) mod N`. This sends `W_2` to `W_a` and `Z^(+/-2)` to `Z^(+/-a)`. For `a=2`, the permutation `Z^-2 W_2` has `m-1` even fixed points and exactly two nontrivial cycles: one of length `N/4+1` and the other of length `N/4`. Thus its rank is `m-1`; reflection gives the same result for `-2`. QED.

The tested lengths `N=8..512` match exactly, and the all-slope cases at `N=16,32,64,128` were independently exhausted by the regression suite.

## Theorem 3 — almost-maximal noncommutation in two constant-work cycles

For the same family,

```
rank(W_a Z - Z W_a) = N - 2.
```

To see this, consider `V=(Z W_a)^-1(W_a Z)`. Away from three exceptional indices, `V` maps even `j` to `j-2a` and odd `j` to `j+2a`. Its exceptional mappings are

```
V(a-2)   = -a,
V(a)     = a-1,
V(-a-1)  = -a-2             (all modulo N).
```

Since `a=2u`, `u` odd and `N` a power of two, the ordinary `+/-2a` steps separately cycle through each residue class modulo four. The three exceptional links merge the classes `0,2,1 (mod 4)` into one `3N/4`-cycle; class `3 (mod 4)` remains an `N/4`-cycle. Therefore `V` has exactly two cycles, and the rank equals `N-2`.

For admissible nonzero `alpha,beta`, put

```
A=I-alpha*W_a,     B=I-beta*Z,
G_a=A^-1,          G_z=B^-1.
```

The identity `[A^-1,B^-1]=A^-1 B^-1 [A,B] B^-1 A^-1` proves

```
rank([G_a,G_z]) = rank([W_a,Z]) = N-2.
```

Both resolvents apply to arbitrary vectors in `O(N)` operations: write the cyclic first-order recurrence in the order of their respective Hamiltonian cycles and solve the wrap equation with the denominator `1-alpha^N` or `1-beta^N`. This rank conclusion is **not** a Fourier identity.

## Theorem 4 — linear-time inverse for the twisted Green sum

Take `a=m+2` and `N>=16`. Define `S=G_a+G_z` with the same resolvents. Then

```
S = A^-1 (A+B) B^-1,
S^-1 = B (A+B)^-1 A.
```

The denominator `A+B=2I-alpha W_a-beta Z` is sparse. Reorder the coordinates in consecutive four-track cells

```
(2t, 2t+1, 2(t+N/4), 2(t+N/4)+1),   t=0,...,N/4-1.
```

In this order, all edges are within bandwidth six **except exactly four** edges, for every size `N>=16`:

```
W: 1 -> m-1,  N-2 -> m,
Z: m-1 -> m,  N-1 -> 0.
```

The transformed `A+B` is therefore a fixed-bandwidth matrix plus four rank-one entry updates. One width-six LU factorization plus a `4x4` Woodbury correction gives an exact `O(N)`-field-work executor for `(A+B)^-1`. Sparse applications of `A` and `B` add `O(N)` work. Precomputation and workspace also use `O(N)` field operations/storage. This is independently implemented in `phase25_twisted.py`; forward/inverse round trips pass through `N=16384` over `F_998244353`.

For **complex** `|alpha|,|beta|<1`, individual resolvents are nonsingular. Let `delta=|alpha|/(1-|alpha|)+|beta|/(1-|beta|)`. Since both permutations are unitary, `||S-2I||_2<=delta`. If `delta<2`, then

```
kappa_2(S) <= (2+delta)/(2-delta).
```

For `alpha=1/4, beta=1/5`, `delta=7/12`, so `kappa_2(S)<=31/17` independently of `N`. The banded matrix is strictly diagonally dominant in that example, guaranteeing nonsingular leading pivots and an invertible Woodbury correction. **These are complex-number stability bounds, not finite-field norm statements.**

## Observation — full natural-cut rank does not certify Fourier complexity

Let `I_nat={0,...,m-1}` and `J_nat={m,...,N-1}`. The twisted cycle has `m-1` edges from `J_nat` to `I_nat`, whereas the natural cycle has one. For a cyclic Green inverse `G=(I-alpha W)^-1`, the off-diagonal rank across complementary sets equals that of `I-alpha W`: by block Schur complement, the rank of `G[I,J]` equals the rank of `A[I,J]` because `A[J,J]` is invertible (a proper induced subgraph of one directed cycle has no directed cycle). Hence

```
rank(G_a[I_nat,J_nat])=m-1,
rank(G_z[I_nat,J_nat])=1.
```

For `alpha=2,beta=3` over `F_998244353`, the **sum** has full natural cut rank `m` at every checked `N=16,32,64,128`. Full rank for arbitrary parameters and every length is **not claimed**.

## Theorem 5 — the hidden all-size rank barrier and approximation-error floor

Despite its full natural cross-cut rank, the twisted family has a **different** balanced partition. Let `N=4q` and

```
I = {0,...,q-1} union {2q,...,3q-1},
J = {q,...,2q-1} union {3q,...,4q-1}.
```

Exactly **three** `W_a` edges and **two** `Z` edges go from `J` to `I`:

```
W_a: q+1 -> 3q-1,   3q+1 -> q-1,   N-2 -> 2q,
Z:   2q-1 -> 2q,    N-1 -> 0.
```

As above, their inverses have the same off-diagonal ranks as their sparse denominators. Thus for the sum and also for a sum with arbitrary **diagonal gauges on each term**,

```
rank(S[I,J]) <= 3+2 = 5                 (ALL N>=16).
```

The checked nondegenerate modular instances attain rank five through `N=128`.

This obstruction persists after **arbitrary external permutations and invertible diagonal scalings**, because such changes simply move the rank-five block to another balanced pair of row/column subsets.

Let `Fhat` be the normalized Fourier matrix. For *any* balanced subsets `R,C` of size `m=N/2`, its submatrix `Fhat[R,C]` has squared Frobenius norm `m^2/N=N/4` (all entries have magnitude `1/sqrt(N)`) and spectral norm at most one (it is a submatrix of a unitary). Consequently its rank is at least `N/4`.

For a rank-at-most-five approximation of that submatrix, the Eckart–Young theorem and the singular-value bound imply

```
||M-Fhat||_2 >= sqrt( (N/4-5)/(N/2-5) )     (N>20),
```

whenever `M` is the twisted sum or any outer monomial equivalent of it. Indeed the sum of squared singular values below the top five is at least `N/4-5`; divided by the remaining `N/2-5` singular values, this forces the sixth singular value squared to be at least the displayed ratio. The limit of this lower bound is `1/sqrt(2)`.

In particular, no amount of outer diagonal scaling or input/output reordering can make this single stage equal, or converge in operator norm to, the arbitrary-input normalized DFT as `N` grows. **This does not rule out products of different Green sums, internal phase layers, or more general shared-state programs.**

## Verification and limitations

1. Exact all-stride rank checks for two-run families through `N=512`; all admissible odd slopes exhausted at `N=16,32,64,128`.
2. Exact commutator-rank identity verified with permutation cycles, and dense finite-field resolvent commutators at `N=8,16,32`.
3. General affine-run Fourier formula compared with independent O(N^2) DFTs at small sizes and independent radix-two NTT through `N=16384`, including `z=0`, roots of unity, and nonroot nodes.
4. Exact two-order Green sum inverse implemented for simple and twisted zigzags, with many modular forward/backward tests through `N=16384`.
5. Full natural-cut and rank-five hidden-cut matrices checked over finite fields at sizes through `N=128`.
6. Complex numerical condition-number checks performed for `N=16,32,64`, while the uniform condition-number inequality is analytic.

Model: fixed prime field for executable exact arithmetic, and exact complex arithmetic for the theorem. There is **no arbitrary-input O(N) FFT**, **no o(NlogN) worst-case bound**, **no new integer multiplication bound**, and no guarantee of numerical stability for arbitrary near-resonant complex parameters.
