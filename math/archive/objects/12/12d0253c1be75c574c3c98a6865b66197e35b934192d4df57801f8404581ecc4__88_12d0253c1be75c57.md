# Inverse-cycle research: proof, exact-capable primitives, and independent checks

9 October 2026. Read `RESULT.md` for the unified outcome and `PROOF.md` plus `COMMUTING_PHASE_GATE.md` for the proofs. This is a portable, self-contained research bundle; it includes no uploaded executable source and makes no publication or priority claim.

## What was established

- An opposite-sign pair of K(M)=(2I-M)(I-M)^-1 stages can be a genuinely dense all-pass unitary with a fully charged O(N) scalar-arithmetic implementation. A complete two-stage classification shows that such a pair is either cancellation or this all-pass family.
- The explicit all-pass blocks have induced-1 condition number below 4. Products of individually unitary blocks, including the stated bounded-condition Green/rank-one wrappers, obey logarithmic factor-count gates.
- Using literally one M and M* cannot produce a flat unitary at any depth.
- Allowing all phase rotations lambda M and lambda M*, lambda^N=1, gives a larger commuting family, but it still needs at least log_2 N original stages for Fourier flatness. Below N/2 stages, every globally scalar-unitary word reorders into unitary opposite-sign pairs. The common-family condition must still hold after any interior monomial conjugations.

No exact arbitrary-input, all-output o(N log N) Fourier algorithm was found. Genuinely noncommuting changes of cycle and arbitrary other commuting cycles remain outside the classification.

## A constructive control for shared work

For even N=2m, the m forward stages with lambda^m=1 fuse exactly to

    [(2^m+1)I+(2^m-1)M^m]/2.

This is scalar-unitary and applies in O(N) scalar arithmetic after preparation, even though applying its displayed stages separately would cost Theta(N^2). It has only two nonzeros per row, so it is not Fourier for N>2. The control demonstrates that shared work and algebraic fusion can be real; a factor-count theorem is not an unrestricted arithmetic lower bound.

`apply_fused_halfcycle.py` supplies a reusable exact-capable evaluator. Weighted-cycle gauge preparation takes O(N) scalar operations. Computing 2^m uses O(log m) field multiplications for m>=2, while the coefficient has Theta(N) bits. Neither this primitive nor the dense all-pass evaluator claims bounded-word arithmetic or O(N) bit complexity.

## Run the checks

Python 3.10+ with NumPy and SymPy is sufficient. The recorded run used Python 3.12.14, NumPy 2.3.5, and SymPy 1.14.0. No network, account, secret, external dataset, or uploaded code is used by the checkers. Install the dependencies in your chosen environment if needed, then run from this directory:

    sha256sum -c SHA256SUMS
    python check_pairs.py
    python check_commuting_phase.py

The checkers overwrite their respective JSON result files. Verify the archived hashes before running them: numerical residuals may differ slightly across platforms. Exact matrix assertions are explicitly distinguished from numerical finite checks. The all-N claims rest on the proofs, not on the enumerations.

Both scripts passed in the working directory and were rerun successfully after clean ZIP extraction. The extension checks cover 238,767 commuting multisets, 12 exact Gaussian-rational phase-matrix cases, all phase indices for N=3,...,12, seven cutoff identities, and six exact weighted fused-evaluator cases. The base checks include eight exact matrix lengths, 872 directed cycles, 64 fixed-cycle powers, six weighted evaluator cases, and eight operation-count cases through N=256.

The ZIP excludes caches and compiled bytecode. Nothing was uploaded or published.
