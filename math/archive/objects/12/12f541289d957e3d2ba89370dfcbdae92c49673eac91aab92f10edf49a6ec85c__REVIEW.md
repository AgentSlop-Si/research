## Findings that matter

1. **The stored network verifier has a vacuous-success route.** In `verify_certificate.py`, lines 66–71 are the only Fourier-root/determinant verification. An empty `finite_fields` array skips them all. Keeping the remainder of a valid graph certificate unchanged then reaches line 72, which claims two primitive-root minors passed, and returns True. One repeated field entry also does not establish two independent fields. The graph cut alone does not establish the Fourier rank lower bound. The verifier also accepts arbitrary modulus values without checking primality, although its Fermat inverse and cyclotomic specialization require the stated field assumptions. The archived object actually has two distinct listed moduli; this flaw does not disprove it.

2. **The tangent verifier mixes two moduli and can accept a realizable direction as incompatible.** `tangent_certificate.py` line 75 loads certificate modulus `P`, but `basis`, `rank_mod`, `row_col_constraints`, and checks at lines 89–91 use the imported field `MOD=12289`. Only the last pairing uses `P`. A static counterexample schema: keep any otherwise accepted nonzero J/G with GJ=0 modulo m=12289; take a nonzero column D=J[:,k] (canonical residues), choose i with D_i nonzero, set q=m e_i, P=m²+1, and pairing=m D_i. Then G D=0 and q J=0 modulo m, whereas 0<m D_i<P, so the final pairing passes and is nonzero. D is explicitly in the image of J. The same schema works with prime P=2013265921>m², so primality checking alone would not repair the field mismatch. No source or mutated certificate was run. The archived certificate uses modulus 12289 and is not invalidated by this schema. Equality of the declared field with the actual arithmetic field, normalization/shape checks, and explicit exceptions would block it.

3. **Assertions are critical acceptance checks.** Optimized Python drops the root, determinant, tangent, curvature, polynomial-control and stress assertions. Unittest's own assertions remain, but tests that only check a verifier's literal True/string can then pass without its mathematical checks. Both suite runners spawn `sys.executable` without `-O`, so invoking a runner under `-O` alone does not propagate that flag; inherited `PYTHONOPTIMIZE`, or directly optimized child/test execution, does. This distinction matters.

4. **The exception-complete encoding has the right restricted scope.** `complete_quadratic.py` directly encodes 112 off-diagonal factor equations plus 64 product equations in 128 matrix-entry and 56 generator variables. It covers zero-generator/zero-anchor cases of the separated rank-one model and needs no inverse or saturation. It does not cover every quasiseparable-order-one matrix, solve the equations, or reduce the actual elimination workload. `exceptional_charts.py` supplies a valid rational inverse counterexample and a singular all-ones spurious solution for the separate inverse/open-chart formulation.

5. **Finite evidence must retain its direction.** A nonzero Fourier determinant over a valid prime field at a primitive 64th root gives a characteristic-zero nonvanishing witness by cyclotomic divisibility. A sampled zero determinant/rank deficit, an unsuccessful witness search, sampled tangent compatibility, or finite synthetic positive controls do not establish characteristic-zero feasibility/nonfeasibility. A modular Jacobian rank is a lower bound upon lifting, not an upper bound. Characteristic-zero transversality from an augmented rank therefore additionally needs the independent structural Jacobian upper bound.

6. **The runners can report success for empty suites.** The older runner checks that four test directories exist and child exit codes are zero, then prints a hard-coded 29-test count. Unittest discovery can return zero after discovering no tests. The newer runner parses actual counts but does not require them to be positive or match an expected manifest. Neither rejects skipped tests, authenticates test hashes, enforces network isolation, or supplies a timeout. These are regression launchers, not hermetic proof-certificate checkers.
