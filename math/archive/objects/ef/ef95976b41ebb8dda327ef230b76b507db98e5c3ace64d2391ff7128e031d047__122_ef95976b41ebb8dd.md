# Next rigorous candidate — high-rank bidirectional-sum stages with internal routing

The previous fixed-layout cut rank obstruction did not handle permutations *between* scans. The **current** inverse-sparsity theorem now rejects `o(log N)` single-direction invertible scans with arbitrary shuffles. It also rejects replacing the missing scans by a subpolynomial total budget of rank-one broadcasts:

    t one-way scans + B broadcast rank  =>  (B+1)(2**t+1)>N.

Do **not** repeat: subtree collision caches; finite-table leaves; Galois orbit symbolic descriptors; packed big integers; short recurrence filters; sparse input updates; dense-output false comparisons; rank-frame certificates optimized for CrocSwap; global one-way scans and arbitrary interleaved permutations alone.

## Surviving, falsifiable proposal

Consider **a single O(N)-work bidirectional-sum stage**

    y = L_forward(x) + U_backward(x) + D*x,

where each one-way scan sees the *same* input, with arbitrary but input-independent weights, and D is diagonal. Unlike a product of one-way scans, a generic sum has an inverse with N nonzeros per row. The current inverse sparsity bound does not apply to such stages. Our exact control found full-density inverse matrices for N=4,8,16,32, not FFTs.

Research question: can a **uniform sequence of o(log N)** such fully charged stages, interleaved with arbitrary O(N)-traffic permutations and diagonals, implement F_N on fresh arbitrary complex inputs?

Required tests before presenting a positive result:

1. Exact factorization identity for infinitely many N, not a finite optimized matrix fit.
2. Each stage evaluated in O(N) ordinary field operations with all needed intermediate arrays explicitly allocated/read/written; if it secretly contains a dense N×N primitive, reject.
3. Count twiddle coefficient generation and root/precision requirements.
4. Show an all-output exact arithmetic recurrence strictly better than known FFT bound in a **matched model**; use direct modular checks on each complete basis for small N.
5. Test the *inverse displacement rank* and cut ranks under successive permutations; failing the one-way proof alone is not evidence of a faster factorization.
6. Compare with the old classical butterfly/Cooley–Tukey and with OpenAI #130 as prior art, without defaulting back to CrocSwap's kappa tuning.
7. If bounded-condition/unitary 2-coordinate gates are claimed, confront existing Morgenstern/Ailon barriers.

**Status:** No sub-log-stage bidirectional-sum factorization found or implied by this project. This is the remaining candidate of this particular global scan program, not a promise that O(N) is achievable.
