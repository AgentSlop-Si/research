# HERO1 mixed-radix v13 independent audit

Read `AUDIT_AND_EXTENSION.md` for the verdict, proofs, test-coverage correction, and bounded shared-randomness/conditioning extensions.

This directory contains only independently authored audit work. No source checkpoint code was imported or executed. Source provenance is in `SOURCE_REFERENCE.json`.

Run with Python 3 and NumPy:

```sh
OPENBLAS_NUM_THREADS=1 python independent_v13_audit.py v13_independent_replay.json
```

The optional output path avoids overwriting sealed recorded results. Checks include exact modular recurrence/CT entries, integer covariance identities, exhaustive complex ensembles, phase-sign/wrong-spacing controls, and completed-bank conditioning. This is an audit implementation, not a benchmark or fast Fourier algorithm.

`SHA256SUMS.txt` seals the report, checker, recorded output, and provenance; verify with `sha256sum -c SHA256SUMS.txt` from this directory.
