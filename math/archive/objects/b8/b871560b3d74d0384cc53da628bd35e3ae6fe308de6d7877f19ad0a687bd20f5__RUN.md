# Quick run

```
cd hero17_phase8_multistage
python -m unittest discover -v
python independent_audit.py
```

No third-party Python packages are required. All fields/roots are discovered in independent test fixtures; the online radix-2 evaluator assumes the primitive root and charges the N−1 root-power multiplications. Do not mistake test fixture primality search for a uniform NTT field-selection algorithm.

Look in `RESEARCH.md` for formulas, `PROOF_CERTIFICATE.md` for proofs, and `AUDIT_RESULTS.json` for exhaustive search tables and individual implementation ledgers.
