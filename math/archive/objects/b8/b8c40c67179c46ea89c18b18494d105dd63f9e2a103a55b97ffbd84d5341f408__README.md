# Phase 26 independent audit

Read `PHASE26_AUDIT.md` for the proof audit, the factor-two Hamiltonian crossing improvement, exact term-budget qualifications, and the strict-witness implementation defect.

The original Library-discovered archive is preserved unchanged under `source_archives/`. `SOURCE_INPUTS.json` gives hashes and provenance. No submitted code was executed.

Run the independently authored controls with:

    python independent_checks.py

The standard library suffices for all exact checks. NumPy, if present, adds a numerical SVD control. Results are saved to `CHECK_RESULTS.json`; the included `RUN.log` records the completed audit run.

Main results:

- The restricted `Omega(log N/log log N)` Green-term bound and complex approximation obstruction are valid.
- A Hamiltonian cycle's incoming crossing count is at most the sum of centered step shifts plus half its exceptional-edge budget, rounded down.
- For `d=1,b=2`, the strengthened first nonexcluded budgets at `N=2^32,2^64,2^128,2^256` are `7,12,21,36`. These are necessary-only cut screens.
- The source's floating witness finder can accept equality instead of its claimed strict bound. The independent finder uses exact integer pigeonholes.
- The weighted `N=256` rank-38 example, full-rank Fourier minor, outer-monomial transfer, and non-affine sampled controls were independently reproduced.
- No arbitrary-input faster FFT or new integer-multiplication bound follows.

The package is a bounded mathematical and code audit, not peer review or a claim of research priority.
