## Proposed carrier-anchor change: static review

The bounded candidate allows acquire() to use a current block's retained carrier slots as XOR-clearing anchors as well as its desired output slots. This is algebraically admissible if those slots are the actual retained carriers of that block, remain XOR sources, and are not also the retired destination. They already have the current frame, and their future destination envelopes contain it. The experiment changes both acquire() call sites and resets the carrier-anchor list each block.

The nominal zero-signal clearing test alone does not establish dirty-scratch safety. The emitted full word must still be replayed on every input and dirty basis vector in both orientations. Its actual frame incidence list must be reconstructed independently, every fixed-basis residual block recomputed, and W/depth/row stock assembled anew. The unchanged complex guard is permissible only because this candidate changes the finite bit circuit rather than the semantic complex transform.

There is no identified general no-gain theorem from the maximum carry matching: matching operates in a local symbolic input space, while reclamation tests global signal dependencies. A failed experiment only excludes this anchor expansion on the fixed two-axis construction.
