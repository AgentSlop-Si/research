# Graph reuse and energy pruning — research continuation, 2026-10-09

**The independent exact, fresh arbitrary-input, full-output FFT goal below
N log N remains unachieved.** This package adds a proved deterministic linear
work approximation at a specified global error scale, a cheaper exact compiler
for related transforms, and fixes to the supplied sparse-surrogate v2 code.
It also establishes an honest O(N log N) comparator for the remaining exact
q-kernel, so beating a quadratic reference is no longer mistaken for beating FFT.

The three newly supplied archives are preserved in `inputs/`. They are reviewed
as evidence, not adopted as an independent breakthrough. In particular the
constructive conditioning theorem remains conditional on a fast local primitive;
the external #130 / integer-mult-kappa route is not counted as our result.

## What survived proof and implementation review

| Result | Scope and cost | Exact-goal implication |
|---|---|---|
| Energy-pruned DIF | All N approximate outputs, error <=epsilon||x||_2 for unitary DFT; deterministic O(N[1+min(log N,log epsilon^-2)]) ideal real work | Linear for fixed epsilon; does not solve exact FFT |
| Target-difference compiler | One ADD_T plus two sparse ADD_J calls per graph edge; arbitrary initial targets restored around their increments | Exact reuse for related queries; first transform remains charged |
| Fast H_q(C) comparator | Ordinary FFTs give O(N log N), coefficient setup O(N) | Full-factorization cancellation recovers an ordinary FFT |
| High-degree tail fusion | r highest degrees of p(C)T act in O(rN+r^2) including preparation | Fixed-r exact linear action; full r=N remains quadratic |
| Shifted resolvent | (lambda I-C)^-1 action O(N), lambda nonzero | N separate weighted resolvents still quadratic |
| Rational degree theorem | H_q(C)=p(C)/r(C) requires deg p+deg r >= N-1 | Excludes bounded total degree, not fast high-degree algorithms |
| Finite tail and cyclic regularization | Exact first-layer spectrum, recurrence and singular limit | Retain the unresolved full operator; no missing boundary terms |
| Surrogate v2 fixes | One-selection head planner; refresh input-dependent cached plans | Repairs planner cost and a reproduced incorrect reuse case |

## Deterministic linear approximation: the contract matters

For U=F_N/sqrt(N), the energy algorithm returns exactly the hard-thresholded
vector in ideal arithmetic: retain (Ux)[k] iff its magnitude exceeds
epsilon||x||_2. A DIF subtree owns disjoint output positions and its energy
bounds each of them. At depth d at most min(2^d,epsilon^-2) nodes can exceed
threshold. Summing their lengths, including every norm scan, proves the bound.
All N outputs are physically returned and O(N) coefficient preparation is paid.

This is an adaptive real-arithmetic algorithm with charged nonlinear norm tests
and comparisons. It is not a fixed linear circuit. The prototype is complex128,
not a certified floating-point realization. Its error contract can permit the
all-zero answer for diffuse spectra. Details and the all-size proof are in
`fft_energy_pruned_research/README.md` and `PROOF.md`.

V2's epsilon||x||_1/sqrt(N) contract is stronger on general inputs. To match it,
use epsilon_E=epsilon||x||_1/(sqrt(N)||x||_2), which can restore N log N work.
An impulse is an explicit example where calibrated pruning runs the full tree
but the surrogate's exact sparse-input path is linear. V2's time-domain sparse
support barrier is valid and does not constrain a general adaptive spectral
threshold algorithm. There is no uniform same-scale domination claim.

The 36 recorded cold timing comparisons produce **zero wall-clock wins** over
NumPy: approximately 1.25–58.63 times slower. Reduced arithmetic work is useful
theoretical progress under this approximation contract, not a measured speedup.
FFT pruning and adaptive FFT-tree traversal have substantial prior art; this
package makes no global novelty claim.

## The exact reuse rule to keep

For TK=JT and R target banks, compute y_r += T K^r x by descending updates
y_r -= J y_(r-1), one y_0 += T x, then ascending updates
y_r += J y_(r-1). Arbitrary initial targets cancel correctly. The source is
restored, dirty workspace is untouched, and J need not be invertible.

With the reference dense triangular T and the actual sparse q-Weyl J, the
emitted online scalar count is

    3N(N+1)/2 + 2(R-1)(6N-3).

At N=128,R=8 this is 35,478 instructions versus 49,716 for the earlier
first-target anchor schedule, for the same map. These are emitted scalar counts,
not CPU times. The first reference T remains quadratic. Known source support S
changes its term to 3 sum_(j in S)(N-j); this is a projected-source map and must
not be used as a speed ratio for an arbitrary dense source. General acyclic
target graphs admit the same descending/inject/ascending proof; only the chain
is implemented in the main compiler audit.

Approximate anchor errors propagate as J^r e. The q-Weyl J is not unitary, so
a Fourier sampling guarantee cannot be silently transferred through it. A
separate ordinary Fourier shift instance does preserve the error norm.

## Repairs and boundaries in the new material

- V2's default planner repeatedly selects/scans all N entries. The replacement
  selects the largest H once, sorts only those entries and evaluates candidates
  from prefix sums: O(N+H log H+J), linear for default polylogarithmic H.
- A cached head-only plan from a spike was accepted for a same-length flat
  vector and violated the requested bound by 99.9 times. The safe adapter uses
  it only as a head-size hint and refreshes masses and sample budget.
- An absolute exponential envelope is insufficient for uniform relative tail
  control. The corrected compressibility hypothesis is relative to ||x||_1.
- The constructive theorem handles earlier padding, scratch and scalar-prefix
  concerns, but still assumes a sub-N-log-N local primitive. A tighter alphabet
  coefficient bound improves a conditional conditioning budget, not arithmetic
  complexity. Its historical SymPy test log is not treated as a fresh PASS.

## Reproduce and navigate

Run `python3 run_all.py` from this directory. Exact algebraic checks use the
standard library. Numerical approximation and source regression suites require
NumPy; `requirements.txt` records that dependency. The driver runs each module
in a separate process and writes concise status plus complete per-suite logs to
`verification/`. Existing benchmark results are retained without rerunning
timings. Missing dependencies are reported as skipped, never passed.

Key finite audit evidence, with different scopes kept separate:

- Energy pruning: 3,331 exact rational cases, 12,959 exact output coordinates;
  4,085 numerical direct-DFT comparisons plus adversarial/range controls.
- Target differences: 120 cases, 3,900 full-state basis vectors and 360 mixed
  states, checking both compiler schedules and emitted counts.
- Fast exact kernel/resolvents: 266 basis vectors, 532 inverse-spectrum bins,
  843 solves, 281 covariance checks and 75 related-query outputs.
- High-degree fusion: 96 configurations and 2,432 basis/mixed checks.
- Rational degree: 407 inconsistent lower-degree systems and 138 sharp
  approximants; all-size conclusion follows from the determinant proof.
- Conditioning: six source height tests and 60 independent rational scalar
  prefixes. The supplied 13-test SymPy suite was blocked by missing SymPy in
  this environment and is not claimed as reproduced.
- V2 repair: six new source tests and 16 planner comparisons; actual full-vector
  selections at N=65,536 reduced from nine to one.

The copied `fft_qbasis_research` and `fft_qweyl_boundary_research` directories
are earlier dependencies, not new discoveries. Each component README states
its conventions, proof, operation model, preparation and limitations.
`SOURCE_MANIFEST.json` identifies the three input archives and prior checkpoint;
`verification/summary.json` records the integrated run.

## Remaining exact research target

The useful unresolved object is the complete H_q(C) action (equivalently its
specific weighted resolvent aggregate) with every finite-boundary term retained.
An independent improvement must reduce the complete graph below the ordinary
O(N log N) comparator while charging all constants, first evaluation and outputs.
Linear individual resolvents, cheap related-query updates and low-rank highest
tails are available primitives, but no current combination closes that gap.
