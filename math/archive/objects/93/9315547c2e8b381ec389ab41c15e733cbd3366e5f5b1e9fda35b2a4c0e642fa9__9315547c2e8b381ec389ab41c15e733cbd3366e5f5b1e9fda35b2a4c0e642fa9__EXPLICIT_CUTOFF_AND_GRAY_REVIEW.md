## 1. Explicit bit-reversal rectangle

Let `N=2^m`, `R_m` be bit reversal, and

\[
C_m(W,t)=\#\{0\le j<W:R_m(j)<t\}.
\]

The following exact rectangle is available for every `m>=1`:

- Even `m`: `W=t=(N-1)/3` and `C=(N+3m-1)/9`.
- Odd `m`: `W=(N+1)/3`, `t=(2N-1)/3`, and `C=(2N+3m+2)/9`.

All quantities claimed as integers are integers. The discrepancy is

\[
D_m=C-Wt/N=\frac m3+\frac19-\frac{(-1)^m}{9N}.
\]

Proof by two parity recurrences: the bases `m=1` and `m=2` each have count one. Increasing `m` by two changes the length to `4N`, and

\[
R_{m+2}(4j+r)=N R_2(r)+R_m(j),\qquad R_2(0,1,2,3)=(0,2,1,3).
\]

For even `m`, `W'=4W+1` and `t'=N+W`. All `r=0` indices are accepted, contributing `W+1`; the `r=2` indices contribute the old count `C`; the other residues contribute zero. Hence `C'=C+W+1`.

For odd `m`, `W'=4W-1` and `t'=2N+t`. Residues 0 and 2 each contribute `W`; residue 1 contributes `C`; residue 3 contributes zero. The omitted final residue is 3, so there is no correction. Hence `C'=C+2W`. Substitution proves the closed forms and discrepancy.

This is an explicit lower bound for the maximum rectangle discrepancy, not an assertion that this rectangle is always maximizing.

## 3. Gray crossing count

For `G_m(j)=j xor (j>>1)`, let `v_m(t)` count the adjacent-index membership changes of the preimage of `[0,t)`. Then

\[
\max_t v_m(t)=m.
\]

To prove it, set `H=2^(m-1)`. The Gray sequence is its `(m-1)`-bit sequence in `[0,H)`, followed by the reversed copy translated by `H`. For `m>=2` the joining edge is from `H/2` to `3H/2`. Consequently, for `1<=u<H`,

\[
v_m(u)=v_{m-1}(u)+1_{u>H/2},
\]
\[
v_m(H+u)=v_{m-1}(u)+1_{u\le H/2},
\]

and `v_m(H)=1`. Exactly one of the two translated old thresholds gains one. The maximum therefore increases by exactly one from its base value one.

A maximizing threshold is `(N+1)/3` for odd `m` and `(2N+1)/3` for even `m`. Since each nonempty prefix preimage contains zero, and it contains `N-1` precisely when `t>N/2`, its number of intervals equals `(v_m(t)+1+1_{t>N/2})/2`. The maximum is therefore `floor(m/2)+1`.
