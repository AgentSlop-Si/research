# Phase21 source inventory and immutable lineage

The directory contains the complete Python implementation, exact-algebra tests, independent direct-DFT audits, benchmark JSON, mathematical proof, cost ledger, prior-art references and explicit limitations.

- `PRIOR_PHASE20_COMPLETE.zip` is an unchanged copy of the user's Phase20 checkpoint; it contains the original Phase19 and earlier lineages. SHA-256 is listed in `MANIFEST.sha256`.
- Old Phase20 modules (`resultant_gate.py`, `blind_sparse_rational.py`, `annihilator_engine.py`, `rational_forcing.py`, `green_sparse.py`, etc.) remain available; new Phase21 source code is in `reciprocal_union.py`, `reciprocal_resultant.py`, `compressed_resultant.py`, and `resultant_pattern.py`.
- The compressed-resultant code relies on **a proved algebraic factorization**, not a fitted dataset-specific degree assumption. Tests cross-check the reduced and full resultant.
- The `MANIFEST.sha256` file contains SHA-256 digests for core source/proof/JSON files, excluding transient Python bytecode and log files. The manifest does not hash itself or this inventory.

No modifications to external GitHub repositories were made.
