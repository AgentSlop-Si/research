# Reproduction and preservation

Run only these newly authored programs, with installed Python, SymPy, and the standard library:

    PYTHONDONTWRITEBYTECODE=1 python fresh_controls.py
    PYTHONDONTWRITEBYTECODE=1 python fresh_binary_control.py
    PYTHONDONTWRITEBYTECODE=1 python fresh_perturbation_control.py

Run from this directory, or use absolute paths. The exact-ring control reads only the accepted audit's REBUILT_17.json as comparison data, after its independent construction. The perturbation program imports only this package's fresh_controls.py. No predecessor source is imported or executed.

The programs overwrite their own corresponding output JSON files with fresh results and timings. This changes sealed file hashes. To verify the original sealed package first, run:

    sha256sum -c MANIFEST.sha256
    sha256sum -c INPUTS_BEFORE.sha256

The generated Python bytecode cache is not part of the sealed deliverable. No private or external source code appears in the package.
