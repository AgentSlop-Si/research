# FFT Weyl-orbit / Krylov gate v20

Run from this directory:

```bash
python run_all.py
```

The command:

- executes the eight automated test groups;
- runs the independent packet verifier;
- regenerates `results.json`, `RESULT_SUMMARY.json`, and `benchmark_results.csv`;
- rewrites `MANIFEST.sha256`.

Main files:

- `RESEARCH.md` — full theorem statements, proofs, limitations, and next gate;
- `weyl_packet.py` — exact Green recurrence, character packet and weighted-orbit formulas;
- `krylov_gate.py` — graph-distance/Krylov certificates;
- `test_checkpoint.py` — primary exact regression suite;
- `independent_verifier.py` — independently implemented packet checks;
- `PRIOR_v19_COMPLETE.zip` — unchanged predecessor bundle.

No third-party Python package is required.
