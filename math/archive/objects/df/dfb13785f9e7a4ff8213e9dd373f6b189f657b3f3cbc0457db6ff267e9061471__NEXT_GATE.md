# Next research gate — get past the R fully paid scans or construct an exact Green executor

## Approximate v12 branch

The centered scheme has an exact kernel identity and a stronger, R-independent local error certificate. Nonetheless, computing R different weighted frequency blocks still takes R length-K FFTs and R length-Q prefix scans. **The input-side fusion and shared phase carrier do not remove those gates.**

A useful next hypothesis must propose a single **joint evaluator** of the coefficient family

    d_r[b] = J_r(pi(b/K-c)) G_0[b],    0<=r<R,

and the corresponding rank-dependent gauged prefix scans. Charge all roots, Bessel orders, translations, writes, intermediate storage, and coefficient generation. A valid construction must return *every* selected output with a provable, uniform deterministic or probabilistic error target and actually beat the RQ sequential work for arbitrary dense fresh inputs. Simply viewing rank as a SIMD dimension is not enough.

A promising mathematical direction is to check whether the sampled generating function

    sum_(r in Z) J_r(z_b) t^r = exp((z_b/2)(t-t^-1))

can be **contracted directly** against output-specific Chebyshev coefficients and the shared chirp Green operator, eliminating the order index before the global scan. This is currently a problem statement, **not** an algorithm or a proven complexity reduction.

## Exact Green branch (Phase 22)

Do not conflate our approximate v12 guarantee with exact FFT progress. The existing exact-characterization target is a real residual C satisfying

    C Z = R C,     C e_0 = v,

where R is sparse and C is orthogonal. Phase 22 showed uniqueness and a phase/Gram obstruction, **not** an O(N) way to apply C. Its own pair-unitary entropy argument blocks a naive orthogonal-butterfly compression but does not settle nonunitary Green networks.

An independent exact path would synthesize a noncommuting shared-state Green circuit G, verify the two Weyl/covariance identities **symbolically or over an exact coefficient ring with a valid lifting argument**, and apply it to all basis vectors. Then count every solve/iteration/coefficient setup. Stop immediately if the construction merely executes conventional CT stages in disguise.

## What would count as an actual breakthrough?

- Exact all-length transform: `G_N x = U_N x` for *every* x (proved matrix identity), fully charged worst-case work `o(N log N)` sequentially, with reasonable coefficient/precision contract.
- Or a genuinely stronger **approximate** theorem specifying target norm, probability, bit precision and work, and improving on v11/v12 under those precise assumptions.

No such stronger asymptotic theorem is established in this checkpoint.
