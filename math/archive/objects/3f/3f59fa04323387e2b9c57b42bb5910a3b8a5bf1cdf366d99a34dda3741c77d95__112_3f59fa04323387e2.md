# Compatible shrinking-error extension, now with certified eager decoding

The new shrinking-error materials combine with our guarded decoder and exact
periodic control variate. Widening each output block with the sample count
keeps descriptor work linear; guarded packed sums control the remaining cost.

The resulting approximate word-RAM bounds, including all cold setup, are:

| Time | Additive error factor |
|---|---|
| O(N) | O(log log N / sqrt(log N)) |
| O(N log N / log log N) | O((log log N)^(3/2) / log N) |
| O(N tau), 1<=tau<=log N | O(log log N / sqrt(tau log N)) |

The factor multiplies `L_box(x)/sqrt(N)`. With the implemented exact periodic
fit it instead multiplies the no-larger `L_box(rho)/(n sqrt(N))`. All outputs
are explicit rational approximations to the unnormalized DFT; the unitary
normalization is used in the error inequality, not treated as a free exact
irrational machine word. `THEOREM.md` gives the full model and proof.

This strengthens the earlier constant-error approximation to vanishing error
relative to total input energy. It does **not** establish an exact arbitrary-
input FFT improvement, a practical FFT replacement, or novelty.

## What was repaired and tested

The uploaded prototype used an on-demand table and scalar online re-packing.
The combined implementation uses the existing complete, directly indexed
eager table, stores rows already packed, checks word widths, and constructs
its trigonometric values with certified integer arithmetic. Increasing
precision costs O(log log N) bits and is fully included in setup.

`parameter_schedule.py` computes exact rational schedules from
`L=ceil(log2 N)` without constructing N or any table. It explicitly reports
the g=0 finite base regime, uses gamma(L-1) to certify the table limit for
nondyadic N, and verifies error, word-field and conservative cold-work bounds.
The general frontier is available with `mode="frontier", tau=Fraction(...)`.

`python run_audit.py` passed:

* 80 symbolic schedule configurations, including the general frontier;
* two complete eager tables, with 65,536 and 32,768 rows;
* 1,158 decoded sample-output comparisons and 386 real fusion-output comparisons;
* five certified integer phasor precision levels, independently checked with
  high-precision standard-library Decimal arithmetic.

The wide-block tests include g=2, multiple packed words, cancellation and final
partial blocks. Finite test parameters are intentionally tractable and are not
claimed to instantiate the enormous asymptotic preprocessing crossover.

`python verify_schedule_edges.py` separately checks the general-N planner's
transition flags against exact small and large endpoints of every ceiling
interval for L=2,...,160. Its results supplement the complete decoder audit;
it does not rerun the expensive table tests.

Sibling dependencies are `fft_wordram_decoder_research`,
`fft_control_variate_fusion_research`, and `fft_wordram_integration`.
Source hashes and actual test results are retained in `results.json` and
`schedule_edge_results.json`.
