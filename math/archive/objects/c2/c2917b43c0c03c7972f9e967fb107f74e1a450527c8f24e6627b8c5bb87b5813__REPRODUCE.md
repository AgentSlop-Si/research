# Reproduce this bounded investigation

Run with Python 3 and the installed SymPy library:

    python characteristic_two_probe.py
    python independent_symbolic_controls.py

The first program covers exactly every composite N in range(5,402,4). It saves the finite-field modulus and result for each case in CHARACTERISTIC_TWO_RESULTS.json. Finite successes prove only their listed characteristic-zero cases; none is a uniform proof.

The second program computes ordinary discriminants in degrees 2 through 12 and verifies the exact sector and q-discriminant negative controls. No predecessor program is loaded. Input archive hashes can be compared with SOURCE_HASHES_BEFORE.json and SOURCE_HASHES_AFTER.json; PRESERVATION.json records checks of the immediate manifests and older protected files.
