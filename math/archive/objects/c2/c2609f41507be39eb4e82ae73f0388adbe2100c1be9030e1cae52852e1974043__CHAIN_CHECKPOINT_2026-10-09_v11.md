# Chain checkpoint — fused all-length lift v11

**Canonical bundle:** `fft_all_length_fused_fp_v11.zip`

## Inherited theorem

For every integer `N`, the v10 dyadic lift gives:

- fixed energy-relative error in `O_epsilon(N)` time;
- polynomially shrinking energy-relative error in `O(N log N/log log N)` time;
- all `N` outputs and `O(N)` intended storage.

## Gap found

The v10 saved prototype materialized `R` full Chebyshev arrays, so the code used `Theta(RN)` memory even though a streamed implementation was possible.

## v11 fixes

1. Exact integer nearest-grid mapping.
2. Selected-only v9 decoder plan.
3. Backward Clenshaw evaluation with two length-`N` arrays.
4. Neumann-addition block fusion:

   `J_r(pi*(bM+t)/Q) = sum_h J_{r-h}(pi*b/K) J_h(pi*t/Q)`.

5. Local channels

   `G_h[b] = sum_t S[b,t] x[bM+t] J_h(pi*t/Q)`

   consume the original input once.

## Certified fusion error

Keeping `|h|<=H` adds uniform kernel error

`kappa_RH = (2R-1) A_H(pi(M-1)/Q)`.

The deterministic error is `(tau_R+kappa_RH)||x||2`, and one-row variance is at most

`(M/N)(1+tau_R+kappa_RH)^2 ||x||2^2`.

For the main shrinking-error regime, `H=0` already gives

`kappa_R0 = O((log N)^2/(N log log N)) = N^(-1+o(1))`,

which is negligible relative to the theorem's `N^-alpha`, `alpha<1/2`.

## Complexity

Input-side compression changes from `Theta(RQ)` to

`O((2H+1)Q + (2H+1)RK)`.

For `H=0`, its ratio to the old compression is `O(1/R+1/M)=o(1)`.

The `R` K-FFTs and `R` length-Q scans remain, so total time is still `O(RN)`.

Storage is now genuinely `O(N)` with no rank-dependent full-length arrays.

## Conditional finite precision

If one dyadic chirp row has error

`C_A u log Q sqrt(MQ)||y||2`,

then the complete all-length row has

`O(u log N sqrt(MN)||x||2)`

leading error, because the weighted Bessel l1 sum is bounded by a universal constant `<27.17`.

Sufficient mantissa bits:

`b >= log2 N + log2 log N - log2 g + O(1)`.

This is conditional on a certified Bessel generator, roots, and FFT backend; the saved complex64 run is only a stress test.
