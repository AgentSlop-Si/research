# Research next gate — after joint-orbit conditioning

**Goal unchanged:** a fresh, arbitrary, all-output exact FFT with O(N) sequential *fully charged* work, or a provable growing improvement in the same computational model as the comparison bound.

## Already falsified or completed

- Exact repeated subtrees, input-orbit hashing, low-rank/sparse updates, output pruning, WHT complete-state tables and binary lookup leaves: previous checkpoints.
- Galois **symbolic** O(N) descriptor is not an evaluated numerical spectrum; expanding a primitive orbit is another half-size FFT.
- One exact primitive scalar -> another conjugate with polynomial/rational arithmetic has exponential degree requirements; previous research.
- The **new restriction**: joint decoding of a complete spectrum from r primitive odd measurements has L>= (2^floor(N/(4r))-1)/N on x=(u,1-u). A polynomially conditioned measurement-only decoder needs r=Omega(N/log N). Quantized measurements need b >= N/(4r)-log2(N+2) fractional bits just to avoid an unavoidable collision.
- Frobenius FFT over extension fields has well-established 2017 prior art; unit-cost field automorphisms are not unit-cost exact-complex operations or low-bit-cost output materialization.
- Degree-two Boolean circuits and nonlinear input-k rewriting reduce to ordinary linear transforms; cubic cancellation and spectral completion experiments previously failed to improve the full transform.
- Do not optimize CrocSwap's network exponent unless explicitly changing to that different project.

## Falsifiable next mathematical object

**A direct multi-output evaluator** that uses the original fresh input and a shared set of intermediate linear/nonlinear forms to produce many primitive-orbit outputs **without first converting them to a few unstable scalar representatives**.

1. Give the exact N-dependent gate list and output format, not a symbolic descriptor or an oracle for all Galois automorphisms.
2. Derive total operations including all input scans, twiddle/constant preparation, routing, and all N explicit numerical outputs; distinguish the complex-register and finite-bit models.
3. Benchmark/compare *the same full outputs* against at least the modulated N/2-point FFT for the odd orbit; C++ speedup or fewer counted pointwise products is not a new asymptotic theorem.
4. Show a strict saving for a growing family of N, on arbitrary dense binary data and generic complex data if making a general FFT claim.
5. In stable or finite-precision claims, exhibit a polynomial bound on the condition number and charge the resulting bit width. The present result forbids achieving that solely by decoding O(log N) ordinary Fourier scalar measurements.

**No surviving all-N circuit candidate has yet been constructed.** A new research phase should begin with an actual evaluation identity and a cost recurrence, not another generic optimizer.
