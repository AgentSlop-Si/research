# Hero #17 Phase 11 — Lazy Spectral Union + Green Rank Gate

**Exact finite-field research:** full arbitrary-input DFT through compressed spectral-projector states; sharp restricted rank-distance theorem for local rational Green filters.

**Result:** all output coefficients are correct and root/preprocessing arithmetic is charged; **no O(N) general FFT**. The lazy refinement is precisely radix-2 O(N log N), despite O(N) retained memory. The Green-rank barrier is restricted to rational functions of a fixed cyclic shift.

## Files

- `phase11.py`: fully charged lazy Fourier-state executor, formal-expression generator, rational mask rank checker, sharp witness constructor, explicit matrix-rank reference, linear-time dense cyclic Green solver.
- `test_phase11.py`: 16 correctness and structure tests, including exhaustive degree-one search over F_17.
- `independent_audit.py`: separate fresh-input DFT checks, large independent FFT control, and exact rank audits.
- `AUDIT_RESULTS.json`: operation counts and test sizes.
- `PROOF_CERTIFICATE.md`: complete proofs, assumptions, sharpness construction, escape counterexample.
- `RESEARCH.md`: quantitative results, novelty limits and next target.
- `CHAIN_CHECKPOINT.md`: handoff instructions.

## Run

```bash
python -m unittest -v test_phase11
python independent_audit.py
```

The independent audit imports the prior Phase 10 `phase10.py` executor as a different full-FFT reference. The full ZIP contains a small frozen copy of that reference under `controls/phase10_reference.py` for standalone reproducibility; run from the extracted package directory and it will be discovered.

Input contract: a certified finite prime `p`, primitive N-th root `w` and input values in `F_p`. In the tests, the fixture is `p=2013265921`, with root generator 31. The executor checks supplied root order and counts field operations; it does not generate or certify arbitrary primes for free. `capture=True` stores all debug levels and uses O(N log N) memory; the normal `capture=False` run uses O(N) space.

No scholarly priority is claimed for the standard Fourier, polynomial-zero or circulant ingredients. The identified restrictions are not unrestricted FFT lower bounds.
