# Addendum: the unchanged bank when q=r m

9 October 2026. This adds the opposite rectangular orientation without changing the earlier reports or their seals.

## Scope correction

Section 7 of `BATCHED_FOURIER_EQUIVALENCE.md` proves the conversion for m=rq. That theorem alone does not cover the original odd-exponent dyadic bank, which uses m=2^floor(k/2), q=2^ceil(k/2), so q=2m when k is odd. The argument below covers q=rm directly. It keeps the bank B_all=I_q tensor F_m unchanged; it does not silently exchange m and q.

The bank still has q blocks of length m. The available batch is L=F_q tensor I_m, namely m independent length-q DFTs. We show how one call to L computes all q original length-m DFTs with a paid inverse small-radix postprocessing stage.

## 1. Exact packing and recovery

Let q=rm and N=mq, with positive unnormalized Fourier matrices over a splitting field whose characteristic does not divide N. Let omega be a primitive N-th root and put

    omega_q=omega^m,       omega_m=omega^q,
    omega_r=omega_q^m.

Group the q bank labels as b=gr+h, where 0<=g<m and 0<=h<r. The input to bank b is x[bm+s], 0<=s<m. Pack it into the interleaved L input by

    z[(h+rs)m+g]=x[(gr+h)m+s].                     (1)

This is a permutation of all N coordinates: every L column g receives one length-q vector containing r original length-m vectors in its residue classes modulo r.

Let Y=Lz. Write an L output frequency as t+mu, with 0<=t<m and 0<=u<r. Expanding the Fourier exponent gives

    Y[(t+mu)m+g]
      =sum_h omega_r^(uh) omega_q^(th) Z_(g,h)[t],
    Z_(g,h)[t]
      =sum_s omega_m^(ts) x[(gr+h)m+s].           (2)

For every fixed pair (g,t), the r values indexed by u are an r-point DFT of the twiddled desired results. Therefore

    Z_(g,h)[t]
      =(1/r) omega_q^(-th)
          sum_(u=0)^(r-1) omega_r^(-hu)
              Y[(t+mu)m+g].                     (3)

Place this value at original bank-output coordinate (gr+h)m+t. Equations (1)-(3) recover exactly B_all x on arbitrary fresh input. The inverse normalization 1/r is required and exists under the field contract.

Equivalently, define a packing permutation R_pack and a postprocessor R_out by

    R_pack[(h+rs)m+g,(gr+h)m+s]=1,
    R_out[(gr+h)m+t,(t+mu)m+g]
      =(1/r) omega_q^(-th) omega_r^(-hu).

Then

    I_q tensor F_m = R_out (F_q tensor I_m) R_pack. (4)

All indices refer to the original q-by-m bank. No F_q bank has been substituted for it.

## 2. Explicit r=2 formula

For the original odd-exponent split q=2m, group banks 2g and 2g+1. Pack

    z[(2s)m+g]=x[(2g)m+s],
    z[(2s+1)m+g]=x[(2g+1)m+s].

After one L call, let Y_0=Y[tm+g] and Y_1=Y[(t+m)m+g]. Since omega_2=-1,

    (F_m x_(2g))[t]=(Y_0+Y_1)/2,
    (F_m x_(2g+1))[t]=omega_q^(-t)(Y_0-Y_1)/2.    (5)

These are paid additions, subtractions, a normalization, and one twiddle per pair. They are not an uncharged inverse transform of growing length.

## 3. Full cost ledger

There are m^2=N/r pairs (g,t), each requiring one inverse r-point DFT. An inverse r-point DFT can be evaluated using one forward r-point DFT, an index reversal, and normalization. Thus (4) costs

    one L call + (N/r) T(r) + O(N).

Packing, unpacking, inverse-root power generation, twiddles, scaling, and output writes are included. For r fixed, especially r=2, this additional work and storage are O(N). If r grows, the displayed small-radix transform cost must remain in the ledger. The construction never calls F_m^-1 or a length-q inverse DFT.

The same primitive root omega supplies every needed root. Tables can be generated by consecutive-power recurrences in O(N) work. A modular test program may use exponentiation for readability; that is a control implementation, not the advertised preparation schedule.

## 4. Consequence for the original active-bank identity

Keep exactly the original bank B_J, the same active set J, and

    P_J=(F_q tensor I_m) Delta B_(J complement),
    F_N=P_J B_J R_0.

Suppose the earlier active-support cover applies, for example J is a nonempty contiguous cyclic interval of j blocks. It evaluates L using k=ceil(q/j) calls to P_J, with O(kN) masks, shifts, phases, and additions. Insert that L evaluator into (4), then form

    B_J x=E_J B_all x+(I-E_J)x.

Finally apply R_0 before the bank and P_J after it. The exact total is

    k+1 calls to P_J
      +(N/r) T(r)+O(kN),                         (6)

with one shared preparation of P_J and O(N) reusable scratch for constant k,r.

For q=2m, a contiguous half-active bank requires three P_J calls and only two-point inverse butterflies outside them. A full bank requires two calls. The original m-point bank has not changed. Empty J remains the separate direct identity F_N=P_empty R_0.

This addendum does not remove the active-interval or bounded-cover assumption. An arbitrary active set need not have the same constant-call cover. It also does not construct an O(N) P_J. It completes the conditional implication for the original near-square orientation: if such a uniform linear-time exterior exists with the stated fixed-fraction cover, then the full DFT has a linear-time evaluator on those original dyadic sizes.
