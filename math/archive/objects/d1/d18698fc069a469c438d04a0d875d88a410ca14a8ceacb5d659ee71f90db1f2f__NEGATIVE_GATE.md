# Phase 30 negative gates

## 1. Naive global expression caching does not improve the Phase 29 120-point kernel

The independently compiled symbolic pre/post networks contain 522 and 516 field additions, respectively. Each intermediate is an integer vector of input coefficients, so equality here is an exact characteristic-zero equality. The CSE scan found zero repeats, including no distinct nodes representing vectors equal up to overall negation.

The full 120-point kernel was also symbolically traced over each original prime field. Its 522 pre-additions, 140 middle multiplications, and 516 post-additions generated **no repeated full linear value** and no repeated scalar multiplication. Every result was compared across both primes. Simple DAG interning thus makes no scalar improvement: `1178 -> 1178`.

This **does not** prove globally optimal addition count; rewriting intermediate expressions, nonlocal multi-expression rewriting, and nonrational multi-layer fusion are outside this search.

## 2. Standalone noncoprime twiddle layer admits no rational single-layer multiplication savings

See Theorem 30.1 and Section 5 of `THEOREM.md`. For `h=2^t`, isolated `(8,h)` twiddle entries form a diagonal with `7(h-1)` irrational (nonrational cyclotomic) scalars. Fifteen independent CRT columns give `105(h-1)`. Rational pre/post transforms plus **one** diagonal scaling bank cannot use fewer nonrational channels, since an entrywise Q-linear projection makes the target diagonal matrix have rank `105(h-1)`.

The existing Phase 29 implementation already achieves this count. A genuine improvement must either interleave the twiddle with surrounding *nonrational* transforms, change the computation model, or use more than one scaling layer with fully charged operations.

## 3. Generic projections have a predetermined nullspace

For cyclic length N, all gcd-orbit indicator inputs lie in the kernel of every traceless Q-linear projection of `F_N`. For generic traceless projection those `tau(N)` vectors span the **entire kernel**. Falsifier: any claimed one-projection recovery that reconstructs arbitrary rational inputs without supplementary data contradicts this rank calculation.

This is a lower bound against an explicitly specified projection interface, **not** against the FFT.
