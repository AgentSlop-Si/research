# Independent review of rank-one orbit fusion

Reviewed `rank_one_orbit.py`, `run_orbit_audit.py`, the rank-one and
described-mode portions of `README.md`, and the relevant q-factorial/tail
helpers. No unresolved correctness or cost issue was found within the
supplied-root, exact-field model. The generic nested-state branch is covered
by a separate reviewer; this note does not independently certify that branch.

## Normalization and Fourier convention

The product of the N-1 upper weights of B is

    g_(N-1) = q^(N-1) product_(r=1)^(N-1)(1-q^(-r)) = N/q.

Since C=T B T^-1, its highest nonzero power is exactly `a b^T`, with
`a_i=t_i` and `b_k=g_(N-1)d_(N-1-k)`. Both diagonals are nonsingular.
Putting Q^j on both sides multiplies an entry by q^(j(i+k)), so the
factorization is `diag(a) F diag(c) F diag(b)`, with zero padding of c
when needed. There is no conjugation and no inverse-FFT normalization.
Its rank is precisely the number of nonzero c entries.

For the description `c_j=sum_a gamma_a q^(aj)`, summing the N roots gives

    (M_c x)_i = N a_i sum_a gamma_a b_(-i-a) x_(-i-a),

with cyclic indices. The implementation has exactly this sign and index.
A single nonzero mode is a nonsingular weighted cyclic antidiagonal
permutation. Thus its full rank and linear work are compatible; rank alone
does not require separately materializing N rank-one output vectors.

## Pruning, transpose, counts, and storage

Let R be the least power of two at least s. The forward recursion retains
the first R frequencies, with N/R leaves of length R. The transposed
recursion distributes these values to the even and odd descendants and
uses F_R again at each leaf, since F_R is symmetric. It correctly returns
all N coordinates.

Across both orientations, the leaves contribute N log_2 R multiplications,
additions, and subtractions of each type. The internal nodes contribute
2(N-R) multiplications and N-R additions. The two outer diagonals and
coefficient weighting add 2N+s multiplications. This independently gives
the README's exact online totals:

    mul = N log_2 R + 4N - 2R + s,
    add = N log_2 R + N - R,
    sub = N log_2 R.

The q-factorial preparation plus the extra root table and right outer-product
vector gives `8N+log_2 N-4` multiplications, N-1 subtractions, N-1 negations,
and one constant inverse. Mode preparation adds N multiplications, or 3N
for the single-mode specialization. Its online counts are N multiplications
for one mode, and (t+2)N multiplications plus (t-1)N additions for t>=2.

Depth-first pruning retains O(R log(N/R)) coefficient entries along its
active path, which is O(N). Including the roots, weights, input scaling,
leaves, and full output therefore gives O(N) live field-element storage.
The described-mode route stores O(N+t) entries; it does not precompute tN
matrices. Copying and validating a supplied t-term description costs O(t),
in addition to the counted field arithmetic. The current integer-index
validation addresses the earlier fractional-index coercion issue. Arbitrarily
large integer parsing/reduction has separate bit cost as the README states.

These are field-element and word-index bounds, not byte bounds for an
explicit cyclotomic representation or runtime measurements. Existing exact
audits were inspected, not rerun; the conclusions here follow from the
algebra and loop accounting rather than extrapolation from those tests.

## Exact closure exclusions

The last-column argument excluding H itself is valid: after division by
`a_i b_(N-1)`, that column is a single nonzero Fourier character. If H were
in the orbit family, uniqueness of the Fourier expansion would force only
the coefficient c_(N-1) to remain. The result would have rank one, whereas
H is invertible for N>=2.

The stronger exclusion of `H-alpha I` for every scalar alpha and N>=4 also
checks. The last column determines

    h_j = B q^(-j-1)

except at cyclic index j=N-2, where the diagonal alteration may intervene.
For column N-2, the normalized H entry is

    A q^(-2i) + B q^(-i),   A != 0.

Choose i=1 and i=N-1. Neither row is the altered diagonal of column N-2,
and neither corresponding index i-2 equals the exceptional cyclic index.
Matching the previously determined h therefore requires

    A q^(-i) = B(q-1)

at two distinct powers of q. Since A is nonzero and q has order N>=4,
this is impossible. N=2 must be excluded from this stronger statement:
there H-I=t_1 C is already a scalar multiple of the highest-power orbit
term. The README treats this exception correctly.

These arguments exclude only the stated scalar-weighted orbit family and
its scalar identity augmentation. They do not establish an obstruction
against other modulations, a different base operator, broader graph fusion,
or exact FFT improvements. The implementation and documentation preserve
that distinction.
