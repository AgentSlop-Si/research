# Common fiber splitting and mask gate

`COMMON_FIBER_SPLITTING_AND_MASK_GATE.md` proves all-size identity premerge monodromy and common D8 transport containment for the specified deterministic nested lift, with even dimensions a,b>=2. This yields one common Walsh 1+1+2 Green splitting. The note gives an exact criterion for four scalar channels and records noncommuting witnesses in 17 finite examples.

Arbitrary endpoint masks mix the sectors. Fiber-constant masks are exactly the termwise 1+1+2-preserving masks. Two-value high-y masks preserve a coarser 2+2 decomposition but commute with the high-x swap. With the pulled-back active bank this symmetry prevents the Fourier target. The b=1 exception is explicit.
