# Exact Fourier bridges and bounded obstructions

9 October 2026. Independent mathematical synthesis of the current project.

## Bottom line

No new sub-N-log-N exact arbitrary-input transform is established. Four concrete results sharpen the remaining target:

1. An explicit complete chirp bank **does give an exact transform**: average M carefully related beta states. It meets the information-rank threshold, and its present evaluation costs order N log N when M is order log N. Expanding its aggregate exactly returns the ordinary Cooley–Tukey identity.
2. The all-length near-grid correction has exact separation rank N/gcd(N,Q), hence rank N at odd N with dyadic Q. A short truncation cannot simply be promoted to exactness.
3. Genuinely internal **linear** complex phases do not defeat a stationary-Green obstruction. A polynomial twisted-displacement bound also permits independently affine-conjugated path orders, unequal phase exponents in a sum, noncommuting factors, arbitrary complex coefficients, and arbitrary conditioning. It still excludes constant-depth, constant-width exact families. Arbitrary path permutations and nonlinear phase masks remain outside the theorem.
4. Phase 20's inverse-support approximation bound improves to sqrt(1-s/N). This constant is sharp for a single sparse inverse row and, for Fourier, for the full-row s=N/2 constraint.

All proof steps below are independent derivations. The accompanying script was authored for this report and imports no uploaded code. The results are mathematical bounds and controls, not publication-priority claims.

## 1. Exact completion of the chirp sketch

Let N=KM in the v9 regime, and write input coordinates as n=Mr+t, 0<=r<K, 0<=t<M. Fix a legal chirp slope a and a beta value beta_0. With zeta=exp(2 pi i/N), let

s_0(r,t)=zeta^{a t(t-1)/2+(aMr+beta_0)t} eta^{(N mod 2)t},

where eta=exp(pi i/N). For h=0,...,M-1 set

beta_h=beta_0+hK mod N,
s_h(r,t)=s_0(r,t) exp(2 pi i h t/M).

Let C_h be the K-by-N block-summary map

(C_h x)_r = sum_t s_h(r,t)x_{Mr+t},

and P_h=C_h^* C_h. These are the **unnormalized** v9 block maps: P_h has rank K and satisfies P_h^2=M P_h. Calling it an orthogonal projection without the factor 1/M would be incorrect.

### The complete-bank identity

Within each block, discrete character orthogonality gives

C_h C_l^* = M delta_{h,l} I_K.

Consequently

P_h P_l=M delta_{h,l} P_h,
E_h=P_h/M,
E_h E_l=delta_{h,l} E_h,
sum_{h=0}^{M-1} E_h=I_N.

Thus E_h are mutually orthogonal projections that resolve the identity. In particular, for the exact row outputs Y_h=F_N P_h x,

**F_N x=(1/M) sum_h Y_h for every complex input x.**

This is a constructive exact correction, with no stochastic statement, rounding, spectral sparsity, or input restrictions. Roots and normalization are exact scalars here; the result does not assert finite-precision exact output.

### Information rank and the exactness threshold

For L fixed states, all their row outputs factor through at most LK complex summary coordinates. If LK<N, their stacked linear summary map has a nonzero kernel. No decoder receiving only those summaries can recover F_N x for every x: x and x+v have identical summaries for a nonzero kernel vector v, but different Fourier transforms. Allowing the decoder the exact norm does not restore a uniform all-input result, since v and -v have identical zero summaries and equal norm.

The same conclusion holds for fixed-seed adaptive linear queries chosen solely from previous summaries: follow the zero transcript, take a nonzero vector in the intersection of the chosen kernels, and obtain the same transcript for v and -v. Query selection directly using additional input information is outside this argument. This is a fixed-seed/uniform-all-input obstruction; it is not a claim that every fixed input fails for every random seed.

The complete beta bank reaches the lower bound L=M exactly. For its first L states, rank(sum_{h<L} P_h)=LK.

For the rank-R all-length lift, each row supplies at most RK summary coordinates, because there are R separately weighted input vectors. Stacking L rows has rank at most LRK on the original N-dimensional input space, so exact summary-only recovery requires LRK>=N. This remains only a necessary condition. In particular, it does not repair the lift's deterministic truncation error.

### Charged evaluation and the fusion bottleneck

The existing evaluator of one row costs O(N+K log K), with an actual length-N scan and output, so separate evaluation of all M rows costs

O(MN+MK log K)=O(NM+N log K).

At M=Theta(log N), K=N/M, this is Theta(N log N) for that specified implementation. Preparing exact phase tables, beta indices, factorizations/normalizers, and routing is charged. A root table and each state's required phase recurrence can be produced in O(N) exact scalar operations when a primitive root and normalization are supplied; supplying/certifying those scalars is an additional explicit model requirement. Streaming one row at a time plus an accumulated output requires O(N) scalar words. Bit cost and finite-precision certification are not supplied by this exact-arithmetic identity.

The summaries have a concrete batch form:

d_{h,r}=sum_t [s_0(r,t)x_{Mr+t}] exp(2 pi i h t/M).

They are K length-M Fourier transforms of chirp-weighted blocks, costing O(N log M) using ordinary short FFTs. The existing decoder also uses M length-K FFTs, costing O(N log K), and naively M full scans.

There is an exact way to eliminate the aggregate scans algebraically, but it exposes the ordinary Fourier factorization. Expanding sum_h Y_h/M and applying character orthogonality cancels s_0 and gives the original double sum. With output index k=v+K ell,

(F_N x)_{v+K ell}
= (1/sqrt N) sum_{t=0}^{M-1} exp(-2 pi i ell t/M) exp(-2 pi i vt/N)
  times sum_{r=0}^{K-1} exp(-2 pi i vr/K) x_{Mr+t}.

This is M length-K transforms, diagonal twiddles, and K length-M transforms: ordinary Cooley–Tukey, O(N log K+N log M)=O(N log N). This establishes an explicit exact endpoint for the sketch construction. It is **not** a lower bound against every possible shared/fused implementation. A faster exact route must supply an additional algorithmic identity that avoids the ordinary short-transform bank cost, rather than merely averaging more sketches.

## 2. Exact rank of the all-length residual kernel

Let Q be the next power of two at least N. Put j_k=round(kQ/N) and theta_k=kQ/N-j_k. Consider the exact residual correction matrix

H[k,n]=exp(-2 pi i n theta_k/Q), 0<=k,n<N.

Write g=gcd(N,Q), d=N/g. Because Q is a power of two and Q>=N, d is odd, so there are no half-integer rounding ties. The fractional residues kQ/N have exactly d distinct values modulo one. Nearest-integer centering preserves this count, so the theta_k have exactly d distinct values in (-1/2,1/2).

Set z_k=exp(-2 pi i theta_k/Q). Distinct theta values give distinct z values: their difference has magnitude less than one and cannot be a nonzero multiple of Q. H[k,n]=z_k^n is therefore a Vandermonde matrix with d distinct rows, possibly repeated. Its first d columns on one representative of each distinct row have determinant product_{i<j}(z_j-z_i), which is nonzero. Hence

**rank H = N/gcd(N,Q).**

Concrete cases are (N,Q,g,d)=(15,16,1,15), (17,32,1,17), (24,32,8,3), and (16,16,16,1).

Any exact separated correction H[k,n]=sum_{r=1}^R a_r(k)b_r(n) needs R>=d. In particular, at every odd N>1 the exact rank is N. The rapidly convergent short approximate Taylor/Bessel/Chebyshev expansions are consistent with this: approximation rank and exact rank are different quantities.

Completing the beta bank in every dyadic term computes the truncated center exactly; it does not make that center the exact arbitrary-length Fourier transform. The rank statement does not rule out a different nonseparable correction or unrestricted exact algorithm.

## 3. Linear-phase stationary Green circuits

### Precise grammar

Let omega=exp(-2 pi i/N), F[j,k]=omega^{jk}/sqrt N, Ze_k=e_{k+1 mod N}, and D=diag(omega^k). Let L be the noncyclic lower shift and U=L^T. Each denominator is an invertible constant-coefficient path matrix

B=alpha I+beta L+gamma U.

A permitted affine conjugation is P e_k=e_{v+uk mod N}, gcd(u,N)=1. Each stage is

S_j=sum_{l=1}^{q_j} c_{jl} D^{a_{jl}} P_{jl} B_{jl}^{-1} P_{jl}^{-1} D^{b_{jl}},

and M=S_t ... S_1. All exponents a_{jl},b_{jl} are integers, equivalently residues modulo N. Coefficients are complex, no unitarity or condition-number bounds are imposed, and different terms/stages need not commute. Extra linear phase masks D^a between stages can be absorbed into adjacent exponents. Invertible scalar multiples are immaterial; zero terms can be dropped.

The conjugation requirement is substantive: already at N=9 the bare multiplier P e_k=e_{2k mod 9} has rank(T(P)-P)=8, so it cannot be inserted using the rank-four allowance. This grammar does not include unrelated left and right permutations, arbitrary bare affine wiring between factors, arbitrary path orders, quadratic phase masks, or general diagonal masks. Cyclic shift masks Z^b can additionally be absorbed without affecting the displacement argument, but are not needed for the stated grammar.

### One Green term has low shift displacement

Define T(A)=Z^{-1}AZ. T is a linear rank-preserving algebra automorphism. Directly,

rank(T(B)-B)<=2

for an unreordered constant path. For affine P, write

PBP^{-1}=C-R,
C=alpha I+beta Z^u+gamma Z^{-u},
rank R<=2.

C commutes with Z, so rank(T(PBP^{-1})-PBP^{-1})<=4. Inversion preserves a displacement-rank bound because

T(A^{-1})-A^{-1}=-T(A)^{-1}(T(A)-A)A^{-1}.

Finally T(D^a)=omega^a D^a. Thus a term A=c D^a P B^{-1} P^{-1}D^b has

rank(T(A)-omega^{a+b}A)<=rho,

where rho=2 in the common standard path order, and rho=4 for arbitrary independently affine-conjugated path orders.

### Product and sum phases

If rank(T(A)-lambda A)<=r_A and rank(T(B)-mu B)<=r_B, then

T(AB)-lambda mu AB
= (T(A)-lambda A)T(B)+lambda A(T(B)-mu B),

so its rank is at most r_A+r_B.

Expand the product of sums symbolically into b=product_j q_j branches A_h. This is for proof only; it does not prescribe an exponentially expanded evaluator. Let lambda_h be the product of each branch's phase roots, and let r_h bound rank(T(A_h)-lambda_h A_h). Then r_h<=rho t. Let d be the number of distinct lambda_h, and define the monic polynomial

p(z)=product_{distinct lambda}(z-lambda).

For each branch, p(z)=(z-lambda_h) q_h(z), where q_h has degree d-1 and at most d monomials. Therefore

p(T)A_h=q_h(T)(T(A_h)-lambda_h A_h).

Each term in this last expression is a scalar times a conjugation of a matrix of rank at most r_h, so

rank p(T)M <= d sum_h r_h <= d b rho t.

Possible cancellations only improve this upper bound. No genericity is assumed.

### Fourier has high polynomial displacement rank

Let W=Z^{-1}D. Weyl commutation gives

T^k(F)=Z^{-k}D^k F=omega^{k(k-1)/2} W^k F.

Thus p(T)F=h(W)F, where the coefficient of z^k in h is the coefficient of z^k in p multiplied by the nonzero scalar omega^{k(k-1)/2}. In particular, h has the same degree d and is nonzero. It is generally **not** the same polynomial p.

W is a weighted cyclic shift with all weights nonzero. Over C its N eigenvalues are distinct: its characteristic polynomial is z^N-product(weights), which has no repeated root. A nonzero degree-d polynomial can vanish on at most d of those eigenvalues. Hence

rank p(T)F = rank h(W) >= N-d.

The inequality is still harmless when d>=N. Alternatively, cyclicity proves nullity h(W)<=deg h without invoking an explicit diagonalization.

### Necessary exactness inequality

If M=F, the two rank bounds imply

**N <= d(1+rho t b) <= b+rho t b^2.**

For fixed q>=2 with q_j<=q, this forces

t >= [log N-O(log log N)]/(2 log q)

for the specified architecture. For q=1, the necessary inequality is N<=1+rho t. In the one-phase case at even N, the Fourier twisted displacement has full rank, improving this to N<=sum_h r_h<=rho t b; in particular q=1 requires N<=rho t. Section 4 gives the stronger non-expanded rank budget when each stage has one net phase. These statements are about architectural depth/width. They do not by themselves prove a scalar-operation lower bound for arbitrary shared-state DAG evaluation.

Examples: two stages with two terms each have b=4,d<=4. Common-order stationary Green factors with arbitrary linear phase exponents require N<=68. Independently affine-conjugated orders require N<=132. Thus these particular two-stage families are excluded at dyadic N>=128 and N>=256 respectively. This is much narrower than the project's arbitrary-permutation/general-phase candidate family.

## 4. Strong spectral bound when each stage has one net phase

If all terms of a stage have the same exponent a+b modulo N, their defects add without a polynomial annihilator. For M, let lambda be the product of the common stage phase roots and r=sum_{j,l} rho_{jl}. Then

rank(MZ-lambda ZM)<=r.

For even N and lambda^N=1,

FZ-lambda ZF=(D-lambda Z)F

has singular values, in descending order,

sigma_{r+1}=2 cos(pi(2 floor(r/2)+1)/(2N)), 0<=r<N.

To see this, D-lambda Z=D(I-lambda D^*Z). The unitary weighted cycle D^*Z has eigenvalues the N roots of -1 when N is even. Multiplication by an Nth root lambda permutes that spectrum. The absolute values of 1 minus these roots occur in equal pairs, giving the stated list.

If E=F-M, then ||EZ-lambda ZE||_2<=2||E||_2. The best rank-r spectral approximation error to the Fourier displacement is its (r+1)st singular value. Therefore

**||M-F||_2 >= cos(pi(2 floor(r/2)+1)/(2N)), for r<N.**

This tends to 1 when r=o(N), improving the weaker Frobenius-energy floor that tends to 1/sqrt(2). It is independent of conditioning. For lambda^N=1 and even N, the Fourier displacement is full rank, so exactness requires r>=N. The formula is not asserted for odd N or arbitrary non-unit lambda.

## 5. Sharp inverse-row approximation bound

Let M be invertible and let even one row b=e_i^T M^{-1} have support in a set S of size s<N. Put v=b/||b||_2, u=e_i^T F^*, and a=1/||b||_2. The exact identity bM=e_i^T gives

||M-F||_2 >= ||a e_i^T-vF||_2=||a u-v||_2.

Since v is supported on S and has norm one,

|<u,v>|<=||u_S||_2=sqrt(s/N).

Consequently

||a u-v||_2^2 >= a^2+1-2a sqrt(s/N)
= (a-sqrt(s/N))^2+1-s/N.

Thus

**||M-F||_2>=sqrt(1-s/N).**

There is no norm or conditioning assumption on M^{-1}. If every inverse row has at most s nonzeros, the same result applies. If a pure product of sparse-denominator solves has inverse row support at most s_0^t, substitute min(N,s_0^t). Sums of solves still do not inherit this inverse-sparsity premise.

### Sharpness for a single constrained inverse row

For any unitary target U, let u=e_i^T U^*, a=||u_S|| in (0,1), and v=u_S/a. Define

M=U+v^*(a e_i^T-vU).

Then the perturbation has spectral norm sqrt(1-a^2). Also vM=a e_i^T, so the ith row of M^{-1} is v/a, supported on S. Invertibility follows from the rank-one determinant lemma: det(MU^*)=a^2>0. This attains the bound exactly, and for Fourier a^2=s/N.

### Sharpness when every inverse row is constrained, s=N/2

For even N, reorder columns into even then odd indices. Fourier has block form

F P = (1/sqrt 2) [[A, D_0 A],[A,-D_0 A]],

where A=F_{N/2} and D_0 is the usual unit-modulus twiddle diagonal. Retain only the two diagonal blocks to form M P. M is invertible; every row of M^{-1} has exactly N/2 nonzeros; and the deleted off-diagonal block matrix has norm 1/sqrt 2. Therefore ||M-F||_2=sqrt(1-(N/2)/N), attaining the bound for a nontrivial all-row family. No all-s general attainability claim is made.
