# Whole-word fusion gate and scan audit

Run with Python 3.8+ and only the standard library:

    python3 check_whole_word.py

The script uses `scan_certificate.json` beside it and overwrites
`results.json`. Dense matrix operations are verification oracles, not a
claimed FFT implementation. No uploaded executable is imported or run.

## Deliverables

- `PROOF.md`: exact all-N rational-degree, single-solve, and local-port
  auxiliary-system gates; constructive rational fusion; half-cycle and
  chirp tightness controls; permutations and precision scope.
- `SCAN_AUDIT.md`: independently verified capacity-16 versus rank-17 upload
  certificate, with its exact limited scope.
- `check_whole_word.py`: newly authored test program.
- `scan_certificate.json`: copied input DATA, no code.
- `results.json`, `test_output.txt`: reproducible results.
- `SHA256SUMS`: package integrity hashes.

## Main result in one paragraph

A rational function of degree d in a matrix of quasiseparable order h has
quasiseparable order at most hd. Every independently permuted and nonzero
diagonally scaled Fourier matrix has a balanced cut of rank at least
floor(N^2/4)/N. Hence the prior common-cycle phase word requires at least
ceil(floor(N^2/4)/N) factors, even when fused as a whole. Similarly, compiling
Fourier to one banded-plus-low-rank solve forces a linear width/rank budget;
adding arbitrarily many auxiliary variables does not help when inputs and
outputs attach to individual coordinates. This is a representation gate,
not a general arithmetic lower bound. The half-cycle example still runs in
O(N) scalar arithmetic with linear cut rank, and the classical chirp identity
represents Fourier as a degree-(N-1) polynomial in a signed cycle without
making its dense convolution cheap.

- 3 singular-principal-block controls for inverse cut-rank preservation
- 56 modular and 10 rational fresh-input half-cycle checks
- 254 half-cycle basis columns, with exactly two nonzeros and linear half-cut rank
- 40 arbitrary auxiliary-port placements
- 125 independently permuted/scaled Fourier cut checks
- 40 actual quasiseparable network minor checks
- 12 complete signed-cycle chirp identities and 36 fresh-input checks
- Supplied N=64 graph reconstructed: cut = max flow = 16; exact Fourier
  17-by-17 minor nonzero at both independently verified prime-field roots

All-N conclusions come from the proofs, not the finite checks. No faster
exact arbitrary-input all-output Fourier algorithm is claimed.
