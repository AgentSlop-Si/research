# One-inner-layer row-membership gate

`ONE_INNER_ROW_MEMBERSHIP_GATE.md` gives a complete exact outer-elimination system when either the input or middle N64 layer varies and the other is the accepted seed's fixed pullback. Both choices have 512 variable inner and 512 variable outer coefficients. No preference by dimension is claimed.

The unrestricted inner gate uses rank-seven off-target matrices and degree-eight cofactor equations. A declared signed high-x symmetry branch pairs the problems into rank-six gates with degree-seven equations and 256 inner parameters. Every singular stratum, pivot chart, endpoint guard, and mean-anchoring caveat is stated. No N64 coefficient search or solution claim is made.

Run:

    python check_row_membership.py
    python check_fixed_inner_guards.py

The first checks all nine template-rank strata, 32 positive/negative paired membership cases, and four entrywise signed-symmetry cases on the actual nested routes. The second reads exact dyadic preconditioners and verifies nonsingularity of both frozen inner pullbacks at the actual algebraic seed. Its optional `--propose` path only regenerates preconditioners numerically; acceptance does not use that path.

The milestone includes accepted seed data and freshly authored helpers. No uploaded source is executed. Independent review of this new gate remains separate from the already accepted seed and outer-only rejection.
