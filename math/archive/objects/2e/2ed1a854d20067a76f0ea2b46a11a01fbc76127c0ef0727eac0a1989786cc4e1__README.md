# Phase 32 — exact five-column Fourier synthesis through Green graph reuse

A standalone exact-arithmetic construction and its limits. Unlike Phases 28–31, which excluded fixed seeded Green parameters, this phase **synthesizes adaptable output-diagonal gauges** to match multiple overlapping Fourier-phase windows. For fixed q the operator has O(qN) online field cost, and exactly matches q Fourier input columns. It is not the general Fourier transform.

Primary files:

- `THEOREM.md`: self-contained generic interpolation theorem, proof, explicit coupling existence, augmented-determinant obstruction, complexity.
- `phase32_interpolation.py`: self-contained field executor, gauge synthesizer, radix-two reference NTT, rank utilities and CLI.
- `tests_phase32.py`: independent modular checks and negative controls.
- `audit.json`: q=5, five exact columns, sizes 8–256.
- `audit_large.json`: q=5, five exact columns, sizes 512–4096.
- `audit_seven.json`: q=7, seven exact columns, sizes 8–32.
- `audit_extra.json`: separate q=k+1 nullspace control.
- `CHECKPOINT.md`: research recovery and next step.
- `previous_full_phase31_checkpoint.zip`: full predecessor archive, including history going back to Phase 12.

Field modulus 998244353, primitive generator 3. FFT convention is omega^(-ij); all phase and rank checks are exact in that finite field. The complex-number theorem is algebraic, but the empirical validations are modular; numerical floating-point conditioning is not guaranteed.
