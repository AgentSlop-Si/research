# FFT Hero #17 — research continuation package

**Goal:** Exact all-output O(N) transform for arbitrary fresh inputs. **Not solved.**

This package contains independent exact finite-field tests and full charged work arguments for four restricted-input or conditional graph families:

| Research branch | Recognizer takes raw input | Exact all-output result | Main scope condition |
|---|---|---|---|
| Tensor-Union | Yes | O_r(N) DFT and cyclic convolution | N=A B coprime balanced; CRT matrix rank <=r |
| Coset-Union | Yes | O_r(N) DFT | one detected cyclic coset, pulled-back bounded chirp rank |
| Fiber-Union | Yes | O_r(N) DFT | N=Q M, Q²=O(N), <=r characters per strided fiber |
| Frequency-Graph Union | Yes (both inputs) | O_{r1,r2}(N) cyclic convolution | input fiber sparsity; O(Q) surviving merged output states |

For fixed `r`, Fiber-Union supports **dense full-rank fiber matrices**, including degree-3 and higher polynomial phases at square and fixed-prime-power lengths. Frequency-Graph Union can convolve pairs of these maximum-rank inputs when frequency graph union stays small.

**Tests and audits:** `test_hero17.py`, `independent_audit.py`, `AUDIT_RESULTS.json`, `SCALING_CHECK.json`

All components work over `F_p` with a supplied primitive root and exact field arithmetic. Prototype is pure Python and does not demonstrate an advantage over an optimized FFT. Classical Good–Thomas, sparse FFT/Prony and polyphase algebra precede this project; publication novelty has not been established.
