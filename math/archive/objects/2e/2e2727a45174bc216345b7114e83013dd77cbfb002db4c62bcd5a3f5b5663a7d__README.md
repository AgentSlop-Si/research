# FFT Research 2026-10-10 — Two-Sided Spectral Separator

This package strengthens the prior project's Green-sum rejection tests with independently selected **Fourier row and column cosets**, a **moving interface** between Green stages, and an **O(N) exact rank oracle** per weighted cyclic-Green branch using forest matching.

Files:
- `THEOREM.md`: all definitions, proofs, limits and constructive next gate.
- `two_sided_verify.py`: standalone independent verification using NumPy and GF(193) exact arithmetic.
- `RESULTS.json`: recorded test counts and complete construction details for the strict N=64 four-branch witness.
- `SOURCE_AUDIT.md`: what's inherited, what is new to this project, and what cannot yet be called novel in the external literature.
- `NEXT_GATE.md`: proposed further exact-FFT search.

Run: `python two_sided_verify.py` (requires NumPy).

**Does not provide an O(N) exact FFT for arbitrary input.** Novelty relative to external published literature is not established.
