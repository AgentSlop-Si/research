# Reproduction

Use Python 3.10+ without external dependencies. Extract the complete research archive, which includes `fft_green_phase12_unitary_escape/`, `fft_green_phase13_phase_coherence/`, and `fft_green_phase14_galois_coherence/` as siblings. From the archive root:

```bash
python -m unittest discover -s fft_green_phase12_unitary_escape/tests -v
python -m unittest discover -s fft_green_phase13_phase_coherence/tests -v
python -m unittest discover -s fft_green_phase14_galois_coherence/tests -v
python fft_green_phase14_galois_coherence/galois_gate.py
python fft_green_phase14_galois_coherence/field_descent.py
python fft_green_phase14_galois_coherence/three_stage_probe.py
```

All finite-field computations are exact in their stated fields. Theorems are characteristic-zero proofs in `THEOREM.md` and should be independently checked; numerical/finite tests alone cannot establish the infinite-family claims.

General conductor tradeoff:
```bash
python fft_green_phase14_galois_coherence/conductor_tradeoff.py
```

Positive two-mask control:
```bash
python fft_green_phase14_galois_coherence/two_mask_control.py
```
