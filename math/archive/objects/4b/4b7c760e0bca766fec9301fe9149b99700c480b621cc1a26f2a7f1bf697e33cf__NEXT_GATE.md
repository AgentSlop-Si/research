# Hero #1 Phase 22 gates — from certified sparse-rational islands to true generic FFT progress

**The structural-input result is real, but generic exact o(NlogN) FFT remains open.** Do not confuse a low-dimensional promise with a new bound for every input.

1. **New input-independent sharing principle:** create a complete, invertible evaluation architecture for all `N`-dimensional inputs where the *charged* DAG cost is o(NlogN), not a union of constant-dimensional sparse families. Reuse of input-dependent sparse certificates cannot by itself accomplish this; see the dimension argument in THEOREM.md.
2. **Optimize the global reciprocal-resultant compiler:** replace 31 repeated 10x10 Sylvester determinants (for s=4) with a shared algebraic compiler, or derive an efficient matrix pencil kernel that reuses the Hankel entries between all w samples. Preserve exact root enumerations, all inversions, and full-vector certificate. Try extending practical structured-input crossover to N~1024 without hiding preprocessing.
3. **Reduced-degree universality:** we have **proved** that the Phase20 one-binomial/two-defect resultant is `w^13 (w-1)^9 U`, with palindromic `deg U<=10`. Transfer the 6-sample reciprocal interpolation and charge its impact against Phase20 and Phase19 mixed detectors, without counting saved probes twice.
4. **Resonance and cancellations:** remove the present restriction that the first `4s` R probes are all nonzero and that the recovered A has no subgroup zeros. Handle O(1) singular frequencies with explicit direct repairs; reject an unbounded number of singular frequencies rather than hiding O(N^2) recovery.
5. **Adaptive sparsity and branch selector:** test s=2,3,4,8, but certify every branch and charge the selector. A generic input should not incur a large O(N) loss before the ordinary FFT; examine provably cheap rejection gates. A low dimensional sparse model remains a promise.
6. **Complex/bit model:** numerical Hankel/Prony recovery may be exponentially ill-conditioned near root collisions; derive provable precision bounds or exact algebraic certificate replays with field/primitive-root construction, memory and bit-cost included. An exact finite-field arithmetic gain does not automatically transfer to floating point.
7. **External audit and prior art:** compare the self-reciprocal Hankel-resultant proposition against existing resultants, structured pencils and sparse rational interpolation before asserting novelty or priority. Confirm it independently in Sage/Lean or another computer algebra kernel; current proof is human-readable plus exact software tests.

**Acceptance criterion for the original grand challenge:** one *all-input*, one-pass, single-query, exact Fourier algorithm with proved o(NlogN) arithmetic work in a precisely specified model, and every setup/forcing/graph/router/table/projection cost included. No such algorithm has been established by Phase21.
