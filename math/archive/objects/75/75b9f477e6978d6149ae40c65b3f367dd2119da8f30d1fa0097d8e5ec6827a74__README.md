# Hero #17 Phase 12 — Green–Union Rigidity

This is an exact-arithmetic, reproducible **restricted no-go** experiment toward an O(N) Fourier transform. It does **not** solve the arbitrary-input O(N) problem.

- `PROOF_CERTIFICATE.md`: complete theorem and proof.
- `RESEARCH.md`: context, cost model, experimental outcomes and novelty caveats.
- `phase12.py`: exact finite-field operators, inverses, Green executors, and rank checks; plus Weyl-orbit average fusion into one long-range Green solve.
- `test_phase12.py`: unit tests.
- `independent_audit.py`: exhaustive small-field certificates and independent search.
- `large_green_audit.py`: 65,536-element O(N) noncommuting Green network checked against the proper operator, and shown not to be the FFT.
- `AUDIT_RESULTS.json` / `LARGE_AUDIT_RESULTS.json`: machine-readable evidence.
- `CHAIN_CHECKPOINT.md`: handoff and do-not-repeat register.

Execute in Python 3.11+ without third-party dependencies: `python -m unittest -v test_phase12 && python independent_audit.py && python large_green_audit.py`.

All proofs of universal mathematical inequalities in this package are stated over complex scalars. Finite-field assertions use explicit modular tests and separate small-size minor checks where required.
