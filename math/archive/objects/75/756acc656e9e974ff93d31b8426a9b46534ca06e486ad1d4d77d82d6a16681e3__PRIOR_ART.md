# Exact prior-art separation

1. **Good–Thomas / prime-factor FFT**: classical no-twiddle decomposition for coprime factors. <https://en.wikipedia.org/wiki/Prime-factor_FFT_algorithm>
2. **Cooley–Tukey FFT**: standard mixed-radix baseline against which Good–Thomas saves the `2(G−1)` twiddles in our chosen implementation. <https://en.wikipedia.org/wiki/Cooley%E2%80%93Tukey_FFT_algorithm>
3. **Winograd / small DFT codelets**: known arithmetic factoring of a length-three transform; our 6-add/2-mul implementation is not claimed novel.
4. **Pruned / cached FFT DAGs**: standard conceptual ingredients; the Phase 24 construction is a project-specific all-input Green-certificate integration.
5. **Nir Ailon, 2013**: matrix-entropy lower bound for normalized FFT in the unitary two-register gate model. <https://arxiv.org/abs/1305.4745>. **2014**: well-conditioned model. <https://arxiv.org/abs/1403.1307>.
6. **Morgenstern, 1973**: bounded-coefficient Fourier lower bound, separate computational model. <https://doi.org/10.1145/321752.321761>.

Phase 25's original project-level output is a verified **combined** Good–Thomas + deferred + Green-certificate implementation with exact arithmetic, honest costs, and regression artifacts. Neither the component identities nor historical priority are asserted new. The target unrestricted exact `o(NlogN)` algorithm remains unproved.
