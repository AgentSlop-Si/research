Rather than repeating the generic Jacobian test or the previous `r=0` inverse-sparsity argument, this round tests the actual escape route mentioned in the original Green research: **globally dense Green stages whose inverses have a sparse local part plus a bounded-rank global defect**.

## New result A — Fourier-specific rank barrier

For any `N x N` matrix `B` with at most `q` nonzero entries **per row**:

```
rank(F_N - B) >= floor(N/(q+1))
```

The result holds after arbitrary permutations and nonzero diagonal rescalings at both Fourier endpoints. Select `m=floor(N/(q+1))` consecutive Fourier frequencies, avoid all columns touched by the q-row-sparse matrix on those rows, and use the corresponding nonsingular Vandermonde minor. This is an elementary exact proof over C, not just a computational statement.

If stages `G_j` have inverse decompositions `G_j^-1 = B_j + E_j`, with `B_j` at most `s_j`-sparse per row and `rank(E_j)<=r_j`, all intermediate permutations or nonsingular diagonal scalings allowed, then an exact Fourier factorization requires:

```
sum_j r_j >= floor(N/(1 + product_j s_j))
```

The proof telescopes the difference between the full inverse-stage product and the sparse baseline. Each rank-r defect contributes at most r rank, while the product of row-sparse matrices is row-(product s_j)-sparse.

For tridiagonal inverses (`s=3`) and a uniformly bounded defect rank r:

```
t >= log_3 N - O(log log N).
```

When r=0 the pure support result `3^t>=N` from the prior Green checkpoint is recovered. For monomial/diagonal baselines (`s=1`) the much stronger tradeoff `sum r_j>=floor(N/2)` holds. This bound assumes nothing about intermediate amplification or coefficient sizes.

## New result B — globally mixing scans that provably escape the sparse+low-rank inverse class

Define a fully dense separated-generator stage

```
S_N[i,j] = 1  (i>j); 3 (i=j); 2 (i<j).
```

Both `S_N` and `S_N^-1` admit fully charged `O(N)` implementations on arbitrary fresh vectors. For the forward map, `Sx[i]=3*x[i]+prefix_before_i+2*suffix_after_i`. For the inverse, solve `T0*y=x` with `T0=I-strict_lower_ones` by a prefix recurrence, then apply a Sherman-Morrison rank-one correction.

The inverse is explicit:

```
D=2^(N+1)-1
S^-1[i,j] = -2^(i-j-1)/D  if i>j
          = (2^N-1)/D    if i=j
          = -2^(N+i-j)/D if i<j.
```

All entries are nonzero. For every banded T of half-bandwidth b (not just tridiagonal), we proved:

```
rank(S_N^-1 - T) >= floor((N+b)/(2*b+2)).
```

The proof uses an explicit `m x m` offband minor with row indices `2(b+1)i` and column indices `2(b+1)j+b+1`. After row/column scaling, it has a constant alpha below the diagonal and beta above; its determinant is `beta*(beta-alpha)^(m-1) != 0`. This is a characteristic-zero all-length theorem.

**Interpretation:** The general separated-generator global scans from the previous checkpoint need not have sparse-plus-constant-rank inverses. Therefore Result A narrows the search without accidentally refuting the very architecture that remains alive.

## Relation to established mathematics

Vandermonde invertibility, rank subadditivity, the matrix determinant lemma, Sherman-Morrison/Woodbury and matrix rigidity are established facts. Dvir and Liu, *Fourier and Circulant Matrices Are Not Rigid* (CCC 2019), https://doi.org/10.4230/LIPIcs.CCC.2019.17, prove Fourier non-rigidity in broader sparsity/rank regimes; our elementary limited-sparsity result does not contradict this. Ben-Artzi, Eidelman and Fishelov, *Numerical solution of the boundary value problems for the biharmonic equations via quasiseparable representations* (2024), https://doi.org/10.1007/s11075-024-01809-9, provides Green/quasiseparable background.

We make no external priority claim for the rank lemmas. The research value is the explicitly scoped stage factorization consequence, the exact all-N separating example, and their independently runnable certificates.
