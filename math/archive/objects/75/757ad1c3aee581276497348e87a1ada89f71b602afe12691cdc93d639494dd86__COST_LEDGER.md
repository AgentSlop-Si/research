# Phase18 full-work arithmetic ledger

## Model, scope, and comparability

Every new transform reads all N input samples and writes all N outputs. All tests use exact finite-field arithmetic, in two explicit NTT-friendly prime fields, with the same cached roots, Green operators and cyclic inverse setup available to both Phase18 and the full Phase17 Bluestein baseline. Common root/Green setup costs O(N) field arithmetic and are excluded from both columns. The benchmark includes nontrivial preprocessing, including every rejected candidate's arithmetic.

The displayed figures are **arithmetic-work proxies**. `PolyStats` tracks the finite-field arithmetic in the Phase17 polynomial/NTT kernels, including within-call twiddle and kernel construction; Phase18's `Work` tracks additional multiplications, additions, inversions, recurrence discovery, scans and Green operations. Repeated-squaring charges in Phase18 are conservative upper bounds. The proxy excludes comparisons, address arithmetic, Python container costs, branch overhead, memory traffic and bit-complexity, so the figures are **not** instruction counts or wall-clock timings.

## General charged path

- `Px`: `2N` scalar multiplications, `N` additions; source and output scans.
- At most two default graph shifts (`delta=1` and a far coprime shift): projective majority with O(N) scalar comparisons/multiplies, followed by an O(N) full defect verification per candidate.
- If `dmax>=2`, bounded prefix BM on each graph orbit: `O(dmax^2)` arithmetic, followed by O(N*dmax) complete certificate scans. Neither detection nor bad candidates are free.
- Sparse graph defect `h` with K nonzeros: K geometric streams (`K<=3`) or Phase17 rational forcing (`O(N log(K+1)+K log²(K+1))`), with denominator/kernel/twiddle construction included.
- Evaluate q at the N graph Fourier eigenvalues: `O(N*d)` scalar operations, one short power setup, and O(N) batch inversion (single field inverse).
- Each exact zero denominator: one independent dense O(N) Fourier-coordinate evaluation. For gcd(N,delta)=1 there are <=d; arbitrary delta has <=d*gcd(N,delta).
- `L^-1`: O(N) cyclic Green recurrence, charged `3N+1` multiplications and `2N` additions.
- Failure: full arbitrary-input Phase17 Bluestein, with all failed discovery work charged. For fixed candidate count and fixed dmax, the worst-case stays `O(N log N)`.
