# Sparse-defect gate audit summary

The Fourier sparse-plus-low-rank inverse-stage theorem survives independent audit, including arbitrary monomial connectors and singular sparse baselines.

The source's banded-only scan proof did not justify its broader arbitrary-sparse escape claim. An independent repair now proves, for every row-q-sparse B,

    rank(S^(-1)-B) >= ceil(floor(N/(q+2))/(2q+1)).

This is linear in N for fixed q and holds after arbitrary endpoint monomials. The full proof covers all support patterns and exceptional coefficients. q=0 gives rank N; q<N always gives rank at least one; q>=N has no uniform positive bound.

Woodbury must be charged O(N+Nr^2+r^3) setup and O(N+Nr+r^2) per fresh vector. Fixed-r O(N) survives. The no-pivot Thomas implementation covers a smaller chart than all nonsingular tridiagonal matrices. Exact scalar work is not bit complexity.

All audit-owned exact checks passed, including 23,042 exhaustive small support patterns, 305 new sparse-repair cases, 444 Fourier cases, and rational/finite-field/NTT/Woodbury controls. No source program was run. See AUDIT_REPORT.md, ARBITRARY_SPARSE_REPAIR.md, INDEPENDENT_CHECKS.json, and independent_checks.py.

No arbitrary-input exact o(N log N) FFT construction or universal FFT lower bound is obtained.
