# New-material fusion checkpoint: independent audit and implemented refinement

9 October 2026. Source: `fft_new_material_fusion_checkpoint_20261009(1).zip`, Library ID `[private-id]`. The archive was safely materialized and inspected without executing uploaded software. Auditor-authored tests run separately.

## Bottom line

This package supplies useful new integration and exact operator identities. Its main claims survive review in their explicitly restricted models. It does not produce an exact arbitrary-input all-output sub-N-log-N Fourier transform. The shrinking-error rates are the same rates already established in the preceding independent v4 audit; their residual-sensitive fusion and implementation components are additions.

The most actionable refinement is now implemented: the source's suggested componentwise median baseline, using actual deterministic linear-time selection. It optimally minimizes the relevant L1 residual among all q-periodic baselines, q=gcd(N,4), without worsening the asymptotic cost or changing the integer model. This is implementation and verification of an already proposed standard idea, not a new discovery.

## 1. Approximate fusion is correct and meaningfully data-dependent

For L=log2 N, ell=log2 L and 1<=tau<=L, the same complete eager-table construction supports

    T=O(N tau),  eta_N=O(ell/sqrt(tau L)).

The original audited points tau=1 and tau=L/ell are recovered. B and sample count are Theta(tau L²/ell²); descriptor and guarded-lane widths are Theta(ell); group size is Theta(L/ell). Paid descriptor generation is O(N), and reading/adding every packed row costs O(N tau). Table construction N^gamma polylog(N)=o(N) is included, as are exact-mass sampling and explicit output writes. The rational schedule, finite base-regime flags, true fresh padding samples, and nondyadic-N key-budget adjustment are consistent with this argument.

**Existing comparator limits the significance of the slower points.** On radix-two lengths, the same polylogarithmic sampled surrogate can instead be evaluated by a pruned sparse-input FFT in O(N log k)=O(N ell) arithmetic operations, with the established bounded-word precision argument preserving that order. The selected-output precursor is described by [Woolfe, Liberty, Rokhlin and Tygert, §3.3](https://tygert.com/frand.pdf); transposition/sparse-input application and the comparison here are deductions. Therefore the O(N tau) table schedule has a better asymptotic time upper bound than this comparator when tau=o(ell), matches its order at tau=Theta(ell), and is slower when tau grows faster than ell. In particular O(N L/ell) is a valid table-schedule point but is dominated by O(N ell) on radix-two lengths. This comparison does not extend to arbitrary lengths by zero-padding, which changes the requested DFT.

The supplied exact-mean baseline fits at most eight real clusters. It computes scaled integer residuals rho=n*x-S_chosen with n=N/q, retaining each class sum or zero by an exact mass comparison. Algebra and scaling check:

    Fx=Fh+F(rho)/n,
    M(rho)/n<=M(x),
    M(rho)/n<=2 M(x-h*) for any q-periodic h*.

Its Gaussian-integer baseline spectrum uses only q<=4 quarter rotations. No hidden FFT or uncharged input-dependent recognition is needed; a constant number of full scans plus the output writes is O(N). Raw class sums additionally give the q exact quarter-root bins, even if some fitted means are rejected.

Consequently the error bound improves from eta_N*M(x)/sqrt(N) to eta_N*M(rho)/(n*sqrt(N)). This improvement is fully measurable for each input, but can equal one in the worst case. Exact zero residual gives exact structured-input outputs only.

The source correctly distinguishes rational UNNORMALIZED DFT output from ordinary numerical unitary output. Its statement about Fhat/sqrt(N) is an error comparison, not a claim to store exact irrational values. A numerical unitary conversion must add its own rounding term. This is especially important at zero residual, where a residual-only zero bound cannot absorb normalization error. The earlier v4 audit already supplies a paid rounded normalization construction for an input-mass-based tolerance, but using it here requires explicitly retaining the extra baseline/conversion error.

## 2. Implemented median refinement

`median_baseline.py` now implements the source's suggested median alternative, independently of the uploaded code. It uses median-of-medians with only five-element sorts. Componentwise medians yield integer r=x-h and

    M(r)=min_{q-periodic h*}M(x-h*)<=M(x).

This removes the factor-two near-periodic comparison and avoids the n-scaled residual. The code writes all N baseline slots and includes a rational decoder adapter with exact quarter-bin overrides, zero-residual bypass and failure propagation. It does not execute or replace the sampler/decoder.

Meaningful example: N=21 with twenty entries 100 and one 101 has median residual mass 1, compared with 40/21 for the retained exact mean and 2101 for zero. Boundary example: N=8 with four +1 followed by four -1 has optimal residual mass 8, equal to the original mass. Thus the enhancement strengthens data-dependent accuracy while preserving the original worst-case limitation.

`MEDIAN_BASELINE.md` contains the proof, exact scaling/word-width contract, detailed examples and checks. Verified: 9,822 selection cases; 1,000 fits; 20 exact finite-field spectrum checks; four adapter checks. Another auditor-authored script independently checked 3,000 rational mean-fit/decomposition cases. None of these tests executed uploaded code.

## 3. Green identities add viable primitives, not the missing factorization

Independent audit supports both new directions:

- For a unit-modulus weighted full cycle M with M^N=-I, K=I+(I-M)^-1 and its inverse are dense, have linear scalar-field evaluators, and satisfy exactly kappa_1(K)=(N+2)2^(N-1)/(2^N+1)=Theta(N). This escapes the particular fixed bounded-condition stage family, as intended. Its affine Fourier conjugate is compatible. Exact rational coefficients may have Theta(N)-bit denominators; this is not a bounded-word linear-time exact FFT.
- For path T=tridiag(-1,3,-1), FTF^-1 is diagonal plus rank at most two. Therefore S=T^-1+(T+I)^-1 and its target conjugate have paid linear scalar-field application formulas. The target inverse's infinity norm is at most 73/18, independently of N. The identity and bound were checked algebraically and by independent finite calculations.

The second bound makes conditional approximation transport meaningful. But forming an easily processed filtered head/residual, certifying finite-word source/target arithmetic, and evaluating any exact head remain required. Direct preconditioning alone does not solve this: for the cycle family, inverse amplification offsets a raw L1 shrinkage up to the stated componentwise-norm constant. Small residual after cheaply evaluated head subtraction is the relevant conditional path.

See `GREEN_FUSION_AUDIT.md` and its self-contained checker for exact formulas, scalar operation counts, the 73/18 proof, source differences and representation restrictions.

## 4. New bounded exact gate: two forward cycle mixers fail

The verified proof in `TWO_STAGE_GATE.md` excludes a product of exactly two forward K stages at every dyadic N>=8, even granting arbitrary unitary interstage and endpoint factors plus global scalars. The common squared-singular spectrum is f(c)=(5-4c)/(2-2c). A scalar-unitary product would require constant reverse-paired products, but

    f(c)f(-c)=4+9/[4(1-c²)]

varies across the cycle eigenangles. This rules out the two-stage candidate family, not a general sub-N-log-N FFT. N=2,4 evade this particular obstruction; coordinate-dependent gains, inverse stages and at least three forward stages remain outside the result. Arbitrary zero-K unitary constructions are of course not excluded. A short multiplicity argument extends the abstract full-cycle exclusion to every N>=3 except N=4; this does not extend the uploaded affine implementation beyond its dyadic coverage.

## 5. What would actually move the original target

For the exact branch, a next decisive result must exhibit a uniformly constructible short factorization of Fourier in the enlarged mixer/permutation family, with factor count, parameter generation, field representation and arithmetic costs all charged, or prove a new obstruction for that enlarged class. A dense cheap mixer, growing condition number, or intertwining identity alone is not that factorization.

For the approximate branch, useful next work is a complete finite-word implementation of a certified Green head/residual pipeline, or a richer template family with paid fitting/evaluation and genuinely smaller residuals on a specified input class. It must track source error, exact-head error, target inverse amplification and output conversion. Adding many full-size template levels without a sharing proof returns to N log N work.

No novelty or practical speed advantage is certified. The guarantee remains maximum-bin additive error relative to a global residual mass, not coefficient-relative accuracy or vanishing relative L2 error of the entire transformed vector.
