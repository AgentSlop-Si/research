# Phase 22 — Gram obstruction, exact mask recovery, and a real Fourier covariance gate

**Date:** 2026-10-09  
**Status:** Rigorous restricted theorems, exact finite-field certificates, constructive controls. **No `o(N log N)` DFT, new integer-multiplication algorithm, or practical FFT speedup has been demonstrated.**

## 0. Definitions and model

Let `N>=4` be even and `omega=exp(-2*pi*i/N)`. The normalized DFT is `F[j,k]=omega^(jk)/sqrt(N)`. Let `Z e_k=e_(k+1 mod N)` and `J e_k=e_(-k mod N)`. Then `F=F^T`, `F^2=F^T F=J`, and `F^*F=I`.

A real Green matrix in this phase means a matrix with real entries obtained by inverting a real sparse cyclic/path operator. An independently reordered weighted cyclic Green term may be applied in `O(N)` operations with the recurrence in `phase22_gram.py`. Sum of `q` such terms costs `O(qN)`; exact diagnostics that materialize all columns or invert general matrices do **not** cost `O(N)`.

## 1. The connected-Gram obstruction to one complex mask between real mixers

**Theorem 1.** For even `N>=4`, if

```
F_N = A Q P B,
```

where `A,B` are invertible **real** matrices, `P` is any coordinate permutation, and `Q` is any invertible **complex** diagonal matrix, then the undirected graph on `{0,...,N-1}` with edges `i--j` whenever `i!=j` and `(A^T A)[i,j]!=0` is disconnected.

**Proof.** The real and imaginary parts of `F_N` have ranks `N/2+1` and `N/2-1`. One proof: `F_N^2=J` and `F_N` is unitary and symmetric. `Re(F_N)=(F_N+F_N^{-1})/2` vanishes precisely on the `-1` eigenspace of `J`, whose dimension is `N/2-1`; similarly `Im(F_N)` vanishes on the `+1` eigenspace, whose dimension is `N/2+1`.

Since `A,P,B` are real and invertible, taking real and imaginary parts of the proposed factorization gives

```
rank Re(F_N) = # {i : Re(Q_ii)!=0} = N/2+1
rank Im(F_N) = # {i : Im(Q_ii)!=0} = N/2-1.
```

These counts sum to `N`. Since `Q` is invertible, its diagonal index set is a disjoint union `R` of `N/2+1` nonzero **real** entries and `I` of `N/2-1` nonzero **purely imaginary** entries. Both are nonempty.

Put `K=A^T A`. From `F_N^*F_N=I`,

```
Q^* K Q = P (B B^T)^(-1) P^T.
```

The right side is real. For `r in R`, `s in I`, the left entry equals `conj(Q_rr)*K_rs*Q_ss`, which is purely imaginary, and hence must be zero. As the two diagonal factors are nonzero, `K_rs=0` for every cross pair. Thus `R` and `I` disconnect the support graph. QED.

**Corollary.** If `A` has strictly positive real entries, then each `(A^TA)[i,j]>0`, so no such Fourier factorization exists. In particular, positive real Green inverses `(I-rho P_cycle)^(-1)` with `0<rho<1`, and sums of these under **independent coordinate orders**, cannot be the left real mixer before a single complex diagonal gate and a real right mixer. This is true irrespective of the condition number of the mixers.

**Scope:** this is a restriction on **one** complex diagonal between **real** invertible mixers; it does not apply if additional complex factors or another complex mask are placed inside, or if `A` or `B` is complex. It follows from elementary spectral/Gram facts; there is no claim of novelty for these general tools.

**Sharpness of the support hypothesis.** The Fourier matrix has a real orthogonal eigenbasis `O` with `F=O diag(1,-1,i,-i) O^T`, with the appropriate multiplicities. Here `O^T O=I` and the off-diagonal Gram graph has no edges. This is an **existence** control; a dense general `O` is not a fast algorithm.

## 2. Exact quadratic Gram gate for arbitrary complex diagonal gauges and permutations

Work in **any field of odd characteristic** containing an `N`th primitive root and `sqrt(N)` (the experiments use `F_998244353`). No positivity or realness assumption is needed for this *bilinear* test.

Suppose fixed invertible matrices `A,B` admit `F_N=A Q P B`, with arbitrary invertible diagonal `Q` and any permutation `P`. Since `F_N^T F_N=J`, define

```
K = A^T A,
C = B^(-T) J B^(-1).
```

Necessarily,

```
                        C = P^T Q K Q P.             (2.1)
```

This is a **necessary condition for Fourier equality**. Satisfying it alone is *not* sufficient (Section 3).

If all diagonal entries are nonzero, define the pairwise invariant

```
                         h_ij(K) = K_ij^2/(K_ii*K_jj).
```

It is unchanged under nonzero diagonal congruence; an intermediate permutation merely reorders its rows/columns. Therefore the unordered multiset of the entire row fingerprint `sort(h_i,*)` must agree for `K` and `C`. Unequal fingerprints rule out **all** `P,Q`, rather than just a sampled parameter choice. Unequal counts of zero diagonal elements are an even simpler complete veto. If both matrices have zero diagonals, the fast fingerprint routine reports **inconclusive**; it must not divide by zero.

When row fingerprints are unique, their matches determine the **only possible permutation**. After this ordering is established, put `Ctilde=P C P^T`; if `K_ij` is nonzero for all `i,j`, put `lambda_ij=Ctilde_ij/K_ij`. Equation (2.1) holds precisely when `lambda_ij=q_i q_j`, i.e. this ratio matrix is rank one in the anchored sense

```
                  lambda_ij*lambda_00 = lambda_i0*lambda_0j
```

and `lambda_00` has a square root in the working field. Take `q_0=sqrt(lambda_00)`, `q_i=lambda_i0/q_0`; verify the complete congruence. The two choices `q` and `-q` are indistinguishable by (2.1) but a Fourier entry calibration removes this ambiguity.

Computational model: building dense `K,C`, including inversion of arbitrary Green *sums*, is cubic here. The Green **application** remains linear, but this exact diagnostic is for small/medium research instances only. The covariance oracle of Phase 20 and the real covariance gate of Section 5 remain appropriate for large `N`.

## 3. Sound negative and positive controls

The experiments include:

1. Two independently permuted, independently weighted cyclic Green **sums**, each with two terms; 24 fixed pairs at `N=8,16,32,64` are all excluded by the exact invariant. This is a finite list of excluded parameters, **not** an all-parameters Green theorem.
2. Twelve *deliberately valid* controls `F=A Q P B` at those sizes with hidden nonzero `Q` and hidden `P`. The gate recovers both exactly, up to global sign, and reconstructs every DFT entry. These controls have **dense** `B`, and are not fast FFTs.
3. Adversarial control `U=S F` for nontrivial diagonal sign matrix `S`, with `S_00=1`. It satisfies `U^T U=J` and `U_00=F_00`; it passes the Gram test and scalar calibration, and the first Weyl equation, but fails the **second** Weyl equation. Thus the quadratic gate is not a Fourier-certification theorem by itself.

The relevant general concept is diagonal gauge equivalence/Gram invariants, related to prior frame-theoretic work cited in `PRIOR_ART.md`. The present gate is a project-specific exact finite-field specialization with explicit controls.

## 4. A constructive exact linear-work phase extraction

Let `h=N/2`. Define the real orthogonal reflection-basis transform `H` whose columns are, in this order,

```
 e_0, e_h,
 s_j=(e_j+e_(N-j))/sqrt(2), j=1,...,h-1,
 a_j=(e_j-e_(N-j))/sqrt(2), j=1,...,h-1.
```

A forward or inverse `H` application requires `O(N)` scalar additions/multiplications. Define `Q=diag(1,...,1,-i,...,-i)`, with `h+1` real units and `h-1` copies of `-i`. Put

```
                         C = Q^(-1) H^T F_N.
```

Then the **exact** factorization is

```
                         F_N = H Q C,               (4.1)
```

where **`C` is real orthogonal**. Its rows are

```
 C[0,k] = 1/sqrt(N),
 C[1,k] = (-1)^k/sqrt(N),
 C[s_j,k] = sqrt(2/N) cos(2*pi*j*k/N),
 C[a_j,k] = sqrt(2/N) sin(2*pi*j*k/N).
```

This is a constructive parity/cosine/sine decomposition, within the well-known family of real Fourier transforms. Its utility here is that `H` and the *complete complex phase mask* `Q` are cheap and completely explicit. **Computing the remaining real orthogonal `C` is still the hard work**; direct dense evaluation is `O(N^2)`, and standard fast cosine/sine methods are `O(N log N)`.

For every entry, `|C_jk|^2 <= 2/N`, so every row's probability entropy is at least `log_2(N/2)`. Hence the matrix entropy obeys

```
                         Phi(C) >= N(log_2 N-1).     (4.2)
```

One two-coordinate unitary gate can increase this entropy by at most 2 bits (see Phase 16). Therefore any circuit for `C` using only two-coordinate orthogonal/unitary gates requires at least

```
                         (N/2)(log_2 N-1) gates.     (4.3)
```

This is *only* a lower bound for this gate model. Nonunitary Green computation with arbitrary, potentially unbounded internal coefficients is not excluded.

## 5. A sparse **real** Fourier covariance identity

The real residual has an additional defining structure. Let `R` act in the `H` reflection basis with blocks

```
 R[0,0]=1,   R[1,1]=-1,
 R on (s_j,a_j) = [ [ cos(theta_j), -sin(theta_j) ],
                    [ sin(theta_j),  cos(theta_j) ] ],
 theta_j=2*pi*j/N.
```

`R` has `O(N)` nonzero entries and an `O(N)` forward application. Then

```
                            C Z = R C.              (5.1)
```

Moreover, the seed vector `v=C e_0` is known explicitly:

```
 v[0]=v[1]=1/sqrt(N),
 v[s_j]=sqrt(2/N),  v[a_j]=0.
```

**Uniqueness theorem:** if `X Z=R X` and `X e_0=v`, then `X=C` exactly, because

```
 X e_k = X Z^k e_0 = R^k v = C e_k
```

for all `k`. This reduces Fourier coherence for the **real** residual to one sparse intertwining equation plus a fully specified first column; there is no arbitrary-scalar ambiguity left. The Phase 22 exact finite-field gate uses one seed call plus two circuit executions per random vector (`1+2t` calls), with `O(N)` additional arithmetic and a one-sided randomized rejection guarantee against nonzero covariance defects. Fixed-seed trials are regression tests rather than independent-probability certification.

**Important:** even though `R` is sparse and `v` is explicit, producing all `N` columns as `R^k v` separately takes `O(N^2)`. This identity is a *correctness/synthesis constraint*, not a linear-time DFT algorithm.
