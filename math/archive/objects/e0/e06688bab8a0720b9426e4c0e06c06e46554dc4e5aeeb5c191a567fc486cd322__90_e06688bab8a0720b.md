## Important correctness boundaries

- `mincut>=rank` is a necessary condition only; no mincut violation != factorization.
- Graph **min-cut constraints** are a relaxation. Different cuts can be satisfied without a single shared generator assignment that matches all Fourier coefficients. The network model itself encodes quasiseparable generators.
- The determinant argument is **exact over complex numbers** because cyclotomic divisibility contradicts nonzero reductions at primitive finite-field roots; simple numerical residuals would not suffice.
- Standard arbitrary input DFT cost includes coefficient preparation, memory and precision. No O(N) or stronger sublinear-in-log FFT has been built by this research.
- The public OpenAI math repository claimed a separate exact `O(N(log N)^(1-1e-13))` result in 2026; its model is specialized and it is **not** this research route. Do not claim here to be first to beat general N log N in that model.
