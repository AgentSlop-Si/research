# Hero #17 continuation — run instructions

Python 3.10+ standard library suffices. The core field algorithm assumes a prime `p>N` with `N | (p-1)`, a supplied primitive `N`th root `omega`, and bounded ranks/spectral modes.

```bash
cd hero17_tensor_union
python -m unittest -v test_hero17
python independent_audit.py
```

Quick usage:

```python
from fused_fft import transform_if_supported
from tensor_union import root_for, direct_dft
from fiber_union import make_fiber_signal

N, p = 256, 65537
w = root_for(N,p)       # testing helper; not part of the online complexity theorem
Q = 16
modes = [[(t, t+1)] for t in range(Q)]
x = make_fiber_signal(N,p,w,Q,modes)
result = transform_if_supported(x,p,w,r=1)
assert result.branch == "fiber-union"
assert result.spectrum == direct_dft(x,p,w)
```

Cyclic convolution for graph-recognized fibers:

```python
from fiber_convolution import convolve_if_supported
z, proof = convolve_if_supported(x, x, p, w, r_x=1, r_y=1)
assert z is not None
```

Online inputs to recognizers are **raw `x` arrays**; generators construct fixtures only. `None` denotes that the fast structured path refused the input; it is not a claim the DFT does not exist. For arbitrary unsupported vectors, use a conventional FFT/NTT fallback. The attached package contains previous Hero #17 `phase_union_general.py` as an inherited building block; this continuation does not claim to originate the underlying classical identities.
