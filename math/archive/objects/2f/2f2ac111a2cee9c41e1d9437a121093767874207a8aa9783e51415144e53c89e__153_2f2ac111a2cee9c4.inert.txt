# Phase 12 auxiliary theorem: five small-angle stages cannot equal the DFT

**Scope:** This veto is restricted to products of at most five stages built with the *fixed parameters of our phase-12 family*, interleaved with arbitrary permutations and arbitrary **unit-modulus** coordinate phases. It is independent of the chosen random path permutations. It does not apply to strong-angle stages or general FFT circuits.

Let `S=V C1 C2` be any of the new unitary stages. Each path adjacency has operator norm <=2, so with `a=1/32` and `C=(I+i a A)(I-i a A)^(-1)`:

```
||C-I||2 <= 2*a*||A||2 <= 1/8.
```

Since the path Cayleys are unitary,

```
||C1 C2-I||2 <= ||C1-I||2+||C2-I||2 <= 1/4.
```

With `e=1/512` and Hermitian involution R,

```
V=(I+i e R)/sqrt(1+e^2),
||V-I||2 <= e+e^2/2.
```

Therefore uniformly for every stage, its inverse, and every permutation-conjugate:

```
||S-I||2 <= eta := 1/4+1/512+1/(2*512^2) < 0.251956.
```

If A is any product of `t` such unitary stages and arbitrary interspersed monomial unitaries, telescoping its factors shows A differs from the product P of only the interspersed monomials by

```
||A-P||2 <= t eta.
```

Here P is itself a monomial unitary. Let `Fhat_N=F_N/sqrt(N)` be the normalized Fourier matrix. Every one of its entries has modulus `1/sqrt(N)`; hence for every monomial unitary P,

```
||Fhat_N-P||F^2
  = 2N-2 Re tr(Fhat_N* P)
  >= 2N-2 sqrt(N).

||Fhat_N-P||2 >= sqrt(2-2/sqrt(N)).
```

For `N>=32`, the last quantity is at least `1.283139...` while `5 eta<1.259776`. Therefore **no product of t<=5 of these specific stages, even with arbitrary unit-phase diagonals, permutations, and inverses, can equal the normalized DFT for N>=32**.

This is a rigorous *finite-depth falsification criterion*, not a growing lower bound: it only forces t>=6 and does NOT rule out o(log N) stage counts. Reparameterizing the strengths can evade this particular bound but must be audited afresh for robust singular values and inverse cost.
