# Measured results for Fourier graph reuse

5 runs per case; medians in milliseconds. Python 3.12.14, NumPy 2.3.5, SciPy 1.17.0.

## Cold dense batches

Every method writes and retains every requested rFFT bin. The graph figures include calibration, metadata, planning, seed FFTs and output writes.
The ratio uses the fastest median among SciPy, the Phase 4 default, and Phase 5 auto; values below 1 mean the graph route is slower.

For the chain, lineage is supplied in the best order and usually wins. Cluster lineage follows chronological requests that alternate families; the graph can select within-family reuse instead. The star and coset ablations separate kernel gains from graph-planning gains.

## One correction with an existing base spectrum

N=262,144, k=64. This separate experiment excludes base-spectrum preparation. Quotient setup, its short FFT, phase construction and dense output are included.

| Support | Reduced length L | Native rFFT ms | 64 direct corrections ms | Quotient correction ms |
| --- | ---: | ---: | ---: | ---: |
| contiguous | 262,144 | 1.956 | 18.312 | 2.794 |
| comb | 64 | 1.900 | 18.217 | 0.716 |
| random | 262,144 | 2.144 | 17.747 | 2.671 |

The quotient helps the evenly spaced support. For contiguous and random supports it has L=N and loses to native rFFT.
