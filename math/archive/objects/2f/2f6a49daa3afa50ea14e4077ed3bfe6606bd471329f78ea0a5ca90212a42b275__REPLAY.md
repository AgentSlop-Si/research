# Reproduction and scope

The independent metadata checker reads source ZIPs only as inert bytes. It uses Python standard-library modules and does not execute or import any source or previous audit program.

Run from this workspace, preserving the source paths recorded in the recovery ledger:

    python verify_recovered_members.py --output recovered_text_metadata_replay

Choose an unsealed output directory. The checker refuses to write into a directory containing SEALED_MANIFEST.json. It verifies all 70 archive members, recovered texts, selected exact local copies and six previously declared audit archive identities. It does not prove theorems, verify historical execution claims, or check all members named in the source manifests.

ITEM_RECONCILIATION.json is an authored item-level status review, not an automatically inferred theorem proof. build_reconciliation_ledger.py records how that ledger was assembled and also refuses to modify a sealed destination; it is not required for metadata replay. The report and twelve hashed earlier reviews explain the mathematical scopes. Earlier reviews and originals remain at their existing paths.

The pre-review hash snapshot is copied unchanged. INPUT_HASHES_AFTER.json has a different presentation schema; equality is checked by the complete 70-element hash sets and each recorded item's archive/member identity.
