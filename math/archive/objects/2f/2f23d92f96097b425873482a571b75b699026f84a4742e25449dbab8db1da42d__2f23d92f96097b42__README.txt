Conditioned macro FFT: constructive conditional theorem and checks
9 October 2026

Start with PROVED_CONDITIONING_TRADEOFF.md.

Main developed results

1. A symbolic algebraic-height pass gives an explicit finite local conditioning
   certificate, including every primitive scalar field instruction.
2. A transparent two-bank implementation restores arbitrary scratch and permits
   serial reuse with no multiplication of conditioning across completed fibers.
3. An explicit slow-radix choice gives sub-N-log-N exact arithmetic work under
   a prescribed efficiently usable condition budget that tends to infinity.
4. A uniform constant bound on the normalized Bluestein chirp multiplier and a
   transparent additive wrapper extend the result to every length.

These are constructive conditional deductions from a uniform input-linear
sub-B-log-B primitive, using the source-reported #130 bound as an example.
No new fast primitive is implemented here. No literature novelty, practical
crossover, numerical stability, bit-complexity result or Ailon-model equivalence
is claimed. The low-condition output is the normalized Fourier transform.

Run the exact integer tests with Python 3 (standard library only):

  python3 -m unittest -v test_height_certificate.py
  python3 height_certificate.py example_height_dag.json

Run the independent mathematical toy checks:

  python3 independent_tests/test_condition_reset_independent.py --output results.json

The latter use SymPy and NumPy; see their own README. Their fused-shear tests
are complemented by the six-scalar-instruction implementation/proof and tests
in the main bundle. The exact tests and numerical checks are labeled separately.

The height extractor assumes a correctly specified local number field and a
verified coefficient DAG. It checks topology and requires nonzero-proof
references, but does not verify those external proofs or the Fourier identity.
It stores the exponent of its condition bound rather than expanding an enormous
integer. This is a usable certificate mechanism, not a bit-efficient evaluator
for the underlying exact transform.
