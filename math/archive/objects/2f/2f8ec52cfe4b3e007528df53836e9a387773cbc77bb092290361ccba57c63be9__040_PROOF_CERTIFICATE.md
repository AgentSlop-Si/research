# Exact Fourier factorization gates: local annihilators and three-stage alphabet obstruction

**Research checkpoint:** 2026-10-10. **Field of the theorems:** complex numbers. The modular program is an independent regression check, not the source of the proofs.

## Notation and precise scope

Let `F_N[i,j] = omega^(ij)`, with `omega` a primitive N-th root of unity. A permutation matrix between stages may be arbitrary. Diagonal factors described as invertible have no zero entries. We count every scalar operation in an eventual algorithm; the statements below are **nonexistence theorems for specified restricted operator families**, not an unrestricted FFT lower bound.

### Theorem A — two O(N) asymmetric-envelope scans are insufficient for N >= 10

Suppose the first stage is any matrix of the form

```
(S1)[i,j] = u[i]*r[j]  if i>j
           = d[i]       if i=j
           = v[i]*r[j]  if i<j
```

where every `r[j]` is nonzero and the row generators `u,v` and diagonal `d` are otherwise arbitrary. Suppose the second stage is any matrix of the form

```
(S2)[i,j] = ell[i]*b[j]  if i>j
           = delta[i]   if i=j
           = ell[i]*e[j] if i<j
```

where every `ell[i]` is nonzero and `b,e,delta` are otherwise arbitrary. Both matrices admit ordinary exact two-scan O(N) matrix-vector applications.

Then for **every** permutation matrix P, every pair of nonsingular diagonal matrices U,V, and **every N >= 10**,

`U F_N V != S2 P S1`.

**Proof.** Select the two adjacent input differences

```
x^(0) = e_0 / r[0] - e_1 / r[1]
x^(1) = e_1 / r[1] - e_2 / r[2].
```

Away from their respective two-coordinate supports, multiplying by S1 gives zero, because both off-diagonal tails have the same factor `r[j]`. Therefore S1*x^(0) is supported in {0,1} and S1*x^(1) in {1,2}. Their union has size at most three, even after the arbitrary permutation P.

Define the local output differences

```
(D y)[i] = y[i+1] / ell[i+1] - y[i] / ell[i],   0 <= i <= N-2.
```

For an input vector z, the component `(D S2 z)[i]` depends **only on** `z[i]` and `z[i+1]`: all contributions with input index below i or above i+1 cancel, by the common row factor `ell`. As a consequence, across the two special input vectors, the union of supports of `D S2 P S1 x^(0)` and `D S2 P S1 x^(1)` has size at most six. Thus at least `N-1-6 = N-7` of the `N-1` output row pairs annihilate **both** columns.

Now suppose that `U F_N V = S2 P S1`. Write `z = omega^i`. For the two special columns of U F_N V, their values in row i have the exact form

```
f_0(i) = U[i] * (alpha_0 + beta_0*z)
f_1(i) = U[i] * z * (alpha_1 + beta_1*z)
```

where each `alpha_j,beta_j` is **nonzero**, because V and r have no zero diagonal entries. If both local differences vanish at row-pair i,i+1, then the vectors `(f_0(i),f_1(i))` and `(f_0(i+1),f_1(i+1))` are linearly dependent. Their determinant is

```
U[i]*U[i+1]*z*H(z),
H(z) = omega*(alpha_0+beta_0*z)*(alpha_1+beta_1*omega*z)
       - (alpha_0+beta_0*omega*z)*(alpha_1+beta_1*z).
```

For the unscaled Fourier input `V=I`, substitution of `alpha_0=1/r[0]`, `beta_0=-1/r[1]`, `alpha_1=1/r[1]`, `beta_1=-1/r[2]` simplifies it to the **three-coefficient quadratic**

`H(z) = (omega-1)/(r[0]*r[1]*r[2]) * [r[2] - (1+omega)*r[1]*z + omega*r[0]*z^2]`.

For arbitrary nonsingular input diagonal V, simply replace `r[j]` by `r[j]/V[j]` in this expression. Thus the relevant quadratic depends on only three effective envelope coefficients, even though both stages have many free parameters. Its constant coefficient is `(omega-1)*alpha_0*alpha_1 != 0` and its quadratic coefficient is also nonzero. It therefore has **at most two** distinct complex roots. The values `omega^i` for `0 <= i <= N-2` are all distinct. Hence at most two row pairs can annihilate both Fourier columns. The factorization would require at least N-7 such pairs, contradicting N-7 > 2 for N >= 10. QED.

**Affine endpoint permutations are also covered.** If the Fourier input and output coordinates are independently reordered by affine maps `j -> t*j+d` and `i -> s*i+c` modulo N, with `gcd(s,N)=gcd(t,N)=1`, then

`omega^((s*i+c)*(t*j+d)) = omega^(c*d) * omega^(s*d*i) * omega^(c*t*j) * (omega^(s*t))^(i*j)`.

The first three factors are nonzero row/column diagonal scalings and `omega^(s*t)` is still primitive. The same proof applies. **General non-affine endpoint permutations, including bit reversal, are NOT covered.**

**Critical limitations.** This theorem does not cover stages with *independent* lower and upper column generators in the first stage **and** independent lower and upper row generators in the second. It also does not survive an arbitrary separate permutation of the Fourier input or output coordinates. It is nevertheless strictly broader than homogeneous scans: all diagonals and one full pair of row/column generator arrays may vary with position.

### Theorem B — two homogeneous scans cannot factor F_N for N >= 6

Define `H(a,b,d)[i,j] = a` below the diagonal, `b` above, `d` on the diagonal. When at least one of a,b is nonzero, select the **forward** cyclic shift if b != 0, otherwise the **backward** cyclic shift. In the forward case, define K with `K[i,i+1]=b` for `i<N-1`, `K[N-1,0]=a`, and let

```
B = K - b*I,
A = (d-b)*K + b*(a-d)*I.
```

Direct multiplication proves `B H = H B = A`, **without any invertibility or nonzero-denominator assumption**. In the backward case use `K[i,i-1]=a`, `K[0,N-1]=b` and

```
B = K - a*I,
A = (d-a)*K + a*(b-d)*I.
```

These identities are equally exact. Each A and B is cyclic bidiagonal, with at most two nonzero entries per row and column.

Suppose `F_N = H2 P H1`. Then `B2 F_N B1 = A2 P A1`. Choose column 1 of B1 if its direction is forward, otherwise column 0. This column is a nonzero multiple of `e_0-e_1`. Its Fourier transform is a nonzero multiple of `1-omega^i`. Taking the B2 difference leaves **N-1 nonzero** interior entries, proportional to `omega^i*(1-omega)`. But the same column of `A2 P A1` has support at most four. This is impossible when `N-1>4`, i.e. `N>=6`.

If either H is scalar, the product is a row/column permutation of a single homogeneous stage. Every such stage has at most three distinct entries per row; the frequency-one row of F_N has N distinct entries. This separately excludes the scalar cases when `N>=6`. QED.

### Theorem C — three homogeneous scans cannot factor F_N for N >= 15

Suppose `F_N=H3 P2 H2 P1 H1` with every H homogeneous and P1,P2 arbitrary permutations. First assume H1,H3 each have at least one nonzero off-diagonal constant, and choose their B and A operators as above. Then

`B3 F_N B1 = A3 P2 H2 P1 A1`.

Use the same special column of B1. On the left, among the N-1 interior coordinates selected by B3, the result is a nonzero multiple of `omega^i`, so **all N-1 values are distinct**.

On the right, A1 maps the special basis vector to a vector with at most two nonzero entries. After P1 and H2, every coordinate except at most two exceptional input positions takes one of **three baseline values**: before the first support point, between the two support points, or after the second. After P2 the multiset property persists: at most two exceptional entries and three ordinary values. Finally, the interior rows of the cyclic-bidiagonal A3 are constant-coefficient combinations of two neighboring entries. Ordinary-ordinary pairs generate at most `3*3=9` distinct values, and at most `2*2=4` neighboring pairs touch an exceptional position. The right-hand interior vector therefore has at most **13 distinct values**. It cannot equal the left-hand vector if N-1>13, i.e. N>=15.

**Scalar endpoints.** If H1 is scalar but H3 is not, right-multiply the supposed Fourier identity by P1^-1, then left-multiply by B3. Choose the frequency-one Fourier column. The left side has N-1 distinct interior values, while the right side is A3 applied to a permutation of one column of H2. Such a column has at most three distinct entries, so A3 produces at most nine distinct interior values; impossible for N>=15. If H3 is scalar but H1 is not, left-multiply by P2^-1 and right-multiply by B1. The left vector has N distinct values, whereas H2 applied to a two-sparse vector has at most five; impossible. If both endpoints are scalar, the resulting matrix is a row-and-column permutation of one H2 and each row has at most three distinct entries. A zero scalar makes the product singular. Hence all scalar degeneracies are also excluded. QED.

**Interpretation:** for powers of two, three homogeneous global scans cannot give a 16-point or larger exact Fourier transform, regardless of internal permutations or coefficient magnitude. This theorem **does not cover** arbitrary nonhomogeneous row/column generators; it does not show an asymptotic depth bound.

## Structural classification — the prior dense scan is a twisted circulant

For a homogeneous H with a,b nonzero and a != b, choose q satisfying q^N=a/b and let `D_q=diag(1,q,...,q^(N-1))`. Then

`D_q^-1 H D_q` is an **ordinary circulant**:

```
C[i,j] = d                    if i=j,
         = b*q^((j-i) mod N)  otherwise.
```

Hence its eigenvectors are ordinary Fourier characters. H has eigenvectors `v_k[i]=(q*omega^k)^i`, with

```
lambda_k = ((d-b)*q*omega^k + (a-d)) / (q*omega^k - 1).
```

The denominator never vanishes because `q^N != 1`. Since a!=b the Möbius map is nonconstant and the N eigenvalues are distinct. For the previously studied dense scan a=1, b=2, d=3, we obtain q^N=1/2 and lambda_k=(q*omega^k-2)/(q*omega^k-1).

**This does not yield a fast FFT**. Cheaply applying a matrix and cheaply computing its eigenvector transform are different tasks. It does explain some of the otherwise surprising algebraic simplicity of the earlier Green/scan example.

## What is and is not established

- **Established in the stated mathematical models:** Theorems A-C, exact cyclic bidiagonal identities, and the twisted-circulant diagonalization.
- **Not established:** Fourier impossibility for arbitrary separated-generator scans in three or more stages; any `o(N log N)` implementation; any universal arithmetic lower bound; any priority claim over the preexisting quasiseparable/linear-circuit literature.
- **Next target:** two/three-stage compatibility with independent lower/upper row AND column generators, exploiting three-tap local annihilators, and then non-affine endpoint layouts. Any constructive claim must be checked against an exact independent NTT and a full scalar-operation count.
