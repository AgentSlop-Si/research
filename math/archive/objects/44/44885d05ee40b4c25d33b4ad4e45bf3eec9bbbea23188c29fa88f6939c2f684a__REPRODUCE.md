# Reproduce

Use Python 3 with its standard library. No additional packages, network calls, source-package code, uploaded code, or numerical root finder is used by either deliverable script.

From this directory:

    python check_classification.py
    python verify_certificates.py

The first run regenerates `MODULAR_CERTIFICATES.json` and `CHECK_RESULTS.json`; the second reconstructs and independently verifies the saved finite certificates and writes `CERTIFICATE_VERIFICATION.json`. The captured successful run took about 40 seconds in the supplied environment, with machine-dependent timing. The elapsed-time field is deliberately not a deterministic mathematical output.

The finite certificates are proofs for the listed characteristic-zero sizes: each nonzero modular discriminant lifts to a nonzero algebraic integer discriminant. The separate report supplies the uniform resonance theorem and the prime-order squarefreeness theorem. A finite run is not substituted for the unresolved composite-order theorem.

`check_classification.py` implements its own modular polynomial arithmetic, polynomial Bezout computations, prime and exact-order checks, rational cyclotomic arithmetic, quotient-algebra trace and scan controls, and Hermite Sylvester determinants. `verify_certificates.py` imports no code from it, reconstructs coefficients by a different recurrence, verifies each saved Bezout identity, and evaluates the polynomial at every finite cycle root.

To check the sealed deliverable without modifying it:

    sha256sum -c MANIFEST.sha256

`SOURCE_HASHES_BEFORE.json` and `SOURCE_HASHES_AFTER.json` agree on all 22 protected input files. `SOURCE_SEAL_VERIFICATION.json` records independent verification of both predecessor manifests. No predecessor or uploaded constructor/checker was executed or imported.

The manifest excludes itself and covers every other file in this directory. There are no binary artifacts or external code dependencies.
