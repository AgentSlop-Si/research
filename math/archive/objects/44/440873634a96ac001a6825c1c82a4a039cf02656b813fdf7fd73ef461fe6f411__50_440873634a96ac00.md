## Verdict for the active exact-output goal

This file is a separate approximation research checkpoint. It expressly asks for approximate Fourier outputs and contains no exact-transform construction. Its equal-magnitude signed-atom sampler is mathematically sound as an unbiased Monte Carlo approximation. Neither unbiasedness nor an all-output additive error bound implies exactness. Setting epsilon to zero is not supported by its sample complexity, alphabet sizes, or tables.

A decisive two-dimensional example: choose a real irrational 0<a<1 and x=(a,1-a), so L_box(x)=1. Every k-sample empirical surrogate has y=(c/k,1-c/k) for an integer c. The second unitary F2 output is (2c/k-1)/sqrt(2), while the desired output is (2a-1)/sqrt(2). These differ for every finite k and every outcome. This is already a failure of exactness before any lookup or phase quantization. Finite rounding cannot repair it uniformly. More generally, with fixed L_box a finite descriptor alphabet cannot encode every point of a continuum injectively, whereas the Fourier map is invertible.

This argument addresses arbitrary complex inputs, as in the active goal. A word-RAM model with bounded-precision inputs is a different model; even there the supplied algorithm claims approximation, not an exact identity.

## What is genuinely useful

1. Split each complex x_j into real and imaginary signed mass. Write L=sum_j(|Re x_j|+|Im x_j|). Sample a unit atom A from {+e_j,-e_j,+i e_j,-i e_j}, with mass probabilities |Re x_j|/L or |Im x_j|/L and the appropriate sign. For L>0, E[A]=x/L. Therefore y=(L/k) sum_l A_l is unbiased. The case L=0 should return zero immediately.
2. Every sample has identical magnitude L/k; no arbitrary complex coefficient needs to be carried in a lookup key.
3. L<=sqrt(2)||x||_1, so the change from complex-magnitude sampling loses at most a constant in the stated additive norm guarantee.
4. For fixed epsilon and fixed failure probability, finite phasor descriptors allow a sublinear-size Four-Russians-style lookup table in principle. The checkpoint properly lists uniform preprocessing, packing, input model, and prior-art review as unfinished obligations.

## Explicit concentration calculation

For a unitary Fourier row m, define Z_l=s_l omega_N^(j_l m). Then |Z_l|=1 and

    (U y-U x)_m = (L/sqrt(N)) [(1/k) sum_l Z_l-E Z_l].

The real and imaginary parts each lie in [-1,1]. If a complex difference has magnitude greater than epsilon, one component has magnitude greater than epsilon/sqrt(2). Applying the elementary bounded-variable tail bound to the two components and taking a union over N rows gives

    Pr[||U y-U x||_infinity > epsilon L/sqrt(N)]
        <= 4N exp(-k epsilon^2/4).

Thus k>=4 epsilon^(-2) log(4N/delta) suffices under independent sampling. Constants can be improved, but the stated O(epsilon^-2 log(N/delta)) is correct. Fresh dense input still has to be inspected to construct its mass distribution.

## Decoder error: correct form, missing conventions

A phasor trajectory for one atom in a block is exp(i(alpha+t beta)) times a signed phase. If start and slope phase errors are bounded by eta_0/2 and eta_s/2, respectively, the complex error at lane t is at most (eta_0+t eta_s)/2, using |exp(iu)-exp(iv)|<=|u-v|. The supplied eta_phase/2 term is valid only if eta_phase bounds the TOTAL block phase discrepancy, not merely the slope quantizer's step. Requiring eta_0+B eta_s=O(epsilon) explains why the slope descriptor requires O(log B+log(1/epsilon)) bits.

Rounding each real and imaginary lane to a grid with spacing h changes the complex number by at most h/sqrt(2). Convexly averaging equal-size groups preserves that bound. Accordingly the displayed sum

    eta_phase/2 + h1/sqrt(2) + h2/sqrt(2)

is a legitimate deterministic normalized-error budget once phase conventions and aggregation weights are specified. For unequal last groups, either weight by group size or pad with zero atoms and use one consistent normalization. Taking an unweighted average of unequal group averages would introduce an additional error not presently charged.

A complete proof must include approximation error in table construction itself and final output scaling/rounding. The checkpoint does not yet do so. Sampling and deterministic errors combine by triangle inequality; deterministic rounding does not need another failure probability.

## Complexity accounting and unresolved assumptions

- The advertised fixed-epsilon asymptotics also need a restriction such as log(N/delta)=O(log N). If delta shrinks much faster, the sample count and all group counts change materially. It is misleading to say G=O(log log N) from fixed epsilon alone while leaving delta unrestricted.
- Arbitrary real/complex input is not a finite word-RAM input format. The theorem must specify input bit widths, common scales or exponent ranges, mass accumulation, random-word access, probability sampling, and output representation. Computing exact arbitrary real probabilities is not an O(1) word operation.
- For bounded-width integer or fixed-point masses, an O(N)-word sampler is plausible using a charged alias/cumulative construction, but it must be specified and its integer widths bounded. Its implementation is not supplied.
- The stored sample coordinate j still needs Theta(log N) bits. The small p=O(log log N+log(1/epsilon)) descriptor is a QUANTIZED block-local phase representation, not a lossless representation of j. Construction/update of those descriptors remains part of the online cost.
- If k=Theta(log N) and block length B=Theta(log N), even constructing all k block descriptors with O(1) word operations apiece costs O((N/B)k)=O(N). This observation can simplify the intended proof: descriptor construction need not itself be o(N).
- The output of a first table is a B-lane vector, not one machine word merely because its input key fits one word. The checkpoint acknowledges this issue. Its asserted O(Bp/w) output-word count is a safe upper bound only after the actual lane format is defined. For fixed epsilon the first-level rounded alphabet can use O(1) bits per lane; atom-descriptor width and lane width should not be conflated.
- A second per-lane table of polylogarithmic size does not by itself prove fast construction of all its lane keys. Transposition or packed accumulation must be an explicit algorithm; calling it 'tabled in packed form' does not settle the cost.
- A table with N^gamma keys and polylogarithmic per-key work and output is sublinear for fixed gamma<1. This supports the stated table-size goal but is not a construction: the key alphabet, invalid/padded keys, coefficient computation, output storage layout, and exact build cost must be given.
- Uniform scalar preparation cannot assume preinstalled arbitrary-real trig or Fourier tables for free. Approximate table constants may be generated with charged bounded-precision work; those errors must join the error budget.
- The note contains no prototype, measured result, or independently checkable complete algorithm. Its seven open obligations are substantive, not cosmetic.

## Interpretation of the approximation guarantee

The tolerance is epsilon L_box(x)/sqrt(N), not epsilon times each Fourier coefficient. It permits large relative error, including loss of small but meaningful coefficients, when the input has large total absolute mass or substantial cancellation. It is an honest additive all-bin guarantee and should be assessed in that form. No exact recovery or relative per-frequency guarantee follows.

## Recommendation

Keep this as an explicitly separate approximate, bounded-precision Word-RAM research branch. The signed-atom simplification is worth retaining there. It does not advance the exact arbitrary-input all-output target, and no claimed O(N) theorem should be promoted before its remaining model, packing, preprocessing, error, and prior-art obligations are discharged.
