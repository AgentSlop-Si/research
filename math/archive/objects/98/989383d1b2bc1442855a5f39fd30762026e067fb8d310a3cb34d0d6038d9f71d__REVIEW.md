## 1. Accepted all-N twirl and stochastic bound

Use the source's negative-exponent unitary Fourier U, S e_j=e_(j+1), D=diag(omega^j), W=D^a S^b and Phi(W)=S^(-a)D^b. The order and phases are correct. With X=U* M, the covariance residual is U[X,W]. Averaging W*XW over all a,b first removes offdiagonal entries and then equalizes the diagonal, giving tr(X)I/N. Expanding the commutator norm therefore gives

    E_W ||M W-Phi(W)M||_F^2 /2
       = ||M||_F^2-|tr(U*M)|^2/N
       = min_lambda ||M-lambda U||_F^2.

This is valid at composite lengths as well. Let tau^2 denote that minimum. For independent standard complex Gaussian z, the sample Z=||[MW-Phi(W)M]z||^2/2 has mean tau^2. Subtracting the minimizing Fourier component bounds every residual Frobenius norm by 2tau. The exact Gaussian quadratic-form fourth moment is ||A||_F^4+tr((A*A)^2), at most 2||A||_F^4. Hence E Z^2<=8tau^4 and Var Z<=7tau^4. The stated k>=ceil(28/epsilon^2) samples per group and h>=ceil(8 log(1/delta)) median groups suffice by Chebyshev and Hoeffding. For tau=0, all exact residuals vanish.

Each sample uses two candidate applications plus shifts, diagonal phases and vector arithmetic. Phase powers can be generated by recurrence in O(N) arithmetic after O(log N) scalar exponentiation, with linear storage. The O(N) claim is conditional on an O(N)-applicable fixed candidate and constant accuracy/confidence, and is an arithmetic-model assertion. Exact Gaussian sampling and numerical precision/stability require an explicit model; no finite floating-point test proves exact equality.

### Optional rigorously justified discrete-probe improvement

The same constants hold with independent z_i uniform on {1,-1,i,-i}. Then E(zz*)=I, and for H=A*A,

    E (z*Hz)^2 = (tr H)^2+tr(H^2)-sum_i H_ii^2

Thus discrete four-phase sampling avoids an ideal exact-Gaussian oracle while preserving the theorem and the same median-of-means constants. This is an independently derived extension, not a claim made by the source. Our exhaustive small-size controls check its mean and fourth-moment identity.

## 3. Accepted fixed-coordinate cut statements

For invertible G=(I-diag(w)P)^(-1), complementary inverse-block nullity gives rank G[A,A^c]=rank(I-diag(w)P)[A,A^c]. The latter is a weighted partial permutation, so its rank equals the count of nonzero crossing edges. Diagonal endpoint gauges cannot increase this rank, even if some endpoint masks are singular. Sums add rank budgets, and a product satisfies

    rank(XY)[A,A^c]<=rank X[A,A^c]+rank Y[A,A^c]

by splitting the intermediate indices into A and A^c. This proves the claimed branch budget for compositions in a fixed global coordinate frame without uncharged shuffles. It does not cover independently unmatched endpoint permutations within different branches.

At prime length in characteristic zero, arbitrary outer nonsingular monomial gauges still leave every rectangle of given dimensions full rank for the Fourier target. Thus a necessary expansion condition can be applied to the core after explicitly factoring those outer gauges. For composite lengths, one must preserve or correctly transport the specific target cut; full rank is not true for all cuts.

## 4. Required correction: common interstage shuffles

Pushing a common interstage permutation through branches conjugates their cycles but generally leaves a residual outer permutation. The source's T4b asserts rank M[A,A^c]<=b_total(A) for the complete transfer M while counting only Green branch crossings. That statement is false.

A robust explicit counterexample uses N=12 and A={0,...,5}. Each of two stages is I=(I/2)+(I/2), with both terms represented as legal zero-weight Green resolvents on the natural Hamiltonian cycle and nonsingular diagonal endpoints. Insert the half-swap P=S^6 between the stages. The resulting M=P has rank M[A,A^c]=6. The four branches have zero nonzero-weight crossings. Even if all potential natural-cycle crossings are counted despite zero weights, the total is only four. Moreover the half-swap commutes with the natural cycle, so conjugating these cycles does not repair the deficit. The example exceeds either crossing convention.

Two valid repairs are available:

1. Count each interstage shuffle as a separate factor, adding rank P[A,A^c] to the same product budget.
2. Factor all shuffles into a residual outer monomial explicitly and state the branch-only inequality for the gauged core, using the corresponding transported target block.

The source's fixed-coordinate parity inference is valid only after this bookkeeping, or when all residual permutations preserve the selected cut. The prime full-minor exact obstruction can survive the second repair, but the unqualified T4b statement cannot be accepted.

## 5. Parity spectral and energy barrier

For N=2m with m odd, the even-row/odd-column unitary Fourier block has Gram matrix I_m/2. Indeed its kernel is a diagonal phase times the m-point Fourier kernel with row multiplier two, which is invertible modulo m. All singular values are 1/sqrt(2). If the actual candidate block has rank below m, restriction and the minimum singular value give ||M-U||_2>=1/sqrt(2). Combining with the seed bound gives tau>=(1/sqrt(2)-delta_0)_+/2 and mean probe energy at least (1/sqrt(2)-delta_0)_+^2/4. Exact seed gives 1/8.

This is an accepted operator statement. Inferring its rank hypothesis from a Green architecture requires the corrected cut accounting above. A cut-capacity pass never proves phase correctness. Neither low stochastic loss nor exact finite-size success establishes a growing uniform exact family.
