# Hero #0 — Phase 5 verified research package

**Target:** Exact arbitrary-input O(N) or O(N log log N) Fourier transform; not yet achieved.

**Current outcome:** Eliminated the separate M exact Green scans by collapsing all phase channels before the long transform. The resulting algorithm is the classic mixed-radix Cooley–Tukey FFT in O(Q log Q). Independently proved and tested a unitary M×M transfer obstruction to low-rank phase compression, exact finite-population Green-frame moment identities, and a Gaussian-distribution accuracy barrier for measurement-only sub-M-row decoders.

Read `THEOREMS.md` for full proofs and precise computational models. Read `CHAIN_HANDOFF.md` for the next research target. The `prior_phase4_bundle.zip` is the archived immediate ancestor, included to preserve provenance.

## Run

Python 3.10+ with NumPy:

```bash
python -m pip install numpy
python run_all.py
```

`finite_field_certificate.py` uses only Python's standard library and does not rely on floating-point arithmetic. Individual scripts write machine-readable JSON certificates/results alongside the code.
