# Hero #0 Phase 8 — certified exact cycle-rational Fourier families

**Research date:** October 10, 2026  
**Status:** Exact algebraic identities with executable modular certificates and negative controls. **Not** a worst-case `O(N)` FFT, `O(N log log N)` FFT, new integer multiplication bound, or independently validated novelty theorem.

## 1. Model and scope

Let `N=KM`, `K>=M`, and for the executable realization let both `K,M` be powers of two. Throughout write `ω_N` for a primitive `N`th root of unity, and define the **unnormalized, negative-exponent** DFT:

`X[k] = sum_{n=0}^{N-1} x[n] ω_N^(-kn)`.

Our certificate programs work over the prime field `F_p`, `p=2013265921`, for transform sizes dividing `p-1`. A formal asymptotic family would use complex exact arithmetic or a family of fields admitting the required roots. Field inversions, comparisons, input scans, preparation, indexing, and the **explicit N outputs** are charged; the algorithms branch on data. Field-operation count is **not bit complexity** and is **not the scalar-linear-circuit model** of all-input exact DFT results. A primitive transform root is supplied/generated under the conventional root-access assumption.

Write the input as `M` length-`K` columns `v_t[b]=x[bM+t]`. Define `ω_K=ω_N^M`. For `0<=ell<K,0<=j<M`, direct algebra yields

```
X[ell+jK] = sum_{t=0}^{M-1} ω_N^(-(ell+jK)t) * F_t[ell],
F_t[ell]   = sum_{b=0}^{K-1} v_t[b] ω_K^(-ell*b).
```

This polyphase identity is classical and exact for **every** input. The improvement below arises only when additional time/column dynamics are *certified*.

## 2. Theorem A: unknown first-order circulant cycle — exact O(N) on accepted inputs

Fix a dictionary `D={d_1,...,d_s}`, with **constant** `s`. The input is accepted when one fixed, initially unknown set of field coefficients `c_d` satisfies **all**

```
v_{t+1}[b] = sum_{d in D} c_d v_t[(b+d) mod K],  0<=t<M-1.
```

An online modular echelon solver finds a suitable `c`, if one exists, using `O(s^2 N)` field operations and `O(N)` storage; its answer is independently checked on every coordinate. A zero test and field inversion are permitted and counted. If this certificate fails, our specialization does not run; a general NTT/FFT fallback still costs `O(N log N)`.

Since `S v[b]=v[b+1]` has Fourier eigenvalue `ω_K^ell`, the learned circulant operator has eigenvalue

```
lambda[ell] = sum_{d in D} c_d * ω_K^(ell*d).
F_t[ell]   = lambda[ell]^t * F_0[ell].
```

Let `rho[ell,j] = lambda[ell]*ω_N^(-(ell+jK))`. The **entire N-bin transform** is

```
X[ell+jK] = F_0[ell] * (1-rho[ell,j]^M)/(1-rho[ell,j]),  if rho!=1,
X[ell+jK] = M*F_0[ell],                                 if rho==1.
```

There is no algebraic division-by-zero error: the second branch is the exact polynomial limit. Moreover, `rho[ell,j]^M=lambda[ell]^M * ω_K^(-ell)`, **independent of j**. A shared numerator is prepared once for each `ell`, and a standard prefix/suffix batch-inversion scheme computes all other denominators with **one field inversion plus O(N) field multiplications**. Build the `N`th-root power table by O(N) repeated multiplications.

Cost:

- O(s² N) exact full-input coefficient discovery and certification;
- O(K log K) for the **single** K-point transform of `v_0`;
- O(sK + KM + N) for eigenvalues, shared powers, all denominators, batch inversion and N explicit outputs.

For constant s, **M=Θ(log N)**, and K=N/M, `K log K=O(N)`. Hence **T(N)=O(N)** for certified inputs, first request, one processor, with all table and output work charged. This claim uses input-dependent division; it does not imply O(N) scalar linear FFT circuits. If `M` is constant, the same method only proves `O(K log K)=O(N log N)`.

### A provably full-column-rank accepted family

This is not only an explicit finite example. Take dictionary `D={0,d}` with `gcd(d,K)=1` and `c_1 != 0`. Then `lambda[ell]=c_0+c_1*ω_K^(d ell)` are **K pairwise distinct** eigenvalues. If the seed `v_0` has at least M nonzero Fourier coefficients, the K×M matrix of column spectra is

`[F_t[ell]] = diag(F_0[ell]) [lambda[ell]^t]_{ell,t}`.

Any M distinct nonzero-seed rows form an invertible Vandermonde matrix. Therefore **rank([v_t]) = M**, the maximum possible. The recognized O(N) family contains dense matrices of maximal ordinary rank for arbitrarily large admissible dimensions, not merely the particular N=128 certificate. This does **not** make the family generic among all N-entry inputs, since the generator still has only K+s degrees of freedom.

### Unknown shift recovered too (generic identifiable subcase)

For `D={0,d}` with initially unknown `d` and unknown `c_0,c_1`, compute only the first **three** Fourier values `F_0[0..2]` and `F_1[0..2]` directly, with O(K) work. If all three denominators `F_0[ell]` are nonzero and `c_1!=0`, `1<=d<K`, then

```
lambda_ell = F_1[ell] / F_0[ell] = c_0+c_1 ω_K^(ell*d),
q = (lambda_2-lambda_1)/(lambda_1-lambda_0) = ω_K^d.
```

An O(K) root walk identifies `d` exactly; then Theorem A recovers/validates the coefficients and the **whole input**. Degenerate cases may be rejected or handled by the scalar dynamics branch. Tests: **140 exact hidden-shift cases**. All roots and divisions were included in the operation counter.

## 3. Theorem B: fixed higher-order circulant cycle — exact O(N)

Let `r` and `s` be **fixed constants**. Assume there exist time-independent but **unknown** coefficients `c_{h,d}` satisfying

```
v_t[b] = sum_{h=1}^r sum_{d in D} c_{h,d} v_{t-h}[(b+d) mod K]
```

for every `r<=t<M` and `0<=b<K`. Again solve the overdetermined linear system over *all* input equations and verify it exactly. There are `rs` unknowns and O(N) equations, so O((rs)² N) discovery/certification work for this implementation.

Define frequency-dependent coefficients `b_h(ell)=sum_d c_{h,d} ω_K^(ell*d)`. Each frequency sequence `a_t=F_t[ell]` obeys

`a_t = sum_{h=1}^r b_h(ell) a_{t-h}`.

For `A_M(z)=sum_{t=0}^{M-1}a_t z^t`, set

```
D(z) = 1 - sum_{h=1}^r b_h z^h,
P_u = a_u - sum_{h=1}^u b_h a_{u-h},                   0<=u<r,
Q_u = -sum_{h=u+1}^r b_h a_{M+u-h},                  0<=u<r,
P(z)=sum_{u=0}^{r-1} P_u z^u,  Q(z)=sum_{u=0}^{r-1} Q_u z^u.
```

The exact **polynomial** identity is

`D(z) A_M(z) = P(z) + z^M Q(z)`.

At the output points `z_j=ω_N^(-(ell+jK))`, `z_j^M=ω_K^(-ell)` is independent of j. All nonsingular values can thus be evaluated by the rational expression

`A_M(z_j) = [P(z_j)+ω_K^(-ell)Q(z_j)] / D(z_j)`

in O(r) work/output plus **one batch inversion**. Since `D(0)=1` and `deg D<=r`, at most **r** among the M distinct `z_j` have `D(z_j)=0` for any fixed `ell`. Evaluate each exceptional output by its original O(M)-term polynomial sum; over all ell, this costs at most `O(rKM)=O(rN)`. The certificate code explicitly takes this branch (tested).

Initial r K-point FFTs: O(rK log K). Computing the last r boundary terms by scalar recurrence: O(rN). Polynomial evaluations, singular handling and output: O(rN). For fixed r,s and `M=Θ(log N)`, this proves **O(N)**, *conditional* on the validated order-r recurrence. Repeated degree-r rational evaluation is a classical algebraic mechanism, not independently established mathematical novelty.

## 4. Theorem C: noncommuting Weyl graph — exact O(N log log N)

Define Weyl generators acting on each length-K column:

```
(W_{p,q}v)[b] = ω_K^(q*b) v[(b+p) mod K].
```

They need not commute: with `S=W_{1,0}`, `D=W_{0,1}`, the exact identity is `S D = ω_K D S`. Suppose each transition is an **unknown, time-varying** combination of `s` publicly fixed generators:

```
v_{t+1} = sum_{i=1}^s c_{t,i} W_{p_i,q_i} v_t.
```

Recover each `c_t` from K exact linear constraints (O(s² K) per time step) and independently certify every coordinate. The key Fourier-space representation is

`F(W_{p,q}v)[ell] = ω_K^((ell-q)p) F(v)[ell-q]`.

Therefore, after ONE K-point FFT of `v_0`, each subsequent full K-spectrum costs O(sK) sparse accesses and operations—even for noncommuting generators. The M spectra combine with **K length-M FFTs** using the all-input polyphase identity from §1.

Total `O(s²N + sN + KlogK + NlogM)` = **O(NloglogN)** for constant s and M=Θ(log N), on inputs admitted by the detector. There is no universal-input result or generic full rank contraction: the input-specific controls contribute only O(sM) new degrees of freedom.

## 6. Precise generic-input barrier

Over a finite field of size q, the Theorem A dictionary-fixed family is generated by K arbitrary seed values and s arbitrary operator coefficients, so it contains at most `q^(K+s)` distinct length-N input vectors. For uniform random input,

`Pr(accepted) <= q^(K+s-N)`.

If one unknown shift d is allowed, multiply this bound by at most K. For N=128, K=16, M=8, s=2, q=2013265921, the latter bound is less than `10^-1022` (the exponent is approximately -1022.23).

The order-r family similarly has at most `q^(rK+rs)` inputs, so it cannot cover all `q^N` inputs when `rK+rs<N`. For the noncommuting time-varying Weyl family with a fixed dictionary, there are at most `q^(K+s(M-1))` inputs, giving probability `<=q^(K+s(M-1)-N)`.

This is a rigorous **restriction on those particular generative families**, not a lower bound for DFT algorithms, algebraic circuits with other operations, or universal exact Fourier transforms. A generic random input independently selects every column; with a fixed two-generator library the next K-vector almost never lies in the span of two prescribed K-vectors.

## 8. Why free per-coordinate controls hide a Fourier transform

Suppose we abandon the fixed sparse Weyl dictionary and allow **any** diagonal control `g_b`, so for nonzero `u[b]` every desired new column `v[b]` is expressible by `v[b]=g[b]*u[b]`. It is tempting to claim that discovering `g=v/u` in O(K) makes every transition fast. But the Fourier update obeys the exact convolution theorem

```
DFT_K(g .* u)[ell] = K^{-1} sum_{q=0}^{K-1} DFT_K(g)[q] * DFT_K(u)[ell-q].
```

The input-domain recognition is linear, but **the spectral update is generically dense**. Over a finite field with K invertible, conditional on a fixed nonzero u and a uniformly random v, g is uniform, so `DFT_K(g)` is also uniform in `F_q^K`. All K Fourier coefficients are nonzero with probability `(1-1/q)^K >= 1-K/q`; low dictionary support is extremely unlikely. For an adaptively selected subset of at most s spectral/Weyl modulation modes:

`Pr(sufficient s-sparse control) <= binom(K,s) q^(s-K)`.

This is a formal obstruction to the **sparse-control** shortcut, not an FFT lower bound. A more sophisticated universal network could share this dense convolution; we have not found such a network. `control_barrier.py` independently verified the full convolution identity and full spectral control support for **180 random examples** across K=8..256, and records the exact cardinality bounds in `CONTROL_BARRIER.json`.
