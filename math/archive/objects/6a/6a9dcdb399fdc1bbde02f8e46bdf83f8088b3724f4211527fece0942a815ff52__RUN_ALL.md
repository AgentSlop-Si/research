# Run all verification checks

From this directory:

```bash
OPENBLAS_NUM_THREADS=1 python verify_paired_gate.py
```

To validate the inherited checkpoint after extracting `prior_checkpoint_full.zip` separately:

```bash
python old/fft_outer_stability_gate_2026-10-10/verify_moment_rational.py
OPENBLAS_NUM_THREADS=1 python old/fft_outer_stability_gate_2026-10-10/verify_outer_stability.py
```

The `old/` path is illustrative: the predecessor archive is retained intact and can be extracted at your chosen location. Verify SHA-256 hashes using `SHA256SUMS.txt` after a clean extraction of the new archive.
