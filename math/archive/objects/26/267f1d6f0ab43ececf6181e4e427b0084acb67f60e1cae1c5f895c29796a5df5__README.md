# FFT Hero #1 — Phase 24: Deferred Green-conjugate Fourier graph

**Result:** a runnable exact finite-field Fourier evaluator that integrates Phase 23's certified sparse-rational branch with an `O(N)`-storage lazy/deferred radix-2 graph. It computes a small Fourier preview, either certifies and decodes a structured signal or completes the same native FFT **without repeating butterfly arithmetic**. A Green conjugation identity avoids generating residuals for typical rejected inputs.

**Status:** Theorem/code/regression checkpoint. It is **not** an unrestricted sub-`N log N` FFT; on tested power-of-two lengths the ordinary native FFT is faster than the structured detection branch. Earlier claims of gains relative to full Bluestein should not be interpreted as gains relative to an optimized dyadic FFT.

## Files

- `THEOREM.md` — exact DIF scheduling proof, Green identity, scratch bound, ten-probe work formula and input-family counting theorem
- `deferred_dif.py` — main per-input deferred computation graph and certified Green evaluator
- `lazy_dif.py` — simpler eager-butterfly lazy graph as a control
- `short_probe_fusion.py` — inherited Phase 23 solver with a backward-compatible optional external probe and lazy residual callback
- `COST_LEDGER.md` — fair comparison against native radix-2 and Phase 23; includes memory-accounting caveats
- `NEGATIVE_GATE.md` — why preview/structured families do not prove generic speedups
- `benchmark_phase24.py`, `PHASE24_BENCHMARK.json` — measured finite-field work counters
- `test_phase24.py`, `audit_phase24.py`, `PHASE24_AUDIT.json` — deterministic independent exact checks
- `PRIOR_PHASE23_COMPLETE.zip` — untouched previous research checkpoint with all earlier lineage
- `NEXT_GATE.md` — research directions with falsifiable acceptance criteria

## Reproduce

```bash
python3 -m unittest discover -p 'test_*.py' -q
python3 audit_phase24.py
python3 benchmark_phase24.py
sha256sum -c MANIFEST.sha256
```

Python 3.11+; no external library. Work counts are field arithmetic, not memory-access, bit-time or normalized floating-point FFT benchmarks. The shared primitive root table is assumed preinitialized on both candidate and reference paths.
