# Exact multiple-port feedback and coupling edits

This package extends the earlier coordinate rank-one feedback compiler to a closing edge with **d observation/injection ports**, including shared Krylov observations. It also implements a useful stronger reuse rule: **a rank-one change to the d×d port coupling updates every output with one rank-one circuit and no new T call**. Every source, target, and unused workspace register may initially be arbitrary.

This is an exact graph reuse result. It does not reduce the cost of a first arbitrary transform or establish an FFT bound below N log N. The small inverse identities are ordinary finite-dimensional linear algebra; the contribution here is their explicit use with this q-Weyl graph, shared coefficient preparation, reversible dirty-state circuits, and exact cost accounting. No numerical approximation is used.

## Operators and graph

Work over a field with an invertible N and an element q of exact order N. The executable audit uses power-of-two N and the prime fields 65537 and 998244353. Let

\[
t_0=1,\qquad t_j=\prod_{a=1}^{j}(1-q^a)^{-1},\qquad
T_{ij}=\begin{cases}t_{i-j}&i\ge j,\\0&i<j.\end{cases}
\]

Use the previous exact q-Weyl operators K=I+B and J=I+C, satisfying TK=JT. The superdiagonal weights are w_i=q−q^(−i) for 0≤i<N−1. K has diagonal 1 and those superdiagonal weights. J has diagonal 1+q^(−i), those superdiagonal weights, and the crucial bottom-left entry −q/N. The implementation retains this finite boundary entry. It does not substitute the uncorrected cyclic operator.

There are R vertices with forcing

\[
b_r=\sum_{(r,s)\text{ an injection}}T x_s.
\]

Repeated source banks and repeated injections are allowed. With U an N×d matrix, Λ a d×d matrix, and V an N×d matrix, the target increments are the unique solution of

\[
z_0=b_0+U\Lambda V^Tz_{R-1},\qquad
z_r=b_r+Jz_{r-1}\quad(1\le r<R).
\]

Here transpose is algebraic transpose, not conjugate transpose. The implementation supports the structured observation columns

\[
V_\ell=(J^T)^{s_\ell}e_{j_\ell},\quad s_\ell\ge0.
\]

Coordinate ports are the special case s_ℓ=0. U may be arbitrary and need not have independent columns. The name d counts ports; the actual closing edge can have rank less than d.

## Exact d×d closure

Set h=R−1. Form the unclosed chain w_0=b_0, w_r=b_r+Jw_(r−1), and define

\[
A^T=V^TJ^h,\quad G=A^TU,\quad
S=I_d-G\Lambda,\quad g=V^Tw_h.
\]

If c=V^T z_h, then c=g+GΛc. Thus S must be invertible for a unique solution for every forcing, and

\[
\boxed{z_r=w_r+J^rU\Lambda S^{-1}g.}
\]

This also proves uniqueness. If S is singular, a nonzero c in its kernel produces the nonzero homogeneous graph solution z_r=J^rUΛc: if UΛc were zero, c=GΛc would also be zero. Singular closures are therefore rejected, rather than regularized or assigned an arbitrary solution.

### Preparing source functionals without another transform

Each component of g is a sum of source functionals:

\[
g_\ell=\sum_{(r,s)}\ell_{\ell,r}^Tx_s,\qquad
\ell_{\ell,r}=(K^T)^{h-r+s_\ell}T^Te_{j_\ell}.
\]

This follows from T^T(J^T)^a=(K^T)^aT^T. The seed T^T e_j is the already known row (t_j,t_(j−1),…,t_0,0,…,0), so producing it invokes no T action. Computing an arbitrary dense row of an unrelated transform is not assumed free.

Ports with a common coordinate j share a single J^T walk seeded by e_j and a single K^T walk seeded by T^T e_j. Both walks stop at h+max(s_ℓ) in that group. Their stored entries give all observation vectors, A rows, and source-functional rows. This is an exact reuse of coefficients, with generated rows and storage charged below.

## Arbitrary dirty-state circuit

The source banks precede one unused arbitrary bank, followed by R arbitrary target banks. The unused bank is untouched. The emitted circuit does the following:

1. In descending r, subtract J y_(r−1) from y_r.
2. Emit one ADD_T for every specified injection (r,s), adding T x_s into y_r.
3. Add UΛS^(−1)g into y_0 using d reversible rank-one additions.
4. In ascending r, add J y_(r−1) into y_r.

Descending subtraction applies the invertible lower-bidiagonal difference operator D to the old targets; ascending addition applies D^(−1). Consequently the old targets are restored exactly, with the desired solution added. No target is presumed zero, and the feedback equation is imposed on the added solution, not on the preexisting target contents.

A rank-one addition y+=u f^T x temporarily stores the scalar functional in one source register whose coefficient is nonzero, adds its multiples into targets, and reverses the preparation. It inverts the known nonzero coefficient, never the source value. A zero-valued source pivot is legal. The source and target register sets are disjoint, and source banks are restored after every rank-one addition. Compiler validation rejects negative source IDs and invalid vertices before register generation.

## Rank-one coupling edit: one correction for all R outputs

Suppose the original graph is nonsingular and Λ changes to Λ+a b^T. The source values and their injection pattern remain the same. Write

\[
z=S^{-1}Ga,\qquad v^T=b^TS^{-1},\qquad
\theta=1-b^Tz.
\]

Then the new small matrix is S−Ga b^T. It is invertible exactly when θ≠0. Direct multiplication verifies

\[
S_{\rm new}^{-1}=S^{-1}+zv^T/\theta.
\]

Writing F(Λ)=Λ(I−GΛ)^(−1), expansion gives

\[
\boxed{F(\Lambda+ab^T)-F(\Lambda)
=\frac{(a+\Lambda z)v^T}{\theta}.}
\]

The a v^T term and the a(b^Tz)v^T/θ term combine because θ+b^Tz=1. Therefore the difference of all graph solutions is the single rank-one map

\[
\boxed{\Delta z_r=J^r u_*\,v^Tg,\qquad
u_*=U(a+\Lambda z)/\theta.}
\]

`coupling_edit_word` prepares the full RN-entry output direction by a J walk, combines the prepared source rows into one functional, and emits one rank-one circuit across all targets. It emits **zero ADD_T calls**. Its returned state also updates Λ, S^(−1), and U F by small/rank-one operations, permitting successive edits without a new d×d inversion. A singular edit is rejected before emitting any gates.

The edit circuit itself adds this linear correction to arbitrary targets. Interpreting the final contents as the new graph solution requires that those targets already contain the old solution (plus arbitrary unchanged background) for the same sources. This is reuse of an existing result, not a fresh-computation cost claim.

## Costs, including coefficient preparation

Let M be the number of injection entries and Q the number of distinct source banks actually referenced. Let

\[
L=\sum_{\text{coordinate groups }j}\left(R-1+\max_{\ell:j_\ell=j}s_\ell\right).
\]

Without sharing the corresponding walk length is Σ_ℓ(R−1+s_ℓ). The code stores 2N Σ_j(1+R−1+max s_ℓ) generated orbit coefficients; row pointers can refer to these existing lists. It additionally stores O(Nd+d²+dR) coefficients/references. This includes the observation vectors and source rows; it is not a constant-size description passed off as a free contraction.

For a nonsingular initial closure, the exact counted field operations in `prepare_ports` are:

| Operation | Count |
|---|---:|
| multiplication | L(3N−1)+2Nd²+4d³ |
| addition | L(2N−1)+(N−1)d²+2d²(d−1)+Nd(d−1) |
| subtraction | d²+2d²(d−1) |
| constant inverse | d |

The inverse uses pivoted Gauss–Jordan and charges even zero-factor elimination. Row-pointer swaps and pivot searches add O(d²) control work and are reported separately. The general order is O(NL+Nd²+d³), including building G and UΛS^(−1).

Preparing the injection functionals costs dMN additions. Let m_ℓ be the number of nonzero coefficients in functional ℓ and k_ℓ the number of nonzero entries in column ℓ of UΛS^(−1). A nonzero rank-one addition costs exactly 6m_ℓ+3k_ℓ−4 scalar instructions; a zero factor costs zero. A scalar instruction is one nonzero field scale or one register addition/subtraction. Shears expand into scale/add/unscale, three instructions, without clean scratch.

The complete initial circuit cost is

\[
\boxed{\frac{3MN(N+1)}2+2(R-1)(6N-3)
+\sum_{\ell\text{ active}}(6m_\ell+3k_\ell-4).}
\]

The first term is every first transform, using the implemented quadratic triangular ADD_T. The second charges every graph edge in both sweeps and materializes all RN target outputs. There is no free dense transform in this formula.

For one coupling edit, the exact coefficient preparation counts, **including updating the next cached small inverse and effective U factor**, are:

| Operation | Count |
|---|---:|
| multiplication | 7d²+2d+2Nd+2N(R−1)+dQN |
| addition | 6d²−2d−1+N(2d+R−2)+dN(M+Q) |
| subtraction | 1 |
| constant inverse | 1 |

The formula counts zero-factor arithmetic too, so a zero edit emits no gates but still performs the reported preparation. The edit circuit costs 6m+3k−4 when nonzero, where m≤QN and k≤RN; it invokes no T. Its order is O(d²+dMN+RN) preparation and O(QN+RN) online scalar work, with all outputs present.

Two further setup layers are charged separately from these tables:

* The copied q-operator plan is prepared once. As written, it uses 3N−2 field multiplications, N additions, 2N−2 subtractions, one negation, and 2N−1 constant inversions, plus root exponentiation/order checking and O(N) list/control work. The primes and generator are supplied parameters; primality is not established by this package. Root preparation is not amortized away for a fresh graph.
* Gate construction/expansion uses O(emitted circuit length) time and space, including copying, modular normalization and sign changes. Each active rank-one circuit requires one source-pivot coefficient inverse to construct its uncompute. Expanding the word uses one cached inverse per distinct nonzero shear coefficient; both counts are included in compiler metadata. If compilation is performed once and reused, its cost is a separate prepared-graph cost, not online arithmetic. Ordinary inverse-gate audit construction is test-only.

Field inversions, root generation, and bit complexity are distinct from scalar gate counts. No claim of N log N bit complexity follows from them.

Its setup grows with d and is explicitly charged.

## Verification and remaining scope

Run `python run_audit.py` from this directory. Standard library only. `prior_affine_reuse.py` is an unchanged local copy; `prior_feedback.py` has one local change: source-to-pivot shears retain dictionary insertion order instead of sorting register IDs. These shears commute, so this removes unnecessary sorting while preserving the exact map and counts. The original packages are untouched.

The audit checks 216 configurations in two prime fields, N=2,4,8, R=1,3, d=1,2,3, coordinate and shared Krylov ports, independent/repeated sources, and 4,704 full-register basis vectors for both the initial circuit and one coupling edit. It also checks 648 arbitrary dense register states and 648 second successive edits, expanded scalar instruction counts, inverse circuit restoration, invalid injection rejection, singular initial/edited closures, and a valid small inverse needing a row swap.

The reference oracle directly builds and inverts the full RN×RN feedback system, then verifies every block residual. It does not assume the d×d closure formula. That dense inversion is test-only and is absent from the compiler and its complexity claim. The general proofs above apply beyond the finite audited sizes; the tests provide separate executable certificates.

This primitive is useful when an exact correction graph already has a small number of observation/injection ports or when its port coupling changes between computations. No such small-port representation of the full fresh Fourier correction has been established here. Letting d grow toward N makes preparation expensive; returning RN outputs itself costs Ω(RN) writes. The implemented first T remains quadratic. An independent full FFT improvement still requires an exact first-input representation/evaluator that reduces that cost, rather than hiding it in row preparation, a small inverse, or preexisting results.
