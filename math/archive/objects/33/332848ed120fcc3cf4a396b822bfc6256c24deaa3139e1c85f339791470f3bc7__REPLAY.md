# Independent bridge replay

Use Python 3.9 or later with the standard library only.

    python independent_checks.py --output regenerated.json
    cmp INDEPENDENT_RESULTS.json regenerated.json

The checker is self-contained and can be copied alone into any empty directory. It does not read or import source_text, the archive, or any uploaded Python. Do not execute the uploaded bridge.py or verify.py. The stored report distinguishes algebraic identity checks, Fourier false-accept controls and the unresolved synthesis problem.
