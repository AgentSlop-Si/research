# Exact Boolean-overlap FFT falsification gate

Continuation after the interrupted FFT research chain (October 9, 2026).

**This is not a new fast FFT.** It determines how nonlinear arithmetic gates can be projected to linear circuits when the target is only required to agree with FFT on binary vectors.

Run from this folder:

```bash
python -m unittest discover -s tests -v
python boolean_overlap.py --output audit_results.json
```

See `RESEARCH.md` for theorem, exact counts, scope, failed candidates and next gate. The generated `audit_results.json` contains seven transform sizes by four circuit variants. Polynomial arithmetic is exact over F_998244353. Input vectors are always fresh; no state is cached between transform requests or parallelized. Precomputation is explicitly recorded separately, so the reported linear-gate counts must **not** be interpreted as fully charged uniform runtimes.
