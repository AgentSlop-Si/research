Run inside the extracted `fft_hero1_phase25/` directory:

```sh
python3 -m unittest -v test_phase25 test_phase25_green
python3 audit_phase25.py
python3 benchmark_phase25.py
(cd phase24_source && python3 -m unittest discover -p 'test_*.py' -q)
sha256sum -c MANIFEST.sha256
```

Use Python ≥3.11 (no third-party packages). The root field `F_2013265921` with generator 31 is used for the main tests; `F_97` with generator 5 supplies an independent small field. All direct-DFT comparisons use an independent formula, not Good–Thomas. The `PRIOR_PHASE24_COMPLETE.zip` must remain unchanged (its SHA-256 is in the manifest).

**Benchmark caveat:** field additions and multiplications are counted; modular integer/bit operations, cold root/generator search, data layout copying, and Python allocation are not collapsed into that arithmetic count. This code is a correctness and structural-accounting experiment, not a claim of execution-time superiority.
