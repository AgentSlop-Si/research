# Phase 27: non-affine Green cycles, uniform cut mixing, and projective Fourier recovery

**Date:** October 10, 2026  
**Status:** Restricted-model mathematical proofs, exact integer/finite-field certificates, executable Python. **No `o(N log N)` FFT and no integer-multiplication improvement. Not independently peer reviewed.**

## 0. Relation to prior phases

- Phase 25 found dense, noncommuting Green operators with hidden low-rank cuts.
- Phase 26 proved a common-cut obstruction for products of Green sums made from boundedly many affine-run cyclic orderings. Truly random Hamiltonian orderings are outside that hypothesis.
- Phase 20 developed exact Weyl and projective cross-ratio necessary tests. Phase 27 strengthens this into a **four-core-probe Fourier gauge recovery algorithm, assuming forward and transpose oracles**.
- Phase 11 studied expanding path Green stages. The expander-to-cut construction below is a new project-specific **cyclic weighted resolvent** implementation, not a claim that graph expanders or Green inverses are newly discovered.

All statements distinguish **matrix rank**, **graph expansion**, **actual circuit application cost**, and **exact Fourier phase coherence**.

## 1. Exact rank distance from any affine Hamiltonian reference

An `N`-cycle successor permutation `W` acts as `W e_j=e_{W(j)}`. For `alpha != 0` with the two denominators nonsingular, let

```
G_W=(I-alpha*W)^(-1),     G_A=(I-alpha*A)^(-1).
```

**Theorem 1 (resolvent-rank preservation).** For *any* permutations `W,A`,

```
rank(G_W-G_A)=rank(W-A)=N-cycles(A^(-1)*W).
```

The first identity is the standard resolvent identity

```
G_W-G_A=alpha*G_W*(W-A)*G_A.
```

The second follows because multiplying `W-A` by `A^(-1)` gives the permutation matrix `A^(-1)W-I`. Its nullspace consists exactly of vectors constant on each cycle, over **any field**. Fourier conjugation preserves both ranks. No normalization/conditioning assumption is necessary.

A crucial negative control: if `tau` swaps labels `0` and `N/4+1`, and `Z` is the ordinary successor, then `W=tau*Z*tau^(-1)` is itself an `N`-cycle, is generally non-affine, yet

```
rank(W-Z)=2
```

for powers of two `N>=8`. This follows from `rank(tau-I)=1` and the identity

```
tau*Z*tau^(-1)-Z = (tau-I)*Z*tau^(-1)+Z*(tau^(-1)-I).
```

Thus the Green resolvent remains rank-two away from the affine Green reference. **Non-affine labels alone cannot establish an escape from Phase 26-style cheap corrections.**

## 2. Uniform random N-cycles are far from every affine reference

For `N=2^k`, the group of affine permutations `A_{u,b}(j)=u*j+b mod N`, where `u` is odd, has size

```
|AGL(1,Z_N)|=N*phi(N)=N^2/2.
```

Let `W` be uniformly random among all Hamiltonian `N`-cycles. Define `C(P)` to be the number of cycles of a permutation. A classical identity for a uniform random permutation `Pi` of `N` labels is

```
E[2^C(Pi)]=N+1.
```

For a fixed affine `A`, the product `A^(-1)Pi` is again uniform; Markov's inequality yields `P(C>=t)<=(N+1)/2^t`. Conditioning the random permutation to have one cycle costs a factor of at most `N`, since `P(Pi is an N-cycle)=1/N`.

Apply the union bound to all `N^2/2` affine permutations:

```
P( exists A with C(A^(-1)*W)>=t )
 <= (N^2/2)*N*(N+1)*2^(-t).
```

Take `t=6 log_2 N` (an integer for powers of two). The right side is `(N+1)/(2N^3)<=N^-2`. Combine with Theorem 1.

**Theorem 2 (all-affine rank gap, simultaneous).** For a uniform random Hamiltonian cycle, with probability at least `1-N^-2`,

```
for EVERY affine A:
    rank(G_W-G_A) >= N-6 log_2 N.
```

This is not a DFT complexity lower bound. It says random Hamiltonian Green operators are **not affine Green operators plus O(1)-rank Woodbury corrections**. Proof ingredients (cycle moments and Markov) are classical; the project-specific deduction is the simultaneous resolvent comparison.

**Exact all-reference audits** (all `N^2/2` affine maps, not sampled maps):

| N | maps checked | exact minimum rank |
|--:|--:|--:|
| 32 | 512 | 24 |
| 64 | 2,048 | 52 |
| 128 | 8,192 | 114 |
| 256 | 32,768 | 240 |

Deterministic Hamiltonian sampler seed `2700+N`. Theoretical lower bounds at these N are `2,28,86,208`; observed examples are stronger. The script `phase27_affine_gap.py` computes ranks directly from cycle decomposition and independently checks small cases with modular Gaussian elimination on the **full Green matrices**.

## 3. Fourier-space density can be almost maximal despite a rank-two correction

Let `F` be normalized DFT, `omega=e^(-2 pi i/N)`, `Z e_j=e_(j+1)`, and `D=FZF^(-1)=diag(omega^j)`. Let `tau` swap labels `0` and `b=N/4+1`, where `N=2^k>=16`. Since `b` is odd and neither `1` nor `N-1`, the conjugated successor `W=tau Z tau^(-1)` satisfies `rank(W-Z)=2`.

Put `v=e_0-e_b`, `u=Fv`. The transposition is `tau=I-vv^T`, so

```
H=F*tau*F^(-1)=I-u*u^*,      u_j=(1-omega^(bj))/sqrt(N).
```

`H^2=I`, and

```
u^* D u = v^* Z v = 0,
F W F^(-1)=H D H = D-u u^* D-D u u^*.
```

For `j!=l`,

```
(FWF^(-1))[j,l] = -u_j * conjugate(u_l) * (omega^j+omega^l).
```

Because `gcd(b,N)=1`, `u_j=0` exactly when `j=0`. For nonzero `j,l`, `omega^j+omega^l=0` exactly when `l=j+N/2 mod N`. The diagonal entries are

```
(FWF^(-1))[j,j]=omega^j*(1-2|u_j|^2),
```

which are nonzero for `N>=16`, because `2|u_j|^2<=8/N<1`.

Counting zero entries: `N-1` in row 0 outside the diagonal, `N-1` in column 0 outside the diagonal, and `N-2` off-diagonal antipodal positions, totaling `3N-4`.

**Theorem 3 (exact density trap).** For these non-affine Hamiltonian cycles,

```
rank(FWF^(-1)-D)=2,
nonzero_entries(FWF^(-1)) = N^2-3N+4.
```

Thus the density tends to **100%**, while the matrix is a rank-two perturbation of a diagonal Fourier operator. This strengthens Phase 25's warning: **dense Fourier-space conjugates are not a valid complexity certificate.**

### Fully exact cyclotomic zero evaluator

For any permutation `W` and powers-of-two `N`, an entry of `F W F^(-1)` is

```
(1/N) * sum_j omega^(a*W(j)-b*j).
```

Let `c_r` count exponents equal to `r mod N`. Since the cyclotomic polynomial is `Phi_N(z)=z^(N/2)+1`,

```
(FWF^(-1))[a,b]=0
iff c_r=c_(r+N/2) for every r=0,...,N/2-1.
```

This is an **integer-only exact zero test**, no floating point or polynomial fitting. It reproduces Theorem 3 for `N=16,32,64,128` and also audits sampled random Hamiltonian cycles. The fact that the matrix is dense does not show that applying it to arbitrary spectral-domain inputs is expensive; the expression `FWF^-1` already contains F and F^-1.

## 4. Finite exact expansion certificates for two cycles

Let `W` be the above uniformly sampled Hamiltonian cycle and `Z` the ordinary Hamiltonian shift. Form the undirected multigraph that contains one edge for each directed successor edge of `W` and `Z`. Its integer Laplacian is `L`. The exact integer Sylvester/Bareiss certificate tests positive definiteness of

```
K = 2N*L + 2J - N*I,
```

where `J` is the all-ones matrix. On the constant vector `K` has eigenvalue `N>0`; on its orthogonal complement the eigenvalues are `N(2*lambda_i(L)-1)`. Thus all positive exact leading principal minors **prove** `lambda_2(L)>1/2`.

Then every balanced set `I` has undirected edge boundary

```
edge_cut(I,I^c) = 1_I^T L 1_I > (1/2)*N/4 = N/8.
```

The exact algorithm passes at `N=32,64,128,256` with deterministic seeds `2700+N`. The 256x256 certificate involves 256 strictly positive fraction-free integer pivots; its pivot list is identified by SHA-256 `8f4e9dfb215562a3c8bdec3b8d458b43cd323fbb79fd8ff0a29c4ab1b1b3994f`. The script rechecks *every balanced cut simultaneously* through the spectral argument, rather than enumerating exponentially many cuts.

This is a **finite collection of certified expanders**, not a proof of a uniform expander family for every N or every sampled seed.

## 5. An O(N)-apply, well-conditioned high-cut-rank Green mixer

Fix `alpha=1/4`, `beta=1/5`, and consider

```
S(lambda) = (I-alpha Z)^(-1) + lambda*(I-beta W)^(-1).
```

Each term is a one-cycle Green solve with `O(N)` field operations. Set `d_Z(I,J)` and `d_W(I,J)` equal to the numbers of directed edges from `J` into `I` for a balanced **complementary** cut `I,J`. Because the restriction of a Hamiltonian cycle to a proper vertex subset is acyclic, the exact block inverse identity gives

```
rank(G_Z[I,J])=d_Z(I,J),
rank(G_W[I,J])=d_W(I,J).
```

Each cycle contributes twice its number of `J->I` edges to the undirected crossing-edge count. Hence, with graph Laplacian gap `lambda_2(L)>c`,

```
d_Z+d_W > c*N/8,
max(d_Z,d_W)>c*N/16.
```

For a fixed cut, choose a square minor of size `r=max(d_Z,d_W)` with nonzero determinant in the larger-rank summand. The same minor of `G_Z+lambda G_W` is a polynomial in `lambda` of degree at most `r`, with a nonzero constant coefficient (if `G_Z` supplies it) or a nonzero leading coefficient (if `G_W` supplies it). It cannot vanish identically. There are finitely many balanced cuts and finitely many roots of the corresponding determinant polynomials.

**Theorem 4 (generic all-balanced-cut rank).** For all but finitely many complex `lambda`, simultaneously for **every complementary balanced** `I,J`,

```
rank(S(lambda)[I,J]) > c*N/16.
```

In the 32/64/128/256 exact certified instances, `c=1/2`, giving rank `>N/32` in *every complementary balanced cut*. These are not lower bounds for every independently selected balanced row and column subset.

Because all Green entries are rational for rational `alpha,beta`, each determinant has rational coefficients. In particular the explicit **transcendental constant `lambda=e`** cannot be one of its finitely many algebraic roots. That makes `S(e)` an exact analytical example with this property, assuming a unit-cost exact-complex-constant arithmetic model. Exact storage/bit implementation of `e` is **not** free or addressed by this statement.

For every real `lambda>0`, since `||G_Z-I||_2<=1/3` and `||G_W-I||_2<=1/4`,

```
||S(lambda)-(1+lambda)I||_2 <= 1/3+lambda/4,

kappa_2(S(lambda))
 <= (4/3+5lambda/4)/(2/3+3lambda/4) < 2.
```

Thus the generic balanced-rank stage can also be uniformly spectrally well conditioned, with `O(N)` forward arithmetic.

### Concrete vs generic certificates

- For `lambda=3/2` over the exact finite field, **all** `C(16,8)=12,870` balanced complementary cut blocks have minimum rank 4 for the sampled N=16 stage.
- At `N=32,64,128`, 80 **sampled** balanced cuts of the same rational stage had minima 11,23,48. These numbers do *not* certify all cuts at those sizes.
- The exact all-cut guarantee at `N=32..256` applies to generic scalar values, particularly the complex scalar `e`, using the spectral certificate and determinant-polynomial argument, not the sampling results.

## 6. A sharp phase failure for the positive Green mixer

**Theorem 5 (projective phase obstruction).** Fix `Z,W,alpha=1/4,beta=1/5` above.

1. For **every positive real** `lambda`, the matrix `S(lambda)` has strictly positive real entries and is invertible. Its nonzero 2x2 cross ratios are positive real. If it were row/column monomially equivalent to the DFT, every cross ratio would be an Nth root of unity. The only positive real root is 1; having all cross ratios equal 1 would force rank one, contradicting invertibility. Thus **no positive lambda produces a Fourier matrix even under arbitrary external row/column permutations and complex nonzero diagonal gauges.**
2. Allow complex `lambda`. The anchored cross ratio `S_00 S_11/(S_01 S_10)` must be one of N roots of unity. For each root `zeta`, the equation

   ```
   S_00(lambda)*S_11(lambda)-zeta*S_01(lambda)*S_10(lambda)=0
   ```

   is a polynomial of degree at most 2 in `lambda`. It is **not identically zero**, since at `lambda=0` the cross ratio of `G_Z` is `alpha^(-N)=4^N`, never an Nth root. Therefore **at most `2N` complex lambda values** can even pass this *single* necessary projective Fourier test. This does not assert that any of those possible values pass all remaining conditions.

This theorem explains why a large rank/expansion score alone does not produce Fourier phases. An internal network with genuinely complex adjustable gauges and multiple stages remains outside these specific exclusions.

## 7. Four-probe reconstruction of hidden Fourier gauges

Let a linear black-box `M` admit both `Mx` and `M^T x` oracles. The desired monomial Fourier form over a field containing a primitive Nth root `omega` is

```
M[i,j] = left[i] * right[j] * omega^(p[i]*q[j]),
```

where `p,q` are unknown permutations and all scalars are nonzero. Fix row 0 and column 0. Define

```
R[i,j] = M[i,j]*M[0,0] / ( M[i,0]*M[0,j] ).
```

For a valid Fourier form,

```
R[i,j] = omega^((p[i]-p[0])*(q[j]-q[0])).
```

Pick a second column `j*` such that `d=q[j*]-q[0]` is invertible modulo N (odd for power-of-two N). Such a column always exists, and sampling a random nonzero second column finds one with probability `N/[2(N-1)]`. From the two **forward** columns, recover the permutation

```
a[i] = log_omega R[i,j*] = (p[i]-p[0])*d mod N.
```

Choose the unique row `i*` with `a[i*]=1`. From the two **transpose** row queries (`row 0` and `row i*`), recover

```
b[j] = log_omega R[i*,j] = (q[j]-q[0])*d^(-1) mod N.
```

The only possible gauge-normalized Fourier candidate consistent with the probes is

```
M_expected[i,j] = M[i,0]*M[0,j]/M[0,0] * omega^(a[i]*b[j]).
```

This is an **exact reconstruction formula** with 2 forward and 2 transpose basis queries **once a primitive second column has been found**. A random search requires roughly 2 second-column attempts in expectation for a positive Fourier instance; it is not a deterministic four-query worst-case search. Root lookup, batch field inversions, and reconstruction of permutations cost `O(N)` finite-field operations beyond the oracle calls. Evaluating the reconstructed expected transform on a vector uses an **ordinary O(N log N) FFT**; it is a verification oracle, not a fast new implementation.

**Soundness of sampled verification.** Once the expected linear operator is fixed from the probes, if the true `M` differs from it, a uniformly random input vector over `F_p^N` will lie in the kernel of their nonzero difference with probability at most `1/p`. Independent trials give `p^(-trials)`. Failure on any sampled vector is a definitive exact modular rejection; passing is *not* a complex identity proof. Choosing a deterministic RNG seed supports reproducibility only, not probabilistic security.

The script `phase27_fourier_recovery.py` passed all tested hidden Fourier row/column permutations and arbitrary nonzero scalings through N=256. Its exact finite-field Green-product examples at N=16,64,256,1024 were each rejected after **only two forward circuit calls**, before transpose recovery. It also rejects a deliberately corrupted matrix that matches all four structural probes but fails a random-vector test.

## 8. Cost and current frontier

| Component | On-current-input arithmetic | What is established |
|---|---:|---|
| Apply one weighted cyclic Green | O(N) | Exact recurrence |
| Apply `G_Z + lambda G_W` | O(N) | Exact forward algorithm |
| Rank-vs-affine audit | O(N^3) worst-case offline | All-affine structural certification, **not** an executor |
| Positive-spectrum certificate | O(N^3) or worse integer work offline | Finite-instance, all balanced cuts |
| Four-probe gauge recovery | O(1) oracle calls in expectation, O(N) field work | Candidate recognition, not DFT acceleration |
| Reconstructed candidate validation | O(N log N) via reference FFT | Only offline comparison |
| Arbitrary-input DFT from these stages | **Unknown** | No `o(N log N)` construction |

The new stage is robust in all **complementary balanced** cuts, but hidden low-rank *independent row/column rectangles*, arbitrary multistage intermediate permutations, phase tuning across networks, word cost, and transcendental precision remain open.

## 9. Prior-art caution

- Rank/cycle identities for permutations and `E[2^C]=N+1` are classical. The probability identity is recorded, for example, by Terence Tao, *The number of cycles in a random permutation* (2011): https://terrytao.wordpress.com/2011/11/23/the-number-of-cycles-in-a-random-permutation/ .
- The cross-ratio is an established Haagerup-type invariant; see Östergård and Valtonen, *Equivalence of complex Hadamard matrices*, Journal of Algebraic Combinatorics (2026): https://link.springer.com/article/10.1007/s10801-026-01568-x . The four-probe reconstruction is our project-specific specialization with forward/transpose access, not a claim of priority over all equivalence algorithms.
- Weyl operators, the DFT/shift duality, Green inverses, matrix Sylvester tests, and graph spectral expansion are established mathematics. Our results combine them for the user's non-affine Green research program.

No paper has been submitted or independently verified. The exact finite-field and integer tests supplement the proofs but do not settle arbitrary-input FFT complexity.
