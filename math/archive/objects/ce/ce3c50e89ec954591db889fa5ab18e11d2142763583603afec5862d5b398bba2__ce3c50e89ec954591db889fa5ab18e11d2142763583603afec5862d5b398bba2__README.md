# Exact opposite-shift conjugation, including the finite boundary

This checkpoint reaches the actual noncommuting middle of the q-factorial
Fourier factorization. It supplies a legal sparse conjugation rule and an O(N)
action for the resulting operator. It does **not** supply a faster arbitrary
Fourier transform: applying the full degree-N-1 polynomial to that sparse
operator remains quadratic in the honest reference evaluator.

No global novelty is claimed. The starting q-factorial Fourier factorization is
known [1], and q-exponential reordering has extensive prior work [2,3]. The finite
root-of-unity boundary is derived and audited explicitly here rather than removed
by importing an infinite formal-series identity.

## Operators and the actual Fourier middle

Let N=2^L >=2, q a primitive Nth root, and work over the exact complex cyclotomic
field or a field of odd characteristic admitting q. Write

    f_j = product_(r=1..j)(1-q^r),  t_j=1/f_j,  f_0=1
    H_q(X) = sum_(j=0..N-1) t_j X^j
    d_j = (-1)^j q^(j(j-1)/2)/f_j.

All f_j are nonzero for 0<=j<N, and f_(N-1)=N. Let A be the lower nilpotent shift,
Q=diag(q^j), R coordinate reversal, D=diag(d_j), and P=diag(f_j). The known exact
Fourier identity is

    F_N = P H_q(A) D R H_q(A) R P.

Set M=DR. Direct conjugation gives B=M A M^-1, an upper weighted shift with

    B[i,i+1] = d_i/d_(i+1) = q-q^(-i),    0<=i<N-1.

Consequently the unresolved middle is exactly H_q(A)H_q(B), up to the displayed
cheap outer weighted reversals and diagonals. It is not a pair of commuting
Toeplitz kernels: the exact finite q-Weyl relation is

    BA = qI-Q^-1
    AB = qI-qQ^-1
    BA-q^-1 AB = (q-1)I.                                    (1)

These equations include both endpoints. In particular q-q^(-(N-1))=0 ensures
the absent last edge has the correct coefficient.

## New-to-this-research exact compiler rule

Let J0=A^(N-1)=e_(N-1)e_0^transpose. Define

    C = B+Q^-1-(q/N)J0.

Then

    H_q(A) B H_q(A)^-1 = C.                                 (2)

For every polynomial p this yields the legal compositional rewrite

    H_q(A) p(B) H_q(A)^-1 = p(C),

and in particular

    H_q(A) H_q(B) = H_q(C) H_q(A).                           (3)

Keeping the order in (3) gives the exact full Fourier rewrite

    F_N = P H_q(C) H_q(A) D P = P H_q(C) H_q(A) Gamma,
    Gamma[j,j] = (-1)^j q^(j(j-1)/2).

Indeed H_q(A) M H_q(A)=H_q(A) H_q(B) M=H_q(C) H_q(A) M,
and MR=D. The audit checks this full matrix against every Fourier matrix entry;
commuting M past H_q(A) at this step would be incorrect.

Equation (2) replaces two dense transform applications surrounding one weighted
shift by a cyclic bidiagonal action. More generally a fixed-degree p produces an
O(N) macro for every input, including the constant preparation below. This is a
noncommuting graph rewrite; it does not assume a match to the earlier orbit rule.

Here is a finite proof. From (1), induction gives

    A^j B = q^j B A^j + q(1-q^j)A^(j-1),    j>=1.

Using (1-q^j)t_j=t_(j-1), the finite sum therefore satisfies

    H_q(A)B = B H_q(qA)+q H_q(A)-(q/N)A^(N-1).

Since A^N=0, H_q(qA)=(I-A)H_q(A) exactly, and
A^(N-1)H_q(A)^-1=A^(N-1). Multiplying on the right by H_q(A)^-1 and using
BA=qI-Q^-1 proves (2). No unbounded series or dropped last coefficient occurs.
An equivalent useful identity is

    B H_q(A)=H_q(q^-1 A)(B-I)+(q/N)A^(N-1).

## The boundary cannot be omitted

Let U=Q^-1 and W=B-(q/N)J0. The cyclic last edge completes the relations

    UW=qWU,    U^N=I,    W^N=-I,    C=U+W,    C^N=0.

For example, the product of B's N-1 upper weights is N/q; multiplying it by the
last weight -q/N gives -1, proving W^N=-I. Nilpotence also follows immediately
from C=H_q(A)B H_q(A)^-1 and B^N=0.

In contrast, omitting the corner gives C0=B+Q^-1 with C0^N=I. The audit verifies
both statements exactly. For an all-N proof, C0 is upper triangular with every
Nth root of unity appearing once on its diagonal. Its characteristic polynomial
is therefore z^N-1, so Cayley-Hamilton gives C0^N=I. Removing a single rank-one term changes a nilpotent
operator into one whose Nth power is the identity.

There is another finite-boundary trap. The ordinary q-binomial expansion gives

    H_q(U+W) = sum_(r+s<N) t_r t_s W^s U^r.

One cannot replace this triangle of terms by the full product H_q(W)H_q(U):
U and W themselves are not nilpotent, so the terms with r+s>=N do not disappear.
At N=2, q=-1,

    U = diag(1,-1),   W = [[0,-2],[1/2,0]].

The false product minus H_q(U+W) is WU/4; on e_0 its error is (0,1/8).
The exact rational negative control records this result. Generic or cyclic
quantum-dilogarithm formulas require their own normalizations and hypotheses;
they do not authorize this omitted-tail substitution.

## Charged action, preparation, and remaining cost

The sparse action is fully explicit:

    (Cx)_i = q^(-i)x_i+(q-q^(-i))x_(i+1),    i<N-1
    (Cx)_(N-1) = q x_(N-1)-(q/N)x_0.

The implementation conservatively charges 2N scalar multiplications and N
additions, including multiplications by 1. It reads 2N input entries and 2N
prepared coefficients, and writes all N outputs. No dense C matrix is built by
the evaluator; dense matrices appear only in the independent verifier.

Given q, sparse-coefficient preparation takes N+log2(N) multiplications,
N-1 subtractions, one negation, and one inversion of the fixed constant 2.
This uses one root-power table and log2(N) multiplications by 1/2 to obtain 1/N.
All scalar storage, table construction, addressing, and vector traffic is O(N)
in an exact-field arithmetic / O(log N)-bit word-index model. This is not a bit
complexity bound or a floating-point stability statement.

For p of degree d, the provided Horner evaluator performs d sparse C matvecs,
3Nd+N multiplications, and 2Nd additions: O((d+1)N). Thus fixed d gives a genuine
O(N) implementation of the matched conjugated-operator graph. The audit includes
p(z)=2-3z+5z^2+z^3 on every tested basis vector.

For the actual remaining H_q(C), d=N-1, so Horner costs

    3N^2-2N multiplications + 2N^2-2N additions,

plus the O(N) q-factorial and sparse coefficient preparation. C has a cheap
single action, but H_q(C) is not thereby a cheap action. Equation (3) alone does
not reduce the asymptotic cost of a fresh Fourier transform.

The concrete unresolved target is an exact way to apply H_q(C), or combine it
with the neighboring H_q(A), using fewer aggregate full-vector passes while
retaining the corner and all high-degree terms. No such evaluator is asserted.

## Reproduce

Run `python run_audit.py` using the Python standard library. It writes
`results/boundary_audit.json`. The suite checks complete basis vectors over
F_65537 and F_998244353 for N=2,4,8,16,32 and exact rational cyclotomic fields for
N=2,4,8. It verifies actual-middle conjugation, the q-Weyl relation, both boundary
formulas, the reordered product, cyclic-pair powers, fixed-degree macros, the
correctly ordered full Fourier rewrite, the
omitted-corner negative control, the false-exponential negative control, and
operation counts. Algebraic proofs above have all-N scope; finite checks audit
the implementation rather than substitute for those proofs.

The unchanged `fixed_kernel.py` and `prior_exact_arithmetic.py` come from the
previous fixed-kernel factorization checkpoint. The new implementation is
`operators.py`; no prior circuit file is silently modified.
