# FFT sparse-defect Green and surviving-scan research checkpoint

**October 10, 2026 — exact proofs and executable tests.**

Main result 1: if `F_N` or its inverse factors through `t` stages with inverse matrices `G_j^-1=B_j+E_j`, where each `B_j` is row-`s_j`-sparse and `rank(E_j)<=r_j`, then

```
sum_j r_j >= floor(N/(1+product_j s_j)).
```

All internal and external nonsingular diagonal/permutation reorderings are allowed. With constant `s>=2` and `r`, this forces `t>=log_s(N)-O(log log N)`. This is a scoped, exact Fourier-specific barrier, **not** an unrestricted FFT lower bound.

Main result 2: the fully dense O(N)-work separated-generator scan `S_ij=1 (i>j), 3 (i=j), 2 (i<j)` and its inverse both admit O(N) exact application. Yet for any banded `T` of half-bandwidth `b`, `rank(S^-1-T)>=floor((N+b)/(2b+2))`. Thus this valid global scan lies outside the bounded-rank sparse-inverse defect model.
