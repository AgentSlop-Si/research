# Hero #1 v13 — independent mixed-radix dyadic sketches and a tight exact phase frame

**10 October 2026.** Continued independent Fourier research. These are exact-arithmetic theorems about a **randomized approximate** full-output DFT, plus an **exact but not faster** deterministic reconstruction. No `o(N log N)` algorithm for arbitrary complex inputs is claimed. The earlier centered v12/Green22/window-rank checkpoints remain valid, distinct projects.

## 1. The exact factorization, for every N

Write `N=Gm` with `G=2^v2(N)` (the largest power of two dividing N) and odd `m`. Include the degenerate odd case `G=1` and the dyadic case `m=1`.

Use *time indices* `n=m*r+s`, with `0<=r<G`, `0<=s<m`; use *frequency indices* `k=k1+G*k2`, with `0<=k1<G`, `0<=k2<m`. Let the normalized DFT be

    (F_N x)[k] = (1/sqrt N) sum_n x[n] exp(-2pi i k*n/N).

For each input column `s`, let `x_s[r]=x[m*r+s]`. Define

    u_s[k1] = (F_G x_s)[k1],
    w_s[k1] = u_s[k1] exp(-2pi i k1*s/N),
    X[k1+G*k2] = (F_m(w_0[k1],...,w_(m-1)[k1]))[k2].

**Identity.** Expanding `k*n/N` gives

    k*n/N = k1*r/G + k1*s/N + k2*r + k2*s/m.

The `k2*r` term is integral and disappears in the root of unity. The three other factors give the above factorization **exactly**. `exact_mixedradix_reference` implements this with direct FFT backends and checks against `F_N`.

## 2. Replacing the G-point DFT with a dyadic one-row sketch

Choose `M|G` a power of 2, `1<=M<=sqrt(G)`, and `K=G/M`. For each `s`, independently sample a uniform odd `a_s` modulo G and a uniform `beta_s` in `Z_G`, defining the inherited v9 `G`-point sketch `S_s=F_G P_s`. The `P_s` is block diagonal with `K` Hermitian rank-one blocks of the form `v v^*`, where each entry of the length-M vector `v` has unit modulus. Hence

    P_s^*=P_s,       P_s^2=M P_s,       rank(P_s)=K,
    E[P_s]=I_G.

The expectation follows directly from the uniform `beta_s`: for two unequal local coordinates `t!=u` the expected offdiagonal multiplier contains the nontrivial character `exp(2pi i beta_s (t-u)/G)` and vanishes, while the diagonal is one. When `M=1` the projection is already the identity.

Let `A_N` be the complete CT algorithm with `F_G` replaced by these sketches. **For each fixed state tuple**, the exact identity is

    A_N = F_N P, 

where `P` acts separately on the `m` interleaved input columns by `P_s`. In particular `P` is Hermitian and its spectrum is `M` (multiplicity `N/M`) and `0` (multiplicity `N-N/M`). Its application, followed by the normal CT transform, is exactly the algorithm in `mixedradix.py`.

### Theorem A — exact unbiasedness and pointwise covariance

For any fixed arbitrary dense input `x` independent of the sampled states, every output `k=k1+G*k2` satisfies

    E[(A_N x)[k]] = (F_N x)[k].

From the saved v9 unit-step chirp theorem (power-of-two case), the one-output covariance of the error in each `G`-point sketch is `Q_{k1}=(M/G) Pi_{k1}`, where `Pi_{k1}` is an orthogonal projector of rank `G-K` for `M>1`. With **independent states between the `m` columns**, the variance after the final unitary `F_m` is exactly

    E| (A_N x)[k]-(F_N x)[k] |^2
       = (1/m) sum_{s=0}^{m-1} x_s^* Q_{k1} x_s
       = (M/N) sum_s ||Pi_{k1} x_s||_2^2
       <= (M/N)||x||_2^2.

The exact expression does **not depend on k2**. This is a pointwise mean-square guarantee, not a uniform `l2` or operator norm guarantee. For `M=1`, the variance is zero and the sketch is an actual exact CT FFT, with the usual large short-FFT cost.

**Independence is indispensable.** If the same sketch state is reused across `m` identical columns and we inspect frequency zero, the errors synchronize. For an input direction saturating the dyadic covariance bound, the actual variance is `m` times the claimed independent-state upper bound. `test_common_seed_is_dangerous` constructs this example and checks the factor exactly by enumerating every state at `G=16`, `M=4`, `m=3`.

### Theorem B — the high-probability inherited robust guarantee

Draw independently across all columns **and** across rows. Every one-row output has variance `<=sigma^2` with `sigma=sqrt(M/N)||x||_2`. Consequently the inherited three-grid streaming majority estimator (with the same exact arithmetic grid contract) returns every coefficient within

    (5/sqrt 2) gamma sqrt(M/N) ||x||_2

except with probability at most

    2N exp(-r D(1/2 || 1/gamma^2)),

for odd `r` rows and `gamma>sqrt(2)`, with `D(1/2||p)=(1/2)log(1/(4p(1-p)))`. No Bessel truncation error is present. To make the **simultaneous** failure probability <=delta, `r=Theta(log(N/delta))` suffices; the corresponding total work has an extra factor `r`. Do not mislabel the one-row *pointwise RMS* result as a high-probability all-output `l_inf` bound.

## 3. Arithmetic accounting, no hidden R

For one row:

- `m` local sketches of length `G`: `O(N + (N/M) log(G/M))` including their local input compressions, root/gauge preparation under the inherited scalar-arithmetic model, `m` length-K FFTs, and `m` full-G scans.
- Cooley–Tukey twiddle multiplies and full output permutation/writes: `O(N)`.
- `G` short length-`m` FFTs: `O(N log(m+1))`, e.g. via Bluestein with all scalar operations counted.
- State generation: `m` independent random states, `O(m)` words (each `O(log G)` random bits) per row. Constant and length-dependent root generation/precision are accounted for separately below.

Choose dyadic `M=Theta(log G)` for all sufficiently large G, with `M<=sqrt G` and power-of-two restrictions. Then `log(G/M)/M=O(1)`, yielding

    T_one_row(N)=O(N + N log(m+1)).

For fixed `m` this is `O(N)` arithmetic. For `m=polylog N`, this is `O(N log log N)`, on the corresponding even lengths. For prime/odd `N`, `G=1`, this construction simply uses a conventional exact length-N FFT of `O(N log N)` time. **This is not an all-length worst-case sub-FFT result.** For one row the accuracy metric is fixed-input/per-coordinate mean-square, not exact equality nor vanishing global relative `l2` error.

For `r` independent robust rows, `O(r N(1+log(m+1)))` arithmetic and `O(N)` word storage using the inherited streaming majority counters. A `G*m` twiddle table can be formed with one primitive N-th root, O(N) multiplications, and O(N) storage; `twiddle_one_root` makes this explicit. Finite-precision root errors accumulate, and a valid target-error certification must charge their effect (or use sufficiently accurate periodic reanchoring). A full finite-precision bit-operation theorem for the composite implementation is **not** established by the current Python tests. Precomputing twiddles once across rows does not require or use cached input-dependent outputs.

## 4. Strong obstruction: one row is a low-rank projection

Since `A_N=F_N P` with `F_N` unitary,

    rank(A_N)=N/M,
    ||A_N-F_N||_{2->2}=||P-I||_{2->2}=M-1 (M>=2),
    ||A_N-F_N||_F^2=N(M-1).

In fact the Frobenius identity holds for **every fixed state tuple**, with no averaging, and the l2 error of a fixed input for a fixed state is exactly `||(P-I)x||_2`. Averaging states gives

    E||A_N x-F_N x||_2^2=(M-1)||x||_2^2.

A simple linear mean of `r` independent rows has expected full-vector squared error `(M-1)/r ||x||_2^2`, so obtaining relative expected squared `l2` error <= `epsilon^2` by this **linear averaging method** needs `r>=(M-1)/epsilon^2` rows. Thus the celebrated `O(N)` one-row cost when `M~log G` does **not** translate directly into an `O(N)` high-accuracy whole-vector approximation.

Further, a linear combination of `r` fixed sketch maps each of rank `N/M` has total rank at most `rN/M`. Any direct sum of **fewer than M** such maps cannot equal the full-rank Fourier operator and has operator-norm error at least one. This is an **architecture-specific rank certificate**, not a lower bound for arbitrary FFT programs or algorithms that read the original input through other transforms.

## 5. Exact recovery in exactly M compensated phase banks (tight barrier)

Fix any dyadic unit-chirp parameter `a_s` and base `beta_s` in each input column. Take phase-bank states `beta_{s,t}=beta_s + tK (mod G)` for `t=0,...,M-1`. The length-M local phase vectors of any block are

    v_t[u]= v_0[u] exp(2pi i t*u/M), 0<=u<M.

The `M` vectors are pairwise orthogonal, each of squared norm M, because the latter factors form a complete Fourier-M character system. Their physical projectors satisfy exactly

    P_{s,t} P_{s,t'} = 0  for t!=t',
    sum_{t=0}^{M-1} P_{s,t}=M I_G.

Thus `M` complete global sketch maps average to the **exact** Fourier transform:

    (1/M) sum_{t=0}^{M-1} A_{N,t} x = F_N x,   for all x.

The rank argument in Section 4 proves that M is the **fewest** such black-box rank-N/M linear sketches whose weighted sum could equal `F_N`. `exact_beta_frame` implements this. The result is **not a novel fast exact FFT**: the M complete passes cost

    O(M N + M N log(m+1) + N log(G/M)),

which is `Omega(N log G)` at `M=Theta(log G)` and fixed `m`. Cross-bank sharing might improve constants or recover a standard CT algorithm, but does not automatically reduce this cost to O(N). It needs a separately proved, fully charged, faster joint executor.

### Finite-field certificate

`finite_field_audit.py` uses prime fields with primitive N-th roots to compare **all N² input-output entries** of the phase-bank construction against the unnormalized exact Fourier matrix. Tested `(N,p,M)=(24,97,2),(40,641,2),(48,97,4),(80,641,4),(96,97,4),(160,641,4)`: **45,696 basis entries** plus **1,664 local projector entries** pass, and every deliberate wrong-spacing mutation is rejected. This certificate validates the finite instances, while the root-of-unity orthogonality argument is the general proof. The checker needs no floating-point libraries. The randomized per-output covariance was separately checked by exhaustive all-state enumeration over the complex numbers at `G=8,16`.

## 6. Adjacent paths, independence, and what is still open

- This project uses classical Cooley–Tukey factorization and the user's existing v9 power-of-two chirp-sketch theorem, not CrocSwap's conditional integer-multiplication exponent. CrocSwap's **verification discipline** inspired independent state accounting, mutation controls, exact finite-field replay and disclosure of the numerical/complexity model. This is a project-specific composition; no first-in-the-world priority is claimed.
- v12 remains preferable for some **odd or weakly dyadic lengths** under its own bias/variance/error contract. Comparing raw proxies across different fidelity targets is not a same-accuracy benchmark.
- The most pointed exact frontier is now **joint evaluation of all M orthogonal beta phase banks** with provably `o(N log G)` total charged operations. The identity and bank-rank obstruction specify precisely what naive caching and ordinary averaging cannot do. An exact Green/covariance-based nonunitary executor is another independent frontier.
- Neither this project nor these finite tests establish an exact `o(N log N)` transform on all lengths, unconditional optimality, certified practical speedups, or a new integer-multiplication result.
