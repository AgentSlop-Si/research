# Hero #17 — Phase 7: Fourier plaquette curvature, optimal rectangle unions, and the real sharing barrier

**Checkpoint date:** October 10, 2026.  
**Status:** Exact scoped theorems, tests over prime fields, a separate exact-cover optimizer, and independently checked full transforms. **No new universal exact `O(N)` FFT, no faster all-input exact arithmetic circuit, and no integer-multiplication improvement.**

## 0. What question this phase answers

Phase 6 derived basis-resistant four-leg tensor cut ranks and showed that an N-sparse internal representation hides two charged Fourier conversions. Phase 7 asks a sharper, graph-oriented question:

> Suppose an implementation tries to replace those conversions with a **single, disjoint cover of the full N-by-N Fourier matrix by rank-one rectangular subcomputations**. What is the *best possible* total independent input/output incidence work, after choosing all subgroups, block sizes, and partitions optimally?

We solve that **restricted** optimization exactly for every integer N. Then we prove a related sharp rank-weighted cost obstruction at perfect-square and prime lengths and show that multi-stage sharing gives the classical Cooley–Tukey circuit back. This *does not lower-bound unrestricted additive or linear circuits*: global changes of basis, arbitrary cancellations, sharing across tiles, and other operation networks are not covered.

## 1. Computational and algebraic contracts

Let `N >= 2`, and `F_N[k,j] = omega^(-k*j)` for `0<=k,j<N`, with `omega` a primitive Nth root in a field K (complex numbers or an appropriate finite field). An **elementary rectangle tile** is a Cartesian set `I × J` such that the restricted matrix `F_N[I,J]` has rank exactly 1. A **one-shot tiling** is a collection of pairwise entry-disjoint such rectangles that together cover the entire full Fourier matrix.

Define the *endpoint-incidence volume*

```
C(P) = sum_{I x J in P} (|I| + |J|).
```

This is the cost of a specified independent rank-one contraction implementation: each tile computes one weighted sum across J, then fans it out (with a coefficient) to its |I| output entries. It counts each endpoint use, without cross-tile reuse. It is **not** a model-independent lower bound on scalar gates; special scalar multiplications, sparse factors, and shared group sums can change real costs.

Finite-field executor counts each nontrivial-or-trivial multiplication as one charged scalar operation, each modular addition as one operation, includes N−1 multiplications to generate a root table from the supplied primitive root, and separately records N explicit output writes. Field/primality discovery in the *test fixture* is not part of the online executor; the primitive root is supplied, as in the benchmark model.

## 2. Theorem A: exact Fourier plaquette rigidity

For any row indices k,k' and column indices j,j', define the multiplicative plaquette phase

```
P(k,k';j,j') := F[k,j] * F[k',j'] / (F[k,j'] * F[k',j])
                = omega^(-(k-k')*(j-j')).
```

There are no zero entries, so this ratio is defined. It is invariant under arbitrary **nonzero diagonal row and column scalings**, and row/column relabeling merely relabels plaquettes. It is *not* invariant under general mixing GL_N basis changes.

A nonempty Fourier rectangle `I x J` has rank one if and only if

```
N divides (k-k0)*(j-j0) for every k in I and j in J
```

for any chosen base row k0 and base column j0. This follows from the 2-by-2 determinant criterion for rank one. The condition is field-independent provided omega has exact order N.

**Subgroup classification.** Let `H` be the subgroup of `Z_N` generated by all row differences `k-k0`; set `d = |H|`. The orthogonal annihilator `H^perp` has size N/d. Thus every rank-one rectangle satisfies

```
I subset k0 + H,                 |I| <= d,
J subset j0 + H^perp,           |J| <= N/d,
|I| |J| <= N.
```

Equality in the area bound requires the two full cosets. In the cyclic case H consists of multiples of N/d and H^perp of multiples of d. The same proof works for character tables of **all finite abelian groups** over splitting fields of compatible characteristic: replace multiplication of residues by the character pairing.

The group's maximal rank-one blocks were already studied in the Fourier rank-deficiency literature. The invariant itself is standard cross-ratio/character orthogonality; we make no blanket novelty claim.

## 3. Theorem B: exact minimum independent rectangle tiling cost

**Statement (all lengths).** For every N>=2,

```
min_{rank-one disjoint rectangle tilings P} C(P)
     = N * min_{d|N} (d + N/d).
```

**Proof of the lower bound.** Fix a tile with a=|I|, b=|J|. The subgroup classification supplies some divisor d of N for which a<=d and b<=N/d. Hence

```
a+b = ab*(1/a+1/b)
    >= ab*(1/d + d/N)
    >= ab/N * min_{e|N}(e+N/e).
```

Summing over the disjoint tiling and using `sum ab=N^2` yields the desired bound.

**Matching construction.** For any divisor d, set q=N/d. Partition rows into q cosets of `H={0,q,...,(d-1)q}` and columns into d cosets of `H^perp={0,d,...,(q-1)d}`. Their Cartesian products yield precisely N rank-one rectangles, each of shape d×q and covering exactly N entries. The endpoint cost is `N*(d+q)`. Choose the minimizing divisor. **Therefore the formula is exact, not just asymptotic.**

**Consequences.**

- `N=M^2`: best d=M, exact cost **2N^(3/2)**.
- `N=p` prime: d=1 or p, exact cost **N(N+1)**.
- General N: choose the closest divisor pair to sqrt(N); exact cost depends on arithmetic factorization.

This cost theorem is explicitly scoped to disjoint one-shot rank-one rectangles with *no sharing of partial sums across tiles*. Replacing its incidence volume by the cost of an arbitrary circuit would be mathematically invalid.

## 4. Theorem C: independently evaluated rank-r tiles cannot fix the square-length barrier

Here we change the **declared cost model**: a rectangle `I x J` may have rank `r = rank(F_N[I,J])`, but we charge `r*(a+b)` *dense-factor endpoints*, as in explicitly calculating r separate scalar projections and r independent fanouts, with no cross-tile sharing. A clever sparse factor or shared circuit may cost less, so this bound applies only to this factor-incidence model.

**Statement for N=M², over C.** Every disjoint arbitrary-rank rectangular tiling has

```
sum_tiles rank(F[I,J])*(|I|+|J|) >= 2N^(3/2).
```

This is attained by the rank-one subgroup tiling in Theorem B.

**Proof.** The complex unnormalized DFT satisfies `||F_N||_2=sqrt(N)`. For any a×b submatrix A, `||A||_F^2 = ab`, `||A||_2 <= sqrt(N)`, hence `r=rank A >= ab/N`. Also r>=1. Therefore

```
r >= max(1,ab/N) >= sqrt(ab/N)
```

and, using `a+b>=2sqrt(ab)`,

```
r(a+b) >= 2ab/sqrt(N).
```

Summing over tiles yields `2N^2/sqrt(N)=2N^(3/2)`.

**Prime N, over C.** Chebotarev's classical nonvanishing-minors theorem gives `r=min(a,b)`. Then `r(a+b)/(ab) >= 1+1/N`, so every such tiling has rank-factor incidence at least `N(N+1)`, again attained by rank-one full rows (or columns). The Chebotarev step is a complex characteristic-zero statement, not assumed for arbitrary small finite fields.

**General composite N, rank-r tiles.** We have NOT proved that higher-rank tiles can never reduce the factor-incidence minimum below the rank-one formula for every N. An exact integer-programming experiment at N=2..6 found no improvement, but does not settle the general case. The universal (but weaker) `2N^(3/2)` factor-incidence bound holds over C for all lengths.

## 5. Why this does *not* prove an FFT lower bound: algebraic graph sharing

In the matching N-tile construction, parameterize each tile by r∈[0,q), c∈[0,d), with row k=r+qv and input index j=c+dw. The Fourier kernel factors exactly:

```
omega^(-(r+qv)*(c+dw))
  = omega^(-r*c) * omega^(-r*d*w) * omega^(-q*v*c).
```

The independent tile executor computes

```
S[r,c] = sum_{w=0}^{q-1} x[c+d*w] * omega^(-r*d*w),
Y[r+q*v] = sum_{c=0}^{d-1} omega^(-r*c)*omega^(-q*v*c)*S[r,c].
```

When each scalar projection is computed directly and separately, this requires precisely `N(d+q)` counted multiplications, `N(d+q-1)` additions, `N-1` root-table multiplications, and N output writes in our implementation.

**Joint evaluation changes everything.** For fixed c, the q values S[r,c] are a length-q Fourier transform; for fixed r, the d outputs are a length-d Fourier transform of twiddle-weighted S[r,c]. Reusing their internal butterfly sums gives the classical mixed-radix Cooley–Tukey FFT. For q,d powers of 2, the provided executor counts exactly

```
B = (N/2)*log2 N classical radix-2 butterflies,
B butterfly multiplies + N intermediate twiddle multiplies,
2B butterfly additions,
N-1 root table multiplies,
N output writes.
```

Thus a *real* graph union that shares across tiles defeats the restricted `N^(3/2)` barrier easily, but it is **still Theta(N log N)**. It does not establish the desired all-input O(N). Any proposed novel architecture must beat **this fully charged shared implementation**, not the artificially independent tile one.

## 7. The research gate for Phase 8

**Do not attempt another single-shot Fourier tile optimization.** Its independent projection/fanout incidence optimum is solved exactly above; rank-one Fourier tile classification and subgroup coset constructions have significant prior art (Delvaux/Van Barel 2007–2008).

Instead, seek a **new uniform joint evaluator** for the two families of Fourier sums `S[r,c]` and the final twiddled d-axis transforms, treating scalar preparation, graph-schedule construction, inputs, and outputs as charged. It must either (i) exhibit an exact fully verified finite circuit with work asymptotically smaller than the appropriate conventional FFT and a uniform recurrence, or (ii) prove a novel, properly scoped restriction on multi-layer sharing. A change of basis that moves hidden FFT work into input recovery is invalid evidence.

The known all-input exact-complex-arithmetic benchmark of October 2026 is OpenAI Math #130 `O(N (log N)^(1−10^(-13)))`; it permits unrestricted exact complex scalars, charges preparation, and does not provide a bit-cost or bounded-coefficient theorem.
