# Proposed routed inverse-branch count obstruction

Status: root analytical proposal, not independently accepted. No novelty or general Fourier complexity claim.

## Model and proposed conclusion

Let F_N be an unnormalized Fourier matrix over a field containing a primitive Nth root. Consider a sum of r branches L_i Q_i^{-1} R_i, where Q_i=D_i+E_i P_i is invertible, D_i,E_i are arbitrary diagonal (zeros allowed), P_i is any permutation, and L_i,R_i are arbitrary monomial matrices (allow diagonal zeros, so monomial-support matrices). Every branch may have its own independent endpoint permutations. No nonmonomial endpoint mixing is allowed.

Claim: if N > r(r+2)^r, this sum cannot equal F_N. Therefore a family of such representations needs r=Omega(log N/log log N). This is a branch-count bound; it is not a lower bound on arbitrary shared arithmetic evaluation of the branches. A straightforward independent application costs O(Nr), but the theorem does not prove that any evaluation must do so.

## Key projective-column lemma

For any set R of k rows, the k-by-N matrix Q^{-1}[R,:] has at most k nonzero projective column directions, plus possibly a zero column direction.

Proof proposal: write A=Q^{-1}[R,:], so A Q[:,R^c]=0. The N-k columns of Q[:,R^c] are linearly independent since Q is invertible. The pattern of each original column of Q has two possible entries at positions j and pi(j), up to convention. Regard it as an edge joining variable nodes j and pi(j); loops are allowed. The resulting multigraph is a disjoint union of cycles, because pi is a permutation, with a fixed point represented by a loop. Removing the k constraint columns leaves untouched cycle components and path components (isolated vertices allowed). A cycle with t removed edges yields t paths; altogether exactly k paths arise, counting original one-vertex loops correctly.

A retained-edge path with v vertices has v-1 constraint columns. These columns are independent, including after restriction to that component, because all retained global columns are independent and disjoint components have disjoint variable supports. Its transposed kernel thus has dimension exactly one, regardless of zero individual coefficients. Untouched cycle components have square invertible constraint matrices and zero kernel. Each row of A belongs to the direct sum of the k one-dimensional path kernels. On a single path, each coordinate column of A is therefore a scalar multiple of the same k-vector of kernel expansion coefficients. It may vanish. This proves the at-most-k nonzero projective directions. Possible edge coefficients zero do not change the independence or decomposition argument; keeping the original cycle edges as a superpattern is legitimate.

If endpoint monomial matrices are present, selecting k output rows selects at most k distinct Q^{-1} rows and scales/reorders them. Right multiplication rescales/reorders columns. Thus at most k+1 categories including zero still suffice for each branch.

## Pigeonhole minor

Take k=r+1 consecutive output rows of F_N. For each branch, partition its N restricted column vectors by their nonzero projective directions and its possible zero category, using at most k+1=r+2 categories. The common refinement over r branches has at most (r+2)^r cells. If N>r(r+2)^r, some cell has at least r+1=k columns.

On those columns each branch has rank at most one, so their sum has rank at most r. But any k consecutive Fourier rows against k distinct columns form a nonsingular Vandermonde matrix, including composite N and any field with a primitive Nth root. This is a contradiction.

For r=2 this excludes every N>=33, even with independent endpoint permutations per branch. For r=1 it gives the conservative N>=4 cutoff. Constants are not claimed sharp. With all cycle blocks Hamiltonian and all relevant inverse entries nonzero one might remove the zero category, but that is not needed for the theorem.

## Mandatory audit points

Permutation matrix orientation and graph incidence; loops and two-cycles with parallel edges; deletion of constraints versus selection of inverse rows; retained column independence and path nullities with zero diagonal/off-diagonal coefficients; monomial endpoints with zero scales; consecutive Fourier row Vandermonde in arbitrary fields; pigeonhole strict inequality; branch-count versus arithmetic-cost distinction; prior literature on inverse cycle matrices, quasiseparable generators, and projective column complexity. Need fresh exact tests including zero coefficients and independently permuted endpoints, plus primary-source comparison before any novelty claim.
