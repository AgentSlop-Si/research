# Phase 36: two-mask Green calibration and phase rigidity

Continue the original noncommuting Green graph-reuse project from Phase 35 without revisiting excluded FFT butterfly or additive-only architectures.

This phase gives two complementary results. **Positive result:** two input/output diagonal masks exactly calibrate the Fourier first row and column for positive bi-regular Green triples via positive matrix scaling, with `O(N)` matrix-free applications and `O(N log(1/tolerance))` approximate mask preprocessing when the middle Green kernel is near-uniform. **Negative result:** even arbitrary *complex* choices of those two masks face a uniform spectral-error floor for positive-middle, near-identity-outer Green triples. Complex single Green solves can evade low phase rank but still have only three projective cross-ratio values.
