# Independent Phase21 replay

Use Python 3.9 or later, standard library only:

    python independent_checks.py --output regenerated.json
    cmp INDEPENDENT_RESULTS.json regenerated.json

The checker can be copied alone to an empty directory. It does not import uploaded programs or require source archives. Full polynomial interpolation and dense reference DFTs are audit costs, not the algorithm's advertised transform costs. No original fallback execution is included. Do not run programs under extracted/.
