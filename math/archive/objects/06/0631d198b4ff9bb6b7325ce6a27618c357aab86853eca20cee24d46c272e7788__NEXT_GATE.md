# Hero #1 Phase 16 — proposed exact-FFT research gate

**Main goal remains OPEN:** no all-input exact `o(N log N)` FFT, no integer multiplication improvement.

Phase15 eliminates M long scans in the stationary full-rank model but proves that the resulting evaluator is exactly gauged Cooley–Tukey, with all M length-K and K length-M FFTs charged. Simply varying `a_i` or using full-rank noncommuting local Gram matrices cannot beat this by itself: the block-local reconstruction is just a basis change. The explicit nonstationary family shows a rank-versus-precision danger as its period L grows.

## Highest-priority next experiment

Search for a **global** Green forcing network that couples *different input blocks before local frame inversion*, rather than a direct sum of invertible M-dimensional charts. It must give an explicit fast application of the dense `B=L F_N` forcing map across all fresh inputs and cannot assume that a rank-q (`q<M`) local projector recovers all x.

Require one of:

- A correct **all-input** noncommuting global update that bypasses `M` independent K-DFT streams, with a symbolic reduction and a complete count of scalar work, memory, roots, routes, setup, and precision.
- A bounded-rank cross-block representation whose **sum is full rank**, plus an exact all-size circuit with sub-`N log N` work; no free or cached data-dependent values.
- A different nonlocal factorization passing both Fourier Weyl intertwining relations or the exact residual Green equation and its genuine seed, not only sparsity or rank tests.

## Immediate rejection and safety checks

1. Any new `a_i == a0 mod K` local frame: Phase15 Theorem2 applies (gauged CT). Avoid redoing this family.
2. Any `V_r` full-rank block-local chart claimed to be a speedup *because it is invertible*: rank does not reduce the number of K-FFT data streams.
3. New nonstationary charts should report `cond(V_r)^2` or a rigorous error-amplification proxy for ALL blocks. Phase15 Theorem4 supplies a constructive exponentially bad case.
4. A linear-work approximation using a fixed lower-dimensional projection cannot claim worst-case all-output small relative error (Phase14 rank/leverage gate).
5. A conditional shortcut based on unitary or well-conditioned FFT lower bounds cannot be transferred as an unrestricted theorem. Identify the computational model exactly.
6. Quantum Fourier transform cannot output N arbitrary classical Fourier coefficients without considering state preparation, readout and precision. It is not a free classical O(N) algorithm.
