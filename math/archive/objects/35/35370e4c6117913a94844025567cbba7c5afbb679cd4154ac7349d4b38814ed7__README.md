# Portable independent bilateral Fourier audit

Read `BILATERAL_TAIL_GATE_AUDIT.md` for the verdict, proofs, hypotheses and scope.

- `independent_symbolic_audit.py`: fresh symbolic reconstruction and all 55 gate minors. Requires SymPy.
- `independent_modular_audit.py`: standard-library finite-field controls and exact formula checks.
- `symbolic_results.json`, `modular_results.json`: machine-readable results.
- `reconstructed_polynomials.json`: independently rebuilt polynomial coefficients.
- `input_data/`: inert comparison certificates and a copied subset of the prior independent coefficient data.
- `source_hashes.json`: source provenance, supplied-manifest validation and local input hashes.
- `SHA256SUMS.txt`: hashes of this audit package, excluding the manifest itself.

Both scripts resolve paths relative to their own file, so the directory is portable and either checker can be launched from any working directory. Neither imports or executes uploaded code. No existing research master was edited.
