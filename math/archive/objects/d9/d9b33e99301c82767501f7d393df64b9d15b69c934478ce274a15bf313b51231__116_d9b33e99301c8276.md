# FFT research: whole-scan information-flow rank certificate

**October 9, 2026 — chain-restored continuation.** A **proof-tool improvement**, NOT a faster FFT. Work continues on exact transforms with fresh unrelated inputs and fully charged arithmetic, without caches, threads, or certificate racing.

## Most important new result

For one explicitly specified **64-point** transform, both input and output coordinates are bit-reversed, and an internal shuffle is fixed. If one attempts an exact Fourier factorization using **two rank-one quasiseparable (forward/backward scan) stages**, a chosen Fourier submatrix has **complex rank at least 17** but the complete information-flow network has a **cut of capacity 16**. Thus that particular factorization is impossible. The previous multi-interval bound for **the same row and column sets** was 17, so it missed the contradiction.

The new certificate is `new_network_certificate_N64.json`, generated by `network_certificate.py`. The standalone verifier `verify_certificate.py` checks the cut partition and the shared 17x17 nonzero determinant at **two independent finite-field primitive 64th roots**, without running the search or computing max flow. Re-run with:

```bash
python verify_certificate.py
python -m unittest discover -s tests -v
python search_witness.py 2 25000
```

The rank-(2,2) case remains **open**. In a fixed set of 25,000 deterministic samples over six classes of input/output position sets, no violated rank-2 network cut was found. This is NOT exhaustive and does not establish a factorization.
