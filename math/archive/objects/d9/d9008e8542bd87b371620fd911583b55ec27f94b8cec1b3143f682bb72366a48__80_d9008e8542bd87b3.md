# Sparse-surrogate Word-RAM FFT checkpoint — 2026-10-09

## Main goal
Fresh arbitrary dense input, all N approximate Fourier outputs, asymptotic speedup derived from our own sparsification / finite-state lookup mechanism. No #130/CrocSwap/Swapnil sub-NlogN primitive.

## Established upstream theorem
For the unitary DFT U_N and fresh x in C^N, importance-sample coordinates with p_j=|x_j|/||x||_1 to form a k-sparse unbiased surrogate y. With failure <= delta,

  ||U_N y - U_N x||_inf <= eps ||x||_1 / sqrt(N)

for k = O(eps^-2 log(N/delta)). Head/tail sparsification improves k for compressible inputs. For fixed eps and polynomially small delta, k=Theta(log N) in the flat worst case up to known approximate-rank factors.

The current arithmetic backend evaluates U_N y in O(N log k)=O(N log log N).

## Failed linear-decoder branches
1. Local one-mode block projection: exact O(N) decoder but variance E||x_tilde-x||_2^2=(M-1)||x||_2^2, forcing Omega(M) sketches.
2. Recursive chirp decoder: O(N) formal recurrence but errors compound badly.
3. Multi-factor averaging/median: coherent alias combs remain on flat/global-mode adversaries.
4. Dense -> sparse surrogate -> linear chirp decoder: fails because E_y[A y | A,x]=A x; stage-1 unbiasedness cannot remove biased stage-2 operator.
5. Shared/affine chirp families: exact linear decoder but all-bin concentration cost reintroduces log log N.

## New live path: finite-precision word-RAM tabulation
Because the target is approximate, quantize the k=Theta(log N)-sparse surrogate before the expensive full-output evaluation.

### First version: tabulated bottom transforms
After a pruned sparse FFT, the remaining bottom transforms have width B=Theta(log N). Round each normalized complex intermediate entry to step Delta=Theta(eps/B). Then each complex entry has only poly(B/eps) states, hence p=O(log B+log(1/eps)) bits.

Use Four-Russians chunks whose input address has at most gamma log N bits, gamma<1. A lookup table stores each chunk's contribution to all B outputs in packed fixed-point form.

If h=O(Bp/log N) chunks are needed per B-transform and one packed B-output vector uses O(Bp/log N) words, all N/B bottom transforms cost

  O(N * B * p^2 / (log N)^2)

word operations.

For fixed accuracy, B=Theta(log N) and p=Theta(log log N), giving

  O(N (log log N)^2 / log N) = o(N).

The O(N) fresh-input scan and O(N) output write then dominate.

### Cleaner second version: direct phasor-trajectory tabulation
Instead of tabulating B-point FFTs, directly tabulate the phasor trajectories of groups of sampled coordinates over blocks of B=Theta(log N) output frequencies.

At fixed accuracy, each sampled coordinate/weight descriptor needs only O(log log N) relevant quantized bits for a B-bin output block. Group

  g = Theta(log N / log log N)

descriptors so one group key fits in gamma log N bits. There are only

  G = Theta(log log N)

groups.

First-level table: group descriptor -> quantized B-lane average trajectory.

Second-level table: after rounding first-level group averages to a constant/poly(1/eps) alphabet, sum/average the G group symbols lane-wise. Because G=Theta(log log N), the second table is only polylogarithmic size for fixed accuracy.

Processing all N/B output blocks requires O(N) or o(N) word operations depending on packing convention; in either case dense input scan/output materialization dominate.

### Deterministic decoder error budget already derived
The two-level table decoder has an additive normalized error bound of the form

  decoder_error <= (eta_phase/2 + h1/sqrt(2) + h2/sqrt(2)) * L_box(x)/sqrt(N),

where

  L_box(x)=sum_j (|Re x_j| + |Im x_j|),

eta_phase is phase quantization error and h1,h2 are the first- and second-level fixed-point rounding steps.

This is compatible with the upstream Monte-Carlo target after allocating the total epsilon budget between sampling and decoder quantization. L_box(x) <= sqrt(2)||x||_1.
