# Phase 26 — the actual research gate

Phase 25 establishes an all-input exact mixed-radix/certificate pipeline and a stringent rejection test. It **does not** produce an unrestricted sub-`N log N` DFT. New experiments should only claim an asymptotic saving after all charges.

## 1. Escape the unitary two-input gate ceiling legitimately

The unitary entropy argument needs `N log₂N/2` gates with two-register unitary operations, irrespective of arbitrary graph wiring or rank-window gates. For a potentially new architecture, specify exactly which assumption is abandoned: larger arity, nonunitary operations, data-dependent branching, extra workspace, or a different computational model. Count its benefit *and* its routing, conditioning and precision toll. Do not treat parallel threads or unlimited precomputation as sequential arithmetic savings.

## 2. Attack global Green forcing, not its easy inverse

Phase 16 shows `LF_N=F_NP` can push all difficulty into the forcing, even for arbitrary permutation graphs and linear-time Green inverses. Produce one new exact all-input family with a complete `F_NP` evaluator whose arithmetic is not just a reindexed Cooley–Tukey. Independently check the full Fourier matrix and the exact recurrence/memory ledger.

## 3. Conditional FFT improvements must be compared with the best native length-specific baseline

For `3·2^t`, use the optimized GT3 source delivered here (not generic Bluestein). For other coprime factors, implement certified Good–Thomas or Winograd codelets first. Measure actual modular arithmetic operations and memory accesses. Admit structured-input searches only if their paid decision cost is competitive; abort under an explicit work budget, with no repeated fallback DAG operations.

## 4. Explore globally shared high-arity kernels

Test whether an exact `b×b` operation admits a computationally shared graph with asymptotic cost sublinear in `b log b`, after expanding that operation into field additions/multiplications. Large uncharged operations merely rename the problem. Fixed-rank projector banks and short-recursion exceptions should be audited on complete generic input bases.

## 5. Confirm historical novelty before claiming it

Good–Thomas, split radix, Ailon's entropy lower bound, Morgenstern, Winograd codelets, and Prony-type sparsity techniques are prior work. The original research contribution must be precisely distinguished from them and submitted for independent review. Even exhaustive finite-field tests are not a mathematical proof of a new all-size `o(NlogN)` algorithm.
