# FFT unit-step chirp v9

This bundle continues the v8 global-chirp project by replacing the phase `a*t^2` with the integer-valued phase `a*binom(t,2)`.

## Main change

Because `binom(t+1,2)-binom(t,2)=t`, the exact output recurrence advances by `a` rather than `2a`. For a unit `a` modulo a prime-power length, the decoder has one cycle.

A parity-dependent half-step linear phase makes the cycle monodromy `-1`, so the balanced scan total supplies the seed for both even and odd prime powers.

For `N=p^L=K*M`, with `K,M` powers of `p` and `K>=M`, every output has exact one-row covariance

```text
Q = (M/N) * Pi
```

where `Pi` is an orthogonal projector of rank `N-K`.

## Reproduce

```bash
python prototype.py --output results.json
python test_checkpoint.py
./build_native.sh
./native_benchmark 262144 5 > native_benchmark_results.csv
python projector_certificate.py --output projector_certificate_results.json
python composite_modulus_audit.py --output composite_modulus_results.json
```

The native build links directly to the available FFTW runtime library. On a system with normal FFTW headers, the declarations in `native_benchmark.cpp` can be replaced by `#include <fftw3.h>`.

## Files

- `RESEARCH.md` — theorem, derivation, finite-precision bridge, and limitations.
- `prototype.py` — generalized prime-power implementation and experiments.
- `test_checkpoint.py` — 14 independent consistency tests.
- `results.json` — deterministic Python experiment output.
- `native_benchmark.cpp` — dyadic C++20/FFTW implementation.
- `native_benchmark_results.csv` — native correctness and timing results.
- `PROJECTOR_CERTIFICATE.md` / `projector_certificate.py` — exact integer/rational certificate.
- `COMPOSITE_MODULUS_AUDIT.md` / `composite_modulus_audit.py` — all-modulus shortcut rejection.
- `CHAIN_CHECKPOINT_2026-10-09_v9.md` — compact recovery checkpoint.

## Boundary

This is a randomized approximate full-output transform, not an exact linear-time FFT and not a machine-precision replacement for FFTW.
