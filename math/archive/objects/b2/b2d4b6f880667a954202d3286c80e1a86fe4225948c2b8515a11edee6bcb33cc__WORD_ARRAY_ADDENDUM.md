# Bounded-word-array addendum to sealed exact NTT theorem

The v1 theorem EXACT_RESTRICTED_NTT.md remains unchanged (SHA256 37ba83e95097b8217456cda82722405fc62e0987e1679084c6b22be4d93cc8ef).

A second freshly written checker, check_word_arrays.py, implements the packed basis conversion literally on lists of bounded-size words. Every bit-range read/write, alignment boundary, shifted XOR and block concatenation is processed with explicit loops. It does not invoke whole-string giant-integer shifts/XORs to implement conversion. Big integers appear only in input generation and the independent reference oracle.

It passes 252 exact comparisons covering coefficient-vector widths 1,3,9, logical word widths 3,7,13,32, and polynomial lengths 4 through 256. The independent oracle performs triangular polynomial-basis elimination separately on each coefficient bit lane.

The largest cost-only run converts 65,536 binary coefficients with 16-bit logical words. It executes 5,144,384 instrumented boundary/XOR work units. Across m=2,4,8,16 with n=2^m and w≈m, these instrumented counts divided by n log2 m stay between 18.5 and 20.5. This is a mechanics and scaling check, not a theorem or a competitive runtime benchmark; not every interpreter/index operation is instrumented. General runtime is supplied by the explicit recurrence proof.

The word-array checks support the point most likely to be hidden by a giant-integer prototype: no free bit transpose, free regrouping, or unit-time operation on a Q-bit string is needed for the binary basis-conversion step.
