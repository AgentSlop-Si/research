# Hero #17 Phase 18 — Magnetic Green–Union

This package contains **exact field-arithmetic proofs, executable source, regression tests, independent audits, an operation ledger, and the complete Phase 17 predecessor archive**.

**Result:** `K` pairwise noncommuting magnetic Green resolvents collapse to a single `O(N)` whole-vector evaluator, even for growing `K|N`. A fixed number of Fourier-weighted sectors also admit linear-time evaluation. These are **NOT** algorithms for the arbitrary-input DFT.

Main files:

- `PROOF_CERTIFICATE.md`: seven scoped theorems and proofs.
- `RESEARCH.md`: summary, operation counts, limitations, prior art, next problem.
- `phase18.py`: source of executors, independent cyclic solver and counters.
- `test_phase18.py`: modular correctness, rank, Weyl-support and covariance tests.
- `independent_audit.py`: separate Gaussian/direct-branch output verification, including full 65,536-vector comparison and growing-K operation scaling.
- `weyl_line_gate.py`: exact finite Weyl coefficient / projective line calculations.
- `AUDIT_RESULTS.json`, `TEST_LOG.txt`, `AUDIT_LOG.txt`, `PREDECESSOR_TEST_LOG.txt`.
- `CHAIN_CHECKPOINT.md`: concise handoff to Phase 19.
- `PHASE17_PREDECESSOR.zip`: complete previous iteration.

Run `python -m unittest -v test_phase18`, `python independent_audit.py`, and `python weyl_line_gate.py` in the extracted directory. No third-party Python packages are required.
