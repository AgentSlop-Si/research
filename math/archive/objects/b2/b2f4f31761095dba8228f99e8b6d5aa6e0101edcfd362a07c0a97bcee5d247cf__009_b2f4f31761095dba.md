# Packed finite-state sparse-surrogate DFT — continuation checkpoint v3

**Date:** 2026-10-09  
**Goal:** continue the recovered fresh-input branch without using OpenAI #130, CrocSwap, or Swapnil-jain as the source of the speedup.

## Executive result

The packing obligation from `SPARSE_SURROGATE_WORDRAM_CHECKPOINT_2026-10-09_v2.md` can be closed more cleanly than the previous two-table proposal suggested.

For fixed accuracy `eps > 0`, polynomially small failure probability `delta = N^{-c}`, and finite-precision inputs on a standard randomized word-RAM with `w = Theta(log N)` bits per word, the signed real/imaginary atom sampler plus a **single first-level Four-Russians phasor table and guarded packed accumulation** gives an input-independent preprocessing size/time `o(N)` and online time `O(N)` for an additive all-bin approximation of the unitary DFT:

    ||Xhat - U_N x||_inf <= eps * L_box(x) / sqrt(N)

with probability at least `1-delta`, where

    L_box(x) = sum_j (|Re x_j| + |Im x_j|).

Equivalently, for the unnormalized DFT `F_N`,

    ||Fhat - F_N x||_inf <= eps * L_box(x).

This is a **model-specific randomized approximate transform result**, not an exact FFT result and not a claim of a new integer-multiplication bound.

The main simplification is that the proposed second-level lookup table is unnecessary. After a first-level lookup returns a quantized `B`-lane group average, all group vectors can be accumulated by SWAR-style word additions with enough guard bits. The packed accumulation costs

    O(N loglog(N) logloglog(N) / log(N)) = o(N)

for fixed accuracy (a looser `O(N (loglog N)^2/log N)` bound is also valid).

The mandatory input scan and `N` output writes therefore dominate.

## 1. Model and statement

Use a randomized word-RAM with:

- word size `w >= C log_2 N` for a sufficiently large fixed constant `C`;
- unit-cost word addition/subtraction, multiplication, shifts, masks and indirect table lookup;
- unit-cost random word generation;
- each input real/imaginary component represented by `O(w)` fixed-point bits;
- output represented to the fixed precision required by the chosen constant `eps`.

For the cleanest exact sampling implementation, scale the nonnegative real/imaginary masses to integers fitting `O(1)` words. A two-pass sorted-threshold sampler then draws the required samples in `O(N + k log k)=O(N)` time.

The theorem below is asymptotic. For small and medium `N`, the conservative table constants are not practical and an ordinary FFT should be used.

### Theorem candidate (now with the packing gap closed)

Fix constants `eps in (0,1)`, `c >= 0`, and `gamma in (0,1)`. Let `delta=N^{-c}`. For all sufficiently large `N`, there is a randomized word-RAM algorithm with input-independent preprocessing `o(N)` words and `o(N)` word operations which, on every fresh finite-precision `x in C^N`, writes all `N` approximate Fourier coefficients in `O(N)` word operations and succeeds with probability at least `1-delta`:

    ||Xhat-U_N x||_inf <= eps L_box(x)/sqrt(N).

No cached transform of `x`, relation metadata, repeated input, or structured input is assumed.

## 2. Signed real/imaginary atom sampler

Write every coordinate as four possible signed atoms:

    Re x_j > 0  -> +e_j
    Re x_j < 0  -> -e_j
    Im x_j > 0  -> +i e_j
    Im x_j < 0  -> -i e_j.

Give each nonzero atom probability equal to its mass divided by

    L = L_box(x).

Draw `k` atoms independently with replacement. If atom `a_l=s_l e_{j_l}` is drawn, define

    y = (L/k) sum_l a_l.

Then `E[y]=x`.

For a unitary Fourier row, one normalized sample contribution has magnitude exactly `L/sqrt(N)`. Applying scalar Hoeffding to real and imaginary parts and then a union bound over all `N` bins gives the safe sufficient sample count

    k0 = ceil(4 eps_s^{-2} ln(4N/delta)).

Thus with probability at least `1-delta`,

    ||U_N y-U_N x||_inf <= eps_s L/sqrt(N).

Later we round `k0` upward to a multiple of the table group size `g`; this can only improve the concentration bound.

## 3. Frequency blocks and finite descriptor alphabet

Split the `N` outputs into blocks of

    B = Theta(log N)

consecutive frequency bins. For a block beginning at `m0`, one sampled atom contributes the `B`-lane trajectory

    s * (omega_N^{j(m0+t)})_{t=0}^{B-1},

with `s in {+1,-1,+i,-i}`.

Describe this trajectory by:

1. its sign/phase `s` (2 bits),
2. a quantized start phase `alpha = j m0/N mod 1`,
3. a quantized slope `beta = j/N mod 1`.

Choose quantizers with

    Q_start >= 2 pi / eps_phi,
    Q_slope >= 2 pi B / eps_phi.

Nearest-bin quantization then gives, for every lane `0<=t<B`,

    |exp(2 pi i(alpha+t beta)) - exp(2 pi i(alpha'+t beta'))| <= eps_phi.

The number of possible non-null descriptors is

    A <= 4 Q_start Q_slope = O(B/eps_phi^2).

Hence one descriptor uses

    p = ceil(log_2(A+1))
      = O(log B + log(1/eps))
      = O(loglog N)

bits for fixed accuracy.

## 4. First-level table

Choose

    g = floor(gamma log_2 N / p).

For sufficiently large `N`, `g>=1`, and a group key of `g` descriptors occupies at most

    g p <= gamma log_2 N

bits, i.e. one word.

The table maps one group key to the quantized **group-average** trajectory

    v_t = (1/g) sum_{r=1}^g s_r exp(2 pi i(alpha_r+t beta_r)),  0<=t<B.

Round each real and imaginary lane to step `h1`. Each group-average component lies in `[-1,1]`.

### Table size and construction cost

There are at most

    A^g <= 2^{pg} <= N^gamma

keys.

Constructing one table entry naively costs `O(gB)` finite-precision operations, and storing it uses only `polylog(N)` bits/words. Therefore total table construction time and memory are

    N^gamma polylog(N) = o(N)

for every fixed `gamma<1`.

This fully charges preprocessing; there is no free exponentially large oracle.

## 5. Online key construction is O(N)

Let `R=ceil(N/B)` be the number of output blocks.

For every block and every one of the `k=Theta(log N)` sampled atoms, form the quantized start-phase descriptor. The slope descriptor is block-independent and can be computed once per sample.

Total descriptor work is

    R k
      = O((N/log N) * log(N/delta))
      = O(N)

for `delta=N^{-c}` and fixed accuracy.

The per-block start phase can be formed by word multiplication/modular arithmetic (or by shift/high-bit arithmetic for power-of-two `N`). No scan of an `N`-length cached object is involved.

## 6. The second lookup table is unnecessary

Let `G=k/g` after rounding `k` upward to a multiple of `g`. Since

    k = Theta(log N),
    g = Theta(log N / p),

we have

    G = O(p) = O(loglog N)

for fixed `eps,c,gamma`.

A first-level lookup returns each rounded lane as a small signed integer. To add `G` group vectors without cross-lane carry:

1. offset every signed lane by a fixed positive bias;
2. allocate

       q = O(log G + log(1/h1))

   bits per lane, including a guard bit;
3. pack `floor(w/q)` lanes in a word;
4. add the packed words with ordinary word addition.

Because the maximum possible accumulated field value is strictly below `2^q`, no carry crosses a lane boundary.

A `B`-lane vector therefore occupies

    O(B q / w) = O(q)

words because `B=Theta(log N)` and `w=Theta(log N)`.

Accumulating all `G` vectors for all `R=N/B` blocks costs

    O((N/B) G q)
      = O(N loglog N logloglog N / log N)
      = o(N)

for fixed accuracy.

Using the looser fact `q=O(loglog N)` still gives

    O(N (loglog N)^2/log N)=o(N).

The prototype in this bundle explicitly emulates these guarded packed additions.

## 7. Final unpack/write

After packed accumulation, each lane is unpacked once, the group average is rescaled, and the final fixed-point rounding step `h2` is applied. Writing all `N` output coefficients costs `Theta(N)` word operations.

Thus the online total is

    input scan/sampling       O(N)
    descriptor construction  O(N)
    first-level lookups       o(N)
    packed accumulation       o(N)
    output unpack/write       O(N)
    --------------------------------
    total                     O(N).

Together with `o(N)` preprocessing, the complete asymptotic cost is `O(N)`.

## 8. Deterministic decoder error

Work in normalized phasor-average units before multiplying by `L/sqrt(N)`.

- start/slope phase quantization contributes at most `eps_phi`;
- first-level real/imag lane rounding contributes at most `h1/sqrt(2)` in complex magnitude;
- final real/imag lane rounding contributes at most `h2/sqrt(2)`.

Therefore

    decoder_error <= eps_phi + h1/sqrt(2) + h2/sqrt(2).

Combine with the sampling event:

    total_error <= eps_s + eps_phi + h1/sqrt(2) + h2/sqrt(2)

in units of `L_box(x)/sqrt(N)`.

For example, choose

    eps_s   = eps/2,
    eps_phi = eps/4,
    h1      = eps/(4 sqrt(2)),
    h2      = eps/(4 sqrt(2)).

Then the four terms sum to `eps`.

Any finite error used to generate table phasors can be absorbed by shrinking `h1` by another constant factor.

## 9. Prototype verification

`prototype.py` implements:

- signed real/imaginary atom sampling;
- quantized start/slope descriptors;
- on-demand first-level group table (to avoid materializing an asymptotically huge table at toy `N`);
- guarded packed integer lanes;
- packed word addition;
- comparison against both the exact sampled signal FFT and the original full FFT;
- an asymptotic cost model.

### Main run

15 cases were tested at `N=256,1024,4096` across:

- flat,
- Gaussian,
- random phase,
- power-law,
- spike + noise.

Observed maximum decoder error, normalized by `L_box/sqrt(N)`:

    0.0370517

Derived deterministic decoder bound for the chosen test parameters:

    0.1436396

Bound violations:

    0 / 15.

A separate 100-case random stress test (`N=128,256,512,1024`) observed

    worst normalized decoder error = 0.0352156
    bound                          = 0.1436396
    violations                     = 0 / 100.

A 100-trial Gaussian sampling check at each of `N=256,1024,4096` used `eps_sample=0.45`; the largest observed sampling errors were about

    0.246, 0.228, 0.243,

with no empirical threshold violations.

These experiments check the algebra and the deterministic packing/rounding budget. They do **not** establish practical speed: toy sizes use an override `g=4` to exercise grouping, because conservative asymptotic word-fit constants make `g` small at realistic sizes.

## 10. Critical limitation: the norm guarantee can be weak

This is the most important boundary.

The theorem controls

    ||Xhat-Ux||_inf <= eps L_box(x)/sqrt(N).

For dense inputs with `|x_j|=Theta(1)`, usually

    L_box(x)=Theta(N),

so the permitted unitary error is

    Theta(eps sqrt(N)).

For cancellation-heavy dense signals (for example random phases), a typical unitary Fourier coefficient can have magnitude only `Theta(1)`. In that regime the allowed error may be much larger than the coefficient itself.

So this result is **not** a conventional high-relative-accuracy replacement for FFT.

The limitation is intrinsic to this coordinate-sampling branch: for a flat-magnitude vector, one importance-sampled contribution to a unitary Fourier bin has magnitude `Theta(sqrt(N))`, so the standard deviation of a `k`-sample average is `Theta(sqrt(N/k))`. Requiring `O(1)` absolute error forces `k=Omega(N)` for this sampler, eliminating the logarithmic-support advantage.

Therefore the packing problem is no longer the main mathematical obstacle. The new frontier is a stronger approximation scale.

## 11. What this does and does not establish

### Established, conditional on the stated word-RAM/fixed-precision model

- The former hidden `loglog N` packing concern can be removed.
- A single finite-state group table plus guarded packed accumulation suffices.
- Preprocessing can be fully charged and remain `o(N)`.
- Online work is `O(N)` for fixed `eps` and `delta=N^{-c}`.
- The recovered all-bin `eps L_box/sqrt(N)` guarantee is compatible with this linear online cost.

### Not established

- exact DFT in `O(N)`;
- floating-point FFT replacement at ordinary machine-precision accuracy;
- a useful small relative error for every dense cancellation-heavy input;
- a new bit-complexity bound for integer multiplication;
- novelty of the general Four-Russians lookup idea.

## 12. Prior-art boundary (quick audit)

The lookup mechanism itself is certainly not new:

- the Method of Four Russians gives logarithmic-factor speedups for matrix products and matrix-vector operations over small/finite alphabets;
- Josh Alman (SOSA 2023, arXiv:2211.04643) uses lookup tables to obtain `O(N log N/loglog N)` bit complexity for the Walsh-Hadamard transform over constant-size finite fields;
- cyclotomic finite-field FFT literature explicitly uses Four-Russians-style matrix-vector multiplication in DFT presummation stages;
- Monte Carlo / importance-sampled approximate matrix multiplication is classical.

In the searches performed for this continuation, I did **not** locate an exact prior paper stating this particular combination:

    signed real/imaginary coordinate sampler
      + per-output-block quantized Fourier phase/slope descriptors
      + one-word Four-Russians group keys
      + guarded packed lane accumulation
      -> O(N) all-output eps*L_box/sqrt(N) approximate DFT.

That absence is **not a novelty proof**. A proper literature review would need broader database coverage and expert verification before any originality claim.

## 13. Correct next research question

The packing obligation is no longer the frontier.

The next question should be:

> Can we retain an `O(N)` or `o(N log N)` fresh-input evaluator while replacing the weak `L_box/sqrt(N)` all-bin error scale by a meaningfully smaller worst-case scale (for example one tied to cancellation, energy, or per-bin magnitude), without reintroducing `Omega(N log N)` work?

The previous chirp/block-projection branches already show that simply replacing coordinates by one local projection is not enough. Any next proposal should be tested first on flat random-phase inputs, because they expose the gap between `L_box/sqrt(N)=Theta(sqrt N)` and typical `Theta(1)` Fourier coefficients immediately.
