# Independent replay

Requirements: Python 3 standard library and a C++17 compiler named g++.

Run:

```
python independent_phase38.py
python charzero_own.py
python additional_controls.py
python verify_seal.py
```

The first command compiles the reviewer-authored exhaustive_own.cpp into a temporary directory, rebuilds all matrices, compares inert source coefficients and runs every ordered mapping at N≤64. No uploaded Python or C++ is run. Full replay takes several minutes depending on the machine. `python isolated_replay.py` repeats all three checkers in a temporary directory and requires byte-identical result files. Sampling at N128/256 uses a new deterministic sequence and is not an all-permutation proof.
