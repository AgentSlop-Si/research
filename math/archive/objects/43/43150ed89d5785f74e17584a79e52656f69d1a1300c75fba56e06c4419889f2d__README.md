## Reproduce locally

Requires Python 3.10+ and `numpy` (plus `scipy` for certain tests in the prior checkpoint).

```bash

python dual_sparse_polynomials.py
python onion_peel.py
python general_onion.py
python exception_s1.py
python test_dual_gate.py
python run_all.py

The system is **not** a symbolic expanded Groebner basis or proof of feasibility; if you evaluate it and all remaining equations vanish, still verify determinants, corner pivots, the intermediate permutation, and complete `BPA=F`.
