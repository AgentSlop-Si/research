# Offset-class prime-power lift and black-box scan-fusion gate

**Research checkpoint:** 9 October 2026  
**Status:** Reproducible theorem/prototype package. The positive result gives an adaptive exact-center randomized approximation for arbitrary lengths whose cost depends on an exact offset-class count. The negative result is a restricted state-rank obstruction for fusing already-materialized Bessel/scan channels. **This is not an exact sub-\(N\log N\) FFT, not a universal lower bound, and not a practical replacement for FFTW.**

## 1. Starting point and reproducibility correction

The inherited v11 checkpoint had reduced the all-length Bessel/Jacobi--Anger lift to genuine \(O(N)\) memory and had fused the input-side Bessel channels. Its remaining arithmetic cost was

\[
O(RN),
\]

because it still evaluated \(R\) length-\(K\) FFTs and \(R\) gauged prefix scans. The exact next target was a genuinely joint evaluator for those channels.

Before extending that code, a cold standalone test exposed a packaging error: the v11 archive omitted `unit_step_core.py`, so its saved tests failed at import with `ModuleNotFoundError`. This v12 package includes the missing core and reruns the repaired v11 suite together with the new v12 suite. Earlier v11 mathematical statements are unchanged, but the old claim that the archive itself was standalone was false.

## 2. Exact offset classes

Let the desired transform length be \(N\), and choose a prime-power lift

\[
Q=p^E\ge N.
\]

For each target frequency \(k\in\{0,\ldots,N-1\}\), choose the nearest \(Q\)-grid index

\[
j_k=\operatorname{round}\!\left(\frac{kQ}{N}\right) \pmod Q
\]

and define the centered residual

\[
\theta_k=\frac{kQ}{N}-j_k\in[-1/2,1/2].
\]

### Theorem 1: exact class count

The set of residuals \(\{\theta_k\}\) has exactly

\[
\boxed{L=\frac{N}{\gcd(N,Q)}}
\]

distinct values.

### Proof

The fractional part of \(kQ/N\) is determined by the residue \(kQ\bmod N\). The additive orbit generated by \(Q\) in \(\mathbb Z/N\mathbb Z\) has size

\[
\frac{N}{\gcd(N,Q)}.
\]

Centering a residue in \([-N/2,N/2]\) and dividing by \(N\) is injective on that orbit, so it does not change the count. QED.

When \(Q=p^E\), if \(N=p^e c\) with \(\gcd(c,p)=1\) and \(E\ge e\), then \(L=c\). Thus the class count is exactly the part of \(N\) not absorbed by the chosen prime-power lift.

## 3. One exact-center chirp row per class

Fix one class residual \(\theta\). Define a length-\(Q\) padded and modulated vector

\[
y_\theta[n]=
\begin{cases}
x[n]e^{-2\pi i n\theta/Q},&0\le n<N,\\
0,&N\le n<Q.
\end{cases}
\]

For every target \(k\) in this class,

\[
\begin{aligned}
\sqrt{\frac QN}\,(U_Qy_\theta)[j_k]
&=\frac1{\sqrt N}\sum_{n=0}^{N-1}
 x[n]e^{-2\pi i n(\theta+j_k)/Q}\\
&=\frac1{\sqrt N}\sum_{n=0}^{N-1}
 x[n]e^{-2\pi i nk/N}\\
&=(U_Nx)[k].
\end{aligned}
\]

So every class is an **exact deterministic modulation identity**. No Taylor, Chebyshev, Bessel, or Jacobi--Anger truncation is used.

Apply one v9 unit-step prime-power chirp row to each \(y_\theta\), sharing the same random chirp state across all classes, and retain only the \(Q\)-DFT entries belonging to that class.

### Theorem 2: unbiasedness and variance

Let \(M\mid Q\) be the v9 prime-power block size. The resulting complete length-\(N\) randomized row satisfies, for every input and every output,

\[
\boxed{\mathbb E\widehat X_k=(U_Nx)[k]}
\]

and

\[
\boxed{
\mathbb E\left|\widehat X_k-(U_Nx)[k]\right|^2
\le \frac{M}{N}\|x\|_2^2.
}
\]

### Proof

For the class of \(k\), v9 is unbiased for \((U_Qy_\theta)[j_k]\). Scaling by \(\sqrt{Q/N}\) and using the modulation identity gives unbiasedness for \((U_Nx)[k]\).

The sharp v9 prime-power operator bound is

\[
\mathbb E|\widehat Y_j-(U_Qy)_j|^2
\le \frac MQ\|y\|_2^2.
\]

Here \(\|y_\theta\|_2=\|x\|_2\). Multiplying the output by \(\sqrt{Q/N}\) gives

\[
\frac QN\frac MQ\|x\|_2^2=\frac MN\|x\|_2^2.
\]

Sharing a random state across classes can correlate different output errors, but it does not alter any single-output expectation or variance. QED.

## 4. Charged complexity

One class performs:

- one pass to construct/modulate a length-\(Q\) padded input;
- block summaries in \(O(Q)\);
- one length-\(K=Q/M\) FFT;
- one length-\(Q\) balanced gauged scan;
- selected output extraction.

Therefore one complete randomized length-\(N\) row costs

\[
\boxed{
T_{\rm class}(N;p,M)
=O\!\left(
L\left[Q+\frac QM\log\frac QM\right]
\right),
\qquad
L=\frac N{\gcd(N,Q)}.
}
\]

Sequentially processing classes uses

\[
\boxed{S(N)=O(Q+N)}.
\]

For a fixed prime \(p\), the next power satisfies \(Q<pN\). If a legal prime-power block \(M=\Theta(\log Q)\) is available, one class is \(O(Q)=O(pN)\), hence

\[
\boxed{T_{\rm class}=O(pLN).}
\]

### Fixed-cofactor family

For

\[
N=c\,p^e,
\qquad \gcd(c,p)=1,
\]

with fixed \(c,p\), choose a sufficiently large \(p\)-power lift. Then \(L=c\), and the method gives a fresh-input, full-output, exact-center randomized row in

\[
\boxed{O(N)\text{ time and }O(N)\text{ memory}.}
\]

For example, \(N=3\cdot2^e\) needs exactly three dyadic offset classes.

This is an arithmetic/asymptotic result, not an exact transform: each chirp row is randomized and approximate around the exact center.

## 5. Robust streaming output

The v8/v9 three-grid Boyer--Moore aggregator applies without change. For

\[
\tau=g\sqrt{\frac MN}\|x\|_2,
\qquad g>\sqrt2,
\]

and \(R_0\) independent offset-class rows,

\[
\Pr\!\left[
\|\widetilde X-U_Nx\|_\infty
>\frac5{\sqrt2}g\sqrt{\frac MN}\|x\|_2
\right]
\le
2N\exp\!\left[-R_0D\!\left(\frac12\middle\|\frac1{g^2}\right)\right].
\]

The candidate/counter states use \(O(N)\) memory independent of \(R_0\). The runtime is \(R_0\) times the one-row class cost.

## 6. Adaptive all-length route

The offset-class route is excellent when \(L\) is small and poor when the lift absorbs little of \(N\). For example, a dyadic lift of an odd prime has \(L=N\), making the class route useless.

The package therefore compares:

1. exact-center offset-class lifts over small primes \(p\in\{2,3,5,7\}\); and
2. the inherited v11 dyadic Bessel-rank lift.

A charged proxy chooses the cheaper route. Schematically,

\[
T_{\rm adaptive}
=O\!\left(
N\min\left\{pL,\ R_{\rm Bessel}\right\}
\right)
\]

up to the explicit \(K\log K\), lift-ratio, and input-fusion terms retained by the implementation.

This is a new **instance/factorization-sensitive frontier**, not a uniform improvement to \(O(N)\) for every length.

## 7. Why the already-materialized scans do not generically collapse

The remaining v11 question was whether \(R\) Bessel-weighted gauged scans could be replaced by one scan with fewer than \(R\) scalar state coordinates.

The following is a deliberately restricted gate. It applies only after the \(R\) channel forcing sequences have already been formed and treats them as arbitrary black-box data.

### Theorem 3: black-box linear scan-fusion rank gate

Suppose \(R\) gauged scans have independent forcing sequences \(q_r[j]\). Across the cut immediately after \(j=0\), set

\[
q_r[0]=z_r,
\qquad
q_r[j]=0\quad(j>0).
\]

At every later scan position, channel \(r\) contains a nonzero diagonal multiple of \(z_r\). Evaluate the final truncated Chebyshev combination at \(R\) distinct offsets \(\theta_i\). Up to nonzero row/column scalings, the map from \(z=(z_0,\ldots,z_{R-1})\) to those outputs is

\[
C_{i,r}=T_r(2\theta_i),
\qquad 0\le i,r<R.
\]

This Chebyshev--Vandermonde matrix has rank \(R\). Hence any **exact linear one-pass state** that transmits arbitrary black-box channel data across this cut requires at least \(R\) scalar state coordinates.

### Proof

The polynomials \(T_0,\ldots,T_{R-1}\) have strictly increasing degrees and nonzero leading coefficients. Evaluation at \(R\) distinct points is a nonsingular change from the ordinary Vandermonde matrix. Nonzero gauges and fixed Jacobi--Anger coefficients only apply invertible diagonal scalings. Therefore the map has rank \(R\), and a linear state of dimension \(d<R\) cannot factor it. QED.

### Scope

This is **not**:

- a lower bound for all FFT algorithms;
- a lower bound for nonlinear encodings with uncharged infinite precision;
- a barrier to exploiting Bessel relationships *before* channel materialization;
- a barrier when the number of distinct offsets is smaller than \(R\).

Indeed, if there are only \(L<R\) distinct offsets, the output-side rank is at most \(L\), exactly matching the offset-class collapse above.

## 9. Prototype performance

The Python implementation is a mathematical prototype. In the recorded cases:

- the streaming class evaluator took about \(1.03\times\) to \(1.38\times\) the v11 Python Bessel evaluator for most tested rows, despite a lower arithmetic proxy in some three-class regimes;
- it was roughly \(90\times\) to \(153\times\) slower than NumPy's optimized FFT;
- batching all classes increased memory to \(O(LQ)\) and did not improve the tested Python timings.

So there is no practical speed claim.

## 10. Prior-art and novelty boundary

Nearby-grid low-rank corrections and NUFFT factorizations as sums of diagonally scaled DFT matrices are established techniques. The offset-class identity itself is an elementary rational-grid modulation/orbit observation. The project-specific combination is with the unit-step chirp row, its sharp prime-power covariance bound, and the robust full-output streaming aggregator.

A limited search did not locate this exact combination, but that is not a novelty proof. Any publication claim requires a broader literature review and independent verification.

## 11. Honest conclusion

The v11 finish-line question now has a split answer:

- **Positive:** when the nearest-grid residuals occupy only \(L\) rational classes, the entire Bessel expansion can be removed and replaced by \(L\) exact phase-modulated prime-power chirp rows. Fixed-cofactor prime-power families therefore admit exact-center \(O(N)\) randomized rows.
- **Negative, restricted:** once \(R\) generic channels have already been materialized, exact linear scan fusion cannot carry them through a cut using fewer than \(R\) scalar states at \(R\) distinct offsets.

For rough lengths with large \(L\), the v11 Bessel route remains the best construction in this project. The next real target is therefore not cosmetic scan batching: it is a pre-materialization joint evaluator exploiting the analytic Bessel structure, or a different direct estimator for rough/prime lengths.
