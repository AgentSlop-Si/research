# Multistage bit reversal independent audit

Read REPORT.md for the mathematical conclusions and scope. All 34 recorded modular Jacobian ranks, six saved square-minor determinants, and the all-size upper-bound argument pass the audit.

This package is self-contained for reproducing the witness checks. It contains independently authored source and integer JSON data copied from the supplied archive. It requires Python 3.10+ and NumPy; it does not run or import uploaded source code, call a compiler, or use the network.

After reviewing the independent code, run:

    python check_bitrev.py
    python self_test_checker.py

The first command writes new results to checks/. To preserve the sealed recorded output, give a separate output directory:

    python check_bitrev.py inputs rerun_checks

The 34-case run took approximately 86 seconds on the audit environment. Runtime varies with hardware.

## Files

- REPORT.md: proof review, complete rank census, exact determinants, bounded extensions, and limitations.
- check_bitrev.py: independent Jacobian, elimination, gauge, finite-difference, and scan checks.
- self_test_checker.py: 80 small-matrix tests using exact-integer determinant expansion and exhaustive minor searches.
- inputs/: the three full-threshold witnesses and two result files from the supplied archive. Smaller-depth parameters are prefixes of these saved full-depth witnesses and are also checked against the stated seed recipe.
- checks/checks.json: all 34 detailed audit records, including independently selected minor witnesses.
- checks/summary.json: successful run summary and environment versions.
- checks/self_tests.json: exact-integer eliminator cross-checks.
- provenance.json: source-archive identity and verification of all 23 original manifest entries.
- run.log: the completed primary audit log.
- SHA256SUMS.txt: supplemental file checksums, excluding the checksum file itself.
