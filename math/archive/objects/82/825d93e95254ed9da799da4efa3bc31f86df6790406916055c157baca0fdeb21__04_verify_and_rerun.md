## Correctness and behavior
verify hashes each SHA256SUMS entry, then compares its listed set against every present non-cache file except the manifest. It rejects missing, changed and extra regular files. main always verifies before proceeding. --verify-only prevents subprocess execution; without it the script copies the chirp audit and extension trees into a temporary directory, invokes their exact entry points with check=True, then compares stored/new result objects. Only original-audit elapsed_seconds is removed; all other values, including its checker hash, are compared. It re-verifies the original package afterward. The temporary-copy design avoids overwriting sealed result files.

## Guards and limits
Hash mismatch/set mismatch and deterministic-result mismatch use explicit exceptions; these checks survive -O. The current parent interpreter's -O flag is not automatically appended to child argv, but an inherited PYTHONOPTIMIZE environment variable could disable child assertions. The script does not scrub the environment or attest interpreter/dependency identity. SHA256SUMS is an integrity manifest, not independently authenticated authorship; a self-consistent substituted package requires an external hash anchor to reject. Relative paths are not sandbox-validated against traversal/symlinks, which matters for an untrusted replacement manifest, not the inspected manifest. It also does not provide resource timeouts. Cache files are deliberately excluded from coverage.
