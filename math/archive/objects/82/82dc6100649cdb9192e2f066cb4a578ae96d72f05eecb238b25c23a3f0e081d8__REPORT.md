Each source has an exact-byte snapshot, a per-hash review, byte/line intervals, line-referenced findings and an identifiable full-read receipt.

## Material findings

1. **F01: Weyl verifier false acceptance outside its intended domain.** Phase14 weyl_gate.py does not validate output length. A callback returning an empty list satisfies its seed predicate and produces no zipped residuals, so it reports a pass. The reported probability bound requires a fixed valid linear map and independent uniform random tests. This is an implementation validation defect, not a counterexample to the Weyl characterization. Control C01 checks the logical failure without invoking the supplied verifier.

2. **F02: Direct-script test coverage is incomplete.** Four files put unittest.main() before appended classes: global-reuse test_audit.py, test_orbits.py, phase13 test_phase13.py, and joint-orbit test_stability.py. Direct invocation omits eleven methods total. Import-based discovery includes them. Archived logs explicitly name those later tests, so this finding does not invalidate the historical recorded discovery runs.

3. **F03: Several certificate checks are weaker than their success wording.** Phase12 verify_all.py trusts stored ranks/nonvanishing flags rather than recomputing their evidence, and parses thresholds.json without checking its contents. Saved phase35 polynomial loops and an ordinary-separator loop can be vacuous if records are omitted. Some wrappers report fixed test counts or ingest an existing numerical result without establishing freshness. The actual phase35 archive contains the expected N=8 and N=16 certificates; no actual omission was found. Three stored Fourier/Green small-block witnesses were independently checked and agree.

4. **F04: A root helper accepts lower-order roots.** Packet-separator primitive_root_of_order checks only the nth-power equation. With p=17, n=4 and custom generator 1, it returns an order-one root. The default known prime/generator examples are not contradicted.

5. **F05: Precision and cost scopes must stay explicit.** Spectral/SVD checks, numerical nearest pairs and floating error allowances are not interval certificates. The single-selection planner can lose a tiny tail through total-minus-head cancellation. One complex audit's scalar minimizes Frobenius error, not necessarily operator error. Several counters are intentionally field-operation, selected-work or butterfly proxies. In particular, growing Fermat-ring operands cannot be treated as fixed-size words, and special-input/approximate computations do not establish an exact generic FFT improvement.

6. **F06: Joint-orbit packaging is not byte-reproducible under changed file metadata.** Its fixed file list and post-write content checks are useful, but ZipFile.write preserves filesystem metadata. Equal payloads with different timestamps can produce different ZIP hashes. The synthetic control changes no original file.

Additional function-boundary and test-oracle limitations are recorded per hash, without promoting each to a theorem contradiction.

## Mathematical conclusions retained

- Adaptive-branch differentiation is a nonuniform fixed-branch conversion with prepared constants. Finite-field examples do not prove an infinite-field open-set theorem, and the examples already contain a conventional FFT.
- Orbit compression is coefficient sharing. Expanding all scalar Fourier values still requires charged evaluation; modular orbit identities do not prove complex stability.
- Energy pruning is approximate hard thresholding with an ideal-arithmetic error/work model. Small exact audits and numerical prototypes have different evidentiary roles.
- High-degree q-Weyl tails, finite tail prefixes, Green packets, graph reuse and structured digit products can be valid useful restricted constructions. Their residual full-degree, fresh-input, precision and bit costs remain.
- Small-arc/cyclotomic, cut-capacity, transverse-rank, symmetry and inverse-support gates constrain specified representations. Product, mixed-axis, conjugate-reconstruction and non-near-identity positive controls explicitly prevent broader conclusions.
- The stationary full-rank joint decoder collapses to a gauged Cooley-Tukey computation with ordinary O(N log N) work. Eliminating long Green scans does not eliminate the remaining short FFT layers.
- No reviewed source establishes a generic exact sub-NlogN FFT in a stated computational model. Correctness of a restricted construction and originality of that construction are separate questions; novelty was not established here.
