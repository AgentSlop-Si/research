# Portable independent replay

Requires Python 3.10 or later and its standard library only. From this directory:

    python independent_checks.py phase9_independent_results.json

The checker does not read, import or execute any source-uploaded file. Its first argument is the result JSON path. Compare that output byte-for-byte with `INDEPENDENT_RESULTS.json`. The source archive and static extracts are evidence only. Do not run their programs as part of this review replay.
