# Bounded-chirp certificate: independent audit and constructive extension

This standalone supplement contains the supplied research note unchanged, an independent audit of its original fixed-rank theorem, a polynomial-cost eliminant extension, and a scoped prior-art review.

## Start here

- `CHECKPOINT_ADDITION.md`: concise additive checkpoint and precise updated claims.
- `chirp_audit/AUDIT_REPORT.md`: original theorem audit, unchanged.
- `eliminant_extension/ELIMINANT_EXTENSION.md`: normalization, constructive proofs, degree/cost ledger, and implementation details.
- `prior_art/REVIEW.md`: unchanged focused literature review. This appendix also discusses a separate Fourier endpoint-rank theorem. That theorem's proof and experiments are outside this chirp supplement; their mention is context, not a claim that this archive reproduces them.

The historical test counts in the supplied note were not reproduced because the associated original programs were not supplied. The original independent audit and the new extension have separate programs, results, and scopes. No uploaded program was executed. The extension is supplied as standalone determinant/evaluation routines; it is not silently substituted into the preserved original recognizer.

## Portable verification and rerun

Requires Python 3.8 or later and its standard library; no external packages or network access.

    python3 verify_and_rerun.py

This first verifies every file hash, then copies the independent programs and their fixtures into a temporary directory and reruns both test suites there. It compares deterministic results with the recorded JSON, ignoring only the original audit's elapsed time. The sealed source/results are never overwritten. Progress and a final JSON report are printed.

For hashes only:

    python3 verify_and_rerun.py --verify-only

The two suites may also be run separately in disposable copies, following their respective instructions. `PACKAGE_VALIDATION.json` records the successful portable rerun used to prepare this package. `SHA256SUMS` covers every packaged file except itself; the sibling ZIP checksum seals the archive byte stream.

## Interpretation

For fixed r, the exact finite-field recognizer remains O_r(N); the extension replaces its factorial eliminant construction with proved polynomial-r bounds. The eliminant has degree at most D=binom(r+2,3), with nonzero constant term at the selected witness. Prime characteristics below D are supported. This does not give an unrestricted O(N) DFT, floating-point stability, an optimized FFT/NTT speed comparison, or a literature-wide novelty certification.
