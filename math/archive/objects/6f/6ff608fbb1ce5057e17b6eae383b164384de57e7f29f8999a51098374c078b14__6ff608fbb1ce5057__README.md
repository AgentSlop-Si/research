# Sparse-source bridge through exact target differences

The new sparse-surrogate material suggests keeping its original sparse source
unchanged at the expensive transform call. This package implements a stronger
exact compiler rule than the previous first-target anchor. It needs one ADD_T,
never evolves the source through K, and transports results through sparse
cross-bank additions of J. No clean workspace or zero initial target is needed.
It does not solve the fresh arbitrary-input exact FFT problem.

## One transform, sparse graph propagation

Assume T K = J T. In the project's q-Weyl instance, T=H_q(A), K=I+B, J=I+C,
including C's essential cyclic corner. The desired map is

    y_r <- y_r + T K^r x,  0<=r<R,

with all initial targets arbitrary and x restored. The legacy dirty workspace w
is never accessed and may be removed. Let h=R-1. Compile:

    for r=h,...,1:  y_r -= J y_(r-1)
    y_0 += T x
    for r=1,...,h:  y_r += J y_(r-1)

Each cross-bank update has distinct source and target banks. If the initial
targets are a_r, the descending pass leaves y_0=a_0 and
y_r=a_r-J a_(r-1). The one ADD_T produces a_0+Tx. Induction through the ascending
pass gives y_r=a_r+J^r Tx=a_r+T K^r x. This proves the map for every source and
every initial target. It also works for noninvertible J: no inverse of J or K
appears in this schedule. The global target-difference map is unit triangular.

At the shear level x is unchanged throughout. The existing elementary scalar
expansion temporarily scales a source register and restores it during each
shear; this preserves its support and restores x exactly. No call to K or K^-1
can expand the source before ADD_T.

## Exact sparse-source specialization

Given a support set S, compile only the columns indexed by S in ADD_T. For an
arbitrary source this implements the precisely defined map

    y_r <- y_r + T K^r P_S x,

where P_S is coordinate projection. If S is the known support of a sparse input
or a sampled surrogate, P_S x=x. There is no zero assumption on targets or
workspace. The audit checks every source coordinate, including coordinates
outside S, against this projected-source specification.

Since T[i,j]=t_(i-j) for i>=j, its selected-column ADD_T needs

    a(S)=sum_(j in S)(N-j)

shears. For dense S, a(S)=N(N+1)/2. The reference scalar model expands each
nonzero shear into two reversible source scalings and one addition, costing
three instructions. The real q-Weyl J has N cyclic edge entries and N-1 nonzero
diagonal entries, so cross-bank ADD_J needs exactly 2N-1 shears. The full online
cost is therefore

    3 a(S) + 2(R-1)(6N-3) scalar instructions.

This is O(N|S|+RN), including all R full outputs, rather than repeatedly paying
for the selected-column transform. For dense arbitrary x the reference anchor
still costs Theta(N^2). The prior first-target schedule cost
3N(N+1)/2+2(R-1)(14N-10); the new dense schedule saves exactly
2(R-1)(8N-7) scalar instructions for the same map.

All constants and addressing are explicit. The copied baseline prepares O(N)
constants using O(N) field operations, including exactly 2N-1 inversions of
input-independent constants in `prepare`, plus root construction/checking.
This is not O(1) inversions. The scalar expansion additionally prepares and
caches reciprocals of its O(N) distinct nonzero shear coefficients. This package
does not claim those inversions are free bit operations. Circuit emission and
its materialized storage cost
O(a(S)+RN), as does traversal. Supplied sparse support validation/sorting takes
O(|S| log(|S|+1)); discovering support from a dense array instead requires an
O(N) scan. The sampler's own input scan, random draws and coalescing must also be
charged when that sampler provides the source. These are algebraic operation
counts, not a native speed measurement or a floating-point stability guarantee.

## A second checked schedule

`terminal_anchor_word` moves the last target backward under J^-1, subtracts it
from preceding targets, applies ADD_T once to the original source, then walks
forward. This first improvement removes K/K^-1 calls and costs
3a(S)+2(R-1)(11N-7). It is correct, but `difference_word` is cheaper for the
current sparse J and avoids inverse operations altogether. Both are retained
and checked independently; the difference compiler is the result to use.

## Directed acyclic graph extension

The same construction applies to a topologically ordered target graph. Suppose
the desired increments satisfy z_v=b_v+sum_(u<v) J_(v,u) z_u. Descending target
indices, subtract each J_(v,u)y_u from y_v; add each injection b_v into its
target; then ascend target indices and add the same edge terms back. The result
is y_v <- a_v+z_v for every arbitrary initial target a_v. The target banks must
be disjoint and dimension-compatible with their edge maps. Each injection b_v
depends only on unchanged external source data, not on the evolving target
state. Each edge ADD and injection ADD must preserve its source data and
restore any borrowed scratch for arbitrary initial contents. With one injection
b_0=Tx and all others zero, the cost is one ADD_T plus two ADD_J calls per edge.
Multiple parents and paths are included by the recurrence; no mixed-path terms
are dropped. This is a triangular graph elimination rule, not a claim that
cyclic dependency graphs admit the same cheap schedule. Only the chain instance
is implemented and tested in this package.

## What sampling does and does not transfer

The compiler exactly transports whichever anchor increment is supplied. If that
increment differs from Tx by e, the rth target error is exactly J^r e. Hence

    max_(r<R) ||error_r||_infinity
       <= max_(r<R) ||J^r||_(infinity->infinity) ||e||_infinity.

The sparse-surrogate package proves a unitary-Fourier error bound. It does not
automatically prove the same bound for the nonunitary q-factorial T, nor does
the q-Weyl J preserve error norms. An exact transform of the sampled surrogate
is still approximate as an answer for the original dense input. Computing the
generic dense residual remains necessary for an exact answer.

For a separate norm-preserving instance, take T to be the unitary DFT and K a
cyclic input shift. Then J is diagonal with unit-modulus entries. A single
all-bin error event at the anchor implies the same error bound for every shift
in the batch, with no extra union bound over R. This is a composition of the
sampling guarantee with classical Fourier shift covariance, not a novelty claim
or an implementation of a new fast exact Fourier transform.

## Exact verification and files

Run `python run_audit.py` with the Python standard library. The suite checks both
schedules over primes 65537 and 998244353, N=2,4,8,16 and R=1,2,4. Supports include
dense, individual edge coordinates, a scattered set, and empty support.
Every source, dirty-workspace and target basis vector is checked, along with
arbitrary mixed states, emitted scalar instructions, inverse recovery and counts.

The run passes 120 cases, 3,900 complete full-register basis vectors and 360
random full states. Example dense scalar counts for the same orbit map:

| N | R | Previous first anchor | Target differences |
|---:|---:|---:|---:|
| 32 | 4 | 4,212 | 2,718 |
| 64 | 4 | 11,556 | 8,526 |
| 128 | 8 | 49,716 | 35,478 |

Sparse counts in `results.json` implement projected-source maps and must not be
presented as speed ratios for the dense-source problem. `prior_affine_reuse.py`
is an unchanged copy of the previous implementation; its SHA-256 is recorded.
`terminal_anchor.py` contains the new schedules, `run_audit.py` their independent
whole-state verifier, and `results.json` the captured output. No global novelty
is claimed for triangular elimination, Fourier shift covariance, or conjugating
an additive circuit; the contribution is the explicit improved project compiler
and its exact sparse-source integration.
