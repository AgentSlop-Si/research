# Phase 29 runbook

Only Python standard library is required. From this directory:

```bash
python -m unittest discover -s tests -v
python phase29_two_parameter.py --n 4
python phase29_two_parameter.py --n 8
python phase29_two_parameter.py --n 16
python phase29_macaulay.py
```

To independently rerun the alternate N=4 finite field:

```bash
PHASE28_PRIME=2013265921 PHASE28_GENERATOR=31 python phase29_macaulay.py
```

`phase29_macaulay.py` creates deterministic N=4 determinant witnesses. Full N=8 exhaustive audit is invoked by tests and in `exhaustive_anchor_audit(8)`. Certifying N=8 **does not** entail enumerating 8! squared complete mappings: three ordered row images and three ordered column images suffice.

The saved N=16 Bézout certificate can be verified rapidly without rebuilding the polynomials:

```python
import json
from phase29_two_parameter import validate
c=json.load(open('certificates/bezout_two_param_N16.json'))
assert validate(c)
```

Rebuilding the N=16 coefficients (rather than verifying them) requires a larger offline symbolic computation; it is not a per-input FFT cost.
