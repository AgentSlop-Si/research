# Fourier rank uncertainty and 11x9 gate collapse

**9 October 2026 · exact research continuation of the user's FFT project**

Two independent new results:

1. A **two-sided, all-length Fourier tail-rank obstruction** for an invertible two-stage quasiseparable factorization. For the last `t` output columns, with largest associated intermediate input index `a`, `r_C_down+r_B_up >= min(t, N-1-a)`. A corresponding mirrored result holds for first `t` output columns.
