# Research continuation: two-stage overlapping FFT gate

**Not a faster FFT.** This is a reproducible mathematical research checkpoint using exact finite-field arithmetic to study two-stage Fourier factorization with arbitrary endpoint and intermediate permutations. The user's original Green/gauge project is retained unchanged in `prior_checkpoint/`.

Read first: [`SESSION_HANDOFF.md`](SESSION_HANDOFF.md), then [`RESEARCH.md`](RESEARCH.md) (proofs and boundaries). The executed source and saved machine-readable certificates are included.

## Reproduce (Python 3.10+)

NumPy is needed for vectorized rank-profile search; basic matrix correctness, direct modular determinants and Green/gauge baseline use the standard library. Run from this directory:

```
python -m unittest discover -s tests -v
python two_stage_ct.py
python prime_gate.py
python rank_certificate.py
python cost_audit.py
python rank_profile_optimizer.py
python interval_gate.py
```

The rank-profile search is heuristic and may find a lower score on another run/platform. Its included saved permutation is the unambiguous identity for the exact N64 certificate. NTT experiments use primes `998244353` and `2013265921`; this does not substitute for analysis of floating-point numerical stability. Nonzero modular determinant of a Fourier cyclotomic minor **does** certify nonzero of the matching complex minor as explained in `RESEARCH.md`.

**Bottom line:** prime-size exact 2-stage rank barrier; power-of-two rank-gate escape demonstrated by a known Cooley–Tukey control; new multicut inequalities and independently verifiable certificate; **no** sub-`NlogN` arbitrary FFT.
