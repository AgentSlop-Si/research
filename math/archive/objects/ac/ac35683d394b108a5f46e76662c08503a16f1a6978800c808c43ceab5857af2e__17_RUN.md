# Reproduce Phase 23

Python 3.11+; standard library only for the Phase 23 new modules.

```bash
cd fft_green_phase23_real_resolvent
python -m unittest discover -s tests -v
python audit.py
python phase23_resolvent.py  # declarations; no CLI output
```

Demonstration:

```python
from phase23_resolvent import RealGreenFourier, adaptive_real_transform
N=1024
engine=RealGreenFourier.create(N)
x=[(7*pow(3,k,998244353)+5*pow(11,k,998244353))%998244353 for k in range(N)]
y, method=adaptive_real_transform(x,engine)
print(method) # green_rank_2; exact C_N*x in O(N) field work
```

`audit.py` independently enumerates all binary Hankel matrices through m=9 and checks `1/2` full-rank probability. It also audits random binary rank over the working prime field and rank-2 checks through N=8192. The automated tests independently implement radix-two NTT+Phase22 parity conversion as a reference, not a circular reuse of the same Green formula.

**Counting:** in the fixed prime-field model, preparing the angles and the seed costs O(N) field multiplications plus O(log p) modular exponent/square-root preparation. Applying a geometric resolvent costs O(N) field multiplications/additions plus a single batch inversion (O(log p) modular exponent). The rank<=2 recognizer also costs O(N). For arbitrary inputs the standard radix-two fallback costs O(N log N). Bit precision and stable complex floating point are not proved.

Cyclic difference demonstration:

```python
from phase23_resolvent import RealGreenFourier, adaptive_real_transform_structured
N=1024
engine=RealGreenFourier.create(N)
x=[7]*400+[12]*(N-400)  # two cyclic changes
y, method=adaptive_real_transform_structured(x,engine)
print(method)  # green_difference_r1; exact C_N*x in O(N) field operations

steps=[(7*k+31)%998244353 for k in range(N)]
y2, method2=adaptive_real_transform_structured(steps,engine)
print(method2)  # green_difference_r2
```

Random binary inputs almost never qualify for these low-complexity detectors.
The exact bound for N>=8 is `(N*(N-1)+34)/2**N` under the fair Bernoulli model.
The full dense input has to be read, and output costs O(N).
