# Explicit cycle geometry milestone

## Results

1. `EXPANDING_HAMILTONIAN_CYCLE_BANK.md`: Eight explicit Hamiltonian cycles for every dyadic size, with an all-balanced-cuts incoming-edge sum. At all N>=2^17, three eight-term Green layers have additive per-term common-subset cut budget greater than N/2. This is only a necessary-cut escape; it gives no Fourier coefficients, coefficient-compatible recursion, faster FFT, or novelty claim.
2. `FIXED_GF2_AFFINE_BANK_OBSTRUCTION.md`: A common parity cut excludes fixed-depth representations using any fixed finite bank of binary-affine-conjugated counter orders, with block-preserving endpoints and same-block banks, over characteristic zero.

## Reproduction

Use Python3. Both checkers use only the standard library and are newly authored. They import and execute no uploaded research source.

    python check_expanding_cycles.py
    python check_affine_bank.py

The first run took about26 seconds in the initial environment. It writes `CONTROL_RESULTS.json`; its captured output is `CONTROL_RUN.log`. The second writes `AFFINE_BANK_CONTROLS.json`; output is `AFFINE_BANK_RUN.log`.

The principal spectral input is the established Margulis–Gabber–Galil theorem, verified in the official AFP source linked in the proof. It is invoked, not reproved by these finite controls. The rectangular quotient, half-loss lemma, cycle totals, thresholds, and affine dimension argument are proved in the supplied notes.

The independent review lives separately in the reviewer's directory; its conclusions are not assumed by these notes.
