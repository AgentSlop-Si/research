# Hero #0 Phase 14 — Transverse-rank and expander compatibility

Read `THEOREMS.md` for the mathematics, and `CHAIN_HANDOFF.md` to continue without retracing dead ends. The main checked claim is **not** a faster Fourier transform: an explicit *linear-work*, all-cut-expanding two-layer Green network is nevertheless Fourier-incompatible for all coefficient choices, with a quantitative operator-error bound approaching 1.

## Files

- `transverse_green.py` — standalone weighted-permutation Green solvers, lifted Cartesian expander graphs, modular DFT blocks and exact rank tests.
- `weyl_gate.py` — independent linear-work randomized candidate check via Fourier's shift/modulation intertwining.
- `exact_audit.py` — generates `RESULTS.json`, checking full N=16 subset space, N=256 exact transverse ranks, N=4096 graph gate, and numerical flat singular values.
- `test_phase14.py` — deterministic regression suite; includes Gaussian-independent algebraic, modular, and numerical conditions.
- `numerical_weight_audit.py` and `NUMERICAL_AUDIT.json` — independent direct complex-matrix inverse test of the norm bound.
- `phase14_tests.log` and `inherited_phase13_tests.log` — 22 new and 21 inherited passing test methods.
- `prior_phase13_bundle.zip` — unchanged previous research package.
- `SHA256SUMS.json` — hashes for this research bundle's contents (excluding itself).

Run:

```bash
OPENBLAS_NUM_THREADS=1 python -m unittest -v test_phase14
OPENBLAS_NUM_THREADS=1 python exact_audit.py
python weyl_gate.py
```

Dependencies: Python 3, NumPy (tests and numerical audits). Arithmetic certificates use Python integer arithmetic modulo 65537.

**Claim scope:** Inputs arbitrary, but the impossibility concerns only the stated *input-independent two-axis-polarized circuit grammar*. It does not rule out the mixed-axis Phase 13 candidate, general circuits, or randomized data-dependent approximations.
