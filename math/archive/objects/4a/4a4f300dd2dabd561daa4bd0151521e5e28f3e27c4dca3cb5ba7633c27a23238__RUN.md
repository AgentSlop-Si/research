# Reproduction instructions — Phase 30

Tested on Linux, Python 3, and g++ 14. In the extracted archive, run commands from `fft_green_phase30_four_parameter/`.

```bash
python -m unittest discover -s tests -v
```

The standard suite reads the archived exhaustive rank records and *independently* verifies more than 400 sampled or boundary rank/determinant witnesses; it does not regenerate all 11,289,600 cases by default.

To reproduce the **entire** first-prime N8 and N16 native certificate:

```bash
g++ -O3 -std=c++17 fullminor_audit_generic.cpp -o phase30_audit
./phase30_audit certificates/four_green_input_N8_p998244353.bin phase30_ranks_N8.bin
./phase30_audit certificates/four_green_input_N16_p998244353.bin phase30_ranks_N16.bin
sha256sum phase30_ranks_N16.bin
# must equal f57c8b81adb0976bd5a3f5bf51d6701dcc897a6f7196d528f0fb3e23fcbc5e44
```

The first-prime N16 native audit runs approximately 2–4 minutes depending on CPU. For ranges, e.g. the first one million maps, pass `0 1000000` after the output filename. To reproduce the **second prime** N8 full audit:

```bash
g++ -O3 -std=c++17 -DPHASE30_MOD=2013265921 fullminor_audit_generic.cpp -o phase30_audit_p2
./phase30_audit_p2 certificates/four_green_input_N8_p2013265921.bin phase30_ranks_N8_p2.bin
```

For **original-row nonzero minor witnesses** on all N8 cases, use the separate native verifier:

```bash
g++ -O3 -std=c++17 fullminor_audit.cpp -o phase30_witness
./phase30_witness certificates/four_green_input_N8_p998244353.bin phase30_witnesses_N8.bin
```

The 21-byte witness record format is 1 rank byte (20), followed by 20 original degree-three Macaulay row positions, in lexicographic ordered-triple-pair order. Exact Python tests compute independent modular 20x20 determinants for selected records. The N16 full record is one rank byte per pair to keep the archive compact and reproducible.

The native planted positive-control matrices are in `certificates/planted_four_green_input_N8.bin`; the corresponding true row/column permutations are recorded in `planted_mapping_N8.json`. Running `phase30_witness` on this input must give one rank-19 case and 112895 rank-20 cases.

For five-term/Segre limitations:

```bash
python phase30_dimension_gate.py
```

Phase 29 predecessor archive is nested as `previous_full_phase29_checkpoint.zip` and its original code/tests may be extracted separately. All resource accounting refers to field arithmetic in these experiments; modular or floating-point operations are not being reinterpreted as constant bit-cost arbitrary-precision operations.
