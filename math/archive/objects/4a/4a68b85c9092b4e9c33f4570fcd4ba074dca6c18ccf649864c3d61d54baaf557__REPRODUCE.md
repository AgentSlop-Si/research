# Portable independent replay

Python 3.9 or later, standard library only; no network or constructor code required.

    python independent_checks.py n5-independent-replay.json
    python -c 'import json; assert json.load(open("n5-independent-replay.json")) == json.load(open("INDEPENDENT_RESULTS.json")); print("EXACT REPLAY PASS")'
    python compare_source_certificates.py n5-source-comparison.json
    python -c 'import json; assert json.load(open("n5-source-comparison.json")) == json.load(open("SOURCE_CERTIFICATE_COMPARISON.json")); print("SOURCE DATA REPLAY PASS")'
    python verify_seal.py

The first checker may be copied alone into an empty directory and reconstructs the complete result. The source-comparison program imports only our own checker and requires the saved source JSON data and our saved result. It executes no code from the source certificate package.
