**Date:** 2026-10-09

## Goal

Fresh arbitrary dense input, all `N` approximate unitary-DFT outputs, sequential work below `N log N`, no use of OpenAI #130/CrocSwap/Swapnil as the speedup primitive.

## Inherited v7 theorem contract

For dyadic `N=KM`, `K>=2M`, one random global quadratic-chirp row:

- is unbiased;
- costs `O(N+K log K)`;
- has exact worst-case per-output variance

  `sup_{||x||2=1} E|Xhat_m-X_m|^2 = 2M/N`.

This is a project theorem candidate, extensively checked but not peer reviewed.

## v8 result 1 — stabilized recurrence

For cycle `m_j=s+2aj mod N`, define

`A_j = exp(2 pi i [a j^2 + (beta+s)j]/N)`.

The original recurrence becomes, after `Z_j=Xhat_{m_j}/A_j`,

`Z_{j+1}=Z_j-F_{m_j}/A_j`.

Therefore both output cycles are exclusive prefix sums. Use a Blelloch balanced scan:

- `O(N)` work;
- `O(log N)` arithmetic depth;
- conditional accumulation bound `gamma_{O(log N)} sum |q_j|` instead of a serial `gamma_{Theta(N)}` path.

This is not yet a complete floating-point theorem because FFT, roots, summary formation, and range reduction remain to be bounded.

## v8 result 2 — exact online robust aggregation

For one real/imaginary scalar target `mu`, suppose a strict majority of rows lie in `[mu-tau,mu+tau]`.

Use three cell grids:

- width `W=7 tau`;
- offsets `0,W/3,2W/3`;
- Boyer--Moore candidate/counter on each grid.

Boundary spacing across all grids is `W/3>2tau`, so at least two grids put every good row in one cell. The median of the three candidate cell centers is within `5tau/2` of `mu`.

Only three candidate IDs and counters per scalar output are stored.

## Probability theorem

Set

`tau = g sqrt(2M/N) ||x||2`, `g>sqrt(2)`, `p=1/g^2`.

For `R` independent rows,

`Pr[ ||Xtilde-U_N x||inf > 5g sqrt(M/N)||x||2 ]`

`<= 2N exp(-R D(1/2 || 1/g^2))`.

Total resources:

- time `O(R[N+(N/M)log(N/M)])`;
- memory `O(N)`, independent of `R`.

## Two asymptotic regimes

### Fixed rows

For `R=2s-1`, `M=Theta(log N)`, constant failure:

- time `O(N)`;
- memory `O(N)`;
- error `O(sqrt(log N) N^{-1/2+1/(2s)} ||x||2)`.

### Growing rows

Let `L=log N`, `ell=log log N`, `1<=f=o(ell)`,

- `M=Theta(L/f)`;
- `g=L^epsilon`;
- `delta=N^{-a}`;
- `R=Theta((1+a)L/(epsilon ell))`.

Then

- time `O(((1+a)/epsilon)(f/ell) N log N)=o(N log N)`;
- memory `O(N)`;
- error

  `O(L^(1/2+epsilon)/sqrt(f) * ||x||2/sqrt(N))`

with probability at least `1-N^{-a}`.
