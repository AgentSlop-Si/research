# Replay

Requires Python 3.10+ and the standard library.

    python check_fourier_reconstruction.py --out-dir f5-reconstruction-replay
    cmp RECONSTRUCTION_RESULTS.json f5-reconstruction-replay/RECONSTRUCTION_RESULTS.json
    python verify_seal.py

The source/CERTIFICATE_INPUT.json file is required inert input. The checker never imports or executes a predecessor program. It writes only to the selected output directory. Portable replay copies the new checker and inert JSON into a fresh directory and compares deterministic results byte for byte.

The result supplements the unchanged, separately sealed three-Green B5 construction. It clarifies grammar-term count versus actual nontrivial Green work and verifies exact F5 reconstruction without an asymptotic performance claim.
