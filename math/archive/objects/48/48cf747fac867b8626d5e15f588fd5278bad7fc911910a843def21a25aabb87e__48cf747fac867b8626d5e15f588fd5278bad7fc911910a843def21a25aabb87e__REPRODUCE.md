# Portable reproduction

Requirements: Python 3.9 or later; standard library only; no network or third-party dependencies.

From this directory run:

    python independent_checks.py bank-interface-replay.json
    python -c 'import json; from pathlib import Path; assert json.loads(Path("bank-interface-replay.json").read_text()) == json.loads(Path("INDEPENDENT_RESULTS.json").read_text()); print("EXACT REPLAY PASS")'
    python verify_seal.py

The checker accepts the output path as its first optional argument, and otherwise writes beside itself. It has no dependency on an absolute workspace path. Input proof/source text is not executed. The verifier deliberately includes strict-threshold, row-only, column-only, total-sparsity, and larger-state controls.
