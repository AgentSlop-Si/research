# Phase19 — Full charged computation and model boundaries

## 1. Root-rich exact field arithmetic

Setup (once per length and modulus): primitive N-th root provided; N powers stored O(N), Green P and L weighted coefficients and cyclic solver coefficients O(N). Prime search, bit-size, arbitrary-precision modular arithmetic and complex rounding are NOT included in unit field-op costs. The fixed benchmarking modulus 2013265921 supports the tested lengths; it does **not** support an asymptotic sequence of arbitrary N without changing fields.

Every FFT invocation computes fresh `r=Px` (2N field products + N additions) and a fresh final solve `Ly=Fr` (approximately 3N+1 field products + 2N additions). No previous-input transform is cached.

## 2. Unknown cyclic shift, one defect

Input inspection: N zero checks; adjacent projective-ratio classification O(N) (at most two multiplications per cross product); at most two candidate shifts generated from class-count modular inverses; 3-edge majority per candidate; at most two certified graph-defect scans O(N) total. Fourier forcing: K=1 geometric stream O(N), spectral denominator stream O(N), one batch inversion O(N) and one field inverse. Singular K=0 Fourier character uses one direct O(N) repair.

The candidate delay is never an oracle. The algorithm does not try N delays, only the at-most-two mathematically certified candidates. Complete correctness check is distinct from fingerprinting. The finite-field exact runtime is O(N) for all detected K<=1 models, with O(N) failed discovery plus O(N log N) fallback on other inputs.

## 3. Ratio-class graph discovery for fixed K>1

For K defect edges with no numerical collision between opposite wrap classes: at most `B=2K^2` adjacent-ratio classes. Classify N ratios in at most 2BN field multiplies. Enumerate at most 2^B subset counts using integer operations; for each coprime candidate u perform extended-Euclid inverse mod N, 2K+1 projective majority tests, and a complete graph verification (stopping after K+1 defects if invalid). Worst-case finite arithmetic O(N * (K^2 + K*2^(2K^2))) for the detector; O(NK) or O(N log(K+1)+K log²(K+1)) forcing after acceptance.

For fixed K this is O(N). For K growing, the constant is potentially prohibitive; no uniform fast result is claimed. Cross-wrap collisions can make an eligible shift undiscoverable by this method; exact fallback is mandatory.

## 4. Sparse circular inverse, support bounded by s

- Directly compute 2s Fourier probes: 2s * N input field products and 2s*N additions; ordinary Fourier-dot power updates cost another 2s*N products in the instrumented direct reference. Total O(sN), not an uncharged oracular DFT.
- Batch inverse these samples: O(s) field products, one field inverse.
- Berlekamp–Massey: O(s²) field operations including inversions.
- Enumerate all N primitive-root powers against recovered degree <=s characteristic polynomial: O(Ns) field products and additions. No general polynomial factoring or discrete logs.
- Solve an s-by-s modular Vandermonde linear system: O(s³) operations and charged pivots/inverses.
- **Mandatory complete cyclic convolution certificate** at all N coordinates: O(Ns). A failed candidate is never accepted based only on first 2s samples.
- Evaluate sparse C on every Fourier root via s complete geometric streams: O(Ns).
- Batch invert the N output denominators: O(N) products, one field inverse. Successful certificate guarantees none is zero.
- Green P and L charged as above.

Total O(Ns+s³), or O(N) when s is a fixed constant. If C is not recovered or fully certified, append the ordinary O(N log N) Bluestein fallback; the worst-case bound of the all-input algorithm is O(Ns+s³+N log N).

When `s=O(log log N)` (and s<=N/2), the *promised inverse-sparse family* has O(N log log N) field arithmetic; that is still NOT an all-input bound, and its bit costs and numerical stability are not established.

Python container/loop overhead and memory traffic are NOT wall-clock speed. Modular field inversion counts as one field inverse in this exact arithmetic model; bit-level inversion grows with modulus size.

## 6. Numerical and theoretical rejection gates

Generic complex r has dense circulant inverse: its inverse-sparse locus has algebraic dimension <=s among N complex coordinates (for s<N), even with adaptive unknown supports. Numerically, clustered root nodes give Vandermonde matrices with condition numbers growing at least Theta(N) already for two nearby N-th roots. A floating-point implementation cannot rely on exact zero comparisons, and no stable complex inverse-sparse implementation has been proved. Any claim of exact arbitrary-input `o(N log N)` FFT still needs a substantially new argument.
