# Reproduce this independent review

Run only the independently authored `independent_checks.py` in this directory, using Python with SymPy and NumPy available. The supplied research programs are preserved as source data and are not imported or executed by this checker.

All file inputs required by the checker are included inside this directory. Originals, extracted data, and the immutable prior-Phase8 comparison copies retain their relative layout. `SOURCE_IDENTITIES.json` maps originals to Library IDs and hashes. The checker writes `INDEPENDENT_RESULTS.json`; numerical SVD error magnitudes can vary slightly by numerical-library build and are tolerance controls, not exact proof claims.

The outer seal covers all originals, extracted files, independent test material, source identities, and reports. It excludes itself and `SHA256SUMS.txt` to avoid self-reference. Do not overwrite this sealed checkpoint when continuing the research; create a new sibling checkpoint.
