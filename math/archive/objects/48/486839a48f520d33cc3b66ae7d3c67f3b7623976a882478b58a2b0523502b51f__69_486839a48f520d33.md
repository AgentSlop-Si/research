# Exact binary phase states: a restricted graph audit

This audit asks a specific question: can an exact Fourier graph, or its correction to a Walsh graph, be compressed into a chain of a constant number of linear phase states while combining many FFT layers? The answer is no for the paired-bit chain defined below. This is **not** a lower bound on general FFT arithmetic circuits and is not a claim that high rank implies slow evaluation.

## Representation and exact composition

Let N = 2^L, let w be a primitive N-th root in a field, and write the input index as j = sum_r j_r 2^r. Reverse the output bits: k = rev_L(b), where b = sum_t b_t 2^t. The unnormalized Fourier kernel is

    F[j,b] = w^(j rev_L(b))
           = product_(0 <= r <= t < L) exp(2 pi i j_r b_t / 2^(t-r+1))

over the complex numbers. The equivalent root-power expression applies over any field with a primitive N-th root.

Cut after s paired sites (j_r,b_r), with q = L-s. Write j = a + 2^s d and b = e + 2^s f. Then

    F[j,b] = A_s[a,e] B_q[d,f] V_s[a,rev_q(f)],
    A_s[a,e] = w^(2^q a rev_s(e)),
    B_q[d,f] = w^(2^s d rev_q(f)),
    V_s[a,c] = w^(a c).

The omitted term in j rev_L(b) is N d rev_s(e), whose root power equals one. This proves exact composition for every input; all mixed phases are retained.

The unfolding has rows (a,e) and columns (d,f), so its dimensions are 4^s by 4^q. Both the input and output site indices are retained. Scaling each row by A_s[a,e]^-1 and each column by B_q[d,f]^-1 reduces it to V_s with duplicate rows in e and duplicate columns in d. Therefore its rank equals the rank of V_s.

## All-size phase-state theorem

Let r = min(2^s, 2^q). The leading r by r submatrix of V_s is Vandermonde on the distinct points 1,w,...,w^(r-1). Its determinant is

    product_(0 <= i < j < r) (w^j - w^i),

which is nonzero. Thus the unfolding rank is exactly 2^min(s,L-s).

For a chain representation

    F[j,b] = M_0[j_0,b_0] ... M_(L-1)[j_(L-1),b_(L-1)],

with scalar boundary dimensions and an internal linear state dimension chi_s, every unfolding factors through that state. Consequently chi_s >= 2^min(s,L-s). At a balanced cut the required dimension is 2^floor(L/2), approximately sqrt(N). This excludes bounded-width exact linear phase-state merging in this order. It does not cover arbitrary graph topology, nonlinear encodings, alternative models of arithmetic, or every possible bit ordering.

The phase states still have a short description and a simple transition:

    phi_a(c) = w^(a c),
    phi_(a + u 2^s)(c) = phi_a(c) w^(u 2^s c), u in {0,1}.

A shared description of these states does not make the states linearly identical. Applying a cached-reference subtraction to the state vectors must retain their independent differences.

## Subtracting the Walsh core

Use the paired-bit Walsh kernel H[j,b] = (-1)^popcount(j & b). It factors into one left vector and one right vector at each cut, so its unfolding rank is one. For E = F-H the general rank-one perturbation bound is

    r-1 <= rank(E unfolded at s) <= r+1.

There is a stronger statement for every interior cut s >= 2 and q >= 2:

    rank(E unfolded at s) = r+1.

Proof: after the same invertible row and column scalings, Fourier is the duplicated V_s and Walsh is the outer product u[a,e] v[d,f], where u = H_s/A_s and v = H_q/B_q. Every vector in the column space of duplicated V_s is constant in e at fixed a. But u is not: for a=1, its entries at e=0 and e=2^(s-1) are 1 and w_2^s^-1, respectively, where w_2^s = w^(2^q). These are unequal. Similarly every Fourier row-space vector is constant in d at fixed f; at f=2^(q-1), v takes the unequal values 1 and w_2^q^-1 for d=0 and d=1. Thus u lies outside the Fourier column space and v outside its row space. A rank-one update with both properties increases rank by exactly one. The argument works in characteristic zero and in the tested odd prime fields.

This correction-state rank differs from the ordinary N by N matrix rank of F-H audited earlier. They answer different architectural questions. Subtracting Walsh does not open a constant-width chain compression loophole here; it actually increases the interior chain rank by one.

## Cost interpretation

The proof counts exact independent linear states, not scalar arithmetic operations. A minimal-rank dense matrix-product-operator description can still occupy O(N) scalar entries: the sum of adjacent bond products is O(N). Description size alone is insufficient.

A straightforward dense-core contraction against an arbitrary N-entry input maintains an intermediate tensor indexed by output prefix, remaining input suffix, and bond. It has N chi_s entries. Such a sweep uses O(N sum_s chi_(s-1) chi_s) scalar work, which is Theta(N^2) for the minimal Fourier rank profile, and as many as Theta(N sqrt(N)) intermediate entries near the middle. Those are costs of this straightforward dense contraction, **not unavoidable costs of every implementation**. Core sparsity, different contraction orders, or new factorizations can change the cost; the ordinary FFT already exploits special structure to do much better.

No scalar preparation, root generation, indexing, output reconstruction, or approximation is being offered for free. This package does not implement a candidate faster FFT, so no runtime speedup is claimed.

## Verification

Run `python verify_phase_states.py`. The standard-library-only program performs:

- 30 complete paired-bit unfolding checks: every nontrivial cut for N = 4,8,16,32,64, over primes 65537 and 998244353. Every entry is checked against the exact composition, and Fourier/correction ranks are checked.
- 90 cross-phase matrix checks: every nontrivial cut for N = 4 through 1024 over the same two primes. Full modular rank is checked, and an independent Gaussian determinant is compared with the explicit Vandermonde product for the leading square minor.
- Exact prefix-state transition checks throughout those cross-phase cases.

All checks passed. `results.json` records every rank and minor determinant. These are algebraic verification sizes, not scaling benchmarks. The proofs above establish the stated all-size results; experiments only check their implementation.

## Prior art and novelty limit

These Fourier tensor-network and low-entanglement connections are established research, not a new general theorem claimed by this package. Relevant primary sources retrieved during this audit:

- Jielun Chen, E. M. Stoudenmire, Steven R. White, *Quantum Fourier Transform Has Small Entanglement*, https://arxiv.org/abs/2210.08468 and https://link.aps.org/doi/10.1103/PRXQuantum.4.040318 . Their stated classical application uses low-bond input representations; operator compressibility relies on decaying Schmidt coefficients, not zero exact coefficients.
- Jielun Chen, Michael Lindsey, *Direct interpolative construction of the discrete Fourier transform as a matrix product operator*, https://arxiv.org/abs/2404.03182 . Their abstract explicitly describes compression error guarantees for a chosen rank.

This package contributes a project-specific exact audit, including the Walsh-correction interior-cut rank calculation, rather than claiming that the Fourier operator-rank fact is novel. Approximate compression and structured inputs remain useful separate settings, but do not satisfy the present fresh arbitrary-input exact target.
