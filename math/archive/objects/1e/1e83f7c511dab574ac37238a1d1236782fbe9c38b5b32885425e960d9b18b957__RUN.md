# Phase16 fresh reproducibility instructions

Run in any modern Python with numpy installed. For deterministic floating-point tests, a single BLAS thread is preferable. Exact Fourier coefficients are checked via the independently calculated complex root-of-unity matrix; the previous Phase15 archive includes exact finite-field tests.

```bash
cd fft_green_phase16_entropy_fusion
OPENBLAS_NUM_THREADS=1 PYTHONPATH=. python -m unittest discover -s tests -v
OPENBLAS_NUM_THREADS=1 python entropy_gate_audit.py
OPENBLAS_NUM_THREADS=1 python component_entropy.py
OPENBLAS_NUM_THREADS=1 python green_givens_compiler.py
OPENBLAS_NUM_THREADS=1 python haar_green_givens.py
OPENBLAS_NUM_THREADS=1 python haar_entropy.py
```

To check the full 55-test old+new regression, extract `previous_full_phase15_checkpoint.zip` to a temporary directory and run the phase 12, 13, 14, 15 test suites with their directories on `PYTHONPATH`, then the Phase16 tests. The local creation run checked all 45 inherited tests and all 10 new tests.

`entropy_gate_audit.py` verifies **every output matrix entry** through N512 to roughly 1.6e-14, in addition to independent per-gate entropy increments. `green_givens_compiler.py` numerically uses dense initial coefficient matrices for *audit purposes only*; mathematical gate existence is proved independently by rank-one Green-factor structure. Nothing in the audit alone establishes O(N) charged parameter precomputation, faster-than-FFT execution, or finite-bit stability.
