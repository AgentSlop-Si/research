# Joint q_h dependence with a growing channel radix

This continuation examines an explicit cross-channel batching identity, its fully charged application schedule, and the exact restriction of the orbit-gauge architecture. It does not exclude arbitrary cross-channel algorithms.

## 1. Joint channel Fourier routing identity

Let M=bm with b dividing M. Group

    h=d+c m,   0<=d<m, 0<=c<b,
    zeta=eta^m,   q_h=q_d zeta^(-c).

For the geometric forward bank,

    C[t,d,c]=sum_j q_d^(tj) zeta^(-ctj) B[j,d,c].

Apply a length-b negative-sign Fourier transform in c on both sides. With hats denoting that transform,

    Chat[t,d,ell]
      =sum_j q_d^(tj) Bhat[j,d,ell+tj mod b].

Thus the entire oscillating c dependence can be converted into exact sheared routing in the channel-Fourier index ell. There is no approximation or input promise. The input and output c transforms, their normalization, and routing are charged.

Split t=r+b a and j=s+b v, with 0<=r,s<b and 0<=a,v<m. Then

    Chat[r+b a,d,ell]
      =sum_s q_d^(rs) (q_d^b)^(sa)
         sum_v (q_d^(b^2))^(av)
               (q_d^b)^(rv) Bhat[s+b v,d,ell+rs].

For each fixed d,r,s,ell the inner sum is a length-m geometric Vandermonde application with diagonal input/output weights. The smaller node is itself canonical-square type:

    Omega=omega^(b^2),   eta'=Omega^m=eta^b,
    q_d^(b^2)=Omega (eta')^(-bd).

It has order m^2. There are m/gcd(b,m) distinct smaller node values among d=0,...,m-1; their coefficient tables can be shared. The independent input vectors still differ.

## 2. Complete growing-radix ledger for this schedule

Let exact length-r geometric convolution-based multiplication cost O(r(1+log r)), using supplied smooth convolution roots. The schedule above has:

- Input and output length-b channel Fourier banks: O(N log b) arithmetic with ordinary FFT primitives, O(N) entries read/written per bank. Suitable roots and plans are charged.
- d,r,s,ell combinations: m*b^3=M b^2 geometric applications, each length m. Their total data volume is N b, not N.
- Input diagonal products, output diagonal products, routed gathers and sum_s accumulations: O(N b) operations/accesses. Stream the blocks to keep O(N) working words; storing every expanded input is unnecessary.
- Geometric input-dependent work: O(N b(1+log m)).
- Root/power preparation: a length-N omega table takes O(N). The input weights indexed by (d,r,v) need m*b*m=N/b entries, the output weights need N/b, and q_d^(rs) needs m*b^2=M b<=N. Thus shared coefficient generation is O(N), even for growing b.
- Smaller geometric-kernel tables may be shared across the m/gcd(b,m) distinct nodes; their total coefficient size is O(m^2/gcd(b,m)), and their charged FFT preparation is at most O(m^2(1+log m)/gcd(b,m)). This reduces preparation, not the N b expanded data applications.

Consequently this explicit shared-radix application costs

    O(N [log b+b(1+log(M/b))])

with O(N) working words and O(N) elementary coefficient preparation. For the displayed FFT schedule the corresponding nonzero data work has the same order (apart from trivial length-one primitives). Since

    log b+b(1+log(M/b)) >= 1+log M,

no growing choice of b saves an asymptotic factor against the original O(N log M) geometric bank in this schedule. At b=M the smaller transforms have length one but the sheared gather/accumulate expands to NM terms. At b=1 one recovers the ordinary channel-local geometric-convolution bank. This is an exact accounting result for the displayed schedule, not a lower bound for every possible way to evaluate the routed sum.

Coefficient reuse is real and explicitly paid for. Treating every equal smaller node as one application would be incorrect: its inputs differ in (r,s,ell), often by input-dependent data and diagonal modulation. Any further saving needs a new joint evaluator of these correlated modulated vectors, not merely a cached kernel.

## 2A. Growing radix in the full inverse/product convolution bank

The inverse from milestone 1 has two convolution banks with q-factorial diagonals between them; the M-step product is itself one twisted two-dimensional convolution bank. Once these banks are compiled using ordinary FFT primitives, a growing radix changes their routing overhead but does not remove the logarithm in their input-dependent arithmetic.

For clarity take a square M-by-M joint FFT, or the M-by-2M padded grid with its harmless final factor two. A radix b dividing M splits both dimensions and gives b^2 subproblems of side M/b. If the small length-b transforms themselves use ordinary FFTs, the actual recurrence is

    T_b(M)=b^2 T_b(M/b)+Theta(M^2 log b).

The term includes both axes' small transforms, twiddles, and their nonzero data arithmetic. It solves to Theta(M^2 log M). More generally let varying radices b_1,...,b_s have product M. The small-transform work sums to

    Theta(N sum_i log b_i)=Theta(N log M).

The phase and root tables can be shared: O(N) root powers cover every level, and per-level routing/twiddles cost O(N), for O(Ns) total overhead. Choosing a larger radix can reduce this O(Ns) overhead, but the summed small-transform work remains Theta(N log M).

If each small DFT is performed directly instead, its b^2 matrix entries act on each arbitrary fresh b-vector. One level costs Theta(Nb), and a constant chosen radix gives

    Theta(N b log_b M)=Theta(N log M * b/log b).

This becomes worse for a growing b. Preparing a small Fourier matrix once and reusing its coefficients does not compute its products with different input vectors for free.

All q-factorial and product coefficient tables can be prepared in O(N) as established in iteration 2. Pointwise diagonals cost O(N) in spectral h coordinates. If one moves these diagonal maps to raw u coordinates, each becomes a cyclic convolution on its row and that application must also be charged; its O(N) coefficient table is not a free application oracle. Thus this analysis covers the actual inverse/product bank using the displayed standard convolution schedule, rather than only the forward geometric bank. It leaves open a genuinely new batched-small-transform primitive or a different raw factorization; neither is supplied merely by growing the radix.

## 3. Exact orbit-gauge cancellation restriction

Let R be the raw M-point row-Fourier bank producing C, let V be block diagonal with blocks V_h, and let A be block diagonal with blocks

    A_h=F_M diag(omega^(-ht)).

The entire universal orbit route has the form

    raw x -> C=R x -> B=V^(-1) C -> output Pi A V B.

For arbitrary input,

    Pi A V V^(-1) R=Pi A R.

This cancellation is exact for every invertible choice of intermediate channel basis, not just the canonical q_h Vandermondes. Replacing their coefficient preparation or using larger channel batches does not change the identity. If a proposed algorithm still explicitly executes R and A using ordinary short-FFT banks, those two banks alone cost Theta(N log M), even if all intermediate orbit work were free.

This is the precise restriction: improvements confined to inserting, recovering, and undoing a channelwise basis between otherwise unchanged raw/output Fourier banks cannot establish the desired sub-N-log-N evaluator. It does not say that every circuit for Pi A R has to use those banks or that a novel cross-channel factorization must have the same cost.

## 4. A genuinely different concrete operator family

A next search should change the raw-coordinate operator rather than insert another channel basis. One available O(N)-apply primitive is the nonseparable directed-grid Green solve

    G(a,b)=(I-D_a L_t-D_b L_u)^(-1),

where t,u lie on an M-by-M grid, L_t and L_u are one-step shifts with zero boundary, and the masks a[t,u], b[t,u] are prepared and charged. In row-major order this denominator is unit lower triangular. Each G applies exactly in O(N) operations by

    y[t,u]=x[t,u]+a[t,u]y[t-1,u]+b[t,u]y[t,u-1].

A pure fixed product of these primitives, diagonals, and permutations is already excluded at growing N: each inverse row has at most three nonzeros, so k such stages give inverse row support at most 3^k, whereas F_N^-1 is dense. This inherited obstruction must not be rediscovered as a promising candidate.

The genuinely different proposed family is instead a fixed product of sums of two independently routed grid Green solves, for example

    H_l = D_(l,0) P_(l,0) G(a_(l,0),b_(l,0)) Q_(l,0) E_(l,0)
        + D_(l,1) P_(l,1) G(a_(l,1),b_(l,1)) Q_(l,1) E_(l,1),
    candidate = H_2 H_1  (or three such factors).

Every diagonal, permutation, mask, sum, and solve costs O(N) to apply. For a fixed number of factors the candidate has O(N) words of parameters and O(N) application work, if and only if parameter/permutation synthesis is itself explicitly supplied and charged. The component solves have no singular branch because their denominators are unit triangular. The sum H_l can be singular, so exact Fourier equality/invertibility must still be verified. Its inverse is generally dense; the preceding three-sparse inverse-product bound does not transfer to the sum.

Unlike a channelwise Vandermonde gauge, generic independently routed masks couple both coordinates and do not cancel algebraically to a fixed short-DFT bank. The existing additive separator limitations still matter for one sum; a product must use genuinely different intermediate routing to escape their stated scope.

A tractable first target is whether two or three such sums satisfy the exact Fourier Weyl intertwining identities and one scalar calibration at M=2,3,4, followed by a symbolic scalable parameter pattern if a valid point appears. Failure of a finite search would not be an unrestricted exclusion. This is a specified next construction family, not a claimed factorization, novelty claim, or speedup.
