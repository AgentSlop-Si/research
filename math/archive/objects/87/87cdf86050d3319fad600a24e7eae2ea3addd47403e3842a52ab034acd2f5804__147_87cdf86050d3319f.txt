Fourier research updates: independent three-archive audit
9 October 2026

Start with SUMMARY.md. The main positive result is the shrinking-error O(N)
model-specific approximation proof in v4/SHRINKING_ERROR_THEOREM.md. Its error
is coordinatewise, not whole-vector l2-relative or ordinary FFT precision.

The macro checkpoint adds eager prepacked implementation components and a
restricted exact affine-input fast path. The Green checkpoint adds scoped
obstructions and an exact FFT-disguise negative control. This research does not achieve the user’s exact
sub-N log N Fourier target in its stated model. Novelty and practical advantage are
not established. See PRUNED_BASELINE.md before comparing the second v4 point
against only a full ordinary FFT.

Portable independent checks, Python 3 standard library only:
  python v4/independent_checks.py
  python macro/check_checkpoint.py
  python macro/exact/independent_checks.py
  python green/check_green_independent.py
  python green/check_f8_endpoint_order.py
  python green/check_spectral_condition.py

All these checkers were independently authored. They do not import or execute
uploaded Python. They write local JSON reports beside themselves. The only
uploaded data fixture is v4/source_v4_results.json, used for static summary and
parameter-consistency checks. It is not a claim that the uploaded experiment
was independently rerun. Other saved JSON reports preserve completed checks.

The optional source/provenance modes described in the sub-audit READMEs need
the original identified source directories, which are not bundled. Default
mathematical checks run without them. No raw ZIPs or uploaded executables are
included. SOURCE_INDEX.json records archive IDs and hashes.

Independent finite tests support the stated algebra, arithmetic identities,
and certificates. Uniform complexity and probability statements rest on the
accompanying mathematical proofs, not numerical timing or finite tests.
