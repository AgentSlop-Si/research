9 October 2026

This package combines the distinct research routes in the recovered October 8–9 corpus with all four newest uploads. The outcome is a stronger approximate/structured transform analysis and three precise exclusions of proposed exact architectures. It does not contain a new exact arbitrary-input Fourier algorithm or a literature-wide novelty claim.

## What is established here

The v6 scheduling change is valid. Its generic result remains approximate, with error measured against global input energy. Our spectral-tail extension connects that result to its structured exact case without asking the algorithm to know the large spectral entries. A periodic mean can remove an inexpensive exact component before sketching. These are mathematical improvements to the analysis and composition; no optimized-runtime win or bounded-word implementation is claimed.

The new exact obstructions have different scopes. Haar–Green's bound is a stage-count statement. The rational-degree and single-solve bounds constrain the entire fused representation and permit arbitrary nonsingular endpoint monomials. Neither is a general lower bound against all Fourier algorithms.

The complete record also includes an existing external exact-arithmetic baseline: the official OpenAI #130 summary states a uniform exact sub-N-log-N algorithm with unrestricted exact complex coefficients and a supplied root. That result is not ours, and it does not by itself supply practical, stable, finite-word FFT performance. See the evidence map for the precise distinction and source.

## Reproduction

Requires Python 3 and NumPy for the numerical checks. The whole-word checker and Haar split checker use standard-library exact arithmetic. All executable files in this deliverable were independently authored during this pass; uploaded executables were neither imported nor run.

Run from this package directory:

    python3 independent_phase13_checks.py
    python3 verify_haar_split.py
    (cd frequency && python3 independent_tests.py && python3 covariance_probe.py && python3 exact_covariance_witness.py)
    (cd whole_word && python3 check_whole_word.py)

The JSON outputs distinguish numerical consistency checks from exact modular/rational certificates. The all-size theorems are proved in the accompanying text; tests do not replace those proofs. No timings here establish superiority over optimized FFT implementations.
