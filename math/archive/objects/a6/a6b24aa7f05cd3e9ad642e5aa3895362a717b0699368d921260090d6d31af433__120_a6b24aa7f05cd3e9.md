# A fully charged O(N) approximate sparse Fourier decoder

The checkpoint's proposed packed transposition is unnecessary. Store each
quantized group-average coordinate in a nonnegative bit field with enough guard
bits for G groups. Add the packed table rows with ordinary word additions, then
extract each output once. No field overflows into its neighbor.

For fixed accuracy and K=O(log N) equal-weight signed/imaginary samples, the
result computes all N approximate sample Fourier means in O(N) bounded-word
operations **including complete cold table construction**. The detailed proof
is in `THEOREM.md`. The root package supplies the dense-input sampler and the
integrated additive-error guarantee.

This is an approximate additive-error word-RAM result. It does not beat the
exact arbitrary-input FFT goal. No practical runtime speedup or novelty claim
is made. The asymptotic table schedule begins only at large N; the finite audit
uses manageable explicit parameters and fully materializes every table row.

## Reproduce

Run `python run_audit.py` in this directory. No third-party package is required.
The resulting `results.json` records source hash, 25 sample-list decodes over
five complete-table configurations, 1,860 output comparisons, independent scalar
unpacking comparisons, four phasor-precision checks, and the asymptotic planner.
The test with 1,000 samples and 80 lanes forces multiple words per packed row.

## API

```python
from guarded_decoder import decode_samples

result = decode_samples(
    N=257,
    samples=[(0, 0), (7, 1), (96, 3), (256, 2)],
    block_size=4,
    phase_grid=64,
    slope_grid=256,
    group_size=1,
    lane_step_bits=5,
    trig_bits=24,
    table_mode="eager",
)
```

Phases 0,1,2,3 denote +1,+i,-1,-i. The negative Fourier exponent is used.
Each `integer_outputs[m]` pair divided by `denominator` is the explicit rational
complex output; `values` is an auxiliary Python complex conversion. Multiply by
the upstream `L_box/sqrt(N)` only with that scaling cost and rounding accounted
for. The deterministic normalized decoder error is returned in `error_bound`.

The eager constructor enumerates all keys and has a default explicit cap of
1,000,000 table rows to prevent accidental huge research runs. The separate
lazy option is a functional demonstrator, not evidence for cold construction.
`asymptotic_parameters` exposes the theoretical tuning and returns `None` in
its finite base regime. A directly evaluated certified transform handles that
base regime in the proof; this module is not an optimized full production
driver for every theoretical N.

Trigonometric setup is implemented with integer Machin and Taylor arithmetic,
not a unit-cost sine/cosine oracle. Every explicitly instrumented arithmetic
operand and result must fit in one chosen machine word. Counters describe
selected word arithmetic and memory operations; loop/control overhead is
charged asymptotically in the proof, not hidden by claiming Python timings.
