# Phase 32 — Exact partial Fourier synthesis with independently ordered Green resolvents

**Date:** 10 October 2026  
**Status:** New project-specific constructive algebraic theorem, exact finite-field implementation, and independently checked finite tests. **NOT a new general-input `o(N log N)` FFT, nor an independently reviewed priority claim.**

## 1. The synthesis problem

Let `N ≥ q ≥ 1`, let `W_0,...,W_(q-1)` be **arbitrary Hamiltonian-cycle permutation matrices** on `N` coordinates (they need not commute, need not be affine, and may all have different cyclic orders). Set

\[
G_s(\alpha_s)=(I-\alpha_sW_s)^{-1},\qquad \alpha_s\ne0,\quad \alpha_s^N\ne1.
\]

We allow **nonzero output-diagonal gauges** `L_s=diag(u_(0,s),...,u_(N-1,s))` and form

\[
M=\sum_{s=0}^{q-1}L_sG_s(\alpha_s).
\]

For a prescribed set of exactly `q` different input coordinates `J={j_0,...,j_(q-1)}`, can we force the *entire N×q restriction* of `M` to agree with the corresponding Fourier columns, while preserving an O(qN)-work application algorithm?

### Theorem A: exact q-column interpolation for arbitrary Hamiltonian orderings

Let `T` be any target `N×N` complex matrix whose entries `T[i,j]` for `j∈J` are **nonzero**. For a nonempty Zariski-open set of parameter vectors `(α_0,...,α_(q-1))`, each `G_s` exists and there are **unique nonzero diagonal gauges** `L_s` such that

\[
\boxed{\left(\sum_{s=0}^{q-1}L_sG_s\right)_{:,J}=T_{:,J}.}
\]

In particular take `T=F_N=(ω^(ij))_(i,j)` (or use the inverse sign convention): **q independently ordered Green solves can reproduce any q complete Fourier basis responses exactly**, using only output-diagonal gates. Each Green solve is a linear-work cyclic recurrence.

This is a partial-input-class construction; it does not yet compute the other `N-q` Fourier columns.

## 2. Proof — a generalized Vandermonde mechanism

Write a Hamiltonian cycle as `v_0→v_1→...→v_(N-1)→v_0`. Let `d_s(i,j)` be the unique exponent in `{0,...,N-1}` for which `(W_s^d)_(i,j)=1`. Since `W_s^N=I`, the exact Green matrix entry is

\[
\boxed{G_s[i,j]=\frac{\alpha_s^{d_s(i,j)}}{1-\alpha_s^N}.}
\]

For a fixed output row `i`, define the `q×q` response matrix

\[
E_i[\ell,s]=G_s[i,j_\ell].
\]

Multiplying each of its columns by `1−α_s^N`, its determinant becomes

\[
P_i(\alpha)=\sum_{\sigma\in S_q}\operatorname{sgn}(\sigma)
 \prod_{s=0}^{q-1}\alpha_s^{d_s(i,j_{\sigma(s)})}.
\]

**All displayed monomials are distinct.** If two assignments differ, then at least one fixed `s` receives a different selected input column. Every Hamiltonian cycle assigns a distinct distance to distinct input columns, so the exponent of that variable `α_s` differs. Hence `P_i` is a nonzero polynomial over characteristic zero.

The product of all `P_i` is nonzero. Therefore we can choose couplings making **every** `E_i` invertible simultaneously. We then solve the independent row systems

\[
E_i u_i=(T[i,j_0],...,T[i,j_{q-1}])^T.
\]

We must also prove each diagonal gauge coefficient `u_(i,s)` is nonzero. By Cramer's rule, its numerator is a determinant in which the `s`th column of `E_i` is replaced with the target vector. After clearing the remaining denominator factors, the determinant expansion again has distinct exponent tuples in the `q−1` remaining variables. Its coefficients are ±one of the **nonzero** target entries. Thus this numerator is a nonzero polynomial. The finite product of every such numerator, all row determinants, and the nonresonance conditions is nonzero. This proves the simultaneous, generic, **invertible-gauge** claim.

The proof works for any prescribed cycle orderings, even fully non-affine and noncommuting ones; it is not tied to a lucky seed.

## 3. A deterministic existence law and a small-parameter probabilistic law

This existence statement can be made explicit over the complex numbers. Set `D=N+1`, `t=1/(2q!)`, and

\[
\alpha_s=t^{D^s},\qquad s=0,...,q-1.
\]

Each monomial's multivariate exponent vector has digits smaller than `D`, so after substitution its exponent in `t` is unique (Kronecker substitution). Every row determinant and Cramer numerator is a sum of at most `q!` terms with distinct integer exponents. For the Fourier target, each nonzero term has coefficient of modulus 1. The lowest-power term cannot be cancelled by all the others: the relative sum of their magnitudes is at most `(q!−1)t<1`. All determinants and numerators are therefore nonzero. Since `0<α_s<1`, the Green denominators are also nonzero.

**Important resource caveat:** this explicit choice becomes extremely small: the exponent `D^(q−1)` is large. It is a mathematical existence certificate, **not** an efficient bit-complexity or numerical-stability prescription.

A less extreme existence result follows from Schwartz–Zippel. The product of all row determinants and all `Nq` Cramer numerators has total degree at most

\[
\boxed{d\le Nq^2(N-1).}
\]

Sampling the `q` scalars independently from any finite set of more than `2d` positive integers gives a valid tuple with probability at least one half. Thus some valid scalar tuple has **polynomially bounded integer size** for fixed `q`; the diagonal gauges and cyclic powers can still need many bits. The finite-field implementation samples couplings from `F_998244353` and rejects any degeneracy.

## 4. The generic q+1-column obstruction

For `q<N`, choose any `q+1` distinct input columns `J'`. Fix a target row `i` and append it to the `q` response rows:

\[
H_i(\alpha)=\begin{pmatrix}
G_0[i,J']\\ \vdots\\ G_{q-1}[i,J']\\ T[i,J']
\end{pmatrix}.
\]

After clearing denominators, `det H_i` is a sum of distinct monomials in the independent `α_s`, because every selected column has a unique cycle distance for each `s`. The remaining target entry in each determinant term is nonzero. Therefore `det H_i` is a **nonzero polynomial**. For generic couplings, the target row is outside the span of the `q` Green response rows: **no choice of output-diagonal gauges can match all q+1 target columns**.

This is a **generic** obstruction, not a universal lower bound excluding exceptional couplings, arbitrary input-diagonal gates, or additional Green stages. The result applies to any target with nonzero entries, including the Fourier matrix.

## 5. Consequences for Phase 31's projective windows and the Weyl gate

Take `q=5` and `J={0,1,2,3,4}`. The online sum of five independently ordered Green resolvents agrees **exactly** with five full Fourier columns. Thus *two overlapping 3×4 Fourier phase windows*, using columns `{0,1,2,3}` and `{1,2,3,4}`, pass at all rows, not just their 2×2 cross-ratios. This does **not** contradict Phase 31's exclusions: Phase 31 fixed the generators' diagonal gauges, while the new construction solves for `5N` rowwise gauge parameters.

For `FZ=DF`, the first four tested standard basis inputs `e_0,...,e_3` pass exactly, because `M e_(j+1)=F e_(j+1)=D F e_j`. For the second Weyl equation `FD=Z^(-1)F`, the five tested basis vectors `e_0,...,e_4` pass. Yet the sampled five-Green stage fails both identities on generic dense vectors. **Overlapping local phase-window success does not imply an FFT.**

## 6. Exact implementation and measured limits

Implementation `phase32_interpolation.py`: `InterpolatedGreen(n, columns, seed, extra=0)` creates `q=k` separately shuffled non-affine Hamiltonian cycles, samples admissible parameters, solves each `k×k` row system in the prime field, and applies the resulting linear operator through `q` separate cyclic recurrences. The `extra=1` path supports the earlier `q=k+1` nullspace method as an independent control.

For fixed `q`, the stored root powers and cycle positions take O(qN) field operations; preparing all responses and solving the row systems costs O(Nq^3) field operations; the online application is O(qN). Memory O(qN). If `q` grows with `N`, do **not** silently treat these as linear bounds. Computing the target Fourier columns costs O(qN) field arithmetic when roots of unity are available.

Verified through N=4096 for q=5, matching **five** complete Fourier columns without error. The immediately next column disagrees in all N coordinates in each seeded instance. Independent iterative radix-two NTT comparison on an unseen dense input also rejects the candidate in all N coordinates. For N=8,16,32,64 the residual matrix on the other N−5 columns has exact rank `N−5` over the audit prime. This latter maximal-rank statement is **finite-instance evidence, not a uniform theorem**.

As a positive full-factorization control, taking `q=N` allows the same construction to reproduce every Fourier entry at N=8 and N=16. The online algorithm then uses N Green recurrences and costs **O(N²)** field arithmetic; the naive row-interpolation setup costs O(N⁴) field arithmetic and stores O(N²) gates. This control demonstrates expressivity, **not speed**.

## 7. Next constructive research gate

The remaining plausible route is to add *input-side diagonal gauges* and share state among noncommuting cycles:

\[
M=\sum_{s=1}^q L_sG_sR_s
\]

with sublinear `q`, attempting to propagate the exact phase constraints from q selected columns to **all** columns. Our current q-column ceiling relies on fixed right-hand inputs and independent per-row left gauges; it does **not** extend automatically to the two-sided model. Any claimed Fourier factorization must pass both Weyl equations globally, include the cost of creating and storing the gauges and coupling parameters, and account for precision and data movement.
