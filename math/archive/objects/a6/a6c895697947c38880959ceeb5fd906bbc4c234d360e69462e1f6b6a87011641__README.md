# HERO #0 — Phase 15: Mixed-axis Green symmetry obstruction

This checkpoint continues the exact arbitrary-input FFT project from Phase 14. It proves a **restricted no-go theorem** for mixed-axis Margulis/Green networks that preserve hidden half-grid translations, and an exact *linear-size symmetry-breaking requirement* for low-rank perturbations of such networks.

## Main rigorous findings

- Every Margulis affine graph permutation on `Z_s x Z_s`, for even `s`, commutes with three half-grid translation involutions.
- With invariant weights, an arbitrary-depth scalar-sum/product Green network commutes with those involutions and **cannot equal** the normalized length-`N=s²` DFT.
- For the high-digit half shift, `rank([U,Pi])=N/2` and `||[U,Pi]||₂=2`. Any commuting matrix has spectral error **at least 1**.
- For the low-digit and double half shifts, the Fourier commutators have **full rank N** and exact singular values `sqrt(2±sqrt(2))`, each `N/2` times.
- With **both** half translations invariant, the exact best relative Frobenius error is `sqrt(3)/2`, an error lower bound independent of graph expansion and layer count.
- Changing only `k` individual vertex-weight entries from an *invertible symmetry-invariant reference* changes the complete network by rank at most `k`. Therefore any exact Fourier factorization requires `k≥N/2` relative to a low-digit-translation-invariant reference; `k<N/2` retains a positive spectral approximation obstruction. This has **no conditioning or weight-magnitude assumption**.
- None of these results precludes truly vertex-dependent weights, graph topologies without those symmetries, or an exact faster Fourier factorization outside this restricted grammar.

Requires Python 3 with NumPy. Unzip the package and run:

```bash
OPENBLAS_NUM_THREADS=1 python -m unittest -v test_phase15
OPENBLAS_NUM_THREADS=1 python audit.py
```
