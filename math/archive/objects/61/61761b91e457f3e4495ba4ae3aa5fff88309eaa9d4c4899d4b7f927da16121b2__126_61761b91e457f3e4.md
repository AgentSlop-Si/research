# Direct FFT Global-Bottleneck Audit

Research continuation, October 9, 2026. **No universal O(N) exact Fourier algorithm discovered.**

The project tests two all-length restrictions on attempts to compress fresh input into a narrow intermediate state, and demonstrates a correct *one-bigint-multiplication* full DFT whose giant bit cost must be charged. This is a counterexample to treating global macros as O(1), not a proposed FFT breakthrough.

### Run

```bash
python -m unittest discover -s tests -v
python audit.py
```

No network or dependencies required. Tested on Python 3.11+. `audit_results.json` is the captured reference; `audit.py` writes the new local timings to `audit_results_run.json` so the archive checksum remains unchanged.

### Contents

- `global_bottleneck.py`: exact finite-field full DFT via Bluestein + carry-safe Kronecker integer substitution; independent direct and radix-2 DFT references; arbitrary nonlinear width/condition capacity functions; exact binary block encoders.
- `tests/test_global_bottleneck.py`: all basis-vector checks, random fresh inputs, four prime fields, binary packing exactness and capacity monotonicity.
- `tests/test_rank_barrier.py`: separate full-rank modular Fourier matrices and matrix-factor rank barrier audit.
- `audit.py`: deterministic five-sample results for N through 16384 and sample width-vs-L tradeoffs.
- `RESEARCH.md`: complete theorems, proofs, hidden-bit-work analysis, negative results, prior art, exact model contracts.
- `NEXT_GATE.md`: original goal and do-not-repeat register.

### Claim boundary

- Any *differentiable complex* all-output factorization C^N -> C^w -> C^N needs w>=N. This is Jacobian rank, not an FFT operation lower bound.
- Any *binary* encoder with bounded coordinates and bounded decoder sensitivity satisfies a general metric-packing inequality; nonlinear encoders are covered. This does not exclude unstable/exponentially precise decoders.
- The packed DFT is mathematically exact modulo a prime but its one variable-width integer multiplication has substantial bit cost; it is not an O(N) operation-count FFT in either a bit machine or the #130 complex register model.
- Fixed p=998244353 results do not by themselves establish an all-N asymptotic family.

### Prior work

The rank and metric packing arguments are elementary mathematical tools. Bluestein and Kronecker are classical. No literature-wide novelty claim is made. See `RESEARCH.md` and the canonical checkpoint for sources and scope.
