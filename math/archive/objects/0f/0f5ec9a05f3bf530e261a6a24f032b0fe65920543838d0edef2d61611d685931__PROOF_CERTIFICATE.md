# HERO #17 — Phase 10 proof certificate

**Date:** 2026-10-10. **Scope:** exact Fourier *spectral projectors* on arbitrary fresh inputs. This is not the full DFT problem, and the underlying projector identities are standard Fourier analysis. The contribution here is a fully charged executable graph-union checkpoint and a correction to an interpretation of Phase 9.

## Model and notation

Fix `N >= 2`, a field `F` in which `N` is invertible, and an element `w` of exact multiplicative order `N`. In the executable finite-field implementation, `F = F_p` with a supplied prime `p`, primitive root `w`, and `p = N^{O(1)}`. This root/field supply is part of the declared contract, not a claim to compute a suitable field at no cost. Exact complex arithmetic also satisfies the algebraic hypotheses.

Define the unnormalized DFT and its inverse by

    (F_N x)[k] = sum_{j=0}^{N-1} w^{-kj} x[j],
    (F_N^{-1} X)[j] = (1/N) sum_{k=0}^{N-1} w^{kj} X[k].

For any set `K` of frequencies let `D_K` be the diagonal matrix with entries `1_{k in K}` and let

    P_K = F_N^{-1} D_K F_N.

The intended output is the *full time-domain vector* `P_K x`, not all Fourier coefficients `F_N x`.

## Theorem A: commuting spectral-projector algebra

For all `A,B` we have

    P_A P_B = P_B P_A = P_{A intersect B},
    P_{A union B} = P_A + P_B - P_A P_B,
    P_A^2=P_A,
    P_{A complement}=I-P_A.

**Proof:** Multiply the diagonal frequency masks and use `F_N F_N^{-1}=I`. Each equation follows from its corresponding identity of 0/1 diagonal matrices. QED.

Thus a nonzero commutator of the *coefficient-quotient reflections* `R_A,R_B` from Phase 9 does **not** imply a nonzero commutator of `P_A,P_B`. The former are `m x m` transfer maps in a chosen monomial quotient coordinate system; the latter are `N x N` operators acting on original signals. Common conjugation preserves the former's commutator rank but does not turn it into a gauge-independent physical obstruction to Fourier spectral projectors. Both rank statements can simultaneously be true.

## Theorem B: exact periodic-frequency comb

Let `d | N`, `m=N/d`, and take a residue set `S subset {0,...,d-1}`. Let

    B = {k in [0,N): k mod d in S}.

Then for all `j` and all fresh `x`, 

    (P_B x)[j] = sum_{ell=0}^{d-1} c[ell] x[(j+ell*m) mod N],
    c[ell] = (1/d) sum_{a in S} w^{-a*ell*m}.

**Proof:** Expand `P_B` using its DFT definition. Write each allowed frequency as `k=a+d*r`, `0<=r<m`. The inner sum over `r` is

    sum_{r=0}^{m-1} w^{d*r*(j-s)}.

This is `m` if `j-s == 0 mod m` and `0` otherwise by orthogonality of the order-`m` roots. For `s=j+ell*m`, the remaining phase is `w^{-a*ell*m}`. The factor `m/N=1/d` completes the formula. QED.

With `d` fixed, computing all `d` weights and all `N` output entries uses `O(N)` field operations and `O(N)` output storage. The implementation charges every weight operation, root generation, multiplication, addition, lookup/index step and output write.

## Theorem C: sparse-frequency exceptional corrections

Let `E_+` be outside the base `B` and `E_-` be inside `B`, with no duplicates, and set

    K = (B \ E_-) union E_+,
    q=|E_+|+|E_-|.

For a singleton `k`, set

    X_k = sum_s w^{-ks} x[s],
    (P_{ {k} } x)[j]=(1/N) w^{kj} X_k.

Then

    P_K = P_B + sum_{k in E_+} P_{ {k} } - sum_{k in E_-} P_{ {k} }.

By the formulas above, we compute `P_K x` in `O((d+q)N)` field operations, plus `O(N+d|S|+q+log p+sqrt(N))` root/weight/inverse/validation preparation operations under the executable field and indexing model. For `d+q=O(1)`, this is **exact O(N)** on *arbitrary fresh x*, including the preparation and all `N` output writes. Retained storage is `O(N+d+q)` words. (The `sqrt(N)` term is a conservative bound for primitive-root order validation by trial division of `N`; one can instead supply a factorization.) QED.

## Theorem D: optimal rank of exceptional correction

For every pair of frequency sets `A,B`,

    rank(P_A-P_B) = |A symmetric_difference B|.

**Proof:** `P_A-P_B=F_N^{-1}(D_A-D_B)F_N`. Multiplication by invertible matrices preserves rank. The diagonal `D_A-D_B` has one entry `+1` or `-1` for each element of the symmetric difference, and zero elsewhere. Those nonzero entries are invertible. QED.

In particular, a base coset projector modified by `q` exceptional frequencies has rank-exact correction `q`, and any additive representation `P_K=P_B+U V` requires at least `q` inner channels. This is **not** a lower bound of `Omega(qN)` on unrestricted circuits, and is not a lower bound for the full DFT.

## Theorem E: multiple consumers with graph union

Suppose `B` full-length projector outputs use the same modulus `d`. Let `s` be the number of distinct residue sets, `q` the number of distinct exceptional frequencies, `h` the total number of signed exceptions across distinct event *patterns*, and `v` the number of distinct exception patterns. Then a single arithmetic graph can:

- prepare powers of `w`, inverses and `s` short weight vectors;
- compute each of the `s` periodic base outputs once;
- compute each of the `q` selected Fourier coefficients `X_k` once, and materialize its rank-one response vector once;
- build each of `v` distinct correction patterns once;
- materialize each consumer's complete final output.

The total field work is

    O( N*(1+s*d+q+h+B) + B*d^2 + log p ),

with retained/output storage `O(N*(s+q+v+B)+B*d)`. Every output materialization costs `Omega(N)` writes, so for fixed `d,s,q,h`, the `O(BN)` contribution is output-optimal. This result concerns multiple related spectral filters, **not** extracting a full DFT from a fresh input. QED by following the explicit operation loops in `BatchSpectralUnion`.

## Restricted mask-signature barrier

Let `B` binary projector masks be used to label each frequency `k` by the membership signature

    sigma(k)=(1_{k in K_1},...,1_{k in K_B}) in {0,1}^B.

If the mask signatures alone must distinguish all `N` frequencies, injectivity requires `2^B >= N`, hence `B>=ceil(log_2 N)`. If the algorithm explicitly materializes the complete length-`N` output of **every** mask as separate arrays, it writes `Omega(N log N)` scalar entries. This applies only to this binary-signature/materialized-filter architecture. It does *not* rule out an FFT using different primitives, implicit/lazy views, or arithmetic combinations of many coordinates.

## Independent validation and limitations

`test_phase10.py` checks the identities and executor with exact modular arithmetic. `independent_audit.py` checks independent direct DFTs at small and nonpower-of-two lengths, an independent iterative bit-reversed NTT at 65,536, and direct individual Fourier coefficients of a large output.

- We do **not** compute all `N` frequency outputs in O(N).
- We do **not** claim new historical priority. Circulant filtering, spectral idempotents, coset averages, and rank-one Fourier modes are established mathematics.
- We do **not** claim bit-complexity linearity or floating-point stability.
- The prime-field input contract is explicit; the test fixture's prime search is not used by the executor.
- We do **not** claim an optimal generic filtering baseline. The comparison uses a clearly labeled generic forward FFT, mask and inverse FFT pipeline, with scalar preparation charged.
