# Universal-orbit evaluator: frozen construction milestone 1

Read JOINT_ORBIT_REPORT.md. All source programs in this directory were independently authored during this research turn; no uploaded program was executed, imported, compiled, or used as a runtime dependency.

Reproduce the main exact identity checks with:

    python3 check_joint_orbit.py
    python3 check_hankel_gate.py

These use only Python's standard library. They regenerate CHECK_RESULTS.json and HANKEL_GATE_RESULTS.json deterministically. `explore_kernel_rank.py` is a separate optional exploration and does not establish a general-rank theorem.

Verify retained bytes with `sha256sum -c SHA256SUMS.txt`. The independent review record is supplied by the reviewer in a separate stable directory; it is not substituted by self-checks in this construction package.

Result: O(N log N) charged recovery and joint evaluation for the square universal orbit basis; an exact q-factorial Hankel gate and canonical-coordinate conditioning bound. The exact arbitrary-input sub-N-log-N target remains open.
