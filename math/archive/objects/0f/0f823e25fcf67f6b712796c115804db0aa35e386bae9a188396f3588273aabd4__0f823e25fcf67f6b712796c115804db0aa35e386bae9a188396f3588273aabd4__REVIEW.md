## 1. Exact route and phase family

Let M be dyadic, N=M^2, and q a primitive Nth root. Write G_q=(I-D_(q^u)L_t-L_u)^(-1). Order vertices i by the pair ((floor(i/M)+1)(i mod M+1),i). Let sigma pair opposite positions of that stable order. It is an involution. Let Q reverse all N input coordinates and P_sigma permute rows by sigma. The two stage pencils are

    H1 = alpha G_q + beta P_sigma G_(q^-1) Q,
    H2 = gamma G_(q^-1) + delta P_sigma G_q Q.

The routed term at row i, column j is G_(q^-1)[sigma(i),N-1-j] in H1. Thus its row support is an upper-right rectangle, independently routed from the first term's lower-left rectangle. This is not conjugation by one common vertex permutation.

For comparable grid coordinates with increments dt,du, a phase Green entry is

    q^(u' dt) * GaussianBinomial(dt+du,dt;q).

All numerator and denominator factors in its product formula have exponents between 1 and 2M-2<N. They are nonzero for q of primitive order N. Consequently these entries are nonzero throughout their structural rectangles, over C, for every M>=2. The same holds for q^-1.

## 2. All-size support bound, including cancellations

For row i let the two rectangle areas be A=xy and B=uv, with x,y,u,v in {1,...,M}. Their intersection is

    I=max(0,x+u-M)*max(0,y+v-M).

Since max(0,x+u-M)<=xu/M, one has I<=AB/N.

For M divisible by four, the union of

    {x>M/2,y>M/4} and {x>M/4,y>M/2}

contains exactly N/2 vertices, all with area greater than N/8. At least N/2 vertices have area at most N/2, for example all x<=M/2. Pairing opposite area ranks therefore gives

    max(A,B)>=N/8,   min(A,B)<=N/2.

Write a=min(A,B), b=max(A,B). Then

    A+B-2I >= a+b-2ab/N >= min(b,N/2) >= N/8.

The middle inequality follows by considering b<=N/2 and b>=N/2. At all positions in the symmetric difference, exactly one component is nonzero. Therefore, whenever alpha beta is nonzero, no scalar cancellation can remove those entries. Every row of H1 has at least N/8 nonzeros. The identical statement holds for H2 when gamma delta is nonzero. This proves the bound for every dyadic M>=4; M=2 is separately checked.

Scope: this is a support theorem for the displayed q-phase masks. Arbitrary independent edge masks may introduce additional path cancellations and do not inherit the same support theorem automatically. Actual zero/path-cancellation subvarieties cannot be dropped from a later full compatibility search.

At N=16 the independent checker explicitly classifies every possible overlap cancellation ratio in Q(zeta16), rather than sampling scalar values. The minimum row support over all nonzero complex coupling pairs is 10. Each pure-term branch has minimum row support 1; the all-zero pair produces the zero operator. Thus the nonzero-pair hypothesis is material and those branches remain separate in subsequent compatibility work.

## 3. Explicit preparation and application cost

The areas are integers in [1,N]. A stable counting sort uses N+1 counters, a prefix sum, and one stable placement pass over row-major vertices. Pairing opposite entries of its order constructs sigma in O(N) arithmetic/index operations and O(N) storage. The provided Python comparison sort is not itself an O(N) implementation, but the independent checker implements the linear counting-sort construction and matches every supplied route.

Given q, the powers q^u for u=0,...,M-1 require O(M) multiplications and can be reused on all rows. Copying or streaming the masks, applying the known permutations, each forward solve, scalar multiplication, and summation all cost O(N). This ledger assumes ordinary exact unit-cost arithmetic/index operations. Root availability, bit complexity, and numerical stability are separate requirements.

## 4. Outer-diagonal normalization is valid but conditional

For already specified H1,H2 and invertible middle monomial C, set T=H2 C H1. Choose a reference row r and column c. If all entries T[r,j] and T[i,c] are nonzero, define

    E_j=F[r,j]/T[r,j],
    D_i=F[i,c]/(T[i,c] E_c).

Then D_r=1, and D T E matches F on the reference row and column. At every other position, equality holds if and only if

    T[i,j] T[r,c] / (T[i,c] T[r,j])
        = q^(-(i-r)(j-c)).

Thus the remaining (N-1)^2 anchored cross-ratio equations are necessary and sufficient. Denominator-free equations are obtained by multiplying by T[i,c]T[r,j]. They must retain the explicit nonzero anchor guard. The middle diagonal entries must also be nonzero when C is required to be invertible.

Zero handling is exact. Any zero in a reference row or column makes this T impossible to diagonally scale to the dense Fourier target, regardless of alternate chart. An interior zero fails its cross-ratio equation. The all-zero stage pair necessarily fails the anchor guard. If the guard and every cross-ratio equation hold, T is diagonally equivalent to invertible F, so both stage sums are automatically invertible; singular sums are not an omitted branch.

This does not synthesize the unknown C, its permutation, or the stage couplings. It only constructs D,E once a suitable T has already been supplied. Brute-force evaluation of all cross ratios is O(N^2) certification work and is not part of an advertised O(N) Fourier application.

## 5. Reverse-sweep row evaluation

For G=U^-1 with U=I-D_a L_t-D_b L_u, an ordinary transpose application is obtained from U^T z=v by reverse grid order:

    z[t,u]=v[t,u]+a[t+1,u]z[t+1,u]+b[t,u+1]z[t,u+1],

with boundary terms omitted. No complex conjugation is performed. Transposed routes reverse their order: (P G Q)^T=Q^T G^T P^T. For the phase masks this is the same q^u coefficient at the vertical successor and coefficient one at the horizontal successor.

The column T[:,c] is obtained from T e_c through forward applications. The row T[r,:] is obtained from T^T e_r=H1^T C^T H2^T e_r using transpose sweeps. Each is O(N) for a fixed number of terms. Reference Fourier phases can also be prepared in O(N) by a geometric recurrence. The O(N) conditional normalization ledger is therefore complete once the underlying parameters are supplied.
