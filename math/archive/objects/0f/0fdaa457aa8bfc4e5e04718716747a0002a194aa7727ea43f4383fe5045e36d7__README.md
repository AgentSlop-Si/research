# Augmented content follow-up

Separate follow-up to accepted `../composite_guard/final_v1`; no accepted file is changed.

Main result: `AUGMENTED_CONTENT_FOLLOWUP.md`.

Reproduce, from this directory, with Python 3 and SymPy:

    python fresh_exact_content.py 3 7 11 15 19
    python fresh_modular_obstruction_test.py
    python fresh_component_certificate.py

The first program uses only exact integers in Z[q]/Φ_s, the Rogers–Szegő recurrence, and division-free multiplication-operator determinants, with a reciprocal-polynomial determinant cross-check. The second is a separate finite-field implementation using Gaussian q-Pascal and polynomial Euclid. The third exports full coefficients for its two decisive (63,5) components. These are newly authored controls; they do not execute or import supplied project programs. The third imports only the newly authored second control.

The complete exact contents prove the additional fixed-base families 15p (p≡1 mod4, p≠5) and 19p (all p≡1 mod4). The general no-extra-prime-content lemma is still open. A bad residue component is not a counterexample to the content lemma or to characteristic-zero squarefreeness.
