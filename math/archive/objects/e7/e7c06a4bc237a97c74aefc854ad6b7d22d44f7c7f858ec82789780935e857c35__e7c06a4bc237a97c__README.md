# Exact fusion of a growing-degree q-Weyl tail

This package gives an exact positive graph rewrite: a polynomial whose degree is
N-1 can act in O(N) time when it contains only a fixed number of its highest
degree terms and is fused with its neighboring H_q(A). It does **not** compute
the remaining terms of the full Fourier transform, and it uses no approximation.

## Operators and scope

Let N=2^L, q a primitive Nth root in a field of odd characteristic or in the
complex cyclotomic field. Define f_j=product_(a=1..j)(1-q^a), t_j=1/f_j, and
H_q(X)=sum_(j=0..N-1)t_j X^j. Let A be the lower nilpotent shift and let B be the
upper weighted shift with B[i,i+1]=q-q^(-i). The previous finite-boundary audit
proved

    C = H_q(A) B H_q(A)^-1
      = B + diag(q^(-i)) - (q/N)e_(N-1)e_0^transpose.

The corner is retained throughout this package. Consequently

    p(C) H_q(A) = H_q(A) p(B)                         (1)

for every polynomial p. The full Fourier middle is G=H_q(C)H_q(A); the macro
below computes a precisely specified summand of G, not an approximation to G.

## Growing-degree fused tail

Fix 1<=r<=N and let

    p(z) = sum_(k=N-r..N-1) a_k z^k.

The only possible nonzero entries of p(B) occupy its first r rows and last r
columns. For 0<=i<=ell<r, set j=N-r+ell and

    w_0=1,  w_j=product_(h=0..j-1)(q-q^(-h)),
    K[i,ell] = a_(j-i) w_j/w_i.

All entries with ell<i vanish. Indeed B^k has only its kth superdiagonal, whose
entry (i,i+k) is w_(i+k)/w_i. Thus the following evaluator is exact for every
input x, with no cached input-dependent values:

1. Read the last r coordinates of x and multiply by the r-by-r upper triangular
   matrix K, producing v_0,...,v_(r-1).
2. Return y_i=sum_(j=0..min(i,r-1)) t_(i-j) v_j for every 0<=i<N.

Equation (1) proves y=p(C)H_q(A)x for all N. The coordinates x_0,...,x_(N-r-1)
do not influence this particular operator. They remain necessary for the other
terms of the complete Fourier transform.

## Preparation and exact reference costs

The primitive root q is supplied as a precondition; the independent audit checks
its order. All prepared constants depend only on q,N and the given
tail coefficients. The identity f_(N-1)=N lets suffix products prepare all t_j
using 1/N; 1/N is built by L multiplications by the fixed scalar 1/2. Moreover

    w_j = (-1)^j q^(-j(j-1)/2) f_j,
    1/w_j = (-1)^j q^(j(j-1)/2) t_j.

No input-dependent inverse is used. The implementation conservatively prepares
the prefix factorials as well as the suffix kernels and charges every such
operation, including multiplication by one. Preparation uses

- 7N-5+L+r(r+1) multiplications;
- 2N-2 subtractions and N-1 negations;
- one inversion of the fixed constant 2;
- O(N+r^2) scalar storage and addressing work.

For the H_q tail, a_k=t_k is already included in this preparation. For a general
tail polynomial its r coefficients are supplied explicitly.

The action takes exactly r(N+1) multiplications and N(r-1) additions. It reads
r(r+1)/2 original input entries, counting repeated reads, and writes r
intermediates and all N outputs. The report separately records prepared
coefficient reads and intermediate reads. Online workspace is O(N+r), in
addition to the prepared constants. The total preparation plus application is
O(Nr+r^2), which is O(Nr) for r<=N. In particular fixed r costs O(N), even
though the maximum polynomial degree grows with N.

These are unit exact-field arithmetic and explicit word-index counts. They are
not bit-complexity bounds or native performance measurements.

## Closed rule for the highest H_q term

For r=1 and a_(N-1)=t_(N-1)=1/N, the product of the upper weights is N/q, hence

    t_(N-1) C^(N-1) H_q(A)x = q^-1 x_(N-1) (t_0,...,t_(N-1)).

The generic evaluator takes N+1 multiplications. Preparing the N coefficients
q^-1 t_i once costs N additional multiplications; the specialized action then
uses exactly N multiplications, no additions, one original input read, and N
output writes. This is a genuine exact growing-degree macro, not a bounded-degree
polynomial or rational approximation.

## Limits

The lower-degree remainder H_q(C)-p(C) still needs evaluation. Taking r=N
recovers the complete G action but raises the reference cost to N(N+1)
multiplications and N(N-1) additions, before the outer Fourier diagonals. No
sub-N-log-N full-transform result follows.

The kernel retains q of order N at every r. Replacing it with the kernel for a
primitive rth root would change the operator and is not a legal recursion.
Faster convolution backends could accelerate parts of this macro, but none is
called or counted as free here. This example also explains why a lower bound on
polynomial/rational degree alone is not an arithmetic time lower bound.

## Reproduce

Run `python run_audit.py` with Python and its standard library. It compares the
fused action with a literal polynomial-in-C Horner evaluator applied after a
full H_q(A) multiplication. The oracle uses the full cyclic corner. Complete
basis vectors are tested for N=2,4,8,16,32,64, over primes 65537 and 998244353,
with several r values, both H_q tail coefficients and explicit signed integer
coefficients. A mixed input is also checked in every case. Counts, ignored-input
support, and the r=1 rule are checked exactly. `results.json` records every case.

The finite tests audit the implementation; the displayed support and conjugation
arguments establish the all-N identity. No global novelty is asserted for the
polynomial similarity or weighted-shift facts. This is a new macro in the
current project, built from its previously audited finite-boundary identity.
