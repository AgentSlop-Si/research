# FFT Word-RAM packed decoder v3

Continuation of the recovered 2026-10-09 sparse-surrogate / finite-state lookup research branch.

Files:

- `RESEARCH.md` — theorem candidate, proof sketch, complexity accounting, error budget, limitations and prior-art boundary.
- `prototype.py` — executable prototype with guarded packed-lane accumulation and cost model.
- `results.json` — reproducible experiment output from `prototype.py`.

Run:

```bash
python prototype.py
```

The code tests a **randomized approximate** DFT construction. It is not an exact FFT and is not presented as a practical replacement for FFTW/NumPy FFT.
