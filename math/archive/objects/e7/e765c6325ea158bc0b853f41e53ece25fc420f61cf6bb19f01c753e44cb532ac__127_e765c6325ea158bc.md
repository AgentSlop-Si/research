# Reduced-center exact-DFT network: independent validation

October 9, 2026

This bundle contains an exact-rational prototype of a proposed algebraic simplification of the finite scalar network in the OpenAI paper *An explicit power saving for the exact discrete Fourier transform* (September 25, 2026). It is independent of the FFT input and requires no hash-consing.

## Reproduce

```sh
python independent_network_test.py
python verify_reduced_center.py
```

Test coverage in `independent_network_test.py`: arbitrary nonzero initial auxiliary states; both forward/inverse eight-gate local invocation at h=6,7,8; three-stage bank exchange for h=6 (8,000 positions per bank; 1,200 invocations; arbitrary auxiliaries); exact-integer geometric constants and high-precision exponent-gap calculations. The separate `full_suite_output.txt` documents 29 passing tests on the earlier structural project, which has not been modified by this bundle.

## Simplification

Original central map uses (c1,...,ch,c*) and coefficient (sum over S of c_j - c*)/2. Eliminate c* and use

    (R' c)_S = (sum_{j in S} c_j)/2 - (sum_{j=1}^h c_j)/6

with (G'x)_j = sum of x_T over triples T containing j. Then

    (R'G' x)_S = sum_T ((|S intersection T|-1)/2) x_T,

matching the original network center contribution. The original side-wire cancellation is untouched. It follows that the same schedule restores arbitrary scratch values.

## Conditional complexity estimate

With h=24 and h rather than h+1 center roles per invocation: v=2024; m=13,824; W=34,666,930,287,616; W_star=2^45; Delta=2,425,172,992; gap = 1 - log_m(m - Delta/W_star) approximately 5.22969896327091e-10.

Subject to independent verification that the original full frame/indexing/all-length proof transfers unchanged, this would imply a theoretical all-length complex DFT bound with exponent 1 - 5e-10 in the same mathematical model. Not a claim of a proven new result or practical FFT performance.
