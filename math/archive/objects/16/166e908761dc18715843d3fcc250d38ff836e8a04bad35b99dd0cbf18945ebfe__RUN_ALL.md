# Reproduce this checkpoint

Unzip the archive. Run with Python 3.10+ and dependencies `numpy` and `sympy`:

```bash
cd fft_bilateral_gate_2026-10-09
python run_new.py
```

The loader extracts the nested previous checkpoint automatically into `_prior_extracted`. It imports the earlier exact cyclotomic arithmetic functions without changing their source.

The combined runner performs:

1. Exact checks of 30 fixed-subspace 4x4 determinants, 10 Plücker identities, and all 55 maximal minors of the saved 11x9 rank gate.
2. A modular 4x4 nonzero determinant proving the degree-two rank-drop polynomial is absolutely irreducible over the complex numbers.
3. 1,188 independently generated Fourier-kernel and arbitrary-subspace rank checks across lengths 8,16,32,64 and two prime fields.
4. Auxiliary determinant/boundary-lock tests across lengths 8,16,32,64 and two primes.
5. Exhaustive screening of every 8-point permutation and fixed-seed sampling of larger lengths.

Expected final output includes:

`ALL NEW GATES VERIFIED: 55 symbolic maximal minors, 30 fixed-subspace identities, 1188 finite-field rank checks`

`PROOF_CERTIFICATE.md` contains the mathematical proofs, which do not depend on sampling. `prior_checkpoint_full.zip` contains the earlier full four-column rank/resultant checkpoint, recursively preserving the research history. To rerun the previous checkpoint's full regression suite, first run the new suite and then execute:

```bash
python _prior_extracted/fft_triple_intersection_gate_2026-10-09/run_all.py
```

The previous checkpoint's full 72-test suite was **not rerun as part of this new runner**; its archived results and tests are preserved unchanged.
