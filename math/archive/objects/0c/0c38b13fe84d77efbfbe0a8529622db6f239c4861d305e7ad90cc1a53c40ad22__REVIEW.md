# Pending 0155 code batch: complete inert-source review

## Result and limits

Thirteen exact source hashes, 70,284 bytes and 1,903 physical lines, were read from beginning to end. This includes every hash in pending batch 02 plus the directly imported Phase 36 two-mask companion from batch 04. They had no mapped complete-read evidence in the frozen inventory; newer top-level coverage declarations were checked for exact hashes before assignment. Complete reading is credited only to these thirteen hashes. No supplied source was executed, imported, compiled, or syntactically parsed by this review. No supplied result, timing, determinant, or PASS message was independently reproduced.

The original frozen inventory and all source bytes are preserved. This package is additive. Exact unmodified source copies, line/byte extents, per-file findings, dependency bindings, witness-data observations, preservation checks, and a checksum seal accompany this report. Complete inspection does not imply correctness on every input, complete test coverage, dependency closure, mathematical proof acceptance, or a new Fourier algorithm.

The useful mathematical mechanisms in this batch are coherent in their stated domains: cyclic Green recurrences, character-packet fusion, two different Schur/rank lifts, a symmetry-commutator obstruction, phase-rank lower-bound calculations, and prefix/suffix Jacobian reconstruction. The checks are restricted-model or finite-instance checks. No code here supplies a universal sub-NlogN exact Fourier construction or a general FFT lower bound.

## Findings that change how results should be used

1. **The native benchmark is observational, not a pass/fail validator.** `native_benchmark.cpp` computes identity and approximation errors but only prints them (lines 225–257); there is no correctness tolerance or nonzero exit for a bad answer. Its `max_error` (204–205) uses `std::max(e, abs(...))`, which can leave `e` unchanged when a difference is NaN. Consequently an all-NaN comparison can report zero. This is a concrete nonfinite-validation defect, not evidence that the supplied nominal run contained NaNs.
2. **The optimizer's evaluated model includes an extra rank-one map.** `optimize_green.py` defines the four-Green operator at 43–47, then uses `seeded(z) = apply(z) + (v-apply(e0))*z[0]` everywhere in the loss and dense diagnostics (48–69). A successful fit would establish a four-Green-plus-rank-one fit. The first-column assertion is enforced by this construction and is not an independent discovery of Fourier accuracy. The file accurately disclaims an FFT algorithm.
3. **The cyclotomic APIs omit a necessary character-index contract.** The direct packet uses the character modulo b, but both fused variants use the unreduced exponent s (25–29 and 161–167). Equality holds for 0 <= s < b. For b=2, s=2 and alpha P=2I over the default field, direct equals (I-4I)^-1 while fused equals 4(I-4I)^-1; both denominators exist and the results differ. Validate or reduce s. Negative exponents also leave the permutation-power shift loop nonterminating (109–117). The current finite tests use valid nonnegative representatives.
4. **Several directly invoked CLIs do not test later helper implementations.** Phase 15's main only calls modular commutator certificates; finite-rank and twirl utilities are defined afterward. The cyclotomic main calls dense packet tests before the vector-apply tests are defined and never calls them. Phase-rigidity main omits the subsequently defined full-phase-rank/cross-ratio and general-angle helpers. These are source-observed entrypoint boundaries; another driver might call them, but that requires its own exact receipt.
5. **Some 'certificate' outputs are narrower than their labels suggest.** `projector_certificate.py` verifies integer shell counts and algebraic telescoping, but assigns ranks/eigenvalues from formulas without constructing or diagonalizing the projector. `bitrev_rank.py` evaluates a stated rank recurrence without constructing a Fourier cut or independently checking the recurrence. Neither limitation invalidates a separately proved theorem; neither program independently proves that theorem.
6. **The full-dimensional verifier needs a separately trusted native helper.** `independent_verifier.py` reconstructs stage matrices and Jacobian columns, then invokes a neighboring executable named `rankmod` (54–60). The archived helper source is identifiable, but the verifier does not hash-bind the executable to it. It reads neighboring witness files that are absent next to the isolated recovered source copy. Runtime closure therefore requires the original package layout and a verified build. No helper was run here. The matching supplied witness integers and dimensions are safely within int64 arithmetic bounds for its two fixed fields, so generic overflow concern is not a demonstrated defect for those files.
7. **Success and convergence handling have gaps.** The projector CLI can print PASS with zero cases if bounds exclude every case. Cyclotomic vector tests advance to the next s on a singular denominator, with no final expected-case-count assertion. Sinkhorn returns its last iterate after the iteration cap without a convergence boolean or failure; its residual is exposed, but a caller must inspect it. These are coverage/contract limitations, not evidence of nominal-run failure.

### 1. Phase 15 Weyl symmetry

- SHA256: `07bbebda0dea7d706fe5ea9e7a38c7b8fd9a355e3e9607f03fb242303ea91aec`

The Margulis-style maps and half translations have consistent indexing. `green_apply` expands y_i-w_i y_pi(i)=x_i around each permutation cycle, divides by one minus the cycle product, and back-substitutes in the correct direction. A zero denominator is rejected. Dense and modular Green constructions use the same row-permutation convention. The commutator formula U[:,tau]-U[tau,:] is valid for the involutive half translations used here; it is not a generic permutation commutator despite the helper's broad argument type.

For the spectral budget, [G,Q]=G[T,Q]G and the product commutator inequality justify the gamma-squared delta contributions and the two-layer bound. The reported necessary error uses ||[U,Q]||=2 for the x half-translation. The finite-rank extension uses rank(T-T0)<=number of changed weights, rank([T,Q])<=2 rank(T-T0), and the rank triangle inequality consistently. For y/xy, the returned `lower_rank_bound` still uses N/2, a weaker x-based bound; it is conservative, not the strongest available axis-specific value.

The CLI checks s=2,4,8,16 and three axes over one prime. It does not exercise Green application, dense budgets, complex spectra, rank defects, or twirls. Those assertions are present in callable helpers but are not runtime evidence. Default int64 products are guarded in modular_matmul and are safe at these dimensions; the helper assumes reduced modular entries and a suitable field. Arbitrary moduli, malformed permutations, singular cycles, and larger dimensions require their stated algebraic/input preconditions. Dense matrices and norms are validation machinery, not O(N) Fourier implementations.

### 2. Native unit-step chirp benchmark

- SHA256: `175f24d4c644db74789f5a85d0a671a9891c2a1344d62fa9b7ac8b6932710ed8`
- Extent: all 10,456 bytes, lines 1–259.
- Read sections: FFTW declarations and arithmetic 1–79; engine construction/compression 81–114; scan and row formula 117–174; three-grid majority state 176–210; complete benchmark driver 212–259.

The chirp difference identity is consistent with the materialized projection. With zeta=exp(2pi i/N), its forcing is y_m-zeta^(-(m+beta))y_(m+a); shifting the local chirp sum cancels interior terms and leaves the two compressed-FFT boundary terms used at 149–150. The gauge ratio between adjacent j values is zeta^(a*j+beta). For even dyadic N and odd a, the full-cycle gauge product is -1, so the scan total divided by two gives the closure seed. The main generates precisely such odd a and uses a dyadic, dividing M. Compression and Blelloch scan have linear work; the remaining K=N/M FFT costs O(K log K). With M near log N this is a short-FFT-based approximate row construction, not removal of Fourier work from the implementation.

The three-grid Boyer–Moore step is conditional on a strict majority of estimates lying within the required error interval. This code does not prove or test that probability, choose rows from a user error/confidence target, or establish a uniform all-input guarantee. It benchmarks one random complex vector and one identity row state per N, then three independently sampled streaming repetitions. Error radii scale with input norm and M/N. Timings exclude engine/root/plan setup and include allocations differently in the compared paths; they are not an independently reproduced speed claim.

Defects/limits: no correctness failure threshold; NaN-hiding reducer; rows may be nonpositive and still yield an output; constructor computes n/m and creates a plan before validating M, so M=0 is not safely rejected. State oddness, input lengths, FFT int-size conversion, shift overflow at enormous dimensions, and finite outputs are not generally validated. FFTPlan has owned raw resources and no disabled copy operations or exception-safe partial-construction cleanup. These API/robustness problems are not exercised by the nominal main. FFTW ABI/library availability and GNU-style unsigned __int128 are external compilation/runtime requirements; none was tested.

### 3. Odd chord and hybrid verifier

### 4. Cyclotomic packet

- SHA256: `25748f16e3a958f1099b14ad672b58791a9903cca1af42bad17c1a89bc316381`
- Extent: all 6,500 bytes, lines 1–185.
- Read sections: matrix fusion and Fourier weights 1–62; dense checks/main 65–106; permutation operations and cycle solve 109–148; vector fusion/checks 151–185.

Character orthogonality gives (1/b) sum xi^(-rs)(I-alpha xi^r P)^-1 = (alpha P)^s(I-(alpha P)^b)^-1 for 0<=s<b and nonsingular denominators. The weight DFT uses positive exponent; multiplication by b in the fused numerator correctly cancels its 1/b normalization. Column-permutation matrix orientation agrees with `apply_perm`; the cycle solver correctly closes y[v_k]-gamma*y[v_(k-1)]=x[v_k]. P^b and P^s are built by binary permutation powering, so the general fused application costs O(N(log b+log s)) for this implementation, with a linear cycle solve; O(N) requires treating exponents/packet size as bounded or separate precomputation.

The s-range and negative-exponent defects are described above. Dense tests cover twelve (n,b) pairs and all s representatives, with one random permutation per n and one weighted packet per pair. Vector tests, if separately called, nominally cover 48 (n,b,s) cases on three Hamiltonian cycles; singular cases are skipped after changing alpha. The direct CLI never calls this vector suite. Matching `algebra_utils.py` has been source-bound and selected implementations inspected, but it has not received full-file credit in this package. Its inverse exceptions are ValueError for singular matrices and ZeroDivisionError for scalar inverses, consistent with the two catch sites.
