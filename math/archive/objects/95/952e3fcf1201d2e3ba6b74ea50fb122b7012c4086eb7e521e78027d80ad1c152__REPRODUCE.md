# Portable replay

Python 3.9 or later, standard library only. The checker uses its own implementation and reads `source/bezout_N*_p*.json` only as inert data.

    python independent_checks.py phase37-review.json
    python -c 'import json; assert json.load(open("phase37-review.json")) == json.load(open("INDEPENDENT_RESULTS.json")); print("EXACT REPLAY PASS")'
    python verify_seal.py

For isolated replay, copy only the checker and those twelve JSON files, retaining the relative `source/` directory. No source Python programs, numerical packages, archive extraction at runtime, or network are required.
