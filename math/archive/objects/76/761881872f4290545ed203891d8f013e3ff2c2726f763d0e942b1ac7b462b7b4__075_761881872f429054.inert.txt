# Three new Fourier-research uploads: consolidated audit

9 October 2026. All three archives are new, and all relevant text, source, and saved results were inspected. No uploaded Python was imported or executed. Independently authored checkers were run separately. Exact Library IDs, names, sizes, and archive SHA-256 hashes are in `SOURCE_INDEX.json`.

## What genuinely advances the research

1. **Shrinking-error v4 improves the theorem.** Increasing the sample count and output-block width together to Theta((log N/loglog N)^2) gives a fully charged O(N) word-RAM approximation with maximum-coordinate error O(loglog N/sqrt(log N)) times L_box(x)/sqrt(N). The standalone proof completes uniform arithmetic, sampling, table preparation, and explicit output writing under bounded-integer/common-scale input assumptions. The increasing-block idea belongs to the v4 upload.
2. **The macro checkpoint improves implementation components.** It eagerly constructs complete tables, stores rows already packed, and uses certified integer phasors and capped exact-mass sampling. This fixes the previous prototype's lazy table and repeated packing limitations. It still lacks a complete implemented growing-parameter/base-case driver, and has no practical speedup evidence. Its fixed small-block integration tests do not instantiate the asymptotic O(N) schedule.
3. **There is a new restricted exact fast path.** The macro checkpoint verifies a weighted-affine residual with at most s defects and evaluates all Fourier outputs in O(N(s+1)) exact field operations. It includes fully dense structured examples and a valid 14N+1 field-operation count for one family. This is a restricted input family; arbitrary inputs retain the FFT fallback. Exact-field operation counts are not general bounded-word/bit-complexity results.
4. **The exact structural screens improve.** Valid new scan/broadcast, tridiagonal-component, permutation-movement, and Green-stage bounds eliminate or constrain specific architectures. The global-Green archive's exact dense Fourier factorization is ordinary FFT behind canceling rank-one changes of coordinates; it is a useful negative control, not a faster transform.

## Important comparison and interpretation

The v4 second parameter point is mathematically valid: O(N log N/loglog N) with error factor O((loglog N)^(3/2)/log N). However, on power-of-two lengths standard signed sampling plus a pruned FFT gives that same error in O(N loglog N), including a bounded-word implementation and charged preprocessing. Do not call the second point a superior general accuracy/time frontier. The O(N) first point is the main advance. See `PRUNED_BASELINE.md` and `SHRINKING_PRIOR_ART.md`.

The vanishing guarantee is coordinatewise l_infinity error relative to input l2 norm, using L_box(x)/sqrt(N)<=sqrt(2)||x||_2. It is **not** vanishing relative l2 error of the whole output vector, coefficient-relative accuracy, or machine-precision Fourier computation. For dense random signs, even zero output satisfies either displayed asymptotic tolerance with high probability. The result still improves the worst-case error allowance and constrains coherent large peaks.

These materials do not achieve the user’s original arbitrary-complex, fresh-input, exact all-output sub-N log N Fourier target. This is a statement about this research construction and its stated model, not a literature-wide impossibility claim. No industrial impact, practical FFT replacement, or literature-wide priority is established. A focused primary-source search found no exact match for the first fully charged shrinking-error linear bound; absence of a match is not a novelty certificate.

## Attachment-by-attachment decision

- `fft_wordram_shrinking_error_v4(2).zip`: all 5 files are new. Accept the shrinking-error construction with the explicit model and finite-arithmetic completion. Its supplied prototype is still lazy and re-packs each lookup; 15/20 saved cases exceed their declared 88-bit word key width, and all 20 exceed the theoretical table-exponent budget. These are toy-control limitations, not counterexamples to the eventual asymptotic theorem. Four symbolic rows also label a clipped total budget below their component bounds.
- `fft_nonunitary_global_green_research_2026-10-09(4).zip`: all 20 files are new; all 19 manifest-covered hashes match. Accept the scoped Green/norm/gauge claims. The independent audit adds a determinant proof that the fixed Green-sum stage without compensating gain cannot reach normalized Fourier at any positive stage count. Global rescaling invalidates that determinant shortcut but not the stated scale-invariant condition budget.
- `fft_macro_wordram_checkpoint_20261009(2).zip`: 75 files, including 32 byte-identical prior files and 43 new files. All 74 manifest-covered hashes match. Accept the eager implementation components, affine fast path, and scoped structural claims. Correct “two fewer comparisons” to “one fewer comparison, saving two multiplications”; the 14N+1 total remains correct. Some packing test tolerances are intentionally vacuous and validate mechanics only.

The prior F8 exact 3-forward/3-backward realization and sharp F32 11-by-11 rank gate are unchanged. A generic warning that low cut rank need not synthesize literal scans does not reopen the already independently verified F8 construction.
