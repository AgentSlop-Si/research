# Latest checkpoint — conditioned macro-FFT

## Main result of this session

The query-engine branch remains a side artifact. The main research target is again the full arbitrary-input, all-output DFT.

A new composition principle was derived:

1. Use the exact sub-`B log B` transform only at a slowly growing macro radix `B`.
2. Convert the local normalized transform `U_B` into a transparent add-to-target primitive using the replay lemma already present in the #130 explicit-DFT manuscript.
3. Three transparent additions implement the unitary catalytic exchange
   `(x,y) -> (-U_B^{-1}y, U_B x)` while restoring borrowed scratch.
4. Process global Fourier macro-levels by alternating two data banks. Each completed macro-level is unitary, so intermediate condition does not multiply across levels.
5. For `N=2^k`, `B=2^b`, the normalized work ratio is
   `O(A(B)/(B b) + 1/b + b/k)`.
6. Since #130 gives `A(B)/(B log B)->0`, any sufficiently slowly growing `b(k)` yields `o(N log N)` work.
7. For each fixed `B`, the transparent word is finite, hence has finite maximal prefix condition `K(B)`. A staircase choice of `B(N)` can fit inside any prescribed unbounded condition budget `R(N)` at sufficiently large thresholds.

## What is proved/tested

- Matrix-level condition-reset lemma.
- Macro work derivation for power-of-two lengths.
- Three-shear unitary bank exchange identity.
- Numerical tests: injected local condition `1e2`, `1e4`, `1e6` does not accumulate after 10--12 macro-levels; completed stages return to condition 1.
- #130 source contains the needed transparent replay lemma for arbitrary borrowed scratch.

## Research boundary

This is not another center/rank/kappa optimization. It uses the existing #130 algorithm as a black box and studies whether its instability can be isolated inside slowly growing macroblocks.
