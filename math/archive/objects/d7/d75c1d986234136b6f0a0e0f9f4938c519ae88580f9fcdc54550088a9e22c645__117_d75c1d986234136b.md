# Fully charged fresh-FFT global-stage research (Green + gauge)

This package examines **exact fresh full DFT**, not cached input updates and not CrocSwap's integer-multiplication exponent certificates.

The research is a **negative result with one genuine surviving subfamily**. It does NOT provide an O(N) FFT or a theorem that forbids all such FFTs.

**Strongest new scoped result:** even our well-conditioned globally dense two-Green stage with a fully dense inverse needs Omega(log N) stages to produce a normalized FFT when inter-stage operations are permutations and unit-modulus phase diagonals. The proof uses induced column-norm growth, NOT inverse sparsity. It is not a general lower bound for arbitrary nonunitary gates.

## Core verified research

- `green_stages.py`: two-sweep tridiagonal Green solvers, sums of two Green operators, inverse of their sum, and exact matrices and cut ranks over `F_998244353`.
- `gauge_fft.py`: a complete fresh radix-2 NTT whose **individual** matrices are fully dense/nonunitary after cheap rank-one changes of intermediate coordinates. Its full action is **exactly an ordinary FFT**, with *more* arithmetic.
- `gauge_recognizer.py`: exact certificate that the dense stages are just one repeated rank-one gauge dressing of ordinary butterfly stages.
- `independent_audit.py`: independent Gauss–Jordan and direct-DFT verifier, full matrix and fresh-random comparisons.
- `norm_budget.py`: exact rational column-sum norms, plus certified integer-only logarithmic stage bounds.
- `real_condition_control.py`: optional NumPy condition-number checks for the real SPD two-Green stage. The analytic bound is in `RESEARCH.md`.
- `synthesis_probe.py`: optional PyTorch heuristic to search two-/three-stage sum-of-scan factorizations. **None of these fits is a verified exact FFT.**
- `benchmark.py`: single-process warm comparison of exact fresh whole-vector FFT and gauge-disguised FFT, including arithmetic counts.

## Reproduce

```bash
cd fft_global_green_gauge
python -m unittest discover -s tests -v
python independent_audit.py
python norm_budget.py            # exact rationals, stdlib
python real_condition_control.py  # numpy
python benchmark.py               # warm full output, fresh vectors
python synthesis_probe.py         # torch, numerical only
```

No network calls, no threading and no precomputed FFT answers. The main field experiments need only Python standard library. Tests run under Python 3.13.

## Critical cost and proof boundaries

`O(N)` applies to one tridiagonal solve or fixed-channel sum of solves **once its local factorization coefficients are prepared**; preparation itself costs `O(N)` field operations/inversions and is accounted separately. The full FFT remains `O(N log N)` with output and data movement charged. Finite-field p=998244353 allows NTT lengths only while N divides p−1, not a new all-length finite-field theorem. The Green support/rank theorems extend algebraically to suitable arbitrary fields, including complex numbers; the numerical code alone does not establish complex bit precision.

The full N-point FFT is not actually accelerated; see `RESEARCH.md`, `benchmark_results.json`, and `NEXT_GATE.md`.
