# Fused all-length unit-step-chirp lift: one-pass Bessel compression and a conditional finite-precision closure

**Checkpoint:** 9 October 2026  
**Status:** Reproducible theorem extension and implementation audit. Randomized and approximate. **Not an exact FFT, not a practical speed claim, not a complete fixed-binary64 theorem, and not a novelty claim.**

## 1. What this checkpoint resolves

The v10 all-length lift evaluates a rank-`R` Jacobi--Anger expansion by calling the same dyadic unit-step-chirp row on `R` Bessel-weighted inputs. Its mathematical storage claim was `O(N)`, because terms can be streamed. However, the saved prototype built a Python list of `R` full length-`N` Chebyshev arrays. The code therefore used `Theta(RN)` storage even though the theorem did not require it.

This checkpoint makes the intended implementation explicit and then reduces the repeated input-side work:

1. **Exact streamed implementation.** The Chebyshev sum is evaluated by a backward Clenshaw recurrence with only two length-`N` vectors. The chirp decoder produces only the selected dyadic frequencies. No `R x N` result or Chebyshev table is retained.
2. **One-pass local compression.** Neumann's Bessel addition identity separates each Bessel weight into a block factor and a tiny local-offset factor. A constant number of local summary channels consumes the original input and chirp phase once.
3. **Finite-precision composition.** Under an explicit numerical contract for the dyadic chirp row, the precision required by the all-length lift has the same leading asymptotic order as v9 and does **not** acquire an extra factor of `R`.

The remaining `R` length-`Q` decoder scans are real. Consequently the total shrinking-error time remains

\[
O(RN)=O\!\left(\frac{N\log N}{\log\log N}\right).
\]

This checkpoint does not claim a new time exponent.

## 2. Setup inherited from v10

For arbitrary input length `N`, let

\[
Q=2^{\lceil\log_2N\rceil}=KM,
\qquad N\le Q<2N,
\]

where `M=Theta(log Q)` is dyadic and `K=Q/M`.

For every target output `k`, define the exact nearest-grid decomposition

\[
\frac{kQ}{N}=j_k+\theta_k,
\qquad |\theta_k|\le\frac12.
\]

The residual kernel has the Jacobi--Anger/Chebyshev expansion

\[
e^{-2\pi i s\theta}
=J_0(\pi s)
+2\sum_{r\ge1}(-i)^rJ_r(\pi s)T_r(2\theta).
\]

Truncating after orders `0,...,R-1` gives a uniform tail `tau_R`, with

\[
R=\Theta\!\left(\frac{\log N}{\log\log N}\right)
\]

for polynomially small deterministic error.

One random v9 chirp state is shared across every expansion term. For each final output, linearity turns the complete term sum into one covariance problem, preserving the one-row variance scale

\[
\frac{M}{N}(1+\tau_R)^2\|x\|_2^2.
\]

## 3. Exact streamed Clenshaw implementation

Let

\[
a_0(k)=Y_0[j_k],
\qquad
a_r(k)=2(-i)^rY_r[j_k]\quad(r\ge1),
\]

where `Y_r` is the dyadic chirp row applied to the input weighted by `J_r(pi n/Q)`.

The required output is

\[
\sum_{r=0}^{R-1}a_r(k)T_r(2\theta_k).
\]

For `x_k=2theta_k`, Clenshaw's backward recurrence is

\[
b_r=a_r+2x_kb_{r+1}-b_{r+2},
\]

with `b_R=b_{R+1}=0`, followed by

\[
S_k=a_0+x_kb_1-b_2.
\]

Only `b_1` and `b_2` are stored, so the Chebyshev part uses two length-`N` complex vectors.

The v9 decoder itself is also specialized. The cycle permutation, gauge, boundary factors, and selected cycle positions are prepared once. For each expansion order, the decoder forms one length-`Q` forcing vector and balanced prefix scan but returns only the `N` selected dyadic entries `j_k`.

The saved implementation agrees with the v10 materialized implementation to

\[
1.1236861156120876\times10^{-14}
\]

in the recorded tests. The selected-only decoder was bit-for-bit identical to slicing the complete decoder in the tested complex128 cases.

## 4. One-pass Bessel block fusion

Write a padded dyadic index as

\[
n=bM+t,
\qquad 0\le b<K,
\qquad 0\le t<M.
\]

Set

\[
z_b=\frac{\pi b}{K},
\qquad
\delta_t=\frac{\pi t}{Q}.
\]

The Bessel generating function implies the integer-order addition identity

\[
J_r(z_b+\delta_t)
=
\sum_{h\in\mathbb Z}J_{r-h}(z_b)J_h(\delta_t).
\tag{4.1}
\]

Choose a halfwidth `H` and retain `|h|<=H`. For the v9 local phase `S[b,t]`, define only `2H+1` input-side channels

\[
G_h[b]
=
\sum_{t=0}^{M-1}
S[b,t]x_{bM+t}J_h(\delta_t),
\qquad |h|\le H.
\tag{4.2}
\]

Then synthesize the order-`r` block summaries as

\[
\widetilde d_r[b]
=
\sum_{|h|\le H}J_{r-h}(z_b)G_h[b].
\tag{4.3}
\]

The original input and phase matrix are consumed once to form the channels. No Bessel-weighted length-`Q` input is materialized for each expansion order.

### 4.1 Certified addition error

For real arguments, `|J_m(z)|<=1`. Let

\[
\Delta=\frac{\pi(M-1)}{Q}.
\]

The omitted local-order tail is bounded by

\[
A_H(\Delta)
=
2\exp\!\left(\frac{\Delta^2}{4(H+2)}\right)
\frac{(\Delta/2)^{H+1}}{(H+1)!}
\frac{1}{1-\Delta/[2(H+2)]}.
\tag{4.4}
\]

Therefore each Bessel order has weight error at most `A_H(Delta)`. Since the absolute sum of the finite Chebyshev-series multipliers is at most `2R-1`, the added kernel error is

\[
\boxed{
\kappa_{R,H}=(2R-1)A_H(\Delta).
}
\tag{4.5}
\]

The fused deterministic center consequently obeys

\[
\boxed{
\|\overline X^{(H)}-U_Nx\|_\infty
\le
(\tau_R+\kappa_{R,H})\|x\|_2.
}
\tag{4.6}
\]

The approximate kernel has magnitude at most `1+tau_R+kappa_RH`. The shared-state covariance proof therefore gives

\[
\boxed{
\mathbb E|\widehat X_k^{(H)}-\overline X_k^{(H)}|^2
\le
\frac{M}{N}
(1+\tau_R+\kappa_{R,H})^2\|x\|_2^2.
}
\tag{4.7}
\]

Thus all v10 robust aggregation statements remain valid after replacing `tau_R` by `tau_R+kappa_RH`.

### 4.2 One local channel is asymptotically enough

The principal shrinking-error theorem has

\[
M=\Theta(\log N),
\qquad
R=\Theta\!\left(\frac{\log N}{\log\log N}\right),
\]

and target exponent

\[
\alpha=\frac12-\frac{1+a}{2s}<\frac12.
\]

For `H=0`, only the channel `J_0(delta_t)` is retained, and

\[
\kappa_{R,0}
=O\!\left(\frac{RM}{N}\right)
=O\!\left(\frac{(\log N)^2}{N\log\log N}\right)
=N^{-1+o(1)}.
\]

This is asymptotically negligible compared with `N^{-alpha}`. Therefore the main polynomially shrinking theorem needs only **one input-side Bessel channel**.

The recorded formal ratios `kappa_R0/N^{-1/3}` were:

| Approx. `log2 N` | Ratio |
|---:|---:|
| 20 | `6.85e-2` |
| 30 | `7.64e-4` |
| 40 | `1.74e-5` |
| 80 | `5.06e-13` |
| 120 | `6.06e-21` |

`H=1` makes the already small error dramatically smaller and is useful at modest sizes.

## 5. Work and storage accounting

### 5.1 Input-side work

The direct v10 compression performs `R` full input/phase passes:

\[
W_{\mathrm{old}}=\Theta(RQ).
\]

The fused compression costs

\[
W_{\mathrm{fuse}}
=
O((2H+1)Q+(2H+1)RK).
\]

For `H=0`, `M=Theta(log N)`, and `R=Theta(log N/log log N)`,

\[
\frac{W_{\mathrm{fuse}}}{W_{\mathrm{old}}}
=O\!\left(\frac1R+\frac1M\right)
=O\!\left(\frac{\log\log N}{\log N}\right)
=o(1).
\tag{5.1}
\]

The saved formal work ratios decreased from `0.1875` around `2^20` to `0.0533` around `2^160`.

### 5.2 Total arithmetic

For every expansion order, the implementation still performs:

- one length-`K` FFT of summaries;
- one length-`Q` gauged forcing/prefix scan;
- one selected-output contribution to the Clenshaw recurrence.

Hence

\[
T(N,R,H)
=
O((2H+1)Q+(2H+1)RK)
+O\bigl(R[Q+K\log K]\bigr)
=
O(RN).
\tag{5.2}
\]

The all-length shrinking-error theorem therefore remains

\[
O\!\left(\frac{N\log N}{\log\log N}\right),
\]

not `O(N)`.

### 5.3 Storage

The implementation retains:

- one padded input/phase block matrix: `O(Q)`;
- `2H+1` local channels: `O((2H+1)K)`;
- static cycle/gauge arrays and one forcing/prefix workspace: `O(Q)`;
- two Clenshaw accumulators and one final output: `O(N)`.

There are no rank-dependent full-length arrays:

\[
\boxed{S(N)=O(N).}
\]

This closes the actual saved-code gap from v10.

## 6. Conditional finite-precision theorem

This section is a composition theorem under an explicit numerical primitive contract. It is not yet a proof about a particular FFT/Bessel library.

Assume one computed v9 dyadic row `A_omega` satisfies, for every input `y`,

\[
\|\operatorname{fl}(A_\omega y)-A_\omega y\|_\infty
\le
C_Au\log Q\sqrt{MQ}\,\|y\|_2,
\tag{6.1}
\]

where `u` is unit roundoff. Assume Bessel values are generated with an absolute-error envelope proportional to the standard factorial majorant, and use Clenshaw summation plus pairwise reductions.

For `0<=z<=pi`,

\[
|J_r(z)|
\le
\exp(\pi^2/8)\frac{(\pi/2)^r}{r!}
\quad(r\ge1),
\]

so

\[
B_J
:=
\sup_{0\le z\le\pi}
\left(|J_0(z)|+2\sum_{r\ge1}|J_r(z)|\right)
\le
1+2e^{\pi^2/8}(e^{\pi/2}-1)
<27.17.
\tag{6.2}
\]

Summing (6.1) over all expansion terms therefore incurs the constant `B_J`, not a factor `R`:

\[
\eta_{\mathrm{rows}}
\le
\sqrt{\frac QN}
C_Au\log Q\sqrt{MQ}\,B_J\|x\|_2.
\tag{6.3}
\]

A conservative auxiliary bound for Bessel generation, Clenshaw recurrence, and pairwise accumulation is

\[
\eta_{\mathrm{aux}}
\le
\sqrt{\frac QN}
C_0uM(1+R^2)B_J\|x\|_2.
\tag{6.4}
\]

Since `Q<2N` and `M,R` are polylogarithmic, the first term dominates asymptotically:

\[
\boxed{
\eta_{\mathrm{fp}}
=O\!\left(u\log N\sqrt{MN}\,\|x\|_2\right).
}
\tag{6.5}
\]

To keep this below a constant fraction of the statistical scale

\[
g\sqrt{\frac MN}\|x\|_2,
\]

it is sufficient that

\[
\boxed{
u=O\!\left(\frac{g}{N\log N}\right)}
\]

or, in mantissa bits,

\[
\boxed{
b
\ge
\log_2N+\log_2\log N-\log_2g+O(1)}
\tag{6.6}
\]

Consequences:

- fixed coarse error, where `g=Theta(epsilon sqrt(N/M))`, needs
  \[
  b\ge\tfrac12\log_2N+\tfrac32\log_2\log N+\log_2(1/\epsilon)+O(1);
  \]
- the five-row constant-failure shrinking regime, where `g=Theta(N^{1/6})`, needs
  \[
  b\ge\tfrac56\log_2N+\log_2\log N+O(1).
  \]

The saved constant-heavy model produced bit budgets of `34, 52, 86, 120, 154` bits for formal sizes near `2^20,2^40,2^80,2^120,2^160` in the five-row proxy regime. The ratios to `log2 N` trend downward toward the predicted leading coefficient.

### Important numerical limitation

The complex64 experiment is a stress test of decoder storage and accumulation only. NumPy's FFT and SciPy's Bessel routine internally use higher precision in this prototype. Therefore the experiment does **not** certify a complete binary32 implementation. A full theorem still needs a specific Bessel generator, root-table construction, and FFT implementation satisfying (6.1).

- exact integer nearest-grid mapping;
- selected-only versus complete v9 decoding;
- Clenshaw-streamed versus v10 materialized rows;
- pointwise Neumann-addition tail bounds;
- deterministic fused-center error bounds;
- asymptotic sufficiency of `H=0`;
- seeded fused-row variance bounds;
- conditional finite-precision stress;

- removal of rank-times-length storage;

Recorded summary:

- streamed/reference maximum discrepancy: `1.1236861156120876e-14`;
- selected decoder discrepancy: `0` in the saved cases;
- maximum deterministic addition-error/bound ratio: `0.00899549`;

- all 13 tests pass.

### Prototype timings

On this container, for `rank=10` and `N=511,...,8191`:

- exact streamed Clenshaw was about `1.44x--1.67x` faster than the v10-style materialized Python reference in the final rerun;
- fused `H=0` was about `2.30x--2.88x` faster;
- fused `H=1` was about `1.79x--2.23x` faster.

These are Python/SciPy prototype timings, not comparisons with FFTW and not evidence of asymptotic wall-clock superiority.

## 8. Prior-art boundary

The ingredients have established histories:

- Jacobi--Anger expansions and the Bessel generating function are classical;
- Neumann's Bessel addition theorem is classical;
- Clenshaw's recurrence is the classical method for evaluating Chebyshev series without materializing every polynomial;
- low-rank correction of nearby Fourier grids is established NUFFT methodology.

The project-specific composition tested here is narrower: apply the Bessel addition theorem inside the unit-step-chirp block summaries, preserve the v10 covariance argument, and stream the selected decoder through Clenshaw with no rank-dependent full-length storage.

A limited literature search did not identify this exact composition. That is not a novelty proof.

---

## 9. Honest conclusion and next target

v11 closes the two concrete engineering/proof obligations left by v10:

1. the saved implementation now really uses `O(N)` storage;
2. the all-length finite-precision budget has no leading multiplicative `R` penalty under a stated dyadic-row contract.

It also proves that one local Bessel summary channel is asymptotically enough, reducing input-side rank work from `Theta(RN)` to `O(N+RN/M)`.

It does **not** remove the `R` decoder scans. The next genuine breakthrough would need a joint evaluator for

\[
\{\operatorname{DFT}_K[J_r(\pi b/K)G_0[b]]\}_{r<R}
\]

and the associated gauged prefix scans without separately traversing all `R` channels. Renaming or vectorizing those scans is not an asymptotic improvement.
