# Reproduction

Requirements: Python 3.11+, NumPy. From the `fft_hero1_phase14` directory:

```bash
python run_all.py
```

Individual checks:

```bash
python -m unittest -v test_phase14 test_stationary check_v13 test_centered v11_test_checkpoint
python field_gram_audit.py
python field_stationary_audit.py
python green_forcing_gate.py
python leverage_gate.py
python experiment_phase14.py
```

`run_all.py` regenerates JSON outputs, checks previously preserved v13 tests, and exits nonzero on any failed test. The modular tests use their own prime-field primitive root and the exact chirp *recurrence*, not a NumPy FFT. Numerical tests against NumPy are not a formal identity proof; the general theorem rests on the algebra in THEOREM.md.

To check source integrity after extraction:

```bash
sha256sum -c MANIFEST.sha256
```

The manifest intentionally excludes itself and volatile test log files. Previous v13 sources are included in the root and the v13 package is nested intact as `PRIOR_v13_COMPLETE.zip`. The byte hashes in SOURCE_INTEGRITY.json tie this checkpoint to the unmodified predecessor.

The full-rank and graph-union extensions are additionally checked by:

```bash
python -m unittest -v test_stationary
python field_stationary_audit.py
python orbit_collision_gate.py
```

The all-basis finite-field stationary test uses a temporary **verifier-only** basis-response cache to make exhaustive checks efficient; the proposed fresh-input algorithm does not have or charge such a cache.
