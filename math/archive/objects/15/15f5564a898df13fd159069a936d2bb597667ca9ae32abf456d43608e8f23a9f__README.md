## Evidence rule

A historical execution claim requires a named past-run/replay statement or equivalent named launch evidence, with a verified binding to these exact bytes. The strongest command-linked examples are the earlier synthesis verification's explicitly passed six commands. Most other historical records are prose/structured replay declarations, **not raw process argv receipts**; the ledger keeps that distinction.

Saved output, a report saying controls pass, authorship, complete static reading, syntactic imports and package membership are separate axes. Their evidence is retained without forcing one into another. The 18-item shortlist uses a deliberately stronger direct-invocation threshold than mere control-output attribution.

No all-programs-run, full-code-review, trusted runtime import closure, exhaustive testing, mathematical correctness, performance or novelty claim follows. The 1,686-program universe is unchanged, and the active source-review queues are untouched. This reconciliation does not request new execution to manufacture historical evidence.
