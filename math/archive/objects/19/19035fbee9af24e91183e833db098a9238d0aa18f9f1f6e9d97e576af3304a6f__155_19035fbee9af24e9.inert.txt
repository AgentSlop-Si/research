FFT fusion audit and median-baseline implementation
9 October 2026

Read AUDIT.md first. This bundle independently checks the supplied fusion checkpoint,
implements its suggested optimal periodic median baseline, and gives a bounded
spectral obstruction to two forward cycle-K stages. The arbitrary-input exact
sub-N-log-N FFT goal remains unresolved.

Main files
- MEDIAN_BASELINE.md: proof, model, examples, exact output representation.
- median_baseline.py: portable deterministic linear-selection fit and rational
  decoder-output adapter, including exact quarter-frequency corrections.
- GREEN_FUSION_AUDIT.md: cycle and path-Green algebra, costs, error transport.
- TWO_STAGE_GATE.md: analytic proof excluding exactly two forward K stages for
  dyadic N>=8 even with arbitrary unitary interstage/end factors.
- SOURCE_INDEX.json: input identity and archive hash.

Reproduce the independently authored checks with standard Python 3:
  python3 median_baseline.py
  python3 check_residual_independent.py
  python3 green_audit/check_green_fusion_independent.py
  python3 green_audit/check_two_stage_gate.py

Each checker writes its result JSON alongside itself. The residual checker can
optionally verify the original source archive's manifest and parse its Python
files (without execution):
  python3 check_residual_independent.py --source /path/to/extracted/checkpoint
Without that optional source directory, only the independent rational checks run.
The included original result JSON records the manifest checks actually run during
this audit; a source-free rerun correctly reports that no source was supplied.

No uploaded code was executed. The median adapter does not run a sampler or
approximate decoder. These scripts are research controls, not an optimized FFT
or a performance benchmark. The median idea was already proposed in the upload;
the added artifact is its independent implementation and verification.
