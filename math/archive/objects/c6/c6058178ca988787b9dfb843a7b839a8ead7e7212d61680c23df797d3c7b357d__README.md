# FFT research — exact parity ranks and binary-affine depth no-go

This is a self-contained continuation of the user's global scan FFT research, dated **2026-10-10**. It includes the complete prior research ZIP and new, executable algebraic certificates.

## Main findings

1. Exact complex rank of all binary parity-by-parity Fourier blocks, in O(1) time per pair: N/4 or N/2 according to the highest set bits of the two masks.
2. An all-length no-go theorem: a Fourier factorization into t order-r quasiseparable scans and **arbitrary GF(2)-affine interstage permutations** must have `log2(N) <= t*ceil(log2(4*r*t))`.
3. The previously rank-feasible seeded 4-stage layout at N=256 **fails** the exact moving-partition gate at N=512 and N=1024 (and larger tested sizes). This doesn't settle its N=256 coefficient feasibility.
4. Verified 50 independent GF(2)-mixer samples per size at N=256,512,1024,2048,4096. The results reject all sampled N>=2048 cases, but are not a universal random-layout theorem.
