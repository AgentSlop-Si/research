# Linear-time, robust, linear-rank global Green stages by random path reordering

**Status:** Probabilistic all-N algebraic existence theorem with explicitly charged O(N) randomized setup, deterministic O(N) application, all-order balanced cut-rank guarantee, and independently exact-certified finite examples. **NOT a Fourier factorization or o(NlogN) FFT.**

## Stage

For even N divisible by 16, N>=32, choose a uniformly random permutation pi of N coordinates and denote its row-reordering matrix by P. Let

```
T=tridiag(-1,3,-1),  G=T^-1,
S_N = G + (1/100) P G P^T.
```

One `T` solve, one scatter/`T` solve/gather, one scalar multiply and an addition give **O(N)** field arithmetic, O(N) data movement, and O(N) storage. Generating the permutation requires O(N) randomized word operations and O(N) words; scalars are the fixed rationals 3,-1,1/100. There is no FFT lookup table, no expander search, no uncharged preprocessing and no enormous numbers.

`S_N` is real SPD and has

```
(1.01)/5 * I <= S_N <= 1.01 * I,
kappa_2(S_N) <= 5
```

because both Green terms have spectrum in [1/5,1].

## Lemma: robust singular values from path-edge expansion

For ANY two Hamilton path edge graphs on the same N vertices (not necessarily random), let e1,e2 be the numbers of their edges crossing a partition `(I,J)`; let E=e1+e2. For S=G1+0.01G2, the block inversion / induced-edge-matching argument in `GRID_THEOREM.md` proves

```
# { sigma_k(S[I,J]) >= 1/2500 } >= floor(E/15).
```

This holds across arbitrary coordinate partitions, without assuming the paths are expanders or the entries are generic. The key is that crossing path edges can be selected in induced matchings of density at least 1/3, producing singular values at least 1/25 in the Green off-blocks, and singular-value inequalities control the perturbation by the second path.

## Theorem: two independent random Hamilton paths expand across EVERY balanced cut

Fix a set U of exactly N/2 vertices, and choose a Hamilton path by a uniformly random permutation. Along that path, the membership pattern of U is a uniformly random balanced binary string. A binary string is determined by its starting bit and its set of transition positions. Thus, if t=N/16,

```
Pr[the path has <= t crossing edges on U]
 <= 2 sum_{j=0}^t binom(N-1,j) / binom(N,N/2).
```

For two **independent** random paths the probability that both have <=t crossing edges for a fixed U is at most the square. Union-bounding over all `binom(N,N/2)` choices of U gives

```
Pr[there exists ANY balanced U with e1(U)<=t and e2(U)<=t]
 <= 4 [sum_{j=0}^t binom(N-1,j)]^2 / binom(N,N/2).
```

The standard binomial entropy bound `sum_{j<=aN} binom(N,j)<=2^(N H_2(a))` (0<a<=1/2), together with `binom(N,N/2)>=2^N/(N+1)`, gives the explicit probability bound

```
p_fail(N) <= 4 (N+1) * 2^(-c N),
c = 1 - 2 H_2(1/16) > 0.3254.
```

For N=32 the RHS is already less than 0.097 and it decreases exponentially thereafter. Therefore with at least `1-p_fail(N)` probability, **every** balanced partition has `e1(U)+e2(U)>N/16` (because both cannot be <=N/16).

The event is invariant under simultaneously relabeling all vertices. Consequently the distribution and bound are identical when the **first path is fixed** in standard order and only the second path is randomly reordered. This is precisely the implementation above.

## Main conclusion

With probability at least `1-4(N+1)2^{-cN}`, every balanced cut of `S_N`—equivalently the central cut of `R S_N R^T` for EVERY permutation matrix R—contains at least

```
floor(N/240)
```

singular values >= 1/2500. In asymptotic notation, `Omega(N)` singular values remain bounded below by an absolute constant for every such cut, while the operator is applied in O(N) arithmetic and remains bounded-condition.

This defeats both previous *narrow obstructions*:

- The stage is not `O(1)` quasiseparable after some easy permutation (it has balanced-cut rank `Omega(N)` in **every** order, on the success event).
- The rank is not created by an arbitrarily tiny epsilon, a pathological condition number, or a superficial rank-one gauge; epsilon is 1/100 and at least `Omega(N)` singular values stay >=1/2500.

It **does not** mean the stage equals a DFT, implies sub-NlogN FFT, or by itself provides an exact DFT factorization of any fixed depth.

## Reproducible finite exact gap certificates

For concrete sampled permutations at N=32,64,128,256, `spectral_certificate.py` independently verifies a stronger deterministic property using **integer-only fraction-free elimination**:

Let Lgraph be the integer Laplacian of the two-path multigraph, and let J be the N x N all-ones matrix. If the integer symmetric matrix

```
K = 4N Lgraph + 4J - NI
```

is positive definite, then `lambda_2(Lgraph)>1/4`, since K has eigenvalue `3N` along the constant vector and `N(4 lambda_j(Lgraph)-1)` along any orthogonal eigenvector. For every balanced set U, the Laplacian Rayleigh quotient of its centered indicator gives

```
e1(U)+e2(U) >= lambda_2(Lgraph) N/4 > N/16.
```

`exact_ldlt_sylvester()` uses the Bareiss fraction-free recurrence, checks each integer division is exact, and requires ALL N leading principal minors to be strictly positive. Sylvester's criterion then certifies positive definiteness *exactly*, not just via floating point. These finite witnesses therefore satisfy the robust cut-rank claim **deterministically**, even though they were generated randomly.

The O(N^3) certificate calculation is a **separate audit only**. It is NOT part of, or hidden inside, the stage's O(N) randomized setup. For arbitrary large N, use the all-N high-probability proof, not a claim of free certification.

## Main research gate still open

Find an **exact** all-N factorization of a Fourier matrix, or a different structured transform of practical significance, into `o(log N)` genuinely independent O(N)-work global stages. Such a factorization must handle scalar and permutation preparation, allow arbitrary fresh complex inputs, and be proved algebraically, not merely suggested by rank or numerical fitting. No such factorization is in this package.
