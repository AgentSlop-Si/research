# Exact expander certificate for the saved four-stage Fourier candidate

**Date:** October 10, 2026  
**Claim:** For the *specific*, unchanged 256-coordinate affine permutation triple in `AFFINE_LAYOUT.json`, **no moving-partition / boundary-rank test of the previous kind can disprove the four-stage rank-one quasiseparable factorization**. This does **not** say that the Fourier factorization exists, nor does it eliminate full-network cuts or polynomial compatibility constraints.

## The input-independent graph

Let \(p_0,p_1,p_2\) be the three explicitly recorded eight-bit GF(2)-linear permutations. Start with the index array \(v_0=(0,1,\ldots,255)\), and define \(v_{j+1}=v_j[p_j]\) for \(j=0,1,2\). Construct an undirected multigraph on the original 256 coordinate labels by connecting each consecutive pair in **each** of the four arrays \(v_0,\ldots,v_3\). There are exactly \(4\cdot255=1020\) edges, counted with multiplicity. Let \(L\) be its integer graph Laplacian. For every set \(A\subseteq\{0,\ldots,255\}\),

\[
\mathbf1_A^T L\mathbf1_A
= \sum_{j=0}^{3}d(A_j),\qquad
A_j\text{ is }A\text{ transported through the first }j\text{ permutations},
\]

where \(d\) counts membership changes between consecutive coordinates in the corresponding stage's natural coordinate order.

## Integer positive-definiteness certificate

Read the **upper triangular integer** 256×256 matrix \(T\) from `INTEGER_CONGRUENCE_CERTIFICATE.json.gz`. Its diagonal entries are all nonzero. Define the entirely integer matrices

\[
M=50L-101I+50J, \qquad H=T^T M T,
\]

where \(J=\mathbf1\mathbf1^T\). All 256 diagonal entries of \(H\) are strictly positive, and every row satisfies

\[
H_{ii}-\sum_{j\neq i}|H_{ij}|\ \ge\ \boxed{4,681,152}>0.
\]

The least actual diagonal entry is **16,706,411**. Thus \(H\) is positive definite by the real symmetric strict-diagonal-dominance theorem. Since \(T\) is invertible, \(M\) is positive definite. On the constant-vector direction \(M\) has eigenvalue \(50(256)-101=12699>0\). On the orthogonal complement of the constant vector, it acts as \(50L-101I\). Hence

\[
\boxed{\lambda_2(L)>101/50=2.02.}
\]

This statement is proved by the **supplied integer matrix**, not by floating-point eigenvalues, Cholesky tolerances, or experimental sampling. `create_certificate.py` explains how the witness was found numerically. `verify_exact.py` verifies the integer witness from scratch; it does not use the numerical algorithm that found it. It also checks 29 independently computed entries using only Python unbounded integers and the sum-of-edge-differences formula.

The certificate has 32,264 nonzero entries and maximum absolute entry 1,416. The verifier proves a conservative absolute bound of **1,379,922,104,160** for its `int64` matrix products, avoiding wraparound.

## Consequence for every moving-partition certificate

For any nonempty proper \(A\), write \(a=|A|\). Let \(x=\mathbf1_A-a\mathbf1/256\). Then \(x\perp\mathbf1\) and

\[
\sum_{j=0}^3d(A_j)=\mathbf1_A^T L\mathbf1_A
=x^TLx
\ge\lambda_2(L)\|x\|^2
>\frac{101}{50}\cdot\frac{a(256-a)}{256}
\ge \min(a,256-a).
\]

(The final inequality follows by considering \(a\le128\) or \(a\ge128\).) In particular, all 128/128 bisections have **at least 130** boundary edges, because the real lower bound is strictly greater than \(129.28\), and edge counts are integers.

A two-sided quasiseparable order-one stage has crossing rank at most the number of its natural-order membership boundaries: partition the selected input columns into maximal runs; off-diagonal rows before and after each run each have rank at most one, with exactly one contribution per exposed run endpoint. Standard rank subadditivity along the four transported partitions gives

\[
\operatorname{rank}((S_4P_3S_3P_2S_2P_1S_1)[A_3^c,A_0])
\le\sum_{j=0}^3d(A_j).
\]

For *any* 256×256 target matrix \(M_{\rm target}\), including the Fourier matrix,

\[
\operatorname{rank}(M_{\rm target}[A_3^c,A_0])
\le\min(a,256-a)\ <\ \sum_{j=0}^3d(A_j).
\]

Thus the upper bound from **every one** of these moving-partition rank tests is too large to contradict even the largest possible target submatrix rank. This does not imply that a product with the target matrix exists.

## Useful generalization

For \(t\) stages of respective two-sided quasiseparable orders \(r_j\), weight each edge of the \(j\)-th transported path by \(r_j\), and call the weighted graph Laplacian \(L_r\). If \(\lambda_2(L_r)\ge2\), then for **all** nonempty proper input sets, this same family of moving-partition tests cannot disprove factorization into those stages. This is a general sufficient *rank-test-immunity criterion*, not a matrix-factorization sufficiency theorem.

## Limits

- This statement is about **one explicitly recorded N=256 permutation triple**. It does not imply an all-length factorization.
- It does **not** rule out an obstruction from a more general cut through the full scalar network, a polynomial identity, conditioning, or actual arithmetic cost.
- `EXPLORATORY_SPECTRAL_RESULTS.json` contains floating-point spectra of alternate layouts. They are **not** exact certificates or further theorems.
- No new O(N), sub-N-log-N, or even finite-size exact FFT factorization is provided.
