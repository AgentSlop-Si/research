# Annihilator-Closed Fourier Feedback

A research proposal and exact verifier, not a completed fast FFT implementation.

The proposed transform is `(I-BA)^(-1)B`. A cubic Fourier phase certificate and a low-degree annihilating polynomial for `BA` would make it an exact `O(N degree(mu))` algorithm when `A,B` and all preparation are uniformly cheap. The universal Fourier-compatible paired-Green factors are not constructed here.

## Files

- `THEORY.md`: the proposed architecture, proved conditional execution theorem, cubic correctness certificate, quadratic specialization, cost ledger and rejection theorems.
- `verify.py`: independent standard-library finite-field verifier and instrumented Green/Horner kernels.
- `RESULTS.json`: actual saved results of all nine test groups.
- `SOURCE_LEDGER.md`: source coverage, version information, prior-art and do-not-repeat boundaries.
- `ARCHIVE_TEXT_INVENTORY.json`: member paths and content hashes for the 1,798 Markdown/text occurrences in the reviewed master archive. This is an inventory, not a copy of the source archive.
- `MANIFEST.sha256`: hashes of the package files other than this manifest.

## Reproduce

From this directory:

```bash
python verify.py --output RESULTS.reproduced.json
```

Python 3.10 or later is required. No third-party modules are needed. The experiments use exact finite-field arithmetic. Dense Fourier matrices and elimination appear only in independent research oracles. The package does not benchmark against a production FFT.

## Essential interpretation

The Fourier-positive algebra controls deliberately use a dense Fourier oracle to generate their matrices. They are not cheap candidate factors. The genuinely cheap random paired-Green loops had degree N in all 40 saved instances and do not yield a faster transform. A uniform Fourier-compatible low-degree family remains the central conjecture.
