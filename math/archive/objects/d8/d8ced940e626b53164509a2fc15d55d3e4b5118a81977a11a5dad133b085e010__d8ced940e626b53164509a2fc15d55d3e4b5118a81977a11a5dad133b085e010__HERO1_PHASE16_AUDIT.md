## Result

The principal new identities and complex conditioning bounds survive. The source constructs a uniformly conditioned family L_pi=7I+D+2P_pi, with arbitrary permutation pi, a linear-arithmetic cyclewise inverse, and fully dense forcing B_pi=L_pi F. Applying L_pi and L_pi^{-1} both costs O(N) with properly charged coefficient construction. Thus computing B_pi and computing F are equivalent up to linear work. This is a valid reduction and warning against hiding a Fourier computation in the forcing, not an FFT lower bound or a new fast transform.

For the ordinary cyclic shift S, Fourier covariance gives LF=F(7I+S+2D^{-1}). More generally S^a D^b F=F D^{-a} S^b, in that order, for signed exponents. A q-atom Weyl list becomes a q-atom input preconditioner, requiring O(qN) direct application. Irregular permutation graphs do not need a sparse Fourier conjugate for the two-way forcing reduction.

Since S,D,P_pi are unitary, the triangle inequality gives ||L_pi||<=10 and sigma_min(L_pi)>=4, so condition number<=5/2. Each complex forcing entry has magnitude between4/sqrt(N) and10/sqrt(N). The source correctly avoids inferring quadratic arithmetic cost from density. Its arbitrary-permutation family includes commuting examples such as pi=identity; uniform noncommutation is asserted only for the original cyclic shift family.

## Unitary entropy content is inherited/reproduced

The source accurately attributes the pair-unitary entropy lower bound to Ailon. In the in-place unitary pair-gate model, the entropy gain is at most 2 bits per gate, so the Fourier target requires at least N log2(N)/2 such gates. The approximate corollary follows from row total-variation <= row Euclidean error, entropy continuity, Jensen and RMS-to-mean: for unitary U within epsilon sqrt(N) Frobenius distance, epsilon<=1/2, the required pair-gate count is at least(N/2)[log2(N)−epsilon log2(N−1)−h2(epsilon)].

This does not provide a new unrestricted arithmetic lower bound. The master already retains the corresponding unitary gate barrier and ancillary-space extension under its own hypotheses. The source's decision not to claim an ancilla extension here must not erase that separately proved prior result. Source floating entropy diagnostics are not exact certificates.

## Implementation ledger corrections

The mathematical O(N) setup is attainable, but the shipped setup does not demonstrate it literally:

- WeylGreen and PermutationGreen generate each omega^k with a separate modular pow, costing O(N log N) ordinary modular multiplications under repeated-squaring accounting. One recurrence-generated root table repairs this.
- permutation_cycles validates with sorted(pi), costing O(N log N) comparisons. A bitmap validation repairs this in O(N) word operations when indices fit the specified word model.
- The displayed setup recurrence h=(-b*h)*inverse_diag has two literal multiplications per coordinate; calling it one presupposes a precombined ratio whose construction must also be charged. This affects constants, not the O(N) attainable bound.
- Field inversions, input reading, coefficient/root preparation, permutation storage, cycle schedules, temporary arrays and output writes remain charged. The exact-complex conditioning bound alone does not provide a finite-precision forward-error or bit-complexity certificate.

No source code was patched; these are audited distinctions between an attainable recurrence implementation and the supplied source schedule.
