# HERO #0 — Phase 16: asymmetric Green circuits and Fourier gauge curvature

**Complete reproducible research checkpoint, 10 October 2026.**

The project tests whether globally mixing, O(N)-executable graph Green resolvents can realize an exact Fourier transform on **every fresh input** with O(N) or O(N log log N) sequential work. **They have not.** This bundle includes two newly derived restricted impossibility families and a finite N=4 positive control, not a universal faster FFT.

Files:

- `THEOREMS.md` — definitions, detailed proofs, quantitative bounds, exactness/model restrictions, prior-art caveats
- `phase16_gauge.py` — exact modular Fourier matrices, monomial-centralizer checks, O(E) gauge recognizers, green network application, rank/support gates
- `test_phase16.py` — independent positive and negative tests
- `positive_small_factor.py` — SymPy **exact** two-layer four-Green-factor certificate for unnormalized F4
- `explore_rook.py` — OPTIONAL exploratory nonlinear fitting, *not* a proof; exact F4 source supersedes it
- `audit.py` — regenerates deterministic metadata and findings in `RESULTS.json`
- `CHAIN_HANDOFF.md` — the Phase 17 mathematical target and known dead ends
- `prior_phase15_bundle.zip` — intact earlier lineage
- `inherited_phase15_tests.log`, `inherited_phase14_tests.log` — independently rerun prior tests

Run:

```bash
OPENBLAS_NUM_THREADS=1 python -m unittest -v test_phase16
OPENBLAS_NUM_THREADS=1 python positive_small_factor.py
OPENBLAS_NUM_THREADS=1 python audit.py
```

The main new discriminator is **genuine gauge curvature**, not merely vertex-dependent coefficient variation. An all-input Fourier factorization still requires solving all Weyl compatibility equations. A graph that passes rank and gauge tests is *only* a candidate.
