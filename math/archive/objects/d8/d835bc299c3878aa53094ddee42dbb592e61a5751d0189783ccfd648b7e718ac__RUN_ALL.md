# Reproduction commands

No extra dependencies for theorem support:

```sh
python -m unittest -v test_gate
python central_partition.py
python verify_cut_certificates.py
```

Optional independent graph and search audit with NetworkX/SciPy:

```sh
python verify_graph_cuts.py
python escape_shuffle_probe.py
python optimize_deficit.py
```

The graph certificate generator (`make_cut_certificates.py`) is a **discovery tool**. Verification of its resulting certificates does **not** require it or any optimization package.

Previous research generation is preserved intact in `prior_checkpoint_full.zip`; extract that archive to replay its earlier tests.
