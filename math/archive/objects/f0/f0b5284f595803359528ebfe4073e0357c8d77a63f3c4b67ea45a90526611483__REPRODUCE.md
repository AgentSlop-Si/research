# Portable independent reproduction

Requires Python 3.10+ and its standard library only. Never execute the uploaded programs under extracted/. The following are independently authored audit scripts.

From the root of this audit directory:

    python3 research/independent_checks.py . multistage-results.json
    python3 research/independent_extra_checks.py multistage-extra-results.json
    cmp multistage-results.json research/INDEPENDENT_RESULTS.json
    cmp multistage-extra-results.json research/EXTRA_RESULTS.json
    sha256sum -c SEALED_MANIFEST.sha256

The main checker reads only uploaded JSON data: audit.json and the three Bezout coefficient files. It independently reconstructs all parameters, solves the sparse resolvent systems, verifies inverses, reconstructs Fourier matrices, verifies the coefficient identities by enough exact evaluations to identify the polynomials, and checks their Bezout identities. Explicit order and gauge arrays are saved in its output. No uploaded Python import or execution is involved.

The extra checker imports only the independently authored first checker as a helper; it performs general Casoratian, moment-invariance and sparse-system controls and records the source API's noncanonical-residue counterexample. It does not import a module from extracted/.

A relocated run was completed in fft_multistage_portable from /tmp, using copied source data and both independent checkers. Both resulting JSON files matched the original saved outputs exactly. PORTABLE_REPRODUCTION.json records hashes and the check outcome. The temporary path is historical run metadata, not a runtime dependency.

The extraction/comparison utility is an audit-provenance script with explicit original master paths, not part of this portable reproduction entrypoint. Source-provided tests/logs are retained unchanged as historical claims; they were not rerun. The all-size statements rely on the written proofs; finite tests are supplementary.
