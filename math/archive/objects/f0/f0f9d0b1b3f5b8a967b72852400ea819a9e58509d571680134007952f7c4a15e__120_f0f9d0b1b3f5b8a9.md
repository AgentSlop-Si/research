# Interleaved scan FFT research: exact stage-count and broadcast-rank obstructions

**October 9, 2026.** A self-contained, reproducible finite-field experiment supporting two all-length, *architecture-specific* proofs for fresh full Fourier transforms.

## Result

For a Fourier matrix F_N factored as invertible weighted **one-way scans**, arbitrary permutations/diagonal scalings and invertible rank-r global broadcast updates:

- Without broadcasts, `t >= ceil(log2(N))` scans; for powers of two `t >= log2(N)+1` from a support-mass refinement.
- With a total broadcast rank budget `B`, `(B+1)(2**t+1)>N`.
- These bounds hold **despite arbitrary permutations between stages**. They are not universal FFT lower bounds.
- A complete radix-2 FFT is implemented by two one-way scans per butterfly level, providing a correctness control (not a faster transform).
- A separate O(N)-cost **sum** of forward/backward scan results can have a dense inverse. That operation lies **outside** the theorem and is a possible next restricted search family, not a discovered FFT shortcut.

## Reproduce

Python 3.11+ standard library only. No network, no SciPy, no threading or cached FFTs.

```bash
cd fft_interleaved_scan_barrier
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s tests -v
PYTHONDONTWRITEBYTECODE=1 python independent_audit.py
PYTHONDONTWRITEBYTECODE=1 python run_audit.py
```

Output files `audit_results.json` and `independent_results.json` contain exact counts. The data FFT is tested on new inputs modulo 998244353, with a separate 2013265921 check. The theorems extend to any characteristic allowing N distinct roots, and to C; these *fixed* modular implementations support finite powers of two and are not all-length bit-complexity theorems.

### Files

- `RESEARCH.md`: self-contained statements, proofs, exclusions and literature comparison.
- `scan_hybrid.py`: weighted scans, their inverses, interleaved random networks, low-rank broadcast matrices, rank and Vandermonde checks, and an ordinary FFT coded using two scans per butterfly level.
- `independent_audit.py`: second implementation of modular rank elimination, root checks and exact factorization identity, with **no imports from the main module**.
- `run_audit.py`: record all finite control tests and the broadcast tradeoff table.
- `tests/test_scan_hybrid.py`: full exact regression tests.
- `NEXT_GATE.md`: the next surviving mechanism and rejection criteria.

Do not interpret low stage counts as lower physical cost. In the all-output FFT control, all scans, permutations, twiddle multiplications, memory moves and root/constant preparation must be included. `audit_results.json` explicitly distinguishes data-path arithmetic from twiddle preparation and stage-root exponentiations.
