# Hero #1 Phase20 — Blind sparse-rational graph reconstruction

**Status:** Exact, tested, project-specific finite-field reconstruction. **Not** an arbitrary-input sub-`N log N` FFT.

The new `resultant_gate.py` recovers an unknown graph delay `delta` and multiplier `alpha` from dense residual `r` when `(I-alpha S^delta)r` has <=2 impulses, under a checked algebraic nondegeneracy condition. It uses only eight directly calculated Fourier probes, two 3x3 Hankel determinants, a degree-<=45 resultant in the unknown shift root, an O(N) root-group evaluator, and a full exact defect certificate. It also handles a single resonant Fourier frequency for coprime delays, including the Phase19 wrap-collision counterexample.

The hybrid `hybrid_phase20.py` runs the original blind-ratio and sparse-inverse detectors first, sharing the same eight Fourier samples between the inverse detector and the new resultant detector when both are needed. All arbitrary input data are handled through a full exact FFT fallback.

**Reproduce:** `python -m unittest discover -p 'test_*.py'`, `python exact_basis_audit.py`, `python exhaustive_small_gate.py`, `python benchmark_phase20.py`. Pure Python standard library; tested on Python 3.13. `RUN.md` documents the full clean-extraction replay.
