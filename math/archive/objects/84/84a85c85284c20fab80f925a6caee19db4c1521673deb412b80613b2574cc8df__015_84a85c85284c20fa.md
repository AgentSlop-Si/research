# Joint Galois-orbit reuse: an exponential stability barrier

**Date:** October 9, 2026.  
**Status:** All-length analytic theorem for a specified measurement/recovery architecture, exact finite-field orbit checks, an exhaustive small binary experiment, and an explicit precision tradeoff. **No novel full exact O(N) FFT algorithm, no worst-case arithmetic lower bound, and no priority claim.**

## 1. The exact target and why this is a new checkpoint

Our main target remains a **complete, explicit, fresh-input exact DFT** in a sequential arithmetic model, with all computation charged, ideally O(N). This pass investigates one precise next step from `fft_boolean_orbit_recovery/NEXT_GATE.md`: *joint recovery* of all Galois conjugates of the primitive Fourier output, rather than the already-rejected scalar-polynomial recovery from one value to one value.

Previous research already showed that for power-of-two N, one exact numerical DFT measurement at each cyclotomic conductor suffices to identify every rational/binary vector, and that these O(log N) exact measurements contain no **cheap scalar-conjugacy extraction**. Here we establish a different quantitative limitation: **any recovery of all outputs from a small number of primitive frequencies is inherently exponentially ill-conditioned on a natural binary subfamily**, regardless of the decoder's algebraic degree, branching, or nonlinear gates. The bound does NOT apply to algorithms that also use the original input or intermediate linear forms during reconstruction.

This is a conditioning and bit-precision obstruction to a specifically **measurement-only** recovery strategy, not an Omega(N log N) arithmetic-gate theorem.

## 2. Binary family and odd-orbit formula

Let N=2m=2^t, t>=3, zeta=exp(2 pi i/N). For each u in {0,1}^m, define a full length-N binary signal

    x(u) = (u_0,...,u_(m-1), 1-u_0,...,1-u_(m-1)).

There are exactly 2^m different signals. For the unnormalized DFT

    X_u[k] = sum_(j=0)^(N-1) x(u)_j zeta^(kj),

its even frequencies are independent of u:

    X_u[0] = m,     X_u[2t]=0 for t=1,...,m-1.

For odd k, write r_j=2u_j-1 in {-1,+1}:

    X_u[k] = sum_(j=0)^(m-1) r_j zeta^(k j),

so |X_u[k]|<=m. Because Phi_N(z)=z^m+1, {1,zeta,...,zeta^(m-1)} is a Q-basis of Q(zeta). Consequently X_u[1] is injective as a function of u, in exact characteristic-zero arithmetic. Every primitive odd k gives another Galois embedding of the same field element. One representative from every conductor and in particular one odd frequency thus suffices for uniqueness, as proved in earlier artifacts.

**Uniqueness is not stability.** The map u -> X_u[1] encodes m independent bits into one exact algebraic complex number of bounded magnitude.

## 3. The theorem: exponential condition number for any joint recovery

**Theorem.** Select **any** r odd Fourier-bin indices k_1,...,k_r, with 1<=r<=m, and let

    H_r(u)=(X_u[k_1],...,X_u[k_r]) in C^r.

Suppose a map G defined at every H_r(u) reconstructs the complete unnormalized Fourier spectrum:

    G(H_r(u))=X_u in C^N  for every u in {0,1}^m.

Measure distances using max absolute complex coordinate norm on both spaces and write L for the Lipschitz constant of G **restricted to these 2^m exact points**. For

    a=floor(m/(2r)),   M=2^a-1,

the following bound holds whenever M>=1:

    **L >= M/(2m) = (2^floor(N/(4r))-1)/N.**

If H_r has a collision, no such function G exists; the theorem is then vacuously stronger. In the canonical r=1 case H_1 is injective, so the bound is a real conditioning restriction.

**Proof.** Every H_r(u) lies in [-m,m]^(2r) after separating real and imaginary parts. Partition each real coordinate interval [-m,m] into M equal cells, so there are M^(2r) cells. Since M^(2r) < 2^m, two distinct bitmasks u,v fall into the same cell. Each real coordinate of H_r(u)-H_r(v) differs by at most 2m/M, so

    ||H_r(u)-H_r(v)||_(infinity,complex) <= 2 sqrt(2) m/M.

The signals x(u),x(v) differ in at least two coordinates, hence ||x(u)-x(v)||_2>=sqrt(2). Unnormalized DFT Parseval gives

    ||X_u-X_v||_2=sqrt(N) ||x(u)-x(v)||_2.

With N output entries, the maximum output magnitude is at least the input l2 norm:

    ||X_u-X_v||_(infinity,complex) >= ||x(u)-x(v)||_2 >= sqrt(2).

Divide the last two inequalities. Necessarily L>=M/(2m)=M/N. QED.

The same condition number holds if the **selected measurements and reconstructed outputs are normalized by the same N**: both input and output distances scale together.

**Corollary (polynomially conditioned recovery).** If one demands L<=N^C for some fixed C>0 for every large N, then

    2^floor(N/(4r))-1 <= N^(C+1),

forcing r=Omega(N/log N). This is a *necessary* number of **primitive odd representative measurements** for this measurement-only scheme, not a sufficient bound or a time lower bound.

For the earlier canonical one-representative-per-conductor selection Q={0,1,2,4,...,N/2}, the entire binary subfamily has identical even measurements. Therefore its global decoder obeys the r=1 bound:

    **L >= (2^(N/4)-1)/N** for N divisible by four.

### Scope of the theorem

- The decoder is allowed unlimited complexity, nonlinear arithmetic, high polynomial degrees and arbitrary branching; only the measurement-only interface and Lipschitz notion are constrained.
- The lower bound is **not** a lower bound on DFT runtime, arithmetic circuit size, or exact unit-cost complex operations. An exact but exponentially unstable decoder is not excluded.
- Computing the full FFT using the original N input bits or richer intermediate state is not covered.
- The argument uses ordinary complex measurements, not unit-cost Galois automorphism oracles. Frobenius FFT over extension finite fields is a different, already published algorithm family (see prior art).

## 4. The finite-precision cost without assuming decoder continuity

Quantize each selected unnormalized odd Fourier value's real and imaginary parts to a uniform grid of spacing 2^-b, where b>=0 is the number of fractional bits.

Since each real part lies in [-m,m], there are at most `N*2^b+2` distinct grid cells per real coordinate. Therefore all r complex values carry at most

    (N*2^b+2)^(2r)

different quantized encodings. For a deterministic quantized representation to identify all 2^m possible u, a necessary condition is

    (N*2^b+2)^(2r) >= 2^m.

Because `N*2^b+2 <= (N+2)*2^b` for b>=0, this implies the conservative asymptotic lower bound

    **b >= N/(4r) - log2(N+2).**

The executable audit computes a stronger integer threshold by checking the exact cell-count inequality directly. At N=1024 and one odd bin, at least 246 fractional bits are necessary even to *avoid a forced quantization collision* among this subfamily; the bound does not guarantee sufficiency at that precision.

This is why treating one unbounded-precision exact algebraic Fourier scalar as one inexpensive 64-bit floating-point number is not valid.

### Measuring more odd bins: a positive stability control

For real-valued inputs, conjugate symmetry gives `X[N-k] = conjugate(X[k])`. Thus for the complementary family we can measure `r=N/4` odd bins `k=1,3,...,N/2-1`, fill the remaining odd bins by conjugation, and fill even bins with the known constants. This all-output reconstruction is exactly **1-Lipschitz** in the max-complex-coordinate norm (provided the fixed even bins are treated as known). Hence the lower bound `r=Omega(N/log N)` for polynomially conditioned recovery is within a logarithmic factor of an elementary `r=N/4` **upper bound on measurement count**. This is **not an FFT arithmetic speedup**: evaluating that many representative frequencies from fresh input still costs work.

A second exhaustive numerical experiment adds odd representative frequencies jointly rather than reconstructing them separately. Verified high-precision examples show sensitivity ratios decreasing from about `43.9` (r=1) to `7.52` (r=2) to `1` (r=4) at N=16, and `1543` (r=1) to `199` (r=2) at N=32. These are lower bounds witnessed by selected pairs; they are not the exact maximum condition numbers. See `joint_measurement_audit.py` and `joint_measurement_results.json`.

## 6. Independent exact arithmetic verification

`modular_audit.py` separately constructs primitive N-th roots over F_998244353 for N in {8,16,32,64}, calculates **all N DFT values** by direct O(N^2) summation for fresh binary signals, and verifies:

- all even Fourier values are constant across the family;
- every odd Fourier value equals the reduced power-basis expression;
- multiplying exponent indices by an odd k acts as a *signed permutation* of the coefficients in the N-th cyclotomic power basis;
- the orbit formula matches a separately evaluated modular expression.

The exact modular audit covers 112 fresh vectors, 1680 even coordinates and 1680 odd-orbit coordinates. It does **not** prove complex injectivity (finite-field specializations can collapse nonzero cyclotomic values). That is proved over Q from the minimal polynomial.

`python -m unittest discover -s tests -v` also checks the packing constants, Parseval separation, growth with r and b, high-precision witnesses, input validation, joint representative controls, and exact modular identities.

## 7. Prior art and why this is not CrocSwap

- Galois orbit compression and finite-field Frobenius FFT are prior art. See van der Hoeven and Larrieu, *The Frobenius FFT*, ISSAC 2017, https://doi.org/10.1145/3087604.3087633 and its 2018 additive extension https://arxiv.org/abs/1802.03932.
- The finite binary family's ambiguity outside the primitive orbit and one-per-conductor exact injectivity were already established in **our** earlier Boolean spectral completion and orbit recovery artifacts. This pass does **not** relabel them as new.
- The packing/quantization argument is elementary information theory; we assert **no first-publication priority** for its application to Fourier measurements. Its value to *our project* is a quantitative falsification of a specific unstable joint-conjugacy shortcut that the earlier **scalar degree** bounds did not rule out: an unrestricted high-degree decoder with good numerical conditioning.
- No CrocSwap integer multiplication kappa/circuit/rank constants were optimized, and no cached signal relation, repeated queries, partial output, multi-core execution or lookup oracle is involved.

## 8. The exact unsolved question after this experiment

One or a few primitive Galois measurements can encode an entire binary spectrum in exact arithmetic, but they cannot be a **polynomially conditioned** all-output decoder under the stated interface.

The remaining challenge is a genuinely **joint, charged evaluator** accessing the original input or sufficiently many shared intermediate states, not a decoder of O(log N) exact scalars. To keep stability polynomial, a measurement-only strategy needs Omega(N/log N) primitive values even before it tries to generate the other outputs, and computing those with the known classical pruned method approaches ordinary FFT complexity.

A proposed new algorithm must supply a complete arithmetic DAG/recurrence for all fresh inputs with all outputs, every preparation and intermediate operation counted; symbolic orbit descriptors, implicit Galois automorphisms and enumeration over output encodings do not qualify.

**Verdict:** Proof of an exponential conditioning and precision barrier for the previously untested joint-orbit recovery interface; **no new uniform O(N) exact FFT or sub-NlogN arithmetic upper bound**.
