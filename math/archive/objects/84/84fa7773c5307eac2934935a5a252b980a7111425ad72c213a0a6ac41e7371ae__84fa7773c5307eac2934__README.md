## Reproduce safely

Requirements: Python 3 and NumPy. There are no external file dependencies: the checker reads the packaged `source_evidence` directory by its own path.

The checker writes its results beside itself. Preserve the seal by copying this entire audit directory to a separate scratch location, then run:

    OPENBLAS_NUM_THREADS=1 python independent_checks.py

This invokes only the fresh checker. It does not invoke the source's tests, prototype, benchmarks, or dependencies beyond the auditor's use of NumPy for clearly marked floating spectral comparisons. Exact arithmetic checks use only standard-library integers and Fractions.

Check the preserved delivery from this directory with:

    sha256sum -c SHA256SUMS.txt

The manifest covers every delivery file except itself and `SEAL.json`; `SEAL.json` records the manifest hash. Reproduction changes the timing field and therefore should be done in a copy.
