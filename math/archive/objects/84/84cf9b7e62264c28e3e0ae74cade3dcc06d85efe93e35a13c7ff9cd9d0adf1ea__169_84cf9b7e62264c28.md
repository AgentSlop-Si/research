# Research fusion: residual-certified Green bridge

The useful result is a finite-word, residual-certified realization of the previously conditional Green → periodic-median residual → decoder → target-inverse pipeline.

- `PROOF.md`: construction, exact error certificate, root generation, complete compositional cost and scope.
- `EVIDENCE_MAP.md`: source-backed connections and why the obvious exact filter composition was not counted as a new result.
- `check_fixed_bridge.py`: independently written fixed-point bridge and checks; no uploaded code is imported.
- `results.json`: recorded results, including near-Green-periodic dense integer inputs and isolated target checks.

Run `python check_fixed_bridge.py` with mpmath installed. mpmath and direct DFTs are test-only oracles. The runtime bridge itself uses integer fixed-point arithmetic and exact bounded-size certificate computations. The complete growing-parameter decoder is a proved external interface, not implemented here.

The exact arbitrary-input all-output sub-N-log-N FFT goal remains open. This is an approximate, data-dependent extension, not a breakthrough claim or a speed benchmark.
