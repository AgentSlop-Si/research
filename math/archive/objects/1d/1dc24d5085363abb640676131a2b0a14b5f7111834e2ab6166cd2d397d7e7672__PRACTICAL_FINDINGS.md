# Practical findings before reusing the research code

These are static findings and separately labeled independent controls. The supplied implementations were not executed, imported, compiled or AST-parsed. A weak generic verifier does not, by itself, invalidate a specific saved certificate.

| Priority | Finding | Evidence and implication |
|---|---|---|
| Memory safety | Native dtype and layout contract omitted | reuse_source_review_0501_b/MAIN_REPORT.md, S31–S32. Raw pointers require one-dimensional contiguous complex128 buffers of the correct size. The archived benchmark uses the intended layout; malformed callers can access beyond buffers. |
| Memory safety | Negative raw sparse offsets | material_extension_source_review_0500/REPORT.md, MEX-03, and remaining_algorithm_source_review_0516/REVIEW.md, source18. C++ remainder can preserve a negative index; validated prepared input and a raw ABI have different safety guarantees. |
| Correctness | Spectrum-only fallback loses the known base | remaining_gates_source_review_0509/REVIEW.md, S40. For N=2, the expected edited spectrum [3,1] is replaced by placeholder-only [1,1]. |
| Correctness | Dependent-basis state and stale cached plans | remaining_gates_source_review_0509/REVIEW.md, S02 and S15; remaining_structure_source_review_0519/REPORT.md, F1. Basis/spectrum dimensions can diverge, or changed input/sample can reuse old data-dependent state. |
| Correctness | Mutation before overflow rejection | remaining_algorithm_source_review_0516/REVIEW.md, source39. Cached output may change before an exception while metadata stays old. |
| Accuracy | Tiny finite vectors classified as zero | nested_macro_source_review_0447/REVIEW.md, S04; remaining_transform_source_review_0515/REVIEW.md, S13. Naive norm underflow breaks the advertised finite-input tolerance outside ordinary-scale tests. |
| Accuracy | Mixed-scale pruning loses representable components | reuse_source_review_0501_b/MAIN_REPORT.md, S32. Dividing a tiny value by a huge global maximum may erase it before zero pruning. |
| Accuracy | Cancellation and reassociation | phase_source_review_0501_a/REVIEW.md and reuse_source_review_0501_b/MAIN_REPORT.md. Ring identities and deliberately passing cancellation tests do not certify floating accuracy; rebase is a distinct operation. |
| Certificate integrity | Vacuous success and omitted guards | inverse_engine_source_review_0445/REVIEW.md, source013; global_reuse_source_review_0459/REPORT.md, F01/F03; remaining_algorithm_source_review_0516/REVIEW.md, source19. Enforce required witness/output populations, strict cut tests and q < 1 independently. |
| Certificate integrity | Incomplete primitive-root checks | global_reuse_source_review_0459/REPORT.md, F04; remaining_transform_source_review_0515/REVIEW.md, S08; archived_audit_source_review_0523/REVIEW.md. Certified fixed dyadic examples and arbitrary input orders have different guarantees. |
| Cost | Hidden scanning, promotion and replanning | nested_macro_source_review_0447/REVIEW.md; phase_source_review_0501_a/REVIEW.md, S076; remaining_algorithm_source_review_0516/REVIEW.md, sources12/34; reuse_source_review_0501_b/MAIN_REPORT.md, S25. Separate worst-case, amortized and selected-work claims. |
| Storage | Plan budgets do not bound all live memory | reuse_source_review_0501_b/MAIN_REPORT.md, S19/S25. Fallback plans, simultaneous candidates, history, object overhead and outputs can exceed the quoted payload budget. |
| Fixed-word claims | Packed objects exceed one word | remaining_small_source_review_0522/REVIEW.md. Many recorded table keys or packed tiles exceed their stated word budgets; unbounded-integer identities need a separate bit/word-cost bill. |
| Evidence | Test invocation and historical versions | Multiple packages document unittest.main before later classes. Discovery can run those classes, so matching historical discovery logs should not be relabeled as truncated. Missing Numba causes one later replay to fail despite an earlier successful environment. |
| Data handling | Expression parsing in a certificate route | archived_validation_source_review_0528/REVIEW.md, S33. SymPy sympify on stored coefficient strings is not an inert JSON-only interface and should not be reused on untrusted expression text without a restricted parser. It was not invoked in this review. |
| Evidence | Candidate-word replay not comprehensive | remaining_small_source_review_0522/REVIEW.md. Nine of ten two-round certificates omit candidate_word; a stored PASS therefore does not establish those nine candidate replays. |

All other source-specific qualifications, positive finite certificates and suggested repair boundaries are retained in the complete packages. No code changes are included in this checkpoint.
