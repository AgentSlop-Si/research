# Consolidated material audit

9 October 2026. Four attachments inspected. No uploaded source or bytecode was executed. New verification programs were written separately and identified below.

## Bottom line

There is genuine progress on a carefully defined coarse approximate transform: the fixed-accuracy signed-atom/table method admits a fully charged O(N) word-RAM evaluation under explicit bounded-input assumptions. The latest attachment supplies the simplest packing closure, using one prepacked table and guarded word additions. The existing prototype does not implement that asymptotic evaluator and supplies no practical speedup evidence. Novelty is not established.

The user's original fresh-input, arbitrary-complex, exact all-output Fourier speedup remains unachieved by these materials. Separately, the exact branch has obtained stronger finite rank exclusions, including the sharp F32 11-by-11 rank gate. None is an exact faster transform.

## Precisely supported approximate proposition

For fixed epsilon in (0,1), fixed c>=1, and fixed C, on a randomized word RAM with w=Theta(log N) large enough for the declared widths, take input real/imaginary integers bounded by N^C (or a common word-encoded dyadic/bounded-rational scale). There is a fully charged O(N)-time, O(N)-word algorithm which reads every fresh input, writes every approximate coefficient explicitly, and with failure probability at most N^(−c) satisfies

    max_m |output_m−(U_N x)_m| <= epsilon L_box(x)/sqrt(N).

The proof charges exact mass sampling, capped random rejection, uniform phasor preparation, all input-independent tables, phase descriptors, packed accesses, output normalization, and output writes. Small sizes have a finite parameter-dependent fallback. Packing is proved; it is not an outstanding condition.

This is a model-specific approximation result. Constants and crossover thresholds can be enormous. The bound can permit error of order epsilon sqrt(N) on flat dense signals with typical coefficients of order one. It is therefore not a replacement for ordinary high-accuracy FFT use. The whole O(N) evaluator has not been implemented or benchmarked here. A proper prior-art review remains necessary before any originality claim.

The particular coordinate-sampled estimator needs Omega(N) samples for uniformly bounded O(1) absolute error with failure below a constant: `../approximation/SAMPLER_STRONG_ACCURACY_LIMIT.md` proves this via a balanced-sign input and a fourth-moment bound. This is not a lower bound on all input-aware approximate Fourier algorithms.

## Exact research advanced alongside this audit

The separate proof at `exact_rank/PROOF.md` establishes that every 11-by-11 complex F32 submatrix has rank at least 5, and supplies a sharp witness. It uses a small exact rational second-moment certificate with 63 polytope vertices and a separate 617-profile audit. Combining this with the earlier two-stage product bound excludes the five remaining unsigned coordinate-bit middle permutations at N32, hence all 120 in that bounded family for arbitrary endpoint orderings. Arbitrary middle permutations and shifted candidates remain open. This is an exact structural advance, not an FFT speedup construction.

## Recommended conclusion

Accept the approximate packing closure and the exact rank/certificate improvements. Correct the endpoint-order wording, retain the explicit model limits, and separate primitive checks from an end-to-end implementation. Do not market these materials as an industry breakthrough, an exact sub-N log N FFT, or a proven novel algorithm before the remaining accuracy, implementation, and literature questions are answered.
