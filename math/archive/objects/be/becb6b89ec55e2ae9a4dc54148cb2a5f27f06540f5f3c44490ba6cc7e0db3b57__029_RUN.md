# Reproduction instructions

Python 3.10+ (stdlib only for Phase 27 code).

```bash
cd fft_green_phase27_nonaffine_phase_recovery
python -m unittest discover -s tests -v
python audit.py
sha256sum -c SHA256SUMS.txt
```

The spectral audit computes exact integer Bareiss pivots for a 256x256 matrix and may take several seconds. It does **not** enumerate all balanced cuts. The eigenvalue deduction from K positive definite certifies every balanced cut.

No Internet, NumPy, or SymPy is required. Phase 27 uses prime 998244353 for finite-field tests. Only proofs stated uniformly in `THEOREM.md` apply to arbitrary N; passing finite-field cases never proves a complex analytic identity or a new FFT runtime.
