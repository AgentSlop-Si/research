# Reproduction and scope

Requirements: Python 3 and installed SymPy. The scripts use exact rational, integer, cyclotomic-field, and finite-field arithmetic. There are no floating-point zero tests.

From this directory:

1. `python fixed_bases.py > FIXED_BASE_RUN.log 2>&1`
2. `python exact_controls.py > CONTROL_RUN.log 2>&1`
3. Compare the resulting exact coefficient arrays, contents, orders, leading polynomials, and exception checks to the sealed JSON results.

`fixed_bases.py` reproduces the complete paired lower-guard remainders for d=3,7,11,15,19. Its elapsed-time fields are incidental and will differ on another run. `exact_controls.py` reproduces seven shared-cluster series checks, four exact full-discriminant checks, denominator-free reciprocal identities, selected characteristic-p Wronskians, and five old finite exception certificates. Its only external input data are the existing certificate JSON for N=9,45,49,121,361. It hashes all files in the three protected input packages before and after running and requires equality.

The ordinary-discriminant controls use a reciprocal quadratic contraction and additionally check that contraction against direct ordinary derivative discriminants for degrees 2–7. The external audit uses a distinct arithmetic route for all five lower-base arrays.

No predecessor implementation is executed, imported, compiled, or used as an arithmetic module. The following exploratory scripts were authored in this package; they are not proof dependencies:

- `explore.py`: exact J-discriminants for A=1,...,8 at the cubic base.
- `explore_disc_mod.py`: selected half-prime J-discriminants, used to look for a symbolic pattern.
- `explore_general_base.py`: denominator-free reciprocal identity at five lower bases.
- `explore_half_prime.py`: a scan of the cubic overlap's possible multiple-root value for primes p<10000 with p≡3 mod4, excluding p=3. It found no vanishing norm. This scans only a lower-cluster expression, not target Rogers–Szegő polynomials, and proves no quantified family. The polynomial Wronskian argument in the report replaces this experiment completely.

The initial exact cyclotomic-field conversion attempt in `fixed_bases.py` was corrected during development to use exact field coefficients directly; the sealed script is the successfully executed version. Failed development attempts did not alter protected files and are not presented as successful controls.
