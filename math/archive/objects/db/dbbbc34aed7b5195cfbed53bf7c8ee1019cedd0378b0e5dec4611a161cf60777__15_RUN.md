All equality checks in these scripts use exact arithmetic in `F_998244353` unless explicitly using numpy for complex/real numerical control. The 24 excluded samples and 12 mask-recovery positive controls are specified in `audit.json`.

**Arithmetic-cost separation**:

- Each weighted cyclic Green `apply` call costs `O(N)` in prepared field arithmetic. Independent coordinate orders only affect gathering/scattering; no dense matrices are used in the forward routine.
- `H`, `H^T`, `R`, the diagonal `Q`, and the real covariance oracle's support work also cost `O(N)` per vector.
- Creating exact dense Gram matrices, inverting arbitrary Green *sums*, recovering matrices via all basis vectors, and dense cosine/sine application are `O(N^2)` to `O(N^3)` **research diagnostics**. None is claimed to be a linear-time Fourier executor.
- Real/complex numerical simulations are independent controls, not machine-precision bit-complexity theorems.
