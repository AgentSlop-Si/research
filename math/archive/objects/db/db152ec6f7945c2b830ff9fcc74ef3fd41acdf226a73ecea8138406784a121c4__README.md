# HERO #0 — Phase 12: All-length Green-sum obstruction

## Main result

A length-N complex Fourier matrix cannot equal a single **sum of two invertible weighted-permutation Green resolvents** at any `N>=2301`. The permutations may each have arbitrarily many cycles and independently chosen weights. The proof additionally covers `N` with any prime factor `p>=29`, including many `N<2301`. A generic finite sum of `r` Green resolvents + fixed correction budgets also faces an explicit all-length threshold.

This is a **negative result for one exact factorization grammar**, not a fast FFT, not a claimed general lower bound, and not a proof of publication novelty. The specific two-layer product grammar remains open and is provably outside this one-layer rank obstruction.

## How to reproduce

```bash
python -m unittest discover -p 'test_*.py' -v
python small_arc_gate.py
python power_two_witness.py > witness_n4096.json
python product_escape_control.py > witness_product_escape.json
python cycle_minor_gate.py --prime 29 --output witness_p29.json
```

The tests use Python's standard library and `mpmath` only for high-precision numerical audits; all core proofs and exact finite-field checks are independent of numerical precision.
