```
cd fft_green_phase25_affine_order
python -m unittest discover -s tests -v
python audit.py
sha256sum -c SHA256SUMS.txt
```

The exact field is `F_998244353` and the supported lengths are powers of two up to `2^23`. FFT reference controls use direct DFTs at small sizes and an independent radix-two implementation at larger sizes. Modular inverse calculations are counted as arithmetic operations; big-integer/bit complexity for growing moduli is not claimed.

The historical source archive is `previous_full_phase24_checkpoint.zip`, and its tests can be rerun separately after extraction.
