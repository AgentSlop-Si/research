# Fast H_q(C) comparator and exact shifted resolvents

This package improves the **implementation baseline** for the existing operator
H_q(C) from quadratic Horner evaluation to ordinary O(N log N) exact arithmetic.
It also implements every shifted resolvent (lambda I-C)^-1 in O(N) work.
Neither result supplies an independent Fourier algorithm below N log N.

Dependencies are the existing sibling packages `../fft_qbasis_research` and
`../fft_qweyl_boundary_research`; their files are imported without modification.
Run `python3 run_audit.py` here. No third-party Python packages are required.

## 1. A stronger comparator than quadratic Horner

Use the already proved notation:

    T=H_q(A), P=diag(f_j), Gamma=diag((-1)^j q^(j(j-1)/2)),
    F_N=P H_q(C) T Gamma.

Every diagonal and T is invertible. Consequently

    H_q(C) = P^-1 F_N Gamma^-1 T^-1.                  (1)

This is a legal evaluator, with no degree-N polynomial Horner loop:

1. Apply the inverse triangular convolution T^-1 to the arbitrary input.
2. Scale by Gamma^-1.
3. Apply one ordinary length-N radix-two Fourier transform.
4. Scale by P^-1.

The inverse triangular convolution uses two ordinary length-2N FFTs. The result
is O(N log N), and retains all N independent input variables and every output.
The identity does not claim a new asymptotic FFT: it explicitly calls the usual
FFT. It is stronger than the alternative similarity implementation
T H_q(B) T^-1, which uses three triangular convolutions.

When inserted back into the full Fourier expression, (1) gives

    P [P^-1 F_N Gamma^-1 T^-1] T Gamma = F_N.

Cancelling before execution eliminates T^-1*T and the inverse diagonals. The
remaining graph is the ordinary Fourier transform. The audit checks the full
unreduced composition against this compiled graph on every basis input. This
is useful compiler simplification, not an independent new way to beat FFT.

## 2. New preparation specialization: the inverse spectrum

Let K(z)=sum_(j=0)^(N-1) d_j z^j be the inverse convolution kernel, with
d_j=(-1)^j q^(j(j-1)/2)/f_j. The finite coefficient recurrence and
d_(N-1)=q/N imply the exact polynomial identity

    K(z)=(1-z)K(qz)+z^N/N.                           (2)

The top boundary is retained. Evaluating at z=1 gives K(1)=1/N; omitting the
boundary would falsely give zero.

As in the earlier forward-spectrum routine, assume a **supplied primitive
2N-th root eta**, and put q=eta^2. This supplied root may require a larger field
than a primitive N-th root alone; its construction is not silently free.
For k modulo 2N, let v_k=K(eta^k). Then

    v_k=(1-eta^k)v_(k+2)+(-1)^k/N.                  (3)

The even orbit starts at the known v_0=1/N and is traversed backward. The odd
orbit is also traversed backward; its full multiplier is
product_r(1-eta^(2r+1))=2. Compose from zero to obtain offset b, set v_1=-b,
and replay the orbit to produce all its entries. This prepares all 2N bins in
O(N) field work without a kernel FFT. It is the backward counterpart of the
previous forward-kernel orbit construction, not a claim of global novelty.

The same root table prepares P^-1 and Gamma^-1 in O(N). The length-N transform
uses the even-indexed root powers and its own linear-size bit-reversal list.

## 3. Charged fast H_q(C) costs

Let L=log2(N). `prepare_fast` counts every field operation, including products by
0 or 1. It uses one inverse to obtain the constant 1/2, then powers of that
constant. Its total is:

    7N+L-4 multiplications,
    4N-1 subtractions,
    N-1 additions,
    N negations,
    one constant inversion.

That is 13N+L-5 counted field operations. All powers, spectrum entries,
permutations, coefficient tables and copies use O(N) storage, addressing work,
and writes. No input-dependent table or repeated-input assumption is used.

The complete online action, including inverse-convolution normalization and
both outer diagonals, is:

    (5/2)NL+8N multiplications,
    (5/2)NL+2N additions,
    (5/2)NL+2N subtractions.

All three FFTs, padding, truncation, and full outputs are included. Online
logical array traffic and indexing are O(N log N), and peak live field storage
is O(N). The code reports logical array traffic, not each Python interpreter
reference operation; list temporaries add O(N) storage and work.

| N | Fast preparation | Fast online | Previous Horner online |
|---:|---:|---:|---:|
| 8 | 102 | 276 | 288 |
| 16 | 207 | 672 | 1,216 |
| 32 | 416 | 1,584 | 4,992 |
| 64 | 833 | 3,648 | 20,224 |

The last column is 5N^2-4N; both online columns exclude their preparation.
The fast preparation is shown explicitly. These are arithmetic counts, not
elapsed speedups or a comparison with a tuned numerical FFT library. The
new comparator is slower for the smallest lengths. No floating-point
stability or bit-complexity assertion follows from these exact field counts.

## 4. A general O(N) shifted-resolvent primitive

Write C=U+W, with u_i=q^(-i) on the diagonal and cyclic upper weights

    w_i=q-q^(-i)   (i<N-1),       w_(N-1)=-q/N.

All w_i are nonzero and product_i w_i=-1. For any nonzero lambda, the system
(lambda I-C)y=x can be written without dividing by any diagonal difference:

    y_(i+1)=a_i y_i+b_i,
    a_i=(lambda-u_i)/w_i,      b_i=-x_i/w_i.

Indices are cyclic. Composing the N affine equations yields

    y_0=(1-lambda^N)y_0+B,

because product_i(lambda-q^(-i))=lambda^N-1 and product_i w_i=-1. Hence

    y_0=B/lambda^N.

One composition pass and one replay produce all N outputs. This remains valid
when lambda equals a diagonal entry q^(-i), where some a_i vanish; no division
by lambda-q^(-i) occurs. Only lambda=0 is excluded, as C is nilpotent.

The implementation prepares inverse weights using a prefix/suffix batch
construction whose final product inverse is exactly -1, so no extra inversion
is needed for those N weights. Including sparse-C preparation, its counts are

    4N+L-1 multiplications, N-1 subtractions,
    two negations, one constant inversion.

Each call charges both lambda-dependent preparation and the vector action:

    4N+L multiplications, N subtractions, 2N-1 additions,
    N negations, one parameter inversion (of lambda^N).

The parameter inversion is explicitly paid and independent of the vector x;
it could be reused for another query with the same lambda. Each call retains
all N outputs and uses O(N) storage and addressing. These are exact-field
counts, not constant-time inversion in a bit model.

## 5. What resolvents do and do not give for H_q(C)

Since C^N=0, a finite geometric expansion gives

    (lambda I-C)^-1 = sum_(k=0)^(N-1) C^k/lambda^(k+1).

Orthogonality of q-powers therefore gives the exact identity

    H_q(C) = sum_(j=0)^(N-1)
       [q^j H_q(q^j)/N] * (q^j I-C)^-1.              (4)

All N scalar weights can be prepared in O(N) using the existing forward-kernel
orbit routine. But evaluating N independent resolvents and summing their N
outputs still costs O(N^2). The verifier checks (4) by direct small calculations;
it deliberately does not advertise this batch as the fast evaluator.

Equation (4) isolates a meaningful unresolved fusion problem: evaluate this
specific weighted aggregate without N separate complete vector passes. The
provided O(N log N) comparator already solves its final action using ordinary
Fourier machinery. An improvement must beat that comparator while charging
all preparation and the complete outputs, not merely beat quadratic Horner.

## 6. Reversible reuse for complete H_q(C) queries

There is also a legal sparse-output update for the full high-degree operator,
once its first result is actually available. Define

    S=(I-A)^-1 Q=TQT^-1,
    K=S(I-C)=-QB+(1/N)A^(N-1).

Then S is weighted prefix summation and K is a weighted cyclic shift:

    (Sx)[i]=sum_(j=0)^i q^j x[j],
    (Ky)[i]=(1-q^(i+1))*y[i+1]     for i<N-1,
    (Ky)[N-1]=y[0]/N.

Both are invertible and have N-th power I. The exact covariance is

    H_q(C) S = K H_q(C).                            (5)

Proof: SCS^-1=q^-1 C, so H_q(C)S=S H_q(qC). Since C^N=0, the finite
q-difference identity gives H_q(qC)=(I-C)H_q(C). Finally, multiplying the
claimed K by I-A verifies K=S(I-C): use AQB=Q-I and AA^(N-1)=0, retaining
the corner coefficient 1/N. Invertibility and K^N=I also follow directly from
product_(j=1)^(N-1)(1-q^j)=N. No highest-degree term was discarded.

`covariance.py` implements a declared family x_j=S*x_(j-1). It charges a first
fast H_q(C) call, physically produces every x_j by prefix summation, and
produces every output via y_j=K*y_(j-1). Preparing K adds N-1 subtractions to
the fast plan. Each subsequent input/output pair costs 2N multiplications and
N-1 additions, including the S input update. Thus the complete family costs
O(N log N+rN) for r updates, with all N coordinates output every time.

This demo retains both complete chains, so storage is O((r+1)N); it does not
claim O(N) storage while retaining rN outputs. Logical output writes are
(r+1)N, related-input writes rN, plus a copy of the initial input. A streaming
consumer could use O(N) working storage, but is not the return format here.

For four related updates, the following counts include every field-operation
preparation and use the **fast** ordinary-FFT H_q(C) comparator on both sides.
Only the cached side is charged the extra K preparation, because the baseline
does not use it.

| N | Cached family, all preparation | Independent fast H_q(C) calls |
|---:|---:|---:|
| 8 | 477 | 1,542 |
| 16 | 1,082 | 3,691 |
| 32 | 2,411 | 8,588 |
| 64 | 5,308 | 19,581 |

This is a reusable graph rule for **related queries**, not a fresh arbitrary
FFT speedup. After substituting the entire Fourier factorization,
S*T=T*Q and P*K*P^-1 is the ordinary cyclic shift. Thus (5) reduces there to
the classical Fourier modulation/shift law; it is not a new general Fourier
identity or a priority claim. Its concrete value here is correct reuse for
the actual H_q(C) operator, with its full boundary and initial cost retained.

## Verification

`run_audit.py` passes 15 configurations: N=2 through 64 over F_65537 and
F_998244353, plus N=2,4,8 over exact rational fields containing a primitive
2N-th root. It verifies:

- 532 inverse-spectrum values against direct polynomial evaluation;
- 266 basis vectors and 15 mixed vectors against independent H_q(C) Horner;
- the full Fourier cancellation on those same vectors;
- 843 shifted-resolvent solves, including shifts equal to diagonal entries;
- 11 complete weighted-resolvent identities;
- 281 complete covariance checks and 75 outputs in charged related-query
  chains, plus S^N=K^N=I on a mixed vector in every configuration;
- all stated implementation operation-count formulas.

The all-size proofs are equations (1)-(4) and their displayed derivations.
Finite tests verify their implementations. Exact scalar arithmetic support and
the earlier conjugation theorem are reused from the previous packages; none
of those earlier results is relabeled as a new discovery here.

The starting q-Pascal Fourier factorization is established prior art:
Alexey Kuznetsov, *Using q-calculus to study LDL^T factorization of a certain
Vandermonde matrix*, https://arxiv.org/abs/1507.02959 .
