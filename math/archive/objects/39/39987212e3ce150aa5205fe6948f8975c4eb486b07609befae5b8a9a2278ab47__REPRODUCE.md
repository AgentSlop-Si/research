# Reproduction

Run only this package's newly authored controls:

    python independent_controls.py > CONTROL_RUN.log

Python 3 and SymPy are required. This reconstructs CONTROL_RESULTS.json. The symbolic proofs are in RESEARCH_REPORT.md; finite checks are controls, not replacements for those proofs.

explore_fresh.py, explore_nontarget.py and explore_nontarget_85.py are fresh exploratory programs. The latter two import arithmetic only from this package's independent_controls.py. They do not import or execute any predecessor implementation. Their existing logs are bounded observations, not uniform certificates.

Verify the output seal with:

    sha256sum -c MANIFEST.sha256

No accepted package is modified by this reproduction command.
