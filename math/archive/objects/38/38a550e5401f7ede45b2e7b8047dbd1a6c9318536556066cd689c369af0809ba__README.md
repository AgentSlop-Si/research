# Hero #17 Phase 8 — multistage bridge rank and polynomial CRT union

**Status: scoped exact research, NOT a universal O(N) FFT.**

This standalone package contains:

- `phase8.py` — prime-field exact DFT executors, multistage cut-rank and Schur certificates, CRT transfer matrices, exact 16-point cyclotomic root-split enumeration, semantic FFT graph union, finite-table and unitary entropy controls.
- `test_phase8.py` — 13 deterministic unit-test groups.
- `independent_audit.py` — separately coded direct modular DFT reference, independently coded modular rank routine, all balanced N=16 CRT bridge checks, and the N=65,536 selected-bin check.
- `RESEARCH.md` — full statement of what was/was not achieved, implementation ledger, historical context.
- `PROOF_CERTIFICATE.md` — line-by-line mathematical proofs and the scope of every theorem.
- `CHAIN_CHECKPOINT.md` — safe handoff and do-not-repeat register.
- `AUDIT_RESULTS.json` — audit numbers and complete exact search histograms.
- `TEST_LOG.txt`, `PREDECESSOR_RUN_LOG.txt`, `SHA256SUMS.txt` — records and integrity manifest.

## Reproduce

Requires **Python 3.11+**, standard library only (no numpy/FFTW/quantum hardware).

```bash
python -m unittest discover -v
python independent_audit.py
```

The test fixture discovers a field and primitive Nth root; finding the test field is *not* claimed as part of the online DFT executor. For the specific exact finite-field DFT executor, the primitive root is supplied and creating all N root powers costs N−1 charged multiplications. Scalar additions, multiplications, plan polynomial construction and input/output counts are recorded. The source itself performs only classical sequential field arithmetic.

## Progress

**New structural result:** a universal balanced Fourier-root split has full-rank CRT bridge, and its unique minimum-support monomial-basis transfer is classical radix-2 DIF. A fixed-cut multistage graph must communicate at least `min(m,N-m)` rank in total, but arbitrary changing-cut circuits are excluded from that lower bound.

**Research frontier:** a genuinely cross-stage arithmetic evaluator of complementary remainder maps that reduces the *complete* arbitrary-input circuit work below the published benchmark, with root and schedule preparation charged.
