# Independent replay

Only the Python standard library is needed. From this checkpoint:

```sh
python check_phase32.py
python check_separation_theory.py
```

Do not execute the uploaded programs under phase32/ or
separation_theory/. The new checkers read their JSON records as data,
reconstruct the relevant instances independently, and write
PHASE32_INDEPENDENT_REVIEW.json and
SEPARATION_THEORY_INDEPENDENT_REVIEW.json. Their hashes must match
PORTABLE_REPLAY.json. The original source files remain unchanged,
including the 16 incorrect Phase32 probe-column metadata labels;
the independent output records their corrected values.

Finite checks do not replace the all-N separation/norm proof or the
generic complex interpolation proof. Those are reviewed separately in
SEPARATION_AND_PHASE32_REVIEW.md. No Fourier speedup is asserted.
