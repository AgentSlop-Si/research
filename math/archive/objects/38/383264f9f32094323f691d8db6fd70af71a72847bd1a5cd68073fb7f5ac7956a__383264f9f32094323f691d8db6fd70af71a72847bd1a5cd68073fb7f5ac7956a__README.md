# FFT global-chirp median v7

This bundle contains a reproducible continuation of the sparse-surrogate / structured-sketch FFT research.

## Main claim under audit

For dyadic `N=K*M` with `K>=2M`, one randomized global quadratic-chirp block-projection row has exact worst-case per-output variance operator norm `2M/N`. The row is decoded in `O(N+K log K)` arithmetic using one `K`-FFT, two seeds, and a first-order recurrence.

Choosing `M=Theta(log N)` makes a row linear-time. Output-domain medians then yield:

- fixed odd row count: `O(N)` full-output approximation with polynomially shrinking energy-relative error;
- `Theta(log N/log log N)` rows: `o(N log N)` time and a polylogarithmic factor above `||x||_2/sqrt(N)`.

See `RESEARCH.md` for the theorem, proof, limitations, and prior-art boundary.
