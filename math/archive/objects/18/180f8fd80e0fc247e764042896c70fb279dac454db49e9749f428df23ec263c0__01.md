## Mathematics and flow

Builds the n-3 by 6 evaluation matrix [1,z^i,z^(2i),z^(5i),U_<5,L_>5]. The generated lower coefficients have three Fourier frequencies; for n>=9 the lower tail reduces modulo the first three evaluation columns to -L3*z^(3i)-L4*z^(4i)-L5*z^(5i). Thus rank is 4 plus the rank of [[U3,-L3],[U4,-L4]], explaining the boundary determinant test and the fixed nonzero Vandermonde ratio.

## Guards and contracts

The caller supplies a prime/primitive root and sufficiently long coefficient arrays. The fixed runner uses n=8,16,32,64, primes 12289/65537 and 50 alternating matched/unmatched draws. n=8 is deliberately exceptional because only five rows exist. samples<=1 can leave the ratio set empty and fail the generic-witness assertion; this is a diagnostic API limit, not evidence against the stored 50-sample witnesses.

## Costs

Matrix construction is quadratic in n as written because each row sums the long lower tail; modular exponentiation adds logarithmic exponent costs. Rank elimination has six columns; these are small research checks, not a fast Fourier evaluator.
