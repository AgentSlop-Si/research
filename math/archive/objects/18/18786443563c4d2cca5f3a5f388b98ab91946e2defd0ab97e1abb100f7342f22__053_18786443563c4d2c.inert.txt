# Exact Fourier computation through a detected weighted affine cycle

This component adds one constructive, exactly checked graph mechanism. It
computes every Fourier output in **O(N(s+1)) exact field operations** when a
fresh input has at most s defects in a verified weighted affine-cycle relation.
For fixed s this is linear work even when every input and output is present.
It is a restricted input family. **It does not beat N log N for arbitrary
fresh exact inputs.** A supplied all-input wrapper uses ordinary radix-2 FFT
after a decline; for a fixed defect budget its worst-case cost remains
O(N log N), with O(N) failed-detection overhead.

The purpose is to use a nonlocal reusable graph, beyond the prior
nearest-neighbor q-linear relation and untwisted Galois permutation defect.
There is no claim of novelty in the Fourier intertwining identity or in
solving weighted cycles. The code and proof are self-contained.

## 1. The exact operator identity

Let N be a power of two, q a primitive Nth root, and

    (F x)[k] = sum_j q^(k j) x[j].

For an odd invertible a modulo N, define

    (M x)[j] = q^(b j) x[(a j+c) mod N].

Changing the summation variable to t=a j+c proves

    F M = Mhat F,
    (Mhat y)[k] = q^(-c a^-1(k+b)) y[a^-1(k+b) mod N].

Thus both source and Fourier-side operators are weighted permutation graphs.
The source recurrence traverses j -> a j+c, and the target traverses
k -> a^-1(k+b). Modulation on one side becomes a translation on the other.
There is no cached previous input, hidden full transform, or automorphism
oracle in this identity.

Choose a=1 mod 4 and odd b,c. Both maps are full N-cycles. Here is an
elementary proof. For f(j)=a j+c and m=2^r,

    f^m(j)-j = (a^m-1) j + c (1+a+...+a^(m-1)).

Repeatedly factor S_(2m)=S_m(1+a^m). Since a=1 mod 4, the second factor has
2-adic valuation one, so v2(S_(2^r))=r. The first summand above has valuation
at least r+2; the second has valuation exactly r. Consequently the orbit
cannot close modulo 2^(r+1) after 2^r steps, and its length modulo N is N.
The target has slope a^-1=1 mod 4 and odd translation a^-1 b, so the same
argument applies. The implementation also verifies both complete cycles
with bounded integer indexing and N-sized boolean arrays.

## 2. Detection and the complete output algorithm

Suppose some scalar lambda makes

    u = (I-lambda M) x

have at most s nonzero entries. The algorithm performs these steps from
scratch for each query:

1. Build and validate all N root powers, and both affine graphs.
2. Compute Mx. If lambda is not supplied, use Boyer-Moore majority voting on
   ratios x[j]/(Mx)[j] with nonzero denominator. Compare ratios by cross
   multiplication; invert just the selected denominator. If m nonzero
   denominators satisfy m>2s, the true ratio is a strict majority because
   there are at most s defects. The all-zero vector has a direct path.
3. Verify every coordinate of u. Decline if the defect budget is exceeded.
4. Compute the full vector v=Fu directly from those s entries, paying 2Ns
   scalar operations. This is s explicitly evaluated geometric modes.
5. Solve (I-lambda Mhat)y=v on its one weighted cycle, materializing all N
   coordinates. The intertwining identity proves y=Fx whenever the cycle
   operator is invertible.

Insufficient majority support is a decline, not an unsupported acceptance.
A caller may supply lambda, but that only removes discovery: every source
row is still verified and all other work is charged.

### Weighted cycle solve and singular cases

In cycle order, write y_i=v_i+d_i y_(i+1), with y_N=y_0. Let C=product_i d_i.
A backward accumulation gives

    B = v_0+d_0 v_1+...+(d_0 ... d_(N-2)) v_(N-1).

Then y_0=B/(1-C); a second backward traversal recovers every y_i. This uses
one inverse and no divisions by individual edge coefficients, so lambda=0
is also valid. For the affine target, the product of the root weights is

    q^(-c sum_j j) = -1

because c is odd and N is even. Hence C=-lambda^N, and the exact
invertibility condition is **1+lambda^N != 0**. The implementation computes
C by an N-step product, explicitly checks 1-C, and declines singular
cycles. It does not guess a missing kernel coefficient or reuse a previous
answer. The all-input wrapper then runs an ordinary FFT.

## 3. Fully dense, genuinely nonlocal examples

For every dyadic N>=4 over the complex numbers, fix a=5,b=c=1,lambda=2,
and choose a one-entry residual u. Since 1+2^N is nonzero, the source
weighted-cycle system uniquely determines x. Every entry of x is nonzero:
the nonzero edge weights propagate a zero through all homogeneous rows,
which would contradict the nonzero residual at the remaining row.

Therefore this is a uniform family of fully dense fresh inputs with an
exact O(N) full DFT. Inputs may vary through the defect position, defect
amplitude, and lambda; they are not arbitrary N-dimensional inputs.

An exact finite-field witness at N=32, a=5,b=c=1,lambda=2 has:

- 32 nonzero input entries;
- rank four for the 31-by-4 matrix whose rows are
  [x_j, q^j x_j, x_(j+1), q^j x_(j+1)], so no nonzero first-order q-linear
  relation of the earlier four-parameter type exists;
- 28 nonzero entries in the untwisted P5x-x defect.

This witnesses a family outside those earlier small-defect paths. It is
not a claim that every prior structured algorithm rejects every member,
or that the new family contains the old families.

## 4. Charged cost and what the model means

The exact field and one primitive root q are common inputs to this evaluator
and its radix-2 comparator. Building and validating the full root table is
paid. Field addition, subtraction, multiplication, and inversion each count
as one operation; input-dependent inversions are explicitly included.
Coefficients are exact, and zero/equality checks are exact. Index arithmetic,
cycle validation, scans, data movement, and writing every output require
O(N(s+1)) bounded-word operations and O(N) auxiliary words. The modular
inverse a^-1 modulo N uses Euclid in O(log N) bounded-word arithmetic, which
is absorbed by O(N). The default a=5,b=c=1 are fixed-size parameters.

For accepted queries with s actual defects, a conservative counted bound is:

| Work | Exact field operations |
|---|---:|
| Root powers and validation | N |
| Mx and ratio discovery | at most 3N |
| Full residual verification | 2N |
| Full transform of s defects, target edge weights | 2Ns+N |
| One-cycle solve, including inverse | 5N+3 |
| **Total with discovery** | **at most (12+2s)N+3** |

With supplied lambda, the bound becomes (10+2s)N+3. On the audited dense
one-defect family, the implemented majority schedule uses two fewer
comparisons than the conservative bound, giving exactly **14N+1** calls.
The comparator's counted total is N+(3/2)N log2 N, with all root powers and
ordinary radix-2 butterflies evaluated. This is one clear comparator, not a
claim to beat every optimized radix or implementation constant.

| N | Affine-cycle method | Radix-2 comparator |
|---:|---:|---:|
| 1,024 | 14,337 | 16,384 |
| 4,096 | 57,345 | 77,824 |
| 8,192 | 114,689 | 167,936 |
| 32,768 | 458,753 | 770,048 |

These are field-operation counts, not wall-clock speedups or bit-complexity
bounds. Exact cyclotomic coefficient sizes can grow, and a field operation
is not a constant-time arbitrary-precision operation. The fixed prime
65,537 used for the table only supports dyadic lengths through 65,536;
the all-length algebraic proof is over fields containing the required roots.
There is no model switch from exact arithmetic to word-RAM approximation.

## 5. Reproduction and validation

Run `python3 run_audit.py` from this directory. It writes `results.json`,
including the SHA-256 hash of the evaluated source. All outputs passed:

- 159 modular accepted fast-path checks and 45 explicit declines;
- 11 correctly declined singular target cycles;
- 540 full basis-vector checks of F M = Mhat F across three prime fields,
  four dyadic lengths, and three nontrivial affine parameter choices;
- six exact complex-algebraic checks in power-of-two cyclotomic fields;
- eight arbitrary-input fallback checks, including independent operation
  tracing of both the failed attempt and ordinary FFT;
- five invalid-input checks, plus four fully dense larger-size comparisons
  to an independently written radix-2 FFT.

Every accepted small query is checked against an independent direct DFT.
An outer field wrapper verifies the evaluator's operation counter and stage
sum on the small cases. The input generator uses a separate forward-affine
closure recurrence; the evaluator uses a backward closure recurrence.
`exact_fields.py` is copied unchanged from the previously audited q-linear
component and provides exact prime/cyclotomic arithmetic.

## 6. Main-goal status

The result is one useful graph fast path: a cold, exact, nonlocal affine
cycle can replace the full transform for a verified dense structured family.
It supplies no decomposition of an arbitrary input into a bounded number
of such families. An unrestricted input usually fails the defect test.
The fallback then costs O(N log N). Consequently **the project's exact
arbitrary-input o(N log N) goal remains unmet** by this component.
