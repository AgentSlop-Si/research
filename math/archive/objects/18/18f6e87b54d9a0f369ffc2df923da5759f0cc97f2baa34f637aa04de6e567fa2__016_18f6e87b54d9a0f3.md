# Phase 11 independent mathematical audit and structured full-DFT extension

Date: 2026-10-08. Original attachment audited: `fft_phase11_fresh_convolution_research(1).zip`, especially `RESEARCH.md` and `fresh_factor.py`. Originals are unchanged. This note and `structured_dft.py` are independently written audit additions; they do not import the original implementation.

## Bottom line

The original sparse-annihilator convolution identity and fixed-order, fresh-structured-input linear **field-arithmetic** result are sound. They do not establish a faster arbitrary-input DFT or a general integer multiplication bit bound. There is a useful additional consequence: the same structure allows an exact **full DFT** of a fresh structured array in linear field arithmetic for fixed recurrence order, with singular Fourier bins explicitly handled. This is classical rational-generating-function algebra, not a discovery or priority claim.

Run the extension/regressions with:

```sh
python structured_dft.py
```

`exact_checks.json` records the successful run. Six length-eight examples, three small edge cases, and a deliberately invalid supplied root were checked. No FFT library or cached spectrum is used. This is an exact proof-of-concept, not a wall-clock performance claim.

## 1. Convolution derivation and boundaries

Write A(z)=sum a_i z^i, B(z)=sum b_i z^i, and L=n+m-1. For filters Q_A,Q_B with constant coefficient one, put D_A=Q_A A and D_B=Q_B B. In the formal power-series ring over any commutative ring,

    AB = Q_B^(-1) Q_A^(-1) (D_A D_B) mod z^L.

The inverse recurrence for Q=1+q_1 z+...+q_d z^d is

    c_i = h_i - sum_{j=1}^{min(d,i)} q_j c_{i-j}.

This uses no division. The constant coefficient one makes the triangular map invertible, including over rings with zero divisors. No assumptions about the input values are needed for correctness.

The original code retains the complete polynomial products D_A,D_B, including right-edge tails. It truncates only terms of their product at degree L and above, which is safe because causal inversion cannot move high-degree terms into lower degrees.

A concrete boundary regression: A=[3,3,3,3], B=[2,1,4], Q_A=1-z. Full D_A=[3,0,0,0,-3] gives AB=[6,9,21,21,15,12]. Omitting the right-edge -3 and then cumulative-summing gives the incorrect [6,9,21,21,21,21]. The original code avoids this mistake.

If a finite array follows an order-d constant-coefficient recurrence on all indices d,...,n-1, Q_A A can be nonzero only in [0,d-1] and [n,n+d-1]. Hence its support is at most 2d. With given filters and s_A=nnz(D_A), s_B=nnz(D_B), the arithmetic bound is

    O((d_A+d_B+1)L + s_A s_B).

Taking Q_B=1 proves O((d+1)(n+m)) operations for fixed-order A and arbitrary fresh B. Comparable lengths are not necessary for this upper bound. These are linear convolutions, not cyclic convolutions.

## 2. Detection and bit-cost qualifications

A constant-size bank of bounded-degree filters costs linear arithmetic to scan exactly. For F filters of maximum degree D, charge O(F D L), rather than treating a growing dictionary as free. Bounded Berlekamp-Massey costs O(LD) field operations for accepted order-at-most-D sequences, with field inversion costs included in the model. The implementation also converts the whole input to residues before any early BM exit; early exit does not eliminate the input scan.

Sampling in the dispatcher can miss a useful filter but cannot corrupt the answer: multiplication and inversion remain exact for every accepted Q with Q(0)=1, even if Q does not annihilate any interior coefficient.

The integer-lift detector is deliberately incomplete. For example, a_i=p^i with the detector's p=998244353 has the exact integer recurrence Q=1-pz. Modulo p the samples become [1,0,0,...]; a centered coefficient lift cannot recover -p from residue zero, and integer verification rejects the candidate. This is a missed optimization, not an incorrect output or a contradiction of the given-filter theorem.

**Arithmetic count is not bit complexity.** Length-n Fibonacci samples already contain Theta(n^2) bits in explicit binary form; F_2048 has 1421 bits. The input, output, modular reductions, and integer arithmetic must all be charged accordingly.

There is nevertheless a useful bound on intermediate growth. If |a_i|<=M_A, |b_i|<=M_B, and U_A,U_B are the filters' coefficient l1 norms, the full filtered product is Q_A Q_B AB. After the first inverse recurrence, the exact intermediate is Q_B AB modulo z^L. Its coefficients are bounded by U_B min(n,m) M_A M_B. The final result is bounded by min(n,m) M_A M_B. The temporary partial sums add only the corresponding filter norms and polynomial-length factors. Thus for bounded-degree filters there is no unexplained exponential extra bit growth beyond the actual input/filter coefficient sizes, although large input coefficients still invalidate a unit-cost bit-time interpretation. Floating-point cancellation and numerical stability are a separate issue.

The integer CRT bound min(n,m) max|a_i| max|b_i| is sufficient, and a CRT product strictly greater than twice that bound supports unique signed reconstruction. The listed finite prime set does not provide an unrestricted all-size fast integer algorithm; exact schoolbook fallback is used when it is insufficient. Similarly, a fixed NTT prime has a finite supported root-order range.

The demonstration `multiply_int` additionally uses repeated division by a fixed digit base and repeated Horner multiplication. For a T-bit integer, these straightforward conversions can themselves require quadratic bit work. Its linear coefficient-convolution cases therefore do not imply linear bit-time multiplication. The distinct near-power routine, for a fixed-bit residual in A=2^t+delta, genuinely uses only shifts, additions and bounded-width multiplication, giving the stated restricted linear bit-work shortcut.

## 3. Useful extension: fresh structured full DFT

### General sparse-filter statement

Work over a field F containing an exact order-N root omega. Let a have length N; let Q(0)=1 have degree d, and let D=QA have s nonzero coefficients, including both boundaries. For every k,

    Q(omega^k) A(omega^k) = D(omega^k).

Reduce D modulo z^N-1 to R. This is **cyclic folding of the numerator for evaluation only**, not the truncation modulo z^N used in causal inversion. At every Fourier point, D and R agree. Let s_R=nnz(R)<=s.

1. Form D in O(N(d+1)) arithmetic and fold in O(N+d).
2. Evaluate the s_R-term R at all N roots in O(N s_R): for each exponent e, compute omega^e once and generate its successive k-th powers. Initial exponentiation costs O(s_R log N), already within O(N(s_R+1)).
3. Generate the roots and evaluate Q at all roots in O(N(d+1)).
4. Where Q is nonzero, divide R by Q. Batch inversion uses O(N) field multiplications and only one nonzero inversion.
5. At a zero of Q, directly evaluate the original A by Horner's rule. A nonzero degree-d polynomial has at most d distinct roots, so all exceptional bins cost at most O(Nd).

Total:

    O(N(s_R+d+1)) field arithmetic plus one field inversion,

including filter application, all root/power preparation, singular-bin recovery, and the explicit output. For d<=N the implementation uses O(N+d) stored field elements. A dense residual can make this quadratic; no universal speedup is claimed.

The caller supplies a prime p and omega for the included finite-field implementation. It checks omega's exact order by trial-factorizing N and checking its proper prime-factor divisors. It does not purport to prove primality of arbitrary p. This root-order preparation is explicit, and its basic arithmetic cost is within the above linear-or-larger count. Bit costs of factoring, exponentiation and inversion depend on N and log p. For a fixed p only N dividing p-1 is available; no unbounded-N fixed-prime theorem follows.

### Stronger recurrence-specific statement

If A follows an order-d recurrence and d<=N, D has support only at the first and last d positions. Therefore

    R(z) = D(z) mod (z^N-1)

has degree less than d, after folding the right tail onto the first d coefficients. Consequently s_R<=d, and the entire full DFT is computable in

    O(N(d+1)) field arithmetic plus one inversion.

This is a full explicit output, not merely selected Fourier coefficients. With fixed order, it is O(N). Detection/verification of a given recurrence can be included at O(Nd).

### Exact example, including the removable singularity

Let p=97, N=8, omega=64, and A=[3,3,3,3,3,3,3,3]. Then Q=1-z and D=3-3z^8, so R=0. At bins k=1,...,7, R/Q=0. At k=0, both numerator and denominator vanish, and direct evaluation gives A(1)=24. The correct spectrum is

    [24,0,0,0,0,0,0,0].

Ignoring singular bins would erase DC. Omitting the -3z^8 boundary term would give 60 at bin 1 instead of zero. Both errors are covered by the standalone regression.

A separate non-DC singular regression takes a_j=64^j mod97 and Q=1-64z. The exceptional bin is k=7; its value is 8, and all other bins are zero. Arithmetic progression and Fibonacci cases also agree exactly with an independent direct DFT.

### Relation to the main arbitrary-fresh-DFT goal

The speed guarantee requires a small-degree Q with small residual support. It is a restricted-input result, even though every input is fresh and the full output is produced.

For a fixed input-independent Q, the nonzero reciprocals Q(omega^k)^(-1) are scalar constants and the restricted map is linear in a. The above preparation is charged in its field-arithmetic model. If Q is discovered from a, selection, equality tests and any input-dependent inversions require their own model justification. Neither version supplies the uniform all-input exact-complex-register circuit needed for the project's general FFT target.

In floating point, small nonzero Q(omega^k) may cause substantial amplification/cancellation. The finite-field exact check gives no numerical-stability guarantee.

## 4. Random-input obstruction, including adaptive selection

For fixed Q with Q(0)=1, the map

    a -> QA mod z^N

is an invertible lower-triangular map on F_p^N. Uniform inputs therefore remain uniform. There are p^d normalized filters of degree at most d, and exactly

    V_p(N,s) = sum_{j=0}^s binom(N,j)(p-1)^j

vectors with at most s nonzero entries. A union bound, valid even when the filter is chosen after inspecting the input, gives

    Pr[exists Q of degree<=d with nnz(QA mod z^N)<=s]
      <= min(1, p^(d-N) V_p(N,s)).

Full right tails can only increase support, so the same upper bound applies to small support of the entire QA polynomial. For uniform binary inputs embedded in F_p, injectivity instead gives the bound min(1,p^d V_p(N,s)/2^N); this may be weak when p>2. For integer filters on random binary arrays, reducing modulo two gives the much more useful original binary bound.

In particular, for p=2, s=N/3 and d=o(N), the original Hoeffding bound 2^d exp(-N/18) tends to zero. The original proof is correct. More generally, an input-adaptive choice among M fixed invertible maps cannot send a uniform binary vector into a sparse target set S with probability more than M |S|/2^N. This is an elementary counting restriction on sparsification by a small-description family, not a Fourier or multiplication lower bound and not a ban on other forms of computational sharing.

## 5. Classical precedent and model precision

- Goresky and Klapper, *Algebraic Shift Register Sequences*, section 15.2, give the rational generating-function/key-equation interpretation and Berlekamp-Massey register synthesis. This supports the classical algebraic basis: https://www.math.ias.edu/~goresky/pdf/algebraic0.pdf
- Richard Crandall's 2002 published patent text describes sparse finite-difference annihilation of spline convolution kernels followed by recurrence backsolution, including exact arithmetic for the structured kernel. It is direct historical precedent for the structured-convolution pattern, not a legal assessment or a claim that every current implementation detail appears there: https://patents.google.com/patent/EP1248995A2/en
- The project's pinned #130 statement is O(N(log N)^theta(log log N)^(4-theta)), with theta approximately 0.999999999999789356. The attachment's simpler O(N(log N)^(1-10^-13)) is a valid weaker asymptotic consequence: the positive exponent slack absorbs the log-log factor. The full pinned expression is more precise. Its exact-complex-register model and scalar-preparation requirements still differ from this finite-field prototype: https://github.com/openai/math/blob/fd4aeeb2ee4fc729c18d98444fed42fd0529eeeb/preprints/An-explicit-power-saving-for-the-exact-discrete-Fourier-transform-September-25-2026/build/sections/introduction.tex
