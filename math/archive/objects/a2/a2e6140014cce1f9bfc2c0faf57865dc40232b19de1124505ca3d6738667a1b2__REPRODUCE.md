# Reproduce the independent audit

The source package is protected: no source script is imported or executed, and the audit writes nothing into it.

From this audit directory:

    sha256sum -c MANIFEST.sha256
    python audit_controls.py global_chirp_bank_audit_replay.json
    cmp AUDIT_RESULTS.json global_chirp_bank_audit_replay.json

The code uses Python's standard library only. All calculations are exact. There is no network dependency, float arithmetic, root finder, or third-party symbolic package. The test prime selector is trial division at the displayed small sizes; it is not part of the asymptotic algorithm being audited.

The script hashes the protected source package before and after running and requires equality. It also refreshes SOURCE_HASHES_AFTER.json in the audit directory; this file is byte-identical on an unchanged source package. Its result JSON is deterministic. The checked-in AUDIT_RUN.log records the original run, and is not overwritten by the replay command above.

Read INDEPENDENT_AUDIT.md for the uniform proof review, the exact field/model qualifications, and the separately proved diagonal-relaxation addendum. Finite controls supplement those proofs; they do not establish a general Fourier complexity lower bound.

MANIFEST.sha256 seals every file in this audit directory except itself. SOURCE_SEAL_VERIFICATION.json records verification of the constructor's own sealed files and archived predecessor hashes. All constructor and predecessor artifacts remained byte-unchanged.
