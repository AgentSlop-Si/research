# Actual source jets: exact packet fusion and an exposed-interface obstruction

## Result

The dependence on one original N-vector can be described exactly. It is not legitimate to substitute the arbitrary-jet lower bound into this source-generated problem; the proof below instead uses an explicit N-input Fourier-packet factorization.

Two useful conclusions follow.

1. **Exact fusion identity.** For actual jets u_j=(Q^j x)_R, every young-feedback packet equals a selected coordinate of the later actual jet. Thus all young feedback can be copied from a computed global orbit, avoiding independent per-jet trajectories. Used inside the causal inverse before that orbit is known, however, this is an alias to the unknown being solved for, not a computation of it.
2. **A new scoped obstruction for the constrained interface.** If the actual source-constrained young-feedback values must themselves be exposed as ordinary exact complex field values, they still require Omega(N log N) bounded-coefficient linear work. Their input dimension is exactly N throughout the proof. The obstruction follows from their Fourier-diagonal Gram matrix, not independence of retained jets. This is not a universal arithmetic lower bound, does not cover an implementation that never exposes this interface, and supplies no finite-field lower bound.

The concrete reuse therefore removes redundant representation and trajectory work but gives no exact sub-N log N algorithm. A complete orbit implementation remains O(N log N), matching the exposed-interface lower bound in its stated model. No faster inverse correction or complete transform is claimed.

## 1. Definitions and scope

Use the accepted marker-cut definitions

    N=2^n, d=n-b, r=2^d, eta=omega^(2^b), L=2^(b-1),
    Q e_s=e_(2s mod N)+omega^s e_(2s+1 mod N),
    R={2^b a:0<=a<r}, u_j(a)=(Q^j x)_(2^b a).

For the young theorem assume b>=7 and L+2b<=n, precisely the no-wrap young regime. The identities themselves apply at smaller parameters whenever their displayed indices are defined. Let K_t be the t-bit words beginning and ending with 1 and avoiding 0^b, and let

    S_t={2^(b+t)q+k : 0<=q<2^(n-2b-t), k in K_t}.

These S_t are disjoint, as proved in the accepted young-feedback reports. Write

    g_h = sum_(1<=t<=L) C_t Q_r^t u_(h-b-t),

with negative-index jets zero and h<=n. The input here is only x in C^N, not an arbitrary array of retained jets.

The lower bound counts binary additions/subtractions and scalar multiplications of modulus at most one, with copies and fixed routing allowed. Input-independent setup may be free for that lower bound. The upper bounds separately pay root/phase preparation, reading, output writes, routing, and arithmetic. A supplied primitive root and O(log N)-bit addresses are the accepted field-operation model. This is neither a bit-complexity statement nor a claim for unrestricted arithmetic.

## 2. Exact source-jet packets

For h>=b, write the retained index uniquely as

    a=2^(h-b)q+c,
    0<=q<2^(n-h), 0<=c<2^(h-b),
    f=rev_(h-b)(c), M=2^(n-h).

The global length-h path formula gives

    u_h(a)=omega^gamma(c) sum_(s congruent q mod M) omega^(s f) x_s.       (1)

Indeed, the appended h-bit word is 2^b c. Its reversal is rev_(h-b)(c), and gamma(2^b c)=gamma(c). There are exactly 2^h summands in (1). This derivation includes all source merges.

Define the unphased dyadic packet

    P_(h,q,f)(x)=sum_(s congruent q mod 2^(n-h)) omega^(s f) x_s.

If y_ell=sum_s omega^(s ell)x_s is the full unnormalized Fourier transform, then

    P_(h,q,f)(x)
      = (1/M) sum_(v=0)^(M-1) omega^(-q v 2^h) y_(f+v 2^h).             (2)

Equation (2) is an exact linear factorization, not a claim that Fourier data or the inverse packet transforms are free. It immediately identifies the packet subspace with the full Fourier frequencies ell congruent to f modulo 2^h.

As a simple exact rank corollary, stack all complete retained jets u_b,...,u_n. A frequency ell occurs in their row-space union exactly when its fixed-length n-bit word contains 0^b. Therefore this stack has rank

    N-a_b(n),                                                        (3)

where a_b(n) counts length-n words avoiding 0^b. This statement concerns that particular stack; it does not assert the same rank for a differently truncated jet array or for a stack also including u_0,...,u_(b-1).

## 3. The fusion identity and its causal failure mode

For every allowed young age t, every j>=0, and j+b+t<=n,

    C_t Q_r^t u_j = 1_(S_t) u_(j+b+t).                               (4)

One proof works directly with full-N paths. Put ell=b+t. At an output state 2^b a with a in S_t, the preceding b bits before its appended ell-bit word are zero. Because ell<=n-b, every predecessor at distance ell is in R. Its intervening appended word is k followed by b zeros, with k in K_t. It starts by leaving R, contains no intervening marker, and returns exactly at ell; the old marker cannot disappear into A first within this horizon. Thus every full-Q path to this output is exactly one of the first-return paths represented by C_t Q_r^t. Their weights are unchanged. Outside S_t that first-return coefficient is zero.

Equivalently, substituting (1) into the accepted routed row formula produces (4), with all phase factors agreeing. The fresh exact controls check both the smaller-Q implementation and global source propagation.

Since the S_t are disjoint, (4) gives the source-specific batch formula

    (g_h)_a=(u_h)_a if a in S_t for some t with b+t<=h,
    (g_h)_a=0 otherwise.                                            (5)

This is substantial dependence: the supposed temporal convolution is a mask of the actual orbit at the same output time. It is also the precise reason a cheap causal alias does not solve the inverse. At such a coordinate and h>=b+t, the retained equation reads u_h(a)=u_h(a); its fresh-source and direct-retained contributions are zero. All backward paths have a strictly earlier retained visit, and the immediate predecessors are eliminated. Replacing the feedback with its future-jet alias therefore removes the equation's computational content. Obtaining that future jet is the missing work.

Once the global orbit has independently been computed, (5) computes all g by O(r(n+1)) mask/copy/write work. Conversely, merely renaming these aliases cannot provide those values from x.

## 4. A selected, genuinely N-input packet bank

Select from g only the locations

    (h,a), a in S_t, 1<=t<=L, 2b+t<=h<=n,

and call the resulting x-to-output matrix H. This is an actual selection of requested values; no extra projected or transformed outputs are assumed available. Let D be its number of rows. Disjoint supports give

    D <= r(n+1).                                                    (6)

For fixed h,t, the inequality h>=2b+t ensures that the constraint a in S_t lies entirely in the c part of (1). Hence all q in [0,M) occur, independently. Its allowed Fourier labels f are

    f = rev_t(k) 2^(h-b-t) + v,
    k in K_t, 0<=v<2^(h-2b-t).                                    (7)

In the fixed-length h-bit representation of f, (7) has the pattern

    0^b  rev_t(k)  0^b  [arbitrary lower bits].                     (8)

Reversal preserves the condition of starting/ending in 1 and avoiding 0^b.

For each pair h,f in (7), H contains the complete q-bank of M packet rows from (1), each of squared norm 2^h. The gamma phases have modulus one and disappear from H*H. The q rows are disjointly supported and orthogonal. Their span is the Fourier subspace ell congruent to f modulo 2^h by (2). Therefore their Gram contribution is 2^h times the orthogonal projection onto that subspace.

Let F_unitary be the normalized full Fourier matrix, used here only to express a spectral identity. Define E_(h,t)(ell) to mean that the low h bits of ell have pattern (8), with some k in K_t. Summing the complete q-bank contributions proves the all-size identity

    H*H = F_unitary* diag(lambda_ell) F_unitary,
    lambda_ell = sum_(t=1)^L sum_(h=2b+t)^n 2^h 1_(E_(h,t)(ell)).     (9)

In particular,

    rank H = #{ell : lambda_ell>0}.                                (10)

All cross-time dependencies, overlaps, and reuse are included in (9). No independent jet blocks have been introduced. For one fixed h the relevant patterns are disjoint, but the formula also correctly handles frequencies selected at several different h.

## 5. A constant-density high-weight set, proved combinatorially

Consider the highest L bits of a uniformly random n-bit frequency ell, divided into two independent halves of length

    m=L/2=2^(b-2).

Within either half count occurrences X of the isolated-marker pattern P=1 0^b 1. There are a=m-b-1 possible starting positions and p=2^(-b-2) is the probability of any one occurrence. For b>=7,

    lambda=E[X]=a p, 1/32<=lambda<=1/16.                            (11)

Two P occurrences at an overlapping shift can coexist only at shift b+1, where they share their bounding 1 and have joint probability 2p^2. Nonoverlapping occurrences are independent. Consequently the deliberately loose bound

    E[X^2] <= lambda+lambda^2+4lambda p < 2lambda

is valid. Cauchy–Schwarz gives

    Pr(X>0) >= E[X]^2/E[X^2] >= 1/64.                            (12)

The halves are independent, so at least a fraction

    c=1/4096                                                     (13)

of all frequencies have an isolated marker in each half.

Such a high L-bit block contains at least two distinct zero runs of length at least b. Choose two successive such runs between the exhibited occurrences. The word k separating the runs starts/ends in 1 and avoids 0^b. Taking the adjacent b-zero suffix/prefix of those runs produces 0^b k 0^b wholly inside this block, with 1<=t=|k|<=L. Orienting the bit string either way preserves these properties. Let h be the position just after the upper chosen b-zero block. Then E_(h,t)(ell) holds, h>=2b+t, and h>=n-L.

Thus at least cN frequencies obey

    lambda_ell >= 2^(n-L).                                       (14)

This proves constant density without assuming independence of overlapping markers, a Poisson approximation, or an empirical fit. The constants are intentionally conservative. No claim of optimal density or optimal lower-bound constant is made.

## 6. Determinant bound for the actual constrained interface

Append the N original coordinate rows to H and write M=[I;H]. Those inputs are already available to a circuit. From (9),

    det(M*M)=det(I+H*H)=product_ell (1+lambda_ell)
             >=2^(cN(n-L)).                                    (15)

Cauchy–Binet expresses this determinant as a sum of squared absolute values of all N-row minors of M. Hence one such minor satisfies

    log2 |det M_I|
      >= (1/2)[cN(n-L)-log2 binom(N+D,N)].                        (16)

Track the maximum absolute determinant of N coefficient rows among all linear forms a circuit has ever made available. Initially it is 1. A scalar multiplier of modulus at most one cannot increase it, and one binary addition increases it by at most a factor 2. Therefore the paid addition count A obeys

    A >= (N/2)[(n-L)/4096
                -log2(e(1+(n+1)/2^b))].                         (17)

A negative right side is simply uninformative. At the accepted marker choice

    b=floor(log2(n/(4 ln n))),

we have L=o(n), (n+1)/2^b=O(ln n), and the subtraction in (17) is O(log log n). Thus

    A >= (1/8192-o(1)) Nn = Omega(N log N).                       (18)

This proof addresses precisely the earlier independence gap: the ambient input dimension is N, H is the actual source-generated output map, and (9)-(16) establish its volume after restriction. The N identity rows do not grant extra data or assume independent jets. They are original inputs retained only for the determinant argument.

For a fixed larger scalar bound K, the usual per-gate determinant factor changes by a constant, so the total-gate order persists. Unbounded multipliers require an explicit growth budget. Finite fields have no corresponding positive complex volume, and the finite-field controls below do not transfer (18) to them.

## 7. Fully paid constructions and what remains uncomputed

### Genuine packet reuse after an orbit is available

Prepare consecutive root powers, gamma/phase tables, and marker/membership lists in O(N+n) field/address work, using the accepted binary-parent/trie constructions. Read the N inputs. Compute Q^h x for h=1,...,n directly, charging every two-edge multiplication and merge, and extract the retained coordinates. This costs O(Nn) work. Apply (5) while each layer is live, writing the actual g outputs in O(r(n+1)) work. The final Q^n x, its Fourier phase/reversal correction, and all N final writes are paid in O(N). Live orbit storage is O(N); retaining all requested g values costs O(r(n+1)) additional words.

Thus (5) replaces independent young-feedback trajectories by copies in this fused execution, but computing the orbit still costs O(Nn). This is a matching-order upper bound for the actual constrained interface, not an arithmetic improvement below that order.

### Why the spectral factorization is not a fast preparation shortcut

If one implements (2) by first computing all y=F_N x, that preparation already costs O(Nn) using the standard scalar FFT. The inverse packet transforms and output routes remain additional operations. Computing them independently costs at most

    O(Nn + sum_h D_h(n-h) + D),

where D_h is the number of selected packet rows at time h; the simple bound is O(Nn+rn^2), potentially worse than the direct orbit. Equation (9) is a spectral certificate, not a license for free Fourier coordinates or packet inversion.

### Fresh source and inverse correction

The accepted marker-cut fresh source can still be prepared in O(N+|T|(n+1)+N2^b)=O(Nn/ln n) work and O(N ln n) words at the marker choice. That preparation neither supplies u nor computes H. Substituting the future-jet aliases into its Schur inverse leaves the tautological coordinates described in Section 3. No new causal correction has been derived, and no correction cost is omitted from a claimed faster algorithm: there is no such algorithm in this report.

An implementation that insists on exposing this actual young g bank already incurs (18) in the stated complex model, before any separate recovery bill. A more deeply fused solver might avoid these values entirely, so this component argument does not rule it out. A finite-field or explicitly changed-gate-model attempt also remains outside this obstruction. The exact constrained factorization and kernel in (9)-(10) are available for such an attempt, but are not by themselves a paid algorithm.
