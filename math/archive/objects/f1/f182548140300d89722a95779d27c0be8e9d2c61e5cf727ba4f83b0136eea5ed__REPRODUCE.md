# Reproduce the exact three-Green B5 construction

Requires only Python 3.10+ and the standard library. Run:

    python check_three_green.py --out-dir three-green-replay
    cmp EXACT_THREE_GREEN_RESULTS.json three-green-replay/EXACT_THREE_GREEN_RESULTS.json
    python verify_seal.py

The checker writes only its deterministic JSON to the output directory. Its arithmetic is rational in Q[zeta]/Phi5 and then in the explicit monic quadratic quotient. Every inverse checks its denominator exactly. It executes no predecessor/uploaded code and has no external dependency.

The report THREE_GREEN_B5_CERTIFICATE.md states the full construction and derivation. EXACT_THREE_GREEN_RESULTS.json contains all target/factor coefficients and guard data. A base-field element is encoded by four rational strings in the basis 1,zeta,zeta²,zeta³; an extension element has `constant` and `delta` base-field coordinates. The monic delta polynomial, pole polynomial and reduction certificate are included.

The positive construction can be verified on its own. The separately accepted TWO-Green impossibility is used only to conclude that THREE is the minimum number for this target; its report and manifest snapshots are preserved as inert data under source/.

The isolated replay copies only the new checker into a clean directory. It reproduces the result JSON byte for byte. No derivation workspace, bytecode cache or mutable scratch is part of this frozen artifact.

SEALED_MANIFEST.json covers all regular files except itself and SEALED_MANIFEST.sha256. The latter seals the former. verify_seal.py reads/hashes files only; it executes no snapshot source code.
