# Portable independent replay

Requires Python 3.11+ and its standard library. Run `python independent_checks.py`; no network or source data imports are used. It regenerates `INDEPENDENT_RESULTS.json` beside itself and prints identical deterministic JSON. Its working directory may differ.

The checker independently recreates the finite parameter grid, algebraic interpolation and full-support gates, explicit source-completeness counterexample, corrected resonance predicate, and mutation controls. It does not execute the uploaded implementation or its fallback/benchmark/test programs. All uploaded code in `source/` and `extracted/` remains inert.

`PHASE20_AUDIT.md` contains the proposed guard correction; no source file was patched. `PORTABILITY.json` records an actual relocated replay. Relative paths and SHA-256 hashes are sealed in `SEALED_MANIFEST.json`, with that manifest's digest in `SEALED_MANIFEST.sha256`.
