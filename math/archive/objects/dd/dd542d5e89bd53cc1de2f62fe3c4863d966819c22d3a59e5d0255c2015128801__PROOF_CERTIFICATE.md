# Exact mathematical certificate — interval windows and Fourier ranks

Date: 2026-10-09. No FFT complexity improvement is claimed. All stages are linear operators and all ranks refer to a field with primitive Nth root of unity; complex numbers and the listed finite fields qualify.

## 1. General window-rank lemma (arbitrary invertible transform)

Let `M` be an invertible `N×N` matrix over a field. Let `C` be invertible, let `pi` be a permutation, and define `B=M C[:,pi]`. Let `r_C^up`, `r_C^down`, `r_B^up`, `r_B^down` be upper-right and lower-left quasiseparable rank bounds: for each `1<=k<N`,

- `rank(C[:k,k:]) <= r_C^up` and `rank(C[k:,:k]) <= r_C^down`,
- likewise for `B`.

Take **any contiguous column window** `I=[u,v]` of B, of length `t=v-u+1`. Set `J={pi[u],...,pi[v]}`, `a=min J`, `b=max J`, `H=[a,b]` (length `h=b-a+1`), `R={0,...,N-1}\I`. Let

`beta = 1_{u>0}r_B^up + 1_{v<N-1}r_B^down`.

Then the following three **unconditional, necessary** inequalities hold:

(Head) `t-(N-a) + rank(M[R, {a,...,N-1}]) <= beta + 1_{a>0}r_C^up`.

(Tail) `t-(b+1) + rank(M[R, {0,...,b}]) <= beta + 1_{b<N-1}r_C^down`.

(Both) `t-h + rank(M[R,H]) <= beta + 1_{a>0}r_C^up + 1_{b<N-1}r_C^down`.

If the left side is negative the bound is vacuous, but remains correct.

**Proof.** Let `X=C[:,J]`, an `N×t` matrix with independent columns because C is invertible. For any choice of row set T outside a consecutive support interval H, define the stacked linear map `L=[projection_to_T; M[R,:]]`. A vector in `ker L` has support inside H and is killed by `M[R,H]`, hence

`dim ker L = |H| - rank(M[R,H])`.

The restriction of L to the t-dimensional column space of X therefore has rank at least

`t - |H| + rank(M[R,H])`.

On the other hand, `rank(M[R,:]X)=rank(B[R,I])<= beta` since the rows outside I split into an upper-right block and a lower-left block. For the head, tail, or both choices of T, `rank(X[T,:])` is bounded respectively by `r_C^up`, `r_C^down`, or their sum, omitting empty sides. Subadditivity for stacked matrices proves all three inequalities. No matrix-entry normalization, genericity, cancellation assumption, or nonzero-corner condition is used. QED.

## 2. Fourier Vandermonde specialization and arbitrary OUTPUT permutations

Assume `M[i,k] = omega^(rho(i)*(c+d*k))` for arbitrary output permutation `rho`, some `c`, and a step d coprime to N. Standard DFT order is `c=0,d=1`; cyclic shifts and odd modular strides for N power of two are also covered. The bases `omega^(d*rho(i))`, as i ranges over **any** row subset R, are distinct. Thus for **any consecutive input-coordinate interval H**, `M[R,H]` is a rectangular Vandermonde matrix up to nonzero row scalings and satisfies

`rank M[R,H] = min(|R|,|H|)`.

Since `|R|=N-t`, substituting into the three general inequalities yields the concrete **window theorem**:

```
min(t,a)       <= beta + 1_{a>0}r_C^up
min(t,N-1-b)   <= beta + 1_{b<N-1}r_C^down
min(t,N-h)     <= beta + 1_{a>0}r_C^up + 1_{b<N-1}r_C^down.
```

These remain valid over the complex numbers, and do not require a large modulus. Arbitrary output permutations are allowed. **Arbitrary NON-affine input permutations are NOT covered by this specialization.** For those, use the general rank-dependent inequalities, not the simplified formulas.

## 3. Permutation-independent counting obstruction for two stages

Put `delta = r_C^down + r_B^up + r_B^down`, `m=delta+1`, and suppose the simplified Fourier Vandermonde conditions apply. Every interior window of B consisting of m consecutive columns (start `u>=1`, end `v<=N-2`) must contain an index from the last m C-column positions `{N-m,...,N-1}`. Otherwise `b<=N-m-1` and `min(m,N-1-b)=m>delta`, contradicting the **tail** inequality.

There are exactly `N-m-1` interior windows of length m whenever this number is nonnegative, and each particular C-column index occurs at exactly one B-column position and can belong to at most m of these windows. Only m indices are in the last-m set. Hence:

`N-m-1 <= m²`, i.e. **`N <= m²+m+1`**.

Likewise define `delta'=r_C^up+r_B^up+r_B^down`, `m'=delta'+1`. The head inequality gives `N <= (m')²+m'+1`. Both necessary bounds hold simultaneously. Small N for which no interior window exists satisfy these numerical bounds automatically.

If all four QS rank bounds are at most r, then `m,m'<=3r+1`, yielding:

`N <= (3r+1)²+(3r+1)+1 = 9r²+9r+3`.

In particular r=1 requires N<=21, and **at any N>=22**, including N=32, no such two rank-one stages exist **for any internal permutation**, provided the Fourier input order is natural or affine coprime-stride (output order may be arbitrary). This architecture-specific bound is weaker than other established restricted-model FFT bounds; it does not say that a general FFT needs Omega(sqrt N) operations or stages.

## 4. Counterexample if one silently allows arbitrary input endpoint permutations

There is an exact 16-point two-factor Cooley–Tukey construction modulo 12289 with N=16, both stage QS orders equal to 1, the following intermediate permutation:

`pi=[0,8,4,12,2,10,6,14,1,9,5,13,3,11,7,15]`.

It has independently reordered Fourier input and output endpoints. In the first three B columns (`I=[0,2]`), `J={0,8,4}`, `H=[0,8]`, `t=3`, and `R=[3,15]`.

- Naively assuming Vandermonde gives `rank(M[R,H])=9`, so the *invalid* simplified lower bound is `3-9+9=3` against budget `2`.
- The **actual exact** rank of this reordered Fourier submatrix is `8`, and the valid lower bound is `3-9+8=2`, equal to budget `2`.

The construction satisfies `M=B A[pi,:]` with both stages QS rank 1, and the verifier checks every one of the 16×16 entries of that equality. This is a decisive positive control: the bound must not be extended to arbitrary input reorderings without using actual Fourier submatrix ranks. An analogous exact N=8 control has ranks 4 instead of 5.

## 6. Novelty and limitation

The rank-nullity lemma and Vandermonde rank arguments are classical mathematics applied here to a specific two-stage architecture; **no priority claim** is made for a new general theorem of FFT complexity. In particular, the counting obstruction applies to a restricted endpoint model and is superseded in strength by previously established stronger barriers for other restricted models. The exact arbitrary-endpoint gate is the safe starting point for any further exploration. No `O(N)` Fourier transform or integer multiplication algorithm has been found.
