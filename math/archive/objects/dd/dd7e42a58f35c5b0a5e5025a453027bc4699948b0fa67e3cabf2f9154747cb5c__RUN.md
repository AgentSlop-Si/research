# Reproducing Phase 31 from a fresh extraction

Requires Python 3.10+ and a C++17 compiler. Uses no external Python packages. Run commands from the extracted `fft_green_phase31_rectangular/` directory.

```bash
python3 -m unittest -v tests_phase31
python3 phase31_six_control.py
python3 phase31_seven_control.py

c++ -O3 -std=c++17 rectangular_seven.cpp -o rectangular_seven
python3 build_input.py 8 phase31_N8.bin
./rectangular_seven phase31_N8.bin phase31_N8_ranks.bin
# Must print: N=8 ... count=564480 ranks: 35:564480

python3 build_input.py 16 phase31_N16.bin
./rectangular_seven phase31_N16.bin phase31_N16_sampled_ranks.bin --indices certificates/indices_N16_100000.bin
# Must print: indexed samples=100000 ranks: 35:100000

python3 build_input.py 8 phase31_planted.bin --plant
./rectangular_seven phase31_planted.bin phase31_positive.bin 9682 9683
# Must print: ranks: 34:1
```

The two C++ binaries verify **exactly modulo 998244353**. Input format: `<uint32 prime><uint32 N>`, then six dense N×N matrices as little-endian uint32 (target followed by five Green components). Each byte of the rank stream stores the degree-three Macaulay rank of one ordered mapping. Mappings are lexicographic `itertools.permutations(range(N),3)` times `permutations(range(N),4)`; for N16, the sample-index file contains little-endian uint64 case IDs.

Check the included certificate hashes in `SHA256SUMS.txt`. The native exhaustive N8 run on our evaluation machine took around 23 seconds; this is **verification time**, not claimed FFT execution time. The entire N16 permutation space contains 146,764,800 cases and was NOT exhaustively audited.

The `tests_phase31` suite uses the stored rank records and independently recomputes a selection of determinants in Python. The `previous_full_phase30_checkpoint.zip` file preserves earlier research; the immediate Phase28/29/30 code dependencies have also been copied into this folder for standalone reproduction. The executor cost counts field operations after building the Hamiltonian cycles and root tables; the power tables are generated by repeated multiplication in O(N).
