# Reproduce Phase 18

1. Use Python 3.10 or later, no extra pip dependencies.
2. From this folder run:

```bash
python -m unittest -v test_phase18
python independent_audit.py
python weyl_line_gate.py
```

3. `AUDIT_RESULTS.json` reports exact counts and comparison cases. The audit repeats the full 65,536-entry random input with a fixed seed and independently sums all K resolvent solutions.
4. To rerun Phase 17:

```bash
mkdir phase17_recovery
cd phase17_recovery
unzip ../PHASE17_PREDECESSOR.zip
# locate test_phase17.py in the extracted folder, then:
python -m unittest -v test_phase17
```

5. Outputs use exact prime-field integers; there is no tolerance or floating-point match criterion. Scalar operation counters charge additions, multiplications and inversions. Hardware runtime numbers are diagnostics, not portable algorithmic benchmarks.
