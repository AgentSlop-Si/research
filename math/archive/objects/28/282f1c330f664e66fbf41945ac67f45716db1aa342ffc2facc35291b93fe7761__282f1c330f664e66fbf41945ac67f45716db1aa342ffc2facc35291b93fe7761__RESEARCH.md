## Theorem 1 — quadratic Boolean correctness yields a general linear evaluator

Let K be a field with characteristic not equal to 2. Suppose a polynomial map P: K^N -> K^M of **total degree <=2** satisfies P(x)=Ax for every x in {0,1}^N. Then

    P(x)=Ax+Σ_i c_i (x_i^2-x_i)

for some fixed output vectors c_i. This follows from the unique multilinear representative on the Boolean cube: the functions 1, x_i, x_i*x_j (i<j) are independent there, and replacing x_i^2 by x_i leaves Ax.

At the center c=(1/2,...,1/2), the correction terms are even under h -> -h:

    (1/2 + h_i)^2-(1/2+h_i) = h_i^2-1/4.

Therefore, **for every h in K^N**:

    Ah = [P(c+h)-P(c-h)] / 2.

If a uniform arithmetic circuit evaluating P has s gates, two evaluations plus O(N+M) coordinate arithmetic give a circuit for Ah. No output coefficient extraction, input-relation metadata, or cached FFT is required. This is a **constant-factor reduction**, not a lower bound better than known general linear-circuit lower bounds. It rules out a *degree-two-only Boolean escape* within that model, not high-degree or lookup/branch-based algorithms.

Checks: exact modular tests for N=2,4,8,16,32,64; independent rational arithmetic for N=2,...,6.

## Theorem 2 — cubic cancellation is possible, but recovery becomes costly in a restricted model

A **homogeneous cubic** P agreeing with Ax on {0,1}^N has the form

    P(x)=Σ_i A_i x_i^3 + Σ_{i<j} Γ_ij (x_i^2*x_j - x_i*x_j^2).

The first sum maps to Ax on the cube. The pairwise antisymmetric terms vanish because x_i^2=x_i. Terms on three distinct variables have uniquely identifiable Boolean monomials and their coefficients must be zero. This normal form holds componentwise, using exact polynomial identities.

There is an explicit recovery formula using **N+1 directional derivative/Jacobian-vector evaluations**:

    Ah = [ D P(1⃗)[h] + Σ_i D P(e_i)[h] ] / 6.

The cube terms contribute 6 Ah; each antisymmetric pair term contributes +1,-1,-1,+1 in the indicated derivative sum and cancels. The proof requires the field characteristic not dividing 6. A directional derivative of a circuit can itself be computed by a constant-factor tangent evaluation, with prepared basepoint values; thus this supplies an O(N s) recovery from a black-box circuit of cost s, not an O(s) shortcut.

For **universal fixed-weight linear combinations of gradients at t predetermined basepoints** a^(r), the second-moment constraints force

    Σ_r w_r a^(r) a^(r)^T = (I+11^T)/6.

The right-hand side has rank N over characteristic-zero fields (and over F_p provided p does not divide N+1 or 6). The left side is a sum of t rank-one matrices, so t>=N. **This lower bound applies only to that fixed-weight gradient-averaging method, not to arbitrary cubic circuits or every way to recover the FFT.** The N+1-point identity above is a simple explicit construction, not an optimal claimed N-call construction.

## High-overlap example with Θ(N²) symbolic terms and O(N) evaluation

Let a,b be arbitrary fixed N-vectors and define

    G(x) = (a·x²)(b·x) - (a·x)(b·x²),

where x² denotes componentwise squaring. Expanding yields

    G(x)=Σ_{i<j} (a_i b_j-a_j b_i)(x_i² x_j-x_i x_j²).

This can have N(N-1)/2 nonzero *symbolic pair coefficients*, yet the factored form evaluates with O(N) ring operations. On every Boolean input x²=x, so G(x)=0. This is a real compression of expression size, but it computes a Boolean-null **gauge**, not the FFT. Adding w_k G(x) to FFT(x³)[k] yields a more complicated circuit with identical Boolean outputs and **more counted work**, not a speedup.

## Theorem 3 — N shared features + linear readout have no nonlinear room

Consider functions f_1,...,f_N on the Boolean cube. Suppose a **linear** output readout of these exact N functions recovers all N Fourier output functions, which are an invertible linear transform of the independent input-coordinate functions x_1,...,x_N. Their N-dimensional function span must equal the entire span of {x_i}. Consequently every f_j must itself be a Boolean-linear function (with zero constant component). An independent nonlinear function requires **at least one extra feature**, but having extra features says nothing about whether total work drops.

The finite rank audit checks an example f_i=x_i+(Σ_j x_j)² at N=2,4,8; it needs N+1 feature dimensions when full Fourier outputs are joined. This is a **linear-readout feature-bank restriction**, not a general FFT lower bound. Complex output encodings, nonlinear readouts and other architectures are not ruled out.

The Θ(N²) number of symbolic interactions is misleading as a complexity metric without the fully charged evaluator—just as the earlier symbolic DAG compression was.

## Actual next research gate

The current unresolved goal is to design a uniform **Boolean-only circuit whose nonlinear gates replace**, rather than add to, the linear computation of all Fourier outputs. Accept only a concrete recurrence or gate list, true total-work savings versus the best available arithmetic circuit in the **same exact model**, full-output correctness for every binary input, and a scalable analysis. Reject gauge add-ons, exponential monomial expansion, repeated-input caches, precomputed full answers, and CrocSwap-style parameter retuning as evidence for the original O(N) conjecture. If a proposed design has exactly N intermediate shared scalar features followed by a linear readout, Theorem 3 already rules out genuinely nonlinear feature directions.
