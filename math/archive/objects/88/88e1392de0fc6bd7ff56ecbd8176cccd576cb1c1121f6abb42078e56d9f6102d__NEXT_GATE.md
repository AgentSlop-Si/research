# Phase 30 — Research handoff

The original FFT goal is an independently established exact all-input algorithm with strictly better asymptotic growth than ordinary `N log N`, ideally toward `O(N)`. Phase 29 does **not** supply that. A public 2026 all-length sub-`N log N` construction is claimed in OpenAI mathematics manuscripts under unrestricted exact arithmetic, while the publicly inspected comparator `lean/ComparatorChallenges/UniformFourier.lean` currently contains `sorry` placeholders; avoid conflating claimed manuscript, formal proof and independently compiled executable result.

**Priority 1: genuinely non-diagonal multiwire sharing.** The `(8,h)` twiddle tensor retains 105(h-1) scalings in the new length-`120h` graph. The C4-free theorem excludes unbounded improvements from row/column gauges alone, and the weighted-four rank gate rejects one fixed-rational one-layer diagonal absorption. Search exact non-diagonal cross-block circuits with provably cheaper *complete* scalar adds+muls, not just a smaller count of high-arity boxes.

**Priority 2: scalable codelet search and reciprocal tensor cost.** Search exact 16- and 32-point rational pre/diag/post decompositions. For each factor record: physical dimension n, diagonal width r, additions p/q, nontrivial scalars, coefficient heights, cold setup, runtime workspace, and location-specific twiddle costs. Reject circuits that save a few multiplications by adding more total operations. A complete 240-point candidate should be compared at the *same* length to Phase 29, preserving characteristic-zero identities.

**Priority 3: independent constant and numerical model.** Benchmark against modern FFT/NTT implementations and measure real memory traffic, index work and floating-point error. Our tests are finite-field modular checks. Winograd multiplicative savings can have adverse addition, preparation, and rounding costs.

**Priority 4: novelty audit.** Before calling any short-DFT diagonal new, compare with published Winograd 8, 16, 32, 60-point transforms, Good–Thomas, and modified split-radix. The Phase 29 120-point tensor is a project integration of established identities, not a historical invention claim.

**Falsifiers:** an incorrect basis column; a missing pre/post scalar; a diagonal coefficient equality hidden by finite-field reduction; coefficient-plan cost counted free; index routing not natural DFT order; a purported `o(N log N)` claim derived only from an `O(N)` saving.
