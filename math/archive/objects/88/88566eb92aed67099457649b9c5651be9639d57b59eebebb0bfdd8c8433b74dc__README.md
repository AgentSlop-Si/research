# FFT divisor-spectrum research v13

Standalone research package for the randomized full-output approximation theorem in `RESEARCH.md`.

## Install

```bash
python -m pip install -r requirements.txt
```

## Reproduce

```bash
python prototype.py --output results.json
python -m unittest -v test_checkpoint.py test_inherited_routes.py
python benchmark.py
sha256sum -c MANIFEST.sha256
```

## Main files

- `RESEARCH.md` — theorem, proof, limitations and audit.
- `CHAIN_CHECKPOINT_2026-10-10_v13.md` — compact handoff.
- `prototype.py` — divisor-sum certificate, composite executor, planner, experiments.
- `composite_cycle_core.py` — arbitrary-composite unit-step row executor.
- `offset_class_core.py` — inherited v12 offset-class route and rank gate.
- `v11_fused_reference.py` — inherited Bessel all-length fallback.
- `unit_step_core.py` — prime-power core used by inherited routes.
- `test_checkpoint.py`, `test_inherited_routes.py` — 20 automated tests.
- `results.json` — saved reproducible experiment data.
- `benchmark_results.csv` — honest Python/NumPy timing comparison.

## Claim boundary

The package implements a randomized additive approximation. It does not implement an exact sub-`N log N` FFT and is not faster than optimized FFT software in the saved benchmarks.
