# Sparse q-difference forcing: an exact restricted-input corollary

This is a constructive extension of the kernel-spectrum recurrence. It computes all N Fourier outputs of a fresh input in O(N(s+1)) exact field operations, where s is a particular residual sparsity, including its detection. It does not guarantee small s for arbitrary inputs. The present evaluator has quadratic worst-case work and is an audit implementation, not a general FFT replacement.

## Algorithm and proof

Let q have exact order N=2^L in a field of characteristic not dividing N. Let P(z)=sum_(j=0)^(N-1) x[j]z^j. Define

    R(z) = P(qz) - (1-z)P(z)
         = x[N-1]z^N + sum_(j=1)^(N-1) r[j]z^j,
    r[j] = (q^j-1)x[j] + x[j-1].

At each Nth root z=q^k, the last term is the constant x[N-1]. The algorithm constructs all powers and r in O(N) work and finds s nonzero middle r[j]. Each supported monomial can be evaluated at every root using a geometric progression in O(N) work, so every value R(q^k) is available in O(N(s+1)).

Put v[k]=P(q^k). The exact equation gives

    v[k+1] = (1-q^k)v[k] + R(q^k), with cyclic indices.

At k=0 its coefficient of v[0] is zero. Therefore v[1]=R(1) without knowing any output in advance. Continuing through k=1,...,N-1 gives all remaining values, including v[0]. This needs N-1 additional multiply/add/subtract steps and emits all outputs. There is no input FFT, cached answer, approximation, or discarded boundary term.

With all operations counted even for unit scalars, the implementation uses

    multiplications = (s+3)(N-1)
    additions       = sN + 2(N-1)
    subtractions    = 2(N-1).

Root-power preparation is included. Support detection, indexing, and logical data movement are O(N(s+1)); storage is O(N). Finding and representing the supplied root are separate model choices. These exact field counts make no bit-complexity or floating-point stability assertion.

## Why the corollary does not solve the general goal

The complete forcing coefficient vector rbar=[x[N-1],r[1],...,r[N-1]] is an invertible linear encoding of the original input. Its inverse is the backward sweep

    x[N-1] = rbar[0],
    x[j-1] = rbar[j] - (q^j-1)x[j], j=N-1,...,1.

Thus rbar is arbitrary for arbitrary x, and there are inputs with all N-1 middle coefficients nonzero. Evaluating arbitrary forcing spectra reintroduces the same polynomial-evaluation problem after invertible O(N) preparation. This is an equivalence of formulations, not a lower bound against every possible faster evaluator.

The zero-middle-forcing family is a scalar multiple of the q-factorial kernel from the preceding checkpoint. That kernel has midpoint Hankel rank N/2, so this criterion is different from requiring a low-order constant-coefficient recurrence. This does not imply a large family of independent arbitrary inputs: fixing an s-location forcing support leaves only s+1 free scalar parameters.

## Verification

Run `python3 sparse_forcing.py`. Two-prime exact checks cover every forcing basis vector for N=2 through 64, inverse encoding, every Fourier output, 24 sparse-family cases through N=256, six dense-forcing negative controls, and the stated operation formulas. These finite tests audit the algorithm; the identities above establish the all-size result under its assumptions.

This is retained as a useful structured-input result, separately from the goal of beating N log N on arbitrary fresh input. No global novelty or general FFT breakthrough is claimed.
