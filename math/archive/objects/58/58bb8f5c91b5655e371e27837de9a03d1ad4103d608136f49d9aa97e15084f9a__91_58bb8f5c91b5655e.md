## Algebra and branch handling

The sign convention is correct for the positive-exponent DFT. Substituting
t=a j+c into sum_j q^((k+b)j) x_(aj+c) gives target index
a^-1(k+b) and phase q^(-c a^-1(k+b)). The code computes that phase using its
already formed target index. Testing inverse primitive roots additionally
checks that the implementation is not accidentally tied to the canonical
root chosen by the field helper.

For a=1 modulo 4 and odd b,c, both affine maps are single cycles modulo a
dyadic N. Their edge product is -lambda^N, so singularity is exactly
1+lambda^N=0. The solver forms this product and declines before inversion
if singular. The all-zero input can correctly return zero independently of
this condition. Nonzero compatible singular queries still decline and the
wrapper pays for an ordinary FFT.

The backward cycle solve is correct: its first pass constructs the numerator
of y_0; division by 1-C obtains the cyclic starting value; its second pass
recovers every coordinate. It does not divide by individual edge weights,
and is valid even when some or all edge weights are zero.

Unknown-lambda discovery requires more than twice the defect budget in
nonzero weighted denominators to guarantee the correct majority. Every
selected candidate is then verified on the whole input. A failed majority
promise cannot cause an unsupported acceptance, but a low-defect input can
be declined if the support is insufficient. Supplied lambda removes this
discovery restriction while preserving full residual verification.

## Cost accounting

The primitive root q is a supplied common input. Both this routine and the
comparison FFT pay N multiplications to prepare and validate their full root
table; neither bill includes finding the initial q.

The nonsingular cycle solver costs exactly 5N+3 field calls: 3N+1
multiplications, 2N additions, one subtraction and one inversion. Its
singular branch costs N+1 calls. With s actual residual entries, the supplied
lambda path therefore costs at most (10+2s)N+3 calls. Discovery adds at
most 2N calls, giving at most (12+2s)N+3.

For the audited dense one-defect-at-zero family, the vote schedule resets
twice; it makes N-2 cross-product comparisons instead of the upper bound
N-1. This saves two field multiplications, yielding exactly 14N+1 calls.
The ordinary radix-2 comparator costs N+(3/2)N log2(N) under the same root
table and scalar-operation contract.

These are exact-field operation counts, not bit complexity or wall-clock
claims. Equality tests and indexing are excluded from the scalar tally but
their number is linear for fixed s and bounded-word affine parameters.
With growing s, the direct defect transform costs 2Ns; a singular rejection
can therefore cost O(N(1+s)), rather than O(N). Inversions are paid scalar
operations, including the input-dependent inverse used in discovery.

## Independent validation

Run `python3 independent_checks.py` in this directory. The check uses direct
Fourier sums with the supplied q and dense Gaussian elimination, and does
not reuse the author's input-generation recurrence or cycle-order routine
as a correctness reference. An external field wrapper independently checks
reported operation totals and stage sums.
