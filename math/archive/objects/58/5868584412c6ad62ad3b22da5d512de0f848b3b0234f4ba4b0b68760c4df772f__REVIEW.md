## Findings that change how the material can be used

1. **Scan macro guard and cost ledger defects (S08).** The root validator checks only w^(N/2) != 1, omitting w^N=1; zero is therefore wrongly accepted as a root. The N=2 path unconditionally prepares a radix-four plan, rejecting the otherwise valid N=2 transform over F3 with generator 2. The pre-stage power-call count is initialized to 22 but the source has 26 calls: two initial root powers, two scan-plan root powers, sixteen matrix-entry powers and six inversions. These are implementation/accounting defects. Under valid roots the construction is conventional mixed-radix FFT, not a faster all-input algorithm.
2. **Strong-scale tail underflow (S13).** This wrapper uses unscaled np.linalg.norm on the tail despite importing a more careful scaled energy-pruning backend. A finite [1e-200,0] tail has NumPy norm zero; with head size zero and epsilon=1/4, the wrapper would return zero although the true unitary Fourier magnitude exceeds the requested tolerance. This is established by fresh library arithmetic plus a static branch trace, not by running the supplied program. The ideal-arithmetic proof and ordinary-scale examples remain separate. The adversary helper also returns an unconditional lower bound for arbitrary epsilon arguments, although the bound requires a small-epsilon condition.
3. **Long-lived and malformed-input guard defects.** S04's signed-int epoch increments eventually overflow before its attempted zero-wrap reset. It can also partially mutate state before encountering an invalid later edit. S01's interpolation API checks p>1 and enough points but not primality; p=9,m=4 admits the noninvertible Newton divisor 3. S57's Boolean encoder validates int(value), silently accepting 0.5 and 1.9. S62 merges individually finite edits without checking finite aggregate values and truncates N through int(N). S63's logarithm helper requires x>=1 for its stated positive-tail orientation but does not enforce it. S69's standalone power helper does not terminate for negative integer exponents, although its constructor uses positive ones.
4. **Certificate validation versus valid stored certificates.** S58 permits negative support indices; S65 checks range but omits uniqueness within each support. These are malformed-artifact guard weaknesses. The actual archived cubic supports all satisfy the required Boolean constraints. Fresh independent reconstruction verifies their nonzero determinants at N=8,16,32, so these guard weaknesses do not invalidate those specific checked certificates.
5. **Runner and label limitations.** In S52, unittest.main appears before the RoutingTests class. Direct execution ordinarily exits before discovering those three routing tests; unittest module import/discovery does include them. S39's fields named “lines” enumerate nonzero direction vectors, counting N-1 representatives per projective line. S47 uses exact Ramanujan formulas but float64 matrices/eigenvalues, so its original printed “exact” counterexample was not an exact evaluated spectral certificate. S55 can return the auto-selected Plan.method after an explicit backend override, misdescribing the backend actually used. S49 writes result/summary files before subsequent subprocess tests; their existence alone does not establish a successful run.
6. **Mathematical conditions matter.** S00's second-moment matrix (I+J)/6 has full rank only when characteristic is neither 2 nor 3 and does not divide N+1. Its fixed-prime supported small tests satisfy these conditions; the unrestricted wording needs qualification. S68/S69 document unit-modulus cycle weights but validate only their product. Algebraic inverse identities under product -1 are distinct from unitarity claims requiring individual unit modulus.

## Positive independent certificate reconciliation

The 46 fresh reviewer checks in `FRESH_REVIEWER_CHECKS.json` all passed. They are independently authored and do not call supplied functions.

- Boolean conjugate-pair cubic certificates: rebuilt evaluation matrices directly from valid Boolean supports and character-matched monomials. N=8: 9 rows/8 monomials, determinant **244742411**; N=16: 41/40, determinant **897006988**; N=32: 169/168, determinant **712284710**, all modulo 998244353. These support the stated degree-restricted noncompletion result, not an unrestricted circuit lower bound.
- Fixed four-Green obstruction: direct inverses of I-T, rather than the supplied geometric-series checker, reconstruct saved A/B and the first-two-column pencil. Its determinant is **55687 modulo 65537**, excluding a nonzero interface diagonal for those fixed stage parameters only.
- Arbitrary-endpoint F8 rank-two obstruction: all **3,136** 3x5 Fourier submatrices independently have modular rank 3. Thus no endpoint ordering can satisfy a rank-two offdiagonal ceiling at cut 3. This is a precise finite architectural obstruction.
- Composite covariance: independently reconstructed the N=12,M=3 matrix using the divisor-sum Ramanujan identity with exact rational arithmetic. A recorded integer vector has exact Rayleigh quotient **1196/3033 > 1/4**; also Q² differs from Q/4. This independently certifies a failure of the proposed prime-power projector extension without trusting numerical eigenvalues.
- Ten synthetic dirty-scratch full-state matrices have the exact serialized hashes reported by their stored summary. Gate counts equal 2N in the stated cancellation-free signed-addition grammar. This is metadata/bill reconciliation, not a replay of the supplied circuit generator.

## Complexity, correctness and novelty

The material contains valid qualified constructions: standard radix/split-radix FFTs, real packing, sparse and low-rank reuse, stateful updates, annihilator convolution, Bluestein/Kronecker reductions, rational Green identities, and exact finite rank/degree certificates. Each has its own model, input promises, precision assumptions, preprocessing and output costs. A small description, one big-integer multiplication, one sampled row, cached spectra, or a count of generic multiplications is not a general fresh-input exact linear-time Fourier transform.

This static audit establishes no new literature-priority or novelty result. The supplied comments calling programs “independent” or “authored” are not accepted as authorship evidence. Qualified mathematical validity, implementation guard/accounting defects, historical execution reports and novelty are kept separate throughout.
