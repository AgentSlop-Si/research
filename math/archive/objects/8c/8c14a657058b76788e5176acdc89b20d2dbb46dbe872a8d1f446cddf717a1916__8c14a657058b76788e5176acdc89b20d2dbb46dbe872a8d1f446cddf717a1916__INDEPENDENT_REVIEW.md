# Independent review: block evaluation of high-degree q-Weyl tails

9 October 2026. Reviewed `README.md`, `tail_blocks.py`, `full_similarity.py`,
`run_audit.py`, and the imported `fixed_kernel.py` and `orbit_kernel.py`
implementations. The block algorithm
and both complete arithmetic-count formulas are consistent. No additional
test runs were needed: the existing audit compares every basis vector with
direct C-Horner evaluation and separately checks the two triangular kernels.

## Exact map checked

Let A^T be the ordinary upper shift, T=H_q(A) the lower triangular kernel, and
g_j=product_(a=0)^(j-1)(q-q^(-a)), with g_0=1. Writing G=diag(g), the nonzero
upper-shift weights give

    B = G^-1 A^T G,     C = T B T^-1.

The inverse triangular kernel coefficients are d_j=1/g_j, exactly the array
`kernel.middle`. Thus

    C^(N-r) p(C) = T G^-1 (A^T)^(N-r) p(A^T) G T^-1.

For deg(p)<r, only the last r coordinates of T^-1 x are used. After scaling
these by g_(N-r+j), the nonzero head coordinates before decoding are

    v_i = (1/g_i) sum_(j=i)^(r-1) p_(j-i) g_(N-r+j) (T^-1 x)_(N-r+j).

The code implements this formula in order: projected T^-1, tail G scaling,
upper Toeplitz p action, head G^-1 scaling, and the first r columns of T.

For source block b, projection uses the Toeplitz coefficient index
`(N/r-1-b)r+i-j`. For output block b, decoding uses `br+i-j`. These are exactly
the centers passed to `_window`. A length-2r cyclic convolution suffices:
the possible differences i-j lie from -(r-1) to r-1, with no alias between
positive and negative embeddings. Padding the input block's second half with
zeros makes the first r convolution outputs the desired window. The upper
polynomial embedding places p_j at index 2r-j, giving the required j>=i sum.

Summing all projection products in frequency space before ONE inverse FFT is
legal by linearity. Reusing the transformed r-dimensional decoding state across
all output windows is likewise exact. Neither step hides an N-point FFT.

## Hypotheses and rank

N and r must be powers of two with 1<=r<=N/2; q must be a supplied primitive
Nth root in a field where N is nonzero. These assumptions imply all g_j and
q-factorials used here are nonzero. Since 2r divides N, the transform root
q^(N/(2r)) is available by indexing the prepared powers. A primitive 2Nth root
is not required. The reciprocal transform length is correctly prepared as
`(N/(2r))*(1/N)`.

The operator has rank AT MOST r for arbitrary p. It has rank exactly r when
p_0!=0, since p(C) is then invertible and C is similar to one nilpotent Jordan
block of size N. The default highest-degree H_q tail satisfies this condition.
More generally, if the first nonzero coefficient is p_v, its rank is r-v;
the zero polynomial has rank zero. The public routine accepts these lower-rank
polynomials too, so an unqualified exact-rank-r statement must be restricted
to its default/nonzero-constant case.

## Arithmetic and storage checked

Put s=log2(2r), L=log2(N). Preparation performs 2N/r+1 forward FFTs of length
2r, hence `(2N+r)s` butterflies. The non-FFT work adds the complete previous
kernel preparation, a new root table, the g prefix products, and reciprocal
length construction. This gives exactly

    multiplications: 8N+L-5+(2N+r)s
    subtractions:    2N-2+(2N+r)s
    additions:       L-s+(2N+r)s
    negations:       N-1
    constant inversions: 1.

Online there are N/r+2 forward and N/r+2 inverse FFTs of length 2r, totaling
`F=(2N+4r)s` butterflies. Including inverse normalizations, spectral products,
projection accumulation and the two diagonal scalings gives exactly

    multiplications: F+6N+8r
    additions:       F+2N-2r
    subtractions:    F.

The two banks of stored window spectra occupy 4N field values in total; the
remaining tables and workspace are O(N). Window construction, padding, array
traversal, indexing and all N output writes fit within O(N log(r+1)). The
counts are exact field-operation counts for the displayed program, not bit
complexity or native machine instruction counts. Supplied-root construction
and representation costs remain explicit model assumptions.

## Scope

The result proves O(N log(r+1)) preparation plus application for the specified
high-degree tail, including r=1. It does not evaluate all of H_q(C) at that
cost for small r. Combining enough disjoint coefficient tails to reconstruct
the full polynomial needs its own cost analysis; none is inferred here.

## Added resolvent identity and same-target comparator

The final README's weighted aggregate is correct. Multiplying
`(lambda I-C)^-1=sum_k C^k lambda^(-k-1)` by
`lambda^(1-r)p(lambda)/N` gives coefficient averages of
`lambda^(j-r-k)`. For 0<=j<r and 0<=k<N, the only exponent divisible by N is
-N, occurring at k=N-r+j. Averaging over all N roots therefore recovers
exactly C^(N-r)p(C). A nonzero constant p indeed makes every resolvent weight
nonzero while leaving the rank-at-most-r restriction intact.

The new full-length comparator implements the SAME operator with three
length-2N convolutions, using a separately supplied primitive 2Nth root.
The upper cyclic embedding places p_j at the negative of its complete exponent
N-r+j, as required. Its online counts independently sum to
`6NL+20N` multiplications and `6N(L+1)` each of additions/subtractions.
Its preparation count is `3NL+12N+2L-4` multiplications,
`3N(L+1)+2N-2` subtractions, `3N(L+1)` additions, `N-1` negations and two
constant inversions. These agree with the displayed loops and final README.
The comparison is explicitly a straightforward full-similarity backend, not
an optimal circuit or the different complete H_q(C) operator.

The final README includes the root and rank qualifications identified above.
No further source change or test rerun was required by this review.
