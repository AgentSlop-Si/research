# Exact FFT bidirectional macro-stage research

This project tests whether global bidirectional prefix/suffix scans can replace a growing number of FFT levels for fresh, arbitrary inputs. **Answer for one-block-per-macro scan architecture: no.** The unrestricted interleaved **nonunitary** global-stage question remains open in the project.

## Contents

- `RESEARCH.md`: rigorous statement of the dyadic three-character lemma, endpoint-order rank-three bound for F8, radix-local channel complexity, unitary-subclass caveat and prior work.
- `exact_scan_macro.py`: working radix-4 and mixed-radix exact NTT expressed via 4-point scan codelets; includes explicit twiddle/index counters.
- `ordering_dp.py`: exhaustive dynamic program over all pairs of independent Fourier input/output endpoint orderings, N<=8.
- `analytic_certificate.py`: independent two-prime exact 3x5 rank enumeration and cyclotomic determinant zero checks.
- `reference_ntt.py`: independent radix-2 exact NTT.
- `benchmark.py`: matched fresh all-output workload benchmarks and charged operation-count audit.
- `unitary_control.py`: exact rational-Givens unitary/quasiseparable control and entropy potential check.
- `tests/`: regression suite.
- `NEXT_GATE.md`: findings and stop/research criteria.

Python 3.11+, standard library only; no network or multithreading needed.

```bash
cd fft_bidirectional_macro_research
python -m unittest discover -s tests -v
python ordering_dp.py
python analytic_certificate.py
python unitary_control.py
python benchmark.py --sizes 256 1024 4096 --repetitions 13
```

**Usage**:

```python
from exact_scan_macro import fft_via_mixed_scan_macros
values = [1, 2, 3, 4, 5, 6, 7, 8]
spectrum, gate_counts = fft_via_mixed_scan_macros(values)
```

Default modulus 998244353, primitive root 3, supports power-of-two transforms up to 2^23. The forward DFT uses positive exponents, as does the independent reference; inverse convention would conjugate twiddle powers. Full complex-algebraic rank statements do not rely on the finite test prime.

**Important**: `scan_additions_upper`, `scan_multiplications_upper` and twiddle counters describe **executed arithmetic in the generic Python algorithm**. `permutation_moves` is a tally of high-level shuffle/gather/scatter word movements, not every Python list access. `modular_power_mult_upper` bounds an implementable binary exponentiation work count (includes constant-time local plan preparation as a conservative overhead). The Python timing is not proof of a new asymptotic algorithm or a native library comparison.
