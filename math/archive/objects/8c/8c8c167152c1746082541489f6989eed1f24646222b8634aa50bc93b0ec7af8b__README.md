# Norm-certified tabulated Fourier research

**Not an exact arbitrary-complex FFT breakthrough.**

See `THEORY.md` for the proposed deterministic relative-l2 finite-word theorem,
its complete preprocessing/error ledger, and its limitations.

## Reproduce

Python 3.10+ and `mpmath` are used by the verifier. The implementation module
itself uses only the Python standard library.

    python verify.py

The recorded `RESULTS.json` contains finite-instance checks, NOT an FFTW timing
comparison. Two toy lookup tables are completely built. High-accuracy transform
tests use a slow, on-demand reference evaluator and forced small radices; their
runtime is not the asymptotic implementation's runtime.

`norm_tabulation.py` provides:

- `FloatAlphabet`: exact integer encoding/quantization and overflow flags.
- `dyadic_coefficient`: rigorous rational complex coefficient error bounds.
- `BlockKernel`, `EagerBlockTable`: complete packed small Fourier block tables.
- `parameters`: the charged precision/radix schedule.
- `ReferenceFFT`: the explicitly labeled exact-dyadic accuracy simulator.

For a useful-precision example:

    from fractions import Fraction
    from norm_tabulation import ReferenceFFT
    x = [(1, 0), (2, 0), (3, 0), (4, 0)]
    y, stats = ReferenceFFT(4, Fraction(1, 1000000), radix=4).run_integer(x)

`y` contains pairs of exact Fractions representing approximations to the
normalized DFT, not exact cyclotomic Fourier values.
