# Independent review of the periodic residual fusion

**Result: algebra, residual certification, scaling and failure handling pass.**
The reviewed implementation is `control_variate.py`; `review_edge_results.json`
records its exact SHA256 so subsequent changes are visible. The reviewer did
not modify the implementation or its end-to-end audit.

The code implements the stronger **exact-mean fit with a scaled integer
residual**, not the simpler rounded-mean proposal. For each real/imaginary
residue cluster it chooses its sum S or zero by comparing the exact integer
costs `sum |n*x-S|` and `n sum |x|`. Therefore the final residual rho satisfies
`L_box(rho)/n<=L_box(x)`. The choices are independent by coordinate and do
not discard a useful imaginary fit when only its real fit is poor.

The short spectrum uses the correct negative-exponent quarter rotations.
For `q=gcd(N,4)` and `n=N/q`, its support is exactly among `t*n`. The rational
mean's denominator cancels when its period is repeated n times, leaving
Gaussian-integer baseline Fourier values. This includes odd lengths with
q=1; nonzero residuals at those lengths still take the approximate path.

If the decoder returns A/D approximating the normalized sample mean, the
proper unnormalized residual contribution is `L_box(rho)*A/(nD)`. The code's
combined numerator `baseline*nD+L_box(rho)*A` and denominator nD are correct.
Its q final replacements are also correct: the raw residue sums directly
give those Fourier outputs, whether or not a mean was rejected. Replacing
them by exact values can only improve the maximum absolute error.

Zero residual bypasses both sampler and decoder and returns a fully exact
integer spectrum. A rejection-cap event returns `failed=True`, does not call
the decoder, and supplies a placeholder output array. That array is not an
accuracy guarantee; the caller must honor the failure flag. Missing or
mismatched decoders are rejected for nonzero residuals.

The final write counter includes both initial materialization and the q
successful-path overrides: `2N+2q` component writes. The flagged-failure
placeholder path has `2N` component writes.

The common width formula is conservative. With input coordinates below
`2^b`, each residual is O(n 2^b), total residual mass O(Nn 2^b), and combined
output numerators O(Nn 2^b D). Thus
`max(decoder.w,b+2 bit_length(N)+bit_length(D)+4)` bounds the required word
width with signed slack. Under `b=O(log N)` and the decoder's fixed-accuracy
regime this remains O(log N). The code reports the bound and checks final
numerators. It does not instrument each intermediate integer operation;
their range follows from these explicit inequalities. Arbitrarily large
Python integer inputs are outside the stated fixed-width asymptotic contract.

## Independent checks

`verify_fusion_identity.py` compares both rounded and exact-mean algebra against
direct modular DFTs: 240 cases and 5,040 output coordinates over twelve lengths.
It verifies exact decomposition, quarter-root support, no-worse residual mass,
the factor-two near-periodic bound for exact means, and zero residual on exact
periodic data. These checks are independent of the root implementation.

`review_edge_checks.py` exercises the actual implementation in 15 focused
groups. Coverage includes independent cluster fitting, real/imaginary rollback,
fractional retained means, explicit quarter-turn signs, q=1 nonzero residual,
the exact bypass, a controlled denominator check, exact DC replacement,
sampling-cap failure, invalid inputs/decoders, and a large-magnitude bit-growth
case. Stub samplers/decoders intentionally isolate scaling and failure logic;
they are not presented as tests of approximation accuracy. The root's separate
full audit exercises the real sampler and real eager-table decoder.

The word-RAM approximation theorem and all exact-goal qualifications in
`THEOREM_REVIEW.md` are retained. In particular this fusion improves the
data-dependent error scale and gives exact structured cases; it does not
remove the nonzero residual's approximation or prove a faster exact transform
for arbitrary fresh inputs.
