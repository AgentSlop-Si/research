# Reproduction

Python >=3.10, standard library for the actual arithmetic executors and finite-field tests.

```
cd fft_green_phase12_unitary_escape
python -m unittest discover -s tests -v
OPENBLAS_NUM_THREADS=1 python audit.py > audit_results_fresh.json
```

Numerical audit requires NumPy only. The exact executor uses no NumPy/SciPy, dense matrices, or runtime FFT. The stochastic pair of paths is generated by the standard library PRNG (uniform over its pseudorandom sample space for each fixed seed), and the all-N probabilistic theorem is for an ideal independently uniform permutation. Prior finite spectral-gap certificates are stored as provenance; a fresh finite certificate can be reproduced with phase11 `spectral_certificate.py` and the saved random-seed recipes.

Finite-field mode works with the deliberately unnormalized `Q=I+i e R`; floating-complex mode uses `V=Q/sqrt(1+e^2)`. The two have different scalar magnitudes but the same structural properties and exact inverses under their respective definitions.
