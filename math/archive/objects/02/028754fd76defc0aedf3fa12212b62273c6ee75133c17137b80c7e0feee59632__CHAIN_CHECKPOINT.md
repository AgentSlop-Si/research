## New Phase 6 results

1. For arbitrary Q,M≥2, N=QM, with `input j=t+Q*u` and `output k=h+M*s`, four-index kernel `T[s,h,t,u]=omega^(-h*t) xi^(-s*t) eta^(-h*u)`.
2. **Exact three balanced ranks:** `(s,h)|(t,u)` = N; `(s,t)|(h,u)` = min(Q,M); `(s,u)|(h,t)` = N. Independent GL transforms on each **individual leg** preserve all three; no invariance claimed for joint-leg/global gauges.
3. **Exact one-cross-cut union width:** min(Q,M), attained; for square N=M² this is sqrtN. The other cuts require N. This is a restricted tensor separator result **not a lower bound for arbitrary FFT circuits**.
4. **Exact four-leg CP rank:** N, with explicit N-term separable expansion and direct flattening rank lower bound.
5. **Endpoint-local support rigidity:** acting with arbitrary invertible A on output digit s and B on input digit u, `nnz(T')=nnz(A F_Q)*nnz(F_M B^T)≥N`. Equality iff both factors are monomial, so A/B must be inverse-Fourier transforms up to permutations/scales. The N-sparse core is only a *representation*; input and output basis conversions still cost Fourier work.
6. **Complex Schmidt spectrum:** the nonzero crossed-cut singular values of normalized T are exactly those of rectangular partial Fourier `V[t,h]=omega^(-h*t)`. The other two paired unfoldings are unitary and have singular values all 1. Numerical rank/entanglement does NOT imply exact field-operation savings, and QFT low entanglement is published prior art.
7. **16 local Fourier/identity gauges:** for square M, central nonzero counts none=M⁴, s only/u only=M³, sh/tu=M³−M²+M, su=M², t only/h only=M⁴−M³+M². The M³−M²+M count reproduces Phase 4's prior routing gate, not a new algorithm.
8. **Fully charged conventional two-axis FFT** prepares N root powers with N−1 field multiplications, uses B=(N/2)log2N butterflies (B multiplications and 2B adds/subs), N twiddle multiplications, N output writes. No FFT hidden inside pow() calls or uncharged root tables. This is still Θ(N logN).
