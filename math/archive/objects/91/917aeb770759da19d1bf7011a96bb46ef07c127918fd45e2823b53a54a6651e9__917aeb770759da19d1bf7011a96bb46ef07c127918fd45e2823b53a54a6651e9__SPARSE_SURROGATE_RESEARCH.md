# Fresh-input sparse-surrogate Fourier research

**Date:** 2026-10-09  
**Status:** theorem/prototype for a randomized **approximate** full DFT on fresh arbitrary inputs, power-of-two lengths. 41 regression tests pass. This does **not** solve the exact FFT problem.

## 1. Goal and boundary

We deliberately do **not** use OpenAI #130, CrocSwap, Swapnil Jain's finite-network certificates, cached prior inputs, or producer-supplied relations as the source of the asymptotic saving.

The input is one fresh arbitrary dense vector `x in C^N`; the output is all `N` Fourier bins. The only relaxation is **approximation**.

Let `U_N = F_N/sqrt(N)` be the unitary DFT.

## 2. Importance-sampled sparse surrogate

For nonzero `x`, put

`L1 = ||x||_1`, `L2 = ||x||_2`, and `p_j = |x_j|/L1`.

Draw `J_1,...,J_k` independently with `P[J_s=j]=p_j` and define

`y = (L1/k) sum_s phase(x_{J_s}) e_{J_s}`.

Repeated indices are coalesced, so `y` has at most `k` nonzero coordinates. It is unbiased:

`E[y]=x`.

### Universal all-bin theorem

For any `0<epsilon,delta<1`, if

`k >= 4 epsilon^{-2} log(4N/delta)`, 

then with probability at least `1-delta`,

`||U_N y - U_N x||_infinity <= epsilon ||x||_1/sqrt(N)`.

### Proof

Fix a frequency `f`. One sampled contribution to `(U_N y)_f` before averaging is

`Z_s = (L1/sqrt(N)) phase(x_{J_s}) omega_N^{f J_s}`.

Thus `E Z_s = (U_N x)_f` and `|Z_s|=L1/sqrt(N)=:a`. Real and imaginary parts lie in `[-a,a]`.

Hoeffding gives, for either component of the sample average,

`P[ |component error| >= t/sqrt(2) ] <= 2 exp(-k t^2/(4a^2))`.

If a complex error has magnitude at least `t`, one of its two components has magnitude at least `t/sqrt(2)`. Therefore

`P[ |(U_N y-U_N x)_f| >= t ] <= 4 exp(-k t^2/(4a^2))`.

Take `t=epsilon a` and union-bound over all `N` frequencies. The failure probability is at most

`4N exp(-k epsilon^2/4) <= delta`.

No Fourier-specific randomness assumption is used.

## 3. Adaptive L2-scale corollary

Define the input flatness

`tau^2(x) = ||x||_1^2 / (N ||x||_2^2)`, `0 < tau^2 <= 1`.

The same proof with target error `epsilon ||x||_2` gives the sufficient condition

`k >= 4 tau^2 epsilon^{-2} log(4N/delta)`

and then

`||U_N y-U_N x||_infinity <= epsilon ||x||_2`

with probability at least `1-delta`.

This can use far fewer samples for non-flat inputs. It is a weaker error scale than the universal `L1/sqrt(N)` statement.

Examples:

- constant-modulus dense input: `tau^2=1` (worst case);
- one nonzero coordinate: `tau^2=1/N`;
- complex Gaussian data: experimentally `tau^2` is around `0.78` for the normalization used here.

## 4. Full-output transform cost using our sparse DFT

The existing `hybrid_sparse.py` identity computes every DFT coefficient of a `s`-sparse length-`N` vector (`N` power of two) as follows.

Choose `b` as the least power of two with `b>=s`, and write `N=b*m`. The transform is reduced to

- `O(m s) <= O(N)` sparse phase accumulation;
- `O(N)` twiddle/index work;
- `m=N/b` independent length-`b` FFTs.

Using the ordinary radix-2 FFT for those inner transforms costs

`O(N log b) = O(N log(s+2))`.

Hence the complete fresh-input algorithm costs

`O(N + k log k + N log(k+2))`.

For fixed `epsilon` and constant or polynomially small `delta`, the universal theorem has `k=O(log N)`, so

`T(N) = O(N log log N)`.

This is a randomized **approximate** all-output DFT for one fresh arbitrary dense input. The output itself is length `N`, so linear work is unavoidable.

### Adaptive exact-sparse bypass

The mandatory input scan also reveals the exact input support. If the fresh input already has fewer nonzeros than the Monte-Carlo budget, the implementation can skip sampling and feed the input directly into the sparse DFT, returning the exact transform in

`O(N log(s+2))`.

## 5. What is classical / originality boundary

The sparsification step is classical in spirit:

- Maurey's empirical method / approximate Caratheodory sparsifies convex combinations;
- Monte-Carlo approximate matrix multiplication samples rank-one/column contributions with importance probabilities.

So **we do not claim the sampling lemma is novel**.

The specific algorithmic composition being tested here is:

`fresh dense input -> importance-sampled sparse surrogate -> input-pruned full-output DFT`.

A focused search did not immediately locate this exact `O(N log log N)` all-output formulation with the stated `l_inf` additive guarantee, but that is not evidence of priority. A proper literature review is still required.

## 6. Empirical validation

`benchmark_sparse_surrogate.py` tested the adaptive `epsilon ||x||_2` theorem at

- `N=4096`, `epsilon=0.30`, `delta=0.05`;
- flat, random-phase, Gaussian, power-law and spike inputs.

Across **1,020 trials**, the theorem-prescribed sample count produced **0 failures**.

Representative results:

| input | tau^2 | k | median error / ||x||2 | 95th percentile | failures |
|---|---:|---:|---:|---:|---:|
| flat | 1.0000 | 565 | 0.1188 | 0.1358 | 0/250 |
| random phase | 1.0000 | 565 | 0.1246 | 0.1412 | 0/250 |
| Gaussian | 0.7862 | 444 | 0.1254 | 0.1426 | 0/250 |
| power law | 0.0517 | 30 | 0.1178 | 0.1357 | 0/250 |
| spike | 0.0002 | 1 | 0 | 0 | 0/20 |

The bound is visibly conservative.

## 7. Arithmetic saving vs current wall clock

For flat inputs (the worst sample count), the inner butterfly depth ratio is essentially

`log2(b)/log2(N)`.

At `N=2^18`:

- `epsilon=0.50`: `k=270`, `b=512`, ratio `0.50`;
- `epsilon=0.35`: `k=551`, `b=1024`, ratio `0.556`;
- `epsilon=0.25`: `k=1079`, `b=2048`, ratio `0.611`.

At `N=2^20`, `epsilon=0.50`, the ratio is `0.45`.

However, even after vectorizing the sparse setup, the Python/SciPy prototype is still slower than SciPy's highly tuned full FFT (about `2.7x` slower at `N=2^20, epsilon=0.5`). This is an implementation result, not a contradiction of the operation count.

## 8. Natural lower-bound/ceiling evidence

For the flat input `x=(1,...,1)`, a nonnegative sparse surrogate with total mass `N` corresponds after normalization to a probability distribution on the cyclic group. Requiring every non-DC Fourier coefficient to be at most `epsilon` is exactly a small-bias / weighted Abelian-Cayley spectral condition.

Recent work on optimal sparsifiers for Abelian Cayley graphs gives weighted sparsifiers with `O(log |G|)` generators and states this logarithmic support is optimal (for constant approximation) in that setting. This strongly suggests that the `Theta(log N)` support scale is not removable inside the **nonnegative-weight** flat-input subclass.

Thus the next possible escape would require signed/complex surrogate weights or a non-sparse representation.

## 9. Signed/complex-weight experiment

`complex_surrogate_search.py` fixes a support and solves an LP for complex weights whose sum is one while minimizing a rectangular upper bound on all nonzero Fourier coefficients. Random support search was run for

- `N=32,64,128,256`;
- `k=2,3,4,5,6,8,10,12,16`.

Complex weights improved some constants but did **not** reveal a fixed-`k` family with shrinking error. For example, at `k=16` the best observed max side-lobe rose roughly

`0.239 (N=32) -> 0.340 (64) -> 0.412 (128) -> 0.461 (256)`.

This is only exploratory. It is not a lower bound. Classical Turan power-sum theory is the relevant obstruction literature for such exponential sums.

## 10. Current verdict

We now have a clean result on **our own path**:

> For power-of-two length `N`, one fresh arbitrary dense input can be converted in linear preprocessing time to a random `O(log N)`-sparse surrogate whose complete unitary DFT approximates all `N` target coefficients simultaneously. Combining this with the project's classical sparse-input full-output FFT gives `O(N log log N)` arithmetic for fixed additive accuracy/confidence.

The important limitations are equally clear:

1. it is approximate, not exact;
2. the guarantee is additive (`l_inf` relative to `||x||_1/sqrt(N)` or `||x||_2`), not relative error on every Fourier coefficient;
3. current implementation constants lose to optimized native FFTs;
4. the sampling lemma is classical; novelty of the composition has not been established;
5. exact arbitrary-input sub-`N log N` remains open for **our mechanism**.
