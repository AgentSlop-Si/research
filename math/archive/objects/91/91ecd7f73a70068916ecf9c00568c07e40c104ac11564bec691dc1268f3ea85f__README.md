## Theorems worth carrying forward

1. Over exact fields with suitable roots, `supp_W(F_N^-1)=N²` for odd `N`, and `N²/2` for even `N`. A product of `L` stages with inverse support at most three Weyl terms each must have `3^L >= supp_W(F_N^-1)`, even for arbitrarily oriented Weyl directions and intervening Weyl monomial gauges.
2. The cyclic quadratic-chirp convolution `C_ij=zeta^((i-j)²)` at `N=2^m>=4` cannot be a product of `m` ordinary cyclic shift Green resolvents with arbitrary strides; `L>=m+1`. This does **not** show that `m+1` is sufficient.
3. The inverse chirp kernel has maximal binary-cut matrix rank `2^min(a,m-a)`, yet its **kernel entries alone** can be generated in linear work. This is not linear-time arbitrary-input chirp convolution.
4. Classical dyadic binomial fusion reduces `m` full-vector stages for a **different Green-derived operator** to a single O(N) cyclic recurrence. The exact `N=65,536` field-operation ledger is `2,097,167` literal versus `393,214` fused (5.33×). This operator is **not** the DFT.

## Running everything

See `RUN.md`; Python standard library is sufficient. No FFT library, NumPy, GPU, threads, oracle tables or uncharged cache are used in the new algorithm. Tests require only suitable finite-field roots, provided by `phase15.py`.

## Strict nonclaims

No `O(N)` general-purpose FFT, no novel integer-multiplication bound, no arithmetic lower bound for unrestricted FFT circuits, no practical floating-point speedup, no historical novelty claim. Weyl support is a **representation** invariant inside the specified grammar, *not* an all-model arithmetic-time invariant.
