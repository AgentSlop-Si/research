# Reproducible independent supplement

This supplement audits the supplied common-quadratic-chirp-rank theorem using a new Python standard-library implementation. It does not execute the uploaded research note, import any uploaded program, claim a universal linear-time FFT, or establish a speed advantage.

Run from this directory:

    python3 independent_checker.py

Outputs are `independent_results.json` and console progress. `independent_run.log` preserves the original audit run. `AUDIT_REPORT.md` contains the proof review, limitations, and independent test totals. `source/RESEARCH (2).md` is the unchanged source note.

`provenance.json` records source identity and byte provenance. `SHA256SUMS` records every packaged file except itself. The parent directory's archive checksum, when supplied, seals the ZIP byte stream separately.

The checker is deliberately simple and portable. Its direct determinant construction is factorial in r and intended only for bounded-rank validation. Its prime/root search is test-fixture generation and is not charged to or claimed by the supplied-field recognition theorem. The transform and recognition routines are exact finite-field code; no floating-point numerical stability claim follows.
