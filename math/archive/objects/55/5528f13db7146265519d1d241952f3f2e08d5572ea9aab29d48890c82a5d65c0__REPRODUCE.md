# Reproduce this independent audit

The audit program requires Python 3 and SymPy. This run used the already installed SymPy library; it did not install packages or execute any source-package program.

Run from any directory:

    python chirp_classification_audit_0301/independent_controls.py

The script reads the three preserved source packages, verifies their manifests and the primary package's archived source snapshots, and writes only in the audit output directory. It reconstructs all 250 T polynomials by the multiplicative Gaussian-binomial formula, checks every saved Bezout identity, independently computes both guard gcds, and rechecks all saved finite-field trial histories.

It then performs independent exact bank controls and symbolic discriminant controls. Small quotient inverses are obtained by linear solving, and algebra traces are evaluated as literal multiplication-matrix traces. These are intentionally expensive checks, not implementations of the reported quadratic setup bound.

`AUDIT_RESULTS.json` provides counts and timings. `SOURCE_HASHES_BEFORE.json` and `SOURCE_HASHES_AFTER.json` must agree. To verify the sealed audit artifacts without changing anything, run in the audit directory:

    sha256sum -c MANIFEST.sha256

Rerunning the audit program updates result files and its elapsed-time field. That requires a new audit manifest; it does not change the source packages. The final manifest excludes itself and includes every other audit file.
