## Independent proofs

### Fourier coset spectrum

For divisors d_r,d_c of N, put r=N/d_r,c=N/d_c,h=N/gcd(N,d_r*d_c). Offset phases are removable by diagonal unitaries. The remaining character has exact order h, with h dividing both r and c. Grouping coordinates modulo h produces repeated h-point Fourier rows and columns, giving exactly h nonzero singular values sqrt(rc/(Nh)). This number is at most one, as required for a unitary submatrix. The remaining min(r,c)−h singular values vanish. This includes one-point and full-set edge cases. For powers of two with exponent sum at most log2N, every nonzero singular value is one.

### Exact Green rectangle rank

For K invertible, the complementary identity is

rank K^{-1}[A,B] = |A|+|B|−N + rank K[B^c,A^c].

It is valid for unrelated sets, including empty/full sets. For a Hamiltonian denominator I−diag(w)P, its bipartite support is a single even cycle when all edges are active. Deleting any row or column breaks it into paths; zero weights can only remove edges. In a forest, two distinct perfect matchings would have an alternating cycle, so a matched square submatrix has a unique nonzero determinant monomial. Its rank is exactly its maximum matching size over any field, for every actual nonzero weight. The only intact-cycle case in the Hamiltonian proof is the full denominator, whose invertibility supplies rank N. Leaf-edge greedy matching is maximum on a forest and has linear work with degree-at-most-two adjacency and a queue.

Invertible diagonal endpoints preserve ranks. Independent row and column permutation endpoints send A,B to separate native sets; they cannot simply be omitted or treated as a conjugation. The checker follows that mapping explicitly. The source's formula assumes invertible endpoint diagonals; with singular masks it remains an upper bound after restricting nonzero coordinates but should not be called the exact unchanged-set rank without accounting for the masks.

The nullity identity is established prior work, summarized in the primary paper [Strang, Fast transforms: Banded matrices with banded inverses](https://pmc.ncbi.nlm.nih.gov/articles/PMC2906572/). The forest proof above is elementary and independent.

A small additional observation is valid: for a general permutation denominator that is invertible on every cycle, a proper rectangle may retain some whole cycle components as well as paths. Each intact component is a nonsingular cycle block and has full matching rank, while each path has the forest property. Thus the same oracle extends to arbitrary permutation cycles with the correct per-cycle guards, including fixed points (whose actual diagonal entry is 1−w). This extension was independently tested; it is not needed for the source's Hamiltonian claims.

### Moving-interface propagation

For any intermediate S,

(AB)[R,C]=A[R,S]B[S,C]+A[R,S^c]B[S^c,C].

Consequently its rank is at most rank B[S,C]+rank A[R,S^c]. Induction gives the exact orientation in the source with S0=R,St=C^c. Summing branch ranks bounds each stage sum. This works for arbitrary stage counts, coordinate sets and independent monomial endpoints, once those endpoints are charged/mapped. It resolves no equality or phase-synthesis problem.

One supplied interface certificate can be checked in O(N times number of branches), including set routing and sparse matching. If its budget is b<h, the Fourier block's flat singular spectrum gives operator error at least s and Frobenius error at least s*sqrt(h−b). The norms of submatrices cannot exceed their ambient error norms. Modular rank checks alone do not imply these complex norm statements; the spectral proof does.

### Two-stage submodularity and search cost

For fixed R,C, each first-stage term rank H[R,S^c] is a column-matroid rank function composed with set complement; complement preserves the submodular inequality. Each second-stage term rank H[S,C] is a row-matroid rank function. Their sum f(S) is submodular. General exact submodular minimization therefore finds its minimum in polynomial time using this value oracle. This is a classical algorithmic consequence; see the primary [Iwata–Fleischer–Fujishige paper](https://arxiv.org/abs/math/0004089). The source does not implement such a general optimizer, and neither the proof nor the finite exhaustive controls establishes O(N) optimization. Linear work applies to a submitted certificate or one oracle evaluation. Weight zero-testing and arithmetic are in the exact field/word model, with bit costs separate.

For one branch per stage, the minimum is the corresponding matroid-intersection min–max value. It can strictly exceed the actual product rank because algebraic cancellation is invisible to this capacity certificate. Passing every such certificate is still only necessary.
