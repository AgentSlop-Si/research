# Phase 19: Green-product stability and exact dual Weyl gauges

All research code is standalone. Requires Python 3.11+ and NumPy; no external internet access. Finite-field tests use the prime 998244353 and primitive power-of-two roots, with exact modular matrix arithmetic. The analytic theorems are in `THEOREM.md`; finite-field controls are evidence/checks rather than literature-priority claims.

Files:
- `field_core.py`: exact finite-field DFT, cyclic operators, matrix inverses and products
- `joint_gate.py`: *both* Weyl identities under one unknown monomial middle operator, without pretending duplicate signatures imply impossibility
- `green_product_audit.py`: actual noncommuting independently ordered two-Green-summand sample stages (dense verification oracle only)
- `harper_monomial.py`: known Harper operator, new one-middle-monomial obstruction within scalar Harper rational calculus
- `stable_green.py`, `spectral_green.py`: norm/condition controls
- `near_resonance.py`: norm budget escape without Fourier phases
- `audit.py`, `audit.json`, `tests/test_phase19.py`: deterministic executions, certificates and unit tests
- `previous_full_phase18_checkpoint.zip`: complete preceding research chain

**Validation:** 29 Phase 19 tests, plus 99 preserved Phase 12–18 tests, all pass after nested fresh extraction.
