# Reproduce Phase 35

Python 3.11+; `sympy` required for exact integer-polynomial gcds. The primary Green executor uses only Python's standard library.

```bash
python -m unittest -v tests_phase35
python phase35_balance.py --output audit_recomputed.json
python phase35_polynomial_certificate.py --output polynomial_recomputed.json --full-coefficients
cmp audit.json audit_recomputed.json
cmp polynomial_audit.json polynomial_recomputed.json
sha256sum -c SHA256SUMS.txt
```

The reconstruction prime `2^127-1` exceeds twice the **proved integer coefficient bound** at `N=8,16`; therefore the lifting step recovers the actual characteristic-zero polynomials. The two sizes and exact cycle orderings are recorded in `polynomial_audit.json`. Both independent integer determinant spot checks and the additional two-field checks are in `tests_phase35.py`.

The previous Phase 34 suite was independently rerun and its 11 passing test results are saved in `inherited_phase34_tests.log`. For a full historical rerun, extract `previous_full_phase34_checkpoint.zip` and use its original `RUN.md`.

Optional large exact-field partial-construction control:

```bash
python phase35_scale.py
```

This checks the complete first Fourier row/column and one additional Fourier column at `N=8192,16384,65536`. It is *not* a full-matrix comparison at these sizes.
