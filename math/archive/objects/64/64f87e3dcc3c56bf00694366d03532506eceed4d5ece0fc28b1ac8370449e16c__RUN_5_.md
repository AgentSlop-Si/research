# Phase 22 reproducibility

Requirements: Python 3.11+, standard library only. From this directory:

```sh
python -m unittest discover -p 'test_*.py' -q
python audit_phase22.py
python benchmark_phase22.py
sha256sum -c MANIFEST.sha256
```

The first target includes all inherited Phase 21 tests and the new algebraic subgroup oracle, exhaustive 4,912-vector finite-field polynomial audit, and exact DFT adversarial tests. The second recomputes every output by a distinct direct O(N^2) modular DFT, over two primes. The benchmark charges each modular addition, multiplication and inversion in the instrumented engine; it uses the same preinitialized Nth roots and Green system as the comparator. It does *not* include external field selection and numerical bit-time and does *not* promise a speedup on unstructured inputs.

Preserved source zip: `PRIOR_PHASE21_COMPLETE.zip`. All newly authored Python files and documentation are included uncompressed and with SHA256 integrity checks.
