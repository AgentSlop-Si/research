# Two-stage Fourier obstruction with an arbitrary intermediate shuffle

**Research date:** 9 October 2026.  **Input project:** the attached 20-file `fft_nonunitary_global_green_research_2026-10-09(2).zip`, read and rerun before this derivation.

**Status:** All-size exact rank argument in a restricted two-stage matrix-factor architecture; separate exact finite-field verifiers. **No general FFT lower bound, no new exact FFT algorithm, no publication/priority claim.**

## 1. What we test—and why it is not another CrocSwap constant search

The original objective is an exact FFT for any **fresh** length-`N` vector with **all** `N` explicit outputs and a fully charged sequential operation count approaching `O(N)`. Prior audits already excluded value-collision caching, 4/8/16-bit codelets, output-pruned queries, near-power integer multiplication, short annihilators, chirp recurrences, large packed-int scalar operations, and transformations that merely disguise an ordinary FFT behind cancelling rank-one gauges.

The uploaded nonunitary Green archive tested `S_2 P S_1` with small rank-structured **full-array** stages and permutations in between. The numerical best at `N=32` for two stages of order `r=2` or `r=3` was not exact. We asked whether an **exact structural certificate** could rule out those specific attempts, rather than retrying the optimizer.

## 2. Definition and transfer lemma

Let `S` be an `N × N` matrix over a field. Its **quasiseparable order** is at most `r` if, for each cut `c=1,...,N-1`, both strictly off-diagonal blocks have rank at most `r`:

- `rank S[0:c, c:N] <= r`;
- `rank S[c:N, 0:c] <= r`.

The two-Green sum `T^{-1}+U^{-1}` from the input archive is of order at most 2. Its exact modular rank is independently checked by `independent_check.py` for `N<=32`. A global stage built from `r` lower and `r` upper separated channels has quasiseparable order ≤ `r`; the standard prefix/suffix-generator implementation uses `O(rN)` arithmetic.

Let `M=S_2 P S_1` be **any** product, where `P` is any permutation matrix (no restriction on distance or number of moved elements). Suppose the quasiseparable orders of `S_1` and `S_2` are at most `r_1` and `r_2`.

**Transfer lemma.** For every `1<=s,j<N`, let `R` be the *first s output indices*, `C0` the *first j input indices*, `C1` the remaining input indices. Then

```
rank M[R,C0] + rank M[R,C1] <= s + 2(r_1+r_2).       (★)
```

**Proof, with every rank term exposed:**

Cut the intermediate *S_2* input at its first `s` coordinates `A` (so `|A|=s`). Cut the intermediate *S_1* output at its first `j` coordinates `J` (so `|J|=j`). Denote by `D=P(J)` the `j` positions in S_2's coordinate system occupied by the `J` side after shuffling. Write `a=|A ∩ D|`, so `|A ∩ D^c|=s-a`.

For the left input block `C0=J`, decompose the matrix product according to the S_1 output split:

```
M[R,C0] = S_2[R,D] (P S_1)[D,C0]
        + S_2[R,D^c] (P S_1)[D^c,C0].
```

The second term has rank at most `r_1`, since it factors through `S_1[J^c,J]`, which is an off-diagonal block of `S_1`. For the first term, `rank(S_2[R,D]) <= a+r_2`: its columns in `D∩A` contribute at most `a`, and the columns in `D∩A^c` lie in `S_2[R,A^c]`, which has rank at most `r_2`. Consequently `rank M[R,C0] <= a+r_2+r_1`.

The same argument with right input block `C1=J^c` gives `rank M[R,C1] <= (s-a)+r_2+r_1`. Adding proves (★). The permutation P cancels from the capacity sum `a+(s-a)=s`, so **every** intermediate shuffle is covered. No invertibility, conditioning or numerical approximation assumptions enter this proof.

## 3. Fourier consequence: linear channel growth in two stages

Let `N=2m`, and `F_N[k,j]=ω^{kj}` for a primitive Nth root of unity `ω` over **C**. At the balanced cuts `s=j=m`, both upper Fourier quadrants have exact rank `m`:

```
rank F_N[0:m,0:m] = rank F_N[0:m,m:N] = m.
```

Reason: for `k=0,...,m-1`, the columns have distinct nodes `ω^j`; the matrix is Vandermonde. Alternatively, for any chosen `m` row frequencies, the left half is Vandermonde in the distinct row roots `ω^k`, and the right half is a diagonal rescaling of it. (Thus the proof survives an **arbitrary output permutation** with input coordinates natural.) For the natural top rows and an arbitrary partition into two m-column blocks, the same Vandermonde-in-column-nodes argument applies. (Thus the proof also survives an **arbitrary input permutation** when the output coordinates are natural.)

Substitute into (★):

```
2m <= m + 2(r_1+r_2)

=> r_1+r_2 >= m/2 = N/4.
```

If `r_1=r_2=r`, necessarily `r >= ceil(N/8)`.

This is an all-even-N theorem over C, with any intermediate shuffle, **provided at most one external endpoint is independently reordered**. It applies to the usual explicit, naturally ordered DFT. It also applies when only input or only output is reordered. It is not an all-layout theorem.

### Concrete 32-point contradiction

For `N=32`, `m=16`, suppose `r_1=r_2=3`, so `r_1+r_2=6`. Both Fourier half-blocks have rank 16. The proof requires

```
16 <= a+6      => a>=10
16 <= (16-a)+6 => a<=6
```

for the *same* intermediate permutation capacity `a`. Contradiction. In particular the `N=32,t=2,r=2/3` numerical fits in the input archive cannot become exact by adding iterations while holding their two-stage architecture and natural endpoint ordering fixed.

For `r=2` in both stages, the theorem excludes all even N>16. The previous Green sum has `r<=2`, so two such stages cannot implement a natural-endpoint DFT at N=32 or larger, irrespective of the shuffle.

### Fully charged work and scope

The **standard separated-generator implementation** of one r-channel quasiseparable stage updates r prefix and r suffix channels on all N positions, performing Θ(rN) elementary scalar operations (when each generator channel is explicitly evaluated). For two such stages, the necessary `r_1+r_2 >= N/4` forces Θ(N²) work **in that implementation**. This is **not** a lower bound on all possible representations or programs applying a high-quasiseparable-rank matrix: a permutation can have high cross-cut rank and still take O(N) swaps; the FFT itself has high rank and a better-than-quadratic executor. No unconditional Ω(N²) DFT lower bound is claimed.


## 4. Prime-length extension: **both** endpoint permutations are harmless

The endpoint-order caveat for composite/power-of-two N has an important exact exception. **Chebotarëv's classical theorem** states that for *prime* `p`, every square minor of the complex p-by-p Fourier matrix is nonzero. Equivalently, any s distinct rows and at least s distinct columns define a submatrix of row rank s. This is an external, established theorem, not a result newly proved by this package. See Tao, *An uncertainty principle for cyclic groups of prime order* (2005), Lemma 1.3, https://intlpress.com/site/pub/files/_fulltext/journals/mrl/2005/0012/0001/MRL-2005-0012-0001-a011.pdf.

Set `p=2m+1`, `s=j=m` in the transfer lemma (★). **Even if both endpoints have arbitrary, independent permutations**, the selected `m` Fourier rows and either block of `m` or `m+1` columns have rank m. Consequently

```
2m <= m + 2(r_1+r_2),
so r_1+r_2 >= ceil(m/2) = ceil((p-1)/4).
```

Thus two equal-order stages require `r >= ceil((p-1)/8)` channels each. This proves a robust two-stage rank obstruction for *all* prime lengths and all endpoint/intermediate permutations, assuming those two stages themselves are quasiseparable in their working coordinate orders. In particular, two rank-2 Green sums cannot produce an exact p=31 Fourier matrix **under any permutation of input, output, or intermediate registers**.

This prime-length corollary does **not** imply the same all-endpoint statement for `N=2^k`: prime Fourier matrices have all minors nonzero, whereas composite Fourier matrices admit singular submatrices. Nor does it give an unconditional runtime lower bound outside the explicit generator-stage implementation.

`prime_endpoints.py` supplements the characteristic-zero theorem with independent finite-field samples (over appropriate distinct primes `q` satisfying `p | q-1`); not every Chebotarëv conclusion automatically transfers to an arbitrary positive characteristic. The characteristic-zero proof rests on the cited theorem.

## 5. The endpoint-shuffle escape matters

The transfer lemma (★) is valid for every endpoint arrangement; however, when *both* input and output are independently reordered, their top-block Fourier submatrices need not have full rank. The resulting lower bound depends on the endpoint order:

```
r_1+r_2 >= max_{1<=s,j<N} ceil((rank F'[0:s,0:j]
                     + rank F'[0:s,j:N] - s)/2),
```

where `F'` is the endpoint-permuted Fourier matrix, and any negative numerator yields only 0.

An exact finite-field stress test shows:

| N | Natural/natural necessary rank sum | Bit-reversal/bit-reversal necessary rank sum |
|---|---:|---:|
|16 | 4 | 1 |
|32 | 8 | 2 |
|64 | 16 (from theorem) | 2 |

This **does not** mean such small-channel factorizations exist for double bit-reversal. It means the current cut-surplus invariant becomes weak after ordering both ends, and a new *multi-layout* invariant or a concrete exact construction is required. Both permutations are individually executable in O(N) random-access moves, so an asymptotic research program must allow them and cannot count their admission as an FFT improvement.

The original no-endpoint-permutation two-stage experiments at N=32 are precisely the part now settled; the **both-endpoints-reordered** version remains open.

## 6. Verification and falsifiability

The proof is exact matrix algebra over C and extends to any field with a primitive Nth root. Computational verification, not a formal proof assistant:

- `cut_budget.py`: independent finite-field Fourier full-rank quadrants, random generator stages, any intermediate shuffle, and general cut-budget / endpoint scoring.
- `independent_check.py`: *separate* modular-elimination implementation; confirms half-block ranks with either endpoint permuted and constructs the previous `T^-1+(T+I)^-1` Green sum directly via exact modular inversion.
- `prime_endpoints.py`: prime-length minor tests and independent input/output permutation checks, using the existing Chebotarëv minor theorem for the full characteristic-zero statement.
- `endpoint_stress.py`: exact rank-budget scans with natural, parity and bit-reversal endpoint layouts. It skips redundant large natural-order rank computations when the theorem already settles them.
- `tests/test_cut_budget.py`: regression checks, including an intentional negative control showing that two external bit-reversals weaken the test.
- All arithmetic is exact mod `998244353` or `2013265921` (roots 3 and 31). These prime-field tests supplement, but do not replace, the all-complex Vandermonde argument.

Reproduce:

```bash
cd fft_two_stage_cut_certificate
python -m unittest discover -s tests -v
python cut_budget.py
python independent_check.py
python endpoint_stress.py
python prime_endpoints.py
```

**Failure checks:** a correct product of two r-quasiseparable matrices with an intermediate permutation that violates (★), a Fourier half-block not full rank in the claimed ordered setting, or a Green sum exceeding rank 2 would falsify a stated component. Note that nothing in the work establishes an exact faster FFT.

## 7. Next open target, distinct from previous experiments

The precise next mathematical challenge is to **derive an endpoint-order-robust multi-cut invariant for power-of-two lengths** (the prime-length two-stage case is now settled by Chebotarëv), for a small number of r-channel quasiseparable stages with arbitrary interstage shuffles, **or give an exact constructive family** achieving strictly less than `N log N` total scalar work and all N Fourier outputs. In particular:

1. For `F'_N=P_{out}F_NP_{in}`, account for the fact that certain input/output order pairs (e.g. bit-reversal at both ends) destroy the balanced Vandermonde-rank argument.
2. For products of `t>=3` stages, track rank flow through intermediate *several cuts*; simply applying (★) once does not resolve the full product.
3. Any positive construction must give an all-N algebraic identity, a charged O(rN) or better stage evaluator, coefficient generation, and an independently checked full transform; reject gauge-dressed butterflies and numerical fits without exact certificates.
4. Keep model distinctions: exact complex field operations are not bit operations on bounded words, and a high `||.||_1` condition number does not automatically prove spectral numerical instability.
