# Phase 24 reproduction

From a clean extraction, change directory to `fft_hero1_phase24`, then run:

```
python3 -m unittest discover -p 'test_*.py' -q
python3 audit_phase24.py
python3 benchmark_phase24.py
sha256sum -c MANIFEST.sha256
```

`test_phase24.py` adds eight focused tests to Phase 23's 58 regression tests (total 66). The independent Phase 24 audit checks complete FFT basis responses plus random structured and generic data in two finite fields. The benchmark uses a native radix-2 field operation reference, unlike earlier Bluestein-based benchmarks. All files needed are inside this ZIP.

The theorem is finite-field exactness and arithmetic-count accounting only; it does not establish unconditional `o(N log N)` complex FFT or word-RAM integer multiplication.
