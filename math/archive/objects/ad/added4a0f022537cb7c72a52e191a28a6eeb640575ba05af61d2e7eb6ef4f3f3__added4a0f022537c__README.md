# Exact rational compression of the nilpotent q-kernel

This result specifies a limitation of a tempting new shortcut: shifted cyclic
bidiagonal systems can be solved in O(N), so could a bounded-degree rational
function replace the full H_q(C)? The answer is no in this exact representation.
This is a degree theorem, **not an arithmetic time lower bound**.

Let N=2^L>=2 and q be a primitive Nth root in characteristic zero or in a field
admitting that root with N invertible. Define

    f_j=product_(a=1..j)(1-q^a),  t_j=1/f_j,
    H_q(z)=sum_(j=0..N-1)t_j z^j.

Let C be the audited cyclic bidiagonal matrix in the sibling
`fft_qweyl_boundary_research` package. C is similar to the weighted upper shift
B whose N-1 upper weights are nonzero. Therefore its minimal polynomial is z^N,
not merely a divisor of z^N.

## The degree theorem

If p,r are polynomials, r(0)!=0, and

    H_q(C)=p(C) r(C)^(-1),

then

    degree(p)+degree(r) >= N-1.

The bound is sharp: p=H_q, r=1 attains N-1. No assumption about small, real,
bounded, or efficiently prepared coefficients is made in this algebraic claim.

Proof. The minimal polynomial makes the operator equality equivalent to
r(z)H_q(z)=p(z) modulo z^N. In particular p(0)=r(0)!=0. Write m=degree(p),
d=degree(r), and suppose m+d<=N-2.

First suppose m>=d-1. The coefficients in degrees m+1 through m+d+1 must vanish:

    sum_(ell=0..d) r_ell t_(m+1+i-ell)=0,   i=0,...,d.

After reversing columns, the square coefficient matrix is a Hankel matrix of
size d+1 and shift s=m+1-d>=0. Its highest kernel index is m+d+1<N.
The previously proved q-factorial determinant formula is

    det[t_(s+i+j)]_(0<=i,j<h)
      = q^(sum_(a=1..h-1) a^2)
        product_(i<j)(q^(s+j)-q^(s+i))
        / product_(i=0..h-1) f_(s+i+h-1).

Every factor is nonzero in the stated index range. Thus the coefficient matrix
is invertible, forcing all coefficients of r to be zero, a contradiction.

If m<d-1, invert the congruence. The inverse kernel is

    H_q(z)^(-1)=H_(q^-1)(q^-1 z) modulo z^N.

Indeed its coefficients are (-1)^j q^(j(j-1)/2)/f_j. Now r/p approximates this
inverse kernel, with numerator degree d and denominator degree m, so the first
case applies. Replacing q by q^-1 preserves primitivity, and modulation by
q^-j only scales the Hankel rows and columns by nonzero factors. Contradiction.

An independent agent checked the proof, including the reciprocal case and all
index endpoints. The executable verifies the claimed inconsistent Padé systems,
the reciprocal identity, determinant certificates, and matching degree-N-1
approximants in exact fields.

## What this does and does not settle

A fixed number of fixed-degree polynomial/resolvent factors in C collapses to
a rational p/r of bounded total degree. It cannot equal H_q(C) as N grows.
For a product, degrees add; cancellation can only reduce them, so this conclusion
also applies to an explicitly bounded-degree product of such rational factors.

It does not follow that evaluating an admissible high-degree rational function
requires quadratic work. Fast convolution, repeated squaring, sparse powers,
mixed noncommuting operators, and shared subgraphs are outside that inference.
For example, the sibling fusion experiment applies C^(N-1)H_q(A) in linear
work, despite its large degree. Nor does this theorem rule out a small sum with
high-degree sparse numerators or an entirely different FFT algorithm.

The generic shifted resolvent in `fft_qweyl_resolvent_research` is still useful
as an O(N) operator primitive. The new barrier explains why a constant number
of ordinary low-degree resolvent filters is not, by itself, the complete exact
q-exponential action.

## Reproduce

Run `python3 run_audit.py` with Python's standard library. It imports the exact
field and q-kernel helpers from the sibling previous checkpoint. No floats,
numerical rank tolerance, or root approximation is used. Results are written to
`results/rational_degree_audit.json`. Finite certificates validate the program;
the degree theorem is the proof above, not extrapolation from those cases.
