# Independent Hero1 Phase24 audit: deferred DIF and Green-conjugated probes

## Verdict

**Accept the exact deferred-butterfly scheduling theorem, fixed-batch backup count, Green-conjugated probe identity, local savings formulas, and restricted-family counting argument.** The certified branch and native fallback are mathematically correct under their explicit engine/field guards. The new fallback completes an ordinary radix-2 FFT without repeating already executed butterfly arithmetic. This is a useful reuse improvement; it supplies no all-input sub-N log N algorithm.

Two implementation boundaries need correction:

1. The inherited Green constructor fails for some fully compatible fields even when its matrices are invertible. At N=16 over GF(17), primitive root 3, default P and L each have determinant 16, but each has a zero diagonal. `CyclicSolver` calls `inv_all`, which raises `ValueError('zero diagonal entry')` before native fallback is available. The stated compatible-root domain alone is insufficient for this engine.
2. The standalone `DeferredDIF` permits `full()` before `preview()`, then permits a preview on already transformed data. For x=e₀ at N=16, full output is all ones; the later DC preview returns 16 instead of 1. The intended preview-then-complete engine path is unaffected. Reject preview after completion, or serve it from completed Fourier data.

The newly exposed native radix-2 comparison is the right direction. All 12 supplied benchmark records still put the detector above that baseline; their full field-operation totals remain incompletely charged because inherited compiler and setup omissions persist. The exact **local** probe/scheduling differences do not depend on accepting those grand totals.

Independent evidence: 706 query-set cases, including all nonempty subsets through N=8 in two fields; 224 full basis-response schedules; exact formulas through N=2^20; 112 Green-conjugation basis checks; six accepted structured inputs; six strict ten-probe adversaries that fail both candidate certificates before exact native fallback; nine early generic rejections; three zero-input controls. ## 2. Exact DIF graph and no-repetition proof

For n=2h and primitive root ω_n, split x into u_j=x_j and v_j=x_(j+h). Then

    A_j=u_j+v_j,
    B_j=(u_j−v_j)ω_n^j,
    Y_(2k)=DFT_h(A)_k,
    Y_(2k+1)=DFT_h(B)_k.

This follows by splitting the defining Fourier sum and using ω_n^h=−1. Each ordinary node contributes h additions, h subtractions and h multiplications, counting even trivial twiddles.

For a fixed nonempty batch Q of queried frequencies, there are three possibilities at an active node:

- Both parity branches are needed: produce A and B normally.
- Only A is needed: save u, overwrite the first half with A, and leave v untouched.
- Only B is needed: save v, overwrite the second half with B, and leave u untouched.

A queried child can alter only its own segment. Therefore an inactive sibling retains precisely the input half needed to form it later, with the other original half in backup. During completion, generate only the missing child before recursing. No already computed branch expression is evaluated again. Distinct node segments ensure no interference.

Consequently full completion has exactly

    additions/subtractions = N log₂N,
    multiplications = (N/2) log₂N,
    total = (3N/2) log₂N.

These are equalities for this fixed radix-2 arithmetic graph. They are not minimum FFT operation counts: multiplication by one is included, and split-radix or other optimizations can improve constants. Repeated `full()` does not repeat butterflies on the intended completed graph, but still incurs traversal/output work.

Our independent scheduler uses flat heap-indexed node states and tracks every primitive operation by (node, local position, addition/subtraction/multiplication). Any repeated primitive raises an assertion. Outputs are compared with independently written direct Fourier sums or explicit basis columns. This tests the exact no-repetition property, not merely the final numeric count.

## 3. Backup theorem and actual storage scope

Let q=|Q| after deduplicating the query batch. Every active node with an inactive sibling saves one scalar per leaf in that inactive subtree. Such subtrees are disjoint and cover exactly the N−q unqueried leaves. No backup is freed during preview. Hence both final-preview live backup count and preview peak are exactly N−q.

This includes q=1 and q=N, and requires Q nonempty. It is a property of this implementation strategy, not an optimal-memory lower bound for other FFT algorithms.

The graph has N mutable input/data slots, at most N−q backup scalar slots, and O(N) node states; the supplied N-root table is separate. `storage_bound()` is a graph-level count, not a complete memory census of the engine. The input argument, returned N-vector, Python dictionary/list/tuple objects, recursion temporaries, compiler workspaces, P/L plans, residual, forcing, spectral denominator and inverses also occupy storage. For fixed s these remain O(N) words in a suitable implementation, but they are not included in the reported graph slot total.

The source's memory counters omit some root accesses, initialization and output reads, state/query-container operations, and backup consumption during preview. Their categories should not be interpreted as a complete physical read/write ledger. In particular final output extraction repeatedly traverses the bit-reversal path, adding O(N log N) integer work even though it adds no field arithmetic. A linear bit-reversal traversal/table can change that word schedule if desired.

## 4. Green-conjugated probes and lazy residual generation

With S the right cyclic shift and D=diag(ω^j), take

    L = aI + bS + cD,
    P = aI + cS + bD⁻¹.

For the positive-sign Fourier convention, FS=DF and FD⁻¹=SF, so LF=FP. Thus with Y=Fx and r=Px,

    (Fr)_k = (a+cω^k)Y_k + bY_(k−1 mod N).

For m=2s+2 residual samples, requesting input-side Fourier indices 0,...,m−1 and N−1 suffices. Once the L diagonal is prepared, conversion uses exactly 2m multiplications and m additions. Preparing that diagonal and the root table is setup, not a free per-experiment discovery result.

The new callback materializes r only when a candidate survives the spectral gates and needs a full cyclic certificate. The residual is cached once, even when a first candidate fails and a second must be checked. The inherited source still verifies every coordinate for acceptance and checks all spectral denominator entries are nonzero. A failed certificate continues to the remaining candidates. If none succeeds, the original-input FFT graph completes directly; it does not transform the residual and then solve L.

The independent integration checks construct P and L directly, verify LF=FP on 112 basis vectors, and use the preview values as the actual input to an independently implemented resultant/trace/Prony/certificate pipeline. Six positive cases accept with one residual load each. Six perturbations add ω^(−10j) to the residual: their first ten Fourier samples remain unchanged, while the complete transform changes. Each causes two failed full certificates, one residual materialization, and correct completion of the same FFT graph. Nine fresh generic inputs reject at the trace gate without loading the residual; zero inputs reject on zero probes without loading it.

These tests do not count the dense comparison oracles as part of a production algorithm. They verify laziness by callback counts, while separate independent oracle calculations are intentionally allowed to read the residual.

## 5. Ten-probe counts and exact local savings

At s=4, Q={0,...,9,N−1}. For every dyadic N≥16, the first three levels have both children at every active node and cost 9N/2 operations. At level 3, three nodes have both branches and five have only the even branch, costing 7N/8. At deeper levels there are ten even-only paths and one odd-only path. Their combined remaining cost is 3N/4−12, including zero remaining levels when N=16. Therefore

    deferred preview = 49N/8−12,
    eager two-child preview = 129N/16−33,
    backup scalars = N−11.

The Phase23 stream uses 19N operations for ten residual probes. Including 30 conversion operations, the Phase24 replacement saves

    19N − (49N/8−12+30) = 103N/8−18.

This exact difference extends to a matched successful certificate path: both versions have identical residual, candidate order, compiler, complete certificate, numerator/denominator recovery and Green-solve work. Any inherited common undercounts cancel in that local difference. It does not establish that either grand total is complete.

Likewise the eager/deferred preview difference is 31N/16−21. On complete fallback the two graph versions have identical total butterfly arithmetic, so their field-count difference disappears. These formulas are independently checked through N=2^20 by traversing the query decision tree, and all relevant formula fields in the 12 supplied benchmark records match. These large formula checks do not execute uploaded benchmarks or simulate their entire compilers.

## 6. Restricted-family size: accepted

Fix invertible P. If A has t≤s nonzero coefficients and A(S) is invertible, then for given support, coefficients, nonzero α, and 1≤δ<N, the relation

    A(S)Px = e₀−αe_δ

determines at most one x. Consequently the number of representable finite-field inputs is bounded by

    (N−1)(p−1) Σ_(t=1)^s binom(N,t)(p−1)^t.

This is an upper bound with possible duplicate parameterizations and includes choices later excluded by invertibility or discovery gates. Divide by p^N, and cap at one if desired, for a uniform-input probability bound. For fixed s and compatible p≥N+1 it tends rapidly to zero as N grows. It is not a count of exactly accepted inputs. As a small independent control, for s=1 and P=I the checker enumerates 192 parameter choices yielding 96 distinct inputs at N=4, GF(5), and 14,336 choices yielding 7,168 inputs at N=8, GF(17). This confirms that duplicate parameterizations need not attain the upper bound.

Over C, each fixed support/delay gives a rational parameterization with at most s+1 complex parameters on the invertibility locus. A finite union has dimension at most s+1 and is measure zero when N>s+1. The short-probe kernel argument separately confirms that fewer than N Fourier measurements cannot identify every arbitrary input. Neither argument lower-bounds general FFT circuits.

## 7. Implementation defects and inherited boundaries

### Compatible-field constructor counterexample

At N=16, p=17, ω=3, a=7,b=2,c=1:

- L has its zero diagonal at index 3.
- P has its zero diagonal at index 11.
- det L=det P=16, so both are invertible.

Our direct matrices satisfy LF=FP and exact solve recovery. The native deferred FFT also works. However, unchanged `CyclicSolver.__init__` calls `inv_all(diag)`, whose zero-product guard raises `ValueError('zero diagonal entry')`. Thus the new native fallback cannot be reached via that constructor. This is a field-domain/implementation incompleteness, not a false accepted Fourier output.

A repair can use a cyclic solver that handles invertible zero-diagonal matrices, select verified compatible Green parameters with charged setup, or initialize the native FFT independently and fall back before Green setup failure. The existing seal does none of these. The nominal fast detector also retains 1≤s≤8 and p>4b_s+20, where b_s=s(s+1)(2s+1)/6. The Phase24 wrapper requires N>2s+2. The headline N≥16 is sufficient for default s=4, not for every allowed s.

### Preview-after-full lifecycle

`full()` does not set `done_preview`. Calling it first leaves transformed data and full node states, but `preview()` then calls `_prepare`, which ignores those completed states and computes new butterflies over the transformed array. Our explicit x=e₀ control gives subsequent DC=N rather than 1. The independent checker adds the recommended rejection; the source remains untouched. The ordinary wrapper always previews first, so this bug is outside its normal sequence.

### Costs not fixed by this phase

- The source holds the root table and Green setup warm. Even early rejection avoids `P.apply` and `L.solve`, not the already performed P/L construction. A cold comparison must charge root derivation/order tests, N−1 running-root multiplies, both cyclic-solver plans and field inversion implementation.
- The carried compiler still omits some monic-gcd normalization, determinant sign, interpolation/sample subtraction and factor-output operations from its field ledger. The active Phase22/23 root-bank omission was already removed; it must not be incorrectly reintroduced as an active Phase24 defect.
- Trace-root extraction still has the inherited Tonelli–Shanks/nonresidue-search qualification. A supplied nonresidue or a fully charged deterministic alternative is needed for a clean uniform setup bound. The complete half-trace scan gives an O_s(N) alternative but is not the implementation chosen for every linear-gcd case.
- The legacy wrong noncoprime-resonance predicate persists only in untouched older paths; the new short-probe engine does not call that predicate.
- Native dyadic fallback no longer needs Bluestein's extra 2N/convolution roots. That is a genuine narrowing of fallback root requirements. The old Bluestein routines remain in legacy entry points.
- Fallback safety assumes the compiler returns a result or decline normally. The wrapper does not catch every potential internal exception and recover from arbitrary implementation errors.

With these distinctions, the mathematical schedule is ordinary O(N log N) fallback plus bounded-family discovery work. The supplied material does not fully prove its broad cold, uniform-in-field bit/word complexity claim from the recorded field counters alone.

## 8. Prior art and evidence status

DIF butterflies, pruning and computation-graph reuse are classical. This audit approves a project-specific verified schedule and exact cost differences, not historical priority. [FFTW's primary pruning discussion](https://www.fftw.org/pruned.html) places selective-output transforms in that established context.

[Ailon's primary paper record](https://arxiv.org/abs/1403.1307) explicitly states its uniform-condition-number restriction and Ω(R⁻¹N log N) bound, and separately discusses the classical bounded-coefficient result. Those hypotheses do not yield an unrestricted Fourier lower bound and are not transferred to finite-field counters. The directly requested Morgenstern DOI failed retrieval in this review; no claim is made to have independently re-read that original proof here.

Source logs, test labels, and hashes have distinct evidentiary roles. The source test called “every query subset” samples query sets rather than exhaustively enumerating them at its listed large lengths. Our own exhaustive subset claim is limited to N≤8; larger controls are explicitly sampled or basis-based. Source hashing confirms identity, not correctness. The all-size scheduling and family-count statements rest on the proofs above.
