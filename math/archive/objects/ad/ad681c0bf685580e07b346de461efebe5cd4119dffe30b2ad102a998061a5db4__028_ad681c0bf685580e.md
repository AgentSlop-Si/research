# Green operators as a bridge between exact graph filters and approximate residuals

This component establishes a concrete compatibility result. The supplied
path-Green operator and its two-resolvent sum have Fourier-side applications
and inverses that use O(N) exact field operations, with explicit formulas
and no transform oracle. This allows a residual approximation to be mapped
back to the original Fourier outputs with a proved error bound.

It does not make an exact Fourier transform of an arbitrary input faster.
Nor does an O(N) exact-field routine automatically become a bounded-word
routine. The current code verifies the exact conjugacy and supplies separate
numerical sanity checks for the approximation bounds; it does not claim a
new integrated Word-RAM implementation.

## 1. The missing-wrap correction makes the bridge explicit

Let F have entries q^(kj), where q is a primitive Nth root, and let
U=F/sqrt(N). Let T be the path tridiagonal matrix with diagonal 3 and
adjacent off-diagonal -1. If P is cyclic shift, then

    T = 3I-P-P^-1 + e_0 e_(N-1)^T + e_(N-1) e_0^T.

The first part is circulant, and the only noncirculant part consists of the
two missing wrap edges. Therefore H=F T F^-1=U T U* is

    (Hy)[k] = (3-q^k-q^-k)y[k]
              + (1/N) sum_l q^l y[l]
              + (q^-k/N) sum_l y[l].

The routine `target_h` implements exactly this formula. Its two global
weighted sums are paid O(N)-work reductions. There is no call to F in this
routine or anywhere in `green_bridge.py`.

More explicitly, for alpha>=0 write

    H+alpha I = D_alpha + A B,
    D_alpha[k,k] = 3+alpha-q^k-q^-k,
    A[k,:] = (1,q^-k),
    B[:,l] = (q^l/N,1/N)^T.

Apply Woodbury using a 2-by-2 correction:

    (H+alpha I)^-1
      = D_alpha^-1
        - D_alpha^-1 A (I_2+B D_alpha^-1 A)^-1 B D_alpha^-1.

Preparing every diagonal entry, both correction columns, the four small
matrix entries, its determinant inverse, and all root powers costs O(N)
exact field operations. Applying the result costs O(N). The code does not
hide a dense matrix-vector product in the 2-by-2 solve.

Over the complex numbers these alpha>=0 preparations have no zero pivots:
the diagonal entries of D_alpha are positive and T+alpha I is positive
definite. Modular test fields can have exceptional zero pivots; the code
explicitly rejects them. None occurred in the reported modular tests.

## 2. The two-Green operator and its inverse

The supplied material uses

    S = T^-1 + (T+I)^-1.

Its conjugate is the equally explicit

    K = U S U* = H^-1 + (H+I)^-1.

For the inverse, the rational identity in the material gives

    S^-1 = (1/2)T + (1/4)I - (1/8)(T+I/2)^-1,
    K^-1 = (1/2)H + (1/4)I - (1/8)(H+I/2)^-1.

Thus the exact source and target directions both require only a fixed
number of tridiagonal actions or diagonal-plus-rank-two actions. The code
prepares all three shifts alpha=0,1,1/2 and validates these identities on
every input basis vector at the tested small lengths.

This is useful because a preconditioner D only helps a Fourier algorithm
when the corresponding K=U D U* is also explicitly applicable or invertible.
Computing K by calling the unknown fast Fourier transform would be circular;
the formula here avoids that circularity.

## 3. A dimension-independent target error-amplification bound

The following is a complex-analytic bound, not a finite-field norm claim.
Let A0=3+alpha, and put

    g_k = 1/(A0-q^k-q^-k),
    t = (1/N) sum_k g_k,
    c = (1/N) sum_k q^k g_k.

Root symmetry makes c real and equal to the analogous sum with q^-k.
Averaging (A0-q^k-q^-k)g_k=1 gives A0 t-2c=1. Hence the Woodbury correction
matrix is

    R = [[1+c,t],[t,1+c]],
    1+c = (1+A0 t)/2.

Since t>0 and A0>=3, its smaller eigenvalue is

    1+c-t = (1+(A0-2)t)/2 >= 1/2.

Its inverse has positive diagonal and negative off-diagonal, so

    ||R^-1||_infinity = 1/(1+c-t) <= 2.

Also g_max<=1/(1+alpha),
||D_alpha^-1 A||_infinity<=2g_max, and
||B D_alpha^-1||_infinity=t<=g_max. Woodbury therefore yields

    ||(H+alpha I)^-1||_infinity
      <= g_max + 4g_max^2.

In particular, ||H^-1||_infinity<=5, while
||(H+I/2)^-1||_infinity<=22/9. The direct rank-two formula gives
||H||_infinity<=5+2=7. Combining the three terms of K^-1 gives the simple
uniform bound

    ||K^-1||_infinity <= 7/2 + 1/4 + (1/8)(22/9)
                       = 73/18.

This constant is deliberately conservative. It is sufficient to show that
transport through this Green bridge need not amplify residual error by a
power of N. It is not a claim that the computed floating-point solver has
already been certified to this accuracy.

## 4. The general residual bridge, including quantization

Let D be any invertible source operator with an explicitly implemented
conjugate K=U D U*. Compute u=Dx, split u=h+r, and evaluate Uh exactly for a
chosen s-entry head h. Suppose a residual decoder returns z approximating
U r with

    ||z-U r||_infinity <= epsilon L_box(r)/sqrt(N),
    L_box(r) = sum_j (|Re r_j|+|Im r_j|).

Then the reconstructed vector

    y_tilde = K^-1 (U h + z)

satisfies

    ||y_tilde-Ux||_infinity
      <= ||K^-1||_infinity epsilon L_box(r)/sqrt(N).

The decoder's success probability is unchanged because this implication is
deterministic on its success event. For the Green S, one may use 73/18 for
the inverse norm. For a chain of filters, the product of the known inverse
norm bounds is a valid, possibly loose substitute.

Finite-word compatibility requires an extra accounting step. Suppose the
actual prepared vector obeys

    h+r_tilde = Dx+e,

where e includes preconditioner evaluation, root approximation, and residual
quantization errors. Let the residual decoder approximate U r_tilde, let
zeta bound any head-transform evaluation error in infinity norm, and let tau
bound any additional target inverse evaluation error in infinity norm. Then
the proved total bound is

    ||y_tilde-Ux||_infinity
      <= R ([epsilon L_box(r_tilde)+L_box(e)]/sqrt(N) + zeta) + tau,
    R >= ||K^-1||_infinity.

The L_box(e) term follows from ||Ue||_infinity<=||e||_1/sqrt(N).
For an exactly evaluated head, zeta=0. The source error cannot be omitted
when an exact complex-field filter feeds an
integer-mass Word-RAM decoder. Our current exact code does not establish
O(log N)-bit storage for its algebraic coefficients, bound their growth, or
certify floating-point tau. Consequently the existing approximate Word-RAM
theorem cannot simply be imported through this code without that work.

Even with no randomized decoder, omitting the tail gives the deterministic
mathematical guarantee

    ||K^-1 U h-Ux||_infinity <= R ||r||_1/sqrt(N).

For a supplied head support this costs O(Ns) Fourier-mode evaluations plus
the paid source/target operators. If r=0, the formula is exact. This last
sparse-defect specialization is a consequence of the verified bridge; no
additional sparse-Green FFT wrapper is claimed to be implemented here.

## 5. Why raw preconditioning can be an illusory gain

A global scalar rescaling does not reduce the complex-L1 error budget:

    ||(aK)^-1||_infinity ||aDx||_1
      = ||K^-1||_infinity ||Dx||_1.

For real positive a, the same identity holds with L_box. Reducing the
residual magnitude and ignoring the inverse amplification is not a valid
accuracy improvement.

There is a stronger exact statement for the affine-cycle family already
implemented in this research. Let M and Mhat be Fourier-conjugate weighted
full N-cycles whose edge weights have magnitude 1 and satisfy M^N=Mhat^N=-I.
For any rational f defined and invertible on their spectra, write

    f(M)^-1 = sum_(t=0)^(N-1) c_t M^t.

The same coefficients represent f(Mhat)^-1 because both obey z^N+1=0.
In each row and column, distinct powers occupy distinct matrix entries,
each with unit-magnitude weight. Consequently

    ||f(M)^-1||_1 = sum_t |c_t| = ||f(Mhat)^-1||_infinity.

For D=f(M) and R=||f(Mhat)^-1||_infinity, it follows for every x that

    R ||Dx||_1 >= ||x||_1,
    R L_box(Dx) >= L_box(x)/sqrt(2).

Thus raw precondition-then-sample error certificates cannot gain an
asymptotic factor through this family. This applies both to I-lambda M and
to the newly examined dense rational stage I+(I-M)^-1. For a composition,
the analogous conclusion holds when R is the product of the individual
inverse norm bounds. A sharper analysis of correlated errors would require
a different argument; this lemma does not rule that out.

For I-lambda M specifically, the exact common norm is

    R = [sum_(t=0)^(N-1) |lambda|^t] / |1+lambda^N|.

The useful fusion is therefore to remove a cheaply transformed exact head
and sample only a small residual tail, not to claim that the entire residual
became free through scaling or a poorly conditioned inverse.

## 6. Executed validation and cost

Run `python3 run_audit.py` from this directory. The only external research
dependency is the sibling `fft_bidirectional_graph_research` exact-field
implementation and its ordinary FFT comparator. The production module uses
only the Python standard library and contains no DFT call.

The exact audit passed 852 conjugacy checks and 568 inverse checks, including
84 cyclotomic conjugacy cases, with no unsupported modular pivot cases. Six
larger modular identities were checked against an independent ordinary FFT,
and 16 wrong-length inputs were rejected. An outer arithmetic wrapper
confirms that every field operation and every setup operation is counted.

| N | Full common preparation | Source S | Target K | Source S^-1 | Target K^-1 |
|---:|---:|---:|---:|---:|---:|
| 64 | 2,783 | 570 | 1,228 | 763 | 1,352 |
| 256 | 11,039 | 2,298 | 4,876 | 3,067 | 5,384 |
| 1,024 | 44,063 | 9,210 | 19,468 | 12,283 | 21,512 |

The preparation and application costs are linear field-operation counts.
These numbers are not an FFT benchmark: the table contains source and
Fourier-side operator applications, not an arbitrary-input Fourier transform.

Run `python3 approximation_sanity.py` for the separate floating-point checks.
They verify the analytic bounds numerically on near-structured dense inputs,
inject bounded artificial decoder errors to test their propagation, check
scalar-rescaling cancellation, compare rational-cycle inverse norms, and
check the Green norm bounds. NumPy DFTs and dense solves are used only for
independent reference values and test-input generation. These checks are
not a residual decoder implementation or a certified floating-point proof.

At N=128, the constructed near-structured example has 128 nonzero inputs.
The raw filtered-mass certificate is 1.00984 times the original L1 certificate;
there is no raw gain. Removing one exact residual head gives an analytic
tail-omission bound 0.066228, about 0.009841 times the original L1 certificate;
the observed error is 0.00066983. This is a structured approximation benefit,
not a universal accuracy improvement or an exact asymptotic breakthrough.

## Main-goal status

The bridge is now explicit, checked, and charged. It permits principled
mixing of exact operator filters with approximate residual processing and
exposes where normalization or conditioning would cancel a claimed gain.
It provides no arbitrary-input exact o(N log N) Fourier algorithm.
