## Important mathematical progress

1. **Weighted marker cut, independently accepted.** The changed retained set has an exact weighted Schur recurrence and nilpotence index n-b for N=2^n. Fresh-source preparation costs O(N log N/log log N), with O(N log log N) field-word storage, at the stated marker choice. The displayed full inverse/recovery still costs Theta(N log N). Its source map has rankN, so a short language automaton is not a sufficient linear summary of arbitrary data. This is a component improvement, not an FFT improvement.
2. **A decisive model boundary for that route.** Every input-dependent gate in the complete complex marker executor uses only unit-modulus scalar multipliers and binary additions. Morgenstern's classical determinant bound therefore applies to any complete redesign retaining those primitives. A proposed general speedup must explicitly justify a paid departure from that model. This does not establish finite-field or unrestricted-arithmetic impossibility.
3. **Global chirp-bank construction, independently accepted.** Every odd-length chirp circulant needs exactly(N+1)/2 scalar resolvents of the same cycle when no separate diagonal correction is allowed. A finite legal-parameter search and root-free implementation are proved. Individual nodes may require an algebraic extension; the sum is computed over the stated cyclotomic base field. Setup is O(N^3), application O(N^2). This completes a global identity but supplies no fast FFT. A free-diagonal relaxation has a shifted-Prony criterion; ongoing classification is separate and not preapproved here.
4. **Restricted finite-field extensions, independently accepted with novelty correction.** The affine-alphabet-adaptive transform and arbitrary-length mod-two convolution have valid charged word-RAM proofs under their imported Frobenius machinery and field model. The matching binary-multiplication O(L log log L) word bound also follows from classical Cantor–Kaltofen polynomial multiplication with blocking and small-ring tables. No asymptotic multiplication priority is claimed.
5. **Previously pending bank certificates now audited.** Mixed-radix routing and correctly oriented monomial actions, the guarded local F4 kernel, and all eight fixed F8 anchor exclusions are accepted at their exact scopes. A matching-mask corollary gives explicit global Hamiltonian branches for existing four-layer N128/N256 butterfly exteriors. Half their edge masks remain zero; this does not lift the all-nonzero cyclic F4 kernel or compress growing FFT depth.
6. **New quantitative finite-layout certificate.** For the pinned N256 outer-inverse layout, a rational fourth-moment enclosure independently gives sigma17>3sqrt(2)/5. The fixed-stage projective-gauge feasibility criteria are accepted. Both are scoped tools, not global no-go theorems.

## Why the code audit matters

Complete code reads found genuine gaps that summaries and source PASS logs missed:

- A saved Macaulay verifier can accept an empty witness dictionary or empty determinant minors.
- A saved two-parameter slice validator accepts polynomials with incorrect degrees and no binding to the intended family.
- A limited C++ enumeration breaks only its inner loop; a different indexed checker ignores a partial trailing index record.
- Some nominally linear initialization/recovery paths use sorting, repeated exponentiation or quadratic list membership omitted from their counters.
- A Green helper silently treats zero inversion as zero; a cycle generator cannot finish below its feasible size; large-size application flags assert checks not actually compared in that branch.
- Several consolidated audit files combine regenerated computations with saved historical reports. Import paths, exact module versions, binary/source binding, input-family binding and expected case coverage must remain explicit.

These defects are attached to exact versions. They do not undo a mathematical claim already proved by a separate valid reconstruction. Conversely, a valid theorem does not certify a defective source verifier.
