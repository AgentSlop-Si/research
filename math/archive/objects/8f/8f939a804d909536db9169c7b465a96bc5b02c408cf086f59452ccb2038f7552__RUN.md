# Reproduce Phase 29

Requires Python 3.10+ and `sympy` for the optional symbolic checks. Both tested modulus/generator pairs are preserved in `crt15.py`. Run from this directory:

```bash
python -m unittest -v test_phase27 test_phase28 test_phase29
python symbolic_phase29.py
python weighted4_rank_gate.py
python weighted4_gate.py
python gauge_obstruction.py
python benchmark_phase29.py
python benchmark_phase29.py alternate
python audit_phase29.py --field primary --max-n 960
python audit_phase29.py --field alternate --max-n 960
```

The full basis audits check lengths 120, 240, 480, 960 in each field; they can take tens of seconds. For a faster but meaningful local check, use `--max-n 240`. `BENCHMARK_PHASE29.json`, `BENCHMARK_PHASE29_ALT.json`, and `AUDIT_PHASE29_*.json` are immutable receipts from this checkpoint and should be regenerated only when intentionally re-auditing.

The original Phase 28 archive is stored as `PRIOR_PHASE28_COMPLETE.zip`, byte-for-byte unchanged. A source checksum manifest is supplied. The archive is not a general FFT library or a numerically stable floating-point solver.
