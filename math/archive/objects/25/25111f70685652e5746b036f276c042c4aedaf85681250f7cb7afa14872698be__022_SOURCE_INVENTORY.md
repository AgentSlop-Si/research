# Phase14 source inventory and lineage

This package is **not** based on CrocSwap's integer-multiplication exponent proof. It inherits the user's dyadic chirp core and all prior FFT research as independent original checkpoints. Original bytes are preserved.

## New files

- `phase_bank.py`: deterministic complete-vector error-energy identity and optimal orthogonal beta-bank selection, known-bank and adaptive recovery, common odd-transform fusion.
- `gram_union.py`: genuinely noncommuting chirp-family Gram projection, q-short-FFT+G-scan evaluator, exact-arithmetic residual energy.
- `one_root_chirp.py`: one-root table and G-term decoder, shared across phase states.
- `leverage_gate.py`: explicit fixed-frame minimax input and trace/rank obstruction.
- `green_forcing_gate.py`: Fourier forcing support density and sharpness over finite fields.
- `field_gram_audit.py`: independent finite-field noncommuting all-basis + cyclic recurrence verifier.
- `stationary_toeplitz.py`: full-rank all-size Toeplitz/Vandermonde chart, reusing one Gram factorization.
- `field_stationary_audit.py`, `test_stationary.py`: independent modular q=M full Fourier basis, stationary Gram checks and regressions.
- `orbit_collision_gate.py`: exact modular-orbit count certifying only constant-factor same-clock destination collision savings.
- `test_phase14.py`, `experiment_phase14.py`: numerical tests and transparent work/accuracy proxies.
- `THEOREM.md`, `NEXT_GATE.md`, `README.md`, `RUN.md`: full proof, boundaries, reproducibility.
