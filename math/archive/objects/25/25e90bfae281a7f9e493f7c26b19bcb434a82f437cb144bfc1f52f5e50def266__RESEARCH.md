# Hero #17 — Phase 8: multistage bridge rank, polynomial CRT union, and charged sparse-table gates

**Date:** 2026-10-10  
**Status:** Reproducible scoped mathematical identities, a finite-width exhaustive search, a working exact NTT executor, an independent audit, and identified historical prior art. **No universal exact O(N) Fourier transform or integer-multiplication breakthrough.**

## 0. Research contract

Our target remains one uniform *sequential* algorithm which receives a **fresh, arbitrary** input vector, computes **all N outputs** of the exact DFT, and pays for arithmetic, root generation, schedules, index work, memory, any lookup-table construction, and output materialization. We do not count GPUs, free simultaneous processing, known sparse edits, structured initial vectors, or prepared input-specific advice as a solution.

Phase 7 optimized **one-pass disjoint rank-one rectangle unions** and proved the exact endpoint-incidence optimum `N * min_{d|N}(d+N/d)`. Phase 8 takes the next step: allow multiple layers, search alternative polynomial root partitions, and check full end-to-end costs. The findings below are NOT unrestricted arithmetic-circuit lower bounds.

The exact runnable executor is over a finite prime field `F_p` containing a primitive Nth root of unity. The algebraic rank theorems apply to any field with N distinct roots of unity and, in particular, to complex DFT matrices. Our executable radix-2 evaluator is classical decimation in frequency and uses Θ(N log N) scalar work.

## 1. Result A — a multistage cross-cut rank certificate

Take any `1 <= m < N`. Fix the coordinate cut `I={0,...,m−1}`, `J={m,...,N−1}` throughout the computation. Let each of L stages have matrix

```
T_t = B_t + E_t,
```

where `B_t` is block diagonal relative to the **same fixed cut** and `rank(E_t) <= r_t`. These matrices need not be unitary, well-conditioned, or have bounded scalar coefficients.

**Theorem A.** If `T_L ... T_1 = F_N`, then

```
sum_t r_t >= min(m, N-m).
```

**Proof:** Set `B=B_L...B_1`, which is block diagonal. The standard telescoping identity is

```
T_L...T_1 - B_L...B_1
  = sum_{t=1}^L T_L...T_{t+1} E_t B_{t-1}...B_1.
```

Each summand has rank at most `r_t`, so `rank(F_N-B) <= sum_t r_t`. Since `B[I,J]=0`, the submatrix `F_N[I,J]` has rank at most that sum. On the other hand, for `k in I` and `j in J`, `F_N[k,j] = z_j^k` with distinct nonzero `z_j=omega^{-j}`. Consecutive powers `k=0,...,m−1` form a rectangular Vandermonde matrix of rank `min(m,N-m)`. QED.

For a balanced cut the required rank budget is `floor(N/2)`; this forbids `O(1)` total **global correction rank** over any number of locally separated layers.

**Sharpness as a rank statement, with a fatal execution caveat.** Write the even-N Fourier matrix in m×m blocks `F=[[A,B],[C,D]]`. Consecutive-row Vandermonde ensures `A` is invertible. Put `H=C A^{-1} B`, `S=D-H`. Then

```
F = diag(0,S) + [I; C A^{-1}] [A, B].
```

The residual has rank m, attaining the lower bound exactly. The saved code also constructs an **invertible** block-diagonal baseline with a rank-m residual by taking `X=tA` and `Y=D-(1-t)^{-1}H` for a suitable `t`. This is *not* a cheap FFT: constructing the dense inverse and multiplying the dense blocks is expensive. Rank by itself does not measure implementation cost.

**Scope:** Arbitrary shuffles between stages, unrelated partitions at different stages, high-rank interactions, ancillary registers, and unrestricted arithmetic circuits are NOT covered. This theorem cannot be added across dyadic cuts without a separate non-overlap charging lemma.

## 2. Result B — the cross-channel CRT transfer has full rank for every root split

Let `N=2m`. Partition the N Fourier evaluation points `z_j=omega^{-j}` into any two subsets `A,B` of cardinality m. Let

```
P_A(z) = product_{j in A}(z - z_j),
P_B(z) = product_{j in B}(z - z_j).
```

For every degree `<2m` polynomial write its coefficient vector as `(low, high)` of length m each, so

```
f(z) = sum_{i<m} low[i] z^i + z^m sum_{i<m} high[i] z^i.
```

Let `R_A` be the m×m linear map whose `t`th column is the coefficient vector of `z^(m+t) mod P_A`; define `R_B` similarly. The coefficient vectors of the two remainder polynomials are

```
a = low + R_A high,
b = low + R_B high.
```

Thus the complete two-child remainder network has transfer matrix

```
            [ I  R_A ]
T(A,B)  =    [ I  R_B ].
```

**Theorem B.** For *every* balanced root partition,

```
det(R_B - R_A) != 0,   rank(R_B - R_A) = m.
```

**Proof:** Let `V_A,V_B` be the m×m Vandermonde evaluation matrices on the two sets. Evaluating the two remainders gives precisely the full Fourier/Vandermonde evaluation operator, with its output rows permuted:

```
F_rows(A,B) = diag(V_A, V_B) * T(A,B).
```

All three matrices `F_rows(A,B)`, `V_A`, and `V_B` are invertible, so `T(A,B)` is invertible. Subtract the first block row from the second. The resulting block triangular matrix has diagonal blocks `I` and `R_B-R_A`, which must therefore be invertible. QED.

**Interpretation:** Changing which roots belong to each half does not reduce the number of independent cross-channel differences below N/2. This is a statement about this exact polynomial-remainder interface, not about the minimum scalar operations needed to compute those m-dimensional differences.

### Theorem C — uniquely sparsest *coefficient wiring* returns classical FFT

As multiplication by `z^m` is invertible in each quotient ring `K[z]/P_A`, both `R_A,R_B` are nonsingular. Each consequently has at least m nonzero entries. Hence

```
min_{balanced root split} (nnz(R_A) + nnz(R_B)) >= 2m=N.
```

If `R_A` has exactly m nonzero entries, it must be a monomial matrix (one nonzero per row and column). Its first column represents `z^m mod P_A`, i.e. minus the m lower polynomial coefficients of the monic `P_A`. Because `P_A(0)` is nonzero (all roots nonzero), the unique nonzero entry of the first column is in its constant term. Thus `P_A(z)=z^m-c`, a binomial. For N=2m, the N Fourier roots satisfy `z_j^m=(-1)^j`, so its root set must be **exactly the even indices or exactly the odd indices**. The complement is the other set and `R_A=cI`, `R_B=-cI`.

It follows that the minimum `N` nonzero transfer entries occurs only for the standard even/odd Fourier-root split, up to swapping the two sides. The corresponding shared computation is

```
t = c * high[i]
a[i] = low[i] + t
b[i] = low[i] - t
```

at each i: the usual **decimation-in-frequency butterfly**. It does not improve asymptotic complexity. Sparse matrix *entries* are not the same as a lower bound on circuit size: dense transfer maps might admit compact multistage arithmetic circuits.

## 3. Exact finite-width root-split search: N=16

The exhaustive search enumerates all `C(16,8)=12,870` subsets and all `6,435` unordered complementary splits. For exact zero testing of the vanishing polynomial coefficients we compute in `Z[zeta_16]`, represented by `Z[t]/(t^8+1)`; this is **characteristic-zero cyclotomic arithmetic**, not floating-point near-zero testing or a single finite-field residue.

**Number of nonzero coefficients in one 8-root annihilator:**

| Support size | Number of subsets |
|---:|---:|
| 2 | 2 |
| 3 | 4 |
| 4 | 8 |
| 5 | 56 |
| 6 | 32 |
| 7 | 32 |
| 8 | 224 |
| 9 | 12,512 |

For complementary pairs, the minimum combined support is **4**, attained only by the even/odd classical split. The minimum among non-periodic root subsets is **15**, with 32 complementary pairs achieving that count. Some non-subgroup sparse annihilators do exist, so we must not equate all sparsity with subgroup membership.

Separately, over `F_17`, every balanced CRT transfer `R_B-R_A` was independently checked to have exact rank 8. The minimum combined transfer-matrix nonzero count is **16**, attained by the classical split; among the tested nonperiodic splits it is **at least 94**. A nonzero `F_17` reduction certifies the corresponding cyclotomic integer is nonzero over characteristic zero, so this latter number is also a *valid lower bound* for the characteristic-zero nonperiodic 16-point instances in this fixed monomial-basis transfer model. A finite-field zero can be accidental; the converse is not valid.

The search is a small-instance structural certificate. It does not prove that no alternative network or basis uses fewer arithmetic gates. Polynomial-remainder FFTs and sparse annihilator ideas have historical precedent (notably Fiduccia 1972 and the family including Bruun's FFT); priority for the mathematical framing is not claimed.

## 4. Executable root-partition experiment — the fully charged ledger

The package contains two independent **implementations**, both computing all outputs of fresh arbitrary inputs:

- `eval_radix2_remainder`: shared binomial quotient reductions, i.e. classical radix-2 DIF FFT.
- `eval_generic_remainder`: arbitrary root partitions with direct monic polynomial divisions. It pays for generating every nontrivial vanishing polynomial, the divisions, input scan, output writes, and root-power table.

For a representative 16-point input over `F_17`:

| Executor | Online add+mul | Root powers | Polynomial preparation | Charged scalar total |
|---|---:|---:|---:|---:|
| Shared binomial FFT | 96 | 15 | 0 | **111** |
| Generic subgroup division | 104 | 15 | 456 | 575 |
| Nonperiodic split division | 380 | 15 | 456 | 851 |
| Contiguous split division | 404 | 15 | 456 | 875 |

These are code-specific operation ledgers, not optimal-circuit lower bounds or wall-clock benchmarks. The generic subgroup division's excess is a useful control: merely noticing its subgroup roots isn't enough; one must **share the two complementary reductions** to recover the ordinary FFT. The root of unity is a supplied algebraic input, while the `N−1` multiplications constructing its power table are charged. Polynomial schedule and in-loop index work are O(the executed loops) but not separately reported as scalar field additions/multiplications.

For `N=65,536`, the exact baseline performed 524,288 classical butterflies, 1,048,576 field additions/subtractions, 524,288 field multiplications and 65,535 root-table multiplications, with 65,536 input reads and 65,536 explicit output writes. It is Θ(N log N), not O(N).

## 5. Graph union: semantic value ≠ computation template

A fixed radix-2 FFT repeats **templates** (same butterfly wiring), but on arbitrary fresh input the full input-to-wire linear forms are different. `radix2_symbolic_merges` represents every wire as a vector of coefficients of the original input symbols over an exact prime field, normalizes away any nonzero scalar and hashes the resulting linear forms.

At level s, each wire has support of size `2^s`; different levels therefore cannot have proportional forms. Within one level the transform is invertible, so its N rows are linearly independent; they also cannot be proportional. Therefore across all levels of a standard radix-2 FFT,

```
exact/proportional input-independent wire-form merges = 0.
```

This is an exact **obstruction to equality-only union-find** on that fixed circuit, not to algebraic cross-stage sharing through new intermediate expressions. Tests for N=4,8,16,32,64 verify no false identities.

A separate counterexample prevents misreading large support as high operation cost: `dense_star` transforms all N input coordinates into N dense, nonzero, linearly independent output forms with just `2(N−1)` in-place addition gates. It is invertible and full-support but **not** the Fourier transform. The tensor/cut rank structure, not coefficient density alone, is the relevant obstruction.

## 6. Unitary/quantum-inspired path and sparse-table path

**Unitary in-place 2-wire gates.** For the normalized DFT `U_N=F_N/sqrt(N)`, each final row has Shannon entropy `log2 N` in the distribution of squared entry magnitudes; initially the identity rows have entropy 0. A 2×2 unitary gate acting on two rows increases the sum by at most 2 bits, because it leaves the input-index marginal fixed and changes only the conditional entropy of a two-valued wire label. Hence at least `(N/2)log2 N` such gates are needed. Radix-2 butterfly networks meet this bound. Our code independently reproduces the entropy increments. **This is known work of Nir Ailon (2013), NOT a new Phase 8 theorem**, and it does not apply to unrestricted nonunitary linear circuits or promise any quantum lower bound.

**Exact finite-field sparse-table blocks.** If a complete explicit truth table for an r-input linear block over a field of size p is charged, its key domain has `p^r` entries. An exact length-N NTT in a prime field needs `p >= N+1`. A polynomial-size table budget `N^c` therefore restricts r to at most c. This rules out growing block-width *via complete truth tables* with polynomial preprocessing. It does not rule out compressed/algebraic tables, changing data models, non-layered circuits, or the OpenAI exact-complex-arithmetic construction.

## 8. What survives for the next phase

The core live question is **not** to make `R_A-R_B` low rank: it is invertible for every balanced split. Nor is it to relabel the binomial split or hide root computations. The viable unexplored target is a *joint arithmetic circuit* evaluating both complementary remainder maps using a nontrivial cross-stage cancellation, beating the charged standard butterfly circuit on arbitrary inputs, with a uniform recurrence. Alternative polynomial division graphs must be compared against the known Bruun/CRT and existing exact arithmetic below-NlogN literature before any priority claim.

The strongest public all-length general exact complex arithmetic comparison checked in this continuation is OpenAI Math #130: `O(N (log N)^(1−10^(−13)))`, with permissive coefficients and a different model from exact finite-field and bit cost. An O(N) universal exact result was **not** obtained.
