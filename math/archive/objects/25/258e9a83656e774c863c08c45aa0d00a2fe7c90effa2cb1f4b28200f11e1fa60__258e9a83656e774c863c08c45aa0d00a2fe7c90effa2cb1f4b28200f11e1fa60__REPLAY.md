# Independent replay

Use Python 3.9 or later and only its standard library. Do not run any program under `extracted/`.

From this directory:

    python independent_checks.py --output regenerated.json
    cmp INDEPENDENT_RESULTS.json regenerated.json

Or copy only `independent_checks.py` into any otherwise empty directory and run it there with the same output option. It neither reads source archives nor imports uploaded code. All seeds and finite cases are fixed. No network, installed packages, absolute path dependencies or artifact setup is needed.

The dense inversions at length 257 and exhaustive small minors are audit costs, not FFT performance measurements. Assertion failures stop replay. The report's symbolic proof, rather than the finite tests alone, supports the all-size theorem. Products of two additive sums are excluded from this replay.
