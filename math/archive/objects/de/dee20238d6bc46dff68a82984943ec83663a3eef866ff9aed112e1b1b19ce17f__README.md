# Hero #0 Phase 9 — exact dense-circulant recovery with sparse innovations

**Research prototype**, not an all-input sub-FFT algorithm.

- `phase9_dense_cycle.py`: learn arbitrary dense circulant operator from two raw columns; recover unknown sparse-position errors; use direct O(N) corrections for O(1) total errors or short M-NTTs for per-step sparse errors; randomized Freivalds membership checker.
- `phase9_spectral_innovations.py`: dual Prony decoder for innovations that are dense in position but sparse in Fourier; O(N) for O(1) spectral modes **per** column, with every cost charged.
- `THEOREMS.md`: exact hypotheses, algebra, derivations, soundness and complexity proofs, negative controls.
- `CHAIN_HANDOFF.md`: recover research in another session.
- `test_phase9.py`, `test_spectral.py`: 17 formal unittest methods with many exact cases.
- `audit_phase9.py`, `audit_spectral.py`: modular checks and operation counts through N65536, witness/rarity proof. `audit_universal_identity.py` independently checks the forced-cycle formula on completely arbitrary inputs, including singular denominators, explicitly charging all M K-NTTs.
- `AUDIT_RESULTS.json`, `SPECTRAL_AUDIT_RESULTS.json`: generated evidence.
- `prior_phase8_bundle.zip`, `phase8_weyl_cycle.py`, `phase6_exact.py`: prior research and source dependencies.

Run `python verify_all.py` from this directory. Requires Python 3.10+; no third-party packages.

**Claims:** exact output on promised special inputs; one-sided error only in membership detection outside the promise. For an arbitrary input, fallback to conventional FFT/NTT means worst-case O(NlogN). Finite-time operation counts do not beat radix-2 on the measured instances, and no real floating-point or bit-complexity speedup is asserted.
