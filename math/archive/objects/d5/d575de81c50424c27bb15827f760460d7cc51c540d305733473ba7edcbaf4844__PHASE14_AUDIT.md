## 2. Exact mixed Green inverse and zero pivots

Let N≥2, ω have exact order N, `S e_j=e_(j+1)`, `T e_j=ω^j e_j`, so TS=ωST. The field must contain ω and have characteristic not dividing N. For signs ε,δ∈{±1}, put `W=αS^ε+βT^δ`. Since `q=ω^(εδ)` is primitive, every intermediate Nth Gaussian binomial coefficient vanishes, while denominators `1−q^j`, 0<j<N, are nonzero. Therefore

`W^N=(α^N+β^N)I`,
`(I−W)^−1=Δ^−1 Σ_(k<N) W^k`, `Δ=1−α^N−β^N`.

The cyclic-bidiagonal determinant is also exactly Δ: only the diagonal and full-cycle permutations contribute. Thus Δ≠0 is both necessary and sufficient.

Relabel physical indices i=εj. Then the solve is `d_j z_j−αz_(j−1)=u_j`, `d_j=1−βq^j`. If α≠0, a backward affine sweep obtains `z0=A z_(N−1)+B`, where `A=Π_(j=1)^(N−1)(d_j/α)`. Closing the j=0 equation gives

`z_(N−1)=(u0−d0 B)/(d0 A−α)`.

The closure denominator multiplied by α^(N−1) equals Δ. A second backward sweep recovers all coordinates. No individual d_j is divided by; β^N=1 and a zero local diagonal are harmless when Δ≠0. For α=0, Δ≠0 ensures every d_j is nonzero, and one batch inversion prepares the diagonal solve.

For supplied primitive ω, preparation and each full input application take O(N) field/address work and O(N) storage. Root powers advance multiplicatively. Root discovery, field construction, bit cost and numerical conditioning are separate. The source root helper uses trial primality testing, factorization and candidate search, and is not part of the O(N) claim. Prepared plans require their original N, field, root, signs and parameters.

## 3. Signed Weyl support and the even obstruction

Canonical Weyl coefficients are extracted by `C_A[a,b]=N^−1Σ_j ω^(−bj)A[j+a,j]`. The quantum-binomial polynomial shows support inside

`T_(εδ)={(εa,δb) mod N: a,b≥0, a+b<N}`.

All Gaussian coefficients with top index below N are nonzero. Over C, varying α,β on the open nonsingular parameter set spans every monomial in the triangle: a linear functional annihilating all these resolvents would, after multiplying by Δ, annihilate an ordinary bivariate polynomial identically, hence every coefficient. This is an existential linear-span result, not a cheap coefficient-synthesis algorithm. It is not automatically a statement about every finite parameter field.

The union of all four triangles is all N² positions for odd N. For even N it omits exactly `(N/2,N/2)`, giving span dimension N²−1. For odd N, each orientation has an exclusive witness at the corresponding signed `(1,1)` position; the odd Fourier Weyl coefficients are all nonzero, so deleting any one family prevents representing F in this grammar.

For even N, the central Fourier coefficient is `G(ω)/N`, `G=Σ_jω^(j²)`. If N≡2 mod4, pairing j with j+N/2 cancels it. If 4|N, the two-to-one map `(x,y)→(x−y,x+y)` on equal-parity pairs gives `G(ω)G(ω^−1)=2N`, so it is nonzero (characteristic must not divide 2N). Consequently over C, F belongs to the four-family span exactly when 4 does not divide N. When 4|N, no finite scalar sum of these four ungauged families equals F.

Endpoint Weyl shifts, other generators or products can populate the missing position. The theorem cannot exclude those larger grammars. Finite sampled span ranks support the proof but do not prove complex existence or a fast implementation by themselves.

## 4. Required odd-length cut repair

The source defines m=floor(N/2), L={0,...,m−1}, R={N−m,...,N−1}. At odd N these do not form a partition. Its displayed two-block product formula omits the middle-coordinate contribution.

Explicit counterexample, valid over any field: N=3, `A=I+e2 e1^T`, `B=I+e1 e0^T`. Both separated cross blocks of A and B are zero, but `(AB)[2,0]=1`. Therefore the stated inequality `ρ(AB)≤ρ(A)+ρ(B)` for these separated blocks is false.

Repair: use the actual partition `L={0,...,m−1}`, `R'={m,...,N−1}`, including the middle coordinate on the right. Define the maximum of the two rectangular cross ranks on this partition. Every nearest-neighbor signed magnetic Green has both ranks at most one. The Green-kernel product formulas separate across any such contiguous cut, including zero diagonal pivots, with no division by those pivots. Diagonal matrices have cross rank zero, and true two-block multiplication gives subadditivity. The Fourier cross blocks have rank m: each contains a square consecutive-exponent Vandermonde minor on distinct roots. Thus a sum of paths with L_b Green stages still requires

`Σ_b L_b≥floor(N/2)`.

The source code's `both_cut_ranks` already uses this genuine partition, while portions of the prose and supporting audit use separated equal-size blocks. The corrected proof also bounds those smaller subblocks by inclusion. Arbitrary diagonal gauges, even singular ones, are allowed; arbitrary long-range permutations/strides or a shared-DAG arithmetic lower bound are not. The repaired theorem is accepted; the false general lemma is retained as a documented source defect.

## 5. N-way fusion and long-range escape

Conjugation averaging by T kills nonzero S exponents, and averaging by S kills nonzero T exponents. Hence, with H=(I−αS−βT)^−1,

`E_T(H)=Δ^−1Σ_(b<N)β^bT^b`,
`E_S(H)=Δ^−1Σ_(a<N)α^aS^a`.

When β^N≠1 or α^N≠1 these are scaled one-direction Green operators. If β^N=1, the first is a single-coordinate selector found by an O(N) root scan; it does not require a discrete logarithm. If α^N=1, the second is an explicit rank-one outer product of geometric sequences, applied by one weighted sum and N output writes. Thus both N-branch averages have O(N) shared evaluators even at these degenerate one-direction poles, provided Δ≠0. Literal branch count alone cannot imply quadratic work.

For even N=2M, `(I−αS^M)^−1=(I+αS^M)/(1−α²)` has balanced cross rank M whenever α≠0 and α²≠1, yet applies in O(N). General stride s decomposes into gcd(N,s) cycles; each is solved by the same backward affine method, and closure denominators can be batch-inverted. The source's strided mixed-diagonal implementation correctly checks each cycle separately rather than applying the nearest-neighbor Δ identity to a noncoprime stride.

In the pure-shift case the guard is `α^(N/gcd(N,s))≠1`. Our inherited resonance countercontrol N=8, F97, α=64, s=2 is accepted: α^8=1 but α^4=−1, so no cycle pole exists. This avoids the false α^N-based guard found in an earlier source family. Zero stride reduces to independent scalar coordinates and is included in the controls.

`assert den * pow_count(alpha,N−1,...) % p == discriminant`.

The array counters omit preparation allocations/writes, coefficient-table reads and several other accesses. They are selected vector-access instrumentation, not a complete traffic census. Static inspection still establishes O(N) actual memory work and storage; no precise universal byte-traffic figure is accepted.

The naive same-operator polynomial count `4N²+N` describes a particular already-prepared loop with its final unused W update included. Its root/discriminant setup is separate; it is not a complete cold comparison or an optimal alternative. The linear recurrence is a valid improvement over that literal polynomial evaluator for the same Green operator. It is not a comparison of equal-output FFT algorithms. No precision or bit-linear conclusion follows.
