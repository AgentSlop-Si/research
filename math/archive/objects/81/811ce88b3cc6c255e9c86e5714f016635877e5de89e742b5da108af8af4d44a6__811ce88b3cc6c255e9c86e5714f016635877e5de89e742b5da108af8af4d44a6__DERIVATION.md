# Sparse Fourier surrogates: a corrected end-to-end planner and quantitative head/tail tradeoffs

**Date:** 2026-10-09. **Scope:** a mathematical extension based on static inspection of `SPARSE_SURROGATE_V2_RESEARCH.md`, `sparse_surrogate.py`, and the sparse-input transform in `hybrid_sparse.py`. No supplied program was executed. The algorithms below are proposed corrections, not claims that the current Python implementation already implements them. No novelty or exact-FFT breakthrough is claimed.

## 1. Statement, normalization, and computational model

Let N be a power of two, U=F_N/√N the unitary DFT, and x∈ℂ^N a fresh input. For x≠0, define L=‖x‖₁ and sorted normalized magnitudes p₁≥⋯≥p_m>0, where p_j=|x|_(j)/L and m=‖x‖₀. Let

ρ_s=1−∑_{j≤s}p_j=‖r_s‖₁/L,    0≤s≤m,

where h_s preserves the s largest coordinates and r_s=x−h_s. Ties use a fixed index order. Fix 0<ε,δ<1 and put

Λ=log(4N/δ),    C=4Λ/ε².

The requested guarantee is

Pr[‖U y−U x‖∞≤ε L/√N]≥1−δ.

This is a normalized additive error guarantee. It is not uniform relative error in individual Fourier coefficients, and it is not the stronger error ε‖x‖₂/√N.

**Model.** Bounds below count arithmetic and comparisons in an ideal real/complex RAM, with unit-cost magnitude, square root, division, floor/index operations, and independent exact continuous uniforms. Roots of unity are available constants, or a length-N root table is generated from one available primitive root in O(N) arithmetic. All length-dependent setup, input scanning, selection, sampling setup, coalescing, working arrays, and all N output writes are charged. This is not a bit-complexity, random-bit-complexity, or floating-point stability theorem. In an implementation, approximated sampling probabilities and FFT roundoff require an additional error analysis/budget.

The zero input is detected in the initial scan and returns N zeros in O(N).

## 2. Three certified choices for a head

For 0≤s≤m define

k_s = 0,                         if ρ_s≤ε;
      ⌈Cρ_s²⌉,                   if ρ_s>ε.

A head-only plan uses y=h_s when k_s=0. Otherwise sample k_s independent tail indices with probabilities |r_s(j)|/(Lρ_s), and set

y=h_s+(Lρ_s/k_s)∑_{t=1}^{k_s}phase(r_s(J_t))e_{J_t}.

After coalescing repeated indices, support is at most s+k_s. If s+k_s≥m, retain x itself instead: the exact-input bypass has support m and no random draws. Thus the certified support objective is

B_s=min{m,s+k_s}.

The number of nonzero head entries is s, because head choices are restricted to s≤m. The actual support q can be smaller than B_s through repeated sampled locations. Exact bypass and deterministic head-only plans are both valid independently of δ. Report requested samples, actual draws, support upper bound, and realized support as separate quantities.

### Proof of the error guarantee

For a fixed Fourier bin, multiply each sampled contribution by √N/(Lρ_s). It becomes a complex random variable Z of modulus one. Its sample mean minus its expectation is the normalized bin error. A real or imaginary part lies in [−1,1]. Hoeffding's inequality applied to each part with threshold t/√2 yields

Pr[|mean(Z)−E Z|>t]≤4 exp(−k_s t²/4).

Take t=ε/ρ_s and union-bound over N bins. The failure probability is at most

4N exp(−k_s ε²/(4ρ_s²))≤δ.

For head-only plans, ‖Ur_s‖∞≤‖r_s‖₁/√N≤εL/√N deterministically. For the exact bypass, y=x.

Selection of s from x does not require a union bound over candidate heads: the planner is deterministic given x and runs before fresh sampling. The sampling theorem applies to its chosen residual. Selecting a plan after observing the same random errors would require a different argument.

## 3. One selection replaces repeated whole-input planning

Let

H=min{m,⌈(log₂(max{2,N}))²⌉}.

A general user-specified cap 0≤H≤m can also be used.

1. Scan the input once for L, m, magnitudes, and indices: O(N).
2. Select the H largest nonzero coordinates once. A deterministic linear-time selection algorithm gives O(N) worst-case comparisons; a conventional randomized quickselect gives expected O(N), which must be labelled expected. Do not infer this guarantee for every library partition routine.
3. Sort just those H entries by decreasing magnitude with fixed tie-breaking: O(H log(H+2)).
4. Form their prefix sums: O(H). These determine every ρ_s for 0≤s≤H without any further selection or whole-vector norm calculation.
5. Evaluate candidate B_s and choose the smallest, with ties broken by fewer random draws and then smaller head size. Store the sorted head indices and reuse them during construction; do not run selection again.

For a geometric planner use

G={0,1,2,4,…≤H}∪{H},

with duplicates removed. Candidate evaluation costs O(log(H+2)). The complete planner costs

O(N+H log(H+2)),

not O(N log log N). With the default H, the extra sorting is O((log N)² log log N)=o(N), so the complete planner is O(N) asymptotically.

### A factor-two guarantee, including the deterministic discontinuity

For every integer 0≤s≤H, let g be the least candidate in G with g≥s. For s=0, g=0. For s≥1, g≤2s. Residual masses decrease with s, and the complete piecewise definition of k_s is nonincreasing, including the jump to zero at ρ_s=ε. Therefore

g+k_g≤2s+k_s≤2(s+k_s),

and hence B_g≤2B_s. Consequently the geometric planner satisfies

B_selected≤2 min_{0≤s≤H} B_s.

This approximates the **certified support objective within the head cap**, not the smallest possible support of any Fourier approximant and not the exact wall-clock runtime. Upward rounding is essential to this proof. A downward-rounded head might miss the deterministic cutoff and suddenly require approximately 4Λ samples.

The first deterministic head s_det=min{s≤H:ρ_s≤ε}, if it exists, is available from the prefix sums. Adding this exact threshold to G removes any rounding loss for the best head-only plan.

### Stronger option at the same asymptotic preprocessing cost

Evaluate **every** prefix s=0,…,H instead of only G. This costs O(H), which is already within the prefix construction/sorting budget. It finds the exact minimizer of B_s within the cap, handles all discontinuities automatically, and avoids any grid approximation. For H≈(log N)² there is no asymptotic reason to prefer the geometric grid; it merely uses fewer constant-time objective evaluations.

## 4. Charge sampling and the full transform

After selecting a plan, mark the chosen head in O(N+H) total space/time and scan the residual once.

One simple rigorous implementation of the sampling step is to generate k uniforms, sort them, and merge them with the tail's cumulative mass in one scan. This samples exactly the intended iid multiset; sorting changes only its order. Equal resulting indices are already adjacent and can be coalesced during the merge. The time is O(N+k log(k+2)), with no hash-table assumption. An ideal-RAM alias table gives another O(N+k) option, but is unnecessary for the stated bound.

Crucially, perform the exact-support bypass **before** drawing samples. On every sampled path, s+k<m≤N, so k≤B_selected≤N. Do not draw a huge sample budget and only afterward decide to use a full FFT.

For realized support q, choose the smallest power of two b≥max{1,q}; then b≤N and b<2 max{1,q}. The sparse-input full-output decomposition has m'=N/b rows, O(m'q) sparse contributions, and m' ordinary length-b FFTs. Its work is

O(N+m'q+N log b)=O(N log(q+2)).

Root-table setup and dense output allocation cost O(N), already included. Intermediate storage is O(N). Putting everything together gives the deterministic operation upper bound (apart from expected selection if that option is chosen)

T=O(N+H log(H+2)+k log(k+2)+N log(q+2))
 ≤O(N+H log(H+2)+N log(B_selected+2)).

With the default cap this is O(N log(B_selected+2)). In particular a constant certified support really gives O(N) **end to end**. Do not replace B_selected by realized q in the final simplified bound without separately charging the draws that may have coalesced.

Since s=0 is a candidate, B_selected≤min{m,⌈C⌉}, so the corrected worst-case bound is

T=O(N[1+min{log N,log(1/ε)+log log(4N/δ)}]).

The additive 1 avoids degenerate small-parameter notation; the minimum records the exact fallback. This is an arithmetic approximation result, not an exact dense-DFT improvement.

## 5. Compressibility must be normalized uniformly

Statements about a sequence x^(N) require constants uniform in N. An unnormalized upper envelope alone is insufficient: any dense flat vector can be scaled down enough to fit |x|_(j)≤A exp(−cj) at a given N without acquiring a small normalized tail. Use a condition on p_j=|x|_(j)/‖x‖₁, or explicitly assume a compatible lower bound on ‖x‖₁.

### Exponential normalized decay

Suppose p_j≤A exp(−cj), with A,c>0 independent of N. Then

ρ_s≤D exp(−cs),    D=A exp(−c)/(1−exp(−c)).

Thus a deterministic head of at most max{0,⌈log(D/ε)/c⌉} entries suffices, capped at m. If this bound lies within H, the corrected planner achieves

T=O(N log(2+log(1/ε)))

for fixed A,c (with the obvious constant adjustment when D<1). Hence fixed ε gives O(N), and ε_N=(log N)^−a gives O(N log log log N), interpreted with bounded-below logarithms for small N. These faster conclusions depend on removing repeated O(N) planning passes.

### Normalized power-law decay

Suppose p_j≤A j^−α, with fixed α>1 and A independent of N. Write β=α−1 and D=A/β. For s≥1, an integral tail bound gives

ρ_s≤D s^−β.

The always-feasible randomized certificate is bounded by

B_s≤min{m, s+⌈C D²s^−2β⌉}.

It remains an upper bound if the actual planner switches to zero samples. A sufficient deterministic head size is

s_D=⌈(D/ε)^(1/β)⌉,

when s_D≤H; if this exceeds m, retaining all m entries is exact.

For the continuous randomized surrogate objective f(s)=s+C D²s^−2β, its unconstrained minimum occurs at

s_R=(2β C D²)^(1/(2β+1)),

with

f(s_R)=(1+1/(2β))s_R.

At this optimizer the randomized term is s_R/(2β): this explicitly quantifies the balancing point between head support and tail samples. For a cap H≥1, clamp s_R into [1,H], then test the neighboring integer(s), the boundary, s=0, and s_D when feasible. This gives a valid quantitative certificate; the full-prefix planner can only improve it.

If the relevant heads fit the cap, the useful support upper bound for fixed α,A is

B=O(min{m, ε^−1/(α−1), (ε^−2Λ)^(1/(2α−1))}).

Do not use the deterministic term when its head is outside H, or the unconstrained randomized term when its balancing head is outside H. The fallback m is always available. A one-sided decay envelope gives upper bounds only; it does not prove this scaling necessary for an arbitrary input under that envelope.

## 6. A two-sided example and an explicit accuracy crossover

For the exact normalized family

p_j=j^−α / ∑_{i=1}^N i^−α,

with arbitrary complex phases and fixed α>1, the tail satisfies, for 1≤s≤N/2,

[2^−α/ζ(α)] s^−β ≤ρ_s≤(1/β)s^−β.

The lower bound follows by summing the s entries j=s+1,…,2s; the upper bound follows by integration and ∑i^−α≥1. Thus in this range the randomized certificate is Θ(s+C s^−2β), and its balanced support scale is Θ(C^(1/(2β+1))).

For unrestricted heads 0≤s≤N, the **minimum certified objective defined here**, including the deterministic branch and the exact fallback, obeys

min_s B_s=Θ(min{N, ε^−1/β, (ε^−2Λ)^(1/(2β+1))}),

with constants depending only on α. To see the lower bound, a deterministic head s≤N/2 needs s=Ω(ε^−1/β); a sampled head s≤N/2 has s+k_s=Ω(C^(1/(2β+1))) by minimizing its two-sided lower envelope (s=0 costs ⌈C⌉); and s>N/2 or the exact bypass costs Ω(N). The upper bound comes from the sufficient deterministic head, a rounded balancing head, or retaining all N entries. This is optimality of this certificate family, not a lower bound on arbitrary surrogate algorithms.

The default capped planner inherits that order whenever a witnessing non-dense head fits within H; otherwise use the constrained formulas above.

Comparing the two non-dense support scales reveals a useful crossover:

- ε roughly at least Λ^−β: deterministic truncation has the better order;
- ε roughly below Λ^−β: retaining a head and sampling its residual has the better order.

For δ=N^−b and ε=(log N)^−a, the two support exponents are

u_D=a/(α−1),    u_R=(2a+1)/(2α−1).

Their crossover is a=α−1. Sampling improves the support exponent in the high-accuracy regime a>α−1. With H≈(log N)², a sufficient asymptotic cap condition is min{u_D,u_R}<2; equality needs attention to constants, and exponents above 2 require the constrained-head analysis or a larger cap. Both polylogarithmic support choices still give O(N log log N), so a support improvement need not change the transform's big-O class.

## 7. What actually vanishes?

For a sequence x^(N), the conclusion is

error_N≤ε_N‖x^(N)‖₁/√N.

If ε_N→0, the **normalized bound** error_N/(‖x^(N)‖₁/√N) tends to zero on the success event. Absolute error is guaranteed to tend to zero only when

ε_N‖x^(N)‖₁/√N→0.

Examples:

- If ‖x^(N)‖₂ is uniformly bounded, then ‖x^(N)‖₁/√N≤‖x^(N)‖₂, so ε_N→0 suffices.
- If x^(N)=(1,…,1), the bound is ε_N√N. Polylogarithmic ε_N and ε_N=exp(−(log N)^γ), 0<γ<1, do not make this absolute bound vanish.
- If normalized exponential compressibility also comes with ‖x^(N)‖₁=O(1), even fixed ε gives an absolute O(N^−1/2) bound.

Failure probabilities δ_N→0 give the corresponding statements in probability. An almost-sure eventual guarantee across a coupled sequence of runs follows from summability ∑δ_N<∞ by the first Borel–Cantelli lemma; independence across runs is unnecessary. Specify the index set: along N=2^n, δ_N=N^−b is summable for every b>0, whereas over every integer N it requires b>1.

## 8. Implementation changes this derivation requires

The inspected code does not yet implement the stronger planner. A minimal correction would:

1. Validate ε,δ even on zero/exact-return paths; bind a supplied plan to the actual input and requested parameters, not merely its length.
2. Compute magnitudes, L, and m once; select/sort one top-H set; cache prefix sums and selected indices.
3. Evaluate all prefixes, or the upward-rounded geometric grid plus the deterministic threshold; use the complete piecewise k_s.
4. Choose exact bypass before sampling, distinguishing zero draws from copied nonzeros in plan metadata.
5. Charge coalescing and sampling explicitly; avoid reporting an operation proxy as a measured wall-clock speedup.
6. Keep finite-precision probability/roundoff guarantees separate from this exact-arithmetic theorem.

The central corrected claim is therefore: **a single O(N) preprocessing pass plus one polylogarithmic head sort makes the compressibility-dependent transform bounds genuinely end to end, and the resulting prefix planner can optimize the complete certified support objective exactly within its cap.**
