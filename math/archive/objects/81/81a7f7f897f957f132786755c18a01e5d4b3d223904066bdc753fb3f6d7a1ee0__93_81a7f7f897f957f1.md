# Sampling plus pruned FFT: a faster baseline for v4's second point

9 October 2026. This is an explicit deduction from standard FFT pruning and the same signed-atom sampler, not a novelty claim. Restrict the comparison to N=2^d.

## Arithmetic comparator

After k samples, coalesce the signed atoms into at most k nonzero integer coordinate counts. Compute their full DFT, then divide by k and apply the input-mass/unitary scale. A radix-two FFT can exploit that input support.

At stage s, one initial nonzero can structurally reach at most 2^s wires. Thus the number of active wires is at most min(N,k 2^s), irrespective of any numerical cancellation. Summing over d stages gives

    sum_(s=0)^d min(N,k 2^s) = O(N(1+log k)).

This bound can be achieved without scanning N slots at each sparse stage. Keep a list of active wire indices, use direct-address generation stamps to enumerate each reached butterfly once, and append its two output indices. Two value arrays and timestamp arrays avoid clearing full arrays at every stage. Initialize those arrays once in O(N), and bit-reverse only the k sampled coordinates in O(k log N)=polylog(N). Every listed wire/butterfly costs O(1) operations. Explicit final output writing costs O(N).

The selected-output counterpart is described by Woolfe, Liberty, Rokhlin, and Tygert, *A fast randomized algorithm for the approximation of matrices*, ACHA 25 (2008), Section 3.3, pages 341–342. Transposing that linear circuit gives sparse-input/all-output arithmetic. The active-wire argument above is a direct independent explanation of the same cost bound. [Author PDF](https://tygert.com/frand.pdf)

## Bounded-word and uniform-preprocessing completion

The cited arithmetic result alone does not settle finite-word costs. Here the sampled input values are signed counts of absolute total at most k=polylog(N), so every exact FFT intermediate has magnitude at most k. This yields a simple conservative fixed-point simulation.

Choose a dyadic component rounding unit tau <= eta/(10^6 N^6), where eta^(-1)=polylog(N). Approximate the primitive root exp(-2pi i/N) to component error at most tau, using uniformly generated pi and elementary convergent series with polynomial-in-log(N) work. Generate all N powers by repeated complex multiplication and rounding to the same grid. The elementary recurrence bounds every twiddle's error by O(N tau), and its magnitude by 1+O(N tau). This construction uses O(N) fixed-word operations and O(N) words, including every stored root.

Let E_s bound the absolute error of a computed FFT intermediate at stage s. A butterfly gives, conservatively,

    E_(s+1) <= 3 E_s + O(k N tau + tau).

There are d=log2 N stages and 3^d<N^2, so E_d=O(k N^3 tau). After dividing by k this is O(N^3 tau), well below eta. The constants and precision above are intentionally excessive; they make the error budget easy to satisfy. Arithmetic operands, rounded products, loop indices, and timestamps require O(log N+log(1/eta)+log k)=O(log N) bits, with a sufficiently large fixed constant in the RAM word size. Each fixed-point multiply/round therefore costs O(1) in the same bounded-word model. Dividing by k and output mass/unitary normalization use the same charged bounded-word techniques as the main proof.

The total preprocessing here is O(N), rather than v4's o(N) input-independent table build. It is fully charged and does not change the O(N(1+log k)) total time. Exact mass sampling and its capped-rejection failure budget also remain O(N+polylog N).

## Consequence for the two displayed tradeoffs

For error factor eta and polynomial failure probability, the same sampler takes k=Theta(log N/eta^2). Both v4 sample counts are polylogarithmic, so the pruned baseline costs O(N loglog N):

- At eta=Theta(loglog N/sqrt(log N)), v4 improves this baseline to O(N) in the stated word model.
- At eta=Theta((loglog N)^(3/2)/log N), the pruned baseline's O(N loglog N) is asymptotically faster than v4's O(N log N/loglog N).

The second v4 point remains a valid parameter setting of its table evaluator. It should not be positioned as a generally superior time/accuracy frontier, even for FFT-friendly lengths. No unrestricted-N reduction is claimed: merely padding a signal to the next power of two changes the DFT being requested.

This comparison does not improve the norm guarantee itself. Both methods retain the same input-mass-scaled coordinatewise error and the same random-sign zero-output caveat.
