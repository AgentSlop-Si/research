INDEPENDENT SOURCE AUDIT: THIN MATRIX TOTAL ARITHMETIC
9 October 2026

RESULT
Published sources explicitly support total O(n^2) operations for n-by-log n times log n-by-n. This is a substantive lead, not merely an inference from a multiplication-count abstract. However, this bounded audit did not find an independently checkable addition-count construction or a correction withdrawing Chan's statement. Accordingly: source-backed claim, unresolved construction audit, no verified new algorithm.

POSITIVE EVIDENCE
1. Chan, Speeding up the Four Russians Algorithm by About One More Logarithmic Factor, 2014, PDF p5, Final Remarks: explicitly gives O(n^2) operations for n-by-log n times log n-by-n and cites Brockett--Dobkin 1976. No construction/addition count is provided.
https://tmc.web.engr.illinois.edu/bmm9_14.pdf

2. Nissim--Schwartzman, Revisiting Rapid multiplication of rectangular matrices, 2024, introduction: explicitly says Theta(n^2)+o(n^2) arithmetic operations, citing Brockett--Dobkin. This is for the permuted n-by-n times n-by-log n orientation; do not transfer the precise statement without a justified model conversion.
https://www.tandfonline.com/doi/full/10.1080/27684830.2024.2388334

3. Reif's Duke lecture slides, slide numbered 32, indexed text: says time n^2+o(n^2), m=O(log n), for n-by-m times m-by-n. Corroborative summary, no proof. Direct PDF open returned 403, so only indexed text was inspected.
https://courses.cs.duke.edu/fall05/cps130/lectures/reif.lectures/ALG3.1.pdf

MODEL CAVEATS
- Original Brockett--Dobkin abstract counts multiplications and requires multiplication/division by 2. Complex arithmetic satisfies this necessary field condition; characteristic 2 does not support these formulas directly. Additional field and uniformity requirements were not independently verified.
https://epubs.siam.org/doi/10.1137/0205041
- Coppersmith 1982, final page, restates the B--D result only as Rank((N,N,log N))=N^2+o(N^2). His introduction defines rank as essential multiplications; this gives no independent addition bound.
https://people.csail.mit.edu/virgi/6.890/papers/copper-rect1.pdf
- Laderman 1976, p128, attributes a commutative 23-product 3x3 algorithm to the same B--D paper, excluding multiply/divide2. This verifies commutativity is relevant to a construction in that paper, but not the precise model of every theorem.
https://www.ams.org/journals/bull/1976-82-01/S0002-9904-1976-13988-2/S0002-9904-1976-13988-2.pdf
- Ja'Ja' 1980 proves that exact multiplicative duality fails for commutative algorithms. Hence a precise product-count statement must not be permuted as tensor rank without conversion. A constant-factor conversion may preserve big-O; this caveat does not refute O(n^2).
https://epubs.siam.org/doi/10.1137/0209056
- Lipton's 2009 post mentions O(n) n-by-log n matrix-vector multiplication without a model, alphabet restriction, preprocessing allowance, or construction. It is too underspecified to resolve this question.
https://rjlipton.com/2009/06/18/high-dimensional-search-and-the-nn-problem/

CONDITIONAL SPARSE-EXPANSION COROLLARY
Assume a uniform exact algorithm over C multiplies arbitrary n-by-p and p-by-n matrices in O(n^2) TOTAL arithmetic for p<=c log n, with an absolute c>0 and constants independent of n. Let k<=C log N, n=ceil(sqrt N), and pad the output index range to n^2. Set
  U[r,s]=z_s^r,
  W[s,b]=a_s(z_s^n)^b,
  0<=r,b<n.
Then (UW)[r,b]=f_(r+bn). Split the k inner coordinates into O(1) groups of size <=c log n. Each group has exactly the ORIGINAL n-by-p times p-by-n orientation; no tensor permutation is needed. Consecutive power tables require O(kn)=o(N) field operations. O(1) thin products, their summation, and output writes require O(N). Thus all N exact values cost O(N) under the hypothesis. Distinctness and roots-of-unity structure are unnecessary for this reduction.

If the total-operation hypothesis is established, this is a consequence of classical prior art, not a newly verified FFT algorithm. Neither failure to retrieve the proof nor the multiplication-only original abstract establishes that the claim is false.
