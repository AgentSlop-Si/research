# The old norm obstruction STILL blocks bare expander-Green stage products; Haar is a non-rank-one control

**This is a correction to any over-optimistic interpretation of the all-cut rank theorem, not a claimed FFT advance.** The user's prior `fft_global_green_gauge/RESULTS_SUMMARY.md` already established the general induced-1-condition budget. We apply it to the newly robust random-path family and demonstrate why high cut rank and high condition budget are distinct requirements.

## No-go: bounded 1-condition even for globally mixing expander stages

For `T=3I-A_path`, `G=T^-1=(1/3)sum_{k>=0}(A_path/3)^k` is nonnegative and has `||G||_1<=1` (because `||A_path||_1<=2`). Also `||T||_1<=5`. For any permutation P and `epsilon=1/100`, define `M=G+epsilon P G P^T`. Then

```
||M||_1 <= 1+epsilon = 101/100.
M=G (I+epsilon T P G P^T).
||epsilon T P G P^T||_1 <= 5epsilon =1/20.
||M^-1||_1 <= 5/(1-1/20) =100/19.
kappa_1(M) <= (101/100)*(100/19) = 101/19 < 5.316.
```

The exact Fourier matrix and its normalized version have `kappa_1(F_N)=N`. In any exact factorization of the Fourier matrix (up to a single overall scalar) into t stages drawn from this `M` family, with **arbitrary between-stage permutations and unit-modulus phase diagonals**, 1-condition submultiplicativity gives

```
N <= product_j kappa_1(M_j) <= (101/19)^t,
t >= log_(101/19)(N) = Omega(log N).
```

Therefore, despite the new linear-rank robust-mixing theorem, **a sublogarithmic number of the bare expander-Green stages cannot be an exact DFT** in this restricted factorization. The same conclusion holds under one overall scalar normalization. Arbitrary non-unit diagonal gains or other high-condition O(N) stages escape this PARTICULAR inequality, but require new work accounting, analysis and a proof that they do something other than telescope.

## An O(N)-work multiresolution control with growing 1-condition

The orthonormal discrete Haar transform `W_N` for `N=2^k` computes at each scale pairwise sums and differences divided by sqrt(2), recursively continuing ONLY the average branch. It retains all detail coefficients, so the total number of two-point butterflies is

```
N/2 + N/4 + ... + 1 = N-1.
```

Thus W is orthogonal (`kappa_2(W)=1`) and applies in O(N) arithmetic (plus fixed 1/sqrt(2) scalar). Its first output is the global average with a row of N entries `1/sqrt(N)`, hence `||W^-1||_1=||W||_infinity=sqrt(N)`. Every column of W has norm 2 equal to 1, so `||W||_1>=1`. On the other hand each column contains one coefficient per dyadic level of magnitudes `2^{-h/2}`, giving `||W||_1<=1/(sqrt(2)-1)+1` uniformly. Therefore

```
kappa_1(W_N) = Theta(sqrt N), kappa_2(W_N)=1.
```

For the O(N)-apply combined stage `S_N=W_N M_N`, submultiplicativity gives

```
kappa_1(W_N) = kappa_1(S_N M_N^-1)
              <= kappa_1(S_N) kappa_1(M_N),
kappa_1(S_N) >= (19/101) sqrt(N).
kappa_2(S_N)=kappa_2(M_N)<=5.
```

This is a **fully charged O(N)**, bounded-spectral-condition primitive with growing induced-1-condition that is NOT merely a rank-one Householder update. A Haar transform has N-1 nontrivial multiscale butterflies and exposes O(N) independent detail coefficients. The finite code checks `rank(W-I)` scales with N. But it is a **known classical transform**, and its use here is only a *structural control*: any proposed factorization must prove that the W factors are not merely canceled gauges. In particular, growing 1-condition does not mean it computes Fourier phases, and the robust every-order cross-cut theorem for M is **not automatically inherited by W M**.

## New exact research question

Can a sequence of multiscale/wavelet *and* graph-Green stages exploit the large 1-condition without just telescoping wavelet matrices, and exactly implement the Fourier shift/modulation intertwining relations? Neither a numerical condition-number gap nor a large cut-rank gap is sufficient to answer that. A uniform exact all-N identity and a fully charged `o(N log N)` cost remain missing.
