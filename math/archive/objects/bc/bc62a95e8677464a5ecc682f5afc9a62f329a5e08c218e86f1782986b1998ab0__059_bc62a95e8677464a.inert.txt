# Exact Fourier reduction to one reusable fixed kernel

This package isolates a concrete algebraic target for the fresh-input, full-output
exact FFT goal. It does **not** provide an algorithm faster than N log N. The
reference evaluator is deliberately quadratic so that no FFT is hidden inside
the proposed improvement. It uses a known q-Pascal factorization, specializes its
preparation to roots of unity, and audits a possible streaming shortcut.

## Exact factorization

Let N be a power of two, q a primitive Nth root in a field whose characteristic
does not divide N, and F[i,j] = q^(ij), with zero-based indices. Define

    f[0] = 1
    f[j] = product_(r=1..j) (1-q^r)
    t[j] = 1/f[j]
    d[j] = (-1)^j q^(j(j-1)/2) / f[j]
    S = diag(f[j])
    T[i,j] = t[i-j] if i >= j, else 0.

Then the full matrix identity is

    F = S T diag(d) T^transpose S.

This is the q-binomial LDL^T factorization: L[i,j] =
f[i]/(f[j] f[i-j]), and its D diagonal is
(-1)^j q^(j(j-1)/2) f[j]. It is already in the literature [1], including its
connection to the discrete Fourier transform. We do not claim this factorization
or the reduction of Fourier transform to convolution as new; Bluestein is another
classical fixed-convolution reduction [2].

The identity follows coefficientwise from the finite q-binomial identity

    q^(ij) = sum_(k=0..min(i,j))
      (-1)^k q^(k(k-1)/2) f[i] f[j] / (f[k] f[i-k] f[j-k]).

It is a rational identity in q. Its denominators remain nonzero at a primitive
Nth root for all indices in this package, since every factor has exponent below N.
The same identity therefore holds over the tested finite fields as well as over
the complex cyclotomic field. No numerical approximation is used.

The two triangular actions use exactly the same immutable length-N kernel t.
T^transpose x = reverse(T reverse(x)); thus all N independent input variables
and all N outputs are retained. This is a graph-reuse opportunity for constants,
not a cache of answers for previously seen inputs.

## Preparation and full costs

The root is part of the input specification. Root search is not hidden in the
following scalar-preparation count. From

    product_(r=1..N-1) (1-q^r) = N

we obtain all inverse factorials using suffix products divided by N. Prefix
products, suffix products, powers, and the chirp recurrence generate every
constant in O(N) exact field operations and O(N) field elements. For N = 2^L,
1/N is generated by L multiplications by the fixed scalar 1/2. The implementation
counts one constant inversion to obtain 1/2; a model providing that scalar can
omit the inversion. There is no input-dependent division.

The implementation deliberately counts even multiplications by 1. Preparation:

- 6N - 4 + log2(N) multiplications;
- N - 1 subtractions and N - 1 negations;
- one constant inversion for 1/2;
- O(N) coefficient storage and traffic.

For any exact truncated-convolution implementation with one-input cost C(N), the
online reduction costs 2 C(N) + O(N), plus its coefficient preparation. Reusing
the same prepared kernel is allowed, but the two input vectors depend on the fresh
input and must both be processed. Standard FFT-based convolution gives O(N log N),
not a new asymptotic improvement. Direct reference evaluation here costs
N^2 + 4N multiplications and N^2 - N additions. Its recorded array traffic includes
N(N+1) kernel reads, N(N+1) convolution-input reads, all diagonal-vector reads and
writes, and 2N reversal copies. Indexing and output materialization are real costs.

All these counts are scalar-field arithmetic counts. This is not a bit complexity
bound, a stability statement, a native performance benchmark, or a claim that
cyclotomic arithmetic on a Turing machine is constant time.

## The tempting short recurrence and why it does not finish the task

Let H(z) = sum_(j=0..N-1) t[j] z^j. Coefficientwise,

    (1-z) H(z) = H(qz) modulo z^N.

The relation follows immediately from (1-q^j)t[j] = t[j-1]. It makes coefficient
generation cheap. It does not by itself make H(z)x(z) cheap for arbitrary x(z):
the right side changes the modulation of the entire input when used as an
operator identity. Iterating m times gives

    H(q^m z) = product_(a=0..m-1)(1-q^a z) H(z) modulo z^N.

At m=N, the product becomes 1-z^N, hence this full-orbit equation is tautological
modulo z^N. At m=N/2, q^m=-1, but the intervening product has degree N/2 and every
coefficient is nonzero: its coefficient of z^k is
(-1)^k q^(k(k-1)/2) f[m]/(f[k]f[m-k]). This does not reduce to a constant number
of shifts. It is not a lower bound on every possible use of the identity.

Also, the coefficients d[j] form the exact truncated-convolution inverse of t[j].
That cancellation is verified, but the two occurrences of T in the Fourier
factorization have a transpose and a nonconstant intervening diagonal. Replacing
their composition by the scalar convolution inverse would be invalid.

## A proved, restricted streaming obstruction

For r >= 1, s >= 0, and s+2r-2 < N, set A[i,j] = t[s+i+j] for 0 <= i,j < r.
Then

    det A = q^(sum_(a=1..r-1) a^2)
            product_(i<j) (q^(s+j)-q^(s+i))
            / product_(i=0..r-1) f[s+i+r-1],

which is nonzero. Proof: multiply row i by f[s+i+r-1]. Column j then evaluates
the polynomial product_(a=j+1..r-1)(1-q^a X) at X=q^(s+i). These polynomials have
distinct descending degrees r-1,...,0. Their leading coefficients and the column
reversal sign leave q^(sum a^2) times a Vandermonde determinant. Distinct evaluation
points and nonzero f factors prove the claim for every admissible N, not merely
the tested sizes.

Consequences with r=N/2:

- The first N coefficients t[j] have no global constant-coefficient linear
  recurrence of order below N/2. Such a recurrence would make the unshifted
  r-by-r Hankel matrix rank deficient.
- In a sequential linear streaming implementation of y=T x that reads each input
  once in order, keeps no readable past-input/output archive except its state,
  and emits future outputs from that state and future inputs, at least N/2 field
  state coordinates are needed at the midpoint. The past-to-future block, after
  reversing its past-input columns, is the shifted Hankel matrix with s=1.
  A state with fewer coordinates cannot transmit that full-rank linear map.

This excludes a short constant-state linear filter. It does **not** prove an
N log N running-time bound, does not prohibit O(N) memory, does not constrain an
unrestricted random-access circuit, and does not exclude a different fast graph.
Generating t[j] via a one-term *variable-coefficient* recurrence is compatible
with this result: coefficient generation is different from filtering arbitrary
independent input samples.

## Precise remaining target

Find a uniform exact circuit for the truncated product

    (sum x[j] z^j) (sum z^j / product_(a=1..j)(1-q^a)) modulo z^N

whose *total* cost, including root-dependent constants, addressing, all outputs,
and any state, is o(N log N) in the chosen model. A genuinely O(N) implementation
would give an O(N) Fourier circuit through the displayed factorization. This is
a reformulation with a specific kernel; no solution to that target is asserted.

## Reproduce and inspect

Run `python run_audit.py` with Python 3 and the standard library. It writes
`results/exact_audit.json`. Complete basis-vector comparisons cover N=2..128
(powers of two) over each of F_65537 and F_998244353, and N=2,4,8,16 over the
exact rational cyclotomic fields. Every case also checks a mixed input, all
q-difference coefficients, the inverse convolution kernel, both midpoint Hankel
determinants, and the operation counts. This is a finite implementation audit
alongside the all-N algebraic proofs above.

`prior_exact_arithmetic.py` is copied unchanged from the existing deferred
correction audit, so the new mechanism does not replace or silently edit it.
