# Fresh exact Fourier transform: global-scan sharing, quasiseparable cut rank, and permutation escape

**Date:** 2026-10-09.  
**Outcome:** An all-length, model-scoped obstruction to replacing the complete fresh FFT by a small number of O(N)-work global prefix-sum passes, including arbitrary endpoint coordinate permutations. Exact executable audits corroborate the algebra. **No new arbitrary-input O(N) FFT and no general N log N lower bound.**

## 0. Problem and originality guard

The target is a fresh arbitrary complex N-vector, N explicit Fourier outputs, no cached previous transform, no precomputed answers, one processor, and fully charged elementary work. Earlier studies rejected exact-subtree collisions, small-field tables transferred to complex values without bit accounting, partial-output dynamic APIs, short recurrence annihilators, compact Galois descriptions, chirp-kernel propagation, nonlinear Boolean reconstruction and single large-integer multiplication. This work **does not redo them**.

We test a different proposed **wide global primitive**: a weighted causal or anti-causal prefix scan. It has N input and N output registers and can share a long sum over the entire array using O(N) arithmetic. A small constant number of such scans might superficially look like a global substitute for butterfly layers. We derive the exact obstacle and examine the effect of coordinate permutations.

The key algebra of rank-bounded offdiagonal submatrices is classical quasiseparable-matrix theory; this report is an application to the specific research question, **not a novelty claim**. See Pernet (2016), *Computing with quasiseparable matrices*, https://arxiv.org/abs/1602.01246 and Pernet–Storjohann (2017), https://arxiv.org/abs/1701.00396. Butterfly factorization work already uses O(log N) global sparse stages for Fourier-like transforms: https://arxiv.org/abs/1502.01379 .

## 1. Exact global scan primitive

A weighted *forward* scan on x has outputs

    y[0] = b[0] x[0]
    y[i] = a[i] y[i−1] + b[i] x[i]   (1≤i<N).

A backward scan uses `y[i] = a[i] y[i+1] + b[i] x[i]` with its final value at i=N−1. Every coefficient `a[i], b[i]` may be arbitrary and input-independent. One full scan requires O(N) scalar arithmetic (or Θ(N) under an implementation that explicitly processes each position). Between scan passes one may use any diagonal scalings (O(N) each). No coordinate permutations are permitted *between* scan passes in the first theorem.

For a cut at s, let L={0,...,s−1}, R={s,...,N−1}. Define `u_s(A)=rank(A[L,R])` and `l_s(A)=rank(A[R,L])`.

- A forward scan is lower triangular: `u_s=0`.
- For all i>=s, the dependence on x_{<s} propagates through the single scalar `y[s−1]`; therefore its lower-left block is an outer product and `l_s<=1`.
- A backward scan is upper triangular: `l_s=0`, `u_s<=1`.
- Diagonal scalings have `u_s=l_s=0`.

These statements also hold if a coefficient is zero (resetting the recurrence).

For product AB,

    (AB)[L,R] = A[L,L] B[L,R] + A[L,R] B[R,R].

Thus `u_s(AB)<=u_s(A)+u_s(B)`; the same argument gives `l_s(AB)<=l_s(A)+l_s(B)`. The algebra holds in any field, without numerical conditioning assumptions.

**Cut budget:** A factorization into f forward scans, b backward scans and arbitrary diagonal scalings obeys `u_s<=b` and `l_s<=f` at **every** cut. Reordering among the individual scans does not change that conclusion.

An O(N)-cost *bidirectional* pass that sums one forward and one backward scan has `u_s<=1,l_s<=1`; t such passes therefore have both ranks <=t. A block with r_f forward and r_b backward independent channels has ranks bounded by r_b and r_f. These are bounds on channels, not a lower bound on all possible shared-arithmetic circuits implementing those channels.

## 2. Natural Fourier layout demands N whole-array scans

Define the **unnormalized** N-point Fourier matrix `F_N[k,j]=omega^(kj)` with `omega` primitive of order N, over C (or a suitable exact field).

For any cut s, `F_N[L,R]` consists of rows k=0,...,s−1 evaluated at distinct nodes `omega^j` for columns j=s,...,N−1. It is a rectangular Vandermonde matrix and has exact rank `min(s,N−s)`; similarly `F_N[R,L]` has that rank (diagonal scalings reduce it to a Vandermonde matrix with consecutive powers).

At the balanced cut s=N/2 (N even), both ranks are N/2. Consequently:

    b >= N/2,    f >= N/2,    f+b >= N.       (Theorem A)

**Scope:** no permutations between global scans. If every full scan is implemented as a Θ(N)-work pass, this architecture costs Ω(N²) total work. This is **not** a universal Ω(N²) circuit lower bound, not a barrier to ordinary FFT butterflies, and not a reason to assume every implementation of a degenerate scan must touch every coordinate.

## 3. Stronger theorem: free initial/final permutations still cannot rescue fixed-layout scans

The following bound holds for *every complex N-point Fourier matrix* and **every** selected row set R and column set C (not necessarily contiguous).

**Theorem B:**

    rank(F_N[R,C]) >= ceil(|R||C|/N).

Proof: normalize `U=F_N/sqrt(N)`, which is unitary. Let `A=U[R,C]`. Every one of the |R||C| entries has magnitude `1/sqrt(N)`; thus

    ||A||_F^2 = |R||C|/N.

A submatrix of a unitary has spectral norm at most one. Therefore every singular value of A is at most one, so

    |R||C|/N = sum(sigma_i^2) <= rank(A).

Scaling U does not change rank. QED. This is a familiar coherence/Frobenius-norm argument, not a new Fourier lower-bound principle.

In particular, for N divisible by 4, every N/2 by N/2 submatrix has rank >=N/4. An arbitrary initial row permutation and an arbitrary final column permutation turn either balanced off-diagonal block into exactly such a submatrix. Thus the product of global scans and diagonals computing a **permuted** Fourier matrix still requires

    b>=N/4, f>=N/4, total scan channels >=N/2.    (Theorem C)

This is an **all-orderings** obstruction for an architecture with no internal permutations. Choosing a single optimal global coordinate layout cannot lead to O(1) scan passes. It remains restricted: the permutations are endpoints only.

**Sharpness:** For N=2m divisible by 4, order both rows and columns with all evens first, odds second. The upper-right balanced block has entries

    omega^(2i(2j+1)) = omega_m^(i(2j+1)),   0<=i,j<m.

Since 2j+1 modulo m traverses exactly m/2 distinct residues, with each repeated twice, this block has rank m/2=N/4 by Vandermonde. The lower-left block has the same rank. Thus the rank N/4 lower bound is tight over all endpoint reorderings.

**Caution:** The proof uses the positive-definite Hermitian/Frobenius norm over **C**. Our exact modular experiments check the ranks for chosen fields and are not a substitute for the all-complex analytic proof. The theorem does not assert a general F_p rank lower bound for every prime without a separate argument.

## 4. Multicut rank potential and the effect of internal permutations

Set

    Phi(A)=sum_{s=1}^{N−1}(u_s(A)+l_s(A)).

By the product rank inequality, `Phi(AB)<=Phi(A)+Phi(B)`. Each single one-direction weighted scan has `Phi<=N−1`; a diagonal factor has zero potential. For naturally ordered even-length Fourier, both cut ranks are `min(s,N−s)`, hence

    Phi(F_N) = 2 sum_s min(s,N−s) = N²/2.

For **any** permutation of Fourier rows and columns, Theorem B applied at every cut yields

    Phi(permuted F_N) >= (2/N)sum_s s(N−s) = (N²−1)/3.

A permutation matrix P with row i selecting column pi(i) satisfies

    Phi(P)=sum_i |pi(i)−i|,

because each element contributes once to every index cut it crosses. Thus for any word of scans, diagonals and **internal permutation matrices**, necessarily

    N²/2 <= (N−1)*(# one-way scan channels) + sum_{internal P} sum_i |pi(i)−i|,

when the output is F_N in natural order. This is a *structural cut-flow budget*, **not** a physical machine-time lower bound: one arbitrarily long-distance permutation may be executed in O(N) indexed memory operations and can have Phi=Theta(N²).

At just the balanced cut, with `c(P)=#{i<N/2: pi(i)>=N/2}`, a scan/permutation word for naturally ordered F_N obeys

    N/2 <= (# backward scan channels) + sum_P c(P),
    N/2 <= (# forward scan channels) + sum_P c(P).

One bit-reversal permutation has c=N/4; so adding **only one** such permutation still needs at least N/4 scan channels in each direction. A half-swap permutation has c=N/2, so this necessary bound becomes vacuous: it does NOT say a half-swap computes a DFT. Several unrestricted permutations similarly defeat this particular invariant.

The possibility of a scalable **interleaved shuffle + genuinely better-than-FFT wide mixing stage** is *not* ruled out here. Classical radix-2 Cooley–Tukey already uses a kind of multilevel shuffle/mixing with O(log N) stages and O(N log N) work. Our task would be to construct and fully count something asymptotically better in a stated model; no such new method is exhibited by this audit.

## 5. Verified finite cases

`wide_scan.py`: all ranks are exact Gaussian elimination modulo p=998244353 (2-power roots supported); 256-point rows/columns are fully generated for cut checks. Tested:

- Natural upper/lower balanced ranks at N=8,16,32,64,128,256: N/2.
- Parity and bit-reversal reordered upper/lower balanced ranks: N/4.
- Gray order still gives N/2, showing that not every shuffle helps.
- At N=8, an **exhaustive** sweep over all choose(8,4)^2=4,900 balanced row/column submatrices gives rank counts: rank2 20, rank3 576, rank4 4304. Minimum exactly N/4.
- Random weighted forward/backward scan matrix products satisfy the one-direction cut-rank budgets.
- The multicut potential identity and permutation-footrule identity hold on test instances, and randomized words with internal shuffles respect the corresponding cut budgets.

`independent_certificate.py` independently implements finite-field rank elimination (without importing the main code), across p=998244353 and p=2013265921, with full 4,900 balanced-submatrix enumeration in each field and larger spot checks.

**Verification is finite, the theorems are all-size arguments.** These are operation/rank counts, not wall-time or optimized FFT-vs-FFT benchmarks. There is no newly faster FFT implementation in this artifact.

## 6. Interpretation for our original project

**Negative:** Wide O(N)-work global prefix scans are insufficient when a computation uses a fixed coordinate layout, even with arbitrary complex weights, multichannel combinations, output diagonal scalings and optimal endpoint permutations. An output format with N scalars and a full-rank map does not by itself forbid an O(N) evaluator; **this particular O(N)-work family** is blocked by stronger off-diagonal rank obligations.

**Positive research clue:** Layout choice changes interaction rank, and internal permutations can change the cut geometry at O(N) *random-access word movements*. Thus a credible different mechanism would jointly optimize **reordering and algebraic mixing**, not rely on a low-width bottleneck, repeated numerical values or merely a dense global scan. But existing Cooley–Tukey and butterfly factorizations already exploit multilevel reordering; a strictly growing savings over those baselines must be explicitly constructed and proved.

**Hard claim boundary:** No O(N) general exact DFT, no improvement over the #130 exact-arithmetic exponent, no integer-multiplication bit result, and no new general linear-circuit lower bound. Rank results are known quasiseparable/coherence arguments applied to the tested primitive.
