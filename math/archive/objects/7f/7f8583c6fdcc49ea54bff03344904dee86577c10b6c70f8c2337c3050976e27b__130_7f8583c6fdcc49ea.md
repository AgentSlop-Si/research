# Joint Galois-orbit stability audit

Reproducible research continuation on **fresh binary inputs, all exact Fourier outputs**, not FFT caching or CrocSwap-style optimization.

## Result

For N=2m power of two, the family of 2^m fresh binary signals x=(u,1-u) shares all even Fourier frequencies. If only r odd frequencies are supplied to an all-output decoder, the decoder's Lipschitz constant on this family is at least

    L >= [2^floor(N/(4r)) - 1]/N.

The proof is in `RESEARCH.md`. This is a **conditioning bound**, **not** a general FFT running-time lower bound. If the decoder also uses the original input or intermediate computations, this bound need not apply. In the one-per-conductor Galois scheme (r=1), instability grows exponentially. Polynomial stability forces Omega(N/log N) odd measurements under this interface.

## Reproduce

```bash
python -m pip install numpy scipy mpmath
python -m unittest discover -s tests -v
python modular_audit.py
python experiment.py
python precision_audit.py
python joint_measurement_audit.py
```

All computation is sequential; no caching between different user signals and no FFT backend in the candidate method. `np.fft.fft` is used **only as an independent full-spectrum numerical reference** for the finite closest-pair experiment.

The theorem is valid in characteristic-zero exact complex Fourier arithmetic. Finite-field checks validate algebraic identities only; floating-point nearest-neighbor searches illustrate rather than prove the all-length conditioning bound. The work here does **not** improve the universal exact-DFT exponent.
