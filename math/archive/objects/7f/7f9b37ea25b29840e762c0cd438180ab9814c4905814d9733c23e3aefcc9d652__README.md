# Exact coefficient and lifting gates

These artifacts are separate from the earlier frozen geometry milestone. No Fourier factorization or faster FFT has been constructed.

## Deliverables

* `N16_CERTIFICATE_SPECIFICATION.md`: The precise restricted384-parameter,24-term seed model;256 global cubic equations; outer128-variable elimination; pivot and endpoint nonzero guards.
* `N16_FIXED_PREFIX_REJECTION.md`: A characteristic-zero rejection of the one fixed prefix with all256 inner coefficients equal to1. All128 outer coefficients remain free; explicit9-by9augmented minors rule them out. The complete384-variable family remains open.
* `N_TO_4N_LIFT_REQUIREMENTS.md`: Exact splice defects and cheap application formulas, weighted/mask descent conditions, full bank-folding identities, and a no-go only for literal unit-scaled coefficient pullback with a proper active bank.
* `HIERARCHICAL_HAMILTONIAN_LIFT.md`: A new quotient-compatible route family retaining the common balanced cut-count guarantee. It starts at N=2^17 and2^18 and is explicitly not supplied by an N16 coefficient seed.

## Reproduction

Run with Python3 from this directory; only the standard library and the included freshly authored checker helpers are used.

    python check_n16_outer_gate.py
    python check_lift_defects.py
    python check_hierarchical_lift.py

The third checker includes actual threshold-base lifts through N=2^20 and takes substantially longer than the first. Results and captured logs have matching names. The checkers execute no uploaded research source and perform no numerical fitting.

The finite-field negative augmented-minor certificates prove characteristic-zero nonvanishing because every denominator and cyclotomic specialization is verified. The positive verifier controls are finite-field controls, not claims of a characteristic-zero Fourier seed. The mathematical specifications describe what an exact positive algebraic certificate would still need.
