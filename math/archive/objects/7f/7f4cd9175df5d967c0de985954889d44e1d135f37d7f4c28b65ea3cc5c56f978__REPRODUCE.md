# Reproducing the independent ramified-family audit

Run only the freshly authored programs in this directory:

```sh
python -u audit_exact.py > EXACT_ARITHMETIC_RUN.log 2>&1
python -u audit_discriminants.py > DISCRIMINANT_RUN.log 2>&1
```

The first uses only Python's standard library. The second requires installed
SymPy (audited here with version 1.14.0). Both perform exact arithmetic.
Run in that order because the second compares its independently computed
fixed-base remainders to the first program's output.

The first program reads only the following predecessor files as JSON data:

- `ramified_chirp_squarefreeness_0341/EXCEPTION_CERTIFICATES.json`
- `diagonal_chirp_classification_0246/MODULAR_CERTIFICATES.json`

It checks only N=25 and N=169; it does not repeat the saved target census.
The two data files must remain accessible at those paths or the path constants
must be changed to copies with verified matching hashes.

No supplied or predecessor program is executed, imported, or compiled.
The exact full-discriminant controls use the reciprocal quadratic-product
identity explained in `INDEPENDENT_AUDIT.md`, cross-checked directly through
degree seven. Local-model controls use rational truncated formal series in
explicit cyclotomic fields and verify all clusters, not numeric root plots.

`SUPPLIED_CLAIM_COMPARISON.json` records a separate data-only comparison between
the fresh symbolic remainder strings and the submitted control-result strings.
`INPUT_SEAL_CHECKS.json` records the input manifest and inherited-hash checks.
`PRESERVATION.json` and the before/after snapshots record unchanged inputs.

`MANIFEST.sha256` seals the final files other than itself. Verify from this
directory with `sha256sum -c MANIFEST.sha256`. A deliberate reproduction can
replace logs or JSON output; verify the seal before reproducing if original
provenance is required.
