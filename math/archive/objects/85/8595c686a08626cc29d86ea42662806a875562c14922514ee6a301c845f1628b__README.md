# Hero #17 — Phase 6: Tensor-Cut Rigidity

This checkpoint contains an exact finite-field research implementation and two complementary verification paths for the full arbitrary-input Fourier tensor. The core result is the four-leg balanced-cut rank profile `(N, min(Q,M), N)` and rigidity of an endpoint-local `N`-nonzero sparse middle: inverse Fourier basis changes are forced, up to permutations and scaling. The result does **not** improve uniform FFT complexity.

## Reproduce

```bash
python -m unittest discover -v
python independent_audit.py
```

### Files

- `RESEARCH.md`: full mathematical statements, proofs, limitations, prior-art boundaries.
- `phase6.py`: four-leg tensor/rank/gauge code, prepared-root cost ledger and fully charged (standard) radix-2 FFT.
- `test_phase6.py`: 14 regression test groups.
- `independent_audit.py`: separately coded exact oracle checks and exhaustive GL(2,F5) support accounting.
- `AUDIT_RESULTS.json`, `TEST_LOG.txt`, `AUDIT_LOG.txt`: verification outputs.
- `CHAIN_CHECKPOINT.md`: exact recovery boundary, negative directions to avoid and next target.
- `SHA256SUMS.txt`: reproducibility integrity hashes, excluding itself.

Python 3.10+ and NumPy are needed for numerical SVD and tensor-leg operations. Exact arithmetic over Fp uses Python integers.
