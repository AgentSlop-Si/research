# Fresh-Input Fourier Reuse: Stage-Template Tabulation and Sampling Audit

**Date:** 2026-10-09  
**Scope:** Full explicit length-`N` output, fresh inputs, one processor, preparation charged.  
**Original target:** Uniform **exact** length-`N` complex DFT in `O(N)` time without uncharged oracle tables.  
**Outcome:** No proof of that target. We proved and implemented two **different, approximate** routes to sub-`N log N` work in precisely weaker computational models, and proved a restriction on the table-based route. These are combinations of established principles, with no originality or priority claim.

## Why this project is not another restart

The checkpoint `FFT_RESEARCH_CANONICAL_CHECKPOINT_2026-10-09.md` had already audited exact collision caching, affine orbits, packed real transforms, split radix, fixed-field Walsh–Hadamard tabulation, binary leaf tables, sparse-delta updates, projected queries, persistent convolution, annihilating filters, dense polynomial bilinear rank, small symbolic circuit searches, and OpenAI/CrocSwap rank/parameter experiments. **We did not rerun those searches as novelty hypotheses.**

The surviving new-to-this-project question is specific: can the **same bounded-precision** small complex DFT table be reused across *different groups of FFT levels*, despite the varying twiddle factors? If yes, does precision/accounting permit a genuine uniform reduction in the number of stages, and can it ever reach `O(N)` with polynomially limited tables?

A second control is **randomized sampling**: if we allow additive error in a normalized transform, compare the table route against an even simpler sampled-input + pruned-FFT algorithm, while explicitly preserving the distinction from exact DFT.

## A. Exact stage-template identity (does not require input collisions)

Let `N=2^L`. Consider `t` consecutive normalized radix-2 decimation-in-time butterfly stages numbered `s+1,...,s+t`. Put `J=2^s`, `K=2^t` and `M=JK`. Within any contiguous length-`M` block with base offset `b`, fix a lower-bit residue `0 <= j < J` and define the strided fiber `a_r = a[b+j+J*r]` for `0 <= r < K`.

Write `rev_t(r)` for the reversal of the `t` binary digits of `r`, and `omega_m=exp(-2*pi*i/m)`.

The t-stage output on the same fiber is exactly

`y[b+j+J*k] = (1/K) sum_{r=0}^{K-1} a_r * omega_M^(j rev_t(r)) * omega_K^(k rev_t(r))`.

Thus **the same normalized length-`K` DFT** applies to the bit-reversed, phase-modulated fiber

`z[rev_t(r)] = a_r * omega_M^(j rev_t(r))`.

Its output is stored at positions `b+j+J*k` for `k=0,...,K-1`. Only the initial phase factors vary with the residue `j`; the **small DFT template does not**. There are `N/K` such fibers per grouped pass.

**Proof sketch:** Follow the standard decimation-in-time Cooley–Tukey factorization for the `t` active high-index bits, holding the lower `s` bits fixed. The factors contributed by the lower bits consolidate into the input diagonal shown above. The remaining butterfly network is exactly the `K`-point DFT on bit-reversed inputs, normalized by `1/K`. It is equivalent to inducting on `t`, starting from the `u +/- omega_{2^(s+1)}^j v` butterfly. This is a classical Fourier identity, not a new circuit.

**Exact checks:** `exact_group_audit.py` uses integer arithmetic in `F_998244353` to compare this grouped map with the original individual stages. The audit covers 119 randomized stage-group configurations and 700 basis-vector configurations, without floating-point equality. `tests/test_tabulation.py` checks the same identity over complex values for a larger range of stage placements. These are finite tests; the general claim rests on Cooley–Tukey algebra.

## B. Complete table for bounded-precision complex values

Restrict the problem **explicitly**:

- fresh `N=2^L` complex input values of magnitude at most one;
- input components have a fixed-point representation fitting in `O(log N)` bits;
- output approximates **the normalized transform `FFT(x)/N`**, not the unnormalized exact DFT;
- output accuracy is worst-case absolute `max_k |y_k - FFT(x)[k]/N| <= epsilon`, with fixed `epsilon > 0`;
- random-access word-RAM with word size `Theta(log N)` bits, constant-time arithmetic/lookup on a constant number of words, and preparation charged;
- root phases can be generated with `O(log N)` bits of guarded fixed-point precision and counted operations.

Quantize each real/imaginary component to the uniform grid `[-1,1]` of mesh `1/R`, clipping to that range. This gives `q=(2R+1)^2` possible complex symbols. An exact complete table for the quantized map on `K` inputs has

`q^K=(2R+1)^(2K)` entries,

and each entry explicitly stores `K` quantized outputs. The table uses `Theta(K q^K)` *machine words*. Preparing its contents with a size-`K` FFT costs `O(K log K q^K)` word operations (or less using shared compilation), counting **all** entries. No table lookup is treated as returning `K` values for free; a query costs `Theta(K)` to pack, read, and output.

A pass through `t=log2 K` consecutive layers:

1. reads each `K`-element fiber;
2. applies its known phase rotations, `O(K)` operations;
3. rounds these values into the fixed alphabet;
4. forms a `K`-symbol lookup key, `O(K)` operations;
5. copies all `K` table outputs.

Thus each grouped pass costs `O(N)` word operations **if the complete table is accessible with constant-time random access**. There are `G=ceil(L/log2 K)` passes. There is one shared `K`-point table for all complete passes; if `L` isn't divisible by `log2 K`, one smaller table handles the remainder.

### Error accounting

Every **exact** intermediate result of these normalized stages has modulus at most `1` if each original input has modulus at most `1`. The normalized `K`-point DFT has induced `l_infinity -> l_infinity` norm at most 1, as does each unit-modulus phase rotation.

Componentwise clipping onto `[-1,1]` is nonexpansive relative to every true component inside that interval. Rounding adds at most `1/(sqrt(2) R)` complex absolute error per round. Each group has two rounds (once after modulation, once after the small DFT), so with exact phases

`max error <= (2G+1)/R`.

With phase approximation at most `1/R` per complex multiplier, allowing for coefficient magnitudes and an extra guard, a coarse conservative estimate of `(4G+1)/R` suffices. Choose

`R=ceil(8(L+1)/epsilon)`,

which ensures the last quantity is smaller than `epsilon` even when `G<=L`. High-precision twiddle generation and its `O(N)` phase table are included in the word-model claim; the floating-point program is *not* a formal fixed-point twiddle implementation.

### Asymptotic table choice and scope

For constant epsilon, `R=Theta(L)`, so `log q=Theta(log L)`. Fix `0<c<1` and choose `K=2^t` as the largest power of two satisfying, conservatively,

`K log2 q + log2 K <= c L`.

Then `K=Theta(L/log L)` (for sufficiently large `L`) and `t=Theta(log L)`. The complete table uses `O(N^c polylog N)` words and preprocessing, hence `o(N)`; the separate root-phase table is `O(N)` words. Online grouped passes cost

`O(N * L/log L) = O(N log N/log log N)` **word operations**.

This is a model-sensitive consequence of standard FFT factorization plus finite-state tabulation, **not** a claim to improve the exact DFT result #130 or integer multiplication. Its mathematical construction is suitable for closer prior-art scrutiny, not an assertion that it is novel. The program implements the algebra and rounding with double precision; it does not realize astronomically large tables or a fixed-point RAM proof implementation.

**WARNING:** At realistic N and useful epsilon, the complete table is impossibly large. At `N=4096`, `epsilon=.05`, the conservative `R` is 2080, already making the *2-point* table contain `4161^4` (>10^14) entries. The actual implementation uses either complete **toy** tables or a **lazy miss-computing emulator**, and explicitly reports misses. Lazy cache misses cost a fresh small DFT; this is not the theoretical complete-table algorithm.

### Why this particular route cannot achieve O(N)

Within the defined **complete-table grouped-stage algorithm family**, if the table is limited to `N^c` words for fixed constant `c`, even the minimal alphabet `q>=2` forces

`K log2 q <= c log2 N`, hence `K=O(log N)` and `t=O(log log N)`.

There are `Omega(log N/log log N)` grouped passes, each visiting and emitting `N` entries. Therefore **this strategy** has an `Omega(N log N/log log N)` online access lower bound. Reaching `O(N)` would require a fundamentally different mechanism, different output/interface assumptions, or much larger (superpolynomial) tables.

This does **not** prove an FFT lower bound outside the specified table family. And in a bit-operation model, an `O(log N)`-bit word operation is not free; even writing the `N` high-precision phase entries consumes `Omega(N log N)` bits with the chosen representation.

## C. Stronger approximate alternative: randomized sampling + input-pruned FFT

There is a simpler alternative once we allow a **randomized additive-error approximation**. It is not a cache and does not require structured inputs.

Fix any complex vector `x` with `|x_j|<=1`. Let `X=FFT(x)/N`. Independently sample `m` indices `J_1,...,J_m` uniformly in `{0,...,N-1}`. Define, for every `k`,

`Y_k = (1/m) sum_{r=1}^m x[J_r] exp(-2*pi*i*k*J_r/N)`.

Then `E[Y_k]=X_k`. For each fixed bin, the real and imaginary parts of a summand belong to `[-1,1]`. Hoeffding plus a union bound over `N` complex bins gives

`Pr[max_k |Y_k-X_k| > epsilon] <= 4N exp(-m epsilon^2/4)`.

So choose

`m=ceil((4/epsilon^2)*ln(4N/eta))`.

For every fixed input `x`, all `N` estimated bins are within absolute epsilon of the normalized DFT with probability at least `1-eta`. This is a **uniform-across-frequency probabilistic guarantee**, not a single random sample set that succeeds for all possible inputs simultaneously. Nor is it an exact DFT guarantee.

Combine repeated samples into at most `m` nonzero coefficients of a length-N sparse vector:

`v[J] = (count(J)/m) * x[J]`.

Then `Y=FFT(v)`, *without* a final division by N. An input-pruned radix-2 FFT with `k<=m` nonzeros visits at most `min(2^d,k)` active subtrees at depth `d`, resulting in

`O(N (1+log(k+1)))`

arithmetic for a **complete N-element output**, including explicit materialization. For fixed epsilon and eta, `m=Theta(log N)`, giving

`O(N log log N)` arithmetic.

This is much closer to O(N) than the complete-table construction in asymptotic arithmetic work, but (a) it is **randomized**, (b) it gives **additive error on the normalized DFT**, (c) finite-precision and random sampling must be charged in a practical implementation, and (d) sampling/pruned Fourier methods have extensive prior art. The guarantee and cost are a combination of elementary known results, not a claim to have invented sparse Fourier algorithms. Advanced sparse Fourier algorithms may offer other approximation guarantees/tradeoffs; the prototype does not prove an optimal approximate-FFT bound.

The `sampled_pruned_fft.py` tests compare its pruned DFT of the sampled sparse vector to a dense NumPy FFT of *that same sparse vector*, separately from comparing its estimator to the original signal's normalized DFT. The union bound is proved analytically; a finite number of tests cannot prove probabilistic failure guarantees. The algorithm's wall-clock performance is not competitive with optimized native FFT software here.

## D. Evidence, negative controls, and falsification

- **Exact modular grouped-stage identity**: 119 random vector configurations, 700 complete basis-vector checks, using a prime field and roots of unity.
- **Numeric grouped-stage identity**: arbitrary complex-valued vectors across sizes and groups, compared to ordinary butterfly stages.
- **Actual full small tables**: `K=2,R=4` (6,561 entries) and `K=4,R=1` (6,561 entries). Every checked lookup matches an independently calculated small DFT at the stated quantization.
- **Useful-precision emulation**: `R=256`, `K=2,4,8`, sizes 256–4096, with lazy dictionary; observed errors below the derived bound. At `N=4096,K=4`, 6,144 requests and **zero cache hits** for a high-entropy input in one run. This is the same core collision limitation under a more complicated representation.
- **Sampling estimator**: correctness of the sparse FFT separately validated; for length 4,096, a pure-tone adversarial input and 40 random sample seeds with epsilon 0.3, zero observed failures and maximal absolute error 0.154. That supports code correctness, not a universal empirical success-rate guarantee.
- **Negative control**: ordinary full FFT in NumPy/SciPy remains much faster than these pure-Python experiments. Never infer a practical speedup from lookup/butterfly counts alone.

### What would falsify each claim?

1. Stage identity: a single modular basis-vector mismatch or failed symbolic proof invalidates all-level table reuse.
2. Table complexity: any hidden `Omega(N log N)` *word* work in twiddle preparation, routing, or random-access table retrieval invalidates the stated bounded-precision claim; a bit-cost reinterpretation changes the theorem.
3. Error: a worst-case bounded input violating the `(4G+1)/R` bound under the exact stated quantizer/phases invalidates its guarantee. Nonrigorous floating approximations alone cannot certify fixed-point phases.
4. Sample estimator: any flaw in independence/boundedness, m formula, or sparse FFT operation accounting invalidates the probabilistic theorem.
5. **Original exact target:** none of the above establishes uniform exact O(N) DFT for arbitrary complex values. No such claim is being made.

## E. Known work and references

- Cooley–Tukey FFT and Good/CRT tensor factorizations are classical. These identities underlie our group-stage derivation.
- Josh Alman (2023), *Faster Walsh-Hadamard Transform and Matrix Multiplication over Finite Fields using Lookup Tables*, https://arxiv.org/abs/2211.04643. It works in a fixed finite-field setting, with different closure and bit-cost assumptions.
- Previous project `fft_lookup_research_note.md`: correctly warned that complex state precision, twiddles, and output encodings must be charged. This project makes the grouped phase template explicit and tests it, **but uses weaker approximate-output assumptions**.
- FFTW, *Pruned FFTs*, https://fftw.org/pruned.html — notes `O(N log k)` arithmetic for `k` nonzero inputs and cautions that native FFT often wins in practice.
- Hassanieh, Indyk, Katabi, Price (2012), *Nearly Optimal Sparse Fourier Transform*, https://arxiv.org/abs/1201.2501 — prior art for randomized sparse-frequency Fourier methods, not the precise estimator here.
- OpenAI exact result #130: https://github.com/openai/math/blob/main/lean/docs/130.md — distinct exact complex arithmetic and all-length model.
- Morgenstern (1973), bounded-coefficient linear computation lower bounds; do not apply them directly to nonlinear random-access lookup or approximation algorithms.

**Overall conclusion:** We have a checked stage grouping, a precise conditional finite-precision lookup construction, a restriction on its ability to reach linear time with polynomial tables, and a stronger approximate sampling alternative. **We still have no new exact O(N) FFT and no new universal integer multiplication bound.**
