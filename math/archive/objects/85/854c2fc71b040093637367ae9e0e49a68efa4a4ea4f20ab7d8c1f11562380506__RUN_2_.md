# Reproduction (standalone)

Requires Python 3.11+, NumPy. Extract the Phase15 ZIP; from its root run:

```bash
python run_all.py
```

To unpack the exact intact Phase14 source from the archive and re-run every inherited test:

```bash
python run_all.py --full-lineage
```

Individual entry points:

```bash
python -m unittest -v test_phase15
python conditioning.py
python slope_tradeoff.py
python field_joint_audit.py
python field_slope_audit.py
```

The finite-field auditors use direct modular arithmetic and only length-K/length-M direct DFTs for the *claimed* joint circuit. The independent N-point reference is used **only for verification**. In the nonstationary auditor, Green impulse-response caching is verifier-only, not a claimed production algorithm.

The checked numeric demo uses NumPy's short FFT backend and floating roots. Theorems are stated for exact arithmetic; this is not an interval-certified or fixed-bit implementation. The `--full-lineage` run unpacks the embedded exact Phase14 ZIP into a temporary directory and runs its archived `run_all.py`, without changing the archival file bytes.

Check source hashes with `sha256sum -c MANIFEST.sha256` (exclude outputs regenerated by `run_all.py`).
