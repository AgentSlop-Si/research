# Exact chirp-convolution reuse audit (2026-10-09)

**Research goal:** Investigate whether a global Fourier transformation can be compressed into an exact linear-time evaluation for arbitrary fresh data, without joining a separate integer-multiplication certificate race.

**Finding:** The DFT equals diagonal scaling, followed by convolution with a fixed quadratic chirp, followed by another diagonal scaling. The chirp kernel obeys a first-order *position-dependent* recurrence, but filtering its convolution with that recurrence still has rank `N-1` and is dense for typical random inputs. A naive moment-propagation scheme needs `N` independent initial moments—exactly another DFT.

**No general FFT speedup or priority claim.** This is an exact negative audit of a concrete candidate, not a universal FFT lower bound.

No dependencies other than Python 3.10+ standard library:

```bash
python -m unittest discover -s tests -v
python run_audit.py
```

Modules:

- `chirp_exact.py`: direct DFT, independently implemented radix-2 NTT, exact chirp convolution, filter operator, modular matrix rank, moment ladder.
- `tests/test_chirp_exact.py`: independent full-output, inverse, rank, moment, and negative-control tests.
- `run_audit.py`: all basis-vector checks and fresh-input controls, creates `audit_results.json`.
- `RESEARCH.md`: full mathematical proofs, limitations, prior-art comparison and next research challenge.
- `PRIOR_WORK_GUARD.md`: what is already done and why this test does not duplicate it.
- `audit_results.json`: observed finite-field certificates and operation-count context.

This work is in `F_998244353`, N even power of two dividing the available roots. Exact identities also work over the complex numbers. Root preparation and memory/addressing must be charged in a real implementation.
