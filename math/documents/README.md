# Authored-document content exports

Each directory is keyed by its source binary hash. DOCX files contribute ordered body, footnote and endnote text; PDF files contribute extracted text; workbook files contribute literal cell/formula records. No formula evaluation, spreadsheet macro, uploaded source program or embedded content was executed.

These text representations support search and historical comparison. They do not certify faithful layout, image content, mathematical-glyph extraction, formatting, charts, comments or cached formula values. The source-binary hashes remain distinct from the hashes of each content export. Original publisher PDFs are excluded. See the binary document coverage manifest for exact per-source status.
